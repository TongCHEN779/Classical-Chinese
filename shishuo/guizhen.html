本门导读

“规箴”是规劝告诫。本门所记，有臣子讽谏君主，有朋友、家人、僚属彼此纠正；进言的方式或旁敲侧击，或借古喻今，或当面直斥，可见当时人敢言、善言的风度。

一｜汉武帝乳母尝于外犯事

汉武帝乳母尝于外犯事，帝欲申宪。乳母求救东方朔，朔曰：“此非唇舌所争，尔必望济者，将去时，但当屡顾帝，慎勿言，此或可万一冀耳。”

  • 汉武帝：刘彻，西汉皇帝，在位五十余年，雄才大略而用法严峻。
  • 申宪：伸张法令，即依法惩办。
  • 东方朔：字曼倩，平原厌次人，武帝近臣，以诙谐善讽著称。
  • 济：成功，得救。
  • 冀：希望。

乳母既至，朔亦侍侧，因谓曰：“汝痴耳！帝岂复忆汝乳哺时恩邪？”帝虽才雄心忍，亦深有情恋，乃凄然愍之，即敕免罪。

  • 心忍：心肠硬，下得了狠手。
  • 愍（mǐn）：怜悯。
  • 敕（chì）：皇帝下诏命令。

二｜京房与汉元帝共论

京房与汉元帝共论，因问帝：“幽、厉之君何以亡？所任何人？”答曰：“其任人不忠。”房曰：“知不忠而任之，何邪？”曰：“亡国之君各贤其臣，岂知不忠而任之？”房稽首曰：“将恐今之视古，亦犹后之视今也。”

  • 京房：西汉易学家，本姓李，字君明，以灾异说政事，因弹劾宦官石显等被外放，后下狱死。
  • 汉元帝：刘奭（shì），宣帝之子，好儒术，宠信宦官石显。
  • 幽、厉：周幽王、周厉王，都是周代著名的昏暴之君。
  • 稽（qǐ）首：叩头至地，最隆重的拜礼。

三｜陈元方遭父丧

陈元方遭父丧，哭泣哀恸，躯体骨立。其母愍之，窃以锦被蒙上。郭林宗吊而见之，谓曰：“卿海内之俊才，四方是则，如何当丧，锦被蒙上？孔子曰：‘衣夫锦也，食夫稻也，于汝安乎？’吾不取也！”奋衣而去。自后宾客绝百所日。

  • 陈元方：陈纪，字元方，陈寔之子，以孝行和德望闻名。
  • 骨立：消瘦到只剩骨头撑着。
  • 郭林宗：郭泰，字林宗，东汉名士，善于品评人物。
  • “衣夫锦也”三句：出自《论语·阳货》，孔子责问宰我不愿守三年之丧的话。
  • 百所日：一百天左右。所，表约数。

四｜孙休好射雉

孙休好射雉，至其时，则晨去夕反。群臣莫不止谏：“此为小物，何足甚耽？”休曰：“虽为小物，耿介过人，朕所以好之。”

  • 孙休：孙权第六子，三国吴景帝，好读书。
  • 雉（zhì）：野鸡。
  • 耽（dān）：沉迷。
  • 耿介：刚直有节操。相传野鸡被捉后宁死不屈，故云。孙休借此搪塞，规谏者的话他并未听进去。

五｜孙皓问丞相陆凯曰

孙皓问丞相陆凯曰：“卿一宗在朝有几人？”陆曰：“二相、五侯、将军十余人。”皓曰：“盛哉！”陆曰：“君贤臣忠，国之盛也；父慈子孝，家之盛也。今政荒民弊，覆亡是惧，臣何敢言盛！”

  • 孙皓：孙权之孙，三国吴末代君主，以残暴著称。
  • 陆凯：字敬风，吴郡吴县人，陆逊族子，官至左丞相，屡次直谏孙皓。
  • 弊：困乏。

六｜何晏、邓飏令管辂作卦

何晏、邓飏令管辂作卦，云：“不知位至三公不？”卦成，辂称引古义，深以戒之。飏曰：“此老生之常谈。”晏曰：“知几其神乎，古人以为难；交疏吐诚，今人以为难。今君一面，尽二难之道，可谓‘明德惟馨’。《诗》不云乎：‘中心藏之，何日忘之！’”

  • 何晏、邓飏（yáng）：曹魏正始年间依附曹爽的名士，后同在高平陵之变中被司马懿所杀。
  • 管辂（lù）：字公明，平原人，三国魏术士，精通《易》与卜筮。
  • 三公：太尉、司徒、司空，朝廷最高官位。
  • 知几其神乎：语出《周易·系辞下》。几，事物细微的苗头。
  • 明德惟馨：语出《尚书》逸篇，见《左传·僖公五年》引。
  • 中心藏之二句：出自《诗经·小雅·隰桑》。

七｜晋武帝既不悟太子之愚

晋武帝既不悟太子之愚，必有传后意，诸名臣亦多献直言。帝尝在陵云台上坐，卫瓘在侧，欲申其怀，因如醉，跪帝前，以手抚床曰：“此坐可惜！”帝虽悟，因笑曰：“公醉邪？”

  • 晋武帝：司马炎，西晋开国皇帝。
  • 太子：司马衷，即后来的晋惠帝，素称痴愚。
  • 陵云台：洛阳宫中的高台。
  • 卫瓘（guàn）：字伯玉，西晋重臣，官至太保。
  • 床：坐榻，这里指御座。

八｜王夷甫妇，郭泰宁女

王夷甫妇，郭泰宁女，才拙而性刚，聚敛无厌，干豫人事。夷甫患之而不能禁。时其乡人幽州刺史李阳，京都大侠，犹汉之楼护，郭氏惮之。夷甫骤谏之，乃曰：“非但我言卿不可，李阳亦谓卿不可。”郭氏小为之损。

  • 王夷甫：王衍，字夷甫，西晋清谈领袖，官至太尉。其妻郭氏是贾后的亲戚。
  • 郭泰宁：郭豫，字泰宁，太原人，西晋官员，早逝。
  • 干豫：干预。
  • 楼护：西汉游侠，字君卿，以结交豪杰、重名节著称。
  • 骤：屡次。
  • 损：减少，收敛。

九｜王夷甫雅尚玄远

王夷甫雅尚玄远，常嫉其妇贪浊，口未尝言“钱”字。妇欲试之，令婢以钱绕床，不得行。夷甫晨起，见钱阂行，呼婢曰：“举却阿堵物！”

  • 雅：素来。
  • 玄远：深奥玄妙的道理，指老庄玄学。
  • 阂（hé）：阻隔，妨碍。
  • 阿堵：六朝口语，犹言“这个”。后世遂以“阿堵物”代称钱。

十｜王平子年十四五

王平子年十四五，见王夷甫妻郭氏贪，欲令婢路上儋粪。平子谏之，并言不可。郭大怒，谓平子曰：“昔夫人临终，以小郎嘱新妇，不以新妇嘱小郎。”急捉衣裾，将与杖。平子饶力，争得脱，逾窗而走。

  • 王平子：王澄，字平子，王衍之弟。
  • 儋（dān）：同“担”，挑。挑粪大概是要积肥卖钱，可见其贪。
  • 夫人：指王衍、王澄的母亲。
  • 小郎：嫂子对丈夫弟弟的称呼。
  • 新妇：已婚妇女的自称。
  • 裾（jū）：衣襟。
  • 饶力：力气大。

十一｜元帝过江犹好酒

元帝过江犹好酒，王茂弘与帝有旧，常流涕谏。帝许之，命酌酒一酣，从是遂断。

  • 元帝：司马睿，东晋开国皇帝。
  • 过江：指西晋末渡江南下，在建康立国。
  • 王茂弘：王导，字茂弘，东晋开国元勋。
  • 酣：畅饮尽兴。

十二｜谢鲲为豫章太守

谢鲲为豫章太守，从大将军下至石头。敦谓鲲曰：“余不得复为盛德之事矣！”鲲曰：“何为其然？但使自今已后，日亡日去耳。”

  • 谢鲲：字幼舆，陈郡阳夏人，名士，曾为王敦长史。
  • 大将军：王敦，王导从兄，东晋初起兵攻入建康。
  • 石头：石头城，在今南京西。
  • 盛德之事：有德者所做的事，指忠臣辅国。王敦此语自知已背负犯上之名。
  • 日亡日去：一天天消失、离去，指嫌隙随时间淡化。

敦又称疾不朝，鲲谕敦曰：“近者明公之举，虽欲大存社稷，然四海之内，实怀未达。若能朝天子，使群臣释然，万物之心，于是乃服。仗民望以从众怀，尽冲退以奉主上，如斯则勋侔一匡，名垂千载。”时人以为名言。

  • 谕：开导，劝告。
  • 实怀未达：真实的心意没有被人理解。
  • 冲退：谦和退让。
  • 侔（móu）：相等。
  • 一匡：指管仲辅佐齐桓公“一匡天下”的功业，语出《论语·宪问》。

十三｜元皇帝时，廷尉张闿

元皇帝时，廷尉张闿在小市居，私作都门，早闭晚开，群小患之，诣州府诉，不得理；遂至挝登闻鼓，犹不被判。

  • 元皇帝：晋元帝司马睿。
  • 廷尉：掌管刑狱的长官。
  • 张闿（kǎi）：字敬绪，丹阳人，东晋大臣。
  • 都门：里巷的总门。
  • 群小：普通百姓。
  • 挝（zhuā）：敲击。
  • 登闻鼓：悬于朝堂外，供百姓击鼓申冤的鼓。

闻贺司空出，至破冈，连名诣贺诉。贺曰：“身被征作礼官，不关此事。”群小叩头曰：“若府君复不见治，便无所诉。”贺未语，令且去，见张廷尉当为及之。

  • 贺司空：贺循，字彦先，会稽山阴人，江南名士，死后追赠司空。
  • 破冈：破冈渎，三国吴开凿的运河，连通秦淮河与太湖水系。
  • 被征作礼官：贺循当时被朝廷征为太常，掌礼仪。
  • 府君：对官长的尊称。
  • 见治：受到处理。

张闻，即毁门，自至方山迎贺。贺出见，辞之曰：“此不必见关，但与君门情，相为惜之。”张愧谢曰：“小人有如此，始不即知，早已毁坏。”

  • 方山：山名，在今南京江宁东南。
  • 见关：与我相关，由我过问。
  • 门情：两家世代的交情。
  • 小人：指百姓。

十四｜郗太尉晚节好谈

郗太尉晚节好谈，既雅非所经，而甚矜之。后朝觐，以王丞相末年多可恨，每见必欲苦相规诫。王公知其意，每引作他言。

  • 郗太尉：郗鉴，字道徽，东晋重臣，死后赠太尉。
  • 晚节：晚年。
  • 雅：素来。
  • 经：擅长，熟习。
  • 矜（jīn）：自夸。
  • 朝觐（jìn）：入朝拜见君主。
  • 王丞相：王导。
  • 末年多可恨：指王导晚年为政宽纵，郗鉴不以为然。

临还镇，故命驾诣丞相，翘须厉色，上坐便言：“方当乖别，必欲言其所见。”意满口重，辞殊不流。王公摄其次曰：“后面未期。亦欲尽所怀，愿公勿复谈。”郗遂大瞋，冰衿而出，不得一言。

  • 还镇：回到镇守之地。郗鉴当时镇京口。
  • 乖别：离别。
  • 摄：接续，紧跟着。
  • 冰衿（jīn）：神色冷峻。王导反过来以“勿复谈”规劝郗鉴，以机锋堵住了对方的规劝。

十五｜王丞相为扬州

王丞相为扬州，遣八部从事之职。顾和时为下传还，同时俱见。诸从事各奏二千石官长得失，至和独无言。王问顾曰：“卿何所闻？”答曰：“明公作辅，宁使网漏吞舟，何缘采听风闻，以为察察之政？”丞相咨嗟称佳，诸从事自视缺然也。

  • 王丞相：王导，时兼领扬州刺史。
  • 八部从事：州刺史派往所辖各郡巡察的属官，扬州辖八郡，故称。
  • 顾和：字君孝，吴郡人，后官至尚书令。
  • 下传（zhuàn）：乘驿车下去巡视。
  • 二千石：郡守的代称。
  • 网漏吞舟：法网宽疏到能漏掉吞船的大鱼，比喻为政宽大。
  • 察察：苛细严察。

十六｜苏峻东征沈充

苏峻东征沈充，请吏部郎陆迈与俱。将至吴，密敕左右，令入阊门放火以示威。陆知其意，谓峻曰：“吴治平未久，必将有乱。若为乱阶，请从我家始。”峻遂止。

  • 苏峻：东晋将领，此时奉命讨伐王敦余党，后来自己也起兵作乱。
  • 沈充：吴兴人，王敦部将。
  • 陆迈：吴郡人，时任吏部郎。
  • 敕：吩咐，命令。
  • 阊门：苏州城西门。
  • 乱阶：祸乱的起因。陆迈是吴郡人，以自家相抵，话说得极重。

十七｜陆玩拜司空

陆玩拜司空，有人诣之索美酒，得，便自起泻著梁柱间地，祝曰：“当今乏才，以尔为柱石之用，莫倾人栋梁。”玩笑曰：“戢卿良箴。”

  • 陆玩：字士瑶，吴郡人，东晋大臣，官至司空。
  • 泻：倾倒。
  • 柱石：支撑房屋的柱子与基石，比喻国家重臣。
  • 戢（jí）：收藏，引申为铭记。
  • 箴（zhēn）：规劝的话。

十八｜小庾在荆州

小庾在荆州，公朝大会，问诸僚佐曰：“我欲为汉高、魏武，何如？”一坐莫答，长史江彪曰：“愿明公为桓、文之事，不愿作汉高、魏武也。”

  • 小庾：庾翼，字稚恭，庾亮之弟，时任荆州刺史，故称“小庾”。
  • 公朝：属官朝见长官。
  • 汉高、魏武：刘邦、曹操，都是取代旧朝自立的人物。
  • 桓、文：齐桓公、晋文公，春秋霸主，尊王攘夷而不篡位。
  • 江彪：生平存疑，书作“江彪”，一说当作“江虨”。

十九｜罗君章为桓宣武从事

罗君章为桓宣武从事，谢镇西作江夏，往检校之。罗既至，初不问郡事，径就谢数日饮酒而还。桓公问：“有何事？”君章云：“不审公谓谢尚何似人？”桓公曰：“仁祖是胜我许人。”君章云：“岂有胜公人而行非者？故一无所问。”桓公奇其意而不责也。

  • 罗君章：罗含，字君章，桂阳人，以文章著称。
  • 桓宣武：桓温，谥宣武。
  • 从事：刺史属官。
  • 谢镇西：谢尚，字仁祖，曾任镇西将军。
  • 作江夏：任江夏相。
  • 检校：查核。
  • 初：全然，一点也（用于否定）。
  • 审：知道。
  • 许：这样，如此。

二十｜王右军与王敬仁、许玄度并善

王右军与王敬仁、许玄度并善，二人亡后，右军为论议更克。孔岩诫之曰：“明府昔与王、许周旋有情，及逝没之后，无慎终之好，民所不取。”右军甚愧。

  • 王右军：王羲之，曾任右军将军。
  • 王敬仁：王修，字敬仁。
  • 许玄度：许询，字玄度，名士。
  • 克：苛刻。
  • 明府：对郡守的敬称，王羲之时任会稽内史。孔岩是会稽人，故自称“民”。
  • 慎终：语出《论语·学而》“慎终追远”，此指对亡友始终如一。

二十一｜谢中郎在寿春败

谢中郎在寿春败，临奔走，犹求玉帖镫。太傅在军，前后初无损益之言，尔日犹云：“当今岂须烦此？”

  • 谢中郎：谢万，谢安之弟，曾任西中郎将，北伐时兵溃。
  • 玉帖镫（dèng）：用玉装饰的马镫。
  • 太傅：谢安，死后赠太傅。
  • 初无：从来没有。
  • 损益之言：指出得失、加以规正的话。
  • 尔日：那天。

二十二｜王大语东亭

王大语东亭：“卿乃复论成不恶，那得与僧弥戏？”

  • 王大：王忱，小字佛大，故称。
  • 东亭：王珣，封东亭侯。
  • 论成：舆论评价已经形成。
  • 不恶：不坏。
  • 僧弥：王珉的小字，王珣之弟。此则文意简省，具体所指存疑。

二十三｜殷觊病困

殷觊病困，看人政见半面。殷荆州兴晋阳之甲，往与觊别，涕零，属以消息所患。觊答曰：“我病自当差，正忧汝患耳！”

  • 殷觊（jì）：殷仲堪的堂兄，时任南蛮校尉，不赞成起兵。
  • 政：通“正”，只。
  • 殷荆州：殷仲堪，时任荆州刺史。
  • 兴晋阳之甲：春秋时晋国赵鞅以晋阳之兵驱逐君侧之臣，后用来指以“清君侧”为名起兵。
  • 属：通“嘱”。
  • 消息：休养，调养。
  • 差（chài）：病愈。

二十四｜远公在庐山中

远公在庐山中，虽老，讲论不辍。弟子中或有堕者，远公曰：“桑榆之光，理无远照，但愿朝阳之晖，与时并明耳。”执经登坐，讽诵朗畅，词色甚苦。高足之徒，皆肃然增敬。

  • 远公：慧远，东晋高僧，居庐山东林寺，净土宗初祖。
  • 辍（chuò）：停止。
  • 堕：通“惰”。
  • 桑榆之光：夕阳照在桑树榆树梢头的余光，比喻晚年。
  • 高足：优秀的弟子。

二十五｜桓南郡好猎

桓南郡好猎，每田狩，车骑甚盛，五六十里中，旌旗蔽隰，骋良马，驰击若飞，双甄所指，不避陵壑。或行陈不整，麏兔腾逸，参佐无不被系束。

  • 桓南郡：桓玄，桓温之子，袭爵南郡公。
  • 田狩：打猎。
  • 隰（xí）：低湿之地，泛指原野。
  • 双甄（zhēn）：围猎时的左右两翼。
  • 陈：同“阵”。
  • 麏（jūn）：同“麇”，獐子。
  • 系束：捆绑。

桓道恭，玄之族也，时为贼曹参军，颇敢直言。常自带绛绵绳著腰中，玄问：“此何为？”答曰：“公猎，好缚人士，会当被缚，手不能堪芒也。”玄自此小差。

  • 桓道恭：字祖猷，桓玄族叔，后随桓玄败亡。
  • 贼曹参军：军府中掌管捕盗事务的属官。
  • 绛（jiàng）：深红色。
  • 芒：粗麻绳上的毛刺。
  • 小差（chài）：稍有好转，指脾气略改。

二十六｜王绪、王国宝相为唇齿

王绪、王国宝相为唇齿，并上下权要。王大不平其如此，乃谓绪曰：“汝为此欻欻，曾不虑狱吏之为贵乎？”

  • 王绪、王国宝：二人是堂兄弟，依附会稽王司马道子专权，后被王恭起兵所逼，皆被杀。
  • 上下：任意摆布。
  • 王大：王忱，王国宝之弟。
  • 欻欻（xū）：忽忽然，形容行事轻率急躁。
  • 狱吏之为贵：西汉周勃被诬下狱，受狱吏欺辱，出狱后叹“吾今日乃知狱吏之贵”，见《史记·绛侯周勃世家》。

二十七｜桓玄欲以谢太傅宅为营

桓玄欲以谢太傅宅为营，谢混曰：“召伯之仁，犹惠及甘棠；文靖之德，更不保五亩之宅？”玄惭而止。

  • 谢太傅：谢安。
  • 谢混：谢安之孙，字叔源，东晋名士。
  • 召（shào）伯：周初召公奭，曾在甘棠树下理政，后人怀念他，不忍砍伐此树，事见《诗经·召南·甘棠》。
  • 文靖：谢安的谥号。
  • 五亩之宅：语本《孟子》，泛指一家的住宅。
