# 《十六国春秋》注译补充要求

《十六国春秋》：旧题北魏崔鸿撰，记十六国（前赵、后赵、前燕、前秦、后秦、蜀、前凉、西凉、北凉、后凉、后燕、南凉、南燕、西秦、北燕、夏）史事。原书已佚，维基文库所存为明人（屠介孙、项琳等）据《晋书》载记等编成的十六卷“别本”，各国一录，每录分列各主传记；全站只此一本，所以内容与《晋书》载记多有重合，照录不删。BOOK = shiliuguochunqiu。载记涉及五胡十六国的人名、地名、官制，不确定写“待考”。

- 先读 `tools/annotation_guide.md`，格式与硬性规则以它为准。
- 作业批次：`sources/shiliuguochunqiu/job_batches.json` 里第 K 项（从 0 数起），每项形如 `[页slug, 起始节, 结束节, 字数]`，结束节不含。
  每个作业：`python3 tools/show_texts.py shiliuguochunqiu 页slug 起始节 结束节` 看原文与切句；
  用 Write 直接写 `sources/shiliuguochunqiu/annotations/<页slug>__<起始节>.json`；再 `python3 tools/check_job.py shiliuguochunqiu 页slug 起始节 结束节` 须输出 OK。
- 题解：点明本篇（传主/合传诸人）讲什么、在全书中的位置（魏书/蜀书/吴书）；合传点明各传主。
- 白话：准确、通顺、现代汉语；人名、官职、地名、年号、郡国首次出现时在白话里点明（如“司空曹操”“荆州刺史刘表”），年号可括注公元年；不加评论；引经文照意译出。
- 注释：每约 150 字原文至少一条，宁多勿少；重点注官制（三公、尚书、侍中、郡守、中郎将、校尉、都督等）、地名（今地有把握才写）、制度（九品中正、屯田、置郡县等）、典章与典故、人物生平与字号、引书出处。同一条目在同一作业内首次出现注一次。
- 底本说明：维基文库《十六国春秋》；底本偶有疑误字、异体字，照录，在注里写“疑当作……”，确实难辨写“字不清”，不要硬编；不确定的人名地名写“待考”。
- 不改原文；只创建你自己的 annotations 文件，不动其他文件。完成后回复一行：已完成的文件名与 OK。
