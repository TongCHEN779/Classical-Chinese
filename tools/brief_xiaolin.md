# 《笑林广记》《云林遗事》注译补充要求

BOOK 为 xiaolinguangji（《笑林广记》，清代笑话集，署游戏主人，十二部，每页一部，页内每则笑话为一节，节名即笑话标题）或 yunlinyishi（《云林遗事》，明顾元庆辑录元末画家倪瓒轶事，一页五节：高逸、诗画、洁癖、游寓、饮食）。作业批次见 `sources/BOOK/job_batches.json` 的第 K 项（从 0 数起），每项是若干作业 `[页slug, 起始节, 结束节, 字数]`（结束节不含）。

- 先读 `tools/annotation_guide.md`，格式与硬性规则以它为准。每个作业：
  `python3 tools/show_texts.py BOOK 页slug 起始节 结束节` 看各段切句；
  Write 写 `sources/BOOK/annotations/<页slug>__<起始节>.json`；再 `python3 tools/check_job.py BOOK 页slug 起始节 结束节` 须输出 OK。
- 题解：一句话点明笑点（谁、做了什么荒唐事、可笑在哪），不照抄原文；《云林遗事》每节一两句概括该篇写倪瓒哪方面。
- 白话：准确、通顺、带点诙谐的现代汉语，保留笑话叙事和对话口吻，把包袱译出来；谐音、双关、歇后语、俗语、方言词（如“恁般”“则个”“兀的”）要译成现代说法，双关处在注里说明；人名官职保留；句数与原文切句一一对应，不省略、不加评论。
- 注释：每约 100 字原文至少一条（笑话很短，也至少写一条点明谐音、双关或典故），宁多勿少。重点注：谐音与双关的本义、明清官制科举与学官（教官、广文、祭丁）、民俗行业与行话、俗语方言、典故与诗文出处、器物名称；《云林遗事》注倪瓒生平交游（张伯雨、张士诚兄弟、柯九思、徐达左等）、书画与茶、饮食方中的食材与做法。不确定的写“待考”，不要编造。
- 笑话里的粗俗、荤段子照常准确译注，但表述克制、点到为止。
- 底本疑误字、异体字照录，必要时在注里写“疑当作……”；不改原文；只创建你自己的 annotations 文件，临时脚本放在你自己新建的 scratchpad 子目录。完成后只回复一行：已完成的文件名与 OK。
