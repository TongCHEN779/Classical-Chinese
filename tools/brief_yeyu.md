# 《夜雨秋灯录》注译补充要求

BOOK = yeyuqiudenglu。清末宣鼎（1832—1880，字瘦梅，号邋遢书生，安徽天长人，游幕多年，擅画）所撰文言笔记小说集，八卷，每卷十余篇，仿《聊斋志异》而多记晚清（道光、咸丰、同治间）仙佛、鬼狐、侠女、孝烈与官场世情。页 x1 蔡尔康序，x2 作者自序，j01–j08 为卷一至卷八；每页一卷，页内每篇故事为一节（节名即篇名）。故事常带太平天国战乱背景（“红巾”“发逆”指太平军，译作“太平军”或“起事者”并在注里说明）。作业批次见 `sources/yeyuqiudenglu/job_batches.json` 的第 K 项（从 0 数起），每项是若干作业 `[页slug, 起始节, 结束节, 字数]`（结束节不含）。

- 先读 `tools/annotation_guide.md`，格式与硬性规则以它为准。每个作业：
  `python3 tools/show_texts.py yeyuqiudenglu 页slug 起始节 结束节` 看各段切句；
  Write 写 `sources/yeyuqiudenglu/annotations/<页slug>__<起始节>.json`；再 `python3 tools/check_job.py yeyuqiudenglu 页slug 起始节 结束节` 须输出 OK。
- 题解：每篇一两句话，点明故事讲什么（谁遇到什么异事、侠义、冤情或报应，结局如何）及可见的寓意，不照抄原文。
- 白话：准确、通顺的现代汉语，保留小说叙事的曲折与对话口吻；人名、官职、地名保留，必要时顺带点明；文中的诗词、联语、题词、书信译出大意；对话里的方言口语译成现代说法；句数与原文切句一一对应，不省略情节。
- 注释：每约 120 字原文至少一条，宁多勿少。重点注：清代官制科举（廪生、庠生、茂才、孝廉、明经、县令、道台、幕客、师爷、臬署、藩司等）与晚清史事（太平军、捻军、湘淮军、上海开埠等，有把握才写）、地名（今地有把握才写）、民俗宗教与志怪名物（符箓、道士法术、城隍、五通神、因果报应、轮回、阴司官制）、典故与诗文出处（《聊斋志异》《左传》《史记》《西厢记》《红楼梦》及唐宋诗词，有把握才写出处）、器物饮食与方言俗语。不确定的写“待考”，不要编造。
- 底本偶有异体字、疑误字，照录，必要时在注里写“疑当作……”；不改原文；只创建你自己的 annotations 文件，临时脚本放在你自己新建的 scratchpad 子目录。完成后只回复一行：已完成的文件名与 OK。
