# 《长物志》加标点

《长物志》底本（四库本）原无标点，已转成简体存在 `sources/changwuzhi/chapters.json`。你的任务：给指定页的每一段加标点，不改一个字。

- 页 slug 由任务给出。读 `sources/changwuzhi/chapters.json` 中该页（用 python 读，按 sections[i].paragraphs[j] 取段）。
- 只能**插入**这些标点：。，、；：？！“”‘’《》。不得增删改任何汉字（俗字如“湏”“扵”“聮”“牕”照录）。
- **名称行**（单独成段的短行，如“门”“阶”“牡丹芍药”）是条目名，**不加任何标点**，原样保留。
- 其余段落按文意断句：句内用，、；：，句末用。？！；书名加《》，引语加“”。每段必须以句末标点结尾（。？！”）。
- 输出：`sources/changwuzhi/punct/<页slug>.json`，内容为二维数组：外层按节，内层按该节的段，每项是加好标点的段落字符串，与原文节数、段数完全一致。
- 写完运行 `python3 tools/check_punct.py <页slug>`，须输出 OK（它核验“去掉标点后与原文逐字相同”与节段数）。
- 一次可做多个页；只创建你自己的 punct 文件，不动其他文件。完成后回复一行：页slug 与 OK。
