# 《饮水词》注释补充要求（只写题解与注释，不写白话）

《饮水词》：清代纳兰性德（原名成德，字容若，1655—1685，满洲正黄旗，大学士明珠之子，康熙十五年进士，授三等侍卫，随扈出塞）的词集，本站所据为维基文库《饮水词》，一页 p01，每首词为一节（节名“词牌（首句前几字）”）。词中涉及悼亡（原配卢氏，康熙十六年（1677）五月病逝）、塞外扈从、友朋（顾贞观〔梁汾〕、姜宸英〔西溟〕、严绳孙〔荪友〕等）、咏物与咏史。BOOK = yinshuici。

- 先读 `tools/annotation_guide.md`，格式与硬性规则以它为准；**本书不写白话**：每段 `"译"` 一律是 `[]`，只写 `"题解"` 与 `"注"`。
- 批次：`sources/yinshuici/job_batches.json` 的第 K 项（从 0 数起），每项是若干作业 `[页slug, 起始节, 结束节, 字数]`（结束节不含）。每个作业：
  `python3 tools/show_texts.py yinshuici 页slug 起始节 结束节` 看各段原文；
  Write 写 `sources/yinshuici/annotations/<页slug>__<起始节>.json`；再 `python3 tools/check_job.py yinshuici 页slug 起始节 结束节` 须输出 OK。
- 每节是一首词：段落依次为“小序/题（若有）”和词的各阕（上阕、下阕…）。`段落` 条数与节内段数一致；没有注的段 `"注": []`，`"译"` 都是 `[]`（一个空数组，包括小序段）。
- 题解：每首一两句话，点明这首词写什么（悼亡、边塞、怀友、咏物、闺情、咏史等）、情绪与特点；词牌的来历、体式（令/慢、字数）可简述；有系年、本事可考的写出（如与卢氏、顾贞观、姜宸英有关的），把握不足就泛写，不要编造本事。
- 注释：每首至少 3 条，每约 30 字至少一条，宁多勿少。重点注：典故与出处（《诗经》《楚辞》《世说新语》、唐宋诗词、历史人物如荀粲、王昭君、韩凭等）、前人诗句的化用（有把握才写出作者与篇名）、生僻字与异体字的读音释义、地名与塞外风物（今地有把握才写）、器物与意象（如胆瓶、心字香、屧粉、鸳瓦、玉钩斜）、词的一般语词与字面义。词语须是该段原文里连续出现的字串。
- 底本字形、俗体、疑误字照录，必要时在注里写“疑当作……”；校异夹注已从原文移出，不用管。不确定的写“待考”，不要编造。
- 不改原文；只创建你自己的 annotations 文件，临时脚本放在你自己新建的 scratchpad 子目录。完成后只回复一行：已完成的文件名与 OK。
