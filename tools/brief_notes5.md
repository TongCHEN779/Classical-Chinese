# 六十种曲、剪灯新话、剪灯余话、花月痕、醒世姻缘传、姑妄言：只写注释（不写白话）

BOOK 为 liushizhongqu、jiandengxinhua、jiandengyuhua、huayuehen、xingshiyinyuan、guwangyan 之一。批次见 `sources/BOOK/job_batches.json` 第 K 项（从 0 数起），每项是若干作业 `[页slug, 起始节, 结束节, 字数]`（结束节不含）。

- 先读 `tools/annotation_guide.md`，但**不写白话**：每个段落只写 `"注"`，`"译"` 一律给 `[]`；每节必写 `"题解"`。
- 每个作业：`python3 tools/show_texts.py BOOK 页slug 起始节 结束节` 看原文与分段；用 Write 写 `sources/BOOK/annotations/<页slug>__<起始节>.json`，再 `python3 tools/check_job.py BOOK 页slug 起始节 结束节` 须输出 OK。
- 作业较大时，用你**自己专属的临时目录**（scratchpad 下新建以批次命名的子目录，脚本文件名带上 BOOK 和 K）分段生成，再合并成最终 JSON；**不要使用共享的 gen.py 等通用文件名**，避免与并行任务互相覆盖。
- 注的“词语”必须是本段原文里的连续字串（原文有〈〉、“？”等符号时，词语不要含这些符号）；同一段内词语不重复。
- 题解：一两句话，概括本节（本出、本回、本篇）情节、人物与在全书中的位置，不抄原文；六十种曲每出点明唱主角、场景和情节作用。
- 不确定的写“待考”，不要编造；底本疑误字照录，在注里写“疑当作……”；不改原文。完成后只回复一行：已完成的文件名与 OK。

## 各书特点与注释密度

- **六十种曲**（传奇剧本，一页一剧、一节一出）：每约 100–150 字至少一条。重点注：曲牌名（首次出现点明所属宫调与体式）、脚色（生旦净末丑外贴等，首次出现点明）、科白提示、典故与用事、诗词与骈句出处、人名地名官制、俗语方言、剧中虚构与史实出入。曲词多化用诗文，要点明所本。原文 〔…〕 为科介，【…】 为曲牌。
- **剪灯新话、剪灯余话**（文言传奇）：每约 120 字至少一条。重点注典故、诗词曲出处、人名地名官制、元末明初史实、佛道与民间信仰；其中诗词多，须点明所用典故与韵事。
- **花月痕**（清代狭邪小说，骈散夹杂，诗词极多）：每约 150 字至少一条。重点注诗词典故、骈文用事、人物原型、官制与风俗、方言行话；诗词注明用典。
- **醒世姻缘传**（明末清初山东方言世情小说）：每约 200 字至少一条。重点注山东方言词与俗语、歇后语、官制科举、风俗礼仪、佛道与因果说法、地名。
- **姑妄言**（清代世情小说，每回后有评语）：每约 200 字至少一条。重点注方言俗语、典故、官制风俗、评语中的用典；涉及性描写之处只释词语、典故与行话，不渲染、不引申。
