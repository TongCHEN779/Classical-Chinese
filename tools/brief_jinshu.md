# 《晋书》注译补充要求

《晋书》：唐房玄龄等奉敕撰，纪传体断代史，记西晋、东晋及十六国：帝纪十卷、志二十卷（天文、地理、律历、礼、乐、职官、舆服、食货、刑法、五行等典章）、列传七十卷、载记三十卷（十六国政权）。BOOK = jinshu。志页标题以“志第…”开头，术语多，注释要给足；载记涉及五胡十六国人名地名，不确定写“待考”。

- 先读 `tools/annotation_guide.md`，格式与硬性规则以它为准。
- 作业批次：`sources/jinshu/job_batches.json` 里第 K 项（从 0 数起），每项形如 `[页slug, 起始节, 结束节, 字数]`，结束节不含。
  每个作业：`python3 tools/show_texts.py jinshu 页slug 起始节 结束节` 看原文与切句；
  用 Write 直接写 `sources/jinshu/annotations/<页slug>__<起始节>.json`；再 `python3 tools/check_job.py jinshu 页slug 起始节 结束节` 须输出 OK。
- 题解：点明本篇（传主/合传诸人）讲什么、在全书中的位置（魏书/蜀书/吴书）；合传点明各传主。
- 白话：准确、通顺、现代汉语；人名、官职、地名、年号、郡国首次出现时在白话里点明（如“司空曹操”“荆州刺史刘表”），年号可括注公元年；不加评论；引经文照意译出。
- 注释：每约 150 字原文至少一条，宁多勿少；重点注官制（三公、尚书、侍中、郡守、中郎将、校尉、都督等）、地名（今地有把握才写）、制度（九品中正、屯田、置郡县等）、典章与典故、人物生平与字号、引书出处。同一条目在同一作业内首次出现注一次。
- 底本说明：维基文库《晋书》；底本偶有疑误字、异体字，照录，在注里写“疑当作……”，确实难辨写“字不清”，不要硬编；不确定的人名地名写“待考”。
- 不改原文；只创建你自己的 annotations 文件，不动其他文件。完成后回复一行：已完成的文件名与 OK。
