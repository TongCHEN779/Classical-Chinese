# 《搜神记》注译补充要求

《搜神记》：东晋干宝撰的志怪小说集，原三十卷，今本二十卷（明胡震亨编刻《秘册汇函》本，系后人辑录）。内容大致：卷一至三神仙方士及其法术，卷四至五灵异感应，卷六至十妖祥梦卜，卷十一历史人物传说，卷十二至十四怪物异闻，卷十五至十六鬼魂复生，卷十七至十九精怪作祟，卷二十因果报应。BOOK = soushenji。每条故事无标题，一条通常是一段；节按字数合并，节名取首段开头。

- 先读 `tools/annotation_guide.md`，格式与硬性规则以它为准。
- 作业批次：`sources/soushenji/job_batches.json` 里第 K 项（从 0 数起），每项是若干作业，每个作业形如 `[页slug, 起始节, 结束节, 字数]`，结束节不含。
  每个作业：`python3 tools/show_texts.py soushenji 页slug 起始节 结束节` 看原文与切句；
  用 Write 直接写 `sources/soushenji/annotations/<页slug>__<起始节>.json`；再 `python3 tools/check_job.py soushenji 页slug 起始节 结束节` 须输出 OK。
- 题解：一两句话点明本节所收各则故事讲什么（如某位方士的神术、某桩灵异或报应），不照抄原文；节内故事较多时概括其类别与主线。
- 白话：准确、通顺、现代汉语，保留志怪故事的叙事口吻；人名、官职、地名、朝代、年号保留，必要时顺带点明；预言、谶语、歌谣译出大意；句数与原文切句一一对应，不省略情节。
- 注释：每约 120 字原文至少一条，宁多勿少；重点注神仙方术与志怪名物（符咒、丹药、灵物、精怪名）、人物生平（有史可考者点明朝代与出处）、官制、地名（今地有把握才写）、风俗礼制、占卜谶纬、典故及与《史记》《汉书》《后汉书》《列仙传》等书的互见（有把握才写）。
- 底本说明：维基文库《搜神记》（秘册汇函本）；底本偶有异体字或疑误字，照录，在注里写“疑当作……”，确实难辨写“字不清”，不要硬编；不确定的内容写“待考”，不要编造。
- 不改原文；只创建你自己的 annotations 文件，不动其他文件。完成后回复一行：已完成的文件名与 OK。
