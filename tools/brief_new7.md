# 七部书的注译补充要求

适用：性命圭旨(xingmingguizhi)、沧浪诗话(canglangshihua)、白雨斋词话(baiyuzhaicihua)、齐民要术(qiminyaoshu)、武林旧事(wulinjiushi)、文史通义(wenshitongyi)、困学纪闻(kunxuejiwen)。

- 先读 `tools/annotation_guide.md`，格式与硬性规则以它为准。
- 任务给出 BOOK（上面的拼音 slug）和批次号 K。你的作业批次：`sources/<BOOK>/job_batches.json` 里第 K 项（从 0 数起），每项形如 `[页slug, 起始节, 结束节, 字数]`，结束节不含。
  每个作业：`python3 tools/show_texts.py <BOOK> 页slug 起始节 结束节` 看原文与切句；
  用 Write 直接写 `sources/<BOOK>/annotations/<页slug>__<起始节>.json`（不要用共享的临时脚本名）；
  再 `python3 tools/check_job.py <BOOK> 页slug 起始节 结束节`，须输出 OK。
- **作者自注**：原文里用〈…〉括起的是作者自注（小字），与正文一起切句、翻译，注释词语照常取自原文连续字串；
  白话里自注部分可译成带括号的补充说明。〈〉符号本身保留在原文，不要改。
- 不改原文；底本疑误字照录，在注里写“疑当作……”，难辨处写“字不清”，不硬编。
- 每约 150 字原文至少一条注释；人名、书名、制度、器物、地名首次出现时点明；引书注出处与大意。

## 各书特点

- **性命圭旨**：明代内丹经典，含大量口诀、歌诀与图说。道教内丹术语（精气神、铅汞、坎离、河车、周天、胎息等）按其本义简要解释，白话译成现代人能读懂的话，不作养生或修炼指导的发挥；诗歌体口诀按句译。
- **沧浪诗话**：诗论。“妙悟”“兴趣”“气象”“体制”等术语按严羽本意解释；所举诗人诗句要点明作者与时代；〈〉为严羽自注。
- **白雨斋词话**：词论，条目短而多。词人、词牌、词句要点明；“沉郁”“本原”“浮”“厚”等概念按陈廷焯本意解释；引词句译成白话。
- **齐民要术**：农书。作物、农具、农时、农艺、酿造、烹饪术语按今名今义解释（如“耩”“耢”“糵”“麹”）；古今度量衡（尺、寸、斗、升、亩、步）说明所指，有把握才折算；原文〈〉大量为贾思勰自注，同样翻译；引《氾胜之书》《四民月令》《尔雅》等注出处。
- **武林旧事**：南宋临安风物，多为名词清单（节庆、菜品、艺人、店铺、官职）。清单项逐项译准，不漏；地名要说明在今杭州何处（有把握才写）；艺人、技艺、官署名称点明性质。
- **文史通义**：史学与文章理论，议论文体。要把论证层次译清，“六经皆史”“道”“器”“史意”“史法”“史德”“方志”“校雠”等概念按章学诚本意解释；引经史注出处；〈〉为章学诚自注。
- **困学纪闻**：札记考证，条目短而密，按王应麟的原意译；经传、史籍、诗文引文注出处；人名、官职、地名首次出现点明；〈〉小注（如有）为原注。
