# 《古文辞类纂》注译补充要求

BOOK = guwenciliezuan。清桐城派古文大家姚鼐（1731—1815）所编古文选本，七十五卷（序目＋七十四卷），分十三类：论辩、序跋、奏议、书说、赠序、诏令、传状、碑志、杂记、箴铭、颂赞、辞赋、哀祭；选战国秦汉至清初方苞、刘大櫆的文章约七百篇。页 x1 为姚鼐序目（讲各类文体源流）；j01–j75 为各卷，每页一卷，页内每篇为一节，节名形如“篇名（作者）”（作者按姚鼐目录的称呼，如“韩退之”“苏子瞻”）。作业批次见 `sources/guwenciliezuan/job_batches.json` 的第 K 项（从 0 数起），每项是若干作业 `[页slug, 起始节, 结束节, 字数]`（结束节不含）。

- 先读 `tools/annotation_guide.md`，格式与硬性规则以它为准。每个作业：
  `python3 tools/show_texts.py guwenciliezuan 页slug 起始节 结束节` 看各段切句；
  Write 写 `sources/guwenciliezuan/annotations/<页slug>__<起始节>.json`（一个作业一个文件，不要把几个作业合并成一个文件）；再 `python3 tools/check_job.py guwenciliezuan 页slug 起始节 结束节` 须输出 OK。
- 题解：每篇两三句话，点明作者、写作缘起与对象（如上书给谁、为谁作序、祭谁、记何处）、主旨与文体特点；《战国策》《史记》《汉书》所出的篇目点明所出与背景；不抄原文。
- 白话：准确、通顺的现代汉语，保留古文议论、叙事的神气；人名（字号官爵）、地名、年号保留，必要时顺带点明；经史引文、典故译出大意；对话、书信的口吻照应；赋、骚、铭、颂、诔等韵文照译意思，不必押韵；句数与原文切句一一对应，不省略。
- 注释：每约 80–100 字原文至少一条，宁多勿少。重点注：典故与出处（《诗》《书》《易》《春秋三传》《论语》《孟子》《庄子》《史记》《汉书》等，有把握才写出处，简述大意）、历史人物（战国秦汉人物、唐宋诸家，注身份与事迹，有把握才写，不确定写“待考”）、历代官制与礼制（三公九卿、封国郡县、唐宋官职、科举、谥法、祭祀、丧葬）、地名（今地有把握才写）、名物制度、赋体与骚体中的难字异体，以及文中的歧义句的理解。
- 底本分两个来源：维基文库（较可靠）和中国哲学书电子化计划（字符识别本，未校对，约两百篇）。后者偶有讹字、漏字，照录原文，在注里写“疑当作……”，不要改原文；节名里的作者称呼是目录所标，不改。
- 篇很长（如《上仁宗皇帝言事书》《二京赋》《两都赋》）时认真逐段做，不要因篇幅省略白话。不改原文；只创建你自己的 annotations 文件，临时脚本放在你自己新建的 scratchpad 子目录。完成后只回复一行：已完成的文件名与 OK。
