# 《郁离子》注译补充要求

BOOK = yulizi。《郁离子》，明初刘基（刘伯温）撰的寓言体政论集，借“郁离子”与诸人问答和短小寓言议论治国、用人、赏罚、世道人心，文笔峻洁，多用战国秦汉典故与自撰寓言。本站所据为明成化六年《诚意伯文集》石刻本，维基文库按目录页分为“序”和五页，每页若干则，页内每一则为一节（节名即该则标题）。第 0 批是吴从善序。作业批次见 `sources/yulizi/job_batches.json` 的第 K 项（从 0 数起），每项是若干作业 `[页slug, 起始节, 结束节, 字数]`（结束节不含）。

- 先读 `tools/annotation_guide.md`，格式与硬性规则以它为准。每个作业：
  `python3 tools/show_texts.py yulizi 页slug 起始节 结束节` 看各段切句；
  Write 写 `sources/yulizi/annotations/<页slug>__<起始节>.json`；再 `python3 tools/check_job.py yulizi 页slug 起始节 结束节` 须输出 OK。
- 题解：一两句话点明本则的寓意或所论之事（讽刺什么、主张什么），不照抄原文；这是寓言，要把“喻意”说出来。
- 白话：准确、通顺的现代汉语，保留寓言叙事和问答的口吻；人名、国名、官名保留（郁离子、艾大夫等虚拟人物保留原名）；典故和比喻译出本义；不省略、不加评论；句数与原文切句一一对应。
- 注释：每约 80 字原文至少一条，宁多勿少。重点注：典故出处（《左传》《战国策》《史记》《庄子》《孟子》《诗经》等，有把握才写出处）、历史人物与事件、古地名与官名制度、僻字异体字与生僻名物（如“𫘝𫘨”“螇螰”“僰人”之类，读音释义写在注里）、神话与寓言中的动植物名、成语来源（如“自讳自矜”“狙公”一类）。底本多异体字，照录，必要时在注里写“同……”“疑当作……”。不确定写“待考”，不要编造。
- 不改原文；只创建你自己的 annotations 文件，临时脚本放在你自己新建的 scratchpad 子目录。完成后只回复一行：已完成的文件名与 OK。
