# 四库本《文献通考》加标点

《文献通考》四库本原无标点；已取出缺失各卷的原文，存在 `sources/wenxiantongkao/sk_pages.json`（{卷号: {"title","paragraphs":[…]}}，每个元素是原书的一行，即一段）。你的任务：给指定卷的每一段加标点，不改一个字。

- 卷号由任务给出（可能多个）。用 python 读 `sk_pages.json` 里该卷的 `paragraphs`。
- 只能**插入**这些标点：。，、；：？！“”‘’《》。不得增删改任何汉字，不得挪动 `〈` `〉`（它们是原书的双行小注记号，必须留在原位；〈…〉里面的小注也要加标点）。原文里的全角空格“　”可保留也可换成标点。
- **小标题行**：单独成行的短行（如“祀山川”“封禅”“唐开元礼”“斋戒”“皇帝封祀泰山仪〈禅社首山附〉”）是篇目/小标题，**不加任何标点**，原样保留（小标题后面的〈…〉小注里也不加）。
  判断：短、无完整句意、是后面几段的题目；叙事或引文的短句（如“七载封昭应山为元德公”）是正文，要加句末标点。
- 其余正文按文意断句：句内用，、；：，句末用。？！；书名加《》，引语加“”（引文很长时，引号可只加在起讫处）。每个正文段必须以句末标点（。？！”）结尾（段尾若是 `〉`，小注内最后也要有句末标点）。
- 小注里常有“疏曰”“注云”“按”之类的引文，照文意断开即可，不必逐层加引号。
- 输出：`sources/wenxiantongkao/punct/<卷号>.json`，内容是字符串数组，与该卷 `paragraphs` 条数、顺序完全一致。用 Write 直接写；必须是合法 JSON（字符串里的英文双引号要转义，建议只用中文引号 “ ”）。
- 写完运行 `python3 tools/check_punct_wxtk.py <卷号> ...`，须输出 OK（它核验“去掉标点后与原文逐字相同”、段数、句末标点）。
- 只创建你自己的 punct 文件，不动其他文件。完成后回复一行：卷号与 OK。
