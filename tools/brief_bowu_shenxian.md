# 《博物志》《神仙传》注译补充要求

BOOK 为 bowuzhi 或 shenxianzhuan，批次见 `sources/BOOK/job_batches.json` 的第 K 项（从 0 数起），每项是若干作业 `[页slug, 起始节, 结束节, 字数]`（结束节不含）。

- **bowuzhi（《博物志》）**：旧题西晋张华撰，十卷，今本为后人缀辑，已非原书。卷一论地理山水、五方人民、物产，卷二外国、异人、异俗，卷三异兽，卷四物性、物理、物类，卷五方士、服食、辨方士，卷六人名考、文籍考、地理考、典礼考、乐考、服饰考、器名考、物名考，卷七异闻，卷八史补，卷九杂说上，卷十杂说下。每页一卷，页内按小标题分节（过长的按段落切开，节名为“标题·首段开头”）；多数段落是一条独立的短记。正文夹有“【周日用曰：…】”之类后人注文，属于底本文字，照常翻译，注里点明是后人所加的注。
- **shenxianzhuan（《神仙传》）**：东晋葛洪撰，十卷，今存八十四位仙人传，补刘向《列仙传》之未载。每页一卷，页内每位仙人为一节（节名即人名，如“广成子”“彭祖”“董奉”）。
- 先读 `tools/annotation_guide.md`，格式与硬性规则以它为准。每个作业：
  `python3 tools/show_texts.py BOOK 页slug 起始节 结束节` 看各段切句；
  Write 写 `sources/BOOK/annotations/<页slug>__<起始节>.json`；再 `python3 tools/check_job.py BOOK 页slug 起始节 结束节` 须输出 OK。
- 题解：一两句话点明本节讲什么（《博物志》说明该类条目所记的内容；《神仙传》点明该仙人是谁、有何仙术或事迹），不照抄原文。
- 白话：准确、通顺的现代汉语，保留叙事口吻；人名、地名、官职、年号、药物名保留，必要时顺带点明；歌谣、谶语、方术口诀译出大意；句数与原文切句一一对应，不省略。
- 注释：每约 100 字原文至少一条，宁多勿少。《博物志》重点注山川地名（今地有把握才写）、古国部族、异兽异物名、药物与方术、征引的古书（《山海经》《尔雅》《河图括地象》《神农经》《史记》等）、人物生平与礼制乐律器名；《神仙传》重点注仙人事迹出处与互见（《列仙传》《史记》《汉书》《后汉书》《抱朴子》等，有把握才写）、道教方术与丹药服食名词（金丹、云母、石脂、符箓、尸解、兵解等）、人物生平、地名与洞天福地、典故。不确定的写“待考”，不要编造。
- 底本偶有异体字、疑误字，照录，必要时在注里写“疑当作……”；不改原文；只创建你自己的 annotations 文件，临时脚本放在你自己新建的 scratchpad 子目录。完成后只回复一行：已完成的文件名与 OK。
