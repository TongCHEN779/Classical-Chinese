# 《物理小识》《长物志》《园冶》注译补充要求

（BOOK slug：wulixiaoshi＝物理小识，changwuzhi＝长物志，yuanye＝园冶。原文来自“中国哲学书电子化计划”，已转简体，不校改。）

- 先读 `tools/annotation_guide.md`，格式与硬性规则以它为准。
- 作业批次：`sources/<BOOK>/job_batches.json` 里第 K 项（从 0 数起），每项形如 `[页slug, 起始节, 结束节, 字数]`，结束节不含。
  每个作业：`python3 tools/show_texts.py <BOOK> 页slug 起始节 结束节` 看原文与切句；
  用 Write 直接写 `sources/<BOOK>/annotations/<页slug>__<起始节>.json`；再 `python3 tools/check_job.py <BOOK> 页slug 起始节 结束节` 须输出 OK。
- 不改原文；底本疑误字（含俗字、形近误字）照录，在注里写“疑当作……”，难辨处写“字不清”，不硬编。
- 每约 150 字原文至少一条注释；人名、书名、制度、器物、地名、术语首次出现时点明；引书注出处与大意。
- **名称行**：原文里单独成段的短行（如“门”“阶”“牡丹芍药”“（一）、门楼”）是条目名/小标题，其后的段落是对它的解释。名称行的白话写成“名称（类属）”即可（如“门（宅门）”），不必展开；其后的解释段译全。

## 各书特点

- **物理小识**：明末方以智的百科式笔记（天类、历类、风雷雨旸类、地类、占候类、人身类、医药类、饮食类、衣服类、金石类、器用类、草木类、鸟兽类、鬼神方术类、异事类），十二卷，常引西学（利玛窦、汤若望、熊三拔等）与中土旧说并陈。条目名即节名（如“光论”“气论”）。
  术语（象数、理气、气、征几、太极、五行、律吕、历法、医药名词）按方以智本意和当时的认识解释；古说与今天科学认识不同处，译文只忠实译原意，在注里可点明“此为古人之说”，不作现代科学的强行对应。
  标点为 ctext 机器标点，句读可能有误；你只对照 `show_texts` 给出的切句翻译。人名（“潜老夫”“愚者”“智”多为方以智自称或其亲友）首次出现注明；引书注出处。
- **长物志**：明末文震亨谈居室、花木、水石、禽鱼、书画、几榻、器具、衣饰、舟车、位置、蔬果、香茗的清玩之书，十二卷，每卷一类。
  器物、花木、书画、古玩、香茗术语按今名今义解释；名称行见上；“雅”“俗”的评语按作者的趣味如实译出。底本有俗字（如“湏”“扵”“聮”“牕”），照录，注里写“同‘须’”等。
  标点是后加的（原底本无标点），句读以 `show_texts` 为准。
- **园冶**：明末计成的造园专著，文言多骈句，名词密集（相地、立基、屋宇、装折、栏杆、门窗、墙垣、铺地、掇山、选石、借景）。
  “（一）、门楼”“（二）、堂”之类为小标题（名称行），其后是对它的说明；“五架梁式”等图式说明按字面译出。
  建筑与造园术语（卷、轩、榭、廊、庑、梁架、柱础、瓦作、叠石）要给出清楚解释；骈句、典故（如“桃花源”“陶令”“庾公”）点明出处。
