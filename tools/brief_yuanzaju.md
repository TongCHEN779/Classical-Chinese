# 元杂剧注译补充要求

BOOK 是元杂剧选本中的一部（梧桐雨、汉宫秋、荐福碑、青衫泪、王粲登楼、李逵负荆、看钱奴、秋胡戏妻、陈州粜米之一，版本为维基文库所录《元曲选》本），每页是一部剧，页内以“楔子”“第N折”为节。作业批次见 `sources/BOOK/job_batches.json` 的第 K 项（从 0 数起），每项是若干作业 `[页slug, 起始节, 结束节, 字数]`（结束节不含）。

- 先读 `tools/annotation_guide.md`，格式与硬性规则以它为准。每个作业：
  `python3 tools/show_texts.py BOOK 页slug 起始节 结束节` 看各段切句；
  用 Write 写 `sources/BOOK/annotations/<页slug>__<起始节>.json`；再 `python3 tools/check_job.py BOOK 页slug 起始节 结束节` 须输出 OK。
- 体例：原文里〔……〕是科介、说白提示（如〔旦云〕〔正末唱〕〔做……科〕〔下〕），【……】是曲牌名；每一“句”在 `show_texts` 里已切好，**科介提示、曲牌名所在的那一句也要配一句白话**（译成短语即可，如“〔旦做弹科〕”译“〔旦角做弹琵琶的动作〕”，“【仙吕•点绛唇】车碾残花”译时保留曲牌名，把曲词译出）。角色提示（正末、正旦、净、外、冲末、孛老、卜儿、禾旦等）首次出现在注里说明。
- 白话：把曲词与宾白译成通顺的现代汉语，意思准确，保留曲词的意象，不必押韵；人名、地名、官职首次出现点明；衬字、俗语、元代口语（如“兀的”“咱”“则”“可兀”“怎生”）译成现代说法。不加评论。
- 题解：每折一两句话，点明本折写什么、在全剧中的位置、唱的是哪套曲或谁主唱。
- 注释：每约 100 字原文至少一条，宁多勿少；重点注曲牌与宫调（首次出现，如“【仙吕•点绛唇】：仙吕宫套曲常用首曲”）、角色脚色名、元代口语与方言词、官制、地名、典故、历史人物与事件（点明与史实的出入）、戏曲术语（科、云、唱、带云、楔子、折）。不确定写“待考”，不要编造。
- 版本中的疑误字、异体字照录，必要时在注里写“疑当作……”；不改原文；只创建你自己的 annotations 文件。完成后回复一行：已完成的文件名与 OK。
