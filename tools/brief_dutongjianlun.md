# 《读通鉴论》注译补充要求

《读通鉴论》：明末清初王夫之读《资治通鉴》的史论，三十卷，依秦至五代的帝王次第，逐条评说史事得失。

- 先读 `tools/annotation_guide.md`，格式与硬性规则以它为准。BOOK = dutongjianlun。
- 你的作业批次：`sources/dutongjianlun/job_batches.json` 里第 K 项（K 由任务给出，从 0 数起），每项形如 `[页slug, 起始节, 结束节, 字数]`，结束节不含。
  每个作业：`python3 tools/show_texts.py dutongjianlun 页slug 起始节 结束节` 看原文与切句；
  写 `sources/dutongjianlun/annotations/<页slug>__<起始节>.json`；再 `python3 tools/check_job.py dutongjianlun 页slug 起始节 结束节` 须输出 OK。
- 节标题形如“景帝·一”“武帝·三”，是所属帝王加条序号，题解要点明本条评论的是哪件史事、作者的论点。
- 内容要求：王夫之议论层层转折，白话要把论证关系译清（“夫……则……”“故……”等不可译丢）；
  所涉史事（人物、官职、制度、战事、年号）在注里交代清楚，人名首次出现点明身份；《资治通鉴》《史记》《汉书》等引书、经书典故（《尚书》《春秋》《孟子》等）注出处与大意；
  王夫之的哲学用语（理、势、道、天、治乱、君子小人、封建郡县等）按本义简要点明。
  每约 150 字原文至少一条注释，不注一看就懂的常用词；公元纪年有把握才写。
- 不修改原文；原文有疑误字照录，在注里写“疑”。
- 全部作业通过后回复一行：已完成的文件名与 OK。只创建你自己的 annotations 文件，不动其他文件。
