# 《李鸿章传》逐句白话补充要求

项目根 /Users/tchen/Documents/Github/Classical-Chinese。BOOK = lihongzhangzhuan（梁启超，清末民初文言体传记，页 z00 序例、z01…z12 第一至第十二章，每页一节，约 2千–1万字）。每页已有 `sources/lihongzhangzhuan/annotations/<页>__0.json`，里面题解和词条注释都写好了，但每段的 `"译"` 是空数组 `[]`。**你的任务：给每段补上逐句白话，只改 `"译"`，不动 `"题解"`、`"注"` 和其他字段。**

## 怎么做

1. 先看 `python3 tools/show_texts.py lihongzhangzhuan <页> 0 1`，列出每段的切句（`|` 分隔，括号里是句数）。白话**一句对一句**，条数 = 括号里的句数，不得合并、拆分、漏句。
2. 读该页现有的 `"注"`（帮助理解难词典故与史实），再把白话写入同一文件：用脚本读入 JSON，给 `items[0]["段落"][j]["译"]` 赋值为长度等于该段句数的字符串列表，写回（`ensure_ascii=False, indent=1`）。段数、顺序不变。临时脚本放在你自己新建的、名字独一无二的 scratchpad 子目录。
3. 写完运行 `python3 tools/check_job.py lihongzhangzhuan <页> 0 1`，必须输出 OK。

## 白话要求

- 准确、通顺的现代汉语，句子译全，不省略关键信息；梁启超的议论、感叹、对比都要保留语气，不改写成评论。
- 人名、官名、地名、年号、条约名保留；古称首次出现时在句中顺带点明（如“合肥”可译作“合肥（李鸿章，因籍贯合肥而称）”，需要时写；“某公”“某侯”译成具体称谓，有把握才写）。
- 历史事件、数字、日期照原文译出；引文（经书、诗句、外国人语录）译出大意，保持引号。
- 原文中以“案：”“按：”领起的作者自注照译。
- 白话里不要出现 `|`、`¦` 和换行。不要抄任何现代译本，一律自己写。
- 不改原文，不动其他文件。不要跑全站检查。完成后只回复一行：页与 OK。
