# 《随园诗话》《瓯北诗话》注译补充要求

BOOK 为 suiyuanshihua 或 oubeishihua。批次见 `sources/BOOK/job_batches.json` 的第 K 项（从 0 数起），每项是若干作业 `[页slug, 起始节, 结束节, 字数]`（结束节不含）。

- **suiyuanshihua（《随园诗话》）**：清袁枚（号随园，主张“性灵说”）所撰诗话，十六卷，另有补遗十卷（页 b01–b10）。随笔体：每条评论一两位诗人或一桩诗坛掌故，常引全诗或警句，涉及清乾隆间官员、文士、闺秀、方外诗人及其唱和。页内相邻若干“条”合成一节（节名“一至十二”表示本节含该卷第一至第十二条），一条一段或数段。
- **oubeishihua（《瓯北诗话》）**：清赵翼所撰诗话，十二卷，专论李白、杜甫、韩愈、白居易、苏轼、陆游、元好问、高启、吴伟业、查慎行诸家，卷十一有“明妃诗”等专题，卷七含陆游年谱。节名多为“诗家·首段开头”，原站硬换行已合并成段；引诗以〔…〕括起，是底本标出的引文，照常翻译。
- 先读 `tools/annotation_guide.md`，格式与硬性规则以它为准。每个作业：
  `python3 tools/show_texts.py BOOK 页slug 起始节 结束节` 看各段切句；
  Write 写 `sources/BOOK/annotations/<页slug>__<起始节>.json`；再 `python3 tools/check_job.py BOOK 页slug 起始节 结束节` 须输出 OK。
- 原文里引诗用〔…〕括起，括号内的句号会把“〔…。〕《诗题》”切成两个“句”（如“〔天兵照雪下玉关，虏箭如沙射金甲。”和“〕《胡无人》”）：照 show_texts 的切法逐个给白话，后一个只剩括号与篇名的残句译作“（出自）《胡无人》”之类即可。
- 题解：一两句话点明本节所论（评了谁、什么观点：性灵、格调、才力、境界、用典、七律体制等，或记哪桩诗坛故事），不照抄原文。
- 白话：准确、通顺的现代汉语，保留评点的口吻；人名（字号官爵）、书名、诗题保留，必要时顺带点明；所引诗句译出大意（不必押韵），〔〕只是引文标记；句数与原文切句一一对应，不省略。
- 注释：每约 100 字原文至少一条，宁多勿少。重点注：诗人生平与字号官职（有把握才写，清代人物点明科第、仕履）、所引诗的作者与出处、典故与前人诗句、诗学术语（神韵、性灵、格调、肌理、才分、对仗、转韵、拗体、七律、乐府等）、史实与官制地名、书名人名（《随园诗话》涉及的清代诗人很多，生平不确定的写“待考”，不要编造）。
- 底本偶有异体字、疑误字，照录，必要时在注里写“疑当作……”；不改原文；只创建你自己的 annotations 文件，临时脚本放在你自己新建的 scratchpad 子目录。完成后只回复一行：已完成的文件名与 OK。
