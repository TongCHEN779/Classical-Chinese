# 《搜神后记》注译补充要求

《搜神后记》：旧题东晋陶潜撰的志怪小说集（实为托名，《四库提要》称为六朝遗书），十卷加第十一卷“补遗”，每卷若干则，页内每一则为一节（节名即该则标题，如“丁令威”“仙馆玉浆”“桃花源”）。内容多为仙境奇遇、鬼魂复生、精怪变化、报应梦兆，故事短小，晋宋人物常带年号与地名。BOOK = soushenhouji。

- 先读 `tools/annotation_guide.md`，格式与硬性规则以它为准。
- 作业批次：`sources/soushenhouji/job_batches.json` 里第 K 项（从 0 数起），每项是若干作业，每个作业形如 `[页slug, 起始节, 结束节, 字数]`，结束节不含。
  每个作业：`python3 tools/show_texts.py soushenhouji 页slug 起始节 结束节` 看原文与切句；
  Write 写 `sources/soushenhouji/annotations/<页slug>__<起始节>.json`；再 `python3 tools/check_job.py soushenhouji 页slug 起始节 结束节` 须输出 OK。
- 题解：一句话点明本则故事讲什么（谁遇到什么异事、结局如何），不照抄原文。
- 白话：准确、通顺、现代汉语，保留志怪叙事口吻；人名、官职、地名、年号保留，必要时顺带点明；诗歌、谶语、对话译出大意；句数与原文切句一一对应，不省略情节。
- 注释：每约 100 字原文至少一条，宁多勿少；重点注晋宋官制与年号（可括注公元年，有把握才写）、地名（今地有把握才写）、神仙方术与志怪名物、人物生平（有史可考者点明朝代与出处）、风俗礼制、占卜谶纬、典故及与《搜神记》《幽明录》《晋书》《世说新语》《异苑》等书的互见（有把握才写）。
- 底本说明：维基文库《搜神後記》；偶有异体字或疑误字，照录，在注里写“疑当作……”，确实难辨写“字不清”，不要硬编；不确定写“待考”。
- 不改原文；只创建你自己的 annotations 文件，临时脚本放在你自己新建的 scratchpad 子目录。完成后只回复一行：已完成的文件名与 OK。
