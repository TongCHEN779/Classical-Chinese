# 《生花梦》只写注释（不写白话）

BOOK = shenghuameng（清初才子佳人小说，署娥川主人，四卷十二回，据维基文库清康熙年间本衙藏板本；繁体转简体，未校对）。批次见 `sources/shenghuameng/job_batches.json` 第 K 项（从 0 数起），每项是 2 个作业 `[页slug, 0, 1, 字数]`（一回一页一节，约 7500–8300 字）。

- 先读 `tools/annotation_guide.md` 和 `tools/brief_notes5.md`，**不写白话**：每个段落只写 `"注"`，`"译"` 一律给 `[]`；每节必写 `"题解"`。
- 每个作业：`python3 tools/show_texts.py shenghuameng 页slug 0 1` 看原文与分段（原文里的诗词在 `原：` 行里，`/` 为分行）；用 Write 写 `sources/shenghuameng/annotations/<页slug>__0.json`，再 `python3 tools/check_job.py shenghuameng 页slug 0 1` 须输出 OK。作业较大，请在你自己专属的 scratchpad 子目录分段生成后合并；不要使用 gen.py 等通用文件名。
- 注的“词语”必须是本段原文里的连续字串，同一段内词语不重复；不确定写“待考”，不要编造；底本疑误字照录，在注里写“疑当作……”；不改原文。
- 题解：一两句话概括本回情节、人物与在全书中的位置，不抄原文；回目上下联所指要点到。
- 注释密度：每约 200 字至少一条，宁多勿少。重点注：诗词曲词的典故与题意（书中每回首尾及情节中诗词很多，须逐首点明用典）、书信与骈语用事、明清官制科举（布政使、按察使、巡抚、知府、太仆寺、大计卓异、京察、荐举、武举、乡试会试等）、军事与盗寨用语（寨、喽罗、豹尾关、降表、谕降、招安）、婚姻礼俗（媒人、聘礼、入赘、冲喜、停妻再娶、改扮女装、认亲）、宗教民俗（神君、妖异、托梦、卜卦、符箓、冥判）、吴语与江南方言俗语、地名（江宁、镇江、毘陵、白公堤、王屋山等，今地有把握才写）、器物称谓。书中虚构的官职地名与史实出入之处点明。涉及情爱与淫乱情节（如第三回）只释词语、典故、礼俗，不渲染。
- 完成后只回复一行：已完成的文件名与 OK。
