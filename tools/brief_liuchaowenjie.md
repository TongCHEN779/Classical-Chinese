# 《六朝文絜》注译补充要求

BOOK = liuchaowenjie。清许梿（1787—1862，字叔夏，号珊林，浙江海宁人，嘉庆道光间进士，官至河南按察使）所编六朝骈文选本，十二卷：卷一赋，卷二诏敕，卷三令教，卷四策问，卷五表疏，卷六启笺，卷七书，卷八移文·序，卷九论，卷十铭，卷十一碑，卷十二诔·祭文；共七十二篇，选宋、齐、梁、陈、北魏、北周诸家。页 x1 是许梿原序（骈体）；j01–j12 为卷一至卷十二，每页一卷，页内每篇为一节，节名形如“篇名（朝代・作者）”。作业批次见 `sources/liuchaowenjie/job_batches.json` 的第 K 项（从 0 数起），每项是若干作业 `[页slug, 起始节, 结束节, 字数]`（结束节不含）。

- 先读 `tools/annotation_guide.md`，格式与硬性规则以它为准。每个作业：
  `python3 tools/show_texts.py liuchaowenjie 页slug 起始节 结束节` 看各段切句；
  Write 写 `sources/liuchaowenjie/annotations/<页slug>__<起始节>.json`；再 `python3 tools/check_job.py liuchaowenjie 页slug 起始节 结束节` 须输出 OK。
- 题解：每篇两三句话，点明作者、写作缘起与对象（如为谁代拟、送给谁、哀悼谁、咏什么题材）、主旨与文体特点（骈偶、用典、抒情或讽喻），不抄原文。
- 白话：准确、通顺的现代汉语，保留抒情骈文的文采与气势；人名（字号官爵）、地名、年号保留，必要时顺带点明；对偶句、典故要译出实际意思，不堆砌词藻，不漏句；赋、铭、诔中的韵语、骚体句照译；句数与原文切句一一对应。
- 注释：每约 80–100 字原文至少一条，宁多勿少（骈文用典密，应多注）。重点注：典故与出处（《诗经》《楚辞》《左传》《史记》《汉书》《世说新语》及前代辞赋，有把握才写出处，并简述典故大意）、历史人物（古人事迹、六朝人物生平官职，有把握才写，不确定写“待考”）、六朝官制与礼制（侍中、太尉、扬州牧、东宫、封国郡王等）、地名（今地有把握才写，如芜城即广陵）、器物名物、辞赋中的特殊字词与异体字。
- 底本偶有异体字、疑误字，照录，必要时在注里写“疑当作……”；节名里的朝代作者是维基文库目录所标，不改；不改原文；只创建你自己的 annotations 文件，临时脚本放在你自己新建的 scratchpad 子目录。完成后只回复一行：已完成的文件名与 OK。
