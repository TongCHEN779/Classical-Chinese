# 《陶渊明集》注译补充要求

BOOK = taoyuanmingji。东晋陶渊明（陶潜，约 365—427，字元亮，号五柳先生，浔阳柴桑人，曾任江州祭酒、镇军参军、彭泽令，辞官归隐）诗文集，七卷：卷之一四言诗，卷之二诗，卷之三、四五言诗，卷之五赋辞，卷之六记传赞述，卷之七疏祭文；页 x1 是萧统序。每页一卷，页内每篇（组诗每首）一节（节名如“停云”“归园田居·其一”“饮酒二十首·其五”）。诗按阕（四句或二句一阕）分段，每段若干句；诗前的小序是散文段。作业批次见 `sources/taoyuanmingji/job_batches.json` 的第 K 项（从 0 数起），每项是若干作业 `[页slug, 起始节, 结束节, 字数]`（结束节不含）。

- 先读 `tools/annotation_guide.md`，格式与硬性规则以它为准。每个作业：
  `python3 tools/show_texts.py taoyuanmingji 页slug 起始节 结束节` 看各段切句；
  Write 写 `sources/taoyuanmingji/annotations/<页slug>__<起始节>.json`；再 `python3 tools/check_job.py taoyuanmingji 页slug 起始节 结束节` 须输出 OK。
- 题解：每首一两句话，点明题旨与写作背景（所写何事何情，系年与本事有把握才写，如“义熙二年”“弃官归隐后”，不确定就泛写），组诗每首各写一句（如《饮酒》其五写“心远地自偏”的隐居意趣）；散文、赋、传、祭文点明体裁、对象和主旨。
- 白话：准确、通顺的现代汉语，诗句译出大意与意象（不必押韵），保留原诗的情味；人名、地名、典故点明；句数与原文切句一一对应，不省略。
- 注释：每约 60 字原文至少一条，宁多勿少。重点注：典故与出处（《诗经》《论语》《庄子》《列子》《史记》《山海经》《楚辞》《古诗十九首》等，有把握才写出处）、人物（黔娄、荣启期、二疏、荆轲、桃花源中人、檀道济、周续之、颜延之等，有史可考者点明）、地名（柴桑、栗里、斜川、浔阳、庐山、曲阿等，今地有把握才写）、官制、名物与农事、晋宋年号与干支纪年（如“庚子”“丙辰”“己酉”可括注公元年，有把握才写）、陶诗常用语（如“无弦琴”“荷锄”“东篱”“柴车”）、赋辞的骈偶与用典。不确定写“待考”，不要编造。
- 异文夹注（“一作…”）已从原文移出，由整理者另补，不用管。底本字形、异体字照录，疑误处在注里写“疑当作……”；不改原文；只创建你自己的 annotations 文件，临时脚本放在你自己新建的 scratchpad 子目录。完成后只回复一行：已完成的文件名与 OK。
