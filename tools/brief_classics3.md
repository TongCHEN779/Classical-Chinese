# 《经典名篇》第三批注译补充要求

项目 /Users/tchen/Documents/Github/Classical-Chinese。你负责若干篇名篇的**题解、逐句白话、词条注释**。骨架已生成在 `src/classic_list/<slug>/001.txt`，原文已经定好，**只准填空，不准改原文**。

## 文件格式（以 `src/classic_list/ailian/001.txt`、`src/classic_list/pipa/001.txt` 为样）

```
# 篇名（分节的篇有多个“# 节名”）
题解：（待写）   ← 改成一两句话的题解
原：原文一整段 ||    ← 在“||”后填白话，每个原文句对应一句，句与句之间用 ¦ 隔开
注：词语：解释      ← 该段的词条注释，一条一行，紧跟在该段“原：”行之后
```

- 每个“原：”段里，原文以 。！？； 结束的每一句，在白话里对应一句，用 `¦` 分隔（`¦` 个数 = 原文句数 − 1）。句数必须一一对应，不得合并、拆分或漏句。诗（如《长恨歌》）每联一段，每联一句。
- 先运行 `python3 tools/classics_batch3.py show SLUG` 看每段的切句与句数。
- 白话：准确、通顺、现代汉语，句子译全；人名、官名、地名、典故首次出现时在白话里顺带点明；诗赋译出大意与意象，不加评论；可参考但不要照抄任何现代译本，一律自己写。白话里不要出现 `|`、`¦`（除分隔外）和换行。
- 题解：一两句话，点明本篇（或本节）写什么、有何主旨或结构，不抄原文。分节的篇每节都要有题解。
- 注释：写成 `注：词语：解释`，**词语必须是该段原文里连续出现的字串**（照原文用字）；每约 100–150 字原文至少一条，宁多勿少，重点注难词、典故、人名地名官名、制度、通假与异体字；诗赋多注典故与意象；解释简明，一条一行。不确定的写“待考”，不要编造；今地没有把握不写。
- 不改原文、不增减段落；原文里的疑误字、异体字照录，必要时在注里说明“疑当作……”。
- 完成后运行 `python3 tools/classics_batch3.py check SLUG`，必须输出 OK（会核对原文未改、句数对应、题解与注释数量）；对你负责的每个 SLUG 都要通过。
- 只改你负责的 `src/classic_list/<slug>/001.txt`，不动其他文件。完成后回复一行：已完成的 slug 与 OK。
