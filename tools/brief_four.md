# 《梼杌闲评》《东度记》《笑得好初集》《笑得好二集》注释补充要求

BOOK 与页 slug：
- taowuxianping（《梼杌闲评》，明末清初白话历史小说，五十回，写魏忠贤、客氏专权，页 p001…p050=第一至五十回，每回约 6700 字）
- dongduji（《东度记》，明方汝浩，神魔小说，一百回，写达摩东度及转世点化，宣扬佛理与劝善，页 p001…p100=第一至一百回，每回约 4500 字）
- xiaodehao1（《笑得好初集》，清石成金笑话集，单页 p001，含自叙、题辞和八十则笑话，每则后有评语）
- xiaodehao2（《笑得好二集》，同上，单页 p001，含题辞和三十余则）

本站只配题解与基础注释，**不写白话译文**。
```json
{"题解": "本回（本集）一两句话概括情节、主旨，不抄原文，客观",
 "注": ["词语：解释", ...]}
```
每页写 `sources/<BOOK>/notes/<页slug>.json`。
- 先 `python3 tools/show_novel.py <BOOK> <页slug>` 读原文（编号只是定位）。写完 `python3 tools/check_novel_notes.py <BOOK> <页slug>` 必须输出 `OK`（核对：每条注的“词语”是否是本页原文里**连续出现的字串**、数量够不够、有无重复）。
- “注”是平铺数组，**按词语在原文中出现的先后顺序排**（构建时每条注挂到含该词的第一段，从上一条所在处往后找）。同一词在本页只注一次。词语写原文字串（可去掉引号）。
- 数量：每约 150 字原文至少一条，宁多勿少。重点注：人名地名官名与明代官制（《梼杌闲评》涉及内阁、六部、东厂、锦衣卫、太监二十四衙门、科道、阉党与东林党人，首次出现时点明身份、职务与史事，有把握才写）、典故成语；佛道术语、鬼神、法术、民俗（《东度记》尤其注佛教名词与寓言人物）；明清白话与方言俗词（如“则个”“兀自”“恁地”“老大”“浑家”“相公”“官人”）；诗词与对联里的意象典故；市井行业、货币度量；笑话的谐音、双关、包袱（《笑得好》要把笑点讲清楚，但不啰嗦）。人物称谓首次出现时点明。不确定写“待考”，不要编造。
- 部分篇目含情爱描写：注释只释词语、典故、制度、风俗、器物，不渲染；题解客观，不加评价性形容。
- 原文取自维基文库，个别字句可能残缺或有明显讹误：原文照录，在注里写“疑当作……”并说明依据，不确定写“待考”。**不改原文**。
- 只创建你自己的 notes 文件，临时脚本放在你自己新建的 scratchpad 子目录；不要跑全站检查。完成后只回复一行：已完成的文件名与 OK。
