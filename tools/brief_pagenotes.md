# 韩非子、桃花扇：补题解与注释（不改白话、不改原文）

BOOK 为 hanfeizi 或 taohuashan。批次见 `sources/BOOK/job_batches.json` 的第 K 项（从 0 数起），每项是若干页的 slug。

- 先读 `tools/annotation_guide.md`（注释体例）。本任务的稿子格式不同：每页写一个 JSON，文件 `sources/BOOK/annotations/<页>.json`：
  `{"题解": "一两句话，概括本篇（本出）内容与地位", "段落": [{"注": ["词语：解释", ...]}, ...]}`
  “段落”与该页以“原：”“诗：”开头的行一一对应（含空注的段，给 `{"注": []}`，不能省）。
- 看原文：`python3 tools/page_notes.py show BOOK 页slug`（列出各段序号、字数、原文）；写完核验：`python3 tools/page_notes.py check BOOK 页slug`，须输出 OK。
- 注释的“词语”必须是**本段原文里的连续字串**，且不能跨“/”（“/”是诗词分行）；同一段内词语不重复；解释只用普通话简明解释，不确定写“待考”，不要编造；疑误字照录，注里写“疑当作……”。
- 作业大时，请在你自己的临时目录里分段生成再合并成最终 JSON；**不要使用共享的 gen.py 等通用文件名**。
- 只写 `sources/BOOK/annotations/` 下的文件，不要改 src、原文、白话、build.py。完成后只回复一行：已完成的页与 OK。

## 各书特点与密度

- **韩非子**（法家政论，先秦文言，已有逐句白话）：每约 120 字至少一条。重点注：法家术语（法、术、势、刑名、参验、人主）、先秦人名地名与史事典故、寓言出处、制度名物、古字通假与难词（点明本字）、引《诗》《书》《老子》之处。
- **桃花扇**（清传奇，一页一出，含前后附文）：每约 100–150 字至少一条。重点注：曲牌名（首次出现点明宫调与体式，把握不足写“宫调待考”）、脚色与科介、南明史事与人物（点明与史实出入，如侯方域、李香君、阮大铖、马士英、史可法、左良玉、弘光朝）、明代官制与科举、典故与诗句出处、金陵（南京）地名、方言俗语。上下场诗与曲词也要注。
