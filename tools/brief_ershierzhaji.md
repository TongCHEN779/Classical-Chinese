# 《廿二史劄记》注译补充要求

《廿二史劄记》：清赵翼的史学札记，三十六卷加补遗，逐史考辨编撰得失、体例异同，并就制度、政事、人物、风俗作综合论说；每条一个题目，节名即条目名（如“汉书移置史记文”）。BOOK = ershierzhaji。

- 先读 `tools/annotation_guide.md`，格式与硬性规则以它为准。
- 作业批次：`sources/ershierzhaji/job_batches.json` 里第 K 项（从 0 数起），每项形如 `[页slug, 起始节, 结束节, 字数]`，结束节不含。
  每个作业：`python3 tools/show_texts.py ershierzhaji 页slug 起始节 结束节` 看原文与切句；
  用 Write 直接写 `sources/ershierzhaji/annotations/<页slug>__<起始节>.json`；再 `python3 tools/check_job.py ershierzhaji 页slug 起始节 结束节` 须输出 OK。
- 题解点明本条考辨什么、结论是什么、在哪几部史书之间比较。
- 内容要求：赵翼考史多“列举史实—对比—断语”，白话要把层次译清，引史文也译成白话（引文原文照原句对应）；
  人名、官职、制度、地名、年号首次出现点明（史书条目名如《史记》《汉书》《三国志》《晋书》等不必解释，但书中涉及的列传、本纪、志篇名可点明）；
  同一事在不同史书中的异同要交代；引用的诏令、奏疏、诗文注出处与大意；每约 150 字原文至少一条注释。
- 原文里已有括号注（如“（塞外）”）与〈…〉小注是底本自带的夹注，随正文切句翻译，注释词语照常取自原文连续字串；〈〉符号保留。
- 不改原文；底本疑误字照录，在注里写“疑当作……”，难辨处写“字不清”，不硬编。
- 完成后回复一行：已完成的文件名与 OK。只创建你自己的 annotations 文件，不动其他文件。
