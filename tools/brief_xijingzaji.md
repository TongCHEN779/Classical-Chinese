# 《西京杂记》注译补充要求

《西京杂记》：旧题西汉刘歆撰、东晋葛洪辑（作者问题历来有争议，注释里不必展开），六卷，约百三十条，杂记西汉长安的宫苑台殿、器物服饰、典章风俗和帝王后妃、文人方士的轶事，是魏晋笔记小说的早期名篇。BOOK = xijingzaji。每条以“一、萧何营未央宫”之类标题为一节。

- 先读 `tools/annotation_guide.md`，格式与硬性规则以它为准。
- 作业批次：`sources/xijingzaji/job_batches.json` 里第 K 项（从 0 数起），每项是若干作业，每个作业形如 `[页slug, 起始节, 结束节, 字数]`，结束节不含。
  每个作业：`python3 tools/show_texts.py xijingzaji 页slug 起始节 结束节` 看原文与切句；
  用 Write 直接写 `sources/xijingzaji/annotations/<页slug>__<起始节>.json`；再 `python3 tools/check_job.py xijingzaji 页slug 起始节 结束节` 须输出 OK。
- 题解：一两句话点明本条记什么（宫苑、器物、人物轶事等），不照抄原文。
- 白话：准确、通顺、现代汉语；帝号、人名、官职、宫殿名、地名保留，必要时顺带点明（如“武帝”首次译作“汉武帝”）；不加评论；诗赋歌谣译出大意，句数与原文切句一一对应。
- 注释：每约 120 字原文至少一条，宁多勿少；重点注宫苑台殿与长安地名（今地有把握才写）、汉代官制与礼制、器物服饰、人物生平与字号、典故，及与《史记》《汉书》的异同（有把握才写）。
- 底本说明：维基文库《西京杂记》；底本偶有异体字或疑误字，照录，在注里写“疑当作……”，确实难辨写“字不清”，不要硬编；不确定的内容写“待考”，不要编造。
- 不改原文；只创建你自己的 annotations 文件，不动其他文件。完成后回复一行：已完成的文件名与 OK。
