# 明清小说、笔记注译补充要求

BOOK 为 歧路灯（qiludeng）、封神演义（fengshenyanyi）、东周列国志（dongzhoulieguozhi）、三侠五义（sanxiawuyi）、情史（qingshi）、古今谭概（gujintangai）之一，底本均为维基文库所录；作业批次见 `sources/BOOK/job_batches.json` 的第 K 项（从 0 数起），每项是若干作业 `[页slug, 起始节, 结束节, 字数]`（结束节不含）。

- 先读 `tools/annotation_guide.md`，格式与硬性规则以它为准。每个作业：
  `python3 tools/show_texts.py BOOK 页slug 起始节 结束节` 看各段切句；
  用 Write 写 `sources/BOOK/annotations/<页slug>__<起始节>.json`；再 `python3 tools/check_job.py BOOK 页slug 起始节 结束节` 须输出 OK。
- 一页是一回（或一卷）；章回小说一回为一节，回目放在题解里点明；情史、古今谭概一页是一卷，卷内每条（人物、故事）为一节。
- 题解：一两句话，概括本回（本条）情节与在全书中的位置，不抄原文；情史、古今谭概的每一条点明讲谁、什么事。
- 白话：准确、通顺的现代汉语，译全每一句；人名、官职、地名、神怪名保留，首次出现点明；回首回末的诗词、“有诗为证”“正是”“且听下回分解”等套语也要译（诗词译出大意，套语译成现代说法）；对话里的方言、俗语（歧路灯多河南中州话，三侠五义多北方口语）译成现代说法，难解处在注里说明；不加评论，不删节。
- 注释：每约 250 字原文至少一条（章回小说），情史、古今谭概（文言）每约 120 字至少一条，宁多勿少；重点注方言口语词、俗语、典故、官制与科举、地名（今地有把握才写）、风俗器物、神怪与宗教名词、历史人物与史实（点明与正史的出入）、诗词出处。封神演义注重神话与道教、商周史实对照；东周列国志注重春秋战国人物事件、与《左传》《史记》《国语》的对应；三侠五义注重宋代官制、包公故事与江湖行话；歧路灯注重清代科举、家训、河南方言；情史、古今谭概注重人物所出的史书与笔记。不确定的写“待考”，不要编造。
- 底本疑误字、异体字照录，必要时在注里写“疑当作……”；不改原文；只创建你自己的 annotations 文件。完成后只回复一行：已完成的文件名与 OK。
