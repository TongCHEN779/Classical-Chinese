# 《汉书》注译补充要求

《汉书》：东汉班固撰，纪、表、志、传四体，西汉断代史；武帝以前大量沿用《史记》，其后是班氏自撰。BOOK = hanshu。本站“表”类各卷只收序言文字，不含表格。

- 先读 `tools/annotation_guide.md`，格式与硬性规则以它为准。
- 作业批次：`sources/hanshu/job_batches.json` 里第 K 项（从 0 数起），每项形如 `[页slug, 起始节, 结束节, 字数]`，结束节不含。
  每个作业：`python3 tools/show_texts.py hanshu 页slug 起始节 结束节` 看原文与切句；
  用 Write 直接写 `sources/hanshu/annotations/<页slug>__<起始节>.json`；再 `python3 tools/check_job.py hanshu 页slug 起始节 结束节` 须输出 OK。
- 题解：点明本篇（传主/事件/志篇）讲什么、在全书中的位置，沿用《史记》的篇目可点明“与《史记》某篇对应”。
- 白话：准确、通顺、现代汉语；人名、官职、地名、年号、郡国首次出现时在白话里点明（如“丞相萧何”“沛公（刘邦）”），不加评论；引《诗》《书》《易》《春秋》等经文照意译出。
- 注释：每约 150 字原文至少一条，宁多勿少；重点注官制（丞相、太尉、御史大夫、列侯、郡守、都尉、中二千石等）、地名（今地有把握才写）、制度（算缗、告缗、均输、平准、察举、酎金等）、典章与典故、人物生平、引书出处。同一条目在同一作业内首次出现注一次。
- 底本说明：这是维基文库的《汉书》（含颜师古注的正文已去掉注），底本偶有疑误字、异体字，照录，在注里写“疑当作……”，确实难辨写“字不清”，不要硬编。
- 不改原文；只创建你自己的 annotations 文件，不动其他文件。完成后回复一行：已完成的文件名与 OK。
