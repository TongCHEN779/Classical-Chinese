# 《国色天香》逐句白话要求

项目根 /Users/tchen/Documents/Github/Classical-Chinese。BOOK = guosetianxiang（《国色天香》，明万历年间文言传奇小说选集，十卷，页 slug p001=序，p002…p011=第一至第十卷；多篇才子佳人传奇，夹大量诗词、书信与骈句）。原文与注释已有，现补**逐句白话**（悬浮显示）。你负责若干个“页 + 段号区间”（见任务说明）。

## 怎么做

1. 先看该页注释 `sources/guosetianxiang/notes/<页>.json`（题解和词条注，帮助理解难词与典故；不要改它）。
2. `python3 tools/gloss_book.py show guosetianxiang <页> 起 止` 列出区间内每段的切句（`|` 分隔，括号里是句数）。
3. 把白话写进 `sources/guosetianxiang/gloss/<页>__起始段号.json`（起始段号四位，如 `p004__0071.json`；先 `mkdir -p` 该目录），格式：

```json
{"start": 71, "白话": ["第 71 段的白话（每句之间用 ¦ 隔开）", "第 72 段的白话", ...]}
```

- `白话` 数组第 k 个元素对应第 start+k 段；段内**每个以 。！？； 结束的原文句，对应白话里的一句**，句与句之间用 `¦` 隔开（`¦` 个数 = 句数 − 1），不得合并、拆分或漏句。括号里的句数就是该段应有的白话句数。
- 白话要求：准确、通顺的现代汉语，译全；人名、官名、地名、典故首次出现时在白话里顺带点明；骈句和诗词译出大意与意象（诗、词、对联每一联分别译出）；书信、奏疏同样译全。段首若是“诗曰”“词曰”之类引语也要译。可参考注释但不要照抄任何现代译本，一律自己写。白话里不要出现 `|`、`¦`（除分隔外）和换行。
- 含男女调笑、情爱描写：白话照原意平实译出，**不添油加醋、不渲染**。
- 不改原文，不动其他文件。写入时可用脚本生成 JSON 以免转义出错，临时脚本放在你自己新建的 scratchpad 子目录。
- 写完逐个区间运行 `python3 tools/gloss_book.py check guosetianxiang <页> 起 止`，必须输出 `OK`。不要跑全站检查。完成后只回复一行：各区间与 OK。
