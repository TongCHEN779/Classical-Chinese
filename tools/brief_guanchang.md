# 《官场现形记》注释补充要求

BOOK = guanchang。晚清李宝嘉（伯元，笔名南亭亭长，1867—1906）所著谴责小说，六十回，白话章回体，以大量官场见闻串起钻营求官、买缺卖官、上下倾轧的丑态（晚清光绪年间，场景在陕西、江西、浙江、江苏、北京等地）。本站只配题解与基础注释，**不写白话译文**。页 slug 是回号 001–060。

你分到的是若干回（作业＝回号）。每回写 `sources/guanchang/annotations/<回号>.json`：

```json
{"题解": "本回一两句话概括情节与讽刺所指，不抄原文",
 "段落": [ {"注": ["词语：解释", "词语：解释"]}, {"注": []}, ... ]}
```

- 先 `python3 tools/show_guanchang.py 回号`：按编号列出各段（含字数）和原站已有的注（**原站已有的词条不要重复**）；`段落` 数组必须与段数一一对应（没有注的段写 `{"注": []}`），顺序不能错。
- 写完用 `python3 tools/check_guanchang_job.py 回号`，必须输出 `OK`（它会核对段落数、注的词语是否出自本段原文、注的数量）。
- 题解：一两句话（可两三句），说明本回写谁、什么事、讽刺什么；回目有诗联的段不必逐句解释，在注里解释难词。
- 注释：每约 150 字原文至少一条，宁多勿少。重点注：晚清官制与科举捐纳（道台、藩台、臬台、督抚、府县官、候补、候补道、差使、委员、保举、捐班、监生、佐杂、师爷、幕友、红顶、花翎、补服等）、官场规矩与黑话（卖缺、打点、门包、规矩、红包、下帖、递手本、端茶送客、顶戴等）、时事（中法战争、甲午战后、洋务、新政、出洋、考察、矿务、机器局、学堂、报馆等）、方言俗语（陕西、江浙、官话口语）、人物称谓（大人、老爷、二爷、夫子、门生、世兄、年伯等）、典故、器物饮食、民俗宗教、货币度量（洋钱、银子、两、吊、钱庄）。注的词语必须是该段原文里连续出现的字串（繁简、标点同原文，可去掉引号）。不确定的写“待考”，不要编造。
- 诗联、回目、骈句只在有难词时注。不改原文；只创建你自己的 annotations 文件，临时脚本放在你自己新建的 scratchpad 子目录。完成后只回复一行：已完成的文件名与 OK。
