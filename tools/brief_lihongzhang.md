# 《李鸿章传》注释补充要求

BOOK = lihongzhangzhuan。梁启超（1873—1929）1901 年李鸿章去世后在日本所撰传记，浅近文言（报章“新文体”），夹叙夹议；页 z00 序例，z01–z12 为第一至第十二章；每页一节（节名即章名）。作业批次见 `sources/lihongzhangzhuan/job_batches.json` 的第 K 项（从 0 数起），每项是若干作业 `[页slug, 起始节, 结束节, 字数]`（结束节不含）。

- 先读 `tools/annotation_guide.md`，格式与硬性规则以它为准；**本书不写白话**：每段 `"译"` 一律是 `[]`，只写 `"题解"` 与 `"注"`。
  每个作业：`python3 tools/show_texts.py lihongzhangzhuan 页slug 起始节 结束节` 看各段；Write 写 `sources/lihongzhangzhuan/annotations/<页slug>__<起始节>.json`；再 `python3 tools/check_job.py lihongzhangzhuan 页slug 起始节 结束节` 须输出 OK。
- 题解：每章两三句，概括本章论述范围、核心论点与在全书里的位置；不照抄原文。
- 注释：每约 100–120 字原文至少一条，宁多勿少。重点注：晚清人物（曾国藩、左宗棠、曾国荃、淮军诸将、戈登、华尔、李秀成等，注其身份与简要事迹）、官制职衔（总督、巡抚、提督、总兵、总理衙门、军机处、北洋大臣等）、史事与条约（太平天国、捻军、天津教案、中法战争、甲午战争、马关条约、三国干涉还辽、中俄密约、戊戌变法、义和团、辛丑和约等，注年份与要点）、地名（今地有把握才写）、洋务机构与舰船军制、外国人名与西方典故（俾斯麦、格兰特等，注其身份）、成语典故与梁氏用语（如“时势造英雄”“大器晚成”等）。梁启超评论处的人物比较，注人物身份即可。不确定的写“待考”，不要编造；数据表格不注。
- 原文里的年号纪年首次出现可注公元年份。梁氏原书的括注（如“（注：……）”）是原文，不要当作你的注释。
- 序例是一个列表，每条一段；第十一、十二章末的条约文本、日本人评论（繁体字，原样保留）是原文，照常按段注，少注即可；挽联、诗句注出处与含义。
- 底本偶有异体字、疑误字，照录，必要时在注里写“疑当作……”；不改原文；只创建你自己的 annotations 文件，临时脚本放在你自己新建的 scratchpad 子目录。完成后只回复一行：已完成的文件名与 OK。
