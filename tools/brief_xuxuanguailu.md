# 《续玄怪录》注译补充要求

《续玄怪录》：唐李复言撰的传奇小说集，承牛僧孺《玄怪录》而作，今本凡二十三篇，分卷一至卷四，另有“辑佚”一卷（后人从《太平广记》等书补辑，其中个别篇目与《玄怪录》辑佚重出）。每篇一事，篇名即页内标题（如“杨敬真”“定婚店”）；个别篇名在底本中被截短（如“凉国武公李”），照录。内容多为人与神仙、鬼魂、精怪相遇及命定姻缘、梦幻奇遇。BOOK = xuxuanguailu。人物多为唐代人，故事常带年号与地名。

- 先读 `tools/annotation_guide.md`，格式与硬性规则以它为准。
- 作业批次：`sources/xuxuanguailu/job_batches.json` 里第 K 项（从 0 数起），每项是若干作业，每个作业形如 `[页slug, 起始节, 结束节, 字数]`，结束节不含。
  每个作业：`python3 tools/show_texts.py xuxuanguailu 页slug 起始节 结束节` 看原文与切句；
  用 Write 直接写 `sources/xuxuanguailu/annotations/<页slug>__<起始节>.json`；再 `python3 tools/check_job.py xuxuanguailu 页slug 起始节 结束节` 须输出 OK。
- 题解：一两句话点明本篇讲什么故事（谁遇到什么异事、结局如何），不照抄原文。
- 白话：准确、通顺、现代汉语，保留传奇叙事口吻；人名、官职、地名、年号保留，必要时顺带点明（年号可括注公元年，有把握才写）；诗歌、对话、谶语译出大意；句数与原文切句一一对应，不省略情节。
- 注释：每约 120 字原文至少一条，宁多勿少；重点注唐代官制与科举、地名（今地有把握才写）、神仙方术与志怪名物、佛道典故、人物生平（有史可考者点明出处）、风俗礼制、占卜谶纬、典故及诗文出处。
- 底本说明：维基文库《续玄怪录》；底本偶有异体字或疑误字，照录，在注里写“疑当作……”，确实难辨写“字不清”，不要硬编；不确定的内容写“待考”，不要编造。
- 不改原文；只创建你自己的 annotations 文件，不动其他文件。完成后回复一行：已完成的文件名与 OK。
