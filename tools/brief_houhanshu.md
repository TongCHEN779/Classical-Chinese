# 《后汉书》注译补充要求

《后汉书》：南朝宋范晔撰，纪、列传，后人并入晋司马彪《续汉书》八志（志页标题以“志第…”开头，内容为律历、礼仪、祭祀、天文、五行、郡国、百官、舆服等典章）。东汉断代史，光武至献帝。BOOK = houhanshu。

- 先读 `tools/annotation_guide.md`，格式与硬性规则以它为准。
- 作业批次：`sources/houhanshu/job_batches.json` 里第 K 项（从 0 数起），每项形如 `[页slug, 起始节, 结束节, 字数]`，结束节不含。
  每个作业：`python3 tools/show_texts.py houhanshu 页slug 起始节 结束节` 看原文与切句；
  用 Write 直接写 `sources/houhanshu/annotations/<页slug>__<起始节>.json`；再 `python3 tools/check_job.py houhanshu 页slug 起始节 结束节` 须输出 OK。
- 题解：点明本篇（传主/事件/志篇）讲什么、在全书中的位置；合传点明各传主。
- 白话：准确、通顺、现代汉语；人名、官职、地名、年号、郡国首次出现时在白话里点明（如“大司马吴汉”“南阳郡蔡阳县”），年号可括注公元年；不加评论；引经文照意译出。
- 注释：每约 150 字原文至少一条，宁多勿少；重点注官制（三公、九卿、尚书台、侍中、郡守、中郎将、校尉等）、地名（今地有把握才写）、制度（察举、孝廉、党锢、外戚宦官、屯田、度田等）、典章与典故、人物生平、引书出处。同一条目在同一作业内首次出现注一次。志页（律历、礼仪、天文、五行、郡国、百官、舆服）术语多，注释要给足；数字、历法、星宿、郡国户口等表式文字白话照意译出，不确定写“待考”。
- 底本说明：维基文库《后汉书》，李贤注已去掉；底本偶有疑误字、异体字，照录，在注里写“疑当作……”，确实难辨写“字不清”，不要硬编；不确定的人名地名写“待考”。
- 不改原文；只创建你自己的 annotations 文件，不动其他文件。完成后回复一行：已完成的文件名与 OK。
