# 注译作业规范（贞观政要、天工开物等“原文＋逐句白话＋题解＋注释”的书）

一个作业 = 某书某页（卷）中连续的若干节（`tools/plan_jobs.py BOOK` 列出）。你要为这些节写**题解、逐句白话、词条注释**，
输出一个 JSON 文件：`sources/<BOOK>/annotations/<页slug>__<起始节>.json`。

## 看原文

```bash
python3 tools/show_texts.py BOOK 页slug 起始节 结束节    # 按程序的切句方式列出每段的句子（白话必须与此一一对应）
```

## JSON 格式

```json
{"start": 起始节序号,
 "items": [
  {"题解": "本节一两句话的题解",
   "段落": [
     {"译": ["第1句的白话", "第2句的白话"], "注": ["词语：解释", "词语：解释"]},
     {"译": ["…"], "注": []}
   ]},
  ...每节一项，顺序与节一致
 ]}
```

## 硬性规则（`python3 tools/check_job.py BOOK 页slug 起始节 结束节` 会逐项核验，不通过要改到通过）

1. `items` 数 = 作业的节数；每节的 `段落` 数 = 该节原文段数；每节必须有非空 `题解`。
2. 每段的 `译` 条数 = `show_texts.py` 列出的该段句数，**一句对一句**，不得合并、拆分、漏句；每句白话非空，不含 `¦` `|` 和换行。
3. 每条 `注` 写成 `词语：解释`；**词语必须是该段原文里连续出现的原文字串**（繁简、标点同原文）。
4. **不改原文**：你只写白话、题解、注释；不要修改、补正、删减原文（疑误字照录，必要时在注里写“疑当作…”）。
5. 不要给原文里本来没有的内容；不引用别人的白话译本，一律自己写。

## 写法要求

- **白话**：准确、通顺、现代汉语；句子要译全，不省略关键信息；专名（人名、官名、地名、年号）保留，必要时在句中顺带点明（如“太宗”可译作“太宗（唐太宗李世民）”首次出现时）。不加评论，不意译过度。
- **题解**：一至三句，概括本节讲什么、论点或事件、在全篇里的位置；不要照抄原文。
- **注释**：解释难词、典故、人名、官名、地名、制度、器物、农艺或工艺术语，每 150 字左右至少一条，**宁多勿少**，但不要注释一看就懂的常用词；
  同一条目在同一作业内重复出现时，每节首次出现注一次即可。解释简明，一条一行，不含换行。
- 各书补充要求见作业说明。

## 完成

写完文件后运行 `check_job.py`，必须输出 `OK`。只改你自己的 annotations 文件，不动其他文件。最后回复一行：文件名与 OK。
