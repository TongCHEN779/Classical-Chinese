# 《惜抱轩文集》注译补充要求

BOOK = xibaoxuan。清桐城派古文大家姚鼐（1731—1815，字姬传，号惜抱，乾隆二十八年进士，曾官刑部郎中、四库馆纂修官，后主讲钟山、紫阳等书院四十年）的文集，十六卷：卷一论，卷二考，卷三、四序，卷五题跋，卷六书，卷七赠序，卷八寿序，卷九策问，卷十传，卷十一碑文，卷十二、十三墓志铭，卷十四记，卷十五赋，卷十六祭文。页 x1 是姚原绂刻书缘起（序）。每页一卷，页内每篇为一节（节名即篇名），过长的篇按段落切成几节（节名“篇名·首段开头”）。作业批次见 `sources/xibaoxuan/job_batches.json` 的第 K 项（从 0 数起），每项是若干作业 `[页slug, 起始节, 结束节, 字数]`（结束节不含）。

- 先读 `tools/annotation_guide.md`，格式与硬性规则以它为准。每个作业：
  `python3 tools/show_texts.py xibaoxuan 页slug 起始节 结束节` 看各段切句；
  Write 写 `sources/xibaoxuan/annotations/<页slug>__<起始节>.json`；再 `python3 tools/check_job.py xibaoxuan 页slug 起始节 结束节` 须输出 OK。
- 题解：每篇一两句话，点明篇旨、写作对象与场合（论某人某事的是非；考某地沿革；为某人文集作序；墓志传记的传主身份与品行；记某处亭楼等），不抄原文；篇被切成几节时，非首节的题解点明该节所述。
- 白话：准确、通顺的现代汉语，保留古文议论、叙事的神气；人名（字号官爵）、地名、书名、年号保留，必要时顺带点明（乾隆、嘉庆年号可括注公元年，有把握才写）；骈偶、典故、引《诗》《书》《易》《左传》的话译出大意；寿序、墓志里的颂辞、铭辞照译；句数与原文切句一一对应，不省略。
- 注释：每约 100 字原文至少一条，宁多勿少。重点注：典故与经史出处（《左传》《史记》《汉书》《后汉书》《论语》《孟子》《诗经》等，有把握才写出处）、清代官制科举（翰林、庶吉士、按察使、道员、巡抚、乡会试等）、地名沿革（今地有把握才写，《郡县考》类的考证文章重点解释所涉郡县与历史地理）、清代人物生平（姚鼐师友门人如刘大櫆、戴震、朱筠、钱大昕、翁方纲、方苞等，有把握才点明字号与籍贯，不确定写“待考”）、桐城派与考据学术语、礼制（谥法、赠官、祠祭、丧葬、旌表节烈）、赋体用语。
- 底本偶有异体字、疑误字，照录，必要时在注里写“疑当作……”；篇题里的〈并序〉等小注照录；不改原文；只创建你自己的 annotations 文件，临时脚本放在你自己新建的 scratchpad 子目录。完成后只回复一行：已完成的文件名与 OK。
