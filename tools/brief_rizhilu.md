# 《日知录》注译补充要求

《日知录》：明末清初顾炎武的读书札记，三十二卷，每条一个题目，考辨经义、政事、世风、礼制、科举、艺文、名义、史法、地理等。

- 先读 `tools/annotation_guide.md`，格式与硬性规则以它为准。BOOK = rizhilu。
- 你的作业批次：`sources/rizhilu/job_batches.json` 里第 K 项（K 由任务给出，从 0 数起），每项形如 `[页slug, 起始节, 结束节, 字数]`，结束节不含。
  每个作业：`python3 tools/show_texts.py rizhilu 页slug 起始节 结束节` 看原文与切句；
  写 `sources/rizhilu/annotations/<页slug>__<起始节>.json`（直接用 Write 写最终 JSON，不要用共享的临时脚本名）；
  再 `python3 tools/check_job.py rizhilu 页slug 起始节 结束节` 须输出 OK。
- 节标题是条目名（如“三易”“河渠”），题解点明本条考辨什么、结论是什么。
- 内容要求：顾炎武考证体，多引经史原文再下论断；白话要把“引文—论断”的层次译清，引文也要译成白话（引文原文照原句对应）；
  引书（《尚书》《诗》《左传》《史记》《汉书》《通典》《文献通考》及各代史籍、碑刻）注出处与大意；
  人名、官职、制度、地名、年号首次出现点明；名物制度的古今变化是本书重点，须交代清楚；
  每约 150 字原文至少一条注释。
- 本书底本录入错字较多（OCR 误识，如“?”或形近字），不修改原文，疑误字照录，在注里写“疑当作……”；确实难辨处写“字不清”，不要硬编。
- 全部作业通过后回复一行：已完成的文件名与 OK。只创建你自己的 annotations 文件，不动其他文件。
