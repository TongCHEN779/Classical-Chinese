# 古典文库

古典文献与白话小说的在线阅读站：文言典籍原文在前，鼠标悬停逐句显示白话；白话小说直接阅读原文，无需悬浮翻译。

- `src/<书>/<笔>/juanNN.txt`：标注文本。每行 `原文句 || 白话`；`# 标题` 开始一则；`注：…` 为折叠注释；空行分段。
- `python3 build.py`：生成静态网页（`index.html`、`rongzhai/…`）。
- 注释每个独立词条单列一行，按钮“注释（数量）”按实际词条计数。新增内容每个词条各写一行 `注：词语：解释`；生成器兼容旧稿合写格式，保留同一词条的连续解释、引文及括注。
