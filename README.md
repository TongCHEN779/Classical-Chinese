# 古典文库

古典文献与白话小说的在线阅读站。静态网页，由 `build.py` 从 `src/` 生成到 `books/`。

- **文言典籍**：原文在前，鼠标悬停（触屏点按）逐句显示自撰白话，每条或每段有折叠的题解和词条注释。
- **白话小说、半白话戏曲**：直接读原文，只附基础注释。
- **大部头史书与类书**：只整理原文，暂无白话、题解与注释。

## 目录结构

| 路径 | 内容 |
| --- | --- |
| `index.html`、`assets/` | 首页（搜索、字母索引）与样式、脚本 |
| `books/<书>/` | 生成的各书目录页与阅读页（网址形如 `…/books/shiji/`） |
| `src/<书>/<页>/*.txt` | 标注文本，见下文格式 |
| `sources/<书>/` | 来源缓存（页面 JSON、版本号、SHA-256）、进度与整理说明；每本书的版本和已知问题见其中的 `README.md` |
| `tools/` | 抓取、整理脚本（`fetch_*`、`prepare_*`）与各书检查脚本（`check_*`） |
| `tests/` | 单元测试 |

维基文库续编范围见 `sources/WIKISOURCE.md`。所有书的原文都**尚未据影印本逐字校勘**；疑误字一律保留并在注中标“疑”“校”。

### 标注文本格式

- `# 标题` 开始一节；可选 `题解：…`。
- 每个原文段一行：`原：原文 || 白话¦白话…`，白话按句以 `¦` 对齐，诗词行用 `/` 分隔。
- `注：词语：解释`，每个词条独占一行；空行分段。
- 无白话的书只写 `原：` 与 `注：`。

## 构建与检查

```bash
python3 build.py                 # 生成网页到 books/ 与 index.html
python3 tools/check_all.py       # 站点体检 + 各书检查脚本 + 单元测试
```

- `tools/check_site.py` 检查全站页面的链接、锚点、重复 id、注释按钮计数，并把所有文言书的悬停句对与源稿逐项比对。
- `check_zuozhuan.py`、`check_xianqing.py`、`check_roupotuan.py`、`check_four_classics.py`、`check_xiaochuang.py`、`check_canying.py` 等另外核对原文与缓存来源逐字一致、句数对齐、注释锚点。
- `*.pdf` 是本地底本，不入库（见 `.gitignore`）。
