# 古典文库

古典文献与白话小说的在线阅读站（静态网页，由 `build.py` 生成）：文言典籍原文在前，鼠标悬停（触屏点按）逐句显示自撰白话，每条或每段有折叠的题解和词条注释；白话小说、半白话戏曲直接读原文，只附基础注释。

## 书目与状态

首页另设“经典名篇”个人选藏，按加入顺序收录10篇完整文章，重复项合并。每篇独立成页，均有原文、逐句悬浮白话、折叠题解和注释；其中末两篇收王鏊、王守仁的制艺全文。6篇原文据维基文库，3篇沿用站内《古文观止》注译稿并参校维基文库；赵秉忠策文暂据其他电子本，疑似脱误处保留加注，尚待影像校勘。条目与来源见 `sources/classic_list/entries.json`，注译稿见 `src/classic_list/`。运行 `python3 tools/check_classics.py` 核对全文与逐句悬浮。

## 目录与源文件

- `src/<书>/<页>/…txt`：标注文本。`# 标题` 开始一节；可选 `题解：…`；每个原文段一行 `原：原文 || 白话¦白话…`（白话按句以 `¦` 对齐，诗词行用 `/` 分隔）；`注：词语：解释` 每个词条独占一行；空行分段。无白话的书只写 `原：` 与 `注：`。
- `sources/<书>/`：来源缓存（页面 JSON、版本号、SHA-256）、进度文件、整理说明。
- `build.py`：生成全部静态网页（首页搜索、各书目录、阅读页；页内目录、注释折叠、悬停提示）。
- `tools/`：来源抓取与整理脚本（`prepare_*.py`、`fetch_wikisource.py`），以及各书检查脚本。

## 构建与检查

```bash
python3 build.py                 # 生成网页
python3 tools/check_all.py       # 站点体检 + 各书检查脚本 + 单元测试
```

`tools/check_site.py` 检查全站页面的链接、锚点、重复 id、注释按钮计数，并把所有文言书的悬停句对与源稿逐项比对；`check_zuozhuan.py`、`check_xianqing.py`、`check_roupotuan.py`、`check_four_classics.py`、`check_xiaochuang.py`、`check_canying.py` 另外核对原文与缓存来源逐字一致、句数对齐、注释锚点。注：`*.pdf` 是本地底本，不入库（见 `.gitignore`）。
