《资治通鉴》卷二百五十八（唐纪七十四），起昭宗龙纪元年（公元八八九年），止大顺二年（公元八九一年），凡三年；记朱全忠灭秦宗权、王建围攻成都陈敬瑄、杨行密与孙儒争夺江淮，以及朝廷谋讨李克用的起因。

起屠维作噩，尽重光大渊献，凡三年。

  • 屠维作噩：岁阳岁阴纪年名，即己酉年，此指唐昭宗龙纪元年，公元八八九年。
  • 重光大渊献：即辛亥年，此指大顺二年，公元八九一年。

昭宗圣穆景文孝皇帝上之上龙纪元年（己酉，公元八八九年）

春，正月，癸巳朔，赦天下，改元。
以翰林学士承旨、兵部侍郎刘崇望同平章事。
汴将庞师古拔宿迁，军于吕梁。时溥逆战，大败，还保彭城。
壬子，蔡将郭璠杀申丛，送秦宗权于汴，告朱全忠云：“丛谋复立宗权。”全忠以璠为淮西留后。
戊申，王建大破山行章于新繁，杀获近万人，行章仅以身免。杨晟惧，徙屯三交，行章屯濛阳，与建相持。
二月，朱全忠送秦宗权至京师，斩于独柳。京兆尹孙揆监刑，宗权于槛车中引首谓揆曰：“尚书察宗权岂反者邪？但输忠不效耳。”观者皆笑。揆，逖之族孙也。
三月，加朱全忠兼中书令，进爵东平郡王。全忠既克蔡州，军势益盛。加奉国节度使赵德𬤇中书令，加蔡州节度使赵犨同平章事，充忠武节度使，以陈州为治所。会犨有疾，悉以军府事授其弟昶，表乞骸骨，诏以昶代为忠武节度使。未几，犨薨。丙申，钱𨱇拔苏州，徐约亡入海而死。钱镠以海昌都将沈粲权知苏州。

  • 癸巳朔：这一年正月初一为癸巳日。
  • 改元：改换年号，昭宗改年号为龙纪，这一年为龙纪元年（己酉，公元八八九年）。
  • 翰林学士承旨：翰林学士中资历最深者，常参与机要，人称内相。
  • 兵部侍郎：尚书省兵部的副长官。
  • 刘崇望：由翰林学士入相，后出为镇守一方的官员。
  • 庞师古：朱全忠部将，曹州人，后成为朱全忠的重要将领。
  • 宿迁：今江苏宿迁。
  • 吕梁：吕梁洪，在今江苏徐州东南的泗水上。
  • 彭城：即徐州，今江苏徐州，是时溥的治所。
  • 郭璠：蔡州秦宗权的部将，擒申丛降朱全忠。
  • 淮西留后：淮西即蔡州一带的节度使的代理人。
  • 三交：地名，在彭州一带，位置待考。
  • 濛阳：今四川彭州东，唐属彭州。
  • 独柳：长安处决死囚的刑场，因有一棵独立的柳树而得名。
  • 京兆尹：京兆府（治长安）的长官。
  • 孙揆：京兆尹，后奉命出任昭义节度使，被李存孝所擒杀。
  • 槛车：囚禁犯人的车。
  • 逖：孙逖，唐玄宗时人，任中书舍人，以文章著名，孙揆的族祖。
  • 东平郡王：朱全忠此时的封爵，东平郡在今山东东平一带。
  • 赵犨：陈州刺史，曾坚守陈州抗击秦宗权与黄巢，后任忠武节度使。
  • 忠武节度使：忠武军节度使，原治许州，此处改以陈州为治所。
  • 陈州：治今河南淮阳。
  • 乞骸骨：请求退休，古代大臣辞官的说法。
  • 薨：诸侯或二品以上大官去世的称呼。
  • 钱𨱇：钱镠的堂弟，用字待考。
  • 海昌都将：海昌军（治今浙江海宁）的都将，都将为一军的统帅。
  • 沈粲：钱镠部下，后来叛钱镠，投奔孙儒。

夏，四月，赐陕虢军号保义。
五月，甲辰，润州制置使阮结卒，钱镠以静江都将成及代之。
李克用大发兵，遣李罕之、李存孝攻孟方立，六月，拔磁、洺二州。方立遣大将马溉、袁奉韬将兵数万拒之，战于琉璃陂，方立兵大败，二将皆为所擒，克用乘胜进攻邢州。方立性猜忌，诸将多怨，至是皆不为方立用，方立惭惧，饮药死。弟摄洺州刺史迁，素得士心，众奉之为留后，求援于朱全忠。全忠假道于魏博，罗弘信不许。全忠乃遣大将王虔裕将精兵数百，间道入邢州共守。

  • 保义：陕虢军的军号。
  • 阮结：钱镠任命的润州制置使。
  • 静江：钱镠部下军名，此处作军号，具体所指待考。
  • 成及：钱镠部将，后被孙儒部将所逐。
  • 孟方立：昭义节度使，邢州人，与李克用的泽潞之争不断。
  • 磁、洺：磁州（今河北磁县）、洺州（今河北永年）。
  • 马溉、袁奉韬：孟方立的大将，兵败被李克用所擒。
  • 琉璃陂：地名，在邢州附近，位置待考。
  • 邢州：治今河北邢台。
  • 迁：孟迁，孟方立之弟，原摄洺州刺史，后降李克用。
  • 假道：向他人借路通过其辖境。

杨行密围宣州，城中食尽，人相啖，指挥使周进思据城困逐赵锽。锽将奔广陵。田𫖳追擒之。未几，城中执进思以降。行密入宣州，诸将争取金帛，徐温独据米囷，为粥以食饿者。温，朐山人也。锽将宿松周本，勇冠军中，行密获而释之，以为裨将。锽既败，左右皆散，惟李德诚从锽不去，行密以宗女妻之。德诚，西华人也。行密表言于朝，诏以行密为宣歙观察使。朱全忠与赵锽有旧，遣使求之。行密谋于袁袭，袭曰：“不若斩首以遗之。”行密从之。未几，袭卒，行密哭之曰：“天不欲成吾大功邪，何为折吾股肱也！吾好宽，而袭每劝我以杀，此其所以不寿与！”
孙儒遣兵攻庐州，蔡俦以州降之。

朱珍拔萧县，据之，与时浦相拒，朱全忠欲自往临之。珍命诸军皆葺马厩，李唐宾部将严郊独惰慢，军吏责之，唐宾怒，见珍诉之。珍亦怒，以唐宾为无礼，拔剑斩之，遣骑白全忠，云唐宾谋叛。淮南左司马敬翔，恐全忠乘怒，仓猝处置违宜，故留使者，逮夜，然后从容白之，全忠果大惊。翔因为画策，诈收唐宾妻子系狱，遣骑往慰抚，全忠从之，军中始安。秋，七月，全忠如萧县，未至，珍出迎，命武士执之，责以专杀而诛之。诸将霍存等数十人叩头为之请，全忠怒，以床掷之，乃退。丁未，至萧县，以庞师古代珍为都指挥使。八月，丙子，全忠进攻时溥壁，会大雨，引兵还。
冬，十月，平卢节度使王敬武薨。子师范，年十六，军中推为留后，棣州刺史张蟾不从。诏以太子少师崔安潜兼侍中，充平卢节度使。蟾迎安潜至州，与之共讨师范。
以给事中杜孺休为苏州刺史，钱镠不悦，以知州事沈粲为制置指挥使。
杨行密遣马步都虞候田𫖳等攻常州。

十一月，上改名晔。

  • 改名晔：皇上此前名李杰，后改名敏，现改为李晔。

上将祀圆丘。故事，中尉、枢密皆衣癸衫侍从。僖宗之世，已具襕笏。至是，又令有司制法服，孔纬及谏官、礼官皆以为不可，上出手札谕之曰：“卿等所论至当。事有从权，勿以小瑕，遂妨大礼。”于是宦官始服剑佩侍祠。己酉，祀圆丘，赦天下。上在籓邸，素疾宦官，及即位，杨复恭恃援立功，所为多不法，上意不平。政事多谋于宰相，孔纬、张濬劝上举大中故事，抑宦者权。复恭常乘肩舆至太极殿。他日，上与宰相言及四方反者，孔纬曰：“陛下左右有将反者，况四方乎！”上矍然问之，纬指复恭曰：“复恭陛下家奴，乃肩舆造前殿，多养壮士为假子，使典禁兵，或为方镇，非反而何！”复恭曰：“子壮士，欲以收士心，卫国家，岂反邪！”上曰：“卿欲卫国家，何不使姓李而姓杨乎？”复恭无以对。复恭假子天威军使杨守立，本姓胡，名弘立，勇冠六军，人皆畏之。上欲讨复恭，恐守立作乱，谓复恭：“朕欲得卿胡子在左右。”

朱全忠求领盐铁，孔纬独执以为不可，谓进奏吏曰：“朱公须此职，非兴兵不可！”全忠乃止。
田𫖳攻常州，为地道入城。中宵，旌旗甲兵出于制置使杜棱之寝室，遂虏之，以兵三万戍常州。

初，张濬因杨复恭以进，复恭中废，更附田令孜而薄复恭。及复恭再用事，深恨之。上知濬与复恭有隙，特亲倚之。濬亦以功名为己任，每自比谢安、裴度。克用之讨黄巢屯河中也，濬为都统判官。克用薄其为人，闻其作相，私谓诏使曰：“张公好虚谈而无实用，倾覆之士也。主上采其名而用之，他日交乱天下，必是人也。”濬闻而衔。上从容与濬论古今治乱，濬曰：“陛下英睿如此，而中外制于强臣，此臣日夜所痛心疾首也。”上问以当今所急，对曰：“莫若强兵以服天下。”上于是广募兵于京师，至十万人。

癸未，以永平节度使王建为西川节度使；甲申，废永平军。建既得西川，留心政事，容纳直言，好施乐士，用人各尽其才，谦恭俭素；然多忌好杀，诸将有功名者，多因事诛之。
杨复恭居第近玉山营，假子守信为玉山军使，数往省之。

  • 李顺节：天威军都将，一度得昭宗宠信。
  • 凤翔：凤翔节度使治所，今陕西凤翔，李茂贞据此。
  • 致仕：官员退休。
  • 上将军：武官散官名，授退职者的荣誉职衔。
  • 几杖：几案和手杖，古代敬老时所赐。
  • 护国节度使：即河中节度使，王重盈任。
  • 王重盈：王重荣之兄，继王重荣据河中。
  • 知留后：代理节度使事务。
  • 张筠：宿州刺史，降朱全忠部将丁会。
  • 永平节度使：治邛州（今四川邛崃），王建曾任此职。
  • 玉山营：长安城中禁军营名，杨复恭在此有宅邸。
  • 玉山军使：统领玉山营的军官。

或告复恭与守信谋反，乙酉，上御安喜门，陈兵自卫，命天威都将李顺节、神策军使李守节将兵攻其第。张绾帅家众拒战，守信引兵助之，顺节等不能克。丙戌，禁兵守含光门，俟其开，欲出掠两市，遇刘崇望，立马谕之曰：“天子亲在街东督战，汝曹皆宿卫之士，当于楼前杀贼立功，勿贪小利，自取恶名。”众皆曰：“诺。”遂从崇望而东。守信之众望见兵来，遂溃走。守信与复恭挈其族自通化门出，趣兴元，永安都头权安追之，擒张绾，斩之。复恭至兴元，杨守亮、杨守忠、杨守贞及绵州刺史杨守厚同举兵拒朝廷，以讨李顺节为名。守厚，亦复恭假子也。
李克用攻王镕，大破镇兵于龙尾岗，斩获万计，遂拔临城，攻元氏、柏乡；李匡威引幽州兵救之。

  • 安喜门：长安大明宫门之一，待考。
  • 天威都将：天威军的统帅。天威军为神策军以外的禁军。
  • 神策军使：神策军的高级军官。
  • 李守节：神策军使，事迹待考。
  • 含光门：长安城门名，位置待考。
  • 刘崇望：时任宰相，此次平乱中出面劝谕禁军。
  • 通化门：长安外郭城东面的城门。
  • 兴元：兴元府，今陕西汉中，山南西道治所。
  • 永安都头：永安军的低级统兵官。
  • 绵州：今四川绵阳。
  • 杨守厚：杨复恭义子，绵州刺史。
  • 王镕：成德节度使，镇州，赵王。
  • 龙尾岗：成德境内地名，在今河北井陉一带，待考。
  • 临城：今河北临城。
  • 元氏：今河北元氏。
  • 柏乡：今河北柏乡。
  • 李匡威：卢龙节度使，治幽州，后为其弟李匡筹所逐。

克用大掠而还，军于邢州。
十一月，曹州都将郭铢杀刺史郭词，降于朱全忠。
泰宁节度使朱瑾将万馀人攻单州。
乙丑，时溥将刘知俊帅众二千降于朱全忠。知俊，沛人，徐之骁将也。溥军自是不振。全忠以知俊为左右开道指挥使。
辛未，寿州将刘弘鄂恶孙儒残暴，举州降朱全忠。
十二月，乙酉，汴将丁会、张归霸与朱瑾战于金乡，大破之，杀获殆尽，瑾单骑走免。
天威都将李顺节恃恩骄横，出入常以兵自随。两军中尉刘景宣、西门君遂恶之，白上，恐其作乱。戊子，二人以诏召顺节，顺节入至银台门，二人邀顺节于仗舍坐语，供奉官似先知自后斩其首，从者大噪而出。

  • 邢州：今河北邢台。
  • 曹州：今山东菏泽曹县一带。
  • 郭词：曹州刺史，朱瑾部下。
  • 泰宁节度使：治兖州（今山东兖州），朱瑾任此职。
  • 朱瑾：泰宁节度使，治兖州，与朱瑄同盟，与朱全忠为敌。
  • 单州：今山东单县。
  • 时溥：感化（武宁）节度使，治徐州，朱全忠的对手。
  • 刘知俊：沛县人，原为时溥部将，后成为朱全忠的名将。
  • 沛：今江苏沛县。
  • 左右开道指挥使：开路先锋的统领官职。
  • 寿州：今安徽寿县。
  • 刘弘鄂：寿州将，待考。
  • 金乡：今山东金乡。
  • 两军中尉：左右神策军中尉，皆由宦官担任。
  • 刘景宣：宦官，右神策中尉。
  • 西门君遂：宦官，左神策军中尉。
  • 银台门：大明宫西面的门，通向翰林学士院一带。
  • 仗舍：宫中值班卫兵的房舍。
  • 供奉官：宦官担任的宫中近侍官。
  • 似先知：人名，供奉官，姓似先，名知。

于是天威、捧日、登封三都大掠永宁坊，至暮乃定，百官表贺。
孙儒焚掠苏、常，引兵逼宣州，钱镠复遣兵据苏州。儒屡破杨行密之兵，旌旗辎重亘百馀里。行密求救于钱镠，镠以兵食助之。
以顾彦晖为东川节度使，遣中使宋道弼赐旌节。杨守亮使杨守厚囚道弼，夺其旌节，发兵攻梓州。癸卯，彦晖求救于王建；甲辰，建遣其将华洪、李简、王宗侃、王宗弼救东川。建密谓诸将曰：“尔等破贼，彦晖必犒师，汝曹于行营报宴，因而执之，无烦再举。”宗侃破守厚七砦，守厚走归绵州。彦晖具犒礼，诸将报宴，宗弼以建谋告之，彦晖乃以疾辞。
初，李茂贞养子继臻据金州，均州刺史冯行袭攻下之，诏以行袭为昭信防御使，治金州。

  • 捧日：与天威、登封同为当时的禁军番号，具体建置待考。
  • 永宁坊：长安的里坊名，在城东北，待考。
  • 钱镠：杭州一带的军阀，后建吴越国。
  • 中使：宫中派出的使者，多指宦官。
  • 宋道弼：宦官，朝廷派到东川的使者。
  • 梓州：今四川三台，东川节度使治所。
  • 华洪：王建义子，后改名王宗涤，待考。
  • 王宗侃：王建的族人或义子，随王建作战，事迹见后文。
  • 王宗弼：王建义子，原名魏弘夫。
  • 犒师：慰劳军队。
  • 砦：同“寨”，营寨。
  • 李茂贞：凤翔节度使，原名宋文通，赐名茂贞。
  • 金州：今陕西安康。
  • 冯行袭：均州刺史，后任昭信防御使，据金州。
  • 昭信防御使：治金州，冯行袭任。

杨守亮欲自金、商袭京师，行袭逆击，大破之。
是岁，赐泾原军号曰彰义，增领渭、武二州。福建观察使陈岩疾病，遣使以书召泉州刺史王潮，欲授以军政，未至而岩卒。岩妻弟都将范晖讽将士推己为留后，发兵拒潮。

  • 泾原军：泾原节度使，治泾州（今甘肃泾川北）。
  • 彰义：泾原军新赐的军号，意在表彰其忠义。
  • 渭：渭州，今甘肃平凉一带。
  • 福建观察使：治福州（今福建福州）。
  • 陈岩：福建观察使，福州人，后其妻弟范晖夺其位。
  • 泉州：今福建泉州。
  • 王潮：光州固始人，王审知之兄，后据福建，为闽国奠基者。
  • 范晖：陈岩的妻弟，任都将。
