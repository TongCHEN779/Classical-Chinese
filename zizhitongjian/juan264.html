卷首

本卷记唐昭宗天复三年二月至天祐元年闰月前后的史事：朱全忠迎昭宗还长安，尽诛宦官，崔胤借其力专权，随后全忠杀崔胤、劫昭宗迁都洛阳，唐室名存实亡。

起昭阳大渊献二月，尽阏逢困敦闰月，凡一年有奇。

  • 昭阳大渊献：岁阳岁阴纪年，昭阳为癸，大渊献为亥，即癸亥年，唐昭宗天复三年（公元903年）。
  • 阏逢困敦：阏逢为甲，困敦为子，即甲子年，唐昭宗天祐元年（公元904年）。
  • 闰月：天祐元年闰四月。

昭宗圣穆景文孝皇帝下之上天复三年（癸亥，公元九零三年）

二月，壬申朔，诏：“比在凤翔府所除官，一切停。”时宦官尽死，淮河东监军张承业、幽州监军张居翰、清海监军程匡柔、西川监军鱼全禋及致仕严遵美，为李克用、刘仁恭、杨行密、王建所匿得全，斩他囚以应诏。
甲戌，门下侍郎、同平章事陆扆责授沂王傅、分司。车驾还京师，赐诸道诏书，独凤翔无之。扆曰：“茂贞罪虽大，然朝廷未与之绝，今独无诏书，示人不广。”崔胤怒，奏贬之。宫人宋柔等十一人皆韩全诲所献，及僧、道士与宦官亲厚者二十馀人，并送京兆杖杀。
上谓韩偓曰：“崔胤虽尽忠，然比卿颇用机数。”对曰：“凡为天下者，万国皆属之耳目，安可以机数欺之！莫若推诚直致，虽日计之不足，而岁计之有馀也。”

  • 壬申朔：朔为每月初一。天复三年二月初一为壬申日。
  • 诏：皇帝下达的文告。
  • 凤翔府：治所在今陕西凤翔，李茂贞的根据地，昭宗曾被劫持于此。
  • 张承业：宦官，时任河东监军，受李克用信任。“淮河东”疑“淮”为衍字，待考。
  • 监军：朝廷派驻藩镇或军队的监督官，多由宦官担任。
  • 致仕：官员退休。
  • 同平章事：唐代宰相的名号，加此衔者即为宰相。
  • 沂王傅：沂王的师傅，多为闲散官位。
  • 分司：在东都洛阳任闲散官职，称分司。
  • 崔胤：唐末宰相，借朱全忠之力诛宦官。
  • 韩全诲：宦官首领，曾与李茂贞劫持昭宗，已被诛。
  • 韩偓：字致尧，时任翰林学士，昭宗亲信。
  • 机数：权术、心计。

丙子，工部侍郎、同平章事苏检，吏部侍郎卢光启，并赐自尽。丁丑，以中书侍郎、同平章事王溥为太子宾客、分司，皆崔胤所恶也。戊寅，赐朱全忠号回天再造竭忠守正功臣，赐其僚佐敬翔等号迎銮协赞功臣，诸将朱友宁等号迎銮果毅功臣，都头以下号四镇静难功臣。上议褒崇全忠，欲以皇子为诸道兵马元帅，以全忠副之。崔胤请以辉王祚为之，上曰：“濮王长。”胤承全忠密旨，利祚冲幼，固请之。己卯，以祚为诸道兵马元帅。庚辰，加全忠守太尉，充副元帅，进爵梁王。以胤为司徒兼侍中。胤恃全忠之势，专权自恣，天子动静皆禀之。朝臣从上幸凤翔者，凡贬逐三十馀人。刑赏系其爱憎，中外畏之，重足一迹。以敬翔守太府卿，朱友宁领宁远节度使。全忠表苻道昭同平章事，充天雄节度使，遣兵援送之秦州，不得至而还。

  • 苏检：昭宗朝宰相，曾与韩全诲一方相通，故被赐死。
  • 王溥：唐末宰相，非后来北宋的王溥。
  • 回天再造竭忠守正功臣：朱全忠得到的功臣名号，功臣号是唐后期给有功将帅的荣衔。
  • 敬翔：朱全忠的主要谋士，后任梁朝宰相。
  • 朱友宁：朱全忠之侄，朱全忠兄朱存之子。
  • 迎銮：迎接皇帝车驾，指朱全忠从凤翔迎回昭宗。
  • 都头：军队中统领一队的低级将领。
  • 诸道兵马元帅：名义上统率各道兵马的最高统帅，多由亲王遥领。
  • 辉王祚：昭宗之子李祚，后即位为昭宣帝（哀帝），改名柷。
  • 濮王：昭宗年长之子，具体指谁待考。
  • 守太尉：官品较低者任较高官职称“守”。太尉为三公之一，此时多为荣衔。
  • 梁王：朱全忠所封爵位，后以此为国号建后梁。
  • 重足一迹：形容极为恐惧，叠足而立，不敢迈步。
  • 太府卿：太府寺长官，掌国库财货。
  • 宁远节度使：宁远军治容州，为遥领的虚衔，待考。
  • 苻道昭：李茂贞旧部，时附朱全忠，被授天雄节度使。
  • 天雄节度使：天雄军治秦州，今甘肃天水。

初，翰林学士承旨韩偓之登进士第也，御史大夫赵崇知贡举。上返自凤翔，欲用偓为相，偓荐崇及兵部侍郎王赞自代。上欲从之，崔胤恶其分己权，使朱全忠入争之。全忠见上曰：“赵崇轻薄之魁，王赞无才用，韩偓何得妄荐为相！”上见全忠怒甚，不得已，癸未，贬偓濮州司马。上密与偓泣别，偓曰：“吻人非复前来之比，臣得远贬及死乃幸耳，不忍见篡弑之辱！”
己丑，上令朱全忠与李茂贞书，取平原公主。茂贞不敢违，遽归之。
壬辰，以朱友裕为镇国节度使。

  • 翰林学士承旨：翰林学士中居首者，常参与机密，相当于宰相预备。
  • 赵崇：字象贤，唐末官员，时任御史大夫。
  • 知贡举：主持科举考试。
  • 王赞：唐末官员，后在梁朝为相。
  • 司马：州刺史的佐官，唐后期多为贬官的闲职。
  • 濮州：今山东鄄城一带。
  • 吻人：疑有讹误，待考，大意似指当时之人。
  • 平原公主：昭宗之女，曾被李茂贞留在凤翔。
  • 朱友裕：朱全忠长子，时任镇国节度使。
  • 镇国节度使：治华州，今陕西华县。

乙未，全忠奏留步骑万人于故两军，以朱友伦为左军宿卫都指挥使，又以汴将张廷范为宫苑使，王殷为皇城使，蒋玄晖充街使。于是全忠之党布列遍于禁卫及京辅。戊戌，全忠辞归镇，留宴寿春殿，又饯之于延喜楼。上临轩泣别，令于楼前上马。上又赐全忠诗，全忠亦和进；又赐《杨柳枝辞》五首。百官班辞于长乐驿。崔胤独送至霸桥，自置饯席，夜二鼓，胤始还入城。上复召对，问以全忠安否，置酒奏乐，至四鼓乃罢。
以清海节度使裴枢为门下侍郎、同平章事，朱全忠荐之矣。
李克用使者还晋阳，言崔胤之横，克用曰：“胤为人臣，外倚贼势，内胁其君，既执朝政，又握兵权。权重则怨多，势侔则衅生，破家亡国，在眼中矣。”朱全忠将行，奏：“克用于臣，本无大嫌，乞厚加宠泽，遣大臣抚慰；俾知臣意。”进奏吏以白克用，克用笑曰：“贼欲有事淄青，畏吾掎其后耳！”

  • 故两军：指原来的左右神策军，宦官被诛后其军被解散。
  • 宿卫都指挥使：统领宫禁宿卫的将领。
  • 汴将：汴州（宣武军）的将领，指朱全忠部下。
  • 宫苑使：掌管宫苑的使职。
  • 皇城使：掌管皇城守卫的使职。
  • 街使：掌管京城街巷巡查治安的使职。
  • 京辅：京城附近地区。
  • 寿春殿：长安宫中殿名，待考。
  • 延喜楼：长安宫城的楼名，昭宗曾在此饯送朱全忠，后又在此看迁都之事。
  • 长乐驿：在长安东郊，近灞水，为送别之处。
  • 霸桥：即灞桥，在长安东，跨灞水。
  • 二鼓：即二更，约夜里九至十一点。
  • 裴枢：唐末宰相，后在白马驿被朱全忠杀害。
  • 清海节度使：治广州，管岭南一带。
  • 晋阳：今山西太原，河东节度使驻地。
  • 李克用：河东节度使，晋王。
  • 进奏吏：藩镇驻京进奏院的官吏，负责传递文书。
  • 淄青：指淄青平卢军王师范的辖地，治青州。
  • 掎：从后牵制。

三月，戊午，朱全忠至大梁。王师范弟师鲁围齐州，朱友宁引兵击走之。师范遣兵益刘𬩽军，友宁击取之。由是兖州援绝，葛从周引兵围之。友宁进攻青州；戊辰，全忠引四镇及魏博兵十万继之。
淮南将李神福围鄂州，望城中积荻，谓监军尹建峰曰：“今夕为公焚之。”建峰未之信。时杜洪求救于朱全忠，神福遣部将秦皋乘轻舟至滠口，举火炬于树杪。洪以为救兵至，果焚获以应之。
夏，四月，己卯，以朱全忠判元帅府事。
知温州事丁章为木工李彦所杀，其将张惠据温州。
王师范求救于淮南，乙未，杨行密遣其将王茂章以步骑七千救之，又遣别将将兵数万攻宿州。全忠遣其将康怀英救宿州，淮南兵遁去。
杨行密遣使诣马殷，言朱全忠跋扈，请殷绝之，约为兄弟。湖南大将许德勋曰：“全忠虽无道，然挟天子以令诸侯，明公素奉王室，不可轻绝也。”殷从之。

  • 大梁：即汴州，今河南开封，宣武军治所，朱全忠根据地。
  • 王师范：平卢（淄青）节度使，据青州，反对朱全忠。
  • 齐州：今山东济南一带。
  • 刘𬩽：王师范部将，时据兖州，后降朱全忠。
  • 兖州：泰宁军治所，今山东兖州。
  • 葛从周：朱全忠部将，宿将。
  • 四镇：指朱全忠兼领的宣武、宣义、天平、护国四镇。
  • 魏博：魏博节度使，治魏州，今河北大名一带，当时附朱全忠。
  • 李神福：杨行密部将，时领兵攻鄂州。
  • 鄂州：今湖北武汉武昌，武昌军治所，杜洪据守。
  • 尹建峰：淮南军派驻的监军，待考。
  • 滠口：滠水入长江之口，在今湖北武汉黄陂一带。
  • 获：疑为“荻”之讹，荻为一种水边草，此处指前文积存的荻草。
  • 判元帅府事：主持元帅府事务。
  • 温州：今浙江温州。
  • 宿州：今安徽宿州。
  • 康怀英：朱全忠部将，后封泰宁节度使。
  • 马殷：湖南武安军节度使，后建楚国。
  • 挟天子以令诸侯：典出汉末曹操，此处指朱全忠控制昭宗。
  • 许德勋：马殷大将，时领湖南兵。

杜洪求救于朱全忠，全忠遣其将韩勍将万人屯滠口，遣使语荆南节度使成汭、武安节度使马殷、武贞节度使雷彦威，令出兵救洪。汭畏全忠之强，且欲侵江、淮之地以自广，发舟师十万，沿江东下。汭作巨舰，三年而成，制度如府署，谓之“和州载”，其馀谓之“齐山”、“截海”、“劈浪”之类甚众。掌书记李珽谏曰：“今每舰载甲士千人，稻米倍之，缓急不可动也。吴兵剽轻，难与角逐；武陵、长沙，皆吾仇也；岂得不为反顾之虑乎！不若遣骁将屯巴陵，大军与之对岸，坚壁勿战，不过一月，吴兵食尽自遁，鄂围解矣。”汭不听。珽，澄之五世孙也。

  • 韩勍：朱全忠部将。
  • 成汭：荆南节度使，据江陵，原为淮西蔡州军人，后割据荆州。

  • 舟师：水军。
  • 和州载：成汭所造巨舰之名，待考其含义。
  • 齐山：战舰名，成汭所造，名称取义待考。
  • 掌书记：节度使幕府中掌管文书的官员。
  • 李珽：成汭的掌书记，其五世祖为李澄。
  • 吴兵：指杨行密的淮南军，杨行密封吴王。
  • 武陵：即朗州，今湖南常德，雷彦威据守。
  • 长沙：指潭州，马殷据守。
  • 巴陵：即岳州，今湖南岳阳。
  • 澄：唐德宗朝的将领，曾任义成等镇节度使，待核。

王建出兵攻秦、陇，乘李茂贞之弱也，遣判官韦庄入贡，亦修好于朱全忠。全忠遣押牙王殷报聘，建与之宴。殷言：“蜀甲兵诚多，但乏马耳。”建作色曰：“当道江山险阻，骑兵无所施。然马亦不乏，押牙少留，当共阅之。”乃集诸州马，大阅于星宿山，官马八千，私马四千，部队甚整。殷叹服。建本骑将，故得蜀之后，于文、黎、维、茂州市胡马，十年之间，遂及兹数。
五月，丁未，李克用云州都将王敬晖杀刺史刘再立，叛降刘仁恭。克用遣李嗣昭、李存审将兵讨之。仁恭遣将以兵五万救敬晖，嗣昭退保乐安，敬晖举众弃城而去。先是，振武将契苾让逐戍将石善友，据城叛。嗣昭等进攻之，让自燔死。复取振武城，杀吐谷浑叛者二千馀人。克用怒嗣昭、存审失王敬晖，皆杖之，削其官。

  • 秦、陇：秦州（今甘肃天水）、陇州（今陕西陇县），当时属李茂贞势力范围。
  • 韦庄：晚唐诗人，时入王建幕府，后为前蜀宰相。
  • 押牙：即押衙，节度使亲信武官。
  • 报聘：回访，回礼的使者。

  • 文、黎、维、茂州：均在今四川西北、甘肃南部山区，为蜀地西北边州，与胡人交易马匹。
  • 胡马：北方或西部民族所产之马。
  • 云州：今山西大同，李克用所领。
  • 王敬晖：云州都将，叛李克用投刘仁恭。
  • 刘仁恭：卢龙节度使，据幽州，原为李克用部下，后反目。
  • 李嗣昭：李克用养子，河东名将。

甲子，车驾至华州，民夹道呼万岁，上泣谓曰：“勿呼万岁，朕不复为汝主矣！”馆于兴德宫，谓侍臣曰：“鄙语云：‘纥干山头冻杀雀，何不飞去生处乐。”朕今漂泊，不知竟落何所！”因泣下沾襟，左右莫能仰视，二月，乙亥，车驾至陕，以东都宫室未成，驻留于陕。丙子，全忠自河中来朝，上延全忠入寝室见何后，后泣曰：“自今大家夫妇委身全忠矣！”
甲申，立皇子祯为端王，祁为丰王，福为和王，禧为登王，祐为嘉王。
上遣间使以御札告难于王建，建以邛州剌史王宗祐为北路行营指挥使，将兵会凤翔兵迎车驾，至兴平，遇汴兵，不得进而还。建始自用墨制除官，云“俟车驾还长安表闻。”

  • 兴德宫：华州行宫，昭宗曾驻此，待考。
  • 鄙语：俗语，民间谚语。
  • 纥干山头冻杀雀：北方民间歌谣，意思是不如飞到温暖处，昭宗借此自喻漂泊，出处待考。
  • 陕：陕州，今河南三门峡陕州区。
  • 何后：昭宗皇后何氏，后被朱全忠一党所迫，终被弑。
  • 大家：宫中对皇帝的称呼。
  • 端王：李祯，昭宗之子，王号。
  • 间使：秘密派遣的使者。
  • 御札：皇帝的亲笔书信。
  • 邛州：今四川邛崃。
  • 剌史：当为“刺史”之讹，州长官。
  • 王宗祐：王建养子，名宗祐，待考其事。
  • 北路行营指挥使：此次出兵的北路统军官。
  • 兴平：今陕西兴平，在长安以西。
  • 墨制：不经皇帝而由藩镇自行用墨书发出的任命文书，以别于皇帝的“朱书”。

三月，丁未，以朱全忠兼判左、右神策及六军诸卫事。癸丑，全忠置酒私第，邀上临幸。乙卯，全忠辞上，先赴洛阳督修宫室。上与之宴群臣，既罢，上独留全忠及忠武节度使韩建饮，皇后出，自捧玉卮以饮全忠，晋国夫人可证附上耳语。建蹑全忠足，全忠以为图己，不饮，阳醉而出。全忠奏以长安为佑国军，以韩建为佑国节度使，以郑州刺史刘知俊为匡国节度使。丁巳，上复遣间使以绢诏告急于王建、杨行密、李克用等，令纠帅籓镇以图匡复，曰：“朕至洛阳，则为所幽闭，诏敕皆出其手，朕意不复得通矣！”
杨行密遣钱传撩及其妇并顾全武归钱塘。以淮南行军司马李神福为鄂岳招讨使，复将兵击杜洪。朱全忠遣使诣行密，请舍鄂岳，复修旧好。行密报曰：“俟天子还长安，然后罢兵修好。”

  • 神策：神策军，唐后期中央主力禁军，原由宦官掌管，此时由朱全忠兼判。
  • 私第：私人的住宅。
  • 韩建：原据华州，曾劫持昭宗，后归附朱全忠，时任忠武节度使。
  • 忠武节度使：忠武军治许州，今河南许昌。
  • 晋国夫人可证：昭宗宫中女官，被封晋国夫人，名可证。
  • 蹑：踩。
  • 佑国军：长安升格为佑国军，即京兆设镇。
  • 郑州：今河南郑州。
  • 刘知俊：朱全忠大将，后因故叛梁投岐。
  • 匡国节度使：匡国军治同州，今陕西大荔。
  • 绢诏：写在绢帛上的密诏，便于缝藏传递。
  • 纠帅：纠合率领。
  • 匡复：挽救并恢复王室。
  • 钱传撩：疑为钱传璙之误，钱镠之子，曾为质于淮南。
  • 顾全武：钱镠大将，曾被杨行密所扣。
  • 钱塘：今浙江杭州，钱镠根据地。
  • 鄂岳招讨使：负责讨伐鄂州、岳州的统军官。
  • 杜洪：武昌节度使，占据鄂州。
  • 舍鄂岳：放弃鄂州、岳州。

夏，四月，辛巳，朱全忠奏洛阳宫室已成，请车驾早发，表章相继。上屡遣宫人谕以皇后新产，未任就路，请俟十月东行。全忠疑上徘徊俟变，怒甚，谓牙将寇彦卿曰：“汝速至陕，即日促官家发来。”闰月，丁酉，车驾发陕。壬寅，全忠逆于新安。上之在陕也，司天监奏：“星气有变，期在今秋，不利东行。”故上欲以十月幸洛。至是，全忠令医官许昭远告医官使阎祐之、司天监王墀、内都知韦周、晋国夫人可证等谋害元帅，悉收杀之。
癸卯，上憩于谷水。自崔胤之死，六军散亡俱尽，所馀击球供奉、内园小儿共二百馀人，从上而东。全忠犹忌之，为设食于幄，尽缢杀之。豫选二百馀人大小相类者，衣其衣服，代之侍卫。上初不觉，累日乃寤。自是上之左右职掌使令皆全忠之人矣。甲辰，车驾发谷水，入宫，御正殿，受朝贺。乙巳，御光政门，赦天下，改元。更命陕州曰兴唐府。诏讨李茂贞、杨崇本。

  • 官家：对皇帝的俗称。
  • 闰月：天祐元年闰四月。
  • 新安：今河南新安，在洛阳以西。
  • 司天监：掌天文历法和占星的官署。
  • 医官使：翰林医官院的长官。
  • 内都知：宦官机构中的官名，掌内廷事务，待考。
  • 元帅：指朱全忠，时任诸道兵马元帅府的副元帅，或相关称呼，待考。
  • 谷水：水名，流经洛阳，此处指谷水驿或其附近，待考。
  • 击球供奉：宫中陪皇帝打马球的侍从。
  • 内园小儿：宫中内园的少年侍从。
  • 缢：勒死。
  • 光政门：洛阳宫的门名，待考。
  • 改元：改年号，此次改为天祐。
  • 兴唐府：陕州升府后的名称。

戊申，敕内诸司惟留宣徽等九使外，馀皆停废，仍不以内夫人充使。以蒋玄晖为宣徽南院使兼枢密使，王殷为宣徽北院使兼皇城使，张廷范为金吾将军、充街使，以韦震为河南尹兼六军诸卫副使，又征武宁留后朱友恭为左龙武统军，保大节度使氏叔琮为右龙武统军，典宿卫，皆全忠之腹心也。癸丑，以张全义为天平节度使。乙卯，以全忠为护国、宣武，宣义、忠武四镇节度使
镇海、镇东节度使越王钱镠求封吴越王，朝廷不许。朱全忠为之言于执政，乃更封吴王。
更命魏博曰天雄军。癸亥，进天雄节度使长沙郡王罗绍威爵邺王。

  • 内诸司：宫内各官署，多由宦官主管。
  • 宣徽：宣徽院，掌宫廷供奉事务，长官称宣徽使，分南、北院。
  • 内夫人：宫中女官，不应再担任使职。
  • 蒋玄晖：朱全忠亲信，时任枢密使，后参与弑昭宗。

  • 左龙武统军：龙武军为禁军，统军为长官。
  • 氏叔琮：朱全忠部将，后因弑昭宗被杀。
  • 天平节度使：天平军治郓州，今山东东平。
  • 忠武：忠武军，治许州，朱全忠兼领。
  • 宣义：宣义军，治滑州，今河南滑县。
  • 镇海、镇东节度使：钱镠兼领，镇海治润州（一说杭州），镇东治越州，待考。

  • 魏博：魏博节度使，治魏州，今河北大名。
