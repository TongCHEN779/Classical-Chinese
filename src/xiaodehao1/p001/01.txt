# 自叙
原：人性皆善，要知世无不好之人。其人之不好者，总由物欲昏蔽，俗习熏陶，染成痼疾，医药难痊。墨子之悲，深可痛也。即有贤者，虽以嘉言法语，大声疾呼，奈何迷而不悟，岂独不警于心，更且不入于耳。此则言如不言，彼则听如不听，真堪浩叹哉！正言闻之欲睡，笑话听之恐后，今人之恒情。夫即以正言训之而不听，曷若以笑话怵之之为得乎？予乃著笑话书一部，评列警醒，令读者凡有过愆、偏私、朦昧、贪痴之种种，闻予之笑，悉皆惭愧改，俱得成良善之好人矣。因以笑得好三字名其书。或有怪予立意虽佳，但语甚克毒，令闻者难当，未免破笑成怒，大非圣言含蕴之比，岂不以美意而种恨因乎？予谓沉疴痼疾，非用猛药，何能起死回生？若听予之笑，不自悔改，而反生愁恨者，是病已垂危，医进良药，尚迟疑不服，转咎药性之猛烈，思欲体健身安，何可得哉？但愿听笑者入耳警心，则人性之天良顿复，遍地无不好之人，方知克毒语言，有功于世者不小。全要闻笑即愧即悔，是即学好之人也。石成金天基撰。

# 虑二百岁寿诞
原：一老人富贵兼全，子孙满堂。百岁寿日，贺客填门。老人攒眉，似有不乐。众问：如此全福，尚有何忧？老人曰：各样都不愁，只愁我后来过二百岁寿诞，来贺的人更添几千几百，教我如何记得清？
原：二百年后，几千几百人来贺者，逐个如何迎送、如何款待、如何答谢，也要预先愁虑，才不痴迷？

# 屎攘心窝
原：龙为百虫之长，一日发令，查虫中有三个名的，都要治罪。蚯蚓与蛆同去躲避。蛆问：“蚯蚓，你如何有三个名？”蚯蚓曰：“那识字的叫我为蚯蚓，不识字的叫我为曲蟮，乡下愚人又叫我作寒现，岂不是三个名？”蚯蚓问蛆曰：“你有的那三个名也？说与我知道。”蛆曰：“我有一名蛆，一名谷䖝，又称我读书相公。”蚯蚓曰：“你既是读书相公，你且把书上的仁义道德讲讲与我听。”蛆愁眉说曰：“我如今因为屎攘了心窝子，那书上的仁义道德一些，总不晓得了。”
原：书上载的仁义道德，俱是圣贤教训嘉言，应该力行，为何不行？非屎迷心而何？予见世间不读书的，还有行仁义道德；偏偏是读书人，行起事来，说起话来，专一瞒心昧己，歪著肚肠，同人混赖。所以叫吃屎的蛆为相公就是此义。说之不改，变蛆无疑。

# 宁可为娼妇
原：有一光棍，专会镟诈良善。乡里诈遍，又想诈掯娼妇。娼家未遂其欲，即写了状子，告他引诱良家子弟，败坏风俗，官准拘审问。官曰：“娼妇虽是下贱，远来孤客、久旷鳏夫，都亏他陪宿，还有些好处；不似你这光棍，到处欺负良善，无风生浪，平地陷人。叫皂隶代我重责四十，枷号示众。”顶枷出来，因有个儿子来看他，就大声叫曰：“我的儿，从今后，宁可叫你妈妈做娼妇，切莫要生事害人！”
原：世有一等人，专好唆人争斗，起人讼事，无端诈害良善。妻女淫报，必然之理。急急改悔，尤嫌迟也。

# 扣除二两一夜
原：一翁慈善好施，因大雪，见一人避于门檐，怜而延入，暖酒敌寒，遂留一宿。次日雪大，又留之。如是三日天晴，此人将别去，因向翁借刀。翁取刀出，其人持刀，谓翁曰：“素不相识，承此厚情，惟有杀此身以报。”翁惊止之，曰：“如此则害我矣。”其人曰：“何所害？”翁曰：“家中死了一个人，一些无事烧埋钱也得十二两，零碎尚多使费。”其人曰：“承翁好意，不好算这许多使费，竟拿烧埋银十二两与我去罢。”翁大怒喧嚷，惊动邻里，为之解劝。处其半，以六两与之。临去，翁叹曰：“谁想遇着这等没良心的人！”其人曰：“不说自己没良心，到说我没良心？”翁曰：“如何是我没良心？”其人点头曰：“你既有良心，止不过留得我三夜，就不该扣除我二両一夜了。”
原：人都说此人恩将仇报，良心丧尽，殊不知世间的事，大而论之，朝廷设官分理，坐高堂，骑大马，俸禄供给，封妻荣子，原是要你爱养百姓、劝善惩恶、兴利除害的，岂知有等人全不念恩，终日以贪酷为能，蠹国害民，到只恨官卑俸少，还要侵欺钱粮，岂不是大负皇恩么？人家养子，十月怀胎，三年乳哺，抚养教导，不知费了多少心力。巴得成人长大，原指望同心创家、养老送终的，岂知有等人不感恩，只恨爹娘少挣下家财；不肯任他浪费，反以父母拘管为雠，只图自己快乐，养生送死之事俱不用心，岂不是大负亲恩么？大抵人心欺负，天理自然难容，反而思之，真正可叹可伤、可笑可哭。

# 黑齿妓白齿妓
原：有二娼妓，一妓牙齿生得乌黑，一妓牙齿生得雪白。一欲掩黑，一欲显白。有人问齿黑者姓甚，其妓将口谨闭，鼓一鼓，在喉中答应“姓顾”。问多少年纪，又鼓起腮答“年十五”。问能甚的，又在喉中答“会敲鼓”。又问齿白者何姓，其妓将口一龇〈音资〉，答“姓秦”。问青春几岁，口又一龇，答“年十七”。问会做什么事，又将口一大龇，白齿尽路，说道“会弹琴”。
原：今人略有坏事，就多方遮掩，略有好事，就逢人卖弄。如此二娼者，正自不少。最可笑者，才有些银钱，便满脸堆富；才读得几句书，便到处批评人，显得自己大有才学；才做得几件平常事，便夸张许多能干。看起来总是此齿白之娼妓也。

# 剩个穷花子与我
原：张、李二人同行，见一抬轿富翁，许多奴仆，张遂拉李向人家门后躲避，曰：“此轿中坐的是我至亲，我若不避，他就要下轿行礼，彼此劳动费事。”李曰：“这是该的。”避过，复同前行。少顷，见一骑马顕者，衣冠齐整，从役多人。张又拉李向人家门后回避，曰：“这马上骑的是我自幼极厚的好友，我若不避，他见我就要下马见礼，彼此劳动费事。”李曰：“这也是应该的，避过复同你行。”偶然见乞丐花子破衣破帽的叫化走来，李乃拉张向人家门后躲避，曰：“此穷花子是我至亲，又是我好友，我要回避他，不然他看见我不面愧？”张骇然间曰：“你怎么有这样亲友？”李曰：“但是富贵好些的，都是你拣了去，只好剩个穷花子与我混混。”
原：向人说与富贵人如何往来，如何厚密，是大没见识人。即亲友中真有富贵者，频对人说，亦惹人厌谤，何况更有假言诳说的，大为可耻。

# 愿变父亲
原：一富翁呼欠债人到家，吩咐说：“你们如果赤贫无还，可对我罚誓你来生如何偿还，我就焚券不要。”一债少人曰：“我愿来生変马与主人骑坐，以还宿债。”翁点头，将借帖烧了。又中等欠户曰：“我愿来生変牛代主人出力，耕田耙地，以还宿债。”翁点头，亦将借帖烧了。最后一债多人曰：“我愿来生変你的父亲还债。”翁大怒曰：“你欠我许多银子，除不偿还，反要讨我便宜，是何道理？”正要打骂，其人曰：“听我实告，我所欠的债极多，不是变牛变马就可以还得完的。我所以情愿来生变你的父亲，劳苦一世，不顾身命，积成若大的田房家业，自己不肯享用，尽数留与你快活受用，岂不可以还你的宿债么？”
原：古人有“枉代儿孙作马牛”之句。世上有等愚人，年纪已老，兀自劳苦，不了总为子孙后来快活受用，非是前生该他许多宿债，焉能如此甘心偿还？可见千真万确，莫把予言作笑话看过。子孙若有贤良守成者，犹感念父祖创业之艰难；若遇不肖子孙嫖赌浪费，只恨父祖监察，不肯任其挥洒，一旦脚直，家业如滚汤泼雪，深为可叹。为父祖明知此理，却不肯看破，行些好事，积些阴德，尚锱铢必较，岂不愚而又愚，真马牛之不若也。

# 还要我的饭吃
原：有父子分居几年，子有馀钱，父因老病不能挣家，贫为乞丐。适过子门，有识者指父问子曰：“此人想必不是你的父亲么？如何全不顾他？”子曰：“我虽然是他生的，我而今除不要他的饭吃就彀了；难道他自己的饭，还想要我与他吃么？”
原：世人虽无此等不孝，然而供给不敬者颇有其人。

# 称儿子
原：父子同行，有不知者指子问曰：“此位何人？”父答曰：“此人虽然是朝廷极宠爱吏部尚书真正外孙第九代的嫡亲女婿却是我生的儿子〈三十三字要一气说〉。”
原：胸中有一盘香，贵亲随口，定要说出，总不觉羞。

# 题呼
原：有一王婆家富而矜夸，欲题寿材，厚赠道士，须多着好字，为里党光。道士思想，并无可称，乃题曰“翰林院侍讲大学士国子监祭酒隔壁王婆婆之柩”。
原：世人每好借贵，殊不知大讨人笑话。

# 相法不准
原：有人问相者曰：“你向来相法十分灵验，而今的相法因何一些不应？”相者蹙额曰：“今昔心相，有所不同：昔人凡遇方面大头的，必定富贵；而今遇方面大头的，反转落寞；惟是尖头尖嘴的，因他专会钻刺，倒得富贵。叫我如何相得准？”
原：主试者若非铁面冰心，巴不得人人会来钻刺。

# 让鼠蜂
原：鼠与蜂结为兄弟，请一秀才主盟。秀才不得已而往，列之行三。人问曰：“公何以屈于鼠辈之下？”秀才答曰：“他両个一个会钻，一个会刺，我只得让他些罢。”
原：不会钻刺的，才是个真秀才。

# 看写缘簿
原：有一军人，穿布衣布鞋游寺，僧以为常人，不加礼貌。军问僧曰：“我见你寺中，也甚淡薄；若少甚的修造，可取缘簿来，我好写布施。”僧人大喜，遂即献茶，意极恭敬。及写缘簿，头一行才写了“总督部院”四个大字，僧以为大官私行，惊惧跪下；其人于“总督部院”下边又添写“标下左营官兵”，僧以为兵丁，脸即一恼，立起不跪；又见添写“喜施三十”，僧以为三十两银子，脸又一喜，重新跪下；及添写“文钱”二字，僧见布施甚少，随又立起不跪，将身一揲，脸又変恼。
原：先不礼貌，因无钱；后甚恭敬，因有钱。先一跪，为畏势；后一跪，为图利。世人都是如此，岂不可叹？

# 哑子说话
原：有一叫化子假妆哑子，在街市上化钱，常以手指木碗，又指自嘴，曰“哑哑”。一日拿钱二文买酒，吃尽，曰：“再添些酒与我。”酒家问曰：“你每常来不会说话，今日因何说起话来了么？”叫化子曰：“向日无钱，叫我如何说得了话？今日有了两个钱，自然会说了。”
原：而今纯是钱说话，那里有个人说话？

# 不肯下剪
原：有请裁缝工人到家中裁衣，其人默视多时，不肯下剪。主人问故，其人曰：“这衣服我若下剪，有了我的就没了你的，若有了你的又没了我的，如何是好。”
原：而今人只顾自己、不顾他人的极多，由此看来，此人能代他人回想，能代他人存地步，还算有良心。

# 反有用
原：除夜遇送年节礼物的，主人取旧历一本与来仆，以作脚钱。仆曰：“此是旧历日，我领回去无用了。”其人大怒，叱之曰：“你既然领去无用，难道我留在家中反有用么？”
原：圣人谓“己所不欲勿施于人”，我看今人“己所不欲专施于人”，己所欲的反不肯与人。不独送人器物，既一切事务俱是如此，乃圣人所以为圣，愚人所以为愚欤！

# 兄弟合种田
原：兄弟二人合种田，至秋收时，弟向兄分稻。兄谓弟曰：“我与你是好兄弟，何必如此琐碎，恐傍人看见说我们较量彼此，有失雅道。不若今年我收得上头的稻谷，你只得下头的稻草；等到明年，我得下头，你得上头。一递一年，何等至公！”弟从之。及至来年春间，弟向兄曰：“今该下秧了。”兄曰：“且住着，我闻得人说今年要旱，竟种芋头，只是记我收下头你收上头，公平良心，一递一年，不许改换就是了。”
原：只思量曰讨便宜，总不管他人有无。世间合本伙计、共事朋友，犯此病者极多。谁知老天难容你算！

# 兄弟合买靴
原：兄弟二人合买靴一双，言过合穿。及买归，其弟日日穿走，竟无兄分。兄心不甘，乃穿靴夜行，总不睡觉〈音叫〉。不几日，靴破，弟谓兄曰：“再合买一双新的。”兄愁眉曰：“不买了，还让我夜间好好睡睡觉罢。”
原：古人说：“合船漏，合马瘦。”总之视为公中之物，全不爱惜；若彼此同心创立，岂不均有大利？

# 屁香
原：有人将妻子卧房糊得雪白、扫得极净，请一富翁到房，求他放一屁，翁惊问何故。其人曰：“我久闻有钱的人，放一个屁就有三日香；所以请老翁来家放一个屁，教我夫妻们好领领香气。”
原：有钱人的屁既是馨香，屙的屎必定是成块黄熟。怪不得替屁曰依稀乎丝竹之音，仿佛乎沉檀之气。人只知富翁屁甚馨香，殊不知单是有钱人极鄙极吝，连屁也没得与人麻口，枉费许多精神。

# 话不应
原：有人到神庙求签，问道士详断。道士曰：“先送下香钱，说的话才灵；若是没有钱，就有话，一些也不灵验的。”
原：人若无钱，就有好话，谁人来听？

# 臭得更狠
原：有钱富翁于客座中偶放一屁，适有二客在傍。一客曰：“屁虽响，不闻有一毫臭气。”一客曰：“不独不臭，还有一种异样香味。”富翁愁眉曰：“我闻得：屁不臭，则五脏内损，死期将近。吾其死乎！”一客用手空招，用鼻连嗅，曰：“才臭将来了。”一客以鼻绉起，连连大吸，又以手掩鼻，蹙额曰：“我这里臭得更狠。”
原：放一屁既如此奉承，若做他事，不知又当何如？

# 变曲蟮
原：帮闲者自夸技能，谓件件俱精、天下无比。一人曰：“你说你有许多能干，我看你不独可比曲蟮，将来还要变曲蟮。”其人惊问，答曰：“杀之无肉，剐之无血；要长就长，要短就短；又会唱曲子，又会呵卵胞。”
原：若帮人行坏事，岂但变曲蟮，只怕还要变蛆。

# 板还一板
原：有一官，但遇责替打的溜儿，即吩咐皂隶用小板轻打，打完必惨然泪下。有人问曰：“此乃无赖之徒，得人银钱，代人捱打，何故痛惜？”官曰：“这就是我后一世的榜样。为官的地方事多，若一时心粗不慎，或是受了人的贿，或是听了人的嘱，用刑错打了人，少不得一板子还他一板子。见了报应，叫我如何不痛？”
原：此是实话，并非戏言。尔我俱是父母生成一般血肉，痛楚相同，何忽错加？敲扑时存此心，功德无量。

# 不许看看
原：有人为官事相会衙门吏书，适值其人他出，有妻在家，答应曰：“尊客到我家，想是要干事的了。只消留一个大大的东道在我房里，凭你甚么时候行事，就依你甚么时候行事。要缴进去，就缴进去。要䐑快些，就䐑快些。你就是要搁起来，也随着你搁起来。只要你银子送得多，包管你快活如意。若是你没得银钱，不但事事不能从命，连看看也不许你看看了。”
原：衙门人有如此作弊，妻女们自然有如此果报。

# 死错了人
原：有人亲家母死，托馆师作祭文，师于旧文集中抄一祭亲家翁者与之。其人看曰：“错了。”师怒曰：“此文乃是刊刻在书上的，一字也不错，除非是他家错死了人。”
原：任着己性，不听人说，焉得不错？

# 红米饭
原：一人有丧偶食红米饭，一腐儒以为非居丧者所宜。问其故，谓红色乃喜色也。其人曰：“红米饭有丧食不得，难道食白米饭的都是有丧服么？”
原：迂人往往以非理之事乱行责备，宜以丧服答之。

# 戏太冷清
原：有设优酌款愚亲家而演《琵琶》者，既十馀出，其人嫌无杀阵，怒见于色，曰：“戏太冷清。”主家阴嘱戏子，复装武戏，杀阵甚酣。其人大喜，顾主翁曰：“这才是的，我不说也罢，只道我不在行〈音杭〉了。”
原：每每假在行，自己还夸张。

# 肌巴烂光
原：有一女子出嫁，夫甚愚蠢，不知房室。至回门，哭诉与母曰：“爹爹不为女儿择婿，令儿嫁个木雕泥塑的丈夫。夜间睡去，动也不动，叫我如何是了。”母曰：“我教你一法：俟丈夫睡着，将鸡屎抹在睡鞋底上，伸在丈夫鼻边。他若闻臭，即叫过头睡。如不晓，又伸过去，自然知臭。你说这头不臭，他自然过来。”女回去，依法三次，方过来并睡，端然不动。女乃扯他手在乳上，亦不知；放在肚上，亦不晓；再牵手放近阴物上，其夫忽大叫起来。隔房公姑惊问，其人高声怒应曰：“世间有这样愚蠢妇人，下身的肌巴卵袋都烂个精光，总不说着；若早些说与我，叫个人医治，也免得这等臭气。”
原：往往不识货，自己反怒叫。

# 梦鼓上掷骰
原：一老年人欲娶妾，得一梦：穿木套上楼，又骰子在鼓上掷，即往详梦。其师不在，徒弟详曰：“穿木套上楼，步步高也；骰在鼓上掷，有声有色。”此老喜极，即娶一妾。不半月，奄奄欲死，乃又到详梦家。适师在，问明前事，曰：“此小徒之误也。穿木套上楼，一步跷一步必跌无疑。”此老曰：“骰在鼓上掷呢？”师曰：“骰在鼓上掷者，这是把枯骨头定要累〈屡〉杀〈撒〉在这两片皮上。”
原：年老精力已衰，你虽爱妇，其如妇不爱你？你勉强为之，一则丑事难防，二则去死愈近，何苦自讨？

# 女勾死鬼
原：阎王差勾死鬼到阳世勾人，空身回来。阎王问故，鬼曰：“他身边先有两个标致女人跟着他，比我勾死鬼更狠。不久他自己就来，不必去勾他。”
原：虽然不见人头落，暗里催君骨髓枯。若是有了两个妇人，更是违限催差，其去不容少缓。

# 讨饭
原：一富翁有米数仓，遇荒年，乡人出加一加二重利，俱嫌利少，不借。有人献计曰：“翁可将此数仓米都煮成粥借与人，每粥一桶，期约丰年还饭二桶。若到丰收熟年，翁生的子孙又多，近则老翁自己去讨饭，若或远些，子孙去讨饭，一些不错〈音锉〉。”
原：富翁不存仁慈，只想刻剥贫民，果报不止于乞丐。

# 大不便宜
原：一人值家费纯用纹银，或劝以倾八九呈银杂用，当有便宜。其人出元宝一锭五十两，托倾八呈，人只倾四十两付之，而赚其馀。其人问：“银几何？”对曰：“四十两。”又问：“元宝五十两，如何倾四十两？”答曰：“此是八呈银，五八得四十，一毫也不错。”其人遽曰：“我悮听了你的说话，用色银真正大不便宜。”
原：用色银的，展转归之穷人，甚是可怜。即少有便宜，亦被人暗里算去，少不得上天加倍扣除。大不便宜的话，千真万确。

# 溺水
原：有人溺水，其子呼人急救，许以重酬。父于水中探头高喊曰：“是三分银便救，若要多的不必来。”
原：钱财比命更重，这三分银子可谓出手太多。

# 打个半死
原：一人极贪，富者语之曰：“我白送你一千两银子，你与我打死了罢。”其人沉吟良久，曰：“只与我五百两，打个半死何如？”
原：世人许多惊风骇浪，因而亡身，都是为财欲。求半死，恐不能矣。

# 烧蚂蚁用邻箕
原：有一家婆，手持数珠，口中高声念“阿弥陀佛、阿弥陀佛”，随即叫云：“二汉二汉，锅上的蚂蚁甚多，我嫌他得狠。把火来，代我烧死些。”又高声念云“阿弥陀佛、阿弥陀佛”，随又叫云：“二汉二汉，你代我把锅下的火灰巴去些，粪箕莫用我自己家里的，恐怕烧坏了，只用邻居张三家的。”
原：如此杀心，如此私心，虽每日念佛万遍而罪过仍在。 全要心口相应，才有功德。

# 吃人不吐骨头
原：猫儿眼睛半闭，口中呼呀呼呀的坐着。有二鼠远远望见，私谓曰：“猫子今日改善念经，我们可以出去得了。”鼠才出洞，猫子赶上咬住一个，连骨俱吃完。一鼠跑脱向众曰：“我只说他闭着眼念经，一定是个良善好心；那知道行出来的事，竟是个吃人不吐骨头的。”
原：有个会念经，也会行坏事。有个不念经，也不行坏事。请问高明人，谁是谁不是？不论经不经，只论行的事。

# 连我才得三人
原：一士谓人曰：“自古至今，圣人最难世出。当初盘古王开天辟地，生人生万物，谁人比得他来？我要让他。”乃屈一指。“其后孔夫子出类拔萃，诗书礼乐，为万世师表，那个人不敬服他？我只好让这第二个。”乃屈二指。“自此二人后，再没有屈得吾指的。”默想良久，点头曰：“是呀，你说圣人难不难，并连我才得三个人！”
原：大言不惭，高自称许，吾知其极厚的面孔。

# 少米少床
原：贫人对众客自夸曰：“我家虽不大富，然而器物件件不少。”乃屈指曰：“所少者，只是龙车凤辇。饮食样样俱有，”乃屈指曰：“所无的，只是龙心凤肝。”旁边有小童愁眉曰：“夜里床也没得睡，地下困草铺，今日晚饭米一粒也没得了，还在人面前说大语！”其人仰头想一想曰：“是极，是极。我也忘了，我家里到底件件俱有，所少的不过是龙心凤肝晚饭米，龙车凤辇夜里床。”
原：贫不可笑，贫而说大话者则可笑。

# 茶饭不周全
原：嫖客破家后，乃沿门唱曲讨饭度日。偶过旧妓之门，妓在内陪客饮酒，低声唱云：“我为你清减了桃花面。”嫖客在外忽高声接唱曰：“我为你茶饭上不周全。”
原：不清减而欲茶饭周全者极少。

# 还是处女
原：一人好赌，田地屋业俱输尽，止剩一妻，复以当。稍不数掷，复输去，因又固请再饶一掷。赢家不肯，输者曰：“房下还是处女，价钱作少了，饶一掷不为过。”赢家曰：“那有此理？”输者曰：“你若不信，但看我自作亲以来，何曾有一夜住在家里宿歇的？”
原：心无二用，好赌者即妻子亦不理着，何况父母兄弟亲友乎？又何况事业乎？真可浩叹。

# 骂父
原：父子同抬柴枝，父悮以枝碰子，子即怒骂曰：“老乌龟！你眼睛肏瞎了！怎么把枝柴砰在我身上呢？”孙在傍，见祖被骂，大不平，曰：“肏娘的贼奴才！生身的父母可是骂得的？”〈碰音烹去声撞也〉
原：但看瓦屋檐前水，点点滴滴不差移。

# 出气
原：一不肖子常殴其父，父抱孙不离手，甚爱惜之。邻人问曰：“令郎不孝，你却甚爱令孙，何也？”答曰：“不为别的，我要抱他长大了，好替我出气。”
原：果报反复，必然之理。

# 喜旗杆
原：眉毛一日想要连身上的宗，细想量曰：“胡须终日没衣穿，我不去连他；胁毛虽有衣穿，却在人的手夹下过日子，我也不喜欢。”想了一会，点头曰：“到是下边竖旗杆的，又硬碀又强势，不与他连宗，还寻那个？”
原：本支宗族不去亲敬，反结连外人，揆其意不过图他势要。孰知有利则亲，有害则取，连而不连同也。

# 门户大
原：有男人欲狎一处女，先举其物，问之曰：“此为何物，汝知之否？”女曰：“那是一张。”因卵字不便说，故作歇后语也。男又问曰：“这等，你腰下是何物？”女曰：“也是一张。”男曰：“你也是一张，我也是一张，可见这两件东西都是姓张的了，五百年前共一家，何不使他通一通谱？”女许之，遂与解裤相狎。事毕之后，女叹曰：“谱便通了，只是这个门户渐渐的大起来，收敛不得，却怎么好。”
原：一与富贵往，还便生出许多事不可收拾。

# 割股
原：有父病延医用药，医曰：“病已无救，除非有孝心之子割股感格，或可回生。”子曰：“这个不难。”医去，遂抽刀出。是时夏月，逢一人赤身熟睡门屋，因以刀割去股肉一块。睡者惊起喊痛，子摇手曰：“莫喊！莫喊！割股救父母你难道不晓得是天地间最好的事么？”
原：损人利己，坏他事成。自名虽无其事，多存此心。

# 疽痛
原：有人腿上患一毒疽，甚是疼痛，叫喊不止。忽将壁上挖一洞，将腿放入穴内。人问其故，患人攒眉曰：“这疽在我腿上，我自己痛不过了，所以挖个壁洞伸过去，也等他好往别人家里疼疼去。”
原：己害思欲脱人，殊不知害仍在己，丧心何益。

# 方蛇
原：有曾遇大蛇的，侈言阔十丈、长百丈，闻者不信。其人递减二十丈，人犹不信；递减至三十丈、二十丈，遂至十丈，忽自悟其谬曰：“阿呀，蛇竟长方了。”
原：世有虚语，未有不被人识破，奈不能自悟，何？

# 大澡盆
原：有外路二客相会，各说本处奇事。一客曰：“敝处有个洗澡盆，可容得千馀人在内沐浴。”一客曰：“此盆还不算奇；敝处有一竿竹子，长得上柱天、下柱地。目今天上长不去，反倒转下来湾着朝地长，才为奇事。”客问曰：“那有这等大竹？”客曰：“若没得我这根大竹子，怎得能彀箍你的这等大澡盆？”
原：有此附和人，方可说此大话，也只好哄得自己。

# 代哭
原：扬俗丧家开吊，用妇女哭于棺旁，孝子多雇觅邻妪代之。久而颇倦，因哭曰：“想来干我甚事呀？”客闻声而尤之曰：“就是雇来的，既然得了人家的银钱，也不该如此哭法？”妪闻而易其哭曰：“想来又干你甚事呀？”
原：孝子居丧不哀，宜用此妇代之，方合拍。

# 皮匠讼话
原：两皮匠涉讼，一友问之曰：“你家讼事如何了？”匠曰：“他手脚好，通了线索，把里边托好了。幸而见官时，他的舌头上打起𠫝〈音掌〉子来，被我细针密线介一说，官府也弗敢蛮揎，竟免供逐出，被我打仔个湾子，伺候渠出来，腓子渠介両记哉！”
原：人只知笑此皮匠说皮匠话，殊不知许多势利小人，满口满脸尽皆势利，更可笑也。

# 两脚桌子
原：一人做桌，要省木，匠迎其意曰：“只做二脚，倚楹而用，可也。”一夕月明，欲移放庭中，难于安顿，召匠责问。匠曰：“你在家里，可以省得；若在外边，却如何省得？”
原：做两脚桌的，如何还想赏月？

# 独脚裤子
原：有命裁缝做裤者，以丈尺太多不从。末一工知意，曰：“我只用六尺，足彀做。”其人大喜。及至做成，乃是独脚裤子，穿起彳亍〈音赤触〉难走，对工人大笑曰：“省到省了，只是一步也行不去。”
原：做独脚裤的，如何还想出门？

# 我不见了
原：一呆役解罪僧赴府，临行恐忘记事物，细加查点，又自己编成二句曰：“包裹雨伞枷，文书和尚我。”途中步步熟记此二句。僧知其呆，用酒灌醉，剃其发，以枷套之，潜逃而去。役酒醒，曰：“且待我查一查着。包裹、雨伞，有。”摸颈上曰：“枷，有。文书”，曰：“有。”忽惊曰：“嗳呀，和尚不见了！”顷之，摸自己光头，曰：“喜得和尚还在，我却不见了。”
原：人只知此人呆失，殊不知世人终日营营、沉酣不醒，将自己要紧的性命，总不知其究竟，任随昏散而死。即有认者，亦非的确，岂不比此呆更甚？

# 笑话一担
原：秀才年将七十，忽生一子，即名曰“年纪”。未几，又生一子，似可读书者，因名曰“学问”。次年又生一子，笑曰：“如此老年，还生此儿，真笑话也。”又名曰“笑话”。及三人年长无事，俱命入山打柴，及归，夫问曰：“三子之柴孰多？”妻曰：“年纪有了一把，学问一些也无，笑话倒有一担。”
原：有年纪而无学问，已是笑话，何况更有笑话乎！

# 一张大口
原：两人好为大言，一人说：“敝乡有一大人，头顶天，脚踏地。”一人曰：“敝乡有一人更大，上嘴唇触天，下嘴唇着地。”其人问曰：“他身子在那里？”答曰：“我只见他一张大口。”
原：此人有了大口，必有厚脸，也须看看他。

# 大舌乌龟
原：一人将肝油在井边洗，悮落一块肝于沟内。一乌龟见而吞之，肝大口小，拖露于口外。一人见而讶之曰：“你们快些来，好看这大舌头的乌龟。”
原：说大话的面目，全亏一个硬壳替他藏躲。

# 切莫动手
原：医家一仆犯事，主人大怒，捏拳欲打。仆哀求曰：“小人服事年久，极知老爹手叚。只求脚踢，切莫动手。脚踢还不伤命；若一动了手，我的性命就难保了。”
原：有这等狠手，不是家里人说出，外人那个知道？

# 看上了你
原：一庸医娶妻，生男女二人。一日医死了人的儿子，遂以子赔之。又医死了人的女儿，复以女赔之。只剩一妻在家，凄凉不堪。忽有人敲门请看病，医问：“看何人？”答曰：“敝房。”医对妻哭曰：“不好了，又有人看上你了。”
原：庸医不名脉药病源，便大胆挂牌行道，医死了人的儿女妻房，必然要将自己的儿女妻房还人。天理果报，一毫也不差错。此等做孽事，切不可做。

# 又支又抽
原：妻摸夫阳物，曰：“此是何物？”夫曰：“是本钱。”夫亦摸妻阴物，曰：“此是何物？”妻曰：“是个店面。”夫曰：“我出本钱，你出店面，合一合伙计议定，本钱安安静静的放在店内，也不许支，也不许抽，包你一日一个对合。”其后合不上，几日大家熬不得了，遂而今日也支，明日也抽。有一日，夫对妻曰：“我们两个人支也支得快活，抽也抽得燥脾，只是我的本钱渐渐缩小，你的店面觉道空白踱踱仔点哉！”
原：今日合伙计的，无人不犯此病，可为浩叹。

# 梦雷打
原：三人同心共事，对天发誓曰：“若有私心，天雷击顶。”内中有一人奸究偏私，暗地得财，夜梦雷神打他，惊慌成病，另托一友还愿，而告以实情。友至庙中，才焚香，忽闻山门崩倒，友悮认为雷，急忙跳祝曰：“雷公爷，雷公爷，不干我事！那打偏手的还在家里害瘟病哩！”
原：存心不公，暗中必有许多消折，岂但瘟病一件？

# 还我原面孔
原：一人赴饮，自家先饮半醉，面红而去。及至席间，酒味甚淡，越饮越醒，席完而前酒尽无，将别时谓主人曰：“佳酿甚是纯𬪩，只求你还我原来的那样半红脸罢。”
原：肴可少，而酒不可淡。以淡酒请客者，大无见识。

# 撒不来
原：有惯撒酒风人，不论饮多饮少，只是要撒。其妻恨之。一日，在家索酒吃，妻与浸苎麻水饮之。未几，亦手舞足蹈起来。妻骂曰：“天杀的！吃了浸苎麻的水，也撒酒风？”顷之，其人大笑曰：“我也道今日如何这等撒不来。”
原：酒醉之人，鲜有坠水食粪者。可见撒酒风的，都是倚风作邪。试问次日见人，可惭愧否？

# 丈夫回家
原：一江西人出外小本经商，凡赚得金银，恐行路小人窃取，尽藏在大伞柄内。日久归家，妻出迎接，见丈夫并无行装，手中止执一伞，心中大不喜欢，怒形于色。夫曰：“我走了远路，肚中甚饿，可快煮饭来我吃。”妻怒曰：“家中米也没得，那里还有饭与你吃？”夫笑曰：“你这等怒色，想是我久在外边，累你孤灯独卧，可同你云雨一回，以联旧情。”妻更大怒曰：“你好心思呀！饭也不与你吃，还想肏𣬼么〈江西人肏音错〉？”夫又笑曰：“你将厨刀取来与我。”妻喜曰：“你这等没本事挣钱的人，到是自刎了甚好。”妻遂送刀与夫。夫接刀，将一柄劈开，尽是藏的碎金银百馀两。妻看见，怒脸变成大喜，对夫笑问曰：“请问亲哥哥，你还是吃了饭肏𣬼呢，还是肏了𣬼吃饭呢〈吃音确肏音错〉？”
原：阎非台先生尝曰：“子弟得志，父兄甘作三分篾片；丈夫无钱，妻子看作九分厌物。”可见糟糠同守者，能有几人？至亲厚如夫妻者，尚且如此，何况其他？

# 归去来辞
原：一人口中偶读古文曰：“临清流而赋诗。”傍有一人急忙问曰：“何处临清刘副使？为甚的不早些对我说？让我好奉承奉承结交他。”其人曰：“此乃《归去来辞》。”这人改颜缓说曰：“我只道他是个现任的官儿，若是这个归去来辞的官儿，我就不理他了。”
原：为问门前客，今朝几个来？真可浩叹！

# 比物
原：一人同小船，路遇有塔，一人要去登塔眺望。及至回船，船上人笑曰：“我方才在船里，远远望见你在七层塔上身子甚小，只有三四寸长，头上红缨帽，戴着就像此物一样的。”随说随以一指头作阳物，一颠一颠的。其人忙将两手大拇指、二指尖长圈起作阴物样，又将中指居圈中，也是一颠一颠的，口中随说曰：“我方才有七层塔上望见你在船中，就像这个一样的。”
原：讨人便宜而不知自失便者多矣，往往如此。

# 面貌一样
原：一人抱儿子在门外闲立，旁有一人戏之曰：“可见父子骨肉真个是一脉，只看你这个儿子的面貌，与我的面貌就是一般无二。”抱子者答曰：“你与这儿子原是一母生出来的弟兄，这面貌怎么不是一样的？”
原：我讨人的便宜，岂知人讨我的便宜更重。古云：“讨便宜即是吃亏的后门。”许多失便宜事，俱从此起。

# 装做米
原：有人行奸，不意亲夫忽然回家，敲门甚急。其人惊慌无措，妇令蹲于门后，将一布袋连头套起，躲藏好了才去开门，问夫曰：“你回家适值我小便也，等我起来才好开门，你因何这等着急？你原说今夜不回家的，因何又回家呢？”其夫战栗曰：“我今晚几乎白丧了一条性命。因与一妇人行奸，谁想他的亲夫一时间回家，我惊得无处藏身，没奈何躲入他厨房柴堆里。那晓得那个人开门的时候，又点灯遍处照看。我见他的灯点到厨房里来，我甚惊慌，身子就发起战来。那人看见柴草摇动，晓得有人，就挐了一把厨刀来杀我。那时我着了急，就飞走出来，用力将他推倒，我才得脱身，飞跑出门。不是这等侥幸，已经被他杀了，至今魂不在身上，你说可不怕死人么！”妻曰：“怪道你这等惊慌，也都是你自讨的苦吃。”其人见妻抢驳，就去照着拴门，因见门后有物，指问妻子，曰：“这是一堆甚么东西？”妻见问及，惊不能答。只见布袋乱摇，袋内战兢兢的答：“这是一袋米呀。”夫曰：“米那里会说话的？这分明是个人了。你到我房里来作甚么？”这人又在袋里战兢兢的说道：“你既然在别人家里做得柴，难道我在你家里就做不得米〈尾二句要攒着眉战兢的说才发笑〉？”
原：诸恶业中，惟色业易犯，损德取祸，莫过于此。我每见邪淫之人，妻女果报，毫发不爽。谚云：“沿河黐雀儿，家里不见大公鸡。”要晓得：我淫人妇，我妇淫人。一还一报，自然之理。只怕本钱之外，另要加上许多利钱，才偿还得。在这篇内描写惊惧的景况，都寓有警惕深意，读者慎勿草草捐过。

# 邀吃茶
原：有携小孩行路经过一门，是其交情之妇也，邀请吃茶，甚坚，其人力辞另日再来。小儿问曰：“这人请茶，正该坐坐，为何不去？”其人曰：“他不是请我吃茶，是要我的银子呢！”小儿喜跳，曰：“是了！是了！怪道我家妈妈等你出了门，就请人来家吃茶，原来都是要人的银子！”
原：淫人妻而己妻淫人者，遍处都是。夫男从何得知？一向醉梦昏昏，安得个个有人提醒？

# 厌常喜新
原：有喜邪淫者，其妻问曰：“人人各有夫妻，同是男女交合，何苦定要奸淫别人的妻女，败坏别人的名节呢？”其夫曰：“我在别人家妇女身上用功，也只为厌常喜新，所以顾不得他人声名节操了。”妻曰：“你在别人家欢娱快乐，我独自寂守孤灯，世间那有这不公不正的事？你是男子汉，知书识礼，尚且不顾人的名节，何况我是愚蠢女流？实不瞒你说，我也学你厌常喜新的好几回了。”
原：丈夫二字，只好照应一丈之内。离一丈之外，其贞否俱存于妇人之心矣。此𡜵妙在先以正言发问，知其不改，然后以直言明说，服之以理，并不隐讳。但世上的妇人，不说明而暗中厌常喜新者，不知其几。世人欲要妻女贞节，先要自己问心，可曾奸淫别人家的妇女否。

# 有趣
原：有喜邪淫的，其妻问曰：“一夫一妻，天生正配，你偏偏反喜欢别人家的妇人，是何缘故呢？”夫曰：“但凡妇人的阴户，越有多人合的，越觉有趣。”妻点头曰：“怪道我相交的人，个个说我有趣得狠。”
原：好有趣的，即以有趣应之。

# 爱标致
原：有人婪一美童，一日偶自外回，忽见此童从妻房内慌忙奔出，其人大怒。童曰：“男女虽异，爱恶则同。你既然爱我的标致，难道尊夫人就爱不得我的标致么？”
原：此童对答之语说得明理词畅，可以诛心，可以服傲。要知美貌少年，人人喜爱，往来有此，必致淫乱。这以前易后的事，势所必有。好男风者，或有不报于目前，而报于后代子孙者，更惨更狠。

# 小使骑马
原：一高大门内有少年华服，骑马奔出，后边一小使流泪跟跑，尚骂走迟，则鞭乱打。有人拉门内白发老人问曰：“这骑马打奴的是何人？如何这等㐫猛？”老人点头曰：“而今世上的事，颠倒错乱，都是自取。方才马上坐的，却是一个奴才，马后跟的，反是一个主人，岂不是自取颠倒么？”其人不解，求说明白。老人推辞再三，点头叹说曰：“我在他家年老，才晓得他家的旧事。先前老主爱上一个仆妇，与他交合，遂而有孕，生出适才那个跟马的小使来。谁知果报昭彰，主婆又爱上这个男仆，也有了孕，生出适才这个骑马的少年来。岂不是主人的骨血反做了奴才，奴才的骨血反做了主人？连这打骂磨难，都是昔年的果报，好不怕人！”
原：富贵之家，奴婢最多。主人以为下人容易淫乱，殊不知尊卑倒置，果报昭彰，大可畏也。更有仆妇成孕生女，而己子又复交媾，竟是子妹通奸。如或生男标致，小主狎之，又是弟兄通奸。上下淫乱，禽兽不若。总因主人一时之悮，遂至如此惨害，岂不深可悲病哉！

# 烂盘盒
原：昔有一官，上任之初，向神发誓曰：“左手要钱，就烂左手；右手要钱，就烂右手。”未久，有以多金行贿者，欲受之，恐犯前誓。官自解之曰：“我老爷取一空盘盒来，待此人将银子摆在内，叫人捧入。在当日发誓是钱，今日却是银，我老爷又不曾动手，就便烂也只烂得盘盒，与老爷无干。”
原：官府受贿，必致屈陷良善，刑罚无辜。此等坏心钱，虽然赚来，吾恐手未烂而心先烂。

# 誓联
原：昔有一官到任后，即贴对联于大门曰：“若受暮夜钱财，天诛地灭；如听衙役说话，男盗女娼。”百姓以为清正。岂知后来贪污异常，凡有行贿者，俱在白日，不许夜晚，俱要犯人自送，不许经衙役手，恐犯前誓也。
原：内存贪污之心，外博清廉之名。如此诈伪，意欲欺神乎？抑欲欺人乎？古云：“暗室亏心，神目如电。”又云：“若要人不知，除非己莫为。”虽欲遮盖，何异掩耳盗铃？才做一欺心事，声名早已遍传，而报应早已种下矣。

# 再出恭
原：村庄农人不知礼，来至儒学殿前散粪一堆。学师闻之，怒送县究。县官审问：“因何秽触圣人？”村农曰：“小人上城，每日皆从学前走。一时恭急，随便解手，非敢亵渎圣人。”官曰：“你愿打愿罚？”村农畏打，曰：“小人愿罚。”官曰：“该问不应，纳银一两五钱，当堂秤下，不须库吏收纳。”村农取出银一锭，约有三两，禀官曰：“待小人去剪一半来交纳。”官曰：“取来我看。”见是纹银一锭，就和颜悦色，先将银子慌忙纳入袖中，对村农曰：“这锭银子不须剪开，当我老爷说过，准你明日再到学殿前出一次大恭罢。”
原：得了钱，便再犯一次法，也可宽恕，何况出恭小事。

# 旧例
原：官解任，有众老置酒来请脱靴。官曰：“我在这地方上，并无恩惠及民，何敢当此。”众曰：“这是旧例，不得不行。”
原：虽是旧例，也要百姓乐为。但居官者，此时自返于心，实无恩惠及民而民来脱靴，岂不自愧？我每见有等官长，才闻离任之信，百姓的恨骂之声便满街满巷，官之贤否可知矣。吾愿居官者，平昔留心爱养，断不可悔后自愧也。

# 书是印成的
原：一子喜游荡，不肯读书，其父怒闭一室，传送饮食，教令眼睛仔细看书，心思仔细想书，如此用功，自然明白。过了三日，父到房内看其功课，子对曰：“蒙父亲教训得极妙，读书果然大有利益。我才看得三日书，心中就明白了。”父喜问曰：“明白了何事？”子亦喜曰：“我一向只认这读的书，是用笔写成的；仔细看了三日，才晓得一张一张的书，都是印板印成的。”
原：今人读书，全不将圣贤言语，体贴身心，却专在字句上用巧，虽读万卷，有何益处？原与此认印书之人一般无二。

# 三十而立
原：师出“三十而立”的破题，令二生做。一生作破曰：“两个十五之年，虽有椅子板凳而不敢坐焉。”一生作破曰：“年过花甲一半，惟有两腿直站而矣。”
原：文不在义旨上运思，却专在字句上著笔，皆此二生之类也。
