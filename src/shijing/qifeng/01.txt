# 齐风
题解：齐风是周代齐国一带的诗歌，齐国是姜太公的封国，都城在临淄（今山东淄博一带），濒海，渔盐之利丰富，民风较为豪放。今存十一篇，内容有男女情事、田猎、婚礼，也有几篇传统上认为讽刺齐襄公与文姜的诗。

# 鸡鸣
题解：这是一首对话体的诗，写一对夫妇（或情侣）清晨时女方一再催促、男方一再推托的情景。《毛诗序》以为是思念贤妃、劝诫君主早朝的诗，今人多读作夫妇晨起的对话。
原：鸡既鸣矣，/朝既盈矣。/匪鸡则鸣，/苍蝇之声。|| 女的说：“鸡已经叫了，朝堂上的人已经到齐了。”男的说：“那不是鸡在叫，是苍蝇嗡嗡的声音。”
注：既：已经。
注：朝既盈矣：朝廷上已站满了人；一说“朝”指早晨，“盈”指天色已大亮。
注：匪：同“非”，不是。
注：则：语助词，与“之”相近。
原：东方明矣，/朝既昌矣。/匪东方则明，/月出之光。|| 女的说：“东方已经亮了，朝会已经热闹起来了。”男的说：“那不是东方发亮，是月亮升起的光。”
注：昌：盛，指人多热闹；一说指天光明亮。
原：虫飞薨薨，/甘与子同梦。/会且归矣，/无庶予子憎。|| 男的说：“虫子嗡嗡地飞，我还想和你一同安睡。”女的说：“朝会将散，人们都要回去了，别让人因此怨恨我和你。”
注：薨薨（hōng）：虫群飞的声音。
注：甘：乐意，情愿。
注：同梦：一同睡梦。
注：会且归矣：朝会将要散了；“会”一说指男女相会，句意存疑。
注：无庶予子憎：不要使人憎恶我们。无，勿；庶，庶几、或许；一说“庶”指众人。

# 还
题解：这是猎人在山中相遇、互相称赞技艺的歌，语气豪爽。《毛诗序》以为讽刺齐哀公好田猎、国人化之成俗，今人多视为猎人互赞之歌。
原：子之还兮，/遭我乎峱之间兮。/并驱从两肩兮，/揖我谓我儇兮。|| 你的身手真敏捷呀，我们在峱山之间相遇了。并马一同追逐两头大兽，你拱手称赞我灵巧。
注：还（xuán）：轻捷灵便的样子；一说为地名。
注：峱（náo）：山名，在齐国都城临淄附近。
注：从：追赶。
注：肩：同“豜”，三岁的大兽，这里泛指大野兽。
注：儇（xuān）：灵巧敏捷。
原：子之茂兮，/遭我乎峱之道兮。/并驱从两牡兮，/揖我谓我好兮。|| 你的本领真出众呀，我们在峱山的路上相遇了。并马一同追逐两头公兽，你拱手夸我身手好。
注：茂：美好，指技艺高超。
注：牡：雄性的野兽。
原：子之昌兮，/遭我乎峱之阳兮。/并驱从两狼兮，/揖我谓我臧兮。|| 你真是健壮英武呀，我们在峱山南坡相遇了。并马一同追逐两只狼，你拱手称赞我了不起。
注：昌：强壮而有神采。
注：阳：山的南面。
注：臧：善，好。

# 著
题解：这是写新郎亲迎的诗，以新娘的口吻，写她看见新郎在门屏间、庭中、堂上依次等候，目光落在他冠饰的充耳美玉上。传统《毛诗序》以为讽刺当时不行亲迎之礼，今人多读作婚礼之诗。
原：俟我于著乎而，/充耳以素乎而，/尚之以琼华乎而。|| 他在门屏之间等我呀，耳边垂着白色的丝绳呀，上面还缀着美玉琼华呀。
注：俟：等候。
注：著（zhù）：通“宁”（zhù，不是安宁的“宁”），大门与屏风之间的地方。
注：乎而：句末语气词连用。
注：充耳：冠冕两侧垂挂、正当两耳的饰物，用丝绳系玉。
注：素：白色，指系充耳的丝绳颜色，下“青”“黄”同。
注：尚：加上。
注：琼华：美玉；与下文“琼莹”“琼英”都是对玉的美称，具体所指存疑。
原：俟我于庭乎而，/充耳以青乎而，/尚之以琼莹乎而。|| 他在庭院里等我呀，耳边垂着青色的丝绳呀，上面还缀着晶莹的琼玉呀。
注：庭：大门以内、堂前的院子。
原：俟我于堂乎而，/充耳以黄乎而，/尚之以琼英乎而。|| 他在堂上等我呀，耳边垂着黄色的丝绳呀，上面还缀着光彩的琼英呀。
注：堂：正厅，堂屋。

# 东方之日
题解：这首诗以男子的口吻，写一位美丽的女子来到自己的居室，与自己亲近相随，一般认为与婚恋有关。《毛诗序》以为讽刺君臣失道、男女淫奔，今人多读作写新婚或男女相悦的诗。
原：东方之日兮，/彼姝者子，/在我室兮。/在我室兮，/履我即兮。|| 像东方升起的太阳呀，那美丽的姑娘，来到我的屋里呀。来到我的屋里呀，紧紧踩着我的脚步跟随我呀。
注：东方之日：以初升的太阳比喻女子容貌的明艳。
注：姝：美丽。
注：履我即兮：“履”是踩、踏；“即”有二说，一说为“膝”，一说为就、靠近，指跟随着我走，存疑。
原：东方之月兮，/彼姝者子，/在我闼兮。/在我闼兮，/履我发兮。|| 像东方升起的月亮呀，那美丽的姑娘，来到我的门内呀。来到我的门内呀，跟着我的步子走呀。
注：闼（tà）：门内，或指内室。
注：发：一说为脚，一说为出发、行走，指随我而行，存疑。

# 东方未明
题解：这首诗写天还没亮，就被国君召唤，慌乱中把衣裳都穿颠倒了，并抱怨掌管时刻的人不能按时报时。《毛诗序》以为讽刺朝廷起居无节、号令不时；也有人读作役人怨苦之诗。
原：东方未明，/颠倒衣裳。/颠之倒之，/自公召之。|| 东方还没有亮，就慌忙把衣和裳穿颠倒了。之所以颠来倒去，是因为国君那边来召唤了。
注：衣裳：上身穿的叫衣，下身穿的叫裳。
注：公：公室，指国君。
注：召：召唤。
原：东方未晞，/颠倒裳衣。/倒之颠之，/自公令之。|| 东方还没有露出曙光，就慌忙把裳和衣穿颠倒了。之所以倒来颠去，是因为国君那边下了命令。
注：晞（xī）：天刚放亮，曙光初现。
注：令：命令，传令。
原：折柳樊圃，/狂夫瞿瞿。/不能辰夜，/不夙则莫。|| 折了柳枝来做园圃的篱笆，那狂妄的人却瞪着眼睛乱看。他不能掌握好夜间的时辰，不是太早就是太晚。
注：樊：篱笆，这里用作动词，指编篱笆围起来。
注：圃：菜园。此句含义有不同说法，一说指用柳枝圈园、徒有其表，一说与计时的漏刻有关，存疑。
注：狂夫：狂妄无知的人，旧说指掌管报时的官吏；一说指监工。
注：瞿瞿（jù）：瞪眼张望的样子。
注：辰夜：掌握夜里的时辰。辰，作动词，守时。
注：夙：早。
注：莫：同“暮”，晚。

# 南山
题解：这首诗一般认为是讽刺齐襄公与其妹文姜私通、鲁桓公不能约束其妻的事（见《左传·桓公十八年》）。前两章责问文姜既已出嫁为何又回齐国，后两章以娶妻必须告父母、凭媒妁为喻，责问鲁桓公为何放纵她。
原：南山崔崔，/雄狐绥绥。/鲁道有荡，/齐子由归。/既曰归止，/曷又怀止？|| 南山高高耸立，雄狐慢慢地游走寻求配偶。通往鲁国的大道平坦宽阔，齐国的女儿从这条路出嫁。既然已经出嫁了，为什么又想着回来？
注：崔崔：山势高大的样子。
注：雄狐绥绥：雄狐缓缓行走、求偶的样子，一般认为暗喻齐襄公。
注：鲁道：通往鲁国的大路。
注：荡：平坦。
注：齐子：齐国国君的女儿，指文姜。
注：由归：从这条路出嫁。
注：曷：为什么。
注：怀：思念，或指回来。
注：止：语助词。
原：葛屦五两，/冠緌双止。/鲁道有荡，/齐子庸止。/既曰庸止，/曷又从止？|| 葛布鞋都是成双的，帽子的缨带也是成对的。通往鲁国的大道平坦宽阔，齐国的女儿由这里出嫁。既然已经由这里出嫁了，为什么又要跟着他？
注：葛屦（jù）：用葛麻编成的鞋。
注：五两：旧说“五”通“伍”，“两”指一双，指鞋成双成对，具体含义历来众说纷纭，存疑。
注：冠緌（ruí）：帽带打结后垂下的部分。
注：双：成对。
注：庸：由，用。
注：从：跟从，指与齐襄公相从；一说指鲁桓公随文姜到齐国。
原：艺麻如之何？/衡从其亩。/取妻如之何？/必告父母。/既曰告止，/曷又鞠止？|| 种麻该怎么办？要把田地横向纵向地耕好。娶妻该怎么办？一定要禀告父母。既然已经禀告了父母，为什么又放纵她到这般地步？
注：艺：种植。
注：衡从：即“横纵”，指东西南北方向整治田垄。
注：取：同“娶”。
注：鞠：穷极，放任到极点。
原：析薪如之何？/匪斧不克。/取妻如之何？/匪媒不得。/既曰得止，/曷又极止？|| 劈柴该怎么办？没有斧头就劈不开。娶妻该怎么办？没有媒人就娶不到。既然已经娶到了，为什么又任她无所顾忌？
注：析薪：劈柴。《诗经》中常以析薪、伐柯比喻婚姻之事。
注：克：能够。
注：极：穷极，放纵到极点。

# 甫田
题解：这首诗写对远方之人的思念，末章写久别重逢时对方已从垂髫少年变成戴冠的成人。《毛诗序》以为讽刺齐襄公无礼义而求大功，今人多理解为思念远人之作，所思者是谁说法不一。
原：无田甫田，/维莠骄骄。/无思远人，/劳心忉忉。|| 不要耕种那大片的田地，那里只会长满高高的杂草。不要思念远方的人，只会让心里忧愁不安。
注：无田甫田：第一个“田”作动词，耕种；甫田，大田。一说“田”指打猎，存疑。
注：莠（yǒu）：狗尾草，田间杂草。
注：骄骄：长得高而茂盛的样子。
注：劳心：忧心。
注：忉忉（dāo）：忧思不安的样子。
原：无田甫田，/维莠桀桀。/无思远人，/劳心怛怛。|| 不要耕种那大片的田地，那里只会长满茂盛的杂草。不要思念远方的人，只会让心里忧伤难过。
注：桀桀：高耸挺出的样子，与“骄骄”义近。
注：怛怛（dá）：忧伤痛苦的样子。
原：婉兮娈兮，/总角丱兮。/未几见兮，/突而弁兮。|| 那个孩子年少清秀，头上扎着两个小发髻。没过多久再见到他，忽然已戴上成人的冠了。
注：婉、娈：年少美好的样子。
注：总角：古代未成年人把头发束成两个髻。
注：丱（guàn）：发髻像两角的样子。
注：未几：不久。
注：突而：突然。
注：弁（biàn）：冠帽，古代男子成年行冠礼后才戴。

# 卢令
题解：这首诗赞美一位带着猎犬的猎人，写他英俊而有风度。《毛诗序》以为讽刺齐襄公好田猎而不修民事，今人多读作赞美猎人之诗，有人以为出于女子之口。
原：卢令令，/其人美且仁。|| 猎犬的颈环叮当作响，它的主人英俊而又仁厚。
注：卢：黑色的猎犬。
注：令令：犬颈下环铃的响声。
注：仁：仁厚，有和善可亲的意思。
原：卢重环，/其人美且鬈。|| 猎犬颈上挂着子母环，它的主人英俊而头发卷曲好看。
注：重环：大环套小环。
注：鬈（quán）：头发卷曲美好；一说为勇壮，存疑。
原：卢重鋂，/其人美且偲。|| 猎犬颈上挂着一大套两小的环，它的主人英俊而又有才干。
注：重鋂（méi）：一个大环套着两个小环。
注：偲（cāi）：多须的样子；一说为有才能，存疑。

# 敝笱
题解：这首诗以破旧的鱼笼拦不住大鱼起兴，写齐国女子出嫁归宁时随从众多的场面。《毛诗序》以为讽刺鲁桓公不能防闲文姜，使她回齐国与齐襄公私通；也有人认为所指只是一般齐国贵族女子出嫁，存疑。
原：敝笱在梁，/其鱼鲂鳏。/齐子归止，/其从如云。|| 破旧的鱼笼放在鱼梁上，里面的鱼是鳊鱼和鳏鱼。齐国的女子回来了，随从多得像天上的云。
注：敝：破旧。
注：笱（gǒu）：捕鱼的竹笼，口有倒刺，鱼进去出不来。
注：梁：拦水捕鱼的石堰。
注：鲂（fáng）：鳊鱼。
注：鳏（guān）：一种大鱼，或说即鳡鱼，存疑。
注：齐子：齐国的女子，旧说指文姜。
注：归：出嫁，或指回娘家。
注：从：随从的人。
注：如云：形容众多。
原：敝笱在梁，/其鱼鲂鱮。/齐子归止，/其从如雨。|| 破旧的鱼笼放在鱼梁上，里面的鱼是鳊鱼和鲢鱼。齐国的女子回来了，随从多得像下雨一样。
注：鱮（xù）：鲢鱼一类。
原：敝笱在梁，/其鱼唯唯。/齐子归止，/其从如水。|| 破旧的鱼笼放在鱼梁上，鱼儿自由地游进游出。齐国的女子回来了，随从像流水一样连绵不断。
注：唯唯：鱼儿相随出入、自由自在的样子。

# 载驱
题解：这首诗写齐国之女乘着华美的车马、带着众多随从在通往鲁国的大道上往来，神态悠闲自得。《毛诗序》以为讽刺齐襄公与文姜公然往来、不顾礼法，与《南山》《敝笱》可以互相参看。
原：载驱薄薄，/簟茀朱鞹。/鲁道有荡，/齐子发夕。|| 车子飞驰，马蹄声声，竹帘遮着车后，红色兽皮装饰着车厢。通往鲁国的大道平坦宽阔，齐国的女子从傍晚就出发了。
注：载：语助词，有“乃”“则”的意思。
注：驱：赶车。
注：薄薄：车马疾行的声音。
注：簟茀（diàn fú）：竹席做的车帘，遮在车后。
注：朱鞹（kuò）：漆成红色的去毛兽皮，用来装饰车子。
注：发夕：一说为傍晚出发，一说与“恺悌”“翱翔”同类，形容悠闲自在，存疑。
原：四骊济济，/垂辔濔濔。/鲁道有荡，/齐子岂弟。|| 四匹黑马整齐健美，垂下的缰绳柔顺地摆动。通往鲁国的大道平坦宽阔，齐国的女子悠然自得。
注：骊：黑色的马。
注：济济：整齐美好的样子。
注：辔：缰绳。
注：濔濔（mǐ）：柔软下垂的样子；一说为众多。
注：岂弟：同“恺悌”，和乐自得、毫无顾忌的样子。
原：汶水汤汤，/行人彭彭。/鲁道有荡，/齐子翱翔。|| 汶水浩浩荡荡地流着，随行的人众多盛大。通往鲁国的大道平坦宽阔，齐国的女子悠游自在。
注：汶（wèn）水：水名，在今山东境内，是齐鲁之间的河流。
注：汤汤（shāng）：水势浩大的样子。
注：行人：随行的人。
注：彭彭：众多的样子。
注：翱翔：逍遥游荡。
原：汶水滔滔，/行人儦儦。/鲁道有荡，/齐子游敖。|| 汶水滚滚地流着，随行的人络绎不绝。通往鲁国的大道平坦宽阔，齐国的女子游玩逍遥。
注：滔滔：水流盛大的样子。
注：儦儦（biāo）：人多走动的样子。
注：游敖：同“游遨”，游玩。

# 猗嗟
题解：这首诗赞美一位少年英俊、善于射箭和舞蹈的贵族男子。旧说以为写鲁庄公（文姜之子、齐国的外甥）的仪容和射艺，有人认为其中含有惋惜讽刺之意，今人多读作赞美之诗。
原：猗嗟昌兮，/颀而长兮。/抑若扬兮，/美目扬兮。/巧趋跄兮，/射则臧兮。|| 啊，他是多么健壮英武，身材高大修长。额头宽阔方正，美丽的眼睛顾盼有神。步履灵巧矫健，射起箭来本领高强。
注：猗嗟（yī jiē）：赞叹声。
注：昌：盛壮美好的样子。
注：颀（qí）：身材高。
注：抑若扬兮：“抑”同“懿”，美好；
注：“扬”指额头宽广。一说“抑”“扬”是低头抬头之态，存疑。
注：趋：小步快走。
注：跄（qiāng）：步伐有节奏、矫健的样子。
注：臧：好。
原：猗嗟名兮，/美目清兮，/仪既成兮，/终日射侯。/不出正兮，/展我甥兮。|| 啊，他是多么光彩照人，美丽的眼睛清澈明亮。射礼的仪式已经完成，他整天对着箭靶射箭，箭箭都不偏离靶心，真不愧是我们的外甥啊。
注：名：通“明”，光彩照人。
注：仪：仪式，指射礼。
注：成：完成，具备。
注：侯：用布或兽皮做的箭靶。
注：正：箭靶中心。
注：展：确实，诚然。
注：甥：外甥；旧说鲁庄公是齐襄公之妹文姜所生，所以齐人称他为甥。
原：猗嗟娈兮，/清扬婉兮。/舞则选兮，/射则贯兮。/四矢反兮，/以御乱兮。|| 啊，他是多么俊美，眉目清秀，神采动人。舞蹈合于节拍，射箭能穿透箭靶。四支箭都射中同一处，凭这样的本领足以抵御祸乱。
注：娈（luán）：美好。
注：清扬：眉目清秀。
注：婉：美好。
注：选：齐，指舞步合于节奏；一说为出众，存疑。
注：贯：射穿箭靶。
注：四矢反兮：射礼每人射四箭；“反”一说指四箭都射中同一处，一说指箭射中后再取回，存疑。
注：御乱：抵御祸乱。
