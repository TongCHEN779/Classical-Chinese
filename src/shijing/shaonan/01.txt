# 召南
题解：“召南”与“周南”并称“二南”，旧说指召公奭所治的南方地区所采之诗，今人多认为“南”兼指南方乐调。本组十四篇，题材涉及婚嫁、祭祀、思妇、行役、恋爱等，内容不尽与召公相关。

# 鹊巢
题解：咏贵族女子出嫁、迎亲车马盛大的诗。《毛诗序》以为美“夫人之德”，今人多视为一般的贺婚之歌。
原：维鹊有巢，/维鸠居之。/之子于归，/百两御之。|| 喜鹊筑好了巢，斑鸠住了进来。这位姑娘出嫁了，上百辆车子来迎接她。
注：鹊：喜鹊，善于筑巢。
注：鸠：鸟名，旧说为鸤鸠（布谷），具体所指存疑。诗以鸠居鹊巢比喻女子嫁入夫家。
注：之子于归：这位女子出嫁。归，女子出嫁。
注：百两：百辆车，极言其多。两，同“辆”。御（yà）：同“迓”，迎接。
原：维鹊有巢，/维鸠方之。/之子于归，/百两将之。|| 喜鹊筑好了巢，斑鸠占有了它。这位姑娘出嫁了，上百辆车子护送着她。
注：方：占有、据有。一说为依傍、并居，存疑。
注：将：送，护送。
原：维鹊有巢，/维鸠盈之。/之子于归，/百两成之。|| 喜鹊筑好了巢，斑鸠住满了它。这位姑娘出嫁了，上百辆车子成全了这桩婚礼。
注：盈：满。或谓喻陪嫁之人众多。
注：成：成就，指婚礼完成。

# 采蘩
题解：写女子为公侯采蘩以供祭祀、早晚奔忙的诗。《毛诗序》以为“夫人不失职”，一说为蚕事而采蘩，今多从祭祀说。
原：于以采蘩？/于沼于沚。/于以用之？/公侯之事。|| 到哪里去采白蒿？在池塘边，在小洲上。采来做什么用？为公侯家办祭祀。
注：于以：在哪里，往何处。
注：蘩（fán）：白蒿，可食，古人用作祭品。
注：沼：水池。沚（zhǐ）：水中小洲。
注：公侯之事：指公侯家的祭祀之事。
原：于以采蘩？/于涧之中。/于以用之？/公侯之宫。|| 到哪里去采白蒿？在山间溪流之中。采来做什么用？送到公侯的宗庙里。
注：涧：山间的溪水。
注：宫：宫室，这里指宗庙。
原：被之僮僮，/夙夜在公。/被之祁祁，/薄言还归。|| 头上的发饰整齐端庄，从早到晚在公家忙碌。发饰已经松散下垂，这才匆匆赶回家去。
注：被（bì）：通“髲”，假发、发饰。
注：僮僮（tóng）：整齐庄重貌。
注：祁祁（qí）：舒缓貌，这里形容发饰散乱。
注：薄言：语助词。

# 草虫
题解：思妇怀念远行丈夫的诗，三章由秋虫鸣叫写到登山采菜，反复申说不见之忧与相见之喜。旧说以为大夫之妻能守礼自防，今人多作思妇诗读。
原：喓喓草虫，/趯趯阜螽。/未见君子，/忧心忡忡。/亦既见止，/亦既觏止，/我心则降。|| 草虫喓喓地叫，蚱蜢一蹦一跳。见不到我的丈夫，心中忧愁不安。如果能够见到他，如果能和他相聚，我的心才能放下。
注：喓喓（yāo）：虫鸣声。草虫：草间鸣虫，旧说为蝈蝈之类。
注：趯趯（tì）：跳跃貌。阜螽（zhōng）：蚱蜢一类。
注：忡忡（chōng）：忧愁不安貌。
注：止：语气词。觏（gòu）：遇见，相会。降：放下，指心安。
原：陟彼南山，/言采其蕨。/未见君子，/忧心惙惙。/亦既见止，/亦既觏止，/我心则说。|| 登上那南山，去采山中的蕨菜。见不到我的丈夫，心里愁闷不绝。如果能够见到他，如果能和他相聚，我心里才会欢喜。
注：陟（zhì）：登上。言：语助词。
注：蕨：蕨菜，嫩叶可食。
注：惙惙（chuò）：忧愁不止貌。
注：说：同“悦”。
原：陟彼南山，/言采其薇。/未见君子，/我心伤悲。/亦既见止，/亦既觏止，/我心则夷。|| 登上那南山，去采山中的野豌豆。见不到我的丈夫，我心里悲伤。如果能够见到他，如果能和他相聚，我的心才能平静。
注：薇：野豌豆，嫩苗可食。
注：夷：平，指心情平静。

# 采蘋
题解：写少女采集蘋藻、烹煮并于宗庙陈设祭品的诗。《毛诗序》以为“大夫妻能循法度”，一说与女子出嫁前在宗庙行教成之祭有关。
原：于以采蘋？/南涧之滨。/于以采藻？/于彼行潦。|| 到哪里去采蘋草？在南山溪涧的岸边。到哪里去采水藻？在那路边积水的地方。
注：蘋（pín）：一种水生植物，可食，用作祭品。
注：滨：水边。
注：藻：水藻。
注：行潦（lǎo）：路旁积水或流动的雨水。
原：于以盛之？/维筐及筥。/于以湘之？/维锜及釜。|| 用什么来装它？用方筐和圆筥。用什么来煮它？用三足锜和无足釜。
注：盛（chéng）：装。
注：筐、筥（jǔ）：竹器，方者为筐，圆者为筥。
注：湘：烹煮。
注：锜（qí）：三足锅。釜：无足锅。
原：于以奠之？/宗室牖下。/谁其尸之？/有齐季女。|| 把祭品摆放在哪里？在宗庙的窗下。谁来主持这祭祀？是那恭敬的少女。
注：奠：陈放祭品。
注：宗室：宗庙。牖（yǒu）：窗。
注：尸：主持。
注：齐（zhāi）：通“斋”，恭敬庄重。季女：少女。

# 甘棠
题解：怀念召伯、爱护他曾停留过的甘棠树的诗。旧说召伯为周初召公奭，一说为周宣王时的召伯虎，存疑。
原：蔽芾甘棠，/勿翦勿伐，/召伯所茇。|| 茂盛的甘棠树啊，不要剪它、不要砍它，召伯曾在树下歇宿。
注：蔽芾（fèi）：枝叶茂盛貌。
注：甘棠：棠梨树。
注：翦：剪除。伐：砍伐。
注：茇（bá）：在草野中暂住，这里指在树下歇宿。
原：蔽芾甘棠，/勿翦勿败，/召伯所憩。|| 茂盛的甘棠树啊，不要剪它、不要毁它，召伯曾在树下休息。
注：败：毁坏。
注：憩（qì）：休息。
原：蔽芾甘棠，/勿翦勿拜，/召伯所说。|| 茂盛的甘棠树啊，不要剪它、不要折弯它，召伯曾在树下停留。
注：拜：拉弯、攀折枝条。
注：说（shuì）：通“税”，停驻，歇息。

# 行露
题解：一位女子拒绝强迫婚姻、不惧诉讼的诗。《毛诗序》以为“召伯听讼”，今人多读作女子抗拒强娶之辞；首章与后两章意思不甚连贯，前人有错简之疑。
原：厌浥行露，/岂不夙夜？/谓行多露。|| 道路上露水浓重，难道我不想早晚赶路？只怕路上露水太多。
注：厌浥（yì）：潮湿貌。行：道路。
注：夙夜：早晚，这里指早起夜行。
注：谓：畏惧，或解为“奈何”，存疑。
原：谁谓雀无角！/何以穿我屋？/谁谓女无家？/何以速我狱？/虽速我狱，/室家不足！|| 谁说麻雀没有尖嘴？不然它怎能啄穿我的屋顶？谁说你没有家业势力？不然怎能把我告上公堂？就算把我告上公堂，想要成婚也休想！
注：角：鸟喙，一说指兽角。
注：女：同“汝”，你。家：家业，或指已有家室，存疑。
注：速：招致。狱：官司，诉讼。
注：室家不足：成婚的理由不充分，即不能成婚。一说聘礼不足。
原：谁谓鼠无牙！/何以穿我墉？/谁谓女无家！/何以速我讼？/虽速我讼，/亦不女从！|| 谁说老鼠没有尖牙？不然它怎能打穿我的墙？谁说你没有家业势力？不然怎能把我告到官府？就算把我告到官府，我也绝不顺从你！
注：墉（yōng）：墙。
注：讼：诉讼，打官司。
注：不女从：不从女，不依从你。

# 羔羊
题解：描写大夫退朝或宴毕归来、从容自得的诗。《毛诗序》以为赞美“节俭正直”，也有人认为含讽刺之意，存疑。
原：羔羊之皮，/素丝五紽。/退食自公，/委蛇委蛇。|| 穿着羔羊皮的衣冠，用白丝线密密缝合。从公门用餐回来，步态从容又自得。
注：羔羊之皮：用羔羊皮制成的皮衣，或指皮冠。
注：素丝：白色丝线。五：通“午”，交错。紽（tuó）：缝合处，一说丝的计量单位，存疑。书中印作纟旁简化字形，此处用通行字“紽”。
注：退食自公：从公家吃完饭回来，一说退朝回家用餐。
注：委蛇（wēi yí）：从容自得貌。
原：羔羊之革，/素丝五緎。/委蛇委蛇，/自公退食。|| 穿着羔羊皮的衣冠，白丝线交错缝成。步态从容又自得，从公门退朝用餐。
注：革：去毛的皮，这里与“皮”同义。
注：緎（yù）：缝合处，义近“紽”。书中亦印作纟旁字形。
原：羔羊之缝，/素丝五總。/委蛇委蛇，/退食自公。|| 穿着羔羊皮的衣冠，白丝线交错缝合。步态从容又自得，从公门用餐回来。
注：缝：缝合处，指皮衣的接缝。
注：總：缝合处，义近“紽”“緎”。书中作繁体“總”，照录。

# 殷其雷
题解：妻子思念因公务远行在外的丈夫，盼其归来的诗。《毛诗序》以为召南大夫远行从政、其室家“劝以义”，今人多读作思妇之辞；末句“归哉”或解为盼归，或解为劝去，此处取盼归之义。
原：殷其雷，/在南山之阳。/何斯违斯，/莫敢或遑？/振振君子，/归哉归哉！|| 隆隆的雷声，响在南山的南坡。为什么此时离开这里，连片刻闲暇也不敢有？忠厚勤勉的夫君啊，快回来吧，快回来吧！
注：殷（yǐn）：雷声。其：语助词。
注：阳：山的南面。
注：何斯违斯：为何此时离开此地。前“斯”指此时，后“斯”指此地，一说两“斯”皆指此人此地，存疑。违：离开。
注：遑：闲暇。振振：诚实忠厚貌，一说奋发貌。
原：殷其雷，/在南山之侧。/何斯违斯，/莫敢遑息？/振振君子，/归哉归哉！|| 隆隆的雷声，响在南山的旁边。为什么此时离开这里，连休息也不敢停留？忠厚勤勉的夫君啊，快回来吧，快回来吧！
注：侧：旁边。
注：息：休息。
原：殷其雷，/在南山之下。/何斯违斯，/莫或遑处？/振振君子，/归哉归哉！|| 隆隆的雷声，响在南山脚下。为什么此时离开这里，连安居片刻也不能够？忠厚勤勉的夫君啊，快回来吧，快回来吧！
注：莫或：没有谁，这里犹言“不敢”。
注：处：安居，停留。

# 摽有梅
题解：女子见梅子落地、时光流逝，希望求婚者及时前来的诗。《毛诗序》以为“男女及时”，今人多读作女子求偶之歌，也有人以为是采梅时的歌谣。
原：摽有梅，/其实七兮。/求我庶士，/迨其吉兮。|| 梅子纷纷落下，树上还剩七成。追求我的小伙子们，趁着这好日子来吧。
注：摽（biào）：落下，一说击打。有：语助词。
注：其实七兮：树上的果实还有七成。
注：庶士：众多未婚男子。
注：迨（dài）：趁着。吉：吉日，良辰。
原：摽有梅，/其实三兮。/求我庶士，/迨其今兮。|| 梅子纷纷落下，树上只剩三成。追求我的小伙子们，就趁今天来吧。
注：今：今日，此时。
原：摽有梅，/顷筐塈之。/求我庶士，/迨其谓之。|| 梅子纷纷落下，用斜口筐来收拾。追求我的小伙子们，只要开口说一声就好。
注：顷筐：浅而斜口的竹筐。塈（jì）：取，拾取。
注：谓：说，开口相告。一说通“会”，指相会，存疑。

# 小星
题解：小吏连夜奔波公务、自叹命运不如人的诗。《毛诗序》以为写“夫人无妒忌之行”及众妾进御，今人多读作小官吏行役自伤之辞。
原：嘒彼小星，/三五在东。/肃肃宵征，/夙夜在公。/寔命不同。|| 微微闪烁的小星，三三五五挂在东方。急急忙忙连夜赶路，早晚都在为公事奔走。真是命运和别人不一样。
注：嘒（huì）：微光闪烁貌。
注：三五：三三五五，形容星少。
注：肃肃：急行貌。宵征：夜里赶路。
注：寔（shí）：同“实”，确实，一说是、此。
原：嘒彼小星，/维参与昴。/肃肃宵征，/抱衾与裯。/寔命不犹。|| 微微闪烁的小星，那是参星和昴星。急急忙忙连夜赶路，抱着被子和床单。真是命运比不上别人。
注：参（shēn）、昴（mǎo）：二星宿名。
注：衾：被子。裯（chóu）：床帐或单被。抱，一说通“抛”，存疑。
注：不犹：不如，比不上。

# 江有汜
题解：被弃者自我宽解、预言对方终将后悔的诗。《毛诗序》以为写媵妾之事，今人或读作女子被弃之怨，或读作男子失恋之歌，说法不一。
原：江有汜，/之子归，/不我以。/不我以，/其后也悔！|| 江水有分出又汇回的支流，这个人出嫁了，不再与我相伴。不再与我相伴，日后你会后悔的！
注：汜（sì）：从主流分出又流回的水。
注：之子：这个人。归：出嫁，或指回去。
注：不我以：不以我，不要我、不和我在一起。
原：江有渚，/之子归，/不我与。/不我与，/其后也处！|| 江中有小洲，这个人出嫁了，不再与我同行。不再与我同行，日后你会忧伤的！
注：渚（zhǔ）：水中小洲。
注：与：相与，相伴。
注：处：忧伤，一说安处，存疑。
原：江有沱，/之子归，/不我过。/不我过，/其啸也歌！|| 江水有别出的支流，这个人出嫁了，不再到我这里来。不再到我这里来，日后你会悲歌哭号的！
注：沱（tuó）：江的支流。
注：过：探访，往来。
注：啸也歌：撮口长啸而又放声悲歌，形容悲痛。

# 野有死麕
题解：写男子在郊野猎鹿、以白茅包裹相赠，向女子求爱的诗。《毛诗序》以为“恶无礼”，今人多读作青年男女相恋之诗，末章为女子的叮嘱。
原：野有死麕，/白茅包之。/有女怀春，/吉士诱之。|| 郊野里有一只死獐，用白茅把它包好。有位姑娘正怀着春情，英俊的小伙子来追求她。
注：麕（jūn）：獐子，似鹿而小。
注：白茅：茅草，古人常用来包裹礼物或祭品。
注：怀春：少女思慕异性。
注：吉士：好男子。诱：追求，求爱。
原：林有朴樕，/野有死鹿。/白茅纯束，/有女如玉。|| 林中有小小的灌木，郊野里有一只死鹿。用白茅捆扎妥当，送给那如玉一般的姑娘。
注：朴樕（sù）：小树、灌木。
注：纯（tún）束：捆扎。
注：如玉：形容女子美丽。
原：舒而脱脱兮，/无感我帨兮。/无使尨也吠。|| 慢一些，轻一些呀，不要动我的佩巾呀，别惹得狗儿叫起来。
注：舒而：舒缓地。脱脱（tuì）：轻缓貌。
注：感：通“撼”，动。帨（shuì）：佩巾。
注：尨（máng）：多毛的狗。

# 何彼襛矣
题解：赞美王姬（周王之女）出嫁、车服华美的诗。所嫁者为齐侯之子还是王姬即齐侯之女，以及“平王”所指，历来说法不一，存疑。
原：何彼襛矣？/唐棣之华。/曷不肃雝？/王姬之车。|| 那是什么这样繁盛艳丽？是盛开的唐棣花。怎能不庄严和睦？那是王姬出嫁的车子。
注：襛（nóng）：花木繁盛貌。
注：唐棣（dì）：木名，即郁李一类，花白或红。
注：曷：何。肃雝（yōng）：庄严和谐。
注：王姬：周王之女，周王室姬姓。
原：何彼襛矣？/华如桃李。/平王之孙，/齐侯之子。|| 那是什么这样繁盛艳丽？花儿就像桃李一样。她是平王的外孙女，齐侯的女儿。
注：平王：旧说为周平王，一说“平”为“正”义，泛指周王，存疑。
注：齐侯之子：齐侯的女儿。一说指齐侯的儿子，为新郎，存疑。
原：其钓维何？/维丝伊缗。/齐侯之子，/平王之孙。|| 钓鱼用的是什么？是丝线合搓成的钓绳。她是齐侯的女儿，平王的外孙女。
注：钓：钓具，这里指钓线。《诗经》常以钓鱼喻求偶、婚配。
注：维、伊：语助词。缗（mín）：丝合成的绳。

# 驺虞
题解：赞美猎人或掌管苑囿之官“驺虞”的短歌。《毛诗序》以为驺虞是仁兽，借以颂美；今人多以驺虞为官名或猎人，具体所指存疑。
原：彼茁者葭，/壹发五豝。/吁嗟乎驺虞！|| 那茂盛的芦苇丛中，一下就赶出五头母猪。啊，好一位驺虞！
注：茁（zhuó）：草木初生茂盛貌。葭（jiā）：初生的芦苇。
注：壹发：一发，或指一箭射中，或指一次驱赶出，存疑。豝（bā）：母野猪。
注：吁嗟乎：赞叹声。
注：驺（zōu）虞：掌管苑囿鸟兽的官，一说猎人，又一说为传说中的仁兽。
原：彼茁者蓬，/壹发五豵。/吁嗟乎驺虞！|| 那茂盛的蓬草丛中，一下就赶出五头小猪。啊，好一位驺虞！
注：蓬：蓬草。
注：豵（zōng）：小野猪。
