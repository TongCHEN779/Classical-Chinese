# 大田
题解：写周王（诗中称“曾孙”）治田的农事诗，从备种耕作、除虫、秋收一直写到祭神求福，与《甫田》题材相近。旧说以为刺幽王、思古之作，今人多看作秋收后报祭的乐歌。
原：大田多稼，/既种既戒，/既备乃事。/以我覃耜，/俶载南亩。/播厥百谷，/既庭且硕。/曾孙是若。|| 大片田地要种的庄稼很多，选好了种子，修整好了农具，一切都准备停当，便开始干活。扛起我锋利的犁头，到向阳的田里开始耕作。播下各种谷物，苗儿长得又直又壮，曾孙看了十分满意。
注：戒：备办，指修理农具。
注：覃（yǎn）耜：锋利的犁头。
注：俶（chù）载：开始从事（耕作）。
注：庭：挺直。
注：若：顺，称心。
原：既方既皁，/既坚既好，/不稂不莠。/去其螟螣，/及其蟊贼，/无害我田稚。/田祖有神，/秉畀炎火。|| 谷子渐渐抽穗结实，籽粒饱满又坚实，田里没有空穗也没有杂草。除掉吃心吃叶的害虫，还有咬根咬茎的虫子，别让它们伤害我田里的嫩苗。田祖神灵显应，把害虫抓去丢进烈火里烧掉。
注：方：谷粒初生而未合拢；
注：皁（zào）：谷粒已成形而未坚实。
注：稂（láng）：空穗不结实的禾；
注：莠：形似禾苗的杂草，即狗尾草。
注：螟、螣（tè）、蟊、贼：分别指吃苗心、苗叶、苗根、苗节的害虫。
注：田祖：农神，相传即神农。
注：秉畀（bì）：拿去交给。
原：有渰萋萋，/兴雨祈祈。/雨我公田，/遂及我私。/彼有不获稚，/此有不敛穧。/彼有遗秉，/此有滞穗，/伊寡妇之利。|| 天上阴云密密地聚拢，下起了绵绵细雨。雨水落到公田里，也普遍滋润了我的私田。那边有没割的嫩禾，这边有割了没收的禾把；那边有遗落的一把把禾秆，这边有散在地上的谷穗：这些都留给寡妇们拾取。
注：渰（yǎn）：阴云兴起的样子。
注：萋萋：云密的样子。
注：祈祈：雨徐徐而下的样子。
注：公田、私：公家的田与农人自家的田，具体制度存疑。
注：穧（jì）：已割而未收起的禾把。
注：秉：一把禾。
原：曾孙来止，/以其妇子，/馌彼南亩，/田畯至喜。/来方禋祀，/以其骍黑，/与其黍稷。/以享以祀，/以介景福。|| 曾孙来到田间，带着妻子儿女，给南边田里的人送饭，田官见了满心欢喜。曾孙接着举行禋祀，献上赤色和黑色的牲畜，还有黍和稷。用来献享，用来祭祀，祈求赐予大福。
注：馌（yè）：给在田里劳作的人送饭。
注：田畯（jùn）：管理农事的官。
注：禋（yīn）祀：升烟祭天的祭礼。
注：方：一说为祭四方之神，存疑。
注：骍（xīng）黑：赤色的牲和黑色的牲。
注：介：祈求，助成。
注：景福：大福。

# 瞻彼洛矣
题解：赞美“君子”来到洛水之滨，戎服佩剑，福禄绵长。《毛诗序》以为思古明王、刺幽王；今人多以为是颂美周王会诸侯或检阅军队的诗。
原：瞻彼洛矣，/维水泱泱。/君子至止，/福禄如茨。/韎韐有奭，/以作六师。|| 远望那洛水，水势浩荡宽广。君子来到这里，福禄多得像堆起的屋顶。他戴着鲜红的皮护膝，统率起六军。
注：洛：洛水，此当指流经关中、入渭水的那一条，存疑。
注：泱泱：水深广的样子。
注：茨（cí）：用茅草盖的屋顶，喻积聚之多。
注：韎韐（mèi gé）：赤黄色皮革做的蔽膝，军服所用。
注：奭（shì）：赤色鲜明。
注：六师：天子的六军。
原：瞻彼洛矣，/维水泱泱。/君子至止，/鞞琫有珌。/君子万年，/保其家室。|| 远望那洛水，水势浩荡宽广。君子来到这里，佩刀的鞘上饰着美玉。愿君子万寿无疆，保有他的家室。
注：鞞（bǐng）：刀鞘。
注：琫（běng）：鞘口的饰物。
注：珌（bì）：鞘尾的饰物。
原：瞻彼洛矣，/维水泱泱。/君子至止，/福禄既同。/君子万年，/保其家邦。|| 远望那洛水，水势浩荡宽广。君子来到这里，福禄都聚集在他身上。愿君子万寿无疆，保有他的国家。
注：同：会聚。

# 裳裳者华
题解：以盛开的花起兴，赞美所遇见的“之子”。《毛诗序》以为刺幽王弃贤者之后；今人或以为宴饮中颂美贵族的诗，或读作女子赞美所爱之人的情诗，说法不一。
原：裳裳者华，/其叶湑兮。/我觏之子，/我心写兮。/我心写兮，/是以有誉处兮。|| 花儿开得多么繁盛，叶子多么茂密。我见到了这个人，心里畅快舒展。心里畅快舒展，因此安乐地与他相处。
注：裳裳：同“堂堂”，花盛的样子。
注：湑（xǔ）：茂盛。
注：觏（gòu）：遇见。
注：写：舒畅，把心中郁结倾吐出来。
注：誉处：安乐相处。誉，通“豫”，一说为称誉，存疑。
原：裳裳者华，/芸其黄矣。/我觏之子，/维其有章矣。/维其有章矣，/是以有庆矣。|| 花儿开得多么繁盛，黄澄澄一片鲜亮。我见到了这个人，他是那样有文采风度。他有文采风度，因此值得庆幸。
注：芸：花色浓黄的样子。
注：章：文采，指仪容举止合乎礼度。
原：裳裳者华，/或黄或白。/我觏之子，/乘其四骆。/乘其四骆，/六辔沃若。|| 花儿开得多么繁盛，有黄的也有白的。我见到了这个人，他驾着四匹黑鬃白马。驾着四匹黑鬃白马，六根缰绳光润柔顺。
注：骆：黑鬃的白马。
注：沃若：光泽润美的样子。
原：左之左之，/君子宜之。/右之右之，/君子有之。/维其有之，/是以似之。|| 往左边去，君子能处置得当；往右边去，君子也样样都有。正因为他内有其德，所以外表也与之相称。
注：左、右：旧说以左为阳、右为阴，喻文武、吉凶诸事；一说指驾车左右驰驱，存疑。
注：似：相像，指外在与内在相称；一说读为“嗣”，继承，存疑。

# 桑扈
题解：以羽毛华美的桑扈鸟起兴，祝颂诸侯君子守礼受福。《毛诗序》以为刺幽王君臣无礼；今人多以为天子宴请诸侯时的乐歌。
原：交交桑扈，/有莺其羽。/君子乐胥，/受天之祜。|| 桑扈鸟飞来飞去，羽毛色彩斑斓。君子欢乐无比，承受上天的福佑。
注：交交：鸟往来飞翔或鸣叫的样子。
注：桑扈：鸟名，即青雀一类。
注：莺：羽毛有文采的样子。
注：胥：语气词。
注：祜（hù）：福。
原：交交桑扈，/有莺其领。/君子乐胥，/万邦之屏。|| 桑扈鸟飞来飞去，颈上羽毛斑斓。君子欢乐无比，是天下万国的屏障。
注：领：颈项。
注：屏：屏障，喻护卫王室的重臣。
原：之屏之翰，/百辟为宪。/不戢不难，/受福不那。|| 既是屏障又是栋梁，诸侯都以他为榜样。他能够收敛自持、恭敬谨慎，所受的福泽怎能不多。
注：翰：通“榦”，主干、支柱。
注：百辟：诸侯。
注：宪：法式，榜样。
注：不戢不难：“不”为语助，戢即收敛，难即恭敬戒惧；一说“不”为否定，存疑。
注：那（nuó）：多。
注：“不那”即“岂不多”。
原：兕觥其觩，/旨酒思柔。/彼交匪敖，/万福来求。|| 犀角酒杯弯弯翘起，美酒醇和柔润。与人交往不骄不傲，万般福气都聚拢而来。
注：兕觥（sì gōng）：犀牛角做的酒器。
注：觩（qiú）：角弯曲的样子。
注：思：语助词。
注：柔：酒味醇和。
注：彼交匪敖：一本作“匪交匪敖”，意为不倨慢、不骄傲。敖，同“傲”。
注：求：聚集。

# 鸳鸯
题解：以鸳鸯和马匹起兴，祝颂君子长寿多福。《毛诗序》以为思古明王、刺幽王；今人多视为一般的祝福之歌，也有人以为与婚礼有关，存疑。
原：鸳鸯于飞，/毕之罗之。/君子万年，/福禄宜之。|| 鸳鸯双双飞翔，用长柄小网、大网去捕捉。祝君子万寿无疆，福禄安享不尽。
注：毕：带长柄的小网。
注：罗：张网捕鸟。
注：宜：安享，相宜。
原：鸳鸯在梁，/戢其左翼。/君子万年，/宜其遐福。|| 鸳鸯栖在鱼坝上，把左边的翅膀收拢藏起。祝君子万寿无疆，享受长久的大福。
注：梁：水中拦鱼的石坝。
注：戢（jí）：收敛。此句写鸟栖息时将嘴插入左翅休息；一说指缚住其左翅，存疑。
注：遐：远，长久。
原：乘马在厩，/摧之秣之。/君子万年，/福禄艾之。|| 驾车的马拴在马棚里，喂它铡碎的草，又喂它谷料。祝君子万寿无疆，福禄长久养护着他。
注：乘（shèng）马：拉车的四匹马。
注：厩：马棚。
注：摧（cuò）：同“莝”，铡碎的草，此作动词，用草喂。
注：秣：用谷料喂马。
注：艾：养，辅助。
原：乘马在厩，/秣之摧之。/君子万年，/福禄绥之。|| 驾车的马拴在马棚里，喂它谷料，又喂它碎草。祝君子万寿无疆，福禄让他安享太平。
注：绥：安。

# 頍弁
题解：写贵族宴请兄弟亲戚，席间既欢乐又隐含忧生之叹。《毛诗序》以为诸公刺幽王暴戾、不亲九族；今人多以为周室衰微时的宴饮诗。
原：有頍者弁，/实维伊何？/尔酒既旨，/尔肴既嘉。/岂伊异人？/兄弟匪他。/茑与女萝，/施于松柏。/未见君子，/忧心奕奕。/既见君子，/庶几说怿。|| 戴着高耸的皮帽，这是为了什么？是因为你的酒甘美，你的菜肴丰盛。来的难道是外人？都是兄弟，没有别人。茑草和女萝，攀附在松柏上生长。没见到君子时，心中忧虑不安；见到君子后，才稍感欢喜。
注：頍（kuǐ）：帽子高耸的样子。
注：弁（biàn）：皮帽。
注：伊何：为何。
注：茑（niǎo）：一种寄生灌木。
注：女萝：即松萝，附生于树上。
注：施（yì）：蔓延攀附。
注：奕奕：忧愁不安的样子。
注：说怿（yuè yì）：喜悦。
原：有頍者弁！/实维何期？/尔酒既旨，/尔肴既时。/岂伊异人？/兄弟具来。/茑与女萝，/施于松上。/未见君子，/忧心怲怲。/既见君子，/庶几有臧。|| 戴着高耸的皮帽，这是为了什么？是因为你的酒甘美，你的菜肴精好。来的难道是外人？兄弟们全都来了。茑草和女萝，攀附在松树上。没见到君子时，忧愁满怀；见到君子后，心情才好了些。
注：何期：犹“何其”，为何。
注：时：善，好。
注：怲怲（bǐng）：忧愁深重的样子。
注：臧：善，指心境转好。
原：有頍者弁，/实维在首。/尔酒既旨，/尔肴既阜。/岂伊异人？/兄弟甥舅。/如彼雨雪，/先集维霰。/死丧无日，/无几相见。/乐酒今夕，/君子维宴。|| 戴着高耸的皮帽，戴在头顶。你的酒甘美，你的菜肴丰足。来的难道是外人？都是兄弟和甥舅。好比天要下雪，先落下雪珠。死亡不知哪天就会到来，相聚的日子已经不多。今晚且欢饮美酒，君子尽情宴乐吧。
注：阜：丰盛，多。
注：雨（yù）雪：下雪。
注：霰（xiàn）：雪珠。以先霰后雪喻衰老死亡的预兆。
注：无日：没有多少日子。
注：无几：不多。

# 车舝
题解：写男子驾车迎娶新娘途中的喜悦与思慕。《毛诗序》以为大夫刺幽王、思得贤女以配君子；今人多以为新婚迎亲之诗。
原：间关车之舝兮，/思娈季女逝兮。/匪饥匪渴，/德音来括。/虽无好友，/式燕且喜。|| 车轴的键吱吱作响，我想念那美丽的少女，前去迎娶她。不是因为饥渴，而是她美好的名声吸引我来与她相会。虽然没有好友相陪，也要宴饮欢喜。
注：间关：车轮转动的声音。
注：舝（xiá）：同“辖”，插在车轴两端、防止车轮脱落的键。
注：娈（luán）：美好。
注：季女：少女。
注：逝：往，指前去迎娶。
注：德音：好名声。
注：括：会合。
注：式：语助词。
注：燕：通“宴”，宴饮。
原：依彼平林，/有集维鷮。/辰彼硕女，/令德来教。/式燕且誉，/好尔无射。|| 平原上树林茂密，长尾野鸡聚在林中。那高大美好的女子，带着美德前来教导。宴饮欢乐，我爱你永远不会厌倦。
注：依：茂盛的样子。
注：鷮（jiāo）：长尾的野鸡。书中印作简化字形。
注：辰：善，美好；一说指时，正当其时，存疑。
注：硕女：身材修长的美女。
注：誉：通“豫”，欢乐。
注：射（yì）：厌弃。
原：虽无旨酒，/式饮庶几。/虽无嘉肴，/式食庶几。/虽无德与女，/式歌且舞。|| 虽然没有甘美的酒，也希望你多喝一些。虽然没有丰盛的菜，也希望你多吃一点。虽然我没有足以配你的德行，也要为你唱歌跳舞。
注：庶几：表示希望。
注：德与女：可以与你相配的美德。女，同“汝”。
原：陟彼高冈，/析其柞薪。/析其柞薪，/其叶湑兮。/鲜我觏尔，/我心写兮。|| 登上那高高的山冈，劈砍柞木当柴薪。劈砍柞木当柴薪，它的叶子多么茂盛。能与你相遇实在难得，我心里畅快舒展。
注：柞（zuò）：柞树。
注：析薪：砍柴，《诗经》中常与婚姻相关。
注：湑（xǔ）：茂盛。
注：鲜：少，难得；一说为善，存疑。
注：觏（gòu）：遇见。
注：写：舒畅。
原：高山仰止，/景行行止。/四牡騑騑，/六辔如琴。/觏尔新昏，/以慰我心。|| 高山令人仰望，大道供人行走。四匹公马奔跑不停，六根缰绳协调得像琴弦一样。能遇上你，与你新婚，正可慰藉我的心。
注：仰止：仰望。止，语助词。
注：景行：大路。
注：騑騑（fēi）：马奔跑不停的样子。
注：如琴：缰绳松紧和谐，如同调好的琴弦。
注：昏：同“婚”。

# 青蝇
题解：以嗡嗡乱飞的苍蝇比喻进谗言的小人，劝君子勿听谗言。《毛诗序》以为大夫刺幽王；具体所指何人何事已难考。
原：营营青蝇，/止于樊。/岂弟君子，/无信谗言。|| 嗡嗡乱飞的苍蝇，停在篱笆上。和乐平易的君子，不要听信谗言。
注：营营：苍蝇飞来飞去的声音。
注：樊：篱笆；一说为树名，存疑。
注：岂弟（kǎi tì）：和乐平易。
原：营营青蝇，/止于棘。/谗人罔极，/交乱四国。|| 嗡嗡乱飞的苍蝇，停在酸枣树上。进谗的人不讲准则，把四方之国搅得纷乱。
注：棘：酸枣树。
注：罔极：没有准则，行为不正。
注：交乱：搅乱。
注：四国：四方各国。
原：营营青蝇，/止于榛。/谗人罔极，/构我二人。|| 嗡嗡乱飞的苍蝇，停在榛树上。进谗的人不讲准则，挑拨离间我们两人。
注：榛（zhēn）：榛树。
注：构：构陷，挑拨离间。

# 宾之初筵
题解：描写贵族宴饮与射礼的场面，由初入席时的井然有礼写到醉后的失态，最后提出饮酒的规诫。《毛诗序》以为卫武公刺幽王，韩诗则以为卫武公饮酒自悔之作，都难以确证。
原：宾之初筵，/左右秩秩。/笾豆有楚，/殽核维旅。/酒既和旨，/饮酒孔偕。/钟鼓既设，/举酬逸逸。/大侯既抗，/弓矢斯张。/射夫既同，/献尔发功。/发彼有的，/以祈尔爵。|| 宾客刚刚入席，左右两边井然有序。笾和豆排列整齐，荤菜果品都陈列好了。酒味醇和甘美，大家一齐举杯共饮。钟鼓已经摆设好，互相敬酒往来不断。大箭靶已经竖起，弓箭都已张开。射手们已经聚齐，各自献出射箭的本领。射中那靶心，好让对方罚酒。
注：初筵：刚刚入席。
注：秩秩：有次序的样子。
注：笾（biān）豆：盛食物的竹器和木器。
注：楚：排列整齐。
注：殽（yáo）：鱼肉等菜肴。
注：核：有核的果品。
注：旅：陈列。
注：孔偕：很是齐同协调。
注：逸逸：往来不绝的样子。
注：大侯：大箭靶。
注：抗：举起。
注：的：靶心。
注：祈：求。
注：爵：酒器，此指罚对方饮酒。
原：籥舞笙鼓，/乐既和奏，/烝衎烈祖。/以洽百礼，/百礼既至。/有壬有林，/锡尔纯嘏，/子孙其湛。/其湛曰乐，/各奏尔能。/宾载手仇，/室人入又。/酌彼康爵，/以奏尔时。|| 执籥起舞，笙鼓齐鸣，乐声和谐协调。进献乐舞，使有功的先祖欢乐，配合各种礼仪。各种礼仪都已完备，场面盛大又繁多。神灵赐给你大福，子孙都和乐安康。和乐安康，便各自献出本领。宾客选取比射的对手，主人也加入再射。斟满那大杯的酒，敬给按时射中的人。
注：籥（yuè）舞：执籥而舞。籥，一种管乐器。
注：烝：进献。
注：衎（kàn）：使欢乐。
注：烈祖：有功业的先祖。
注：洽：配合。
注：壬：大。
注：林：多。
注：纯嘏（gǔ）：大福。
注：湛（dān）：快乐。
注：手仇：选取对手。仇，匹配。
注：室人：主人一方。
注：又：再，指再射。
注：康爵：大酒杯。
注：时：一说指射中之时，或指善射的本领，存疑。
原：宾之初筵，/温温其恭。/其未醉止，/威仪反反。/曰既醉止，/威仪幡幡。/舍其坐迁，/屡舞仙仙。/其未醉止，/威仪抑抑。/曰既醉止，/威仪怭怭。/是曰既醉，/不知其秩。|| 宾客刚刚入席，温和而恭敬。还没喝醉时，仪容庄重谨慎。一旦喝醉了，仪容便轻浮失度。离开自己的座位乱走，一次次地翩翩起舞。还没喝醉时，举止谨慎端严。一旦喝醉了，举止就轻慢无礼。这是说喝醉了以后，就不知道礼仪秩序了。
注：反反：慎重的样子。
注：幡幡：轻浮失度的样子。
注：迁：移动。
注：仙仙：舞动轻扬的样子。
注：抑抑：谨慎庄重的样子。
注：怭怭（bì）：轻慢无礼的样子。
原：宾既醉止，/载号载呶。/乱我笾豆，/屡舞僛僛。/是曰既醉，/不知其邮。/侧弁之俄，/屡舞傞傞。/既醉而出，/并受其福。/醉而不出，/是谓伐德。/饮酒孔嘉，/维其令仪。|| 宾客喝醉以后，又是号叫又是喧闹。弄乱了我的笾豆，一次次歪歪斜斜地跳舞。这是说喝醉了以后，就不知道自己的过失。皮帽歪向一边，跳舞跳个不停。喝醉了就离席而去，宾主都能得福。喝醉了还不离去，这就叫败坏德行。饮酒本是很好的事，只是要保持美好的仪态。
注：号：大声叫喊。
注：呶（náo）：喧闹。
注：僛僛（qī）：醉舞歪斜的样子。
注：邮：通“尤”，过错。
注：俄：倾斜。
注：傞傞（suō）：醉舞不止的样子。
注：伐德：败坏德行。
原：凡此饮酒，/或醉或否。/既立之监，/或佐之史。/彼醉不臧，/不醉反耻。/式勿从谓，/无俾大怠。/匪言勿言，/匪由勿语。/由醉之言，/俾出童羖。/三爵不识，/矧敢多又。|| 凡是这样饮酒，有人醉了有人没醉。已经设立了酒监，又配上史官记录。那醉酒的人行为不好，反倒取笑没醉的人。不要跟着去劝人多饮，免得他们更加失礼怠慢。不该说的话不要说，没有根据的话不要讲。要是听信醉话，就会让人去交出没角的公羊来。喝了三杯就已糊涂，哪还敢再多劝酒。
注：监：酒宴上监察礼仪的人。
注：史：记录言行的官。
注：臧：善。
注：式勿从谓：不要跟着劝酒；具体句意历来有异说，存疑。
注：怠：怠慢失礼。
注：由：依从，凭据。
注：童羖（gǔ）：没有角的公羊，世上本无此物，喻醉话荒谬，或说为罚醉者交出不可能之物，存疑。
注：识：知晓，指清醒。
注：矧（shěn）：何况。
注：又：通“侑”，劝酒；一说为再饮，存疑。
