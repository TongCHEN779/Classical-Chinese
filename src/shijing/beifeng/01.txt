# 邶风
题解：邶是周初分封的国名，旧说在殷都朝歌以北，后来并入卫国，所以《邶风》十九篇大多是卫地的诗，只是沿用邶地的名称和乐调。诗中多写弃妇之怨、思妇之愁、征人之苦与离别之悲，情调普遍沉郁。

# 柏舟
题解：抒写一个人遭受群小欺侮、孤立无援而又坚守自我的忧愤。《毛诗序》认为是仁人不遇于卫顷公之作，朱熹等则以为是妇人不得于夫的自伤之辞，作者身份至今说法不一。
原：泛彼柏舟，/亦泛其流。/耿耿不寐，/如有隐忧。/微我无酒，/以敖以游。|| 那只柏木小船，在河中随波漂荡。我心神不宁，整夜睡不着，好像怀着深深的忧伤。并不是我没有酒可以消愁，也不是没有地方去游玩散心。
注：泛：漂浮。
注：柏舟：用柏木造的船。
注：耿耿：心中不安、难以入睡的样子。
注：隐忧：深重的忧伤；一说“隐”通“殷”，盛大。
注：微：非，不是。
注：敖：同“遨”，游玩。
原：我心匪鉴，/不可以茹。/亦有兄弟，/不可以据。/薄言往愬，/逢彼之怒。|| 我的心不是一面镜子，不能把什么都照单全收。我虽也有兄弟，却靠他们不住。我姑且去向他们诉说苦衷，正碰上他们大发脾气。
注：匪：通“非”。
注：鉴：铜镜。
注：茹：容纳，包容；一说为猜度，存疑。
注：据：依靠。
注：薄言：语助词，略有“姑且”之意。
注：愬（sù）：同“诉”，诉说。
原：我心匪石，/不可转也！/我心匪席，/不可卷也！/威仪棣棣，/不可选也！|| 我的心不是石头，不能随便转动；我的心不是席子，不能随意卷起。我的仪容端庄从容，不能任人挑剔、屈从于人。
注：威仪：仪容举止。
注：棣棣（dì）：雍容娴雅的样子。
注：选：一说通“巽”，退让屈服；一说为计数、挑剔，两说并存。
原：忧心悄悄，/愠于群小。/觏闵既多，/受侮不少。/静言思之，/寤辟有摽。|| 我心中忧愁不已，被一群小人所怨恨。遭遇的祸患已经很多，受到的侮辱也不少。静下心来仔细想想，醒来捶胸，痛苦难当。
注：悄悄：忧愁的样子。
注：愠（yùn）：怨恨。
注：群小：众小人。
注：觏（gòu）：遭遇。
注：闵：忧患，祸害。
注：寤：醒着。
注：辟：通“擗”，以手拍胸。
注：摽（biào）：捶打。
原：日居月诸，/胡迭而微？/心之忧矣，/如匪浣衣。/静言思之，/不能奋飞！|| 太阳啊月亮啊，为什么轮番昏暗无光？我心中的忧愁，就像没有洗过的脏衣服一样纠缠不去。静下心来仔细想想，恨不能展翅高飞，离开这里。
注：居、诸：语助词。
注：迭：交替，轮流。
注：微：昏暗不明，一说指日月亏蚀。
注：匪浣衣：没有洗的脏衣服，比喻忧思烦乱不洁；一说“匪”同“彼”，存疑。
注：奋飞：振翅高飞。

# 绿衣
题解：诗人睹物思人，借亡妻亲手缝制的衣裳寄托悼念之情，向来被视为悼亡诗的先声。《毛诗序》说是卫庄姜伤妾上僭、己失位而作，今人多从悼亡之说。
原：绿兮衣兮，/绿衣黄里。/心之忧矣，/曷维其已！|| 绿色的衣啊，绿色的上衣黄色的衬里。心中的忧伤啊，什么时候才能停止！
注：衣：上衣。
注：里：衣服的衬里。
注：曷：何，何时。
注：维：语助词。
注：已：止，停止。
原：绿兮衣兮，/绿衣黄裳。/心之忧矣，/曷维其亡！|| 绿色的衣啊，绿色的上衣黄色的下裳。心中的忧伤啊，什么时候才能忘掉！
注：裳：下身穿的衣服，类似裙。
注：亡：通“忘”；一说同“已”，止息。
原：绿兮丝兮，/女所治兮。/我思古人，/俾无訧兮！|| 绿色的丝啊，是你亲手整理缝制的。我思念故去的人，是她让我少犯过错。
注：女（rǔ）：同“汝”，你。
注：治：整理，指纺织缝制。
注：古人：故人，指亡妻。
注：俾：使。
注：訧（yóu）：同“尤”，过失。
原：絺兮绤兮，/凄其以风。/我思古人，/实获我心。|| 细葛布啊粗葛布，穿在身上被风一吹凉意凄凄。我思念故去的人，她最能体贴我的心意。
注：絺（chī）：细葛布。
注：绤（xì）：粗葛布。
注：凄其：凄然，寒凉的样子。
注：获我心：合我心意，深知我心。

# 燕燕
题解：一首送别诗，写送远嫁女子时的依依不舍。《毛诗序》认为是卫庄姜送归妾戴妫之作；从末章“先君”“寡人”等语看，今人多理解为国君送妹远嫁，具体人物难以确考。
原：燕燕于飞，/差池其羽。/之子于归，/远送于野。/瞻望弗及，/泣涕如雨。|| 燕子双双飞翔，翅羽参差舒展。这位姑娘就要出嫁，我远远送她到郊野。望着她的身影直到看不见，我泪流如雨。
注：燕燕：燕子，叠称；一说指一双燕子。
注：于：语助词。
注：差（cī）池：参差不齐的样子，形容燕尾和双翼张开。
注：之子：这个人，指出嫁的女子。
注：于归：出嫁。
注：野：城外郊野。
注：弗及：赶不上，看不见。
原：燕燕于飞，/颉之颃之。/之子于归，/远于将之。/瞻望弗及，/伫立以泣。|| 燕子双双飞翔，忽而向上忽而向下。这位姑娘就要出嫁，我远远地送她一程。望着她的身影直到看不见，我久久站在那里哭泣。
注：颉（xié）：向上飞；
注：颃（háng）：向下飞。旧注上下说法相反，此从一说。
注：将：送。
注：伫立：久立。
原：燕燕于飞，/下上其音。/之子于归，/远送于南。/瞻望弗及，/实劳我心。|| 燕子双双飞翔，鸣声忽低忽高。这位姑娘就要出嫁，我远远送她到南边。望着她的身影直到看不见，实在令我伤心。
注：下上其音：鸣声随着飞翔忽高忽低。
注：南：南郊；一说“南”当作“林”，存疑。
注：劳：忧伤，愁苦。
原：仲氏任只，/其心塞渊。/终温且惠，/淑慎其身。/先君之思，/以勖寡人。|| 二妹为人诚信可靠，心地笃实而深沉。她既温和又柔顺，立身善良而谨慎。临行还叮嘱我要怀念先君，用这话来勉励我。
注：仲氏：排行第二的人，这里指出嫁的女子。
注：任：诚实可信；一说指任姓，存疑。
注：只：语气词。
注：塞：诚实。
注：渊：深沉。
注：终……且……：既……又……。
注：惠：柔顺。
注：淑：善良。
注：先君：已故的国君。
注：勖（xù）：勉励。
注：寡人：国君自称。

# 日月
题解：一个被冷落的女子呼告日月、怨诉对方变心、不再善待自己。《毛诗序》以为卫庄姜伤己不见答于庄公之作，今人多理解为弃妇之辞。
原：日居月诸，/照临下土。/乃如之人兮，/逝不古处。/胡能有定？/宁不我顾。|| 太阳啊月亮啊，光辉照临大地。可是像这样的人啊，竟不再像从前那样待我。他的心怎么才能安定下来？竟然不再顾念我。
注：居、诸：语助词。
注：下土：大地。
注：乃如之人：竟像这样的人。
注：逝：发语词。
注：古处：像过去那样相处；一说“古”通“故”。
注：胡：何。
注：定：心意安定，指行为有常。
注：宁：乃，竟。
原：日居月诸，/下土是冒。/乃如之人兮，/逝不相好。/胡能有定？/宁不我报。|| 太阳啊月亮啊，光辉覆盖大地。可是像这样的人啊，竟不再和我相亲相爱。他的心怎么才能安定下来？竟然对我毫不回应。
注：冒：覆盖，指光照普及。
注：相好：相亲相爱。
注：报：回报，回应；一说与古代婚俗有关，存疑。
原：日居月诸，/出自东方。/乃如之人兮，/德音无良。/胡能有定？/俾也可忘？|| 太阳啊月亮啊，从东方升起。可是像这样的人啊，说的话做的事全无善意。他的心怎么才能安定下来？难道要我把这一切都忘掉？
注：德音：言语，名声；这里指对方的言行。
注：无良：不善。
注：俾：使。
注：俾也可忘：一说使我忘掉忧伤，一说指对方把我遗忘，两说并存。
原：日居月诸，/东方自出。/父兮母兮，/畜我不卒。/胡能有定？/报我不述。|| 太阳啊月亮啊，从东方升起。爹啊娘啊，他对我的爱护没能始终如一。他的心怎么才能安定下来？对待我全不循常理。
注：畜：爱养，喜爱。
注：卒：终，到底。
注：述：遵循，指合乎常道；一说为“遂”，成就，存疑。

# 终风
题解：一个女子诉说对方性情暴戾、对自己戏谑轻慢，却仍难以割舍的复杂心情。《毛诗序》以为庄姜伤州吁之暴，今人多理解为女子怨其所爱之诗。
原：终风且暴，/顾我则笑。/谑浪笑敖，/中心是悼。|| 风刮得又大又猛，他一回头看我就笑。那轻佻放肆的嬉笑，让我心里又怕又伤。
注：终：既。
注：暴：疾风，暴风。
注：顾：回头看。
注：谑浪笑敖：戏谑放荡，轻慢调笑；敖，同“傲”，存疑。
注：悼：伤心，害怕。
原：终风且霾，/惠然肯来。/莫往莫来，/悠悠我思。|| 风刮得又大又昏，尘土飞扬，他倘若心里有我，就会来看我。如今他不来也不往，我的思念绵绵不断。
注：霾（mái）：风夹尘土，天色昏暗。
注：惠然：顺从的样子，有爱顾之意。
注：肯：愿意。
注：悠悠：思念绵长的样子。
原：终风且曀，/不日有曀。/寤言不寐，/愿言则嚏。|| 风刮得又大又阴，没过一天又是阴沉沉。我醒着无法入睡，思念他思念得直打喷嚏。
注：曀（yì）：天色阴沉而有风。
注：不日：不到一天；一说“不见日”。
注：有：又。
注：寤言：醒着；
注：“言”为语助词。
注：愿：思念。
注：嚏：打喷嚏；古俗认为被人思念时会打喷嚏，存疑。
原：曀曀其阴，/虺虺其雷。/寤言不寐，/愿言则怀。|| 天色阴沉沉，雷声轰隆隆。我醒着无法入睡，思念他，心中伤感。
注：曀曀：阴沉昏暗的样子。
注：虺虺（huǐ）：雷声低沉初发的样子。
注：怀：思念，伤怀。

# 击鼓
题解：一个卫国士兵随军南征、久戍不归，追忆与妻子的誓约而发出绝望的悲叹。《毛诗序》系于卫州吁用兵，也有学者联系其他史事，确切背景难以断定。
原：击鼓其镗，/踊跃用兵。/土国城漕，/我独南行。|| 战鼓擂得镗镗响，兵士们踊跃操练刀枪。别人在国内修路筑城于漕地，唯独我要随军南征。
注：镗（tāng）：鼓声。
注：踊跃：跳跃，形容操练时的动作。
注：兵：兵器。
注：土国：在国都服土木之役。
注：城漕：在漕邑修筑城墙。漕，卫国地名。
原：从孙子仲，/平陈与宋。/不我以归，/忧心有忡。|| 跟随统帅孙子仲，去调停陈国和宋国。却不让我回家，我的心忧愁不安。
注：孙子仲：人名，当时卫国的将领。
注：平：调和、平定。
注：陈、宋：均为诸侯国名，在卫国南面。
注：不我以归：即“不以我归”，不让我回家。
注：有忡：忡忡，忧虑不安。
原：爰居爰处，/爰丧其马。/于以求之？/于林之下。|| 在哪里驻扎安身？在哪里丢失了战马？到哪里去寻找它？原来在那片树林下面。
注：爰：何处，于何；一说为语助词“于是”。
注：居、处：住，驻扎。
注：丧：丢失。
注：于以：在哪里。
原：死生契阔，/与子成说。/执子之手，/与子偕老。|| 无论生死聚散，我和你早已立下誓约。我曾紧握你的手，说要与你一同白头到老。
注：契阔：聚合与离散；一说指勤苦，存疑。
注：子：你，指妻子。
注：成说：订下誓言。
注：偕老：共同老去。
原：于嗟阔兮，/不我活兮！/于嗟洵兮，/不我信兮！|| 唉，相隔太远了啊，让我无法与你相会！唉，离别太久了啊，让我无法兑现誓言！
注：于（xū）嗟：感叹词。
注：阔：远离。
注：活：一说通“佸”，相会；一说指活命，两说并存。
注：洵：远；一说指诚信，存疑。
注：信：一说通“伸”，实践誓言；一说为信守。

# 凯风
题解：儿子感念母亲含辛茹苦、抚育七子，而自愧不能使母亲宽慰。《毛诗序》以为卫地之母不安其室、七子自责之诗，具体本事已难确考，今人多读作颂母自责之作。
原：凯风自南，/吹彼棘心。/棘心夭夭，/母氏劬劳。|| 和暖的南风吹来，吹拂着那小酸枣树的嫩芽。嫩芽生长得茁壮茂盛，母亲却为此辛苦劳累。
注：凯风：和风，南风。
注：棘：酸枣树，丛生多刺。
注：棘心：棘木初生的嫩芽，比喻幼子。
注：夭夭：茁壮美好的样子。
注：劬（qú）劳：辛苦劳累。
原：凯风自南，/吹彼棘薪。/母氏圣善，/我无令人。|| 和暖的南风吹来，吹拂着已经长成柴薪的棘木。母亲明理又善良，我们兄弟却没有一个成器。
注：棘薪：长大可以当柴烧的棘木，比喻子女已经长大。
注：圣：明达事理。
注：令：善，好。
原：爰有寒泉，/在浚之下。/有子七人，/母氏劳苦。|| 有一眼清凉的泉水，在浚邑城下流淌。母亲有七个儿子，自己还要辛苦操劳。
注：寒泉：清凉的泉水；一说为泉名。
注：浚（xùn）：卫国邑名。
原：睍睆黄鸟，/载好其音。/有子七人，/莫慰母心。|| 黄鸟婉转鸣叫，声音那么动听。母亲有七个儿子，却没有一个能宽慰她的心。
注：睍睆（xiàn huǎn）：鸟鸣声清和宛转；一说指黄鸟美丽的样子。
注：黄鸟：黄雀，一说黄鹂。
注：载：语助词，有“则”之意。

# 雄雉
题解：妻子思念远役的丈夫，牵挂难已，末章转而责问在位者。《毛诗序》以为讽刺卫宣公淫乱、军旅数起，今人多读作思妇之诗。
原：雄雉于飞，/泄泄其羽。/我之怀矣，/自诒伊阻。|| 雄野鸡飞上天，缓缓扇动着翅膀。我心中这样思念，是自己给自己找来的忧愁。
注：雉：野鸡。
注：泄泄（yì）：鼓翅缓飞的样子。
注：怀：思念。
注：诒（yí）：留下，给予。
注：伊：语助词，一说为“此”。
注：阻：忧患，一说指阻隔。
原：雄雉于飞，/下上其音。/展矣君子，/实劳我心。|| 雄野鸡飞上天，鸣声忽上忽下。我那诚实的丈夫啊，实在让我挂心。
注：展：诚然，确实；一说诚实。
注：君子：这里指丈夫。
注：劳：忧思，牵挂。
原：瞻彼日月，/悠悠我思。/道之云远，/曷云能来？|| 望着那太阳和月亮，日复一日，我的思念悠长不尽。道路这样遥远，他什么时候才能回来？
注：瞻：仰望。
注：日月：指时光流转。
注：云：语助词。
注：曷：何时。
原：百尔君子，/不知德行？/不忮不求，/何用不臧！|| 你们这些在位的君子们，难道不懂什么叫德行？不去害人也不贪求，做什么会不好呢！
注：百尔：凡是你们，泛指众人。
注：君子：指在位的贵族、官员。
注：忮（zhì）：嫉妒，害人。
注：求：贪求。
注：何用：为何，怎么。
注：臧：善，好。

# 匏有苦叶
题解：一个女子清晨在济水渡口等候心上人前来迎娶，催促他及时过河，不愿随舟子先渡。《毛诗序》以为讽刺卫宣公与夫人淫乱，今人多理解为女子盼婚之诗。
原：匏有苦叶，/济有深涉。/深则厉，/浅则揭。|| 葫芦的叶子已经枯黄，济水上有深深的渡口。水深就索性连衣涉水，水浅就提起衣裳趟过来。
注：匏（páo）：葫芦。
注：苦叶：枯叶；“苦”一说通“枯”。叶枯则葫芦成熟，可系在身上助人渡水。
注：济：水名，在卫地。
注：涉：渡口。
注：厉：连衣涉水；一说为腰系葫芦渡水，存疑。
注：揭（qì）：提起衣裳。
原：有瀰济盈，/有鷕雉鸣。/济盈不濡轨，/雉鸣求其牡。|| 济水涨得满满的，雌野鸡在咿咿地叫。济水虽满，却淹不湿车轴头；雌野鸡鸣叫，是在呼唤它的伴侣。
注：瀰（mǐ）：水满的样子。
注：盈：满。
注：鷕（yǎo）：雌雉的叫声。
注：濡：沾湿。
注：轨：车轴的两端。
注：牡：雄性鸟兽，这里指雄雉。
原：雝雝鸣雁，/旭日始旦，/士如归妻，/迨冰未泮。|| 大雁雝雝地鸣叫，太阳刚刚升起。你如果真要娶妻，就趁着河冰还没有融化的时候。
注：雝雝（yōng）：雁鸣的和声。
注：旭日：初升的太阳。
注：旦：天明。
注：归妻：娶妻。
注：迨（dài）：趁着。
注：泮（pàn）：融解；一说为合、冻结，两说并存。
原：招招舟子，/人涉卬否。/人涉卬否，/卬须我友。|| 船夫招着手叫人上船，别人都渡河去了，我却不去。别人都渡河去了，我却不去，我在等候我的心上人。
注：招招：招手的样子。
注：舟子：船夫。
注：卬（áng）：我，女子自称。
注：否：不，指不渡河。
注：须：等待。
注：友：情侣，指心上人。
