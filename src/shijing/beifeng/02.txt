# 谷风
题解：一位被丈夫遗弃的妇人诉说往日持家的辛劳与今日的冷遇。《毛诗序》说是刺卫国夫妇失道、“新昏而弃其旧室”，今人多读作弃妇诗。
原：习习谷风，/以阴以雨。/黾勉同心，/不宜有怒。/采葑采菲，/无以下体？/德音莫违，/及尔同死。|| 山谷里的风呼呼地吹，天色阴沉又下起雨来。我们本该同心协力过日子，你不该对我动辄发怒。采蔓菁、采萝卜的人，难道会因为叶子不好就连根也扔掉吗？当初的好话不该违背，说过要和你同生共死。
注：习习：风声连绵不断。谷风：从山谷吹来的风，一说东风。
注：黾（mǐn）勉：尽力，勉力。
注：葑（fēng）、菲：蔓菁和萝卜一类的菜，根叶都可食。下体：指根茎。两句以菜根比喻人的根本品德，不该因容色衰减而被弃。
注：德音：善言，指当初的誓言。
原：行道迟迟，/中心有违。/不远伊迩，/薄送我畿。/谁谓荼苦？/其甘如荠。/宴尔新昏，/如兄如弟。|| 我走在离家的路上步子迟缓，心里百般不情愿。不求你远送，只送到近处也好，你却只送我到门槛边就止步。谁说苦菜味道苦？比起我的苦处，它甜得像荠菜。你们新婚燕尔正快乐，亲热得像兄弟一般。
注：违：怨恨不舍，一说离别。
注：伊：语助词。迩：近。畿（jī）：门内，门槛。
注：荼（tú）：苦菜。荠（jì）：荠菜，味甘。
注：宴：安乐。昏：同“婚”。
原：泾以渭浊，/湜湜其沚。/宴尔新昏，/不我屑以。/毋逝我梁，/毋发我笱。/我躬不阅，/遑恤我后。|| 泾水因为和渭水相比才显得浑浊，它的水底其实清清亮亮。你们新婚快乐，却不屑再与我为伍。不要到我筑的鱼坝上去，不要打开我编的鱼篓。可我自己都已不被容纳，哪还顾得上身后的事情？
注：泾、渭：两条河名，泾水注入渭水。两水清浊的说法历来不一，此处大意是妇人自比本来清白，存疑处从略。
注：湜（shí）湜：水清见底。沚：水底，一说小洲，存疑。
注：屑：顾惜，愿意。以：与，相处。
注：梁：拦水捕鱼的石坝。笱（gǒu）：竹编的捕鱼篓。躬：自身。阅：容纳。遑：何暇。恤：忧虑，顾及。
原：就其深矣，/方之舟之；/就其浅矣，/泳之游之。/何有何亡，/黾勉求之。/凡民有丧，/匍匐救之。|| 遇到深水，就用筏子、用船渡过去；遇到浅水，就下水游过去。家里有什么、缺什么，我都尽力去张罗。邻里乡亲有了灾难，我也拼尽全力去帮忙。
注：就：遇到，走近。方：竹木筏，此作动词，乘筏渡水。舟：乘船。
注：亡：无。
注：民：人，指邻里。丧：灾祸。匍匐：手足并行，形容竭尽全力。
原：能不我慉，/反以我为雠。/既阻我德，/贾用不售。/昔育恐育鞫，/及尔颠覆。/既生既育，/比予于毒。|| 你不但不爱惜我，反而把我当成仇人。你拒绝了我的一片好意，就像货物卖不出去被人嫌弃。从前日子穷困，总怕生计艰难，和你一同吃尽苦头。如今家境好了，你却把我比作毒物。
注：慉（xù）：爱，养。此句通行本多作“不我能慉”，书中依《说文》所引作“能不我慉”。
注：雠：仇敌。阻：拒绝。德：好意，恩情。贾（gǔ）：卖。
注：育：生，指过日子。鞫（jū）：穷困。颠覆：困顿，艰难。此两句文意古来解说不一，存疑。
注：生、育：指生计好转，一说指生儿育女。毒：毒物。
原：我有旨蓄，/亦以御冬。/宴尔新昏，/以我御穷。/有洸有溃，/既诒我肄。/不念昔者，/伊余来塈。|| 我储存了些美味的干菜，好用来度过寒冬。你们新婚快乐，当初娶我不过是拿我来抵挡贫穷。你对我粗暴凶狠，把劳苦的活儿全推给我。你一点不念从前，当初你是那样爱我。
注：旨：味美。蓄：储藏的菜。御：抵挡。
注：洸（guāng）、溃：形容粗暴发怒的样子。诒（yí）：给予。肄（yì）：劳苦。
注：伊：语助词，一说“惟”。塈（xì）：爱，一说休息，存疑。

# 式微
题解：《毛诗序》说是黎侯寓居于卫、其臣劝他归国之作；今人或读作服役者的怨歌，或读作男女相会时的戏答，说法不一。
原：式微式微，/胡不归？/微君之故，/胡为乎中露？|| 天色暗了，天色暗了，为什么还不回去？若不是为了你的缘故，我何必待在露水里？
注：式：发语词。微：昏暗，指天将黑。
注：微：非，若不是。君：你，一说指君主。
注：中露：露中，倒文。
原：式微式微，/胡不归？/微君之躬，/胡为乎泥中？|| 天色暗了，天色暗了，为什么还不回去？若不是为了你本人，我何必待在泥水里？
注：躬：身体，自身。

# 旄丘
题解：《毛诗序》以为黎国臣子责卫国不肯救助流亡的黎侯；今人也有读作女子思念久出不归的情人之作，此处译文从后一种理解。
原：旄丘之葛兮，/何诞之节兮。/叔兮伯兮，/何多日也？|| 旄丘上的葛藤啊，枝节怎么长得这样长了。叔啊伯啊，为何一去这么多日子？
注：旄（máo）丘：前高后低的土丘，一说卫地名。
注：诞：延长，蔓延。节：葛藤的节，一说指枝节长。
注：叔、伯：兄弟排行，用作对男子的称呼。
原：何其处也？/必有与也。/何其久也？/必有以也。|| 为什么安居不动？想必是有了同伴。为什么拖延这么久？想必有别的缘故。
注：处：安居，滞留。与：同伴，盟友。以：原因，一说同“与”。
原：狐裘蒙戎，/匪车不东。/叔兮伯兮，/靡所与同。|| 狐皮袍子已经蓬乱，不是没有车子东来。叔啊伯啊，却没有人与我同心。
注：蒙戎：毛蓬松散乱的样子。
注：匪：非，一说“彼”。东：向东来，动词。此句解说不一，存疑。
注：靡：无。与同：同心，同在一处。
原：琐兮尾兮，/流离之子。/叔兮伯兮，/褎如充耳！|| 渺小啊卑微啊，我们这些流离失所的人。叔啊伯啊，你们却像耳朵塞住了一样不闻不问！
注：琐、尾：细小卑微的样子，一说指鸟鸣，存疑。
注：流离：流亡离散；一说即鸟名“鹠鷅”。
注：褎（yòu）如：盛服的样子，一说笑貌。充耳：古人冠旁垂饰，塞于耳旁，这里比喻装聋不闻。

# 简兮
题解：描写宫廷前表演万舞的舞师，并抒发对他的爱慕。《毛诗序》说是刺卫国不用贤人、使贤者仕于伶官，今人多读作赞美舞师之诗。
原：简兮简兮，/方将万舞。/日之方中，/在前上处。|| 鼓声咚咚，盛大的万舞就要开始。太阳正当中午，舞师站在前列的显要位置。
注：简：鼓声，一说形容舞者威武。
注：万舞：古代大型乐舞，包括执干戚的武舞和执籥翟的文舞。
注：在前上处：在前列上首，一说指舞位在堂前高处。
原：硕人俣俣，/公庭万舞。/有力如虎，/执辔如组。|| 那高大的舞人身姿魁梧，在公侯的庭院里跳起万舞。他力气大得像老虎，握着缰绳就像握着一束丝带般从容。
注：硕人：身材高大的人。俣（yǔ）俣：魁梧健壮的样子。
注：辔（pèi）：马缰绳。组：编织的丝带。此句形容舞中模拟驾车动作娴熟。
原：左手执籥，/右手秉翟。/赫如渥赭，/公言锡爵。|| 他左手拿着籥管，右手举着野鸡尾羽。脸色红润得像涂了赭土，公侯吩咐赏他一杯酒。
注：籥（yuè）：古管乐器，似笛。秉：持。翟（dí）：野鸡的长尾羽，文舞所执。
注：赫：赤红色。渥（wò）：浸润、涂染。赭（zhě）：红土。
注：锡：同“赐”。爵：酒器，这里指酒。
原：山有榛，/隰有苓。/云谁之思？/西方美人。/彼美人兮，/西方之人兮！|| 山上长着榛树，洼地长着苓草。我心中想念的是谁？是那西方来的美男子。那个美男子啊，他是西方来的人啊！
注：榛（zhēn）：落叶灌木，果实似栗而小。隰（xí）：低湿之地。苓：草名，说法不一，或说甘草、卷耳，或说通“莲”，存疑。
注：西方美人：西方来的美人，指舞师；旧说以西方指西周王室，喻贤者。

# 泉水
题解：卫国女子远嫁他国，思念故乡想回去却不能如愿。《毛诗序》说是卫女嫁于诸侯、父母已终、思归宁而不得之作。
原：毖彼泉水，/亦流于淇。/有怀于卫，/靡日不思。/娈彼诸姬，/聊与之谋。|| 那涌流的泉水，尚且能流进淇河。我心里怀念卫国，没有一天不在思念。那些美好的同族姊妹，我姑且和她们商量商量。
注：毖（bì）：泉水涌流的样子，一说同“泌”。
注：淇：卫国河名，流经今河南北部。
注：娈（luán）：美好。诸姬：随嫁的同姓女子。卫为姬姓，故称。
注：聊：姑且。谋：商量。
原：出宿于泲，/饮饯于祢。/女子有行，/远父母兄弟。/问我诸姑，/遂及伯姊。|| 当初出嫁，在泲地住宿，在祢地喝了饯行酒。女子出嫁，就要远离父母兄弟。临行时问候各位姑母，也问候了大姐。
注：泲（jǐ）、祢（nǐ）：地名，都在卫国附近，具体所在存疑。饯：设酒送行。
注：有行：出嫁。
注：诸姑：父亲的姊妹们。伯姊：大姐。
原：出宿于干，/饮饯于言。/载脂载舝，/还车言迈。/遄臻于卫，/不瑕有害？|| 回去时就在干地住宿，在言地饮饯行酒。给车轴上好油，插紧车辖，掉转车头就出发。很快就能回到卫国，这难道会有什么不妥吗？
注：干、言：地名，所在不详。
注：脂：用油涂车轴，动词。舝（xiá）：同“辖”，插在车轴头上固定车轮的销子，这里作动词。
注：还（xuán）车：掉转车头。言：语助词。迈：行。
注：遄（chuán）：迅速。臻：到。不瑕：不至于，一说“瑕”通“何”。
原：我思肥泉，/兹之永叹。/思须与漕，/我心悠悠。/驾言出游，/以写我忧。|| 我想起肥泉，不禁连连长叹。想起须邑和漕邑，我的心绪悠长无尽。只好驾车出去游一游，好排遣我的忧愁。
注：肥泉：卫国泉名。兹：同“滋”，更加。永叹：长叹。
注：须、漕：卫国地名。悠悠：忧思绵长。
注：写：同“泻”，抒发、排除。

# 北门
题解：一个小官吏公务繁重、家境贫寒，回家又遭家人责怪，只能归之于天命。《毛诗序》说是“刺仕不得志”。
原：出自北门，/忧心殷殷。/终窭且贫，/莫知我艰。/已焉哉！/天实为之，/谓之何哉？|| 我从北门走出来，心里忧愁沉沉。既寒酸又贫穷，没人知道我的艰难。算了吧！这是老天安排的，我又能怎么样呢？
注：殷殷：忧伤深重的样子。
注：终：既。窭（jù）：贫寒简陋，困窘。
注：已焉哉：算了吧。谓之何：对它能怎么办。
原：王事适我，/政事一埤益我。/我入自外，/室人交遍谪我。/已焉哉！/天实为之，/谓之何哉？|| 王家的差事扔给我，公家的杂务全都加在我身上。我从外面回到家里，家人却轮番责备我。算了吧！这是老天安排的，我又能怎么样呢？
注：王事：王朝或国家的差事。适：通“擿”，投掷，一说“之”。
注：一：全都。埤（pí）益：增加。
注：室人：家里人。交遍：交相、轮番。谪（zhé）：责备。
原：王事敦我，/政事一埤遗我。/我入自外，/室人交遍摧我。/已焉哉！/天实为之，/谓之何哉？|| 王家的差事压给我，公家的杂务全都推给我。我从外面回到家里，家人轮番挖苦我。算了吧！这是老天安排的，我又能怎么样呢？
注：敦：逼迫，催促，一说堆积。
注：遗（wèi）：交给，加给。
注：摧：讥刺，挫辱。

# 北风
题解：在风雪交加的时节，诗人呼唤所爱之人携手同去，情势急迫。《毛诗序》说是卫国暴虐、百姓相携而去；今人或读作男女相约出奔之诗。
原：北风其凉，/雨雪其雱。/惠而好我，/携手同行。/其虚其邪？/既亟只且！|| 北风多么寒冷，大雪纷纷扬扬。你若真心爱我，就和我携手同行。哪里还能从容迟缓？事情已经十分急迫了！
注：雨（yù）雪：下雪，“雨”作动词。雱（pāng）：雪下得很大。
注：惠：爱，一说语助词。好：喜爱。
注：虚：同“舒”，宽缓。邪（xú）：同“徐”，迟缓。
注：亟：急。只且（jū）：语气词。
原：北风其喈，/雨雪其霏。/惠而好我，/携手同归。/其虚其邪？/既亟只且！|| 北风呼呼急吹，雪花漫天飞舞。你若真心爱我，就和我携手同归。哪里还能从容迟缓？事情已经十分急迫了！
注：喈（jiē）：风声急疾，一说寒冷。
注：霏：雪纷飞的样子。
注：同归：一同去往归宿之处。
原：莫赤匪狐，/莫黑匪乌。/惠而好我，/携手同车。/其虚其邪？/既亟只且！|| 没有不红的狐狸，没有不黑的乌鸦。你若真心爱我，就和我携手同车。哪里还能从容迟缓？事情已经十分急迫了！
注：匪：非。两句意为狐狸都是赤色、乌鸦都是黑色，旧说以喻当政者同样凶恶，今人解说不一，存疑。

# 静女
题解：写一对青年男女约会、互赠信物的欢愉。《毛诗序》以为刺卫君无道、夫人无德；今人多读作情诗。
原：静女其姝，/俟我于城隅。/爱而不见，/搔首踟蹰。|| 文静的姑娘多么美丽，约好在城角等我。她藏起来不让我看见，急得我挠着头来回徘徊。
注：静女：娴静的女子，一说贞静善良的女子。姝（shū）：美好。
注：俟（sì）：等待。城隅：城墙的角落，一说城角楼。
注：爱：通“薆”，隐藏。踟蹰（chí chú）：徘徊不前。
原：静女其娈，/贻我彤管。/彤管有炜，/说怿女美。|| 文静的姑娘多么美好，送给我一支红色的管儿。这红管儿光彩鲜亮，我喜爱你的美丽。
注：娈（luán）：美好。贻：赠送。
注：彤管：红色的管状物，究竟是何物说法很多，或说红笔管，或说乐器，或说初生的草茎，存疑。
注：炜（wěi）：鲜红有光。说怿（yuè yì）：喜悦。女：同“汝”，指彤管，一说指姑娘。
原：自牧归荑，/洵美且异。/匪女之为美，/美人之贻。|| 她从郊野采来茅草嫩芽送我，这东西确实美好又特别。并不是你这茅芽本身有多美，因为是美人送的才珍贵。
注：牧：郊外放牧之地。归：通“馈”，赠送。荑（tí）：初生的茅草嫩芽。
注：洵（xún）：确实。异：特别，与众不同。
注：女：同“汝”，指荑草。

# 新台
题解：《毛诗序》说卫宣公为儿子伋娶齐女，却在河上筑新台把她截为己妻，国人作此诗讽刺；今人多从此说，视为讽刺之作。
原：新台有泚，/河水瀰瀰。/燕婉之求，/籧篨不鲜！|| 新台多么鲜亮，河水漫漫流淌。本想嫁个温和美好的人，得到的却是个不能俯身的丑陋之人！
注：新台：台名，旧说为卫宣公在黄河边所筑。泚（cǐ）：鲜明的样子。
注：瀰（mǐ）瀰：水盛大的样子。
注：燕婉：安和美好，指好配偶。之求：是求，所追求的。
注：籧篨（qú chú）：粗竹席，借指胸部突出不能俯身的人，用来讥丑。鲜：善，一说少，存疑。
原：新台有洒，/河水浼浼。/燕婉之求，/籧篨不殄！|| 新台多么高峻，河水平平满满。本想嫁个温和美好的人，得到的却是个丑陋不堪的人！
注：洒（cuǐ）：高峻的样子，一说鲜洁。
注：浼（měi）浼：水盛平满的样子。
注：殄（tiǎn）：善，与上章“鲜”义近，一说同“腆”。
原：鱼网之设，/鸿则离之。/燕婉之求，/得此戚施！|| 张设渔网本为捕鱼，却网到了一只大鸟。本想嫁个温和美好的人，得到的却是这个驼背的丑家伙！
注：鸿：大鸟，一说即蛤蟆，近人有此说，存疑。离：通“罹”，遭遇、落入。
注：戚施：驼背不能仰视的人，借指丑陋之人。

# 二子乘舟
题解：《毛诗序》说卫宣公的两个儿子伋和寿争相赴死，国人伤之而作此诗；今人也有只读作送别远行者的诗。
原：二子乘舟，/泛泛其景。/愿言思子，/中心养养。|| 两个人乘着小船，飘飘荡荡远去。我深深思念你们，心中忧虑不安。
注：二子：两个人，旧说指卫宣公之子伋与寿。
注：泛泛：船在水上漂流的样子。景：通“影”，一说读为“憬”，远行貌。
注：愿：思念的样子。言：语助词。养养：忧愁不定的样子。
原：二子乘舟，/泛泛其逝。/愿言思子，/不瑕有害？|| 两个人乘着小船，漂漂荡荡离去。我深深思念你们，但愿你们不会遭遇祸害吧？
注：逝：往，离去。
注：不瑕：不至于，参见《泉水》注。
