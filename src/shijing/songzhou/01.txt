# 周颂
题解：《周颂》共三十一篇，是西周王室在宗庙祭祀、典礼时所用的乐歌和颂辞，多数被认为作于周初（武王、成王、康王前后）。篇幅大多短小，往往不分章、少用韵，语气庄重，内容以颂扬先王功德、祈求福佑、告诫臣下与劝农为主。

# 清庙
题解：《毛诗序》以为周公营成洛邑后，率诸侯祭祀文王的乐歌。诗写助祭者的恭敬与文王德业的不可忘，向来被列为《周颂》首篇。
原：於穆清庙，/肃雝显相。/济济多士，/秉文之德。/对越在天，/骏奔走在庙。/不显不承，/无射于人斯。|| 啊，庄严而清静的宗庙里，助祭的公卿恭敬和顺、德行昭著。众多的执事之士整齐肃穆，都秉持着文王的美德。他们颂扬着在天上的先王之灵，在庙中快步奔走、忙于祭事。先王的功德何其显赫，何其承传不绝，人们对他永远不会厌倦。
注：於（wū）穆：赞叹之辞，“於”犹“啊”，“穆”指庄严美好。
注：肃雝（yōng）：恭敬和顺。
注：显相：有声望的助祭者。
注：对越：犹“对扬”，颂扬、报答。
注：骏：迅疾。
注：不显不承：“不”读为“丕”，大；言显赫而能承继。
注：无射（yì）：不厌，“射”通“斁”。

# 维天之命
题解：祭祀文王的颂辞。从天命运行不息说到文王德行纯美，再表示子孙要承受文王恩泽、笃守其道。
原：维天之命，/於穆不已。/於乎不显，/文王之德之纯！/假以溢我，/我其收之。/骏惠我文王，/曾孙笃之。|| 想那上天的命令，庄严美好，运行不止。啊，多么光明显赫，文王的德行那样纯粹！他把恩惠施加给我们，我们一定恭敬地承受。顺着我们文王的道路走下去，后代子孙要永远笃守不懈。
注：维：句首语气词。
注：於乎：即“呜呼”。
注：不显：即“丕显”，大而光明。
注：假以溢我：大意为以恩惠施及我们；《左传》引作“何以恤我”，确切所指存疑。
注：骏惠：大顺，一说专心顺从。
注：曾孙：后世子孙，指主祭的周王。
注：笃：厚，坚守。

# 维清
题解：祭祀文王的短颂，称美文王所定的典章法度是周朝福运的开端。篇幅极短，前人或疑有脱文。
原：维清缉熙，/文王之典。/肇禋，/迄用有成。/维周之祯。|| 清明而又光辉的，是文王留下的典章法度。从他开始举行禋祀，直到后来成就大业。这正是周家的吉祥福瑞。
注：缉熙：光明，绵延不断地发扬光明。
注：肇（zhào）：开始。
注：禋（yīn）：烧柴升烟以祭天的祭礼，此处借指建国受命。
注：迄：至，终于。
注：祯（zhēn）：吉祥。

# 烈文
题解：周王（一般认为是成王）在祭祖典礼上告诫助祭诸侯的诗，勉励他们勿犯大错、尊崇王室、效法先王之德。
原：烈文辟公，/锡兹祉福，/惠我无疆，/子孙保之。/无封靡于尔邦，/维王其崇之。/念兹戎功，/继序其皇之。/无竞维人，/四方其训之。/不显维德，/百辟其刑之。/於乎前王不忘！|| 有功业又有文德的诸侯们，先祖赐给你们这样的福禄，恩惠我们没有止境，子孙要永远保有它。不要在你们的国内犯下大错，周王才会尊崇你们。要记住这伟大的功业，继承下去并使它发扬光大。最强大的莫过于得到贤人，四方都会顺从他；最显耀的莫过于德行，诸侯们都会以此为榜样。啊，前代的君王永远不能忘记！
注：烈文：有武功、有文德。
注：辟（bì）公：诸侯。
注：锡：赐。
注：祉（zhǐ）：福。
注：封靡：大罪过，一说指贪财奢侈，存疑。
注：崇：尊重，一说立。
注：戎功：大功。
注：皇：光大。
注：竞：强。
注：训：顺从。
注：刑：同“型”，效法。

# 天作
题解：祭祀岐山（兼及太王、文王）的乐歌。追述太王开辟岐山、文王继续经营，期望子孙永保基业。
原：天作高山，/大王荒之。/彼作矣，/文王康之。/彼徂矣岐，/有夷之行。/子孙保之。|| 上天造就了这座高大的岐山，太王开始开垦拥有它。太王兴建了基业，文王又使它安定繁荣。那岐山原本险峻难行，如今有了平坦的大道。子孙们要永远守护它。
注：高山：指岐山，在今陕西岐山县一带。
注：大（tài）王：即太王古公亶父，文王的祖父。
注：荒：开垦，占有。
注：康：安定，一说继续经营。
注：彼徂矣岐：通行断句作“彼徂矣，岐有夷之行”，此从书中排法；“徂”或读为“岨”，险阻，诸说不一，存疑。
注：夷：平坦。
注：行（háng）：道路。

# 昊天有成命
题解：一般认为是祭祀成王（或成王祭天）的颂辞。说文王、武王受命于天，成王勤勉不懈，使天下安定。
原：昊天有成命，/二后受之。/成王不敢康，/夙夜基命宥密。/於缉熙！/单厥心，/肆其靖之。|| 皇天有既定的命令，文王、武王二位君主承受了它。成王不敢安逸享乐，日夜勤勉，奠定天命，宽厚而又谨慎。啊，多么光明！他竭尽全部心力，所以使天下安定。
注：昊天：皇天。
注：二后：指文王、武王。
注：成王：一般指周成王；一说“成王”意为成就王业，存疑。
注：康：安逸。
注：基命宥密：奠定天命，宽和而周密；各家解说不一，存疑。
注：单：通“殚”，尽。
注：肆：所以。
注：靖：安定。

# 我将
题解：《毛诗序》以为祭祀文王于明堂的乐歌，祭天而以文王配享。诗写献牲、效法文王典章，并表示敬畏天威。
原：我将我享，/维羊维牛，/维天其右之。/仪式刑文王之典，/日靖四方。/伊嘏文王，/既右飨之。/我其夙夜，/畏天之威，/于时保之。|| 我捧上我献的祭品，有肥羊也有肥牛，愿上天保佑我们。我效法文王的典章，每天谋求安定四方。伟大的文王啊，已来享用这些祭品。我日日夜夜，敬畏上天的威严，以此保住天命和国家。
注：将：奉献，一说为一种烹煮献神的祭名。
注：享：献祭。
注：右：同“佑”，保佑；一说“右飨”指劝神享用。
注：仪、式、刑：都是效法之意。
注：靖：安定。
注：嘏（jiǎ）：大。
注：于时：于是。

# 时迈
题解：一般认为是武王克商后巡行诸侯、祭祀山川时的乐歌，旧说出于周公之手。诗中宣示天命归周、收兵止战、推行美德。
原：时迈其邦，/昊天其子之。/实右序有周，/薄言震之，/莫不震叠。/怀柔百神，/及河乔岳。/允王维后！/明昭有周，/式序在位。/载戢干戈，/载櫜弓矢。/我求懿德，/肆于时夏。/允王保之！|| 周王按时巡视各个诸侯之国，皇天把他当作自己的儿子。上天确实保佑周家、使它兴盛，周王稍一振作威势，四方无不震动畏惧。他安抚祭祀各方神灵，连黄河与高山也都受到礼敬。周王真是天下的君主！周朝光明显赫，按照次序安排诸侯的职位。于是收起干戈，把弓箭装进袋里。我们追求美好的德行，把它施行于整个华夏。周王必能永保天命！
注：时：按时，一说是、此。
注：迈：行，指巡行。
注：子之：以之为子。
注：右序：佑助。
注：震叠：震惊恐惧，“叠”通“慑”。
注：怀柔：安抚。
注：乔岳：高大的山岳。
注：允：诚然，确实。
注：后：君。
注：戢（jí）：收藏兵器。
注：櫜（gāo）：盛弓箭的袋子，此作动词，装进。
注：懿（yì）德：美德。
注：肆：陈布，施行。
注：时夏：这中国，指华夏之地。

# 执竞
题解：祭祀武王、成王、康王的诗（朱熹等主此说）。先颂三王功业，再写祭祀时钟鼓齐鸣、神灵降福。
原：执竞武王，/无竞维烈。/不显成康，/上帝是皇。/自彼成康，/奄有四方，/斤斤其明。/钟鼓喤喤，/磬筦将将，/降福穰穰。/降福简简，/威仪反反。/既醉既饱，/福禄来反！|| 自强不息的武王，他的功业无人能比。光辉显赫的成王和康王，上帝也赞美他们。自从成王、康王以来，全面拥有了四方，他们明察秋毫。钟鼓之声洪亮，磬与管乐铿锵，神灵降下丰盛的福祉。降下的福禄盛大，祭祀的仪容庄重谨慎。神灵已经酒醉食饱，福禄一次又一次地降临！
注：执竞：持守自强之心，一说指制服强敌。
注：烈：功业。
注：皇：美，赞美；一说训君。
注：奄：全部，尽。
注：斤斤：明察的样子。
注：喤喤（huáng）：钟鼓声洪亮。
注：磬（qìng）：石制乐器。
注：筦：同“管”。
注：将将（qiāng）：乐声和谐。
注：穰穰（ráng）、简简：众多、盛大。
注：反反：谨慎庄重。
注：来反：反复到来。

# 思文
题解：祭祀周人始祖后稷的颂辞，称颂他德可配天、赐民麦种、养育万民的功绩。
原：思文后稷，/克配彼天。/立我烝民，/莫匪尔极。/贻我来牟，/帝命率育。/无此疆尔界，/陈常于时夏。|| 有文德的后稷啊，你的功德足以与上天相配。你使我们万民得以安身立命，无不是你的恩德所至。你留给我们小麦和大麦，奉上帝之命普遍养育人民。不分彼此的疆界，在整个华夏推行农事常法。
注：思：语助词。
注：后稷：周人始祖，相传教民种植五谷。
注：立：通“粒”，以谷物养活，一说安定。
注：烝（zhēng）民：众民。
注：极：至，一说准则。
注：贻：留给。
注：来牟：小麦与大麦，一说都指麦。
注：率育：普遍养育。
注：陈常：布施常道（指农事），具体所指存疑。
注：时夏：这华夏之地。

# 臣工
题解：周王于春季耕籍、视察农事时告诫群臣与农官的诗，一般归于成王时代。诗中询问田事、期望丰年，命农人整备农具。
原：嗟嗟臣工，/敬尔在公。/王釐尔成，/来咨来茹。/嗟嗟保介，/维莫之春，/亦有何求？/如何新畬？/於皇来牟，/将受厥明。/明昭上帝，/迄用康年。/命我众人：/庤乃钱镈，/奄观铚艾。|| 喂，你们这些群臣百官，对公家的事务要恭敬谨慎。君王赏赐你们已有的成绩，你们要来商量、来斟酌。喂，你们这些农官，现在已是暮春时节，还有什么需要？新开的田、熟了的田情况怎样？啊，那小麦大麦多么茂美，快要抽穗成熟了。光明的上帝，将赐给我们一个丰年。命令我们的众农夫：备好你们的铲子和锄头，将要一起去观看收割。
注：臣工：群臣百官。
注：釐（lí）：赐予。
注：咨：商议。
注：茹：度量，一说慰问。
注：保介：一般认为是协助管理农事的官员，一说披甲护卫之士，存疑。
注：莫：同“暮”。
注：新、畬（yú）：开垦二年的田叫新，三年的田叫畬。
注：来牟：小麦与大麦。
注：庤（zhì）：准备。
注：钱：铲类农具。
注：镈（bó）：锄类农具。
注：铚（zhì）艾：镰刀，此指收割。

# 噫嘻
题解：与《臣工》相近的劝农诗，写成王（或周王）在春耕时督促农夫，号召万人在广阔田地上耦耕。
原：噫嘻成王，/既昭假尔。/率时农夫，/播厥百谷。/骏发尔私，/终三十里。/亦服尔耕，/十千维耦。|| 啊，成王已经诚心祷告，神灵降临到你们这里。率领这些农夫们，播下各种谷物。赶快开发你们的田地，遍及三十里的广阔原野。你们都要从事耕作，上万人两两并肩而耕。
注：噫嘻：叹词。
注：昭假（gé）：以诚心祷告，使神灵降临；一说召集。
注：率：率领。
注：时：这些。
注：厥：其。
注：骏：迅速。
注：私：私田，一说当作“耜”，农具，存疑。
注：终：尽，遍及。
注：服：从事。
注：十千：一万，极言人多。
注：耦（ǒu）：两人并肩耕作。

# 振鹭
题解：周王款待来朝助祭的宾客（旧说为夏、商之后的杞、宋国君）的诗，以白鹭比喻宾客的洁白容仪，并祝愿他们永保美誉。
原：振鹭于飞，/于彼西雝。/我客戾止，/亦有斯容。/在彼无恶，/在此无斁。/庶几夙夜，/以永终誉。|| 一群白鹭振翅飞翔，飞到那西边的泽池。我的客人到来了，也有白鹭般高洁的仪容。他们在本国无人怨恨，来到这里也无人厌弃。希望他们日夜勤勉，永远保持美好的声誉。
注：振：群飞的样子。
注：鹭：白鹭，水鸟。
注：西雝（yōng）：西边的水泽，一说指辟雍。
注：戾（lì）：到。
注：止：语气词。
注：斁（yì）：厌弃。
注：终誉：盛大的声誉，“终”一说通“众”。

# 丰年
题解：丰收之后报祭神灵和祖先的乐歌，写粮食满仓、酿酒献祭、祈求福泽。
原：丰年多黍多稌，/亦有高廪，/万亿及秭。/为酒为醴，/烝畀祖妣，/以洽百礼，/降福孔皆。|| 丰收之年，黍子和稻子都很多，还有高大的粮仓，储存的粮食数以万亿计。用它酿成清酒和甜酒，献给男女祖先享用，配合着各种祭礼，神灵降下的福泽十分普遍。
注：稌（tú）：稻。
注：廪（lǐn）：粮仓。
注：万、亿、秭（zǐ）：都是极大的数目，极言其多。
注：醴（lǐ）：甜酒。
注：烝：进献。
注：畀（bì）：给予。
注：祖妣：男女祖先。
注：洽：配合，齐备。
注：孔：很。
注：皆：普遍，一说通“嘉”。

# 有瞽
题解：《毛诗序》以为周初始作乐而合奏于太祖之庙时的诗。描写盲乐师排列庙庭、乐器齐备、合奏和鸣，先祖与宾客同听。
原：有瞽有瞽，/在周之庭。/设业设虡，/崇牙树羽。/应田县鼓，/鞉磬柷圉，/既备乃奏，/箫管备举。/喤喤厥声，/肃雝和鸣，/先祖是听。/我客戾止，/永观厥成。|| 一个个盲乐师，聚在周王宗庙的庭院里。架起了挂乐器的木架，架上饰着崇牙，插着彩色羽毛。小鼓、大鼓和悬挂的鼓，还有鞉、磬、柷、敔，一切齐备就开始演奏，箫和管一齐吹响。乐声洪亮，庄重和谐地共鸣，先祖的神灵也来倾听。我的宾客已经到来，一直观赏到乐曲终了。
注：瞽（gǔ）：盲人，古代乐师多由盲人担任。
注：业：乐器架横木上的大板。
注：虡（jù）：悬挂钟磬的木架立柱。
注：崇牙：架上锯齿状的挂钩。
注：树羽：插上羽毛作装饰。
注：应、田：小鼓与大鼓。
注：县：同“悬”。
注：鞉（táo）：有柄的摇鼓。
注：柷（zhù）、圉：均为乐器，柷用于起乐，圉同“敔”（yǔ），用于止乐。
注：喤喤：乐声洪亮。
注：肃雝：庄重和谐。
注：戾止：到来。
注：成：乐曲奏完一遍。

# 潜
题解：在宗庙献鱼祭祀的乐歌，《毛诗序》以为季冬荐鱼、春献鲔之诗。
原：猗与漆沮，/潜有多鱼。/有鳣有鲔，/鲦鲿鰋鲤。/以享以祀，/以介景福。|| 啊，美好的漆水和沮水，水中鱼窝里鱼儿众多。有鳣鱼也有鲔鱼，还有鲦鱼、鲿鱼、鲇鱼和鲤鱼。用它们来献享、来祭祀，祈求赐予大福。
注：猗（yī）与：赞叹词。
注：漆、沮：两条河名，在今陕西境内。
注：潜：放置柴木于水中供鱼栖息，用以捕鱼；一说“潜”即深水，存疑。
注：鳣（zhān）、鲔（wěi）：都是大鱼，旧说分别为鲟、鳇之类，存疑。
注：鲦（tiáo）：白条鱼。
注：鲿（cháng）：黄颡鱼一类。
注：鰋（yǎn）：鲇鱼。
注：介：祈求。
注：景福：大福。

# 雝
题解：《毛诗序》以为禘祭太祖时的诗，一般认为是周王祭祀后撤去祭品时所奏之乐。诗写诸侯助祭、天子肃穆，并祈求先父先母赐福。《论语》载孔子讥三家以《雍》彻，即指此诗。
原：有来雝雝，/至止肃肃。/相维辟公，/天子穆穆。/於荐广牡，/相予肆祀。/假哉皇考，/绥予孝子。/宣哲维人，/文武维后。/燕及皇天，/克昌厥后。/绥我眉寿，/介以繁祉。/既右烈考，/亦右文母。|| 来时和顺从容，到了庙中庄严恭敬。助祭的是各国诸侯，主祭的天子端庄肃穆。啊，献上肥大的公牛，帮助我陈设祭品。伟大的先父啊，请安慰我这孝子。你作为臣子明智通达，作为君主文武兼备。你使上天也安宁喜悦，能让子孙繁荣昌盛。赐给我长寿，佑助我以众多的福祉。已经劝请功业显赫的先父享用，也劝请有文德的先母享用。
注：雝雝（yōng）：和顺的样子。
注：肃肃：恭敬的样子。
注：相：助祭者。
注：辟公：诸侯。
注：穆穆：庄严肃穆。
注：荐：进献。
注：广牡：大公牛。
注：肆：陈列。
注：假：大。
注：皇考：对亡父的美称。
注：绥：安抚，一说赐予。
注：宣哲：明达聪慧。
注：后：君主。
注：燕：安。
注：眉寿：长寿。
注：介：助。
注：祉：福。
注：右：通“侑”，劝食。
注：烈考、文母：有功业的先父、有文德的先母，具体所指（如文王、太姒）存疑。
