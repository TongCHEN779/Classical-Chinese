# 载见
题解：诸侯朝见新即位的周王，随王祭祀武王庙的乐歌。旧说多以为成王即位、诸侯来朝助祭时所作。
原：载见辟王，/曰求厥章。/龙旂阳阳，/和铃央央。/鞗革有鸧，/休有烈光。/率见昭考，/以孝以享，/以介眉寿，/永言保之。/思皇多祜。/烈文辟公，/绥以多福，/俾缉熙于纯嘏。|| 诸侯们初来朝见君王，求取新朝的礼法典章。画着蛟龙的旗帜鲜明飘扬，车上的和铃、旗铃叮当作响。马辔头上的铜饰闪闪发亮，美好而又光彩辉煌。君王率领他们去拜谒先父的宗庙，献上祭品表达孝敬，祈求赐予长寿。愿先王长久保佑，降下大量福祉。有功有德的诸侯们，先王也安抚你们、赐你们多福，使你们的光明德业承受大福。
注：载：始，初；一说为句首语词。辟王：君王，指周王。
注：曰求厥章：曰，句首语词；章，典章法度。
注：鞗（tiáo）革有鸧（qiāng）：鞗革，马辔头的铜饰；有鸧，金饰闪亮或相击有声的样子。
注：昭考：已故的父王，一般认为指武王。纯嘏（gǔ）：大福。

# 有客
题解：周王款待并饯送来朝宾客的乐歌。旧说客人指殷商后裔宋微子，今人多从此说，但客人具体是谁已难确考。
原：有客有客，/亦白其马。/有萋有且，/敦琢其旅。/有客宿宿，/有客信信。/言授之絷，/以絷其马。/薄言追之，/左右绥之。/既有淫威，/降福孔夷。|| 有客人来了，来了客人，驾车的马一色洁白。随从众多，个个仪容端整、举止有礼。客人住了一夜又一夜，住了两夜又两夜。拿出绳索交给他，把他的马拴住，好把客人留下。临别时为他送行，左右群臣都来安抚慰劳。客人既享有盛大的威仪，上天降福也就格外丰厚平顺。
注：亦白其马：殷人尚白，故以白马为贵，旧说据此认为客人是殷人之后。
注：有萋有且（jū）：形容随从众多。敦琢：即雕琢，形容随从仪容整饬。
注：宿宿、信信：住一夜为宿，两夜为信，叠用表示多留几日。絷（zhí）：拴马的绳索，又作动词“拴”。
注：淫威：盛大的威仪；一说指大德。夷：平易，一说训大，存疑。

# 武
题解：歌颂武王克商功业的乐歌，一般认为是周初《大武》乐舞中的一章，《左传》称其卒章为“耆定尔功”。
原：於皇武王，/无竞维烈。/允文文王，/克开厥后。/嗣武受之，/胜殷遏刘，/耆定尔功。|| 啊，伟大的武王！他的功业无人能比。确有文德的文王，开创了后世的基业。继位的武王承受下来，战胜殷商、制止杀戮，终于成就了你的功业。
注：於（wū）皇：赞叹之辞，犹“啊，伟大”。无竞：无人能比。烈：功业。
注：允：诚然，确实；一说为发语词。
注：嗣武：继承者武王；一说“武”指足迹，“嗣武”即继承前人的事业。
注：遏刘：制止杀戮。刘，杀。耆（zhǐ）：致，达成。

# 闵予小子
题解：嗣王在宗庙中自述孤苦、追念先父先祖并表示继承大业的诗。旧说以为成王除武王之丧后朝庙所作。
原：闵予小子，/遭家不造。/嬛嬛在疚。/於乎皇考！/永世克孝。/念兹皇祖，/陟降庭止。/维予小子，/夙夜敬止。/於乎皇王，/继序思不忘。|| 可怜我这年轻的后生，家中遭逢不幸，孤孤单单陷在忧伤之中。啊，伟大的先父！您一生都能尽孝。想起这位伟大的祖父，他的神灵在朝廷上下往来。我这年轻的后生，早晚都恭谨从事。啊，伟大的先王们，继承你们的事业，我决不敢忘记。
注：闵：通“悯”，可怜。予小子：周王对祖先的自称。不造：不幸，遭逢变故。
注：嬛嬛（qióng）：孤独无依的样子。疚：忧病，哀痛。
注：皇考：对亡父的尊称，旧说指武王；皇祖：对亡祖的尊称，旧说指文王。
注：陟（zhì）降：上下往来，指神灵降临。继序：继承功业；序，通“绪”。

# 访落
题解：嗣王初即位，在宗庙中向先王咨询求助、祈求保佑的诗。旧说属成王，也有学者因“判涣”等语另作别解，存疑。
原：访予落止：/率时昭考。/於乎悠哉，/朕未有艾，/将予就之，/继犹判涣。/维予小子，/未堪家多难。/绍庭上下，/陟降厥家。/休矣皇考，/以保明其身。|| 我在即位之初谋划政事：要遵循先父的法度。啊，路途多么遥远，我还没有什么阅历；即使有人扶助我去做，也恐怕会散漫不定。想我这年轻的后生，承受不住国家的多难。愿先父的神灵在朝廷上下往来，降临护佑我的家邦。美好啊，伟大的先父，请保佑我、勉励我自身。
注：访：咨询，谋划。落：开始，指即位之初；一说读为“格”，训至。止：语助词。
注：率：遵循。时：是，这。昭考：对亡父的美称。
注：艾：阅历，经验。将：扶助。判涣：涣散不定，或释为逍遥自放，存疑。
注：绍：一说读为“昭”，显明。保明：保佑；一说“明”通“勉”。

# 敬之
题解：周王自我警戒、勉励群臣的诗，旧说以为群臣进戒嗣王之作，今人多认为是嗣王自儆，具体是哪位周王已难确定。
原：敬之敬之，/天维显思，/命不易哉。/无曰高高在上，/陟降厥士，/日监在兹。/维予小子，/不聪敬止。/日就月将，/学有缉熙于光明。/佛时仔肩，/示我显德行。|| 要警惕啊要警惕，上天明察一切，保住天命实在不容易。不要说上天高高在上，它上下往来察看人事，天天都监视着这里。我这年轻的后生，不够聪明却要敬慎行事。日有所成、月有所进，学习不断积累直到光明。请辅助我担负重任，指示我光明的德行。
注：敬：警惕，戒慎。显：明察。思：语气词。命不易：天命难以保持。
注：陟降厥士：上下往来察看其事；士，事，一说当作“土”，存疑。
注：日就月将：每日有所成就，每月有所进步。缉熙：积累而至于光明。
注：佛（bì）：通“弼”，辅助。仔肩：所担负的责任。

# 小毖
题解：周王经历困境之后自我警戒、悔过自勉的诗。旧说以为成王平定管蔡之乱后所作，存疑。
原：予其惩而毖后患，/莫予荓蜂，/自求辛螫。/肇允彼桃虫，/拚飞维鸟。/未堪家多难，/予又集于蓼。|| 我要吸取教训，谨慎防备后患。没有谁使蜂来蜇我，是我自己招来了刺痛。起初我真以为那只是小小的桃虫，谁知它一飞就成了大鸟。我承受不住国家的多难，如今又落进了辛苦的境地。
注：惩：警戒，吸取教训。毖（bì）：谨慎。
注：荓（píng）：使。螫（shì）：毒虫刺人。
注：肇：开始。允：信，以为。桃虫：鹪鹩一类的小鸟。拚（fān）飞：翻飞，飞起。
注：蓼（liǎo）：一种味辛的草，此喻辛苦困厄；一说为地名，存疑。

# 载芟
题解：春耕时节籍田并祭祀社稷、祈求丰年的乐歌，《毛诗序》以为“春籍田而祈社稷”。诗中写了从开荒、耕作到收获、祭祀的全过程。
原：载芟载柞，/其耕泽泽。/千耦其耘，/徂隰徂畛。/侯主侯伯，/侯亚侯旅，/侯彊侯以。/有嗿其馌，/思媚其妇，/有依其士。/有略其耜，/俶载南亩。/播厥百谷，/实函斯活。/驿驿其达，/有厌有杰。/厌厌其苗，/绵绵其麃。/载获济济，/有实其积，/万亿及秭。/为酒为醴，/烝畀祖妣，/以洽百礼。/有飶其香，/邦家之光。/有椒其馨，/胡考之宁。/匪且有且，/匪今斯今，/振古如兹。|| 割除野草、砍去树木，翻耕的土地松软疏散。千百对农夫一齐锄草，从低湿的洼地到高处的田埂。家长和长子来了，叔伯子弟来了，强壮的帮手和雇工也都来了。田头吃饭的声音一片热闹，送饭的妇人多么可爱，身边的男子也健壮有力。锋利的犁头，开始在向阳的田里耕作。播下各种谷物，种子饱含生机。禾苗接连破土而出，壮苗高高挺立。禾苗齐整茂盛，长长的禾穗不断吐穗扬花。收获时人们熙熙攘攘，粮食在场上堆得满满，数目多得以万亿计。用它酿成清酒和甜酒，献给男女祖先，用来完备各种礼仪。祭品散发着浓香，这是国家的荣光。酒香芬芳远闻，使老人们得到安宁。不只是这里才如此，不只是今年才如此，自古以来就是这样。
注：芟（shān）：除草。柞（zé）：砍除树木。泽泽：土块松散的样子。
注：耦：两人并耕。隰（xí）：低湿地。畛（zhěn）：田间的界路。
注：主：家长；伯：长子；亚：次子；旅：众子弟；彊：强壮有余力者；以：受雇帮工者。各家解释不一，存疑。
注：嗿（tǎn）：众人吃饭的声音。馌（yè）：送到田间的饭食。依：壮盛的样子。
注：略：锋利。耜（sì）：犁头。俶（chù）载：开始耕作。函：含。活：有生机。
注：有厌有杰：通行本作“有厌其杰”，此从书中所印；杰，指先长出的壮苗。麃（biāo）：禾穗吐出扬花，一说为耘田，存疑。
注：秭（zǐ）：数词，万亿为秭。烝畀（bì）：进献给予。洽：合，使完备。
注：飶（bì）：食物的香气。椒：香气，一说当作“馥”。胡考：长寿之人。振古：自古。

# 良耜
题解：秋收之后祭祀社稷、报答神恩的乐歌，与《载芟》相为表里，一写春耕，一写秋收。
原：畟畟良耜，/俶载南亩。/播厥百谷，/实函斯活。/或来瞻女，/载筐及筥，/其饟伊黍。/其笠伊纠，/其镈斯赵，/以薅荼蓼。/荼蓼朽止，/黍稷茂止。/获之挃挃，/积之栗栗。/其崇如墉，/其比如栉，/以开百室。/百室盈止，/妇子宁止。/杀时犉牡，/有捄其角。/以似以续，/续古之人。|| 锋利的好犁头深深入土，开始在向阳的田里耕作。播下各种谷物，种子饱含生机。有人来看望你们，提着方筐和圆筐，里面装着送来的黄米饭。头戴编结的斗笠，手拿锄头铲地，除去荼草和蓼草。荼草、蓼草腐烂了，黍子和稷子长得茂盛。收割时嚓嚓作响，粮食堆得密密实实。谷堆高得像城墙，密集得像梳齿，打开家家户户的粮仓。粮仓都装满了，妇女孩子都安宁了。宰杀那头黄毛黑唇的大公牛，它的角弯弯长长。用它祭祀，继承延续，延续先人的传统。
注：畟畟（cè）：犁头锋利、深入土中的样子。俶载：开始耕作。
注：瞻女：来看望你，女，通“汝”。筐、筥（jǔ）：方形与圆形的竹器。
注：饟（xiǎng）：送给田间劳作者的饭食。书中此字印作“镈”，当为“饟”之误，据通行本改。
注：纠：编结。镈（bó）：锄类农具。赵：刺土，铲除。薅（hāo）：拔除田草。荼、蓼：两种田间杂草。
注：挃挃（zhì）：收割禾穗的声音。栗栗：堆积众多、紧密的样子。墉：城墙。栉：梳篦。
注：犉（chún）牡：黄毛黑唇的大公牛。捄（qiú）：角弯曲的样子。似：通“嗣”，继承。

# 丝衣
题解：祭祀之后宴请扮演祖先的“尸”的乐歌，旧说称为“绎宾尸”之诗。
原：丝衣其紑，/载弁俅俅。/自堂徂基，/自羊徂牛，/鼐鼎及鼒。/兕觥其觩，/旨酒思柔。/不吴不敖，/胡考之休。|| 丝制的祭服洁白鲜明，戴着皮帽，仪态恭顺。从庙堂走到门内阶基，从羊看到牛，大鼎小鼎一一察看。犀角酒杯弯弯翘起，美酒柔和醇厚。不喧哗也不傲慢，祈得长寿与福禄。
注：紑（fóu）：洁白鲜明的样子。弁（biàn）：皮帽。俅俅：恭顺的样子。
注：基：门内的台阶或门塾之基，旧说不一，存疑。徂：往，到。
注：鼐（nài）：大鼎。鼒（zī）：小鼎。兕觥（sì gōng）：犀角形的酒器。觩（qiú）：弯曲的样子。
注：吴：喧哗。敖：通“傲”。胡考：长寿。休：美，福。

# 酌
题解：歌颂武王兴师伐商的诗，一般认为属《大武》乐章之一，其在乐章中的次序诸说不一。文字古奥，历来解说分歧较大。
原：於铄王师，/遵养时晦。/时纯熙矣，/是用大介。/我龙受之。/蹻蹻王之造，/载用有嗣，/实维尔公允师。|| 啊，辉煌的王师，顺应时势，在昏暗之时养精蓄锐。等到天下大放光明，于是披甲大举出兵。我们荣幸地承受了天命。勇武的王家将士，由继位之王开始起用，这实在是效法您的功业。
注：於（wū）铄（shuò）：赞叹辉煌盛美。遵养时晦：顺时养晦，旧说解法不一，存疑。
注：纯熙：大放光明。大介：大披甲胄，指大举用兵；一说介训助。
注：龙：通“宠”，荣耀。蹻蹻（jué）：勇武的样子。造：一说为成就，一说指士众，存疑。
注：有嗣：继位者，指武王。尔公：一说“尔”指文王，“公”通“功”；允：信，用；师：效法。

# 桓
题解：颂扬武王克商、安定天下的诗，《左传》以为属《大武》乐章。
原：绥万邦，/娄丰年，/天命匪解。/桓桓武王，/保有厥士，/于以四方，/克定厥家。/於昭于天，/皇以间之？|| 安定了天下万国，连年获得丰收，天命对周毫不懈怠。威武的武王，保有他的国土和士众，进而据有四方，安定了周家。啊，他的光辉上达于天，有谁能取代他呢？
注：绥：安定。娄：通“屡”，屡次。匪解：不懈怠，解，通“懈”。
注：桓桓：威武的样子。士：事，或说当作“土”，存疑。
注：于以：乃以，于是。昭：光明显耀。皇：何。间：代替。

# 赉
题解：武王继承文王之业、封赏功臣的乐歌，一般认为属《大武》乐章；“赉”意为赏赐。
原：文王既勤止，/我应受之，/敷时绎思，/我徂维求定。/时周之命，/於，绎思！|| 文王已经辛勤创业，我理当承受下来，把这功业推广下去，不断地思念继承。我前往四方，只求天下安定。这是周邦承受的天命，啊，要永远继承下去！
注：勤：辛劳。止：语气词。应：当。
注：敷：布，推广。时：是，此。绎：连续不断；一说“绎思”为寻思，存疑。
注：徂：往，指出征或经营四方。

# 般
题解：武王巡守、登临山川祭祀的乐歌，旧说以为巡守而祀四岳河海，今人或以为克商归途中祭祀山川之作；一般认为属《大武》乐章。
原：於皇时周，/陟其高山，/嶞山乔岳，/允犹翕河。/敷天之下，/裒时之对，/时周之命。|| 啊，伟大的周邦，登上那高高的山岭，看小山连着大岳，又紧紧依傍着黄河。普天之下的诸侯，都聚集在这里配合祭祀，这是周所受的天命。
注：般：乐也，一说通“盘”，盘桓游观，题意解释不一，存疑。
注：嶞（duò）山：狭长的小山。乔岳：高大的山。
注：允犹翕河：信然又与黄河相合；翕（xī），合，解释不一，存疑。
注：敷：通“普”。裒（póu）：聚集。对：配，指配享受祭；一说为答谢。
