# 周南
题解：《周南》是《国风》的第一组，共十一篇。“南”旧说指南方的乐调或周公所治的南方地区，诗篇多与婚恋、家庭、祝福有关，具体产地与时代历来众说不一。

# 关雎
题解：《毛诗序》以为咏“后妃之德”，今人多读作一首男子思慕淑女、渴望与之成婚的恋歌，也有人认为是婚礼上的乐歌。
原：关关雎鸠，/在河之洲。/窈窕淑女，/君子好逑。|| 雎鸠关关地对鸣，栖息在河中的小洲上。那位美好贤淑的姑娘，正是君子的好配偶。
注：关关：雎鸠鸟相和的鸣声。
注：雎（jū）鸠：一种水鸟，一般认为即鱼鹰之类，存疑。
注：窈窕（yǎo tiǎo）：美好娴静的样子。
注：逑：配偶。
原：参差荇菜，/左右流之。/窈窕淑女，/寤寐求之。|| 长短不齐的荇菜，顺着水流左右去捞取。那位美好贤淑的姑娘，我醒着睡着都想追求她。
注：参差（cēn cī）：长短不齐。
注：荇（xìng）菜：一种浮在水面的水生植物，嫩叶可食。
注：流：顺水流捞取，一说即“求”。
注：寤寐（wù mèi）：醒着和睡着，意谓日日夜夜。
原：求之不得，/寤寐思服。/悠哉悠哉，/辗转反侧！|| 追求她却得不到，日夜都把她放在心上。思念绵绵无尽啊，翻来覆去睡不着！
注：思服：思念。服，也是想念的意思。
注：悠：长，指思念深长。
注：辗转反侧：在床上翻来覆去，难以入眠。
原：参差荇菜，/左右采之。/窈窕淑女，/琴瑟友之。|| 长短不齐的荇菜，左边右边去采摘。那位美好贤淑的姑娘，我要弹琴鼓瑟来亲近她。
注：琴瑟：两种弦乐器。
注：友：亲近，交好。
原：参差荇菜，/左右芼之。/窈窕淑女，/钟鼓乐之！|| 长短不齐的荇菜，左边右边去挑拣。那位美好贤淑的姑娘，我要敲钟击鼓让她欢喜！
注：芼（mào）：择取，一说为烹煮，存疑。
注：乐：使之快乐。

# 葛覃
题解：《毛诗序》以为写“后妃之本”，今人多以为写女子采葛织布、准备回娘家探望父母的诗，也有人认为与出嫁有关。
原：葛之覃兮，/施于中谷，/维叶萋萋。/黄鸟于飞，/集于灌木，/其鸣喈喈。|| 葛藤长长地伸展，一直蔓延到山谷当中，叶子长得茂密青翠。黄鸟飞来飞去，落在丛生的灌木上，叫声和美动听。
注：葛：多年生蔓草，茎皮纤维可织布。
注：覃（tán）：延长、蔓延。
注：施（yì）：延伸。中谷：即谷中。
注：喈喈（jiē）：鸟鸣声。
原：葛之覃兮，/施于中谷，/维叶莫莫。/是刈是濩，/为絺为綌，/服之无斁。|| 葛藤长长地伸展，一直蔓延到山谷当中，叶子已经长得浓密。割下来再放进锅里煮，织成细布和粗布，做成衣服穿着永不厌弃。
注：莫莫：茂密的样子。
注：刈（yì）：割。濩（huò）：煮。
注：絺（chī）：细葛布。綌（xì）：粗葛布。
注：斁（yì）：厌倦。
原：言告师氏，/言告言归。/薄污我私，/薄浣我衣。/害浣害否，/归宁父母。|| 我去告诉女师，说我要回娘家了。赶紧搓洗我的贴身衣，再洗净我的外衣。哪些该洗哪些不洗？我要回去问候父母。
注：言：语首助词。师氏：教导女子的保姆或女师。
注：薄：语助词，含勉力之意。污：搓洗去污。私：贴身内衣。
注：害（hé）：同“曷”，何。
注：归宁：出嫁女子回娘家问候父母；一说指出嫁使父母安心，存疑。

# 卷耳
题解：旧说多附会后妃求贤，今人多以为是妻子怀念远行丈夫的诗，后三章设想丈夫在旅途中的劳苦；也有人认为是夫妻两方各自抒怀。
原：采采卷耳，/不盈顷筐。/嗟我怀人，/寘彼周行。|| 采了又采卷耳菜，总也装不满浅浅的筐子。唉，我思念着远方的人，干脆把筐子放在大路边。
注：卷耳：一种野菜，即苍耳，嫩叶可食。
注：顷筐：前低后高的浅筐。
注：寘（zhì）：放置。一说通“视”，存疑。
注：周行（háng）：大路。
原：陟彼崔嵬，/我马虺隤。/我姑酌彼金罍，/维以不永怀。|| 登上那高峻的石山，我的马累得腿软。我姑且斟满那铜酒器，借酒让自己不再长久思念。
注：陟（zhì）：登。崔嵬（wéi）：高而不平的山。
注：虺隤（huī tuí）：疲病腿软的样子。
注：姑：姑且。罍（léi）：一种青铜酒器。
注：永怀：长久思念。
原：陟彼高冈，/我马玄黄。/我姑酌彼兕觥，/维以不永伤。|| 登上那高高的山脊，我的马累得毛色焦枯。我姑且斟满那兕角酒杯，借酒让自己不再长久忧伤。
注：玄黄：马因疲病而毛色变得焦黄。
注：兕觥（sì gōng）：兽角形的酒器。
原：陟彼砠矣，/我马瘏矣，/我仆痡矣，/云何吁矣！|| 登上那石头山岗，我的马累病了，我的仆从也累垮了，这忧愁怎能说得完啊！
注：砠（jū）：覆土的石山。
注：瘏（tú）：病，指马劳累致病。
注：痡（pū）：疲惫不堪。
注：云：语助词。吁（xū）：忧叹。

# 樛木
题解：一般认为是祝福“君子”多福的颂歌，以葛藟缠绕弯曲的大树起兴；《毛诗序》以为写后妃不嫉妒而能惠及下人。
原：南有樛木，/葛藟累之。/乐只君子，/福履绥之。|| 南方有枝条下弯的大树，葛藤缠绕在上面。快乐的君子啊，福禄使他安稳。
注：樛（jiū）木：树枝向下弯曲的树。
注：葛藟（lěi）：与葛相似的蔓生植物。累：缠绕。
注：只：语助词。
注：福履：福禄。绥：安定。
原：南有樛木，/葛藟荒之。/乐只君子，/福履将之。|| 南方有枝条下弯的大树，葛藤覆盖在上面。快乐的君子啊，福禄扶助着他。
注：荒：覆盖。
注：将：扶持，一说壮大。
原：南有樛木，/葛藟萦之。/乐只君子，/福履成之。|| 南方有枝条下弯的大树，葛藤回旋缠绕。快乐的君子啊，福禄成全了他。
注：萦：回旋缠绕。
注：成：成就，成全。

# 螽斯
题解：以群飞的螽斯比喻子孙众多，是祝愿人家多子多孙、家族兴旺的诗。
原：螽斯羽，/诜诜兮。/宜尔子孙，/振振兮。|| 螽斯振动着翅膀，成群聚集。祝你的子孙后代，兴旺盛大。
注：螽（zhōng）斯：一种蝗类昆虫，繁殖力强。
注：诜诜（shēn）：众多的样子，一说为群飞之声。
注：宜：适宜，此有祝愿之意。
注：振振：盛多兴旺的样子。
原：螽斯羽，/薨薨兮。/宜尔子孙，/绳绳兮。|| 螽斯振动着翅膀，嗡嗡群飞。祝你的子孙后代，绵延不绝。
注：薨薨（hōng）：众虫齐飞的声音。
注：绳绳：连绵不断的样子。
原：螽斯羽，/揖揖兮。/宜尔子孙，/蛰蛰兮。|| 螽斯振动着翅膀，聚在一起。祝你的子孙后代，和睦众多。
注：揖揖（jí）：会聚的样子。
注：蛰蛰（zhé）：众多而和集的样子。

# 桃夭
题解：以盛开结实的桃树比兴，祝贺女子出嫁，愿她使夫家和顺美满。
原：桃之夭夭，/灼灼其华。/之子于归，/宜其室家。|| 桃树枝叶繁茂，花开得鲜艳夺目。这位姑娘出嫁了，定能使她的家庭和顺。
注：夭夭：茂盛而有生气的样子。
注：灼灼：花色鲜明。华：同“花”。
注：之子：这个人，指出嫁的女子。于归：出嫁。
注：宜：和顺，使之和美。室家：家庭，指夫家。
原：桃之夭夭，/有蕡其实。/之子于归，/宜其家室。|| 桃树枝叶繁茂，结出累累的果实。这位姑娘出嫁了，定能使她的家庭和顺。
注：蕡（fén）：果实大而多的样子。
原：桃之夭夭，/其叶蓁蓁。/之子于归，/宜其家人。|| 桃树枝叶繁茂，叶子浓密青翠。这位姑娘出嫁了，定能使她的家人和睦。
注：蓁蓁（zhēn）：叶子茂盛的样子。

# 兔罝
题解：赞美张网狩猎的武士，称他们是公侯的屏障和亲信；《毛诗序》以为写贤人众多。
原：肃肃兔罝，/椓之丁丁。/赳赳武夫，/公侯干城。|| 兔网结得严密整齐，打桩声叮叮作响。威武雄壮的武士，是公侯的盾牌和城墙。
注：肃肃：整饬严密的样子。罝（jū）：捕兽的网。
注：椓（zhuó）：敲击，指打木桩固定网。丁丁（zhēng）：敲击声。
注：赳赳：雄健威武的样子。
注：干城：盾牌与城墙，比喻捍卫者。
原：肃肃兔罝，/施于中逵。/赳赳武夫，/公侯好仇。|| 兔网结得严密整齐，张设在道路交叉处。威武雄壮的武士，是公侯的好帮手。
注：中逵（kuí）：四通八达的道路之中。
注：仇（qiú）：同伴，伴侣。
原：肃肃兔罝，/施于中林。/赳赳武夫，/公侯腹心。|| 兔网结得严密整齐，张设在树林深处。威武雄壮的武士，是公侯的心腹之人。
注：中林：林中。
注：腹心：亲信可托的人。

# 芣苢
题解：一般认为是妇女们结伴采摘芣苢时唱的劳动歌，反复咏唱，节奏轻快；《毛诗序》以为与求子有关，存疑。
原：采采芣苢，/薄言采之。/采采芣苢，/薄言有之。|| 采呀采芣苢，快快把它采起来。采呀采芣苢，快快收进手里来。
注：芣苢（fú yǐ）：车前草，一说即薏苡，存疑。
注：薄言：语助词，含勉力、急促之意。
注：有：取得，收存。
原：采采芣苢，/薄言掇之。/采采芣苢，/薄言捋之。|| 采呀采芣苢，一颗一颗拾起来。采呀采芣苢，一把一把捋下来。
注：掇（duō）：拾取。
注：捋（luō）：顺着茎把籽实成把抹下。
原：采采芣苢，/薄言袺之。/采采芣苢，/薄言襭之。|| 采呀采芣苢，提起衣襟兜起来。采呀采芣苢，掖起衣襟装回来。
注：袺（jié）：手执衣襟兜东西。
注：襭（xié）：把衣襟掖在腰带上兜东西。

# 汉广
题解：写男子爱慕汉水边的女子却无法追求，以江汉宽长难渡比喻可望而不可即；旧说以“游女”为汉水女神，存疑。
原：南有乔木，/不可休息。/汉有游女，/不可求思。/汉之广矣，/不可泳思；/江之永矣，/不可方思！|| 南方有高大的树，树下却不能歇息。汉水边有出游的女子，却无法去追求。汉水这么宽广，无法游过去；长江这么绵长，无法乘筏渡过！
注：乔木：高大的树。
注：休息：一本作“休思”，思为语助词。
注：汉：汉水。游女：出游的女子，一说汉水女神。
注：永：长。方：用竹木筏渡水。
原：翘翘错薪，/言刈其楚。/之子于归，/言秣其马。/汉之广矣，/不可泳思；/江之永矣，/不可方思！|| 杂乱的柴草丛生，我要割下其中的荆条。那姑娘如果出嫁，我愿去喂饱她的马。汉水这么宽广，无法游过去；长江这么绵长，无法乘筏渡过！
注：翘翘（qiáo）：高出的样子。错薪：杂乱的柴草。
注：楚：荆条。
注：秣（mò）：喂马。
原：翘翘错薪，/言刈其蒌。/之子于归，/言秣其驹。/汉之广矣，/不可泳思；/江之永矣，/不可方思！|| 杂乱的柴草丛生，我要割下其中的蒌蒿。那姑娘如果出嫁，我愿去喂饱她的小马。汉水这么宽广，无法游过去；长江这么绵长，无法乘筏渡过！
注：蒌（lóu）：蒌蒿，一种可食的草。
注：驹：少壮的马。

# 汝坟
题解：一般认为写妇女在汝水边思念、终于见到远役归来的丈夫，末章言王室危急而父母在近；具体背景历来说法不一，存疑。
原：遵彼汝坟，/伐其条枚。/未见君子，/惄如调饥。|| 沿着汝水的堤岸走，砍下树的枝干。还没见到我的丈夫，心中忧思像早晨饿肚子一样难受。
注：遵：沿着。汝：汝水，在今河南境内。坟：河堤。
注：条枚：树的枝条和枝干。
注：惄（nì）：忧思。调（zhōu）饥：早晨未进食时的饥饿；调，同“朝”。
原：遵彼汝坟，/伐其条肄。/既见君子，/不我遐弃。|| 沿着汝水的堤岸走，砍下树上新生的枝条。终于见到了我的丈夫，他没有远远地抛弃我。
注：肄（yì）：砍伐后再生的嫩枝。
注：遐：远。不我遐弃：即“不遐弃我”。
原：鲂鱼赪尾，/王室如燬。/虽则如燬，/父母孔迩！|| 鳊鱼的尾巴累得发红，王室的事急如烈火。虽然急得像烈火一样，父母就在近旁啊！
注：鲂（fáng）鱼：鳊鱼。赪（chēng）：红色，旧说鱼劳则尾赤。
注：燬（huǐ）：烈火。
注：孔：很。迩（ěr）：近。末二句含义历来解释不一，存疑。

# 麟之趾
题解：以麒麟比喻贵族子孙，赞美公侯子孙宗族仁厚兴旺，一般视为祝颂之歌。
原：麟之趾，/振振公子。/于嗟麟兮！|| 麒麟的脚趾，就像仁厚兴盛的公子。啊，真是麒麟啊！
注：麟：麒麟，古人视为仁兽。趾：足。
注：振振：仁厚兴盛的样子。公子：公侯的儿子。
注：于（xū）嗟：赞叹词。
原：麟之定，/振振公姓。/于嗟麟兮！|| 麒麟的额头，就像仁厚兴盛的公侯之孙。啊，真是麒麟啊！
注：定：通“顁”，额头。
注：公姓：公侯的同姓子孙。
原：麟之角，/振振公族。/于嗟麟兮！|| 麒麟的独角，就像仁厚兴盛的公侯宗族。啊，真是麒麟啊！
注：公族：公侯的同祖宗族。
