# 王风
题解：“王风”是东周王都洛邑（今河南洛阳一带）及其周围地区的诗歌。周平王东迁以后王室衰微，地位与诸侯相近，故其诗列于国风；今存十篇，多写乱离、行役、思念之情，基调偏于哀怨。

# 黍离
题解：《毛诗序》以为东周大夫行经西周旧都，见宗庙宫室尽为禾黍，彷徨不忍离去而作，后世遂以“黍离之悲”指亡国之痛；今人也有理解为流浪者抒发无人理解的忧愁。
原：彼黍离离，/彼稷之苗。/行迈靡靡，/中心摇摇。/知我者，/谓我心忧；/不知我者，/谓我何求？/悠悠苍天！/此何人哉？|| 那黍子一行行长得茂盛，那高粱刚刚抽出新苗。我走在路上脚步迟缓，心中忧愁不安、无处着落。了解我的人，说我心中忧伤；不了解我的人，问我在寻求什么。高远的苍天啊，这是谁造成的呢？
注：黍：黄米，一种谷物。离离：成行成列、茂盛的样子。
注：稷：谷类作物，旧说为高粱或粟，具体所指历来有争议。
注：行迈：行走，远行。靡靡：迟缓的样子。
注：此何人哉：是什么人造成这样的局面？一说是诗人自问“我是怎样的人”，存疑。
原：彼黍离离，/彼稷之穗。/行迈靡靡，/中心如醉。/知我者，/谓我心忧；/不知我者，/谓我何求？/悠悠苍天！/此何人哉？|| 那黍子一行行长得茂盛，那高粱已经抽出穗子。我走在路上脚步迟缓，心中昏沉像喝醉了一般。了解我的人，说我心中忧伤；不了解我的人，问我在寻求什么。高远的苍天啊，这是谁造成的呢？
注：如醉：形容忧思深重，神志恍惚。
原：彼黍离离，/彼稷之实。/行迈靡靡，/中心如噎。/知我者，/谓我心忧；/不知我者，/谓我何求？/悠悠苍天！/此何人哉？|| 那黍子一行行长得茂盛，那高粱已经结了籽实。我走在路上脚步迟缓，心中堵塞像被噎住一样。了解我的人，说我心中忧伤；不了解我的人，问我在寻求什么。高远的苍天啊，这是谁造成的呢？
注：噎（yē）：食物堵住喉咙，喻忧愁郁结、气息不畅。

# 君子于役
题解：妻子思念在外服役的丈夫。黄昏时分鸡入窝、牛羊归圈，而丈夫久久不归，诗人即景生情，思念与牵挂交织。《毛诗序》说是大夫刺平王，今人多读作思妇诗。
原：君子于役，/不知其期，/曷至哉？/鸡栖于埘，/日之夕矣，/羊牛下来。/君子于役，/如之何勿思？|| 丈夫出门服役，不知道要多久，什么时候才能回来？鸡已经回到墙上的窝里，天色已近黄昏，羊和牛也从山坡上下来了。丈夫出门服役在外，叫我怎能不想念他？
注：君子：这里是妻子对丈夫的称呼。于役：去服役。
注：曷至哉：何时回到家。曷，何，何时。
注：埘（shí）：在墙上挖洞做成的鸡窝。
注：如之何勿思：怎么能不思念。
原：君子于役，/不日不月，/曷其有佸？/鸡栖于桀，/日之夕矣，/羊牛下括。/君子于役，/苟无饥渴！|| 丈夫出门服役，日子长得已经无法按日按月计算，什么时候才能相聚？鸡已经栖息在木桩上，天色已近黄昏，羊和牛也下坡回圈了。丈夫出门服役在外，但愿他不要挨饿受渴！
注：不日不月：没有日月可计，极言时间之长。
注：佸（huó）：相会，团聚。
注：桀：同“橛”，鸡栖息的木桩。
注：括：至，会聚，指牛羊归来聚集。苟：但愿，表希望。

# 君子阳阳
题解：写一位男子执乐器、招呼同伴一起奏乐歌舞的欢乐情景。《毛诗序》以为周室衰乱、贤者相招为禄仕以全身远害；今人多读作描写欢乐歌舞、或情人相邀共舞之诗。
原：君子阳阳，/左执簧，/右招我由房。/其乐只且！|| 那人神采飞扬，左手拿着笙簧，右手招呼我一起奏房中之乐。真是快乐啊！
注：阳阳：得意、欢快的样子。
注：簧：笙一类的乐器，此处代指笙。
注：由房：从事房中之乐，一说指一种乐曲或舞蹈，具体所指存疑。
注：只且（jū）：句末语气词。
原：君子陶陶，/左执翿，/右招我由敖。/其乐只且！|| 那人和乐陶陶，左手拿着羽毛舞具，右手招呼我一起跳舞游乐。真是快乐啊！
注：陶陶：和乐的样子。
注：翿（dào）：用鸟羽制成的舞具。
注：由敖：一起游乐，或指一种舞曲、舞位，存疑。

# 扬之水
题解：戍守在外的士卒思念家中亲人而盼望归乡。旧说平王为母家申国派兵戍守申、甫、许，士卒久戍不归而有怨言。
原：扬之水，/不流束薪。/彼其之子，/不与我戍申。/怀哉怀哉！/曷月予还归哉？|| 缓缓流动的河水，漂不走一捆柴草。家中的那个人啊，不能和我一起戍守申国。想念啊想念！哪一个月我才能回家呢？
注：扬之水：激扬的水，一说缓流的水；也有学者以“扬”为地名，存疑。
注：束薪：一捆柴草。古诗常以“束薪”喻婚姻，此处兴起思家之情。
注：彼其（jì）之子：那个人，指家中的妻子（一说指留在家中不必出征的人）。
注：申：国名，姜姓，在今河南南阳一带，为周平王母舅之国。
原：扬之水，/不流束楚。/彼其之子，/不与我戍甫。/怀哉怀哉！/曷月予还归哉？|| 缓缓流动的河水，漂不走一捆荆条。家中的那个人啊，不能和我一起戍守甫国。想念啊想念！哪一个月我才能回家呢？
注：楚：荆条，一种灌木。
注：甫：国名，即吕国，在今河南南阳西。
原：扬之水，/不流束蒲。/彼其之子，/不与我戍许。/怀哉怀哉！/曷月予还归哉？|| 缓缓流动的河水，漂不走一捆蒲柳。家中的那个人啊，不能和我一起戍守许国。想念啊想念！哪一个月我才能回家呢？
注：蒲：蒲柳，一说指蒲草。
注：许：国名，在今河南许昌东。

# 中谷有蓷
题解：以山谷中益母草的干枯起兴，哀叹一位遭遇不幸、流离失所的女子。旧说多认为写荒年中被丈夫抛弃的妇女。
原：中谷有蓷，/暵其干矣。/有女仳离，/嘅其叹矣。/嘅其叹矣，/遇人之艰难矣！|| 山谷里长着益母草，已经被晒得干枯了。有个女子被离弃了，她长声叹息。她长声叹息啊，是因为遇上了日子艰难的人！
注：中谷：即谷中。蓷（tuī）：益母草。
注：暵（hàn）：干枯，被晒干的样子。
注：仳（pǐ）离：分离，多指妇女被丈夫离弃。
注：嘅（kǎi）：叹息声。遇人之艰难：一说指嫁人遭遇艰难，一说指所嫁之人处境艰难。
原：中谷有蓷，/暵其脩矣。/有女仳离，/条其啸矣。/条其啸矣，/遇人之不淑矣！|| 山谷里长着益母草，已经晒得枯干了。有个女子被离弃了，她长声悲号。她长声悲号啊，是因为遇上了不善的人！
注：脩：干枯，本指干肉。
注：条：长。啸：撮口出声，抒发悲愤。
注：不淑：不善，或指遭遇不幸。
原：中谷有蓷，/暵其湿矣。/有女仳离，/啜其泣矣。/啜其泣矣，/何嗟及矣！|| 山谷里长着益母草，已经晒得干了。有个女子被离弃了，她抽抽噎噎地哭泣。她抽抽噎噎地哭泣，可是叹息又有什么用呢！
注：湿：旧说为“将干”之意，或读为“䁘”，干的意思；字义存疑。
注：啜（chuò）：抽泣的样子。
注：何嗟及矣：即“嗟何及矣”，叹息已来不及、无济于事。

# 兔爰
题解：一个生逢乱世的人怀念往昔安宁，感叹如今忧患重重，只愿长睡不醒。《毛诗序》以为写周桓王失信、诸侯背叛、君子不乐其生。
原：有兔爰爰，/雉离于罗。/我生之初，/尚无为。/我生之后，/逢此百罹。/尚寐无吪！|| 兔子自在悠闲，野鸡却落进了罗网。我刚出生的时候，天下还太平无事。我长大以后，却遭遇了种种忧患。但愿睡着了不再醒来动弹！
注：爰爰：舒缓自在的样子。兔狡猾得以逍遥，雉耿直反陷罗网，旧说以此比喻小人得志、君子遭难。
注：离：同“罹”，遭遇。罗：捕鸟的网。
注：无为：没有事端，指天下太平；一说指没有劳役。
注：百罹（lí）：种种忧患。尚：希望。吪（é）：动。
原：有兔爰爰，/雉离于罦。/我生之初，/尚无造。/我生之后，/逢此百忧。/尚寐无觉！|| 兔子自在悠闲，野鸡却落进了网车。我刚出生的时候，天下还没有什么事端。我长大以后，却遭遇了种种忧愁。但愿睡着了不再醒来！
注：罦（fú）：一种装有机关的捕鸟网。
注：无造：与“无为”意近，指没有事端或劳役。
注：无觉：不醒。
原：有兔爰爰，/雉离于罿。/我生之初，/尚无庸。/我生之后，/逢此百凶。/尚寐无聪！|| 兔子自在悠闲，野鸡却落进了网中。我刚出生的时候，天下还没有劳役。我长大以后，却遭遇了种种灾祸。但愿睡着了什么也听不见！
注：罿（chōng）：捕鸟的网。
注：庸：劳役。
注：百凶：种种灾祸。无聪：不闻，什么也听不到。

# 葛藟
题解：一个远离亲人、寄居他人家中的人，称别人为父母兄长，却得不到关怀，倍感孤苦。旧说以为刺周平王弃其九族；今人或以为流亡者、入赘者的悲歌。
原：绵绵葛藟，/在河之浒。/终远兄弟，/谓他人父。/谓他人父，/亦莫我顾。|| 葛藤绵延不断，生长在河岸边。我已经远离了兄弟亲人，管别人叫父亲。管别人叫父亲，别人也不肯照顾我。
注：绵绵：连绵不断的样子。葛藟（lěi）：葛藤一类的蔓生植物。
注：浒（hǔ）：水边。
注：终：既，已经。远：远离。
注：莫我顾：即“莫顾我”，不照顾我。
原：绵绵葛藟，/在河之涘。/终远兄弟，/谓他人母。/谓他人母，/亦莫我有。|| 葛藤绵延不断，生长在河水边。我已经远离了兄弟亲人，管别人叫母亲。管别人叫母亲，别人也不肯亲近我。
注：涘（sì）：水边。
注：有：相亲，友爱。
原：绵绵葛藟，/在河之漘。/终远兄弟，/谓他人昆。/谓他人昆，/亦莫我闻。|| 葛藤绵延不断，生长在河岸上。我已经远离了兄弟亲人，管别人叫哥哥。管别人叫哥哥，别人也不肯过问我。
注：漘（chún）：河岸，水边。
注：昆：兄。
注：闻：通“问”，体恤、过问。

# 采葛
题解：思念情人的短歌，“一日不见，如三秋兮”成为后世形容思念殷切的名句。《毛诗序》以为惧谗之作，今人多读作恋歌。
原：彼采葛兮，/一日不见，/如三月兮！|| 那个采葛的人啊，一天没有见到，就像隔了三个月啊！
注：葛：蔓生植物，茎皮纤维可以织布。
原：彼采萧兮，/一日不见，/如三秋兮！|| 那个采萧的人啊，一天没有见到，就像隔了三个季度啊！
注：萧：香蒿，古人祭祀时用来焚烧取香。
注：三秋：三个秋季，即九个月；一说指三年。
原：彼采艾兮，/一日不见，/如三岁兮！|| 那个采艾的人啊，一天没有见到，就像隔了三年啊！
注：艾：艾蒿，叶可入药，用于针灸。

# 大车
题解：女子对所爱的男子表白心意，担心对方不敢与自己相从，誓言生不能同居、死后也要同穴。旧说以为刺周大夫不能听男女之讼，今人多读作爱情诗。
原：大车槛槛，/毳衣如菼。/岂不尔思？/畏子不敢！|| 大车行驶槛槛作响，车上的毛毡车帷青如初生的芦苇。我怎么会不想念你？只怕你不敢！
注：大车：大夫所乘的车，一说为牛车。槛（kǎn）槛：车行声。
注：毳（cuì）衣：用兽毛织成的车帷，或说为大夫所穿毛织礼服。
注：菼（tǎn）：初生的荻，色青绿。
注：岂不尔思：即“岂不思尔”。子：你，指所爱的人。
原：大车啍啍，/毳衣如璊。/岂不尔思？/畏子不奔。|| 大车行驶啍啍作响，车上的毛毡车帷红如美玉。我怎么会不想念你？只怕你不肯和我一起出奔。
注：啍（tūn）啍：车行沉重缓慢的声音。
注：璊（mén）：红色的玉。
注：奔：私奔，指不经正式婚礼而相从。
原：穀则异室，/死则同穴。/谓予不信，/有如皦日！|| 活着时不能同住一个屋子，死后也要葬在一个墓穴。如果你说我的话不可信，有这明亮的太阳作证！
注：穀：活着。异室：分居两处。
注：同穴：合葬于同一墓穴。
注：有如皦（jiǎo）日：有明亮的太阳为证，古人发誓的用语。

# 丘中有麻
题解：女子在山丘上等候所爱之人，盼他到来并以佩玉相赠。《毛诗序》以为思念被放逐的贤人，今人多读作男女相约的情歌。“留”或以为姓氏，子嗟、子国为人名，具体所指存疑。
原：丘中有麻，/彼留子嗟。/彼留子嗟，/将其来施施。|| 山丘上长着麻，那里有刘家的子嗟。那刘家的子嗟啊，盼他高高兴兴地走来。
注：丘中：即丘上，山丘之中。
注：留：一说为姓氏，即“刘”；一说训为“留住”。子嗟：人名。
注：将：请，希望。施（shī）施：悠然喜悦地走来的样子；一说为施予、惠赠之意，存疑。
原：丘中有麦，/彼留子国。/彼留子国，/将其来食。|| 山丘上长着麦子，那里有刘家的子国。那刘家的子国啊，盼他到来一起吃饭。
注：子国：人名，旧说为子嗟之父，存疑。
注：食：吃饭；一说暗指男女欢会。
原：丘中有李，/彼留之子。/彼留之子，/贻我佩玖。|| 山丘上长着李树，那里有刘家的那个人。那刘家的那个人啊，送给我一块佩玉。
注：之子：那个人。
注：贻：赠送。佩玖（jiǔ）：佩带的玉石。玖，像玉的黑色美石。
