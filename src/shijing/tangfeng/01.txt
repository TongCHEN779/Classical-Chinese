# 唐风
题解：唐是周成王封其弟叔虞的故地，在今山西南部汾水流域，后改国号为晋，《唐风》实即晋地的诗歌，共十二篇。诗中多忧时惜日、勤俭自警之情，也有婚恋、行役、悼亡之作，《左传》记吴季札观乐时称其“思深”，有唐尧遗风。

# 蟋蟀
题解：岁暮感时之作，劝人及时行乐而又不可荒废本职。《毛诗序》以为刺晋僖公俭不中礼，今人多看作士人岁末自勉或相互劝诫之辞。
原：蟋蟀在堂，/岁聿其莫。/今我不乐，/日月其除。/无已大康，/职思其居。/好乐无荒，/良士瞿瞿。|| 蟋蟀已经躲进堂屋，一年就要到头了。如今我若不寻些快乐，光阴就白白溜走了。可也别乐得太过分，要常想想自己的本分。爱好享乐却不荒废正事，贤良的人总是警惕自省。
注：聿（yù）：语助词，无实义。莫：同“暮”，岁莫即年终。
注：除：过去，消逝。
注：无已大康：不要太过于安乐。已，甚；康，乐。
注：瞿瞿（jù）：惊顾警惕的样子。
原：蟋蟀在堂，/岁聿其逝。/今我不乐，/日月其迈。/无已大康，/职思其外。/好乐无荒，/良士蹶蹶。|| 蟋蟀已经躲进堂屋，一年就要过去了。如今我若不寻些快乐，日月便匆匆远去。可也别乐得太过分，本分以外的事也要顾及。爱好享乐却不荒废正事，贤良的人总是勤勉奋发。
注：迈：远行，指时光流逝。
注：外：分外之事，或指意外的变故。
注：蹶蹶（guì）：勤勉敏捷的样子。
原：蟋蟀在堂，/役车其休。/今我不乐，/日月其慆。/无已大康，/职思其忧。/好乐无荒，/良士休休。|| 蟋蟀已经躲进堂屋，服役的车子也该歇下了。如今我若不寻些快乐，岁月就这样逝去。可也别乐得太过分，要想到可能的忧患。爱好享乐却不荒废正事，贤良的人总是安详从容。
注：役车：服役运输用的车，岁末农事已毕，车也停用。
注：慆（tāo）：逝去。
注：休休：安闲自得的样子；一说勤勉貌。

# 山有枢
题解：讽劝守财不用者及时享用的诗，语带悲凉。《毛诗序》以为刺晋昭公不能修道治国，今人多以为是没落贵族或世人感叹人生短促之作。
原：山有枢，/隰有榆。/子有衣裳，/弗曳弗娄？/子有车马，/弗驰弗驱？/宛其死矣，/他人是愉！|| 山上长着刺榆，洼地长着白榆。你有好衣裳，怎么不穿也不披？你有车和马，怎么不驾也不骑？等你一朝死去，别人就拿去享乐！
注：枢：刺榆，一种有刺的榆树。
注：隰（xí）：低湿之地。
注：曳、娄：拖曳、提挈，指穿着衣裳；娄，读如“搂”。
注：宛：枯萎倒下的样子；一说同“苑”，形容死去。愉：乐，享用。
原：山有栲，/隰有杻。/子有廷内，/弗洒弗扫？/子有钟鼓，/弗鼓弗考？/宛其死矣，/他人是保！|| 山上长着山樗，洼地长着檍树。你有庭院和堂屋，怎么不洒水也不打扫？你有钟和鼓，怎么不敲也不击？等你一朝死去，就归别人占有！
注：栲（kǎo）：山樗；杻（niǔ）：檍树，皆木名，具体所指存疑。
注：廷内：庭院和室内。廷，同“庭”。
注：考：敲击。
注：保：占有。
原：山有漆，/隰有栗。/子有酒食，/何不日鼓瑟？/且以喜乐，/且以永日。/宛其死矣，/他人入室！|| 山上长着漆树，洼地长着栗树。你有美酒佳肴，何不天天弹瑟作乐？姑且借此寻些欢喜，姑且借此消磨长日。等你一朝死去，别人就住进你的屋室！
注：永日：消磨整日，延长白昼的欢乐。

# 扬之水
题解：《毛诗序》以为刺晋昭公，说晋大夫将归附曲沃桓叔，诗中“从子于沃”与此史事相关；也有人读作女子与情人相会之歌。诗旨历来有争议。
原：扬之水，/白石凿凿。/素衣朱襮，/从子于沃。/既见君子，/云何不乐？|| 激扬的流水，水中白石鲜明。穿着白衣红领，跟随你来到沃地。见到了君子，怎能不快乐？
注：扬：激扬；一说为水名，存疑。
注：凿凿：鲜明的样子。
注：襮（bó）：绣有花纹的衣领。
注：沃：曲沃，晋国城邑，在今山西闻喜东北；一说泛指水边。
原：扬之水，/白石皓皓。/素衣朱绣，/从子于鹄。/既见君子，/云何其忧？|| 激扬的流水，水中白石洁白。穿着白衣绣着红纹，跟随你来到鹄地。见到了君子，还有什么忧愁？
注：皓皓：洁白的样子。
注：鹄（hú）：地名，当在曲沃附近，具体所在存疑。
原：扬之水，/白石粼粼。/我闻有命，/不敢以告人！|| 激扬的流水，水中白石清亮。我听到了命令，不敢把它告诉别人！
注：粼粼：水清石明的样子。
注：命：指令，传统说指桓叔起事的密谋；读作情诗则指约会之言。

# 椒聊
题解：以花椒结实繁多起兴，赞美一个身材高大的人，兼有祝其子孙繁衍之意。《毛诗序》以为指曲沃桓叔势力日盛，今人多以为赞美妇人或男子之歌。
原：椒聊之实，/蕃衍盈升。/彼其之子，/硕大无朋。/椒聊且，/远条且！|| 花椒树结的果实，繁茂得能装满一升。那个人啊，高大无人能比。花椒啊，香气飘得多远啊！
注：椒聊：花椒。聊，语助词；一说指成串的果实。
注：蕃衍：繁盛众多。升：量器。
注：硕大：高大丰满。无朋：无可相比。
注：且（jū）：语末助词。远条：香气远扬；条，长。
原：椒聊之实，/蕃衍盈匊。/彼其之子，/硕大且笃。/椒聊且，/远条且！|| 花椒树结的果实，繁茂得能装满一捧。那个人啊，高大而又厚实。花椒啊，香气飘得多远啊！
注：匊（jū）：两手合捧，同“掬”。
注：笃：厚实，忠厚。

# 绸缪
题解：写新婚之夜的喜悦，一说为闹新房时打趣新人之辞。《毛诗序》以为刺晋国之乱使婚姻不得其时，今人多读作贺婚之歌。
原：绸缪束薪，/三星在天。/今夕何夕，/见此良人？/子兮子兮，/如此良人何？|| 一捆柴薪缠得紧紧，三星刚升上天空。今晚是什么样的夜晚，竟见到这样的好人？你呀你呀，拿这好人怎么办呢？
注：绸缪（chóu móu）：缠绕捆束。束薪：成捆的柴，古诗中常与婚姻相关。
注：三星：参宿三星，一说心宿三星，存疑。
注：良人：好人，此指丈夫。
原：绸缪束刍，/三星在隅。/今夕何夕，/见此邂逅？/子兮子兮，/如此邂逅何？|| 一捆草料缠得紧紧，三星挂在天角。今晚是什么样的夜晚，竟有这样的遇合？你呀你呀，拿这好遇合怎么办呢？
注：刍（chú）：喂牲口的草。
注：隅：天的一角，指星位移动，夜已渐深。
注：邂逅：不期而遇，指称心的相遇，或指所遇之人。
原：绸缪束楚，/三星在户。/今夕何夕，/见此粲者？/子兮子兮，/如此粲者何？|| 一捆荆条缠得紧紧，三星正对着门户。今晚是什么样的夜晚，竟见到这样美丽的人？你呀你呀，拿这美人怎么办呢？
注：楚：荆条。
注：在户：星光照到门口，已是深夜。
注：粲（càn）者：美人，此指新娘。

# 杕杜
题解：流落之人孤独无助、哀叹没有兄弟的诗。《毛诗序》以为刺晋君不亲宗族，今人多看作孤独行旅者的自伤之辞。
原：有杕之杜，/其叶湑湑。/独行踽踽，/岂无他人？/不如我同父。/嗟行之人，/胡不比焉？/人无兄弟，/胡不佽焉？|| 一棵孤零零的棠梨，叶子倒还茂盛。我独自走路孤孤单单，难道没有别的人吗？可总不如同父的兄弟。唉，路上的行人啊，为何不来亲近我？我没有兄弟，为何不来帮帮我？
注：杕（dì）：孤立特出的样子。杜：棠梨，赤棠。
注：湑湑（xǔ）：茂盛的样子。
注：踽踽（jǔ）：孤独行走的样子。
注：比：亲近，相依辅。佽（cì）：帮助。
原：有杕之杜，/其叶菁菁。/独行睘睘，/岂无他人？/不如我同姓。/嗟行之人，/胡不比焉？/人无兄弟，/胡不佽焉？|| 一棵孤零零的棠梨，叶子青葱茂密。我独自走路无依无靠，难道没有别的人吗？可总不如同姓的亲族。唉，路上的行人啊，为何不来亲近我？我没有兄弟，为何不来帮帮我？
注：菁菁（jīng）：茂盛的样子。
注：睘睘（qióng）：孤独无依的样子。
注：同姓：同宗族的人，与上章“同父”互文。

# 羔裘
题解：有人身居高位而对旧人傲慢，诗人表示不满又念旧情。《毛诗序》以为刺在位者不恤其民，今人或读作妇人怨丈夫、情人负心之辞，诗中人物关系存疑。
原：羔裘豹祛，/自我人居居。/岂无他人？/维子之故。|| 穿着豹皮袖口的羔裘，对我们却那样倨傲。难道没有别人可依吗？只因念着你是故人。
注：羔裘：羊羔皮袍，卿大夫的服饰。祛（qū）：袖口。
注：自：对于。我人：我们，一说指自家人。
注：居居：同“倨倨”，傲慢的样子。
注：故：故旧之情。
原：羔裘豹褎，/自我人究究。/岂无他人？/维子之好。|| 穿着豹皮镶袖的羔裘，对我们却那样骄横。难道没有别人可依吗？只因念着与你旧日的交好。
注：褎（xiù）：同“袖”。
注：究究：傲慢不亲的样子，与“居居”义近。
注：好：交好，情谊。

# 鸨羽
题解：久役在外的人哀叹王事无休、不能耕种奉养父母，向苍天呼告。《毛诗序》以为晋昭公以后大乱、君子下从征役而作，今人多看作一般徭役者的怨歌。
原：肃肃鸨羽，/集于苞栩。/王事靡盬，/不能艺稷黍。/父母何怙！/悠悠苍天，/曷其有所？|| 鸨鸟沙沙扇着翅膀，落在丛生的栎树上。官家的差事没完没了，没法回去种稷种黍。父母依靠什么过活！高远的苍天啊，何时我才能安居？
注：肃肃：鸟振翅的声音。鸨（bǎo）：鸟名，似雁而大，不善栖树，此以喻处境不安。
注：苞：丛生。栩（xǔ）：栎树。
注：靡盬（gǔ）：没有止息。艺：种植。
注：怙（hù）：依靠。曷：何时。所：安居之处。
原：肃肃鸨翼，/集于苞棘。/王事靡盬，/不能艺黍稷。/父母何食！/悠悠苍天，/曷其有极？|| 鸨鸟沙沙扇着翅膀，落在丛生的枣树上。官家的差事没完没了，没法回去种黍种稷。父母拿什么吃！高远的苍天啊，这苦日子哪天到头？
注：棘：酸枣树。
注：极：尽头。
原：肃肃鸨行，/集于苞桑。/王事靡盬，/不能艺稻粱。/父母何尝！/悠悠苍天，/曷其有常？|| 鸨鸟一行行飞过，落在丛生的桑树上。官家的差事没完没了，没法回去种稻种粱。父母还能尝到什么！高远的苍天啊，何时才能恢复正常？
注：行（háng）：行列；一说指鸟的翅羽。
注：尝：吃，品尝。
注：常：正常的生活。

# 无衣
题解：赞美对方所赠衣服的短诗，一说为请求赐命服之作。《毛诗序》以为美晋武公请命于周天子，今人多读作感谢赠衣或睹衣思人之辞，具体关系存疑。
原：岂曰无衣？/七兮。/不如子之衣，/安且吉兮。|| 怎能说我没有衣服？我有七件呢。只是比不上你给的衣服，又舒适又美好。
注：七：七件衣服；旧说指侯伯七命之服，存疑。
注：子之衣：你的衣服，或指你所赠之衣。
注：安且吉：舒适而且美好。
原：岂曰无衣？/六兮。/不如子之衣，/安且燠兮。|| 怎能说我没有衣服？我有六件呢。只是比不上你给的衣服，又舒适又暖和。
注：六：变换数字以成章，旧说附会天子之卿六命，存疑。
注：燠（yù）：温暖。

# 有杕之杜
题解：以路旁孤生的棠梨起兴，盼望心中的君子前来相会。《毛诗序》以为刺晋武公不能求贤，今人多读作恋歌。
原：有杕之杜，/生于道左。/彼君子兮，/噬肯适我？/中心好之，/曷饮食之！|| 一棵孤零零的棠梨，长在道路的左边。那位君子啊，可肯到我这里来？心里实在喜欢他，何不请他吃喝一顿！
注：道左：道路东边；一说道路左侧。
注：噬（shì）：发语词；一说同“曷”，何时。适：往，到。
注：中心：心中。
注：曷：何不。饮食之：请他饮酒吃饭；一说隐指男女欢会，存疑。
原：有杕之杜，/生于道周。/彼君子兮，/噬肯来游？/中心好之，/曷饮食之！|| 一棵孤零零的棠梨，长在道路的拐角。那位君子啊，可肯来这里游玩？心里实在喜欢他，何不请他吃喝一顿！
注：周：道路弯曲处；一说道路右侧。

# 葛生
题解：妻子悼念亡夫、誓言死后同穴的诗，是《诗经》中著名的悼亡之作。《毛诗序》以为刺晋献公好攻战，致使国人多丧，今人多读作悼亡诗，亦有以为丈夫悼妻者。
原：葛生蒙楚，/蔹蔓于野。/予美亡此，/谁与？独处！|| 葛藤长着盖满了荆树，蔹草蔓延在野地里。我心爱的人已不在这里，谁来陪伴？只剩我独自度日！
注：蒙：覆盖。楚：荆树。
注：蔹（liǎn）：蔓生草本植物，白蔹之类。
注：予美：我所爱的人。亡此：已不在此，指死去。
注：谁与：与谁相伴。
原：葛生蒙棘，/蔹蔓于域。/予美亡此，/谁与？独息！|| 葛藤长着盖满了枣树，蔹草蔓延在墓地上。我心爱的人已不在这里，谁来陪伴？只剩我独自安歇！
注：棘：酸枣树。
注：域：墓地；一说田野。
注：息：休息，安寝。
原：角枕粲兮，/锦衾烂兮。/予美亡此，/谁与？独旦！|| 角枕还是那样鲜亮，锦被还是那样灿烂。我心爱的人已不在这里，谁来陪伴？只剩我独自熬到天明！
注：角枕：用兽角装饰的枕头；一说为殓葬所用，存疑。
注：粲、烂：鲜明灿烂。衾（qīn）：被子。
注：独旦：独自醒到天亮。
原：夏之日，/冬之夜。/百岁之后，/归于其居。|| 夏天的白昼那样漫长，冬天的黑夜那样漫长。等我百年之后，就去和你同居一处。
注：夏之日，冬之夜：夏日长、冬夜长，喻度日如年。
注：百岁之后：死后的委婉说法。
注：其居：指亡者的坟墓。
原：冬之夜，/夏之日。/百岁之后，/归于其室。|| 冬天的黑夜那样漫长，夏天的白昼那样漫长。等我百年之后，就去和你同住一室。
注：其室：亦指墓穴，与上章“其居”同义。

# 采苓
题解：劝人勿听信谗言的诗。《毛诗序》以为刺晋献公好听谗言，今人多看作一般的戒谗之作。
原：采苓采苓，/首阳之巅。/人之为言，/苟亦无信。/舍旃舍旃，/苟亦无然。/人之为言，/胡得焉？|| 采甘草啊采甘草，到首阳山的山顶。别人编造的话，千万不要相信。丢开它吧丢开它，千万不要当真。别人编造的话，能得到什么呢？
注：苓（líng）：旧说为甘草；一说指莲，所指存疑。
注：首阳：山名，在今山西永济南；一说在晋地他处，存疑。
注：为言：伪言，捏造的话。为，同“伪”。苟：确实，千万；一说姑且。
注：舍旃（zhān）：舍弃它。旃，“之焉”合音。然：认为是对的。
原：采苦采苦，/首阳之下。/人之为言，/苟亦无与。/舍旃舍旃，/苟亦无然。/人之为言，/胡得焉？|| 采苦菜啊采苦菜，到首阳山的山下。别人编造的话，千万不要附和。丢开它吧丢开它，千万不要当真。别人编造的话，能得到什么呢？
注：苦：苦菜。
注：与：赞许，附和。
原：采葑采葑，/首阳之东。/人之为言，/苟亦无从。/舍旃舍旃，/苟亦无然。/人之为言，/胡得焉？|| 采芜菁啊采芜菁，到首阳山的东面。别人编造的话，千万不要听从。丢开它吧丢开它，千万不要当真。别人编造的话，能得到什么呢？
注：葑（fēng）：芜菁，即蔓菁。
注：从：听从。
