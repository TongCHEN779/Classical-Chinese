# 陈风
题解：陈风是陈国一带的诗歌。陈国在今河南淮阳一带，相传是周武王封舜的后人建立的。这里巫风盛行，人们喜好歌舞游乐。现存十篇，多写男女相会、恋慕与歌舞，也有几篇讽刺陈国君臣。

# 宛丘
题解：写宛丘上下的歌舞。《毛诗序》说是讽刺陈幽公荒淫游荡，今人多读作恋慕一位舞者的诗，诗中“子”到底指谁，各家说法不一。
原：子之汤兮，/宛丘之上兮。/洵有情兮，/而无望兮。|| 你放情歌舞，在宛丘的高处尽兴。我对你确实有情，却没有什么指望。
注：汤：同“荡”，放情游荡，舞姿奔放。
注：宛丘：四面高、中间低的土丘，是陈国人游乐的地方。
注：洵：确实。
注：望：指望；一说“望”指威仪、声望。
原：坎其击鼓，/宛丘之下。/无冬无夏，/值其鹭羽。|| 咚咚地敲着鼓，在宛丘下面。不论冬天夏天，总举着鹭羽在跳舞。
注：坎：击鼓声。
注：值：持着，拿着；一说竖立。
注：鹭羽：用白鹭羽毛做的舞具。
原：坎其击缶，/宛丘之道。/无冬无夏，/值其鹭翿。|| 咚咚地敲着瓦缶，在宛丘的路上。不论冬天夏天，总举着鹭羽的舞旗。
注：缶（fǒu）：瓦器，可敲击打拍子。
注：鹭翿（dào）：用鹭羽装饰的舞具，形似伞或旗。

# 东门之枌
题解：写陈国男女在良辰吉日聚会歌舞、互相赠物定情。《毛诗序》认为是讽刺男女荒废本业、聚众淫乐，今人多看作描写民间歌舞集会的诗。
原：东门之枌，/宛丘之栩。/子仲之子，/婆娑其下。|| 东门外有白榆，宛丘上有柞树。子仲家的姑娘，在树下翩翩起舞。
注：枌（fén）：白榆。
注：栩（xǔ）：柞树。
注：子仲：姓氏。之子：这个人，指那位姑娘。
注：婆娑：舞蹈的样子。
原：谷旦于差，/南方之原。/不绩其麻，/市也婆娑。|| 选好了吉日良辰，到南边的平原上去。她不再纺她的麻，到人多的地方去跳舞。
注：谷旦：好日子，吉日。差：选择；一说通“徂”，前往。
注：原：平原；一说是姓氏“原氏”。
注：绩：把麻搓捻成线。
注：市：人群聚集的地方。
原：谷旦于逝，/越以鬷迈。/视尔如荍，/贻我握椒。|| 趁着好日子前往，大家结伴同行。我看你像锦葵花一样美，你送我一把花椒。
注：逝：往。
注：越以：发语词，于是。鬷（zōng）：众，聚在一起；一说是一种锅。迈：行。
注：荍（qiáo）：锦葵，花呈淡紫或粉红色。
注：握椒：一把花椒，古人用作香物互赠，表示情意。

# 衡门
题解：一首安于简朴生活的诗。《毛诗序》说是劝诱陈僖公立志；朱熹以为隐居自乐者之辞；也有人读作男子失恋后的自我宽解。
原：衡门之下，/可以栖迟？/泌之洋洋，/可以乐饥？|| 简陋的横木门下，不也可以安身歇息吗？泌水的泉流浩浩荡荡，不也可以疗饥吗？
注：衡门：横一根木头当门，指简陋的住处。
注：栖迟：栖息，休息。
注：泌（bì）：泉水名，一说水名，所在已难考。洋洋：水流盛大的样子。
注：乐饥：“乐”通“疗”，解饿；一说喻慰解情思的饥渴。
原：岂其食鱼，/必河之鲂？/岂其取妻，/必齐之姜？|| 难道吃鱼，一定要吃黄河的鳊鱼？难道娶妻，一定要娶齐国姜家的姑娘？
注：鲂（fáng）：鳊鱼，鱼中味美者。
注：取：同“娶”。
注：齐之姜：齐国国君姓姜，泛指贵族女子。
原：岂其食鱼，/必河之鲤？/岂其取妻，/必宋之子？|| 难道吃鱼，一定要吃黄河的鲤鱼？难道娶妻，一定要娶宋国子家的姑娘？
注：宋之子：宋国国君姓子，也泛指贵族女子。

# 东门之池
题解：男子在东门外的水池边，向美好的姑娘表达倾慕，愿与她对歌交谈。《毛诗序》另有讽时之说，今人多读作情歌。
原：东门之池，/可以沤麻。/彼美淑姬，/可与晤歌。|| 东门外的水池，可以浸泡麻。那位美好的姑娘，可以和她对唱情歌。
注：池：水池；一说护城河。
注：沤（òu）：长时间浸泡，使麻皮易于剥取。
注：淑姬：善良美好的女子。姬，女子的美称。
注：晤：相对，面对面。
原：东门之池，/可以沤纻。/彼美淑姬，/可与晤语。|| 东门外的水池，可以浸泡纻麻。那位美好的姑娘，可以和她面对面说话。
注：纻（zhù）：苎麻。
原：东门之池，/可以沤菅。/彼美淑姬，/可与晤言。|| 东门外的水池，可以浸泡菅草。那位美好的姑娘，可以和她倾心交谈。
注：菅（jiān）：一种茅草，浸泡后可以编绳、织席、做草鞋。

# 东门之杨
题解：写约在黄昏相会，等到群星闪亮对方还没有来。《毛诗序》说是讽刺婚姻失时，今人多读作约会久候不至的情诗。
原：东门之杨，/其叶牂牂。/昏以为期，/明星煌煌。|| 东门外的白杨，叶子沙沙作响。约好了黄昏见面，等到启明星都已闪闪发亮。
注：牂牂（zāng）：风吹树叶的声音；一说枝叶茂盛的样子。
注：昏以为期：约定黄昏相会。
注：明星：一说启明星，即金星；一说泛指明亮的星。煌煌：明亮的样子。
原：东门之杨，/其叶肺肺。/昏以为期，/明星晢晢。|| 东门外的白杨，叶子簌簌作响。约好了黄昏见面，等到星星都已明亮闪烁。
注：肺肺（pèi）：与“牂牂”义近，形容枝叶茂盛或风吹之声。
注：晢晢（zhé）：明亮的样子。

# 墓门
题解：讽刺一个品行不良、屡劝不改的人。《毛诗序》以为讽刺陈佗，也有人读作妻子劝诫丈夫之作，所刺何人存疑。
原：墓门有棘，/斧以斯之。/夫也不良，/国人知之。/知而不已，/谁昔然矣！|| 墓门前长着酸枣丛，要拿斧头砍掉它。那个人品行不好，全国人都知道。知道了他也不改，从前就一直这样！
注：墓门：墓道的门；一说陈国城门名。
注：棘：酸枣树，多刺。
注：斯：劈开，砍。
注：谁昔：从前，往昔。
原：墓门有梅，/有鸮萃止。/夫也不良，/歌以讯之。/讯予不顾，/颠倒思予！|| 墓门前长着梅树，有猫头鹰聚在上面。那个人品行不好，我作歌来劝诫他。劝了他也不理会，等到败落时才会想起我的话！
注：梅：一说当作“棘”或“楳”，存疑。
注：鸮（xiāo）：猫头鹰，古人视为不祥之鸟。萃：聚集。止：语气词。
注：讯：通“谇”（suì），告诫，劝谏。
注：讯予不顾：即“予讯不顾”，我劝告了他却不理睬。颠倒：倾覆、狼狈之时；一说指心神反复不安。

# 防有鹊巢
题解：担心有人从中挑拨离间，夺走自己所爱之人。《毛诗序》说是忧虑谗言的诗，今人多读作恋人间忧谗的情诗。
原：防有鹊巢，/邛有旨苕。/谁侜予美？/心焉忉忉！|| 堤坝上怎会有鹊巢，土丘上怎会长苕草？是谁在欺骗我的心上人？我心里忧愁不安！
注：防：堤坝；一说地名。
注：邛（qióng）：土丘。旨：美。苕（tiáo）：一种蔓生草，多长在低湿之处。前两句说不合常理的事，喻谗言荒诞。
注：侜（zhōu）：欺骗，挑拨。予美：我所爱的人。
注：忉忉（dāo）：忧愁的样子。
原：中唐有甓，/邛有旨鹝。/谁侜予美？/心焉惕惕！|| 庭院的路上怎会铺着瓦砖，土丘上怎会长绶草？是谁在欺骗我的心上人？我心里惶恐不安！
注：中唐：庭院中的路。甓（pì）：砖瓦。
注：鹝（yì）：绶草，多生于低湿之地。
注：惕惕：恐惧不安的样子。

# 月出
题解：月下思念美人的诗，每章以月光起兴，写美人的容貌体态与诗人的忧思。《毛诗序》以为刺好色，今人多读作纯粹的情诗。
原：月出皎兮，/佼人僚兮。/舒窈纠兮，/劳心悄兮。|| 月亮出来多么皎洁，那美人多么俊俏。她体态舒缓而优雅，让我忧心难平。
注：皎：洁白明亮。
注：佼人：美人。僚：美好；一说通“嫽”。
注：舒：舒缓，从容；一说发语词。窈纠（yǎo jiǎo）：形容女子体态轻盈柔美。
注：劳心：忧心。悄：忧愁的样子。
原：月出皓兮，/佼人懰兮。/舒忧受兮，/劳心慅兮。|| 月亮出来多么明亮，那美人多么娇艳。她步态舒缓而轻柔，让我心中烦忧。
注：懰（liǔ）：美好、妩媚。
注：忧受：形容步态舒缓柔美，与“窈纠”义近。
注：慅（cǎo）：忧愁不安。
原：月出照兮，/佼人燎兮。/舒夭绍兮，/劳心懆兮。|| 月亮出来照耀大地，那美人光彩照人。她身姿舒展而婀娜，让我愁苦不已。
注：燎：明亮，形容光彩照人。
注：夭绍：形容体态婀娜多姿。
注：懆（cǎo）：忧愁不安。通行本作“惨”，此从书中所印。

# 株林
题解：讽刺陈灵公与夏姬私通、频频驾车前往株林。事见《左传》宣公九年、十年，诗用问答口吻，含蓄而带嘲讽。
原：胡为乎株林？/从夏南；/匪适株林，/从夏南！|| 为什么要去株林？说是去找夏南；不是要往株林去，只是找夏南罢了！
注：株林：陈国大夫夏氏的封邑，在今河南柘城一带。
注：从：跟随，找；一说训“因”。夏南：夏徵舒，字子南，夏姬之子。表面说找儿子，实指其母夏姬。
注：匪：非，不是。适：往。
原：驾我乘马，/说于株野；/乘我乘驹，/朝食于株。|| 驾着我的四匹马，停歇在株邑的郊野；坐着我的四驹车，赶到株邑去吃早饭。
注：乘（shèng）马：四匹马拉的车。
注：说（shuì）：通“税”，停车歇息。
注：驹：少壮的马；一说当作“骄”，高大的马。
注：朝食：吃早饭；有人认为暗指男女私会，存疑。

# 泽陂
题解：在池塘边思念一位美好的人，伤感得辗转难眠。《毛诗序》以为刺陈灵公君臣淫乱，今人多读作相思之诗，抒情者是男是女说法不一。
原：彼泽之陂，/有蒲与荷。/有美一人，/伤如之何？/寤寐无为，/涕泗滂沱！|| 那池塘的堤岸边，长着蒲草和荷花。有一个美好的人，想念得叫我怎么办？醒着睡着都无心做事，眼泪鼻涕像下雨一样流！
注：陂（bēi）：池塘的堤岸。
注：蒲：香蒲，水草。荷：荷花。
注：伤：思念而忧伤；一说“伤”当读作“阳”，即“我”。
注：涕泗：眼泪和鼻涕。滂沱：雨大的样子，形容泪多。
原：彼泽之陂，/有蒲与蕑。/有美一人，/硕大且卷。/寤寐无为，/中心悁悁！|| 那池塘的堤岸边，长着蒲草和莲蓬。有一个美好的人，身材高大，头发卷曲好看。醒着睡着都无心做事，心中郁闷忧愁！
注：蕑（jiān）：一说即兰草；一说当作“莲”，指莲蓬。
注：硕大：高大健美。卷（quán）：头发美好卷曲；一说仪容美好。
注：悁悁（yuān）：忧郁不乐的样子。
原：彼泽之陂，/有蒲菡萏。/有美一人，/硕大且俨。/寤寐无为，/辗转伏枕！|| 那池塘的堤岸边，长着蒲草和含苞的荷花。有一个美好的人，身材高大，神态端庄。醒着睡着都无心做事，翻来覆去伏在枕上！
注：菡萏（hàn dàn）：荷花的花苞。
注：俨：端庄庄重的样子。
