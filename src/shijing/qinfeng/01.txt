# 秦风
题解：秦本是西方以养马见长的部族，西周末年护送平王东迁有功而受封，逐渐占有关中故地。《秦风》存诗十篇，多写车马、田猎、征战与送别，风格刚健质朴，与东方诸国的诗风颇有不同。

# 车邻
题解：《毛诗序》以为美秦仲始有车马礼乐之好；今人多读作写贵族与友人相见宴乐的诗，在欢乐中流露出人生短促、及时行乐的感慨。
原：有车邻邻，/有马白颠。/未见君子，/寺人之令。|| 车子辚辚地驶来，驾车的马额头一片雪白。还没见到那位君子，先要等侍从进去通报传令。
注：邻邻：车行声，通“辚辚”。
注：白颠：额上有白毛的马。颠，额顶。
注：寺人：宫中近侍之臣。
注：令：传达命令；一说“令”指使唤，存疑。
原：阪有漆，/隰有栗。/既见君子，/并坐鼓瑟。/今者不乐，/逝者其耋！|| 山坡上有漆树，低湿的洼地里长着栗树。见到了君子，便与他并肩而坐弹起瑟来。此刻若不尽情欢乐，转眼之间就到了老年。
注：阪（bǎn）：山坡。
注：隰（xí）：低湿之地。
注：逝者：往后，将来。
注：耋（dié）：年老，古称八十岁为耋。
原：阪有桑，/隰有杨。/既见君子，/并坐鼓簧。/今者不乐，/逝者其亡！|| 山坡上有桑树，洼地里长着杨树。见到了君子，便与他并肩而坐吹起笙簧。此刻若不尽情欢乐，将来就会离开人世。
注：簧：笙一类吹奏乐器中的簧片，此代指笙。
注：亡：死去。

# 驷驖
题解：《毛诗序》以为美秦襄公始受封为诸侯、有田猎园囿之乐；诗写秦君带领亲近之人在园中狩猎，车马精良，射技高明，气象从容。
原：驷驖孔阜，/六辔在手。/公之媚子，/从公于狩。|| 四匹铁青色的骏马十分高大健壮，六条缰绳握在御者手中。国君所宠爱的人，跟随国君一起去打猎。
注：驖（tiě）：毛色赤黑如铁的马。
注：孔：很。
注：阜：肥大。
注：六辔：四马本有八条缰绳，两旁骖马内侧的两条系在车上，御者手执六条。
注：媚子：所宠爱亲近的人，或说指国君之子，或说指宠臣，存疑。
原：奉时辰牡，/辰牡孔硕。/公曰左之，/舍拔则获。|| 掌管园囿的官吏把应时的雄兽驱赶出来，这些雄兽个个肥大。国君吩咐从左边追射，一放箭便射中了猎物。
注：奉：驱赶进献。
注：时：这，指这些。
注：辰：应时，合于季节的。
注：牡：雄兽。
注：左之：从左侧射它。古人田猎习惯从兽的左方射击。
注：舍拔：放箭。拔，箭尾扣弦处。
原：游于北园，/四马既闲。/輶车鸾镳，/载猃歇骄。|| 猎罢在北园中游览，四匹马已经驯熟从容。轻便的车子上马衔铃声叮当，车上载着休息的猎犬。
注：闲：熟练，驯服。
注：輶（yóu）车：轻便的车。
注：鸾镳（biāo）：马嚼子两端挂着铃铛。
注：猃（xiǎn）、歇骄：都是猎犬名，猃为长嘴犬，歇骄为短嘴犬；一说“歇骄”指让骄犬歇息，存疑。

# 小戎
题解：《毛诗序》以为美秦襄公征伐西戎；诗以妇人口吻，先细数丈夫出征所乘的兵车、战马和兵器，再抒发对远征丈夫的思念，刚健与柔情兼具。
原：小戎俴收，/五楘梁辀，/游环胁驱。/阴靷鋈续，/文茵畅毂，/驾我骐馵。/言念君子，/温其如玉。/在其板屋，/乱我心曲。|| 轻便的兵车车厢浅小，弯曲的车辕上缠着五道皮条，游环和胁驱都安排停当。拉车的皮带系着白铜环，车上铺着虎皮褥，车毂长长，驾着青黑色的骐马和白脚的馵马。想起我那位君子，他温和得像美玉一样。如今他住在西戎的木板屋里，让我心乱如麻。
注：小戎：兵车。
注：俴（jiàn）：浅。
注：收：车厢后的横木，代指车厢。
注：五楘（mù）：用皮条在车辕上缠绕五处。
注：梁辀（zhōu）：弯曲如屋梁的车辕。
注：游环、胁驱：都是控制骖马的部件，具体形制存疑。
注：阴靷（yǐn）：拉车的皮带。
注：鋈（wù）续：以白铜环相连。
注：文茵：有花纹的车褥，多用虎皮。
注：畅毂（gǔ）：长长的车毂。
注：骐：青黑色有纹的马。
注：馵（zhù）：后左足白的马。
注：板屋：木板房，西戎地区的居所。
原：四牡孔阜，/六辔在手。/骐駵是中，/騧骊是骖。/龙盾之合，/鋈以觼軜。/言念君子，/温其在邑。/方何为期？/胡然我念之？|| 四匹公马高大健壮，六条缰绳握在手中。骐马和駵马驾在中间，騧马和骊马驾在两边。画着龙纹的盾牌成双竖立，内侧缰绳扣在白铜环上。想起我那位君子，他在西戎城邑中依然温和。他何时才是归期？叫我怎能不想念他？
注：駵（liú）：赤身黑鬣的马。
注：騧（guā）：黄身黑嘴的马。
注：骊：纯黑的马。
注：中：中间驾辕的两匹服马。
注：骖：两旁的马。
注：龙盾之合：两面画龙的盾合在一起竖在车上。
注：觼（jué）軜（nà）：系骖马内辔的有舌铜环，具体形制存疑。
注：邑：城邑，指他驻守之地。
注：方：将。
原：俴驷孔群，/厹矛鋈錞。/蒙伐有苑，/虎韔镂膺。/交韔二弓，/竹闭绲縢。/言念君子，/载寝载兴。/厌厌良人，/秩秩德音。|| 披着薄甲的四匹马十分协调，三棱矛的柄端套着白铜套。画着杂羽纹的盾牌色彩斑斓，虎皮弓袋上饰着雕镂的金属。弓袋里交叉插着两张弓，用竹制弓檠绳索捆紧。想起我那位君子，我躺下又起来难以安睡。那安详的好人啊，他的好名声井然远扬。
注：俴驷：披着薄金属甲的四马；一说是不披甲，存疑。
注：孔群：很协调。
注：厹（qiú）矛：三棱锋的矛。
注：錞（duì）：矛柄末端的金属套。
注：蒙伐：画有杂羽纹的盾。
注：苑：花纹貌。
注：虎韔（chàng）：虎皮弓袋。
注：镂膺：雕饰的金属装饰；或说指马胸带，存疑。
注：闭：竹制的校弓器，防弓变形。
注：绲（gǔn）縢（téng）：用绳子捆扎。
注：厌厌：安静和善貌。
注：秩秩：有条理、清明的样子。

# 蒹葭
题解：《毛诗序》以为刺秦襄公不能用周礼；今人多视为一首追寻意中人而不可得的怀人之作，“伊人”可望而不可即，意境空灵，也常被引申为对理想的追求。
原：蒹葭苍苍，/白露为霜。/所谓伊人，/在水一方。/溯洄从之，/道阻且长。/溯游从之，/宛在水中央。|| 芦苇青青一片，白露凝结成了霜。我心中念着的那个人，就在河水的另一边。逆着水流去寻她，道路险阻又漫长；顺着水流去找她，她仿佛就在水的中央。
注：蒹（jiān）葭（jiā）：芦苇一类的水草。
注：苍苍：青色浓郁的样子。
注：伊人：那个人。
注：溯洄：逆流而上。
注：溯游：顺流而下。
注：宛：仿佛，好像。
原：蒹葭萋萋，/白露未晞。/所谓伊人，/在水之湄。/溯洄从之，/道阻且跻。/溯游从之，/宛在水中坻。|| 芦苇繁密茂盛，白露还没有晒干。我心中念着的那个人，就在河的岸边。逆着水流去寻她，道路险阻又陡高；顺着水流去找她，她仿佛就在水中的小洲上。
注：萋萋：茂盛的样子。
注：晞（xī）：干。
注：湄（méi）：水与草相接的岸边。
注：跻（jī）：升高，指道路陡峭。
注：坻（chí）：水中的小块高地。
原：蒹葭采采，/白露未已。/所谓伊人，/在水之涘。/溯洄从之，/道阻且右。/溯游从之，/宛在水中沚。|| 芦苇丛丛密密，白露还没有消尽。我心中念着的那个人，就在河的水边。逆着水流去寻她，道路险阻又曲折；顺着水流去找她，她仿佛就在水中的沙洲上。
注：采采：众多茂盛的样子。
注：未已：未止，未干。
注：涘（sì）：水边。
注：右：迂回曲折；一说偏向右方，存疑。
注：沚（zhǐ）：水中的小洲。

# 终南
题解：《毛诗序》以为戒秦襄公之作；今人多读作秦人赞美并祝福其君（或贵客）的诗，以终南山的物产起兴，称颂其服饰仪容，末以长寿相祝。
原：终南何有？/有条有梅。/君子至止，/锦衣狐裘。/颜如渥丹，/其君也哉！|| 终南山上有什么？有山楸，也有梅树。君子来到这里，穿着锦绣衣裳和狐皮袍。他的脸色红润得像涂了丹砂，真不愧是我们的国君啊！
注：终南：终南山，在今陕西西安以南，属秦岭。
注：条：山楸树；一说柚树，存疑。
注：梅：梅树；一说楠木，存疑。
注：渥（wò）丹：浓厚的朱砂，形容面色红润。
注：其君也哉：一说“君”为赞美之辞，存疑。
原：终南何有？/有纪有堂。/君子至止，/黻衣绣裳。/佩玉将将，/寿考不亡！|| 终南山上有什么？有杞柳，也有棠梨。君子来到这里，穿着黑青花纹的上衣和五彩刺绣的下裳。身上佩玉锵锵作响，祝他长寿无疆，永享安康！
注：纪：通“杞”，杞柳；
注：堂：通“棠”，棠梨。一说“纪”“堂”指山的边角与平台，存疑。
注：黻（fú）衣：绣有黑青相间花纹的礼服。
注：将将（qiāng）：佩玉相击声。
注：寿考：长寿。
注：不亡：不已，长存；通行本多作“不忘”。

# 黄鸟
题解：据《左传·文公六年》，秦穆公死后以子车氏三子奄息、仲行、鍼虎殉葬，国人哀之而作此诗。诗分三章，各哀一人，控诉了以人殉葬的残酷。
原：交交黄鸟，/止于棘。/谁从穆公？/子车奄息。/维此奄息，/百夫之特。/临其穴，/惴惴其栗。/彼苍者天，/歼我良人！/如可赎兮，/人百其身！|| 黄雀交交地哀鸣，落在酸枣树上。是谁跟着穆公殉葬？是子车家的奄息。说起这位奄息，是百人之中的杰出者。走到墓穴的边上，他浑身恐惧发抖。苍天哪苍天，竟要毁灭我们的好人！如果可以赎回他，我们愿意拿一百个人来换他一个！
注：交交：鸟鸣声。
注：黄鸟：黄雀。
注：棘：酸枣树。“棘”谐“急”，有急迫之意。
注：从：从死，殉葬。
注：子车：氏；
注：奄息：名。
注：特：杰出者，一人抵得过百人。
注：惴惴（zhuì）：恐惧的样子。
注：歼：灭，杀。
注：人百其身：用百人赎他一身。
原：交交黄鸟，/止于桑。/谁从穆公？/子车仲行。/维此仲行，/百夫之防。/临其穴，/惴惴其栗。/彼苍者天，/歼我良人！/如可赎兮，/人百其身！|| 黄雀交交地哀鸣，落在桑树上。是谁跟着穆公殉葬？是子车家的仲行。说起这位仲行，一人足以抵挡百人。走到墓穴的边上，他浑身恐惧发抖。苍天哪苍天，竟要毁灭我们的好人！如果可以赎回他，我们愿意拿一百个人来换他一个！
注：桑：“桑”谐“丧”。
注：防：相当，相抵；一说为“比”义，存疑。
原：交交黄鸟，/止于楚。/谁从穆公？/子车鍼虎。/维此鍼虎，/百夫之御。/临其穴，/惴惴其栗。/彼苍者天，/歼我良人！/如可赎兮，/人百其身！|| 黄雀交交地哀鸣，落在荆树上。是谁跟着穆公殉葬？是子车家的鍼虎。说起这位鍼虎，一人能抵御百人。走到墓穴的边上，他浑身恐惧发抖。苍天哪苍天，竟要毁灭我们的好人！如果可以赎回他，我们愿意拿一百个人来换他一个！
注：楚：荆树，丛生灌木。“楚”谐“痛楚”之“楚”。
注：鍼（qián）虎：人名。
注：御：抵挡，与“特”“防”意近。

# 晨风
题解：《毛诗序》以为刺秦康公弃其贤臣；今人多读作女子思念久不归来的爱人、担心被遗忘的诗，一说为被弃之辞。
原：鴥彼晨风，/郁彼北林。/未见君子，/忧心钦钦。/如何如何？/忘我实多！|| 那晨风鸟飞得迅疾，飞向茂密的北边树林。见不到那位君子，我心里忧愁不安。怎么办啊怎么办？他把我忘得太多了！
注：鴥（yù）：鸟疾飞的样子。
注：晨风：鸟名，即鹯，一种猛禽；一说指早晨的风，存疑。
注：郁：树木茂密的样子。
注：钦钦：忧思难忘的样子。
注：实：是，确实。
原：山有苞栎，/隰有六驳。/未见君子，/忧心靡乐。/如何如何？/忘我实多！|| 山上有丛生的栎树，洼地里长着梓榆。见不到那位君子，我心里没有一点欢乐。怎么办啊怎么办？他把我忘得太多了！
注：苞：丛生。
注：栎（lì）：栎树。
注：六驳：树名，梓榆一类，树皮斑驳；一说为兽名，存疑。
注：靡：无。
原：山有苞棣，/隰有树檖。/未见君子，/忧心如醉。/如何如何？/忘我实多！|| 山上有丛生的郁李，洼地里长着挺立的山梨。见不到那位君子，我心中忧愁得像喝醉了一样。怎么办啊怎么办？他把我忘得太多了！
注：棣（dì）：郁李一类。
注：树：直立。
注：檖（suì）：山梨。

# 无衣
题解：《毛诗序》以为刺秦君好用兵；今人多读作秦人同仇敌忾、慷慨从军的战歌，表现出同袍共战、生死相依的豪情。
原：岂曰无衣？/与子同袍。/王于兴师，/修我戈矛，/与子同仇！|| 谁说没有衣裳？我和你同穿一件战袍。国君要出兵打仗，修整好我们的戈和矛，和你一起对付共同的敌人！
注：袍：长衣，行军时白天当衣、夜里当被。
注：王：指秦君，一说指周王，存疑。
注：于：语助词；一说为“往”，存疑。
注：兴师：出兵。
注：同仇：共同对敌。
原：岂曰无衣？/与子同泽。/王于兴师，/修我矛戟，/与子偕作！|| 谁说没有衣裳？我和你同穿一件内衣。国君要出兵打仗，修整好我们的矛和戟，和你一同奋起！
注：泽：通“襗”，贴身的内衣。
注：戟（jǐ）：兼有戈、矛之用的长兵器。
注：偕作：一同起身行动。
原：岂曰无衣？/与子同裳。/王于兴师，/修我甲兵，/与子偕行！|| 谁说没有衣裳？我和你同穿一条下裳。国君要出兵打仗，修整好我们的铠甲兵器，和你一起奔赴战场！
注：裳：下衣，裙裳。
注：甲兵：铠甲和兵器。
注：偕行：一同出征。

# 渭阳
题解：《毛诗序》说秦康公为太子时送舅父晋公子重耳返国，至渭水之北，念及亡母而作此诗；诗写甥舅送别之情。后世遂以“渭阳”代指舅甥情谊。
原：我送舅氏，/曰至渭阳。/何以赠之？/路车乘黄。|| 我送别舅父，一直送到渭水北岸。拿什么送给他呢？一辆大车，配上四匹黄马。
注：舅氏：舅父，旧说指晋公子重耳，即后来的晋文公。
注：曰：语助词。
注：渭阳：渭水的北岸，水北为阳。
注：路车：诸侯所乘的大车。
注：乘（shèng）黄：四匹黄马。
原：我送舅氏，/悠悠我思。/何以赠之？/琼瑰玉佩。|| 我送别舅父，心中思绪绵长。拿什么送给他呢？美石与玉做的佩饰。
注：悠悠我思：思念绵长；旧说兼指思念亡母，存疑。
注：琼瑰：似玉的美石。
注：玉佩：玉制的佩饰。

# 权舆
题解：《毛诗序》以为刺秦康公待贤者有始无终；今人多读作没落贵族或失意士人感叹今不如昔、待遇日薄之作。
原：於我乎夏屋渠渠，/今也每食无余。/于嗟乎不承权舆！|| 唉，当初我住着高大深广的屋子，如今每顿饭都吃不到剩余。可叹啊，再也比不上起初的光景了！
注：於（wū）：叹词；一说读为“吁”。
注：夏屋：大屋；一说指盛食物的大器具，存疑。
注：渠渠：深广的样子。
注：于（xū）嗟乎：叹息声。本章书中印作“於嗟乎”，与次章及书中注文不一致，据通行本改作“于”。
注：承：继续。
注：权舆：起初，开端。
原：於我乎每食四簋，/今也每食不饱。/于嗟乎不承权舆！|| 唉，当初我每顿饭都摆着四簋食物，如今每顿饭都吃不饱。可叹啊，再也比不上起初的光景了！
注：簋（guǐ）：古代盛饭食的圆形器皿，有耳。
