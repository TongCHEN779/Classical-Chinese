# 狡童
题解：女子因心上人不理睬自己而寝食难安的小诗。《毛诗序》以为刺郑昭公不能与贤人图事，今人多读作恋人闹别扭时的怨语。
原：彼狡童兮，/不与我言兮。/维子之故，/使我不能餐兮。|| 那个滑头的小子啊，竟然不肯跟我说话。就为了你的缘故，害得我饭都吃不下啊。
注：狡童：狡黠的少年，此处是带嗔意的昵称。
注：维子之故：因为你的缘故。维，语助词。
原：彼狡童兮，/不与我食兮。/维子之故，/使我不能息兮。|| 那个滑头的小子啊，竟然不肯和我一同吃饭。就为了你的缘故，害得我夜里无法安歇啊。
注：不与我食：不和我一起吃饭；一说“食”另有隐语意味，存疑。
注：息：安睡，休息。

# 褰裳
题解：女子以泼辣戏谑的口吻对恋人说：你若想我，就提衣渡河来找；你不想我，难道就没别人？《毛诗序》以为思见正于大国，今人多视为情歌。
原：子惠思我，/褰裳涉溱。/子不我思，/岂无他人？/狂童之狂也且！|| 你若是真心想念我，就提起衣裳蹚过溱水来。你若是不想我，难道就没有别人了吗？你这个傻小子真够傻的！
注：惠：爱，顺；一说语助词。
注：褰（qiān）裳：提起下衣。
注：溱（zhēn）：郑国水名。
注：也且（jū）：句末语气词。
原：子惠思我，/褰裳涉洧。/子不我思，/岂无他士？/狂童之狂也且！|| 你若是真心想念我，就提起衣裳蹚过洧水来。你若是不想我，难道就没有别的男子了吗？你这个傻小子真够傻的！
注：洧（wěi）：郑国水名，与溱水相汇。
注：士：未婚男子。

# 丰
题解：女子懊悔当初没有随前来迎娶的男子而去，如今盛装以待，盼他再来驾车相迎。《毛诗序》以为刺婚姻之道缺失；具体变故诗中未言。
原：子之丰兮，/俟我乎巷兮。/悔予不送兮！|| 你那样丰润俊美，曾在巷口等候我。后悔我当时没有跟你同去啊！
注：丰：容貌丰满美好。
注：俟（sì）：等候。巷：里中的道路。
注：送：随行，跟从；一说指送女出嫁。
原：子之昌兮，/俟我乎堂兮。/悔予不将兮。|| 你那样健壮英武，曾在堂前等候我。后悔我当时没有随你同行啊。
注：昌：强盛健壮的样子。
注：堂：门侧的堂屋。
注：将：随从，同行。
原：衣锦褧衣，/裳锦褧裳。/叔兮伯兮，/驾，予与行！|| 我身穿锦衣外加罩衫，下着锦裙外加罩裙。哥哥啊郎君啊，快驾车来，我跟你一起走！
注：褧（jiǒng）：麻布制的单罩衣，出嫁时罩在锦衣外。前一个“衣”、“裳”作动词，意为穿。
注：叔、伯：对男子的称呼，这里指所思之人。
注：驾：驾车，指迎亲的车。
原：裳锦褧裳，/衣锦褧衣。/叔兮伯兮，/驾，予与归。|| 我下着锦裙外加罩裙，身穿锦衣外加罩衫。哥哥啊郎君啊，快驾车来，我随你回家成婚。
注：归：女子出嫁称归。

# 东门之墠
题解：思念一个近在咫尺却难以亲近的人。旧说刺男女不待礼而奔，今人多读为男女对唱之辞，前章似男子所唱，后章似女子作答。
原：东门之墠，/茹藘在阪。/其室则迩，/其人甚远。|| 东门外那片平地，茜草长在山坡上。她的家离我很近，她的人却离我很远。
注：墠（shàn）：经过平整的空地。
注：茹藘（rú lǘ）：茜草，根可作红色染料。阪：山坡。
注：迩（ěr）：近。
原：东门之栗，/有践家室。/岂不尔思？/子不我即。|| 东门外的栗树下，有排列整齐的人家。我怎么会不想念你？只是你不肯到我这里来。
注：栗：栗树。
注：践：排列整齐的样子；一说善好。
注：即：就，靠近。

# 风雨
题解：风雨晦暗、鸡鸣不止的时刻终于见到所思之人，心中忧思顿消。《毛诗序》以为思君子，今人多读为女子喜见丈夫或恋人归来。
原：风雨凄凄，/鸡鸣喈喈。/既见君子，/云胡不夷！|| 风雨凄冷，鸡声喈喈。终于见到了你，我的心怎能不平静！
注：凄凄：寒凉的样子。
注：喈喈（jiē）：鸡鸣声。
注：云胡：为什么。夷：平，指心情平复。
原：风雨潇潇，/鸡鸣胶胶。/既见君子，/云胡不瘳。|| 风雨潇潇，鸡声胶胶。终于见到了你，我的心病怎能不痊愈。
注：潇潇：风雨急骤的样子。
注：胶胶：鸡鸣声。
注：瘳（chōu）：病愈。
原：风雨如晦，/鸡鸣不已。/既见君子，/云胡不喜。|| 风雨交加，天色昏暗如夜，鸡鸣声不停。终于见到了你，我怎能不欢喜。
注：晦：昏暗。
注：不已：不止。

# 子衿
题解：女子在城楼上等候恋人，埋怨他不来也不捎信，一日不见如隔三月。《毛诗序》以为刺学校废，今人多读为相思之诗。
原：青青子衿，/悠悠我心。/纵我不往，/子宁不嗣音？|| 你那青青的衣领，让我心中长久思念。纵然我没去找你，你难道就不能捎个音信来？
注：衿（jīn）：衣领；一说系佩的带子。
注：悠悠：思念绵长的样子。
注：宁：难道。嗣音：传来音讯；嗣，一说通“诒”，寄送。
原：青青子佩，/悠悠我思。/纵我不往，/子宁不来？|| 你那青青的佩带，让我长久思念。纵然我没去找你，你难道就不能过来？
注：佩：佩玉的绶带。
原：挑兮达兮，/在城阙兮。/一日不见，/如三月兮。|| 我来来回回地踱步，徘徊在城楼之上。一天见不到你，就像过了三个月。
注：挑、达：走来走去、往来不定的样子。
注：城阙：城门两侧的楼台。

# 扬之水
题解：劝亲人不要轻信旁人离间之言，彼此相依为命。《毛诗序》以为闵忽无忠臣良士，今人多读为夫妇或兄弟间的叮咛。
原：扬之水，/不流束楚。/终鲜兄弟，/维予与女。/无信人之言，/人实迋女。|| 缓缓流动的河水，连一捆荆条也漂不走。我们本就少有兄弟，只有我和你相依。不要相信旁人的话，他们实在是在骗你。
注：扬之水：缓流的水；一说激扬的水，存疑。
注：束楚：成捆的荆条。
注：终：既，已经。鲜（xiǎn）：少。
注：女：同“汝”，你。迋（kuáng）：通“诳”，欺骗。
原：扬之水，/不流束薪。/终鲜兄弟，/维予二人。/无信人之言，/人实不信。|| 缓缓流动的河水，连一捆柴薪也漂不走。我们本就少有兄弟，只有我们两人相依。不要相信旁人的话，他们实在不可信。
注：束薪：成捆的柴草，诗中常与婚姻相关联。
注：不信：不可信。

# 出其东门
题解：男子出城东门，见游女如云，却只钟情于那位衣着朴素的意中人。《毛诗序》以为闵乱，今人多读为表白专一爱情的诗。
原：出其东门，/有女如云。/虽则如云，/匪我思存。/缟衣綦巾，/聊乐我员。|| 走出那东城门，姑娘们多得像天上的云。虽然多得像云，却不是我所思念的人。那位白衣青巾的女子，才能让我快乐。
注：如云：形容人多。
注：匪我思存：不是我心中所念。匪，非。存，在。
注：缟（gǎo）衣：白色绢衣。綦（qí）巾：青灰色的佩巾。
注：聊：且。员：语助词，同“云”。
原：出其闉阇，/有女如荼。/虽则如荼，/匪我思且。/缟衣茹藘，/聊可与娱。|| 走出那外城门，姑娘们多得像白茅花。虽然多得像白茅花，却不是我所思念的人。那位白衣红巾的女子，才能与我同乐。
注：闉阇（yīn dū）：城门外的曲城，即瓮城之门。
注：荼（tú）：茅草的白花，形容众多。
注：且（cú）：通“徂”，往，思之所往。
注：茹藘：茜草，这里借指用茜草染成的红色佩巾。

# 野有蔓草
题解：清晨或黄昏，男女在露水沾湿的郊野不期而遇，一见倾心。《毛诗序》以为思遇时，今人多读为男女相会的恋歌。
原：野有蔓草，/零露漙兮。/有美一人，/清扬婉兮。/邂逅相遇，/适我愿兮！|| 原野上蔓草青青，露水凝聚成团。有一位美丽的人，眉目清秀，温婉可爱。我们不期而遇，正合我的心愿！
注：蔓草：蔓延的野草。
注：零：落。漙（tuán）：露水浓聚的样子。
注：清扬：眉目清明。婉：美好。
注：邂逅（xiè hòu）：不期而遇。适：合。
原：野有蔓草，/零露瀼瀼。/有美一人，/婉如清扬。/邂逅相遇，/与子偕臧！|| 原野上蔓草青青，露水浓重。有一位美丽的人，温婉而眉目清秀。我们不期而遇，愿与你一同美好相处！
注：瀼瀼（ráng）：露水浓多的样子。
注：婉如：即婉然，美好的样子。
注：偕臧：一同美好；臧，善。一说“臧”同“藏”，指一同隐藏起来。

# 溱洧
题解：写郑国春日溱洧水畔男女游春相会、互赠芍药的风俗场面。《毛诗序》以为刺乱，今人多视为上巳节水边嘉会的写照。
原：溱与洧，/方涣涣兮。/士与女，/方秉蕑兮。/女曰：观乎？/士曰：既且。/且往观乎？/洧之外，/洵訏且乐！/维士与女，/伊其相谑，/赠之以勺药。|| 溱水和洧水，春水正在浩荡奔流。男男女女，手里都拿着兰草。姑娘说：“去看看吧？”小伙子说：“我已经去过了。”“那就再去看看嘛！洧水那边，地方宽敞，实在热闹。”于是男男女女，彼此说笑嬉戏，互相赠送芍药。
注：涣涣：春水盛大的样子。方：正。
注：秉：拿着。蕑（jiān）：兰草，古人用以祓除不祥。
注：既且（cú）：已经去过了；且，通“徂”，往。
注：洵：实在。訏（xū）：宽广。勺药：即芍药，男女以之相赠表示结好。
原：溱与洧，/浏其清矣。/士与女，/殷其盈矣。/女曰：观乎？/士曰：既且。/且往观乎？/洧之外，/洵訏且乐！/维士与女，/伊其将谑，/赠之以勺药。|| 溱水和洧水，清澈见底。男男女女，熙熙攘攘挤满水边。姑娘说：“去看看吧？”小伙子说：“我已经去过了。”“那就再去看看嘛！洧水那边，地方宽敞，实在热闹。”于是男男女女，一起说笑嬉戏，互相赠送芍药。
注：浏：水清的样子。
注：殷：众多。盈：满。
注：将：相，一说“将”为“相”之误，存疑。
