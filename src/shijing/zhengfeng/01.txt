# 郑风
题解：《郑风》是郑国一带的诗歌，今存二十一篇。郑国初封于今陕西华县一带，西周末东迁到今河南新郑附近，这些诗大多产生于东迁以后。其中写男女恋情的篇章特别多，古人因此有“郑声淫”的说法，今人则多看重它们感情真率、语言活泼。

# 缁衣
题解：一首关于为人缝制黑色朝服的诗。《毛诗序》认为是郑人赞美郑武公、桓公父子做周王卿士而尽职；今人多读作妻子或情人为所爱之人添衣备食、表达关怀的歌。
原：缁衣之宜兮，/敝，予又改为兮。/适子之馆兮，/还，予授子之粲兮。|| 这身黑色的衣服你穿着多合身，穿破了，我再给你做一件新的。你到你办事的馆舍去吧，等你回来，我给你端上饭菜。
注：缁（zī）衣：黑色的衣服，古代卿大夫在官署办事时穿的服装。
注：敝：破旧。
注：改为：重新做。
注：适：往，到。
注：馆：馆舍，办公或居住的处所。
注：粲：精米做的饭，泛指饭食；一说指新衣的鲜明，存疑。
原：缁衣之好兮，/敝，予又改造兮。/适子之馆兮，/还，予授子之粲兮。|| 这身黑色的衣服你穿着多好看，穿破了，我再给你缝一件。你到你的馆舍去吧，等你回来，我给你端上饭菜。
注：改造：与“改为”同义，重新缝制。
原：缁衣之蓆兮，/敝，予又改作兮。/适子之馆兮，/还，予授子之粲兮。|| 这身黑色的衣服你穿着多宽舒，穿破了，我再给你做一件。你到你的馆舍去吧，等你回来，我给你端上饭菜。
注：蓆（xí）：宽大舒适。
注：改作：同“改为”“改造”。

# 将仲子
题解：一位女子劝告心上人别再翻墙来相会，她并非不爱他，而是畏惧父母、兄长和众人的议论。《毛诗序》附会为讽刺郑庄公纵容其弟共叔段；今人多看作恋爱中女子在礼俗压力下的矛盾心声。
原：将仲子兮！/无逾我里，/无折我树杞。/岂敢爱之？/畏我父母。/仲可怀也，/父母之言，/亦可畏也！|| 求求你啊，仲子！别翻过我们闾里的墙，别弄断我家种的杞柳。哪里是舍不得那几棵树？是怕我的父母啊。仲子，我心里是想着你的，可父母的责骂，也实在叫人害怕呀！
注：将（qiāng）：请，表示恳求。
注：仲子：男子的称呼，“仲”是排行第二。
注：逾：越过。
注：里：古代居民聚居的单位，四周有墙，这里指里墙。
注：杞：杞柳，一种落叶灌木或小乔木。
注：爱：吝惜，舍不得。
原：将仲子兮！/无逾我墙，/无折我树桑。/岂敢爱之？/畏我诸兄。/仲可怀也，/诸兄之言，/亦可畏也！|| 求求你啊，仲子！别翻过我家的院墙，别弄断我家种的桑树。哪里是舍不得那桑树？是怕我的几位哥哥啊。仲子，我心里是想着你的，可哥哥们的话，也实在叫人害怕呀！
注：墙：自家院墙，比“里”更近一层。
原：将仲子兮！/无逾我园，/无折我树檀！/岂敢爱之？/畏人之多言。/仲可怀也，/人之多言，/亦可畏也！|| 求求你啊，仲子！别翻进我家的园子，别弄断我家种的檀树！哪里是舍不得那檀树？是怕旁人说长道短。仲子，我心里是想着你的，可旁人的闲话，也实在叫人害怕呀！
注：园：种植树木果蔬的园圃，四周有墙。
注：檀：檀树，木质坚硬的乔木。

# 叔于田
题解：赞美一位名叫“叔”的青年：他出门打猎，整条巷子仿佛都空了。《毛诗序》认为是写共叔段受国人爱戴；今人多看作女子赞美心上人的歌。
原：叔于田，/巷无居人。/岂无居人？/不如叔也，/洵美且仁。|| 叔去打猎了，巷子里好像没有人住了。难道真的没有人吗？只是谁都比不上叔，他实在英俊又仁厚。
注：叔：对青年男子的称呼；旧说指郑庄公之弟共叔段。
注：于：往。
注：田：打猎。
注：巷：里中的小路。
注：洵：确实，实在。
注：仁：厚道，有仁爱之心。
原：叔于狩，/巷无饮酒。/岂无饮酒？/不如叔也，/洵美且好。|| 叔去狩猎了，巷子里好像没人饮酒了。难道真的没人饮酒吗？只是谁都比不上叔，他实在英俊又和善。
注：狩：打猎，古时多指冬猎。
原：叔适野，/巷无服马。/岂无服马？/不如叔也，/洵美且武。|| 叔到郊野去了，巷子里好像没人会驾马了。难道真的没人驾马吗？只是谁都比不上叔，他实在英俊又威武。
注：适：往。
注：野：郊外。
注：服马：驾驭马匹。

# 大叔于田
题解：铺写“叔”在一场大规模田猎中驾车、搏虎、射箭的英姿。《毛诗序》以为讽刺郑庄公放任共叔段，今人多视为赞美猎手勇武的诗，与《叔于田》相近而更富铺陈。
原：叔于田，/乘乘马。/执辔如组，/两骖如舞。/叔在薮，/火烈具举。/襢裼暴虎，/献于公所。/将叔无狃，/戒其伤女！|| 叔去打猎了，驾着四匹马拉的车。他手握缰绳，像编织丝带一样整齐，两旁的骖马跑得像在跳舞。叔来到草泽，围猎的火把一齐燃起。他脱去上衣赤手搏虎，把猎物献到国君那里。请叔不要再这样冒险了，当心老虎伤了你！
注：乘（shèng）马：四匹马；前一“乘”字是动词，驾。
注：辔（pèi）：马缰绳。
注：组：丝织的宽带，形容缰绳排列整齐。
注：骖（cān）：四马车中两边的马。
注：薮（sǒu）：水草丛生的沼泽，野兽藏身之处。
注：火烈：田猎时围场放的火。
注：具：俱，都。
注：襢裼（tǎn xī）：脱衣露臂。
注：暴（bó）虎：空手搏虎。
注：狃（niǔ）：习以为常，一再这样做。
注：女：同“汝”，你。
原：叔于田，/乘乘黄。/两服上襄，/两骖雁行。/叔在薮，/火烈具扬。/叔善射忌，/又良御忌。/抑磬控忌，/抑纵送忌。|| 叔去打猎了，驾着四匹黄马。中间两匹马昂首在前，两旁的骖马像雁阵一样稍稍错后。叔来到草泽，围猎的火焰一齐腾起。叔善于射箭，又精于驾车。时而勒马停住，时而放马奔驰。
注：服：四马车中间驾辕的两匹马。
注：上襄：高昂向前；“襄”有上举之意，存疑。
注：雁行：像雁飞行的队列，指骖马略后于服马。
注：忌：句末语气词。
注：御：驾车。
注：抑：发语词。
注：磬控：勒马使止。
注：纵送：放马奔驰；一说“纵”“送”分指放箭与追逐，存疑。
原：叔于田，/乘乘鸨。/两服齐首，/两骖如手。/叔在薮，/火烈具阜。/叔马慢忌，/叔发罕忌。/抑释掤忌，/抑鬯弓忌。|| 叔去打猎了，驾着四匹黑白杂色的马。中间两匹马并头齐进，两旁的骖马像左右手一样配合。叔来到草泽，围猎的火焰正旺。叔的马渐渐慢了下来，叔发的箭也少了。他打开箭筒盖子收起箭，把弓装进弓袋里。
注：鸨（bǎo）：黑白毛相杂的马。
注：如手：像人的两只手，形容配合协调。
注：阜：盛，旺。
注：罕：少。
注：掤（bīng）：箭筒的盖子；释掤指打开盖子收藏箭。
注：鬯（chàng）：同“韔”，弓袋，这里作动词，把弓装进袋中。

# 清人
题解：写郑国清邑的军队驻守黄河边，车马雄壮却无所事事、四处游逛。据《左传》闵公二年，郑文公厌恶大臣高克，派他领兵御狄而久不召回，军队终于溃散，郑人作此诗；旧说多认为意在讽刺。
原：清人在彭，/驷介旁旁。/二矛重英，/河上乎翱翔。|| 清邑的军队驻扎在彭地，披甲的四马奔跑不停。车上两支长矛缀着重重红缨，他们在黄河边上闲逛游荡。
注：清：郑国城邑名。
注：彭：地名，与下文“消”“轴”都在黄河边，具体位置存疑。
注：驷介：披着铠甲的四匹马。
注：旁旁（bāng）：马强壮而奔驰不息的样子。
注：二矛：车上插的两支矛。
注：重英：矛上饰有两层红缨。
注：翱翔：游荡，闲逛。
原：清人在消，/驷介麃麃。/二矛重乔，/河上乎逍遥。|| 清邑的军队驻扎在消地，披甲的四马威武雄健。车上两支长矛挂着重重羽饰，他们在黄河边上悠闲逍遥。
注：麃麃（biāo）：威武的样子。
注：乔：矛上用来挂缨的钩饰，一说指野鸡羽毛的饰物，存疑。
原：清人在轴，/驷介陶陶。/左旋右抽，/中军作好。|| 清邑的军队驻扎在轴地，披甲的四马跑得悠然。左边的人转车，右边的人抽刀，主将在车中摆出一副好看的架势。
注：陶陶：驱驰自得、和乐的样子。
注：左旋右抽：车左的人掉转车头，车右的人拔刀；一说泛指兵士百无聊赖地操演，存疑。
注：中军：主将，居车中间，这里指高克。
注：作好：做出姿态好看的样子；一说作乐取乐。

# 羔裘
题解：赞美一位身穿羔羊皮袍的官员，称他正直、勇武、贤能，是国家的栋梁。《毛诗序》以为借古讽今，今人多读作直接赞美贤大夫的诗，也有人看作女子赞美所爱之人。
原：羔裘如濡，/洵直且侯。/彼其之子，/舍命不渝。|| 羔羊皮袍润泽光亮，穿它的人实在正直又美好。就是那个人啊，至死都不改变操守。
注：羔裘：羔羊皮做的袍子，古代大夫的朝服。
注：如濡：像被水润湿一样有光泽。
注：洵：确实。
注：侯：美；一说为君主之意，存疑。
注：彼其（jì）之子：那个人。
注：舍命：舍弃性命；一说接受使命，存疑。
注：渝：变。
原：羔裘豹饰，/孔武有力。/彼其之子，/邦之司直。|| 羔羊皮袍用豹皮镶边，穿它的人十分勇武有力。就是那个人啊，是国家主持正义的人。
注：豹饰：用豹皮装饰袖口。
注：孔：很，甚。
注：司直：主持公正、纠察过失的人，一说为官名。
原：羔裘晏兮，/三英粲兮。/彼其之子，/邦之彦兮。|| 羔羊皮袍鲜明亮丽，袍上的装饰灿烂夺目。就是那个人啊，是国家的俊杰。
注：晏：鲜艳的样子。
注：三英：袍上的三道装饰，具体形制存疑。
注：粲：鲜明。
注：彦：才德出众的人。

# 遵大路
题解：一位女子在大路上拉住将要离开的人的衣袖和手，恳求他不要嫌弃自己、不要忘了往日情分。《毛诗序》以为郑人思念君子；今人多读作被弃或惜别的恋歌。
原：遵大路兮，/掺执子之祛兮，/无我恶兮，/不寁故也。|| 沿着大路走啊，我拉住你的衣袖，请你不要厌恶我啊，不要这么快就丢下旧日的情分。
注：遵：沿着。
注：掺（shǎn）：拉住，抓住。
注：祛（qū）：袖口。
注：无我恶（wù）：不要厌恶我。
注：寁（zǎn）：迅速，一说为舍弃。
注：故：旧情，故人。
原：遵大路兮，/掺执子之手兮，/无我魗兮，/不寁好也。|| 沿着大路走啊，我拉住你的手，请你不要嫌我丑啊，不要这么快就丢下往日的恩爱。
注：魗（chǒu）：同“丑”，嫌弃。
注：好：相好，恩爱之情。

# 女曰鸡鸣
题解：以夫妻对话的形式写一对夫妇清晨的生活：妻子催丈夫起身去射猎，设想与他饮酒偕老，丈夫则赠佩玉回报她的情意。《毛诗序》以为刺当时不悦德而好色，今人多看作描写和美家庭生活的诗。
原：女曰：“鸡鸣！”/士曰：“昧旦！”/“子兴视夜，/明星有烂。/将翱将翔，/弋凫与雁。”|| 妻子说：“鸡叫了！”丈夫说：“天还没亮呢！”“你起来看看夜色，启明星正亮得很。鸟儿就要飞来飞去了，快去射些野鸭和大雁。”
注：士：男子，这里指丈夫。
注：昧旦：天将亮未亮之时。
注：兴：起身。
注：明星：启明星，即黎明时的金星。
注：烂：明亮。
注：翱翔：鸟飞来飞去，一说指人出游。
注：弋（yì）：用系着丝绳的箭射鸟。
注：凫（fú）：野鸭。
原：弋言加之，/与子宜之。/宜言饮酒，/与子偕老。/琴瑟在御，/莫不静好。|| 射中了野鸭大雁，我为你烹调成菜肴。用它来下酒，愿和你白头到老。琴瑟就在身边弹奏，日子无不安宁美好。
注：加：射中；一说指将猎物加于餐中，存疑。
注：言：语助词。
注：宜：做成菜肴；一说相宜、匹配。
注：偕老：一起到老。
注：御：用，指弹奏。
注：静好：安宁美好。
原：知子之来之，/杂佩以赠之。/知子之顺之，/杂佩以问之。/知子之好之，/杂佩以报之。|| 知道你对我体贴关照，我把杂佩送给你。知道你对我温顺和气，我把杂佩送给你表示问候。知道你对我情深意好，我把杂佩送给你作为报答。
注：来：殷勤招来，关怀；一说通“勑”，慰劳，存疑。
注：杂佩：由多种玉石串成的佩饰。
注：顺：和顺。
注：问：赠送，表示慰问。
注：报：回报。

# 有女同车
题解：男子赞美与他同车而行的女子，说她容貌如木槿花，佩玉叮当，品德美好令人难忘。《毛诗序》以为刺郑太子忽不娶齐女；今人多看作描写迎亲或赞美美人的诗。
原：有女同车，/颜如舜华。/将翱将翔，/佩玉琼琚。/彼美孟姜，/洵美且都。|| 有位姑娘与我同车，容颜像木槿花一样美。她的身姿轻盈得像要飞翔，身上佩着琼琚美玉。那美丽的姜家大姑娘，确实漂亮又娴雅。
注：舜：木槿，夏秋开花，朝开暮落。
注：华：同“花”。
注：翱翔：形容行步轻盈如鸟飞。
注：琼琚（jū）：精美的佩玉。
注：孟姜：姜姓的长女，后泛指美女。
注：都：娴雅美好。
原：有女同行，/颜如舜英。/将翱将翔，/佩玉将将。/彼美孟姜，/德音不忘。|| 有位姑娘与我同行，容颜像木槿花一样美。她的身姿轻盈得像要飞翔，身上的佩玉叮当作响。那美丽的姜家大姑娘，她美好的名声让人难以忘怀。
注：英：花。
注：将将（qiāng）：佩玉相击的声音。
注：德音：美好的声誉，也可指美好的言谈。

# 山有扶苏
题解：女子与情人见面时的戏谑之辞：说没等来美男子，却碰上了你这个狂小子。《毛诗序》以为刺郑昭公所用非人；今人多读作男女相悦、打情骂俏的情歌。
原：山有扶苏，/隰有荷华。/不见子都，/乃见狂且！|| 山上长着扶苏树，洼地里开着荷花。没见到美男子子都，却碰见你这个狂小子！
注：扶苏：树名，具体所指存疑，一说为桑树，一说泛指枝叶茂盛的大树。
注：隰（xí）：低湿之地。
注：荷华：荷花。
注：子都：古代著名的美男子，这里泛指美男子。
注：狂：狂妄、轻狂之人。
注：且（jū）：语助词；一说通“伹”，指拙笨的人，存疑。
原：山有乔松，/隰有游龙。/不见子充，/乃见狡童！|| 山上长着高大的松树，洼地里长着红蓼。没见到好男儿子充，却碰见你这个滑头小子！
注：乔：高大。
注：游龙：水草名，即荭草、红蓼；
注：“龙”通“茏”。
注：子充：与“子都”类似，泛指美男子。
注：狡童：狡黠的少年，带戏谑意味。

# 萚兮
题解：秋风吹落叶，女子呼唤男子们一起唱和。《毛诗序》以为刺君弱臣强；今人多看作男女聚会时互相唱和的歌。
原：萚兮萚兮！/风其吹女。/叔兮伯兮，/倡，予和女。|| 落叶啊落叶！风正吹着你。小伙子们啊，你们起个头，我来跟着唱。
注：萚（tuò）：枯落的树叶。
注：女：同“汝”，你，这里指落叶。
注：叔、伯：对男子的称呼，伯为兄长，叔为弟。
注：倡：同“唱”，领唱。
注：和（hè）：应和。
原：萚兮萚兮，/风其漂女。/叔兮伯兮，/倡，予要女。|| 落叶啊落叶，风正把你飘起。小伙子们啊，你们起个头，我来接着唱完。
注：漂：同“飘”，吹动。
注：要（yāo）：会合，这里指接着唱、与之相合；一说为歌的尾声，存疑。
