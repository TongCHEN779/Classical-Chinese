# 正文
题解：此为《贫俭部》总叙，冯梦龙（子犹）区分“俭”与“吝”，说明贫者必俭、俭者未必贫，而以吝为不可取，并交代部目名称。
原：〔子犹曰：贫者，士之常也；俭者，人之性也。贫不得不俭，而俭者不必贫，故曰：性也。然则俭不可乎？曰：吝不可耳。夫俭非即吝，而吝必托之于俭。俭而吝，则虽堆金积玉，与贫乞儿可异？故吾统而名曰《贫俭》第十三。〕
注：子犹：冯梦龙别号，明末文学家，编《古今谭概》，评语常署“子犹曰”。
注：贫者，士之常也：古人以安贫为士人本分，参《列子》“贫者，士之常也”。
注：性也：天性如此。
注：吝：吝啬，舍不得财物；与“俭”之区别在于俭是节用，吝是该用不用。
注：堆金积玉：形容财富极多。
注：贫乞儿：穷苦乞丐。
注：统而名曰：合起来命名为。
# 齿声
题解：供奉官罗承嗣的邻居夜夜听到击物声，原来是寒冷中牙齿相叩，写贫寒之极。
原：供奉官罗承嗣住州西。邻人每夜闻击物声，达旦不辍；穴隙视之，乃知寒冻齿相击耳。
注：供奉官：宋代武臣阶官，为内廷供奉的低级官职。
注：罗承嗣：待考。
注：达旦：直到天明。
注：不辍：不停止。
注：穴隙：从墙缝中。
# 桶中人
题解：吕徽之冒雪去富家换谷种，被人认出，其妻无衣只得坐在米桶中，写文人安贫之窘。
原：吕徽之安贫乐道。尝冒雪往富家易谷种，闻阁中吟哦声，乃一人分韵得“滕”字，未就。先生因请以“滕王蛱蝶”事足之。问其姓名，不言，刺船而去。众疑为吕处士，遣人遥尾其后，路甚僻远，识其所而返。雪霁往访焉，唯草屋一间，值先生不在。忽米桶中有人，乃先生妻也，因天寒无衣，故坐桶中。
注：吕徽之：北宋隐士，号吕处士，居江南，贫而乐道，事见宋人笔记，待考。
注：安贫乐道：安于贫困，乐守其道，语本《后汉书·韦彪传》等。
注：易谷种：换取谷种。
注：分韵：作诗时约定若干字为韵，每人拈一字。
注：滕：韵字；下文“滕王蛱蝶”指唐滕王李元婴善画蝶，用此典可足一句。
注：先生：众人对吕徽之的称呼。
注：刺船：撑船。
注：遥尾其后：远远跟在后面。
注：吕处士：即吕徽之，“处士”指不仕的士人。
注：雪霁：雪后放晴。
# 无裤吟
题解：储遇冬天没有裤子，作打油诗自嘲“借与有裤人家着”，贫中带谑。
原：义兴储遇家贫，冬月无裤，作口号云：“西风吹雨声索索，这双大腿没下落。朝来出榜在街头，借与有裤人家著。”
注：义兴：今江苏宜兴，宋代称义兴。
注：储遇：待考。
注：口号：随口吟成的诗，不加推敲。
注：索索：风雨声。
注：没下落：没有着落，双关腿无裤可裹。
注：著：同“着”，穿。
# 簇酒、敛衣
题解：辛洞无钱好饮，持榼讨酒，伊处士向众人讨布聚而成衣，各有雅称，写贫士的窘中机巧。
原：《徐闻录》：辛洞好酒而无资。尝携榼登人门，每有取一盏投之，号为“簇酒”。《搔首集》：伊处士从众人求尺寸之帛，聚而服之，目曰“敛衣”。
注：徐闻录：书名，待考。
注：辛洞：待考。
注：榼：盛酒器。
注：簇酒：从众人处各取一盏聚成一壶，“簇”为聚集。
注：搔首集：书名，待考。
注：伊处士：待考，“处士”指有德才而不出仕的人。
注：敛衣：向人敛集布帛缝成衣服。
# 夏侯妓衣
题解：夏侯亶吝啬，家中妓妾无衣，客至只隔帘奏乐，被称为“夏侯妓衣”，是讽刺吝啬的笑谈。
原：夏侯豫州亶，性极吝。晚年好音乐，有妓妾数十，无被服姿容。客至，常隔帘奏乐。时呼帘为“夏侯妓衣”。
注：夏侯豫州亶：夏侯亶，字世龙，南朝梁谯郡人，曾任豫州刺史，故称“夏侯豫州”，事见《梁书》本传；《梁书》称其“性吝”。
注：妓妾：歌舞的侍妾。
注：被服：衣着。
注：帘：此处隔帘奏乐，帘当其衣，故谑称“妓衣”。
# 小宰羊
题解：时戢任青阳县丞，清廉勤政，日买豆腐数个，百姓戏称豆腐为“小宰羊”，借“宰羊”形容无肉的清苦。
原：时戢为青阳丞，洁以勤民，肉味不知，日市豆腐数个。邑人呼豆腐为“小宰羊”。
注：时戢：北宋人，生平待考。
注：青阳丞：青阳县的县丞，青阳在今安徽。
注：洁以勤民：自身清廉，勤于民事。
注：市：买。
注：小宰羊：以豆腐代肉，故戏称“小宰羊”，言其宰豆腐如宰羊。
# 双枯鱼
题解：赵谘任东海太守，以节俭化民，别人送他两条干鱼，吃了三年才吃完。
原：东郡赵谘为东海郡，以俭化俗。人遗其双枯鱼者，啖之，三岁不尽。
注：赵谘：即赵咨，字德度，东汉东郡燕人，官东海相，以俭约著称，事见《后汉书·赵咨传》。
注：东郡：郡名，治今河南濮阳。
注：东海郡：治今山东郯城。
注：遗：赠送。
注：枯鱼：干鱼。
注：啖：吃。
# 献姜
题解：孔琇之为官清廉，卸任只献干姜二片，连武帝也为之叹息，是清官俭德的笑谈。
原：孔琇之为临川太守，在任清约。罢郡还，献干姜二片。武帝嫌其少，知琇之清，乃叹息。
注：孔琇之：南朝齐会稽山阴人，官临川内史，清廉，事见《南齐书·良政传》。
注：临川：郡名，治今江西抚州。
注：清约：清廉简朴。
注：罢郡：卸任郡守。
注：干姜：晒干的生姜，供调味入药。
注：武帝：南齐武帝萧赜。
# 鲁学士祝寿
题解：赵永和鲁铎以半条枯鱼为李东阳祝寿，写明代京官的清贫与淳朴。
原：赵司城永，号类庵，京师人。一日过鲁学士铎邸。鲁曰：“公何之？”赵曰：“忆今日为西涯先生诞辰，将往寿也。”鲁问：“公何以为贽？”赵曰：“帕二方。”鲁曰：“吾贽亦应如之。”入启笥，无有。踌躇良久，忆里中曾馈有枯鱼，令家人取之。家人报已食，仅存其半。鲁公度家无他物，即以其半与赵俱往称祝。西涯烹鱼沽酒，以饮二公。欢甚，即事倡和而罢。
注：赵司城永：赵永，号类庵，京师人，生平待考；“司城”指工部官员。
注：鲁学士铎：鲁铎，字振之，号莲北，景陵人，明正德间翰林学士，国子祭酒。
注：西涯先生：李东阳，号西涯。
注：贽：拜见时赠的礼物。
注：帕二方：手帕两条。
注：笥：竹制盛物器。
注：踌躇：犹豫。
注：里中：同乡。
注：沽酒：买酒。
注：倡和：作诗相唱和。
# 御史目渔
题解：韦广任御史卸职归乡，故人来访无物招待，自己捕鱼，被人窥破，写官员的窘境。
原：粤西韦广为御史归，贫甚，居荒村。故人按部，广意其必来访，无所得馔，自渔于江。故人猝至，驺从既过，广登岸即走，逾后垣入，衣冠肃客。客曰：“公何汁流渍发？”广曰：“适在近村，闻公至，竭蹶趋迎故耳。”左右窃笑曰：“绝似江中打渔人。”
注：粤西：广西。
注：韦广：待考。
注：御史：监察官。
注：故人按部：旧友巡察所辖地区。
注：馔：饭食。
注：驺从：随行的骑从。
注：逾后垣：翻过后墙。
注：肃客：恭敬迎客。
注：汁流渍发：水汁浸湿头发。
注：竭蹶：奔走急迫、力竭的样子。
# 郑馀庆
题解：郑馀庆清俭，以蒸葫芦粟饭待客，众人空腹匿笑，反映其节俭，也被视为吝。
原：郑馀庆极清俭。一日，忽召亲朋官数人会食。众皆惊讶，侵晨赴之。日高，馀庆方出，闲话移时，众腹已枵。馀庆呼左右曰：“分付厨家烂蒸去毛，莫拗折项！”众相顾，以为必蒸鹅鸭之类。又久之，盘出，酱醋亦极香新。但见每人前下粟饭一碗，蒸葫芦一枚，皆匿笑强进。
注：郑馀庆：字居业，唐荥阳人，历相德宗、宪宗，《旧唐书》有传，记其清俭事。
注：亲朋官：亲友同僚。
注：侵晨：天刚亮。
注：枵：空虚，腹饥。
注：烂蒸去毛，莫拗折项：叮嘱厨师蒸鹅鸭时要熟烂去毛，别折断了脖子，众人以为有大菜，其实只是蒸葫芦；此话出《卢氏杂说》。
注：粟饭：小米饭。
注：匿笑：暗笑。
# 王罴
题解：王罴俭率，见使者裂饼边便训斥，又见客削瓜皮厚便取而自食，写其节俭。
原：《北史》：王罴性俭率。镇河东日，尝有台使至，罴为设食，乃裂去薄饼缘。罴曰：“耕种收获，其功已深，舂爨造成，用力不少。尔之选择，当是未饥！”命左右撤去之。使者愕然。又尝与客食瓜。客削瓜皮侵肉稍厚，罴就地取食之。
注：北史：二十四史之一，唐李延寿撰。事见《北史·王罴传》。
注：王罴：字熊罴，北魏、西魏时人，性俭朴。
注：河东：郡名，今山西西南部。
注：台使：朝廷使者。
注：裂去薄饼缘：撕掉饼边。
注：舂爨：舂米做饭。
注：当是未饥：想来你还不饿。
# 变家风
题解：范仲淹家法清俭，范纯仁拜相后留晁美叔吃饭，因盐豉上多了两簇肉，被说成“变家风”，是对范氏俭德的善意调侃。
原：范氏自文正公贵显，以清苦俭约称于世，子孙皆守其家法。忠宣正拜后，尝留晁美叔同匕著。美叔退谓人曰：“丞相变家风矣！”或问之。晁答曰：“盐豉棋子上有肉两簇，岂非变家风乎？”闻者大笑。
注：范氏：指范仲淹家，仲淹谥文正。
注：忠宣：范纯仁，字尧夫，范仲淹次子，谥忠宣，官至宰相。
注：正拜：正式拜相。
注：晁美叔：晁端彦，字美叔，北宋人，曾官知制诰，事见宋人笔记。
注：同匕著：同用匕箸，即一同进食；“著”同“箸”。
注：盐豉：盐和豆豉，佐饭小菜。
注：有肉两簇：盐豉之上放了两小堆肉，“簇”指小堆。
# 翟参政请客
题解：翟汝文任参政，请客前先大谈节俭，结果果然只上粗菜，是借俭作吝的小讽。
原：翟公巽，字汝文，绍兴初为参政。虽身历两府，自奉甚于贫士。一日招客，未饮时，先极言近世风俗移靡，燕乐之间尤甚，因正色曰：“德大于天子者，然后可以食牛；德大于诸侯者，然后可以食羊。”客自度今日之集，必无盛馔，已而果以恶草具进。
注：翟公巽：翟汝文，字公巽，宋润州丹阳人，高宗时官参知政事，《宋史》有传；原文此处“字汝文”，待考。
注：参政：参知政事，宰相之副。
注：两府：宋代称中书省与枢密院为二府。
注：自奉：自己的生活用度。
注：移靡：奢侈风气转移。
注：德大于天子者，然后可以食牛：语出《礼记》，大意是德行高于天子才配得上吃牛，用以说明不可奢侈。
注：恶草具：粗劣的饭菜，语出《史记·陈丞相世家》。
# 陈孟贤
题解：陈孟贤吝啬，被同僚编成灶神笑话，灶神因主人不请客而身上不黑，以此谑其吝。
原：陈孟贤素吝。同僚造一谑笑云：腊月廿四，天下灶神俱朝上帝。众尽皂衣，一人独白。上帝怪之。曰：“臣陈孟贤家灶神也。诸神俱烟薰，故黑。臣在孟贤家，自三餐外不延一客，臣衣何由得黑？”后人凡言冷澹事，辄曰“陈家灶神”。
注：陈孟贤：待考。
注：腊月廿四：旧俗祭灶神之日，灶神此日上天向玉帝奏事。
注：灶神：民间供奉的家神，掌一家饮食与善恶。
注：上帝：玉皇大帝。
注：皂衣：黑衣。
注：烟薰：烟熏。
注：冷澹：冷清淡薄。
# 食韭
题解：庾景行、庾亮两则：一则任昉戏言韭菜二十七种，一则陶侃留薤白并称庾亮能治实务，都以俭食为题。
原：瘐景行清贫，食唯韭菹、瀹韭、生韭、杂菜，任昉戏之曰：“谁谓庾郎贫？一食常有二十七种。”
注：瘐景行：当即庾杲之，字景行，南朝齐人，清贫自守，见《南齐书·庾杲之传》；原文“瘐”疑当作“庾”。
注：韭菹：腌韭菜。
注：瀹韭：煮韭菜。
注：任昉：字彦昇，南朝文学家，擅长公文，与沈约并称“任笔沈诗”。
注：谁谓庾郎贫？一食常有二十七种：“二九”为十八，“三九”为二十七，三种韭谐“九”，戏言一食有二十七种。
原：庾太尉亮见陶公侃，陶公雅相赏重。陶性俭吝，及食啖薤，庾因留白。问：“用此何为？”庾云：“故可种。”于是大叹庾“非唯风流，兼有治实。”
注：庾太尉亮：庾亮，字元规，东晋名臣，官至太尉，事见《世说新语·政事》。
注：陶公侃：陶侃，字士行，东晋名将。
注：薤：薤头，似小蒜，其白叶近根处称“薤白”。
注：留白：留下薤白的根部，以备栽种。
注：治实：办理实务。
# 王导
题解：王导节俭，帐下水果不舍得吃，放到烂掉也不许说被人知道，写节俭近吝。
原：王导性俭。帐下有甘果，不忍食，至春烂败。弃之者犹曰：“勿使大郎知！”
注：王导：字茂弘，东晋宰相，辅佐元帝、明帝、成帝，《晋书》有传，其俭事见《世说新语》。
注：帐下：部下，身边近侍。
注：大郎：王导长子王悦，一说指王导自己，待考。
# 王戎
题解：王戎嫁侄只给一件单衣又索回，又钻透李核防人得种，写其吝啬。
原：王戎从子婚，与一单衣，后更责之。家有好李，卖之，恐人得种，恒钻其核。
注：王戎：字濬冲，竹林七贤之一，性吝啬，《世说新语·俭啬》记其事。
注：从子：侄子。
注：单衣：单层衣服。
注：好李：品质好的李子。
注：钻其核：把李核钻破，使人无法播种。
# 和峤
题解：和峤吝李，被王济率人去园中吃光并砍树，写吝啬招祸的可笑。
原：和峤性至俭，家有好李，诸弟往园食李，皆计核责钱。王武子求之，与不过数十。武子因其上直，率将少年持斧诣园，共饱啖毕，伐之。送一车枝与和公，问曰：“何如君李？”和唯笑而已。
注：和峤：字长舆，西晋大臣，性至俭，《世说新语·俭啬》记其事。
注：核：李核。
注：责钱：索要钱款。
注：王武子：王济，字武子，西晋名士。
注：上直：上班值夜，指和峤在宫中当值不在家。
注：伐：砍。
注：和公：对和峤的敬称。
# 沈峻
题解：沈峻要送布给张温，找了半天却说无粗布，终于不送，写其吝啬。
原：沈峻欲赠张温。入内检视良久，出语温曰：“欲择一端布送卿，而无粗者。”竟不送。
注：沈峻：吴人，张温同时，待考。
注：张温：字惠恕，吴大臣，事见前文《姚彪》。

# 子孙榼
题解：江西人节俭，酒榼分格内却多为木雕，客人欲取食才知是假，笑点在“子孙榼”与“重修”的反讽。
原：江西俗俭，果榼作数格，唯中一味或果或菜可食，馀悉充以雕木，谓之“子孙榼。”又不解熔蔗糖，亦刻木饰其色以代匮。一客欲食，取之，方知赝物，便失笑。覆视之，底有字云：“大德二年重修。”
注：榼：盛酒或果品的器具，此指食盒。
注：子孙榼：意为传给子孙使用的榼，实际不能吃。
注：熔蔗糖：熬制蔗糖。
注：匮：缺乏，此指缺失的糖果。
注：赝物：假货。
注：大德二年：元成宗大德二年，即公元1298年。
注：重修：此处谐佛寺、官署碑记“重修”套语，讥其用了许多年。

# 珊瑚笔格

# 归廉泉
题解：归廉泉富而极吝，买肉嫌酱，买糖又还糖取米，细节层层写其吝，是本部最长的一则。
原：吴人归副使廉泉富吝俱极。暑月暴水日中浴之，省爨薪也。生平家食，未尝御肉。客至，未尝留款。一日，有内亲从远方来，必欲同饭。乃解袖中帨角上五钱，使人于熟店批数片肉。肉至无酱，复解一钱。市得，便嫌其不佳，使还之，仍取钱。已问：“酱楪何在？”尚有馀咸味，足消此肉也。幼儿见食条糖者而泣。值租入时，乳母奉内命，将米半升易糖。公适自外来，见之。诘其故，乃取糖一根，自折少许尝之，复抑少许置儿口，谓曰：“味止此耳，何泣为？”即还糖取米。卖者言糖已损。乃手撮数粒偿之。
注：廉泉：归廉泉，吴人，官副使，待考。
注：副使：官名，此处指提刑按察副使一类。
注：暴水日中：把水放在日头下晒热，免用柴。
注：御肉：食肉。
注：内亲：内亲戚，指妻方亲戚。
注：帨：巾，擦手的小布。
注：批：切成片，批削。
注：酱楪：盛酱的小碟。
注：条糖：条形糖。
注：租入：收租之时。
注：抑：按，放。
# 半边圣人
题解：士夫贪取而吝给，说“一介不与”是圣人之道，被讽为“半边圣人”，是借圣人之言讽吝。
原：《百可堂》云：有一士夫，性极贪。取人不遗锱铢；而己之所有，分毫不舍。或讥其吝。答曰：“‘一介不与’，圣人之道也。”或曰：“‘一介不取’，君以为何如？”曰：“学而不能。”曰：“然则君只好学得半边圣人。”
注：百可堂：书名，待考。
注：士夫：士大夫。
注：锱铢：极小的计量单位，六铢为一锱。
注：一介不与：语出《孟子·万章上》“一介不以与人，一介不以取诸人”，一介，一根草，指极小东西。
注：半边圣人：只学到圣人一半。
# 汉世老人

注：侵夜：天色已晚。
注：求丐：求乞。
注：瞻：供给，赡养。

注：广行五记：书名，待考。

注：邓差：待考。

# 吝祸
题解：金华豪民李甲欲毒杀施僧，其两个儿子反而吃毒饼死去，是吝与恶招祸的故事。
原：金华有豪民李甲，克众肥家。居近古刹，有二僧颇为村人所钦仰，往求施，人多喜舍，亦时时受甲妻之密惠。甲知之，衔忌尤深。一日二僧以事至其家，甲故为殷勤之态，而私令仆干作四饼，置毒其中，以出劝二僧。僧方饭饱，不下咽，乃怀其饼归寺。明旦，二小儿采衣垂发，入寺游观。问之，则甲子两子也。惊曰：“此李公爱子，可以果饵延之。”命其徒遍搜于房，弗得，唯饼在几上，即取以饲之。二儿吝食其一，仍怀其一还家。入门大呼腹痛，并仆地踯躅以死。甲莫喻其故，询其仆，搜其身，馀饼在焉，仍知中毒而亡；吞声饮泣而已。
注：金华：今浙江金华。
注：克众肥家：剥削众人以使自家富有。
注：古刹：古寺。
注：钦仰：敬重。
注：密惠：暗中施舍。
注：仆干：仆役，干仆。
注：采衣垂发：采衣，彩色衣服，孩童所穿；垂发，未成年。
注：果饵：果品点心。
注：踯躅：徘徊，此指扑腾挣扎。
注：吞声饮泣：忍泪不敢出声。
