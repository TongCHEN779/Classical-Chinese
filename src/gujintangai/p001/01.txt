# 正文
题解：全书总评式小序，冯梦龙以“子犹”之名点出迂腐误事，并预告本部所收丙吉、司马光、梁鸿、程颐诸人之事。
原：〔子犹曰：天下事被豪爽人决裂者尚少，被迂腐人担误者最多。何也？豪爽人纵有疏略，譬诸铅刀虽钝，尚赖一割。迂腐则尘饭土羹而已，而彼且自以为有学、有守、有识、有体，背之者为邪，斥之者为谤，养成一个怯病天下，以至于不可复而犹不悟。哀哉！虽然丙相、温公自是大贤，特摘其一事之迂耳。至如梁伯鸾、程伊川所为，未免已甚，吾并之及，正欲后学大开眼孔，好做事业，非敢为邪为谤也。集《迂腐》第一。〕
注：子犹曰：子犹，冯梦龙之号；本书《古今谭概》每部前后常有此类按语。
注：铅刀虽钝，尚赖一割：用《后汉书·班超传》“铅刀贵一割之用”意，谓钝刀也能割一次，喻豪爽者纵有疏漏仍可成事。
注：尘饭土羹：儿童游戏以尘土作饭、泥作羹，中看不中用，语本《韩非子》“尘饭涂羹”。
注：怯病天下：谓使天下人染上畏事怯懦的毛病。
注：丙相、温公：丙吉（汉宣帝丞相）与司马光（封温国公）。
注：梁伯鸾、程伊川：梁鸿，字伯鸾，东汉隐士；程颐，号伊川，北宋理学家，二人事迹在本部有所涉及。
注：已甚：过分，语出《孟子》“仲尼不为已甚者”。
注：大开眼孔：开阔眼界。
# 问牛
题解：丙吉问牛不问人斗，事见《汉书·丙吉传》，本部开篇以名相之迂为例。
原：丙吉为丞相，尝出，逢斗者，死伤横道。吉过之不问。已而逢人逐牛，牛喘吐舌，吉止驻，使骑吏问：“逐牛行几里矣？”掾吏谓丞相前后失问。吉曰： “民斗相杀伤，长安令、京兆尹职所当禁备逐捕，岁竟，丞相课其殿最，奏行赏罚而已。宰相不亲小事，非所当于道路间也。方春，少阳用事，未可太热，恐牛近行，用暑故喘，此时气失节，恐有伤害。三公典调阴阳，职所当忧，是以问之。”
注：丙吉：西汉宣帝时丞相，封博阳侯。
注：横道：横陈于道路。
注：骑吏：骑马随从的属吏。
注：掾吏：丞相府的属员。
注：长安令、京兆尹：长安令是京城所在县的县令，京兆尹是治理京畿的长官，二者主管治安捕盗。
注：殿最：古代考绩，下等为殿，上等为最。
注：少阳用事：古人以春季属少阳，阳气初生，主事。
注：三公典调阴阳：古称三公职在燮理阴阳，故宰相应关心节气寒暑。
# 驱驴宰相
题解：王及善为相无所作为，只会驱赶令史的驴，事见《旧唐书·王及善传》。
原：王及善才行庸鄙，为内史，时谓“鸠集凤池”。俄迁右相，无他施设，唯不许令史辈将驴入台，终日驱逐。时号“驱驴宰相。”
注：王及善：唐武则天朝大臣，曾任内史、文昌右相，《旧唐书》称其性刚正，此处取讥讽之说。
注：内史：武周时中书令改称内史，为宰相之职。
注：鸠集凤池：凤池即凤凰池，指中书省；鸠为凡鸟，讥其才不称位。
注：令史：官署中的书吏。
注：台：此指官署（中书省/宰相府）。
# 弹发御史
题解：御史任满百日不言即罢，王平乃弹宫膳中有头发，借《诗》语自嘲其迂，成为笑谈。
原：宋御史台仪：凡御史上事，一百日不言，罢为外官。有王平，拜命垂满百日，而未言事。同僚讶之，或曰：“王端公有待而发，必大事也。”一日闻进札子，众共侦之，乃弹御膳中有发。其弹词曰：“是何穆若之容，忽睹鬈如之状。”
注：御史台仪：御史台的成例。
注：上事：到任视事。
注：王端公：御史的尊称，唐宋以来称侍御史为端公。
注：札子：宋代臣下奏事的公文，亦称劄子。
注：御膳中有发：御用膳食里发现头发。
注：穆若之容：穆若，温和端庄貌；语近《诗经·大雅·烝民》“穆如清风”。
注：鬈如之状：鬈，头发卷曲好貌，语本《诗经·齐风·卢令》“其人美且鬈”；这里谐指饭中头发卷曲，作为弹劾辞，故成笑料。
# 鹅鸭谏议
题解：南宋建言者提议禁鹅鸭，被讥为“鹅鸭谏议”，讽刺臣下不务实事。
原：高宗朝，黄门建言：“近来禁屠，止禁猪羊，圣德好生，宜并禁鹅鸭。”适报金虏南侵，贼中有“龙虎大王”者甚勇。胡侍郎云：“不足虑！此有‘鹅鸭谏议’，足以当之。”
注：高宗：宋高宗赵构。
注：黄门：门下省官员，此指给事中、谏官之类。
注：禁屠：禁止屠宰。
注：龙虎大王：金人对其将领的称号，所指具体何人待考。
注：侍郎：六部副长官，胡侍郎其人待考。
注：鹅鸭谏议：以谏议大夫的名衔戏称，谓其只会管鹅鸭。
# 成、弘、嘉三朝建言
题解：成化、弘治、嘉靖三朝，言官所建之言皆琐碎不关大计，所以并列为迂腐之例。
原：成化间，一御史建言顺适物情，云：“近京地方，行役车辆骡驴相杂。骡性快力强，驴性缓力小。今并一处驱驰，物情不便，乞要分别改正。”弘治初，一给事建言处置军国事，云：“京中士人好著马尾衬裙，因此官马被人偷拔鬃尾，有误军国大计，乞要禁革。”嘉靖初，一员外建言崇节俭以变风俗，专论各处茶食铺店所造看桌糖饼：“大者省功而费料，小者料小而费功，乞要擘画定式，功料之间，务在减省，使风俗归厚。”
注：成化：明宪宗年号（1465—1487）。
注：给事：给事中，掌封驳、谏诤的言官。
注：员外：员外郎，六部属官。
注：弘治：明孝宗年号（1488—1505）。
注：马尾衬裙：明代中叶流行以马尾织成的衬裙，穿在裙内使裙撑起。
注：鬃尾：马的鬃毛与尾毛。
注：擘画：筹划，安排。
注：茶食铺：卖糕点的店铺，明代称点心为茶食。
注：看桌：筵席上陈设供观赏的果饼桌。
# 宋罗江
题解：卫士作乱后宋禧请养罗江狗以守宫掖，被时人讥为“宋罗江”。
原：庆历中，卫士震惊宫掖，寻捕杀之。时台官宋禧上言：“此失守于防闲故耳。闻蜀罗江狗赤而尾小者，其儆如神。须诏索此狗，豢于掖庭，以备仓卒。”时号为“宋罗江”。
注：庆历：宋仁宗年号（1041—1048）；庆历八年有卫士谋乱入宫之事。
注：宫掖：宫禁。
注：台官：御史台官员。
注：罗江：县名，在今四川德阳，此以产地称其狗。
注：儆：警，指狗警觉。
注：仓卒：事出匆忙，同“仓促”。
# 罗擒虎、张寻龙
题解：罗相请捕杀越州之虎，张次贤请禁人盘岭行人，都被太学生以对偶戏之，见言官之迂。
原：嘉靖中，察院罗相上言：“越州多虎，乞行下措置多方捕杀。”正言张次贤上言：“人盘岭乃禁中来龙，乞禁行人。”太学诸生遂有“罗擒虎”、“张寻龙”之对。
注：察院：都察院。
注：越州：今浙江绍兴一带。
注：措置多方：多方设法处置。
注：正言：宋代谏官有左、右正言；此处泛称言官。
注：来龙：风水术语，指山脉延伸而来的龙脉。
注：人盘岭：待考。
注：禁中：皇宫之内。
注：罗擒虎：以罗相姓氏与所请捕虎之事合成，与“张寻龙”对仗为戏，讥其迂。
注：张寻龙：张次贤请禁人盘岭行人，以“来龙”故称寻龙。
# 引《月令》
题解：匡衡引《月令》反对悬陈郅支首级，拘泥礼书而不顾大局。
原：甘延寿、陈汤既斩郅支单于首，请悬头槁街蛮夷邸间，以示万里，明犯强汉者，虽远必诛。丞相匡衡议：“《月令》：春，掩骼埋胔之时。宜勿悬。”
注：甘延寿、陈汤：西汉西域都护与副校尉，建昭三年（前36）合兵斩郅支单于。
注：郅支单于：匈奴首领，西迁中亚后被汉军击杀。
注：槁街：汉长安街名，蛮夷邸（外国使者馆舍）所在。
注：匡衡：汉元帝时丞相，以说《诗》闻名，《汉书》有传。
注：《月令》：《礼记》篇名，所载“掩骼埋胔”见孟春之月。
注：掩骼埋胔：枯骨与带腐肉的尸体，春天应掩埋之。
注：明犯强汉者，虽远必诛：陈汤上疏中的名句，见《汉书·陈汤传》。
# 谏折柳
题解：程颐以“方春发生”谏皇帝折柳，使上不乐，是理学家迂执的著名例子。
原：程颐为讲官。一日讲罢，未退，上偶起凭栏，戏折柳枝。颐进曰：“方春发生，不可无故摧折。”上掷枝于地，不乐而罢。
注：程颐：北宋理学家，元祐初任崇政殿说书，为哲宗讲官。
注：讲官：为皇帝讲经史的官员。
注：上：指宋哲宗；此事见《宋史》《二程外书》等。
注：发生：春天万物生长。
# 贤良相面
题解：一位征君入对，只说皇帝清瘦，贻笑朝野，肃宗仍授他县令之职。
原：唐肃宗时初诏贤良，一征君首应。上极喜，召对。无他词，但再三瞻望上颜，遽奏曰：“微臣有所见，陛下知不？”上曰：“不知。”对曰：“臣见圣颜瘦于在灵武时。”上曰：“宵旰所致耳。”举朝大笑。帝亦知其为妄人，恐塞贤路，乃除授一令。
注：肃宗：唐肃宗李亨。
注：贤良：贤良方正科，唐代制举科目。
注：征君：被朝廷征召而未做官的隐士。
注：灵武：肃宗即位之地，在今宁夏灵武。
注：宵旰：宵衣旰食，天未明起、天晚才食，形容勤政。
注：除授：授予官职。
# 京兆尹祷雨
题解：京兆尹黎干造土龙祈雨无验，反被皇帝借孔子语取笑。
原：唐代宗朝，京兆尹黎干以久旱祈雨，于朱雀门街造土龙一具，悉召城中巫觋，以身杂入，共舞于龙所。观者嗤笑。弥月不雨，又请祷于文宣王庙。上闻之，戏曰：“丘之祷久矣。”
注：代宗：唐代宗李豫。
注：京兆尹：京城长安的行政长官。
注：黎干：代宗朝京兆尹，事见《旧唐书·黎干传》，史称其以祷雨为人所笑。
注：土龙：古时祈雨，以土作龙形，见《淮南子》等。
注：巫觋：女巫与男巫。
注：文宣王庙：孔庙；唐开元二十七年追谥孔子为文宣王。
注：丘之祷久矣：《论语·述而》孔子语，“丘”为孔子之名；这里是皇帝借此戏讥黎干多次求神仍无雨。
# 请禅天下
题解：眭孟据《春秋》之意劝汉帝禅位于贤人，以致被诛，此为迂于灾异之说的一例。
原：孝昭时，泰山莱芜山南汹汹有数千声。民视之，有大石自立，高丈五尺。又上林苑中，大柳树断枯卧地，亦自立生。眭孟推《春秋》之意，以为“石立柳生，当有从匹夫为天子者。”即说曰：“董仲舒有言：‘虽有继体守文之君，不害圣人之受命。’汉家尧后，有传国之运。汉帝宜谁差天下，求索贤人，禅以帝位，而退自封百里，如殷、周二王后，以承顺天命。”使友内官长赐上此书。霍光恶其妖言惑众，诛之。
注：孝昭：汉昭帝刘弗陵。
注：眭孟：即眭弘，字孟，昭帝时任符节令，《汉书》有传，因上书被霍光所杀。
注：莱芜山：在今山东莱芜一带。
注：上林苑：汉代皇家苑囿，在长安西。
注：推《春秋》之意：汉儒以《春秋》灾异附会人事，认为大石自立、枯柳复生是天命更替的征兆。
注：董仲舒：西汉大儒，倡天人感应。引文见《汉书·眭弘传》。
注：继体守文之君：继承帝位、遵守成法的君主。
注：谁差：见《汉书·眭弘传》，大意为访问、选择；颜师古有注。
注：殷、周二王后：殷后封宋，周后封杞，即“二王之后”，指前代帝王之后裔受封得奉其祀。
注：内官长：宫内宦官之长。
注：霍光：汉昭帝时大司马大将军，辅政。
# 卦宜娱乐
题解：林瑀据《需》卦象辞主张天子须频繁宴乐，因而被仁宗斥退。
原：宋侍读林瑀，自谓洞于《周易》，尝以仁宗时合《易》之《需》：“《需》之象曰：‘君子以饮食宴乐。’须频宴游，务娱乐，始合卦体，而天下治。”仁宗骇其说，斥之。
注：林瑀：宋仁宗时侍读，精《易》，事见《宋史》，此处取其迂说。
注：侍读：侍读学士，为皇帝讲读经史。
注：《需》：《周易》卦名，象辞“云上于天，需；君子以饮食宴乐”。
注：合卦体：与卦象相合。
# 哭天
题解：王莽兵败之际仍求助于哭天、符命、厌胜，临死犹自比孔子，是迂腐迷信的极致。
原：汉兵盛，莽忧甚，不知所出。崔发言：“《周礼》及《春秋》：国有大灾，则哭以厌之。故《易》称‘先号咷而后笑’。宜哭天求救。”莽乃率群臣至南郊，陈其符命本末，因搏心大哭，气尽，伏而叩头。又作告天策千馀言。诸生小民令旦夕哭，为设餐粥，凡能诵策文者，除以为郎，至五千馀人。汉兵入都门，宫中火，莽避火宣室前殿，火辄随之，宫人号呼。时莽绀袀服带玺韨，持虞帝匕首，天文郎按栻于前，时日加某，莽旋席随斗柄而坐，曰：“天生德于予，汉兵其如予何！”
注：莽：王莽，新朝皇帝。
注：崔发：王莽的亲信，经学之士，《汉书·王莽传》有载。
注：《周礼》：此语近《周礼·春官·女巫》“国有大灾，则歌哭而请”。
注：厌：压胜，用祷祝镇压灾祸。
注：先号咷而后笑：《周易·同人》九五爻辞。
注：符命：天降的祥瑞征兆，王莽以此证明其受命。
注：告天策：向天陈述的策文。
注：绀袀服：深青透红色的纯色礼服。
注：玺韨：玺印与系印的绶带（韨为蔽膝，此处疑兼指绶）。
注：虞帝匕首：相传为虞舜所用之匕首，见《汉书·王莽传》。
注：天文郎：掌天象的官员。
注：栻：占卜用的式盘，用以推算时日方位。
注：斗柄：北斗柄，莽以所指方向定坐向。
注：天生德于予，汉兵其如予何：改自《论语·述而》“天生德于予，桓魋其如予何”。
# 《孝经》可退贼、息讼、却病
题解：向栩与王渐都以诵《孝经》退贼、息讼，被作为迂腐的例子。
原：张角作乱，向栩上便宜：“不须兴兵，但遣将于河上，北向读《孝经》，贼自消灭。”
注：张角：东汉末黄巾起义领袖。
注：向栩：东汉人，《后汉书·独行传》有传，上书言诵《孝经》可退黄巾。
注：便宜：臣下因时制宜的建议。
注：《孝经》：儒家经典，十三经之一。
原：国初有孝子王渐，作《孝经义》五十卷，事亦该备。而渐性鄙朴，凡乡里有斗讼，渐即诣门高声诵《义》一卷。后有病者，亦请渐诵书。
注：国初：明初。
注：王渐：明初人，事迹待考。
注：《孝经义》：解释《孝经》之书。
注：该备：详备，完备。
注：诣门：登门。
# 修身为本
题解：吴梦蜚家有鬼怪，徐公只以“修身为本”四字去镇，反被鬼嘲笑。
原：藩司吴梦蜚家有怪，时出以窃饮食，间窃衣饰金银。吴厌苦之，偶诉监司徐公。徐曰：“邪不胜正。”朱书“修身为本”四大字，令贴堂中。鬼见，拍手揶揄，且出秽语。徐大怍。
注：藩司：明代布政使的别称。
注：吴梦蜚：事迹待考。
注：监司：按察司或道员等监察官员。
注：徐公：其人待考。
注：邪不胜正：谓邪不能胜正，旧时对付鬼怪的套话。
注：朱书：用朱砂书写，以辟邪。
注：揶揄：嘲笑。
注：怍：惭愧。
# 迂腐有种
题解：郑棨祖孙与杜丰父子都拘泥无用，所谓“迂腐有种”，所举各事一一荒唐。
原：唐昭宗时，郑棨为相。太原兵至渭北，天子竭于攘却之术。棨奏对，请于文宣王谥号中加一“哲”字。后棨孙玨相梁末帝。唐庄宗兵入汴，帝惶恐不知所为。玨献一策：“愿得陛下传国宝，驰入唐军。以缓其行，而待救兵之至。”帝曰：“宝不足惜，顾卿之行能了事否？”玨俯首徐思曰：“但恐不易耳！”
注：郑棨：疑即唐昭宗朝宰相郑綮，待考。
注：太原兵：指晋王李克用之兵。
注：渭北：渭水以北。
注：文宣王谥号：孔子被追谥为文宣王，加“哲”字，无补于时事。
注：玨：疑即郑珏，后梁末帝朱友贞宰相，事见五代史籍。
注：梁末帝：后梁最后一位皇帝朱友贞。
注：唐庄宗：后唐李存勖，灭梁。
注：汴：今河南开封，后梁都城。
注：传国宝：历代相传的皇帝玉玺。
原：开元间，上东封泰山。历城令杜丰办供应，以为从幸人多，设有不虞，仓卒不备，乃造凶器三十具，置诸行宫，光彩赫然。有刺史骇谓：“主上封岳祈福，谁造此不祥？”将索治丰。丰逃卧妻床下，诈死，得免。时丰子杜锺为兖州参军，掌厩马刍豆，曰：“御马至多，临日煮之不给，不若先办。”乃煮粟豆二千馀石，热纳窖中，及至，皆臭败矣。
注：开元：唐玄宗年号（713—741）；开元十三年玄宗封泰山。
注：东封：到泰山行封禅之礼。
注：历城：今山东济南。
注：杜丰：事迹待考。
注：凶器：丧葬用具。
注：行宫：帝王巡行时的临时居所。
注：兖州参军：兖州属官；杜锺事迹待考。
注：刍豆：草料与豆料。
注：窖：地窖。
# 治平之学
题解：胡石塘应聘入京，帽子倾斜却自夸“治国平天下之学”，被忽必烈取笑。
原：元胡石塘应聘入京，世祖召见，不觉戴笠倾侧。及问所学，对曰：“治国平天下之学。”上笑曰：“自家一笠尚不端正，又能平天下耶？”竟不用。
注：胡石塘：元代人，事迹待考。
注：应聘：应朝廷聘召。
注：世祖：元世祖忽必烈。
注：笠：斗笠，此处指帽子。
注：治国平天下：《大学》“修身齐家治国平天下”。
# 舒太守笑
题解：舒玉大笑是因悟《咸》《蹇》二卦，而不是笑倡优，表现经学家的迂。
原：舒玉性耽经史，对客语，未尝有笑容。知常州日，值宾僚大会，倡优在庭，公忽大笑。僚佐呼优，犒之曰：“汝能使太守开颜，真可赏也！”一人窃疑公笑不由此，乘间问公。公曰：“畴日席上，偶思《咸》、《蹇》二卦，豁悟微旨。自喜有得，故不觉发笑耳！”
注：舒玉：事迹待考。
注：经史：经书与史书。
注：知常州：任常州知州。
注：倡优：乐舞杂戏艺人。
注：僚佐：幕僚属官。
注：畴日：往日。
注：《咸》、《蹇》：《周易》第三十一、三十九卦。
# 许子伯哭
题解：许子伯与友人论汉末时事，慨然痛哭，时称“许伯哭世”。
原：许子伯与友人言次，因及汉无统嗣，幸臣专朝，世俗衰薄，贤者放退，慨然据地悲哭。时称“许伯哭世”。
注：许子伯：事迹待考。
注：汉无统嗣：汉朝没有继承的正统。
注：幸臣：被宠幸的近臣。
注：据地：伏地。
注：许伯哭世：以此人哭世事而得名。
# 孝泌
题解：江泌以孝闻，却迂于不食菜心、怕虱饥死，被世人称为“孝泌”。
原：江泌，字士深，有孝行，族有与泌同名者，世谓为“孝泌”以别之。然菜不食心，谓其有主意。衣敝多虱，以绵置壁前；恐虱饥死，复置衣中。
注：江泌：南朝齐人，《南齐书·孝义传》有传。
注：族：同族。
注：菜不食心：传说其不吃菜心，认为是菜的根本。
注：绵：丝绵。
# 郭逵将略
题解：郭逵伐交州，所下军令繁琐无用，徐禧讥其如读一部《尚书》。
原：郭逵伐交州，行师无纪律，其所措置，殆可笑也。进兵有日矣，乃付诸将文字各一大轴，谓之将军下令，字画甚细，节目甚繁。又戒诸将不得漏泄。诸将近灯火窃观之。徐禧尝见之，云：“如一部《尚书》多，禧三日夜读之，方竟。”则诸将仓卒之际，何暇一一也？内一事云：“一、交人好乘象，象畏猪声，仰诸军多养猪，如象至，则以锥刺猪，猪既作声，象自退走。”
注：郭逵：北宋名将，熙宁间任安南行营招讨使，伐交趾。
注：交州：今越南北部一带，宋时为交趾。
注：行师：行军。
注：将军下令：此指主帅发给诸将的书面军令。
注：徐禧：宋神宗时人，后死于永乐城之役。
注：《尚书》：儒家经典，文字繁多。
注：仰：宋时公文中的“着令”“责成”之语。
注：象畏猪声：古有象怕猪叫之说，用以克敌。
# 反支日忌日
题解：张竦因忌反支日不去，被贼所杀；薛昌绪临难拘忌日礼不肯上马，都是迂腐之例。
原：王莽败，张竦客池阳。知有贼，当去，会反支日，不去，因为贼所杀。
注：王莽败：指新朝覆灭，更始、赤眉等起兵时。
注：张竦：王莽时人，《汉书》有传，后封淑德侯。
注：池阳：汉县名，在今陕西泾阳西北。
注：反支日：古代选择吉凶日期的一种禁忌，据《后汉书·王符传》，反支日不宜出行或上奏。
原：泾州书记薛昌绪，天性迂僻。梁师入境，泾帅宵遁，临行攀鞍，忽记曰：“传语书记，速请上马！”连促之，薛自匿草庵下，出声曰：“传语太师：但请先行，今日辰是某不乐！”泾帅怒，使人提上鞍鞒，捶其马而逐之，尚以物蒙其面，云：“忌日礼不见客。”
注：泾州：今甘肃泾川一带。
注：书记：节度使的幕僚，掌文书。
注：梁师：后梁之兵。
注：泾帅：泾原节度使，其人待考。
注：鞍鞒：马鞍。
注：传语：转告。
注：今日辰是某不乐：古有“辰日不哭”之忌，此处拘泥于忌日，其详待考。
注：忌日礼不见客：先人忌日不会客。
# 检谱角抵
题解：顾云得孔明兵书便以兵法自负，实则不过是“检谱角抵”，只会照谱比划。
原：江陵顾云，偶于市上收得孔明兵书，遂负可将十万，吞并四海。每至论兵，必攘袂叱吒，若真对大敌，时谓之“检谱角抵”。
注：顾云：其人待考。
注：孔明兵书：传为诸葛亮所著兵书。
注：负可将十万：自以为能统兵十万。
注：攘袂叱吒：挽袖大声呼喝。
注：检谱角抵：按谱册翻书对付摔跤，比喻纸上谈兵、不知变通。
# 奇技自献
题解：新莽时人献奇技攻匈奴，试飞者坠地，王莽仍封为理军，可见求名好大。
原：新莽时，博募奇技可以攻匈奴者，将待以不次之位。言便宜者以万数。或言能渡水不用舟楫，连马接骑，济百万师。或言不持斗粮，服药物，三军不饥。或言能飞，一日千里，可窥匈奴。莽试之。取大鸟翮为两翼，头与身皆著毛，通引环纽，飞数百步，堕。莽犹欲获其名，皆拜理军。
注：新莽：王莽建立的新朝。
注：不次之位：不按资历、破格授予的官位。
注：便宜：有利的计策。
注：斗粮：一斗粮食，指军粮。
注：翮：鸟羽的茎，此指翅羽。
注：环纽：环扣钮带，用以系缚羽翼。
注：理军：王莽所授军职名，见《汉书·王莽传》。
# 李晟、张一中谈兵
题解：李晟、张一中屡以兵事上书，皆大言无用，终被罢斥，均见明朝实录与史传。
原：成化二年，都察院经历李晟言边务兵机各五事。以荐用旧臣，非所宜言，降调为通判。弘治元年，复上疏，言“臣学兵法四十年，得其奇要。”上《战法》一篇、《急务》二篇，高自称许。上命工部试造战车弓弩，俱不可用，坐虚废钱粮，降四级，为云南曲靖卫知事。十年，复上疏言边事，稍迁都察院照磨。十五年，迁郧阳府抚民同知，不肯行。明年，复上疏，愿边方自效，得旨候有西北边兵备员缺推补。正德四年，冒候缺兵备佥事上书，献《按攘六论》。下兵部，参其大言无实，垂老不悟，姑免罪，放回闲住。八年，再冒衔上兵书五种，仍放回。史称其所制全身铁甲，工部铸而俾试之，行数步辄仆焉。
注：成化二年：1466年。
注：都察院经历：都察院的属官，掌文书出纳。
注：通判：府的佐官，掌粮运、水利、诉讼。
注：弘治：明孝宗年号。
注：战车：明代军队用的火器战车。
注：曲靖卫知事：曲靖卫（云南）的知事，掌文书。
注：照磨：掌管文卷的小官。
注：郧阳府抚民同知：郧阳府设抚民同知，管流民。
注：兵备佥事：整饬兵备的按察司佥事。
注：《按攘六论》：书名，作者李晟，具体内容待考。
注：闲住：革职闲居。
注：铁甲：此言所制铁甲不实用。
原：张进士一中，初名宽，湖广襄阳人。流贼犯襄阳，宽以翰林检讨自乞赞军务，建策驱流人还乡，累死者以千万计。寻升按擦佥事，坐贪淫革职。至是北虏犯塞，潜来京师，上疏请易旗号盔甲皆为黄色，牌面皆作虎形，曰：“黄为中央之土，以克北方之水。虎惊胡马之目，见必惧退，然后以神枪药箭射之。”且自谓秘机，不敢详于副封，奏疏乞留中不出。下兵部，参其庸妄干进，罢之。
注：张进士一中：初名宽，襄阳人，事见《明史》。
注：流贼：指明时流民起义军。
注：检讨：翰林院属官，掌修史。
注：赞军务：参谋军事。
注：按擦佥事：原文如此，当指按察司佥事，疑“擦”为“察”之误。
注：北虏：明人对蒙古的称呼。
注：黄为中央之土，以克北方之水：五行说，黄属土，北方属水，土克水。
注：胡马：胡人之马，指蒙古骑兵。
注：留中：奏章留在宫中不下发。
注：副封：附于奏疏的副本。

# 刘、王辱骂
题解：刘宽以怕奴仆自杀而不怒，王昕则以骂人极深自矜，二事皆宽缓迂阔。
原：刘宽尝坐客，遣苍头市酒。去久，大醉而还。客不堪之，骂曰：“畜产！”宽须臾遣人视奴无恙否，顾左右曰：“此人被骂畜产，辱莫甚焉，吾惧其自杀耳！”
注：刘宽：东汉名臣，性仁恕，事见《后汉书·刘宽传》。
注：苍头：奴仆，汉代指奴隶。
注：畜产：骂人如牲畜之语。
原：王昕在东莱，获杀其同行侣者，诘之，未服。昕从容谓曰：“彼物故不归，卿无恙而返，何以自明？”邢邵见文襄，说此以为笑乐。昕闻之，诣邵曰：“卿不识造化！”还谓人曰：“子才应死，我骂之极深。”
注：王昕：北齐人，《北齐书》有传。
注：东莱：今山东莱州。
注：物故：死亡。
注：邢邵：字子才，北齐文士。
注：文襄：北齐文襄帝高澄。
注：造化：此处意为玄机、门道，谓不知其中的妙处。
# 罚人食肉
题解：李载仁性迂缓，罚相殴者对食猪肉，并威胁猪肉中加酥，可笑。
原：李载仁，唐之后也。避乱江陵，高季兴署观察推官。性迂缓，不食猪肉。一日将赴召，方上马，部曲相殴。载仁怒，命急于厨中取饼及猪肉，令相殴者对餐之。复戒曰：“如敢再犯，必于猪肉中加之以酥！”
注：李载仁：唐宗室后裔，五代时居荆南，其事见《北梦琐言》。
注：高季兴：后唐封荆南节度使，建立荆南政权。
注：观察推官：节度使、观察使的僚属，掌推勘刑狱。
注：部曲：此指家兵、仆从。
注：酥：用牛羊乳制成的油，唐代常见食品。
# 河南令
题解：河南令为推农政而以长锥种麦、令百姓献鸡灭蝗，都是迂得可笑的办法。
原：宋子京留守西都，有同年为河南令，好述利便。以农家艺麦费耕耨，改用长锥刺地下种，自旦至暮，不能一亩。又值蝗灾，科民畜鸡，云“不唯去蝗之害，兼得畜鸡之利。”克期令民悉呈所畜。群鸡既集，纷然格斗，势不能止，逐之飞走，尘埃障天。百姓喧阗不已，相传为笑。
注：宋子京：宋祁，字子京，北宋文学家，曾任西京留守。
注：留守西都：任西京（洛阳）留守。
注：同年：同年登科的进士。
注：河南令：河南县县令，在洛阳。
注：耕耨：耕地与锄草。
注：科民：向百姓摊派。
注：喧阗：喧闹声盛。
# 归、王吏治
题解：归有光以朱笔洒胥吏，王中吴以“羞极面赤”为责十板之数，皆是书生治吏的笑谈。
原：归太仆有光谪官吴兴。每治事，胥吏辈环挤案旁，几不容坐。归以朱笔饱蘸，捉向诸人，曰：“诸君若不速退，我便洒将来也！”合堂大笑。
注：归太仆：归有光，明代散文家，曾任南京太仆寺丞。
注：谪官吴兴：归有光曾任湖州长兴县令。
注：胥吏：官府的小吏。
注：朱笔：红笔，官府批阅用。
原：吾苏王中吴先生，厚德而拙于吏治。由乡科为县令，每视事有疑，辄密缄条纸，质之记室。一日拆封，见吏匿银，怪之，亟为传问，得教云：“此弊也，宜重惩。”王为点头。久之拆完，王问吏何以匿银，吏坚讳。搜之不得，怒责十板。既退，馀怒未息，述诸记室。记室曰：“何不监追赃物，而轻释乃尔！”王摇首曰：“使不得！责至七八板时，彼羞极，面俱发赤矣！”
注：王中吴：吴县（苏州）人王某，事迹待考。
注：乡科：乡试中举。
注：记室：此指幕客，掌书记。
注：监追：官府监督追缴赃物。
# 掾史养名

注：䯄字：此字（騧，马黄喙黑）旁有“呙”，形近“祸”，故改写，其说待考。
注：祝：祷祝的文辞。
注：太牢：祭祀用牛、羊、豕三牲全备。
注：土神：主管土木的神，修造动土须祭。
注：江谧：南朝宋人，《南史》载其言“白门”触宋文帝之忌。
注：白门：建康（今南京）宣阳门俗称白门；“白”又与丧事相关，帝因此忌之。
注：白汝家门：诅咒语，意为让你家门办丧事。
注：后梁萧詧：南北朝时后梁宣帝，史称其性猜忌。
注：汝南陈伯敬：东汉汝南人，事迹待考。
原：谢在杭云：“余所见缙绅中有恶鸦鸣者，日课吏卒左右，彀弓挟弹，如防敌然。值大雪，即不出，恶其白也。官文书一切“史”字、“丁”字、“孝”字、“老”字，皆禁不得用。
注：谢在杭：谢肇淛，字在杭，明福建长乐人，著《五杂组》。
注：缙绅：官绅，本指插笏于绅带者。
注：彀弓挟弹：拉弓持弹丸。
注：“史”字：史与“死”音近；“丁”与“钉”或“凶”相涉，“孝”“老”则涉丧与衰，均被忌用。
原：柳冕为秀才，性多忌讳，应举时，有语“落”字者，忿然见于词色。仆夫犯之，辄加棰楚。常谓安乐为安康。闻榜出，遣仆视之。须臾，仆还，冕迎门曰：“得否？”仆曰：“秀才康了。”
注：柳冕：唐代官员，《新唐书》有传，此事见唐人笔记。
注：秀才：此指应举的读书人。
注：棰楚：杖打。
注：安康：因避“落”字，把“安乐”改称“安康”（乐、落音近）。
注：康了：仆人以“康”代“落”，谓“秀才落榜了”。

# 装胡桃
题解：吴石湖装胡桃不成，僮仆以巧法得之，他却叹“民伪日滋”，迂极。
原：相国吴石湖一日宴客，以胡桃装就而后笼罩。公屡装不就。一僮先以桃下罩，用碟盛起。公抚膺叹曰：“民伪日滋矣！”
注：相国：对宰相的敬称，明代指大学士。
注：吴石湖：事迹待考。
注：胡桃：核桃。
注：民伪日滋：感叹人心日益巧诈，语意出自古人叹世风日下。
