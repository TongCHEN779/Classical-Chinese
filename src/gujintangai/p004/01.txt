# 正文
题解：《专愚》部总序：以盗钟掩耳、愚公移山，讽自以为英雄者之愚。
原：〔子犹曰：人有盗范氏锺者，负之有声；惧人之闻，遽自掩其耳。太行、王屋二山，高万仞，愚公年九十，面山而居，恶而欲移之。二事人皆以为至愚，抑知秦政之鞭石为移山，曹瞒之分香为掩耳乎？彼自谓一世之英雄，孰知乃千古之愚人也。故夫杨广与刘禅同亡，国忠与苍梧齐蔽。平生凶狡，徒作笑柄；静言思之，不愚有几？集《专愚》第四。〕
注：子犹曰：子犹，冯梦龙之号。
注：范氏锺：《吕氏春秋·自知》载有人盗范氏之钟，椎毁而钟声大响，恐人闻，遽自掩耳，即“掩耳盗铃”之本。
注：愚公：《列子·汤问》载北山愚公欲移太行、王屋二山。
注：秦政之鞭石：秦始皇（名政）传说鞭石为桥，欲过海看日出，见《三齐略记》。
注：曹瞒之分香：曹操（小字阿瞒）遗令分香给诸夫人，见陆机《吊魏武帝文》。
注：杨广与刘禅同亡：隋炀帝杨广与蜀后主刘禅，皆亡国之君。
注：国忠与苍梧齐蔽：杨国忠与苍梧绕，皆愚昧被蔽之人，事见本部。
注：静言思之：安静时想一想，语出《诗经·卫风·氓》。
# 昏主
题解：历代昏君之愚：刘玄刮席，刘禅不思蜀，晋惠帝闻蛙，齐后主失将士心，宋子业，陈后主藏井，隋炀帝杀人。
原：刘玄称帝，群臣列位，低头以手刮席，汗流不止。
注：刘玄：更始帝，绿林军所立，《后汉书》载其即位时羞愧，刮席不敢仰视。
原：司马文王问刘禅：“思蜀否？”禅曰：“此间乐，不思。”却正教禅：“若再问，宜泣对曰：‘先墓在蜀，无日不思。’”会王复问，禅如正言，因闭眼。王曰：“何乃似却正语？”禅惊视曰：“诚如尊命！”
注：司马文王：司马昭，封晋文王。
注：刘禅：蜀汉后主，亡国后被迁洛阳，“乐不思蜀”之典出自此。
注：却正：郤正，蜀汉大臣，随刘禅入洛，事见《三国志》。
原：晋惠帝在华林园闻虾蟆声，问左右曰：“此鸣者为官乎？为私乎？”侍中贾胤对曰：“在官地为官，在私地为私。”时天下荒馑，百姓多饿死。帝闻之，曰：“何不食肉糜？”
注：晋惠帝：司马衷，史称痴愚。
注：华林园：洛阳皇家园林。
注：虾蟆：蛙。
注：侍中：皇帝近侍官。
注：贾胤：待考。
注：荒馑：饥荒。
注：何不食肉糜：晋惠帝语，《晋书·惠帝纪》载之。
原：晋阳失守，齐后主出奔。斛律孝卿请帝亲劳将士，为帝撰辞，且曰：“宜慷慨流涕，感激人心。”众既集，帝不复记所受言，遂大笑。左右亦群咍。将士莫不解体。
注：晋阳失守：北齐承光元年（577），北周攻占晋阳，后主高纬出奔。
注：斛律孝卿：北齐大臣。
注：咍：嗤笑。
注：解体：离心。
原：王太后疾笃，使呼宋主子业。子业曰：“病人间多鬼，那可往？”太后怒，谓侍者：“取刀来剖我腹，那得生宁馨儿？”
注：王太后：宋前废帝刘子业之母王太后，宋孝武帝皇后。
注：宋主子业：刘子业，前废帝，荒淫凶暴，被杀。
注：宁馨儿：晋宋间俗语，意为这样的孩子。
原：隋兵入台城，群臣劝依梁武见侯景故事。后主曰：“吾自有计。”乃挟宫人十馀出景阳殿，欲投井中。袁宪及夏侯公韵苦谏，不从；以身蔽井。后主与争，久之方得入。军人呼井不应，欲下石，乃闻叫声。以绳引之，怪其太重，乃与张贵妃、孔贵嫔同束而上。后人名为“辱井”。初，贺若弼拔京口，彼人密启告急。叔宝为饮酒，遂不省之。高颎至，犹见启在床上，未开封也。叔宝既谒隋主，愿得一官号。隋主曰：“叔宝全无心肝！”
注：台城：南朝宫城，在今南京。
注：依梁武见侯景故事：梁武帝见侯景时，整肃仪容，不失君主之尊。
注：景阳殿：陈宫殿名。
注：袁宪：陈大臣，隋军入城时劝后主正衣冠坐殿。
注：夏侯公韵：陈后主之侍臣。
注：张贵妃、孔贵嫔：陈后主所宠之妃嫔。
注：辱井：陈后主藏身之井，在今南京，亦称胭脂井。
注：贺若弼：隋名将，伐陈。
注：京口：今江苏镇江。
注：密启：秘密启奏。
注：高颎：隋文帝重臣，统兵灭陈。
注：叔宝：陈后主陈叔宝。
注：全无心肝：隋文帝评语，《南史》载之。
原：杨玄感败。帝命推其党与，曰：“玄感一呼而从者十万，益知天下人不欲多，多则相聚为盗耳。不尽加诛，无以惩后！”由是所杀三万馀人。帝后至东都，顾盼街衢，谓侍臣曰：“犹大有人在！”
注：杨玄感：隋大臣杨素之子，大业九年（613）反隋失败。
注：帝：隋炀帝杨广。
注：推其党与：追究其党羽。
注：东都：洛阳。
注：犹大有人在：炀帝语，意为谋反之人仍多。
# 逃债、埋钱
题解：周赧王避债登台，宋明帝埋钱为私藏，皆是愚拙之举。
原：周赧王为诸侯所侵逼，名为天子，实与家人无异。贳于民，无以偿，乃登台避之。因名曰“逃债台”。
注：周赧王：东周最后一位天子，被诸侯所迫，居洛阳王城。
注：贳：赊欠。
注：逃债台：旧址在今河南洛阳，一说在山东，其说待考。
原：宋明帝奢费过度，府藏空虚，乃令小黄门于殿内埋钱，以为私藏。
注：宋明帝：南朝宋明帝刘彧，奢侈。
注：府藏：国库。
注：小黄门：宦官。
# 反贼
题解：张丰听道士的话造反，被斩前仍以“肘后有玉玺”自欺；王始称帝，被杀前仍坚持称尊。
原：张丰好方术。有道士言丰当为天子，以五采囊裹石，系丰肘，云“石中有玉玺”。丰信之，遂反。既当斩，犹曰：“肘后有玉玺。”旁人为椎破之，乃知被诈，仰天曰：“当死无恨！”
注：张丰：东汉初渔阳人，《后汉书·彭宠传》载其听信方术谋反。
注：五采囊：五彩的布袋。
注：肘后有玉玺：张丰语，以为玉玺在肘后。
注：椎：槌击。
原：南燕慕容德建平四年，娇贼王始聚众泰山，自号“太平皇帝”，父冏为太上皇，兄林为征东将军，泰为征西将军。德遣车骑将军王镇讨擒之。人谓之曰：“何为妖妄，自贻族灭？父及兄弟何在？”始曰：“太上皇蒙尘在外，征东、征西为乱兵所杀。如朕今日，复何聊赖！”其妻赵氏怒曰：“君止坐此口，以至于死，如何临刑犹自不革？”答曰：“皇后不达天命，自古及今，岂有不亡之国哉！”行刑者以刀环筑其口。始曰：“朕今为卿所苦，崩即崩尔，终当不易尊号。”
注：南燕慕容德：十六国南燕开国君主。
注：建平四年：南燕年号，约403年。
注：娇贼：贼首，原文“娇”疑为“妖”，见《晋书》。
注：王始：泰山人，聚众称“太平皇帝”，《晋书·慕容德载记》载其被擒。
注：太上皇：皇帝之父的尊号。
注：蒙尘：帝王出奔在外。
注：自贻族灭：自招灭族之祸。
注：刀环：刀柄上的环。
注：崩：帝王之死。
# 蠢父蠢子
题解：徐检庵听信日者要妾忍着不生，导致母子俱毙；吴蠢子怕多活两年无靠；某人在邻居死后哭而不哀。
原：苏州徐检庵侍郎，老而无子，晚年二妾怀孕，小言争竞，已坠其一矣。其一临蓐欲产，徐预使日者推一吉时，以其尚早，劝令忍勿生。逾时子母俱毙。
注：徐检庵侍郎：苏州徐某，待考。
注：临蓐：临产。
注：日者：占卜的人。
原：《稗史》：吴蠢子年三十，倚父为生，父年五十矣。遇星家推父寿当八十，子当六十二。蠢子泣曰：“我父寿止八十，我到六十以后，那二年靠谁养活？”
注：《稗史》：泛指野史小说，此处所指待考。
注：星家：星命家，算命先生。
原：《韩非子》云：“东家母死，哭之不哀。西家子曰：“社胡不速死？吾哭之必哀。”
注：《韩非子》：先秦法家著作，此引文待考。
注：东家母死：此段出处待考。
注：社胡不速死：这里“社”指社日？待考，意为他家怎么不早死，以便自己哭得更悲。
# 蠢夫
题解：苍梧绕以美妻让兄，杨国忠被妻骗而认子，陶丘氏因岳母老而休妻，越中士人藏妾于佛寺，皆是蠢夫。
原：苍梧绕娶妻而美，以让其兄。
注：苍梧绕：传说中的人物，古书载其娶美妻而让与其兄，具体出处待考。
原：杨国忠出使江浙。逾年，妇在家产男，名朏。国忠归，妇告以“远念成疾，忽昼梦尔我交会，因得孕。”国忠以为夫妇相念，情感所至，欢然不疑。
注：杨国忠：唐玄宗时宰相，杨贵妃从祖兄。
注：江浙：杨国忠曾奉使剑南，江浙之说待考。
注：朏：杨国忠妻子所生之子名，其人待考。
注：昼梦尔我交会：白日做梦与你交合，是妇人托辞。
原：平原陶丘氏娶妇，色甚令，复相敬重。及生男，妇母来看，年老矣。母既去，陶遣妇颇急。妇请罪。陶曰：“顷见夫人衰齿可憎，亦恐新妇老后，必复如此，是以相遣，实无他也。”
注：平原：今山东平原。
注：陶丘氏：复姓陶丘，其人待考。
注：令：美好。
注：衰齿：年老。
注：新妇：媳妇，指自己的妻子。
原：越中一士登科，即于省中娶妾。同年友问曰：“新人安在？”答曰：“寄于湖上萧寺。”同年云：“僧俗恐不便。”答曰：“已扃之矣。”同年云：“其如水火何？”答曰：“锁钥乃付彼处。”
注：登科：考中科举。
注：省中：京城官署，此指京城。
注：同年：同榜进士。
注：萧寺：佛寺。
注：扃：关闭、锁上。
注：水火：指烧水做饭。
# 呆谕德
题解：崔阡不识朝典，问太子见面是否称臣，笑谈。
原：唐顺宗在东宫，韦渠荐崔阡拜谕德，为侍书。阡触事面墙，对东宫曰：“某山野鄙人，不识朝典，见陛下合称臣否？”东宫笑曰：“卿是宫僚，自合知也。”
注：唐顺宗：李诵，即位前为太子，居东宫。
注：韦渠：疑即韦渠牟，德宗朝官员。
注：崔阡：唐德宗时人，《因话录》等有载，待考。
注：谕德：太子谕德，东宫官。
注：侍书：东宫侍书，掌书法。
注：面墙：像面对墙壁，一无所见。
注：宫僚：东宫的属官。
# 呆刺史
题解：孙彦高被突厥围，吓得藏进柜里。
原：周定州刺史孙彦高，被突厥围城，不敢诣厅，文符须征发者，于小窗接入。锁州宅门，及报贼登垒，乃身入柜中，令奴曰：“牢掌钥匙，贼来，慎勿与！”
注：周定州刺史孙彦高：武周时定州刺史，事见《朝野佥载》。
注：突厥：北方游牧民族，武周时屡扰河北。
注：诣厅：到公堂。
注：文符：公文符信。
注：垒：营垒，此指城垒。
# 呆参军
题解：独孤守忠只会说“逆风不得张帆”。
原：杭州参军独孤守忠，领租船赴都。夜半急集船人，至则无别语，但曰：“逆风必不得张帆。”
注：参军：州府官，掌文书。
注：独孤守忠：事见《朝野佥载》，其人待考。
注：租船：运输租赋的船。
注：张帆：扬帆。
# 呆县丞
题解：郭务静与马信的呆话。
原：南皮丞郭务静，初上典王庆案。郭曰：“尔何姓？”庆曰：“姓王。”须臾庆又来，又问何姓，庆又曰：“姓王。”郭怪愕良久，仰看庆曰“南皮左史总姓王。”又一日，与主簿刘思庄语，曰：“夜来一贼从内房出。”刘问：“亡何物？”郭曰：“无所亡。”刘曰：“不亡物，安知为贼？”郭曰：“但见其踉跄而走，未免致疑耳。”
注：南皮丞：南皮县丞，南皮在今河北。
注：郭务静：事见《朝野佥载》，其人待考。
注：典：吏员。
注：左史：此指同署的吏员，待考。
注：主簿：县属官，掌文书。
注：踉跄：走路不稳。
原：山东马信由监生为长州县丞，性朴实。一日乘舟谒上官，上官问曰：“船泊何处？”对曰：“船在河里。”上官怒，叱之曰：“真草包！”信又应声曰：“草包也在船里。”
注：马信：山东人，监生出身，待考。
注：监生：国子监的学生，明代可由监生入仕。
注：长州：今苏州一带的县。
注：草包：本指盛草之包，此处用作骂人“蠢材”。
# 呆主簿
题解：德清马主簿半夜叩县令门提建议，又怕倭子。
原：德清有马主簿，本富家子，愚不谙事。忽一晚三更时，扣大令门甚急。令以为非火即盗，惊惶而出。簿云：“我思四月间田蚕两值，百姓甚忙，何不出示，使百姓四月种田，十月养蚕，何如？”令曰：“十月间安得有叶？”簿无以对，徐云：“夜深矣，请睡罢。”自以后每夜出，其妻必绐以“倭子在外，不可出。”遇圣节，其妻曰：“可出行礼。”簿摇手曰：“且慢且慢，有倭子在外！”
注：德清：今浙江德清。
注：大令：对县令的尊称。
注：田蚕两值：农事与蚕事同时忙。
注：倭子：对倭寇的称呼。
注：绐：欺骗。
注：圣节：皇帝的生日。
# 智短汉
题解：娄师德得知吃肉原因，嘲庖人“智短汉”。
原：则天朝大禁屠杀。御史娄师德使至陕，庖人进肉。问：“何为有此？”庖人曰：“豺咬杀羊。”师德曰：“豺大解事！”又进鲙，复问之。庖人曰：“豺咬杀鱼。”师德叱曰：“智短汉！何不道是獭？”
注：则天朝大禁屠杀：武则天长寿元年（692）禁断天下屠杀。
注：娄师德：武周宰相，性宽厚，“唾面自干”之典即其事。
注：庖人：厨师。
注：豺大解事：豺狼很懂事。
注：鲙：切细的鱼肉。
注：獭：水獭，会捕鱼。
注：智短汉：笨蛋。
# 服槐子
题解：黄可误听潘佑的“服槐子”，抱槐树而食。
原：道士黄可，孤寒朴野。尝谒舍人潘佑，潘教以服槐子，可丰肌却老，未详言服法。次日，潘入朝，方辨色，见槐树烟雾中有人若猿狙状。追视之，可也。怪问其故，乃拥槐徐对曰：“昨蒙指教，特斋戒而掇之。”潘大噱而去。
注：黄可：南唐道士，事见《江南野史》，待考。
注：孤寒朴野：出身孤贫，朴拙粗野。
注：潘佑：南唐大臣，后主时任中书舍人。
注：槐子：槐树的果实，古人以为服之可轻身延年。
注：辨色：天刚亮能辨物色。
注：猿狙：猴子。
注：掇：采摘。
注：噱：大笑。
# 诵判
题解：沈子荣背判而不能用，是呆学问。
原：周沈子荣诵判二百道，赴天官试，竟日不下笔。人问荣，荣曰：“与平日诵判绝不相当。有一道事迹同而人名别，遂曳白而出。”来年选判水碓，又搁笔。人问荣，荣曰：“我诵水碓是蓝田，今富平，如何下笔？”

# 脉望
题解：张尚书之子信“脉望”之说，碎剪神仙字入瓶中，成心疾。
原：《北梦琐言》：张易攵尚书少子，尝闻壁鱼入道函中，蠹食“神仙”字，身有五色，是名“脉望”，吞之则仙。遂多书“神仙”字，碎剪入瓶中，捉壁鱼投之，冀得蠹食。不能得，忽成心疾。
注：《北梦琐言》：五代孙光宪撰笔记。
注：张易攵尚书：疑为张易，待考，原文字不清。
注：壁鱼：蠹鱼，书中的蛀虫。
注：道函：道教经书匣。
注：蠹食：虫蛀。
注：脉望：传说蠹鱼蛀食“神仙”字后化为脉望，吞之可仙，见《酉阳杂俎》。

注：纺缁：丝织的黑衣。
注：襌缁：单层黑衣。

注：豚：小猪。
原：郢人欲为大室，使人求三大围之木。人与之车毂，跪而度之，曰：“大虽有馀，长实不足。”
注：郢人：楚国郢都人。
注：三大围：三围粗，一围约尺五。
注：车毂：车轮中心的圆木。

注：钻火：钻木取火。
注：阴瞑：阴暗。

注：车轭：套在牛马颈上的横木。

注：历辘：疑为“历戾”，狡诈，待考。

注：晬：婴儿满周岁。

# 虾蟆为马
题解：伯乐之子按图索骥，把蟾蜍当马。
原：伯乐令其子执《马经》画样求马，经年无似者。更求之，得一大虾蟆，归白父曰：“得一马，隆颅跌目，脊郁缩，但蹄不如，累趋。”伯乐笑曰：“此马好跳踯，不堪御也。”
注：伯乐：春秋秦穆公时善相马者，传有《相马经》。
注：《马经》：相马之书。
注：隆颅跌目：额高、眼凸，相马术语。
注：脊郁缩：背脊弯曲收缩，其实是蟾蜍特征。
注：跳踯：跳跃。
# 艾子
题解：艾子讥木履“生于生”，以“鞋楦”对核。
原：齐人献木履于宣王，略无刻斫之迹。王曰：“此履岂非出于生乎？”艾子曰：“鞋楦是其核也。”
注：木履：木鞋。
注：宣王：齐宣王。
注：艾子：《艾子杂说》中的人物，书托名苏轼。
注：鞋楦：制鞋用的木模，与“核”相对，“核”谐“楦”之形似。
# 沈屯子
题解：沈屯子听说书而替古人担忧，是愚而痴的极致。
原：沈屯子入市，听唱书，至杨文广被围柳城，内乏粮，外阻救，蹙然兴叹不已。友拉之归，日夜忧念不置，曰：“文广围困至此，何由得解？”家人因劝出游，以纾其意。忽见担竹入市者，则又念曰：“竹末甚锐，道上行人必有受其刺者。”归益忧病。家人为之请巫。巫曰：“稽冥籍，若来世当轮回作女人。所适夫麻哈回也，貌甚陋。”沈忧病转剧。亲友来省者慰曰：“善自宽，病乃愈耳。”曰：“若欲吾宽，须杨文广围解，负竹者归家，麻哈回作休书见付乃得也？”
注：沈屯子：其人待考。
注：唱书：说书，宣讲话本。
注：杨文广：北宋名将杨延昭之子，在民间说书中有“杨文广平南”事。
注：柳城：说书中的地名，实指待考。
注：冥籍：阴间名册。
注：轮回：佛教所谓生死循环。
注：麻哈回：说书中人物，貌丑，待考。
注：休书：休妻的文书。

原：家有一坐头，绝低矮。公每坐，必取瓮片支其四足，后不胜烦，忽思得策，呼侍者移置楼上坐。及坐时，低如故。乃曰：“人言楼高，浪得名耳！”遂命毁楼。

# 物性之愚
题解：物性自愚：翠鸟、猩猩、鲥鱼、白鹇、孔雀、蛔虫、猱皆以其性被捕或被害。
原：《交趾异物志》：翠鸟先高作巢以避患。及生子，爱之，恐坠，稍下作巢。子长羽毛，复益爱之，又更下巢，而人遂得而取之矣。《水经注》：猩猩知往而不知来，山谷间常数十为群。里人以酒并糟设于路侧，织草为屦，更相连结。猩猩见酒及屐，知里人设张，则知张者祖先姓字。乃呼名云：“奴欲张我！”舍而去，复自再三，相谓曰：“试共尝酒。”乃饮其味，逮手醉，因取屐著之而踬。乃为人擒，无遗者。
注：《交趾异物志》：汉杨孚所撰，记交趾（今越南北部、广西一带）物产。
注：翠鸟：翠鸟为羽美的小鸟，其羽用作饰物。
注：《水经注》：北魏郦道元所撰。
注：猩猩：传说中的灵兽，好酒，嗜屐，见《水经注》等。
注：糟：酒糟。
注：屦：草鞋。
注：屐：木屐。
注：踬：绊倒。
原：鲥鱼入网辄伏者，惜其鳞也。
注：鲥鱼：长江名贵鱼，传说爱惜鳞片，遇网则伏。
原：白鹇爱其尾，栖必高枝。每天雨，恐污其尾，坚伏不动。雨久，多有饥死者。又孔雀爱尾，潜则露尾，人因取之。虫有蛔者，一身两口，争食，因相龁以死。
注：白鹇：雉科鸟，尾长。
注：孔雀：羽美鸟。
注：蛔：寄生虫，此处传说一身两口。
注：龁：咬。
原：兽有猱，小而善缘，利爪。虎首痒，辄使猱爬搔之。久而成穴，虎殊快，不觉也。猱徐取其脑啖之，而以其馀奉虎。虎谓其忠，益爱近之。久之，虎脑空，痛发；迹猱，猱则已走避高木。虎跳踉大吼，乃死。
注：猱：猿类，或指一种擅长攀援的兽。
注：跳踉：跳跃。
