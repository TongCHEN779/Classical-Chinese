# 正文
题解：本部总论，冯梦龙以“子犹”之名论妒与惧内，说明为官尚须无欲，丈夫惧内却自天子至庶人皆然，并交代本部为全书第十九部《闺诫》。
原：〔子犹曰：女德之凶，无大于淫妒；然妒以为淫地也。壁如出仕者，中无贪欲，则必不忌贤而嫉能矣。然丈夫多惧内。自天子以至于庶人皆不免焉，则又何也？语曰：“当断不断，反受其乱。”集《闺诫》第十九。〕
注：子犹：冯梦龙的号之一。
注：女德：妇女的德行。
注：淫妒：淫邪与妒忌。
注：壁如：当作“譬如”，底本疑误。
注：出仕者：做官的人。
注：忌贤而嫉能：忌恨贤者，嫉妒能者。
注：惧内：怕妻子。
注：当断不断，反受其乱：语出《史记·春申君列传》“当断不断，反受其乱”，《汉书》亦引。
注：《闺诫》：本部名，意为对闺中之事的戒鉴。
# 潘妃
题解：东昏侯畏潘妃而被责打，只得令虎贲不进大荆条，写帝王亦怕所宠。
原：东昏侯宏畏潘妃，动遭嗬杖，不敢忤意。乃敕虎贲不得进大荆子。
注：东昏侯宏：南朝齐废帝萧宝卷，谥东昏侯。底本“宏”字疑有误，待考。
注：潘妃：潘玉儿，东昏侯宠妃，史称其“步步生莲花”。
注：嗬杖：呵责并杖打。
注：忤意：违背其意。
注：虎贲：禁卫武士。
注：荆子：用荆条制的刑杖，即笞杖，“大荆子”指粗大者。
# 宜城公主
题解：宜城公主因驸马裴巽有外宠而施酷刑，被唐玄宗降为郡主，写悍妒之祸与皇家处置。
原：唐裴选尚宜城公主。选有外宠一人。公主遣阍人执之，截耳劓鼻，剥其阴皮，缦驸马面上，令出厅判事。僚吏骇笑。上闻之，怒降公主为郡主，驸马左迁。
注：裴选：当作裴巽，唐代驸马，娶宜城公主。事见《朝野佥载》。
注：宜城公主：唐玄宗之女，下嫁裴巽。
注：外宠：在正妻之外所宠幸之人。
注：阍人：守门人。
注：截耳劓鼻：割耳割鼻，劓，割鼻刑。
注：剥其阴皮：此处指酷刑，不详述。
注：缦：覆盖，蒙。
注：驸马：皇帝女婿的称号。
注：判事：处理公事。
注：左迁：降职。
注：郡主：宗室女封号，位低于公主。
# 胭脂虎
题解：陆慎言之妻朱氏凶悍妒忌，擅自干政，被吏民称作“胭脂虎”，名号由此而来。
原：陆慎言妻朱氏，沉惨狡妒。陆宰尉氏，政不在己。吏民语曰“胭脂虎”。
注：陆慎言：唐人，曾任尉氏县令。
注：沉惨：阴沉狠毒。
注：狡妒：狡猾而妒忌。
注：尉氏：县名，今河南尉氏。
注：宰：任县令。
注：政不在己：政事不由自己做主。
注：胭脂虎：对悍妇的俗称，以其涂脂抹粉而凶如老虎得名。
# 畏妇除官
题解：杨弘武因畏妻而为人授官，据实向高宗承认，高宗笑而宽之，说明惧内之弊连及朝政。
原：杨弘武为司戎少常伯，尝除一人官，高宗问曰：“某人何因，辄授此职？”弘武曰：“臣妇韦性悍，昨以此见属，臣不从，恐有后患。”帝嘉其不隐，笑遣之。
注：杨弘武：唐初人，杨恭仁之子，历官司戎少常伯等。
注：司戎少常伯：司戎，兵部在龙朔年间的别称；少常伯，侍郎的别称。
注：除：授官。
注：高宗：唐高宗李治。
注：性悍：性情凶悍。
注：见属：嘱托我。
注：嘉：赞许。
# 裴谈
题解：本节两段：先记裴谈以三种可畏来解释惧内，后记中宗朝优人以《回波词》讽刺，皇后闻而厚赐，说明惧内在上层成风。
原：裴谈素奉释氏；妻悍妒。谈谓人曰：“妻有可畏者三：少妙时，视之如生菩萨，安有不畏生菩萨？男女满前，视之如九子魔母，安有人不畏九子魔母？及五十、六十，薄施妆粉，或青或黑，视之如鸠盘茶？安有人不畏鸠盘荼？”
注：裴谈：唐中宗、睿宗时官员，官至御史大夫，曾任刑部尚书，事见《朝野佥载》。
注：释氏：佛教，因释迦牟尼得名。
注：生菩萨：活的菩萨。
注：九子魔母：即鬼子母，佛教中育有众多孩子的恶神，这里指儿女满堂的妻子。
注：鸠盘茶：即鸠盘荼，佛教中形貌丑恶的鬼，能啖人精气。
原：唐中宗时，优人进《回波词》，曰：“回波尔时栲栳，怕妇亦是大好。外面只有裴谈，内面无如李老。”后闻之，乃厚赐优。当时君臣皆以惧内为固然矣。
注：中宗：唐中宗李显。
注：优人：宫廷中的伶人。
注：《回波词》：唐代教坊曲，常用于宴席上随口应对。
注：栲栳：用竹柳编成的盛物器，此处谐“老”音，指裴谈，笑点在“怕妇”。
注：李老：一说指唐中宗李显自己，意谓中宗也惧内。
注：后：韦皇后。
# 李大壮
题解：吴儒李大壮怕妻甚，被令头顶灯碗，朋友戏称他“黑凤凰”，写惧内者的窘态。
原：吴儒李大壮畏服小君，万一不遵号令，则叱令正坐，为绾扁髻，中安灯碗燃灯。大壮屏气定体，如枯木土偶。人目之曰：“补阙灯檠。”又尝值妻病，求鸦为药。大壮积雪中多方引致，仅获一枚。友人戏之曰：“圣人以凤凰来仪为瑞，君获此免祸，可谓黑凤凰矣！”
注：吴儒：吴地读书人。
注：小君：对妻子的称呼，本为诸侯夫人称。
注：绾：盘结。
注：扁髻：扁形的发髻。
注：灯碗：灯盏。
注：屏气定体：屏住气息，身体不动。
注：土偶：泥塑的像。
注：补阙灯檠：补阙，唐代谏官。灯檠，灯台。此处戏称头顶灯碗者。
注：鸦：乌鸦，旧时有以乌鸦入药的说法。
注：凤凰来仪：语出《尚书·益稷》“凤皇来仪”，指凤凰飞来为祥瑞。
注：黑凤凰：戏称乌鸦为凤凰。
# 水香劝盏
题解：扈戴怕妻，出门须靠滴水、香印计时，同席诸友以联句劝酒戏之，写惧内的种种诙谐。
原：扈戴畏内特甚。未仕时，欲出，则谒假于细君。细君滴水于地，水不干须归。若去远，则燃香印，掐至某所，以为还家之验。因宴聚，方三行酒，戴色欲遁。众客觉之，哗曰：“扈君巩砌水隐形，香印过界耳，是当罚也！吾徒人撰新句一联，劝请酒一盏。”众以为善，乃俱起，一人捧瓯吟曰：“解禀香三令，能遵水五申。”逼戴饮尽。别云：“细弹防事水，短热戒时香。”别云：“战兢思水约，匐匍赴香期。”别云：“出佩香三尺，归防水九章。”别云：“命系逡巡水，时牵决定香。”戴连沃六、七巨觥，吐呕淋漓。既上马，群噪曰：“若夫人怪迟，但道被水香劝盏留住。”
注：扈戴：疑为人名，生平待考。
注：谒假：请假。
注：细君：本指诸侯夫人，后用作对妻子的称呼。
注：香印：用香粉压成篆文，点燃后计时的香。
注：三行酒：酒过三巡。
注：遁：逃走。
注：巩砌水隐形：疑指妻所滴之水，意为用水计时，待考。
注：瓯：小盆、碗。
注：香三令：香计时，如三令五申。
注：水五申：用水计时，如五申。
注：细弹防事水：此联句意谓小心防备妻所滴的水，待考。
注：短热戒时香：短，指时间不长；意为戒惧香的限期。
注：战兢：恐惧发抖。
注：水约：滴水之约。
注：匐匍：同“匍匐”，爬行，此处形容仓皇。
注：香期：香燃尽的期限。
注：佩香三尺：待考。
注：九章：指约法章程。
注：逡巡：迟疑徘徊。
注：巨觥：大酒杯。
注：淋漓：形容吐得很多。
# 王夷甫
题解：王衍之妻郭氏悍妒，被乡人大侠李阳所震慑，王衍借此一言使妻稍有收敛，写畏人之人亦有可畏。
原：王夷甫妇，郭泰宁女，才拙而性刚，聚敛无厌，干预人事。夷甫患之，而不能禁。时其乡人幽州刺史李阳，京都大侠，犹汉之楼护。郭氏惮之，夷甫骤谏，乃曰：“非但我言卿不可，李阳亦谓卿不可！”郭氏小为之损。
注：王夷甫：王衍，字夷甫，西晋名士，官至太尉。
注：郭泰宁：王衍妻郭氏之父，疑指郭豫，字泰宁，待考。
注：聚敛无厌：搜刮钱财不知满足。
注：幽州刺史：幽州，今河北北部一带。刺史为州长官。
注：李阳：晋人，《世说新语》载其为京都大侠。
注：楼护：西汉游侠，字君卿，以口才和交游著称。
注：骤谏：屡次劝谏。
注：小为之损：稍有收敛。
# 九锡
题解：王导之妻曹氏性妒，王导躲避不及，被蔡谟讥为“短辕犊车，长柄麈尾”，笑谈中见其狼狈。
原：王丞相以曹夫人性忌，乃密营别馆，众妾罗列，男女成行。一时，夫人于蔬园中，望见两三小儿骑羊，脸端正可念。语婢：“汝出问，是谁家儿？”给使不达旨，乃云：“此是第四、五等诸郎。”曹惊恚，便命车驾，将黄门及婢二十人，持食刀自出寻讨。王亦飞辔出门，左手扳车栏，右手提麈尾，以柄打牛，狼狈奔驰，仅得先至。蔡司徒闻之，谓王曰：“朝廷欲加公九锡。”王自叙谦志。蔡曰：“不闻他物，唯闻短辕犊车，长柄麈尾耳。”王大笑。
注：王丞相：王导，东晋丞相。
注：曹夫人：王导之妻曹氏。
注：别馆：正宅之外的别院。
注：可念：可爱。
注：给使：供使唤的人。
注：第四、五等诸郎：指王导的庶出诸子，意谓是你家第四、第五等的儿子。
注：黄门：宫中侍从，这里指曹夫人带来的使役。
注：食刀：厨刀。
注：麈尾：魏晋名士清谈时所执的拂尘。
注：蔡司徒：蔡谟，东晋官员，官至司徒。
注：谦志：谦让之意。
注：短辕犊车：短辕牛车，供急速奔驰。
注：九锡：古代帝王赐给大臣的九种礼器，是殊礼。事见《世说新语·轻诋》。
# 王中令
题解：王铎镇荆南，既要抵御黄巢，又畏夫人北来，幕僚戏言“不如降黄巢”，写畏妻甚于畏敌。
原：王中令铎镇渚宫，为都统以拒黄寇；兵渐近。于是，赴镇以姬妾自随，其内未行，本以妒忌。忽报夫人离京在道。中令谓从事曰：“黄巢渐以南来，夫人又自北至。旦夕情味，何以安处？”幕僚戏曰：“不如降黄巢。”公亦大笑。
注：王中令铎：王铎，唐末宰相，官至中书令，故称“中令”。
注：渚宫：春秋楚国宫名，后称江陵（今湖北荆州）。
注：都统：军事统帅，王铎曾任诸道行营都统。
注：黄寇：黄巢起义军。
注：从事：幕府僚属。
注：旦夕情味：日常相处的情形。
注：幕僚：幕府中的参谋人员。
# 安鸿渐
题解：安鸿渐被妇翁丧事逼哭，以湿纸贴额伪装泪，又以“水出高源”自圆其说，写惧内者的滑稽。
原：安鸿渐滑稽惧内。妇翁死，哭于路。妇性素严，呼入幕中，诟之曰：“何因无泪？”安曰：“以帕试干。”妇曰：“来日早临棺，须见泪！”安计窘，来日以宽巾纳湿纸于额上，大叩其颡而恸。恸罢，其妇又呼入，诟之曰：“泪出于眼，何故额流？”安曰：“岂不闻水出高源？”
注：安鸿渐：唐人，生平待考，事见《因话录》类笔记。
注：滑稽：诙谐多智。
注：妇翁：岳父。
注：诟：责骂。
注：宽巾：宽大的头巾。
注：颡：额头。
注：水出高源：水从高处的源头流出。
注：恸：痛哭。
# 四畏堂
题解：王钦若夫人悍妒，王建“三畏堂”，杨亿戏称可改“四畏”，因而结怨，终无子嗣。
原：王钦若夫人悍妒，不畜姬侍。王于后圃作堂，名“三畏”。杨亿戏曰：“可改作‘四畏’。”王问其说。曰：“兼畏夫人。”王深以为恨，卒无嗣。
注：王钦若：北宋真宗朝宰相，江西临江人，与丁谓等并称“五鬼”。
注：不畜姬侍：不蓄养侍妾。
注：后圃：后花园。
注：三畏：语出《论语·季氏》“君子有三畏”，畏天命、畏大人、畏圣人之言。
注：杨亿：北宋文学家，西昆体代表，字大年。
注：卒无嗣：终无子嗣。
# 为婢取水
题解：周必大夫人妒，将所盼之婢拘于庭，公以“义井”自嘲，写宰相亦受制于妻。
原：周益公夫人妒。有媵，公盼之，夫人縻之庭。公适时，时炎暑，以渴告，公酌以水。夫人窥于屏内曰：“好个相公，为婢取水！”公笑曰：“独不见建义井者乎？”
注：周益公：周必大，南宋宰相，封益国公，故称“益公”。
注：媵：随嫁的侍女，也指陪嫁妾。
注：縻：拘系，束缚。
注：炎暑：酷热。
注：酌：斟。
注：建义井：修建义井，施水给路人。
# 车武子妇
题解：车武子之妻因夜见绛裙而疑夫私通，拔刀上床，发现是兄长而羞惭退去，写妒妇误会之笑。
原：车武子妇妒。武子偶偕妇兄夜归，留宿外馆，取一绛裙挂屏上。妇出窥，疑有所私，拔刀径上床；发被，乃其兄也，惭而退。
注：车武子：晋人，事见《太平广记》所引《世说》类笔记。
注：外馆：外屋、客馆。
注：绛裙：深红色裙子。
注：屏：屏风。
注：私：私通，指有私情。
注：径：径直。
注：发被：揭开被子。
# 池水清
题解：韩伸好赌善饮，被悍妻持棒伏击，误打同席客，蜀人戏称其为“池水清”。
原：《王氏见闻录》云：“渠州人韩伸善饮博，多留连于花柳之间。其妻怒甚，时复自来驱趁同归。尝游谒东川，经年方返，复致妓与搏徒同饮，妻闻之，率女仆潜匿邻舍，俟其宴合，遂持棒伺于暗处。伸不知，方攘臂浮白，唱“池水清”，声犹未绝，脑后一棒，打脱襆头，扑灭灯烛。伸即蹿于饭床之下。有坐客暗遭毒挞；复遣二青衣把髻子牵行，一步一棒决之，骂曰：“这老汉，何落魄不归也！”烛下照之，乃是同座客。蜀人传笑，遂呼韩为“池水清。”
注：《王氏见闻录》：五代前蜀王仁裕所撰笔记，或指《玉堂闲话》，待考。
注：渠州：治今四川渠县。
注：饮博：喝酒赌博。
注：花柳：妓院，也泛指风月场所。
注：驱趁：追赶。
注：东川：唐代剑南东川节度使辖区，在今四川东部。
注：搏徒：赌徒。
注：宴合：酒宴正酣。
注：攘臂：捋袖伸臂。
注：浮白：满饮一大杯酒。
注：池水清：当时流行的曲子。
注：襆头：幞头，一种头巾。
注：蹿：跳。
注：饭床：饭桌。
注：毒挞：狠打。
注：青衣：婢女。
注：髻子：发髻。
注：落魄：流荡，失意。
# 击僧
题解：张氏族中多惧内，一山被妻追打，躲入寺中，妻误打酣睡的僧人，写惧内之滑稽与妇人悍。
原：渭溪张氏族多惧内。少宗伯午峰公之兄号一山者，尤甚。一日忤其妇，妇逼之急，匿房后树上。妇持竹竿驱下，用铁索系之柱。宗伯公见之，乃曰：“我将见嫂请释。”兄摇手低声曰：“且慢且慢！待她性过，自放”。又二日，被责，潜逃邻寺。妇竟追至寺。一僧方酣卧。妇不暇详视，竟以大杖击僧。僧张目曰：“小僧无罪！”妇踉跄而归。
注：渭溪：地名，疑在今安徽，待考。
注：少宗伯：礼部侍郎的别称。
注：午峰公：张午峰，明人，官至礼部侍郎，事迹待考。
注：忤其妇：触怒妻子。
注：宗伯公：即少宗伯午峰公。
注：铁索：铁链。
注：嫂：指兄之妻。
注：性过：气消。
注：酣卧：熟睡。
注：踉跄：走路不稳。
# 谢太傅夫人
题解：本节两段：前段记谢安夫人刘氏拒绝夫君观伎乐；后段记谢氏子弟以《诗经》诸篇劝夫人，被夫人驳回，写贤相亦受制于妻。
原：刘夫人帏诸婢使作技。太傅暂见，便下帏。太傅索更一开。夫人拒之曰：“恐伤盛德！”
注：刘夫人：谢安之妻，刘惔之妹。
注：帏：以帷幕围起。
注：作技：作伎乐表演。
注：太傅：谢安，官至太傅。
注：下帏：垂下帷幕。
注：盛德：盛大的德行，指谢安的清德。
原：谢公既深好音乐，颇欲立妓妾。兄子外甥辈微达此旨，共问讯刘夫人，因方便称《关雎》、《螽斯》有不忌之德。夫人知以讽己，乃问：“谁撰此诗？”云：“是周公。”夫人曰：“周公是男子相为耳，若使周姥撰诗，当无此言！”
注：谢公：谢安。
注：立妓妾：蓄养歌伎妾侍。
注：兄子外甥辈：谢安的侄子和外甥辈。
注：微达：略微表达。
注：问讯：请安。
注：《关雎》、《螽斯》：《诗经·周南》篇名，序称《关雎》“乐得淑女”、《螽斯》“后妃子孙众多”，毛序谓后妃不妒忌。
注：不忌之德：不妒忌的德行。
注：周公：旧说《周南》为周公所作。
注：周姥：假设周公的妻子。
# 李福
题解：李福乘夫人沐浴假称腹痛召女奴，裴氏急以人溺为药，李福事后自嘲“虚咽一瓯溺”，写惧内之窘。
原：李福妻裴氏，性极妒。一日乘裴沐浴，伪言腹痛，召一女奴。奴既往，左右告裴曰：“相公腹痛不可忍。”裴竟跣步，以药投儿溺中，进之。明旦，监军使悉来候问，李具以实告，因曰：“一事无成，已矣；所恨者，虚咽一瓯溺耳！”
注：李福：唐宣宗至懿宗朝官员，曾任义昌军节度使等。
注：裴氏：李福妻。
注：沐浴：洗澡。
注：伪言：假说。
注：跣步：光脚走路。
注：儿溺：童子小便，旧时作药引。
注：监军使：唐代派往藩镇监视军务的宦官。
注：候问：问候。
注：一事无成：事情没办成。
注：瓯：小碗。
# 妒无须人
题解：荀氏之妇庾氏悍妒，连无须男子也不许与夫说话，被邻少年打翻在地而不悔。
原：荀氏妇庾，妒甚，不容无须人与荀语。邻有少年近荀，庾便索刀杖。少年不平，候庚前，便与斗，捽庾至地，打垂死。庾终不悔。
注：荀氏妇庾：晋人荀氏之妻庾氏，事见《太平广记》所引笔记。
注：无须人：没有胡须的人，指年轻男子。
注：捽：揪住。
注：垂死：几乎死去。
# 妒画
题解：刘瑱令人画鄱阳王与宠妃照镜图，以激妹妹之妒，使其病愈，写以妒治病的奇事。
原：刘瑱妹为鄱阳王妃，性极妒。王为明帝所诛，妃追伤成疾。瑱不能止，乃令殷蒨画王与宠妃照镜状，如欲偶寝，以示妃。妃唾骂曰：“故宜早死！”病亦寻愈。
注：刘瑱：南朝齐人，其妹为鄱阳王萧锵之妃。
注：鄱阳王：萧锵，齐高帝之子，被明帝所杀。
注：明帝：南朝齐明帝萧鸾。
注：追伤：追思悲伤。
注：殷蒨：南朝齐画家，擅画人物。
注：照镜：对镜。
注：故宜早死：本当早死。
注：寻愈：不久痊愈。
# 妒花
题解：阮宣武之妻以妒杀花，写妒妇连桃花也不放过。
原：《妒女记》：武历阳女嫁阮宣武，绝忌。家有一桃树，花叶灼耀。宣叹美之。即便大怒，使婢取刀斫树，摧折其花。
注：《妒女记》：南朝宋刘义庆所作笔记，今已佚。
注：武历阳女：待考。
注：阮宣武：阮裕，字思旷，东晋人，官至侍中，卒谥宣武。
注：绝忌：极其妒忌。
注：灼耀：鲜明光亮。
注：斫树：砍树。
注：摧折：折毁。
# 任环二姬
题解：唐太宗赐任瑰二姬，其妻柳氏妒而毁之，太宗赐毒酒试其妒，柳氏毅然饮下，太宗反使二女别居，写帝王亦无奈。
原：太宗赐任尚书环二艳姬。妻妨，烂其发秃尽。帝闻之怒，伪为冘，敕柳：“饮之，立死；如不妒，即不须饮。”柳氏拜敕曰：“妾与环俱出微贱，更相辅翼，遂至荣官。今多内嬖，诚不如死！”竟饮尽，无他。帝谓环曰：“人不畏死，不可以死恐。朕尚不能禁，卿其奈何？”二女令别宅安置。
注：任尚书环：任瑰，唐初大臣，曾任兵部尚书，妻柳氏。事见《朝野佥载》。
注：妨：妒忌。
注：烂其发：烧坏头发。
注：伪为冘：疑指伪造毒酒，待考。
注：敕柳：下令给柳氏。
注：微贱：出身卑贱。
注：辅翼：辅佐。
注：内嬖：宠幸的内室侍妾。
注：拜敕：接受敕命。
注：恐：恐吓。
注：别宅安置：另宅安顿。
# 妨妇津
题解：妒妇津的由来：刘伯玉妻段氏因夫赞洛神而投水，死后化神，后世妇人渡津须毁妆，写妒的传说。
原：临济有妒妇津。传言晋太始中刘伯玉妻段氏，字明光，性妒忌。伯玉常于妻前诵《洛神赋》，语其妻曰：“得妇如此，吾无憾矣！”段曰：“君重水神而轻我。吾死，何患不为水神？”某夜乃自沉而死。死后七日，见梦于刘。刘自是不敢复渡此水。有妇人渡此水者，皆毁妆而济，不尔，风波暴发。其鬼妇虽加妆饰，神亦不妒也。
注：临济：古县名，今山东章丘东北，一说在山东高青。
注：妒妇津：因妒妇之传说而得名的渡口。
注：太始：晋武帝年号，265—274年，此处“太始”当作“泰始”。
注：刘伯玉：晋人。
注：《洛神赋》：三国魏曹植所作，描写与洛水女神的相遇。
注：水神：此指洛神宓妃。
注：见梦：托梦。
注：毁妆：毁坏妆饰。
注：济：渡。
# 人鸡相妒
题解：人鸡相妒：胡泰之母托生为鸡，啄打继母，终被后母扑杀，写民间志怪与家庭妒争。
原：河间卫千户胡泰母死十年，父再娶。弘治己酉，忽梦母曰：“我已托生为雌鸡，毛色黪黄。明日为屯军之贽，来汝家也。”及旦，泰外出，果有屯军携鸡来者。家欲烹以享军。鸡作人语曰：“毋烹我，侍泰儿还！”家人以为怪。泰还，鸡绕泰喃喃叙其家事甚悉。泰涕泣告父，畜之。既久，飞啄后妻，诟置不已。泰出，后妻逐入炕下，扑杀之。
注：卫千户：卫所千户，明代卫所军官，正五品。
注：河间：府名，在今河北。
注：弘治己酉：明孝宗弘治二年，1489年。
注：托生：转世投生。
注：黪黄：浅黄带灰。
注：屯军：屯田的军士。
注：贽：见面礼。
注：烹：煮。
注：诟置：责骂，“置”疑当作“詈”。
注：炕：北方的土炕。
# 二洪之乐
题解：洪适、洪迈兄弟皆畏内，王宣子对其兄弟之乐的调侃，写畏内兄弟二十年后重述同一句话，笑中见同。
原：洪迈与兄适皆畏内，虽少年贵达，家有声妓，往往不能快意。王宣子知饶州。适家居丧偶，宣子吊焉。适延客至内斋，唤酒。甫举杯，群妾坌出，酒行无算。适半酣，握王手曰：“不图今日有此乐！”后二十年，宣子谢事归越，迈来为守，时已鳏居。暇日宣子造郡斋，迈留款，亦出家姬侑席，笑谓王曰：“家兄有言：‘不图今日有此乐！’”王为绝倒。
注：洪迈：南宋学者，著《容斋随笔》《夷坚志》。
注：适：洪适，洪迈之兄，官至宰相。
注：声妓：歌舞妓。
注：王宣子：王佐，字宣子，南宋官员，曾知饶州。
注：饶州：治今江西鄱阳。
注：丧偶：妻子去世。
注：内斋：内室书房。
注：坌出：纷纷涌出。
注：酒行无算：饮酒不计数。
注：谢事：辞官。
注：越：越州，今浙江绍兴。
注：守：太守。
注：鳏居：丧妻独居。
注：侑席：劝酒陪席。
注：绝倒：大笑得倒下。
# 贺丧妻
题解：解缙吊友人丧妻而说“恭喜”，暗示自己的夫人悍妒，写调侃与自嘲。
原：解学士尝吊友人丧妻，入门曰：“恭喜！”继曰：“四德俱无，七出咸备，鸣呼哀哉，大吉大利！”盖学士夫人亦悍也。
注：解学士：解缙，明初才子，曾官翰林学士，主编《永乐大典》。
注：四德：古代妇女应具备的妇德、妇言、妇容、妇功。
注：七出：古代丈夫休妻的七种理由：无子、淫佚、不事舅姑、口舌、盗窃、妒忌、恶疾。
注：鸣呼哀哉：祭文套语，表示悲痛。
注：大吉大利：吉利。
注：悍：凶悍。
# 不乐富贵
题解：引《韩非子》和王琰之妻事，说明妻子惟恐丈夫富贵纳妾，故不乐富贵，写妒妇的心理。
原：《韩非子》云：卫人有夫妻祷者而祝曰：“使我无故得百束布。”其夫曰：“何少也？”对曰：“益是，子将以买妾。”上谷都尉王琰以功封，其妻大哭于家。人问之。曰：“如此富贵，必更娶妾矣！”
注：《韩非子》：先秦法家著作，此段见《内储说下》。
注：祷：祈祷。
注：束布：成束的布。
注：益是：再多于此。
注：买妾：买来做妾。
注：上谷：郡名，在今河北西北部。
注：都尉：郡的武官。
注：王琰：待考。
# 竞宠
题解：郭子仪二姬争宠，一姬妒意未消，当场扫兴，皇帝听后一笑，写争宠之态。
原：郭尚父二姬竞宠。上赐金帛箸环，命宫人载酒和之。方欲歌以送酒，一姬畜怒犹盛，歌未发，遽引满置觞于席。曰：“酒尽，不须歌矣！”上闻笑之。
注：郭尚父：郭子仪，唐中兴名将，封汾阳王，号“尚父”。
注：竞宠：争夺宠爱。
注：箸环：筷子与环饰，指赏赐物品。
注：引满：满饮。
注：觞：酒杯。
# 面首
题解：山阴公主向宋前废帝要面首三十人，写皇家贵女的荒唐，亦是“不禁内”的一种。
原：宋文帝姊山阴公主，适何戢，谓帝曰：“陛下六宫数百，妾唯驸马一人，太不均！”帝笑为置面首三十人。
注：宋文帝：当作宋前废帝刘子业，山阴公主为其姐，文帝应为误。
注：山阴公主：刘楚玉，宋文帝之女，前废帝之姊。
注：何戢：南朝宋大臣，娶山阴公主。
注：六宫：皇后的六个宫室，泛指后宫。
注：面首：供贵妇人玩乐的美男子。
# 唐无家法
题解：本节两段：前段记武三思与韦后博戏、中宗在旁点筹；后段记唐玄宗与杨贵妃、安禄山的调笑，说明唐宫帷中无礼法。
原：武三思通于韦后，或升御床。与韦博戏。中宗从旁之典筹。
注：武三思：武则天侄，中宗朝权臣，与韦后私通。
注：韦后：唐中宗皇后韦氏，欲效武则天，后被李隆基诛杀。
注：御床：皇帝的坐床。
注：博戏：赌博游戏。
注：典筹：掌管筹码。
原：贵妃中酒，微露其乳。帝扪之，曰：“软温新剥鸡头肉。”安禄山在旁曰：“滑腻初凝寨上酥。”帝笑曰：“信是胡儿只识酥！”
注：贵妃：杨贵妃，唐玄宗宠妃。
注：中酒：醉酒。
注：鸡头肉：芡实的果肉，比喻白嫩。
注：安禄山：唐代胡人将领，安史之乱发动者。
注：寨上酥：当作塞上酥，塞外乳制品，酥油。
注：胡儿只识酥：讥安禄山为胡人，只知酥酪。
# 易内

注：内实：此处指姬妾，家室。

# 不禁内
题解：徐之才不防妻私、韩熙载设“自在窗”，写“不禁内”者的放达，与惧内形成对照。
原：北齐徐之才见其妻与男子私，仓惶走避，曰：“恐妨少年嬉笑。”南唐韩熙载，后房妓妾数十，房室侧建横窗，络以丝绳，为窥觇之地，旦暮亦不禁其出入。时人目为“自在窗”。若窃与诸生淫。熙载过之，笑而趋曰：“不敢阻兴！”或夜奔客寝，客赋诗有“最是五更留不住，向下枕畔著衣裳”之句。
注：徐之才：北齐名医，字士茂，善诙谐。
注：私：与人私通。
注：仓惶：慌张。
注：嬉笑：嬉戏玩笑。
注：韩熙载：五代南唐大臣，字叔言，以夜宴闻名。
注：窥觇：偷看。
注：络以丝绳：以丝绳连结窗格。
注：自在窗：形容自由自在的窗子。
注：诸生：读书人，此处指客人。
注：不敢阻兴：不敢妨碍你们的兴致。
注：五更：天快亮时。
注：著衣裳：穿衣服。
# 刘氏诗题
题解：许义方之妻刘氏自称端洁，以《月夜招邻僧闲话》诗露出破绽，写自欺欺人的妇人。
原：许义方妻刘氏，端洁自许。义方出经年，始归，语妻曰：“独处无聊，亦与邻里亲戚妪家往还乎？”刘曰：“自君之出，足未尝履阈。”义方谘叹不已，又问：“何以自娱？”答曰：“唯时作小诗以适情耳。”义方欣然索诗，观之，开卷第一题云《月夜招邻僧闲话》。
注：许义方：唐人，事见《太平广记》类笔记。
注：端洁：端正清白。
注：自许：自负。
注：出：外出。
注：妪家：老妇人家。
注：履阈：踏入门槛。
注：谘叹：叹息，谘同“咨”。
注：自娱：自我消遣。
注：适情：抒发情怀。
注：月夜招邻僧闲话：诗题，暗指刘氏与邻僧有私，笑点在此。
