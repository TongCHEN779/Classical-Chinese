# 正文
题解：《微词部》总序，论口舌之用，谓讽刺含蓄而不违、不谤，编为第三十。
原：〔子犹曰：人之口，含阴而吐阳。阳也而阴用之，则违之而非规，抑之而非谤，刺之而非怨，嫉之而非仇，上可以代虞人之箴，而下亦可以舆人之诵。夫是非与利害之心交明，其术不得出乎此；馀此《春秋》定、哀之际三致意焉。集《微词》第三十。〕
注：子犹：冯梦龙之号。
注：含阴而吐阳：口为阴阳之所，此处指言辞内含褒贬而外示温和。
注：违之而非规：意谓违背而不是规谏，委婉讽刺而不直言。
注：虞人之箴：《左传·襄公四年》载虞人作箴以谏，《虞人之箴》。
注：舆人之诵：《左传·僖公二十八年》“听舆人之诵”，指众人的讽诵。
注：定、哀之际三致意焉：《公羊传》称孔子作《春秋》，于定公、哀公之世多用隐微之辞，故云“三致意”。
注：微词：含蓄委婉的批评，为《古今谭概》第三十部。
# 凌阳台
题解：孔子借陈惠公筑凌阳台之事，婉讽其滥杀工匠，使其赦吏。
原：陈惠公大城，因起凌阳之台，未终而坐法死者数十人，又执三监吏。孔子适陈，闻之，见陈侯，与俱登台而观焉。孔子曰：“美哉台也！贤哉王也！自古圣王之为城台，焉有不戮一人而能致功若此者！”陈候阴使人赦所执吏。见《孔丛子》。
注：陈惠公：陈国国君，此处时代待考。
注：凌阳之台：高台名。
注：坐法：因触犯法律而获罪。
注：三监吏：负责监工的三名官吏。
注：孔子适陈：孔子曾适陈，后人史载为陈湣公时。
注：致功：成功。
注：孔丛子：旧题孔鲋撰，记孔子及其子孙言行。
# 支解人
题解：晏子借问“从何支始”，讽谏齐景公止杀。
原：齐景公时，民有得罪者。公怒，缚至殿下，召左右支解之。晏子左手持头，右手持刀而问曰：“古明主支解人，从何支始？”景公离席曰：“纵之！”
注：晏子：晏婴，齐国名相，事迹见《晏子春秋》。
注：齐景公：春秋齐国国君。
注：支解：肢解，古酷刑。
注：离席：起身离座，表示惶恐。
注：纵之：放了他。
# 枉死人面
题解：郑涉借“看枉死人面”劝刘玄佐赦翟行恭。
原：刘玄佐镇汴，尝以谗欲杀军将翟行恭，无敢辩者。处士郑涉能谐隐，见玄佐曰：“闻翟行恭抵刑，付尸一观。”玄佐怪之。对曰：“尝闻枉死人面有异，一生未识，故借看耳。”玄佐悟，乃免。
注：刘玄佐：唐德宗时宣武军节度使，镇汴州（今河南开封）。
注：军将：军官。
注：翟行恭：待考。
注：谐隐：谐谑隐语，以委婉方式进言。
注：处士：有才德而不仕之人。
注：抵刑：被处刑。
注：枉死人：被冤死之人。
# 油衣
题解：谷那律以“以瓦为之”讽高宗田猎。
原：高宗出猎遇雨，问谏议大夫谷那律曰：“油衣若为不漏？”对曰：“以瓦为之则不漏。”上因此不复出错。
注：高宗：唐高宗李治。
注：谏议大夫：谏官，掌谏诤。
注：谷那律：唐初大臣，博学，以直谏著称，有“九经库”之称。
注：油衣：涂油防雨的衣物。
注：以瓦为之：以瓦为雨衣则不漏雨，言外之意要降低出猎。
# 抽税
题解：申渐高以“雨不敢入城，惧抽税耳”讽税繁重。
原：南唐时，关司敛率繁重，商人苦之。属畿甸亢旱，烈祖宴于北苑，谓群臣曰：“外境皆雨，独不及都城，何也？”申渐高曰：“雨不敢入城，惧抽税耳。”烈祖大笑，即除之。
注：烈祖：南唐烈祖李昪。
注：关司：关卡税务官。
注：敛率：征税。
注：畿甸：国都附近地区。
注：北苑：宫中园林名，在南京。
注：申渐高：南唐伶人，滑稽。
注：抽税：征税，此处指关津抽税。
# 使宅鱼
题解：罗隐以“使宅鱼”诗讽钱镠，免渔民之征。
原：钱氏时，西湖渔者日纳鱼数斤，谓之使宅鱼；有不及数者，必市以供。颇为民害。罗隐侍坐，壁间有《磻溪垂钩图》，武肃指示隐索诗。隐应声曰：“吕望当年展庙谟，直钩钓国更谁知。若教生在西湖上，也是须供使宅鱼。”武肃王大笑，遂蠲其征。
注：钱氏：吴越王钱氏，此指钱镠。
注：使宅：节度使官署。
注：使宅鱼：每日向使宅献鱼，渔者苦之。
注：罗隐：晚唐诗人，余杭人，吴越钱镠幕僚，诙谐有讽。
注：磻溪垂钩图：姜太公在磻溪垂钓的画。
注：武肃：钱镠谥武肃，吴越国王。
注：吕望：姜太公，字子牙，吕氏，号太公望。
注：直钩钓国：姜太公用直钩钓鱼，愿者上钩，终得周文王重用。
注：蠲：免除。
# 臣书帝书
题解：王僧虔对齐高帝“臣书臣中第一”之答，以语巧自保。
原：齐高帝尝与王僧虔书，毕，帝曰：“谁为第一？”僧虔曰：“臣书臣中第一，陛下书帝中第一。”帝大笑曰：“卿善自谋。”
注：齐高帝：南朝齐开国皇帝萧道成，善书。
注：王僧虔：南朝书法家，琅琊王氏，官至侍中。
注：善自谋：善于为自己谋划，即巧于自保。
# 徘徊
题解：教坊杂剧以“徘徊”讽“徘徊”之诗。
原：仁宗赏花钓鱼宴，锡诗，馆阁侍从和篇，皆押徘徊字。诗罢就坐。教坊进杂剧，为数人寻税第者，诣一宅观之，至前堂，观玩不去。问其所以，曰：“徘徊也。”又至后堂、东西序，复然。问之，则又曰：“徘徊也。”其一人笑曰：“可则可矣，但未免徘徊太多耳！”
注：赏花钓鱼宴：宋代宫中宴，每春在后苑赏花钓鱼。
注：锡诗：皇帝赐诗。
注：馆阁侍从：馆阁官员，指翰林学士等。
注：押徘徊字：以“徘徊”二字为韵脚。
注：教坊：官署名，掌宫廷乐舞。
注：杂剧：宋代滑稽戏，一种短剧。
注：税第：租房。
注：序：东西厢房。
注：徘徊：来回走动，此处影射词臣皆押“徘徊”之韵。
# 二胜环
题解：伶人以“二胜环俱放在脑后”讽高宗不思二帝。
原：绍兴初，杨存中在建康，诸军之旗中有双胜交环，谓这“二胜环”，取两宫北还之意。因得美玉，琢成帽环以进，高庙日常御裹。偶有一伶人在傍，高宗指示环示之：“此杨太尉进来，名二胜环。”伶人接奏云：“可惜二胜环俱放在脑后。”高宗为之改色。此所谓“工执艺事以谏”者也。
注：杨存中：南宋名将，本名杨沂中，字正甫，官太尉。
注：建康：今南京。
注：双胜交环：二胜环，即两个环交叠。
注：两宫北还：徽、钦二帝还朝，“两宫”指徽宗、钦宗。
注：高庙：高宗庙号，此指宋高宗。
注：御裹：皇帝所戴头巾。
注：二胜环俱放在脑后：谐“二圣还”，言“二圣”（徽、钦）不在心上，讥高宗不思迎还。
注：工执艺事以谏：《左传·襄公十四年》“工执艺事以谏”，乐工以技艺劝谏。
# 馄饨不熟
题解：伶人以“合下大理”戏高宗赦厨师之罪。
原：高宗时，饔人瀹馄饨不熟，下大理寺。优人扮两士人相貌，各问其年。一曰“甲子生”，一曰“丙子生”。优人告“合下大理”。帝问故。优人曰：“𩚲子饼子皆生，与馄饨不熟者同罪耳。”上大笑，赦原饔人。
注：饔人：厨师。
注：瀹：煮。
注：馄饨：一种面食。
注：大理寺：掌刑狱的官署。
注：甲子生：谐“饺子生”，饺子未熟。
注：丙子生：谐“饼子生”，饼子未熟。
注：𩚲子饼子：𩚲即饺，生熟之“生”与“生年”之“生”双关。
注：原：宽免。
# 当十钱
题解：伶人以买水喻当十钱之弊。
原：宣和间，用当十钱。伶人以为当十钱买水者，水一杯一钱，于是必令饮十杯，至于委顿。上见之笑，遂废不用。
注：宣和：宋徽宗年号（1119—1125）。
注：当十钱：一枚当十钱使用的大钱，北宋崇宁年间发行，币值虚高。
注：委顿：疲惫困顿。
# 芭蕉
题解：焦德借“巴蕉”讽宫苑花木取自远方。
原：宣和间，乐部焦德以谐谑被遇，时借以讽谏。一日，从幸禁苑。上指花竹草木以询其名。德曰：“皆巴蕉也。”上诘之。对曰：“禁苑花竹，皆取于四方。道里远涉，巴至上林，则已焦也。”上大笑。
注：乐部：宫中乐工机构。
注：焦德：宋徽宗时乐工，待考。
注：被遇：被皇帝赏识。
注：巴蕉：芭蕉，“巴”指巴蜀，“蕉”谐“焦”。
注：上林：汉代宫苑名，借指宫苑。
# 阿丑
题解：阿丑以院本讽朝政，影射汪直之党羽。
原：成化末，刑政多频。阿丑于上前作六部差遣状，命精择之。一人云：“姓公名论。”主者曰：“公论如今无用。”一人曰：“姓公名道。”主者曰：“公道如今难行。”后一人曰：“姓胡名涂。”主者曰：“胡涂如今尽去得。”
注：成化：明宪宗年号（1465—1487）。
注：阿丑：成化年间宫中宦官，善演院本。
注：六部差遣状：六部官员选授差遣的文书。
注：姓公名论：以姓名双关，“公论”。
注：姓公名道：“公道”。
注：姓胡名涂：“胡涂”即糊涂，三名合讽朝政无公论、无公道、糊涂当道。
原：中官阿丑每于上前作院本。时王赵、陈钺媚汪直，结为死党。丑作直持双斧趋跄而行。或问故。曰：“吾将兵唯仗此两钺耳！”问钺何名。曰：“王越、陈钺也！”
注：中官：宦官。
注：院本：金元时的戏曲脚本，此指宫廷滑稽戏。
注：王赵：疑当作“王越”，王越与陈钺。
注：陈钺：成化时官辽东巡抚，附汪直。
注：汪直：成化间宦官，掌西厂，权倾一时。
注：趋跄：快步走。
注：钺：斧头，指兵器；“王越”“陈钺”谐“两钺”。
# 和峤
题解：和峤婉言太子质愚。
原：和峤为武帝所亲重。语峤曰：“东宫顷似差进，卿试往看。”还，问何如。答曰：“皇太子圣质如初。”
注：和峤：西晋人，字长舆，晋武帝时官中书令，曾劝谏太子。
注：武帝：晋武帝司马炎。
注：东宫：太子居所，此指太子司马衷（后为惠帝）。
注：圣质如初：太子资质一如从前，言外之意仍愚笨。
# 李纬须
题解：唐太宗调侃李纬“好须”，改授太子詹事。
原：唐太宗以李纬为民部尚书。会有自京师来者，帝曰：“玄龄闻纬为尚书谓何？”曰：“唯称纬好须，无他语。”帝遽改太子詹事。
注：李纬：唐初大臣，贞观中任民部尚书（户部）。
注：民部尚书：民部即后之户部。
注：玄龄：房玄龄，唐初名相，时留守京师。
注：太子詹事：东宫属官，掌东宫事务。
# 三百里湖
题解：徐铉答冯谧，借“三百里湖”讽“所乏者贺知章”。
原：南唐冯谧，尝对诸阁老言及玄宗赐贺知章三百里湖事，因曰：他日赐归，得宗武湖二十里足矣。”徐铉答曰：“主上尊贤下士，岂爱一湖？所乏者，贺知章耳。”众大笑。
注：冯谧：南唐大臣，官至兵部尚书，后降宋。
注：阁老：对翰林学士、宰相的敬称。
注：贺知章：唐代诗人，官秘书监，晚年请为道士还乡，玄宗赐镜湖剡川一曲。
注：徐铉：南唐文臣，后入宋，精文字学。
注：宗武湖：待考，疑指南唐宫苑湖名。
# 刺李西涯
题解：刘大夏、李东阳二事，借“记大功德”讽李东阳为刘瑾撰碑。
原：刘大夏自作《寿藏记》。李西涯戏云：“天下皆如公，翰林文章无用也。”公曰：“先生辈文章宜记大功德者，予何敢相累哉？”盖西涯先为刘瑾作碑文，公嘲之也。
注：刘大夏：明弘治时兵部尚书，字时雍，号东山。
注：寿藏记：生前为自己作的墓志，寿藏即生前预造之墓。
注：李西涯：李东阳。
注：刘瑾：正德初宦官，权倾朝野，被诛。
注：嘲：讥刺。
原：正德间，大臣议攻刘瑾，李西涯俯首不语。后刘健、谢迁被斥，李祖道涕泣。刘曰：“当日出一语，不用今日泣也。”又吕柟斥回，陆完亦祖道相送。陆曰：“公去矣，予亦将行。”吕曰：“如真去，我在三十里外相候。”
注：刘健、谢迁：明弘治、正德时内阁大臣，因反对刘瑾被斥。
注：祖道：设宴送行。
注：吕柟：明代理学家，字仲木，号泾野，因直言被贬。
注：陆完：明代官员，字全卿，官至兵部尚书，后因宁王事被贬。
# 文潞公
题解：文彦博八十四再起，刘贡父借语讥刺郑穆。
原：文潞公八十四再起，时学士郑穆表请致仕。刘贡父为给事中，问同舍曰：“郑年若干？”答曰：“七十三。”刘遽云：“莫遂其请，且留取伴八十四底。”潞公闻之，甚不怿。
注：文潞公：文彦博，封潞国公，历仕仁、英、神、哲四朝。
注：八十四再起：元祐初文彦博以太师平章军国重事再入朝。
注：郑穆：北宋人，字闳中，福州人，官至国子祭酒。
注：致仕：退休。
注：刘贡父：刘攽。
注：给事中：门下省官员，掌封驳诏令。
注：同舍：同僚。
注：且留取伴八十四底：意谓不必准郑穆退休，留下来陪伴八十四岁的文彦博，讥文彦博年老不退。
# 锯匠诗
题解：赵东山以锯匠诗讽两挚友的求官。
原：赵东山里有二挚友，其一因投荒过家，其一以磨勘需调，皆栖栖桑榆，犹恋鸡肋者。一日同访东山，见庭下有锯匠解木，因以命题。东山口占绝句曰：“一条黑路两人忙，傍晚相看鬓已霜。你去我来何日了，亏他扯拽度时光”二挚手知诗意讽已，相与感叹罢去。
注：赵东山：待考。
注：投荒：被贬至荒远之地。
注：磨勘：宋代对官员政绩的考核，有任满铨选之制。
注：栖栖：忙碌不安貌。
注：桑榆：晚年。
注：鸡肋：《三国志》注引《九州春秋》，曹操以“鸡肋”喻弃之可惜、食之无味。
注：口占：随口吟诵。
注：扯拽：拉锯。
# 远志
题解：郝隆借“远志”“小草”讥谢安出仕。
原：谢公始有东山之志，后就桓公司马。会有饷桓公药，中有远志。醒取以问谢：“此药又名小草。何一物有二称？”谢未及答，郝隆在座，应声曰：“此甚易解：处则为远志，出则为小草。”谢有愧色。
注：谢公：谢安，东晋名相，初隐东山。
注：东山之志：隐居之志。
注：桓公：桓温，东晋权臣，曾辟谢安为司马。
注：远志：药名，又名小草。
注：郝隆：东晋人，桓温幕僚，有才，诙谐。
注：处则为远志，出则为小草：《世说新语·排调》载郝隆语，讥谢安出仕。
# 兔册
题解：刘岳讥冯道“忘持《兔册》”，因其貌陋如乡塾教师。
原：冯道形神庸陋，及为宰相，士人多笑之。刘岳与任赞偶语，见道行而复顾，赞曰：“新相回顾何也？”岳曰：“定见忘持《兔册》来。”北中村墅，多《多园册》训蒙，以是讥之。
注：冯道：五代时人，历仕四朝十君，自号长乐老。
注：刘岳：后唐、后晋官员，字昭辅，官至礼部尚书。
注：任赞：后晋官员，待考。
注：兔册：《兔园册》，乡村蒙学读物，唐代杜嗣先撰，北方村塾多用。
注：训蒙：教童蒙。
# 刺严相
题解：王世贞以《大学》“十目所视，十手所指”刺严嵩。
原：世庙时，宫中尝见鬼，多手多目。以问张真人，张不能对。或以王元美博识，往询之。元美曰：“何必博识？《大学》云：“‘十目所视，十手所指’，是说甚么？”盖刺严相也。严闻而衔之。
注：世庙：明世宗嘉靖帝庙号。
注：张真人：龙虎山正一道天师，明代历代受封“真人”。
注：王元美：王世贞，字元美。
注：十目所视，十手所指：《大学》“十目所视，十手所指，其严乎”，“严”指严嵩，双关。
注：严相：严嵩，嘉靖朝首辅。
注：衔：怀恨。
# 题何吉阳轴
题解：某黄庠士题诗何迁画轴，讽其恭顺严嵩。
原：何吉阳迁，故与黄庠士某以学问友善。吉阳巡抚江西，过家。某青衫来谒，门者不即为通，因散步堂上，环视壁间悬轴，其首则严分宜笔也。遂索前刺，书一绝曰：“椒山已死虹塘谪，天下维人是介翁？今日华堂诵诗草，始知公度却能容。”嘱门者投之，遽拂衣去。吉阳得诗自惭，亟遣追之，舟去远矣。
注：何吉阳迁：何迁，字益之，号吉阳，明嘉靖进士，官至南京刑部尚书。
注：黄庠士：待考，疑为庠生。
注：青衫：下级官员或生员穿的衣服。
注：门者：守门人。
注：严分宜：严嵩，江西分宜人。
注：刺：名帖。
注：椒山：杨继盛号椒山，因弹劾严嵩被杀。
注：虹塘谪：虹塘待考。
注：介翁：待考。
注：公度：指何迁字，待考。
注：亟：急。
# 二相公庙
题解：苏轼戏称韩氏堂为“二相公庙”。
原：韩持国兄弟皆拜相，客欲扁其堂为“三相”。俄持国罢相。东坡戏之曰：“今只可云‘二相公庙’矣！”
注：韩持国：韩维，字持国，北宋大臣，官至门下侍郎。
注：扁：作匾额。
注：三相：指韩氏兄弟三人拜相，与史实略有出入（韩维官至门下侍郎）。
注：二相公庙：拜相者缩为二人，戏称“二相公庙”。
# 荆公水利
题解：刘贡父以“别穿一梁山泊”讥王安石水利之议。
原：王介甫为相，大谋天下水利。刘贡父尝造之，值一客献策曰：“梁山泊沃而涸之，可得良田万顷，但未择得利便之地诸许水耳。”介甫倾首沉思。贡父抗声曰：“此甚不难！”介甫欣然以为有策，遽问之。曰：“别穿一梁山泊，则足以贮此水矣！”介甫大笑，遂止。
注：王介甫：王安石。
注：水利：王安石新法中的农田水利法。
注：梁山泊：古水泊，在今山东梁山一带，宋代范围广大。
注：沃：灌溉；涸：干。
注：抗声：高声。
# 蝗虫感德
题解：刘贡父诗讽王安石罢相仍有蝗灾，言“蝗虫感德”。
原：王荆公罢相，出镇金陵。时飞蝗自北而南，江南诸郡皆有之。百官饯王于城外。刘贡父后至，追之不及，见其行塌上有一书屏，因书一绝以寄之，云：“青苗助役两妨农，天下嗷嗷怨相公。唯有蝗虫感德，又随车骑过江东。”
注：荆公：王安石。
注：出镇金陵：王安石熙宁九年罢相，判江宁府。
注：飞蝗：蝗虫成群飞行。
注：饯：设宴送行。
注：塌：床榻，此处指行舟或车上的榻。
注：青苗助役：王安石新法中的青苗法、助役（免役）法。
注：嗷嗷：哀鸣之声。
注：蝗虫感德：以蝗虫随车骑讥王安石新法为害。
# 刺章子厚
题解：林特借画工故事讥章惇。
原：章子厚生辰会客，门人林特以诗为寿。客指诵德处工。特颇不平，忽曰：“昔有令画工传神，以其不似，命别为之。凡三四易，画工怒曰：‘若画得似，是甚模样！’”满席烘然。
注：章子厚：章惇，字子厚，北宋宰相，新党，后贬雷州。
注：门人：门下之客。
注：林特：待考。
注：寿：祝寿诗。
注：传神：画像，写真。
注：烘然：哄堂大笑。
原：苏长公在惠州，天下传其已死。后七年，北归，时章丞相方贬雷州。东坡见南昌太守叶祖洽。叶问曰：“世传端明已归道山，今尚尔游戏人间耶？”坡曰：“途中见章子厚，乃回反耳。”
注：苏长公：苏轼，苏氏兄弟之长。
注：章丞相：章惇，时贬雷州。
注：南昌太守叶祖洽：叶祖洽，北宋人，英宗治平年间状元。
注：端明：苏轼曾官端明殿学士，故称。
注：道山：仙山，此处指死亡。
注：回反：疑为“反复”之意，待考。
# 夏言
题解：夏言借“搬去礼部”戏谐郭勋，竟成入阁之兆。
原：夏言在礼部时，内阁唯李时一人，夏日夕望入阁。修九庙𤮉㼾㼧𤭧不堪者，皆运积东长安街侧，多为有力者潜取用。李时偶与郭武定勋言：𤮉㼾类旧皆满目，今何其零落？”郭笑曰：“熟敢窃？皆夏宗伯搬去礼部，躧以望内阁耳。”言虽戏，实得夏心。是年终，夏遂入阁。
注：夏言：明嘉靖朝首辅，字公谨，号桂洲，后被严嵩构陷。
注：礼部：掌礼仪科举的官署，夏言时任礼部尚书。
注：李时：嘉靖朝内阁大学士。
注：九庙：宗庙，明初始建九庙。
注：郭武定勋：郭勋，封武定侯，嘉靖朝权贵。
注：夏宗伯：宗伯指礼部尚书，夏言。
注：躧：拖着鞋。
注：入阁：入内阁，任大学士。
# 神童
题解：屠应诶以“年晚生”戏赵司寇。
原：赵司寇乃费阁老同年，每投揭，书“年晚生”。屠应诶曰：“赵老真神童！”人问其故。云：“费鹤湖二十作状元，年最少。今渠称‘年晚生’，非神童而何？”
注：赵司寇：司寇即刑部尚书，赵姓，待考。
注：费阁老：费宏，字子充，号鹤湖，成化二十三年状元，官至首辅。
注：同年：同榜进士。
注：投揭：投递名帖。
注：年晚生：晚辈对同年中年长者的自称，实际费宏年少，故说“神童”。
注：屠应诶：待考。
# 束玉
题解：内臣见席书束玉，故作不识，讥其骤贵。
原：嘉靖间，席都御史书以议大礼称旨，擢礼部尚书，洊加少保兼太子太保。一内臣见其束玉，阳为不识，曰：“此带无乃大理石所为？”
注：席都御史书：席书，字文同，号元山，嘉靖初因议大礼，支持世宗，擢礼部尚书。
注：议大礼：嘉靖初关于世宗生父尊号的争论。
注：洊加：屡次加封。
注：少保兼太子太保：加官，名义上的荣衔。
注：内臣：宦官。
注：束玉：玉带，高官佩带。
注：大理石：云南大理出产的石头，质地不及真玉。

原：穆宗登极，诏五品以上致政者进阶一级。有一州守被革者，遂被称朝列大夫，衣金紫。其弟亦大僚，忽莞尔曰：“恨不数赦，吾兄且腰玉矣！”
注：穆宗：明穆宗隆庆帝。
注：登极：即位。
注：致政：退休，此指致仕。
注：朝列大夫：文散官名，从五品。
注：金紫：金鱼袋与紫袍，指高官服饰。
注：大僚：高官。
注：莞尔：微笑。
注：腰玉：佩玉带。
# 讳出外
题解：王仲荀以“出外”讳语之事。
原：熙宁中，王仲荀谒一朝士，阍者以不在辞之。王勃然叱曰：“凡人死称不在，汝乃敢出此言！”阍者拱谢曰：“然则当何辞？”王曰：“第云出外可也。”阍者愀然蹙额曰：“我主宁死，讳却出外字面。”
注：熙宁：宋神宗年号（1068—1077）。
注：王仲荀：待考。
注：朝士：朝廷官员。
注：阍者：守门人。
注：勃然：突然。
注：愀然蹙额：忧愁皱眉。
注：讳却出外字面：忌讳“出外”二字（疑谐“出”“外”，指出而不返）。
# 清凉散
题解：刘筠称疾，石中立戏谓“清凉散”。
原：刘子仪不能大用，称疾不出。朝士问疾。刘云：“虚热上攻。”石文定在座，云：“只消一把清凉散。”
注：刘子仪：刘筠，字子仪，北宋文学家，与杨亿齐名。
注：石文定：疑指石中立，待考。
注：清凉散：清热解暑之药，此处讽刘子仪“虚热上攻”，戏言需清凉。
# 束薪监案
题解：赵仁奖以一束薪拜官，宋务光戏之。
原：唐赵仁奖在王戎墓侧，善歌《黄獐》。景龙中，负薪一束诣阙，云：“助国调鼎。”即除台官。中书令姚崇曰：“此是黄獐耶？”授以当州一尉。惟以黄獐自炫。宋务光嘲之曰：“赵仁奖出王戎墓下，入朱幄台中。舍彼负薪，登兹列指。行人不避骢马，坐客惟听黄獐。”有顷见一夫负两束薪。宋指曰：“此合拜殿中。”人问其由。曰：“赵以一束拜监察，此两束，岂不合授殿中？”
注：赵仁奖：待考。
注：王戎：晋代名士，竹林七贤之一，王戎墓在今山东邹县，传说赵仁奖善唱《黄獐》。
注：黄獐：唐代民间歌曲名。
注：景龙：唐中宗年号（707—710）。
注：助国调鼎：协助朝廷执政，调鼎比喻宰相。
注：姚崇：唐玄宗朝名相，此时官中书令。
注：当州一尉：本州县尉。
注：宋务光：唐初文士，官至监察御史，待考。
注：骢马：御史所乘之马，指御史。
注：殿中：殿中侍御史。
注：监察：监察御史。
# 不语唾
题解：孙御医以“不语唾”治疥讽言官失声。
原：宪庙永年，言官噤不敢言朝事。孙御医者，素善谑。人问：“生疥何以愈之？”曰：“请六科给事中舔之。”人问故。曰：“不语唾，可治疥也。”
注：宪庙：明宪宗庙号。
注：言官：给事中、御史等监察官。
注：孙御医：待考。
注：六科：吏、户、礼、兵、刑、工六科，设给事中。
注：不语唾：旧传晨起未语之唾可治疥疮，故称。

注：武儒衡：中唐大臣，武元衡之弟。
注：无稹：疑当作“元稹”，中唐诗人，字微之，曾因宦官崔潭峻之助入翰林。
注：寅缘：攀缘。
注：知制诰：掌起草诏令，唐代中书省属官。
注：绳集：苍蝇聚集。
# 有气力

原：崔湜为吏部侍郎，掌铨。有选人自陈：“某能翘关负米。”湜曰：“若壮，何不兵部选？”答曰：“外人皆云，崔侍郎下有气力者便得。”
注：崔湜：唐睿宗时吏部侍郎，字澄澜，依附权贵，后被杀。
注：掌铨：掌管选官。
注：翘关：举起门闩，以练力，唐代武举有“翘关”科。
注：负米：背米，武举项目。
注：兵部选：武举由兵部主持。
# 泰山之力
题解：黄幡绰戏称“泰山之力”，岳丈称“泰山”本此。
原：张说婿郑鉴，随上封禅，以九品骤至五品。黄幡绰戏曰：“此乃泰山之力也！”泰山有丈人峰，故云。后人称妇翁，本此。
注：张说：唐玄宗朝名相。
注：郑鉴：张说女婿，因封禅升五品，此作“郑鉴”，史作“郑镒”，待考。
注：封禅：古帝王祭天地的大典，开元十三年（725）玄宗封禅泰山。
注：泰山之力：谐“岳丈（泰山）之力”。
注：丈人峰：泰山之峰，故以“泰山”称岳父。
注：妇翁：妻之父。
# 安石配享
题解：优人戏演王安石配享孔庙，借孔门人物讥蔡卞。
原：初，崇宁既建辟雍，诏以荆公封舒王，配享宣圣庙，肇创坐像。未几其婿蔡卞方烜赫用事，议欲升安石于孟子之上，优人尝因对御戏，为孔子正坐，颜、孟与安石侍侧。孔子命之坐，安石揖孟子居上。猛辞曰：“天上达尊，爵居其一。轲仅蒙公爵，相公贵为真正，何必谦光如此？”遂揖颜子。颜曰：“回也陋巷匹夫，平生无分毫事业。公为名世真儒，位貌其间，辞之过矣。”安石遂处其上。夫子不能安席，亦逊位。安石惶惧，拱手云：“不敢。”往复未决，子路在外，愤愤不能堪，径趋从祀堂，挽公治长臂而出。公治为窘迫之状，谢曰：“长何罪？”乃责数之曰：“汝全不救护丈人，看取别人家女婿！”其意以讥卞也。
注：崇宁：宋徽宗年号（1102—1106）。
注：辟雍：太学。
注：舒王：王安石追封舒王。
注：宣圣庙：孔庙，唐封孔子为文宣王。
注：蔡卞：王安石女婿，蔡京之弟，权倾一时。
注：烜赫：显赫。
注：天上达尊，爵居其一：《孟子·公孙丑下》“天下有达尊三：爵一，齿一，德一”，此处作“天上”。
注：轲：孟子名轲。
注：公爵：孟子封邹国公。
注：相公贵为真正：王安石为宰相，封舒王，故称“真正”。
注：谦光：谦逊。
注：颜子：颜回，孔子弟子。
注：陋巷匹夫：《论语·雍也》“回也……在陋巷”。
注：名世真儒：当世名儒。
注：子路：孔子弟子，性刚勇。
注：公治长：孔子弟子，孔子以女妻之。
注：丈人：岳丈，指孔子。
注：看取别人家女婿：“蔡卞为王安石女婿”，讥其助岳丈上座而不顾孔子。
# 钻弥远
题解：优人借《论语》“钻”字讥史弥远用事。
原：史丞相弥远用事，选者改官，多出其门。一日制阃设宴，优人扮颜回、宰予。予问回曰：“汝改乎？”曰：“回也不改。”回曰：“汝何独改？”予曰：“钻遂改。汝何不钻？”回曰：“非不钻，但钻之弥坚耳。”予曰：“钻差矣。何不钻弥远？”
注：史丞相弥远：史弥远，南宋宁宗、理宗朝权相，专权二十余年。
注：选者：待选的官员，选人改官须通过史弥远。
注：制阃：制置使，此处指统军官署。
注：宰予：孔子弟子，“昼寝”者。
注：回也不改：《论语·雍也》“回也不改其乐”，此处借“不改”官阶。
注：钻之弥坚：《论语·子罕》颜渊喟然叹“仰之弥高，钻之弥坚”，“钻”谐“钻营”。
注：弥远：史弥远，与“钻之弥坚”之“弥”双关。
# 孔门弟子
题解：优人借孔门弟子扮选人，讥选人淹滞。
原：嘉定间，选人淹滞。遇内宴，优人扮古衣冠数人，皆称待选，系是孔门弟子。即而通名，有曰“常从事”者，有曰“于从政”者，有曰“吾将仁”者，各相叹惋，曰：“吾辈久淹于此，日用逝矣，奈何！”旁有一人谓曰：“汝等不在七十二人之列，盍诣颜、闵而请教焉？”诸人一时俱往。颜、闵同声答曰：“此夫子事，尔辈须见夫子。”及进见祈哀，夫子不答。众人因退，而相谓曰：“钻燧改火，期可已矣。吾辈有文学，且留中国教授。有圭田者，不若退而耕于野也。”于是烘然而散。
注：嘉定：宋宁宗年号（1208—1224），史弥远专权时期。
注：选人：宋官阶中的低级官员，需“改官”方能升迁。
注：内宴：宫中宴会。
注：常从事：以“从事”之语改写，扣《论语》“从事于斯矣”。
注：于从政：“于从政乎何有”，《论语·雍也》。
注：吾将仁：谐《论语·阳货》“吾将仕矣”，“仕”误“仁”，戏言。
注：颜、闵：颜回、闵子骞，孔门德行科。
注：夫子：孔子。
注：钻燧改火，期可已矣：《论语·阳货》宰我问三年之丧，“钻燧改火，期可已矣”；“钻”谐钻营，“改火”谐“改官”。
注：文学：孔门四科之一，指子游、子夏。
注：中国教授：京城教授。
注：圭田：《孟子》“卿以下必有圭田”，此处讥选人不如退耕。
# 韩侂胄
题解：韩侂胄兄弟专权，伶人借算命、卖伞之谑讥之。
原：韩侂胄兄弟专权。优人为日者。有问官禄之期，日者厉声曰：“若要大官，须到大寨！要小官，须到小寨！”
注：韩侂胄：南宋宁宗朝权臣，封平原郡王，发动开禧北伐，后被杀。
注：日者：占卜者。
注：官禄之期：官运期限。
注：大寨：谐“大宰”，指大官。
注：小寨：谐“小宰”，指小官。
原：嘉泰末年，平原公恃有扶日之功，凡事自作威福，政事皆不由内出。会内宴，伶人王公瑾曰：“今日政如客人卖伞，不油里面。”
注：嘉泰：宋宁宗年号（1201—1204）。
注：平原公：韩侂胄封平原郡王。
注：扶日之功：扶佐宁宗即位，“日”喻皇帝。
注：内宴：宫中宴。
注：王公瑾：宁宗时伶人，待考。
注：客人卖伞，不油里面：谐“不由里面”，意谓政事不由宫内（皇帝）作出。
# 五经题
题解：程敏政鬻题，被优人戏谓“五更啼”。
原：孝宗时，程学士敏政主试，鬻题。优人持鸡出曰：“此鸡价值千金。”问曰：“何鸡而价高如此？”对曰：“程学士家名为五更啼也！”
注：孝宗：明孝宗弘治帝。
注：程学士敏政：程敏政，字克勤，弘治十二年会试主考，因泄题案下狱。
注：鬻题：出卖考题。
注：五更啼：鸡五更而啼，“五经题”谐“五更啼”。
# 头场题
题解：万历丙午浙江乡试，有人买得头场试题中式，郡守设宴令优人演戏暗讥，以“古董”谐中式者姓董。
原：万历丙午浙试，一有力者以钱神买初场题中试。立试者锁闱日，得罪杭郡公，郡公衔之。撤棘后，郡公宴主试，密令优人刺之。其日演《荆钗记》，无从发挥。至“至承局寄书”出，李成问：“足下何来？”局答曰：“京城来。”成曰：“有新闻否？”曰：“关白内款矣。”成曰：“旧闻。”曰：“贡方物矣。”成曰：“何物？”曰：“一猪。”成曰：“猪何奇而贡之？”曰：“绝大。”成曰：“驴大乎？”曰：“不止。”“牛大乎？”又曰：“不止。”“象大乎？”又曰： “不止。”成曰：“大无过此矣！”曰：“大不可信。且无论其全体，只猪头、猪肠、猪蹄，你道易价几何？”成曰：“多少？”曰：“只头肠蹄亦卖千金！”成曰：“何人买得起？”曰：“一收古董人家。”盖指中式者董姓耳。主试闻之，赤颊，不欢而罢。
注：万历丙午：万历三十四年（1606）。浙试：浙江乡试。
注：钱神：钱的拟人化，晋鲁褒《钱神论》，此指金钱。
注：初场题：乡试头场所考四书、五经之题。
注：锁闱：考官入闱后锁院，不得外出。
注：杭郡公：杭州知府。
注：撤棘：考试结束，撤去围院的棘篱。
注：主试：主考官。
注：荆钗记：南戏，写王十朋与钱玉莲事。
注：承局：宋元官署中的差役、使者，此处指戏中送信人。
注：李成：《荆钗记》中的人物，待考。
注：关白：指日本丰臣秀吉，日本官职关白；万历年间日本侵朝，明廷与之交涉。
注：内款：求和、款附。
注：贡方物：进贡本地特产。
注：古董：谐“董”姓，以“一收古董人家”暗指中式者姓董。
注：赤颊：脸红。
# 锺庸大鹤
题解：临安优人戏演“锺庸”与“大鹤”，讥魏了翁及理学。
原：魏了翁既当路，未及有经略而罢。临安优人装一生儒，手持一鹤。另一生儒与之邂逅，问其姓名，曰：“姓锺名庸。”问所持何物。曰：“大鹤也。”因倾盖欢然，呼酒对饮。其人大嚼洪吸，酒肉靡有孑遗，忽颠扑于地，群数人曳之不动。一人乃批其颊，大骂曰：“说甚《中庸》、《大学》，吃了许多酒食，一动也不动不得！”遂一笑而罢。或谓有使其为此以姗侮君子者，京尹乃悉黥其人。
注：魏了翁：南宋理学家，字华父，号鹤山，嘉定间官至礼部尚书、同知枢密院事。
注：当路：执掌政权。
注：经略：筹划经营。
注：临安：南宋都城，今杭州。
注：倾盖：路遇交谈，如故。
注：姓锺名庸：“锺庸”谐“中庸”，《礼记》篇名，宋儒列为“四书”之一。
注：大鹤：谐“大学”，也是《礼记》篇名，宋儒列为“四书”之一。
注：姗侮：讥笑侮辱。
注：京尹：京兆尹，此指临安府尹。
注：黥：在脸上刺字的刑罚。
# 刺大言
题解：朱朴好大言，以经学登相位而无所作为，内优借佛语讥之；另有胡昉大言被讥。
原：光化中，朱朴好大言，自《毛诗》博士登庸。对易攵之日，而陈时事数条，每言“臣为陛下致之。”洎操大柄，一无施展，自是恩泽日衰，中外腾沸。内优穆刁陵作念经行者，至御前，曰：“若是朱相，即是非相。”翌日出宫。
注：光化：唐昭宗年号（898—901）。
注：朱朴：唐昭宗时宰相，以《毛诗》博士拜相，好大言，无实政。
注：《毛诗》博士：讲授《毛诗》的博士。
注：登庸：被任用，擢升。
注：易攵：待考，疑为“易代”之类讹字。
注：洎：及，到。
注：内优：宫中优伶。
注：穆刁陵：宫中伶人，待考。
注：若是朱相，即是非相：谐《金刚经》“若见诸相非相，即见如来”，“朱相”谐“诸相”。
原：胡昉大言夸诞，当国者以为天下奇才，力加荐引。一日不语坐客云：“朝廷官爵，是买吾曹头颅，岂不可畏！”一客趋前云：“也买脱空。”众大笑。
注：胡昉：待考。
注：当国者：当权者。
注：曹：辈。
注：脱空：说谎，落空。

# 半日闲
题解：贵人诵唐诗“半日闲”，被僧讥。
原：有贵人游僧舍，酒酣，诵唐人诗云：“因过竹院逢僧话，又得浮生半日闲。”僧闻而笑之。贵人问僧何笑。僧曰：“尊官得半日闲，老僧却忙了三日。”
注：因过竹院逢僧话，又得浮生半日闲：唐李涉《题鹤林寺僧舍》“因过竹院逢僧话，偷得浮生半日闲”。
注：酒酣：酒喝到畅快。
注：尊官：对官员的敬称。

# 孙凤洲诗
题解：朝士还乡，鼓吹喧阗，友人诵孙凤洲诗讽之。
原：长沙有朝士某者，还乡，意气盈满，宾至鼓吹喧阗。一挚友来访。朝士问曰：“翁素好诵诗，近日诵得何诗？”答曰：“近诵孙凤洲赠欧阳圭斋诗，甚有味。”乃朗诵曰：“圭斋还是旧圭斋，不带些儿官样回。若使他人登二品，门前箫鼓闹如雷。”朝士大惭，即辍鼓吹。
注：长沙：今湖南长沙。
注：鼓吹：乐队。
注：喧阗：喧哗热闹。
注：孙凤洲：待考。
注：欧阳圭斋：欧阳玄，号圭斋，元代文学家，官翰林学士承旨。
注：二品：官品第二等。
注：箫鼓：箫与鼓，指迎接的乐队。
注：辍：停止。

# 元祐钱
题解：崇宁初禁元祐之学，优人以戏讽之。
原：崇宁初，斥远元祐忠贤，禁锢学术。凡偶涉其时所为所行，无论大小，一切不得志。伶者对御为戏，推一参军作宰相，据坐宣扬朝政之美。一僧乞给公凭游方。视其戒牒，则元祐三年者，立涂毁之，而加以冠巾。一道士失亡度牒，问其披戴时，亦元祐也。剥其羽衣使为民。一士人以元祐五年获荐，当免举，礼部不为引用；来自言，即押送所属屏斥。已而主管宅库者附耳语曰：“今日于左藏库请得相公料钱一千贯，尽是元祐钱，合取钧旨。”其人俯首久之，曰：“从后门搬入去！”副者举所持挺扶其背曰：“你做到宰相，元来也只好钱！”是时至尊亦解颐。
注：崇宁：宋徽宗年号（1102—1106）。
注：元祐：宋哲宗年号（1086—1094），司马光等旧党执政时期。
注：斥远：排斥疏远。
注：禁锢：禁止仕进。
注：参军：参军戏，宋金杂剧中的脚色，此处扮作宰相。
注：公凭：官府发给的证明文书。
注：戒牒：僧人受戒的凭证，即度牒。
注：冠巾：令还俗，戴冠巾。
注：度牒：官府发给僧道的出家凭证。
注：羽衣：道士所穿的衣服。
注：免举：免予参加解试等。
注：引用：引荐使用。
注：宅库：官宅的库房。
注：左藏库：宋代国库，掌钱帛。
注：料钱：俸钱。
注：钧旨：对官长命令的敬称。
注：元祐钱：元祐通宝，宋哲宗时所铸钱币。
注：解颐：开颜而笑。
# 善天文
题解：伶人演天文家，借浑天仪讥张俊贪财。
原：张循王善货殖。伶为术人善天文者，云：“世间贵人，必应天象。用浑天仪窥之，则见星不见人。今可用一铜钱代。”令窥帝，曰：“此帝是也。”窥秦桧，曰：“相星。”韩世忠，曰：“将星。”至循王，则曰：“不见星。”众骇，再令窥之，曰：“终不见星，但见张王在钱眼里坐。”满坐大噱。
注：张循王：张俊，南宋名将，封循王，善经营积产，富甲一时。
注：货殖：经商营利。
注：术人：方术之士。
注：浑天仪：古代测天仪器。
注：相星：宰相之星。
注：将星：大将之星。
注：韩世忠：南宋名将，与岳飞同为抗金名将。
注：钱眼：铜钱方孔。
注：大噱：大笑。

# 赵良臣
题解：梅西野借改“良臣”为“爷爷”，讥世称官长之谄。
原：《西堂纪闻》：梅西野尝与邑大夫会饮。论及时事，云：“先时百姓称官长，止云某老爹。今则不问尊卑，俱呼爷爷矣。”因言吾乡有赵良臣者，延一西宾教子。其宾避主人讳，至《孟子》“我能辟土地”章，改“良臣”二字为“爷爷”，命其子读云：“今之所为爷爷，古之所为民贼也。”
注：西堂纪闻：笔记名，待考。
注：梅西野：待考。
注：老爹：明代对官员的称呼。
注：爷爷：称官员为“爷爷”，更显阿谀。
注：赵良臣：待考。
注：西宾：家塾教师。
注：我能辟土地：《孟子·告子下》“今之事君者曰：我能为君辟土地，充府库”。
注：今之所为爷爷，古之所为民贼：《孟子·告子下》作“今之所谓良臣，古之所谓民贼也”。

注：江盈科：号绿萝，万历长洲县令。

# 割碑
题解：州守以“割碑”讥侍郎割姚尚书神道碑。
原：颍川有姚尚书墓，其神道碑穹窿高厚，四面均焉。国初州人侍郎某者，欲割三分之一以刻墓表，告之州守。守曰：“何不割三分之二？”或问其故。守曰：“吾欲使后人割侍郎碑者，犹得中分耳。”侍郎闻之，惭悔。
注：颍川：今河南许昌一带，此指颍州。
注：姚尚书：待考。
注：神道碑：立在墓道前记载死者生平的石碑。
注：穹窿：高耸。
注：墓表：竖于墓前的记述墓主事迹的碑。
注：州守：知州。
注：中分：从中分开。
# 《道馀录》
题解：姚广孝《道馀录》毁儒家，张洪焚之；赵挺之不悦于黄庭坚讥其润笔。
原：姚广孝著《道馀录》，识者非之。张洪舆曰：“少师于我厚，今死矣，吾无以报，但见《道馀录》，辄为焚弃耳。”
注：姚广孝：明初僧人，法名道衍，助燕王朱棣夺位，官太子少师。
注：道馀录：姚广孝作，诋毁程朱理学。
注：张洪舆：待考，疑为张洪。
注：少师：太子少师，姚广孝官衔。
原：赵挺之尝曰：“乡中最重润笔，第一志文成，则大平车中满载相赠。”黄山谷笑曰：“想俱是萝卜瓜齑斋耳！”赵衔之，自是挤排不遗馀力，卒有宜州之贬。
注：赵挺之：北宋大臣，官至右仆射，蔡京一党。
注：润笔：请人作文、书画付给的酬金。
注：志文：墓志铭。
注：大平车：古代载物的大车。
注：黄山谷：黄庭坚，号山谷道人。
注：萝卜瓜齑：用萝卜、瓜腌的小菜，意谓所赠不过是素食。
注：宜州之贬：黄庭坚晚年被贬宜州（今广西宜山），死于贬所。
# 明文天话
题解：明文、天话两则，皆以人名词语谐音讥讽。
原：近日有达官自刻其文，且问于作者曰：“吾文何如古人？”或对曰：“一代之兴，有一代之文。故汉曰汉文，唐曰唐文。公之文可谓明文也。”其人不悟。
注：达官：显贵官员。
注：一代之兴，有一代之文：谓每个朝代各有其代表性的文体，如汉文、唐诗、宋词、元曲。
注：明文：谐“明文”，既指明代文章，又谐“明文规定”，讥其文平庸。
原：杨升庵云：滇中有一先辈，谕诸生读书为文之法甚悉。语毕，问诸生曰：“吾言是否？”一人应曰：“公天人，所言皆天话也！”
注：杨升庵：杨慎，号升庵，明代学者，正德六年状元，因大礼议被谪云南。
注：滇中：云南。
注：先辈：对年长者的敬称。
注：天话：待考，疑为“天花乱坠”之类的谐语。
# 鞋底
题解：杨亿被涂改草制，自题“世业杨家鞋底”。
原：杨文公亿在翰林时草制，为执政者多所涂削。杨甚不平，因取涂处加以浓墨，如鞋底样，题其旁曰：“世业杨家鞋底。”人问之，杨曰：“此语见别人脚迹。”当时传以笑。后草制被墨黜者，相谑曰：“又遭鞋底。”
注：杨文公亿：杨亿，字大年，谥文，北宋文学家。
注：草制：起草诏令。
注：涂削：涂改删削。
注：世业杨家：杨氏世代的家传事业，意谓文章被改。
注：鞋底：因墨团似鞋底。
注：黜：贬抑。
# 耻见妻子
题解：李迥秀机智应对落选者“耻见妻子”。
原：吏部侍郎李迥秀好机警。有选人被放。诉云：“羞见来路。”李曰：“从何来？”曰：“从浦津关来。”李曰：“取潼关路去。”曰：“耻见妻子。”李曰：“贤室本是相谙，亦不应怪。”
注：李迥秀：唐代人，字茂之，官至吏部侍郎。
注：选人：候选官员。
注：被放：落选。
注：来路：来时路。
注：浦津关：当作蒲津关，在今山西永济，黄河渡口。
注：潼关：关名，在今陕西潼关。
注：贤室：对他人妻子的称呼。
注：相谙：互相熟悉。
# 罗隐不第
题解：沈嵩戏称“两度折挂”，以月宫折桂喻落第。
原：沈嵩与罗隐从事浙西幕下。主帅出妙妓，众以嫦娥誉之。嵩曰：“嫦娥甚陋，安可及？”师惊曰：“书记识嫦娥乎？”曰：“嵩两度到月宫折挂，何为不识？”
注：沈嵩：待考。
注：罗隐：晚唐诗人，屡试不第。
注：从事：幕府僚属。
注：浙西：浙西节度使，治所在润州。
注：主帅：节度使。
注：嫦娥：传说后羿之妻，奔月成仙。
注：书记：幕府书记。
注：月宫折挂：“折桂”，指科举及第；“折挂”谐“折桂”，此处沈嵩戏称两度落第。
# 腹负

原：党太尉尝食饱，扪腹叹曰：“我不负汝！”左右曰：“将军不负此腹，恨此腹负将军。”
注：党太尉：党进，宋初将领，官至太尉，质朴。
注：扪腹：抚摩肚子。
注：负：辜负，亏待。

# 纳粟
题解：岐山王生纳粟得官，李生借“驮得三千斛谷”戏。
原：岐山王生，循故例纳粟三千斛，授官助教。以厚价市骏马乘，每不惬意。医者李生故称壮健，以为价贱。王怪问之。李曰：“驮得三千斛谷，岂非壮健耶？”
注：岐山：今陕西岐山。
注：纳粟：捐纳谷物以买官。
注：斛：古量器，十斗为斛。
注：助教：国子监教官。
注：市：买。
注：骏马：良马。
注：惬意：满意。
# 边面
题解：陈理从军立功而赏轻，贺子忱以“边面”戏之。
原：武臣陈理从军三十馀年，立功十次，谓贺子忱曰：“朝廷推赏，一次轻一次。”贺笑曰：“只为边面，一次近一次。”
注：陈理：待考。
注：贺子忱：待考。
注：边面：谐“边”“面”，指边面（边地）和面子，亦指“边”功，一次近一次。
# 太平幸民
题解：康定中朝廷失败，老相致仕自称“太平幸民”，石中立刺之。
原：康定中，西戎寇边，王师失律。当国一相以老谢去，亲知就第为贺。饮酣，自矜曰：“某，一山民耳。遭时得君，告老于家，当天下无事之辰，可谓太平幸民矣！”石中立曰：“只有陕西一伙窃盗未获。”
注：康定：宋仁宗年号（1040—1041）。
注：西戎：西夏，赵元昊。
注：失律：用兵不遵纪律，此指败绩。
注：当国一相：当权宰相，疑指吕夷简，待考。
注：谢去：辞职离去。
注：太平幸民：太平盛世中的幸运之民。
注：窃盗：盗贼，此处借指西夏。
# 庾亮
题解：庾亮平苏峻屡败，陶侃以“古人三败”劝。
原：庾亮击苏峻，屡败。陶侃曰：“古人三败，君候姑二。当今事急，不宜数败。”
注：庾亮：东晋外戚，字元规，苏峻之乱起因于他征召苏峻。
注：击苏峻：咸和二年（327）苏峻叛乱，庾亮兵败。
注：陶侃：东晋名将，字士行，平定苏峻之乱的统帅。
注：古人三败：《史记》载曹沫三败于齐。
注：君候：当作“君侯”，对显贵者的敬称。
# 丛公厉禁
题解：丛兰整顿开支过苛，滑稽生以“去一存一”进言。
原：丛兰巡抚淮安，务汰冗费，未免已甚。一滑稽生进言曰：“公尚有禁革未尽者。”丛忻然请教。曰：“裤以蔽形，今两股是虚费也。去一存一，所有多矣。”丛良久曰：“得无不便于行乎？”生曰：“公但禁之，谁敢言不便者？”丛知刺己，乃稍弛厉禁。
注：丛兰：明弘治、正德间官至兵部尚书，字廷秀，曾巡抚、总督漕运。
注：淮安：今江苏淮安。
注：汰冗费：裁减冗费。
注：禁革：禁止革除。
注：蔽形：遮蔽身体。
注：两股：两条裤腿。
注：弛：放松。
# 六千兵
题解：保国公私役营军，伶人借项羽“八千子弟”讥之。
原：国朝保国私役营二千治第。伶人为诵诗句曰：“楚歌吹散六千兵。”一人曰：“八千也！”解者曰：“那二千兵为保国公盖宅去矣！”
注：国朝：本朝，此指明代。
注：保国：保国公朱晖，成化年间封，家富。
注：私役营二千：私自役使营兵二千。
注：治第：建造私宅。
注：楚歌吹散六千兵：化用“四面楚歌”，项羽带江东八千子弟兵，诗句改作“六千”，答者说“八千也”，伶人谓二千兵被调去盖宅。
# 预借
题解：官员因预借被罢，妓女歌“十月小春梅蕊绽”讥之。
原：《行都纪事》：某邑宰因预借违旨，遭按而归。某府府将乃宰公之故旧，因留连而燕饮之。有妓慧黠，得宰罢官之由，时方仲秋，忽歌《渔家傲》：“十月小春梅蕊绽。”宰曰：“何太早耶？”答曰：“乃预借也。”宰大惭。
注：行都纪事：笔记名，待考。
注：邑宰：县令。
注：预借：提前征收下一年的赋税。
注：违旨：违背朝廷旨意。
注：府将：地方将领。
注：燕饮：宴饮。
注：仲秋：农历八月。
注：渔家傲：词牌名。
注：十月小春梅蕊绽：十月称小春，梅花在十月绽开太早，谐“预借”。
# 妲己赐周公
题解：孔融戏曹操“妲己赐周公”，后答“想当然耳”。
原：五官将既纳袁熙妻，孔文举与曹公书曰：“武王伐纣，以妲己赐周公。”曹公以文举博学，信以为然。后问文举。答曰：“以今度之，想当然耳。”
注：五官将：曹丕曾任五官中郎将。
注：袁熙妻：甄氏，袁熙之妻，后为曹丕之后。
注：孔文举：孔融，字文举，东汉末文人，后被曹操所杀。
注：武王伐纣，以妲己赐周公：孔融杜撰典故讽曹丕纳袁熙妻，见《世说新语·言语》注引《魏氏春秋》。
注：曹公：曹操。
注：以今度之，想当然耳：孔融答语，以今日之事推测古事。
# 滕甫类虞舜
题解：章惇戏滕甫似虞舜，“父顽、母嚣、象傲”。
原：滕甫有弟申，狠暴无礼，其母独笃爱，用是数凌侮其兄，而阃政多紊。章子厚与甫旧狎，一日语之曰：“公多类虞舜，然亦有不似者。”甫究其说。子厚曰：“类者父顽、母嚣、象傲。不类者，克谐以孝耳。”
注：滕甫：字元发，北宋名臣，苏轼友人。
注：阃政：家庭内政。
注：章子厚：章惇。
注：虞舜：传说中古帝舜。
注：父顽、母嚣、象傲：《尚书·尧典》“父顽，母嚚，象傲”，舜的父亲愚顽、继母凶恶、弟象傲慢。
注：克谐以孝：《尚书·尧典》“克谐以孝，烝烝乂，不格奸”。
# 马希声
题解：马希声居丧不戚，潘起讥之。
原：马殷卒，子希声居丧不戚，葬之日，顿食鸡隺数盘。其臣潘起讥之曰：“昔阮藉居母丧，食蒸豚，何代无贤！”
注：马殷：五代楚国开国君主，封楚王，卒于后唐明宗长兴元年。
注：希声：马希声，马殷之子，嗣位。
注：顿食：一顿吃下。
注：隺：同“鹤”；“鸡”与“隺”之间原文有缺字（字形不可识），此句所食何物待考。
注：潘起：马殷、马希声时官员，待考。
注：阮藉：阮籍，居母丧时饮酒食蒸豚，见《晋书·阮籍传》。
注：何代无贤：借以讥马希声以居丧食肉者为“贤”。
# 鸳鸯楼

注：口占：随口诵出。
注：逊、抗、机、云：陆逊、陆抗、陆机、陆云，东吴陆氏世家，相继为名将、文士。

注：走马呼医：快马去请医生，意味着有人将死，即有碑志可作。
# 光福地
题解：光福地多地师，村农说“带纱帽者来寻地”。
原：袁了凡好谈地理，曾访地至光福，问一村农曰：“颇闻此处有佳穴否？”曰：“小人生长于斯，三十馀年矣。但见带纱帽者来寻地，不见带纱帽者来上坟。”袁默然而去。
注：袁了凡：袁黄，号了凡，明代学者。
注：光福：苏州光福镇。
注：佳穴：好墓穴。
注：纱帽：官员所戴官帽。
注：上坟：扫墓。
# 陆念先
题解：陆念先以“三千金”戏王太守悭吝。
原：陆念先口无择言，时出微词，乃足绝倒。故与王太守中表戚。太守富甲吴中，而终日蹙迫，甚于窭人。尝对念先忧贫，语次，念先忽拊髀大呼曰：“嗟乎！如某者，安得三千金以快吾意！”太守亦惊曰：“知兄居贫，唯是朝夕计急耳；胡所费，而骤须三千金？”念先曰：“然，故有所用之。”因屈一指曰：“千金以赡三党戚属暨穷交兄弟。”再屈一指曰：“千金以饭僧暨恤无告乞儿。”又屈一指曰：“千金即以赠弟，令汝展一日眉头也。”
注：陆念先：待考。
注：口无择言：说话不择词语。
注：微词：含蓄委婉的批评。
注：中表：表亲。
注：窭人：贫人。
注：拊髀：拍大腿。
注：三党：父党、母党、妻党，即亲族。
注：饭僧：施斋饭给僧人。
注：展一日眉头：舒展眉头一天，指让他高兴一日。
# 张伯起
题解：张伯起借“关白”戏吴一郎，使其离席。
原：苏州王氏仆吴一郎，富而恣，以资得官，尝乘四人轿赴姻家席。张伯起恶之，时有关白之警，乃遽谓吴曰：“近阅邸报，关白已就擒矣。”吴欣然来问。张白：“关白原是一怪，身长数丈，腰大百围。截其头，重数百斤，碎之而后能举也。”吴曰：“那有此事？”张曰：“只一个鼻头，亦用四人抬之。”吴不终席而去。
注：吴一郎：苏州王氏仆人，因捐官发迹，待考。
注：张伯起：张凤翼，字伯起，明苏州戏曲家，作《红拂记》。
注：关白：日本丰臣秀吉。
注：邸报：明清官方发布朝廷消息的文书。
注：就擒：被捕。
注：百围：极粗。
# 舜禹诗
题解：傧者张仲素朗吟“舜耕”“禹凿”之句，李程借舜禹之事戏答。
原：元祐中，大官有婚于中表者，已涉溱洧之嫌。及夜深，女家索诗。傧者张仲素朗吟曰：“舜耕馀草木，禹凿旧山川。”坐有李程者应声笑曰：“舜、禹之事，吾知之矣！”
注：大官：高官。
注：中表：表亲。
注：溱洧之嫌：《诗经·郑风·溱洧》写男女相会，此处指婚前越礼之嫌。
注：傧者：婚礼司仪。
注：张仲素：中唐诗人，字绘之，官至翰林学士。
注：舜耕馀草木，禹凿旧山川：舜耕历山、禹凿龙门的传说，嵌“耕”“凿”二字。
注：李程：唐代宗室，字表臣，官至宰相，诙谐。
# 忠孝奴
题解：祝允明为老人二妾命名“忠奴”“孝奴”，以《论语》语戏之。
原：一人年老纳二宠，托友祝枝山命名。祝以“忠奴”“孝奴”名之。其人曰：“何所取义？”祝曰：“孝当竭力，忠则尽命。”众大笑。
注：祝枝山：祝允明，号枝山，明苏州书法家。
注：二宠：两个宠妾。
注：孝当竭力，忠则尽命：《论语·学而》“事父母，能竭其力；事君，能致其身”，此处借以戏谑老人。
# 乡老垦荒
题解：郎瑛与乡老游山，戏言需“生铁”才不死。
原：郎瑛与一乡老游山，见荒地数顷，土人曰：“欲送人召粮者。”老人默然久之，语郎曰：“即当载米及铁器，令若干人来垦此地，数年可富矣。”郎曰：“还须载生铁数百斤。”老人曰：“何用？”郎曰：“铸汝不死耳。”
注：郎瑛：明杭州人，字仁宝，撰《七修类稿》。
注：召粮：招人开垦，认纳粮赋。
注：乡老：乡间老人。
注：铸汝不死：以生铁铸身，免死。
# 三星
题解：吏部前小儿卖食，以“三星”称举人、岁贡、纳监。
原：北京吏部前诸小儿卖食物者，常云：“相公每都是三星的，才得到此。”予初不知，问之。曰：“举人进士是福星，岁贡是寿星，纳监的是财星也。”
注：吏部：掌官员铨选的部。
注：福星：吉星，此指举人进士。
注：寿星：南极老人星，此指年老的岁贡生。
注：岁贡：府州县学按年选送入国子监的生员，年纪往往较大。
注：纳监：捐纳入国子监。
注：财星：以财买官，故称“财星”。
# 洗儿诗
题解：苏轼《洗儿诗》。
原：东坡频年谪居，尝作《洗儿诗》曰：“人家养子爱聪明，我为聪明误一生。但愿生儿愚且鲁，无灾无害到公卿。”
注：洗儿：旧俗婴儿出生第三日洗浴，亲友聚会。
注：东坡：苏轼号东坡居士。
注：谪居：贬官居住。
注：愚且鲁：《论语·先进》“参也鲁”“柴也愚”。
注：公卿：高官。
# 打甲帐
题解：马仲良买学田，居间者乘机索钱，有人编“子路、申枨、子夏”笑话，以“打申枨”误作“打甲帐”（“打夹帐”）收尾。
原：凡交易事，居间者索私赠，名为“打夹帐”。马仲良督浒墅关，出羡馀市田以赡学宫。其价稍厚，一时居间者皆乘之要利。或作语嘲之，云：子路与申枨同会。子路讥申曰：“枨也欲，焉得刚？”枨遂曰：“由也不得其死然。”子路大怒，诉之夫子。夫子曰：“罪在枨。”用牌大书“打申枨”三字送子夏。适子夏丧明，认字不真，惊曰：“谁人打甲帐？”
注：居间者：买卖双方之间的中介人。
注：索私赠：索取私下的好处费。
注：打夹帐：当时行话，指中介抽取回扣；“夹帐”“甲帐”谐音，故下文有“打甲帐”之误读。
注：马仲良：马之骏，字仲良，明末官员，曾任浒墅关榷税。
注：浒墅关：在今苏州，明代设钞关，收取过往船货之税。
注：羡馀：税收盈余。
注：市田：买田。
注：赡学宫：供养府县学，即以田租充学校经费。
注：乘之要利：乘机谋取好处。
注：子路：孔子弟子仲由。
注：申枨：孔子弟子，《论语·公冶长》载孔子谓其“枨也欲，焉得刚”。
注：枨也欲，焉得刚：《论语·公冶长》，孔子说申枨多欲，不得为刚。
注：由也不得其死然：《论语·先进》，孔子说子路“若由也，不得其死然”。
注：夫子：孔子。
注：子夏：孔子弟子卜商，晚年丧子哭瞎双眼，《礼记·檀弓上》载“子夏丧其子而丧其明”。
注：打申枨：谓“打”“申枨”，下文子夏将“申枨”误认作“甲帐”，与“打夹帐”相应。
