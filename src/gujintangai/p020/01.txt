# 正文
题解：本部总论：冯梦龙以项籍重瞳、左丘失明等对举，说明形貌有缺而精神不亏，笑形体可以，执以为可笑则不可，并交代本部为全书第二十部《委蜕》。
原：〔子犹曰：项籍之瞳，不如左丘之眇；啬夫之口，不知咎繇之暗；鄋㒼之长，不如晏婴之短；夷光之艳，不如无盐之陋；庆忌之足，不如娄公之跛。语曰：“豹留皮，人留名。”此言形神之异也。故窘极生巧，足或刺绣；愤极忘死，胸或发声。是皆有神行焉。借以为笑可，执以为可笑则不可。集《委蜕》第二十。〕
注：子犹曰：冯梦龙自称。
注：项籍之瞳：项羽（名籍）相传有重瞳，即一目两瞳。
注：左丘之眇：左丘明相传失明（眇，此处指目盲）。《国语》《左传》旧题其作。
注：啬夫之口：汉文帝时虎圈啬夫，善答上林禽兽簿，口才敏捷，见《史记·张释之列传》。
注：咎繇之暗：咎繇即皋陶，传说他舜时为士师，“暗”指口不能言，一说不能多言。
注：鄋㒼之长：鄋瞒，春秋时狄人国，其人长大，见《左传》文公十一年。
注：晏婴之短：晏婴，春秋齐相，身材矮小，仍名闻诸侯。
注：夷光之艳：夷光即西施，春秋越国美女。
注：无盐之陋：无盐指钟离春，齐无盐邑女，貌丑而有德才，见《列女传》。
注：庆忌之足：庆忌，春秋吴王僚之子，以勇力及步行迅疾著称。
注：娄公之跛：娄公，指跛足者，此处用以对举“足”，具体所指待考。
注：豹留皮，人留名：语出《新五代史·王彦章传》，“豹死留皮，人死留名”。
注：窘极生巧：处境窘迫到极点反生巧思。
注：足或刺绣：无手者以足刺绣，指肢体残缺者另有技能。
注：愤极忘死：愤怒极点而不畏死。
注：胸或发声：胸腔也可发声，指无口者以胸发声。
注：有神行焉：有精神在其中运行。
注：委蜕：本指蝉蜕之皮，喻形体；《庄子·知北游》“是天地之委蜕也”。
# 体重
题解：本节罗列三人体重之重，写肥重之极。
原：安禄山三百五十斤。司马保八百斤。孟业一千斤。
注：安禄山：唐代胡人将领，史载其体重三百五十斤，行动需人扶持。
注：司马保：西晋南阳王，史载其体肥，重八百斤，见《晋书》。
注：孟业：当为“孟业”，北魏或北齐人，身重过千斤，疑出传闻，待考。
# 肥
题解：本节四则：写唐举子骑驴嘲郑昌图之肥、苏轼戏顾子敦、张倬戏姜典史、赵翁醉卧被孙儿投李，以肥为笑料。
原：咸通中，以进士服用僭侈，不许乘马。时场中不下千人，皆跨“长耳”。或嘲之曰：“今年敕下尽骑驴，短辔长鞭满九衢。清瘦儿郎犹自可，就中悉杀郑昌图。”郑肥伟，故云。
注：咸通：唐懿宗年号，860—874年。
注：僭侈：超越身份的奢侈。
注：长耳：指驴。
注：敕：皇帝的命令。
注：九衢：京城的大道。
注：清瘦儿郎：瘦弱的青年。
注：就中：其中。
注：悉杀：杀得很，极端之意。
注：郑昌图：唐懿宗朝进士，后官至宰相，肥伟。
原：顾子敦肥伟，号“顾屠”。尹京时，与从官同集慈孝寺。子敦凭几假寐，东坡大书案上曰“顾屠肉案”。同会皆大笑。乃以三十钱掷案上。子敦惊觉。东坡曰：且片批四两来！”
注：顾子敦：顾临，字子敦，北宋官员，体肥，曾任开封知府。
注：顾屠：以其肥似屠夫。
注：尹京：任京兆尹，此指知开封府。
注：从官：随从属官。
注：慈孝寺：北宋汴京寺名。
注：凭几假寐：靠着几案打盹。
注：东坡：苏轼。
注：顾屠肉案：戏说顾子敦如屠户的肉案。
注：片批：切肉成片称片批。
原：山阴张倬，景泰初，为昆山学博，年未三十，以聪敏闻。典史姜者，体极肥，尝戏张云：“二三十岁小先生。”张应云：“四五百斤肥典史。”同僚大笑。
注：山阴：今浙江绍兴。
注：张倬：明景泰时人，曾任昆山县学教谕，待考。
注：景泰：明代宗年号，1450—1456年。
注：学博：学官，指教谕、训导。
注：典史：知县属官，掌缉捕狱囚。
注：小先生：对年轻学官的戏称。
注：四五百斤肥典史：对姜典史体肥的回敬。
原：赵翁肥大，夏日醉卧，孙儿辈缘其腹上，戏以李八九枚投脐中。后日李大溃烂，翁乃泣谓家人曰：我肠烂，将死。”家人料理其脐，得核，乃知孙儿辈所纳李也。
注：缘：攀登。
注：投脐中：投入肚脐里。
注：溃烂：腐烂。
注：核：李子的核。
# 垂腹
题解：本节两则：申王患肉疾、玄宗赐冷蛇消暑；周岱腹垂至膝，琢水精为腹带，写胖者畏暑之苦。
原：申王㧑有肉疾，腹垂至骭。每出，则束以白练。至暑月，常苦热。玄宗诏南方取冷蛇赐之。蛇长数尺，色白，不螫人，握之如冰。王腹有数约，夏月置约中，不复知烦暑。
注：申王㧑：唐睿宗之子李成义，封申王。
注：肉疾：肥胖病。
注：骭：小腿。
注：白练：白色熟绢。
注：暑月：夏天。
注：玄宗：唐玄宗李隆基。
注：冷蛇：传说中的冷血蛇，握在手上如冰。
注：螫：毒虫刺人。
注：约：腹部皱褶，此处指肚腹的折叠处。
注：烦暑：烦热。
原：周比部岱体甚肥，腹垂至膝。每当暑月，琢水精为腹带，日三易之，犹云不堪，自为文以告上帝，祈速化。
注：周比部岱：周岱，明人，曾任刑部比部郎中。
注：比部：刑部下属的一司，掌勾稽。
注：水精：水晶。
注：腹带：束腹的带子。
注：告上帝：向上天祷告。
注：祈速化：祈求尽快化去。
# 伟妓
题解：东坡在豪士家见侍姬身躯魁伟，戏题联语以舞袖影摇龙蛇、歌声撼动风雨状其伟，妓赧然。
原：东坡尝饮一豪士家。出侍姬佐酒。内一善歌舞者，容虽丽而躯甚伟，尤豪所钟爱。向公乞诗，公戏题四名云：“舞袖翩跹，影摇千尺龙蛇动；歌喉宛转，声撼半天风雨寒。”妓赧然。
注：东坡：苏轼，号东坡居士。
注：豪士：豪爽有钱的人。
注：侍姬：侍妾。
注：钟爱：特别喜爱。
注：乞诗：请求写诗。
注：翩跹：舞姿轻盈。
注：影摇千尺龙蛇动：舞袖摇动的影子如千尺龙蛇。
注：歌喉宛转：歌声婉转。
注：声撼半天风雨寒：歌声震动半空，如风雨交加。
注：赧然：羞愧脸红的样子。
# 姚、张绰号
题解：魏光乘给朝士起绰号，姚崇以“趁蛇鹳”、张元一以“逆流虾蟆”被戏，魏光乘因此坐贬，写武周朝士绰号之事。
原：魏光乘任左拾遗，题品朝士。丞相姚元之长大行急，目为“趁蛇鹳”。坐此贬，左司郎中张元一腹粗脚短，项缩眼突。吉顼目为“逆流虾蟆”。
注：魏光乘：武周时人，官左拾遗，好品题人，见《朝野佥载》。
注：左拾遗：谏官名，唐代门下省官，从八品上。
注：题品：品评。
注：姚元之：即姚崇，本名元崇，字元之，唐玄宗朝名相。
注：趁蛇鹳：追蛇的鹳鸟，形容其身高腿长行急。
注：坐：因某事获罪。
注：左司郎中：尚书省左司的主官，从五品上。
注：张元一：武周时人，官左司郎中，滑稽善谑。
注：项缩眼突：脖子缩进、眼睛突出。
注：吉顼：武周时酷吏，官至中丞。
注：逆流虾蟆：逆水而游的蛤蟆。
# 短
题解：本节两段：先引《庄子》所传务光让天下事，笑其短；后引《南史》言张仲师身长一尺二寸，写身短之说。
原：汤既伐桀，让于务光。光笑曰：“以九尺之夫而让天下于我，形吾短与！”羞而沉于水，有咫尺之鱼，负之而去。
注：汤既伐桀：商汤灭夏桀。
注：务光：夏时隐士，汤让天下给他而不受，投水而死，见《庄子·让王》。
注：九尺之夫：身高九尺之人，指汤。
注：形吾短与：难道嫌我矮小吗？
注：咫尺之鱼：长一尺左右的鱼。底本此说有演绎，非《庄子》原文。
原：《南史》云：“汉光武时，颍川张仲师长一尺二寸。
注：《南史》：唐李延寿撰，记南朝宋、齐、梁、陈史事。
注：汉光武：东汉光武帝刘秀，25—57年在位。
注：颍川：郡名，在今河南中部。
注：张仲师：东汉人，长一尺二寸，事见《博物志》等，此处称《南史》所记，待考。
# 短小
题解：本节两段：写何尚之与颜延之互相戏谑猿猴，以及赵璘貌陋，薛能为傧相戏以诗，皆以身短貌陋为笑。
原：尚书令何尚之与太常颜延之少相好狎。二人并短小。何尝谓颜为猿，颜目何为猴。同游太子西池，颜问路人曰：“吾二人谁似猿？路人指何为似。颜方矜喜，路人曰：“彼似猿，君乃真猴。”二人俱大笑。
注：何尚之：南朝宋人，官至尚书令，字彦德。
注：颜延之：南朝宋文学家，官至太常，与谢灵运并称“颜谢”。
注：好狎：亲昵戏谑。
注：太子西池：太子宫西面的池苑。
注：矜喜：自得欣喜。
原：赵璘仪质琐陋，成名始婚。薛能为傧相，谑以诗。略云：“巡关每傍樗蒲局，望月还登乞巧楼。第一莫教娇太过，缘人衣带上人头。”又曰：“不知元在鞍鞒里，将谓空驮席帽归。”又曰：“火炉床上平身立，使与夫人作镜台。”
注：赵璘：唐人，著《因话录》，宣宗朝进士。
注：仪质琐陋：容貌身材猥琐丑陋。
注：成名：登科。
注：薛能：晚唐诗人，字太拙，官至工部尚书。
注：傧相：婚礼赞礼人。
注：巡关：巡视关隘，此处指赌场。
注：樗蒲：古代博戏。
注：乞巧楼：七夕乞巧的楼阁。
注：缘人衣带上人头：意为因为人的衣带上有人头，此诗以赵璘矮小开玩笑，意旨待考。
注：鞍鞒：马鞍前后隆起处。
注：席帽：古代一种士子所戴的帽子。
注：火炉床：火炉的支架。
注：镜台：梳妆台，意谓身矮可作镜台。
# 貌寝陋
题解：本节五则：写裴佶貌寝被误为甘草、袁应中貌陋得“奉敕陋”之号、罗隐貌丑使郑畋之女失望、许郝两家子弟貌陋、王世贞戏画士黄鹄，皆写貌陋遭遇。
原：朱泚乱。裴佶与衣冠数人佯为奴，求出城。佶貌寝，自称曰“甘草”。门兵曰：“此数子必非人奴，如甘草，不疑也。”
注：朱泚乱：唐德宗建中四年，朱泚在长安称帝。
注：裴佶：唐人，事见《唐语林》等。
注：衣冠：士大夫。
注：貌寝：容貌丑陋。
注：甘草：药名，药中国老，此处谐“衣冠”之陋，意为常见者，待考。
原：袁应中，博学者，有时名，以貌寝，诸公莫敢荐。绍圣间，蔡元度引之，乃得对。袁鸢肩，上短下漏，又广颡尖额，面多黑子，望之如洒墨，声嗄而吴音。哲宗一见，连称“大陋”。袁错愕不得陈述而退。缙绅目为“奉敕陋。”
注：袁应中：宋人，生平待考。
注：绍圣：宋哲宗年号，1094—1098年。
注：蔡元度：蔡卞，字元度，王安石婿，蔡京之弟。
注：鸢肩：肩膀上耸如鸢。
注：上短下漏：上身短，下身粗松。
注：广颡：宽额头。
注：嗄：声音嘶哑。
注：吴音：吴地口音。
注：哲宗：宋哲宗赵煦。
注：错愕：仓促惊愕。
注：缙绅：官宦。
注：奉敕陋：奉皇帝之命称其貌陋。
原：郑畋少女好罗隐诗，常欲委身。一日隐谒畋。畋命其女隐帘窥之。见其寝陋，遂终身不读江东篇什。举子或以此谑隐。答曰：“以貌取人，失之子羽。”众皆启齿。
注：郑畋：唐僖宗朝宰相，字台文。
注：罗隐：晚唐诗人，貌陋，屡试不第，著《谗书》。
注：委身：以身相许。
注：江东篇什：指罗隐的诗篇，罗隐为江东人。
注：以貌取人，失之子羽：语出《史记·仲尼弟子列传》，孔子称以貌取人则失之子羽（澹台灭明，貌丑而有德才）。
注：启齿：笑。
原：长安仁和坊后部侍郎许钦明宅，与中书令郝处俊乡党亲族。两家子弟类多鬼陋，而盛饰车马以游里巷。京落为之语曰：“衣裳好，仪观恶。不姓许，即姓郝。”
注：仁和坊：唐长安坊名。
注：许钦明：唐高宗朝大臣，曾官户部侍郎，待考。
注：郝处俊：唐高宗朝宰相，官至中书令。
注：乡党亲族：同乡亲戚。
注：鬼陋：丑陋如鬼。
注：盛饰车马：把车马装饰得很华丽。
注：京落：当作“京洛”，指京城。
注：仪观：仪表。
原：王元美宴弇州园，偶与画土黄鹄联席。鹄貌极陋。元美曰“人皆谓我命带桃花煞，果然！”人问：“何也？”曰：“得与美人联席。”吴人皆举为口实，凡见貌陋者，必曰“命带桃花。”
注：王元美：王世贞，字元美，号弇州山人，明代文学家。
注：弇州园：王世贞在太仓所建的弇山园。
注：画土：画工。
注：黄鹄：人名，待考。
注：联席：并席而坐。
注：桃花煞：命理中谓有桃花运者招致色情之灾。
注：口实：话柄。
# 短而伛
题解：崔善为身矮驼背，诸曹以其聪察而作诗嘲之，诗中“膊上全无项，胸前别有头”，写人因才被嘲。
原：武德中，崔善为历尚书左丞，甚得时誉。诸曹恶其聪察，因其身短而伛，嘲之曰：“崔子曲如钩，随例得封侯。膊上全无项，胸前别有头。
注：武德：唐高祖年号，618—626年。
注：崔善为：唐初大臣，历官尚书左丞等。
注：尚书左丞：尚书省长官之佐，掌管省内事务。
注：诸曹：各部曹官吏。
注：聪察：聪明明察。
注：伛：驼背。
注：随例得封侯：随常例封侯。
注：膊：肩膀。
# 身短面长
题解：桑维翰身矮面长，自叹七尺之躯不如一尺之面，同榜戏称“三个半人”，写五代宰相的外貌笑谈。
原：桑维翰身短面长，每引镜自叹曰：“七尺之躯，何如一尺之面？”后登第，同榜四个，陈保极戏谓人曰：“今岁有三个半人及第。”以桑短，谓之半人。
注：桑维翰：五代后晋宰相，字国侨，身短面长。
注：引镜：照镜子。
注：七尺之躯，何如一尺之面：古人七尺为成年男子身高，此言脸长一尺。
注：同榜：同榜登第者。
注：陈保极：后唐进士，生平待考。
注：及第：科举考中。
注：半人：因桑维翰个头矮，故以半人称之。
# 面狭长

# 面黑

原：焦阁老芳，面黑而长，如驴。尝谓西涯曰：“君善相，烦一看。”李久之乃曰：“左相象马尚书，右相象卢侍郎，必至此地位。”“马”与“卢”合，乃一“驴”字，始知其戏。

题解：崔涯作诗嘲妓李端端，端端惶恐，涯改诗称其为白牡丹，众商争至，写文人讥诗之力与世态炎凉。

注：铛：温酒器，此处指圆耳。
注：昆仑山上月初生：昆仑，指肤色黝黑的昆仑奴；在黑昆仑山上插象牙梳，似月初生。
注：战栗祈哀：发抖恳求。
注：黄骝：黄毛黑鬣的骏马。
注：鞁：给马套上鞍鞯。
注：善和坊：扬州街坊名。
注：白牡丹：以白牡丹比之，反转为赞美。
注：居豪大贾：富豪大商。
注：竞臻其户：争相登门。
注：墨池：洗笔砚的池，此处喻黑。
注：雪岭：雪山，此处喻白。

# 陈癞子
题解：陈癞子讳言己病，游客以“添减病”之说暗讽，伶人以“碧纱幪”引诗戏之，写讳疾忌医与伶人诙谐。
原：《玉堂闲话》：唐营丘有豪民陈姓病风疾，众目之为“陈癞子”。陈极讳之。家人或误言，必遭怒苔。宾客亦不敢犯。或言所苦减退，具得丰款。有游客谒之，初谓：“君疾近日尤减。”陈欣然命酒。将撤，又问：“某疾果退否？”客曰：“此亦添减病”。曰：何谓也？”客曰：“添者，面上添渤沤子。减者，减却鼻孔。”长揖而去。数日不怿。又每年五月，值生辰，必召僧道启斋宴，怜伦百戏俱备。斋罢，赠钱数万，一伶既去，复入，谓曰：“蒙君厚惠，偶忆短李相诗一联，深叶圣德。”陈曰：“试诵之。”时陈坐碧纱帏中，左右环侍。令曰：“诗云：‘三十年前陈癞子，如今始碧纱幪。’”遭大诟而去。
注：《玉堂闲话》：五代王仁裕所撰笔记。

注：风疾：麻风病。
注：癞子：长癞疮的人，也指秃头。

注：长揖：作大揖。
注：不怿：不高兴。
注：生辰：生日。
注：斋宴：斋会宴席。
注：怜伦：当作“伶伦”，乐人。
注：百戏：杂戏。
注：短李相：李绅，身材矮小，称“短李”，官至宰相。

# 勇士庙
题解：朱遵为汉郡功曹，抗公孙述而战死，失首犹能退至此，后人立祠，称勇士庙，写忠勇之异。
原：汉朱遵仕郡功曹。公孙述僭号，遵拥郡人不伏。述攻之，乃以兵拒述，埋车绊马而战死。光武追赠辅汉将军。吴汉表为置词。一曰：“遵失首，退至此地，绊马讫，以手摸头，始知失首。于是士人感而义之，乃为置祠，号为“健儿庙”。后改“勇士庙”。见《新汉县图记》。
注：朱遵：东汉初犍为郡功曹，守武阳抗公孙述。
注：功曹：郡的属官，掌人事。
注：公孙述：东汉初割据蜀地称帝。
注：僭号：非法称帝。
注：埋车绊马：埋住车轮，绊住马足，以示不退。
注：光武：汉光武帝刘秀。
注：辅汉将军：朱遵死后所追赠称号。
注：吴汉：东汉名将，大司马。
注：置词：当作“置祠”，立祠堂。
注：健儿庙：因勇敢而称“健儿”。
注：勇士庙：后改称。
注：《新汉县图记》：待考。
# 无头亦佳
题解：贾雍被斩首后仍上马还营，说“无头亦佳”后死去，写勇烈之异与语言诙谐。
原：贾雍出界讨贼，为贼听去头，复上马还营。营中将士争来看。雍从胸中语曰：“诸君视有头佳、无头佳乎？”吏泣曰：“有头佳。”雍曰：“不然，无头亦佳！”言毕而绝。
注：贾雍：三国魏人，事见《搜神记》，待考。
注：出界：出境。
注：听去头：斩去头。
注：绝：断气。
# 人妖
题解：本节四则：写民间所传寿命异常之“人妖”，如宋卿九代祖、池州翁媪、胡顼所见七代祖姑、董桥店孟媪化名丈夫的奇闻。
原：宋卿家九代祖，如小儿，在鸡窠中，不饮不食，不知年岁。子孙朔望罗拜，垂头下视。太原王仁裕远祖母约二百馀岁，形才三四尺，饮啖甚少，往来无迹。唯床头有柳箱，戒子弟勿启。一日无赖孙醉启之，唯一铁篦。自此竟不回。
注：宋卿：待考。
注：鸡窠：鸡窝。
注：朔望：初一、十五。
注：罗拜：环绕行礼。
注：王仁裕：五代文学家，字德辇，天水人。此处称太原，待考。
注：柳箱：柳条编的箱。
注：铁篦：铁梳篦。
注：自此竟不回：此后一去不返。
原：池州村祖翁媪二人，各长三尺，绵衾拥体，坐佛龛中。两眼能动，蘸酒口中，亦能舐之。皮皆粘骨，不知年岁。
注：池州：今安徽池州。
注：祖翁媪：祖辈老翁老妇。
注：绵衾：丝棉被。
注：佛龛：供佛的小阁。
注：蘸酒：沾酒。
注：舐：舔。
注：粘骨：贴着骨头。
原：夏县尉胡顼尝至金城县界，止于人家。方具食，见一老母长二尺，来窃食。新妇搏其耳，曳入户。云是七代祖姑，寿三百馀矣。苦其窃，常絷槛中，兹偶逸耳。
注：夏县尉：夏县县尉。
注：胡顼：待考。
注：金城县：今陕西兴平。
注：新妇：儿媳。
注：搏：打。
注：七代祖姑：七世祖姑。
注：絷：拘系。
注：槛：栅栏。
原：唐三原县董桥店有孟媪，年百馀岁而卒。店入皆呼为“张大夫店”。媪自言：“二十六嫁张詧，詧为郭汾阳所任。詧之貌酷类某，詧卒，吾遂为丈夫衣冠，投名为詧弟，得继事汾阳。寡居十五年。自汾阳薨，吾已年七十二，军中累奏兼御史大夫。忽思茕独，遂嫁此店潘老为夫。迩来复诞二子，曰滔、曰渠。滔五十有五，渠五十有二云。”见《干巽子》。
注：三原县：今陕西三原。
注：董桥店：待考。
注：孟媪：孟老妇人。
注：张大夫店：以张詧得名。
注：张詧：待考。
注：郭汾阳：郭子仪。
注：投名：报名。
注：寡居：守寡。
注：薨：诸侯死。
注：茕独：孤独。
注：《干巽子》：即《干巽子》，唐温庭筠所撰笔记，此处底本作“干”字后带一造字。
