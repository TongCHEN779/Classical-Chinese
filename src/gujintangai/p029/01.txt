# 正文
题解：《谈资部》总序，说明酒令、对句、灯谜、拆字皆为聪明所寄，编为第二十九。
原：〔子犹曰：古人酒有令，句有对，灯有谜，字有离合，皆聪明之所寄也。工者不胜书，书其趣者，可以侈目，可以解颐。集《谈资》第二十九。〕
注：子犹：冯梦龙之号。
注：离合：字谜的一种，拆合字形。
注：侈目：悦目，开眼界。
注：解颐：开颜而笑。
注：谈资：谈话资料，此为《古今谭概》第二十九部。
# 李先主雪令
题解：南唐烈祖李昇以雪令试群臣，徐融语触其忌而被杀。
原：李先主〈南唐烈主李昇〉欲讽动僚属，雪天大会，出一令，借雪取古人名，仍词理通贯。时宋齐丘、徐融在座。昇举杯为令曰：“雪下纷纷，便是白起。”齐丘曰：“著屐过街，必须雍齿。”融意欲挫昇，遽曰：“明朝日出，争奈萧何？”昇大怒，是夜收融，投于江。自是唯齐丘与谋。
注：李先主：南唐烈祖李昇（徐知诰），南唐开国之君。
注：令：酒令。
注：词理通贯：词义条理贯通。
注：宋齐丘：南唐重臣，字超回，仕烈祖、元宗，后被囚致死。
注：徐融：待考。
注：白起：战国秦将，号武安君，雪白谐“白起”。
注：屐：木底鞋。雍齿：汉初功臣，刘邦所憎，后封什邡侯，“雍”谐“拥”，“齿”谐“屐齿”。
注：萧何：汉初丞相，“消何”双关，雪融（日出则消），暗讥李昇。
注：收：逮捕。投于江：沉江。
# 卦名令
题解：苏轼倡酒令，以两卦名证一故事。
原：苏子瞻倡酒令，以两卦名证一故事。一人云：“孟尝门下三千客，大有同人。”一人云：“光武兵渡滹沱河，即济未济。”一人云：“刘宽婢羹污朝衣，家人小过。”苏云：“牛僧孺父子犯罪，先斩小畜，后斩大畜。”盖为荆公父子云。
注：卦名：《周易》六十四卦名，此令每句嵌二卦名。
注：大有同人：嵌《周易》“大有”“同人”二卦名，谓孟尝君门下客众，与人亲和。
注：即济未济：嵌《周易》“既济”“未济”（“即济”疑当作“既济”）二卦名；光武渡滹沱河，冰合而济，故云。
注：刘宽：东汉人，宽厚，婢女羹污朝衣，神色不变。家人、小过：卦名。
注：牛僧孺：唐代宰相，其子牛蔚。此处暗指王安石父子，非史实。
注：小畜：《周易》卦名，戏指牛僧孺之子。
注：大畜：《周易》卦名，戏指牛僧孺。
注：荆公：王安石，封荆国公，其子王雱。
# 二十八宿令
题解：苏轼与佛印起令，曲名与二十八宿相对。
原：东坡谓佛印起令曰：“要头是曲名，尾是二十八宿，四个字不间。”东坡曰：“黄莺儿，扑蝴蝶不著，虚张尾翼。”佛印应声答曰：“二郎神，绕佛阁，想是鬼奎危娄。”
注：佛印：了元，北宋云门宗僧，字觉老，与苏轼交游，多机锋。
注：曲名：词曲牌名。
注：二十八宿：古代天文，沿黄道分布二十八星座。
注：黄莺儿：曲牌名。
注：虚张尾翼：“虚”“张”“尾”“翼”皆星宿名，四字相连。
注：二郎神：曲牌名。
注：鬼奎危娄：“鬼”“奎”“危”“娄”皆星宿名。
# 贾平章令
题解：贾似道设酒令，讥其误国。
原：咸淳中，贾平章似道宴马丞相廷鸾、江丞相万里。贾举令曰：“我有一局棋，寄与洞中仙。洞中仙不受，云：自出洞来无敌手，得饶人处且饶人。”《洞中仙》，曲名。下二句，古诗也。马云：“我有一渔竿，寄与渔家傲。渔家傲不受，云：夜静水寒渔不饵，满船空载月明归。”江云：“我有一犁锄，寄与使牛子。使牛子不受，云：且存方寸地，留与子孙耕。”盖讥似道也。
注：咸淳：宋度宗年号（1265—1274）。
注：贾平章似道：贾似道，字师宪，南宋权相，官平章军国重事。
注：马丞相廷鸾：马廷鸾，南宋大臣，字翔仲，官右丞相。
注：江丞相万里：江万里，南宋大臣，字子远，号古心，官左丞相，后殉国。
注：洞中仙：曲牌名。
注：自出洞来无敌手，得饶人处且饶人：旧时棋诀，指对弈。
注：渔家傲：词牌名。
注：夜静水寒渔不饵：唐代德诚禅师《拨棹歌》“夜静水寒鱼不食，满船空载月明归”，此处“渔不饵”为异文。
注：使牛子：曲牌名，待考。
注：且存方寸地，留与子孙耕：谚语，劝人留福。
# 韩襄毅公令
题解：韩雍与夏埙以拆字合谚语行令。
原：韩襄毅公雍与夏公埙饮，各出酒令。公欲一字内有大人小人，复以谚语二句证之，曰：“伞字有五人。下列众小人，上侍一大人。所谓有福之人人伏事，无福之人伏事人。”夏云：“爽字有五人。旁列众小人，中藏一大人。所谓人前莫说人长短，始信人中更有人。”
注：韩襄毅公雍：韩雍，字永熙，明景泰、成化时名臣，谥襄毅。
注：夏公埙：夏埙，待考。
注：伞字有五人：“傘”字中有五个“人”。
注：有福之人人伏事：“伏事”即服侍，“有福之人人服侍”，谚语。
注：爽字有五人：“爽”字有五个“人”，中为大“人”，旁为小“人”。
注：人前莫说人长短，始信人中更有人：俗语。
# 陈祭酒令
题解：陈询等人拆字行令，结句皆用诗书成句。
原：云间陈祭酒询，每酒酣耳热，有不平事及人有过，辄面发之。在翰林时，忤一权贵，出为州同。同僚饯行，有倡酒令各用二字，分韵相协，以诗书一句结之。陈学士循云：“轰字三个车，余斗字成斜。车车车，远上寒山石径斜。”高学士谷云：“品字三个口，水酉字成酒。口口口，劝君更尽一杯酒。”又一人云： “犇字三个牛，田寿字成畴。牛牛牛，将有事乎田畴。”陈云：“矗字三个直，黑出字成黜。直直直，焉往而不三黜！”合席大笑。
注：陈祭酒询：陈询，云间（松江）人，明代曾官国子监祭酒，待考。
注：酒酣耳热：酒喝到畅快时。
注：州同：知州的佐官，州同知。
注：陈学士循：陈循，字德遵，号芳洲，永乐进士，官至华盖殿大学士。
注：轰字三个车：“轰”由三“车”组成。
注：余斗字成斜：“余”“斗”合成“斜”。
注：远上寒山石径斜：杜牧《山行》诗。
注：高学士谷：高谷，字世用，明初官华盖殿大学士，待考。
注：品字三个口，水酉字成酒：“品”三口，“水”“酉”合成“酒”。
注：劝君更尽一杯酒：王维《送元二使安西》诗。
注：犇字三个牛，田寿字成畴：“犇”三牛，“田”“寿”合成“畴”。
注：将有事乎田畴：化用陶渊明《归去来兮辞》“将有事于西畴”。
注：矗字三个直，黑出字成黜：“矗”三“直”，“黑”“出”合成“黜”。
注：焉往而不三黜：《论语·微子》“直道而事人，焉往而不三黜”。
# 梅、郭二令相同
题解：拆字令后接俗语，杜渭江等人合作。
原：蜀人杜渭江〈朝绅〉令麻城，居官执法，不敢干以私。一日宴乡绅，梅西野倡令，要拆字入俗语二句。梅云：“单奚也是奚，加点也是溪，除却溪边点，加鸟却为鸡。俗语云：得志猫儿雄似虎，败翎鹦鹉不如鸡。”毛石崖云：“单青也是青，加点也是清。除却清边点，加心却为情。俗语云：火烧纸马铺，落得做人情。”杜答云：“单相也是相，加点也是湘。除却湘边点，加雨却为霜。俗语云：各人自扫门前雪，莫管他家瓦上霜。”又云：“单其也是其，加点也是淇。除却淇边点，加欠却为欺。俗语云：龙居浅水遭虾戏，虎落平阳被犬欺。”
注：杜渭江：杜朝绅，蜀人，麻城县令，待考。
注：麻城：今湖北麻城。
注：梅西野：待考。
注：单奚也是奚：“奚”加点为“溪”，去点加“鸟”为“鸡”。
注：得志猫儿雄似虎，败翎鹦鹉不如鸡：俗语。
注：毛石崖：待考。
注：火烧纸马铺，落得做人情：俗语，纸马铺被烧，以余物送人情。
注：各人自扫门前雪，莫管他家瓦上霜：俗语，元明戏曲小说多见。
注：龙居浅水遭虾戏，虎落平阳被犬欺：俗语。
原：苏州钱兼山、郭剑泉二宦初甚相善，晚以小嫌成讼。袁节推断之，未服。某官置酒解和，并邀袁公。郭为令曰：“良字本是良，加米也是粮。除却粮边米，加女便为娘。语云：买田不买粮，嫁女不嫁娘。”盖有所刺也。钱曰：“其字本是其，加水也是淇。除却淇边水，加欠便成欺。语云：马善被人骑，人善被人欺。” 袁曰：“禾字本是禾，加口也是和。除却和边口，加斗便成科。语云：官无悔笔，罪不重科。”某官执酒劝曰：“工字本是工，加力也是功。除却功边力，加糸便成红，语云：人无千日好，花无百日红。”
注：钱兼山、郭剑泉：苏州二宦，生平待考。
注：节推：节度推官，宋代州府属官，明代指推官。
注：买田不买粮，嫁女不嫁娘：谚语，意谓买田要看赋税，嫁女要看家底。
注：马善被人骑，人善被人欺：俗语。
注：官无悔笔，罪不重科：谚语，官判不能反悔，罪不再罚。
注：人无千日好，花无百日红：谚语，宋元以来常用。
# 刘端简公令
题解：刘端简公出令，取唐诗一句附以方言，讥邑大夫。
原：古亭刘端简公居乡，邑大夫或慢之。值宴会，端简公出令佐酒，各用唐诗一句，附以方言，上下相属。语云：“一枝红杏出墙来：见一半，不见一半。”含有诮意。一士夫云：“旋斫松柴带叶烧：热灶一把，冷灶一把。”邑大夫云：“杖藜扶我过桥东：我也要你，你也要我。”一时喧传，以为绝唱。
注：古亭刘端简公：刘端简，待考。
注：邑大夫：知县。
注：一枝红杏出墙来：宋叶绍翁《游小园不值》“一枝红杏出墙来”。
注：旋斫松柴带叶烧：唐诗，待考。
注：杖藜扶我过桥东：宋志南《绝句》“杖藜扶我过桥东”。
原：一说又云：“隔断红尘三十里，你也看不见我，我也看不见你。”解之者曰：“点溪荷叶叠青钱，你也使不得，他也使不得。”
注：隔断红尘三十里：唐诗句，宋孙觌诗有“隔断红尘三十里”，待考。
注：点溪荷叶叠青钱：杜甫《绝句漫兴》“点溪荷叶叠青钱”。
# 沈石田令
题解：沈周等人游虎丘，行拆字令。
原：沈石田、文衡山、陈白阳、王雅宜游饮虎丘千人石上。时中秋，月色大佳，石田行令云：“取上一字，下拆两字，字义相协。”倡云：“山上有明光，不知是日光、月光。”文云：“堂上挂珠帘，不知是王家的、朱家的。”陈云：“有客到馆驿，不知是舍人、官人。”王云：“半夜生孩儿，不知是子时、亥时。”各赏大觥。
注：文衡山：文徵明，号衡山，明代书画家。
注：陈白阳：陈淳，号白阳，明代画家。
注：王雅宜：王宠，字履吉，号雅宜山人，明代书法家。
注：虎丘：苏州名胜，千人石在其中。
注：大觥：大酒杯。
注：明光：“明”拆为“日”“月”，故云日光、月光。
注：王家的、朱家的：“珠”拆为“王”“朱”。
注：舍人、官人：“馆”拆为“舍”“官”。
注：子时、亥时：“孩”拆为“子”“亥”。
# 高丽僧令
题解：高丽僧与朝使以谐音行令。
原：高丽一僧陪宴朝使，戏行一令曰：“张良、项羽争一伞。良曰凉伞，羽曰雨伞。”朝使信口曰：“许由、晁错争一葫芦。由曰油葫芦，错曰醋葫芦。”
注：高丽：朝鲜王朝（时指李朝）。
注：朝使：朝廷使臣，此指明朝使臣。
注：凉伞：“张良”谐“凉”；羽谐“雨”。
注：许由：上古隐士，拒受尧让天下，洗耳。
注：晁错：汉景帝时御史大夫，被腰斩，“晁”谐“醋”。
注：由曰油葫芦：“由”谐“油”。
注：错曰醋葫芦：“错”谐“醋”。
# 都宪令
题解：都宪与兵官酒席互相讽刺，太监以俗语解围。
原：有镇边都宪与兵官不合。都宪于酒席间出令云：“天上有天河，地下有萧何。萧何手里持一本律，口称‘犯法之事莫做，发病之物莫吃。’”有所指于兵官也。兵官云：“天上有太阳，地下有张良。张良手里持一把剑，口称‘钢刀虽快，不斩无罪之人。’”时一太监在座欲为分解，即云：“天上有雪山，地下有寒山。寒山手里持一把扫帚，口称‘各人自扫门前雪，莫管他家瓦上霜！’”遂一笑而散。
注：都宪：都察院长官，此处指巡抚。
注：兵官：武官。
注：萧何：汉初丞相，制定律令。
注：发病之物莫吃：谚语，有病之物不吃。
注：张良：汉初谋臣，在此处持剑，“钢刀虽快”谚。
注：钢刀虽快，不斩无罪之人：谚语。
注：寒山：唐代诗僧，传说手持扫帚。
# 罗状元令
题解：罗洪先等以塑像为令，讥衣饰简陋。
原：《豫章诗话》云：罗状元念庵，与邹公、某公有寺观之集。邹指塑像出令曰：“祖师买巾，价只要轻。以是买不成，披发到于今。”某曰：“玉皇买伞，价只要减。以是买不成，头顶一片板。”罗曰：“观音买鞋，价只要捱。以是买不成，赤脚上莲台。”
注：豫章诗话：清代笔记，待考。
注：罗状元念庵：罗洪先，号念庵，明嘉靖八年状元。
注：邹公：待考。
注：祖师买巾：此令以寺中塑像拟句，“买巾”“买伞”“买鞋”。
注：玉皇：玉皇大帝。
注：观音：观世音菩萨。
注：莲台：佛座，莲花座。
注：捱：延，拖延。
# 《四书》令
题解：以《四书》典故作令。
原：有人为令云：“子路百里负米，不知是熟米、糙米？若是熟米，子路不对；若是糙米，子路请祷。”一人云：“子路宿于石门，不知开门、闭门？若是开门，由也升堂；若是闭门，子路拱而立。”
注：子路百里负米：《孔子家语》载子路为亲负米于百里之外。
注：子路不对：《论语·述而》“叶公问孔子于子路，子路不对”。
注：子路请祷：《论语·述而》“子疾病，子路请祷”。
注：子路宿于石门：《论语·宪问》“子路宿于石门”。
注：由也升堂：《论语·先进》“由也升堂矣，未入于室也”。
注：子路拱而立：《论语·微子》“子路拱而立”。
# 薛涛令
题解：薛涛与高骈行令，以字形应对。
原：薛涛辨慧。有黎州刺史作《千字文》令，带鱼禽鸟兽。乃曰：“有虞陶唐。”涛曰：“佐时阿衡。”其人谓语中无鱼鸟，行罚。薛曰：“衡字内有小鱼字。使君‘有虞陶唐’，都无一鱼。”坐客大笑。又高骈镇成都，命涛为一字令，曰：“须得一字象形，又须逐韵。”高曰：“口，有似没梁斗。”涛曰：“川，有似三条椽。”节度曰：“如何一条曲？”涛曰：“相公为西川节度使，尚使一没梁斗。至于穷酒佐，三条椽内一条曲，又何足怪？”
注：薛涛：中唐蜀地女诗人，字洪度，成都名妓。
注：黎州：今四川汉源一带。

# 金用元对
题解：金用元借潘姓与“番水”对句，答对机敏。
原：苏士金用元，每嘲人，诗歌俳语顷刻立就，争相传笑。一日在文内翰家浪谑，蒙师潘愠曰：“吾有一语，能对甘悔。曰：‘王大夫昆季筑墙，一土蔽三人之体。’”金即曰：“潘先生父子沐发，番水灌两牛之头。”满座大笑。
注：金用元：苏州士人，以诙谐善嘲著称，待考。
注：内翰：翰林的别称。
注：文内翰：姓文的翰林，待考。
注：蒙师：启蒙老师。
注：昆季：兄弟。
注：一土蔽三人之体：“王”可拆为“一”“土”，以下“三人”，拆字之意待考。
注：沐发：洗头。
注：番水灌两牛之头：“潘”可拆为“水”“番”，“牛头”之意待考。
# 三光日月星
题解：苏轼接待辽使，以“四德元亨利”对“三光日月星”。
原：元祐初，东直复除翰林学士，充馆伴北使。辽使素闻其名，思以奇困之。其国旧有一对曰“三光日月星”，无能属者，首以请于坡。坡唯唯，谓其介曰： “我能而君不能，亦非所以全大国之体。‘四诗风雅颂’，天生对也。盍先以此复之？”介如言。使方叹愕，坡徐对曰：“四德元亨利。”使睢盱欲起辩。坡曰： “而谓我忘其一耶？谨而舌，两朝兄弟邦，卿为外臣，此固仁祖之庙讳也。”使出其不意，大骇服。
注：元祐：宋哲宗年号（1086—1094）。
注：东直：疑指苏轼（号东坡），底本如此，待考。
注：馆伴：接待外国使者的官员。
注：北使：辽国使臣。
注：三光：日、月、星。
注：四诗：《诗经》分风、雅、颂，“四诗”指风、小雅、大雅、颂。
注：介：副使。
注：全大国之体：保全大国体面。
注：盍：何不。
注：睢盱：张目直视。
注：四德元亨利：《周易·乾》“元亨利贞”四德，缺“贞”字，因“贞”与仁宗赵祯同音，须避讳。
注：庙讳：已故君主的名讳。
注：仁祖：宋仁宗赵祯。
# 刘季孙
题解：刘季孙以《心经》咒语对《尚书》句，王安石大笑。
原：王荆公尝举书句语刘季孙曰：“念兹在兹，释兹在兹，名言兹在兹。有何可对？”季孙应声曰：“揭谛揭谛，波罗揭谛，波罗僧揭谛。”安石大笑。
注：王荆公：王安石，封荆国公。
注：刘季孙：北宋诗人，字景文，曾官隰州知州，苏轼友。
注：念兹在兹，释兹在兹，名言兹在兹：《尚书·大禹谟》句。
注：揭谛揭谛，波罗揭谛，波罗僧揭谛：《般若波罗蜜多心经》咒语，“揭谛”（去吧）。
# 戴大宾对
题解：戴大宾少时善对，所对多含讥刺。
原：戴大宾八岁游泮，主师指厅上椅属对云：“虎皮褥盖学士椅。”即对云：“兔毫笔写状元坊。”主师大奇之。十三中乡试，有贵公来谒其父，见戴戏庭侧，尚是一婴稚，以为业童子艺也，出一对曰“月圆”。即应曰“风扁”。问：“风何尝扁？”曰：“侧缝皆入，不扁何能？”又出一对曰“凤鸣”，即应曰“牛舞”。问：“牛何尝舞？”曰：“百兽率舞，牛不在其中耶？”贵公大加叹赏，询之，即大宾也，已成乡举矣。对语皆含刺云。
注：戴大宾：明代人，少年中举，待考。
注：游泮：入学为生员，泮宫即学宫。
注：属对：对对子。
注：状元坊：科举中状元所立的牌坊。
注：乡试：省试，中式者为举人。
注：业童子艺：学习童子的功课。
注：风扁：对“月圆”。
注：侧缝皆入：风从侧缝吹入，指“扁”可通过缝隙。
注：牛舞：对“凤鸣”。
注：百兽率舞：《尚书·益稷》“百兽率舞”。
注：乡举：乡试中举。
# 随口对
题解：解缙应对明成祖“色难”，及李东阳与庶吉士戏对。
原：文皇学谓解学士曰：“有一书句甚难其对，曰‘色难’。”解应声曰：“容易。”文皇不悟，顾谓解曰：“既云易矣，何久不属对？”解曰：“适已对矣。”文皇始悟，为之大笑。
注：文皇：明成祖朱棣，谥文皇帝。
注：解学士：解缙，字大绅，明初才子，参与编《永乐大典》。
注：色难：《论语·为政》“色难，有事弟子服其劳”，意为在父母面前保持和颜悦色最难。
注：容易：与“色难”相对。
原：李西涯居政府时，庶吉士进谒，有言“阁下李先生”者。公闻之，既相见，因曰：“请诸君属一对，云‘庭前花始放’。”众疑其太易，转思未工。各沉吟间，公曰：“何不对‘阁下先生’？”相赞而笑。
注：李西涯：李东阳。
注：政府：内阁。
注：庶吉士：翰林院中学习的新进士。
注：阁下李先生：对李东阳的称呼。
注：阁下先生：以“阁下”对“庭前”，“先生”对“花始放”（花先出生），戏用庶吉士的称呼作对。
注：相赞：互相称赞。
# 蔡霞山对
题解：蔡霞山督学，命生对“未明求衣”。
原：蔡霞山督学楚中，行部试士，见一生坐小舟读书。蔡呼生至，令其属对曰：“未明求衣。”生未答。蔡曰：“何不对‘临渴掘井’？”
注：蔡霞山：待考，疑为明代学官。
注：督学：提督学政。
注：楚中：湖广一带。
注：行部：巡视所属州县。
注：未明求衣：旧语，天未亮即起穿衣，形容勤于政事，常作“昧爽求衣”，待考出处。
注：临渴掘井：渴了才挖井，比喻事到临头才准备，与“未明求衣”相对。
# 孙临对
题解：孙临以“李金吾”对“韩玉汝”。
原：韩玉汝治秦川，尚严。人语曰：“宁逢暴虎，莫逢韩玉汝。”孙临滑稽，尤善对。或问曰：“‘莫逢韩玉汝，’当何以对？”临应声曰：“何怕李金吾？”闻者赏之。
注：韩玉汝：韩缜，字玉汝，北宋大臣，官至右仆射，治事严刻。
注：秦川：陕西，宋时韩缜曾知秦州或帅陕西。
注：暴虎：《论语·述而》“暴虎冯河”，指空手搏虎。
注：孙临：待考。
注：李金吾：金吾，执金吾，掌京师治安，此处以“李金吾”对“韩玉汝”，“玉汝”“金吾”相对。
# 世宗朝长对
题解：嘉靖帝出长联，词臣对答以媚上。
原：世宗皇帝修玄，学士争献清词为媚。时远方有献灵龟者，上自出对云：“赤水灵龟双献端。天数五，地数五，五五二十五数，数数合于道。道号元始天尊，一诚有感。”一词臣对云：“丹山彩风两呈祥。雌声六、雄声六，六六三十六声，声声闻于天。天生嘉靖皇帝，万寿无疆。”上喜甚，厚赉之。
注：世宗：明世宗嘉靖皇帝，崇信道教。
注：修玄：修习道教玄术。
注：清词：青词，道教斋醮时献给上天的表文，用朱笔写在青藤纸上。
注：赤水灵龟：赤水为神话中河流，灵龟为祥瑞。
注：天数五，地数五：《周易·系辞上》“天数五，地数五，五位相得而各有合”。
注：元始天尊：道教最高神“三清”之首。
注：丹山彩风：“风”当作“凤”，丹山产凤，凤为祥瑞。
注：雌声六、雄声六：古人称凤凰鸣声合六律六吕，“六六三十六声”。
注：嘉靖皇帝：明世宗年号嘉靖。
注：赉：赏赐。
# 朱云楚
题解：赣妓朱云楚借席间藕片对“栗绽缝黄见”。
原：赣妓朱云楚子卿，警慧知书。赵时逢遁可为守，尝会客，果实有炮栗。赵指之曰：“栗绽缝黄见。”坐客属对，皆莫能。楚辄曰：“妾有对。”取席间藕片以进曰：“藕断露丝飞。”赵大奇之。见《谈薮》。
注：赣：江西赣州。
注：朱云楚：待考。
注：赵时逢遁可：赵时逢，字遁可，待考。
注：炮栗：烤栗子。
注：栗绽缝黄见：栗子炮熟裂开，露黄肉。
注：藕断露丝飞：藕断丝连，对“栗绽缝黄”。
注：谈薮：笔记名，宋庞元英撰。
# 妓对
题解：妓女以“扇车扇”对“汤盏汤”。
原：有郡丞席上作对，属云：“酒热不须汤盏汤。”一妓对曰：“厅凉无用扇车扇。”见《文酒清话》。
注：郡丞：知府属官。
注：汤盏：盛热水的小盏。
注：扇车：风扇车，扇谷物用的农具。
注：文酒清话：笔记名，待考。
# 古人姓名谜
题解：以诗为谜，隐指朝官姓名；又以今事影射古人名。
原：元祐间，士夫好事者，取达官姓名为诗谜，如“长空雪霁见虹霓，行尺天涯遇帝畿。天子手中执玉简，秀才不肯著麻衣。”谓韩绛、冯京、王珪、曾布也。又取古人而传以今事，如“人人皆戴子瞻帽，君实新来转一官，门状送还王介甫，潞公身上不曾寒。”谓仲长统、司马迁、谢安石、温彦博。
注：元祐：宋哲宗年号。
注：士夫：士大夫。
注：诗谜：以诗作谜。
注：韩绛：北宋宰相，字子华。虹霓之“绛”，红色。
注：冯京：北宋状元，官至枢密使，字当世。
注：王珪：北宋宰相，字禹玉，“玉简”之玉。
注：曾布：北宋宰相，字子宣，“麻衣”之布。
注：子瞻帽：东坡帽，一种高筒帽，“子瞻”指苏轼。
注：君实：司马光字君实。
注：门状：拜见时递的名帖。
注：王介甫：王安石字介甫。
注：潞公：文彦博，封潞国公。
注：仲长统：东汉思想家；“人人皆戴子瞻帽”，东坡帽高筒，“长”扣“统”。
注：司马迁：西汉史学家；“君实转一官”，司马光（君实）迁官，扣“司马迁”。
注：谢安石：东晋名相；“门状送还王介甫”，王安石（字安石）还门状，扣“谢”。
注：温彦博：唐初宰相；“潞公身上不曾寒”，文彦博（潞公）身暖，扣“温彦博”。
原：“佳人佯醉索人扶，露出胸前白玉肤，夏入帐中寻不见，任他风雨满江湖。”隐贾岛、李白、罗隐、潘阆名谜。
注：佳人佯醉索人扶：“假倒”，谐“贾岛”。
注：露出胸前白玉肤：指“李白”，“白”。
注：夏入帐中寻不见：“罗帐隐”，指罗隐。
注：任他风雨满江湖：“潘阆”，潘阆有“满城风雨近重阳”之说，待考。
注：贾岛：中唐苦吟诗人。
注：李白：唐代大诗人。
注：罗隐：晚唐诗人。
注：潘阆：北宋诗人，字逍遥。
# 灯谜
题解：灯谜：诗谜分别暗射药名、病名。
原：“十谒朱门九不天，满头风雪却回来。归家懒睹妻儿面，拨尽寒炉一夜灰。”一药名：常山、砒霜、狼毒、焰硝；一病名：喉闭、伤寒、暴头、火丹。
注：十谒朱门九不天：多次拜谒权贵而不得志。
注：常山：药名，常用于截疟。
注：砒霜：毒药，砒石升华而成。
注：狼毒：药名，有毒。
注：焰硝：硝石，药名。
注：喉闭：病名，喉部闭塞。
注：伤寒：病名。
注：暴头：病名，头暴肿。
注：火丹：病名，即丹毒。
# 陈亚谜
题解：陈亚自作“亚”字谜。
原：陈亚自为亚字谜曰：“若教有口便哑，且要无心为恶。中间全没肚肠，外面任生棱角。”
注：陈亚：北宋人，字亚之，好谐谑。
注：若教有口便哑：“亚”加“口”为“哑”。
注：无心为恶：“亚”加“心”为“恶”。
注：中间全没肚肠：“亚”字中间空，无肚肠。
注：外面任生棱角：“亚”字外有棱角。
# 辛未状元谜
题解：袁舜臣以谜诗射“辛未状元”。
原：辛未会试，江阴袁舜臣作谜诗于灯上，云：“六经蕴籍胸中久，一剑十年磨在手。吉花头上一枝横，恐泄天机莫露口。一点累累大如斗，掩却半床何所有？完名直待挂冠归，本来面目君知否？”唯苏州刘瑊一见能识之，乃“辛未状元”四字。
注：辛未：干支，此处指会试之年。
注：会试：科举中的京城考试，在乡试之后。
注：江阴：今江苏江阴。袁舜臣：待考。
注：蕴籍：含蓄。
注：一剑十年磨在手：贾岛《剑客》诗“十年磨一剑”。
注：一点累累大如斗：谜面，射“状”或“元”字之类，待考。
注：完名直待挂冠归：挂冠即辞官归隐。
注：刘瑊：苏州人，待考。
注：辛未状元：谜底四字，谜面各句分扣之，具体待考。
# 招饮答谜
题解：遣书招客与答书，以拆字相隐。
原：《古今诗格》有遣书招客云：“板户公堂，斫脚露丧。”答云：“斑犬良赋，趋龟空肚。”板户，木门，“闲”字；公堂，官舍，“馆”字；斫脚，斩足，“踅”字；露丧，尸出，“屈”字。谓“闲馆踅屈”也。斑犬，文苟，“敬”字；良赋，尚田，“当”字；趋龟，走卜，“赴”字；空肚，欠食，“饮”字。谓“敬当赴饮”也。
注：古今诗格：书名，待考。
注：板户公堂，斫脚露丧：拆字谜面。
注：板户：木门，门字加木为“闲”。
注：公堂：官舍，“官”加“舍”为“馆”。
注：斫脚：斩足，“足”去脚，“踅”字。
注：露丧：尸出，“尸”加“出”为“屈”。
注：斑犬：文苟，“文”加“苟”为“敬”。
注：良赋：尚田，“尚”加“田”为“当”。
注：趋龟：走卜，“走”加“卜”为“赴”。
注：空肚：欠食，“欠”加“食”为“饮”。
# 开元寺
题解：客人在广陵开元寺题字谤僧，沙弥识破为“合寺苟卒”。
原：乾符末，有客寓广陵开元寺，不为僧所礼，题门而去。题云：“龛龙去东涯，时日隐西斜。敬文今不在，碎石入流沙。”僧众皆不解。有沙弥知为谤语，是“合寺苟卒”四字。
注：乾符：唐僖宗年号（874—879）。
注：广陵：扬州。
注：开元寺：唐代扬州名寺。
注：不为僧所礼：僧人不礼遇他。
注：龛龙去东涯：“龛”去“龙”为“合”。
注：时日隐西斜：“时”去“日”为“寺”。
注：敬文今不在：“敬”去“文”为“苟”。
注：碎石入流沙：“碎”去“石”为“卒”。
注：沙弥：未受具足戒的小僧。
# 大明寺
题解：令狐绹镇淮南，游大明寺题壁，班蒙解谜。
原：令狐相镇淮海日，尝游大明寺，见西壁题云：“一人堂堂，二曜同光，泉深尺一，点去冰傍。二人相连，不欠一边。三梁四柱烈火然，除却双钩两日全。” 诸宾幕莫辨。有支使班蒙曰：“一人，大字。二曜者日月，明字也。尺一者，十一寸，非寺字乎？冰去点，为水。二人相连，天字。不欠一边，下字。三梁四柱而烈火，无字。两日除双钩，比字也。是言‘大明寺水，天下无比’。”
注：令狐相：令狐绹，唐宣宗朝宰相，后镇淮南。
注：大明寺：扬州古寺。
注：二曜：日、月。
注：泉深尺一：谜面。
注：宾幕：宾客幕僚。
注：支使：幕府属官，掌文书。
注：班蒙：待考。
注：十一寸：“寺”字，“土”（十）加“寸”。
注：冰去点：“冰”去点为“水”。
注：二人相连：“天”。
注：不欠一边：“下”字，“不”去一笔。
注：三梁四柱烈火：“无”字。
注：比：“双钩”除两日，谜底为“比”字。
注：大明寺水，天下无比：大明寺水名列天下第五，唐张又新《煎茶水记》载。
# 皇华驿
题解：鬼诗谜，丁谓解为“独眠孤馆”。
原：《博异记》云：广州押衙崔庆成抵皇华驿，夜见美人，鬼也，掷书曰：“川中狗，百姓眼，马扑儿，御厨饭。”庆成不解。后丁晋公曰：“川中狗，蜀犬也。百姓眼，民目也。马扑儿，瓜子也。御厨饭，官食也。乃‘独眠孤馆’。”
注：博异记：唐谷神子所撰志怪小说。
注：押衙：节度使属下掌仪仗侍卫之官。
注：崔庆成：《博异记》人物，待考。
注：皇华驿：驿站名。
注：马扑儿：瓜子，“扑儿”指瓜子。
注：御厨饭：官食。
注：丁晋公：丁谓，宋真宗朝宰相，封晋国公；此条见宋人笔记附会，待考。
注：独眠孤馆：谜底，“川中狗”（独）“百姓眼”（眠）“马扑儿”（孤，瓜子）“御厨饭”（馆，官食）。
# 顾圣之谜
题解：顾圣之谜，打两僧两头睡。
原：吴人顾圣之作一谜云：“两头两头，中间两头。两头大，两头小。两头破，两头好。两头光，两头草。两头竖。两头倒。”乃二僧两头宿也。
注：顾圣之：吴人，待考。
注：两头两头：谜面。
注：两头光，两头草：待考。
注：两头宿：二僧各枕一头而睡。
# 祝枝山谜
题解：祝允明以佛语叉袋谜戏之。
原：祝枝山学佛语叉袋谜云：“无佛不开口，开口便成佛。盘多罗，诘多罗，佛多刹多，佛多难陀。”
注：祝枝山：祝允明，号枝山，明代书法家，诙谐，苏州人。
注：叉袋：口袋，布袋。
注：无佛不开口，开口便成佛：谜面，意指叉袋。
注：盘多罗，诘多罗：佛经咒语，音译。
注：佛多难陀：难陀，佛弟子名，此句待考。
