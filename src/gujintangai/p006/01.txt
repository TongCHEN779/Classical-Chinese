# 正文
题解：《无术》部卷首小引，子犹借温岐、梅询之事，说明不读书者未必不快活，但全然不识字又难免出丑，由此引出本部专收无学之人的笑谈。
原：〔子犹曰：夫人饭肠酒腑，不用古今浸灌，则草木布已。温岐悔读《南华》第二篇，而梅询见老卒卧日中，羡之，闻其不识字，曰：“更快活。”此皆有激言之，非通论也。世不结绳，人不面墙，谁能作聋瞽相向？但不当如弥正平开口寻相骂耳。集《无术》第六。〕
注：子犹曰：冯梦龙自称“子犹”，此为其评语；下同。
注：饭肠酒腑：谓只知吃喝、肚中无学问之人。
注：浸灌：浸润灌注，指以古今典籍熏陶。
注：草木布已：像草木一样生长罢了，意谓与草木无异。
注：温岐：即温庭筠，本名岐，晚唐诗人。
注：《南华》第二篇：《南华真经》即《庄子》，第二篇为《齐物论》。
注：梅询：北宋人，官至翰林侍读学士，此事见宋人笔记。
注：老卒：年老的兵卒。
注：更快活：比识字的人更快活。
注：有激言之：因有所激愤而说的话。
注：通论：持平通达的议论。
注：结绳：上古未有文字，结绳记事。
注：面墙：《论语·阳货》“其犹正墙面而立也与”，喻无知无识。
注：聋瞽：耳聋眼瞎之人，喻不通文墨者。
注：弥正平：即祢衡，字正平，东汉末名士，以狂傲骂曹操著称；“弥”当作“祢”。
注：集《无术》第六：本书《古今谭概》第六部为《无术》。
# 署名
题解：记北朝几位武将不识字，签名费力，闹出“穿锤”“吉”字的笑话，是《无术》部开篇。
原：厍狄干不能书，每署名，逆上画之，人谓之“穿锤”。又有武将王周者，署名先为“吉”，而后成其外。
注：厍狄干：北齐名将，字盛，《北齐书》本传称其不识文字，署名作“干”字倒书，世号“穿锤”。
注：逆上画之：从下往上逆着笔顺画字。
注：穿锤：形容所署之字像锤贯穿其中。
注：王周：北齐武将，名见《北齐书》，事迹待考。
注：署名：签署姓名。
原：《北史》：斛律金不识文字。初名敦，苦其难署，改名为金，从其便易；犹以为难，司马子如乃指屋角令况之。
注：《北史》：唐代李延寿所撰北朝四代正史。
注：斛律金：北齐名将，敕勒族，善歌《敕勒歌》，《北齐书》本传载其不识字。
注：司马子如：北魏、东魏、北齐重臣，曾教斛律金署名。
注：指屋角令况之：指着屋角让他仿效其形来写“金”字。
# 大字、大诺
题解：宋武帝与梁将陈伯之皆不通文字，一个靠写大字遮掩，一个只会写大“诺”字。
原：宋武帝素不能书，刘穆之教以纵笔作大字径尺。帝从之。一纸不过六七字便满。
注：宋武帝：南朝宋开国皇帝刘裕，出身寒微，少时不好读书。
注：刘穆之：刘裕谋臣，官至尚书左仆射，《宋书》有传。
注：纵笔作大字径尺：放笔写大字，直径一尺。
原：梁陈伯之为江州，目不知书。得文案，佯视之，唯作大“诺”。
注：陈伯之：南朝梁将，曾任江州刺史，后降北魏又归梁，《梁书》有传，记其“不识书”。
注：江州：治所在今江西九江。
注：文案：公文案卷。
注：诺：应允批语。
# 造字
题解：曹景宗不识字便自己造字，事见《南史》，属不学而强作之例。
原：梁曹景宗尚胜，每作书，字有不解，辄意造之。
注：曹景宗：南朝梁名将，字子震，破魏军于钟离，《梁书》有传。
注：尚胜：好强争胜。
注：意造：凭己意造字。
# 高手笔
题解：陈希闵不堪文笔，提笔半日写不出，窜改又多，被府吏取了两个绰号。
原：司直陈希闵，以非才任官。每秉笔，支颔半日不下。府史目之为“高手笔”。又窜削至多，纸面穿穴，亦名“按孔子”。
注：司直：官名，隋唐大理寺、御史台等设，掌复核案件。
注：陈希闵：唐人，事迹待考。
注：非才：才不称职。
注：支颔：以手托下巴。
注：府史：官府中的小吏。
注：高手笔：反语，讥其文笔拙劣。
注：窜削：涂改删削。
注：按孔子：谐音，“按孔”即纸上涂得孔洞；“按孔子”一语双关，取笑意。
# 不知置辞
题解：焦度不会措辞，想向齐高帝要个郡守，临场说成“无食”，反得赏米。
原：齐焦度材涩，欲就高帝求郡，不知置辞。人教之，习诵上口。监自陈，卒忘所教，大言曰：“度启公，度启公，度无食。”帝大笑曰：“卿何忧无食？”赐米百斛。
注：焦度：南齐将领，字文绩，勇力过人，《南齐书》有传。
注：材涩：才具生涩，不善言辞。
注：高帝：南齐高帝萧道成。
注：置辞：措辞，组织言辞。
注：习诵上口：背熟在口。
注：启：陈述、禀告。
注：斛：量器，宋以后十斗为一石，五斗为斛；此处百斛指大量米粮。
# 不习仪式
题解：游楚不懂朝仪，应声回答“诺”，皇帝只好一笑了之。
原：魏陇西太守游楚上殿，不习仪式。帝令侍中赞引呼“陇西太守前”。楚不觉大应称“诺”。帝笑劳之。
注：游楚：三国魏人，曾为陇西太守，《三国志》裴注引《魏略》有传。
注：陇西：郡名，治今甘肃临洮一带。
注：侍中：官名，侍从皇帝左右。
注：赞引：朝会时唱名引导的礼官。
注：劳：慰劳、安慰。
# 初学
题解：张敬儿不识字，以战功做到大官，才学读《孝经》《论语》，私下练习礼仪被妾侍偷笑。
原：张敬儿不识书，由战功起方伯，始学读《孝经》、《论语》。征护军，乃于密室屏人学揖让对答，空中俯仰，妾侍窥笑焉。
注：张敬儿：南齐名将，《南齐书》有传，本传称其“不识书”。
注：方伯：一方诸侯之长，此指地方长官。
注：《孝经》、《论语》：儒家启蒙经典。
注：护军：官名，护军将军，统领禁军。
注：屏人：使人退避。
注：揖让：宾主相见的礼节。
注：妾侍：侍妾。
# 照样举笏
题解：武臣中不识字者见别人在笏上抄好军数，也照样举笏，当众闹笑话。
原：宋祖召问武臣军数。其识字者，预写笏上，临问，高举笏，当面见字，随问即对。有一不识字者，不知他人笏上有字，照样举笏，近前大声曰：“启覆陛下，军数都在这里！”
注：宋祖：宋太祖赵匡胤。
注：军数：军队的数目。
注：笏：大臣上朝时手持的手板，可用来记事。
注：启覆：向上禀告。
# 龙战龙见
题解：记两则关于“龙”的无学笑话：梁冀把“龙战”当征兆，高阿那肱把星宿“龙见”当真龙。
原：朱穆以梁冀地势亲重，望其挟持王室，因推灾异奏记，以劝戒冀，而引《易》卦“龙战于野”之文，又荐种暠、栾巴等。明年，黄龙二见于沛国。冀无学，遂以穆“龙战”之言为验，于是引用暠、巴而举穆高第为侍御史。
注：朱穆：东汉人，字公叔，曾任冀州刺史，《后汉书》有传。
注：梁冀：东汉外戚，顺帝梁皇后之兄，专权跋扈。
注：奏记：下属向长官进呈的书函。
注：“龙战于野”：《周易·坤卦》上六爻辞，喻阴盛逼阳，战争与祸乱。
注：种暠：当作“种暠”，东汉名臣，有清名，《后汉书》有传。
注：栾巴：东汉人，官至尚书，以直言著称。
注：沛国：东汉郡国，治今安徽濉溪一带。
注：高第：考课优等。
注：侍御史：御史台属官，掌监察、弹劾。
原：北齐源师摄祠部，尝白高阿那肱“龙见当雩”。阿那肱惊曰：“何处龙见？其色何如？”师曰：“龙星初见，礼当雩祭，非真龙也。”阿那肱怒曰：“汉儿多事，强知星宿！”
注：源师：北齐人，名文宗，一说此为源彪，待考；曾任祠部郎中。
注：祠部：礼部下属官署，掌祭祀、礼仪。
注：高阿那肱：北齐权臣，鲜卑化人，《北齐书》入《恩幸传》。
注：龙见当雩：《左传》桓公五年“龙见而雩”，杜预注谓龙星（角亢）初现于夏历四月，因而举行求雨之祭。
注：雩：求雨的祭祀。
注：汉儿：北朝鲜卑对汉人的称呼，含轻蔑。
# 金熙宗赦草
题解：金熙宗因“龙见”之异欲大赦，译者曲解“寡昧”“小子”，反使学士张钧被杀。
原：金熙宗亶皇统十一年夏，龙见宫中，雷雨大至，破柱而去。亶惧，欲肆赦以禳之。召掌制学士张钧视草，中有“顾兹寡昧”及“渺予小子”之言。文成奏御，译者不解谦冲之义，乃曰：“汉儿强知识，托文字以詈上耳。”亶惊问故，译释之曰：“寡者，孤独无亲。昧者，不晓人事。渺为瞎眼。小子为小孩儿。”亶大怒，遂诛钧。
注：金熙宗亶：金朝第三代皇帝完颜亶。
注：皇统十一年：公元1151年，金熙宗皇统年号至九年止，此处纪年疑误，待考。
注：禳：祭祀祈祷以消灾。
注：肆赦：大赦。
注：张钧：金朝翰林学士，《金史》载其因草诏被杀。
注：顾兹寡昧：自谦为德寡识昧，诏书套语。
注：渺予小子：谦称，《尚书》有“渺渺予末小子”类语。
注：译者：女真语译员。
注：谦冲：谦虚。
注：视草：审阅诏书草稿。
# 谢眺诗杜荀鹤诗
题解：两则关于诗句的笑话：官员误以谢眺诗句，为杜若专取其出处；又有人对“野鹰征徭”一句望文生义。
原：贞观中，尚药奏求杜若，敕下度支。有省郎以谢眺诗云：“芳洲生杜若”，乃委坊州贡之。本州曹官判云：“坊州不出杜若，应由读谢眺诗误。华省名郎，作此判事，岂不畏二十八宿笑人？”
注：贞观：唐太宗年号。
注：尚药：尚药局，掌皇帝医药，此指尚药局官员。
注：杜若：香草名，可入药。
注：度支：户部下属，掌财政支出与物资调配。
注：省郎：尚书省各部郎官。
注：谢眺：当作“谢朓”，南朝齐诗人，诗句“芳洲有杜若”见《江上曲》、《之宣城》等。
注：坊州：治今陕西黄陵一带。
注：曹官：州府属吏。
注：华省：指尚书省，清贵之署。
注：二十八宿：古人二十八星宿，此处以天上星宿笑人。
原：经生多有不省文章。尝一邑有两人同官，其一或举杜荀鹤诗，称赞“也应无计避征徭”之句。其一难之曰：“此诗误矣！野鹰何尝有征徭乎？”举诗者解曰：“古人有言，岂有失也？必是当年科取翎毛耳。”
注：经生：治经者，指读死书者。
注：杜荀鹤：晚唐诗人，诗风浅近。
注：“也应无计避征徭”：杜荀鹤《山中寡妇》尾句，原写寡妇逃不过赋役，并非野鹰；此作者误引。
注：科取翎毛：按户摊派征收翎毛。
# 吕、李二将读诗
题解：张士诚旧部吕珍、李将军不懂诗意，把“不惊越女”“黄金合铸李将军”当作侮辱，贻为笑谈。
原：张氏据有平江日，其部将左丞吕珍守绍兴，参军陈庶子、饶介之在张左右。一曰，陈赋诗，饶染翰，题一纨扇以寄吕，云：“后来江左英贤传，又是淮西保相家。闻说锦袍酣战罢，不惊越女采荷花。”饶素负书名，且诗语俊丽，为作者所称。吕俾人读罢，大怒曰：“吾为主人守边疆，万死锋镝间，岂务爱女子而不惊之耶？见则必杀之！”又元帅李其姓者，杭州庚子之围解，颇著功劳。一士人投之以诗，将有求焉。其诗有“黄金合铸李将军”之句。李大怒，曰：“吾劳苦数年，止是将军，今年才得元帅。乃复令我为将军耶！”命帐下策出之。二事一时相传为笑。
注：张氏：指元末张士诚，据平江（今苏州）称吴王。
注：左丞：官名，此为张士诚政权官职。
注：吕珍：张士诚部将，守绍兴，后与朱元璋军战，《明史》有传。
注：绍兴：今属浙江。
注：参军：幕僚官。
注：饶介之：元末明初文人，字介之，与张士诚幕府往来，善书。
注：染翰：蘸笔作书。
注：纨扇：细绢团扇。
注：江左：长江下游以东，即江南。
注：淮西保相家：淮西指宋代淮西军，保相家为宋代保卫王室的将门；此指吕珍为淮西人，诗意称颂其出身。
注：锦袍：战袍。
注：越女采荷花：用西施事及越女采莲典，喻平定地方不扰民；吕珍却误会为羞辱。
注：庚子之围：元至正二十年（1360）张士诚军围杭州，次年解围，此指杭州之围，待考。
注：元帅：军中统帅官名。
注：黄金合铸李将军：用“黄金铸范蠡”类典故颂扬功臣；此处诗中“李将军”指汉李广，李元帅却嫌自己只是将军。
注：帐下：部下。
注：策：驱赶。
# 刘述引古
题解：刘述不识经典真意，探病时叫人吃酒肉，丧期中误引“父子聚麀”，表现其引古不当。
原：刘述字彦思，性庸劣。从子俣疾甚，述往候焉。其父母相对涕泣，述立命酒肉，令俣进之。皆莫知其意，或问之，答曰：“岂不闻《礼》云：‘有疾，饮酒食肉可也。’”又尝有丧，值其子亦居忧。客问：“其子安否？”答曰：“所谓‘父子聚麀’，何劳齿及？”
注：刘述：东晋、南朝人，事迹待考，此事出《世说新语》类笔记，待考。
注：庸劣：平庸低劣。
注：从子：侄子。
注：候：探望。
注：有疾，饮酒食肉可也：《礼记·曲礼上》“有疾，饮酒食肉”，指居丧者若有病可例外食肉。
注：居忧：居丧。
注：父子聚麀：《礼记·曲礼上》“夫唯禽兽无礼，故父子聚麀”，指父子共一母兽，喻乱伦；刘述全然误用。
注：齿及：提到。
# 宋鸿贵读律
题解：宋鸿贵不懂律文，将“枭首”误读成“浇手”，竟生断人手后用水浇之，实属荒唐。
原：宋鸿贵仕齐，为北平府参军。见律有“枭首”罪，误为“浇手”，乃生断兵手，以水浇之，然后斩决。
注：宋鸿贵：北齐人，事见《北齐书》或《北史》，待考。
注：北平府参军：北平府属下参军事，北平郡治今河北。
注：枭首：斩首并悬头示众，古代死刑。
注：浇手：此为误读。
# 锦衾烂兮
题解：康福因生病拥被而坐，幕客以“锦衾烂兮”称之，被误听作“烂奚”，遭怒斥。
原：晋康福镇天水日，尝有疾。幕客谒问，福拥锦衾而坐。客退，谓同列曰：锦衾烂兮！”福闻之，遽召言者，怒之曰：“吾虽产沙陀，亦唐人也，何得呼我为‘烂奚’？”
注：康福：五代后唐、后晋将领，沙陀人，镇天水时，《旧五代史》有传。
注：天水：郡名，今属甘肃，唐末五代为秦州。
注：幕客：幕僚。
注：锦衾烂兮：《诗经·唐风·葛生》“锦衾烂兮”，写悼念亡人，用以问疾不吉；一说客人系暗讽。
注：沙陀：西突厥别部，唐末建后唐、后晋。
注：烂奚：“奚”为北方民族，康福疑其被称为烂的奚人，故怒。
# 水厄对
题解：元乂以“水厄”戏问萧正德，正德误会为水灾，答“阳侯之难”，二人笑话不通。
原：侍中元乂为萧正德设茗，先问：“卿于水厄多少？”正德不晓乂意，答曰：“下官虽生水乡，立身以来，未遭阳侯之难。”
注：元乂：北魏权臣，《魏书》有传。
注：萧正德：梁武帝之侄，曾降北魏，后叛梁，《梁书》入《侯景传》。
注：设茗：摆设茶饮。
注：水厄：《世说新语·纰漏》，指饮茶之苦，因士人不惯茗饮戏称“水厄”。
注：阳侯之难：阳侯为传说中的波涛之神，此指水难、遇溺之灾。
注：水乡：江南多水之地。
# 三十而立
题解：韩简听讲《论语》，把“三十而立”误解为古人身体虚弱，到三十岁才能站立，可笑不学。
原：魏博节度使韩简，性粗质，每对文士，不晓其说，心常耻之。乃召一士人讲《论语》，至“为政”篇。明日喜谓同官曰：“近方知古人禀质瘦弱，年至三十，方能行立。”
注：魏博节度使：唐方镇名，治魏州（今河北大名）。
注：韩简：唐末魏博节度使，《旧唐书》有传，称其“性粗质”。
注：为政：《论语·为政》有“三十而立”。
注：禀质：天生体质。
# 董公遮
题解：考官不知《史记》“董公遮说汉王”之典，竟把“公遮”当成人名，笑倒一时。
原：淳熙丁未，洪景卢知举。一考官大笑绝倒，问之，则云：“试卷中有用‘董公遮说汉王’事，以‘公遮’为董三老之名。”
注：淳熙丁未：南宋孝宗淳熙十四年（1187）。
注：洪景卢：洪迈，字景卢，南宋学者，著《容斋随笔》。
注：知举：主持科举考试。
注：董公遮说汉王：《史记·高祖本纪》载新城三老董公拦住汉王，劝其为义帝发丧，“遮”为拦阻之意，非人名。
注：董三老：指新城三老董公，三老为乡官。
# 尧舜疑事
题解：欧阳修主持考试，士子问“尧、舜”是一事还是二事，欧公不动声色，教其不必用，一座笑倒。
原：欧文忠知贡举。省闱故事：士子有疑，许上请。文忠方以复古道自任，将明告以崇雅黜浮，以变文格。至日午，犹有喋喋弗已者，过晡稍<门见>。与诸公方酌酒赋诗，士又有叩帘者。文忠复出，所问士忽前曰： “诸生欲用尧、舜字，而疑其为一事或二事，唯先生教之。”观者哄然笑。文忠不动色，徐曰：“似此疑事，诚怕其误，但不必用可也。”
注：欧文忠：欧阳修，谥文忠。
注：知贡举：主持科举礼部考试，欧阳修于嘉祐二年（1057）主试。
注：省闱：礼部试，因由尚书省礼部主持，故称。
注：上请：向考官请教。
注：复古道：欧阳修倡导古文运动。
注：崇雅黜浮：推崇雅正、贬斥浮华文风，指其反对“太学体”险怪文风。
注：晡：申时，下午三至五时。
注：叩帘：敲帘询问，考场内有帘隔。
注：喋喋：多言。
# 不识羊太傅、陆士衡
题解：记张敬儿不知羊祜是谁，欲迁堕泪碑；刘道綦不识陆机，以为诗句是在戏弄他。
原：张敬儿开府襄阳，欲移羊叔子“堕泪碑”。纲纪白云：“此羊太傅遗德，不宜迁动。”敬儿怒曰：“太傅是谁？我不识！”
注：张敬儿：见前节。
注：开府：设置府署，自选僚属，高官之荣衔。
注：襄阳：今湖北襄阳。
注：羊叔子：西晋名将羊祜，字叔子，镇襄阳有德政，死后百姓立碑，望碑者无不流泪，称“堕泪碑”。
注：纲纪：州郡主簿等总理文书的属官。
注：羊太傅：羊祜死后追赠太傅。
原：刘道綦封营道侯，凡鄙无识。始兴王濬戏谓曰：“陆士衡诗云‘营道无烈心’，何意？”道綦曰：“下官初不识士衡，何忽见苦？”
注：刘道綦：南朝宋人，封营道侯，名当作“刘道产”类待考。
注：始兴王濬：宋文帝子刘濬，封始兴王。
注：陆士衡：西晋文学家陆机，字士衡。
注：营道无烈心：陆机《赴洛二首》“营道无烈心”，原指营求仕途之人无刚烈气节，此处谐“营道侯”，故戏之。
注：凡鄙：平庸鄙陋。
# 说韩信
题解：武人党进听到“说韩信”便以为是在背后说自己，将说书人打走。
原：党进镇许昌。有说话客请见，问：“说何事？”曰：“说韩信。”即杖去。左右问之，党曰：“对我说韩信，对韩信亦说我矣！”
注：党进：北宋初名将，《宋史》有传，称其不识字。
注：许昌：古许州，今河南许昌。
注：说话客：说书艺人，宋代有“说话”之伎。
注：杖：用刑杖打。
注：左右：身边人。
# 问欧阳修
题解：谢逸家中有举子问起欧阳修是何许人，可见其不学；谢逸之子觉得好笑，偷着走开。
原：谢无逸闲居，多从衲子游，不喜对书生。有一举子来谒，坐定，曰：“每欲问公一事，辄忘之。尝闻人言欧阳修，果何如人？”无逸熟视久之，曰：“旧亦一书生，后甚显达，尝参大政。”又问：“能文章否？”无逸曰：“文章也得。”无逸子宗野时七岁，闻之，匿笑而去。
注：谢无逸：谢逸，字无逸，北宋诗人，号溪堂，临川人，江西诗派。
注：衲子：僧人。
注：举子：应科举的读书人。
注：欧阳修：北宋文坛领袖，官至参知政事。
注：参大政：任参知政事，即副宰相。
注：宗野：待考。
# 不知杜少陵
题解：俗人闻“杜少陵可杀”一语，误以为林司业与彭正字在天竺谋杀，是不识杜甫的笑话。
原：宋乾道间，林谦之为司业，与王字彭仲举游天竺小饮。论诗，谈到少陵妙处，仲举微醉，忽大呼曰：“杜少陵可杀！”有俗子在邻壁，闻之，遍告人曰：“有一怪事，林司业与彭正字在天竺谋杀人。”或问：“所谋杀为谁？”曰：“杜少陵也，但不知何处人。”闻者绝倒。
注：乾道：南宋孝宗年号（1165—1173）。
注：林谦之：林光朝，字谦之，南宋学者，曾任国子司业。
注：司业：国子监副长官。
注：王字彭仲举：当作“王、彭仲举”，待考；彭仲举名未详。
注：天竺：指杭州天竺山，有天竺寺。
注：少陵：杜甫自号少陵野老。
注：正字：秘书省官名，校勘典籍。
注：绝倒：笑得前仰后合。
# 班固、王僧孺
题解：张由古不识《文选》中班固的文章，混淆班孟坚；又将《王僧孺集》说成“王僧襦集”，被杜文范讥笑。
原：张由古有吏才，而无学术，累历台省，于众中叹“班固有大才，而文章不入《选》”。或曰：“《两者赋》、《燕山铭》、《典引》等并入《文选》，何得言无？”张曰： “此是班孟坚。吾所笑者，班固也。”又尝谓同官曰：“昨买得《王僧襦集》，大有道理。”杜文范知其误，应声曰：“文范亦买得‘佛袍集’，倍胜‘僧襦’。”
注：张由古：唐人，事迹待考。
注：吏才：办事干练之才。
注：累历台省：多次历任御史台、尚书省官职。
注：班固：东汉史学家，字孟坚，著《汉书》。
注：《选》：《昭明文选》。
注：两者赋：当作《两都赋》，班固名篇，底本误。
注：《燕山铭》：班固《封燕然山铭》，此作“燕山”误。
注：《典引》：班固所作颂文，亦入《文选》。
注：王僧襦集：当作《王僧孺集》，王僧孺为南朝梁文学家，《梁书》有传；底本作“襦”。
注：杜文范：唐人，事迹待考。
注：佛袍集：与“僧襦”相对的戏语。
# 司马相如宫刑
题解：几个缙绅闲谈司马相如与文君，一人以宫刑戏之，袁太冲错把“司马”认作司马光，闭目叹“吃一吓”。
原：相国袁太冲，同二缙绅在宾馆中坐久。一公曰：“司马相如日拥文君，好不乐甚！”一公曰：“宫刑时却自苦也！”袁闭目摇首曰：“温公吃一吓！”
注：袁太冲：袁福征，字太冲，明代人，官至相国之类，待考；一说为袁炜之类，待考。
注：缙绅：官员的代称。
注：司马相如：汉代辞赋家，与卓文君私奔。
注：宫刑：阉割之刑，此指《史记》中司马迁受宫刑，此处张冠李戴。
注：温公：司马光，封温国公；此句取笑把司马迁与司马光混为一谈。
# 萧望
题解：达官不知“萧望之”本是三字全名，主张删去“之”字，暴露无知。
原：春明门外当路墓前有堠，题云“汉太子太傅萧望之墓”。有达官见而怪之，曰：“春明门题额正方，加‘之’字可耳。如此堠直行书，只合题‘萧望墓’，何必‘之’字？”
注：春明门：唐长安城东面之门。
注：堠：土堆，古代路旁标志里程或墓处的土墩。
注：萧望之：西汉大臣，官至太子太傅，《汉书》有传。
注：太子太傅：辅导太子之官。
注：题额：匾额、碑额。
注：直行书：竖写。
# 倒语
题解：“倒语”诗以倒置字句取笑不学之人，是明代文人游戏之作。
原：《诗林广记》载宋人“嘲倒语”诗，所谓“如何作元解，归去学潜陶”者，人皆知之。景泰中，吾苏一监郡不学，误呼石人为“仲翁”。或作诗嘲云：“翁仲将来作仲翁，皆因书读少夫工，马金堂玉如何入？只好州苏作判通。”又《水南翰记》云：英庙大猎时，有祭酒刘某和诗，以“雕弓”作“弓雕”。监生诗诮之曰：“雕弓难以作弓雕，似此诗才欠致标，若使是人为酒祭，算来端的负廷朝。”
注：《诗林广记》：南宋蔡正孙编的诗话选集。
注：嘲倒语：以倒文取笑。
注：如何作元解，归去学潜陶：“元解”应作“解元”，“潜陶”应作“陶潜”，即陶渊明。
注：景泰：明代宗年号。
注：吾苏：苏州，冯梦龙为苏州人。
注：监郡：知府属官，通判之类。
注：翁仲：传说秦时人，后用以称墓前石像。
注：判通：通判，知府佐官。
注：《水南翰记》：明代李如一撰笔记。
注：英庙：明英宗。
注：祭酒：国子监长官。
注：雕弓：雕饰的弓。
注：监生：国子监学生。
注：酒祭：“祭酒”倒置。
# 字误
题解：几则关于“误字”的笑谈，如韩昶改“金根车”为“银根车”、李林甫误读“杕杜”、萧炅读“伏腊”为“伏猎”等。
原：韩昶是吏部子，虽教有义方，而性颇暗劣。尝为集贤校理，史传有“金根车”，昶以为误，悉改为“银”。桓玄篡位，尚书误“春蒐”为“春菟”。
注：韩昶：韩愈之子。
注：集贤校理：集贤院的校勘官。
注：金根车：天子所乘之车，《后汉书》有载；韩昶以为误，改为“银根车”。
注：桓玄篡位：桓玄于东晋元兴二年（403）称帝建楚。
注：春蒐：春天田猎，“蒐”误作“菟”。
原：李林甫无学术。典选部时，选人严迥判语用“杕杜”二字。林甫不识，谓吏部侍郎韦陟曰：“此云杕杜，何也？”陟俛首不敢言。太常少卿姜度，林甫妻舅也。度妻诞子，林甫手书之：“闻有弄獐之喜。”客视之，掩口。
注：李林甫：唐玄宗朝宰相，口蜜腹剑，《新唐书》入《奸臣传》。
注：典选部：主持吏部铨选。
注：严迥：待考，一作“严迥”。
注：判语：科举中判词。
注：杕杜：《诗经·唐风》篇名，有“有杕之杜”。
注：韦陟：唐人，吏部侍郎。
注：姜度：李林甫的妻舅，官至太常少卿。
注：弄獐之喜：误写“弄璋”为“弄獐”，璋为玉器，生男之喜，“獐”为兽，故被笑。
注：掩口：掩口而笑。
原：《唐书》：吏部侍郎萧灵，素不学。尝读“伏腊”为“伏猎”。严挺之曰：“省中岂容有‘伏猎侍郎’！”《清夜录》：哲宗朝，谢悰试贤良方正，赐进士出身。悰辞云：“敕命未敢祗受。”乃以“抵”为“祗”，以“授”为“受”。刘安世奏曰：“唐有伏猎侍郎，今有抵授贤良。”李建勋罢相江南，南镇豫章。一日游西山田间茅舍，有老叟教村童，公觞于其庐。宾僚有曰：“犁号五脏刀斧，不宜多食。”叟笑曰：“《鹖冠》云：五脏刀斧，乃离别之离，非梨也！”就架取小帙，振拂以呈。公大叹服。
注：《唐书》：此指《新唐书》。
注：萧灵：当作“萧炅”，唐玄宗朝吏部侍郎，《旧唐书》载其不识“伏腊”。
注：伏腊：夏伏日与冬腊祭，指节令。
注：严挺之：唐玄宗朝名臣，《新唐书》有传。
注：《清夜录》：宋俞文豹撰笔记。
注：谢悰：当作“谢景温”类，待考；北宋哲宗朝人。
注：贤良方正：汉代科目名，宋代制科有类似。
注：祗受：恭敬接受。
注：刘安世：北宋名臣，以直言敢谏著称，号“殿上虎”。
注：李建勋：五代南唐宰相，罢相后出镇豫章。
注：豫章：今江西南昌。
注：西山：南昌西山。
注：《鹖冠》：即《鹖冠子》，战国道家著作。
注：五脏刀斧：此指犁，实为离别之“离”的引申，待考。
注：小帙：小卷册。
# 琵琶果
题解：莫廷韩与袁太冲讥笑“琵琶四斤”之误，屠赤水续成诗句，此为“枇杷”与“琵琶”之别。
原：莫廷韩过袁太冲家，见桌上有帖，写“琵琶四斤”，相与大笑。适屠赤水至，而笑容未了，即问其故。屠亦笑曰：“枇杷不是此琵琶。”袁曰：“只为当年识字差。”莫曰：“若使琵琶能结果，满城箫管尽开花。”屠赏极，遂广为延誉。
注：莫廷韩：莫是龙，字云卿，号廷韩，明代书画家。
注：袁太冲：见前。
注：琵琶四斤：应作“枇杷”，枇杷为果，琵琶为乐器。
注：屠赤水：屠隆，字长卿，号赤水，明代戏曲家。
注：延誉：为人宣扬名声。
# 茄字鸽字
题解：记两则写字出错的笑话：把“茄”写成“蒙”，又把“鸽”误写成“人日鸟”。
原：尚书赵从善子希苍，官绍兴日，令庖人造烧茄。判食次，问吏“茄”字。吏曰：“草头下著‘加’。”即援笔书“艸”，下用“家”字，乃“蒙”字矣。时人目曰“烧蒙”。
注：赵从善：南宋宗室，官至尚书，《宋史》有传。
注：希苍：待考。
注：庖人：厨师。
注：判食次：批阅菜单。
注：烧茄：烤茄子。
注：蒙：与“茄”字结构相近而误，“蒙”字上有艹头；原文意谓草字头下误写“家”。
原：南康王建封不识文义。族子有《动植疏》，俾吏录之。其载鸽妻，以传写讹谬，分一字为三，变而为“人日鸟”。建封信之，曰：“每人日开宴必首进此味。”
注：南康王建封：疑指某王子，事迹待考。
注：《动植疏》：记动植物的书，当指《毛诗草木鸟兽虫鱼疏》之类。
注：俾：使。
注：鸽妻：疑为“鸽”字，“鸽”字拆为“人日鸟”，即“人”“日”“鸟”三字。
注：人日：农历正月初七，传说此日有宴饮之俗。
# 蹲鸱
题解：张九龄与萧炅往来书信，因“蹲鸱”（芋头）二字被萧误作恶鸟，满座大笑。
原：张九龄一日送芋萧炅，书称“蹲鸱”。萧答云：“损芋拜嘉，唯蹲鸱未至。然寒家多怪，亦不愿见此恶鸟也。”九龄以书示客，满座大笑。
注：张九龄：唐玄宗朝宰相、诗人，《旧唐书》有传。
注：萧炅：见前，吏部侍郎，不学。
注：蹲鸱：大芋，因形似蹲伏的鸱鸮而得名，见《史记·货殖列传》。
注：损芋：谦词，谓承蒙赠芋。
注：寒家：谦称自己家。
注：恶鸟：鸱鸮，古人以为恶鸟。
# 昭执
题解：程覃不识“照执”，官吏指出少了四点，他便将“执”改添四点成了“热”，被诸生作传嘲笑。
原：程覃尹京日，有治声，唯不甚知字。尝有民投牒，乞执状造桥。覃大书“昭执”二字。民见其误，遂白之：“合是‘照执’，今漏四点”。覃取笔于“执”字下添四点，为“昭热”。痒舍诸生作传诮焉。

注：尹京：任京兆尹，即京城长官。
注：治声：政绩名声。
注：牒：公文、状子。
注：执状：持文凭。
注：昭执：误写。
注：照执：此为“照”字，“灬”即四点。
注：痒舍：疑当作“庠舍”，即学校。
注：作传诮：写传文嘲讽。
# 多感元年
题解：权龙襄误将“改年多感”当作改元，把书信当诏书宣读，闹出“多感元年”的笑话。
原：权龙襄，景龙中为瀛州刺史。遇新岁，京中人附书云：“改年多感，敬想同之。”乃将书呈判书以下云：“有诏改年号为‘多感元年’。”众大笑。龙襄不悟，犹复延颈，怪赦书来迟。
注：权龙襄：唐人，曾为瀛州刺史，《太平广记》引《朝野佥载》载其事。
注：景龙：唐中宗年号（707—710）。
注：瀛州：今河北河间一带。
注：改年多感：本是书信套语，意为年岁更新，感触良多。
注：判书：指官署中判署公文的长官。
注：多感元年：误以为新年号。
注：赦书：颁布大赦的诏书。
# 精粗

原：宋神宗时，叶温叟提举陕西保甲。一日，御批问“所隶诸州保甲精粗如何？”叶上札子言：“臣所教保甲，委是精粗。”帝得奏大笑，谓侍臣曰：“温叟将谓精粗是精确也。”
注：叶温叟：宋神宗时人，曾任陕西提举保甲。
注：陕西保甲：“提举”官，主管保甲法的推行。
注：御批：皇帝的批示。
注：札子：奏章的一种。
注：委是：确实是。
注：精确：此为误解。

注：叶义问：南宋官员，曾任枢密院事，督视江淮军马，《宋史》有传。

注：刘锜：南宋名将，曾大败金军于顺昌，《宋史》有传。

# 史思明诗
题解：史思明因寄樱桃的诗句顺序被建议调换，怒其“我儿居周贽之下”，以此笑其不学。

注：怀王：史思明之子史朝义，封怀王。
注：周贽：史思明部将，一说为史思明之子，待考。
注：叶：协韵。
# 党进读书
题解：党进不识字，临辞行时硬背两句“上古朴略”语，以示自己读过书。
原：党进不识一字。朝廷遣防秋，陛辞，故事例有敷陈。进把笏前跪，移时不能道一字，忽仰天颜厉声曰：“朕闻上古，其风朴略，愿官家好将息！”侍卫掩口。后左右问曰：“太尉何故念此二语？”党曰：“要官家知我读书。”
注：党进：见前。
注：防秋：古代为防备北方民族秋季入侵而屯兵。
注：陛辞：臣下临行向皇帝辞别。
注：敷陈：向皇帝陈说。
注：笏：见前。
注：官家：宋人对皇帝的称呼。
注：朕闻上古，其风朴略：古代颂扬帝王的套语，党进误作自己说的话。
注：太尉：宋代武臣高阶，党进曾官太尉。
注：将息：保养身体。
# 邑丞通文
题解：某县丞不通文墨，偏爱装腔用典，一句句用错，是对“强作解人”的讽刺。
原：某邑一丞，素不知文，而强效颦作文语。其大令病起，自怜消瘦，丞曰：“堂翁深情厚貌，如何得瘦？”又侍大令饮，而大令将赴别席，辞去。丞曰：“乞其馀不足，又顾而之他。”县令修后堂，颇华整。丞趋而进曰：“山节藻棁，何如其智也！”一日，县治捕强盗数人，令严刑讯鞫，盗哀号殊苦。丞从傍抚掌笑曰： “恶人自有恶人磨！”
注：一丞：县丞，县令的副手。
注：效颦：模仿。
注：大令：对县令的敬称。
注：堂翁：对县令的尊称。
注：深情厚貌：误将“深情厚谊”乱用。
注：乞其馀不足：此言“乞余”《孟子·离娄下》，齐人乞食之事，此处乱用。
注：山节藻棁：《论语·公冶长》，指雕刻山形的斗拱、画水藻的梁柱，原为讥臧文仲僭越，此处赞县令修后堂，误用。
注：何如其智：《论语·公冶长》“何如其智也”，原讥臧文仲不智；县丞赞为智，实为反用。
注：鞫：审讯。
注：恶人自有恶人磨：俗语。
# 中官通文
题解：太监杜渐等不通文墨而学人说文话，闹出“溘然”“焉用佞”等笑话。
原：嘉祐、治平间，有中官杜渐者，好与举子同游，学文谈，不悉是非。居扬州，凡答亲旧书，若此事甚大，必曰“兹务孔洪”，如此甚多。苏子瞻过维扬，苏子容为守，杜在坐。子容少怠，杜遽曰：“相公何故溘然？”其后子瞻与同会，问典客曰：“为谁？”对曰：“杜供奉。”子瞻曰：“今日不敢睡，真是怕那溘然。”
注：中官：宦官。
注：杜渐：宋代宦官，事迹待考。
注：嘉祐、治平：宋仁宗、英宗年号（1056—1067）。
注：兹务孔洪：此事甚大之意，文言套语。
注：苏子瞻：苏轼，字子瞻。
注：维扬：扬州。
注：苏子容：苏颂，字子容，北宋科学家，曾知扬州。
注：溘然：突然，用于指人去世，此处杜渐误用以问“相公何故溘然”（何故打盹）。
注：典客：接待宾客的官吏。
注：供奉：宦官官名。
原：时有一权珰，与缙绅饮。诸缙绅方剧谈，而珰者不能置一语，仰见屋上烟笼葱起，谬曰：“焉用佞！”众闻之，疑珰者诮己。及移时，复仰视曰：“烟太佞！”四座大笑，疑遂释。
注：权珰：有权势的宦官。
注：缙绅：官宦。
注：烟笼葱起：烟气升起如葱，指屋上炊烟。
注：焉用佞：《论语·公冶长》“焉用佞”，意为何必要口才；此处误以为“烟用佞”。
注：烟太佞：谐音“焉用佞”，闹笑话。
原：《广记》：唐有内大臣学作别纸言语。凤翔节度使寄柴数车，回书谢云：“蒙惠‘也愚’若干。”
注：《广记》：《太平广记》。
注：别纸：书信附纸，用以致谢或另说他事。
注：柴数车：几车柴。
注：也愚：“也”字误用，此谓“蒙惠也愚若干”，指柴。
# 中官出对
题解：太监府中历事监生考试，太监让以对句取士，监生以“尧舜骑病猪”应对，太监竟大加称赞。
原：《耳谭》：太监府有历事监生，遇大比，亦是本监考取，类送乡试。一珰不深书义，曰：“今不必作文论，只一对佳者，便取。”因出对云：“子路乘肥马。”诸生俯首匿笑。一黠者对云：“尧舜骑病猪。”珰大称善。
注：《耳谭》：明代笔记，王同轨著。
注：历事监生：国子监生到各衙门实习历练者。
注：大比：三年一次乡试。
注：乡试：省一级科举考试。
注：不深书义：不精通经书文义。
注：子路乘肥马：《论语·雍也》“乘肥马”，“子路”对仗的下联应为人名，此处太监出对。
注：尧舜骑病猪：与“子路乘肥马”对仗，谐“病”对“肥”，“猪”对“马”，意在嘲弄太监不学。
# 史学
题解：以王莽“紫色蛙声”语被误认为形容其相貌，说明自诩史学者亦会不读原文。
原：《王莽传》赞云：“紫色蛙声，馀分闰位。”谓以伪乱真也。颜之推共人言及莽状，一俊士自许史学，名价甚高，乃云：“王莽非直鸱目虎吻，亦且紫色蛙声。”
注：《王莽传》赞：《汉书·王莽传》赞语，班固评王莽。
注：紫色蛙声，馀分闰位：紫为间色，蛙声为淫声，喻王莽伪乱正统，篡位为“馀分闰位”。
注：以伪乱真：用虚假冒充真实。
注：颜之推：北齐、隋文学家，著《颜氏家训》。
注：鸱目虎吻：《汉书·王莽传》“莽为人侈口蹶颔，露眼赤精”，鸱目虎吻是《汉书》用语，指凶相。
注：俊士：才俊之士。
# 强作解字
题解：两则不学而强作解的笑话：朱某以“冯妇”为美妇，姜夔上书议乐却不识锦瑟。
原：会稽朱某以贩茶鬻官，皆呼为“茶官”，素不学。偶于姻家遇词客，印证今古，谈及宣尼，击节曰：“据如此说，是一才子矣！”又言冯妇，则曰：“果是当时一美妇人，予闻久矣！”近临溪人姚京，与村学究孙一经夏日纳凉，顷之云翳。孙曰：“必有大风。”姚诘之，曰：“夏云多奇风。”闻者肠断。
注：会稽：今浙江绍兴。
注：贩茶鬻官：贩茶并买官。
注：姻家：亲家。
注：宣尼：孔子，汉平帝追谥“褒成宣尼公”。
注：击节：赞叹，以手打拍子。
注：冯妇：《孟子·尽心下》载晋人冯妇善搏虎，后复为士所笑，“冯妇”是男子。
注：临溪：地名，待考。
注：学究：旧时塾师，也指迂腐儒生。
注：云翳：阴云遮蔽。
注：夏云多奇风：用陶渊明《四时》“夏云多奇峰”，原作“峰”，此处讹为“风”。
注：肠断：笑到肠痛。
原：庆元间，有士人姜夔上书，乞正奉常雅乐。诏赴太常同寺官校正。乐师赍出大乐，首见锦瑟，指问何乐。众方讶其正乐不识乐器，既知为瑟，乃令乐师曰：“语云‘鼓瑟希’，未闻弹之。”众官咸笑而散，其议遂寝。

注：奉常：太常，掌礼乐祭祀。
注：雅乐：宫廷典礼所用正乐。
注：太常：太常寺。
注：大乐：古代宫廷乐。
注：锦瑟：绘有锦纹的瑟，李商隐有诗名《锦瑟》。
注：鼓瑟希：《论语·先进》“鼓瑟希，铿尔”，指曾点弹瑟渐稀；谓鼓瑟尚未听闻，故笑。
注：寝：搁置。
# 《公羊传》
题解：甲欲谒县令，临时抱《公羊传》，被问“谁杀陈他”，吓得赤足逃出，笑其不学又胆小。

# 祭文策问
题解：黄陂季生满口怪词，代写祭母文竟通篇用其怪词；另有叶生出的策题东拉西扯，皆以文字错乱取笑。
原：《谑浪》云：黄陂季生无学，好弄笔。求人文稿曰“文犒”，见耒耜曰“来报”，见唾咳曰“垂亥”，每于尺牍中用“嗬嗬”，称医家曰“国首”，简亵曰“简艺”，租粮曰“相量”，写人号下又加“尊号失记”，写过己名，又书“名具别幅”。此等不可胜数，传为笑谈。一日母死，托邑人段祺作堂祭文。段代为言曰：“某年月日，儿某举亡母柩，就封某山，某不敢索文犒于人，谨写某胸中所有而言曰：“呜呼！躬秉来报，二十馀年，垂亥不闻，又经一年。人皆嗬嗬，我泪如泉，方母病剧，国首难寻。仓忙举事，简艺殊深。大荒之后，相量少足。诸亲俱在，无人不哭。尊号失记，母心如烛。各有姓名，具有别幅。”
注：《谑浪》：当指《笑谈谑浪》，明人笑话集，作者待考。
注：黄陂：今湖北武汉黄陂区。
注：文犒：“稿”误作“犒”。
注：耒耜：古代翻土的农具。
注：来报：与“耒耜”谐音误读。
注：垂亥：与“唾咳”谐音。
注：嗬嗬：叹息声，此处乱用。
注：国首：与“国手”类，谓名医。
注：简亵：“简慢”，此处误作“简艺”。
注：相量：“商量”之谐音，此处指租粮。
注：尊号失记：不记得别号。
注：名具别幅：姓名另附纸上。
注：段祺：此为托名，待考。
注：堂祭：灵堂中的祭礼。
注：柩：装殓遗体的棺材。
注：大荒之后：灾荒之后。
注：如烛：心中明白、如烛火般。
原：钱塘叶生少学识。有假作叶策题问云：“《孝经》一序，义亦难明，且如‘韦昭王’是何代之主？‘先儒领’是何处之山？孔子之志四时常有也，何以独言‘我志在春’？孔子之孝四时常行也，何以独言‘秋行在孝’？既曰‘夫子殁’，而又何以‘鲤趋而过庭’？”
注：钱塘：今浙江杭州。
注：叶生：钱塘叶姓书生。
注：策题：科举策问试题。
注：《孝经》一序：指《孝经序》，唐玄宗御注。
注：韦昭王：《孝经序》无此，当为“韦昭”误解，笑其不识。
注：先儒领：疑为“先儒颁”之误，此处作地名，亦笑其不通。
注：我志在春：《孝经钩命决》载孔子言“吾志在《春秋》，行在《孝经》”，此处误解为春秋季节。
注：夫子殁：孔子去世。
注：鲤趋而过庭：《论语·季氏》载孔鲤快步经过庭院，孔子教其学《诗》《礼》；此言孔子已殁怎能见鲤，是不通。
# 袭旧
题解：唐阳滔抄袭旧文，宁破窗取旧稿；东汉有人抄袭葛龚奏记却连名一同抄，均为剽袭之笑谈。
原：唐阳滔在中书，文皆抄袭。时命制敕甚急，而令史持库钥他适，苦无旧本检阅，乃斫窗跃入得之。时号为“斫窗舍人”。
注：阳滔：唐人，中书舍人，事见《太平广记》，待考。
注：中书：中书省，掌起草诏令。
注：制敕：皇帝诏令。
注：令史：官署中的书记。
注：库钥：库房钥匙。
注：斫窗：砸开窗户。
注：舍人：中书舍人。
原：桓帝时，有辟公府掾者，倩人作奏记。人不为作，因语曰：“梁国葛龚先作记文可用。”遂从人言誊写，不去龚名姓。府公大惊，罢归。时人语曰：“作奏虽工，宜去葛龚。”
注：桓帝：东汉桓帝刘志。
注：辟：征召任职。
注：公府掾：三公府的属官。
注：倩人：请人代笔。
注：奏记：下对上的书函。
注：梁国：汉国名，治今河南商丘。
注：葛龚：东汉文人，善文，事见《后汉书·文苑传》。
注：府公：三公。
注：作奏虽工，宜去葛龚：谚语，嘲讽抄袭不去原作者名。
# 改制词
题解：唐玄宗要拜苏颋为相，令萧嵩草制，词中“瑰宝”犯颋父苏瑰之名讳，嵩苦思改动，玄宗讥其“虚有其表”。
原：唐玄宗尝器重苏颋，欲倚以为相，秘密不欲令左右知。迨夜艾，乃令草诏，访于侍臣曰：“外庭谁直宿？”命秉烛召来。至则中书舍人萧嵩。上即以颋姓名授嵩，令草制书。既成，词中有“国之瑰宝”。上寻绎三四，谓嵩曰：“颋，瑰之子。朕不欲斥其父名，卿为刊削之。”上仍令撒帐中屏风与嵩。嵩惭惧流汗，笔不能下者久之。上以嵩抒思移时，必当精密，不觉前席以观。唯改曰“国之珍宝”，他无更易。嵩既退，上掷其草于地曰：“虚有其表耳！”
注：唐玄宗：李隆基。
注：苏颋：苏瑰之子，唐玄宗时宰相，封许国公，《旧唐书》有传。
注：夜艾：夜深。
注：草诏：起草诏书。
注：直宿：值夜。
注：中书舍人：中书省官，起草制诰。
注：萧嵩：唐玄宗朝宰相，《旧唐书》有传。
注：制书：诏书。
注：瑰：苏颋之父苏瑰。
注：刊削：删改。
注：帐中屏风：撤去帐中的屏风，赐给萧嵩，指玄宗体恤；一说“撒”字疑为“撤”。
注：前席：将坐席向前移，表示专注。
注：虚有其表：徒有外表，实则无才。
# 判鸟翎
题解：梁士会判文用“鸟翎”二字太多，改为“雁翅”仍是翻来覆去，传为笑柄。
原：唐灵昌尉梁士会，官科鸟翎，里正不送，举牒判曰：“官唤鸟翎，何物里正，不送鸟翎？”佐使曰：“公大好判，但‘鸟翎’太多。”会改曰：“官唤鸟翎，何物里正，不送雁翅？”闻者笑之。
注：灵昌：唐县名，今河南滑县一带。
注：尉：县尉，县令佐官，管治安。
注：梁士会：唐人，事见《朝野佥载》。
注：官科：官府摊派。
注：鸟翎：鸟羽，用作箭羽。
注：里正：唐代乡里基层管理者。
注：举牒：拿起公文。
注：佐使：下属小吏。
注：雁翅：雁翼之羽。
# 朱巩一联
题解：南唐学士朱巩一联粗俗却自夸，借“好物不在多”自我解嘲。
原：南唐元宗会群臣赋诗。学士朱巩短于韵语，竟日不能终篇，止进一联，又极鄙俚，乃自炫曰：“好物不在多。”
注：南唐元宗：李璟。
注：朱巩：南唐学士，事迹待考。
注：韵语：诗歌。
注：鄙俚：粗俗。
注：自炫：自我夸耀。
# 约法三章
题解：魏长齐才学平常，虞存嘲他入仕须“约法三章”，魏只一笑，写其雅量。
原：魏长齐雅有体量，而才学非所经。初宦当出，虞存嘲之曰：“与卿约法三章：读者死，文笔者刑，商略抵罪！”魏怡然而笑。
注：魏长齐：东晋人，魏顗，字长齐，《晋书》有传。
注：体量：气度宽宏。
注：虞存：东晋人，擅文，《晋书》有传。
注：约法三章：汉高祖入关与父老约法三章，此处戏用。
注：文笔：指作文。
注：商略：品评议论。
注：怡然：安然。
