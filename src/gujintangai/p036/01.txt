# 正文
题解：《杂志》部序语：冯梦龙称史传、稗官、客谈均不能尽，遇奇事如获珍珠，因不忍遗弃而编为《杂志》，点明本部为全书第三十六部。
原：〔子犹曰：史传所载，采之不尽；稗官所述，阅之不尽；客座所闻，录之不尽。中流失船，一壶千金。谈诸方畅，谑笑纷遝，忽焉喙短词穷，意败矣；尔时得一奇事，如获珍珠船。因不忍遗，置为《杂志》第三十六。〕
注：子犹曰：冯梦龙自称，下为评语。
注：稗官：古代采集民间街谈巷语的小官，后指小说家。
注：客座所闻：宾客座谈所闻。
注：中流失船，一壶千金：《鶡冠子》“中流失船，一壶千金”，喻平时不值钱之物在紧要关头极贵重。
注：谑笑：戏笑。
注：纷遝：纷繁杂沓。
注：喙短词穷：无话可说。
注：珍珠船：陈继儒有《珍珠船》，指汇集珍异之书，此处喻得奇事如获珍宝。
注：《杂志》第三十六：《杂志》为全书第三十六部，所收杂事。
# 勇可习
题解：魏杜袭任西鄂长时，柏孝长在刘表攻城时先怕后勇，说“勇可习也”，是练胆的趣事。
原：魏杜袭为西鄂长。刘表攻西鄂时，柏孝长在城中，入室闭户，牵被覆头，相攻半日，稍敢出面。其明，侧立而听。二日，出户问消息。四、五日后，乃负楯亲斗，语袭曰：“勇可习也！”
注：杜袭：三国魏官员，字子绪，曾任西鄂长，后官至尚书。
注：西鄂：汉县名，在今河南南阳北。
注：刘表：东汉末荆州牧。
注：柏孝长：待考，《三国志》作“柏孝长”。
注：楯：盾牌。
# 真主奇征
题解：明太祖幼时以青白纸旗指挥群鹅，一只花鹅无所适从，被视为真主的奇兆。
原：我太祖幼时，尝见群鹅游于庭。戏以青白二纸旗左右竖立，命之曰：“青者立青旗下，白者立白旗下。”群鹅应声如命而往。一花鹅不知所适，往来于青白之间。
注：我太祖：明太祖朱元璋。
注：花鹅：毛色花斑的鹅。
注：所适：该去的地方。
# 周尹氏
题解：周尹氏五代同居，饥荒时设粥会食，声闻数里，是大家族共食的盛况。
原：周尹氏贵盛，五叶不别。天饥，作粥会食，声闻数里外。
注：尹氏：周代世族。
注：五叶：五代。
注：不别：不分家。
注：作粥会食：煮粥聚食。
# 八字无凭
题解：赵普与军校同年同月同日同时生，赵升迁则军校受罚，说明八字不足凭信。
原：昔赵韩王时，有军校与同年、月、日、时。若赵有一大迁除，军校则一大责罚；小迁转，则军校微有谴叱。
注：赵韩王：赵普，封韩王，宋太祖、太宗朝宰相。
注：军校：下级军官。
注：大迁除：大的升迁。
注：责罚：处罚。
注：谴叱：斥责。
# 帝王言命
题解：明太祖微行国子监，听老生员叹命，应声作答，是帝王论命的故事。
原：太祖尝至国子监，有厨人进茶，偶称旨，诏赐冠带。有老生员夜独吟云：“十载寒窗下，何如一盏茶。”帝微行，适闻之，应声云：“他才不如你，你命不如他。”
注：太祖：明太祖朱元璋。
注：国子监：明代最高学府。
注：称旨：合意。
注：冠带：官帽与官服，此处指赐予官身。
注：生员：入学的秀才。
注：十载寒窗下，何如一盏茶：感叹读书不如厨人送茶得赏。
注：微行：微服出行。
# 岳神戏梦
题解：东岳神以梦示“问秦枣三孺人”，乡试之人遇丐妇之骂声“入你娘的到会中”，竟应验中举，是岳神戏梦。
原：浮碧山之神，唯东岳最灵，凡以梦祈者应如响。邑中有父子同应乡试者，褥于岳。以梦示曰：“汝往问秦枣三孺人可矣。”二人未解所谓。偶下山，见一丐妇浣于河，问之曰：“秦枣三孺人者为谁？”其妇张目吒曰：“汝奚问为？”盖此妇与邑少年秦枣三狎，故有是号，忽闻其语而心怪之也。二人犹未悟，对曰：“吾欲问我父子谁中？”其妇骂曰：“入你娘的到会中！”其年，父果中。
注：浮碧山：待考。
注：东岳：东岳大帝，泰山之神。
注：乡试：明清省级考试。
注：褥于岳：在岳庙中铺褥子过夜，求梦。
注：孺人：明清七品官妻封号，此处指丐妇与人私通者。
注：浣：洗衣。
注：狎：亲昵，此处指私通。
注：入你娘的到会中：骂语，“到会中”谐“倒会中”，借“中”字解为乡试中式；此条为骂话而成吉兆。
# 造化弄人
题解：两则梦应的故事：管九臬梦神授七题而落第，莆田秀才梦遇官被语意双关。
原：万历癸未，管明府九臬，始与同侪赴公车选，梦神人属以七题。次早，构房间文佳者熟读之。及入试，七题果符所梦。因信笔以所熟文写就，不暇构思，自喜得神助，必中矣。乃是年主考厌薄旧文，尽括坊间文入内磨对，凡同者掷之。管以是下第，选授富顺令。
注：万历癸未：万历十一年（1583）。
注：管明府九臬：管九臬，曾任富顺知县，待考。
注：公车：举人赴京会试。
注：房间文：坊间房稿，考试范文。
注：坊间文：书坊所刻文章。
注：磨对：对照。
注：富顺：今四川富顺。
原：莆田一秀才往九鲤湖求梦。梦曰：“明日所遇官，即尔功名。”次日遇锺御史、李大参，皆其里人。生大喜，告以故。李曰：“学锺先生。”锺曰：“学李先生。”皆言当如其官也。后仅以岁荐任教职卒。人始悟为“学中先生、学里先生”云。
注：莆田：今福建莆田。
注：九鲤湖：福建仙游，传说灵验，求梦之地。
注：锺御史、李大参：莆田籍官员，待考。
注：岁荐：岁贡，明清选送国子监的贡生。
注：教职：府州县学的教官。
注：学中先生、学里先生：谐“学锺（中）先生、学李（里）先生”，即官学教官。
# 恶虫啮顶
题解：两个“恶虫啮顶”故事：吴与弼因蝎螫而无法答对，史寺丞因被蜈蚣咬而落泪反得升官，见敬君者不遇、欺君者蒙恩，是命数使然。
原：天顺间，征士吴与弼到京。英宗御文华殿召对，吴默然无应，唯曰：“吾臣上疏。”众方骇异，上不悦，架起。吴出至左顺门，除帽视之，有蝎在顶，螫皮肉红肿。方知其适不能答者，以螫故也。宋淳熙间，史寺丞轮对。适言高宗某事，史忽泪下。上问故，对曰：“因念先帝旧恩耳！”孝宗亦下泪。明日御批史为侍郎。不知当时乃为蜈蚣所啮，故下泪也。呜呼，均为恶虫啮顶，敬君者不遇，欺君者蒙恩，岂非数哉！”
注：天顺：明英宗年号。
注：征士：被征召的隐士。
注：吴与弼：明初理学家，号康斋，天顺元年被召入京。
注：英宗：明英宗朱祁镇。
注：文华殿：明宫殿，皇帝召见大臣处。
注：召对：被召回答问题。
注：左顺门：奉天殿左侧的门。
注：螫：蜇。
注：宋淳熙：宋孝宗年号。
注：史寺丞：寺丞，官名；其人待考。
注：轮对：宋制百官轮流上殿奏对。
注：高宗：宋高宗赵构。
注：孝宗：宋孝宗赵昚。
注：御批：皇帝批示。
注：数：命数。
# 张生失金
题解：张姓商人梦金锭辞别，次日往江头寻回，韩饼家分金，四锭金分饼中，被四乞丐换了，金终归韩家，说明财命有数。
原：嘉靖时，杭人张姓者，自幼为小商，老而积金四锭，各束以红线，藏于枕，忽夜梦四人白衣红束，前致辞曰：“吾等随子久，今别子去江头韩饼家。”觉而疑之，索于枕，金亡矣。踌躇叹息，之江头询韩，果得之。张告韩曰：“君曾获金四锭乎？”韩惊曰：“君何以知？”张具道故。韩欣然出金示张，命分其半。张固辞谢，遂出门。韩留觞之，举一锭分为四，各裹饼中，临行赆之。张受而各，中途值乞者四，求之哀，各济以饼一。四乞诸计曰：“此饼巨而冷，不可食，何不至韩易小而热者乎？”遂之韩，韩笑而易之。
注：嘉靖：明世宗年号。
注：小商：小本商人。
注：白衣红束：白衣、红腰带，指银锭上红线。
注：江头：杭州钱塘江边。
注：踌躇：犹豫。
注：赆：送行的礼物。
注：觞：请酒。
# 奇蹇
题解：记卢婴、王休佑、雍瞻若三位命运奇蹇之人，逢人便带来灾祸。
原：昔淮南卢婴平生奇蹇，谓至人家，其家必遭横祸，或小儿堕井，幼女失火。王休佑所执水手板，得者必不祥。近雍瞻若野王，多能而贫甚。始客鲁，鲁人皆避畏之，呼为：“耗神”。已造一讼者及病者家，二家俱败死。比至京，京中复闻斯语。会二人博，而雍坐负者旁。或语负者，谓胜者教之。负者怒，殴之几死。
注：卢婴：待考。
注：至人家：到某户人家。
注：横祸：意外灾祸。
注：王休佑：待考。
注：水手板：水手所持的木板。
注：雍瞻若：明人，待考。
注：野王：待考。
注：耗神：消耗精神的神，谐“耗财之神”。
注：讼者：打官司的人。
注：博：赌博。
# 嫁娶奇合
题解：嘉靖间昆山民冲喜，女家以少子扮女出嫁，两个年轻人竟成夫妻，叶御史判作夫妇，沈璟作传奇《四异记》。
原：嘉靖间，昆山民为男聘妇，而男得痼疾。民信俗有“冲喜”之说，遣媒议娶。女家度婿且死，不从。强之，乃饰其少子为女归焉，将以为旬日计。既草率成礼，男父母谓男病，不当近色，命其幼女伴嫂寝，而二人竟私为夫妇矣。逾月，男疾渐瘳。女家恐事败，给以他故邀假女去，事寂无知者。因女有娠，父母穷问得之。讼之管狱，连年不解。有叶御史者，判牒云：“嫁女得媳，娶妇得婿，颠之倒之，左右一义。”遂听为夫妇焉。吴江沈宁庵吏部作《四异记》传奇。
注：昆山：今江苏昆山。
注：痼疾：久治不愈的重病。
注：冲喜：旧俗以办喜事冲去病灾。
注：归：出嫁。
注：旬日计：十天的权宜之计。
注：瘳：病愈。
注：给：欺骗。
注：娠：怀孕。
注：管狱：主管狱讼的官。
注：叶御史：待考。
注：判牒：判词。
注：吴江沈宁庵吏部：沈璟，号宁庵，吴江人，曾官吏部员外郎，曲学吴江派领袖。
注：《四异记》：沈璟传奇，写此事，已佚。
# 赵母奇语
题解：赵母送女出嫁，叮嘱“慎勿为好”，被女儿追问后答“好尚不可为，况恶乎”，是《世说新语》中的有名对话。
原：赵母嫁女，女临去，敕之曰：“慎勿为好！”女曰：“不为好，当为恶耶？”母曰：“好尚不可为，况恶乎！”
注：赵母：赵姬，嫁女时诫其“勿为好”，见《世说新语·贤媛》。
注：敕：嘱咐。
注：为好：做好事，此处指显出特异。
# 一日得二贵子
题解：杨公被倭寇掳走，十九年后归，经守丞杨世道与闽帅蘖公之母辨认，一日得二贵子，是离合悲欢的奇遇。
原：杨公某，关中盩厔人。妇李氏生一子，才七岁，公复贾于闽漳浦，主蘖氏家。蘖新寡，复为其家赘婿，生一子，冒姓蘖氏，亦已三岁。倭夷突犯海上诸郡，略公以去。居十九年，髡跌跳战，皆倭习矣。又后随众犯闽。会闽帅败之去，而公得遁归，为累囚，属绍兴郡丞杨公世道者厘辨之：“夷耶、民耶？”公曰：“我闽中民也！”因道其里族妻子名姓，多与己合，异之，归以问母。母令再谳，而听于屏后，不数语，大呼曰：“而翁也！”起之囚中，拜哭皆恸，洗浴更衣，庆忭无极。次朝蘖公知公得翁，举羔雁为贺。公觞之，翁出行酒，蘖公问翁，何由入闽，翁言其始末，又与蘖公家里族妻子名姓合。异之，亦归以问母。其日翁来报谒，蘖公觞之。而母窃听其语，又大呼曰：“而翁也！”其为悲喜犹杨丞家。于是闽郡黎老欢忭，呼为循吏之报，士大夫羔雁成群。盖守丞即异地各姓，实同体兄弟。而翁以髡跣跳战之卒，且为累囚，一日而得二贵子、两夫人，以朱轓千锺养焉。其离而合，疏而亲，贱而荣，岂非天故为之哉！
注：杨公某：杨姓人，关中盩厔人，待考。
注：盩厔：今陕西周至。
注：闽漳浦：今福建漳浦。
注：蘖氏：此处指姓蘖之人，待考。
注：赘婿：入赘女家的男子。
注：倭夷：倭寇，明代沿海的日本海盗。
注：略：劫掠。
注：髡跣：剃头赤脚，倭人装束。
注：累囚：被囚禁的人。
注：郡丞：知府的佐官。
注：杨公世道：杨世道，绍兴郡丞，待考。
注：厘辨：辨别。
注：再谳：再审。
注：庆忭：喜悦。
注：羔雁：古代送礼用的羊羔与雁。
注：黎老：老人。
注：循吏：奉公守法的好官。
注：朱轓：红色车耳，指高官所乘之车。
注：千锺：形容俸禄丰厚。
# 醉殴奇祸
题解：甲殴乙以为死，乙苏醒潜归，守者失尸被诬，实乃另一醉人被打死，层层误会酿成祸事。
原：甲乙二人俱醉，遇于途。甲殴乙仆，视之，死矣，径去。总甲见之，亟白于官。时已暮，姑以苇席四悬障尸，众寝卫于外。夜半，乙稍寤，已迷前事，思 “安得处此？必犯夜禁。”潜起逸归。及明，守者失尸，惊惧。须臾官来，谓受贿弃尸，痛中棰楚。守者诬服。请取尸来，乃供往伺于郊。一人醉而来，众前扑杀之，舁之苇室。而乙方大醒，记得曾被甲殴，诣甲喧。甲以贿求解。比官以杀人捕甲，甲邀乙往白。官讯守者尸所来，不能讳，坐死。
注：总甲：明代乡村治安小吏。
注：苇席：芦苇编席。
注：寝卫：就寝守护。
注：稍寤：略微醒过来。
注：夜禁：夜间戒严。
注：棰楚：杖打。
注：舁：抬。
注：喧：吵嚷。
注：讳：隐讳。
# 世事翻覆
题解：厉氏改嫁曹咏，曹咏借秦桧姻亲显达，秦桧死后被贬，厉氏晚景凄凉，叹悔不当初，世事翻覆如此。
原：曹咏侍郎夫人厉氏，馀姚大族女。始嫁四明曹秀才，与夫不相得，仳㒧而归，乃适咏。时咏尚为武弁。不数年，以秦桧之姻党，易文阶，骤擢至直徽猷阁，守鄞。元夕张灯州治，大合乐宴饮。曹秀才携家来观，见厉服用精丽，左右供侍，备极尊严，语其母曰：“渠乃合在此中居厚享。如此富贵，吾家岂能留？”叹息久之。咏日益显，为户部侍郎。桧殂，咏眨新州而亡。厉领二子扶丧归葬。二子复不肖，家资荡析，至不能给朝晡。赵德光之妻，厉之从父妹也，怜其老且无聊，招置四明里第，养之终身。厉间出访亲旧，见故夫婿曹透才家门庭整洁，花木蓊茂，谓侍婢曰：“我当时能自安于此，岂有今日！”因泣下数行，二十年间，夫妻更相悔羡。
注：曹咏：南宋官员，附秦桧，官至户部侍郎，后因桧死被贬新州。

题解：隋炀帝开运河，用殿脚女与羊牵龙舟，虞世基献计种柳，炀帝赐柳姓杨，是“杨柳”之名的传说。
原：炀帝开河成，取吴越民间女年十五、六者五百人，谓之“殿脚女”。至于龙舟，每采缆一条，女十人牵之，间以羊十口。时盛署，虞世基献计，请用垂柳栽于汴梁两堤上，一则树根四出，鞠护河堤，二则牵舟之女获其荫，三则牵舟之羊食其叶。上大喜，诏民间有柳一株，卖一缣。百姓竞献之。帝自种一株。群臣次第种，方及百姓栽。栽毕，帝御笔赐垂柳姓杨，曰：“杨柳”。
注：炀帝：隋炀帝杨广，开通大运河。
注：殿脚女：隋炀帝巡游时拉龙舟的宫女。
注：龙舟：皇帝所乘的大船。
注：采缆：彩缆，彩色的缆绳。
注：虞世基：隋炀帝宠臣，后被宇文化及所杀。
注：汴梁：今河南开封，此指通济渠（汴河）。
注：鞠护：养护。
注：缣：双丝细绢，古代作货币。
注：杨柳：谐“杨”与“柳”，此条为小说家言，出《开河记》。

# 高德基《平江纪事》二条
题解：引高德基《平江纪事》，记嘉定近海一带称“吾侬”“你侬”的方言和苏州“卖痴呆”的民俗。
原：嘉定近海外，乡人自称曰：“吾侬”、“我侬”，称他人曰：“渠侬”、“你侬”，问人曰“谁侬”。夜闻有叩门者，主人问曰：“谁侬”？外客曰：“我侬。”主人不知何人，开门方认，乃曰：“却是你侬！”后因名其处“三侬之地”。
注：嘉定：今上海嘉定。
注：吾侬：吴语“我”，“侬”意为人。
注：渠侬：吴语“他”。
注：谁侬：吴语“谁”。
注：三侬之地：以“我侬”“谁侬”“你侬”而名。
原：吴人自相呼为“呆子”，又谓之“苏州呆”。每岁除夕，群儿绕街呼叫云：“卖痴呆！千贯卖汝痴，万贯卖妆呆。见卖尽多送，要赊随我来。”
注：苏州呆：苏州人自嘲为“呆”，习俗上除夕“卖痴呆”。
注：卖痴呆：吴地除夕习俗，孩童绕街叫卖，祈愿聪明。
注：贯：钱串，千文为一贯。
注：赊：赊账。
# 老人、贵人、妇人八反
题解：总述老人、贵人、妇人各有“八反”的矛盾行为，以谐谑笔法写人情世态。
原：老人、贵人、妇人各有数反。夜不卧而昼睡；子不爱而爱孙；近事不记而记远事；哭无泪而笑有泪；近不见而远却见；打却不痛，不打却痛；面白却黑，发黑却白；如厕不能蹲，作揖却蹲。此老人“八反”也。夜宜卧而饮宴；早当起而高卧；心当逸而劳，身当劳而逸；当使钱处不使，不当使处却使；无病常服药，有病却不肯服药；人未做时争做，从皆做时却不做；请人必欲人来，人请却不肯去；买贱物不嫌贵，买贵物必要贱；美妻妾不甚爱，平常侍儿却爱。此贵人“八反”也。不爱长子而爱少子；不爱子而爱女；不信人而信鬼；惜小钱而不惜大钱；为姑时定怨嫂，为嫂时却嫌姑；最忌讳，却最咒诅；最怕不到老，又最怕人说老；丈夫举动，最善防闲，丫环淫奔，却不介意。此妇人“八反”也。
注：八反：八种相反的习惯。
注：昼睡：白天睡觉。
注：作揖却蹲：作揖时腰弯，老人反而下蹲，言体弱。
注：高卧：安然睡卧。
注：防闲：防范管束。
注：咒诅：诅咒。
注：丫环淫奔：丫鬟私奔。
# 世事相反
题解：列举世事相反之处：达官不忧天下而草莽忧之，文官谈兵武官不战，僧道茹荤而俗人持素等，以对比讽世。
原：今世人事亦有相反者。达官不忧天下，草莽之士忧之；文官多谈兵，武官却不肯厮杀；有才学人不说文章，无学人偏说；富人不肯使钱，贫人却肯使；僧道茹荤，平人却多持素；闾阎会饮却通文，秀才却粗卤；有司官多裁，势豪乡官却把持郡县；官愈尊则愈言欲退休，官愈不达则愈自述宦绩。
注：草莽之士：民间士人。
注：谈兵：谈论军事。
注：茹荤：吃肉食。
注：持素：吃素。
注：闾阎：里巷，指民间。
注：粗卤：粗鲁。
注：有司官：地方官。
注：把持：垄断操纵。
