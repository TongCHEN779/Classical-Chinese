# 正文
题解：《非族》部序语：冯梦龙称学者少见多怪，取域外奇风异俗以广见闻，并附以蛇虎之属，点明本部为全书第三十五部。
原：〔子犹曰：学者少所见，多所怪。穷发之国，穴胸反趾，独臂两舌，殊风异尚，怪怪奇奇，见于记载者侈矣。不阅此，不知天地之大；不阅此，不知中国之尊。予特采其尤可骇笑者著焉，而附以蛇虎之属，若曰“夷狄禽兽”云尔。是为《非族》第三十五。〕
注：子犹曰：冯梦龙自称，下为评语。
注：穷发之国：极北不毛之地，《庄子·逍遥游》“穷发之北有冥海”。
注：穴胸反趾：穴胸国人胸有孔，反趾国人脚趾向后，见《山海经》《淮南子》。
注：独臂两舌：一臂国、两舌国，见《山海经》。
注：殊风异尚：风俗各异。
注：夷狄禽兽：旧时对少数民族与外邦的轻蔑之称，此为作者所处时代的偏见，今不取。
注：非族：不属华夏之族，即异族异类。
# 南海异事三条
题解：引南海三种异俗：以猪油梳发卖发、女屠夫宰牛前数其罪、穷人指腹卖子，皆见于宋人笔记。
原：南海男子女人皆缜发。每沐，以灰投流水中，就水以沐，以彘膏涂其发。至五、六月，稻禾熟，民尽髡，鬻于市。既髡，复取彘膏涂之。来岁五、六月又可鬻。
注：南海：此指两广沿海一带。
注：缜发：浓密的头发。
注：彘膏：猪油。
注：髡：剃发。
注：鬻：卖。
原：解牛多女人，谓之“屠婆”、“屠娘”。皆缚牛于大木，执刀数其罪：“某时牵若耕，不得前；某时乘若渡水，不得行。今何以免死耶！”以策举颈，挥刀斩之。
注：解牛：宰牛。
注：屠婆：宰牛的妇女，亦称“屠娘”。
注：若：你。
注：策：马鞭，此处指刀具。
原：贫民妻方孕，则诣富室指腹以卖之，俗谓“指腹卖”。或己子未胜衣，邻之子稍可卖，往贷以鬻。折杖以识其短长，候己子长与杖等，即偿贷者。鬻男女如粪壤，父子两不戚戚。
注：指腹卖：胎儿未生就订下买卖。
注：胜衣：能穿得起衣服，指稍大。
注：粪壤：粪土，比喻轻贱。
注：戚戚：忧戚。
# 蜜唧唧
题解：右江西南獠民吃“蜜唧唧”，以蜜渍初生老鼠为食，咬时发唧唧声，是岭南异食之俗。
原：右江西南多獠民，好为“蜜唧唧”。鼠胎未瞬，通身赤蠕者，渍之以蜜，置盘中，犹嗫嗫而行。以箸挟取咬之，唧唧作声，故曰“蜜唧唧”。
注：右江：广西右江，今南宁一带。
注：獠：古代南方少数民族。
注：蜜唧唧：以蜜渍的幼鼠，咬时发声，见《岭外代答》类书。
注：未瞬：未睁眼。
注：嗫嗫：细小声。
# 产翁
题解：引《南楚新闻》，南方獠人有产翁之俗：妻生子后，丈夫卧床坐月，是风俗颠倒的奇闻。
原：《南楚新闻》云：南方有獠妇，生子便起；其夫卧床褥，饮食皆如乳妇。稍不卫护，疾亦如之。其妻子无所苦，炊爨樵苏自若。又越俗：妻诞子，经三日，便澡身于溪河。返，具糜饷婿。婿拥衾抱雏坐于寝榻，称为“产翁”。其颠倒如此！
注：《南楚新闻》：唐五代笔记，已佚。
注：獠妇：獠族妇女。
注：乳妇：产妇。
注：炊爨樵苏：烧火做饭、打柴割草。
注：越俗：越地风俗。
注：糜：粥。
注：产翁：夫代妻坐月子的风俗，即“拟娩”。
# 土獠蛮俗
题解：记土獠蛮的习俗：拔牙婚嫁、手食、高跷、崖葬，反映西南民族风俗。
原：土獠蛮俗：男子十四、五，则左右击去两齿，然后婚娶。无匙箸，手搏饭而食之。足蹑高橇，上下山坡如奔鹿。人死。以棺木盛之，置千仞颠崖之上，以先堕者为吉。
注：土獠：獠族之一。
注：击去两齿：拔去牙齿，为成年标志。
注：匙箸：勺子和筷子。
注：手搏饭：用手抓饭。
注：橇：登山的木屐类用具。
注：千仞：形容极高。
# 倭国
题解：引《北史》，倭国王以天为兄、以日为弟，日出后停止听政，是对日本早期政俗的传闻。
原：《北史》云：倭国王以天为兄，以日为弟。未明时，出听政；日出便停理务，曰“委我弟”。
注：《北史》：唐李延寿撰。
注：倭国：古代对日本的称呼。
注：听政：处理政务。
注：委我弟：交给我弟（太阳）。
# 占城
题解：记占城国酿酒、吸酒、采人胆之俗，是对东南亚风俗的传闻。
原：占城国酿酒法：以米和药入瓮中，卦固日久，俟糟生蛆为佳酝。他日开封，用长节竹竿三、四尺，量人多少入水。以次吸竹，则酒入口。吸尽，再入水。若无味则止；有味，封留再饮。岁时，纵人采生人胆鬻官。其酋或部邻得胆入酒中，与家人同饮，又以浴身，谓之“通身是胆”。
注：占城：古国名，在今越南中南部。
注：卦固：封固。
注：糟：酒渣。
注：酋：酋长。
注：部邻：邻部。
注：通身是胆：以人胆酒浴身，以求勇。
# 头飞
题解：记占城、岭南的“飞头”传说，描述头颅脱体飞出觅食的奇闻，并引陈刚中诗。
原：占城国妇人有头飞者，夜飞食人粪。夫知而固封其项，或移其身，则死矣。陈刚中在安南，有纪事诗曰：“鼻饮如瓴<商瓦>，头飞似辘轳。”
注：头飞：传说中的落头民，头颅夜间脱体飞出。
注：陈刚中：陈孚，字刚中，元代诗人，曾使安南。
注：安南：今越南北部。
注：鼻饮：用鼻吸饮，古代南方的风俗。
注：瓴<商瓦>：疑为“瓴甋”，一种砖瓦，用来盛酒之器；“<商瓦>”为底本字形，待考。
注：辘轳：汲水用的滑轮。
原：岭南溪洞口，往往有飞头者，故有“飞头獠子”之号。头将飞一日前。颈有痕匝项如红缕。妻子遂看守之。其人及夜，状如病，头忽生翼，脱身而去。乃于岸泥寻蟹蚓之类食之。将晓飞还，如梦觉，其腹实矣。
注：岭南：五岭以南。
注：溪洞：溪洞蛮，南方少数民族。
注：飞头獠子：传说中会头飞的獠人。
注：匝项：绕颈一周。
# 吐蕃
题解：唐贞元中击败吐蕃，见其为战死主将举行的葬仪礼：问痛、问食、问衣、问归，以“礼”待死者，异乎中土。
原：唐贞元中，王师大破吐蕃于青海，临阵杀吐蕃大兵马使乞藏遮。或云是尚结赞。吐蕃乃收尸归。有百馀人行哭随尸，威仪绝异：使一人立尸旁代语，问以 “疮疾痛乎？”代应曰：“痛。”即膏药涂之：又问：“食乎？”应曰：“食。”即为具食；又问：“衣乎？”应曰：“衣。”即命裘衣之；又问：“归乎？”应曰：“归。”即具舆马载尸而去。若此异礼，必国之贵臣也。
注：贞元：唐德宗年号（785—805）。
注：青海：青海湖一带，唐蕃交战之地。
注：吐蕃：古代藏族政权。
注：大兵马使：吐蕃军职。
注：乞藏遮：吐蕃将领，待考。
注：尚结赞：吐蕃名相，曾与唐平凉劫盟。
注：行哭：边走边哭。
注：疮疾：伤口。
注：膏药：外敷药。
注：裘衣：以皮衣覆盖。
注：舆马：车马。
# 契丹
题解：记契丹三事：正月十三日放国人为盗三日、牛马以雪辨“熟”、契丹主死后尸身盐腌称“帝羓”。
原：契丹俗：每正月十三日，放国人为贼三日，唯不许盗及十贯以上。北呼为“鹘里叵”，华言“偷时”也。
注：契丹：古代北方民族，建立辽。
注：鹘里叵：契丹语，意为“偷”，待考。
注：华言：汉语。
注：十贯：十千钱。
原：契丹牛马有熟时，如南方之养蚕也。有雪而露草寸许，牛马大熟。若无雪，或雪没草，则不熟。
注：牛马有熟时：牛马肥壮之时，谓“熟”，比喻养蚕。
注：露草：露出雪面的草。
原：契丹主至临城，得疾，至杀胡林而卒。国人剖其腹，实盐数斗，载之北去。晋人谓之“帝羓。”
注：契丹主：辽太宗耶律德光，947年死于杀胡林。
注：临城：今河北栾城，旧称栾城。
注：杀胡林：地名，在今河北栾城。
注：实盐：填入盐。
注：晋人：后晋人。
注：羓：干肉，帝羓即帝尸风干。
# 夷妇
题解：引《夷俗记》，夷妇乳长可垂至腹，刺绣时儿从腋后取乳而食。
原：萧兵峰《夷俗记》：夷妇乳长，重至腹下。时当刺绣，儿辄从腋后索而食之。
注：萧兵峰：明人，著《夷俗记》，生平待考。
注：《夷俗记》：记载少数民族风俗之书，待考。
注：夷妇：少数民族妇女。
# 鞑鞑
题解：记鞑靼体质与习俗：不畏死、不避人，见妇乳被戏则喜，被握手则怒。
原：鞑鞑肠极细，如猪肠。人身瘦长而阔膀。不畏死，得胜则唱，败则哭。鞑妇至中国，人戏弄其乳则喜，以为是其子也。至隐处亦不为意。唯执其手则怒，谓执手为夫妇，动挟刃刺其人。
注：鞑鞑：鞑靼，明代对蒙古诸部之称。
注：膀：臂膀、肩。
注：隐处：隐秘之处。
注：挟刃：持刀。
# 浑脱
题解：北人以小牛皮制“浑脱”，盛乳酪酒水，是北方游牧民族的器物。
原：北人杀小牛，自脊上开一孔，逐旋取去内头骨肉，外皮皆完。揉软，用以盛乳酷酒水处湩，谓之“浑脱”。
注：浑脱：以整张兽皮制成的皮囊。
注：乳酷酒水处湩：乳酪酒水，湩为乳汁；此处文字有误，待考。
注：逐旋：慢慢。
# 种羊
题解：大汉以西人“种羊”，埋羊骨于地，次春吹笳咒语即生小羊，是西域奇闻。
原：大汉迤西人能种羊。取羊骨，以初冬未日埋地中，初春未日为吹笳咒语，即有小羊从地中出。
注：大汉：此指大漠，一说蒙古，待考。
注：迤西：以西。
注：未日：十二支中的“未”日。
注：笳：胡笳，古代北方民族乐器。
注：咒语：念咒。
# 回鹘
题解：回鹘酋长共塑佛像，斋时以羊血涂佛口、捧佛足而嗬，是回鹘信佛旧俗。
原：回鹘酋长共为一堂，塑佛像其中。每斋，必刲羊，以指染血涂于佛口，或捧其足而嗬之，谓之亲敬。
注：回鹘：古代民族，唐时曾信摩尼教，后信佛教等。
注：斋：宗教斋会。
注：刲羊：宰羊。
注：嗬：呵气。
# 木乃伊
题解：引《博物志补》，回回国舍身济众的人以蜜养身，死后石椁蜜浸百年成“木乃伊”，可治折伤。
原：回回地面，有年老自愿舍身济众者，乃澡身绝食，口啖蜂蜜。数月，便溺皆蜜矣。既死，国人殓以石椁，仍以满蜜浸之，镌志年月。俟百年启视之，则已成蜜剂，名曰“木乃伊”。人有损折肢体者，食少许立效。见《博物志补》。
注：回回地面：西域回回之地。
注：舍身济众：舍弃身体救济众人。
注：满蜜：灌满蜂蜜。
注：镌志：刻志。
注：木乃伊：阿拉伯语 mumiya，指经过防腐处理的尸体，旧时作为药用。
注：《博物志补》：明代书籍，待考。
# 大食国木花
题解：大食国山谷有生花如人头的树，与人说话则笑而落，是奇花之说。
原：大食国，西南二千里外，山谷间有木，生花如人首。与语辄笑，则落。
注：大食：阿拉伯帝国，唐宋时对阿拉伯的称呼。
注：生花如人首：传说中的“人头花”，见《酉阳杂俎》。
# 古莽
题解：古莽国人多睡，五十日醒一次，以梦为实，以昼所见为虚，借《庄子》“庄周梦蝶”之意。
原：古莽之国，其人多眠，五旬一觉。以梦之所为为实，昼之所见为虚。
注：古莽之国：传说中的国名，见《列子》“古莽之国”，其人“五旬一觉”。
注：五旬一觉：五十天醒一次。
# 白狼国
题解：白狼国居于石室，如佛塔，上层藏货，中层居人，下层养畜，是对西南夷居住方式的记载。
原：西夷有白狼国者，依山以居，垒石为室，如浮图然，以梯上下，货藏于上，人居于中，畜豢于下。
注：白狼国：汉代西南夷国名，《后汉书·西南夷传》有白狼夷。
注：垒石为室：用石头垒成房屋。
注：浮图：佛塔。
注：畜豢：圈养牲畜。
# 裸人
题解：引《天宝实录》，日南厩山一带的裸人风俗：刺胸、画眼、去前二齿。

注：《天宝实录》：书名，待考。
注：日南：汉郡，今越南中部。
注：厩山：待考。
注：白民：传说中的国名，见《山海经》。
注：去前二齿：拔去前两颗牙。
# 大宛
题解：大宛国人深目多须、善经商、尊重女子，是汉代西域风俗的记述。
原：大宛国人，皆深目多须髯。善贾市，争分铢。贵女子，女子所言，丈夫乃决正。
注：大宛：西域古国，在今乌兹别克斯坦费尔干纳盆地。
注：贾市：做买卖。
注：分铢：极小的重量。
注：决正：裁断。
# 女国
题解：引《隋书》，女国在葱岭南，妇人地位高于男子，男女皆涂面披发。
原：女国在葱岭之南。其俗妇人轻丈夫，而性不妒忌。男女皆以彩色涂面，一日之中，或数度变改之。人皆被发。见《隋书》。
注：女国：古国名，隋唐西域女国，即东女国。
注：葱岭：帕米尔高原。
注：彩色涂面：以彩色涂面。
注：被发：披散头发。
注：《隋书》：唐魏征等撰。
# 金齿蛮
题解：金齿蛮处女婚前淫乱，未嫁而死者有众多相好送葬，是边地风俗的记述。
原：金齿蛮俗，处女淫乱同狗彘。未嫁而死者，所通之男子持一幡相送。有至百人者，父母哭曰：“女爱者众，何期夭逝！”
注：金齿蛮：云南西部的少数民族，以金饰齿而得名。
注：狗彘：狗和猪。
注：幡：旗幡。
注：夭逝：早亡。
# 麻逸
题解：麻逸国崇尚节义，夫死妇削发绝食与夫尸同寝，七日不死则亲戚劝食。
原：麻逸国，族尚节义。夫死，其妇削发绝食，与夫尸同寝，多与并逝者。逾七日不死，则亲戚劝以饮食。
注：麻逸：古国名，在今菲律宾。
注：节义：节操与情义。
注：并逝：一同去世。
# 吐火罗
题解：吐火罗国兄弟共妻、轮流入房，以衣挂户外为志，生子归长兄，是一妻多夫制的记载。
原：吐火罗国，都葱岭西五百里，与挹怛杂居。都城方二里，胜兵者十万人，皆习战。其俗奉佛。兄弟同一妻，迭寝焉。每一人入房，户外挂其衣以为志。生子属其长兄。
