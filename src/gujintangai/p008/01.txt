# 正文
题解：《不韵》部卷首小引：子犹谈“韵”须有夙根，行事语言不雅者洗胃涤肠亦不能救，借此引出本部收录不雅之事。
原：〔子犹曰：语韵则美于听，事韵则美于传。然韵亦有夙根，不然者，虽复吞灰百斛，洗胃涤肠，求一语一事之几乎韵，不得矣。山谷常嘲一村叟云：“浊气扑不散，清风倒射回。”此犹写貌，未尽传神。极其伎俩，直欲令造化小儿羞涩，何止风伯避尘已也？集《不韵》第八。〕
注：子犹曰：冯梦龙评语。
注：语韵则美于听，事韵则美于传：语韵指言辞有韵致，事韵指行事有韵致。
注：夙根：前世根基，佛家语。
注：吞灰百斛，洗胃涤肠：“吞灰洗肠”，比喻洗心革面，典出《南史·荀伯玉传》；“百斛”极言其多。
注：山谷：黄庭坚号山谷。
注：浊气扑不散，清风倒射回：黄庭坚戏讽村叟，写其俗气使清风也被逼回。
注：写貌：描摹外貌。
注：传神：传其神韵。
注：造化小儿：命运之神，《新唐书》“造化小儿”。
注：风伯避尘：风神也避开其俗气；“风伯避尘”。
注：集《不韵》第八：本书第八部。
# 汗臭汉
题解：余靖言谏仁宗，仁宗嫌其身有汗臭，是宋人记不韵之事开篇。
原：余靖不事修饰。作谏百日，因赐对面陈。时方盛暑，上入内云：“被一汗臭汉薰杀！喷唾在吾面上。”
注：余靖：北宋名臣，字安道，曾任谏官，《宋史》有传。
注：作谏：任谏官，宋仁宗朝。
注：赐对：皇帝召见。
注：上：皇帝，指宋仁宗。
注：汗臭汉：身有汗臭的汉子。
注：薰杀：熏死。
# 不洗脚
题解：阴子春因迷信洗脚会失财，终身不洗，是《不韵》部中不洁之例。
原：《北史》：阴子春身服垢污，脚常数年不洗，云：“洗辄失财败事。”妇甚恶之，曾劝令一洗。不久，值梁州之败，谓洗脚所致，大恨妇，遂终身不洗。
注：《北史》：阴子春之事载《北史》或《南史》，待考。
注：阴子春：南朝梁人，《梁书》有传，官至太守。
注：垢污：污垢。
注：梁州之败：梁州，今陕西汉中，此指梁军败于梁州事，待考。
# 三鹿郡公
题解：袁利见粗疏，方棠称他已封“三鹿郡公”，以三鹿相合“粗”字谐音取笑。
原：袁利见性粗疏，方棠谓：袁生已封“三鹿郡公”。
注：袁利见：明人，事迹待考。
注：方棠：明人，待考。
注：三鹿郡公：“三鹿”合为“麤”，同“粗”，戏谓其粗疏，封郡公。
# 都宪弄鸟
题解：胡宗宪醉后当众摩弄下体，别人掩目，他自若，写其不韵。
原：胡少保宗宪素自负嫪毒之具，醉后辄欹坐肩舆中，以手摩之，东西溺舁夫及从官肩。咸掩目而笑，胡故自若。
注：胡少保宗宪：胡宗宪，字汝贞，明代抗倭名臣，官至太子少保、兵部尚书、总督。
注：嫪毒：嫪毐，秦始皇时宦官，以阳具大著称，《史记·吕不韦列传》。
注：欹坐：斜坐。
注：肩舆：轿子。
注：舁夫：抬轿的人。
# 马上食饼
题解：张衡在路边买新蒸饼，于马上食，被弹劾罢官，是官员失仪之例。
原：张衡由令史至三品，已团甲，退朝，于路傍见蒸饼新熟，遂买得，于马上食之。为御史弹奏，竟落甲。
注：张衡：隋人，官至三品，《隋书》有传。
注：令史：官署书记。
注：三品：官品。
注：团甲：隋代官员考课名册。
注：蒸饼：蒸制的面饼。
注：御史：监察官。
注：落甲：被削去考课名次。
# 决文宣王、亚圣
题解：广南某刺史不知礼，释奠时让书吏扮作孔子与颜回，又判“各决若干”，闹出笑话。
原：《岭南志》：广南际海郡，不立文宣王庙。有刺史不知礼，将释奠，预署二书吏为文宣王、亚圣，鞠躬于门外。或进止不如仪，即判云：“文宣王、亚圣各决若干。”
注：《岭南志》：待考。
注：广南：广南东路、广南西路，宋代岭南地区。
注：文宣王：唐开元二十七年追谥孔子为文宣王。
注：释奠：祭祀先圣先师的典礼。
注：亚圣：孟子被尊为亚圣，此处用来指代，疑当作“颜子”，待考。
注：决：判处杖刑。
# 缚诗人
题解：杨懋忠游山被误作盗，以诗自供“窃语言”，指挥误会“陈编”是同伙，后反因诗得知赏，是文士被误为盗的趣事。
原：《皇明世说》：滕县杨懋忠涉学，好为诗。不得意于诸生，弃去，遍游名山，还过琅琊。捕盗指挥以为盗，执之。杨乞纸笔自供，因题一诗，内有“曾向陈编窃语言”之句。指挥不通文，问曰：“陈编是汝伙中人耶？”杨曰：“否。是被盗者。”指挥大喜，执送兵备；见其诗，大相知赏，叱出指挥，解杨缚，延上坐，与论诗竟日。既出，指挥来谢罪。杨曰：“不因公，何以受知兵宪？但如此荐法，令人一时难堪耳。”
注：《皇明世说》：明人笔记，待考。
注：滕县：今山东滕州。
注：杨懋忠：明人，事迹待考。
注：涉学：读过书。
注：诸生：秀才。
注：琅琊：今山东诸城一带。
注：捕盗指挥：负责捕盗的卫所武官。
注：陈编：旧书，旧编。
注：窃语言：借用前人语言。
注：兵备：兵备道，明代按察司官员，分巡地方军事。
注：兵宪：对兵备道的尊称。
注：荐法：此指举荐方式。
# 役长史
题解：吴稷隐居，官府误以其名摊役，他注明“不能为官，岂能为役”，令官愧悔。
原：吴长史稷归隐，有司莫识其面。里举践更役，误以公名报。令不知，悬之榜。公亲往注其下曰：“不能为官，岂能为役？”令闻大愧。
注：吴长史稷：吴稷，明人，曾为长史，待考。
注：长史：王府属官。
注：有司：官府。
注：里举践更役：乡里推举轮番服役；“践更”是汉代轮流服徭役。
注：榜：公告。
# 沈周
题解：沈周被苏州知府当作画工拘来，沈以《焚琴煮鹤图》讽刺知府，后知府悔谢。
原：沈周名重一时。苏州守求善画者，左右以沈对，便出朱票拘之。沈至，命立庑下献技。沈乃为《焚琴煮鹤图》以进。守不解，曰：“亦平平耳。”其明年入觐，见守溪王公。首问：“石田先生无恙乎？”守茫然无以应。归以质之从者，则朱票所拘之人也。守大惭恨，踵门谢过焉。
注：沈周：号石田，明代画家，吴门画派开创者。
注：苏州守：苏州知府。
注：朱票：官府拘票。
注：庑下：廊下。
注：焚琴煮鹤：杀风景之事，李商隐《杂纂》。
注：入觐：入京朝见。
注：守溪王公：王鏊，号守溪，苏州人，官至大学士。
注：石田先生：沈周。
注：踵门：登门。
# 《毁茶论》
题解：陆羽擅长品茶，李季卿却以三十文打赏，陆羽愤而作《毁茶论》，是权贵轻慢才士的事例。
原：陆羽嗜茶，著《茶经》三篇。李季卿至江南，有荐羽者，召羽煮茶。羽衣野服，挈具而入。公心鄙之，命奴子取钱三十文相酬。羽愧甚，著《毁茶论》。
注：陆羽：唐人，字鸿渐，著《茶经》，被尊为“茶圣”。
注：《茶经》：世界上第一部茶学专著，三卷十篇。
注：李季卿：唐代官员，曾为江南宣慰使。
注：野服：平民的服装。
注：《毁茶论》：陆羽所作，已佚。
# 碑祸
题解：两则毁碑之事：林㷆磨平泰山唐玄宗御碑，姜遵取汉唐名碑当砖壁，都是不韵之举。
原：唐玄宗东封泰山，命张许公摩崖为碑。至明八百馀年，为林㷆磨平，以“忠孝廉节”四大字覆之。
注：东封泰山：开元十三年（725）唐玄宗封禅泰山。
注：张许公：张说，封燕国公；此“许公”指苏颋，疑当作“张燕公”，待考。
注：摩崖：在山崖上刻字。
注：林㷆：明代官员，事见明人笔记，待考。
注：忠孝廉节：泰山摩崖上有“忠孝廉节”四字，相传明代所刻。
原：天圣中，营浮图。姜遵在永兴，悉取汉、唐碑之坚好者，以代砖壁。有县尉叩头争之，继之以泣。遵怒，并劾去之。
注：天圣：宋仁宗年号。
注：浮图：佛塔。
注：姜遵：北宋官员，曾知永兴军，《宋史》有传。
注：永兴：永兴军，治所在长安。
注：县尉：县中小官。
注：劾：弹劾。
# 花仇
题解：韩弘把牡丹铲除，杨州琼花被隋炀帝移栽枯死，都是对花的不韵之举。
原：唐韩弘罢宣武节度，归长安私第，有牲丹杂花，命㔉去之，曰：“吾岂效儿女辈耶！”
注：韩弘：唐代宣武军节度使，《旧唐书》有传。
注：宣武节度：治汴州。
注：长安私第：京城私宅。
注：牲丹：当作“牡丹”，底本疑误。
注：㔉：当作“铲”之类，待考。
注：儿女辈：妇孺之辈。
原：杨州琼花，天下无双。炀帝特移栽金陵，而枝叶枯瘁。帝怒，乃杖八十发回，复活一年而死。
注：杨州琼花：扬州琼花，宋代著名，相传天下无双，《扬州府志》载。
注：炀帝：隋炀帝杨广；传说隋炀帝欲观琼花下扬州。
注：金陵：今南京。
注：枯瘁：枯萎。
注：杖八十：杖责八十。
# 刮几垩壁
题解：王羲之字被门生之父刮去，玄览禅师命人涂白壁上的画，皆是不识珍惜书画的例子。
原：王羲之尝诣一门生家，设佳馔供给，意甚感之，欲以书相报。见有一新榧几，王便书之，草正相半。门生送往归郡，比还家，其父已削括都尽。
注：王羲之：东晋书法家。
注：门生：弟子。
注：榧几：榧木小几。
注：草正相半：草书与楷书各半。
注：归郡：回到郡中。
注：括：刮去。
原：玄览禅师性僻，住荆州陟屺寺。张躁于壁间画古松，符载为赞，卫象为赋。览师怒曰：“何疥吾壁？”命加垩焉。
注：玄览禅师：唐代荆州僧人，事见《唐国史补》。
注：荆州：今湖北荆州。
注：陟屺寺：荆州寺院。
注：张躁：张璪，唐代画家，善画松石。
注：符载：唐代文人。
注：卫象：唐代诗人。
注：疥：长疥，比喻弄脏。
注：垩：白色涂料。
# 方竹杖
题解：李德裕赠僧方竹杖，僧竟将其磨圆漆光，是不识天然之趣的笑谈。
原：润州甘露寺有僧，道行孤高。李德裕廉问日，以方竹杖一赠焉。方竹杖出大宛国，坚实而正方，节须四面对出。及再镇浙右，其僧尚在。问曰：“竹兄无恙否？”僧曰：“至今宝藏。”公请出观之，则老僧已规圆而漆之矣。公嗟惋弥日。故当时曾有诗云：“削圆方竹杖，漆却断纹琴。”
注：润州：今江苏镇江。
注：甘露寺：镇江名刹。
注：李德裕：唐代宰相。
注：廉问：考察地方吏治，即任观察使时。
注：大宛国：古西域国，今中亚费尔干纳盆地。
注：节须四面对出：竹节四面相对而出。
注：浙右：浙西，李德裕曾任浙西观察使。
注：竹兄：对竹杖的戏称。
注：规圆：用圆规削圆。
注：断纹琴：古琴漆面因年久裂纹者，名贵。
注：嗟惋：叹息惋惜。
# 砚眼
题解：陆庐峰命门人买砚，门人嫌砚上鸲鹆眼突起而磨平，使名砚尽毁。
原：吴郡陆公庐峰侯选京师，尝于市遇一佳砚，议价未定。既还邸，使门人某者往，以一金易归。讶其不类，某坚证其是。公曰：“前砚有鸲鹆眼，今何无之？”答曰：“某嫌其微凸，偶值石工甚便，幸有馀银，已倩为平之矣。”公大惋惜。
注：吴郡：今苏州一带。
注：陆公庐峰：陆庐峰，待考。
注：选京师：赴京等候铨选。
注：邸：旅舍。
注：鸲鹆眼：砚石上的一种圆斑，状如八哥之眼，为砚中珍品。
注：倩：请。
# 鸣鹅

注：市：买。

# 快牛
题解：王恺“八百里駮”牛被王济射赌后立刻取心炙食，是《世说新语·汰侈》著名故事。
原：王恺有快牛，名“八百里駮”，常莹其蹄角。王武子语君夫：“我射不如卿，今赌卿牛，以千万对之。”君夫既恃手快，且谓骏物无有杀理，便相然可，令武子先射。武子一起便破的，却据胡床，叱左右：“速探牛心来！”须臾炙至，一脔便去。
注：王恺：字君夫，西晋外戚，与石崇斗富。
注：八百里駮：王恺之牛名，“駮”即“驳”，毛色斑驳。
注：莹：磨亮。
注：王武子：王济，字武子，西晋驸马。
注：对之：以千万钱作赌注。
注：手快：射术高。
注：的：箭靶。
注：胡床：交椅，从胡地传入。
注：炙：烤肉。
注：脔：切成块的肉。
# 白鸥脯
题解：张佖与陈乔之子游玄武湖，一个雅语，一个粗语，被作半茎风毛、一堆牛屎相对，后一人得绰号。
原：张佖、陈乔之子，秋晚并游玄武湖。时群鸥游泛，佖子曰：“一轴内本《潇湘》！”乔子俄顾卒吏云：“此白色水禽，可以作脯否？”众谓“张佖子半茎风毛，陈乔男一堆牛屎”。乔子由是有“陈一堆”及“白鸥脯”之号。
注：张佖、陈乔：均为五代南唐人，陈乔为南唐大臣，后殉国，《宋史》有传。
注：玄武湖：南京城北的湖。
注：一轴内本《潇湘》：《潇湘图》，指董源所画《潇湘图》。
注：卒吏：随从。
注：脯：干肉。
注：风毛：风吹毛羽，喻文雅。
注：牛屎：粗俗。
注：陈一堆：绰号。
# 金鱼
题解：金鱼被送作礼物，守公却当食物烧了，是不识观赏物的玩笑。
原：金鱼有“九尾狐”及“紫袍玉带”种种之异，文房畜为清玩，价亦不廉。或以一盆赠张幼于，张转以赠守公。他日守公谓张曰：“前惠鱼但美观耳，味殊淡。”盖守北人，已将鱼付爨下也。张但唯唯而已。
注：九尾狐：金鱼品种名，尾分多叉。
注：紫袍玉带：金鱼品种名，身紫而带白纹。
注：文房：书房。
注：清玩：清雅的赏玩物。
注：张幼于：张献翼，字幼于，明代文士。
注：守公：知府。
注：爨下：灶下。
注：唯唯：应答声。
# 谢灵运须
题解：谢灵运须作维摩诘像须，后被安乐公主取去斗草，是奇闻也是糟蹋。
原：谢灵运须美，临刑，施为南海祇垣寺维摩诘像须。唐中宗时，安乐公主端午斗草，欲广其物，驰驿取之；又恐为他所得，乃剪弃其馀。
注：谢灵运：南朝宋诗人，被诛于广州。
注：南海祇垣寺：南海，今广州；祇垣即祇园精舍，此处寺名。
注：维摩诘：佛教居士，维摩诘菩萨。
注：唐中宗：李显。
注：安乐公主：唐中宗之女，骄纵，事见《旧唐书》。
注：斗草：端午节游戏，各以草比赛。
注：驰驿：驿马飞传。
# 国公诗
题解：吴主事求文不成而得英国公作诗，以官爵大为荣，是俗人慕势之笑。
原：湖州吴主事家素饶，求李西涯文寿其父。时公为学士，鄙其人，不许。吴问其友曰：“今朝中爵位极尊者为谁？”曰：“英国公太师左柱国也。”吴即缄币求英公。英公令门馆作诗与之。吴得诗，夸于人云：“英国当朝第一人，乃为我作诗，何必李学士也！”
注：吴主事：湖州人，待考。
注：李西涯：李东阳，号西涯，明代内阁大学士。
注：学士：翰林学士。
注：英国公：英国公张懋，明代勋贵。
注：太师左柱国：最高勋官。
注：缄币：封好礼金。
注：门馆：门客。
# 党进画真
题解：党进要画像贴金眼，以为大虫（老虎）也用金箔贴眼，是粗人论画的笑话。
原：党进命画工写真。写成，大怒，诘画师云：“我前时见画大虫，犹有用金箔贴眼。我消不得一对金眼睛？”
注：党进：见前。
注：写真：画人像。
注：大虫：老虎。
注：金箔：金片。
注：消不得：担当不起。
# 高太监
题解：高隆见名画有空白处，要添“三战吕布”，是不懂画者自作主张。
原：南京守备太监高隆，人有献名画者，上有空方。隆曰：“好好！更须添画一个‘三战吕布’。”
注：南京守备太监：明代南京守备由宦官担任。
注：高隆：明代宦官，待考。
注：空方：空白处。
注：三战吕布：《三国演义》刘、关、张三英战吕布。
# 《五马行春图》
题解：沈周为太守画《五马行春图》，被责没有随从，戏称“绢短”补画，太守欣然。
原：沈周作《五马行春图》赠一太守。守怒曰：“我岂无一人相随耶？”沈知之，另写随从者送入，因戏之曰：“奈绢短，止画前驱三对。”守喜曰：“今亦足矣！”
注：《五马行春图》：太守出行的颂词，汉代太守乘五马，故以“五马”称太守。
注：前驱：前导。
注：绢短：画绢尺寸不足。
# 障簏
题解：祖约因贪财，客来时用身体遮住两只小箱，被《世说新语》载为鄙吝。
原：祖约好财。客诣祖，见方料视财物，因客至，屏当未尽，馀两小簏，置背后，以身障之，强与客语。
注：祖约：东晋人，祖逖之弟，后叛乱。
注：诣：拜访。
注：屏当：整理收拾。
注：簏：竹箱。
注：障：遮蔽。
# 种珠
题解：陈继善富而吝，亲自在园中以珍珠“种”于地，可见其鄙俗。
原：陈继善自江宁尹拜少傅致仁，富于资产，性鄙屑；别墅林池，未尝暂适；既不嗜学，又杜绝宾客。惟自荷一锄，理小圃成畦，以真珠布土壤三间，若种蔬状。记颗俯拾，周而复始，以此为乐焉。
注：陈继善：南唐人，官至少傅，待考。
注：江宁尹：金陵府尹。
注：少傅：太子少傅。
注：致仁：退休。
注：鄙屑：鄙吝琐碎。
注：畦：田垄。
注：真珠：珍珠。
注：记颗：数粒数。
# 银靴
题解：李元宗与冯权幼时之情，即位后赐银三十斤以代“银靴”，冯权真锻靴穿之，是不韵的玩笑。
原：元宗幼学之年，冯权常给使左右，深所亲幸。每曰：“我富贵，为尔置银靴。”保大初，听政之暇，命亲王及东宫旧僚击鞠。欢极，颁赉有等。语及前事，即日赐银三十斤，以代银靴。权遂命工锻靴穿焉。
注：元宗：南唐元宗李璟，宋人称“元宗”，因避宋讳。
注：冯权：南唐宦官，待考。
注：给使：侍候。
注：保大：南唐元宗年号。
注：击鞠：打马球。
注：颁赉：赏赐。
注：东宫旧僚：太子时期的旧属。
# 黑牡丹
题解：以水牛喻“黑牡丹”，讽刺富人刘训，可见人以富比牡丹之俗。
原：晚唐时，京师春游，以牡丹为胜赏。有富人刘训邀客赏花。客至，见其门系水牛累百，笑指曰：“此刘氏黑牡丹也！”
注：胜赏：美好的赏玩。
注：刘训：唐代长安富人，事见《唐摭言》，待考。
注：黑牡丹：戏称水牛。
# 大厅胜寺
题解：李约以大厅比寺院，说“大厅”胜寺，是以俗胜雅的反语。
原：李约每于庶人锜前称金陵招慧寺标致。庶人既宴寺中，明日谓曰：“子尝称招隐，昨日游宴，何如中州？”约曰：“某赏者疏野耳。若远山将翠幕遮，古松用采物裹，膻腥涴尘泡泉，音乐乱山鸟声，此则实不如在叔父大厅也！”
注：李约：唐代宗室，字存博，嗜茶爱古，《新唐书》有传。
注：庶人锜：李锜，唐德宗时镇海节度使，后叛，贬为庶人。
注：金陵招慧寺：寺名，今南京一带；“招隐”指招隐寺，待考。
注：标致：风致。
注：翠幕：绿帐。
注：采物：彩饰。
注：涴：污染。
注：泡泉：烹泉水。
# 僧拒客
题解：众僧闭户拒客，一僧跷足书空，被问“书空跷足睡”，表明僧人性情疏懒，不韵。
原：宋吴荆溪云：往岁江行风阻，与友生沿岸野步，穿岭而下，忽见兰若甚多。僧院睹客来，皆扃户不内。独有一院，大敞其户，见一僧跷足而眠，以手书空，顾客殊不介意。窃意此必奇僧也，直入造之。僧虽强起，全无喜容。不得已而问曰：“先达有诗云：‘书空跷足睡，路险侧身行。’和尚其庶几乎？”僧曰：“贫道不知何许事，适者指挥侍辈，欲掩关少静耳。”遂不辞而出。
注：吴荆溪：吴荆溪，待考。
注：兰若：佛寺，梵语阿兰若简称。
注：扃户：关门。
注：书空：以手指在空中写字，《晋书》殷浩“书空作咄咄怪事”。
注：先达：前辈诗人。
注：书空跷足睡，路险侧身行：原诗不详，待考。
注：贫道：僧人自称。
# 陈叔陵
题解：陈叔陵好吃好装样子，在车马上读书朗诵，是《不韵》部中的虚饰之例。
原：陈始兴王叔陵性不好卧，不饮酒，惟多置殽胾，昼夜食啖。又好饰虚名，每入朝，常于车中马上执卷读书，高声朗诵，扬扬自若。
注：陈始兴王叔陵：陈叔陵，陈宣帝次子，后叛乱被杀，《陈书》有传。
注：殽胾：肉食。
注：啖：吃。
注：扬扬自若：得意自如。
# 俗谶
题解：宋时太学斋舍以枣、荔枝、蓼花作“早离了”之谶，俗不可耐。
原：宋时太学各斋，除夕设祭品，用枣子、荔枝、蓼花，取“早离了”之谶。执事者帽而不带，以绦代之，谓之“叨冒”。鄙俗可笑！
注：太学：国家最高学府。
注：斋：太学学舍。
注：蓼花：一种面食点心，或为米粉所制。
注：早离了：谐枣、荔、蓼之音，祈早日离开学舍。
注：执事者：负责人员。
注：叨冒：谐“绦帽”之音，也指贪冒。
# 俗礼
题解：白席者唱赞之词啰嗦呆板，韩琦被其所扰，是北方民间俗礼的讽刺。
原：北方民家吉凶辄有相礼者，谓之“白席”。韩魏公自枢密归邺，赴一姻家礼席。偶筵中有荔枝，欲啖，白席者遽唱曰：“资政吃荔枝，请众客同吃荔枝！”公憎其饶舌，因置不取。白席者又云：“资政放荔枝矣，请众客放下荔枝！”
注：相礼：协助行礼的人。
注：白席：宴席上唱喝礼仪者。
注：韩魏公：韩琦，封魏国公。
注：枢密：枢密使。
注：邺：今河北临漳一带，韩琦曾守相州。
注：资政：资政殿学士，韩琦曾任。
注：啖：吃。
# 方三拜
题解：方干对王龟一拜再拜，被称“方三拜”，是礼数过分的笑话。
原：诗人方干，吴人也。王龟大夫重之，既延入内，乃连下两拜。亚相安详以答之，未起间，方又致一拜。时号“方三拜”。
注：方干：晚唐诗人，浙江桐庐人。
注：王龟：唐代官员，曾任浙东观察使。
注：亚相：御史大夫，王龟曾任此官。
注：安详：从容。
# 秽史
题解：朱敬则谏武则天宠幸男宠，此条是史书记载之秽事，用于《不韵》部。
原：则天荒淫，右补阙朱敬则谏曰：“陛下内宠已有薛怀义、张易之、昌宗，欲应足矣。近闻尚食奉御柳模，自言子良宾洁白美须眉；左监门卫祥云阳道壮伟，过于怀义，昨欲自进，堪充供奉。无礼无义，溢于朝听！臣职在谏诤，不敢不言。”则天劳之曰：“非卿直言，朕不知此。”赐采百段。
注：则天：武则天。
注：右补阙：谏官，属中书省。
注：朱敬则：唐代名臣，《旧唐书》有传。
注：薛怀义：武则天宠幸的僧人。
注：张易之、昌宗：武则天男宠张易之、张昌宗兄弟。
注：尚食奉御：殿中省尚食局长官。
注：柳模：唐人，事见《旧唐书·朱敬则传》。
注：良宾：柳模之子柳良宾。
注：左监门卫：禁军官署。
注：左监门卫祥云：当作左监门卫长史侯祥云，《旧唐书·朱敬则传》作“侯祥”，待考。
注：阳道：男性生殖器。
注：供奉：陪伴宫禁。
注：谏诤：直言规劝。
注：劳：慰劳。
注：采：同“彩”，彩帛。
# 杨安国进讲
题解：杨安国讲经带乡音，将“箪食瓢饮”讲成“箩粟米饭”，又说“孔子也要钱”，是宋人鄙俗讲官的笑话。
原：杨安国言动鄙朴，尝侍讲仁宗。一日讲“一箪食，一瓢饮”，乃操东音曰：“颜回甚穷，但有一箩粟米饭，一葫芦浆水。”又讲“自行束修以上”一章，遽启曰：“官家，昔孔子教人，也须要钱！”帝哂之。
注：杨安国：北宋人，官至龙图阁直学士，侍讲仁宗。
注：侍讲：为皇帝讲读经史。
注：一箪食，一瓢饮：《论语·雍也》赞颜回之语。
注：东音：山东（东路）口音。
注：浆水：清水或米汤。
注：自行束修以上：《论语·述而》“自行束修以上，吾未尝无诲焉”，束修即十条干肉，指最低的学费。
注：官家：宋代对皇帝的称呼。
注：哂：笑。
# 志文
题解：胡卫道三子名宽、定、宕，友人直写“生三子宽、定、宕”，谐“宽定宕”之音，令人掩鼻。
原：胡卫道三子：孟名宽，仲名定，季名宕。卫道妻亡，俾友作志。友直书曰：“夫人生三子：宽、定、宕。”读者掩鼻。
注：胡卫道：宋人，待考。
注：孟名宽，仲名定，季名宕：孟、仲、季为兄弟排行。
注：志：墓志。
注：宽、定、宕：谐音“宽”“定”“荡”，后成淫语，笑点在连读谐音。
# 判带帽语
题解：府吏为禁带帽露网巾，写“前不露边，后不露圈”被太守改为“前后不露圈边”，是公文避骈偶之笑。
原：《祝氏猥谈》云：一守禁带帽不得露网巾。吏草榜云：“前不露边，后不露圈。”守曰：“公文贵简，何作对偶语？”吏白：“当如何？”守曰：“前后不露圈边。”
注：《祝氏猥谈》：明祝允明《猥谈》，一作《祝氏志怪》。
注：网巾：明代男子束发的网状头巾。
注：榜：告示。
注：对偶语：骈偶句。
# 宣水
题解：石曼卿讥相公“宣水”之名，借“农水”反问，是辨析官署用语不当的趣事。
原：石曼卿在中书堂。一相曰：“取宣水来！”石曰：“何也？”曰：“宣徽院水甘冷。”石曰：“若司农寺水，当呼为农水也？”坐者大笑。
注：石曼卿：石延年，字曼卿，北宋诗人，诙谐。
注：中书堂：宰相处理政务处。
注：宣徽院：宋代官署，掌宫廷事务。
注：司农寺：掌仓廪粮储，此处石曼卿以“农水”相戏。
# 于阗国表
题解：于阗国进表文辞粗朴，称宋帝为“阿舅大官家”，是中外交往中的奇文。
原：宋政和间，有于阗国进玉表章，其首云：“日出东方赫赫大光照见西方五百里国，五里里国内条贯主黑汗王，表上日出东方赫赫大光照见四天下，四天下条贯主阿舅大官家。”又元丰四年，于阗国上表，称：“于阗国偻㑩大福力量知文法黑汗王，书与东方日出处大世界田地主汉阿舅大官家。”
注：政和：宋徽宗年号。
注：于阗国：西域古国，今新疆和田一带。
注：玉表章：以玉制成的表章。
注：条贯主：管辖之主。
注：黑汗王：喀喇汗王朝君主。
注：阿舅：对外甥国对宋帝的尊称。
注：大官家：对皇帝的称呼。
注：元丰四年：1081年，宋神宗年号。
注：偻㑩：待考，当为于阗语对音。
注：日出处：东方，指中国。
注：田地主：土地之主。
# 元世祖定刑
题解：元世祖制五刑，宽免死刑，仁心似戏，是对帝王笑话的记录。
原：元世祖定天下之刑，苔、杖、徒、流、绞五等。笞杖罪既定，曰：“天饶他一下，地饶他一下，我饶他一下。应笞一百者，止九十七；杖亦如之。”此虽仁心，亦近於戏矣。
注：元世祖：忽必烈。
注：苔、杖、徒、流、绞五等：即五刑，“苔”疑当作“笞”，笞杖轻，徒流重，绞为死刑。
注：天饶他一下，地饶他一下，我饶他一下：每减三下，笞一百减为九十七。
注：笞：用小竹板打。
注：杖：用大木杖打。
注：近於戏：近似儿戏。
# 管子治齐
题解：管仲设女闾征夜合之资，事见《战国策》，此类笑话属于秽史。
原：管子之治齐，为女闾七百，征其夜合之资以佐军国。
注：管子：管仲，春秋齐国名相。
注：女闾：女子聚居的闾巷，指官营妓院；《战国策·东周策》“管仲设女闾七百”。
注：夜合之资：过夜的费用。
注：军国：军事与国家。
# 七世庙讳
题解：侯景不知“七庙”，以为要立其祖，听说父名标，当在朔州，这是不识礼之笑谈。
原：侯景篡梁，王伟请立七庙。景曰：“何谓七庙？”伟曰：“天子登七世祖考也。”因请七世讳。景曰：“前世吾不复忆，唯阿爷名标，且在朔州，伊那得来啖是？”众皆掩口。
注：侯景：北魏、东魏将领，后叛入梁，篡位称帝。
注：王伟：侯景谋士，《梁书》有传。
注：七庙：天子宗庙制度，祭祀七世祖先。
注：七世讳：七世祖先的名讳。
注：阿爷：父亲。
注：朔州：今山西朔州。
注：啖：吃，此处以为须要供奉他吃祭品。
# 蜀先主
题解：顾敻戏造蜀先主武举牒，以各种绰号冒充进士，是对前蜀军人出身的讥讽。
原：蜀先主起自利阆，亲骑军各有名号，顾敻戏造武举牒，谓侍郎李叱叱下进士及第三十馀人，姜癞子、张打胸、李嗑蛆、李破肋、李吉了、郝牛屎、陈波斯、罗蛮子等，试《亡命山泽赋》、《到处不生草》诗。一时传以为笑。
注：蜀先主：前蜀高祖王建，早年为盗。
注：利阆：利州、阆州，今四川广元、阆中一带。
注：顾敻：五代词人，曾事前蜀。
注：武举牒：武举考试的公文。
注：侍郎李叱叱：假想的侍郎。
注：姜癞子、张打胸、李嗑蛆、李破肋、李吉了、郝牛屎、陈波斯、罗蛮子：皆武人绰号，戏拟及第者。
注：《亡命山泽赋》：戏题，指为盗。
注：《到处不生草》诗：戏题，指战乱荒芜。
# 诨衣
题解：穆宗赐宫人写满淫词的衣服，号“诨衣”，是《不韵》部收录的秽事。
原：《史讳录》：穆宗以玄绡白书、素纱墨书为衣服，赐承幸宫人，皆淫鄙之词。时号诨衣。至广平中，犹有存者。
注：《史讳录》：书名，待考。
注：穆宗：唐穆宗李恒。
注：玄绡：黑色绡纱。
注：素纱：白色纱。
注：承幸宫人：被皇帝宠幸的宫女。
注：诨衣：戏谑之衣。
注：广平：待考，一说年号“广平”，待考。
# 厕筹
题解：胡应麟以《西厢记》崔莺莺故里博陵论厕筹瓦砾，是文人拿古事调侃的笑话。
原：有客谓胡元瑞曰：“尝客安平，其俗如厕，男女皆用瓦砾代纸，殊可呕哕。”胡笑曰：“安平，唐之博陵，莺莺所产也。”客曰：“大家闺秀，或未必然。”胡因历引古用厕筹事，且云：“厕筹与瓦砾等，吾能不为莺莺要处掩鼻？”客大笑。
注：胡元瑞：胡应麟，字元瑞，明代学者。
注：安平：今河北安平，唐时属博陵郡。
注：瓦砾：碎瓦。
注：呕哕：作呕。
注：博陵：今河北定州一带，崔氏郡望。
注：莺莺：《西厢记》女主角崔莺莺，博陵崔氏。
注：厕筹：古代如厕用的竹木片，《汉书》有“厕筹”。
注：要处：私处。
# 效颦
题解：三则效颦之事：学者仿林宗巾，群妪乱唾左思，人掩鼻学谢安，都是东施效颦的变体。
原：郭林宗尝于陈、梁间行，遇雨，其巾一角垫而折，其后学者著冠，乃故折其一角，以为“林宗巾”。
注：郭林宗：郭泰，字林宗，东汉太学领袖，事见《后汉书》。
注：陈、梁：古陈国、梁国。
注：巾：头巾。
注：林宗巾：后世称“林宗巾”。
原：潘岳妙有姿容，少时挟弹出洛阳道，妇人遇者，莫不连手共萦之。左太冲绝丑，亦复效岳遨游。于是群妪齐共乱唾之，委顿而返。
注：潘岳：西晋美男子，“掷果盈车”。
注：挟弹：携带弹弓。
注：萦：围绕。
注：左太冲：左思，字太冲，貌丑。
注：群妪：众老妇。
注：委顿：疲困。
原：谢安能为洛下诸生咏，有鼻疾，故其音浊。时名流爱其咏，或掩鼻而效之。
注：谢安：东晋名相，能作洛下书生咏。
注：洛下诸生咏：洛阳书生的吟诵声，音调重浊，《世说新语·雅量》。
注：鼻疾：鼻病。
注：掩鼻而效之：用手掩鼻学其声。
# 拟古人名字
题解：东丹国王子赐姓李，却想比拟白居易，自称“乡贡进士黄居难，字乐地”，是仿拟古人姓名之笑。
原：东丹国长子奔唐，赐姓李，名华，颇习诗文。甚慕白居易，思配拟之，每通名刺，曰“乡贡进士黄居难，字乐地”。
注：东丹国：契丹所建，长子耶律倍曾为东丹王。
注：奔唐：投奔后唐。
注：赐姓李，名华：李赞华，耶律倍入唐后改名。
注：白居易：字乐天，与“乐地”相拟。
注：名刺：名片。
注：乡贡进士：由乡里推荐应试的进士。
注：黄居难：疑当作“黄居难”，宋代画家黄居寀之兄，此处仿“居易”。
# 媚猪
题解：刘𬬮宠幸黑胖的波斯女，赐号“媚猪”，是南汉荒淫之笑料。
原：南汉主刘𬬮得波斯女，黑腯而慧艳。𬬮嬖之，赐号“媚猪”。
注：南汉主刘𬬮：南汉后主刘鋹，在位昏庸。
注：波斯女：波斯籍侍女。
注：黑腯：黑而肥胖。
注：嬖：宠爱。
注：媚猪：以猪喻其肥。
# 相婆
题解：王安石遇路边老妇，以药相赠，老妇回赠麻线并称“相婆”，把宰相之妻戏称相婆，是民间俗语的笑话。
原：王和甫守金陵。荆公退居半山。一日路遇和甫，公入编户家避之。老姥见公带药笼，告之病。公即给以药。姥酬麻线一缕，语公曰：“相公可将归与相婆。”荆公笑则受之。
注：王和甫：王安礼，字和甫，王安石之弟，曾知江宁。
注：荆公：王安石。
注：半山：王安石退居江宁半山园。
注：编户：平民之家。
注：药笼：盛药的筐。
注：相公：对宰相或官员的尊称。
注：相婆：相公之妻。
# 瓜战
题解：以“茗战”类比“瓜战”，是钱氏子弟的游戏，讥其庸俗。
原：昔人喜斗茶，故称茗战。钱氏子弟取霅上瓜，各言子之的数，剖之以视胜负，谓之“瓜战”。然茗犹堪战，瓜则俗矣。
注：斗茶：宋代以品茶评优劣的游戏，也称“茗战”。
注：钱氏子弟：钱镠后代，吴越王室后人。
注：霅上：霅溪之畔，今湖州。
注：的数：确切数目。
# 锻工、屠宰
题解：杨慎所记锻工戴东坡巾、屠宰号“一峰子”，与苏轼、罗伦同名，是以名士号混用之讽。
原：杨升庵云：永昌有锻工，戴东坡巾；屠宰，号“一峰子”。一善谑者，见二人并行，遥谓之曰：“吾读书甚久，不知苏学士善锻铁，罗状元能省牲，信多能哉！”传以为笑。
注：杨升庵：杨慎。
注：永昌：今云南保山，杨慎谪居之地。
注：东坡巾：苏轼所戴高筒帽式头巾。
注：一峰子：罗伦，号一峰，明成化二年状元，永昌谪地。
注：罗状元：罗伦，成化状元。
注：省牲：宰牲，罗伦字“应魁”，此处借“省牲”之职戏之。
注：苏学士：苏轼。
# 别号
题解：今人无人不号，且兄弟父子取同类号，实不雅，作者举冰壶老拙等例讥之。
原：《猬谈》云：道号别称，古人间自寓怀，非为敬名设也。今则无人不号矣。“松”、“兰”、“泉”、“石”，一坐百犯，又兄“山”则弟必“水”，伯“松”则仲、叔必“竹”、“梅”，父此物，则子孙引此物于不已，愚哉！向见一嫠媪，自称“冰壶老拙”，则妇人亦有号矣。又嘉兴女郎朱氏，能诗，自号“静庵”，见《说听》。又江西一令讯盗，盗忽对曰：“守愚不敢。”令不解。傍一胥云：“守愚，其号也。”
注：《猬谈》：待考，明人笔记。
注：别称：别号。
注：嫠媪：寡妇。
注：冰壶老拙：号。
注：朱氏：嘉兴才女，号“静庵”，见《说听》。
注：《说听》：明人笔记，陆延枝撰。
注：守愚：号。
注：胥：小吏。
# 印章
题解：门达的门客刻“锦衣西席”，甘棠刻“翰苑东床”，是明代门客印章的巧对。
原：天顺间，锦衣门达甚得上宠。有桂廷珪为达门客，乃私镌印章云“锦衣西席”。后有甘棠为洗马江朝宗婿，而棠亦有印章云“翰苑东床”。一时传赏，可为的对。
注：天顺：明英宗年号（1457—1464）。
注：锦衣：锦衣卫。
注：门达：明英宗朝锦衣卫指挥使，权势熏天。
注：桂廷珪：待考。
注：西席：家塾教师称“西席”。
注：甘棠：待考。
注：洗马：太子洗马，翰林官。
注：江朝宗：待考。
注：东床：女婿的雅称，王羲之“东床坦腹”。
注：翰苑：翰林院。
注：的对：恰切的对仗。
