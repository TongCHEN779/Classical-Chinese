# 正文
题解：《巧言部》总序，子犹论谐谑之巧，说明本部编次为第二十八。
原：〔子犹曰：古人戒如簧之舌，岂不以巧哉，然“谈言微中，可以解纷”，夫独非巧言乎？如此曰谐谑而已，功与罪两不居焉，则诸公口中三寸，真有天孙机杼在矣！集《巧言》第二十八。〕
注：子犹：冯梦龙之号。
注：如簧之舌：《诗经·小雅·巧言》“巧言如簧，颜之厚矣”，斥花言巧语。
注：谈言微中，可以解纷：《史记·滑稽列传》“谈言微中，亦可以解纷”，谓委婉之言切中事理，可解纠纷。
注：三寸：指舌头，口舌。
注：天孙机杼：天孙即织女，传说善织云锦，喻文辞巧妙织就。
注：《巧言》：《古今谭概》第二十八部。
# 花名
题解：温庭筠以“赐紫”“镀金”谐谑花名。
原：温庭筠曰：“葡萄是赐紫樱桃，黄葵是镀金木槿花。”
注：温庭筠：晚唐诗人词人，字飞卿，才思敏捷，行为放诞。
注：赐紫：唐代官员服色，三品以上着紫；五品以上赐紫者为“赐紫”，此处戏喻葡萄紫色。
注：樱桃：以樱桃红比官服，此处调侃，樱桃红色，又“赐紫樱桃”之说。
注：黄葵：花名，黄蜀葵。镀金：以金涂饰。木槿花：花名，朝开暮落。
# 黄幡绰
题解：黄幡绰以谐语应对唐玄宗，三则逸事。
原：明皇与诸王会食。宁王错喉，喷上须。王惊惭不遑。上顾其悚悚，欲安之。黄幡绰曰：“此非错喉。”上曰：“何也？”对曰：“是喷帝。”上大悦。〈“喋”音“帝”。〉
注：明皇：唐玄宗李隆基，谥“明皇”。
注：宁王：李宪，玄宗长兄，睿宗长子，让位于玄宗，封宁王。
注：错喉：吃东西呛住，指喷出食物。
注：黄幡绰：唐玄宗时著名伶人，善滑稽。
注：喷帝：宁王噎喷在玄宗须上，黄幡绰谐“喷嚏”作“喷帝”，替他解围；文末小注谓“喋”音“帝”。
原：玄宗尝登苑北楼望渭水，见一醉人临水。上问左右是何人，左右不知。黄幡绰曰：“此是年满典史。”上曰：“何以知之？”对曰：“更一转入流。”上笑。
注：年满典史：典史为县级末流小官，不入流品；任满后“转入流”才算入品官，故戏称醉人晃动将“转入流（水）”。
注：更一转入流：双关，“流”既指入流品官，也指流水。
注：渭水：渭河，流经长安北。
原：玄宗小字三郎。幸蜀时，过梓潼县，上停驿问黄幡绰曰：“车上铃声颇似人语。”对曰：“似言‘三郎郎当’、‘三郎郎当’。”后因名琅珰驿。
注：三郎：玄宗在兄弟中行三，宫中称三郎。
注：幸蜀：安史之乱中玄宗奔蜀，事在天宝十五载（756）。
注：梓潼：今四川梓潼。
注：郎当：潦倒狼狈貌，驿铃声似“郎当”，故驿名“琅珰驿”，事见《明皇杂录》。
# 三果一药
题解：刘贡父与苏轼以药名对话相戏。
原：刘贡父觞客。苏子瞻有事欲先起。刘以三果一药调之曰：“幸早里，且从容。”苏答曰：“奈这事，须当归。”
注：刘贡父：刘攽，字贡父，北宋史学家，《汉书》学者，诙谐。
注：觞客：设酒宴待客。
注：苏子瞻：苏轼，字子瞻。
注：幸早里：谐“杏枣梨”，三种水果。
注：从容：谐“苁蓉”，药名。
注：奈这事：“奈”谐“柰”，果名。
注：须当归：当归，药名，兼有“该回去了”之意。
# 投壶
题解：邵雍与李君锡投壶戏谑，借“耳”“壶”双关。
原：邵康节与李君锡投壶。君锡末箭中耳。君锡曰：“偶尔中耳。”康节曰：“几乎败壶。”
注：邵康节：邵雍，北宋理学家，谥康节。
注：李君锡：待考。
注：投壶：古代宴会游戏，把箭投入壶中。
注：末箭中耳：最后一箭投中壶耳。“耳”又为语气词，“偶尔中耳”。
注：几乎败壶：谐“几乎败乎”，“壶”谐“乎”。
# 尹字
题解：苏颋幼时拆字咏“尹”字，嘲京兆令。
原：苏颋幼时，有京兆令咏“尹”字。乃云：“丑虽有足，甲不全身。见君无口，知伊无人。”
注：苏颋：唐代名相，字廷硕，幼敏悟，封许国公。
注：京兆令：京兆府属县之县令。
注：丑虽有足，甲不全身：拆字戏，“尹”字形似“丑”“甲”各缺一部分，故云。
注：见君无口：“君”去“口”为“尹”。
注：知伊无人：“伊”去“人”（亻）为“尹”。
# 姓名谑
题解：郭忠恕与聂崇义以姓名相谑。
原：郭忠恕嘲司业聂崇义云：“近贵全为聩，攀龙只是聋。虽然三个耳，其奈不成聪！”聂应声曰：“莫笑有三耳，何如蓄二心？”
注：郭忠恕：北宋初书画家、文字学家，字恕先，性疏放。
注：司业：国子监副长官。
注：聂崇义：北宋礼学家，官国子司业，著《三礼图集注》，“聂”字为三个“耳”。
注：三耳：“聂”字三耳。
注：近贵全为聩：“聩”为耳聋，与“贵”字形音相近，戏嘲聂崇义耳聩。
注：攀龙只是聋：“聋”字含“龙”，戏其耳聋。
注：二心：怀有二心，反讥郭忠恕反复。
# 王、甘姓
题解：甘洽与王仙客拆字相谑。
原：唐时有甘洽者，与王仙客友善，因以姓相嘲。洽曰：“王，计尔应姓田，为你面惫懒，抽却你两边。”仙客应声曰：“甘，计尔应姓丹，为你头不曲，回脚向上安。”
注：甘洽：唐人，待考。
注：王仙客：唐人，待考。
注：计尔应姓田：拆字戏，谓“王”字应改作“田”，待考其详。
注：惫懒：顽劣，无赖。
注：回脚向上安：拆字戏，谓“甘”应作“丹”，待考其详。
# 王、卢
题解：徐之才以拆字嘲王昕、卢元明。
原：北齐徐之才善谑，尝嘲王昕姓云：“有言则𧥶，近犬则狂，加颈足为马，拖角尾成羊。”嘲卢元明云：“卿姓在亡为虐，在丘为虚，生男为虏，配成马驴。”
注：徐之才：北齐名医，博学滑稽，见《北齐书》。
注：王昕：北齐人，字元景，有才学。
注：有言则𧥶：“王”加“言”成“𧥶”，同“诳”，意为欺诳。
注：近犬则狂：“王”加“犬”旁成“狂”。
注：加颈足为马：“王”加头颈脚而成“马”。
注：拖角尾成羊：“王”加角、尾成“羊”。
注：卢元明：北齐人，名元明，有文才。
注：在亡为虐：“卢”字拆之，“虍”下“亡”为“虐”。
注：在丘为虚：虍下丘为“虚”。
注：生男为虏：虍下男为“虏”。
注：配成马驴：“卢”“驴”相近，以“驴”配“马”。
# 麦、窦
题解：隋麦铁杖应对窦威以“麦豆”谐姓。
原：隋麦铁杖为汝南太守，因朝集，考功郎窦威嘲之曰：“麦是何姓？”铁杖曰：“麦豆不殊，何忽见怪？”威赧然无以应。
注：麦铁杖：隋朝大将，勇武，事见《隋书》。
注：汝南：郡名，今河南汝南。
注：朝集：地方官入京朝集。
注：考功郎：吏部考功司郎中。
注：麦豆不殊：麦与豆同属五谷，不分彼此，以“窦”谐“豆”回敬。
注：窦威：隋唐间人，字文蔚，官内史舍人，入唐官内史令，“窦”“豆”谐音。
注：赧然：脸红羞愧。
# 沈、陈姓对
题解：沈筠谿与陈氏兄弟以姓氏对句，巧绝。
原：归安沈筠谿先生少绝敏颖，弱冠补博士弟子，与弟偕之城。时风雨暴作，遇陈方伯兄弟于邸。方伯戏曰：“大雨沉沉，二沈伸头不出。”公矢口曰：“狂风阵阵，两陈摇尾不开。”人称巧绝。
注：归安：今浙江湖州。沈筠谿：待考。
注：博士弟子：即秀才，府学生员。
注：陈方伯：陈姓布政使，“方伯”为布政使别称，待考。
注：矢口：脱口而出。
注：大雨沉沉，二沈伸头不出：“沉”谐“沈”，戏言沈氏兄弟被雨沉住，伸不出头。
注：两陈摇尾不开：“阵”谐“陈”，反戏陈氏兄弟如摇尾之犬被风阵压住。
# 乂名
题解：林叔弓作赋嘲张乂天身小，以拆字、用典相戏。
原：张乂天太学为斋长，其人渺小，动以苛礼律诸生。林叔弓作赋嘲云：“身材短小，欠曹交六尺之长；腹内空虚，乏刘义一点之墨。”又诗云：“中分爻两段，风使十横斜，文上全无分，人前强出些。”
注：张乂天：待考。太学为斋长：太学生中管理一斋的学生长。
注：苛礼：苛刻的礼法。
注：林叔弓：待考。
注：曹交：《孟子·告子下》载其身长九尺四寸；“交”字去“六”即“乂”，故云欠六尺。
注：刘义：待考；“义”字去一点为“乂”，故云乏一点之墨。
注：中分爻两段：“爻”字从中分开，各成一“乂”，拆字戏。
注：风使十横斜：“十”字斜置即成“乂”。
# 安石名
题解：刘邠拆王安石名字相谑。
原：刘邠与王安石最为故旧，尝拆安石名戏之曰：“失女便成宕，无宀真是妒。下交乱真如，上头误当宁。”王大惭。〈“宀”音“绵”。〉
注：刘邠：即刘攽，字贡父，“邠”“攽”形近，待考。
注：王安石：北宋宰相，字介甫，号半山。
注：故旧：旧友。
注：失女便成宕：“安”字失去“女”剩“宀”，加“石”成“宕”，拆字戏。
注：无宀真是妒：“安石”去“宀”，剩“女”“石”合成“妒”。
注：下交乱真如：待考。
注：上头误当宁：“宁”字与“安”同头，待考。
# 王汾、刘攽、王觌
题解：王汾、刘攽、王觌互相以名号相谑。
原：王彦和汾与刘贡父攽同趋朝。王戏刘曰：“内朝日日须呼汝。”盖常朝知班吏，多云“班班”，谓之“唤班”。〈“攽”音“班”，故戏之。〉刘应声曰：“寒食年年必上公。”〈汾、坟音近。〉刘又尝戏王觌云：“公何故见卖？”王答曰：“卖公值甚分文？”
注：汾：王汾，字彦和，北宋人，官至龙图阁直学士。
注：趋朝：入朝。
注：常朝：日常朝参。知班吏：负责朝班点名的吏。
注：唤班：点名叫班，“班”与“攽”音近。
注：寒食：节令名，清明前一两日，寒食扫墓。“汾”与“坟”音近。
注：上公：上坟，也指封“上公”之爵，双关。
注：王觌：字明叟，北宋人，官御史、尚书。
注：见卖：被出卖。
注：值甚分文：值得几文钱。
原：治平初，濮安懿王原寝皆用红泥杂饰，刘贡父谓王汾曰：顷闻王坟赐绯，得非子有银章之命耶。
注：治平：宋英宗年号（1064—1067）。
注：濮安懿王：英宗生父赵允让，英宗即位后追封，引发“濮议”。
注：原寝：陵寝。红泥：以红泥涂饰陵寝。
注：王坟：谐“王汾”。赐绯：朝廷赐绯色官服，“绯”与“坟红泥”相应。
注：银章：银印，品官佩带。
# 陈亚、蔡襄
题解：陈亚与蔡襄以名字拆字互嘲。
原：陈少卿亚，维扬人，善诗，滑稽尤甚。尝与蔡君谟会于僧舍。君谟题诗屏间曰：“陈亚有心终是恶。”亚即索笔对曰：“蔡襄无口便成衰。”
注：陈少卿亚：陈亚，官太常少卿。
注：维扬：扬州。
注：蔡君谟：蔡襄，字君谟，北宋书法家，名列“宋四家”。
注：陈亚有心终是恶：“亚”字加“心”成“恶”。
注：蔡襄无口便成衰：“襄”字去“口”为“衰”。
# 上官弼
题解：陈亚与上官弼用姓名相谑。
原：陈亚知润州，幕中有上官弼，为亚所亲。任满将去，谓亚曰：“郎中才行无玷，宜简调谑。”亚曰：“君乃上官弼也，如下官口何？”弼笑而去。
注：润州：今江苏镇江。
注：上官弼：待考。
注：幕中：幕府。
注：无玷：没有污点。
注：简调谑：减少调侃。
注：下官：官员自称，“下官口”双关，“上官”相对“下官”，如何堵住“下官口”。
# 贾黄中、卢多逊
题解：贾黄中与卢多逊以谐音相谑。
原：贾黄中与卢多逊俱在政府。一日，京中有蝗虫，卢笑曰：“某闻所有乃假蝗虫。”贾应声曰：“亦闻不伤禾，但芦多损耳。”
注：贾黄中：北宋初人，官参知政事。
注：卢多逊：北宋初宰相，后被贬崖州。
注：政府：宋称中书门下为政府。
注：假蝗虫：“贾”谐“假”，戏称蝗虫是假的。
注：芦多损：“卢多逊”谐“芦多损”，蝗虫食稻而不伤禾，则只损芦苇。
# 苏子瞻、姜制之
题解：苏轼以药名戏姜制之。
原：苏子瞻与姜制之饮。姜举令云：“坐中各要一物，是药名。”乃指子瞻曰：“苏子。”子瞻应声曰：“君亦药名也。若非半夏，定是厚朴。”众请其故。子瞻曰：“非半夏，非厚朴，何故曰姜制之？”
注：姜制之：姜潜，字至之，此作“制之”，待考。
注：半夏：药名，炮制时以姜制。
注：厚朴：药名，亦以姜制，故以“姜制之”相戏。
# 章得象
题解：石中立戏章得象，用“象”画名相戏。
原：章郇公得象，与石资政中立素相善。而石喜谈谑，尝戏章云：“昔时名画有戴松牛、韩干马，今又有章得象也！”
注：章郇公得象：章得象，字希言，北宋仁宗朝宰相，封郇国公。
注：石资政中立：石中立，字曼卿，官资政殿学士，滑稽诙谐。
注：戴松牛：戴嵩画牛，“松”或为“嵩”之误。
注：韩干马：韩干，唐代画马名家。
注：章得象：“象”与“牛”“马”并列，戏称其为“象”。
# 华嵩
题解：华嵩因宿娼被枷，师桓以此戏夏昕。
原：京卫指挥华嵩以宿娼枷示。时中书夏仲昭以画竹名，适过马师桓家，因教坊相近，欲易便服，拉师桓往游。师桓戏曰：“你不见华嵩事，又来画竹！”
注：京卫指挥：京城卫所指挥使。华嵩：待考。
注：枷示：戴枷示众。
注：夏仲昭：夏昶，字仲昭，明代画竹名家，官太常寺卿。
注：中书：中书舍人，掌书画。
注：马师桓：待考。
注：教坊：官设乐妓管理机构，此处指妓院。
# 黑齿常之
题解：张鷟以俳谐赋戏黑齿常之，用“尝脂”谐“常之”。
原：张文成工为俳谐诗赋。时大将军黑齿常之将出征，或勉之曰：“公官卑，何不从行？”文成曰：“宁可且将朱唇饮酒，谁能逐你黑齿尝脂？”
注：张文成：张鷟，字文成，唐代文学家，著《游仙窟》，行文诙谐。
注：黑齿常之：百济人，唐朝名将，官至燕然道大总管。
注：朱唇：红唇，指妓女。
注：黑齿尝脂：“黑齿常之”谐音戏言，“尝脂”指舔脂粉。
# 许敬宗
题解：许敬宗以“彪”“狼”“羊”预言杨思玄败。
原：吏部侍郎杨思玄，贵恃外戚，倨待选流，为选者夏候彪所讼，又为御史中丞郎馀庆奏免。时中书许敬宗曰：“杨必败矣！”人问之。许曰：“一彪一狼，共著一羊，岂得不败？”
注：杨思玄：唐吏部侍郎，外戚。
注：倨待选流：傲慢对待候选官员。
注：夏候彪：当作“夏侯彪”，唐人。

注：谏议：谏议大夫。
注：执政：宰相、参知政事。
注：迟回：犹豫。
注：台：御史台。
注：鸣鼓而攻之：《论语·先进》孔子骂冉求“鸣鼓而攻之，可也”。
注：暗箭子：暗中放箭之人，与“鸣鼓”相对。
注：鸣鼓儿：谐刘贡父讥其公开攻击。
# 陆伯阳
题解：潘沧浪以“六百羊”戏“陆伯阳”。
原：潘沧浪邂逅一客，扣姓字。客曰：“姓陆字伯阳。”潘笑曰：“齐景公有马千驷，民无得而称焉。六百羊值甚的？”
注：潘沧浪：待考。
注：邂逅：偶然相遇。
注：扣姓字：问姓名与表字。
注：齐景公有马千驷：《论语·季氏》“齐景公有马千驷，死之日，民无得而称焉”。
注：六百羊：“陆百羊”，“陆伯阳”谐“六百羊”，戏之。
# 王和尚
题解：吴僧还俗骄人，被优伶借《苏季子》传奇讥讽。
原：吴僧姓王，因兄登第，还俗娶妇，而气极骄。众甚鄙厌。一日，偶同宴会。众谓优人曰：“王和尚颇作怪，汝可诮之。”因演《苏季子》传奇，起课者有“黄河尚有澄清日，岂可人无得运时”之语。优念云：“王和尚有成亲日，起课人无得运时。”众大笑，王逃席去。
注：吴僧：吴中和尚。
注：登第：考中进士。
注：优人：戏曲演员。
注：苏季子：苏秦，字季子，战国纵横家。《苏季子》传奇，演苏秦事。
注：起课：占卜。
注：黄河尚有澄清日：谚语，黄河也有清的时候，比喻时来运转。
注：成亲日：“王和尚有成亲日”，戏其还俗娶妻。
注：得运时：好运来之时。
# 铁炮杖
题解：铁炮杖以“红蜻蜓”嘲百户。
原：万历初，吴中优人有铁炮杖者，以黑短得名，善谑浪。某百户以红袍赴新亲宴，坐客嘱优嘲之。适演考试事，出“纸灰飞作白蝴蝶”。铁炮杖对曰：“百户变了红蜻蜓。”一座大笑。
注：铁炮杖：苏州优伶，以黑短得名。
注：百户：卫所武官，正六品。
注：红袍：此处指官服。
注：新亲宴：新婚亲家酒宴。
注：纸灰飞作白蝴蝶：南宋高翥《清明日对酒》句，“泪血染成红杜鹃”为下句。
注：红蜻蜓：与“白蝴蝶”相对，红袍百户。
# 娄师德园
题解：娄师德园变袁德师楼，洛中人以谐语为戏。
原：袁德师尝买得娄师德故园地，起书楼。洛中人语曰：“昔日娄师德园，今乃袁德师楼。”
注：袁德师：待考。
注：娄师德：唐武后朝名相，宽厚，被称“唾面自干”。
注：洛中：洛阳。
注：娄师德园：“娄师德”与“袁德师”音近，戏作对句。
# 无法无聊
题解：陈延之以“无法无聊”戏僧人和宦官。
原：都人陈延之，见一僧与中贵游金陵诸刹，因叙款曲，戏曰：“二君不是无法，即是无聊。”
注：陈延之：待考。
注：中贵：有权势的宦官。
注：金陵诸刹：南京诸佛寺。
注：款曲：衷情，此处指闲谈。
注：无法：僧人“无法”，戏谑；“法”谐“僧法”。
注：无聊：“聊”谐“寮”，戏言“无聊”，待考。
# 家兄孔方
题解：袁中郎与江盈科以“孔方”戏言不收贿。
原：袁中郎与江菉萝分宰长、吴二邑，中郎一无问馈。时兄石浦在翰林，江潮中郎曰：“他人问馈，以孔方为家兄。君不问馈，以家兄为孔方耳。”
注：袁中郎：袁宏道，公安派代表，万历二十三年任吴县令。
注：江菉萝：江盈科，号绿萝，万历时长洲县令，著《雪涛谐史》等。
注：长、吴二邑：长洲县、吴县，同属苏州府。
注：问馈：收受馈赠。
注：兄石浦：袁宗道，号石浦，官翰林院编修，袁宏道之兄。
注：孔方：铜钱，因中有方孔。
注：孔方为家兄：晋鲁褒《钱神论》称钱为“孔方兄”。
注：家兄为孔方：反用，意谓只认家兄不认钱。
# 吴妓张兰
题解：苏州妓张兰与陆龙石以“老少”“大小”互谑。
原：吴妓张兰色丽而年已娘行。一日客携游山，陆龙石戏曰：“老便老，还是个小娘。”陆有太医札付。张应声曰：“小便小，也是个老爹。”众皆鼓掌。〈《耳谈》作杜生、张好儿事。 〉
注：张兰：苏州妓女，待考。
注：娘行：旧称成年妇人。
注：陆龙石：待考。
注：小娘：对年轻女子的称呼，亦指妓女。
注：太医札付：太医院的任职文书。
注：小便小，也是个老爹：“小便”双关，“老爹”指父老，兼谐“太医”。
注：耳谈：明王同轨著笔记，所记多异闻。
注：杜生、张好儿：《耳谈》中人物，待考。
# 丑妇八字
题解：南里先生娶丑妻，艾子往贺，借八字戏之。
原：南里先生娶妻，求国色，故久而不就。一旦为媒氏所欺，反奇丑。艾子往贺，因询其庚甲，欲为推算。南里先生闭目摇首而答曰：“辛酉戊辰，乙巳癸丑！”
注：南里先生：宋代笑话人物，苏轼《艾子杂说》中人。
注：国色：绝色美女。
注：媒氏：媒人。
注：艾子：《艾子杂说》中虚构人物，托名苏轼所作。
注：庚甲：生辰八字，也称“庚帖”。
注：辛酉戊辰，乙巳癸丑：八字，“辛”“酉”等与“丑”“巳”谐，“癸丑”谐“怪丑”；待考。
原：巧言部终
注：巧言部终：《巧言部》到此为止。
# 附注
题解：录入者对《蟫精隽》所引“杏枣李”“奈蔗柿”之注。
原：（录入者注，非原文内容，仅供参考。）
注：录入者注：后人整理加注，不是冯梦龙原文。
原：〈注：《 蟫精隽 》幸早里，且从容。盖以“杏、枣、李”三果，贯“从容”一药。坡曰：奈这事，须当归。“奈、蔗、柿”亦三果，贯“当归”一药。〉
注：蟫精隽：明徐𤊹所著笔记《蟫精隽》，所记多为文人轶事、谐语。
注：幸早里：谐“杏枣李”三果，与“从容”（苁蓉，药名）相贯。
注：杏、枣、李：三种水果。
注：奈、蔗、柿：三种水果，“奈”谐“柰”，“蔗”谐“这”，“柿”谐“事”。
注：当归：药名。
