# 正文
题解：《口碑》部的总评，感叹无论君主还是权贵，终究最怕民间的舆论与讥谣，并点明本部为全书第三十一部。
原：〔子犹曰：古来不肖之人，皇灵不能使忌，天谴不能使霅，而独畏匹夫匹妇之口。何也？皇灵天谴皆不必，而匹夫匹妇之口必也。郑侨采乡校之仪，宋毕避东门之讴，而免近庸君，如宋理宗，亦谓谏官曰：“尽忠由你，只莫将副本传将外去。”人之多口，信可畏夫！而犹有甘心遗臭由人笑骂者，彼何人哉！集《口碑》第三十一。〕
注：子犹曰：冯梦龙（号子犹）自称，下为其评语。
注：皇灵：皇天神灵，指上天的威权。
注：天谴：上天的谴责惩罚。
注：霅：疑为“慴”之误，意为使之畏惧；待考。
注：匹夫匹妇：普通百姓，平民男女。
注：郑侨采乡校之仪：郑侨即子产，《左传·襄公三十一年》载他不毁乡校，听取国人议论而择善改之。
注：宋毕避东门之讴：典出《左传·宣公二年》，华元败于郎，筑城者歌“睅其目，皤其腹”讥之，华元使骖乘答以“牛则有皮”；“宋毕”之名待考，疑为误记。
注：宋理宗：赵昀，南宋第五位皇帝，在位期间权臣迭出，朝议多讥。
注：谏官：负责规谏皇帝与弹劾百官的言官，宋代有台谏之称。
注：副本：奏章的抄副件；理宗语意是不许谏官把奏章抄出外传，出处待考。
注：遗臭：留下恶名。
注：集《口碑》第三十一：《古今谭概》以部分类，《口碑》为其中第三十一部，所收多为民间谣谚讥刺。
# 世修降表
题解：李昊先后为前蜀、后蜀两度草拟降表，蜀人以“世修降表李家”嘲之。
原：蜀主孟昶李昊草降表。前王蜀之亡于唐也，降表亦昊为之。蜀人夜书其门曰：“世修降表李家”。
注：孟昶：后蜀末代君主，乾德三年（965）降宋。
注：李昊：字穹佐，前蜀王衍、后蜀孟昶朝皆仕，二度为降表草稿，事见《十国春秋》等。
注：降表：投降时呈献给胜方的表文。
注：前王蜀：指前蜀王衍，后唐同光三年（925）灭于后唐；“唐”指后唐。
注：世修降表李家：谓李家世代以写降表为业，讥其无节。
# 阎立本、姜恪
题解：阎立本以画名而官至宰相，与姜恪并称，时人以“宣威沙漠”“驰誉丹青”相对，讥其非宰相之才。
原：阎立本精于画，朝野珍之。即辅政，但以俗材应务，无宰相器。时姜恪以战功擢左相。时人为之语曰：“左相宣威沙漠，右相驰誉丹青。”
注：阎立本：初唐画家，善人物，官至右相，总章元年（668）拜右相。
注：辅政：入相辅佐朝政。
注：姜恪：唐将，以战功拜左相，曾破吐谷浑等。
注：左相：龙朔二年（662）改尚书左仆射为左相，与右相对。
注：宣威沙漠：在沙漠扬威，指姜恪征战之功。
注：驰誉丹青：以绘画驰名，指阎立本善画；事见《旧唐书·阎立本传》。
# 源休、郭倪
题解：以“火迫酂侯”“带汁诸葛”两例，嘲讽妄自比拟古人而不堪其实的人。
原：唐源休受朱泚伪官，自比萧何之功，入长安日，首收图籍。时人笑之，目曰：“火迫酂候。”宋南渡，有郭倪为将，自比诸葛。酒后辄咏“三顾频繁，两朝开济”之句，而屏风、便面一一皆书此二句。未几败于江上，仓惶涕泣而匿。时谓之“带汁诸葛”。正可作对也。
注：源休：唐德宗时官员，随朱泚叛，任伪职，后被杀。
注：朱泚：泾原兵变后被拥为帝，国号秦，后兵败被杀。
注：萧何：汉初相国，入关首收秦丞相府图籍，封酂侯。
注：酂候：“酂侯”，萧何封号；“火迫酂侯”谐“火烧”，以源休狼狈作比，意谓被火逼迫的萧何，有嘲谑意。
注：郭倪：南宋将领，韩侂胄北伐时任山东、京东招抚使，兵败于江上。
注：三顾频繁，两朝开济：杜甫《蜀相》诗句，咏诸葛亮。
注：便面：扇子，古人用以遮面，故名。
注：带汁诸葛：谓败后狼狈流涕如带着汁水的诸葛，也与前“火迫酂侯”相对为嘲。
# 姜师度、傅孝忠
题解：姜师度好凿渠、傅孝忠善占星，时人以“看天”“穿地”相对成语。
原：唐河中尹姜师度好沟洫，所在必发众穿凿。虽时有不利，而成功益多。先是太师令傅孝忠善占星纬。时人为之语曰：“傅孝忠两眼看天，姜师度一心穿地。”
注：姜师度：唐玄宗朝官员，以水利著称，曾任河中尹，开渠引水。
注：沟洫：田间水道，此指水利工程。
注：太师令：当为“太史令”之误，掌天文历法；待考。
注：傅孝忠：唐太史令，善天文占候。
注：星纬：星象与纬书，泛指天文占候之术。
# 陈和叔、孔仲誉
题解：陈和叔、孔仲誉前后行迹不同，王平甫以“杜园贾谊”对“热熟颜回”，成为一联趣对。
原：陈和叔为举子，通率少检；后举制科，骤为质朴。时号“热熟颜回”。时孔仲誉对制策，言“天下有可叹息痛哭者”。既被斥，和叔曰：“孔生真杜园贾谊也。”王平甫闻之曰：“‘杜园贾谊’，好对‘热熟颜回’。”
注：陈和叔：陈绎，字和叔，北宋官员。
注：举子：参加科举的应试者。
注：制科：由皇帝特诏举行的非常规考试。
注：通率少检：放纵率意，不检点。
注：热熟颜回：颜回为孔门德行之首，“热熟”谓装得谨饬，讥其应举前后判若两人。
注：孔仲誉：宋人，应制科言事被斥，生平待考。
注：对制策：应制科考试，回答皇帝策问。
注：天下有可叹息痛哭者：化用贾谊《治安策》“可为痛哭者一，可为流涕者二，可为长太息者六”。
注：杜园：杜撰之园，谓不实、造作；“杜园贾谊”谓假冒的贾谊。
注：王平甫：王安国，字平甫，王安石之弟，北宋文人。
# 张𬸦、董万举
题解：张𬸦与董万举一贵一贱，“青钱学士”对“白腊明经”，工整成对。
原：张𬸦，号“青钱学士”，以其万选万中。时有明经董万举，九上不第，时嘲曰“白腊明经”。时以为的对。
注：张𬸦：“张鷟”之异写，唐人，号“青钱学士”，著《游仙窟》《朝野佥载》。
注：青钱学士：员半千称张鷟之文如青铜钱，万选万中，见《新唐书》。
注：明经：唐代科举科目，较进士易。
注：九上不第：九次应考而未中。
注：白腊明经：“白腊”即白蜡，谐“白蜡”，质轻而易折，讥其屡试不中；亦以“白”对“青”。
注：的对：恰当工整的对仗。
# 孔太守
题解：记嘉靖前后松江一带官场谣谚，以谐音人名嘲官。
原：孔太守在任时，聂双江初到，有“三耳无闻，一孔不窍”之谣。近年又有“松江同知贪酷，拼得重参；华亭知县清廉，允宜光荐”之对。时潘天泉为同知，名仲骖；倪东洲为华亭县尹，名光荐故也。
注：孔太守：疑指孔姓松江知府，生平待考。
注：聂双江：聂豹，号双江，嘉靖间曾任松江府官，后官至兵部尚书；此谣所指时事待考。
注：三耳无闻，一孔不窍：谐“聂”字三耳与“孔”字，言聂、孔二官皆昏聩；“三耳”拆“聂”，“一孔”指孔太守。
注：同知：知府副职，掌盐粮捕务。
注：重参：再三弹劾。
注：允宜光荐：谐“光荐”为人名，意为应当荐举。
注：潘天泉：松江同知，名仲骖，事迹待考。
注：倪东洲：华亭知县，名光荐，事迹待考。
注：县尹：知县。
# 严子陵
题解：因“严子陵”“王孙贾”之名，以古人姓名嘲讽认父抱孙之事。
原：凌某拜严介溪为父，人称“严子陵”。后有缙绅王姓者，抱他人子为孙，世即对为“王孙贾”。
注：严介溪：严嵩，号介溪，明嘉靖朝权相。
注：严子陵：东汉严光，字子陵，隐士；此以“严”之子，谐“严子”之陵。
注：缙绅：有官职的士大夫。
注：王孙贾：春秋卫国大夫；此谐“王孙”（王家之孙）与“贾”（假）。
# 鸱鸮公
题解：记南京国子监祭酒的两则绰号，因所好而得名。
原：《水南翰记》：南京国子监有鸮鸣。祭酒周洪谟令监生能捕者，放假三日，人目为“鸱鸮公”。其后刘先生俊为祭酒，好食蚯蚓。监生名之曰“蚯蚓子”，以为对。
注：《水南翰记》：明李如一撰笔记，水南为其号。
注：国子监：明代设南北两监，南京国子监为南监。
注：鸮：猫头鹰，古人视为不祥之鸟。
注：祭酒：国子监主官。
注：周洪谟：字尧弼，明英宗时人，官至礼部尚书，曾任南京国子祭酒。
注：监生：国子监的学生。
注：鸱鸮公：谐“鸱鸮”（猫头鹰）。
注：刘先生俊：刘俊，明国子祭酒，事迹待考。
注：蚯蚓子：以其好食蚯蚓而称之。
# 陈仪、窦俨
题解：陈仪酒后一语，成为“陈三更，窦半夜”的谚语。
原：梁颢在翰林时，胡旦知制诰院，赵昌言为枢密副使，陈仪、窦俨俱为三司盐铁副使。五人者旦夕饮会，茶觞壶矢，未尝虚日。每沉醉，夜分方归。金吾吏逐夜候马首声喏。仪醉，以鞭指其吏曰：“金吾不惜夜，玉漏莫相催。”于是谚曰：“陈三更，窦半夜。”
注：梁颢：北宋官员，端拱二年（989）状元，官至翰林学士。
注：胡旦：北宋官员，官知制诰。
注：知制诰：负责起草诏令的官员。
注：赵昌言：北宋官员，曾任枢密副使。
注：陈仪：北宋官员，三司盐铁副使。
注：窦俨：北宋官员，事迹待考。
注：三司：宋代掌财政的盐铁、度支、户部三司。
注：茶觞壶矢：以茶酒饮宴、投壶为乐。
注：金吾：执金吾，宋代为京师巡夜的卫士。
注：声喏：高声应诺。
注：金吾不惜夜，玉漏莫相催：化用苏味道《正月十五夜》“金吾不禁夜，玉漏莫相催”。
注：陈三更：“更”谐“庚”，对“窦半夜”，皆嘲其夜饮晚归。
# 汤一面
题解：汤胤𪟝因荐辞而得号“汤一面”，又因夸口被一箭射中而改号“汤一箭”。
原：汤胤𪟝博学英发，成化初，言者荐以将才，有“才兼文武，可当一面”之语。时号“汤一面”。及镇陕西孤山，有故人来谒，留饮。值报虏薄城下，汤语故人曰：“先生姑且酌，吾往，生擒胡雏来并睹。”方出城，有胡匿沟中，一箭中咽而死。人又号曰“汤一箭”。
注：汤胤𪟝：即汤胤勣，明成化间将领，曾镇守陕西；“𪟝”为底本异体。
注：成化：明宪宗年号（1465-1487）。
注：将才：将帅之才。
注：才兼文武，可当一面：谓能独当一方，故号“汤一面”。
注：孤山：明代陕西孤山堡，属榆林一带。
注：薄城下：逼近城下。
注：胡雏：对胡人的蔑称。
# 沈度、许鸣鹤
题解：永乐时翰林学士沈度善书、中书舍人许鸣鹤善文，各不相称，朝中以语相嘲。
原：永乐间，沈度以能书为学士，许鸣鹤以能文为中书。朝中语曰：“学士不能文，中书不能书。”
注：沈度：松江人，善书，永乐时官翰林学士。
注：许鸣鹤：永乐间中书舍人，事迹待考。
注：中书：中书舍人，掌缮写诏敕文书。
# 晋帝奕
题解：记晋废帝司马奕痿疾而以假子为嗣的传闻，民谣讥之。
原：晋帝奕夙有痿疾，使左右向龙与内侍接，生子以为己子。百姓歌之曰：“凤凰生一雏，天下莫不喜。本言是马驹，今定成龙子。”
注：晋帝奕：东晋海西公司马奕，后被桓温废。
注：痿疾：阳痿一类的疾病。
注：向龙：人名，事见《晋书》，史载其与内侍相私，生子。
注：内侍：宫中侍从。
注：本言是马驹：“马驹”暗指司马氏，“龙子”谐向龙之子，讥其非晋室血脉。
# 和事天子
题解：唐中宗命争执双方结为兄弟，被时人称“和事天子”，讥其无决断。
原：中宗朝，监察御史崔琬对弹宗楚客，楚客忿然作色。上命结为兄弟，以各解之。时人谓之“和事天子”。
注：中宗：唐中宗李显，在位期间朝政多由韦后、宗楚客等把持。
注：崔琬：中宗时监察御史，景龙年间弹劾宗楚客。
注：宗楚客：中宗时宰相，附韦后，后被杀。
注：监察御史：御史台官，掌监察百官。
注：和事天子：讥中宗“和稀泥”，不治其罪。
# 昭宗尊号
题解：昭宗屡遭祸难而自嘲，时人为其戏上“避贤招难存三奉五皇帝”的尊号。
原：唐昭宗尝曰：“朕东西所至，祸难随之。愿避贤者路。”人戏上尊号曰“避贤招难存三奉五皇帝”。
注：唐昭宗：李晔，唐末君主，受藩镇与宦官挟制，数度出奔。
注：东西所至：指昭宗被迫奔凤翔、华州等地。
注：避贤：让出贤者之路，语意双关。
注：尊号：臣下上给皇帝的美称。
注：存三奉五：疑指昭宗时李茂贞、朱温等“三”“五”之说；待考。
# 恶发殿
题解：钱镠殿名“握发”，因吴语“握”“恶”音近被戏称“恶发殿”。
原：钱武肃王镠所居殿，名“握发”。吴音“握”“恶”相乱。钱唐人遂谓曰：“此大王恶发殿也。”
注：钱武肃王镠：钱镠，吴越国创建者，谥武肃。
注：握发：取周公“一沐三握发”之意，表示礼贤。
注：吴音：吴地方音。
注：钱唐：今杭州。
注：恶发：谐“握发”，意为发怒、发狠。
# 麒麟楦
题解：杨炯以“麒麟楦”讥讽徒有其表的朝士，是著名的典故。
原：唐杨炯每呼朝士为麒麟楦。或问之。曰：“今假装麒麟，必修饰其形，覆之驴上。及去其皮，还是驴耳。”
注：杨炯：初唐四杰之一，性情刚直，好讥讪。
注：朝士：朝中官员。
注：麒麟楦：楦，填塞物；戏中用驴披麒麟皮装扮，去皮则为驴，事见《朝野佥载》。
# 两李益
题解：唐代有两个李益，一以文章，一以门第，故时人以“文章”“门户”区分。
原：李君虞以礼部尚书致仕。有宗人庶子同名，俱出于姑臧。时人谓尚书为“文章李益”，庶子为“门户李益”。
注：李君虞：李益，字君虞，中唐诗人，官至礼部尚书。
注：致仕：退休。
注：宗人：同宗之人。
注：庶子：官名，太子属官；此指另一李益。
注：姑臧：郡望，今甘肃武威，李氏著名郡望。
注：门户：指门第、家世。
# 三不开相公
题解：五代马胤孙为相时谨默自保，时号“三不开相公”。
原：五代废帝时，马胤孙为相，时号“三不开相公”：入朝印不开，见客口不开，归宅门不开。
注：废帝：后唐末帝李从珂，被称废帝。
注：马胤孙：后唐宰相，生平谨默。
注：三不开相公：言其印不开、口不开、门不开。
# 三旨相公
题解：王珪任相十六年而不作为，凡事唯承旨，被称“三旨宰相”。
原：王珪相神宗十六年，无所建明。时称“三旨宰相”：进呈云“取圣旨”，可否讫云“领圣旨”，退谕禀事者云“已得圣旨矣”。
注：王珪：北宋宰相，神宗朝任相。
注：神宗：宋神宗赵顼。
注：无所建明：没有什么建树。
注：三旨宰相：“取圣旨”“领圣旨”“已得圣旨”三旨，见《宋史》。
注：进呈：向皇帝呈进奏章。
# 三觉侍郎
题解：赵叔问身为侍郎而嗜睡，被称“三觉侍郎”。
原：赵叔问为天官侍郎，肥而喜睡，又厌宾客，在省还家，常挂歇息牌于门首。呼为“三觉侍郎”，谓“朝回、饭后、归弟”也。
注：赵叔问：宋人，官至吏部侍郎，事迹待考。
注：天官侍郎：吏部侍郎。
注：歇息牌：谢客的牌子。
注：三觉：三次睡眠。
注：朝回：退朝之后。
注：归弟：“弟”为“第”之误，指回家；待考。
# 《外史梼杌》二事
题解：引《外史梼杌》，记蜀官因谨默而得“睡相”“软饼中丞”的绰号。
原：徐光溥为相，喜论事，为李昊等所嫉。后不言，每聚议，但假寐而已，时号“睡相”。
注：徐光溥：后蜀宰相，事见《十国春秋》。
注：李昊：前蜀、后蜀名臣，曾草降表。
注：假寐：闭目打盹。
注：睡相：谐“宰相”，讥其以睡避事。
原：蜀韦嘏，唐相贻范之子。仕孟昶时，历御史中丞，性多依违，时号“软饼中丞”。
注：韦嘏：后蜀官，唐相韦贻范之子。
注：贻范：韦贻范，唐昭宗时宰相。
注：孟昶：后蜀后主。
注：御史中丞：御史台副长官。
注：依违：左右不定，不置可否。
注：软饼中丞：喻其软弱而无主张。
# 阁老饼
题解：丘濬自制的软饼因被传为美谈，称为“阁老饼”，亦见其为人吝啬。
原：丘文庄自制饼，软腻适口。托中官进上。食之，嘉，命司膳监效为之。不中式，俱被责，因请之丘。丘靳不以告。由是京师盛传为“阁老饼”。
注：丘文庄：丘濬，谥文庄，明中期大学士，著《大学衍义补》。
注：中官：宦官。
注：司膳监：当为“司礼监”或“光禄寺”之误，宫中管膳食机构；待考。
注：不中式：不合式样。
注：靳：吝惜。
注：阁老：对内阁大学士的敬称。
# 刘棉花
题解：内阁刘吉耐得住弹劾，被称“刘棉花”，讥其耐弹。
原：成化中，内阁刘吉丁外艰起复，百媚科道以免弹劾。弘治改元，侍读张升数其十罪，反为御史魏璋所劾，左迁。世以吉耐弹，目为“刘棉花”。
注：刘吉：明成化弘治间内阁首辅，善于逢迎。
注：丁外艰：遭遇父丧。
注：起复：丧期未满而被召复职。
注：百媚科道：对科道言官百般讨好。
注：科道：六科给事中与监察御史。
注：张升：成化时侍读，曾弹劾刘吉。
注：侍读：翰林院侍读。
注：魏璋：弘治时御史，附刘吉，反劾张升。
注：左迁：降职。
注：刘棉花：棉花耐弹，故以喻其不惧弹劾。
# 两字尚书
题解：施纯彦因为皇帝改口为“照例”二字而得升尚书，被称“两字尚书”。
原：成化间，上患舌涩，诸司御前奏事，准行者苦答“是”字。鸿胪卿施纯彦请易“照例”二字，上答甚便，寻擢尚书。时人嘲曰：“两字尚书”。
注：成化：明宪宗年号。
注：舌涩：说话不便。
注：鸿胪卿：鸿胪寺卿，掌朝会礼仪。
注：施纯彦：当为“施纯”，明宪宗朝鸿胪寺卿后升尚书；此处待考。
注：两字尚书：言其仅凭“照例”二字升官。
# 襄样节度
题解：于頔、郑元二位节度使暴虐，被比为襄阳漆器的标准，称“襄样节度”。
原：襄阳人善为漆器，天下取法，谓之“襄样”。及于司空为帅多暴，郑元镇河，亦暴。远近呼为“襄样节度”。见《国史补》。
注：襄阳：今湖北襄阳，唐代漆器著名。
注：襄样：襄阳样式，天下仿效。
注：于司空：于頔，曾任山南东道节度使，使相，官至司空，暴虐。
注：郑元镇河：郑元其人及镇守河东之事待考。
注：《国史补》：唐李肇《唐国史补》。
# 白兔御史
题解：王弘义因怨诬告园有白兔，被人称“白兔御史”。
原：王弘义始贱时，求傍舍瓜，不与。及为御史，乃腾文言园有白兔。县为集众捕逐，畦蓏无遗。内史李昭德曰：“昔闻苍鹰狱吏，今见白兔御史。”
注：王弘义：武则天时酷吏，凭诬告为御史。
注：贱：微贱，未显达。
注：傍舍：邻居。
注：腾文：传布文书。
注：白兔：祥瑞之物，借以敛财。
注：畦蓏：菜园瓜田。
注：李昭德：武周时宰相，正直。
注：苍鹰狱吏：指酷吏郅都，号“苍鹰”，见《史记·酷吏列传》。
# 驮官人
题解：记明代曹钦之变时王翱被主事背负逃生，后主事得升，号“驮官人”。
原：曹钦谋逆，已杀寇深，又索王尚书翱。王正在一室，窘迫。一主事长大多力，遽负之逸。王后擢此人要津。时呼为“驮官人”。
注：曹钦：明英宗天顺五年（1461）发动叛乱，被杀。
注：寇深：时任刑部尚书，被曹钦所杀。
注：王尚书翱：王翱，时任吏部尚书，事见《明史》。
注：主事：六部属官。
注：要津：重要职位。
注：驮官人：背官员之人。
# 杨仲嗣、魏伯起
题解：记两则以动物比喻浮躁轻薄之人的绰号。
原：《佥载》云：杨仲嗣躁率，魏光乘目为“热鏊上猢狲”。《北史》：魏伯起在京洛，轻薄尤甚，人号为“惊蛱蝶”。
注：《佥载》：当作《朝野佥载》，唐张鷟撰。
注：杨仲嗣：唐人，躁率。
注：魏光乘：唐人，好赠人绰号。
注：热鏊上猢狲：鏊为烙饼炊具，热鏊上的猴子，坐立不安。
注：《北史》：唐李延寿撰。
注：魏伯起：魏收，字伯起，北朝文人。
注：京洛：指洛阳。
注：惊蛱蝶：形容其轻薄不定。
# 李拾遗
题解：李弼出使被迫食粪，被人讥为“能食突厥之遗”，谐“拾遗”。
原：周左拾遗李弼奉使北蕃，匈奴以木盘盛粪饲之，临以白刃。弼惧，勉食，一盘并尽，乃放还。人诮之曰：“李拾遗能食突厥之遗。”
注：周：指武周。
注：左拾遗：谏官，从八品。
注：李弼：武周朝官员，生平待考。
注：北蕃：北方少数民族，即突厥。
注：白刃：出鞘的刀。
注：拾遗：官名，谐音“食遗”。
# 度宗榜
题解：度宗崩后新榜的三名举子，因名字被人编成谐谑的谣谚。
原：度宗崩，幼君谅阴。榜第一名王龙潭，二名路万里，三名胡幼黄。京师为之语曰：“龙在潭，飞不得；万里路，行不得；幼而黄，医不得。”
注：度宗：南宋赵禥，咸淳十年（1274）崩。
注：谅阴：居丧，此指新君居丧。
注：榜：科举榜。
注：王龙潭：状元，事迹待考。
注：路万里：榜眼，事迹待考。
注：胡幼黄：探花，事迹待考。
注：幼而黄：“黄口小儿”，谓幼稚，医不得。
# 城隍墙上画
题解：洪武年间以画讽谏之事，教坊司以“有官无法”解之，朱元璋因而宽法。
原：洪武间，有人画僧顶一冠，一道士顶十冠，蓬松其发；一断桥，甲士与各民左右立而待渡。揭于城隍墙上。朝廷见之，敕教坊司参究其事以奏。明日奏云：“僧顶冠，有官无法；道士十冠，官多法乱；军民立桥边，过不得。”自后法网稍宽，盖以滑稽而谏者。
注：洪武：明太祖年号。
注：城隍：城隍庙。
注：敕：诏令。
注：教坊司：明代掌乐舞俳优的官署。
注：参究：研究其事。
注：有官无法：“僧顶冠”谐“僧”谐“有发”，“官”与“法”双关；“有官无法”谓有官而无佛法，一说谐“有冠无发”。
注：滑稽：诙谐讽谏。
# 朱勔
题解：宋徽宗朝亲王戚属以金带关子鬻官，朱勔家奴满带金带，时人作谣讥之。
原：宣和间，亲王及戚畹入宫者，辄得金者、关子。得者，旋填姓名鬻之，即卒伍屠沽，自一命以上皆可得。朱勔家奴，服金带至有数十人。时云：“金腰带，银腰带，赵家世界朱家坏。”
注：宣和：宋徽宗年号。
注：戚畹：外戚。
注：金者、关子：官职凭证，一说“金带、关子”；“关子”宋代凭证，此处待考。
注：朱勔：徽宗朝佞臣，主持花石纲。
注：金腰带，银腰带：金带为高官之服。
注：赵家世界朱家坏：赵家天下被朱勔败坏。
# 师王
题解：韩侂胄擅权，群小称“师王”，钱象祖被史弥远合谋杀死，传谣即由此而来。
原：韩侂胄擅权日，一时献佞者皆称“师王”。参议钱象祖尝谏用兵，与有隙，史弥远因与合谋。既罢相，遂私批杀之。宁宗不知也。都下语曰：“释迦佛中间坐，胡汉神立两傍。文殊、普贤自斗，象祖打杀师王。”
注：韩侂胄：南宋宁宗时权臣，发动开禧北伐。
注：师王：称韩侂胄为“师”“王”，皆僭越。
注：钱象祖：南宋官员，曾谏阻北伐。
注：史弥远：宁宗、理宗朝权相，与杨皇后合谋诛韩侂胄。
注：私批：未经皇帝而私批诏书。
注：宁宗：南宋宁宗赵扩。
注：释迦佛：喻皇帝。
注：胡汉神：待考，似指胡、汉门神。
注：文殊、普贤：佛教二菩萨，喻朝臣。
注：象祖：钱象祖。
# 十七字谣
题解：三则南宋至元初的十七字诗谣，分别讥史嵩之起复、太学诸生迎驾、伪齐用人之败。
原：淳祐间，史嵩之入相。以二亲年耄，虑有不测，预为起复之计。时马光祖未卒哭，起为淮东总领；许堪未终丧制，起为镇江守臣。里巷为十七字谣曰：“光祖做总领，许堪为节制。丞相要起复，援例。”
注：淳祐：宋理宗年号（1241-1252）。
注：史嵩之：理宗朝宰相，父丧而起复，为太学生所攻。
注：耄：老年。
注：起复：官员遭父母丧而夺情复职。
注：马光祖：南宋官员，字华父，官至沪帅。
注：未卒哭：居丧未满百日。
注：总领：总领所官，管军饷。
注：节制：节度，掌兵权。
注：援例：援引先例。
原：淳祐间，车驾幸景灵宫，太学、武学、宗学诸生俱在礼部前迎驾。有作十七字诗曰：“驾幸景灵宫，诸生尽鞠躬。头乌身上白，米虫。”盖讥其岁糜廪禄，不得出身，年年唯迎驾耳。
注：车驾：皇帝。
注：景灵宫：宋代供奉祖先神御之所。
注：太学、武学、宗学：宋代三所官学。
注：头乌身上白：“头乌”指乌帽，“身上白”指白襕衫。
注：米虫：讥诸生白食廪禄。
注：廪禄：官府给的粮食。
原：伪周用王敬夫、蔡彦文、叶德新三人谋国事，而抵于亡。丁未春，伏诛于南京，风干蔡、叶之尸于称竿者一月。先是民间作十七字诗云：“丞相做事业，专用黄、祭、叶。一夜西风来，干鳖。”后竟验焉。
注：伪周：指伪齐刘豫之类，具体待考。
注：王敬夫、蔡彦文、叶德新：三人名待考。
注：丁未：纪年。
注：称竿：悬挂的杆子。
注：黄、祭、叶：谐“王、蔡、叶”。
注：干鳖：谐“干蔡叶”；谓风干。
# 王婆醋钵
题解：记元末张士诚据平江，华亭县令俞俊酷剥百姓，袁海叟诗以王婆醋钵喻其覆亡。
原：张士诚据有平江日，松江俞俊以贿通伪尹郑焕，署宰华亭。用酷刑朘剥，邑民恨入骨髓。袁海臾有诗曰：“四海清宁未有期，诸公衮衮正当时。忽然一日天兵至，打破王婆醋钵儿。”或者不知醋钵之义，以问臾。臾曰：“昔有不轨伏诛，暴尸于竿。王婆买醋，经过其下。适索朽尸坠，醋钵为其所压，著地而碎。王婆年老无知，将所谓死者所致，顾谓之曰：‘汝只是未曾吃恶官司来！’”闻者皆绝倒。
注：张士诚：元末群雄，据平江，自称吴王。
注：平江：今苏州。
注：俞俊：张士诚部下，署华亭县令，事迹待考。
注：郑焕：伪尹，待考。
注：宰华亭：任华亭知县。
注：袁海臾：袁凯，号海叟，华亭人，元末明初诗人。
注：天兵：指明军。
注：醋钵：盛醋的器皿。
注：不轨：谋反。
注：索：绳索。
注：绝倒：笑倒。
# 落指君子
题解：记晋江刘震臣令常熟时用刑过酷，百姓呼其“落指君子”。
原：晋江刘明府震臣，先年令常熟，极有吏才，但法尚严峻。尝枉征财课，百姓庾狱中、毙杖下者，十而九矣。又拷掠之惨，至于手足指堕。于是虞人歌之曰：“落指君子，民之父母。”
注：明府：对县令的尊称。
注：刘明府震臣：晋江人刘震臣，曾任常熟知县，余事待考。
注：吏才：处理政务的才干。
注：庾狱：关押死于狱中。
注：虞人：常熟古称，“虞”地之人。
注：落指君子，民之父母：讥《诗》“岂弟君子，民之父母”之辞。
# 桑渐
题解：桑渐不认可对县长“明如镜、平如秤”的夸赞，讥其为胥吏所蒙蔽。
原：桑渐为孟州佥判。或誉县长“明似镜，平似秤”。渐不然其言，抑之曰：“却被押司走上厅，打破镜，踏折秤。”
注：桑渐：宋人，事迹待考。
注：孟州：今河南孟州。
注：佥判：签书判官厅公事，州官属员。
注：明似镜，平似秤：夸官清明公平。
注：押司：宋代州县衙门中掌文案的胥吏。
# 常州守谣
题解：记常州两任太守受贿与廉而不严，各留下一句讽谚。
原：《马氏日抄》云：常州守莫愚巧于取贿，而纠察郡吏，使无所得。郡人为之语曰：“太守摸鱼，六房晒网。”继莫者叶蓁，有廉操，而律下不严，吏曹得行其诈。又为语曰：“外郎作鲜，太守拽罾。”言劳而无获也。
注：《马氏日抄》：明马愈撰笔记。
注：莫愚：常州知府，待考。
注：六房：吏、户、礼、兵、刑、工六房，指衙中胥吏。
注：摸鱼：喻取贿。
注：晒网：言吏无所获。
注：叶蓁：继任知府，待考。
注：外郎：胥吏的俗称。
注：作鲜：作鱼脍，指吏自行取利。
注：罾：渔网。
# 刘宠庙
题解：绍兴钱清镇的刘宠庙，王叔能以诗讽刺后世官吏假效“一钱太守”而实贪。
原：一钱太守刘宠庙，在绍兴钱清镇。王叔能过庙下，赋诗曰：“刘宠清名举世传，至今遗庙在江边。近来仕路多能者，也学先生拣大钱。”

注：张少傅：张孚敬，嘉靖初大礼议功臣，官太子少傅，后致仕。
注：致仕：退休。
注：彗孛：彗星与孛星。
# 赵鹤、江潮
题解：赵鹤督学东省严苛而罢，继任江潮亦严，诸生题壁讥之。
原：赵鹤督学东省过严，竟以此罢官。江潮代之，亦风裁凛然。诸生题壁云：“赵鹤方剪羽翼，江潮又起风波。”
注：赵鹤：明嘉靖间山东提学副使，以严著称，后被罢。
注：东省：山东。
注：江潮：继任山东提学，待考。
注：风裁：风采裁断，即威严。
注：剪羽翼：赵鹤之“鹤”因羽翼被剪，喻罢官。
# 真希元
题解：真德秀应召入朝，百姓对其期望高，以谚相嘲其不切实际。
原：端平间，真希元应召而起。百姓仰之，若元祐之仰涑水也。时楮轻物贵，市井喁喁为之语曰：“若要百物贱，直待真直院。”及入朝，进对，首以“正心诚意”为言。愚民无知，以为不切时务，遂续前语曰：“吃了西湖水，打作一锅面。”继参大政，未及有所建置而薨。
注：端平：宋理宗年号（1234—1236）。
注：真希元：真德秀，字景元，一字希元，南宋理学家。
注：元祐：宋哲宗年号，元祐更化时司马光主政。
注：涑水：司马光，涑水先生。
注：楮：楮币，即纸币，宋代会子。
注：喁喁：众人仰慕之貌。
注：真直院：真德秀曾任直学士院。
注：正心诚意：《大学》修身之道，真德秀著《大学衍义》。
注：西湖水：杭州西湖，“吃了西湖水”谐“真直院”不济事。
注：参大政：参知政事。
注：薨：诸侯或大臣之死。
# 王文成二高弟
题解：王阳明高弟陆澄、徐珊的遭际，反映大礼议中的进退，时人对学道者发出讽语。
原：陆澄，字原静，王文成公之高弟也。始张桂议大礼，澄以刑部主事上疏攻之，旋以忧去。服阕至京，复上疏，称张桂为正论，而悔前之失言。上理其前疏，谪广东高州通判。又徐珊，亦文成高弟也。癸未会试，以策问低文成学，拂衣而出，天下高之。后选得辰州贰府，坐侵军饷事缢死。时人为之语曰：“君子学道则害人，小人学道则缢死也。”
注：陆澄：字原静，王阳明弟子。
注：王文成公：王阳明，谥文成。
注：张桂：张璁、桂萼，嘉靖大礼议的支持者。
注：议大礼：嘉靖初关于世宗尊崇本生父的大礼议。
注：刑部主事：刑部属官。
注：忧去：居丧离职。
注：服阕：服丧期满。
注：广东高州通判：通判为州府佐官，高州在广东。
注：徐珊：王阳明弟子。
注：癸未：嘉靖二年（1523）。
注：策问：会试考题之一。
注：低文成学：贬低王阳明学说。
注：拂衣：甩袖，表示不屑。
注：辰州贰府：辰州府同知或通判，辰州今湖南沅陵一带。
注：缢死：自缢而死。
# 金鼓诗
题解：元末廉访使赃污，迎官与解贼所用鼓声相近，时人作诗嘲其官贼不争多。
原：至正间，风纪之司，赃污狼籍。是时金鼓音节迎送廉访使，例用二声鼓、一声锣。起解强盗，则用一声鼓、一声锣。有轻薄子为诗嘲曰：“解贼一金并一鼓，迎官两鼓一声锣。金鼓看来都一样，官人与贼不争多。”
注：至正：元顺帝年号。
注：风纪之司：监察官署，即肃政廉访司。
注：廉访使：提刑按察使在元代改称廉访使。
注：起解：押解。
注：强盗：盗贼。
# 痴床
题解：宋代侍御史号“杂端”，台中聚会设“痴床”，言其傲慢。
原：宋时，侍御史号杂端，最为雄剧。台中会聚，则于座南设横榻，号南床，又曰痴床。言登此床者，踞傲如痴。
注：侍御史：御史台官员。
注：杂端：侍御史知杂事者的别称。
注：雄剧：要职，权重位尊。
注：南床：御史台会聚时的座位。
注：踞傲：傲慢蹲坐。
# 南吏部
题解：明代吏部权在北京，南京吏部只在考察之年显威，都下谣语讥之。
原：国朝吏部之权俱在北曹，南曹殊落莫。唯考察年，南京官五品以下，黜调皆在其手，声势赫奕。过此，则又如常矣。都下谣曰：“今日南京真吏部，明朝吏部又南京。”
注：国朝：本朝，指明朝。
注：北曹：北京吏部。
注：南曹：南京吏部。
注：考察年：明代京官每六年一考察，称京察。
注：黜调：罢黜或调任。
注：赫奕：显赫。
# 名帖大字
题解：讥宦途竞相把名字写大，戏谓只恐费墨。
原：近来宦途好胜，书名竞作大字。有人嘲云：“诸葛大名垂宇庙，今人名大欲如何？虽于事体无妨碍，只恐文房费墨多。”
注：书名竞作大字：写名帖时竞用大字显示声势。
注：诸葛大名垂宇庙：化用杜甫《咏怀古迹》“诸葛大名垂宇宙”，“宇庙”疑当作“宇宙”。
注：事体：事情。
注：文房：笔墨纸砚。
# 海公
题解：海瑞巡抚南直隶抑豪强，有人投匿名状，借伯夷叔齐旧事讥讽，海瑞读后稍作收敛。
原：海公巡抚南国，意主搏击豪强，因而刁风四起。有投匿名状者，曰：“告状人柳跖，告为势吞血产事：极恶伯夷、叔齐兄弟二人，倚父孤竹君历代声势，发掘许由坟冢。被伊族告发，恶又贿求嬖臣鲁仲连得免。今某月日，挽出恶兄柳下惠，捉某箍禁孤竹水牢，日夜痛加炮烙极刑，逼献首阳薇田三百馀亩。有契无文，崇侯虎见证。窃思武王至尊，尚被叩马羞辱，何况区区蝼蚁！激切上告。”海公见状，颇悔前事，讼党少解。
注：海公：海瑞，嘉靖、万历间名臣，曾巡抚应天。
注：搏击：打击。
注：刁风：刁讼之风。
注：匿名状：不署名的诉状。
注：柳跖：即盗跖，传说柳下惠之弟，反面人物。
注：血产：血汗所得的产业。
注：孤竹君：商代孤竹国君，伯夷、叔齐之父。
注：许由：传说尧让天下而不受的隐士。
注：发掘许由坟冢：典出传说，此处反用，虚构控词。
注：嬖臣：受宠的小臣。
注：鲁仲连：战国齐人，义不帝秦。
注：柳下惠：春秋鲁国大夫，坐怀不乱。
注：炮烙：商纣所用酷刑。
注：首阳：首阳山，伯夷叔齐饿死之地。
注：薇：野菜，伯夷叔齐采薇而食。
注：有契无文：有契约而无文字凭据。
注：崇侯虎：商纣之臣，曾向纣进谗言。
注：叩马：伯夷、叔齐叩马谏武王伐纣。

# 荒年谣
题解：荒年物价高涨，杭人以拆字诗言饮水、杀我，谑中含悲。
原：荒年百物腾涌，颇艰饮啖。杭人戏作诗曰：“丰年人不觉，家家喜饮酒。荒年要酒吃，除却酒边酉。”言饮水也。又曰：“丰年人不觉，鹅肉满案绕。荒年要鹅吃，除却鹅边鸟。”言杀我也。谑亦有意。
注：腾涌：物价飞涨。
注：饮啖：饮食。
注：酒边酉：“酒”字除去“氵”边，剩“酉”，意即“酉”，喻无酒饮水；此处言水。
注：鹅边鸟：“鹅”去“鳥”剩“我”，言杀我。
注：谑：戏谑。
# 郑世尊
题解：司马安仁以“郑世尊”称败家子，兼用唐传奇《李娃传》郑生行乞与佛陀乞食两义。
原：或谓不肖子倾产破业，所病不瘳，其终奈何。司马安仁曰：“为郑世尊而已。”盖郑子以李娃故，行乞于市，几为馁鬼。佛世尊欲与一切众生结胜因缘，遂于舍卫次第乞食。合二义以名之。
注：不肖子：不成材的子弟。
注：所病不瘳：病情不愈。
注：司马安仁：待考。
注：郑子以李娃故：唐白行简《李娃传》，荥阳郑生与李娃事，郑生落魄，唱挽歌乞食。
注：馁鬼：饿鬼。
注：世尊：佛的尊号。
注：舍卫：古印度舍卫国，佛陀曾在此说法乞食。
注：胜因：善因。
# 龟兹王
题解：西域龟兹王娶乌孙公主之女，仿汉制，外人讥为“骡”。
原：乌孙公主遣女至汉学鼓琴，还过龟兹。龟兹王绛宾留以为夫人，上书言得尚汉外孙，愿与公主女俱入朝。自是数来朝贺。乐汉衣服制度，归其国，治宫室，作徼道周卫，出入传呼，撞锺鼓，如汉家仪。外国胡人皆曰：“驴非驴，马非马，若龟兹王，所谓骡也。”
注：乌孙公主：汉乌孙公主解忧之女。
注：龟兹：西域国名，在今新疆库车。
注：绛宾：龟兹王之名。
注：尚：娶帝王之女称尚。
注：徼道周卫：巡逻道路、周匝戒卫。
注：传呼：出入时传声呼喝。
注：骡：驴马杂交，非驴非马。
