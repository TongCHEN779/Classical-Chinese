# 正文
题解：《文戏》部总序：冯梦龙论以文为戏之才，并举孔子、邓艾、朱熹之戏为例，开启本部，所收为诗文游戏。
原：〔子犹曰：“迂士主文而讳戏，俗士逐戏而离文。其能以文为戏者，必才士也。尼父之戏也以俎豆，邓艾之戏也以战阵，晦翁之戏也以八卦，何独文人而不然？且夫视文如戏，则文之兴益豪；而虽戏必文，则戏之途亦窄，或亦砭迂针俗之一助云尔。集《文戏》第二十七。〕
注：子犹曰：子犹，冯梦龙之号。
注：迂士：迂腐的读书人。
注：尼父之戏也以俎豆：孔子幼时陈俎豆（祭器）为戏，见《史记·孔子世家》。尼父，对孔子的尊称。
注：邓艾之戏也以战阵：三国魏邓艾少时见高山大泽，辄规度指画军营处所，见《晋书·邓艾传》，此条出处待考。
注：晦翁之戏也以八卦：朱熹（号晦庵）少时在沙上画八卦，见《朱子语类》。
注：砭迂针俗：砭、针都是治病之物，喻讽刺迂腐与俗气。
注：集《文戏》第二十七：本部为全书第二十七部。
# 成语诗
题解：成语诗：林观过七岁，市中以卖诗自命，被戏令咏“泄气”，用《老子》《孟子》成语作诗。
原：林观过年七岁，嬉游市中，以鬻诗自命。或戏令咏泄气，云：“视之不见名曰希，听之不闻名曰夷。不啻若是其口出，人皆掩鼻而过之。”
注：林观过：宋代神童，福建人，七岁能诗，待考。
注：鬻诗：卖诗。
注：泄气：放屁。
注：视之不见名曰希，听之不闻名曰夷：《老子》第十四章“视之不见名曰夷，听之不闻名曰希”，此处互调。
注：不啻若是其口出：《尚书·秦誓》“不啻若自其口出”，此处改“自”为“是”，谐谑。
注：掩鼻而过：《孟子·离娄下》“虽有恶人，斋戒沐浴，则可以祀上帝”，此处借指掩鼻而过之，出处为《孟子》。
# 改《观音经》语
题解：改《观音经》语：东坡嫌《观音经》“还著于本人”不慈悲，改作“两家都没事”。
原：《观音经》云：“咒咀诸毒药，所欲害身者，念彼观音力，还著于本人。”东坡居士曰：“观音慈悲，若说还著本人，岂其心哉？”乃改云：“念彼观音力，两家都没事。”
注：《观音经》：《妙法莲华经·观世音菩萨普门品》的别称，即《观音经》。
注：咒咀：诅咒。
注：所欲害身者：想要害人身体的。
注：还著于本人：害人的咒语反而作用于施咒者本人。
注：东坡居士：苏轼号。
# 改苏诗
题解：改苏诗：苏轼诗“无事此静坐，一日似两日”被任达者改为“游戏”“三日”“二百一”，冯梦龙又改作“多事劳扰”。
原：苏诗：“无事此静坐，一日似两日。若活七十年，便是百四十。”近有任达者更之曰：“无事此游戏，一日似三日。若活七十年，便是二百一。”
注：苏诗：苏轼《司马君实独乐园》外的《书轩》一类诗，此处引诗见《东坡志林》，出处待考。
注：任达：任性放达。
注：百四十：七十年每日如两日，即一百四十年。
注：二百一：七十年每日如三日，即二百一十年，此为约数。
原：子犹尝反其诗云：“多事此劳扰，一日如一刻，便活九十九，凑不上一日。”
注：子犹：冯梦龙。
注：凑不上一日：言事多则一天还不到一刻。
# 旧律易字
题解：旧律易字：广东二贡士争名相殴，友人化用旧诗改字，嘲其争斗之状。
原：广东二贡士争名，至相殴。友人用旧诗更易诮之曰：“南北斋生多发颠，春来争榜各纷然。网巾扯作黑蝴蝶，头发染成红杜鹃。日落二人眠阁上，夜归朋友笑灯前。人生有打须当打，一棒何曾到九泉。”
注：贡士：被推荐入京参加会试的人。
注：网巾：明代男子束发的网状头巾。
注：南北斋生：南北斋舍的学生。
注：多发颠：疑当作“多发癫”。
注：人生有打须当打：旧诗“人生有酒须当醉”之谐改。
注：九泉：地下，黄泉。
# 旧绝句易字
题解：旧绝句易字：元稹诗末句被改，谢师厚改“凤凰栖”为“老鸦栖”嘲营妓与吏；王锡爵以诗戏张居正政敌，旧诗句被改为“蜜翁翁”“土空”。
原：元微之贬江陵，过襄阳，夜召名妓剧饮。将别，作诗云：“花枝临水复临堤，也照清江也照泥。寄语东风好抬举，夜来曾有凤凰栖。”宋谢师厚作襄倅，闻营妓与二胥相好，此妓乞书扇，遂用元诗改末句云：“夜来曾有老鸦栖。”
注：元微之：元稹，字微之，中唐诗人，曾贬江州司马、江陵士曹参军。
注：江陵：今湖北荆州。
注：襄阳：今湖北襄阳。
注：抬举：提拔、恩惠，此处谐谑。
注：谢师厚：谢景初，字师厚，北宋官员，曾通判襄州。
注：襄倅：襄阳通判。
注：营妓：军营中的官妓。
注：二胥：两个小吏，“胥”即小吏。
注：老鸦栖：把“凤凰”改成“老鸦”，贬低其狎客。
原：南昌张相公、兰溪赵相公，皆与张江陵相左。由翰林谪州同后屡迁，俱于辛卯入内阁。太仓王元驭当国，以诗戏之曰：“龙楼凤阁城九重，新筑沙堤拜相公。我贵我荣君莫羡，十年前是两州同。”
注：南昌张相公：张位，字明成，南昌人，万历朝大学士。
注：兰溪赵相公：赵志皋，兰溪人，万历朝首辅。
注：张江陵：张居正，湖广江陵人，万历首辅。
注：相左：不合，对立。
注：州同：州同知，州官副职。
注：辛卯：万历十九年（1591）。
注：太仓王元驭：王锡爵，字元驭，太仓人，万历朝首辅。
注：沙堤：唐宋宰相上任时用沙铺的路，“沙堤拜相”指拜相。
原：《西堂纪闻》云：“昨夜阴山贼吼风，帐中惊起黑髯翁，平明不待全师出，连把金鞭打铁骢。”此诗不知谁作，颇为边人传诵。有张师雄者，居洛中，好以甘言媚人，洛人呼为“蜜翁翁”。会官塞上，一夕传虏犯边，师雄仓惶震恐，衣皮裘两重伏土窟中。秦人呼土窟为土空。有人改前诗以嘲之曰：“昨夜阴山贼吼风，帐中惊起蜜翁翁。平明不待全师出，连著皮裘入土空。”
注：《西堂纪闻》：笔记，待考。
注：阴山贼吼风：形容北风呼啸。
注：张师雄：北宋官员，待考。
注：蜜翁翁：“蜜”形容甘言，“翁”为绰号。
注：皮裘：兽皮衣。
注：土空：“土窟”之音讹，“窟”“空”音近，秦地方言。
# 用旧诗句
题解：用旧诗句：杭州一寡妇改嫁被讼，金编修在审问时借“月移花影上阑干”诗句，使官员轻判。
原：杭有一妇，夫死，未终七即嫁，被讼于官，凂金编修为居间。临审时，金佯问问官云：“此辈何事？”官曰：“丈夫身死未终七，嫁与对门王卖笔。”金曰：“月移花影上阑干，春色恼人眠不得。”官笑而从末减。
注：未终七：未满七七四十九日的丧期。
注：凂：请托。
注：金编修：金某，翰林院编修，待考。
注：居间：从中调停。
注：问官：审问官。
注：月移花影上阑干，春色恼人眠不得：王安石《夜直》诗句，“春色恼人眠不得，月移花影上栏杆”，借以暗示寡妇难耐孤寂。
注：末减：从轻处罚。
# 改用旧诗句
题解：改用旧诗句：方于鲁盛夏着兰州绒衣，被作诗嘲讽；太仓富人宴客，王世贞以“世上万般愁苦事”改诗应对。
原：方于鲁，徽人，用造墨起家，多荐绅交。有长安贵人寄兰州绒于方，时夏四月矣，方急制为衣服之，以夸示宾客。或作诗嘲之曰：“爱杀兰州䩐鞑绒，寄来春后趱裁缝。寒回死等桃花雪，暖透生憎柳絮风。忽地出神挦细脚，有时得意挺高胸。寻常一样方于鲁，才著绒衣便不同。”或云此诗汪南溟作也。
注：方于鲁：明代制墨名家，徽州歙县人，著《方氏墨谱》。
注：荐绅：缙绅，有官职的人。
注：兰州绒：兰州产的毛织物。
注：䩐鞑绒：一种毛织物，待考。
注：趱：赶、催。
注：桃花雪：桃花开时的春寒。
注：柳絮风：柳絮飞舞时的暖风。
注：挦：拔、扯。
注：汪南溟：汪道昆，号南溟，明代戏曲家、文学家，“后五子”之一。
原：太仓一富人宴客，王元美与焉。馔有臭鳖及生梨子。元美曰：“世上万般愁苦事，无过死鳖与生梨。”坐客大噱。
注：太仓：今江苏太仓。
注：王元美：王世贞。
注：臭鳖：腐臭之鳖。
注：生梨子：“生梨”谐“生离”，“死鳖”谐“死别”，改自“世上万般愁苦事，无过死别与生离”。
注：大噱：大笑。
# 缩字诗
题解：缩字诗：石曼卿登第后被讼，覆试落榜，授三班借职，作诗自嘲，诗中缩字，谐“借”“参”“进”“南”。
原：石曼卿登第，有人讼科场，覆考落者数人，曼卿在焉。方与同年期集，使至，追所赐敕牒。馀人皆泣而起，独曼卿笑语终席。次日，放黜者受三班借职。曼卿作诗曰：“无才且作三班借，请俸争如录事参。从此免称乡贡进，且须走马东西南。”
注：石曼卿：石延年。
注：科场：科举考场。
注：期集：宋代进士及第后，同年聚会，称“期集”。
注：敕牒：朝廷授予功名的文书。
注：三班借职：宋代武官最低阶，三班院所属。
注：录事参：录事参军，州府属官，主管文案。
注：乡贡进：“乡贡进士”之省，称“缩字”，指省去末字。
注：走马东西南：省“北”字，暗指流放远方。
# 歇后诗
题解：歇后诗：以吴语、《百家姓》《四书》等隐去末字作歇后诗，嘲时少湾吝啬、监生肚中无物、云间求忠书院考试。
原：有时少湾者，延师颇不尽礼，致其师争竞而散。或用吴语赋歇后诗嘲之曰：“少湾主人吉日良〈时〉，束修且是爷多娘〈少〉。身材好像夜叉小〈鬼〉，心地犹如短剑长〈枪〉。三杯晚酌金生丽〈水〉，两碗晨餐周发商〈汤〉。年终算帐索筵席〈百家姓有“索咸席赖”句〉，劈拍之声一顿相〈打〉。”
注：时少湾：待考，延师而不尽礼者。
注：延师：聘请塾师。
注：争竞：争吵。
注：束修：学生送老师的酬金，十条干肉。
注：金生丽：《千字文》“金生丽水，玉出昆冈”，歇后“水”。
注：周发商：《千字文》“周发殷汤”，歇后“汤”。
注：索筵席：《千字文》“肆筵设席”，此处似《百家姓》“索咸籍”，待考。
原：相传嘲监生诗云：“革车买得截然高〈大帽〉，周子窗前〈草〉 满腹包。有朝一日高曾祖〈考〉，焕乎其有〈文章〉没分毫。”
注：监生：国子监学生，可捐纳。
注：革车：兵车，《孟子》“革车三百乘”。
注：截然高：《孟子》，“截然”之意，此处歇后“大帽”。
注：周子窗前：周敦颐窗前草不除，歇后“草”，“满腹草包”。
注：焕乎其有：《论语·泰伯》，歇后“文章”。
原：云间求忠书院，为方正学建也。一日院观风，有儒童告考，张郡侯命学博往书院试之，缄二题，一曰“人力所通”，一曰“鼻之于臭也”。时人为之语曰：“贡院求忠书，监场方考孺。不见人力所，但闻鼻之于。”
注：云间：今上海松江。
注：方正学：方孝孺，号正学，明初大儒，被朱棣灭族，建文旧臣。
注：观风：地方官巡行考察风俗和士子，称观风。
注：张郡侯：张某，知府，待考。
注：学博：学官。
注：人力所通：《中庸》“人力所通，舟车所至”，歇后“舟车所至”，“舟”“车”谐“周”“车”。
注：鼻之于臭也：《孟子·尽心下》，歇后“鼻之于臭也，四肢之于安佚也”，此处言“鼻之于”。
# 《千文》歇后诗
题解：《千文》歇后诗：封抱一以《千字文》语嘲面黄身短者；袁凯以《千字文》语嘲陈东璧教子无方。
原：《启颜录》：唐封抱一任栎阳尉，有客过之，面黄身短，又患眼及鼻塞。抱一用《千字文》语嘲之曰：“面作天地玄，鼻有雁门紫。既无左达承，何劳罔谈彼？”
注：《启颜录》：隋侯白撰，唐代亦有续作，笑话集。
注：封抱一：唐代官员，待考。
注：栎阳尉：栎阳县尉，栎阳在今陕西西安临潼区。
注：面黄身短：面色黄、身材短。
注：天地玄：《千字文》“天地玄黄”，以“黄”为歇后，指面黄。
注：雁门紫：《千字文》“雁门紫塞”，歇后“塞”，指鼻塞。
注：左达承：《千字文》“左达承明”，歇后“明”，指眼不明。
注：罔谈彼：《千字文》“罔谈彼短，靡恃己长”，歇后“短”。
原：袁景文凯初甚贫，尝馆授一富家。景文性疏放，师道颇不立，未几辞归。其家别延陈文东璧。陈惩前事，待子弟甚严，然无他长，但善书耳。一日景文来访，文东适出，因大书其案云：“去年先生靡恃己，今年先生罔谈彼。若无几个始制文，如何教得犹子比。”
注：袁景文凯：袁凯，字景文，号海叟，元末明初诗人，官御史，因装疯被释。
注：馆授：在富家设馆教书。
注：疏放：放任不羁。
注：师道颇不立：不顾师严之道。
注：陈文东璧：陈某，字东璧，待考。
注：靡恃己：《千字文》“靡恃己长”，歇后“长”，指自己无长处。
注：始制文：《千字文》“始制文字”。
注：犹子比：《千字文》“孔怀兄弟，同气连枝……犹子比儿”，指教不好孩子。
# 诸理斋诗
题解：诸理斋诗：夏五延师不称，其妻责增口；诸理斋以“夏五”“增口便成吾”作谑，又以《千字文》歇后诗嘲夏五矮、其妻长。
原：凤林夏五，名景倩，延师周四维训子。以不称，欲再延。妻曰：“何为又增人口？”夫不从，又延罗成吾。时诸理斋亦馆于夏，戏曰：“夏五本是五，增口便成吾。四维尚未去，如何又请罗？”又夏五甚短，妻极长，每同立，仅齐妻乳。理斋作歇后语谑曰：“夏五官人罔谈彼，夏五娘子靡恃己。有时堂前相遇见，刚刚撞著果珍李。”
注：凤林：地名，待考。
注：夏五：名景倩，姓夏排行五，《春秋》“夏五”缺“月”字，借以讽其“缺”。
注：周四维：塾师名；罗成吾，同，待考。
注：诸理斋：诸某，号理斋，待考。
注：夏五本是五，增口便成吾：“五”加“口”为“吾”，借“罗成吾”之名。
注：果珍李：《千字文》“果珍李柰，菜重芥姜”，歇后“柰”，与“奶”谐。
# 广文嘲语
题解：广文嘲语：士风日薄，学官被送瘟猪肉、五分铜银，作“尧舜”嘲语，借《孟子》“尧舜其犹病诸”“尧舜与人同”。
原：广文先生之贫，自古记之。近日士风日趋于薄。有某学先生者，人馈之肉，乃瘟猪也。先生嘲之曰：“秀才送礼，言之可羞。瘦肉一方，尧舜其犹。”又有以铜银为贽者，又嘲之曰：“薄俗送礼，不过五分，启封视之，尧舜与人。”或作破云：“时官之责门人也，言必称尧舜焉。”
注：广文先生：对教官的雅称，唐代设广文馆博士，杜甫诗“广文先生官独冷”。
注：瘟猪：病死的猪。
注：瘦肉一方，尧舜其犹：《论语·雍也》“尧舜其犹病诸”，借“犹”谐“肉”，“病”指瘟猪。
注：贽：见面礼。
注：尧舜与人：《孟子·公孙丑上》“取诸人以为善，是与人为善者也”，此谓“尧舜与人”谐“要人与”，指少礼。
注：破：破题。
# 缩脚诗
题解：缩脚诗：赋阙唇者之诗，用《四书》句缩脚（略去末字），皆隐“阙”字；沈宁庵赋老翁似土地神，顾达诗嘲不学而狂者。
原：旧有赋阙唇者云：“多闻疑，多见殆，吾犹及史之，君子于其所不知。”盖四语皆出《四书》，皆隐“阙”字，而末句尤奇。吴江一老翁，貌似土地，沈宁庵吏部亦用此体赋云：“入疆辟，入疆芜，诸侯之宝三，狄人之所欲者吾。”又吴中有顾秀才名达者，不学而狂。同学者嘲之云：“在邦必，在家必，小人下，不成章不。”并堪伯仲。
注：赋阙唇者云：缩脚诗，隐去句末字的游戏诗体，歇后。
注：阙唇：兔唇。
注：多闻疑，多见殆：《论语·为政》“多闻阙疑，多见阙殆”，隐去“阙”字。
注：吾犹及史之：《论语·卫灵公》“吾犹及史之阙文也”。
注：君子于其所不知：《论语·子路》“君子于其所不知，盖阙如也”。
注：吴江：今江苏苏州吴江区。
注：土地：土地神，面相老者。
注：沈宁庵：沈位，号宁庵，明代官员，待考。
注：入疆辟，入疆芜：《孟子·告子下》，隐去“土地”二字，谐“土地”，借老翁貌似土地。
注：诸侯之宝三：《孟子·尽心下》“诸侯之宝三：土地、人民、政事”，隐“土地”。
注：狄人之所欲者：《孟子·梁惠王下》“狄人之所欲者，吾土地也”，隐“土地”。
注：在邦必，在家必：《论语·颜渊》“在邦必闻，在家必闻”，隐“闻”，嘲其无闻。
注：小人下，不成章不：《论语·宪问》“小人下达”，缺“达”；《孟子》“不成章不达”，缺“达”，“顾达”之名。
注：伯仲：兄弟排行，喻不相上下。
# 贯酸斋解大绅
题解：贯酸斋解大绅：贯云石以“泉泉泉”应诗，被问是否贯酸斋，答“然然然”；解缙题道士小像“贼贼贼”，借以谑称偷仙丹。
原：钱塘有数衣冠士人游虎跑泉，饮间赋诗，以“泉”字为韵。中一人但哦“泉、泉、泉”，久不能就。忽一叟曳杖而至，问其故，应声曰：“泉、泉、泉，乱迸珍珠个个圆。玉斧砍开顽石髓，金钩搭出老龙涎。”众惊问曰：“公非贯酸斋乎？”曰：“然、然、然。”遂邀同饮，尽醉而去。
注：虎跑泉：杭州西湖名泉，在虎跑寺内。
注：哦：吟哦。
注：珍珠：形容泉水迸溅。
注：玉斧砍开：传说中“玉斧”劈山凿泉。
注：老龙涎：龙之涎沫，比喻泉水。
注：贯酸斋：贯云石，号酸斋，元代散曲家，畏兀儿人，曾官翰林侍读学士。
原：寿春道士以小像乞解学士题咏。解作大书“贼、贼、贼”。道士愕然。续云：“有影无形拿不得。只因偷却吕仙丹，而今反作蓬莱客。”
注：寿春：今安徽寿县。
注：解学士：解缙，曾任翰林学士。
注：小像：小幅人像。
注：贼、贼、贼：解缙戏写“贼”，因像“有影无形”，“拿不得”。
注：吕仙：吕洞宾，道教八仙之一。
注：蓬莱客：蓬莱仙人，此处指道士。
# 十七字诗
题解：十七字诗：正德间无赖子作十七字诗讥讽府守祈雨，被捕仍以诗应对，“差多”“打杀”都是十七字诗之末的谐语。
原：正德间，有无赖子好作十七字诗，触目成咏。时大旱，府守祈雨未诚，神无感应。其人作诗嘲之曰：“太守出祷雨，万民皆喜悦，昨夜推窗看，见月！”守知，令人捕至，曰：“汝善作十七字诗耶？试再吟之，佳则释尔。”即以别号“西坡”命题。其人应声曰：“古人号东坡，今人号西坡。若将两人较，差多！”守大怒，责之十八。其人又吟曰：“作诗十七字，被责一十八。若上万言书，打杀！”守亦哂而逐之。
注：正德：明武宗年号（1506—1521）。
注：十七字诗：只有十七字的小诗，一种戏谑诗体。
注：无赖子：游手好闲之人。
注：府守：知府。
注：祈雨：求雨。
注：见月：言无雨，反见月。
注：西坡：与“东坡”相对，苏轼号东坡。
注：差多：差得远。
注：责之十八：杖责十八下。
注：万言书：王安石上仁宗《万言书》；此处指上书言事。
原：一说：守坐以诽谤律，发配郧阳，其母舅送之，相持而泣。泣止，曰：吾又有诗矣。发配在郧阳，见舅如见娘，两人齐下泪，三行。盖舅乃眇一目者也。
注：坐以诽谤律：以诽谤罪论处。
注：郧阳：今湖北十堰郧阳，明代为流放地。
注：母舅：舅舅，“眇一目”即只有一只眼，“三行”“泪三行”因一目有泪，一目无。
注：眇一目：瞎一只眼。
# 吴、翟戏笔
题解：吴兰、翟永龄戏笔：吴兰为富人作《观音赞》《寿星图题》，翟永龄在靖江遭轻慢，题扇画诗以嘲吏，皆嬉笑之作。
原：霍山进士吴兰高才玩世，以主事居乡。乡富人持大士像索赞。赞曰：“一个好奶奶，世间那里有。左边一只鸡，右边一瓶酒。只怕苍蝇来，插上一枝柳。” 又有持寿星图求题，图有长松、明月、玄鹤、白鹿、灵龟。吴题云：“一枝松遮半边月，一只黄狗带著雪。若无老翁持杖赶，老鹰飞来抓去鳖。”
注：霍山：今安徽霍山。
注：吴兰：明代进士，霍山人，待考。
注：玩世：以游戏态度对待世事。
注：大士：观音大士。
注：赞：像赞。
注：苍蝇来，插上一枝柳：观音常持杨柳枝，“柳”可驱蝇，借以揶揄。
注：寿星图：祝寿的图，常有松、鹤、鹿、龟。
注：玄鹤：黑鹤。
原：翟永龄偶过靖江，人咸以相公称之。时有一吏在坐，亦称相公。翟意谓人不加敬。后有出扇求诗者，此吏捉笔竟题于前。次至永龄，故为不能之状，题曰： “山不山，水不水，一片板上两个鬼。〈扇景一船二人，一吹笛，一摇橹。〉一个吹火通，一个舒火腿。吓得鸡婆，飞上天去。〈扇上画雁。〉世间名画见千万，不知此画出何许。”询知海槎，众人甚赧。
注：翟永龄：明代人，字岐生，号潜斋，苏州人。
注：靖江：今江苏靖江。
注：相公：此处泛称有身份者。
注：火通：吹火筒。
注：舒火腿：伸出火腿，借以描摹摇橹之状。
注：鸡婆：母鸡，此处指雁。
注：海槎：翟永龄之号，待考。
注：赧：羞愧脸红。
# 二苏诗
题解：二苏诗：苏轼读《传灯录》，灯花烧去“僧”字，戏作诗；苏辙见白足妇洗衣，作诗嘲佛印。
原：东坡夜宿曹溪、读《传灯录》，灯花堕卷上，烧一“僧”字，即以笔记于窗间，曰：“山堂夜沉寂，灯下读《传灯》。不觉灯花落，茶毘一个僧。”
注：曹溪：广东韶关，六祖慧能所居曹溪南华寺，此处“曹溪”或指苏轼谪居惠州时的所在。
注：《传灯录》：《景德传灯录》，宋代禅宗史书，道原编。
注：灯花：油灯燃烧时的结花。
注：茶毘：梵语“荼毗”，意为火葬。
原：苏子由见白足妇洗衣，作诗嘲佛印云：“玉箸插银河，红裙蘸绿波。再行三五步，浸入老僧窠。”
注：苏子由：苏辙。
注：白足妇：赤脚的妇女，洗衣时。
注：玉箸：玉制的筷子，喻妇人之足。
注：老僧窠：僧人居处，此处谑指裙内。
# 七十新郎
题解：七十新郎：王雅宜七十娶妾，许高阳作《七十新郎》诗嘲之，诗用“新郎”“残花”“秋燕”“病鸳鸯”“衔泥不上梁”等比。
原：王雅宜七十娶妾。许高阳嘲曰：“七十作新郎，残花入洞房。聚犹秋燕子，健亦病鸳鸯。戏水全无力，衔泥不上梁。空烦神女意，为雨傍高唐。”
注：王雅宜：王宠，字履吉，号雅宜山人，明代书法家，苏州人，卒于嘉靖。
注：许高阳：许初，字复初，号高阳山人，明代诗人，苏州人。
注：洞房：新房。
注：空烦神女意：宋玉《高唐赋》，楚王梦巫山神女，朝云暮雨。
# 骂孟诗
题解：骂孟诗：李觏爱酒，士人以数首诗骂孟子骗取酒食，后再以诋佛三篇来骗，李觏笑说前次酒被你饮尽，今次不敢留。
原：李太伯贤而有文章，素不喜佛，不喜孟子，好饮酒。一日有达官送酒数斗，太伯家酿亦熟。一士人无计得饮，乃作诗数首骂孟子。其一云：“完廪捐阶未可知，孟轲深信亦还痴。岳翁方且为天子，女婿如何弟杀之。”又云：“乞丐何曾有二妻？邻家焉得许多鸡？当时尚有周天子，何必纷纷说魏齐。”李见诗大喜，留连数日，所与谈，莫非骂孟子也。无何酒尽，乃辞去。既而闻又有送酒者，士人再往，作《仁义正论》三篇，大率诋佛。李览之，笑曰：“公文采甚奇。但前次酒被公饮尽，后极索寞，今次不敢相留。”
注：李太伯：李觏，字泰伯，北宋思想家，著《直讲李先生文集》，曾作《常语》疑孟。
注：达官：显贵之官。
注：完廪捐阶：《孟子·万章上》载舜父瞽瞍令舜修仓廪，从下纵火，又令舜浚井，掩之。
注：岳翁方且为天子：尧是舜之岳父，且为天子，舜之弟象杀舜之说不可信。
注：乞丐何曾有二妻：《孟子·离娄下》“齐人有一妻一妾”，乞食于东郭墦间。
注：邻家焉得许多鸡：《孟子·滕文公下》“今有人日攘其邻之鸡者”，此处讥其难信。
注：魏齐：魏国、齐国，战国诸侯，孟子游说梁（魏）、齐诸国。
注：《仁义正论》：士人所作之文，待考。
注：索寞：寂寞，无趣。
# 蜘蛛诗
题解：蜘蛛诗：杨凝式令歌妇杨苎罗嘲云辨僧，苎罗以蜘蛛为题，嘲其“体充肚大”，杨叫“和尚将绢来”。
原：洛阳歌妇杨苎罗，聪慧有才思，杨凝式甚怜之。时有僧云辨者，善讲经，杨令对歌者讲。忽蜘蛛垂丝飏云辨前，杨笑谓歌者曰：“试嘲得著，奉绢二匹。” 歌者应声曰：“吃得肚婴撑，寻思绕寺行。空中设罗网，只待杀虫生。”辨体充肚大，故嘲之。杨见诗绝倒，大叫“和尚将绢来！”云辨惭且笑，与绢五匹。
注：杨苎罗：洛阳歌妓，待考。
注：杨凝式：五代书法家，字景度，号虚白，华阴人，官至太子少保，号“杨风子”。
注：云辨：僧人，待考。
注：讲经：僧人说法。
注：飏：飘扬。
注：肚婴撑：肚皮撑饱，谐“吃得肚饱”。
注：罗网：蜘蛛网。
注：杀虫生：“杀生”之戒，佛教不杀生。
# 杨公复诗
题解：杨公复诗：杨公复任大理少卿，家养猪，命童采玄武湖萍藻，被都察院吴思庵拒绝；杨以“肚里好撑船”之诗戏之。
原：南京大理少卿长兴杨公复，在京甚贫，家畜一豕，日命童于玄武湖壖采萍藻为食。吴思庵时握都察院章，以其密迩厅事，拒之。杨戏作小诗送云：“太平堤下后湖边，不是君家祖上田。数点浮萍容不得，如何肚里好撑船？”〈谚云：宰相肚里好撑船。〉
注：大理少卿：大理寺副长官。
注：长兴：今浙江长兴。
注：杨公复：杨某，字公复，待考。
注：玄武湖：南京玄武湖，又称后湖，明代为黄册库所在。
注：壖：河边空地。
注：吴思庵：吴廷举，号思庵，明弘治朝官员，曾任都察院左都御史。
注：密迩：靠近。
注：太平堤：玄武湖堤。
注：宰相肚里好撑船：俗语，喻宽容大度。
# 嘲林和靖
题解：嘲林和靖：许洞以诗嘲隐士林逋，用“饥老鼠”“老猕猴”“鹅伸颈”“鳖缩头”比喻，借其孤傲。
原：隐士林和靖傲许洞。许嘲之云：“寺里掇斋饥老鼠，林间咳嗽老猕猴。豪民送物鹅伸颈，好客临门鳖缩头。”
注：林和靖：林逋，字君复，北宋隐逸诗人，隐居杭州孤山，谥和靖。
注：许洞：北宋文人，字洞夫，著《虎钤经》。
注：掇斋：取斋饭，指僧人乞食。
注：咳嗽：咳嗽之声，此处指干咳。
注：鹅伸颈：形容鹅探头，指豪民送物谄媚。
注：鳖缩头：龟鳖遇人缩头，指林逋避客。
# 四十翁
题解：四十翁：欧阳重巡抚云南，被夺职归，四十岁自称“涯翁”，被无名氏作二绝嘲之，借“醉翁”之说。
原：庐陵欧阳重巡抚云南，以不给军粮夺职归。每过馆驿，必题诗壁上，大抵怨望之辞也。时年甫四十，称“涯翁书”。有无名氏书二绝于其诗后，云：“怨辞随处满垣飞，闻道先生放逐归。四十称翁非太早，人生七十古来稀。”“醉翁千古号文宗，此日涯翁姓偶同。却想齐名就充老，世间安有四旬翁？”
注：庐陵：今江西吉安，欧阳修籍贯。
注：欧阳重：明代官员，字德大，号涯翁，吉安人，曾巡抚云南，待考。
注：夺职：革职。
注：怨望：怨恨。
注：涯翁：欧阳重之号。
注：人生七十古来稀：杜甫《曲江》诗句。
注：醉翁：欧阳修号“醉翁”，作《醉翁亭记》。
注：文宗：文章宗师。
注：齐名：此处指欧阳重自比欧阳修。
原：近考庐陵谪滁，号“醉翁”，年止四十，作诗者未知也，然中丞之窃比文宗，诚可诮。
注：庐陵谪滁：欧阳修贬滁州，号醉翁，时年四十一岁。
注：窃比文宗：私自比拟文章宗师。
# 钱鹤滩
题解：钱鹤滩：钱福归田后访江都张妓，妓已属盐商，题诗嘲“淡”，谑嫁盐商。
原：状元钱鹤滩已归田。有客言江都张妓动人，公速治装访之。既至，已属盐贾。公即往叩。贾重其才名，立日请饮。公就酒语求见。贾出妓，衣裳缟素，皎若秋月，复令妓出白绫帕请留新句。公即题云：“淡罗衫子淡罗裙，淡扫蛾眉淡点唇。可惜一身都是淡，如何嫁了卖盐人？”
注：钱鹤滩：钱福，字与谦，号鹤滩，明弘治三年（1490）状元，松江华亭人。
注：归田：辞官回乡。
注：江都：今江苏扬州。
注：盐贾：盐商，扬州盐商富甲天下。
注：缟素：白色丧服。
注：白绫帕：白色丝帕。
注：淡罗衫子淡罗裙：此诗谑“盐”，“淡”与“盐”相对，借卖盐人之妻，“淡”指无味。

# 食蕈

注：行脚僧：云游的僧人。
# 唐解元二诗
题解：唐解元二诗：唐伯虎在枷上题诗嘲令之索取，题画海蛳嘲皂隶，皆以巧语讥讽官差。
原：吴令命役于虎丘采茶。役多求，不遂，谮僧。令笞僧三十，复枷之。僧求援于唐伯虎，伯虎不应。一日过僧所，戏题枷上云：“官差皂隶去收茶，只要纹银不要赊。县里捉来三十板，方盘托出大西瓜。”令询之，知为唐解元笔，笑而释僧。
注：唐伯虎：唐寅，字伯虎，乡试解元，故称唐解元。
注：虎丘：苏州名胜，产虎丘茶。
注：谮：诬陷。
注：枷：木制刑具，套在犯人颈上。
注：皂隶：衙役。
注：纹银：成色好的白银。
注：赊：欠。
注：方盘托出大西瓜：谐“光头和尚”，西瓜似僧头，托盘喻“枷”。
原：伯虎尝出游遇雨，过一皂隶家。乞纸笔求画，唐遂画海蛳数百，题其上云：“海物何曾数著君，也随盘馔入公门。千呼万唤不肯出，直待临时敲窟臀。”
注：海蛳：海螺。
注：窟臀：屁股。“海物数著君”，此处以海蛳之“蛳”谐“师”，“千呼万唤不肯出，直待临时敲窟臀”，指逼出海蛳须敲其尾，借衙役索贿。

# 应履平诗
题解：应履平诗：应履平任德化令，吏部考试因貌不扬不得列上，题诗于都门，吏呈冢宰认出，遂升考功。
原：应履平为德化令，满考，吏部试论；文优而貌不扬，不得列上。乃题诗都门前云：“为官不用好文章，只要须胡及胖长。更有一般堪笑处，衣裳糨得硬绷绷。”不书姓名。吏呈冢，曰：“此必应知县也。”遂升考功。
注：应履平：应履平，明代官员，浙江人，待考。
注：德化：今江西九江德化，一说福建德化。
注：满考：任期届满的考核。
注：论：论文，策论。
注：须胡：胡须。
注：糨：用浆糊浆衣服使其挺硬。
注：绷绷：硬挺。
注：考功：吏部考功司。

# 龙宫海藏
题解：浙江试题“龙宫海藏”，答不出者作诗嘲笑答出者徒劳，诙谐于科场应试。
原：正德中，御史某按浙，以“龙宫海藏”命题试，且云：“记出处者东立，不记者西退。”东西各半。已而东立者所作不称意，无赏。西退者作诗诮之曰：“东廊且莫笑西廊，我笑东廊枉自忙。海藏龙宫无你分，大家随我度钱唐。”
注：正德：明武宗年号（1506—1521）。
注：御史某按浙：监察御史巡按浙江，掌考察地方官吏并监临考试。
注：龙宫海藏：佛经称龙宫藏有经典，《华严经》相传龙树入龙宫取经；“海藏”指佛经之海。题目冷僻，须记出处方能作答。
注：东立：站到东边，表示记得出处。
注：西退：退到西边，表示不记得出处。
注：东廊：指站东边的作文者。
注：西廊：指退到西边的人。
注：钱唐：即钱塘，今杭州，浙江省会，乡试所在。“度钱唐”谓渡过钱塘江回家。
# 写真
题解：苏州蒋氏父子互相画像都不像，时人作诗嘲讽。
原：姑苏蒋思贤父子写真。一日交写，皆不肖。时人嘲之曰：“父写子真真未像，子传父像像非真。自家骨肉尚如此，何况区区陌路人。”
注：姑苏：苏州的别称，因城西姑苏山得名。
注：写真：画肖像。
注：不肖：此处指画得不相像（兼有“不贤”的双关）。
注：像像非真：“像”字叠用，此为文字游戏，意谓画像都不像真人。
注：陌路人：路人，陌生人。
# 弄瓦诗

注：瓦窑：烧瓦之窑，谓其妻专生“瓦”（女儿）。
# 独眼龙
题解：吴中聚会行令，输者行酒，其人眼红，刘元声以“红”字作诗，戏称“独眼龙”。
原：吴中小集，有便宜行事之令，较拳高下，最后者为老儒，使之行酒。有行酒者，方病目一睛红赤。众以“红”字为韵赋诗，唯刘元声最胜。诗云：“赢得人称独眼龙，怪来青白总非同。怜他满座能行酒，也算当场一点红。”
注：便宜行事之令：酒令名，大意谓可随意行事；待考。
注：较拳：划拳。
注：行酒：斟酒劝饮。
注：刘元声：吴中人，待考。
注：独眼龙：本指独眼之人，五代李克用号“独眼龙”。
注：怪来青白总非同：化用阮籍青白眼典，一目红赤，故青白之分不同。
注：一点红：双关，既指红眼，又指“万绿丛中一点红”的当场出彩，兼指酒令中行酒者。
# 恶字
题解：荆南从事收到朋友字迹极恶的书信，作诗戏称其字可当符箓。
原：李郁为荆南从事。有朝士寄书，字体殊恶。李寄诗曰：“华缄千里到荆门，章草纵横任意论。深荷故人相爱处，天行时气许教吞。”言堪作符也。
注：李郁：待考。
注：荆南：唐方镇名，治荆州（今湖北江陵）。从事：节度使等的幕僚。
注：朝士：朝廷官员。
注：章草：汉字书体之一，由隶书草化而来，此处借指潦草字迹。
注：荆门：荆州一带，此处指李郁所在。
注：天行时气：流行性时疫。旧俗以符水吞服可治病，诗戏言其字堪作符，吞之可以治时疫。
注：符：道士所画符箓，笔画诡曲难识，与恶字相比。
# 柏子庭诗
题解：松江大旱，方士沈雷伯求雨无验，柏子庭以诗联嘲之。
原：至元丙子，松江亢旱。闻方士沈雷伯道术高妙，府官遣吏赍香币过嘉兴迎之。比至，傲甚，谓雨可立致。结坛仙鹤观，行月孛法，下铁简于湖泖潭井，日取蛇燕焚之。了无应验，羞赧宵遁。柏子庭和尚素称滑稽，有诗一联云：“谁呼蓬岛青头鸭，来杀松江赤练蛇。”闻者绝倒。
注：至元丙子：元世祖至元十三年（1276）。时宋亡，元军已入临安。松江：今上海松江，当时为松江府。
注：亢旱：大旱。
注：方士：求仙炼丹、行法术之士。
注：赍：携带。香币：香与币帛，祭神所用。
注：嘉兴：今属浙江，与松江相邻。
注：月孛法：道教法术，月孛为星名（计都、月孛、罗睺为凶星）；此处为求雨之法，待考。
注：铁简：道教祈禳投入水中的铁牌，名“铁简”，用以告神。
注：湖泖潭井：松江一带多湖泖，故投铁简于此。
注：蛇燕：烧蛇燕以求雨，旧俗以蛇、燕为龙属，或可致雨。
注：赧：羞愧脸红。宵遁：夜间逃走。
注：柏子庭：元代和尚，素称滑稽，生平待考。
注：青头鸭：戏称方士，或因其头戴青巾，待考。
注：赤练蛇：蛇名，此处指方士焚杀之蛇，亦“松江赤练”双关。
注：绝倒：笑得前仰后合。
# 东坡戏联
题解：苏轼贬惠州，戏赠邻居老校书得子一联；又以酒为“青州从事”写失酒诗。
原：东坡谪惠州日，与一村校书为邻。年已七十，其妾生子，为具邀公。公欣然往。酒酣乞诗。公问妾年几何。曰：“三十。”乃戏赠一联云：“圣善方当而立岁，顽尊已及古稀年。”一时大噱。
注：谪惠州：宋哲宗绍圣元年（1094）苏轼贬惠州。惠州今属广东。
注：村校：乡村学塾的塾师。
注：圣善方当而立岁：“圣善”本指母，《诗经·邶风·凯风》“母氏圣善”；“而立”为三十岁，《论语·为政》“三十而立”。
注：顽尊已及古稀年：“顽”指愚顽，称其父；“古稀”七十岁，杜甫《曲江》“人生七十古来稀”。
注：大噱：大笑。
原：东坡居惠，广守月馈酒六壶，吏尝跌而亡之。坡有诗云：“不谓青州六从事，翻成乌有一先生。”
注：广守：广州知州。
注：六从事：酒六壶，戏称“从事”；《世说新语·术解》称好酒为“青州从事”，劣酒为“平原督邮”，以青州有齐郡，“齐”谐音“脐”，酒味下达脐。
注：乌有一先生：司马相如《子虚赋》中虚构人物，意为本无此人。以“乌有”戏谓酒已失去。
# 而已诗
题解：洪舜俞因奏疏中的“而已”二字被台官弹劾罢官，自作诗解嘲，并引宋太祖“之乎者也”典。
原：洪舜俞为考功郎，应诏言事，论台谏失职，词甚剀切。内有“其相率勇往而不顾者，惟恭请圣驾款谒景灵宫而已”句，遂为台官所谪，谓“祗见宗庙，重事也，而舜俞乃云‘而已’，有轻宗庙之意”，因被落三官。舜俞自为诗云：“不得之乎成一事，却因而已失三官。”
注：洪舜俞：宋人，官考功郎，生平待考。
注：考功郎：吏部考功司郎中，掌官吏考课。
注：台谏：御史台与谏院官员，掌弹劾与进谏。
注：景灵宫：宋代供奉祖先神御之所，在开封，南渡后在临安。
注：落三官：降三级官阶。
注：不得之乎成一事：“之乎”指虚词，诗谓因“而已”二字失官，用“之乎者也”之典。
原：宋艺祖幸朱雀门，指门额问赵晋，何不止书朱雀门，乃著“之”字。晋曰：语助耳。艺祖曰：之乎者也，助得甚事。洪语本此。
注：宋艺祖：宋太祖赵匡胤，庙号太祖，“艺祖”为对开国之君的美称。
注：朱雀门：宋开封内城南门。
注：赵晋：疑当作赵普，宋太祖朝名相，底本如此，待考。
注：语助：语气助词，即“之”字之类。
注：洪语本此：洪舜俞“而已”之语出于此类虚词之讥。
# 榜后诗
题解：孙山落榜末，所谓“名落孙山”之典，及王十朋、周师厚榜后嘲诗。
原：孙山应举，缀名榜末。朋侪以书问山得失。答曰：“解名尽处是孙山，馀人更在孙山外。”览者大笑。
注：孙山：宋代吴地人，滑稽，“名落孙山”典出范公偁《过庭录》，谓榜末为孙山，后以落榜为“名落孙山”。
注：缀名榜末：名字排在榜末。
注：朋侪：朋友同辈。
注：解名：解试（乡试）录取名次。
原：王十朋正榜第一，李三锡副榜第一。时有戏正榜尾者曰：“举头虽不窥王十，伸脚犹能踏李三。”
注：王十朋：南宋名臣，绍兴二十七年（1157）状元。

注：李三锡：待考。

注：周师厚：北宋人，待考。
注：郑獬：北宋安陆人，皇祐五年（1053）状元，官翰林学士。
注：陈传：待考。

# 长妓瘦妓
题解：杜牧赠肥妓，李宣古嘲瘦妓，一肥一瘦互相映衬。
原：杜牧为宣州幕。时有酒妓肥大，牧赠诗曰：“盘祖当时有远孙，尚令今日逞家门。一车白土将泥脸，十幅红绡补破裩。瓦棺寺里逢行迹，华岳山前见掌痕。不须啼哭愁难嫁，待与将书问岳神。”牧同时沣州酒糺崔云娘，形貌瘦瘠，每戏调，举罚众宾；兼恃歌声，自以为郢人之妙。李宣古当筵一咏，遂至箝口。诗曰：“何事最堪悲，云娘只首奇。瘦拳抛令急，长嘴出歌迟。只见肩侵髩，唯忧骨透皮。不须当户立，头上有锺馗。”
注：杜牧：晚唐诗人，字牧之，曾入宣州沈传师幕。宣州今安徽宣城。
注：酒妓：陪酒歌妓。
注：盘祖：盘古，神话中开天辟地者。此句谓其体型如盘古后裔。
注：白土：白色细泥。红绡：红色生丝织物。
注：裩：裤子，同“裈”。
注：瓦棺寺：金陵寺名，顾恺之曾于壁画维摩诘像。行迹：待考。
注：华岳山前见掌痕：华山有“巨灵擘山”的传说，掌痕即“仙人掌”，喻其手掌巨大。
注：岳神：华山之神。
注：沣州：当作澧州，今湖南澧县一带。酒纠：行酒令的监酒者。
注：崔云娘：待考。
注：郢人之妙：《庄子·徐无鬼》郢人运斤成风的故事，喻技艺精妙。
注：李宣古：晚唐诗人，大中时人。
注：箝口：闭口。
注：锺馗：传说中捉鬼之神，形象瘦削；诗戏其瘦如鬼。
# 生张八
题解：北都妓女举止生涩，被称“生张八”，魏野赠诗以“生熟”相戏。
原：北都有妓美色，而举止生梗，土人谓之“生张八”。因宴会，乞诗于处士魏野。野赠曰：“君为北道生张八，我是西州熟魏三。莫怪尊前无笑语，半生半熟未曾谙 〈一作“也难毚”〉。”
注：北都：宋代北京大名府，一说太原，此处待考。
注：生梗：生硬笨拙。
注：生张八：宋代俗语，称不熟悉者为“生张八”，与“熟魏三”相对，源自笔记所载。
注：魏野：北宋处士，字仲先，号草堂居士，陕州人，隐居不仕。
注：西州：指陕州一带，魏野为陕州人。
注：也难毚：底本小注，疑为异文，待考。
# 贫娼
题解：友人写吴生所恋娼家之贫，诗以俗语入诗，一时传笑。
原：吴生恋一娼，其人家甚贫。友人李云卿赋其事曰：“可笑犁园地，翻为寂寞场。当街为客座，隔壁是厨房。屋柱悬灯挂，泥坯甃火厢。烟烟三幅幔，旧旧一张床。草荐累堆厚，绵衾褦襶胖。竹竿衣架短，麻布手巾长。双陆无全马，棋盘少二将。恐惶之茂甚，不可也之当。”一时传笑。吴生耻，遂绝往。
注：犁园地：指娼家的场地，“犁园”疑当作“梨园”，待考。
注：甃火厢：用砖砌的火炉，“甃”为砌砖。
注：褦襶：不晓事、粗笨，亦指厚重粗陋貌。
注：双陆：古代博戏，用棋子黑白各十五，分两路比赛。
注：恐惶之茂甚，不可也之当：集用文言虚词作结，诗戏仿之乎者也，言其贫陋不堪。
# 通判
题解：知县转为管粮通判，同僚作诗贺之，实则暗讽降职，后来贺诗者自己亦被贬为属吏。
原：有以知县转管粮通判者。一郎中作诗贺之云：“最妙无如转判通，州官门报气何雄！班联喜得先推府，尊重何须羡老同？丞簿晚生今已矣，教官侍教且从容。更有一般堪羡处，下仓攒典列西东。”后郎中亦谪济南通判，先通判者官德州，其属吏也。到任时，僚属满堂，即书此诗，持轴往贺之。及言其故，无不绝倒。
注：管粮通判：通判为知府副贰，管粮通判专管漕粮。明代通判官阶（正六品）高于知县（正七品）。
注：郎中：六部各司的主官。
注：门报：官员出行时在门前通报的牌示。
注：推府：推官，府内掌刑名，诗谓通判班次先于推官。
注：老同：老同年之类，待考。
注：丞簿：县丞、主簿。
注：教官：府州县学的教谕、训导。
注：攒典：吏职，管仓库出纳。
注：济南通判：济南府通判。
注：德州：今山东德州，属济南府。
# 药名诗
题解：陈亚好以药名作诗，诸条所引皆以药名双关。
原：陈亚好用药名为诗，曾知祥符县，亲故多干托借车牛。因作诗曰：“地名京界足亲知 〈荆芥〉，托借寻常无歇时 〈全蝎〉。但看车前牛领上 〈车前子〉，十家皮没五家皮 〈五加皮〉。”亚尝言： “药名用于诗，无不可，而斡运曲折，使各中理，存乎其人。”或曰：“延胡索可用乎？”沉思久之，吟曰：“布袍袖里怀漫刺，到处迁延胡索人。”此可赠游谒措大。
注：陈亚：北宋扬州人，咸平进士，官至太常少卿，以药名诗著称。
注：祥符县：今河南开封一带。
注：荆芥：药名，此处谐“京界”。全蝎：药名，谐“全歇”。车前子：药名，谐“车前子”本字。五加皮：药名，谐“五家皮”。
注：延胡索：药名，谐“迁延”。
注：漫刺：名帖。迁延：拖延逗留。
注：措大：对贫寒读书人的戏称。
原：陈亚药名诗百首，如“风雨前湖近 〈前胡〉，轩窗半夏凉 〈半夏〉。”“棋为腊寒呵子下 〈呵子〉，衣嫌春暖缩砂裁 〈缩砂〉。”《咏白发》云：“若是道人头不白 〈道人头〉，老君当日合乌头 〈乌头〉。”《赠乞雨自曝僧》云：“不雨若令过半夏 〈半夏〉，定应晒作葫芦巴 〈葫芦巴〉。”最脍炙人口。
注：前胡：药名，谐“前湖”。半夏：药名，亦指夏季过半。
注：呵子：即诃子，药名，谐“呵子”。缩砂：即缩砂仁，药名，谐“缩纱”。
注：道人头：药名，谐“道人头不白”。乌头：药名，谐“乌头（黑发）”。
注：自曝僧：僧人暴晒身体求雨，旧俗以此祈雨。
注：葫芦巴：药名，谐“葫芦”。
注：脍炙人口：比喻诗文受人称赞。
原：萧凤仪桑寄生传四诗亦佳，然终避其奇巧。
注：萧凤仪：待考。桑寄生：药名，同题作《桑寄生传》。
注：奇巧：指过于求奇求巧。
# 吃语诗

注：吃语诗：吃，即口吃；此诗每句多用同声母字，读来如口吃。
注：王居士：武昌王姓居士，待考。
注：挂经：悬挂经卷。
注：菰茭：菰与茭白，水生植物。
注：笳鼓：胡笳与战鼓，军中乐器。
注：箕踞：两腿伸开坐，表示放肆。
注：赓歌：酬唱和诗歌。
注：荆笄：荆条做的发簪，借指贫女。
注：聒：吵闹。
原：一孝廉口吃，谢在杭与徐兴公各赠绝句以难之。谢二首云：“绿柳龙楼老，林萝岭路凉。露来莲漏冷，两泪落刘郎。”又“梨岭连连路，兰陵累累楼。流离怜冷落，郎辇懒来留。”兴公一首云：“留恋兰陵令，淋漓两泪流。岭萝凉弄濑，路柳绿连楼。”

# 《反酒箴》
题解：引《汉书·陈遵传》所载扬雄《酒箴》，借酒器讽喻。
原：《汉书》：陈遵与张竦相善，而操行不同。竦居贫无宾客，而遵昼夜酣呼。先是黄门郎扬雄作《酒箴》以谏成帝，或为酒客难法度士云：“譬之于物，子犹瓶矣。观瓶之居，居井之眉。处高临深，动常近危。酒不沾口，臧水满怀。不得左右，牵于𬙊徽。一旦叀碍，〈叀，上缉反，县也，犹云挂碍。〉为瓽所轠。〈瓽，丁浪反，砖甃井也。轠，音雷。〉身提黄泉，骨肉为泥。自用如此，不如鸱夷。〈韦囊以盛酒。〉鸱夷滑稽，腹大如壶。尽日盛酒，人复借酤。常为国器，托于属车。〈天子属车，常载酒食。〉出入两宫，经营公家。繇是言之，酒何过乎？”遵大喜，谓竦曰：“吾与尔犹是矣！”
注：陈遵：西汉人，字孟公，嗜酒豪放，官至河南太守，事见《汉书·游侠传》。张竦：字伯松，与陈遵同里。
注：黄门郎：给事黄门侍郎，侍从皇帝。扬雄：西汉文学家，字子云，作《酒箴》。
注：酒箴：以酒为题的箴诫文，实为扬雄借以讽谏。
注：瓶：汲水器。
注：臧水：藏水，“臧”通“藏”。
注：徽：绳索，井上汲水之绳。
注：叀碍：悬挂牵绊。叀，《汉书》作“𧶽”；此处为注文，意为悬挂。
注：瓽：井壁。轠：垒，砖砌井。
注：鸱夷：皮囊，盛酒之器。
注：滑稽：古代酒器名，转注酒不竭，亦喻善辩。
注：属车：皇帝出行时随从的副车。
注：两宫：长乐宫与未央宫，指皇帝与太后。
# 《反金人铭》
题解：孙楚《反金人铭》反用《金人铭》。
原：孙楚《反金人铭》曰：“晋太庙左阶前有石人焉，大张其口，而书其胸曰：我古之多言人也，无少言，少言少事，则后生何述焉。夫惟立言，名乃长久，胡为槐然，自缄其口？”

注：反金人铭：《金人铭》刻于周太庙金人之背，劝人慎言；孙楚反其意而作。
注：太庙：帝王祖庙。
注：槐然：待考，疑当作“愧然”，意不可知。

# 仿《春秋》
题解：莫氏仿《春秋》笔法，在酒楼壁上续题，讥嘲轻薄子。
原：霅川月河莫氏称望族，家世以《春秋》驰声。至一酒楼饮，见壁间题云：“春王正月，公与夫人会于此楼。”盖轻薄子携妓来饮所题也。莫即援笔题其下云：“夏大旱，秋饥，冬雨雪，公薨。君子曰：‘不度德，不量力，其死于饥寒也宜哉！’”见者大笑。
注：霅川：湖州（今浙江湖州）之别称，因霅溪得名。
注：月河：湖州的一处河名。
注：《春秋》：鲁国编年史，相传孔子所修，笔法简严，称“春秋笔法”。莫氏以《春秋》为家学。
注：春王正月：《春秋》每年首句，“春王正月”。
注：公与夫人会于此楼：仿《春秋》“公会夫人于某地”句式，讥其携妓。
注：公薨：诸侯去世曰薨。
注：君子曰：《左传》评论之体。
注：不度德，不量力：出自《左传·隐公十一年》“不度德，不量力，不亲亲，不征辞，不察有罪，犯五不韪而以伐人”。
# 笋墓志
题解：傅奕自作墓志，陶谷仿作《笋墓志》以滑稽。
原：傅奕病，未尝问医。忽酣卧，蹶然曰：“吾死矣乎！”即自志曰：“傅奕，青山白云人也，以醉死，呜呼！”陶谷戏效之，作《笋墓志》曰：“边幻节，字脆中，晋林琅玕之裔也，以汤死。建隆年月日立石。”
注：傅奕：唐初太史令，反佛，临终自作墓志。
注：忽酣卧，蹶然曰：突然沉睡，又猛地起身。
注：青山白云人也：傅奕自志语，见《旧唐书》本传。
注：陶谷：五代宋初人，字秀实，仕后晋、后汉、后周、宋，博学多文，多诙谐。
注：边幻节，字脆中：以“笋”的节、脆拟名。
注：琅玕：竹的美称。
注：汤死：笋被煮熟。
注：建隆：宋太祖年号（960—963）。
# 《曲中月令》
题解：陈铎作《曲中月令》，以妓院月令戏仿《礼记·月令》。
原：指挥陈铎善嘲，作《曲中月令》。其二月有云：“是月也，壁虱出，沟中臭气上腾，妓靴化为鞋。”
注：指挥：明代卫所武官，有指挥使等。陈铎：字大声，号秋碧，明南京人，世袭指挥使，善散曲，著《秋碧乐府》等，其《曲中九奇》等亦有名。
注：曲中：旧时指妓院所在之处，北京称“曲”。
注：月令：《礼记》篇名，记每月时令与政事。
注：是月也：《月令》固定句式，每月皆以“是月也”开头。
注：壁虱：臭虫。
注：妓靴化为鞋：戏谓冬靴换成春鞋。
# 辊卦
题解：潘纯以《周易》体戏作“辊卦”，讽世人圆滑取容。
原：宋末淮南潘纯戏作“辊卦”。其词曰：“辊，亨，可小事，亦可大事。彖曰：辊，亨，天地辊而四时行，日月辊而昼夜明，上下辊而万事成。辊之时义大矣哉！象曰：地上有木，辊。君子以容身固位。初六，辊，出门无咎。象曰：出门便辊，又何咎也？六二，传于銕轊。象曰：传于銕轊，天下可行也。六三，君子终日辊辊，厉无咎。象曰：终日辊辊，虽危无咎也。九四，模棱吉。象曰：模棱之吉，以随时也。六五，神辊。象曰：六五，神辊，老于事也。上六，或锡之高爵，天下揶揄之。象曰：以辊受爵，亦不足敬也。”切中挽近膏肓，可发谐笑。
注：潘纯：宋末淮南人，待考。
注：辊：滚动，喻圆滑；“辊”卦为戏拟。
注：亨：《周易》卦辞常见字，意为通达。
注：彖曰：《周易》解释卦义之辞。
注：象曰：解释卦象与爻象之辞。
注：地上有木：仿《观》《晋》等卦象辞“某上有某”。
注：容身固位：苟且保住官位。
注：初六：爻题，阴爻称六，初指最下爻。
注：九四：阳爻称九，四指第四爻。
注：銕轊：铁制车轴头，圆转之物，亦指“辊”字之义。
注：模棱：唐苏味道语“模棱持两端”，后称含糊不决为模棱。

# 买僮券
题解：王褒《僮约》节录，戏写买来的僮仆便了所须承担的全部劳役，为汉代滑稽文名篇。
原：王褒买僮，名便了。僮曰：“欲使便了，皆当上券。不上券，便了不能为也。”褒乃为券曰：“神爵三年正月十五日，资中男子王子渊，从成都安志里女子杨惠买夫时户下髯奴便了，决卖万五千。奴从百役，不得有二言。晨起早扫，饮食洗涤，居常穿臼，缚帚裁盂，凿井浚渠，缚落鉏园，研陌杜埤。地刻大枷，屈竹作杷，削治鹿卢。出入不得骑马载车，踑足大呶，下床振头。垂钩刈蒭，织履作粗，粘雀张鸟，结网捕鱼。缴雁弹凫，登山射鹿。入水捕龟，浚园纵鱼。雁鹜百馀，驱逐鸱鸟。持梢牧猪，种姜养芋。长育豚驹，粪除堂庑，餧食马牛。鼓四起坐，夜半益蒭。舍中有客，提壶行沽，汲水作铺。但当食豆饮水，不得嗜酒欲美。饮酒惟得沾唇渍口，不得倾盂覆斗。不得晨出夜入，交关伴偶。多取薄蒲。益作绳索。雨堕无所为，当遍将织薄。植种桃李，梨柿柘桑，三丈一树，八树为行，果类相从，纵横相当。果熟收敛，不得吮尝。犬吠当起，惊告邻里。撑门拄户，上楼击柝，持盾曳矛，环落三周。勤心疾作，不得遨游。筋老力索，种苋织席，事讫欲休，常舂一石。夜半无事，浣衣当白。若有私钱，主急宾客，不得奸私，事事关白。若不听教，当笞一百。”
注：王褒：西汉蜀人，字子渊，宣帝时为谏大夫，作《圣主得贤臣颂》《僮约》。

注：上券：写入契约，列明职责。
注：神爵三年：汉宣帝神爵三年（前59）。
注：资中：汉县名，属犍为郡，今四川资阳一带。
注：成都安志里：成都里名。杨惠：卖僮之主，据《僮约》为寡妇。
注：髯奴：多须之奴。
注：决卖万五千：议价一万五千钱成交。
注：穿臼：凿石臼，用以舂米。
注：缚帚裁盂：编扫帚，削木盂。
注：浚渠：疏通沟渠。缚落鉏园：扎篱笆，锄园。
注：研陌杜埤：整修田间路，堵塞矮墙缺口，“研”疑当作“斫”，待考。
注：地刻大枷：文义待考。

# 题小像
题解：唐伯刚题邾仲谊小像，岳正自题小像，皆以画像为题的谐语。
原：唐伯刚题邾仲谊小像云：“七尺躯威仪济济，三寸舌是非风起。一双眼看人做官，两只脚沿门报喜。仲谊云：是谁是谁？伯刚云：是你是你！”
注：唐伯刚：唐寅，字伯虎，此处作“伯刚”，疑误或另有其人，待考。
注：邾仲谊：待考。
注：威仪济济：仪容整肃。《诗经》“济济多士”。
注：三寸舌：指口舌，喻能言。
注：沿门报喜：挨门报喜，喻攀附。
原：岳正再起再废。有自京师来者，传天子语于正曰：“岳正倒好，只是大胆。”正因写小像，遂隐括其辞，题于上曰：“岳正倒好，只是大胆。唯帝念我，必当有感，如或赦汝，再敢不敢？”
注：岳正：明代，字季方，号蒙泉，天顺初入阁，因得罪石亨、曹吉祥被贬，后又被起复，著《类博稿》，事见《明史》本传。
注：再起再废：天顺元年（1457）入阁，不久被贬，后起官，又被免。
注：隐括：对原有文字加以剪裁改写。
注：帝念我：英宗称其“倒好，只是大胆”，诗中因之作答。
# 《化须疏》
题解：沈周为赵鸣玉写《化须疏》，以劝募胡须为题，戏仿疏文。
原：沈石田有《化须疏》，其序曰：“兹因赵鸣玉髠然无须，姚存道为之告助于周宗道者，于其于思之间，分取十鬛，补诸不足，请沈启南作疏以劝之。”疏曰：“伏以天阉之有刺，地角之不毛，须需同音，今其可索，有无以义，古所相通。非妄意以干，乃因人而举。康乐著舍施之迹，崔谌传插种之方。唯小子十茎之敢分，岂先生一毛之不拔！唯有馀以补也，宗道广及物之仁；乞诸邻而与之，存道有成人之美。使离离缘坡而饰我，当榾榾击地以拜君。把镜生欢，顿觉风标之异；临流照影，便看相貌之全。未容轻拂于染羹，岂敢易撚于觅句？感矣荷矣，珍之重之！敬疏。”
注：沈石田：沈周，字启南，号石田，明苏州画家。
注：化须疏：仿僧道募化的疏文，此处向人募须。
注：赵鸣玉：沈周友人，生平待考。
注：姚存道：沈周友人，生平待考。
注：周宗道：沈周友人，生平待考。
注：髠然：光秃貌。
注：于思：多须貌，《左传·宣公二年》“于思于思，弃甲复来”。
注：十鬛：十根须。
注：天阉：先天生理缺陷者，此处指无须。
注：地角之不毛：天边地角寸草不生，喻光秃无须。
注：须需同音：“须”“需”同声，戏言可以索求。
注：康乐著舍施之迹：南朝谢灵运（封康乐公）施须于南海祇洹寺作维摩诘像须，见《南史·谢灵运传》。
注：崔谌传插种之方：崔谌，北魏人，待考；“插种”戏言种须之方。
注：一毛之不拔：《孟子·尽心上》“杨子取为我，拔一毛而利天下不为也”。
注：及物之仁：广施恩惠。
注：成人之美：《论语·颜渊》“君子成人之美”。
注：离离：繁茂下垂貌。榾榾：象声或指叩头声，待考。
注：染羹：胡须沾羹。撚：捻须，觅句时撚须，用卢延让“吟安一个字，撚断数茎须”。
# 《烹鸡诵》
题解：唐寅游僧舍请烹雌鸡，作《烹鸡诵》，以佛语戏谑。
原：唐六如游僧舍，见雌鸡，请烹为供。僧曰：“公能作诵，当不靳也。”援笔题曰：“头上无冠，不报四时之晓；脚跟欠距，难全五德之名。不解雄先，但张雌伏。汝生卵，卵复生子，种种无穷；人食畜，畜又食人，冤冤何已？若要解除业障，必先割去本根。大众先取波罗香水，推去头面皮毛，次运菩萨慧刀，割去心肠肝胆。咄！香水源源化为雾，镬汤滚滚成甘露。饮此甘露乘此雾，直入佛牙深处去，化生彼国极乐土！”僧笑曰：“鸡得死所，无憾矣！”乃烹以侑酒。
注：唐六如：唐寅，号六如居士，明苏州才子。
注：不靳：不吝惜。
注：冠：鸡冠。距：公鸡脚后的突出部分。
注：五德：《韩诗外传》称鸡有文、武、勇、仁、信五德。
注：雄先：“雄鸡先鸣”，指雄先唱晓。雌伏：雌鸡孵卵。
注：业障：佛教谓恶业所致障碍。
注：波罗香水：佛家香水，“波罗”为梵语音译。
注：慧刀：佛教喻智慧之刀。
注：镬汤：油锅热汤。
注：甘露：佛教称不死之药，法雨。
注：佛牙：佛牙舍利。
注：极乐土：西方极乐世界。
注：死所：得死之所。
注：侑酒：佐酒。
# 献海螺简
题解：舒雅向韩熙载献海螺，以简文戏言螺为“无心斑道人”。
原：舒雅才韵不在人下，以戏押得韩熙载之心。一日得海螺甚奇，宜用滑纸，以简献于熙载，云：“海中有无心斑道人，往诣门下。若书材糙涩逆意，可使道人驯之，即证发光地菩萨。”熙载喜受之。〈发光地，十地之一，出《华严经》。〉
注：舒雅：宋初人，南唐时曾仕为校书郎，入宋后官至兵部郎中，工文辞。
注：韩熙载：南唐大臣，字叔言，好文，善声伎。
注：海螺：作砚或磨光滑纸之用。
注：滑纸：光滑的纸，此处指用螺壳磨纸。
注：斑道人：以螺的斑纹拟人，称“斑道人”。
注：书材糙涩逆意：纸张粗糙不合意。
注：驯：使之驯服，指磨平。
注：发光地：佛教菩萨十地之第三地，《华严经》作“发光地”。
注：十地：菩萨修行十个阶位。
# 行人司告示
题解：行人司官员稀少冷落，有人戏写告示，讽其闲散。
原：行人司闲僻，官吏罕到，市人每日取汲厅前，顽童戏坐公座。或有戏揭告示云：“示仰各吏典，以后朔望日，仍要赴司作揖。凡男妇汲水者，毋得仍前擅坐公座。”
注：行人司：明代官署，掌捧节、出使、册封诸事，官位清闲。
注：朔望：农历初一、十五。
注：作揖：拱手行礼，此处指点卯。
注：擅坐公座：擅自坐官员座位。
# 策结
题解：二编修谒李东阳，戏对策题，李公为之升官。
原：有二编修谒李西涯。公曰：“近有一策题：‘两翰林九年考满，推擢何官？’”二君笑云：“策破未有，先有一结：执事，事也，执事，责也，愚生何有焉？”公大笑，题升宫坊。
注：编修：翰林院官，修国史。
注：李西涯：李东阳，号西涯，明弘治、正德时内阁首辅，诗人。
注：策题：科举考试问策之题。
注：九年考满：明制官员三年一考，九年考满。
注：策破：作策的破题。
注：执事：对对方的敬称，此处戏作结尾。
注：愚生：自谦之辞。
注：宫坊：詹事府（左右春坊）属官，如谕德、洗马等，常由翰林官迁转。
# 词
题解：徐渊子以海物戏丁少詹，使其回家；另有袁可潜以《如梦令》赠新婚者。
原：徐渊子舍人善谐谑。丁少詹与妻有违言，弃家居茶寮，茹斋诵经，日买海物放生，久而不归。妻求徐解之，徐许诺。见卖老婆牙者，买一篮饷丁，作词曰： “茶寮山上一头陀，新来学得么？蝤蛑螃蟹与乌螺，知他放几多？有一物，似蜂窠，姓牙名老婆。虽然无奈得他何，如何放得他？”丁大笑而归。
注：徐渊子：徐似道，字渊子，南宋人，诙谐。舍人：中书舍人。

注：么：疑问语气词，“吗”。
注：蜂窠：蜂巢。
注：姓牙名老婆：双关，谐“老婆”。
原：一人娶妻，无元。袁可潜赠之《如梦令》云：“今夜盛排筵宴，准拟寻芳一遍。春云已多时，问甚红深红浅。不见不见，还你一方白绢。”

注：盛排筵宴：广设酒宴。

# 叶祖诗词
题解：叶祖洽诗不分晓，辞官后与僧人饯别，借《如梦令》戏答。
原：叶祖负隽声，尝曰：“世间有不分晓事，吾因一联咏之：醉来黑漆屏风上，草写卢仝月蚀诗。”后以多语去官，独西湖二三僧相善，为之祖饯。僧曰：“世事如梦而已。”叶曰：“如梦如梦，和尚出门相送。”闻者绝倒。
注：叶祖：当为叶祖洽，北宋人，英宗治平二年进士第一（状元）。
注：隽声：才名。
注：卢仝月蚀诗：唐卢仝作《月蚀诗》，诗风怪诞险奥。
注：去官：丢官。
注：西湖：杭州西湖。
注：祖饯：设宴送别。
注：如梦如梦：用《如梦令》词牌戏答。

原：〈注：《 千字文 》天地玄黄。雁门紫塞。左达承明。罔谈彼短。；《千字文》靡恃己长。罔谈彼短。始制文字。犹子比儿。；《千字文》罔谈彼短。靡恃己长。果珍李奈。；《 论语 》修己以安百姓，尧舜其犹病诸。；《 孟子 》何以异于人哉！尧舜与人同耳。；《孟子》(1)入其疆，土地辟，田野治。(2)入其疆，土地荒芜，遗老失贤。(3)孟子曰：诸侯之宝三，土地、人民、政事。(4)狄人 之所欲者，吾土地也。；《论语》(1)在邦必达，在家必达。(2)君子上达，小人下达。《孟子》君子之志于道也，不成章不达。；《 易经 》是以君子将有为也，将有行也，问焉而以言。《 诗经 》乃生男子，载寝之床。《孟子》匠人斲而小之，则王怒，以为不胜其任矣。《诗经》匪面命之，言提其耳。；《诗经》(1)爰居爰处，爰丧其马。(2)无逝我梁，无发我笱。；《 尧山堂外纪 》没意头、无巴鼻，皆当时俗语。〉
注：《千字文》：南朝梁周兴嗣编的蒙学书。
注：天地玄黄：《千字文》首句。
注：雁门紫塞：《千字文》句，指北方边塞。
注：左达承明：《千字文》句，承明为汉代殿名。
注：罔谈彼短：《千字文》句，意为不要谈论别人的短处。
注：靡恃己长：《千字文》句，意为不要倚仗自己的长处。
注：犹子比儿：《千字文》“犹子比儿”。
注：尧舜其犹病诸：《论语·雍也》。
注：君子将有为也：《易·系辞下》，与前文《成语赋谑》所用相合。
注：载寝之床：《诗经·小雅·斯干》。
注：匠人斲而小之：《孟子·梁惠王下》。
注：言提其耳：《诗经·大雅·抑》。
注：爰丧其马：《诗经·邶风·击鼓》。
注：无逝我梁：《诗经·邶风·谷风》。
注：尧山堂外纪：明蒋一葵所著笔记，多记历代逸事。
注：没意头、无巴鼻：宋元俗语，“没意头”即“没主意”，“无巴鼻”即“没来由”。
