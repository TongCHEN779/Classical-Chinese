# 正文
题解：本部总论：冯梦龙论智如日月之光，无处不入，用于机械则为小人，用于神明则为君子，并交代本部为全书第二十一部《谲智》。
原：〔子犹曰：人心之智，犹日月之光。粪壤也，而光及焉，曲穴也，而光入焉。智不废谲，而有善有不善，亦宜耳。小人以之机械，君子以之神明。总是心灵。唯人所设，不得谓智偏属君子，而谲偏归小人也。集《谲智》第二十一。〕
注：子犹曰：冯梦龙自称。
注：粪壤：粪土，肮脏之地。
注：曲穴：曲折的孔洞。
注：谲：诡诈，权变。
注：机械：机巧，权诈之心。
注：神明：此处指通达神妙的智慧。
注：谲智：本部名，指机变、诡诈之智。
# 魏武
题解：本节两段：曹操少时装中风骗叔父、使亲信装怀刀被捕以试心动的故事，写魏武的权诈。
原：魏祖少游荡，叔父数言于其父蒿。祖患之，伪败面口偏。叔父见，云“中风”。又告蒿，蒿惊呼曰：“叔父言汝中风，已差乎？”对曰：“初不中风，但失爱于叔父，故见罔耳。”自是叔父所告，嵩皆不信。
注：魏祖：指曹操，魏武帝，旧称太祖。
注：游荡：放纵不羁。
注：嵩：曹嵩，曹操之父，官至太尉。
注：败面口偏：脸歪嘴斜，装中风。
注：中风：中风病。
注：差：病愈，同“瘥”。
注：见罔：被欺骗，被冤枉。事见《世说新语·假谲》。
原：魏武常言人欲危己，已辄心动。因语所亲小人曰：“汝怀刃密来我侧。我必说心动，执汝行刑。汝但勿言某使，无他，当厚相报。”此人信之，被执不惧，遂斩之。
注：危己：危害自己。
注：心动：心神不安。
注：所亲小人：亲近的下人。
注：行刑：执行刑罚。
# 体认天理
题解：《西堂纪闻》讥湛若水口称“体认天理”，实则借建书院之名占山川田庄，乡人讥之，写道学家的虚伪。
原：《西堂纪闻》：湛甘泉若水，每教人随处体认天理。居乡时，凡山川佳胜、田庄膏腴者，假以建书院、置学田为名，必得之为自殖计，皆资势于当路之门生。乡人常曰：“此甘泉随处体认天理也！”
注：《西堂纪闻》：笔记，待考。
注：湛甘泉若水：湛若水，号甘泉，明代理学家，王阳明同时，官至南京兵部尚书。
注：体认天理：湛若水学说主张“随处体认天理”。
注：膏腴：肥沃。
注：学田：为办学而置的田产。
注：自殖：为自己增殖财产。
注：当路：当权者。
# 《朝野佥戴》两孝子事
题解：本节两则：写《朝野佥载》所载的两个假孝子，一个以撒饼引乌，一个把猫犬互换哺乳，以求旌表，写骗取名誉之伪。
原：东海孝子郭纯丧母，每哭，则群乌大集。使检有实，旌表门闾。后讯，乃是每哭即撒饼于地，群乌争来食之。其后数如此，乌闻哭声，莫不竞凑，非有灵也。
注：东海：郡名，今山东郯城一带。事见唐张鷟《朝野佥载》。
注：郭纯：唐人，事见《朝野佥载》，待考。
注：群乌：成群的乌鸦。
注：旌表门闾：官府表彰其门第。
注：撒饼：撒饼食。
原：河东教子王燧家猫犬互乳其子，州县上言，遂蒙旌表。乃是猫犬同时产子，取猫儿置犬窠中，取犬子置猫窠内，饮惯其乳，遂以为常耳。
注：河东：今山西一带。
注：教子王燧：待考。
注：互乳其子：互相哺乳对方的子。
注：州县上言：州县上奏。
注：旌表：官府表扬。
注：窠：窝。
# 崔、张豪侠
题解：崔涯、张祜以侠相许，被假侠客以猪首诈取十万缗，豪侠之气顿失，写不实的虚名为骗子所乘。
原：进士崔涯、张祜下第后，游江淮，嗜酒狂吟，以侠相许。崔尝有诗云：“太行岭上三尺雪，壮士怀中三尺铁。一朝若遇有心人，出门便与妻儿别。”由是侠名播于人口。一夕，有非常人，装饰甚武，腰剑，手囊贮一物流血于外，入门曰：“此张侠士居耶？”曰：“然。”张揖客甚谨。即坐，客曰：“有一仇人，十年莫得，今夜获之，喜不可已。”指囊曰：“此其首也！”问：“有酒否？”张命酒，客饮嚼甚壮，曰：“闻公义气，薄有所请，可乎？”张唯唯。客曰：“此去三数里，有一义士，余所深德，君可假十万缗，立俗酬之。若济，则平生恩仇毕矣。此后赴汤蹈火，亦无所惮。”张且不吝，深喜其说，乃筹其缣素中品之物，罄以畀之。客曰： “快哉！死无恨！”乃留囊首而去，期以却回。及期不至，五鼓绝声，东曦既驾。杳无踪迹。张虑囊首彰露，客既不来，将遣家人埋之；开囊，乃豕首也。方悟见欺，迩后豪侠之气顿丧。
注：崔涯：唐代吴越狂生，诗人。
注：张祜：唐代诗人，字承吉，与崔涯同游江淮。
注：下第：科举不中。
注：以侠相许：自许为侠士。
注：太行岭：太行山。
注：三尺铁：三尺剑。
注：有心人：有志向的人。
注：揖客：拱手迎客。
注：缗：成串的钱，一千文为一缗。
注：立俗酬之：当作“立刻酬之”，疑“俗”误。
注：赴汤蹈火：在热汤和烈火中行走，比喻不避艰险。
注：缣素：细绢和白绢，值钱之物。
注：罄以畀之：全部给他。
注：五鼓：五更。
注：东曦既驾：太阳升起。
注：豕首：猪头。
# 干红猫
题解：孙三以染成红色之猫诈取内侍三百千钱，染色渐褪而露其伪，写骗局之巧。
原：《夷坚支》：临安北门外西巷，有卖熟肉翁孙三者，每出必戒其妻曰：“照管猫儿，都城并无此种，莫使外人闻见；或被窃，绝我命矣！我老无子，此当我子无异也！”日日申言不已。邻里数闻其语，心窃异之，觅一见不得。一日忽拽索出，到门，妻急抱回。见者皆骇，猫干红深色，尾足毛须尽然，无不叹羡。孙三归，痛棰厥妻。已而浸达于内侍之耳，即遣人啖以厚值。孙峻拒。内侍求之甚力，反复数四，竟以钱三百千取去。孙涕泪，复棰其妻，竟日嗟怅。内侍得猫喜极，欲调驯，然后进御。已而色泽渐淡，才及半月，全成白猫。走访孙氏，既陟居矣。盖用染马缨绋之法，积日为伪，前之告戒棰怒，悉奸计也。
注：《夷坚支》：南宋洪迈《夷坚志》支集。
注：临安：南宋都城，今杭州。
注：熟肉翁：卖熟肉的老头。
注：申言：反复说。
注：拽索：用绳牵出。
注：干红：深红。
注：痛棰：重打。
注：内侍：宫中宦官。
注：啖以厚值：以重金诱之。
注：峻拒：严厉拒绝。
注：调驯：调教驯服。
注：进御：进献皇帝。
注：陟居：当作“徙居”，搬走。
注：马缨绋：马饰的缨穗，染色法用于此。
注：奸计：诡计。
# 贷金
题解：士人候选京邸，被骗子装扮的内相所骗，送出百金礼物却一无所得，写骗局的人情陷阱。
原：《耳谭》：嘉靖间，一士人候选京邸。有官矣，然久客橐空，欲贷千金，为所故游客谈。数日，报命曰：“某中贵允尔五百”。士人犹恨少。客曰：“凡贷者，例以厚贽先。内相家性，苟得其欢，何不何？”士人拮据凑贷器币，约值百金。为期入谒。及门，堂轩丽巨，苍头庐儿，皆曳绮缟，两壁米袋充栋，皆有“御用”字。久之，主人出。主人横肥，以两童子头抵背而行。享礼微笑，许贷八百。庐儿曰：“已晚，须明白。”主人曰：“可”。士人既出，喜不自任。客复属耳：“当早至，我俟于此。”明日至，寥然空宅，堂下两堆煤土，皆袋所倾。问主宅者，曰：“昨日内相赁宅半日，知是谁何”客亦失迹，方知中诈。
注：《耳谭》：明王同轨所撰笔记。
注：嘉靖：明世宗年号。
注：候选：等待授官。
注：京邸：京城寓所。
注：橐空：口袋空。
注：贷：借。
注：中贵：有权势的宦官。
注：贽：见面礼。
注：内相：对宦官的称呼。
注：拮据：竭力筹措。
注：苍头庐儿：奴仆，此处指仆役。
注：曳绮缟：穿着绸缎。
注：御用：皇家专用。
注：横肥：体肥。
注：喜不自任：高兴得不能自持。
注：属耳：附耳低语。
注：赁宅：租房。
注：中诈：中了骗局。
# 一钱诓百金
题解：盗贼用一钱雇卖胡床者，诓马主之马，又诓官店段匹，终使有司只能平分马价，写京师骗局之精巧。
原：《湖海奇闻》：胠箧唯京师为最黠。有盗能以一钱诓百金者，作贵游衣冠，先诣马市，呼卖胡床者，与一钱，戒曰：“吾即乘马，尔以胡床侍。”其人许诺。乃谓马主：“吾欲市骏马，试可乃已。”马主谨奉羁靮。其人设胡床而上，盗上马疾驰而去。马主追之。盗径扣官店，维马于门，云：“吾某太监家人，欲段匹若干，以马为质，用则奉价。”店睹其良马，不之疑，如数畀之。负而去。俄而马主迹至店，与之争马，成讼。有司不能决，为平分其马价云。
注：《湖海奇闻》：明代笔记，待考。

注：黠：狡猾。
注：贵游：贵族。
注：马市：买卖马匹的市场。
注：胡床：折叠椅。
注：骏马：良马。
注：羁靮：马络头和缰绳。
注：官店：官设店铺。
注：段匹：布匹，“段”通“缎”。
注：质：抵押。
注：畀：给。
注：有司：官府主管部门。
# 乘驴妇
题解：三妇人雇驴同行，一男子随之，少妇借故使男子送，使他误了其余，三驴皆被窃，写骗局的一环套一环。
原：《耳谭》：有三妇人雇驴骑行，一男子随之。忽少妇下驴择便地，呼二妇曰：“缓行俟我！”方其下驴，男子佐之，少妇即与调谑若相悦者。已乘驴，曰：“我心痛，不能急行。”男子既不欲强少妇，追二妇又不可得，乃憩道旁，而不知少妇反走久矣。是日三驴皆失。
注：《耳谭》：明王同轨所撰笔记。
注：择便地：找个方便的地方。
注：缓行俟我：慢点走等我。
注：佐之：扶助她。
注：调谑：戏谑。
注：憩：休息。
注：反走久矣：已经走了很久。
# 京都道人
题解：道人自称三百岁，却被客人看到其父伛偻老态，揭穿骗局，写假仙术之伪。
原：北宋时，有道人至京都，称得丹砂之妙，颜如弱冠，自言三百馀岁。贵贱咸争慕之，输货求丹、横经请益者，门如市肆。时有朝士数人造其第，饮啜方酣，阍者报曰：“郎君从庄上来，欲参觐。”道士作色叱之。坐客或曰：“贤郎远来，何妨一见？”道士颦蹙移时，乃曰：“但令入来。”俄见一老叟，须发如银，昏耄伛偻，趋前而拜。拜讫，叱入中门，徐谓坐客曰：“小儿愚𫘤，不肯服食丹砂，以至此，都未及百岁，枯槁如斯。常日斥至村墅间耳。”坐客愈更神之。后有人私诘道者亲知，乃云：“伛偻者，即其父也。”

# 丹客
题解：本节两则：写骗子以丹术行骗，让富翁以为损坏了丹而再出钱、嘉靖中松江监生被丹士骗，反被利用，写丹术之骗。

# 《耳谈》二谲僧
题解：本节两段：写奸僧以牛肉丸冒充绝粒活佛、村僧以盐诱牛舔头骗牛，皆以神异骗人。
原：有僧异貌，能绝粒，瓢衲之外，丝粟俱无，坐征商木筏上，旬日不食，不饥。商试之，放其筏中梳，又旬日，亦如此。乃相率礼拜，称为“活佛”，竞相供养。曰：“无用供养。我某山寺头陀，以大殿毁，欲从檀越乞布施，作无量功德。”因出疏，令各占甲乙毕，仍期某月日入寺相见。及期，众往询，寺绝无此僧，殿即毁，亦无乞施者。方与僧骇之，忽见伽蓝貌酷似僧，怀中有簿，即前疏。众诧神异，喜施千金，恐泄语有损功德，戒勿相传。后乃知始塑像时，因僧异貌，遂肖之，作此伎俩。而不食，乃以干牛肉脔大数珠数十颗，暗啖之。皆奸僧所为。
注：绝粒：不吃饭。
注：瓢衲：瓢与衲衣，僧人用品。
注：征商：收税之商。
注：活佛：已证觉悟的佛。
注：头陀：行脚僧。
注：檀越：施主。

# 术制继母

# 制妒妇

# 下马常例
题解：王氏任监官，把吏民所献下马钱锁在柜中，任满后以“寻常既有此例”为理，将柜载走，写以智取利。
原：宋时有世赏官王氏，任浙西一监。初莅任日，吏民献钱物几数百千，仍白曰“下马常例”。王公见之，以为污己，便欲作状，并物申解上司。吏辈祈请再四。乃令取一柜，以物悉纳其中，对众封缄，置于厅治，戒曰：“有一小犯，即发！”由是吏民惊惧，课息俱备。比终任荣归，登舟之次，吏白厅柜。公曰：“寻常既有此例，须有文牍。”吏赍案至，俾舁柜于舟，载之而去。

注：监：监官，监税务或酒务等。
注：莅任：到任。
