# 正文
题解：《雅浪》部总序：冯梦龙论谑浪，主张“雅谑不伤心”，与前《酬嘲》的锋芒相对，开启本部。
原：〔子犹曰：谑浪，人所时有也。过则虐，虐则不堪，是故雅之为贵，雅行不惊俗，雅言不骇耳，雅谑不伤心。何病乎唇弄？何虞乎口戒？何惮乎犁舌地狱？集《雅浪》第二十六。〕
注：子犹曰：子犹，冯梦龙之号。
注：谑浪：戏谑放浪，语出《诗经·邶风·终风》“谑浪笑敖”。
注：雅行不惊俗，雅言不骇耳，雅谑不伤心：冯梦龙自撰之说，主张谐谑以不伤人为尚。
注：唇弄：言语戏弄。
注：口戒：佛教“口业”之戒，戒妄语、绮语。
注：犁舌地狱：佛教传说中的拔舌地狱，犯口业者堕入，被铁犁耕舌。
注：集《雅浪》第二十六：本部为全书第二十六部。
# 千岁
题解：魏王知训陪烈祖曲宴：知训举金觞祝“千岁”，魏王取他器分一半，答“愿与陛下各享五百”，是兄弟间的雅谑。
原：魏王知训陪烈祖曲宴，引金觞赐酒曰：“愿我弟千岁！”魏王引他器匀之，进曰：“愿与陛下各享五百！”
注：魏王知训：杨知训，五代十国时吴国杨行密之子，封魏王，一说“徐知训”，为徐温之子，待考。
注：烈祖：南唐烈祖李昪，原名徐知诰；此条事见《南唐近事》等，所述待考。
注：曲宴：帝王在宫中的私宴。
注：觞：酒杯。
注：匀之：分出一半。
# 舍命陪君子
题解：李东阳“舍命陪君子”：李东阳醉言“舍命陪君子”，郡侯笑称“我不是君子，老先生不要轻生”，反用俗语为谑。
原：李西涯在翰林时，一日陪郡侯席，过饮大觥，醉而言曰：“治生今日舍命陪君子矣！”郡候笑曰：“学生也不是君子，老先生不要轻生。”
注：李西涯：李东阳，号西涯。
注：郡侯：对太守、知府的尊称。
注：觥：大酒杯。
注：治生：自称谦辞，“治下之生”，李东阳官学生时曾自称。
注：舍命陪君子：俗语，意为不顾一切地陪伴朋友。
# 鸡肋
题解：刘伶不与俗人争斗：刘伶醉后被俗人欲殴，答“鸡肋不足以安尊拳”，其人笑而止。
原：刘伶尝因大醉，与俗人忤。其人攘袂奋拳而往。伶徐曰：“鸡肋不足以安尊拳。”其人笑而止。
注：刘伶：西晋“竹林七贤”之一，嗜酒，作《酒德颂》。
注：忤：冲撞、争执。
注：攘袂奋拳：捋起袖子，挥起拳头。
注：鸡肋不足以安尊拳：此事见《世说新语·文学》注及《晋书·刘伶传》，言自己瘦弱，拳头无处可安。
# 父子围棋
题解：王导与长豫围棋：王长豫与父王导下棋，王导欲举子，长豫按住不听，导笑称“相与似有瓜葛”。
原：王长豫幼便和令。丞相爱恣甚笃。每共围棋，丞相欲举行，长豫按指不听。丞相笑曰：“讵得尔？相与似有瓜葛。”
注：王长豫：王悦，字长豫，王导长子，早卒，事见《世说新语·方正》。
注：丞相：王导，东晋宰相。
注：爱恣：宠爱。
注：举行：此处“举行”指起棋子，王导要悔棋。
注：讵得尔：怎能这样。
注：瓜葛：瓜、葛皆蔓生，喻亲戚关系。
# 靳阁老子
题解：靳阁老子：靳贵之子不肖，其孙却登第，阁老督责时被反问“翁父不如我父，翁子不如我子”，笑而止。
原：丹徒靳阁老有子不肖，而其子之子却登第。阁老每督责之。曰：“翁父不如我父，翁子不如我子，我何不肖？”阁老大笑而止。
注：丹徒：今江苏镇江。
注：靳阁老：靳贵，字充道，丹徒人，明武宗朝内阁大学士。
注：不肖：不成器。
注：翁父不如我父：“翁父”指靳贵之父，“翁子”指靳贵之子，称孙辈之父。
# 旱雷
题解：旱雷：谢公送别，有人不悲，左右说“殊密云”，公说“旱雷”，借“有雷无雨”喻其只作声而不流泪。
原：有人别谢公，公流涕，此人不悲。左右云：“向客殊密云。”公曰：“非徒密云，乃是旱雷。”
注：谢公：谢安，东晋宰相，事见《世说新语》，此处待考。
注：密云：《周易·小畜》“密云不雨”，喻有云而不雨。
注：旱雷：干打雷，不下雨，喻哭而无泪。
# 大雷
题解：崔儦谈“大雷”：崔儦说昨夜大雷未醒，卢思道戏问“震雷何以不动蛰”，借《月令》蛰虫惊动之说为谑。
原：北齐崔儦尝谓同座曰：“昨夜大雷，吾睡不觉。”卢思道在坐戏曰：“如此震雷，奈何不能动蛰？”坐间大笑。
注：崔儦：北齐隋之间人，字岐叔，博学善谈，事见《北史·崔儦传》。
注：卢思道：北朝至隋初文学家，字子行，范阳人。
注：蛰：冬眠的虫。《礼记·月令》“雷乃发声，始电，蛰虫咸动”。
# 口欢手怒
题解：口欢手怒：和凝（鲁公）笑声大，杨永符善草书，戏说“口欢”，永符以“手怒”回敬，借“怒”“欢”相对。
原：和鲁公慷慨厚德，每滑稽，则哄堂大笑。时博士杨永符能草圣，有省郎闻鲁公笑声，戏谓杨曰：“丞相口欢。”永符曰：“予忝事笔墨，方挥扫之际，亦谓太博‘手怒’耶？”
注：和鲁公：和凝，字成绩，五代至宋初人，后晋宰相，封鲁国公，善文辞。
注：博士：官名，此指太常博士等。
注：杨永符：待考。
注：草圣：草书高手，后汉张芝号“草圣”。
注：省郎：尚书省郎官。
注：太博：太常博士的省称。
# 小戊子雌甲辰
题解：“小戊子”与“雌甲辰”：程琳戏庞籍为“小戊子”，庞升大拜后程反称“大戊子却为小小戊子”；裴度与庾威以“雌树”“雌甲辰”互谑。
原：程文惠与庞公司同戊子生，程已贵，庞尚为小官。尝戏庞曰：“君乃小戊子也。”庞后大拜。程曰：“今日大戊子却为小小戊子矣！”
注：程文惠：程琳，谥文简，一说程戡；此处“文惠”待考。
注：庞公：庞籍，字醇之，北宋宰相。
注：戊子：同年生人，同为戊子年生。
注：大拜：拜相。
原：或以槐瘿遗裴晋公。郎中庾威在坐，曰：“此是雌树生者。”公偶及年甲，对云：“与公同是甲辰。”公笑曰：“郎中便是雌甲辰。”
注：槐瘿：槐树上的树瘤，可作器。
注：裴晋公：裴度，封晋国公，唐中期宰相。
注：庾威：待考，唐人。
注：甲辰：干支纪年，与公同年。
注：雌树：槐瘿被称“雌”，借以嘲“雌甲辰”。
# 安给事生辰
题解：安给事生辰：安磬避寿，蔡巨源讲“猫呼鼠千岁”的故事，谑他出来领祝寿，安遂出。
原：安给事磐，蜀人，初度避生，同僚尾至所在。蔡巨源戏曰：“闻一老鼠避一瓶中，猫捕之不得，以须略鼠，鼠因喷嚏。猫在外呼曰：‘千岁！’鼠曰：‘汝岂真为我寿？诱我出欲嚼我耳。’”安遂出。
注：安给事磐：安磐，底本作“磐”，，蜀人，待考。
注：初度：生日，《离骚》“皇览揆余于初度兮”。
注：尾至：陆续赶到。
注：蔡巨源：蔡襄之族，待考。
注：略：当作“赚”，诱骗，待考。
注：千岁：祝寿用语。
# 太公年
题解：太公年：苏轼戏说姜太公的年岁，被东方朔减八岁，被宋玉增十岁，一加一减，借典故谑谈。
原：人尝言太公八十遇文王。宋玉楚词又云：“太公九十显荣兮。”东方朔云：“太公体仁行义，七十有二，见用周武。”东坡笑曰：“太公赖东方朔减了八岁，却被宋玉增了十岁。”
注：太公：姜太公吕尚，辅佐周文王、武王。
注：八十遇文王：《史记·齐太公世家》，传说吕尚年八十遇文王。
注：宋玉楚词：宋玉《九辩》，今传“太公九十乃显荣兮，诚未遇其匹合”，此处称“楚词”。
注：东方朔云：东方朔《答客难》，称“太公体仁行义，七十有二，逢文王得行其说”。
注：东坡：苏轼。
# 何次道志勇
题解：何次道志勇：何充礼佛勤，阮裕戏说他“志大宇宙，勇迈千古”，因为阮图郡守尚不得，何竟图“作佛”。
原：何次道往瓦官寺礼拜甚勤。阮思旷语之曰：“卿志大宇宙，勇迈千古。”何曰：“卿今日何故忽见推？”阮曰：“我图数千户郡，尚不能得。卿乃图作佛，不亦大乎？”
注：何次道：何充，字次道，东晋官至尚书令，信佛，事见《世说新语·排调》。
注：瓦官寺：东晋金陵的佛寺。
注：阮思旷：阮裕，字思旷，东晋名士。
注：数千户郡：封邑数千户的大郡。
# 墨磨人
题解：墨磨人：石昌言蓄李廷珪墨不肯磨，人戏言“子不磨墨，墨将磨子”。
原：石昌言蓄李廷珪墨，不许人磨。或戏之曰：“子不磨墨，墨将磨子。”
注：石昌言：石扬休，字昌言，北宋官员，藏墨甚多。
注：李廷珪：南唐制墨名家，其墨极名贵。
# 吃衣著饭
题解：吃衣著饭：杨医官传“食绢衣”为神仙上药，另有“稻席治寒疾”之方，被人嘲为“吃衣著饭”。
原：杨医官传“食绢衣”，为神仙上药。又一方，有寒疾者，盖稻席当愈。或嘲之曰：“君吃衣著饭，大是奇方。”
注：杨医官：待考。
注：绢衣：绢制的衣服。
注：稻席：稻草席子。
注：寒疾：因寒所致的疾病。
注：著饭：吃饭，“著”读如“着”，“穿衣吃饭”之意。
# 玄龄不死
题解：玄龄不死：裴玄本戏言房玄龄病甚“何须问”，后探病，玄龄笑说“裴郎中来，玄龄不死也”。
原：裴玄本好谐谈。为户部郎中时，左仆射房玄龄疾甚。省郎将问疾，玄本戏曰：“仆射病可，须问之；既甚矣，何须问也？”有泄其言者，既而随例看玄龄。玄龄笑曰：“裴郎中来，玄龄不死也！”
注：裴玄本：唐初人，官至司勋郎中，善谐谑，事见《朝野佥载》。
注：户部郎中：户部属官，尚书省六部分司。
注：房玄龄：唐初宰相，与杜如晦并称“房杜”。
注：省郎：尚书省郎官。
# 死后佳
题解：死后佳：叶衡罢相病中问客“死后佳否”，士人以“使死而不佳，死者皆逃归矣”答之，使满座皆笑。
原：叶衡罢相归。一日病，问诸客曰：“某且死，但未知死后佳否？”一士人曰：“甚佳。”叶惊问曰：“何以知之？”士人曰：“使死而不佳，死者皆逃归矣。一死不返，以是知其佳也。”满座皆笑。
注：叶衡：字梦锡，南宋孝宗朝右丞相，金华人。
注：罢相：罢去宰相职位。
# 大八字
题解：大八字：有人以星术（算命）见王世贞，客争问吉凶，世贞说自己明白“大八字”——人人都要死。
原：有以星术见王元美者。座客争扣吉凶。元美曰：“吾自晓‘大八字’，不用若算。”问：“何为大八字？”曰：“我知人人都是要死的。”
注：星术：以星象、生辰推算命运之术。
注：王元美：王世贞，字元美，号凤洲，明代文学家，“后七子”之一。
注：大八字：相对于“生辰八字”而说，戏言人人皆死。
# 娵隅
题解：娵隅：郝隆在桓温幕作诗罚酒，以“娵隅跃清池”答，借“蛮语”自嘲官职卑下。
原：郝隆为桓公南蛮参军。三月三日，会作诗，不能者罚酒三升。隆既受罚，揽笔便作一句云：“娵隅跃清池。”桓问：“娵隅是何物？”隆曰：“蛮名鱼为娵隅。”又问：“作诗何用蛮语？”隆曰：“千里投公，始得蛮府参军，那得不作蛮语？”
注：郝隆：字佐治，东晋官员，事见《世说新语·排调》。
注：桓公：桓温，东晋权臣。
注：南蛮参军：桓温任南蛮校尉，郝隆为其参军。
注：三月三日：上巳节，修禊之日，文人作诗饮酒。
注：娵隅：鱼名，“蛮语”称鱼为“娵隅”，《世说新语》作“娵隅跃清池”。
# 鲶鱼上竹竿
题解：鲶鱼上竹竿：梅尧臣晚年修《唐书》，说“猢狲入布袋”，其妻刁氏说“还是鲶鱼上竹竿”，借俗语自嘲。
原：梅圣俞以诗知名三十年，终不得一馆职。晚年预修《唐书》，语其妻刁氏曰：“吾之修书，可谓猢狲入布袋矣。”刁曰：“还是鲶鱼上竹竿。”
注：梅圣俞：梅尧臣，字圣俞，北宋诗人，开宋诗风气。
注：馆职：馆阁官职，如集贤院学士。
注：《唐书》：即《新唐书》，宋祁、欧阳修等修。
注：猢狲入布袋：俗语，意为不得自由。
注：鲶鱼上竹竿：俗语，意为滑溜难上，形容难受。
注：刁氏：梅尧臣继室刁氏，刁约之妹。
# 枝头干
题解：枝头干：晁补之说苏辙“除不离核”，张耒（张文翰）答“岂不胜汝枝头干乎”，借荔枝之喻谑“枝头干”。
原：元祐初，用治平故事，令大臣荐士试馆职。一时名士在馆者，率论资考次迁，未有越次进用者。张文翰、晁无咎俱在其间。一日，二人阅朝报，见苏子由自中书舍人除户部侍郎，无咎以为平缓，曰：“子由除不离核。”谓如果之粘核者。张曰：“岂不胜汝枝头干乎？”
注：元祐：宋哲宗年号。
注：治平：宋英宗年号（1064—1067）。
注：馆职：馆阁官职。
注：张文翰：当作张文潜，张耒。
注：晁无咎：晁补之，字无咎，苏门四学士之一。
注：朝报：官府颁布的政事公告，即邸报。
注：苏子由：苏辙，字子由。
注：中书舍人：中书省官员，起草诏令。
注：除：授官。
注：不离核：荔枝类果实，肉粘核，借喻升迁不离原职。
注：枝头干：果实留在枝头，枯干，喻晁补之仍在原位。
# 梓州郪县
题解：梓州郪县：李镇恶授梓州郪县令，在信中戏说“州带子号，县带妻名”，只有儿媳的官职，不属老夫。
原：唐李镇恶谒选，授梓州郪县令。与友人书云：“州带子号，县带妻名。由来不属老夫，并是儿妇官职。”
注：谒选：到吏部候选授官。
注：梓州：今四川三台一带。
注：郪县：今四川三台县，“郪”从“妻”，故说“带妻名”。
注：州带子号：“梓”字带“子”。
注：老夫：自称。
# 孙少卿
题解：孙少卿：北魏孙绍年老始拜太府少卿，灵太后说“年太老”，答“臣年虽老，臣卿太少”，指官职之少，后笑“是将正卿”。
原：北魏孙绍历职内外，垂老始拜太府少卿。谢日，灵太后曰：“公年似太老。”绍拜曰：“臣年虽老，臣卿太少。”后笑曰：“是将正卿。”
注：孙绍：北魏官员，博学，官至太府少卿，事见《魏书·孙绍传》。
注：太府少卿：太府寺副长官，掌财货。
注：谢日：谢恩之日。
注：灵太后：北魏孝明帝之母胡太后。
注：正卿：九卿之正职，指太府卿。
# 唐、宋二宗雅谑
题解：唐、宋二宗雅谑：裴休游曲江，与教坊黄衣者以“喏，即不敢”互相戏答，后拜相仍以此语书制；寇准留客，李宗谔被赐酒，皇帝令“不须从门扉下出”。
原：曲江池，本唐开元中疏凿为胜境，南即紫云楼、芙蓉院，西即杏园、慈恩寺，花卉环周，烟火明媚。都人游赏，盛于中和、上巳节。即赐宴臣僚会于山亭，赐太常教坊乐，池备彩舟，唯宰相、三使、北省官、翰林学士登焉。倾动皇州，以为盛观。裴休廉察宣城，未离京，值曲江池荷花盛发，同省阁名士游宴。自慈恩寺屏左右，随以小仆，步至紫云楼，见教坊人坐于水滨，裴与朝士憩其傍。中有黄衣，半酣，轩昂自若，指诸人笑语轻脱。裴意稍不平，揖而问曰：“贤所任何官？” 率尔对曰：“喏，即不敢，新授宣州广德令。”反问裴曰：“押衙所任何职？”裴效之曰：“喏，即不敢，新授宣州观察使。”于是狼狈而步，同座亦皆奔散，朝士抚掌大笑。不数日，布于京华。后于铨司房之，云有广德令请换罗江。宣皇在藩邸，闻是说，与诸王每为戏谈。其后龙飞，裴入相，因书麻制，谓枢近曰：“喏，即不敢，新授中书门下平章事矣。”
注：曲江池：唐代长安著名游览胜地，在今西安曲江。
注：开元：唐玄宗年号。
注：紫云楼、芙蓉院：曲江池畔的建筑。
注：杏园、慈恩寺：曲江边的名胜，进士及第后宴于杏园，慈恩寺有大雁塔。
注：中和、上巳节：二月初一中和节，三月三日上巳节，均为游赏时节。
注：太常教坊乐：太常寺和教坊所属乐伎。
注：三使：指盐铁、度支、户部三使。
注：北省官：中书、门下省官员。
注：盛观：盛大景象。
注：裴休：唐宣宗朝宰相，字公美，信佛。
注：廉察：观察使的别称，宣城即宣州。
注：省阁：尚书省、中书省、门下省。
注：黄衣：黄色衣服，此指教坊乐人。
注：轻脱：轻佻。
注：宣州广德令：广德，今安徽广德，宣州属县。
注：押衙：藩镇节度使属官，亦指仪仗官。
注：观察使：唐代州一级监察、统兵长官，高于县令。
注：铨司：吏部选官的机构。
注：罗江：今四川德阳罗江，县名，与广德同级。
注：宣皇：唐宣宗李忱，即位前为光王，居藩邸。
注：龙飞：即位。
注：书麻制：用黄白麻纸书写任命状。
注：枢近：枢密近臣。
注：中书门下平章事：唐代宰相的正式官衔。
原：寇准在中书，每召两制就第饮宴，必闭关苛留之。李宗谔尝于门扉不出走。后为修宫使，恩顾渐深。一日召至玉宸殿赐酒，宗谔坚辞以醉，且云“日暮”。上令中使附耳语云：“此中不须从门扉下出。”

注：苛留：强留。

注：中使：宫中派出的宦官。

# 高晋陵
题解：高晋陵：高爽往谒刘蒨不被礼遇，后代刘蒨为县，刘蒨致送甚厚，爽署书“高晋陵”，说“刘自饷晋陵令耳，何关爽事”。
原：高爽尝经晋陵，诣刘蒨，了不相接。高甚衔之。俄爽代蒨为县，蒨迎赠甚厚。爽受饷，答书署“高晋陵”。人问其故。爽曰：“刘自饷晋陵令耳，何关爽事？”
注：高爽：字晖远，北魏人，官至吏部郎中，著文集，事见《魏书·高爽传》，条中人物或不同，待考。
注：晋陵：今江苏常州，古称晋陵。
注：刘蒨：待考。
注：饷：赠送。
# 鲁直律语
题解：鲁直律语：黄庭坚为礼部试官，有人送柳枝，法官说“漏泄春光有柳条”，鲁直接“榆条准此”，用律文“馀条准此”谑。
原：黄鲁直为礼部试官。或以柳枝来，有法官曰：“漏泄春光有柳条。”鲁直曰：“榆条准此。”盖律语有“馀条准此”也。一坐大噱。
注：黄鲁直：黄庭坚，字鲁直，号山谷。
注：礼部试官：礼部试（省试）的考官。
注：漏泄春光有柳条：《唐律》“漏泄大事”语，并用王安石“漏泄春光有柳条”诗，此处借喻，待考。
注：馀条准此：律文常用语，意为其他条款依照此例。
注：大噱：大笑。
# 如厕谑
题解：如厕谑：彭彦实与陈方洲在文渊阁东如厕相遇；唐时一丞内急，借大优穆刁绫宅，优人谑之“侍郎他日内逼，再请光访”。
原：彭彦实一日往文渊阁东如厕，值少保陈方洲公亦来，却立。公疾行而过，笑曰：“以缓急为序。”他日公如厕，周赞善尧佐先在内。公戏曰：“人生何处不相逢。”
注：彭彦实：彭时，字彦修，一说彭彦实，明代官员，待考。
注：文渊阁：明代内阁办公处，在紫禁城。
注：陈方洲：陈循，号芳洲，明景泰朝首辅，一说陈方洲，待考。
注：周赞善尧佐：周尧佐，待考。赞善，太子东宫官。
注：人生何处不相逢：俗语。
原：唐时一丞，偶因马上内逼急，诣大优穆刁绫宅。已登溷轩，而忧适至。丞惭谢之。优曰：“侍郎他日内逼，再请光访。”
注：内逼：内急，想大小便。
注：大优：优伶之首。
注：穆刁绫：唐代教坊乐人，待考。
注：溷轩：厕所。
注：侍郎：官名，此处称丞为“侍郎”，戏谑。
# 目送美姝
题解：目送美姝：王翱不喜谈谐，见大臣目送美女，戏言“此姝甚有力”，因“公头何以掣转”。
原：王忠肃公不喜谈谐。一日朝退，见一大臣目送美姝，复回顾之。忠肃戏云：“此姝甚有力！”大臣曰：“先生何以知之？”王应曰：“不然，公头何以掣转？”
注：王忠肃公：王翱，字九皋，谥忠肃，明英宗朝吏部尚书，以清廉著称。
注：美姝：美女。
注：掣转：扭转。
# 西施山
题解：西施山：袁宏道与陶望龄游西施山，陶诗句“宿几夜娇歌艳舞之山”，袁戏言此诗需注明，否则谥“文恪”不得。
原：西施教歌舞之地，名西施山。袁宏道与陶望龄同游。陶诗云：“宿几夜娇歌艳舞之山。”袁曰：“此诗当注明。不然，累君他日谥‘文恪公’不得。”
注：西施山：浙江绍兴的山，传说为西施学歌舞处，一说在诸暨。
注：袁宏道：字中郎，号石公，“公安派”领袖。
注：陶望龄：字周望，号石篑，明万历进士，官至国子监祭酒，卒谥文简；“文恪”为谐戏，言其谥号。
注：累：连累。
# 《锺馗图》
题解：《钟馗图》：刘廷美有《钟馗图》，求刘原博题诗，元旦悬于中堂，贺客先书名，朝士见诗各取簿叶抄录，中书金本清戏称“耗纸鬼”。
原：刘廷美有《锺馗图》，求刘原博题诗于上，元旦悬之中堂。京顺节日主人皆出贺，唯置白纸簿并笔砚于几；贺客至，书其名。是日朝士至者，见诗，各摘簿一叶录之而去。顷间簿已尽矣。明日复置一簿，亦如之。中书金本清戏曰：“此锺馗乃耗纸鬼也。”
注：刘廷美：待考，明代人。
注：刘原博：刘定之，字主静，一说刘原博，待考。
注：锺馗：传说中打鬼的神，唐代即有《钟馗图》，除夕悬挂，辟邪驱鬼。
注：白纸簿：登记宾客姓名的簿子。
注：中书金本清：金本清，中书舍人，待考。
注：耗纸鬼：“耗”谐“好”，鬼耗物，“钟馗捉鬼”，此谑为“耗纸鬼”。
# 梅河豚
题解：梅河豚：梅尧臣《河豚诗》盛传，刘原甫戏称“梅河豚”，比“郑鹧鸪”。
原：梅圣俞有《河豚诗》：“春洲生荻芽，春岸飞扬花。河豚于此时，贵不数鱼虾。”时盛传之。刘原甫戏曰：“郑都有鹧鸪诗，人称郑鹧鸪。圣俞有河豚诗，当呼梅河豚矣。”
注：河豚诗：梅尧臣《范饶州坐中客语食河豚鱼》，“春洲生荻芽，春岸飞扬花”。
注：荻芽：芦荻嫩芽，河豚春季产卵。
注：扬花：柳絮。
注：刘原甫：刘敞，字原父，亦作原甫。
注：郑都：郑谷，唐末诗人，因《鹧鸪》诗得名“郑鹧鸪”，官都官郎中，故称“郑都官”。
# 银花合
题解：银花合：张昌龄戏苏味道，以“银花合”为其诗佳处，苏回敬“还有金铜钉”，指张诗中“丁令威”。
原：张昌龄、苏味道俱有诗名。一日昌龄曰：“某诗所以不及相公者，为无‘银花合’也。苏有《观灯》诗‘火树银花合，星桥铁锁开”之句。苏曰：“公虽无‘银花合’，还有‘金铜钉’。”张有《赠张昌宗》诗曰：“昔日浮丘伯，今同丁令威。”故云。相与抚掌。
注：张昌龄：初唐诗人，与苏味道同时，此处与张昌宗相混，待考。
注：苏味道：字守真，武周宰相，“苏模棱”，有《正月十五夜》诗。
注：银花合：苏味道《正月十五夜》“火树银花合，星桥铁锁开”。
注：浮丘伯：传说中的仙人，王子乔之师。
注：丁令威：传说中化鹤归来的仙人，名辽东丁令威，见《搜神后记》。
注：金铜钉：谐“丁”字，苏味道借“丁令威”，戏称张诗“有金铜钉”。
# 黄鹂自古少
题解：黄鹂自古少：熊眉愚与江菉萝同官棘寺，江叹黄鹂少，熊引杜诗“两个黄鹂鸣翠柳”答。
原：熊眉愚与江菉萝同官棘寺。一日江曰：“此中不乏佳树，惜黄鹂甚少。”熊曰：“黄鹂自古少也。”江问：“何以见之？”熊曰：“杜诗云：‘两个黄鹂鸣翠柳’，那得多？”
注：熊眉愚：待考。
注：江菉萝：待考。
注：棘寺：大理寺的别称，“棘”指九棘，古代朝廷判案处。
注：两个黄鹂鸣翠柳：杜甫《绝句》“两个黄鹂鸣翠柳，一行白鹭上青天”。
# 杜宗武
题解：杜宗武：杜宗武以诗示阮兵曹，阮以石斧还之，宗武曰“斧，父斤也”，阮闻说他误，认为是砍断其手。
原：杜甫子宗武以诗示阮兵曹，答以石斧一具，并诗还之。宗武曰：“斧，父斤也。使我呈父加斤削也。”阮闻之曰：“误矣！欲子斫断其手。此手若存，天下诗名又在杜家矣。”
注：杜甫子宗武：杜宗武，杜甫次子，小名骥子。
注：阮兵曹：待考，兵曹参军。
注：石斧：石头斧头，谐“斧正”。
注：斧，父斤也：“斧”字拆“父”“斤”，“斤削”意为“指正”。
# 不廉
题解：不廉：沈约戏朱异“何乃不廉”，因天下文义棋书，被一人尽占，“不廉”乃指“不廉让”，是雅谑。
原：沈约戏朱异曰：“卿年少，何乃不廉？”异逡巡未达其旨。约乃曰：“天下唯有文义棋书，卿一时将去，安得称廉？”
注：沈约：南朝梁文学家、史学家，字休文，著《宋书》。
注：朱异：字彦和，南朝梁官员，博学，精棋，官至中领军。
注：逡巡：徘徊迟疑。
注：文义棋书：朱异兼擅文章、经义、围棋、书法。
# 梦仙诗
题解：梦仙诗：王安石笑“梦仙诗”不识字，不勘自招，毅夫说用李白诗句，王又笑“自首减等”，借律语相谑。
原：王介甫尝见送毅夫《梦仙》诗云：“授我碧简书，奇篆幡凡砂。读之不可识，翻身凌紫霞。”大笑曰：“此人不识字，不勘自招。”毅夫曰：“不然，吾用李太白诗句耳。”王又笑曰：“自首减等。”
注：王介甫：王安石，字介甫。
注：毅夫：杨绘字元素；一说“毅夫”为郑獬字，北宋官员，待考。
注：碧简书：道教仙书。
注：奇篆：奇异的篆字，指道家符篆。
注：幡凡砂：当作“蟠凡砂”或“翻凡砂”，待考。
注：不勘自招：不经审问自己招认，喻不识字之说。
注：自首减等：律文，犯人自首可以减刑。
# 《文选》
题解：《文选》：张凤翼刻《文选纂注》，士夫诘“既云《文选》，何故有诗”，张答“昭明太子著作，于仆何与”，一问一答成笑话。
原：张凤翼刻《文选纂注》。一士夫诘之曰。“既云《文选》，何故有诗？”张曰：“昭明太子著作，于仆何与？”曰：“昭明太子安在？”张曰：“已死。”曰：“既死，不必究他。”张曰：“便不死，亦难究。”曰：“何故？”张答曰：“他读得书多。”
注：张凤翼：字伯起，号灵墟，明代戏曲家、藏书家，长洲人。
注：《文选纂注》：张凤翼辑《文选纂注》十二卷，明刊本。
注：士夫：士大夫。
注：昭明太子：萧统，南朝梁，主编《文选》。
# 徒以上罪
题解：徒以上罪：欧阳修行酒令，须作犯“徒以上罪”的诗句，别人举盗劫之例，他举“酒粘衫袖重，花压帽檐偏”，答“当此时，徒以上罪亦做了”。
原：欧阳公与人行令，作诗两句，须犯徒以上罪者。一云：“持刀哄寡妇，下海劫人船。”一云：“月黑杀人夜，风高放火天。”欧云：“酒粘衫袖重，花压帽檐偏。”或问之。答曰：“当此时，徒以上罪亦做了。”
注：行令：行酒令。
注：徒以上罪：古代五刑笞、杖、徒、流、死，“徒”为服劳役之刑，“徒以上”指较重之罪。
注：酒粘衫袖重，花压帽檐偏：欧阳修《渔家傲》之类的句子，此处似自作，待考。
# 待汤
题解：待汤：李东阳在京邸宴请同乡会试者，说“东面而征西夷怨”，戏说“侍汤”，借《孟子》“后我”谐“候汤”。
原：李西涯在京邸，款同乡会试。酒数行，诸君告起，欲卦他席。公曰：“且住，有一题商之：‘东面而征西夷怨’二句，诸君安知所以然乎？”众默然。公笑曰：“无他意，只是‘侍汤’。”
注：京邸：京城邸舍。
注：款：宴请。
注：会试：三年一次，在京城举行的全国考试。
注：东面而征西夷怨：《孟子·梁惠王下》“东面而征，西夷怨；南面而征，北狄怨，曰：‘奚为后我？’”。
注：侍汤：“待汤”，等候热水，意为让客人喝茶散席。
# 制馄饨法
题解：制馄饨法：乔仲山家馄饨制得好，常被宾朋索食，便在每位客人前放一帖，食毕展看，乃是制法，众人大笑而不再来索。
原：乔仲山家制馄饨得法，常苦宾朋索食。一日，于每客前先置一帖，且戒云：“食毕展卷。”既而取视，乃置造方也，大笑而散。自后无复索者。
注：乔仲山：待考。
注：馄饨：面制的食品，包馅煮食，今称馄饨。
注：置造方：制作的配方。
# 李康靖柬
题解：李康靖柬：李若谷同韩亿游汝州，太守每设猪肉款待韩，李在信中说“久思肉味”，戏请韩早来。
原：韩忠献亿、李康靖若谷同游至汝州。太守赵学士请康靖为门客，尤敬待韩，每至，即设猪肉。康靖尝柬韩云：“久思肉味，请兄早访。”
注：韩忠献亿：韩亿，字宗魏，北宋官员，谥忠献；此处“忠献”疑为“忠宪”，待考。
注：李康靖若谷：李若谷，字子渊，北宋官员，谥康靖，曾官参知政事。
注：汝州：今河南汝州。
注：赵学士：待考。
注：柬：书信。
# 海蜇
题解：海蜇：王敏道食海蜇，说为何嗜它“一晌而已”，意为不耐咀嚼，片刻即无。
原：王敏道食海蜇，曰：“人何苦嗜之哉？一晌而已。”
注：王敏道：待考，宋人。
注：海蜇：海洋腔肠动物，可食用，口感脆。
注：一晌：一会儿，片刻。
# 春菜诗
题解：春菜诗：黄庭坚和东坡《春菜》诗，劝其归，苏轼戏说“以苦笋硬差致仕”，说他强令辞官。
原：黄鲁直尝和东坡《春菜》诗云：“公如端为苦笋归，明日春衫诚可脱。”苏戏语客云：“吾固不爱做官，鲁直遂欲以苦笋硬差致仕。”
注：黄鲁直：黄庭坚。
注：春菜：苏轼《春菜》诗，今传，称“春日荠菜”。
注：苦笋：苦味笋，黄庭坚《苦笋赋》。
注：春衫诚可脱：言可脱去官服。
注：致仕：退休辞官。
# 错著水、为甚酥
题解：错著水、为甚酥：东坡在黄州，赴何秀才宴食油果，问其名答无名，问“为甚酥”，坐客说可作名；又以“错着水”戏酒味淡。
原：东坡在黄州时，尝赴何秀才会，食油果甚酥，因向主人：“此名为何？”主人对以无名。东坡又问：“为甚酥？”坐客皆曰：“是可以为名矣！”又潘长官以东坡不能饮，每为设醴。坡笑曰：“此必错著水也。”他日忽思油果，作小诗以求之，云：“野饮花前百事无，腰间唯系一葫芦。已倾潘子错著水，更觅君家为甚酥。”
注：黄州：今湖北黄冈，苏轼谪居之地。
注：油果：油炸的面食。
注：酥：酥脆。
注：潘长官：潘大临之族，一说潘丙，苏轼在黄州之友。
注：醴：甜酒。
注：错著水：酒中错掺了水，指酒淡。
注：野饮：郊野饮酒。
注：葫芦：酒葫芦。
# 伐冢
题解：伐冢：苏辙执政，苏轼在翰林，故人求差遣，苏轼讲盗墓贼遇杨王孙、汉文帝、伯夷的故事，以隐喻所求无所获，故人笑去。
原：子由秉政，子瞻在翰苑。有故人欲干子由，因见子瞻，求其转言，冀得差遣。公徐曰：“旧闻一人贫甚，无以为生，乃谋伐冢，遂破一墓，见一人裸体而坐，曰：‘我杨王孙也，无物济汝。’复凿一冢，用力颇艰，既入，见一王者，曰：‘我汉之文帝，遗制圹中无纳金玉，器皆陶瓦，汝可速出。’复二冢相连，乃先穿其左者，久之方透，见一人羸瘠而有饥色，曰：‘我伯夷也，饿死首阳，安得应汝之求？’其人叹曰：‘用力勤矣，竟无所获，不若更穿西冢，庶几有得。’羸瘠者谓曰：“劝汝别谋于他所。汝视我形骸如此，舍弟叔齐岂能为人也’。”故人大笑而去。
注：子由：苏辙，字子由。
注：秉政：执政。
注：子瞻：苏轼，字子瞻。

# 破僧戒

# 唐明皇骷髅
题解：唐明皇骷髅：安氏家藏唐明皇骷髅，后析居争之，斧为数片；张耒说“明皇生死为姓安人极恼”，又以“贾生过秦”戏秦观。
原：长安有安氏，家藏唐明皇骷髅，作紫金色，其家事之甚谨，因尔家富达，遂为盛族。后其家析居，争骷髅，斧为数片。张文潜闻之，即语曰：“明皇生死为姓安人极恼。”合坐大笑。时秦少游方为贾御史弹不当授馆职，文潜戏少游曰：“千馀年前贾生过秦，今复尔也。”闻者以为佳谑。
注：唐明皇：唐玄宗。骷髅：头骨。
注：紫金色：紫红色的金色。
注：析居：分家。
注：张文潜：张耒。
注：安：“安禄山”“姓安”，唐玄宗被“安”所恼。
注：贾御史：贾易，北宋御史，弹劾秦观。
注：秦少游：秦观，字少游。

# 猫五德
题解：猫五德：僧彬师以猫比鸡之五德，“仁义礼智信”，每条皆指猫的不当行为，成谐谑。
原：万寿僧彬师尝对客，猫踞其旁。谓客曰：“人言鸡有五德，此猫亦有之。见鼠不捕，仁也；鼠夺其食而让之，义也；客至设馔则出，礼也，藏物甚密而能窃食，智也；每冬月辄入灶、信也。”

注：灶：猫冬天爱钻灶旁取暖。
# 《阿房宫赋》两句
题解：《阿房宫赋》两句：苏轼读杜牧《阿房宫赋》数遍，老兵不解，只喜“天下之人不敢言而敢怒”，苏轼笑称“这汉子也有鉴识”。
原：东坡在玉堂，一日读《阿房宫赋》，凡数遍，每一遍讫，即再三赏叹，至夜分犹不寐。有二老兵给事左右，坐久，甚苦之。一人长叹曰：“知他有甚好处，夜久寒甚不肯睡，连作冤苦声。”其一人曰：“也有两句好。”先一人怒曰：“你又理会得甚的？”曰：“我爱他道‘天下之人不敢言而敢怒’。”叔觉卧而闻之，明日以告东坡。东坡笑曰：“这汉子也有鉴识！”
注：玉堂：翰林院的美称。
注：阿房宫赋：杜牧作，借秦亡以讽唐朝。
注：夜分：夜半。
注：老兵：老卒。
注：理会：懂、明白。
注：不敢言而敢怒：《阿房宫赋》句。
注：叔觉：苏轼家仆，待考。
注：鉴识：鉴别能力。
# 天下极贱人

# 马湘兰
题解：马湘兰：名妓马湘兰拒见监生举人，后其中进士，授礼部主事，拘之，湘兰回应“唯其有昔日之虚名，所以有今日奇祸”；其死后哀挽成帙，张官王仿《赤壁赋》作祭文，闻者绝倒。
原：金陵名妓马湘兰，以豪侠得名。有坐监举人请见，拒之。后中甲榜，授礼部主事。适有讼湘兰者，主事命拘之。众为居间，不听。既来见，骂曰：“人言马湘兰，徒虚名耳！”湘兰应曰：“唯其有昔日之虚名，所以有今日奇祸。”主事笑而释之。湘兰死后，哀挽成帙。或谓张官王曰：“闻君有祭文甚佳。”张曰：“吾乃仿《赤壁赋》作者。”使诵之。张但举一语云：“此固一世之雌也，而今安在哉！”闻者绝倒。
注：马湘兰：马守真，字月娇，号湘兰，明代南京名妓，善画兰，有才名，卒于万历。
注：豪侠：慷慨好义。
注：坐监：在国子监读书的监生。
注：甲榜：进士榜。
注：礼部主事：礼部属官。
注：居间：从中说合。
注：哀挽：挽诗、挽联。
注：张官王：待考。
注：赤壁赋：苏轼名作。
注：一世之雌：苏轼《赤壁赋》“此非孟德之困于周郎者乎……固一世之雄也，而今安在哉”，此处改“雄”为“雌”。
