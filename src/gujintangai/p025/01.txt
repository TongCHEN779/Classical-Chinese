# 正文
题解：《塞语》部总序：冯梦龙论言语可以止言，真正聪明者能以一语堵住他人之舌，并开启本部。
原：〔子犹曰：天下之事，从言生，还可从言止。不见夫射者乎？一夫穿杨，百夫挂弓。何则？为无复也。心心喙喙，人尽南越王自为耳。不得真正大聪明人，胸如镜，口如江，关天下之舌，而予之以不然，隙穴漏卮，岂其有窒！若夫理外设奇，厄人于险，此营丘士之智也，吾无患焉。集《塞语》第二十五。〕
注：子犹曰：子犹，冯梦龙之号。
注：一夫穿杨，百夫挂弓：典出养由基百步穿杨，百人皆放弃射箭，喻一人技高，众人不再争。
注：心心喙喙：人人各有主张，各自争辩。喙，口。
注：南越王自为耳：南越王赵佗自称帝，事见《史记·南越列传》，喻各自为主。
注：胸如镜，口如江：胸中明澈如镜，口才如江水滔滔。
注：隙穴漏卮：漏洞与漏杯，喻言语的破绽。卮，酒器。
注：营丘士：营丘为齐国初都，此指齐地之人；《战国策》载营丘士之说，此处指设奇厄人者，待考。
注：集《塞语》第二十五：本部为全书第二十五部，“塞”谓以言堵人之口。
# 祠灵山河伯
题解：晏子止祠灵山河伯：齐景公大旱欲祭灵山、河伯，晏子以山、河同样盼雨为由劝止，是《塞语》部之首。
原：齐大旱，景公欲祠灵山。晏子曰：“不可。夫灵山，以石为身，以草木为发。天久不雨，发将焦，身将热，彼独不欲雨乎？祠之何益？”公曰：“祠河伯可乎？”晏子曰：“不可。河伯以水为国，以鱼鳖为民。天久不雨，百川竭，国将亡，民将灭矣，彼独不雨乎？祠之何益？”
注：景公：齐景公。
注：祠：祭祀。
注：灵山：山名，《晏子春秋》所记，具体位置待考。
注：河伯：黄河之神。
注：晏子：晏婴。
注：鱼鳖为民：以鱼鳖为百姓。
# 骆猾牦好勇
题解：墨子辨“好勇”：骆猾牦称好勇而杀勇士，墨子指出是“恶勇”，因其好恶相违。
原：墨子谓骆猾牦曰：“吾闻子好勇。”曰：“然。吾闻其乡有勇士焉，吾必与斗而杀之。”墨子曰：“天下莫不予其所好，夺其所恶。今子闻其乡有勇士，而斗而杀之，是恶勇，非好勇。”
注：墨子：墨翟，战国初墨家创始人。
注：骆猾牦：墨子弟子禽滑釐，字滑釐，《墨子》作“禽滑釐”，此处作“骆猾牦”，疑为异写，见《墨子·耕柱》。
注：予其所好，夺其所恶：给予其所喜好，除去其所憎恶。
# 弹雀
题解：宋艺祖弹雀：宋太祖弹雀，臣僚称有急事，实乃常事，被问“何急”，答“亦急于弹雀”，劝谏之语。
原：宋艺祖一旦后苑挟弓弹雀。有臣僚称其急事请见。及见，乃常事。帝曰：“此事何急？”对曰：“亦急于弹雀。”
注：艺祖：宋太祖赵匡胤。
注：后苑：宫内后花园。
注：挟弓弹雀：拿弓射雀；此事见《渑水燕谈录》等。
# 禁酿具
题解：简雍禁酿具：刘备禁酒，搜得酿具即议罚，简雍指路人“有淫具”，谏止其苛。
原：蜀先主尝因旱俭禁酿酒。吏于人家检得酿具，以其欲酿，将议罚。时简雍从先主游，见一男女行道，谓先主曰：“彼人欲行淫，何以不缚？”先主曰：“何以知之？”雍曰：“彼有淫具。”先主大笑，命原欲酿者。
注：先主：蜀先主刘备。
注：旱俭：旱灾歉收。
注：酿具：酿酒的器具。
注：简雍：字宪和，刘备同乡，随之左右，滑稽善辩，事见《三国志·蜀书·简雍传》。
注：淫具：指男女生殖器官，雍以此喻持酿具者未必酿酒，谏止刘备。
注：原：宽宥。
# 禁松薪
题解：张廷范以“月明”嘲禁松薪：李茂贞为军费榷油、禁松薪，优人张廷范说“不如并月明禁之”，茂贞笑而止。
原：唐昭宗时，李茂贞榷油以助军资，因禁松薪。优人张廷范曰：“不如并月明禁之。”茂贞笑而驰禁。
注：唐昭宗：唐末皇帝李晔。
注：李茂贞：唐末凤翔节度使，封岐王。
注：榷油：专卖油，榷，专利。
注：松薪：松木柴，可用于点灯。
注：张廷范：唐末伶人，后任太常卿，后被朱全忠所杀，事见《新五代史》。
注：月明：月光亦可照明，以此讽禁松薪之荒谬。
注：驰禁：解除禁令。
# 《陶母剪发图》
题解：岳柱诘《陶母剪发图》：元岳柱八岁，诘画师何澄“有金钏可易酒，何用剪发”，画师大惭而改。
原：元岳柱八岁时，观画师何澄画《陶母剪发图》，指陶母手中金钏诘之曰：“有此可易酒，何用剪发？”何大惭，即易之。
注：岳柱：元代画家，字止所，蒙古人，善画竹石。
注：何澄：元代画家，字清夫，燕人，善画山水人物。
注：陶母剪发：陶侃之母湛氏剪发换酒肉招待客人范逵，见《晋书·列女传》。
注：金钏：金镯子。
# 新衣
题解：桓冲不好新衣：桓冲嫌新衣，妻故送新衣，桓怒；妻答“衣不经新，何由而故”，桓遂笑而着之。
原：桓冲不好新衣。浴后，妇故送新衣与。冲怒，催使持去。妇更持还，传语云：“衣不经新，何由而故？”桓笑著之。
注：桓冲：字幼子，东晋桓温之弟，官至车骑将军，事见《世说新语·规箴》。
注：浴后：沐浴之后。
注：衣不经新，何由而故：衣服不先新，怎么能旧。
# 彭祖面长
题解：东方朔笑彭祖面长：汉武帝说人中长一寸年百岁，东方朔大笑，称“彭祖面长”，指出此说荒谬。
原：汉武帝对群臣云：“相书云：鼻下人中长一寸年百岁。”东方朔大笑。有司奏不敬。朔免冠云：“不敢笑陛下，实笑彭祖面长。”帝问之。朔曰：“彭祖年八百。果如陛下言，则彭祖人中长八寸，面长一丈馀矣。”帝亦大笑。
注：相书：相面之书。
注：人中：鼻下上唇上的凹沟。
注：有司奏不敬：主管官员奏他不敬。
注：免冠：摘掉帽子，表示谢罪。
注：彭祖：传说中长寿八百岁之人，见《庄子》《列子》等。
# 仙福
题解：唐六如与术士：术士向唐寅夸炼丹之妙，唐寅以“何不自为”反问，并题诗讥其“担水河头卖与人”。
原：有术士干唐六如，极言修炼之妙。唐云：“如此妙术，何不自为，乃贶及鄙人？”术士云：“恨吾福浅。吾阅人多矣，仙风道骨，无如君者。”唐笑曰： “吾但出仙福，有空房在北城，甚僻静，君为修炼，炼成两剖。”术士犹未悟，日造门，出一扇求诗。唐大书云：“破布衫中破布裙，逢人便说会炼银。如何不自烧些用，担水河头卖与人。”
注：唐六如：唐寅，字伯虎，号六如居士，明代书画家，吴县人。
注：干：干谒，求见。
注：贶：赐予。
注：仙风道骨：形容神仙气质。
注：北城：苏州北城。
注：炼成两剖：炼成后两人分成。
注：炼银：炼丹术中炼制白银，即“烧炼黄白”。
# 医意
题解：欧阳修论医意：欧公举“舵牙”治病的故事，说“医者，意也”，苏轼戏言“当令多食笔墨灰”，讥学者昏惰。
原：欧文忠公语东坡曰：“昔有乘船遇风而得疾者，医家取多年舵牙，为舵工手汗所渍处刮末，和丹砂伏神之剂煎饮，疾遂愈。乃知医者，意也。”东坡曰：“如公言，今学者昏惰，当令多食笔墨灰。”
注：欧文忠公：欧阳修，谥文忠。
注：舵牙：船舵的把柄，被舵工之手汗渍。
注：丹砂：朱砂，可入药，安神。
注：伏神：茯神，一种茯苓，安神。
注：医者，意也：语出《后汉书·郭玉传》“医之为言意也”，言医凭意会。
注：笔墨灰：以笔墨之灰烧作药，谑学者之昏惰，言可“治懒读书”。
# 轮回报应
题解：轮回之说被“杀人”反讥：有人盛说轮回报应，许文穆以“莫如杀人”应对，因下世还可得人身讨债。
原：一人盛谈轮回报应：慎无轻杀，凡一牛一豕，即作牛豕以偿；至蝼蚁亦罔不然，时许文穆曰：“莫如杀人。”众问其故。曰：“那一世责债，犹得化人也。”
注：轮回报应：佛教认为众生依业力在六道中生死循环。
注：豕：猪。
注：蝼蚁：蝼蛄和蚂蚁，泛指小虫。
注：许文穆：许国，谥文穆，明万历朝大学士。
注：责债：讨债。
# 为宅
题解：徐孺子拆“困”“囚”字：徐孺子随郭林宗游，驳其以“口中有木”为“困”之说，指出“口中有人”则为“囚”，使郭无言以对。
原：徐孺子，南昌人，十一岁与太原郭林宗游。同稚还家，林宗庭中有一树，欲伐去之，云：“为宅之法，正如方口。‘口’中有‘木’，‘困”字不祥。”徐曰：“为宅之法，正如方口。‘口’中有‘人’，‘囚’字何殊？”郭无以难。
注：徐孺子：徐稚，字孺子，东汉豫章南昌人，隐士，号“南州高士”。
注：郭林宗：郭泰，字林宗，东汉太原人，著名人物品评者。
注：为宅之法：建宅风水之法。
注：困：“木”在“口”中为“困”字。
注：囚：“人”在“口”中为“囚”字。此事见《世说新语》注引，本为徐孺子十岁事，此处写十一岁，待考。
# 蔡元定地理
题解：蔡元定地理之误：蔡元定精地理，为人择葬多不验，及被贬，有人以诗讥其“何不先言去道州”。
原：蔡元定善地理，每与乡人卜葬改定，其间吉凶不能皆验。及贬，有赠诗者，曰：“拙尽人家好丘陇，冤魂欲诉更无由。先生若有尧夫术，何不先言去道州？”
注：蔡元定：字季通，南宋学者，朱熹挚友，精律吕、地理，被贬道州，卒于贬所。
注：地理：风水之术。
注：卜葬：选择葬地。
注：丘陇：坟墓。
注：尧夫术：邵雍，字尧夫，北宋理学家，精《易》数，能预知吉凶。
注：道州：今湖南道县，蔡元定贬谪之地。
# 哈立麻
题解：哈立麻：李继鼎评论西僧哈立麻，若有神通，当说汉语，何待翻译。
原：永乐四年，西僧哈立麻至京，启建法坛，屡著灵异。翰林李继鼎私曰：“若彼既有神通，当作中国语，何待译者而后知乎？”
注：永乐四年：公元1406年。
注：哈立麻：明初西藏噶举派领袖，被封“大宝法王”，永乐四年到南京，建灵谷寺法会，事见《明史·西域传》。
注：启建法坛：设立法坛，举办法会。
注：李继鼎：明初官员，曾任翰林，待考。
注：译者：翻译人员。
# 请僧住院
题解：晏景初请僧住院：晏景初请名僧住院，僧以“巧媳妇煮不得无米粥”推辞，景初反问“若有米，拙媳妇亦能煮”。
原：晏景初请一名僧住院，僧辞以穷陋不可为。景初曰：“高才固易耳。”僧曰：“巧媳妇煮不得无米粥。”景初曰：“若有米，拙媳妇亦自能煮。”
注：晏景初：晏殊曾孙，一说晏敦复，待考。
注：住院：住持寺院。
注：穷陋：贫穷简陋。
注：巧媳妇煮不得无米粥：俗谚“巧妇难为无米之炊”。
# 辟僧
题解：辟僧：欧阳修以贱名为小儿命名之理答僧；昆山学博张倬以“人食之物狗亦食”答僧论佛儒。
原：欧阳公家儿小名有僧哥者，一僧谓公曰：“公不重佛，安得此名？”公笑曰：“人家小儿要易长，往往以贱物为小名，如狗、马、牛、羊之类是也。”僧大笑。
注：欧阳公：欧阳修。
注：僧哥：欧阳修子小名，取其易养。
注：贱物为小名：旧俗为小孩取贱名以易养。
原：昆山学博张倬与一僧谈。僧曰：“儒教虽正，不如佛学之玄。如僧人多能读儒书，儒人不能通释典。本朝能通释典者，宋景濂一人而已。”张笑云：“不然。譬如饮食，人可食者，狗亦能食之，狗可食者，人决不食之矣。”
注：学博：府学、县学教官的别称。
注：张倬：昆山学官，待考。
注：释典：佛经。
注：宋景濂：宋濂，字景濂，明初文人，明代开国文臣之首，通释典。
# 重袈裟
题解：赵悦道重袈裟：赵抃罢政后喜僧拒士，阍者答“只是重袈裟”，士人以“蓝衫”应，阍者言“半看佛面”，士答“半看孔夫子面”。
原：赵悦道罢政闲居，喜僧而拒士。有士往谒再四，阍者不为通。士曰：“参政直得如此敬重和尚？”阍者曰：“寻常僧亦平平，相公只是重袈裟。”士曰：“我这领蓝衫凭地不值钱？”阍者曰：“也半看佛面。”士曰：“也半看孔夫子面。”
注：赵悦道：赵抃，字阅道，北宋名臣，谥清献，晚年信佛。
注：罢政：罢去宰执职位。
注：阍者：守门人。
注：参政：参知政事，宰执副职。
注：袈裟：僧人所穿的法衣。
注：蓝衫：宋代未入仕的读书人所穿的青衫。
注：凭地：这般、如此。
# 辨鬼
题解：阮宣辨鬼：阮宣以“衣服亦有鬼耶”反驳人死有鬼之说，是破鬼神之谈。
原：阮宣闻人说人死有鬼，宣独以为无，曰：“今见鬼者，云著生时衣服。若人死有鬼，衣服亦有鬼耶？”
注：阮宣：阮修，字宣子，西晋陈留尉氏人，清谈家，事见《晋书·阮籍传》附。
注：著生时衣服：穿着生前的衣服。
# 鬼董辨十王
题解：《鬼董》辨十王：《鬼董》引佛经，说明“十王”之说无据，阎罗与十八王、转轮王等各异，七七日经历七王而小祥后仅二王，疏密不均。
原：佛言琰魔罗统摄一素诃世界，今讹为阎罗。又《阿含》等经有十八王，王主一狱，乃阎罗僚属。十王之说，不知何来？转轮王王四天下，亦非主冥道，乃概列于十王。馀如宋帝、五官之类又皆无稽。又七七日而所历者七王，自小祥以后二年，乃仅经二王，何疏密太悬耶？
注：佛言：佛经所说。
注：琰魔罗：梵语“Yama-rāja”，佛教称地狱之主，意译“阎罗王”。
注：一素诃世界：“素诃”，佛教说小世界，“一素诃世界”之说见《长阿含经》，待考。
注：阿含：《阿含经》，佛教早期经典。
注：十八王：佛经说地狱中有十八王。
注：转轮王：佛教称统治四大部洲的圣王，与地狱无关。
注：宋帝、五官：十殿阎罗之“宋帝王”“五官王”，“十王”为中国民间附会，见《十王经》。
注：七七日：人死后七个七日（四十九日），佛教要做斋事。
注：小祥：父母死后一周年的祭祀。
# 论神佛
题解：论神佛：北魏元浚驳卢裕“如神在”之说，张商英作《无佛论》，其妻问“既无，又何论”，二说都以语义反诘。
原：北魏简平王浚，年八岁，谓博士卢裕曰：“祭神如神在，为有神也，无神也？”对曰：“有。”浚曰：“有神当云‘神在’，何烦‘如’字？”张商英夜执笔，妻向氏问何作。曰：“欲作《无佛论》。”向曰：“既无矣，又何论？”公骇其言而止。
注：简平王浚：北魏简平王元浚，元燮之子，八岁即聪慧，事见《魏书》。
注：卢裕：北魏经学家，官至博士。

# 苏公论佛
题解：苏轼与范镇论佛：范镇不信佛，苏轼以医生切脉为喻，说明“未见而信”乃常事。

注：苏公：苏轼。
注：切脉：诊脉。

# 歌哭
题解：苏轼与程颐争“歌则不哭”：司马光死，朝臣因致斋未及奠，程颐引《论语》阻苏轼等往吊，苏轼说“不云歌则不哭”，成理学与旧党之争。
原：司马温公死，当明堂大飨，朝臣以致斋，不及奠。肆赦毕，苏子瞻率同辈往。程颐固争，引《论语》“子于是日哭则不歌”以阻之。子瞻曰：“不云歌则不哭。”
注：明堂大飨：宋代在明堂举行的合祭天地祖先的大典。
注：致斋：祭祀前斋戒。
注：肆赦：大赦。
注：程颐：字正叔，北宋理学家，与兄程颢并称“二程”。
注：子于是日哭则不歌：《论语·述而》“子于是日哭，则不歌”，意为当日哭过丧事，不再唱歌。

# 理学新说
题解：理学新说：理学家解“年四十而见恶焉”，周元孚以“惟仁者能好人，能恶人”应之，戏谑理学穿凿。
原：理学家多主新说。有解“年四十而见恶焉，其终也已”曰：“人当其年尚见可恶之人，则德不进可知矣。”周元孚笑曰：“惟仁者能好人，能恶人，应是三十九岁时也。”
注：理学家：宋明理学家，主张义理性命之学。

注：周元孚：参见前文，待考。

原：有一道学每曰：“天不生仲尼，万古如长夜。”刘翰林谐曰：“怪得羲皇以上圣人，尽日燃烛而行也！”
注：道学：宋明理学的别称。
注：天不生仲尼，万古如长夜：朱熹引唐人语，称赞孔子，见《朱子语类》。

# 《列子》辩日
题解：《列子》两小儿辩日：孔子东游遇两小儿争日远近，孔子不能决，见《列子·汤问》。
原：孔子东游，见二儿争辩日远近。一曰：“日出之时，大如车轮；日中之中，小如盘。岂非日出之处去人近，近见大而远见小乎？”一曰：“日出之时，苍苍凉凉；日中之时，热如探汤。岂非日出之处去人远，远者凉而近者热乎？”孔子不能决。
注：孔子东游：此事见《列子·汤问》。
注：车轮：车子的轮子。
注：盘：盘盂。
注：苍苍凉凉：清冷之貌，《列子》作“沧沧凉凉”。
注：探汤：把手伸入沸水，喻极热，语出《论语·季氏》“见不善如探汤”。
# 不读书
题解：王安石“不读书”：王安石行新法，怒目诸公，指“此辈坐不读书”，赵抃反问“皋、夔、稷、契之时，有何书可读”。
原：王荆公初参政，视庙堂如无人。一旦行新法，怒目诸公，曰：“此辈坐不读书耳！”赵清简公同参知政事，独折之曰：“君言失矣！如皋、夔、稷、契之时，有何书可读？”公默然。
注：王荆公：王安石，封荆国公。
注：参政：参知政事，副宰相。
注：赵清简公：赵抃，谥清简。
注：皋、夔、稷、契：皋陶、夔、后稷、契，传说舜时贤臣，当时无书可读。
# 《字说》
题解：《字说》：王安石作《字说》穿凿，刘攽、苏轼用“犇”“麤”“笃”“笑”“坡”等字诘之；苏轼又以“鸠”戏谑，张耒与张方平论《字说》。
原：王荆公作《字说》，穿凿杜撰。刘贡父问之曰：“牛之体壮于鹿，鹿之行速于牛。今‘犇’、‘⒕’二字，其意皆反之，何也？”坡公亦问曰：“以竹鞭马为‘笃’，不知以竹鞭犬有何可‘笑’？”又尝举“坡”字问荆公何义。公曰：“坡者，土之皮。”坡公笑曰：“然则滑者，水之骨乎？”荆公并无以答。
注：《字说》：王安石所著文字学著作，用会意法解释字形，多附会，今佚。
注：刘贡父：刘攽。
注：犇：牛群奔走，《字说》解为三牛“犇”。
注：⒕：当为“麤”字，三鹿，“行速”，此是刘攽问“犇”“麤”之意相反。
注：以竹鞭马：《字说》说“笃”从“竹”“马”，以竹鞭马。
注：以竹鞭犬：苏轼以“笑”从“竹”“犬”反问。
注：坡者，土之皮：王安石之解。
注：滑者，水之骨：苏轼以“滑”由“水”“骨”反问。
原：又东坡尝语荆公：“‘鸠’从九亦有说。”荆公欣然就问。东坡曰：“‘鸣鸠在桑，其子七兮。’连娘带爷，恰是九个。”张文潜尝问张安道：“司马君实直言王介甫不晓事，是如何？”安道云：“贤只消去看《字说》。”文潜云：“《字说》也只是二三分不合人意。”安道云：“若然则足下亦有七八分不晓事矣。”
注：从九亦有说：《字说》谓“鸠”字从“九”，苏轼就此说笑。
注：鸣鸠在桑，其子七兮：《诗经·曹风·鸤鸠》，鸤鸠养七子；加上父母，合“九”。
注：张文潜：张耒，字文潜，苏门四学士之一。
注：张安道：张方平，字安道，北宋大臣。
注：司马君实：司马光，字君实。
注：王介甫：王安石，字介甫。
# 《牧誓》
题解：唐高定问《牧誓》：高定七岁读《牧誓》，问“以臣伐君”，驳父亲“应天顺人”，指出“不用命戮于社”不顺人心。
原：唐高定七岁时，读书至《牧誓》，问：“奈何以臣伐君？”父郢曰：“应天顺人耳。”曰：“‘用命赏于祖，不用命戮于社。’岂是顺人？”郢不能答。
注：唐高定：唐代高定，字不详，待考。
注：《牧誓》：《尚书》篇名，周武王伐纣时在牧野誓师之辞。
注：奈何以臣伐君：与《孟子》“臣弑其君可乎”相似。
注：父郢：高郢，字公楚，唐代名臣。
注：用命赏于祖，不用命戮于社：《尚书·甘誓》，“用命，赏于祖；弗用命，戮于社”，此处误记为《牧誓》，疑出处有误。
# 论诗
题解：论诗：李东阳《岳阳楼》诗受人批评，杨守陈以“吴楚东南坼”为反驳；方棠陵与张昆仑论诗之情实，张以“清酒百壶”辩诗人托物。
原：李西涯尝有《岳阳楼》诗云：“吴楚乾坤天下句，江湖廊庙古人情。”杨文懿公亟称之。有同官不以为然，驳之曰：“吴楚乾坤之句，本妙在‘坼’字‘浮’字。今去此二字，则不见其妙矣。”杨曰：“然则必云‘吴楚东南坼乾坤日夜浮天下句’而后为足耶？”
注：李西涯：李东阳，号西涯。
注：《岳阳楼》：李东阳有《岳阳楼》诗，此处引句出处待考。
注：杨文懿公：杨守陈，字维新，谥文懿，明代官员。
注：坼：裂开，杜甫《登岳阳楼》“吴楚东南坼，乾坤日夜浮”。
原：方棠陵以广东宪副入贺。张昆仑山人以诗饯之。方曰：“君诗虽佳，而非情实，如无山称山，无水赋水，非欢而畅，不戚而哀。予诗虽劣，情实俱在。”答曰：“诗人婉辞托物，若文王之思后妃，岂必临河洲见睢鸠耶？即如饯行，何必携百壶酒而云‘清酒百壶，唯笋及蒲’？若据情实，则老酒一瓶，豆腐面筋耳。”京师闻者大笑。
注：方棠陵：方豪，字思道，号棠陵，明代诗人，官至广东按察司副使。
注：宪副：按察副使。
注：张昆仑：张诗，字子言，号昆仑山人，明代诗人。
注：文王之思后妃：《诗经·周南·关雎》。
注：睢鸠：即雎鸠，鸟名。
注：清酒百壶，唯笋及蒲：《诗经·大雅·韩奕》“清酒百壶……其蔌维何，维笋及蒲”。

# 六字地名
题解：六字地名：杨慎在史馆，对同列误以六字地名为三地名者，以班马叙外域之例相驳。

注：杨用修：杨慎，号升庵，明代文学家，状元，官翰林修撰。
注：史馆：编修国史的机构。
注：土官：明代西南少数民族首领，世袭官职。
注：水尽源通塔平长官司：明代湖广永顺宣慰司所属长官司，“水尽源通塔平”为一地名。
注：大明官制：《大明官制》，明代典章之书。
注：司马适《西南夷传》：当作“司马迁”，《史记·西南夷列传》。
注：班固《匈奴传》：《汉书·匈奴传》。
注：指掌：如指掌上之物，言了解透彻。

# 诸葛恪
题解：诸葛恪驳张昭：孙权命诸葛恪劝酒，张昭不饮，恪以姜太公之例反驳；又以“白头翁”答孙权，张昭戏求“白头母”，恪以“鹦母”回敬。
原：孙权大会将佐，命诸葛恪行酒。次至张辅吴，先有酒色，不肯饮，曰：“此非养老之礼也。”权谓恪曰：“卿但令张公辞屈乃饮耳。”恪即难张曰：“昔尚父九十，秉旄仗钺，犹未告老。今军旅之事，将军在后，酒食之事，将军在前，何谓不养老也？”张无辞，遂为尽爵。
注：张辅吴：张昭，字子布，封辅吴将军，东吴重臣，事见《三国志·吴书·张昭传》。
注：养老之礼：古代尊敬老人之礼。
注：尚父：吕尚，即姜太公，周文王尊为“师尚父”，九十余岁辅佐周室。
注：秉旄仗钺：手持旄牛尾饰的旗与斧钺，指统军。
注：尽爵：把酒喝完。
原：曾有白头鸟集吴殿前。孙权问群臣：“此何鸟也？”诸葛元逊对云：“此名白头翁。”张昭自以坐中最老，疑戏之，因曰：“恪欺陛下，未尝闻鸟名白头翁者。试令恪复求白头母。”元逊曰：“鸟名鹦母，未必有对。试使辅吴复求鹦父。”张不能答。
注：白头鸟：白头翁，鸟名。
注：诸葛元逊：诸葛恪，字元逊。
注：鹦母：鹦鹉，“鹦母”谐“鹦武”，借“母”对“翁”。
# 犯夜
题解：犯夜：张观问犯夜者，巡者答“若有证见，亦是犯夜”，指无证不能论罪。
原：张观知开封日，有犯夜巡者，缚致之。观曰：“有证见乎？”巡者曰：“若有证见，亦是犯夜矣。”
注：张观：字思正，北宋官员，官至御史中丞。
注：知开封：知开封府。
注：犯夜：触犯夜禁，夜间外出。
注：证见：证人，见证者。
# 捕蝗檄
题解：捕蝗檄：泰兴令谎称无蝗，后言蝗自如皋飞来，钱穆甫判云“却请贵县押来”，戏之。
原：钱穆甫为如皋令，会岁旱蝗发，而泰兴令独绐郡将云：“县界无蝗。”已而蝗大起，郡将诘之。令辞穷，乃言“县本无蝗，悉自如皋飞来者。”仍檄本县严捕，无令侵及邻境。穆甫得檄，判云：“蝗本天灾，非令不才。既自敝邑飞去，却请贵县押来。”
注：钱穆甫：钱勰，字穆父，北宋人，官如皋令，善诙谐。
注：如皋：今江苏如皋。
注：泰兴：今江苏泰兴。
注：绐：欺骗。
注：郡将：太守，州郡长官。
注：敝邑：谦称自己的县。
注：押来：押送过来，指把蝗虫押回。
# 举人大帽
题解：举人大帽：举人戴大帽谒见按君，按君问“始自何年”，答“始于老大人乘轿之年”，讥其违制。
原：祖制：京官三品始乘轿，科道多骑马；后来皆私用轿矣。王化按浙，一举人大帽入谒。按君不悦，因问曰：“举人戴大帽，始自何年？”答曰：“始于老大人乘轿之年。”
注：祖制：祖宗成法，指明代制度。
注：科道：六科给事中和十三道监察御史。
注：王化：明代官员，巡按浙江，待考。
注：按君：巡按御史。
注：大帽：明代一种官帽。
注：老大人：对前辈官员的尊称。
# 西安令
题解：西安令：俞君宣性懒，选得衢州西安，友人以“衢”字四轮劝勤，俞以“偏安”答之。
原：俞君宣性懒，选得衢州之西安。友人规之曰：“清慎君所有馀，第在冲要地，不可不勤。”俞曰：“何以知冲要也？”曰：“是四轮之地。不然，何以谓之衢州？”俞曰：“是偏安之邑，不然何以谓之西安？”友人无以难。
注：俞君宣：待考。
注：衢州之西安：今浙江衢州，明清时西安县为衢州府治。
注：冲要：交通要地。
注：四轮：“衢”字有四通之意，“衢”之字形似“行”中有“瞿”，友人称之为四轮之地。
注：偏安：偏居一隅，借“西安”二字讥。
# 贪令
题解：贪令：某县令贪，监司欲斥，陈渠说此地穷，监司以“盗劫贫家，岂得无罪”回应。
原：某令贪，监司欲斥之。陈渠为中丞，笑曰：“此地穷苦，不比贵乡，墨不满橐也。”监司曰：“盗劫贫家，岂得无罪！”
注：监司：宋代对路级监察官员的称呼，如转运使、提刑。
注：陈渠：待考。
注：中丞：御史中丞。
注：墨不满橐：贪墨之财装不满囊，“墨”谐贪。
# 海瑞非圣人
题解：海瑞非圣人：海瑞抚江南，处理徐阶家田宅过严，缙绅劝“圣人不为已甚”，海瑞答“海瑞非圣人”。
原：海忠肃抚江南，为华亭公处分田宅，奉行者稍过，遂致不堪。缙绅咸为华亭解纷，谓海曰：“圣人不为已甚。”海艴然曰：“诸公岂不知海瑞非圣人耶？”缙绅悉股栗而退。
注：海忠肃：海瑞，号刚峰，谥忠介，明代清官，此处称“忠肃”或有误。
注：抚江南：海瑞巡抚应天十府，力抑豪强。
注：华亭公：徐阶，松江华亭人，明嘉靖朝首辅。
注：处分：处置。
注：圣人不为已甚：《孟子·离娄下》“仲尼不为已甚者”。
注：艴然：生气变色貌。
注：股栗：两腿发抖。
# 蹩媪
题解：蹩媪问田巴：田巴弟子禽滑厘遇蹩媪，被问“马鬃尾长短与人须发”之理，答不上，田巴亦无以应，只能责禽滑厘“幸自无事”，借以讽辩者之穷。
原：田巴居于稷下，是三王而非五帝，一日屈千人，其辩无能穷之者。弟子禽滑厘出逢蹩媪。揖而问曰：“子非田巴之徒乎？宜得巴之辩也。媪有大疑，愿质于子。”禽滑厘曰：“媪姑言之，我能析其理。”媪曰：“马鬃生向上而短，马尾生向下而长，其故何也？”禽滑厘笑曰：“此易晓耳。鬃上抢势逆而强，故短；尾下垂势顺而逊，故长。”媪曰：“然则人之发上抢，逆也，何以长？须下垂，顺也，何以短？”滑厘茫然自失，乃曰：“吾学未足以臻此，当归谘师。媪幸留此，我其有以奉酬。”即入见田巴，曰：“适出遇蹩媪，以鬃尾长短为问，弟子以逆顺之理答之，如何？”曰：“甚善。”滑厘曰：“然则媪申之以须顺而短，发逆而长，则弟子无以对。愿先生析之。媪方坐门以候。”巴俯首久之，乃以行呼滑厘曰：“禽大！禽大！幸自无事，也省可出入！”
注：田巴：战国齐国辩士，居稷下，“是三王而非五帝”，事见《鲁仲连子》，后被鲁仲连说服。
注：稷下：齐国都城临淄稷门附近，齐国设稷下学宫，招揽学者。
注：三王而非五帝：肯定夏商周三王，否定五帝，指其立论奇异。
注：屈千人：使千人折服。
注：禽滑厘：墨子弟子，名滑釐，此处与田巴同时，事不合，系寓言。
注：蹩媪：跛脚的老妇人。蹩，同“蹩”，跛行。
注：质：询问、求证。
注：析其理：分析其道理。
注：上抢：向上冲，抢，撞。
注：逆而强：逆势而强劲。
注：谘师：向老师请教。
注：奉酬：奉上回答。
注：省可：少、不必，宋元口语。
# 怀绳见王
题解：艾子怀绳见王：邾石父谋叛，宣王欲灭其族，艾子怀三尺绳见王，以“公子巫降秦”之事，请王“引决”，以讽之，王遂赦免。
原：齐大夫邾石父谋叛，宣王诛之，欲灭其族。邾之族大以蕃，咸泣拜于艾子之庭，祈请于王。艾子曰：“得一绳可免。”邾氏以为戏言，亦不敢诘，退而索以馈。艾子怀其三尺以见王，曰：“为逆者一石父，其宗何罪而戮之？”王曰：“先王之法不敢废也。政典曰：‘与叛同宗者，杀无赦。’”艾子顿首曰：“臣亦知王之不得已也。窃有一说：往年公子巫以邯郸降秦，非王之母弟乎？然则王亦叛臣之族，理合随坐，愿王即日引决，勿惜一身而伤先王之法。”因献短绳三尺。王笑而起曰：“先生且休，寡人赦之矣。”
注：艾子：宋代苏轼《艾子杂说》中的虚拟人物，常以滑稽谏诤，此条出该书，后人托为苏轼作。
注：邾石父：邾国人，待考。
注：宣王：齐宣王。
注：蕃：繁盛，指族人众多。
注：政典：古代国家法典，《尚书·胤征》引“政典曰”，此处借称。
注：公子巫以邯郸降秦：公子巫，待考；邯郸降秦为公元前228年事，距宣王已久，此是故事虚构，以示滑稽。
注：母弟：同母弟。
注：理合随坐：理应一同连坐。
注：引决：自杀。
# 营兵士
题解：营丘士与艾子：营丘士好问，连问车驼铃铎、塔铃、鹰铃，艾子不得不连连解释，最后以“挽郎铎”反责，是塞语的反例。
原：营丘士性不通慧，好折难而不中理。一日造艾子，问曰：“凡大车之下与橐驼之项，多缀铃铎，其故何也？”艾子曰：“车驼之为物甚大，且多夜行，忽狭路难避，借鸣声相闻，使为计耳。”营丘士曰：“佛塔之上，亦设铃铎，岂谓塔亦夜行而使相避耶？”艾子曰：“君不通事理乃至如此！凡鸟鹄多托高以巢，粪秽狼籍，故塔之铃，所以警鸟鹊也，岂以车驼比耶？”营丘士曰：“鹰鹞之尾，亦设小铃，安在鸟鹊巢于鹰鹞之尾乎？”艾子大笑曰：“怪哉君之不通也！夫鹰隼击物，或入林中，而绊足掐线，偶为木所绾，振羽之际，铃声可寻而索也。岂谓防鸟鹊之巢哉？”营丘士曰：“吾尝见挽郎秉铎而歌，不究其义，今乃知恐为木枝所绾，而便于寻索也。抑不知绊郎之足者，用皮乎？用线乎？”艾子愠而答曰：“挽郎乃死者之导也，为死人生前好诘难，故铎以乐其尸耳！”
注：营丘士：营丘人，营丘为齐国旧都，此指齐地之人，被设为不通慧的形象。
注：折难：诘难，驳难。
注：橐驼：骆驼，背有肉峰如橐。
注：铃铎：铃铛。铎，大铃。
注：鸟鹄：当作“鸟鹊”，下文即作“鸟鹊”。
注：粪秽狼籍：鸟粪遍布，污秽杂乱。
注：鹰鹞：猛禽，常用于打猎。
注：绊足掐线：脚下系着线绳，鹰隼脚上系绳以便驯养。
注：绾：缠绕、挂住。
注：挽郎：古代出丧时执绋唱挽歌的人，《晋书》载挽郎用清贵子弟充当。
注：秉铎而歌：手持大铃唱挽歌。
注：愠：怒。
