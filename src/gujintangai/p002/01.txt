# 正文
题解：《怪诞》部总序：冯梦龙指出人情厌常喜异，而做官最忌作怪。
原：〔子犹曰：人情厌故而乐新，虽雅不欲怪，辄耳昵之，然究竟怪非美事。纣为长夜之饮，通国之人皆失日。以问箕子，箕子不对。箕子非不能对也，以为独知怪矣。楚王爱细腰，使群臣俱减餐焉。议者谓六宫可也，群臣腰细何为？不知出宫忽见腰围如许，王必怪，怪则不测，即微王令，能忽减餐乎哉？夫使人常所怪而怪所常，则怪反故而常反新矣。新故须臾，何人情之不远犹也？昔富平孙冢宰在位日，诸进士谒选，齐往受教。孙曰：“做官无大难事，只莫作怪！”真名臣之言乎，岂唯做官！集《怪诞》第二。〕
注：子犹曰：子犹，冯梦龙之号。
注：长夜之饮：纣王昼夜饮酒，事见《韩非子·说林上》，群臣皆不知日子，问箕子，箕子称不知以自保。
注：箕子：商纣王的叔父，贤臣。
注：楚王爱细腰：楚灵王好细腰，臣下节食，事见《墨子》《韩非子》。
注：六宫：后妃居所，此指后宫。
注：微王令：即使没有王的命令。
注：不远犹：疑指“不远复”之类的谬误，待考。
注：富平孙冢宰：孙丕扬，陕西富平人，万历间吏部尚书，冢宰为吏部尚书别称。
注：谒选：到吏部听候铨选授官。
# 天文冠
题解：王莽制天文冠，以怪诞自威，孔仁因妻被连累而摘冠，反被劾大不敬。
原：新莽好怪，制天文冠，使司命冠之，乘乾车，驾坤马，左苍龙，右白虎，前朱鸟，后玄武，右仗威节，左负威斗，号曰赤星，以尊新室之威命。司命孔仁妻坐祝诅事连及，自杀。仁见莽，免冠谢。莽使尚书劾仁“擅免天文冠，大不敬”。有诏勿问，更易新冠。
注：新莽：王莽建立的新朝。
注：天文冠：王莽所制之冠，饰以天象，见《汉书·王莽传》。
注：司命：王莽所设官名，主管军事。
注：乘乾车，驾坤马，左苍龙，右白虎，前朱鸟，后玄武：车马以乾坤为名，左右前后分别饰东、西、南、北四象。
注：威斗：王莽所铸北斗形的铜器，据称可压胜。
注：赤星：王莽对这一套装束的称号。
注：新室：新朝皇室。
注：孔仁：王莽的司命，后因事自杀（一说为妻之事连及）。
注：尚书：此指王莽朝尚书。
# 大像
题解：武则天宠信薛怀义，造夹纻大像，以牛血作画，遇大风被毁，怪诞滥费。
原：天后宠僧怀义，为作夹纻大像，小指中犹容十数人，构天堂以居焉。又杀牛取血画大像，首高二百尺。雲怀义刺漆血为之。张于天津桥南，忽大风起，烈像为数百段。
注：天后：武则天。
注：怀义：薛怀义，本名冯小宝，武则天宠僧。
注：夹纻：以麻布、漆为胎的塑像工艺。
注：天堂：武周所建明堂之北的佛堂，高大，后遭火。
注：天津桥：洛阳洛水上的桥。
注：刺漆血：以血和漆。事见《旧唐书·薛怀义传》。
注：雲：古同“云”，此指有说法。
注：烈像：疑当作“裂像”。
# 《酉阳杂俎》载札青事
题解：《酉阳杂俎》载唐人札青之风，从泼皮到蜀市人皆以刺青自矜，以及葛清通身刺白居易诗。
原：上都市肆恶少，好为札青。有张干者，札左膊曰：“生不怕京兆尹”，右膊曰：“死不畏阎罗王”。又有王刁奴，以钱五千召札工，于胸腹为山池亭院草木飞走，无不毕具，细若设色。京兆尹薛元赏悉杖杀之。又高陵县捉得镂身者宋元素，札七十一处，刺左臂曰：“昔日已前家未贫，千金不惜结交亲。及至凄惶觅知己，行尽关山无一人。”右膊札葫芦，上札出人首，如傀儡戏所谓“郭公”者。县吏不解，问之，言葫芦精也。
注：札青：即刺青，纹身。
注：京兆尹薛元赏：唐宣宗朝京兆尹，事见《酉阳杂俎》。
注：阎罗王：佛教地狱之主。
注：高陵县：今陕西西安高陵区。
注：镂身：在身上刺花纹。
注：傀儡戏：木偶戏。“郭公”即郭郎，傀儡戏中的丑角。
注：葫芦精：民间传说中的精怪。
原：蜀市人赵高，满背镂毗沙门天王。吏欲杖其背，见天王辄止。恃此转为坊市患。李夷简擒而杖之，叱杖子打天王尽则已。经旬日，高袒衣历门叫呼，乞“修理天王功德钱”。
注：毗沙门天王：佛教四大天王之北方多闻天王，唐人多崇信。
注：李夷简：唐宗室，曾任剑南西川节度使，《新唐书》有传。
注：杖子：差役，行杖者。
注：修理天王功德钱：赖皮之语，谓其背上天王被打坏，要钱来修。
原：段成式门下驺路神通，背刺天王像，自言能得神力。每朔望，具乳糜，焚香袒坐，使妻儿供养其背而拜焉。
注：段成式：唐代文人，《酉阳杂俎》作者；上文札青诸事多出此书。
注：驺：随从骑卒。
注：路神通：人名，段成式的随从。
注：朔望：每月初一和十五。
注：乳糜：用牛乳煮成的粥，佛教供养用。
原：贞元中，荆州市中有鬻札者，制为印，上簇针为众物状，如蟾蝎鸟兽，随人所欲，印之刷以石墨，精细如画焉。
注：贞元：唐德宗年号（785—805）。
注：荆州：今湖北荆州一带。
注：石墨：黑色矿物颜料，此指墨。
注：蟾蝎：蟾蜍与蝎子。
原：荆州街男子葛清，自颈已下，通札白居易诗。段成式尝与荆客陈至呼观之，令其自解。背上亦能暗记，反手指其札处，至“不是花中偏爱菊”，则有一人持杯临菊丛。“黄夹缬窠寒有叶”，则指一树，树上挂缬窠，窠纹绝细。凡札三十馀首，体无完肤。陈至呼为“白舍人行诗图”。
注：葛清：荆州人，以通身刺白居易诗而知名，事见《酉阳杂俎》。
注：陈至：荆客，其人待考。
注：不是花中偏爱菊：白居易《菊花》诗句，下句为“此花开尽更无花”。
注：黄夹缬窠寒有叶：白居易诗句，“夹缬”是一种以夹板印染的花布。
注：白舍人行诗图：白居易曾任中书舍人，故称白舍人；“行诗图”意为走着的诗意图。
原：蜀小将韦少卿，少不喜书，嗜好札青。其季父尝令解衣，视胸上札一树，树杪集鸟数千，其下悬镜，镜鼻系索，有人止于侧牵之。叔不解，问焉。少卿笑曰：“叔不曾读张燕公诗云‘挽镜寒鸦集’耶？”叔大笑不已。
注：韦少卿：事见《酉阳杂俎》，其人待考。
注：季父：叔父。
注：张燕公：张说，封燕国公，唐代文学家。
注：挽镜寒鸦集：诗句，意为对镜寒鸦栖集（待考），韦氏误以为牵镜，所以刺了牵镜之图，是笑点。
# 剃眉
题解：彭几见范仲淹像而叹自己无耳毫，见狄仁杰像而剃眉尾，模仿古人形貌到可笑。
原：彭渊材初见范文正公画像，惊喜再拜，前磬折，称“新昌布衣彭几幸获拜谒。”既罢，熟视曰：“有奇德者，必有奇形。”乃引镜自照，又捋其须曰：“大略似之矣，但只无耳毫数茎耳，年大当十相具足也。”又至庐山太平观，见狄粱公像，眉目入鬓，又前再赞曰：“有宋进士彭几谨拜谒。”又熟视久之，呼刀镊者使刺其眉尾，令作卓枝入鬓之状。家长辈望见惊笑。渊材怒曰：“何笑？吾前见范文正公恨无耳毫，今见狄梁公不敢不剃眉，何笑之乎？”
注：彭渊材：彭几，字渊材，宋人，新昌（今江西宜丰）人，好奇诞。
注：范文正公：范仲淹，谥文正。
注：磬折：弯腰如磬，表示恭敬。
注：新昌布衣：彭几自称，新昌即其籍贯。
注：耳毫：耳中长毫毛，旧时相术以为长寿之相。
注：十相具足：佛教所谓佛有三十二相，此处戏言。
注：太平观：庐山道观。
注：狄粱公：狄仁杰，封梁国公，原文作“粱”，当作“梁”。
注：卓枝：待考，疑指眉形的名称。
注：刀镊者：理发修面的人。
# 异服
题解：古今奇装异服者，米芾、宋道晖、翟耆年等，皆以怪服取笑。
原：进士曹奎作大袖袍。杨衍问曰：“袖何须此大！”奎曰：“要盛天下苍生。”衍笑曰：“盛得一个苍生矣！”
注：曹奎：事迹待考。
注：杨衍：待考。
注：苍生：百姓。
原：翟耆年好奇，巾服一如唐人，自名唐装。一旦往见许颜周。颜周髽髻，著犊鼻裤，蹑高屐出迎。翟愕然。彦周徐曰：“吾晋装也，公何怪？”
注：翟耆年：宋人，《籀史》作者，好古。
注：唐装：此指唐人服装，非今日所谓唐装。
注：许颜周：即许顗，字彦周，宋人，《彦周诗话》作者。
注：髽髻：丧服束发的样式，此处指蓬散发髻。
注：犊鼻裤：短裤，司马相如曾着。
注：蹑高屐：穿高齿木屐。
注：晋装：晋人放达，故作自嘲语。
原：北齐宋道晖，阜城人，与同郡熊安生并称经师。道晖好著高翅帽、大屐，州将初临，辄服以谒见，仰头举肘，拜于屐上，自言“学士比三公”。后齐任城王湝鞭之，道晖徐呼“安伟！安伟！”出谓人曰：“我受鞭不著体。”复蹑屐翩翩而去。冀州为之语曰：“显公锺，宋公鼓，宋道晖屐，李洛姬肚。”谓之“四大”。显公，沙门也。宋公，安德太守。
注：宋道晖：北齐经师，《北史·儒林传》有传。
注：阜城：今河北阜城。
注：熊安生：北周、北齐经学家，字植之。
注：高翅帽：两翼高耸的帽子。
注：州将：州刺史之类的长官。
注：任城王湝：北齐任城王高湝。
注：安伟：熊安生之字，此处宋道晖借以脱嘲。
注：显公锺，宋公鼓：谓显公之钟、宋公之鼓，是冀州“四大”之说。
注：李洛姬：待考，其腹大名。
注：沙门：僧人。
注：安德太守：安德郡太守。
原：元祐中，米元章居京师，被服怪异。戴高檐帽，既坐轿，为顶盖所碍，遂撤去，露顶而坐。一日出保康门，遇晁以道。以道大笑。下轿握手，问曰：“晁四，你道似甚底？”晁云：“我道你似鬼章！”二人抚掌绝倒，时西边获贼寨首领鬼章，槛车入京，故以为戏。
注：米元章：米芾，字元章，北宋书画家，行为怪异，人称“米颠”。
注：元祐：宋哲宗年号（1086—1094）。
注：保康门：北宋东京城门。
注：晁以道：晁说之，字以道，北宋学者。
注：鬼章：青唐吐蕃首领鬼章，元祐二年（1087）被宋军俘获。
注：槛车：囚车。
原：蜀中日者费孝先筮《易》，以丹青寓吉凶，谓之“卦影”。其后转相祖述。画人物不常，鸟或四足，兽或两足，人或儒冠而僧衣，故为怪以见象。米元章好怪，常戴俗帽，衣深衣，而蹑朝靴。人目为“活卦影”。
注：日者：占卜者。
注：费孝先：北宋蜀中术士，擅作“卦影”。
注：筮《易》：以《周易》蓍占卜。
注：丹青：绘画颜色，此指图画。
注：卦影：以图画寓吉凶的占卜，称“卦影图”。
注：深衣：古代贵族的家居礼服。
注：朝靴：上朝时穿的靴。
# 假面假衣冠
题解：张幼于以假面假衣冠与人往来，行为怪异。
原：张幼于燕居，多用假面。少与山僧处嘿厚。一日往京觅官，过别。张笑谓曰：“我儒人尚无宦情，汝反不禁中热耶？”及拜官归，乘马相访。张星冠以羽服，戴假面出迎，口不发一辞，推以乘骑，观者载道，马不得前。又郁山人璠，携村妓至，曰：“妇能诗，请联句。”坐方洽，其夫忽以儒衣冠登座，讶客不当近其内。客欲散，止之曰：“吾当以干戚解围。”仍用羽服假面与揖逊，夫惊而逸。
注：张幼于：张献翼，字幼于，明代长洲（今苏州）人，行止怪异。
注：燕居：闲居。
注：假面：面具。
注：嘿厚：嘿同“默”，投合深厚。
注：禁中热：耐不住心里的热衷，指宦情。
注：星冠以羽服：道士所穿的饰星之冠与羽衣。
注：载道：满路。
注：郁山人璠：山人是明代自称隐逸而游食者，郁璠其人待考。
注：联句：多人各作一句合成诗。
注：干戚：盾和斧，古代的舞具，《尚书》载舜舞干戚而有苗服。
注：揖逊：作揖谦让。
原：张敉尝过江阴薛世和，薛方拜鸿胪归，见架上衣冠，门有系马，竟服其衣冠，乘马张盖，报张、薛二孝廉之谒。二公具衣冠送迎，宾主略不相讶。
注：张敉：疑即张献翼之别名，待考。
注：薛世和：江阴人，曾官鸿胪，其人待考。
注：鸿胪：鸿胪寺官，掌朝会仪节。
注：孝廉：明清称举人。
# 宴死祭生
题解：张献翼为已故的友人设宴，又有人先请他设祭自己，皆怪诞之举。
原：黄彪夜看张敉，见其斋中设筵，敉独居主人位，嘿若谈对。问其故。答曰：“今日宴死友张之象、董宜阳、何良傅、莫如忠、周思兼五人。我念所至，辄与心语。”彪笑曰：“以公所邀，谅诸君必赴。”
注：黄彪：其人待考。
注：张之象、董宜阳、何良傅、莫如忠、周思兼：皆明嘉靖间松江、华亭一带文人，张献翼的亡友。
注：嘿若谈对：默默地像是在交谈。
原：张孝资与张敉善，尝谓敉曰：“予倘先君殁，当烦设祭。及吾未也，盍先诸？”敉奇其意，为卜日，悬祭文，设几筵笾豆。孝资至，先延之后阁，令傧相赞礼，伶人奏乐，出之，正襟危坐，助祭者朗诵祭章，声伎满堂，香烟缭绕。敉赠以诗云：“祭是生前设，魂非死后招。”
注：张孝资：其人待考。
注：殁：死。
注：几筵笾豆：祭祀用的几案、席与竹豆、木豆。
注：傧相：礼仪的司仪。
注：伶人：乐工。
注：祭是生前设，魂非死后招：张献翼赠诗句。
# 张幼于赎罪
题解：张幼于以匾坠为祖宗怒，自行“赎罪”，又自行“释罪”，行事怪诞。
原：张居士腊月朔谒家庙，楼匾忽堕。张曰：“此祖宗怒我也！”因沐浴茹素，作“自责文”，囚服长跽谢过，凡七日，以巨石压顶，令家奴下杖数十。已而口占“赎罪文”，备述生平读书好客之事。因起更衣，插花，披锦，鼓乐导之而出，曰：“祖宗释我矣！”
注：张居士：张幼于，居士是在家信佛者的称呼。
注：腊月朔：十二月初一。
注：家庙：祠堂。
注：茹素：吃素。
注：囚服：囚犯的服装。
注：长跽：长跪。
注：口占：随口吟成。
# 苏、湛引过
题解：苏世长引咎自鞭而被人认为诡诈，湛文朴令江夏每过遥望阙下自劾，皆是作态。

# 倪云林事
题解：倪云林嗜洁成癖，既不为张士信作画，又对人对事嫌秽，一言不发而被鞭。
原：倪云林名瓒，元镇其字也。性好洁。文房拾物，两僮轮转拂尘，须臾弗停。庭前有梧桐树，旦夕汲水揩洗，竟至槁死。尝留友人宿斋中，虑有污损，夜三四起，潜听焉。微闻嗽声，大恶之，凌晨令童索啖痕，不得，童惧笞，拾败叶上有积垢似啖痕以塞责。倪掩鼻闭目，令持弃三里外。其寓邹氏日，邹熟师有婿曰金宣伯，一日来访。倪闻宣伯儒者，倒屣迎之。见其言貌粗率，大怒，掌其颊。宣伯愧忿，不见主人而去。邹出，颇怪之。倪曰：“宣伯面目可憎，语言无味，吾斥去之矣！”初张士诚弟士信，闻倪善画，使人持绢，侑以重币，欲及其笔。倪怒曰：“倪瓒不能为王门画师！”即裂去其绢。士信深衔之。一日，士信与诸文士游太湖，闻小舟中有异香。士信曰：“此必一胜流。”急傍舟近之，乃倪也。士信大怒，即欲手刃之。诸人力为营救，然犹鞭倪数十。倪竟不吐一语。后有人问之，曰：“君被窘辱而一语不发，何也？”倪曰：“一说便俗！”

注：衔：怀恨。
注：胜流：名流。

注：一说便俗：说话即俗，倪瓒的名言。
原：倪元镇于女色少所当意。一日眷金陵赵歌姬，留宿别业，心疑不洁，俾之浴。既登榻，以手自顶至踵，且扪且嗅。扪至阴，复俾浴。凡再四，东方即白，不复作巫山之梦。

# 晒腹书
题解：郝隆七月七日仰卧晒腹，自称“晒书”，以讥风俗。
原：郝隆七月七日出日中仰卧。人问其故，答曰：“我晒书。”
注：郝隆：东晋人，《世说新语·排调》载其七月七日晒腹事。
注：七月七日：古人有七夕曝书晒衣之俗。
注：我晒书：郝隆自称腹中有书，故以晒腹代晒书。
# 解语神柩
题解：苗耽借灵柩休息，被守门人讥为“解语神柩”，笑谈。
原：苗耽进士尝自外游，归途疾甚，不堪登升。适有辇棺而回者，以其价贱，即就而寝息其中。至洛东门，阍者不知其中有人，诘其来由。耽谓其讶己，徐答曰：“衣冠道路得病，贫不能致他物相与，无怪也！”阍者曰：“吾守此三十年矣，未尝见有解语神柩！”
注：苗耽：唐代进士，事见《唐摭言》等，待考。
注：辇棺：用车载运棺材。
注：洛东门：洛阳东城门。
注：阍者：守门人。
注：衣冠：士大夫。
注：解语神柩：会说话的灵柩，戏语。
# 陆舟
题解：张融自称“陆处无屋，舟居非水”，被从兄戏解为牵小船上岸居住。
原：张思光给假东去。世祖问：“卿往何处？”答云：“臣陆处无屋，舟居非水。”后日，上以问其从兄思曼。思曼曰：“融近东出，未有居止，权牵小船于岸上往。”
注：张思光：张融，字思光，南齐文学家，《南齐书》有传。
注：给假：给予假期。
注：世祖：南齐武帝萧赜。
注：思曼：张融从兄，名张思曼（待考）。
注：权：暂且。
