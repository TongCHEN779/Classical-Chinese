# 正文
题解：本部《苦海》卷首小引：子犹说郑光业收嗤诗于皮箧号“苦海”，自己也收集拙诗以供谐戏，并告诫莫轻笑别人。
原：〔子犹曰：昔郑光业兄弟，遇人献词，句有可嗤者，辄投一巨皮箧中，号曰“苦海”，宴会则取视，以资谐戏。夫为词而足以资人之谐戏，此词便是天地间一种少不得语，犹胜于尘腐蹈袭，如杨升阉所谓“虽布帛菽粟，陈陈相因，不可衣食”也。故余喜而采之。而古诗之病经人指摘者，亦附入之，又以见巨皮箱中，人人有份，莫要轻易便张口笑人也。集《苦海》第七。〕
注：子犹曰：冯梦龙评语。
注：郑光业：唐人，状元，事见《太平广记》，称其兄弟以他人可笑句投皮箧。
注：可嗤：可笑。
注：巨皮箧：大皮箱。
注：苦海：佛教语，喻尘世苦难，此处借喻拙诗之薮。
注：资谐戏：供取笑。
注：杨升阉：杨慎，号升庵，此“阉”当作“庵”；引语出自其《升庵诗话》，待考。
注：尘腐蹈袭：陈腐抄袭。
注：布帛菽粟：喻平常必需。
注：陈陈相因：陈粮叠陈粮，指沿袭旧套，语出《史记·平准书》。
注：集《苦海》第七：本书《古今谭概》第七部为《苦海》。
# 采石诗
题解：采石矶李白墓前题诗者太多，有客写讽刺绝句，用“鲁班门前掉大斧”点明班门弄斧。
原：采石江头，李太白墓在焉。往为诗人题咏殆遍。有客书一绝云：“采石江边一抔土，李白诗名耀千古。来的去的写两行，鲁般门前掉大斧。”
注：采石：采石矶，在今安徽马鞍山，传说李白死于当涂。
注：李太白墓：在当涂青山下，唐代即有墓。
注：一抔土：一捧土，指坟墓。
注：鲁般：即鲁班，战国巧匠，“鲁般门前弄大斧”谓在行家面前卖弄。
# 同东集
题解：吴僧法海的恶诗集由刘从事作序，序中以“同东”戏拟，并攀比杜牧、杜甫，讥其诗拙。
原：《悦生堂随抄》云：吴僧法海好作恶诗，萃成帙，刘从事为序。刘序云：“师虽习西方之教，颇同东鲁之风，因题曰《同东集》。长于譬喻，动有风骚。昔唐小杜既为老杜之次，今师又在小杜之下。”
注：《悦生堂随抄》：南宋贾似道所撰笔记。
注：法海：吴地僧人，事迹待考。
注：恶诗：拙劣之诗。
注：刘从事：待考。
注：西方之教：佛教。
注：东鲁之风：儒家，鲁为孔子故里。
注：风骚：《诗经》国风与《离骚》，代指诗文。
注：唐小杜：杜牧称小杜；老杜指杜甫。
# 盘门诗伯
题解：苏州盘门外兄弟以恶诗互相唱和自矜，被人以诗嘲骂，笑其无学。
原：万历初，苏州盘门外昆弟二人，忘其姓，一号兰溪，一号兰洲，争以恶诗唱和，高自矜许。或作诗嘲之曰：“盘门城外两诗伯，兰溪兰洲同一脉。胸中全无半卷书，纸上空污数行墨。浣花溪头杜少陵，浔阳江口李太白。二公阴灵犹未散，终日在天寻霹雳。有朝头上咶声能，打杀两个直娘贼。”
注：万历：明神宗年号。
注：盘门：苏州城南的城门。
注：一号兰溪，一号兰洲：兄弟二人之号，姓名佚。
注：诗伯：对诗坛前辈的称呼。
注：浣花溪：杜甫在成都的草堂所在。
注：杜少陵：杜甫。
注：浔阳江：李白诗中屡有提及，此处取“李白”。
注：霹雳：雷声，指要来劈打。
注：直娘贼：粗口骂人语，宋元俗语。
注：咶：同“咋”，呼声。
# 自诧才华
题解：北齐并州士族自夸才华，招人称赞，妻子劝阻，他叹才华不为家人所容。
原：《广记》：北齐并州有土族，好为可笑诗赋，轻蔑邢、魏诸公。众共嘲弄，虚相称赞，必击牛漉酒延之。妻知其妄，屡用泣谏。其人叹曰：“才华不为妻子所容，何况行路？”
注：《广记》：《太平广记》。
注：并州：今山西太原一带。
注：土族：当作“士族”，即门第人家；底本作“土”，疑误。
注：邢、魏：邢邵、魏收，北齐文坛名家。
注：击牛漉酒：宰牛滤酒，指宴请。
注：行路：路上陌生人。
# 阳俊之
题解：阳俊之的粗俗歌诗流传市肆，他还自夸才士，成为嘲谑对象。
原：阳俊之多作五言歌，词荡出拙，世俗流传，名为阳五伴侣，写卖不绝。俊之遇于市，言其字误，取而改之。卖者曰：“阳五，古之贤人。君何所知，轻敢议论！”俊之大喜，自言“有集十卷，虽家兄亦不知吾是才士”。
注：阳俊之：北齐人，阳休之之弟，《北齐书》有记。
注：五言歌：五言诗。
注：词荡出拙：言词荒诞而拙。
注：阳五伴侣：因其排行第五，称阳五，作品被称“伴侣”。
注：写卖：抄写贩卖。
注：家兄：阳休之，北齐著名文士。
# 崔泰之
题解：崔泰之哭李峤的诗全是俗语，却被他自夸有“真味”。
原：唐黄门崔泰之哭特进李峤诗曰：“台阁神仙地，衣冠君子乡。昨朝犹对坐，今日忽云亡。魂随司命鬼，魄逐见阎王。此时罢欢笑，无复向朝堂。”谓人曰：“作诗须有此真味！”
注：黄门：黄门侍郎。
注：崔泰之：唐人，官黄门侍郎，崔日用之弟，事见《太平广记》。
注：特进：唐代文散官，位在三公之下。
注：李峤：初唐“文章四友”之一，官至宰相，赠特进。
注：台阁：尚书台，指朝廷。
注：衣冠：官宦。
注：司命：掌命运之神。
注：阎王：阴间之主。
# 卢延让
题解：卢延让写诗好用狐、狗、猫、鼠等俗物，居然得到几位大人赏识，他自嘲得力于“狐狗猫鼠”。
原：卢延让业诗，二十五举方登第。卷中有“狐冲官道过，狗触店门开”之句，张濬每称赏之。又有“贼猫临鼠穴，馋犬舐鱼砧”，为成汭所赏。“栗爆烧毡破，猫跳触鼎翻”，为王建所赏。卢谓人曰：“平生谒尽公卿，不意得力于狐狗猫鼠！”
注：卢延让：唐末诗人，光化年间登第。
注：举：科举考试次数。
注：张濬：唐末宰相。
注：成汭：唐末荆南节度使，本为群盗，后据荆州，以粗豪得名。
注：王建：前蜀开国皇帝，早年为盗，后割据蜀地。
注：官道：官府修筑的大道。
注：砧：切鱼的案板。
注：毡：毡毯。
注：鼎：炊器。
# 包贺
题解：进士包贺的诗句粗鄙，且有一首“自落便宜诗”，以俚语入诗，令人发笑。
原：进士包贺作诗多粗鄙之句，如“苦竹笋抽青橛子，石榴树挂小瓶儿”，又“雾是山巾子，船为水靸鞋”，又“棹摇船掠鬓，风动水捶胸”，俱可笑。世传逸诗云：“窗下有时留客宿，斋中无事伴僧眠”，号曰：“自落便宜诗”。
注：包贺：唐人，事见《唐摭言》，待考。
注：青橛子：形容竹笋如橛子。
注：小瓶儿：喻石榴。
注：山巾子：山像头巾。
注：水靸鞋：水像拖鞋。
注：棹：船桨。
注：捶胸：拍胸。
注：便宜：占便宜。
# 高敖曹
题解：高敖曹所作杂诗皆用土俗比喻，粗朴可笑。
原：高敖曹尝为杂诗三首。其一：“冢子地握槊，星宿天围棋。开坛瓮张口，卷席床剥皮。”其二：“相送重相送，相送至桥头。培堆两眼泪，难按满胸愁。”其三：“桃生毛弹子，瓠长棒槌儿。墙欹壁凸肚，河冻水生皮。”
注：高敖曹：北齐名将高昂，字敖曹，《北齐书》有传。
注：冢子：坟墓；此指土堆。
注：握槊：古代博戏，类似双陆。
注：瓮：陶瓮。
注：培堆：泪水堆积，培土之意；一说疑误，待考。
注：毛弹子：弹丸。
注：瓠：葫芦。
注：欹：倾斜。
# 权龙襄
题解：权龙襄好作粗俗诗，通篇口语，反被皇帝喜欢，叫他“权学士”，是诗中“俗体”的代表。
原：唐左卫将军权龙襄，性褊急，常自矜能诗。通天年中，为沧州刺史。初到，乃为诗呈州官曰：“遥看沧海城，杨柳郁青青。中央一群汉，聚坐打杯觥。”诸公谢曰：“公有逸才！”襄曰：“不敢，趁韵而已。”又为《喜雨》诗曰：“暗去也没雨，明来也没云。日头赫赤出，地上绿氤氲。”又《皇太子宴夏日赋》诗： “严霜白浩浩，明月赤团团。”太子援笔为赞曰：“龙襄才子，秦州人士。明月昼耀，严霜夏起。如此诗章，趁韵而已！”襄以张易之事出为容山府折冲，后追入，献诗曰：“无事向容山，今日向东都。陛下敕进来，今作右金吾。”上大笑，每呼为权学士，凡与诸学士赋诗，辄令与焉。
注：左卫将军：禁卫将军。
注：权龙襄：唐人，曾为沧州刺史。
注：褊急：气量狭窄急躁。
注：矜：夸耀。
注：通天：武则天年号（696—697）。
注：沧州：今河北沧县一带。
注：杯觥：酒杯。
注：趁韵：为押韵而凑句。
注：《喜雨》诗：权龙襄所作。
注：赫赤：鲜红。
注：氤氲：烟气弥漫。
注：《皇太子宴夏日赋》：太子宴上命题作诗。
注：严霜：厉霜。
注：秦州：今甘肃天水一带。
注：张易之：武则天宠臣，被诛于神龙政变。
注：容山府：府兵名，待考。
注：折冲：折冲都尉，府兵长官。
注：东都：洛阳。
注：金吾：执金吾，禁卫官。
原：龙襄又《秋日述怀》曰：“檐前飞七百，雪白后园强。饱食房里侧，家粪集野螂。”参军不晓，请释。襄曰：“鹞子檐前飞，值七百文。洗衫挂后园，干白如雪。饱食房中侧卧，闻家中粪堆，集得野泽蜣螂。”谈者嗤之。
注：《秋日述怀》：权龙襄诗。
注：参军：幕僚。
注：鹞子：鹰类小猛禽。
注：蜣螂：屎壳郎。
注：嗤：讥笑。
# 宋宗子
题解：哲宗朝宗室子的拙诗，经他自释，满是谐音和曲解，连皇帝听了也笑得不能灸疗。
原：哲宗朝，有宗子好为诗，而鄙俚可笑。尝作《即事》诗云：“日暖看三织，风高斗两厢。蛙翻白出阔，蚓死紫之长。泼听琵琶凤。馒抛接建章。归来屋里坐，打杀又何妨？”人问其诗意。答曰：“始见三蜘蛛织网于檐前，又见二雀斗于两厢廊。有死蛙翻腹，似‘出’字，死蚓如‘之’字。方吃泼饭，闻邻家作《风栖梧》。食馒头未毕，阍人报建安章秀才上谒。按章既归，见内门上画锺馗击小鬼，故云‘打死又何妨’。”哲宗方欲灼艾，有小内侍诵此诗，笑极，遂罢炙。
注：宗子：宗室子弟。
注：《即事》诗：此宗子所作。
注：斗两厢：两廊相斗。
注：泼听琵琶凤：吃泼饭时听琵琶曲《凤栖梧》。
注：建章：汉宫名，此借指建安章秀才。
注：阍人：守门人。
注：建安：今福建建瓯。
注：风栖梧：词牌名《凤栖梧》。
注：锺馗：传说中捉鬼之神。
注：灼艾：用艾灸治病。
注：内侍：宦官。
注：罢炙：停止艾灸。
# 雪诗
题解：张打油之《雪》诗与陆诗伯的雪诗，均以俗语入诗，是打油诗的典型。
原：唐人有张打油，作《雪》诗云：“江上一笼统，井上黑窟窿。黄狗身上白，白狗身上肿。”
注：张打油：唐代民间诗人，“打油诗”之名由此而来。
注：一笼统：浑然一片。
注：黑窟窿：水井口。
原：陆诗伯《雪》诗云：“大雪洋洋下，柴米都长价。板凳当柴烧，吓得床儿怕。”又云：“玉皇大帝卖私盐，一个苏州拖面煎。”又云：“不闻天上打罗橱，满地纷纷都是面。”又云：“昨夜玉皇哀诏到，万里江山都带孝。”
注：陆诗伯：待考。
注：柴米都长价：柴米涨价。
注：板凳当柴烧：形容寒冷。
注：玉皇大帝卖私盐：想象雪如盐。
注：拖面煎：拖面煎饼。
注：罗橱：面箩。
注：哀诏：帝王去世的诏书，借喻天帝之丧，万里河山披雪如戴孝。
# 李廷彦
题解：李廷彦为求对偶工整，竟说兄弟全亡，被上官同情，他承认并无此事；一客取笑，把他的妾妻也拉进去。
原：李廷彦献百韵诗于上官，中云：“舍弟江南没，家兄塞北亡。”上官恻然，曰：“君家凶祸，一至于此！”廷彦曰：“实无此事，图对偶亲切耳。”一客谑云：“何不言‘爱妾眠僧舍，娇妻宿道房’？犹得保全兄弟。”
注：李廷彦：北宋人，献百韵诗，事见《闻见录》类笔记，待考。
注：百韵诗：一百韵（二百句）的长诗。
注：上官：上司。
注：没：死。
注：恻然：同情。
注：对偶亲切：对仗工整。
注：道房：道士住所。
# 诗僧
题解：曹琰讥诗僧所作诗句，以“卑吠狗儿肥”“犬吠张三嫂”挖苦其用字过俗，是以诗论诗的戏谑。
原：郎中曹琰，有僧以诗卷投谒。阅首篇，是《登润州甘露阁》云：“下观扬子小。”琰曰：“何不道‘卑吠狗儿肥’？”次阅一篇《送僧》云：“猿啼旅思凄。”琰曰：“何不道‘犬吠张三嫂？’”坐中大笑。
注：郎中：尚书省各司主官。
注：曹琰：宋人，事迹待考。
注：投谒：呈上诗卷拜见。
注：润州：今江苏镇江。
注：甘露阁：镇江甘露寺楼阁。
注：扬子：扬子江。
注：卑吠：“下观扬子小”的对仗；此句出自僧人原诗。
注：旅思：旅途的愁思。
# 不韵诗
题解：曲崇裕不通韵律，诗句生硬，被称“大才士”；明代织造太监的诗也只叶韵而已。
原：唐冀州参军曲崇裕《送司功入京》诗曰：“崇裕有幸会，得遇明流行。司士向京去，旷野哭声哀。”司功曰：“大才士！先生其谁？”曰：“吴儿博士教此声韵。”司功曰：“师明弟子哲！”
注：冀州：今河北冀县一带。
注：参军：地方官属。
注：曲崇裕：唐人，事见《太平广记》，待考。
注：司功：州府官名，掌考课。
注：明流行：此为诗中生硬词。
注：博士：州学博士。
注：师明弟子哲：老师高明，弟子才智。
原：嘉靖间，有织造太监在杭州，征索不遂，为诗云：“朝廷差我到苏州，府县官员不理咱。有朝一日朝京去，人生何处不相逢！”监司叹曰：“好诗！”答曰：“虽不成诗，叶韵而已。”
注：嘉靖：明世宗年号。
注：织造太监：明代派往苏杭督造织物的宦官。
注：监司：监察官，此指对太监有监管之权者。
注：叶韵：押韵。
# 重复诗
题解：本则以通篇重复词语的“诗”作笑料，如“一个孤僧独自归，关门闭户掩柴扉”，叠床架屋。
原：雍熙中，一诗伯作《宿山房即事》诗，曰：“一个孤僧独自归，关门闭户掩柴扉。半夜三更子时分，杜鹃谢豹子规啼。”又《咏老儒》诗曰：“秀才学伯是生员，好睡贪鼾只爱眠。浅陋荒疏无学术，龙钟衰朽驻高年。”
注：雍熙：北宋太宗年号。
注：诗伯：诗坛老手，此为讥称。
注：柴扉：柴门。
注：子时：夜十一时至一时。
注：杜鹃谢豹子规：三者均为同一鸟的异名。
注：秀才学伯是生员：秀才、学伯、生员均指读书人，叠加重复。
注：龙钟：老迈。
# 王大夫
题解：王祈自夸竹诗，被苏轼笑称“十条竹竿共一片叶”，形容夸饰失实。
原：王祈有竹诗两句，最为得意，为东坡诵之，曰：“叶垂千口剑，干耸万条枪。”苏笑曰：“好则好矣，只是十条竹竿共一片叶也。”又苏尝言：“看王大夫诗，难得不笑。”
注：王祈：北宋人，字晋卿，与苏轼同时。
注：王大夫：王祈曾任大夫官。
注：东坡：苏轼号东坡居士。
注：千口剑：喻竹叶如剑。
# 李超无自嘲
题解：李超无还俗后作诗自嘲，将僧人“贼秃”“光郎”之称写入诗。
原：李超无逃儒归墨，作诗自嘲云：“滚汤呼贼秃，摇铎骂光郎。”
注：逃儒归墨：从儒家逃至墨家；此处借指僧人还俗，实作者讥语。
注：贼秃：对僧人的辱称。
注：摇铎：摇铃，铎为金属铃，僧道和货郎常用。
注：光郎：对光头人的戏称。
# 涩体
题解：徐彦伯好以怪字替换常用词，所作被称“涩体”，是追求新奇过度的例子。
原：徐彦伯为文，多变奇求新，以“凤闱”为“鸥阃”，以“龙门”为“虬户”，以“金谷”为“铣溪”，以“刍狗”为“卉犬”，以“竹马”为“篠骖”，以“月兔”为“魄兔”，以“风牛”为“焱犊”。后追效之，谓之“涩体”。
注：徐彦伯：唐代文士，《旧唐书》有传。
注：变奇求新：追求新奇。
注：凤闱：中书省。
注：鸥阃：以“鸥”换“凤”，“阃”换“闱”，生造词。
注：龙门：山名，亦为科举登第之喻。
注：虬户：虬即龙，以“户”换“门”。
注：金谷：金谷园，西晋石崇别墅。
注：铣溪：以“铣”换“金”、“溪”换“谷”。
注：刍狗：祭祀用的草狗，《老子》有“天地不仁，以万物为刍狗”。
注：卉犬：以“卉”换“刍”，以“犬”换“狗”。
注：竹马：儿童以竹竿为马，嬉戏。
注：篠骖：以“篠”换“竹”，“骖”换“马”。
注：月兔：月中玉兔。
注：魄兔：“魄”指月之魄，仍指月兔。
注：风牛：《左传》“风马牛不相及”，风牛指走失的牛马。
注：焱犊：以“焱”换“风”，“犊”换“牛”。
注：涩体：文风艰涩之体。
# 虞子匡戏诗
题解：虞子匡将岳飞《送张紫岩北伐》诗逐字换成同义字，作文字游戏，讽刺嘉靖年间好奇字者。
原：嘉靖中，有好为六朝诗者，不独巧丽，且欲用不经人道之语，易字换句，遂至妄诞不稽。虞子匡一日递一诗示郎仁宝，请商之，仁宝三诵，不知何题。虞曰：“吾效时人换字之法，戏改岳武穆《送张紫阳北伐》诗也。”其诗曰：“誓律飙雷速，神威震坎隅。遐征逾赵地，力斗越秦墟。骥蹂匈奴颈，戈歼鞑靼躯。旋师谢彤阙，再造故皇都。”岳云：“号令风霆迅，天声动北陬。长驱渡河洛，直捣向燕幽。马蹀月氏血，旗袅可汗头。归来报明主，恢复旧神州。”不过逐字换之。遂抚掌相笑。
注：六朝诗：南朝文风绮丽。
注：不经人道：前人没有说过的。
注：妄诞不稽：荒谬无稽。
注：虞子匡：明人，事迹待考。
注：郎仁宝：郎瑛，字仁宝，明代杭州人，著《七修类稿》。
注：岳武穆：岳飞，谥武穆。
注：《送张紫阳北伐》：岳飞诗，应为《送紫岩张先生北伐》，“紫阳”为误，紫岩指张浚。
注：坎隅：北方；坎方为正北。
注：彤阙：朱红宫阙，指朝廷。
注：月氏：古代西域部族，借指金兵。
注：可汗：北方游牧民族首领。
注：燕幽：燕州、幽州，今河北北部。
# 宋景文修史
题解：宋祁修《新唐书》好用艰深文字，欧阳修以“宵寐匪祯，札闼洪休”戏讽，宋祁惭而改。
原：宋景文修唐史，好以艰深之辞，文浇易之说。欧公思有以训之。一日，大书其壁曰：“宵寐匪祯，札闼洪休。”宋见之，曰：“非‘夜梦不祥，题门大吉’耶？何必求异如此？”欧公曰：“《李靖传》云：‘震霆不暇掩聪’，亦是类也！”宋公惭而改之。
注：宋景文：宋祁，谥景文，与欧阳修同修《新唐书》。
注：唐史：《新唐书》。
注：文浇易之说：底本作“文浇”，疑当作“文浅易之说”，谓把浅显的话写成艰深。
注：欧公：欧阳修。
注：宵寐匪祯，札闼洪休：意为“夜梦不祥，题门大吉”，仿宋祁文风。
注：《李靖传》：《新唐书·李靖传》。
注：震霆不暇掩聪：本于《六韬》“疾雷不及掩耳”。
# 嘲窃句
题解：六则关于诗文剽窃的笑话，从陈亚、惠崇到西昆体、张怀庆、刘楚雄，嘲弄“偷句”之人。
原：陈亚《嘲窃古人诗句》诗云：“昔贤自是堪加罪，非敢言君爱窃词。叵奈古人无意智，预先偷子一联诗。”
注：陈亚：北宋人，好作药名诗。
注：叵奈：不可奈何。
注：意智：智谋。
注：偷子一联诗：偷了你一联诗。
原：僧惠崇能诗，其尤自负者：“河分冈势断，春入烧痕青。”崇之子弟嘲曰：“河分冈势司空曙，春入烧痕刘长卿。不是师兄多犯古，古人诗句犯师兄。”
注：惠崇：宋初九诗僧之一，擅画。
注：河分冈势断，春入烧痕青：惠崇句。
注：司空曙：唐代“大历十才子”之一，其《送郑明府贬岭南》有“河分冈势断”之句。
注：刘长卿：唐代诗人，其《送严维》有“春入烧痕青”之句。
注：犯古：与古人诗句相重。
原：潘邠老诗多犯老杜。王直方云：“老杜复生，须与潘十厮炒。”
注：潘邠老：潘大临，字邠老，北宋江西诗派诗人。
注：犯老杜：多袭杜甫诗句。
注：王直方：北宋人，著《王直方诗话》。
注：潘十：潘邠老排行十。
注：厮炒：吵闹争论。
原：祥符、天禧中，杨大年、钱文禧、晏元献为诗，皆宗李义山，号“西昆体”。后进效之，多窃取义山诗句。尝内宴，优人作戏，有为义山者，衣服破裂，告人曰：“吾为馆职诸公挦扯，以至如此！”坐者皆笑。
注：祥符、天禧：宋真宗年号。
注：杨大年：杨亿，字大年，西昆体领袖。
注：钱文禧：钱惟演，谥文僖。
注：晏元献：晏殊，谥元献。
注：李义山：李商隐，字义山。
注：西昆体：以《西昆酬唱集》得名，宗法李商隐，辞藻华丽。
注：后进：后辈。
注：内宴：宫廷内的宴会。
注：优人：演戏的艺人。
注：馆职诸公：秘阁、史馆等官员。
注：挦扯：撕扯。
原：李义甫《白燕》诗云：“镂月为歌扇，裁云作舞衣。自怜回雪影，好取洛川归。”有枣强尉张怀庆，好偷窃名士文章，乃增二字为七言，云：“生情镂月为歌扇，出性裁云作舞衣。照鉴自怜回雪影，来时好取洛川归。”时人谓之“活剥张昌龄，生吞郭正一”。
注：李义甫：疑当作“李义府”，唐高宗时宰相，其《咏鸟》诗被改，此处“《白燕》”，待考。
注：镂月：以月为形雕刻。
注：裁云：剪云为衣。
注：回雪：形容舞姿，曹植《洛神赋》“飘飖兮若流风之回雪”。
注：洛川：洛水，洛神所居。
注：枣强：今河北枣强县。
注：尉：县尉。
注：张怀庆：唐人，事见《朝野佥载》。
注：活剥张昌龄，生吞郭正一：张昌龄、郭正一为唐代文士，此言张怀庆抄袭他们；活剥生吞形容抄袭生硬。
原：武太常邦御，以水竹楼求刘楚雄为记，其文曰：“淇澳之斐，而瀑布急雨之，而碎玉密云之，而投壶铮铮之，而围棋丁丁之。巨细疾徐，皆先生之甔磬匏丝也。”又曰：“氅衣幅巾，见者以为神仙中人。”全用王元之《竹楼记》中语。有戏者曰：“昨梦一人，峨冠博带，意甚不平，曰：‘我宋学士王禹偁也，昔作郡守，有竹楼一座。今被刘楚雄拆毁，且将楼中之物，一一窃去。问是何物，曰：“楸枰一局，壶矢十二枝，文集十卷，氅衣一袭，幅巾一顶，止遗囊琴一张在焉。’又问：‘窃此何焉？’曰：‘都贮于太常水竹楼中，故不平也。’”
注：武太常邦御：待考。
注：水竹楼：楼名，待考。
注：刘楚雄：待考。
注：淇澳之斐：《诗经·卫风·淇奥》“有斐君子”，此处套用。
注：甔磬匏丝：用以指乐器，此处为王禹偁文中语。
注：氅衣幅巾：鹤氅和头巾，隐士装束。
注：王元之《竹楼记》：北宋王禹偁，字元之，《黄冈竹楼记》，中有“幅巾”“鹤氅”等语。
注：峨冠博带：高冠宽带，士大夫装束。
注：楸枰：棋盘。
注：壶矢：投壶用的矢。
注：囊琴：装在囊里的琴。
# 点金成铁
题解：王安石改王籍诗，将“鸟鸣山更幽”改作“一鸟不鸣山更幽”，被黄庭坚讥为“点金成铁”。
原：梁王籍诗云：“蝉噪林愈静，鸟鸣山更幽。”王荆公改用其句曰：“一鸟不鸣山更幽。”山谷笑曰：“此‘点金成铁’手也！”
注：王籍：南朝梁诗人，《入若耶溪》。
注：蝉噪林愈静，鸟鸣山更幽：王籍名句。
注：王荆公：王安石，封荆国公。
注：山谷：黄庭坚号山谷道人。
注：点金成铁：喻改坏好句。
# 倩笔
题解：吴平山请沈节甫改诗，沈另作一首，吴却把二句并入，凑成十句重一韵，成了笑话。
原：《霅溪纪闻》：湖州吴平山，素不能诗，值座师王荆石公寿，试作八句，求同年沈公节甫改削。沈用其韵，更制一首，复嫌于全革，姑举笔点其末二句，而并归之。吴大喜，谓沈所赏，语必佳；不忍弃，即书沈诗，而并载已二句于末，遂为十句，重一韵。王公大笑。
注：《霅溪纪闻》：笔记，待考。
注：霅溪：湖州，今浙江湖州。
注：吴平山：湖州人，待考。
注：座师：科举考生对主考官的称呼。
注：王荆石：王锡爵，号荆石，明代宰辅。
注：同年：同榜进士。
注：沈公节甫：沈节甫，湖州人，明代官员，嘉靖进士。
注：全革：全部改动。
注：重一韵：重复同一韵脚。
# 文当戒俗
题解：杨亿告诫门人避俗语，自己的表中却用“德迈九皇”，郑戬借“卖韭黄”“卖生菜”戏之。
原：杨文公尝戒其门人“为文宜避俗语”，即而公因作表示：“伏惟陛下，德迈九皇。”门人郑戬请于公曰：“卖韭黄讫，未审何时得卖生菜？”公大笑，易之。
注：杨文公：杨亿，谥文，北宋西昆体领袖。
注：德迈九皇：德行超越三皇五帝。
注：郑戬：北宋人，曾任参知政事。
注：卖韭黄：谐“九皇”。
注：生菜：谐“三皇”，戏谓“九皇”之后应有“三皇”。
# 书马犬事
题解：欧阳修以马踏狗的事为题，用“逸马杀犬于道”六字，说明记事须简练。
原：欧阳公在翰林时，常与同院出游。有奔马毙犬，公曰：“试书其一事。”一曰：“有犬卧于通衢，逸马蹄而杀之。”一曰：“有马逸于街衢，卧犬遭之而毙。”公曰：“使子修史，万卷未已也。”曰：“内翰云何？”公曰：“逸马杀犬于道。”相与一笑。
注：欧阳公：欧阳修。
注：翰林：翰林院。
注：通衢：大路。
注：逸马：脱缰之马。
注：内翰：翰林学士的尊称。
注：修史：撰写史书，欧阳修曾修《新唐书》《新五代史》。
# 明堂赦文
题解：胡卫、卢祖所草赦文有“尽扫于胡尘”，太学生以“于”字结尾戏嘲，转“胡卢”为“葫芦”。
原：胡卫、卢祖在翰林，草明堂赦文云：“江淮尽扫于胡尘。”太学生嘲之曰：“胡尘已被江淮扫，却道江淮尽扫于。传语胡、卢二学士，不如依样画胡卢。”
注：胡卫：南宋人，事迹待考。
注：卢祖：当作“卢祖皋”，南宋词人，曾任翰林。
注：明堂：古代帝王祭祀、颁布政令的场所。
注：赦文：大赦诏书。
注：胡尘：指金兵。
注：太学生：太学学生。
注：依样画胡卢：俗语“依样画葫芦”，胡卢即葫芦，双关“胡卢二学士”。
# 押韵
题解：梅权衡押“谅”字出奇，竟以《老子》句式诌出怪句；苗振押“王”字却照搬“莫非王”，得“倒绷孩儿”之讥。
原：唐梅权衡，吴人也，入试不持书策，人皆谓奇才。及府题出《青玉案赋》，以“油然易直子谅之心”为韵。场中竞谈 “谅”字难押。梅于庭树下，以短棰画地起草。日晡，梅赋先成。张季遐求视所押，以为师模。梅大言曰：“押字须商量，争应进士举？”季遐自谦薄劣，乃率数十人请益。梅曰：“此韵难押，诸公且厅上坐，听某押处解否。”遂朗吟曰：“恍兮惚兮，其中有物。惚兮恍兮，其中有谅。犬蹲其旁，鸱拂其上。”因讲青玉案者是食案，所以言“犬蹲其傍，鸱拂其上”也。众大笑
注：梅权衡：唐吴人，事见《太平广记》。
注：府题：府试题目。
注：青玉案赋：以“案”为题。
注：油然易直子谅之心：出自《礼记·乐记》“易直子谅之心油然生矣”。
注：押：押韵。
注：晡：申时。
注：张季遐：待考。
注：师模：学习典范。
注：恍兮惚兮，其中有物：《老子》第二十一章“惚兮恍兮，其中有物”，梅氏此处将“物”换成“谅”。
注：鸱：鸱鸮。
注：食案：食桌。
原：苗振召试馆职。晏丞相语曰：“宜稍温习。”苗曰：“岂有三十年作老娘，而倒绷孩儿者乎？”既试赋，韵有“王”字。振押云：“率土之滨莫非王。”不中选。晏笑曰：“苗君竟倒绷孩儿矣！”
注：苗振：北宋人，曾召试学士院。
注：馆职：秘阁、史馆等官职。
注：晏丞相：晏殊。
注：老娘：接生婆。
注：倒绷孩儿：给婴儿打包被倒了，喻因熟极而出错。
注：率土之滨莫非王：《诗经·小雅·北山》“率土之滨，莫非王臣”，苗振因“王”字押韵，仅用“莫非王”，不成句。
# 赋
题解：胡旦、杨孜至庆历、熙宁诸赋的奇句，以及褚归的赋，都被时人当作可笑之作。
原：胡旦作《长鲸吞舟赋》云：“鱼不知舟在腹中，其乐也融融；人不知舟在腹内，其乐也泄泄。”又曰：“双须竿直，两目星悬。”杨孜览而笑曰：“许大鱼，眼孔恁小！”又庆历中，试题为《天子之堂九尺》。赋者曰：“成汤当陛而立，不欠一分；孔子历阶而升，止馀六寸。”用《孟子》曹交言汤九尺、《史记》言孔子九尺六寸事。
注：胡旦：北宋状元，著《长鲸吞舟赋》。
注：融融：和乐。
注：泄泄：舒缓自得，《左传》隐公元年“其乐也融融，其乐也泄泄”，指舟中之乐。
注：杨孜：宋人，待考。
注：许大：这么大。
注：庆历：宋仁宗年号（1041—1048）。
注：《天子之堂九尺》：此为试题。
注：成汤：商汤。
注：陛：台阶。
注：曹交言汤九尺：《孟子·告子下》，曹交问“交闻文王十尺，汤九尺”。
注：孔子九尺六寸：《史记·孔子世家》。
原：熙宁中，省试《王射虎侯赋》。有一卷云：“讲君子必争之艺，饰大人所变之皮。”又欧阳公主文，试《贵老为其近于亲赋》。有一卷云：“睹兹黄耆之状，类我严君之容。”
注：熙宁：宋神宗年号。
注：省试：礼部试。
注：《王射虎侯赋》：以《周礼》“王大射，则共虎侯、熊侯、豹侯”为题。
注：君子必争之艺：《论语·八佾》“君子无所争，必也射乎”。
注：大人所变之皮：《周易·革》“大人虎变”。
注：欧阳公主文：欧阳修主持礼部考试，指嘉祐二年。
注：《贵老为其近于亲赋》：题出《礼记·祭义》。
注：黄耆：黄发耆老，亦暗指中药黄芪；形容老者。
注：严君：父亲。
原：褚归应试，作《大舜善与人同》，破云：“道虽贯于万世，善犹同于众人。”见黜。一友戏慰曰：“公以‘尿罐’对‘油筒’，宜其黜落。”
注：褚归：宋人，待考。
注：《大舜善与人同》：题出《孟子·公孙丑上》。
注：破：作文开头破题。
注：黜：落选。
注：尿罐：与“油筒”对举，谐“善同”“与人”之对仗拙劣，意在戏谑，待考。
# 经义
题解：政和年间有学生答《周礼》“禁宵行者”，竟以宰予昼寝为证，说他是在白天睡好，夜里出来乱走。
原：政和中，举子皆试经义。有学生治《周礼》，堂试以《禁宵行者》为题，此生答义云：“宵行之为患者大矣，凡盗贼奸淫为过恶者，白昼不能显行也，必昏夜合徒窃发。踪迹幽暗，虽欲捕治，不可物色。故先王命官曰‘司寤氏’，而立法以禁之，有犯无赦，宜矣！不然，则宰予昼寝，何以得罪于夫子？”学官者甚喜其议论有理，但不晓以宰予为证之意，因召问之。答曰：“昼非寝时也。今宰予正昼而熟寐，其意必待夜间出来胡行乱走耳！”学官为笑而止。
注：政和：宋徽宗年号（1111—1118）。
注：经义：以经书文句出题的论说文。
注：《周礼》：儒家经典，记职官制度。
注：堂试：学校内部考试。
注：禁宵行者：《周礼·秋官》“司寤氏”职掌禁夜行。
注：物色：寻访。
注：司寤氏：《周礼·秋官》官名，掌夜晚禁止行走。
注：宰予昼寝：《论语·公冶长》“宰予昼寝，子曰：朽木不可雕也”。
注：学官：学校教师。
# 时艺
题解：四则八股时文笑话：陈献章破题被批“等一等”，徐州士把“冯妇”当女人，另有分股、立柱之怪文，以及求教唐寅者被讥。
原：陈白沙献章，当成化初会试，虽负重名，亦投时好，竞出新奇，作《老者安之，朋友信之，少者怀之》题，其破云：“物各有其等，圣人等其等。”考官戏批其傍云：“若要中进士，还须等一等！”
注：陈白沙献章：陈献章，号白沙，广东新会人，明代理学家，“江门学派”创始人。
注：成化：明宪宗年号。
注：会试：京城举行的全国性科举考试。
注：时好：时尚文风。
注：《老者安之，朋友信之，少者怀之》：《论语·公冶长》孔子言志，为八股试题。
注：破：八股文的“破题”，即开头点明题意的两句。
注：物各有其等，圣人等其等：“等其等”，意为按等级对待；考官据“等”字，戏批其须“等一等”再中进士。
原：张鳌山提学江北，以《冯妇善搏虎》为题。徐州一士云：“冯妇，一妇人也，而能搏虎；不惟搏也，而又善焉。夫搏虎者何？扼其吭，斩其头，剥其皮，投于五味之中而食之也，岂不美哉！”
注：张鳌山：张鳌山，明人，曾任提学，待考。
注：提学：提学官，主管一省学政。
注：江北：长江以北。
注：《冯妇善搏虎》：《孟子·尽心下》“晋人有冯妇者，善搏虎，卒为善士”。
注：扼其吭：扼住咽喉。
注：五味：各种调味，指烹食。
原：王荆湖学博谈及吴郡一士，作《今交九尺四寸以长》题，文中将“九尺以长”、“四寸以长”分股。又一士作《二女果》题，文中二股立柱云：“尧非不欲以之自奉也，舜非不欲以之奉瞽瞍也。”闻者绝倒。
注：王荆湖：待考。
注：学博：府州县学教官。
注：吴郡：今苏州一带。
注：《今交九尺四寸以长》：《孟子·告子下》曹交语“交长九尺四寸以长”。
注：分股：八股文分为若干“股”，此士将一句截成两股，不通。
注：《二女果》：《孟子·尽心下》“舜之饭糗茹草也……及其为天子也，被袗衣，鼓琴，二女果”，意为尧使二女侍奉舜。
注：立柱：八股文中提出对偶论点的两股称“立柱”。
注：瞽瞍：舜之父。
原：一士作《能近取譬》题文，质于唐六如。唐称赞不已。士又再三求正，唐曰：“细玩‘能近取’三字不做，觉偏枯些。”士嘿然而去。
注：《能近取譬》：《论语·雍也》“能近取譬，可谓仁之方也已”。
注：质：求教。
注：唐六如：唐寅，号六如居士，明代书画家。
注：偏枯：偏重一边，不匀称。
注：嘿然：沉默。
# 评唐诗
题解：杨慎批评《全唐诗话》滥收劣诗，以燕赵佳人中混有跛眇之辈作比，说明选诗不严之弊。
原：杨用修曰：“唐诗有极劣者，宋人采入《全唐诗话》，使观者曰：“是亦唐诗一体。”譬之燕、赵多佳人，其间有跛者、眇者、羝者、氲者、疥且痔者，乃专房宠之，曰：“是亦燕、赵佳人之一种。”可乎？
注：杨用修：杨慎，字用修，号升庵，明代学者。
注：《全唐诗话》：宋人尤袤所编唐诗话，此处实指《唐诗纪事》类，待考。
注：一体：一种风格。
注：燕、赵多佳人：古诗“燕赵多佳人，美者颜如玉”。
注：眇：一眼瞎。
注：羝者：疑指有腋臭者。
注：氲者：待考，疑当作“氤”或指其他病症。
注：疥：疥疮。
注：痔：痔疮。
注：专房宠：独占宠爱。

题解：集中罗列前人诗文之病：或谐音，或用字重复，或堆砌典故、数字，或以俗对雅，直指选词造句之弊。
原：简文时，费旭诗有句云：“不知是耶非？”殷芸诗有“飘飏云母舟”句。帝大笑曰：“旭既不识其父，芸又飘飏其母耶？”

原：有迁楚藩者，李于鳞以诗送之，云：“江汉日高天子气，楼台秋入大王风。”一友曰：“二语似贺陈友谅登极。”
注：迁：调任。
注：楚藩：楚王藩国，明代封于武昌。
注：李于鳞：李攀龙，字于鳞，明代后七子领袖。
注：江汉日高天子气：写楚地有天子气，犯忌。
注：大王风：宋玉《风赋》“楚襄王游于兰台……有风飒然而至，王曰：快哉此风！寡人所与庶人共者邪”，此处借指楚王。
注：陈友谅：元末起义军首领，据武昌称帝建汉。
原：《古今诗话》：乐天《长恨歌》云：“峨眉山下少人行，旌旗无光日色薄。”峨嵋在嘉州，与幸蜀路全无交涉。杜甫《武侯庙柏》诗云：“霜皮溜雨四十围，黛色参天二千尺。”四十围乃径七尺，无乃太细长也。史称防风氏身广九亩，长三丈。按广大尺，九亩乃五十丈四尺，如此防风之身乃一饼餤身。此文章之病也。
注：《古今诗话》：宋人所撰诗话，待考。
注：峨眉山下少人行：白居易《长恨歌》句，写玄宗入蜀。
注：嘉州：今四川乐山，峨眉山在其西南。
注：幸蜀：皇帝逃往蜀地。
注：霜皮溜雨四十围，黛色参天二千尺：杜甫《古柏行》（诗题《武侯庙柏》），沈括《梦溪笔谈》批评此语太细长。
注：围：古代一围约五寸或双臂合抱。
注：防风氏：古代传说中的巨人，《国语·鲁语下》言其骨节专车。
注：广大尺：待考。
注：饼餤：薄饼，一种饼食。
原：张文潜常云：“子瞻每笑‘天边赵盾益可畏，水底右军方熟眠’，谓‘汤𬊈了王羲之也’。”文潜戏谓子瞻云：“公诗有‘独看红蕖倾白堕’，不知‘白堕’是何物？”子瞻云：“《洛阳伽蓝记》有刘白堕，善酿酒。”文潜曰：“白堕既是人，何以言倾？”子瞻笑曰：“魏武《短歌行》云：‘何以解忧？惟有杜康’。杜康亦是酿酒人名也。”文潜曰：“毕竟用得不当。”时文潜有仆曹某，失去酒器。子瞻笑曰：“公且先去理会曹家那汉，却来此间厮魔。”满座大笑。
注：张文潜：张耒，字文潜，苏门四学士之一。
注：子瞻：苏轼，字子瞻。
注：天边赵盾益可畏，水底右军方熟眠：苏轼诗句，写日、月之影，《左传》文公七年酈缺称“赵衰，冬日之日也；赵盾，夏日之日也”。
注：汤𬊈：疑当作“烫”，此处指水中右军被热水烫，戏言。
注：王羲之：东晋书法家，官至右军将军。
注：红蕖：红色荷花。
注：白堕：刘白堕，北魏洛阳善酿酒者，见《洛阳伽蓝记》。
注：倾：倒，倒酒。
注：《短歌行》：曹操乐府诗，“何以解忧，唯有杜康”。
注：杜康：传说中酿酒始祖。
注：曹某：张耒的仆人，姓曹。
注：理会：处置，追问。
注：厮魔：纠缠，嬉闹。
# 九字诗
题解：记中峰和尚、卢赞元的九字诗，字数过多、句法拗口，是“不合体”之诗的例子。
原：中峰和尚有九字梅花诗云：“昨夜西风吹折千林梢，渡口小艇滚入沙滩坳。野树古梅独卧寒屋角，疏影横斜暗上书窗敲。”卢赞元酴醿花诗：“天将花王国艳殿春色，酴醿洗装素颊相追陪。绝胜浓英缀枝不韵李，堪友横斜照水搀先梅。”
注：中峰和尚：元代高僧中峰明本。
注：九字梅花诗：每句九字，不合常见诗体。
注：卢赞元：待考。
注：酴醿：花名，即荼蘼，春末开。
注：花王：牡丹。
注：艳殿春色：在春尽时开放。
注：照水搀先梅：待考。
