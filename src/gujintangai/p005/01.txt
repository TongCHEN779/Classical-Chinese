# 正文
题解：《谬误》部总序：冯梦龙借“郑人争年”“枕流嗽石”等例，说明谬误无定名，不误犹误。
原：〔子犹曰：谬误原无定名，譬之郑人争年，后息者胜耳。喙长三尺，则“枕流嗽石”，语自不错。若论灾发妖兴，贼民横路，即太极之生天、生地、生人，亦是第一误事，将谁使正之？齐有人，命其狗为“富”，命其子为“乐”。方祭，狗入于室，叱之曰：“富出！”其子死，哭曰：“乐乎！乐乎！”人以为误也，则孰知其非误也，然而不可谓非误也。夫不误犹误，何况真误？集《谬误》第五。〕
注：子犹曰：子犹，冯梦龙之号。
注：郑人争年：《韩非子·说林上》载二人争年龄大小，一人称与尧同年，一人称是黄帝之兄同年，三年不决，后说话者获胜。
注：喙长三尺：语出《庄子》，形容善辩，此处讥其强辩。
注：枕流嗽石：孙楚想说“枕石漱流”，误作“漱石枕流”，被王济问，强辩为“漱石欲砺其齿”，见《世说新语·排调》。
注：太极之生天、生地、生人：宋儒周敦颐《太极图说》所言宇宙生成。
注：命其狗为“富”，命其子为“乐”：事见《笑林》等，此处用作误称例，出处待考。
# 祠庙
题解：民间对祠庙名称的传讹：蒲池寺成菩提寺，小孤山成小姑，阙口庙成豁口大王等。
原：欧公《归田录》云：世俗传讹，惟祠庙之名为甚。今成都显圣寺者，本名蒲池寺，周显德中广之，更名显圣，而俚俗多沿旧名，今传为菩提寺矣。江中有大小孤山，以独立得名，而世俗传“孤”为“姑”。江侧有大石矶，谓之澎浪矶，遂传为“彭郎矶”，云彭郎，小姑婿也。予尝登小孤，庙像乃一妇，而敕额为“圣母庙”，岂止俚俗之戮哉！西京龙门山，夹伊水上自端阙，望之如双阙，故谓之“阙塞”，而山口有庙曰“阙口庙”。予尝见其庙像甚勇，手持屠刀尖锐，按膝而坐。问之，云：“此乃豁口大王也。”此尤可笑。
注：欧公《归田录》：欧阳修《归田录》，此条见其卷二。
注：显圣寺：在成都，原名蒲池寺。
注：周显德：后周世宗年号（954—960）。
注：大小孤山：长江中的两座孤山，小孤山在今江西彭泽。
注：澎浪矶：小孤山旁的矶石。
注：彭郎矶：传说彭郎为小姑之婿，实为误传。
注：敕额：朝廷颁赐的庙额。
注：戮：辱，此处作玷辱解。
注：西京龙门山：洛阳龙门山，伊水流经，古称伊阙。
注：阙塞：伊阙，汉时称“阙塞”。
注：豁口大王：误由“阙口”传讹，神像持屠刀，被俚俗附会。
原：汲郡有肖像“三仁”并及商纣者，谓之“四王”。
注：汲郡：今河南卫辉一带，传有比干墓。
注：三仁：殷末微子、箕子、比干，孔子称“殷有三仁焉”。
注：四王：误把纣王也列为神像，合称四王。
原：沮州有“杜拾遗庙”，后讹为“杜十姨”，塑妇人像。邑人以“五撮须相公”无妇，移以配之。五撮须，盖伍子胥也。又江陵村事子胥，误呼“伍髭须”，乃塑五丈夫，皆多须者。每祷祭，辄云“一髭须”、“二髭须”至“五髭须”。
注：沮州：待考，或为地名误字。
注：杜拾遗庙：祭祀杜甫（官左拾遗）的庙。
注：杜十姨：民间误称，塑成妇人像。
注：五撮须相公：误传，实指伍子胥。
注：伍子胥：春秋时楚国人，吴大夫，被吴王夫差赐死，民间奉为潮神。
注：髭须：胡须。
原：陈州厄台寺，相传孔子绝粮处，旧榜“文宣王”，因风雨洗剥，但存“王”字及“宣”字下一画。僧遂附会为“一字王佛”。
注：陈州厄台寺：在今河南淮阳，传为孔子厄于陈蔡处。
注：文宣王：唐开元二十七年追谥孔子为文宣王。
注：一字王佛：佛教的佛号，此处是风雨剥蚀后“王”字被误认，附会为佛。
# 蔡伯喈
题解：驿吏供奉杜康、陆羽、蔡伯喈，可笑。
原：江南一驿吏，以干事自任。典郡者初至，吏曰：“驿中毕备，请阅之。”刺史入酒室，见一像，问之，曰：“是杜康。”又入茶室，见一像，问之，曰：“是陆鸿渐。”刺史大喜。又一室，诸菜毕备，亦有一像，问之，曰：“蔡伯喈。”刺史大笑，曰：“此不必。”
注：典郡：主持一郡事务，即太守。
注：杜康：传说中的酿酒始祖，酒神。
注：陆鸿渐：陆羽，字鸿渐，唐代“茶圣”，著《茶经》。
注：蔡伯喈：蔡邕，字伯喈；“蔡”与“菜”同音，驿吏以他作菜神，是谐音错误。
# 茶神
题解：茶肆奉陆羽像为茶神，以茶祭之。
原：唐传载云：时有鬻茶之家，陶为陆羽像，置炀器间，谓之茶神。有交易，则以茶祭之；无，则以釜汤沃之。
注：唐传载：唐刘馀撰《传载》，一称《大唐传载》，后世转引。
注：陶为陆羽像：用陶土塑陆羽像。
注：炀器：烹茶的器具，炀即烧火煮茶。
注：釜汤沃之：用锅里的热水浇灌。
# 鬼误
题解：楚俗信鬼，被好事者戏弄成灵；夜行人遇雨，与另一人互疑为鬼。
原：《谑浪》：楚俗信鬼，有病必祷焉。尝夜祷于北郭门外，好事者遇之，窃翳身于葬，而投以砂砾。祷者恐，稍远去；益投，益远去，乃撄其肉而食焉。人以为灵也，祷益盛，而北郭门之灵鬼遂著。其后祷者不失肉，即反谓鬼不享而忧之。
注：《谑浪》：明代江盈科等所编笑话集之类，具体书待考。
注：北郭：北城门外。
注：翳身：藏身。
注：葬：疑当作“莽”，指草丛。
注：砂砾：沙粒碎石。
注：撄：触，此处作取讲。
原：《续笑林》：有赴饮夜归者，值大雨，持盖自蔽，见一人立檐下溜，即投伞下同行。久之，不语，疑为鬼也，以足撩之，偶不相值，愈益恐，因奋力挤之桥下而趋。值炊糕者晨起，亟奔入其门，告以遇鬼。俄顷复见一人，遍体沾湿，踉跄而至，号呼“有鬼”，亦投其家。二人相视愕然，不觉大笑。
注：《续笑林》：明代笑话集，《笑林》的续书。
注：檐下溜：屋檐滴水处。
注：撩：用脚拨动。
注：踉跄：走路摇晃。
# 凶宅误
题解：袁继谦居凶宅，其实是狗头入油瓮；洪都大户怪响，原是巨鼠。
原：袁继谦郎中，顷居青社。假一第，素多凶怪，昏曀即不敢出户庭，合门惊惧。忽一夕闻吼呼，若瓮中声，至浊。举家怖惧，谓其必怪之尤者，穴窗窥之。是夕月晦，见一物苍黑色，来往庭中，似黄狗身，而首不能举。乃以铁挝击其脑，忽轰然一声，家犬惊吼而去。盖其日庄上输油至，犬以首入油瓮中，不能出故也。举家大笑，遂安寝。
注：袁继谦：北宋人，事见宋人笔记，待考。
注：青社：青州，今山东青州。
注：假：租借。
注：昏曀：昏暗。
注：铁挝：铁制的敲击器。
注：庄上：田庄上。
原：洪都村中一大家，厅楼崇敞。每夜声响特异，以为妖，避而虚其室。有道士过门，称自龙虎山来。其家大喜，邀入，与约妖除当厚酬。道士入居之。夜见硕鼠尾巨如椎，跃入破柱，从柱击出，斩之。盖鼠尾始被啮流血，行沙中，霑沙重，既干，巨如椎；其作响皆是物，非妖也。道士乃山下鬻赝符者，幸获重赂，其名遂著。
注：洪都：今江西南昌。
注：龙虎山：江西贵溪，道教天师道祖庭。
注：椎：槌。
注：赝符：假的符箓。
# 庐山精
题解：刘秉仁带来的骆驼被野人当成“庐山精”射杀。
原：《稗史》：唐刘秉仁为江州刺史，自京将一橐驼至郡，放之庐山下。野人见而大惊，鸣鼓率众射杀之，乃以状白州，曰：“某日获庐山精于某处。”刘命致之，乃所放驼耳。
注：《稗史》：野史笔记。
注：刘秉仁：事迹待考。
注：橐驼：骆驼，北方所产。
注：庐山精：庐山精怪。
# 惊潮
题解：达鲁不花因不知海潮而惊慌失措，闹出笑话。
原：海上每遇八月，秋涛大作，潮声夜吼，震撼城市。至正间，有达鲁不花者初至，闻此，夜不敢卧。因呼门者问之。门者从睡中应曰：“潮上来也！”既觉，自知失答，连曰：“祸到！祸到！”狂走而出。不花惊趋入内，呼其妻曰：“本冀作官荣耀，不意今夕共作水鬼！”合门号恸，外巡徼闻哭，以为有变，传报正佐诸官，皆颠倒衣裳来救。乃叩门，不花恐水涌入，坚闭不纳。同僚破扉排墙而入，见不花夫妇及奴婢皆升屋大呼“救我”。同僚询知其实，忍笑而散。
注：至正：元顺帝年号（1341—1368）。
注：达鲁不花：元代官员，此事具体所指待考。
注：秋涛：钱塘潮，农历八月最盛。
注：巡徼：巡逻差役。
注：正佐：正官和佐官。
注：升屋：爬上屋顶。
# 甘子布
题解：甘子布被误认为布裹柑子的案情，令长史疑惧。
原：益州进柑，例以纸裹。后长史易布，犹虑损坏。俄有御史姓甘名子布者至驿，驿吏驰报。长史疑敕御史来推布裹柑子事，参谒后，但叙布裹柑子为敬。御史初不解，久方悟，付之一笑。
注：益州：今四川成都一带。
注：进柑：进贡柑橘。
注：长史：州府佐官。
注：姓甘名子布：唐代官员，“甘子布”谐“柑子布”。
注：参谒：拜见。
# 皮遐叔
题解：卢尚书把“皮遐叔”当成姓卢的同宗，闹笑话。
原：卢尚书弘宣，与弟卢衢州简辞同在京。一日衢州早出归，尚书问有何除改，答云：“无大除改，唯皮遐叔蜀中刺史。”尚书不知“皮”是“遐叔”姓，谓是宗人，低头久之，曰：“我弭节当家，没处得卢皮遐来。”衢州为言之，皆大笑。
注：卢尚书弘宣：唐代官员，即卢弘宣，官至刑部尚书。
注：卢衢州简辞：卢简辞，唐代官员，曾任衢州刺史，弘宣之弟。
注：除改：任命、调动官职。
注：皮遐叔：人名，姓皮。
注：弭节：停车，此处语意待考。
注：宗人：同宗之人。
# 同姓议婚
题解：同姓议婚，被保姆、被对方点破而悟。
原：唐张守信为馀杭守，爱富阳尉张瑶，欲以女妻之，为具衣装矣。女之保母问曰：“欲以女适何人？”守信以张瑶对。保母曰：“女婿姓张，不知主翁之女何姓？”守信方悟，乃止。
注：张守信：唐代余杭太守，事见《朝野佥载》。
注：富阳尉：富阳县尉。
注：保母：保姆。
注：主翁：对主人家主的尊称。
原：唐御史李逢年娶妇郑，不合，去之。尝属益府尹曹李睨更求一妇。睨言兵曹李扎妹新寡可娶，叩扎，扎亦许诺，约日成婚。及期，逢年饰装往迎，中道忽惊曰：“李睨过矣！”因诣睨曰：“君思扎妹为复何姓？”睨亦惊，过李扎曰：“吾乃大误！但知为公求好婿，为御吏求好妇，都不思姓氏！”各懊恨而退。
注：李逢年：唐代御史，事见《朝野佥载》。
注：益府尹曹：益州府的官员。
注：李睨：与李逢年同姓。
注：兵曹：兵曹参军。
注：李扎：同姓之人。
# 疑姓
题解：县令妇伍氏以为陆氏、戚氏与她作对，因姓字谐音误会。
原：阳伯博任山南一县丞，其妻陆氏，名家女也。县令妇姓伍。他日会诸官之妇，既相见，县令妇问赞府夫人何姓，答曰：“姓陆。”次问主簿夫人，答曰： “姓戚。”县令妇勃然入内。诸夫人不知所以，欲却回。县令闻之，遽入问其妇。妇曰：“赞府妇云姓陆，主簿妇云姓戚，以吾姓伍，故相弄耳！馀官妇赖吾不问，必曰姓八、姓九矣！”令大笑曰：“人各有姓。”复令妇出。
注：阳伯博：唐代人，任山南某县县丞。
注：赞府：县丞的别称。
注：陆氏：谐“六”。
注：姓戚：戚谐“七”；伍氏，陆、戚、伍连起，则被疑嘲弄。
注：姓八、姓九：令妇妄想别人会再往后说“八”“九”。
# 兄弟误
题解：兄弟貌相似，被误认，与一人吃尽青梅。
原：张伯喈、仲喈兄弟，貌绝相类。仲喈妻妆竟，忽见伯喈，戏曰：“今日妆好不？”伯喈曰：“我伯喈也。”妻急趋避。须臾又见伯喈，复以为仲喈，告云：“向大错误。”伯喈云：“我故伯喈。”
注：张伯喈、仲喈：兄弟二人，事待考。
原：长洲刘宪副瀚之族，有兄弟二人，初本孪生，貌极相肖。市有鬻青梅者，梅甚大，其兄戏与决赌云：“能顿食百颗。”市人云：“果尔，当尽以担中梅相饷。”刘食其半，佯称便，旋入门。而其弟代之出，食至尽。众莫能辨，遂为所胜。
注：长洲刘宪副瀚：刘瀚，明代长洲人，曾官按察副使。
注：孪生：双胞胎。
注：青梅：未熟的梅子。
注：决赌：打赌。
# 意气
题解：虞啸父误会孝武帝“献替”，答以鱼鳖，笑话。
原：虞啸父为孝武侍中。帝从容谓曰：“卿在阁下，初不闻有献替。”虞家富春近海，误谓帝望其意气，对曰：“天时尚暖，鱼鳖虾蜣未可致。寻当有献。”帝抚掌大笑。
注：虞啸父：东晋人，《晋书》有传，官侍中。
注：孝武：晋孝武帝司马曜。
注：献替：进献可行之事，替除不可行者，即向君主进言。
注：富春：今浙江富阳。
注：意气：此处为兴致。
# 误食
题解：王敦误食塞鼻枣、澡豆。
原：王敦初尚主，如厕，见漆箱盛干枣，本以塞鼻。王谓厕上亦下果，遂至食尽。既还，婢擎金澡盘盛水，琉璃盘盛澡豆。因倒著水中而饮之，谓是干饭。群婢掩口。
注：王敦：东晋权臣，曾尚晋武帝女襄城公主。
注：漆箱盛干枣：厕所中备用以塞鼻。
注：澡豆：古代洗手用的豆粉。
注：干饭：干粮饭。
# 鸡舌香
题解：迺存口含鸡舌香而误以为毒药。
原：桓帝侍中迺存，年老口臭，上出鸡舌香与含之。鸡舌颇小，辛螫不敢咀咽，嫌有过赐毒，归舍辞诀。家人哀泣，莫知其故，求舐其药，出在口香，乃咸嗤笑。
注：桓帝：汉桓帝。
注：侍中迺存：《汉官仪》所载，待考。
注：鸡舌香：丁香花蕾，古时侍臣奏事口含以香口。
注：辛螫：辛辣刺口。
注：辞诀：告别。
# 常春藤
题解：姜抚称服常春藤可长生，民间以此酿酒，多暴死。
原：唐姜抚云：服太湖常春藤，终南山旱藕，可长生。玄宗诏使自求之。民间以藤渍酒，多暴死，抚逃去。
注：姜抚：唐玄宗时方士，《新唐书》有载。
注：常春藤：五加科植物，此处作药用。
注：旱藕：终南山产的一种药物，相传能延年。

# 罗长官

注：扪：摸。
注：重辟：死刑。

原：至元丁丑六月，民间谣言朝廷将采童男女以授鞑靼为奴婢，且俾父母护送交割。自中原至江南，人家男女年十二、三以上，便为婚嫁，扰扰十馀日方息。吴僧柏子庭有诗戏之，曰：“一封丹诏未为真，三杯淡酒便成亲。夜来明月楼头望，唯有嫦娥不嫁人。”隆庆戊辰，有私阉人者，名张朝，假传奉旨来浙直选宫女。一时惊婚者众，舆人、厨人无从顾觅，亦如至元故事。有人改子庭诗云：“抵关内使未为真，何必三杯便做亲？夜来明月楼头望，吓得姮娥要嫁人。”又讹言并选寡妇伴送入京。于是孀居无老少，皆从人，有守制数十年，不得已，亦再适。又有人为诗曰：“大男小女不须愁，富贵贫穷错对头。堪笑一班贞节妇，也随飞诏去风流。”
注：至元丁丑：元世祖至元十四年（1277）疑，或后至元三年（1337），待考。
注：鞑靼：对蒙古人的称呼。
注：扰扰：纷乱。
注：吴僧柏子庭：柏子庭，僧人，诗人，待考。
注：隆庆戊辰：隆庆二年（1568）。
注：私阉人：私自阉割的人。
注：浙直：浙江和南直隶。
注：姮娥：嫦娥。
注：孀居：寡居。
注：守制：守寡。
# 蝎虎冤
题解：求雨时以蝎虎代蜥蜴，蝎虎受冤。
原：守宫与蜥蝎二种。守宫即蝎虎，常悬壁。蜥蝎毒甚于蛇，又名“蛇医”，俗言与龙为亲家，故能致雨。古法用蜥蝎数十，置水瓮中，数十儿持柳枝咒曰：“蜥蜴蜥蜴，兴云吐雾，降雨滂沱，放汝归去。”宋熙宁中，求雨时觅蜥蜴，不能尽得，以蝎虎代之，入水即死。小儿更咒曰：“冤苦冤苦，我是蝎虎。似尔昏沉，怎得甘雨？”
注：守宫：壁虎，又称蝎虎。
注：蜥蝎：蜥蜴类。
注：蛇医：蜥蜴的别名。
注：熙宁：宋神宗年号（1068—1077）。
注：咒：祈祷语。
# 马冤
题解：舞马被误当妖，被打死。
原：舞马已散在人间，禄山尝睹其舞而心爱之，自是因以数匹卖于范阳。其后转为田承嗣所得，不之知也。杂战马中，置之外栈。忽一日，军中享士，乐作，马舞不能已。厮养皆谓其为妖，操棰击之。马谓其舞不中节，愈加抑扬顿挫。厩吏遽以马怪白之，棰至死。时人亦有如其舞马者，以暴故，终不敢言。
注：舞马：唐玄宗时训练的会随乐起舞的马。
注：禄山：安禄山。
注：范阳：今北京一带，安禄山镇所。
注：田承嗣：安史旧将，后为魏博节度使。
注：外栈：马厩外圈。
注：厮养：奴仆。
注：棰：鞭打。
