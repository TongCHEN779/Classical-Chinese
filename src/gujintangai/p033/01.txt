# 正文
题解：《荒唐》部总评：冯梦龙以鱼腹舟人、独活石髀等习闻之谬与章惇、苏轼对待妄言的不同态度，论荒唐之言的可笑与游戏三昧，并点明本部为全书第三十三部。
原：〔子犹曰：相传海上有驾舟入鱼腹。舟中人曰：“天色何陡暗也！”取炬燃之。火热而鱼掠，遂吞而入水。是则然矣，然舟人之言，与其取炬也，孰闻而孰见之！《本草》曰：独活有风不动，无风自摇。石髀入水即干，出水则湿。出水则湿，诚有之矣；入水即干，何以得知？言固有习闻而不觉其害于理者，可笑也。既可笑，又欲不害理，难矣。章子厚做相，有太学生在门下，素有口辩。子厚一日至书室，叩以《易》理。其人纵横辩论，杂以荒唐不经说。子厚大怒曰：“何故对吾乱道！”命左右擒下杖之，其人哀鸣叩头乃免。而同时坡仙，乃强人妄言以为笑乐。以理论，子厚似无害，究竟子厚一生正经安地？赢得死后作猫儿，何如坡仙得游戏三昧也？集《荒唐》第三十三。〕
注：子犹曰：冯梦龙自称，下为评语。
注：驾舟入鱼腹：海上传说，鱼吞舟人之奇谈，见笔记，具体出处待考。
注：掠：此处指被火灼伤而翻腾。
注：《本草》：中国药物学著作，此处泛指本草书。
注：独活：药名，《本草》谓“有风不动，无风自摇”。
注：石髀：石髀，药名，所谓“入水即干，出水则湿”，具体出处待考。
注：习闻：听惯了的说法。
注：章子厚：章惇，字子厚，北宋宰相，与苏轼早年交好，后新党当政贬苏轼。
注：太学生：太学的学生。
注：叩以《易》理：向其请教《周易》的道理。
注：荒唐不经：荒谬无稽。
注：坡仙：对苏轼的美称，号东坡。
注：安地：安稳之地，待考；疑指章惇一生处世“正经”。
注：作猫儿：指章惇死后化猫之说，见本部“章惇为猫”条。
注：游戏三昧：佛教语，指超然自在之境。
注：集《荒唐》第三十三：《荒唐》为全书第三十三部，所收为夸诞不经之谈。
# 镇阳二小儿
题解：赵文王以“镇阳二小儿”的更大谎言回应公孙龙的大鹏钓鳌之说，使其丧气而退，是“以谎克谎”的寓言。
原：公孙龙见赵文王，将以夸事炫之，因为王陈大鹏九万里钓连鳌之说。文王曰：“南海之鳌，吾所未见也。独以吾赵地所有之事报子。寡人之镇阳有二小儿，曰东里，曰左伯，共戏于渤海之上。须臾有所谓鹏者，群翔水上。东里遽入海以捕之，一攫而得。渤海之深，才及东里之胫。顾何以贮也，于是挽左伯之巾以囊焉。左伯怒，相与斗，久之不已。东里之母乃拽东里回。左伯举太行山掷之，误中东里之母，一目眯焉。母以爪剔出，向西北弹之。故太行山中断，而所弹之石，今为恒山也。子亦见之乎？”公孙龙逡巡丧气而退。弟子曰：“嘻，先生持大说以夸炫人，宜其困也。”
注：公孙龙：战国赵国名家，著《白马论》。
注：赵文王：当为赵惠文王，公孙龙曾游说于平原君，此处为小说家言。
注：大鹏九万里：《庄子·逍遥游》“鹏之徙于南冥也，水击三千里，抟扶摇而上者九万里”。
注：钓连鳌：《列子·汤问》载龙伯国大人钓连六鳌之事。
注：镇阳：战国赵地名，今河北正定一带，古称镇州，此处作地名用。
注：东里：虚设的小儿名。
注：左伯：虚设的小儿名，与东汉造纸名家左伯同名。
注：渤海：今渤海。
注：攫：抓取。
注：胫：小腿。
注：挽：拽。
注：囊：用袋子装。
注：太行山：山脉，东出河北，西接山西。
注：眯：眼睛被异物所入而难以睁开。
注：恒山：五岳之北岳，在今山西浑源。
注：逡巡：迟疑。
注：大说：大言，夸大之说。
# 三老人
题解：三位老人比寿，各以盘古、沧海桑田、蟠桃核比山来夸大自己的年岁。
原：尝有三老人相遇。或问之年，一人曰：“吾年不可记，但忆少年时与盘古有旧。”一人曰：“海水变桑田时，吾辄下一筹。尔来我筹已满十间屋。”一人曰：“吾所食蟠桃，弃其核于昆仑山下，今与昆仑山齐矣！”
注：盘古：传说中开天辟地的神。
注：筹：计数的竹签。
注：海水变桑田：麻姑故事，谓“东海三为桑田”，见《神仙传》。
注：十间屋：筹满十间屋，喻岁月之久。
注：蟠桃：传说西王母所种仙桃。
注：昆仑山：古代神话中的西方神山。
# 赵方士
题解：赵国方士自夸长寿，历述上古诸帝之事，一遇赵王求千年血竭便露馅，揭示“大言”之虚妄。
原：赵有方士好大言。人问：“先生寿几何？”方士哑然曰：“余亦忘之矣。忆童稚时，与群儿往看宓羲画八卦，见其蛇身人首，归得惊痫。赖宓羲以草头药治余，得不死。女娲之世，天倾西北，地陷东南。余时居中央平稳之处，两不能害。神农播百谷，余以辟谷久矣，一粒不曾入口。蚩尤犯余以五兵，因举一指击伤其额，流血被面而遁。苍氏子不识字，欲来求教；为其愚甚，不屑也。庆都十四月而生尧，延余作汤饼会。舜为父母所虐，号泣于旻天。余手为拭泪，敦勉再三，遂为孝闻。禹治水经余门，劳而觞之，力辞不饮而去。孔甲赠龙醢一脔，余误食之，于今口尚腥臭。成汤开一面之网以罗禽兽，尝亲数其不能忘情于野味。履癸强余牛饮，不从，置余炮烙之刑，七昼夜而言笑自若，乃得释去。姜家小儿钓得鲜鱼，时时相饷，余以饲山中黄鹤。穆天子瑶池之宴，让余首席。徐偃称兵，天子乘八骏而返。阿母留余终席，为饮桑落之酒过多，醉倒不起。幸有董双成、绿萼华两个丫头，相扶归舍，一向沉醉至今，犹未全醒。不知今日世上，是何甲子也？”问者唯唯而退。俄而赵王堕马伤胁。医云：“须千年血竭敷之，乃瘥。”下令求血竭，不可得。人有言方士者。王大喜，密使人执方士，将杀之。方士拜且泣曰：“昨日吾父母皆年五十，承东邻老姥携酒为寿。臣饮至醉，不觉言辞过度，实不曾活千岁。”王乃叱而赦焉。
注：方士：古代求仙炼丹的术士。
注：哑然：笑出声。
注：宓羲：伏羲，传说中画八卦的三皇之一，蛇身人首。
注：惊痫：受惊而发的癫痫。
注：草头药：草药。
注：女娲之世，天倾西北：女娲补天、共工触不周山的神话，见《淮南子·览冥训》。
注：神农播百谷：神农氏教民耕种。
注：辟谷：不食五谷，道家修炼法。
注：蚩尤犯余以五兵：蚩尤发动战争，用五种兵器，后被黄帝擒杀。
注：苍氏子：苍颉，传说创造文字者。
注：庆都：传说尧之母。
注：十四月而生尧：传说尧母怀孕十四个月才生尧。
注：汤饼会：生子满三日举行的宴会，吃汤饼。
注：旻天：秋天，也泛指上天；舜遭父母虐待，号泣于旻天，见《孟子·万章》。
注：禹治水经余门：大禹治水三过家门而不入，此处化用。
注：孔甲：夏代君主，传说好龙，曾食龙肉。
注：龙醢：龙肉酱。
注：成汤开一面之网：商汤网开三面，见《史记·殷本纪》。
注：履癸：夏桀之名。
注：牛饮：大口豪饮，桀有酒池牛饮之传说。
注：炮烙：传说为商纣所用刑具，此处与夏桀混用，属笑谈。
注：姜家小儿：指姜太公之类，疑为“姜太公”故事的戏拟。
注：穆天子瑶池之宴：周穆王在昆仑瑶池会西王母，见《穆天子传》。
注：徐偃称兵：徐偃王起兵，传说周穆王乘八骏急归，见《史记》《后汉书》。
注：八骏：周穆王所乘八匹骏马。
注：阿母：西王母。
注：桑落之酒：古代名酒，出河东蒲州。
注：董双成：传说西王母的侍女。
注：绿萼华：传说中的女仙。
注：甲子：干支纪年，意为什么时候。
注：血竭：药名，又称麒麟竭，止血生肌；“千年血竭”为戏谑，与方士“千岁”暗合。
注：瘥：病愈。
注：东邻老姥：东边的老妇人。
# 古强李泌
题解：记两个虚言者古强与李泌：古强自称目击尧舜禹汤，李泌自称与神仙往来，皆是编造的荒唐。
原：昔有古强者，敢为虚言，云：“尧、舜、禹、汤皆历历目击。孔子常劝我读《易》，曰：‘此良书也。’”西狩获麟，我语孔子曰：‘此非善祥。’”又稽使君曾以一玉卮赠强。强后忘之，忽语稽曰：“昔安期先生以此相遗。”
注：古强：传说中说大话的人，事见《笑林》类书，待考。
注：西狩获麟：《春秋》载鲁哀公十四年西狩获麟，孔子哀叹，其时孔子已晚年。
注：稽使君：指稽姓使君，待考。
注：玉卮：玉制酒杯。
注：安期先生：安期生，传说中的仙人。
原：李泌为相，以虚诞自任。尝对客令家人：“速洒扫，今夜洪崖先生来宿。”有人携美酝一榼，有客至，乃曰：“麻姑送酒来，与公同饮。”饮未毕，门者曰：“某侍郎取酒榼。”泌命还之，了无愧色。
注：李泌：唐代名臣，肃宗、德宗朝宰相，好谈神仙。
注：虚诞：虚妄荒诞。
注：洪崖先生：传说中的古仙人。
注：美酝：美酒。
注：榼：盛酒器。
注：麻姑：传说中的女仙。
注：侍郎：六部副长官。
# 张怀素
题解：方士张怀素自夸与孔子、楚汉战事皆有关，蔡元席因而深信，反映当时轻信方士的风气。
原：方士张怀素好大言，自云：“道术通神，能呼遗飞走之属。孔子诛少正卯，我尝谏以为太早：楚汉成皋相持，我屡登高观战。”蔡元席深信之，谓陈莹中曰：“怀素殆非几百岁内人也！”
注：张怀素：北宋末方士，后谋反被诛，见《宋史》。
注：遗飞走之属：驱遣飞禽走兽。“遗”疑当为“遣”，底本作“呼遗”，疑误。
注：孔子诛少正卯：《荀子·宥坐》载孔子为鲁司寇，诛少正卯。
注：成皋：古地名，楚汉战争时期的重要战场，在今河南荥阳。
注：蔡元席：蔡元，北宋士人，待考。
注：陈莹中：陈瓘，字莹中，北宋名臣。
注：几百岁内人：几百岁以内的人。
# 斥仙
题解：项曼都假称学仙十年，被斥后回家，时人讥之为“斥仙”。
原：项曼都学仙十年，归家，诈云：“到泰山，仙人以流霞饮我，不饥渴。忽思家，到帝前谒拜，失仪见斥。”河东因号“斥仙。”。
注：项曼都：汉代人，托言学仙，见《抱朴子》。
注：流霞：神话中的仙酒。
注：失仪：礼仪有失。
注：斥：斥逐。
注：河东：今山西西南一带。
# 姜识
题解：仁宗皇后曹氏去世，姜识自言可使其复生，数旬不验，被斥。
原：慈圣光献皇后薨，上悲慕甚。有姜识自言神术，可使死者复生，上试其术，数旬不效。乃曰：“臣见太皇太后方与仁宗宴，临白玉栏干赏牡丹，无意复来人间也！”上知诞妾，但斥于彬州。蔡承禧进挽词曰：“天上玉栏花已折，人间方士术何施。”
注：慈圣光献皇后：曹后，宋仁宗皇后，谥慈圣光献，神宗时尊为太皇太后。
注：薨：去世。
注：上：皇上，指宋神宗。
注：姜识：术士，生平待考。
注：仁宗：宋仁宗。
注：诞妾：疑当作“诞妄”，荒诞虚妄。
注：彬州：即郴州，今湖南郴州，宋时有避讳作彬州者。
注：蔡承禧：北宋官员。
注：挽词：悼念死者的哀词。
# 醒神
题解：记明代“醒神”老人自称数百岁，陈继儒讥其言如一部活《西游记》。
原：万历壬辰间，一老人号“醒神”。自云数百岁，曾见高皇、张三丰。又自诡为王越，至今不死。又云历海外诸国万馀里。陈眉公曰：“听醒神语，是一本活《西游记》。”
注：万历壬辰：万历二十年（1592）。
注：高皇：明太祖朱元璋，谥高皇帝。
注：张三丰：传说明初武当道士，长生不老。
注：王越：明代名将，官至兵部尚书，死后有“未死”传说。
注：自诡：自己假托。
注：陈眉公：陈继儒，号眉公，晚明名士。
注：《西游记》：明代神魔小说。
# 《妖乱志》吕用之事
题解：摘引《妖乱志》，写吕用之以神仙方术惑高骈：造神碑、请侠士护身、遣萧胜取宝剑、纵火，层层欺骗，反映晚唐藩镇迷信之祸。
原：高骈末年，惑于神仙之说。吕用之用事，自谓“磻溪真君”，公然云与上仙来往。每对骈，或叱咄风云，顾揖空中，谓见群仙方过。骈随而拜之。用之指画纷纷，略无愧色。
注：高骈：晚唐淮南节度使，晚年迷信神仙，被部下毕师铎所杀。
注：吕用之：晚唐妖人，惑高骈，专权。
注：磻溪真君：以姜太公自比，磻溪为太公垂钓处。
注：叱咄：呵斥。
注：上仙：仙人。
原：中和元年，诏于广陵立骈生祠，并刻石颂。差县人采碑材于宣城。及至扬子院，用之一夜遣人，密以犍牯五十，牵至县南，凿垣架濠，移入城内。及明，栅缉如故。因令扬子县申府：“昨夜碑石不知所在。”遂悬购之。至晚云：“被神人移置街市。”骈大惊，乃于其傍立一大木柱，金书其上，云：“不因人力，自然而至。”即令两都出兵仗鼓乐，迎入碧筠亭。至三桥拥闹之处，故理石以碍之。伪云“人牛拽不动”，教骈朱篆数字，贴于碑上。须臾去石，乃行。观者互相谓曰： “碑动也！”识者恶之。明日扬子有一村妪，指府陈牒云：“夜来里胥借耕牛牵碑，误损其足。”远近传笑焉。
注：中和元年：881年，唐僖宗年号。
注：广陵：今扬州，淮南节度使治所。
注：生祠：为活着的人立的祠。
注：宣城：今安徽宣城。
注：扬子院：唐代在扬子县设转运使院。
注：犍牯：公牛。
注：凿垣架濠：凿开城墙、搭桥过护城河。
注：栅缉：栅栏修补。
注：悬购：悬赏寻求。
注：碧筠亭：高骈园中的亭子。
注：三桥：扬州桥名。
注：朱篆：红色的篆字，符箓。
注：里胥：乡里小吏。
原：骈常与丞相郑公不协，用之知之。忽曰：“适得上仙书，宰执间阴有图令公者，使一侠士来，夜当至。”骈惊悸问计。用之徐曰：“张先生少年时，常学斯术于深井里聂夫人，近日不知肯为否。若得此人当之，无不齑粉者！”骈立召守一语之。对曰：“老夫久不为此戏，手足生疏。然为令公，有何不可！”及朝，骈衣妇人衣，匿于别室。守一寝骈卧内，至夜分，掷一铜铁于阶砌，铿然有声。遂出皮囊中彘血，洒于庭户间，如格斗状。明日骈泣谢守一再生之恩，乃躬辇金玉及通天犀带酬之。
注：郑公：指宰相郑畋，时与高骈不和。
注：宰执：宰相与执政大臣。

# 落星潭
题解：后唐时庐山落星潭有人形物被莓苔裹住，风吹日晒后化为人，熟知山川旧事，复入水中，吏民为之立祠。
原：后唐长兴中，庐山落星潭有钓者，得一物如人状，为积岁莓苔所裹，不甚分辨，比木则重，比石则轻，弃之潭侧。后数日，风日剥落，又经雨淋洗，忽见两目俱开，则人也！然而起，就潭水盥手靧面。渔者惊异，共观之。其人具悉本地山川之名，及朝代年月。语讫。复入水中。吏民为建祠于潭上。
注：长兴：后唐明宗年号（930—933）。
注：庐山落星潭：庐山一带水潭，待考。
注：莓苔：青苔。
注：剥落：外壳脱落。
注：盥手靧面：洗手洗脸。
注：吏民：官吏和百姓。
# 橘叟
题解：巴邛橘园中剖橘见二老叟对弈，所述赌债均为仙家之物，后乘龙而去，是著名的“橘中之乐”故事。
原：有巴邛人，不知姓名。家有橘园。因霜后，诸橘尽收，馀有两大橘，如三斗盎。巴人异之，即令摘下，轻重亦如常橘。剖开，每橘有二老叟，身长尺馀，须眉皤然，肌体红明，皆相对象戏，谈笑自若。剖开后，亦无惊怖，但相与决赌。赌讫，一叟曰：“君输我海龙王第七女髲发十两，智琼额黄十二枚，紫绡帔一副，绛台山霞实散二庾，瀛洲玉尘九斛，阿母疗髓凝酒四锺，阿母女态盈娘子济虚龙缟袜八两，后日于王先生青城草堂还我耳。”又一叟曰：“王先生许来，竟待不得。橘中之乐，不减商山，但不得深根固蒂，为愚人摘下耳！”又一叟曰：“仆饥矣，当取龙根脯食之。”即于袖中出一草根，方圆径寸，形状宛如龙，毫厘罔不周悉。因削食之，随削随满。食讫，以水噀之，化为一龙。四叟共乘之，足下泄泄云起，须叟风雨晦冥，不知所在。
注：巴邛：今四川重庆、邛崃一带，此处指巴邛人。
注：盎：腹大口小的瓦器。
注：皤然：须发皆白。
注：象戏：象棋。
注：决赌：以棋局决胜负。
注：髲发：假发。
注：智琼：传说中的神女，名智琼，仙女。
注：额黄：古代妇女在额头涂黄色的装饰。
注：紫绡帔：紫色轻纱披肩。
注：绛台山：仙山名，待考。
注：庾：古量器，容十六斗（或二斗四升）。
注：瀛洲：海上三神山之一。
注：斛：古量器，十斗。
注：阿母疗髓凝酒：王母的仙酒，名号待考。
注：锺：古量器。
注：青城：青城山，道教名山。
注：商山：商山四皓隐居之处，此处比喻橘中之乐不减商山之乐。
注：深根固蒂：《老子》“深根固柢”，此处谓橘不应早摘。
注：龙根脯：以龙根制成的肉脯，传说。
注：噀：含水喷出。
注：晦冥：昏暗。
# 朝荣观
题解：李凉公朔方园中生巨菌，菌上有楼台、二叟对弈，掘地后见巨蟒吐沫成菌，梦中有黄衣人告知，是蟒吐气成幻。
原：李凉公镇朔方，有园，树下产菌一本，其大数尺。上有楼台，中有二叟对博。刻成三字，曰“朝荣观”。公今掘地数尺，有巨蟒目光如镜，吐沫成菌。是夜公梦黄衣人致命曰：“黄庐公昨与朝荣观主博，为愚人持献公。”
注：李凉公：李听，唐代，封凉国公，镇朔方、灵武等，或李愬；待考。
注：朔方：唐方镇名，治所在灵州。
注：菌：蘑菇。
注：对博：对弈。
注：朝荣观：幻想中的楼观名，“朝荣”指朝菌，朝生暮死。
注：巨蟒：大蛇。
注：黄衣人：梦中使者。
注：黄庐公：蟒的拟人化称呼；待考。
# 树中乐声
题解：万历丁酉河南巩县的木匠砍树，从树中放出细小的乐人，是奇闻。
原：万历丁酉，河南巩县大道，有木匠持斧往役于人。憩树下，忽闻鼓乐声，不知其自。谛听之，乃出树中，遂将斧击树数下。其内曰：“不好不好，必砍进矣！”匠益重加斧，乃有细人长三、四寸，各执乐器自树中出地上，犹自作乐数叠。来观者益多，乃仆地。
注：万历丁酉：万历二十五年（1597）。
注：巩县：今河南巩义。
注：憩：休息。
注：谛听：仔细听。
注：叠：乐曲一遍。
# 龙宾
题解：唐玄宗御墨有“龙香剂”之号，其墨精“黑松使者”自称世人文章墨上皆有龙宾十二。
原：玄宗御墨曰：“龙香剂”。一日，墨上有小道士如蝇而上。叱之，即呼“万岁”，曰：“臣墨之精，黑松使者。凡世人有文者，墨上皆有龙宾十二。”上神之，以墨赐掌文官。
注：玄宗：唐玄宗。
注：龙香剂：墨名，唐代龙香御墨，见《开元天宝遗事》。
注：黑松使者：墨之精，松烟制墨，故称。
注：龙宾十二：龙宾，墨的别称，“十二”指十二神。
注：掌文官：掌管文书的官员。
# 五寸舟
题解：杭州徐副使晚年见荷缸中落下五寸小舟，舟上小人操舟，旋驾帆而去，作者引《搜神记》池阳小人事相印证。
原：杭州徐副使，清苦之士。致仕后，偶巡行小院，凭栏观缸中菡萏盛开。忽有物瞥然堕于水面。视之，乃一小舟也。其长五寸许，蒿橹帆楫，合用之物，无不毕具。有三人皆寸半，操蒿把舵，与生人不异。大以为怪，呼其儿二官者同玩。其喧呼动转，俨若世态，有时舟欹侧，亦复手足纷纭，若救护之状。已而三人同拽一帆张之，帆与竹叶等，驭风排空而去。竟莫喻其怪。按干宝《搜神记》，汉时池阳有小人，所操持之物，大小悉称。其即此类耶？
注：副使：按察副使或提学副使一类官职，此处泛称。
注：致仕：退休。
注：菡萏：荷花。
注：蒿橹：撑船的篙与橹。
注：帆楫：帆与桨。
注：欹侧：倾斜。
注：干宝《搜神记》：东晋干宝撰志怪小说。
注：池阳：汉代县名，在今陕西泾阳一带，《搜神记》载池阳小人事。
# 龙蛰耳
题解：以薛杨、戴春所说二则，记人患耳鸣、指甲筋动，其实为龙蛰所致，雷雨之时龙去，并与青州妇人事相类。
原：薛主事杨，河东人。言其乡人有患耳鸣者，时或作痒。以物探之，出虫蜕，轻白如鹅翎管中膜。一日与其侣并耕，忽雷雨交作，语其侣曰：“今日耳鸣特甚，何也？”言未既，震雷一声，二人皆踣于地。其一复醒；其一脑裂而死，即耳鸣者。乃知龙蛰其耳，至是化去也。戴主事春，松江人。言其乡有卫舅公者，手大指甲中红筋时或曲直，或蜿蜒而动。或惧之曰：“此必承雨濯手，龙集指甲也！”卫因号其指曰“亦龙甲”。一日与客泛湖，洒半，雷电绕船，水波震荡。卫戏与坐客语曰：“或家赤龙将欲去耶！”乃出手船窗外，龙果裂指而去。此正与青州妇人青筋痒则龙出事相类。传云：神龙或飞或潜、能大能小者也。
注：薛主事杨：薛杨，官主事，河东人，待考。
注：河东：今山西西南部。
注：虫蜕：虫的蜕壳。
注：鹅翎管：鹅毛的茎管。
注：踣：倒下。
注：蛰：潜伏。
注：戴主事春：戴春，官主事，松江人，待考。
注：卫舅公：姓卫的舅公，待考。
注：蜿蜒：蛇行貌。
注：濯手：洗手。
注：赤龙：红色之龙。
注：青州妇人青筋痒则龙出：青州妇人手臂上青筋痒，有龙出，事见笔记，待考。
注：神龙或飞或潜：《周易·乾卦》“飞龙在天”“潜龙勿用”，又《管子·水地》言龙能大能小。
# 王布衣
题解：引《续仙传》，王布衣用药丸治眉上肉块，其中出蛇，布衣乘蛇而去。

注：《续仙传》：五代南唐沈汾撰神仙传记。
注：终南：终南山。
注：王布衣：传说中的药师，生平待考。
注：柳信：富人之名，待考。
注：傅：涂敷。
# 巴妪项瘿
题解：引《幽怪录》，写伶人之妻项瘿里藏着泰山猕猴精，因躲避天诛而寄身，终以药治愈。
原：《幽怪录》：伶人刁俊朝妻巴妪，项瘿如数斛囊，作琴瑟笙磬声。妻欲以刃决拆之，瘿忽拆裂，一猱跳出。有黄冠叩门曰：“予泰山猱也！本是老猴精，解致风雨。与老蛟往还。天诛蛟，搜索党与，故匿夫人之额。于凤凰山神处，得起亡膏，涂之即愈。”如言果验。
注：《幽怪录》：唐牛僧孺《玄怪录》，宋避讳改作“幽怪录”。
注：伶人：乐工。
注：刁俊朝：伶人之名，待考。
注：项瘿：颈部的肿瘤，大脖子病。
注：斛：量器，容十斗。
注：琴瑟笙磬：各类乐器。
注：猱：猿猴。
注：黄冠：道士。
注：老蛟：年久之蛟龙。
注：党与：同党。
注：凤凰山：此处待考。
注：起亡膏：能起死回生的药膏，疑为传说中神药名。
# 《志怪录》二事
题解：两则耳中生物的怪事：苏州媪耳中不断拿出杂物，永乐间吴城老父耳中竟有小木椅与小人。
原：往年葑门一媪，年逾五十。令人剔其耳，耳中得少绢帛屑。以为偶遗落其中，亦不异之。已而每治耳，必得少物，丝线谷粟稻穗之属，为品甚多。始大骇怪，而无如之何。久亦任之，不为惊异，且每收置之。迨年七、八十而卒。核其所得耳物，凡一斛焉。
注：葑门：苏州城门名。
注：媪：老妇。
注：剔其耳：掏耳。
注：绢帛屑：丝绸碎屑。
注：谷粟稻穗：粮食作物。
注：斛：十斗。
原：永乐中，吴城有一老父偶治耳，于耳中得五谷金银器皿等诸物，凡得一箕。后更治之，无所得。视其中洁净，唯正中有一小木椅，制甚精妙。椅上坐一人，长数分，亦甚有精气。其后亦无他异。
注：永乐：明成祖年号。
注：吴城：苏州。
注：箕：簸箕。
注：数分：几分，言其小。
注：精气：精神。
# 兜玄国
题解：薛君曹见二青衣从耳中驾犊而出，窥见耳中“兜玄国”，作《思归赋》后从童子耳中落下，是耳中藏世界之奇想。
原：薛君曹见二青衣驾赤犊出耳，谓薛曰：“兜玄国在吾耳中。”一童子倾耳示薛，别有天地花卉。遂扪耳投之，至一都会，城池楼堞，穷极环丽。因作《思归赋》，忽自童子耳中落。
注：薛君曹：事迹待考。
注：青衣：侍女，此处指穿青衣的仆从。
注：赤犊：红色小牛。
注：兜玄国：耳中的幻想国名。
注：倾耳：侧耳。
注：扪耳：摸耳。
注：城池楼堞：城墙、楼阁、垛口。
注：环丽：奇丽。
注：《思归赋》：作者想念故乡之作，待考。

题解：引《神异经》（实多为佛经与志怪杂说）所记金翅鸟食龙、如意珠、巨人、食鬼人，皆为荒唐奇异之谈。
原：阎浮提中及四天下有金翅鸟，名“伽楼罗王”。此鸟业报，应食诸龙，日食一龙王，及五百小龙。此鸟两翅，相去六千馀里。以翅博海水擗龙，见而取食之。龙取袈裟戴于顶上，乃得免。
注：阎浮提：佛教的南赡部洲，即人类所居的世界。
注：四天下：佛教所说须弥山四方的四大洲。

注：伽楼罗：梵语 Garuda，金翅鸟之音译。
注：业报：佛教因果报应。
注：擗：分开，此处指拨开。
注：袈裟：僧人法衣；传说龙戴袈裟则金翅鸟不能食。

注：摩竭大鱼：佛经中的摩竭鱼，梵语 Makara，传说为巨鱼。
注：金刚坚：形容珠之坚固。

# 夸父支鼎石

# 树生儿

# 异蝇
题解：儒生张益被二蝇变人拽足，长高三尺，遂弃儒当上大汉将军，是荒诞趣谈。
原：儒生张益夜卧一室，见二蝇飞集几上，忽变为人，将张抚抑，遂不能语。其一人抱首，一人尽力以拽其足。觉身随拽而长，与屋檐语。二人仍变蝇飞去。张晨起，顿长三尺。举家惊异。遂弃儒，奏作大汉将军。
注：张益：儒生，待考。
注：抚抑：按压。
注：拽：拉。
注：大汉将军：明代锦衣卫宫廷侍卫，身材魁梧，称“大汉将军”。
# 奇酒
题解：引《博物志》，记千日酒的传说：刘玄石饮千日酒醉卧千日，被家人误葬，又有田及人造千日酒，赵英醉后被葬，二则相类；另有枸楼国水仙树的仙浆，饮者七日醉。
原：张茂生《博物志》云：昔有人名玄石，从中山酒家，与之千日酒而亡语其节。归日尚醉，而家人不知，以为死也，棺殓葬之。酒家经千日忽悟。而往告之。发冢适醒。
注：张茂生《博物志》：张华，字茂先，西晋撰《博物志》；“茂生”疑为“茂先”之误。
注：玄石：刘玄石，传说中的酒徒，见《搜神记》，《博物志》作“刘玄石”。
注：中山：今河北定州一带，古产名酒。
注：千日酒：传说能醉千日的酒。
注：节：节制，此处指酒的厉害。
注：棺殓：入棺收殓。
注：发冢：挖开坟墓。
原：齐人田及人，能为千日酒，饮过一升，醉卧千日。有故人赵英饮之，逾量而去。其家以尸埋之。及之计千日当醒，往至其家。破冢出之，尚有酒气。
注：田及人：待考。
注：赵英：待考。
注：逾量：超出酒量。
原：枸楼国有水仙树，腹中有水，谓之“仙浆”。饮者七日醉。
注：枸楼国：传说中的国名，待考。
注：水仙树：传说树腹有水，称“仙浆”。
# 眉间尺
题解：眉间尺为报父仇，以头与剑托付客人，客人替他杀王，三头同烂，合葬为“三头冢”，是著名的复仇传说。
原：眉间尺仇楚，逃之山，道逢一客曰：“吾能为子报仇，然须子之头与子之剑。”尺与之头。客之楚，献王。王以镬煮其头，七日不烂。自临视之，客从后截王头入镬，两头相啮。客恐尺头不胜，自拟其头入镬，三头相咬，七日后，一时俱烂，乃分其汤葬之。名曰“三头冢”。
注：眉间尺：干将、莫邪之子，传说其父干将为楚王铸剑被杀，眉间尺立志复仇，事见《搜神记》，鲁迅《铸剑》所本。
注：仇楚：向楚王报仇。
注：客：侠客。
注：镬：大锅。
注：截王头：割下楚王之头。
注：相啮：相咬。
注：三头冢：传说在汝南宜春县。
# 梁武前生是蟮
题解：梁武帝与人下棋，随口说“杀却”，榼头师因而被杀，却自称前世因断蟮而得此报，是荒诞的因果之谈。
原：梁有榼头师者极精进，为武帝所敬信。一日敕使唤至。帝方与人奕，欲杀一段，应声曰：“杀却！”使遽传命斩之。奕罢召师，使者曰：“已得旨杀却矣。”帝惊叹，因问：“死时何言？”使曰：“师云，前劫为沙弥时，以锹划地，误断一曲蟮。帝时为蟮，今此报也。”
注：榼头师：梁时高僧，生平待考。
注：精进：佛教语，勤奋修行。
注：武帝：梁武帝萧衍，崇佛。
注：敕使：皇帝派去的使者。
注：奕：围棋。
注：杀一段：围棋术语，吃掉对方一块棋子。
注：沙弥：初出家的男子。
注：锹：铁锹。
注：曲蟮：蚯蚓。
注：前劫：前世。
# 天帝召歌
题解：贺道养善卜筮，说歌女非死，是被天帝召去唱歌，以土块放在心上而苏醒。
原：贺道养工卜筮，经过工歌女人病死，筮之曰：“此非死，天帝召之歌耳。”乃以土块加其心上，俄顷而苏。
注：贺道养：南朝宋人，善卜筮，事见《宋书》《南史》。
注：卜筮：占卜。
注：工歌：乐工，歌者。
注：筮：占卜。
注：苏：苏醒。
# 城精
题解：梁武帝围郢城，夜里数万毛人越墙而泣，投入黄鹄矶，是城精所化。
原：梁武逼郢城。已未夜，郢城有数万毛人逾堞且泣，因投黄鹄矶。盖城之精也。
注：梁武：梁武帝萧衍，曾围攻郢城（今湖北武汉）。
注：郢城：此指南朝齐的郢州城，在今武汉武昌。
注：已未：此处指己未日。
注：毛人：身上有毛的怪物。
注：堞：城上矮墙。
注：黄鹄矶：武昌的黄鹤山矶头。
