# 正文
题解：《灵迹》部总评：冯梦龙认为道术幻术之妙，根本在于精神专一，并点明本部为全书第三十二部。
原：〔子犹曰：凡有道术者，皆精神之异于常人者也。真有真精神，幻亦有幻精神。冬起雷，夏造冰，几于镂天雕地矣。非精神能感召，其然耶？下至一技之工，一虫之戏，亦必全副精神与之娴习而后能之。拜树而树应，诵驴而驴灵，非真并非幻也，精神之至也。精神无伪，伪极亦是真也。恒言遇所不能，辄谓仙气。余意凡道术止是如此，无二法门。集《灵迹》第三十二。〕
注：子犹曰：冯梦龙自称，下为评语。
注：道术：道家方术，泛指神异之术。
注：镂天雕地：喻造化神工，极言其奇妙。
注：感召：感应招致。
注：拜树而树应，诵驴而驴灵：指幻术家对草木牲畜施咒而应验的传闻，具体出处待考。
注：恒言：常语，俗话。
注：仙气：俗谓非常人所能，有仙家气象。
注：二法门：两种途径；法门，佛教指入道之门。
注：集《灵迹》第三十二：《灵迹》为全书第三十二部，所收为各类神异方术故事。
# 顶穴乳穴
题解：记僧伽与佛图澄身有孔穴、夜出异光异香的传说，两事相类。
原：唐时，西域僧伽居京师之荐福寺，常独居一室。顶上有穴，恒以絮窒之。夜则去絮，烟气从顶穴中出，芬芳满室。
注：僧伽：唐代西域僧，居泗州，唐中宗迎入京，居荐福寺，传为观音化身。
注：荐福寺：唐长安名寺，中宗时为荐福寺。
注：絮窒：用棉絮塞住。
原：石勒时，有佛图澄者，左乳旁有一穴，恒就水洗濯肠肺，以絮窒之。夜欲读书，辄拔絮，则光自穴出，一室洞明。
注：石勒：后赵建立者，十六国羯族君主。
注：佛图澄：西域高僧，被石勒、石虎尊为“大和尚”，见《晋书·艺术传》。
注：洗濯肠肺：传说佛图澄能从腹旁孔穴取出肠胃洗涤，见《高僧传》。
注：洞明：通明。
# 二小儿登肩
题解：鸠摩罗什被逼纳妇生子，又吞针示众，以明唯有神通者方可效法。
原：天竺僧鸠摩罗什阐教于秦。一日忽下高座，谓秦主兴曰：“有二小儿登吾肩，欲障；须妇人。”兴遂以宫女进之，一交而生二子。自尔别立廨舍，供给丰盈。诸僧有欲效之者，什聚针盈钵，谓曰：“若能相效食此者，乃可畜室。”因举匕进针，不异常食。
注：鸠摩罗什：后秦高僧，译经大家。
注：天竺：古印度。
注：秦主兴：后秦君主姚兴。
注：高座：说法的讲台。
注：障：障碍，此指欲念之障。
注：廨舍：官舍，此指僧人别居之所。
注：钵：僧人食器。
注：畜室：蓄养妻室。
注：匕：勺子。
# 鸤鸠和尚
题解：引《云溪友议》，邓州和尚食鸠，二鸠自口出，故号“鸤鸠和尚”。
原：《云溪友议》云：邓州和尚日食二鸠。有贫士求餐，分二足与食。食既，僧盥嗽，双鸠从口出，一能行，一匍匐在地。士惊愕吐饭，二足亦出，号“南阳鸤鸠和尚”。
注：《云溪友议》：唐范摅撰笔记。
注：邓州：今河南邓州，唐时州名。
注：鸠：斑鸠。
注：盥嗽：洗手漱口。
注：鸤鸠：布谷鸟之古名，此处谐“食鸠”。
注：匍匐：伏地爬行。
注：南阳：邓州属南阳郡。
# 香阇黎
题解：香阇黎令众人戒杀，以口吐出所食鸡鱼活物，使人悔悟。
原：香阇黎者，莫测其来，止益州青城山寺，时俗每至三月三日，必往出游赏，多将酒肉酣乐。香屡劝之，不断。后因三月，又如前集。香令人穿坑，方丈许，忽曰：“檀越等常自饮啖，未曾见及，今日须餐一顿。”诸人争奉肴酒。随得随尽，若填巨壑。至晚曰：“我大醉饱，扶我就坑，不尔污地。”及至坑所，张口大吐。雉肉自口出，即能飞鸣；羊肉自口出，即能驰走；酒浆乱泻，将欲满坑；鱼吓鹅鸭，游泳交错。众咸惊嗟，誓断宰杀。
注：阇黎：梵语“阿阇黎”之省，意为导师，僧人尊称。
注：益州青城山：今四川都江堰青城山。
注：三月三日：上巳节，民间有春游之俗。
注：檀越：施主，佛教称布施者。
注：方丈：一丈见方。
注：雉：野鸡。
注：酣乐：纵情欢乐。
# 昝老
题解：昝老以神术救治被毒蛇咬伤者，用米饭捣成蛇形引蛇吸毒。
原：长寿寺僧昝，言他时在衡山，村人为毒蛇所噬，须臾而死，发解肿起尺馀。其子知昝老有术，遂迎昝至。乃以灰围其尸开四门，先曰：“若从足入，则不救矣。”遂踏步握固，久之蛇不至。昝大怒，乃取饭数升捣蛇形，咀之，忽蠕动出门。有顷，饭蛇引一蛇从死者头入，径吸其疮。尸肿渐低，蛇疱缩而死，村人乃活。
注：昝：老僧之姓，长寿寺僧，余事待考。
注：衡山：南岳衡山。
注：发解：头发散开。
注：握固：道教、佛教养生之法，握拳固守。
注：咀：嚼。
注：蠕动：像虫一样蠕行。
注：疮：伤口。
# 孤月
题解：孤月法师行异术，使女乘肩舆者无法前行，以示神通。
原：僧孤月擅异术。行桥上，会女妇乘肩舆至，骂僧不避。顷之，舁夫下桥复上，往返数度，犹不能去，旁人曰：“必汝犯月大师耳，可拜祈之。”僧曰：“吾有何能，尔自行耳。”言讫，舁未足轻如故。
注：孤月：僧人名，事迹待考。
注：肩舆：轿子。
注：舁夫：抬轿人。
注：犯月大师：触犯孤月大师。
# 散圣长老
题解：引《狯园》，记江长老受上清秘法，能使鸡蛋在臼中跳跃而不破。
原：《狯园》：江长老者，桃源江副使之族也。受良常山上真秘法，号“散圣长老”。能取生鸡卵二十枚，置臼中杵之，鸡卵纷然跃起，复入臼中，如是者数四，无一损环。
注：《狯园》：明钱希言撰，记神怪奇闻。
注：江长老：生平待考。
注：桃源：地名，湖南桃源，待考。
注：良常山：句曲山（茅山）别名，道教名山。
注：上真：道教上真，指仙真。
注：杵：舂捣。
注：损环：损坏，“环”疑为“坏”之误。
# 左元放
题解：左慈玩弄曹操，以幻术脱身，变身群羊，是汉末方士故事的名篇。
原：左慈，字元放，庐江人也。曹公尝闭一石室中，使人守视。断谷期年，乃出之，颜色如故。公谓必左道，欲杀之。慈已预知，为乞骸骨。公曰：“何以忽尔？”对曰：“欲见杀，故求去。”公曰：“无之。”乃为设酒。慈拔簪画杯，酒中断，即饮半，半与公。公未即饮，慈尽饮之。饮毕，以杯掷屋栋，举坐莫不视杯，良久乃坠，已失慈矣。寻问之，还其所居。公益欲杀之，数收慈。慈走入群羊中，俄有大羊前跪而曰：“为审尔否？”吏相谓曰：“此跪羊，慈也。”欲收之。群羊咸向吏言曰：“为审尔否？”
注：左慈：字元放，东汉末方士，见《后汉书·方术列传》。
注：庐江：汉郡名，在今安徽。
注：曹公：曹操。
注：断谷：辟谷，不食五谷。
注：左道：邪门歪道。
注：乞骸骨：请求辞官告老。
注：簪：发簪。
注：举坐：满座。
注：跪羊：跪着的羊。
注：审尔否：“你可是真的”，意为盘问。
# 笔仙

原：昔有高士，置笔竹筒，买者置钱其中，笔自跃出。号“笔仙”。
注：高士：隐居有操守之人。

# 咒桃斗
题解：樊夫人与刘纲各以咒术斗法，所咒桃树互斗，刘纲之桃败走。
原：樊夫人与夫刘纲俱有道术，各自言胜。中庭有两桃树，夫妻各咒其一，桃便斗。纲所咒桃，走出篱外。
注：樊夫人：樊云翘，传说为刘纲之妻，同修道成仙，见《神仙传》。
注：刘纲：东汉末道士，官上虞令。
注：咒：以符咒之法催动。
注：篱：篱笆。
# 种瓜
题解：徐光向人乞瓜不得，种瓜顷刻结实，卖瓜者所卖之瓜尽失。
原：吴时有徐光者，尝从人乞瓜，其主勿与。便索瓜子种之。俄而瓜生蔓延，生花成实，乃取食之，因遍给观音。鬻者反视，所出卖，皆亡耗矣。
注：徐光：三国吴方士，《搜神记》有其种瓜之事。
注：勿与：不给。
注：鬻者：卖瓜人。
注：亡耗：丢失。
注：观音：疑为“观者”之误；待考。
# 殷七七
题解：殷七七以栗为令，使嘲笑他的倡优受幻术所困，求谢而解。
原：道人殷七七，尝在一官僚处饮酒，有佐酒倡优共笑侮之。殷白主人，欲以二栗为令。众喜，谓必有戏术。乃以栗巡行，接者皆闻异香。唯笑七七者，栗化作石，缀在鼻，掣拽不落，秽气不可闻。二人共起狂舞，花细委地，相次悲啼；鼓乐皆自作。一席之人，笑皆绝倒。久之祈谢，石自鼻落，复为栗，花细悉如旧。
注：殷七七：唐代道士，事见《续仙传》《太平广记》。
注：佐酒倡优：陪酒的歌舞艺人。
注：令：酒令。
注：掣拽：拉扯。
注：绝倒：大笑。
注：花细：妇女头上花饰；“细”疑为“钿”之误。
# 轩辕集
题解：轩辕集夜垂发盆中沥酒，并令笑他貌古的宫人变作老妪，后谢罪复原。
原：罗浮先生轩辕集善饮，虽百斗不醉。夜则垂发盆中，其酒沥沥而出。唐宣宗召入内庭，坐御榻前。有宫人笑集貌古，须臾变成老妪，遂令谢先生，而貌复故。
注：罗浮先生：轩辕集，唐代道士，隐居罗浮山，宣宗召入宫。
注：唐宣宗：李忱，晚唐君主。
注：内庭：宫禁之内。
注：沥沥：酒滴落之声。
注：老妪：老妇。
# 陈七子

原：陈复林者，号陈七子。尝于巴南太守筵中，为酒妓所侮。陈笑视其面。须臾，妓者髯长数尺。泣诉于守，为祈谢。陈咒酒一杯，使饮之，髯便脱落。
注：陈复林：号陈七子，事迹待考。
注：巴南：今重庆一带。
注：酒妓：陪酒的妓女。
注：髯：胡须。
# 孙道人
题解：万历间孙道人以画圈、借桃、数鱼等小术，惩侮他的妓女，显其神异。
原：孙道人有异术。尝画墨圈于掌中，遥掷人面，虽洗之不去。顷之，以手挥曰：“当移著某人臂上。”虽重裘之内，而圈已在臂矣。尝至吴中，为小妓所侮。孙顾卖桃人担云：“借汝一桃。”遂拾以掷其面，妓右颊遽赤肿如桃大，楚不可忍，哀祈再四。乃索怀咒之，取下仍是一桃，妓肿遂消。此万历己酉年间事。
注：重裘：厚皮衣。
注：吴中：今苏州一带。
注：卖桃人：卖桃的人。
注：楚：痛。
注：万历己酉：万历三十七年（1609）。
原：又孙道人至一大家，见鱼池绝大，问：“鱼有数否？”主人曰：“不知。”孙曰：“可数也。”乃命二童子持长绳跨池相向而立，孙按绳徐掠池水，至半，止，连呼“双来双来”。顾童子曰：“紧持而数之。”鱼大小成对，从绳上跃过。一童大笑，绳脱，鱼遂群跃焉。
注：双来：道术中呼令鱼成对。
注：掠：轻轻拂过。
# 李秀才
题解：引《广记》，李秀才受僧人无礼，以神力令杖自击、僧人自投，示其威力而不杀。
原：《广记》：虞部郎中陆绍，元和中，尝看表兄于定水寺。因为院僧具密饵时果，并招邻院僧。良久，与一李秀才偕至。乃环坐，笑语颇剧。院僧顾弟子煮茗，巡将匝而不及李。陆不平，为言之，院僧颇出谩语。李怒，僧犹大言不止。李乃白座客：“某不免对贵客作造次矣。”因袖手据两膝，叱其僧曰：“粗行阿师，争敢无礼！柱杖何在，可击之！”其僧房门后有筇杖子，忽跃出连击其僧。时众亦有闭护，杖伺人隙捷中，若有物执持者。李复叱曰：“捉此僧向墙！”僧乃负墙拱手，色青气短，唯言乞命。李又曰：“阿师可下阶。”僧又趋下，自投无数，衄鼻败颡不已。众为请之。李徐曰：“缘衣冠在，不能杀此为累。”因揖客而去。僧半日方能言，如中恶状，竟不之测矣。
注：《广记》：《太平广记》，宋李昉等编，此条疑出《传奇》等小说，待考。
注：虞部郎中：工部虞部司主官，掌山泽苑囿。
注：陆绍：唐人，事迹待考。
注：元和：唐宪宗年号（806—820）。
注：表兄：姑舅兄长。
注：定水寺：寺名，待考。
注：密饵：蜜制糕饼。
注：谩语：轻侮的话。
注：粗行阿师：粗鲁的和尚；阿师，对僧人的称呼。
注：筇杖：竹杖，以邛竹所制。
注：中恶：中邪。
# 针奴脚

# 杖虎
题解：于子仁知登州，令虎入城伏罪受杖，可见其德政感动猛兽。
原：于子仁知登州府，部有诉其家人伤于虎者。子仁命卒持牒入山捕虎，卒泣不肯行。子仁笞之，更命他两卒。两卒不得已，入山，焚其牒。火方息而随至，弭耳贴尾，随行入城，观者如诸。虎至庭下，伏不动。子仁历声斥责，杖之百而舍之。虎复循故道而去。
注：于子仁：明代人，曾任登州知府，生平待考。
注：登州府：今山东蓬莱一带。
注：部：所辖地域。
注：牒：官府文书。
注：弭耳贴尾：耳朵下垂尾巴夹起，表示驯服。
注：历声：厉声。
# 葛孝先
题解：葛玄（葛孝先）能吐火、饭化蜂、使虫鸟起舞，为早期方士典型。
原：葛玄，字孝先。尝与宾同坐，复有来者，出迎之，坐上又有一玄与客语。时天寒，玄谓客人曰：“贫居不能人人得炉火，请作火，共使得暖。”玄因张口吐气，赫然火出，须臾满屋，客尽得如在日中。尝与客对食，食毕，嗽口，口中饭尽成大蜂数百头，飞行作声。良久张口，群蜂还飞入口中，玄嚼之，故是饭也。手拍床，虾蟆及诸虫飞鸟燕雀鱼鳖之属，使之舞，皆应弦节如人。玄止之，即止。
注：葛玄：字孝先，三国吴方士，后被道教尊为太极左仙公。
注：炉火：取暖之火。
注：赫然：火光盛貌。
注：蜂：此指饭变蜜蜂。
注：虾蟆：蛤蟆。
注：弦节：弦乐的节拍。

原：申屠有涯放旷云泉，常携一瓶，时跃身入瓶中。时人号为“瓶隐”。

# 外国道人
题解：引《灵鬼志》，记外国道人入笼吐人、吐妇、吐外夫的幻术，并设法使悭吝富人行善济贫。
原：《灵鬼志》：有道人外国来，解含刀吐火。行见一人担担，上有小笼子，可受升馀。语担人云：“吾步行疲极，欲寄君担。”担人以为戏也，应曰：“自可尔。君欲何许自厝？”答云：“若见许，正欲入笼子中。”担人愈怪之，乃下担。入笼中，笼更不大，其人亦不更小。担之亦觉重于先。既行数里，树下住食。担人呼共食。云：“我自有食。”不肯出，止住笼中，饮食器物罗列，肴膳丰腆亦办。乃呼担人食。未半，语担人“我欲妇共食”。腹中吐出一女子，年二十许，衣裳容貌甚美。二人共食。食欲竟，其夫便卧。妇语担人曰：“我有外夫，欲来共食。夫觉，君勿道之。”妇便口中出少年丈夫。此笼中便有三人。有顷，其夫动如欲觉，妇便以外夫内口中。夫起，语担人曰：“可去。”即以妇内口中，及食器物。此人即至国中，有一家大富贵，财巨万而性悭吝。语担人云：“试为君破悭。”即至其家。有好马，其珍之，系在柱上，忽失去，寻索不得。明日见马在五升瓮中，终不可破，便语曰：“君作百人厨，以周一方穷乏，马得出耳”。主人如其言，马还在柱下。明早其父母在堂上，忽然不见，举家惶怖。开装器，忽然见父母在泽壶中，不知何由，复往请之。其人云：“君更作千人饮食以饴百姓穷者。”当时便见父母在床也。
注：《灵鬼志》：南朝荀氏撰志怪，已佚；此条见《续齐谐记》亦有异文，故事源自佛经。

注：厝：安置。
注：丰腆：丰盛。
注：外夫：情夫。
注：悭吝：吝啬。
注：五升瓮：容五升的瓮。
注：百人厨：设宴宴请百人的厨具。
注：泽壶：沼泽中的壶，疑出“壶”幻术；待考。
注：饴：施予，给人以食物。

# 板桥三娘子
题解：引唐代传奇，板桥店三娘子以荞麦烧饼将旅客变驴，被赵季和以饼易之，反变成驴，终被老人释放。
原：《古今说海》：唐汴州西有板桥店，店娃三娘子者，独居鬻餐有年矣。而家甚富，多驴畜，每贱其估以济行客。元和中，许州客赵季和将诣东都。过客先至者，皆据便榻。赵得最深处一榻，逼主房。既而三娘子致酒极欢。赵不饮，但与言笑。二更许，客醉。合家灭独而寝。赵独不寐，忽闻隔壁窸窣声。偶于隙中窥之，见三娘子向覆器下取烛挑明，市箱中取小木牛、木人及耒耜之属，置灶前，含水噀之，人牛俱活。耕床前一席地讫，取荞麦子授木人种之。须臾麦熟，木人收割，可得七、八升。又安置小磨，即硙成面。却收前物仍置箱中，取面作烧饼。鸡鸣时，诸客欲发。三娘子先起，点灯设饼。赵心动，遽出，潜于户外窥之。乃见诸客食饼未尽，忽一时踣地作驴鸣。顷之，皆变驴矣。驱入店后，而尽没其财。赵亦不告于人。后月馀，赵自东都回。将至板桥店，预作荞麦烧饼大小如前，复寓宿焉。其席无他客，主人殷勤更甚。天明，设饼如初。越乘隙以已饼易其一枚。言烧饼某自有，请撤去以俟他客。即取己者食之。三娘子具茶。赵曰：“请主人尝客一饼。”乃取所易者与啖。才入口，三娘子据地即变为驴，甚壮健。赵即乘之，尽收其木人等，然不得其术。赵策所变驴，周游无失，日行百里。后四年，乘入关，至岳庙旁，见一老人拍手大笑曰：“板桥三娘子，何得作此！”因捉驴谓赵曰：“彼虽有过，然遭君已甚，可释矣。”乃从驴口鼻边，以两手掰开，三娘子从皮中跳出，向老人拜放讫，走去，不知所之。
注：《古今说海》：明陆楫编小说丛书，所收此篇出唐薛渔思《河东记》。
注：汴州：今河南开封。
注：板桥店：汴州西的旅店，位于板桥。
注：娃：女子，此指女店主。
注：鬻餐：卖饭食。
注：估：价格。
注：元和：唐宪宗年号。
注：许州：今河南许昌。
注：赵季和：故事主人公。
注：东都：洛阳。
注：便榻：方便处的床铺。
注：致酒：置酒款待。
注：合家：全家。
注：窸窣：细小声响。
注：耒耜：农具。
注：噀：含水喷出。
注：硙：石磨，此作动词，磨。
注：踣地：倒地。
注：岳庙：华山西岳庙。
注：掰开：用手扒开。
# 贵竹幻术
题解：贵州一带夷人能以木换人足，两个幕僚因奸淫之事被换足，官府追究后才复原。
原：贵竹地羊驿，民夷杂处，多幻术，能以木易人之足。那丞某过其地。记室二人，皆游于淫地。一人与淫，其夫怨，易其一足。一人不与淫，妇怨，易其一足。明日亍彳于庭，见丞。骇问，始知其故，即逮二家至。惧以罪，二人各邀其人归作法，足遂复。
注：贵竹：明代贵州贵竹长官司，今贵阳一带。
注：地羊驿：驿站名，待考。
注：民夷杂处：汉人与少数民族杂居。
注：丞：县丞。
注：记室：掌文书的幕僚。
注：淫地：指淫乱之事。
注：亍彳：踟蹰缓行貌，分开为行走不便之态。
注：逮：拘捕。
# 神巫
题解：吴景帝求觋验试，以埋鹅冢设局，觋者实言不见鬼，只见白鹅，可见其诚。
原：吴景帝有疾，求觋视者，得一人。帝欲试之，乃杀鹅埋苑中。架小屋，施床几，以妇人屐履服物著其上。使觋视人，曰：“若能说此冢中鬼妇人状，当加赏。”竟夕无言。帝推问之急，乃曰：“实不见鬼，但见一头白鹅立墓上耳。”
注：吴景帝：孙休，三国东吴君主。
注：觋：男巫。
注：苑：宫苑。
注：几：小桌。
注：屐履：木屐鞋履。
注：推问：追问。
# 数学
题解：管辂数术，预言苑玄龙家火灾由狐妖所致，教以留宿角巾书生化解。
原：管辂精于数学。乡里苑玄龙苦频火。辂云：“有角巾诸生，驾黑牛故车来，必留之宿。”后果有此生来，范固留之。生急求去，不听，遂宿。主人罢入。生惧图己，乃持刀门外，倚薪假寐。忽有一物以口吹火。生惊斫之，死，视之，狐也。自是不复有灾。
注：管辂：三国魏术数家，字公明，精通易数。
注：数学：术数之学。
注：苑玄龙：疑当作“范玄龙”，管辂乡人，见《搜神记》；底本前后作“苑”“范”。
注：频火：屡遭火灾。
注：角巾：有棱角的头巾，隐者所戴。
注：故车：旧车。
注：假寐：和衣小睡。
注：斫：砍。
# 卜天津桥、万寿寺
题解：记钱知微津桥卜卦的隐语与吴下张东谷卜佛寺迁毁，皆以灵验称。
原：唐天宝末，术士钱知微尝至洛，居于津桥卖卜，一卦帛十匹。历旬，人皆不诣之。一日，有贵公子意其必异，命取帛如数，卜焉。钱命蓍而卦成，曰：“君戏耳。”其人曰：“卜事甚切，先生岂误乎！”钱请为隐语曰：“两头点土，中心虚悬，人足踏跋，不肯下钱。”其人本意卖天津桥绐之。其精如此。
注：天宝：唐玄宗年号。
注：钱知微：唐代术士，事见《太平广记》。
注：津桥：洛阳天津桥。
注：帛十匹：占一卦收绢十匹。
注：蓍：蓍草，卜筮用。
注：隐语：谜语一类的话。
注：两头点土，中心虚悬：指桥的形状，“天津桥”之“桥”两头为土，中间悬空。
注：踏跋：疑为“踏”“跋”二字相连，意为踩踏；待考。
注：绐：欺骗。
原：相传吴下张东谷精于卜算，设肆于万寿寺前。或往卜，问是住宅。卦成，张云：“三日内合当迁毁。”其人指万寿寺曰：“吾戏卜佛住居也。千年香火，安得有此！”大笑而去。后三日，按台下檄，改寺为长洲新学，果如其言。
注：张东谷：吴人，精卜算，生平待考。
注：万寿寺：苏州万寿寺。
注：迁毁：迁移拆毁。
注：按台：巡按御史署。
注：长洲：明代苏州府属县，此指长洲县学。
# 射覆
题解：朱升善六壬射覆，以射语“一味鱼，两味鱼”言中盒中之物，并对借马牵驴之事作戏语。
原：朱允升早从资中黄楚望游，偕同郡赵汸受经，馀暇遂得六壬之奥。偶访友人，见案上置四合。戏谓：“君能射覆乎？中则奉之，否则为他人饷也。”朱更索一合书射语，亦合而置之，曰：“少俟则启。”适有借马者，友人令奴于后山牵驴应之。朱即令一时俱启，前四合皆鱼也。射语云：“一味鱼，两味鱼，其馀两味皆是鱼。有人来借马，后山去牵驴。”宾主为之绝倒。
注：朱允升：朱升，字允升，元末明初，辅佐朱元璋。
注：资中黄楚望：黄泽，字楚望，元代经学家，四川资中人。
注：赵汸：元末明初经学家，字子常，与朱升同乡。
注：六壬：术数之一，与遁甲、太乙合称“三式”。
注：射覆：猜测覆盖物下的东西，一种占卜与酒令游戏。
注：合：盒子。
注：饷：赠送。
# 拆字
题解：谢石以拆字占验神奇，受徽宗召见，以“也”字解怀孕十三月为蛇妖；又有周生拆“杭”字、“退”字与“串”字的案例。
原：谢石润夫，成都人。宣和至京师，以拆字言人祸福。求相者，但随意书一字，即就其字离析而言，无不奇中。名闻九重，上皇因书一“朝”字，令中贵人持往试之。石见字，即端视中贵人曰：“此非观察所书也。”中贵人愕然曰：“但据字言之。”石以手加额曰：“朝字，离之为十月十日字，非此月此日所生之天人，当谁书也！”一座尽惊。中贵驰奏。翌日召至后苑，令左右及宫嫔书字示之。论说俱有精理。锡赉甚厚，补承信郎。缘此四方求相者，其门如市。有朝士，其室怀娠过月，手书一“也”字，令其夫持问。是日坐客甚众。石详视字，谓朝士曰：“此阁中所书否？”曰：“何以言之？”石曰：“谓语助者，焉哉乎也。固知是公内助所书。阁盛年三十一否？”曰：“是也。”以也字上为三十，下为一字也。然吾官寄此，当力谋迁动而不可得否？”曰：“正以此为挠耳。”“盖也字，著水则为池，有马则为驰。今池运则无水，陆驰则无马。是安可动也！又尊阁父母兄弟，近身亲人皆当无一存者。以也字著人则是他字，今独见也字，而不见人故也。又尊阁其家物产亦当荡尽否？以也字著土，则为地字。今不见土，只见也。俱是否？”曰：“诚如所言。”朝士即谓之曰：“此皆非所问者。但贱室忧怀娠过月，所以问耳。”石曰：“是必十三个月也。以也字中有十字，并两傍二竖，下画为十三也。”石熟视朝士曰：“有一事似涉奇怪。固欲不言，则吾官所问，正决此事。可尽言否？”朝士因请其说。石曰：“也字著虫为虵字。今尊阁所娠，殆蛇妖也。然不见虫，则不能为害。谢石亦有薄术，可为吾官以药下验之，无苦也。”朝士大异其说，固请至家。以药投之，果下数百小蛇。都人益共神之，而不知其竟挟何术。
注：谢石润夫：谢石，字润夫，北宋末拆字术士，见《宋稗类钞》等。
注：成都：今四川成都。
注：宣和：宋徽宗年号。
注：拆字：测字，把字形拆开附会吉凶。
注：九重：指皇宫。
注：上皇：徽宗禅位后称太上皇。
注：中贵人：宦官。
注：观察：官名，对武臣的敬称。
注：离析：分拆。
注：天人：指皇帝。
注：朝：拆为“十月十日”，指徽宗生于十月十日，即天宁节。
注：后苑：宫中后花园。
注：宫嫔：宫中妃嫔。
注：锡赉：赏赐。
注：承信郎：宋武阶官，低级。
注：朝士：在朝官员。
注：怀娠：怀孕。
注：内助：妻子。
注：阁：对他人妻子的敬称。
注：挠：阻挠。
注：也字，著水则为池：“也”加水旁为“池”。
注：也字著土：“也”加土旁为“地”。
注：十三个月：怀孕十三个月。
注：虵：同“蛇”。
原：建炎间，术者周生善相字。车驾至杭，时虏骑惊扰之馀，人心危疑。执政呼周生，偶书“杭”字示之。周曰：“惧有警报。”乃拆其字，以右边一点配木上，即为兀术。不旬日，果传兀术南侵。当赵、秦庙谟不协，各欲引退。二公各书“退”字示之。周曰：“赵必去，秦必留。‘日’者君象，赵书‘退’字，‘人’ 去‘日’远，秦书‘人’字密附‘日’下，字在左笔下连，而‘人’字左笔斜贯之。踪迹固矣，欲退得乎！”既而皆验。
注：建炎：宋高宗年号。
注：周生：宋代测字术士，生平待考。
注：车驾至杭：指高宗驻杭州。
注：兀术：完颜宗弼，金军统帅。
注：赵、秦：赵鼎与秦桧，皆高宗朝宰相。
注：庙谟：朝廷谋划。
注：君象：古以日喻君。
原：往年有叩试事者，书“串”字。术士曰：“不特乡闱得隽，南宫亦应高捷。盖以串寓二‘中’字也。”一生在旁，乃亦书“串”字令观。术者曰：“君不独不与宾兴，更当疾。”询其所以，曰：“彼以无心书，故当如字。君以有心书，‘串’下加‘心’，乃‘患’字耳。”已而果然。
注：乡闱：乡试。
注：得隽：中举。
注：南宫：礼部会试。
注：宾兴：乡举之礼，借指应举。
注：串：中间一“中”字二个叠合，故言“二中”。
# 临安术士
题解：临安术士“铁扫帚”预言细民有大戮之灾，细民果因怒打死术士而获罪，是命理预言的反讽。
原：临安术士，自榜曰“铁扫帚”，设卜肆于执政府墙下，言多验。淳熙甲辰季冬，一细民来问命。告之曰：“君星数甚恶，明春恐不免大戮。若禁足一月，可免。”民颇不信，而以所戒惇切，勉为杜门。至正月晦日，度已无恙，乃往咎其不验，术士再为推测，布局才就，复云：“今日尚是正月，犹虑有人命之危。”民忿恚，诋其诞妾，相与争詈不已，不胜忿，曰：“我只打杀汝以验汝术！”奋脚中胁，立死，遂得罪。
注：临安：今杭州。
注：铁扫帚：术士的自号。
注：卜肆：占卜的铺子。
注：执政府：宰相府。
注：淳熙：宋孝宗年号（1174—1189）。
注：甲辰：淳熙十一年（1184）。
注：星数：命理。
注：大戮：死刑。
注：晦日：每月最后一天。
注：推测：推算。
注：诞妾：疑当作“诞妄”，荒诞虚妄。
注：争詈：争吵辱骂。
# 神画
题解：南唐冯延巳误以屏风上画的西施为真人，以显画艺之神，并联想孙权弹蝇事。
原：南唐后主坐碧落宫，召冯延巳论事。至宫门，逡巡不进。后主使使促之。延巳云：“有宫娥著青红锦袍当门而立，故不敢径进。”使随共行谤视，乃八尺琉璃屏画《夷光独立图》。问之，董源笔也。此与孙权弹蝇何异。
注：南唐后主：李煜。
注：碧落宫：南唐宫殿名，待考。
注：冯延巳：南唐宰相，词人；此事时代与后主不合，当为中主李璟时。
注：逡巡：徘徊不前。
注：琉璃屏：以琉璃镶成的屏风。
注：夷光：西施之字。
注：董源：南唐画家，善山水。
注：孙权弹蝇：三国吴曹不兴为孙权画屏风，误落墨作蝇，权以为真，挥手弹之，见《吴录》。
# 神篆
题解：章友直以篆书称名，当着翰林篆字待诏之面，粗细疏密毫发不爽，令众人折服。
原：章友直伯益以篆得名，召至京师。翰林院篆字待诏数人闻其名，未心服也。俟其至，俱来见之，云：“闻妙艺久矣，愿见笔法。”伯益命粘纸各数张作二图，即令泚墨濡毫。其一纵横各十九画，成一棋局；一作十圆圈，成一射贴。其笔之粗细疏密，毫发不爽。众大惊服，再拜而去。
注：章友直：字伯益，北宋篆书名家，以篆名世。
注：翰林院篆字待诏：宋翰林院设书艺局，有待诏。
注：泚墨：蘸墨。
注：濡毫：润笔。
注：射贴：射箭靶。
# 神射
题解：督君谟善闭目射箭，弟子王灵智欲杀师，反被以口啮箭，示其更高一筹。
原：隋末有督君谟，善闭目而射。志其目，则中目；志其口，则中口。有王灵智者，学射于君谟。久之，曲尽其妙，欲射杀君谟，独擅其美。君谟时无弓矢，执一短刀，箭来辄截之。末后一矢，君谟张口承之，遂啮其镝。于是笑曰：“汝学射三年，不教汝啮镞法耳。”
注：督君谟：隋末射手，名见《朝野佥载》，待考。
注：志：标记。
注：王灵智：督君谟弟子，待考。
注：擅其美：独占其善。
注：镝：箭头。
注：啮：咬。
# 张芬
题解：张芬弹丸写字、拈蝇而不失，是唐人笔记中的神技。
原：张芬曾为韦皋行军，多力善弹。每涂墙方丈，弹成“天下太平”字。字体端严，如人摸成。曾有一客，于宴席上以筹碗中菉豆击蝇，十不失一。一座惊笑。芬曰：“无费吾豆。”遂指起蝇，拈其后脚，略无脱者。
注：张芬：唐人，曾在韦皋手下任行军。
注：韦皋：唐德宗时剑南西川节度使。

# 河北将军
题解：河北夏姓将军弯弓、击鞠、掷豆贯刺，皆是技艺中的绝活。
原：建中初，有河北将军姓夏，弯弓数百斤。常于球场中累钱十馀，走马以击鞠杖击之，一击一钱飞起，高六七丈。其妙如此。又于新泥墙安棘荆数十。到烂豆，相去一丈，掷豆贯于刺上，百不差一。又能走马书一纸。
注：建中：唐德宗年号（780—783）。
注：弯弓数百斤：拉动重量数百斤的强弓。
注：击鞠：打马球。
注：鞠杖：马球棍。
注：棘荆：荆棘。
注：烂豆：煮烂的豆。
# 杨大眼绝枝
题解：杨大眼向李冲展示系发奔跑的绝技，以求任职，传其神力过人。
原：后魏杨大眼，武都氐难当之孙，少有胆气，跳走如飞。高祖南伐，李冲典选征官。大眼求焉，冲不许。大眼曰：“尚书不见知，为尚书出一技。”便以绳长三丈，系髻而走，绳直如矢，马驰不及。见者莫不惊叹。
注：杨大眼：北魏将领，氐族人，勇冠三军。
注：武都氐难当：杨难当，十六国时仇池国王，杨大眼的祖父。
注：高祖：北魏孝文帝。
注：李冲：孝文帝朝重臣，尚书仆射。
注：典选：主管选官。
注：髻：发髻。
# 汪节等
题解：记神策将军汪节、王俳优、王大娘三则力士技艺，皆负重而舞，毫无困乏。
原：神策将军汪节有神力。尝对御俯身负一石碾，碾上置二丈方木，又置一床，床上坐龟兹乐人一部，奏曲终而下，无压重之色。
注：神策将军：唐禁军神策军统领。
注：汪节：唐德宗时神力将军，待考。
注：碾：石碾。
注：龟兹乐：西域龟兹传入的乐舞。
原：唐乾符中，绵竹王俳优者，有巨力。每遇府中饷军宴客，先呈百戏。王腰背一船，船中载十二人，舞《河传》一曲，略无困乏。
注：乾符：唐僖宗年号（874—879）。
注：绵竹：今四川绵竹。
注：俳优：以滑稽表演为业者。
注：百戏：杂技乐舞的总称。
注：河传：词牌兼乐曲名。
原：德宗时，三原王大娘，以首戴十八人而舞。
注：德宗：唐德宗。
注：三原：今陕西三原。
注：王大娘：唐代杂技艺人，以顶竿著称。
# 善走

原：徐州人张成喜疾走，日行五百里。每举足，辄不可禁，必著墙抱树，方止，体犹振动久之。

注：张成：唐代人，生平待考。

# 木僧
题解：将作大匠杨务廉造木僧，能行乞并发声“布施”，为古代机械傀儡的名例。
原：将作大匠杨务廉甚有巧思。尝于沁州市内刻木作僧，手执一碗，自能行乞。碗中投钱，关键忽发，自然作声云：“布施。”市人竞观，欲其作声，施者日盈数千。
注：将作大匠：掌管宫室营造的官员。
注：杨务廉：唐初巧匠，官至将作大匠。
注：沁州：今山西沁源一带。
注：关键：机关枢纽。
注：布施：佛教语，施舍财物。
# 东岳精艺
题解：太山东岳庙会集天下技艺，凿纸钱不伤下纸，庖人以背为砧细切肉，皆属绝技。
原：蒋大防母夫人云：少日随亲谒太山东岳，天下之精艺毕集。人有纸一百番，凿为钱，运如飞。既毕举之，其下一番，未尝有凿痕之迹；其上九十九番，则纸钱也。又一庖人，令一人袒背，俯偻于地，以其背为刀几，取肉二斤许，运刀细缕之。撤肉而拭其背，无丝毫之伤。
注：蒋大防：待考；或作“蒋大防之母”，故“蒋大防母夫人”指其母。
注：太山：泰山。
注：东岳：东岳庙，在泰山下。
注：番：张。
注：刀几：砧板。
注：袒背：露出背部。
注：俯偻：弯腰曲背。

# 雕刻绝艺
题解：引《狯园》，记吴人顾四以桃核刻成小舟、胡桃壳为秘戏床，雕刻之精令人叹服。
原：《狯园》云：吴人顾四刻桃核作小舸子，大可二寸许，逢樯舵橹纤索莫不悉具。一人岸帻卸衣，盘礴于船头，衔杯自若。一人脱巾袒卧船头，横笛而吹。其傍有覆笠一人，蹲于船尾，相对风炉扇火温酒，作收舵不行状。船中壶觞竹案，左右皆格子眼窗，玲珑相望。窗楣两边有春贴子一联，是“好风能自至，明月不须期”十字。其人物之细，眉发机棙，无不历历分明。又曾见一橄榄花篮，是小章所造也，形制精工丝缕若析。其盖可开，合上有提，当孔之中穿绦，与真者无异。又曾见小顾雕一胡桃壳，壳色摩刷作橘皮文，光泽可鉴。揭开，中间有象牙壁门双扇。复启视之，则红勾栏内安紫檀床一张，罗帏小开，男女秘戏其中。眉目疑画，形体毕露，宛如人间横陈之状。施关发机，皆能摇动如生，虽古棘刺木猴无过也。其弟子沈子叙，亦良工有名。
注：《狯园》：明钱希言撰。
注：顾四：吴人，雕刻巧匠，待考。
注：桃核：桃的核。
注：舸子：小船。
注：樯舵橹纤：桅、舵、橹、拉船的绳。
注：岸帻：把头巾推起，露出前额。
注：盘礴：箕踞，随意坐状。
注：风炉：烧水温酒的小炉。
注：壶觞：酒器。
注：格子眼窗：格子窗。
注：好风能自至，明月不须期：待考，疑出自宋人诗句。
注：机棙：机关。
注：小章：指雕刻匠小章，待考。
注：绦：丝带。
注：勾栏：栏杆。
注：紫檀：名贵木材。
注：棘刺木猴：《韩非子·外储说左上》载燕王求“棘刺端造猴”之事，为虚诞之喻。
注：沈子叙：顾四弟子，待考。
# 虫戏
题解：引《辍耕录》《湖海搜奇》，记驯养蛙、蚁、鼠的杂耍，感叹不知其如何教导。
原：《辍耕录》云：在杭州，尝见一弄百禽者。畜虾蟆九枚，先置一小墩于席中，其最大者乃踞坐之，馀八小者左右对列。大者作一声，众亦一声；大者作数声，众亦数声。既而小者一一至大者前点首作声，如作礼状而退。谓之“虾蟆说法”，又谓“虾蟆教学”。
注：《辍耕录》：元陶宗仪撰笔记《南村辍耕录》。
注：弄百禽者：以驯养各种动物为业的艺人。
注：虾蟆：蛤蟆。
注：墩：土墩。
注：踞坐：蹲坐。
注：点首：点头。
注：说法：佛教讲经。
原：王兆云《湖海搜奇》云：京师教坊赤、黑蚁子列阵，能按鼓合金退之节，无一混淆者。又予在山东，见一人卖药。二大鼠在笼中。人求药，呼鼠之名曰：“某为我取人参来！”鼠跃出笼，衔人参纸裹而至。又呼其一曰：“某为我取黄连来！”亦复如是，百不失一。不知何以教导也。
注：王兆云：明代人，撰《湖海搜奇》。
注：教坊：宫廷乐舞官署。
注：按鼓合金退之节：按击鼓前进、鸣金后退的节拍。
注：混淆：杂乱。
注：人参：贵重药材。
注：黄连：苦味药材。
