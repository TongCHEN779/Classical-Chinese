# 正文
题解：《佻达》部卷首小引：子犹说不拘小节之士中多有魁杰高才，姑且收集，以洗俗士肺肠。
原：〔子忧曰：百围之木，不于枝叶取怜。士之介自喜、不拘小节者，其中尽有魁杰骏雄、高人才子。或潜见各途，能不尽见，吾亦姑取焉，以淘俗士之肺肠。集《佻达》第十一。〕
注：子忧曰：当作“子犹曰”，冯梦龙评语；底本“忧”疑误。
注：百围之木，不于枝叶取怜：粗大的树不在乎枝叶是否可爱，喻大才不拘小节。
注：不拘小节：不拘泥于细小礼节；“介自喜”指孤高自赏。
注：魁杰骏雄：杰出英雄。
注：潜见各途：有的隐有的显，各走不同道路。
注：淘：洗涤。
注：集《佻达》第十一：本书第十一部。
# 简文帝
题解：简文帝为抚军时，床上积尘不让拂拭，见鼠迹反以为佳，写其任诞。
原：简文为抚军时，床上尘不听拂，见鼠行迹，视以为佳。
注：简文：晋简文帝司马昱，即位前为抚军将军，《世说新语·言语》载此事。
注：抚军：抚军将军。
注：听：允许。
注：鼠行迹：老鼠走过的痕迹。
# 张徐州
题解：裴宽遇衣着破旧的张徐州，认为必当富贵，尽以船上钱帛奴婢相赠，张受之不让，写豪举。
原：裴宽尚书罢郡西归汴日，晚维舟，见一人坐树下，衣服极敝。与语，大奇之，曰：“以君才识，必当富贵。”举船钱帛奴婢悉以贶之。客受贶不让，登舟，奴婢稍偃蹇，辄鞭之。裴公益异焉。其人，张徐州也。
注：裴宽：唐代名臣，曾官礼部尚书，《旧唐书》有传。
注：罢郡：解任郡守。
注：汴：汴州，今河南开封。
注：维舟：系船。
注：贶：赠与。
注：偃蹇：傲慢。
注：张徐州：张建封，曾任徐州刺史，《旧唐书》有传。
# 杨铁崖
题解：杨维桢愿为蒋氏教子，提出不拘日课、供行乐费、备别墅三条，三年后其子皆成名士，写其放达。
原：姑苏蒋氏，巨家也。有子甫八龄，欲为求师。时杨铁崖先生居吴淞，放情山水，日携宾客妓女，以文酒为乐。蒋往延之。杨曰：“能从三事则可，币不足计也。一无拘日课，二资行乐费，三须一别墅以贮家人。”蒋欣然从之。杨留三年，后其子俱成名士。
注：姑苏：苏州。
注：蒋氏：苏州富家。
注：杨铁崖：杨维桢，号铁崖，元末明初文学家，诗风奇谲。
注：吴淞：吴淞江，今上海一带。
注：放情山水：纵情山水。
注：币：礼金。
注：日课：每日功课。
注：别墅：别宅。
注：贮家人：安置家人。
# 酒濯足
题解：马周初入京师，看不起他的公子们饮酒，他买酒濯足，写落魄时的傲气。
原：马周初入京，至霸上逆旅。数公子饮酒，不之顾。周即市斗酒，濯足于旁。
注：马周：唐初名臣，初为布衣，后受唐太宗重用，《旧唐书》有传。
注：霸上：长安东，今陕西西安东。
注：逆旅：旅店。
注：斗酒：一斗酒。
注：濯足：洗脚。
# 百裈
题解：梁吉士瞻少时赌博无裤，为人所侮，成将军后赐绢三万匹，写以前的穷困与后来的豪举。
原：梁吉士瞻少时，掷搏无裈，为侪辈所侮。及为将军，所绢三万匹，为百裈，其外并赐军士。
注：吉士瞻：南朝梁将，当作“吉士瞻”，《梁书》有传，一说为“吉士瞻”或“吉翂”，待考。
注：掷搏：赌博。
注：裈：裤子。
注：侪辈：同辈。
注：百裈：一百条裤子。
# 盗
题解：祖逖渡江后俭薄，忽见华服珍饰，说“昨夜复南塘一出”，戏称自己曾去“偷盗”，写其诙谐。
原：祖车骑过江时，公私俭薄，无好服玩。王、瘐诸公共就祖。忽见裘袍重迭，珍饰盈利。诸公怪问之。祖曰：“昨夜复南塘一出。”
注：祖车骑：祖逖，官车骑将军，北伐名将。
注：过江：东晋南渡。
注：俭薄：贫穷。
注：王、瘐诸公：王导、庾亮等人，“瘐”当作“庾”。
注：裘袍：皮衣。
注：珍饰：珍贵的饰物。
注：南塘：建康秦淮河南，旧时为商民聚居处，祖逖戏称去南塘劫掠。
# 乞
题解：韩熙载散尽月俸，乞食取笑，写其颓放与逃避。
原：南唐韩熙载，字叔言，肆情坦率，鼓乐百馀人，日与荒乐。所得月俸，散与诸姬。熙载敝衣芒履，作瞽者，持独弦琴，俾门生舒雅执板挽之，随房乞食，以为笑乐。
注：韩熙载：南唐名臣，字叔言，《南唐书》有传，有《韩熙载夜宴图》。
注：肆情：放纵情感。
注：鼓乐：乐伎。
注：月俸：每月薪俸。
注：芒履：草鞋。
注：瞽者：盲人。
注：独弦琴：一弦琴。
注：舒雅：南唐文人，韩熙载门生，后入宋。
注：执板：拿拍板。
注：随房乞食：沿门乞讨。
# 唱莲花道情
题解：祝允明、唐寅、张灵装乞儿唱《莲花落》，又披氅登虎丘，唱道情，写吴中才子放浪。
原：苏郡祝允明、唐寅、张灵、皆诞节倡狂。尝雨雪中，作乞儿鼓节，唱《莲花落》，得钱沽酒野寺中，曰：“此乐惜不令太白知之！”又尝披氅持篮，相与跻虎丘，为道人唱。有客吟颇涩，乃借笔疾书数韵，云烟满纸，翻然而逝。各纵迹之，不得，遂疑为仙。
注：苏郡：苏州。
注：祝允明：字希哲，号枝山，明代书法家。
注：唐寅：字伯虎，号六如，明代画家。
注：张灵：字梦晋，吴中才子，与唐寅交好。
注：诞节倡狂：放诞狂妄。
注：鼓节：打节拍。
注：《莲花落》：乞丐所唱的歌，也称莲花乐。
注：沽酒：买酒。
注：太白：李白，诗酒狂士。
注：披氅：穿鹤氅。
注：虎丘：苏州名胜。
注：涩：不流畅。
注：云烟满纸：笔势如云烟。
注：翻然：迅速地。
# 募缘
题解：唐伯虎、祝希哲假扮道士向盐使者募缘，赋诗得金，转用于游乐，后事发而盐使者爱才不问。
原：唐子畏、祝希哲两公，浪游维扬，资用乏绝。戏谓盐使者课税甚饶，乃伪作玄妙观募缘道士，衣冠甚伟，诣台造请。盐使者怒吒之。两公对曰：“贫道非游食者流也。所与交，皆天下贤豪长者，即如吾吴唐伯虎、祝希哲辈，咸折节为友。明公不弃，请奏薄技。惟公所命。”御史霁威，随指牛眠石为题，命赋之。唐先祝继，立就一律，词云：“嵯峨怪石倚云间，头角峥嵘势俨然。苔藓作毛因雨长，藤萝穿鼻任风牵。长眠不食溪边草，无力难耕陇上田。怪杀牧童鞭不起，笛声斜挂夕阳烟。”御史得诗，笑曰：“诗则佳矣，意欲何为？”两公进曰：“明公轻财好施，天下莫不闻。今姑苏玄妙观圮甚，倘捐俸葺之，名且不朽。”御史大悦即檄下长、吴二邑，资金五百为葺观费。两公遂乘扁舟归，投檄二邑，更修刺谒二尹，诈为道士，关说得金如数。乃悉召诸妓及所与游者，畅饮数日而尽。异日，盐使者按吴，诣观瞻礼，见倾圮如故，召令责之。对曰：“前唐解元、祝京兆两公自维扬来，极道明公为此胜举，金已如数畀之久矣。”盐使者怅然，心知两公，然惜其才，不问也。
注：唐子畏：唐寅，字子畏、伯虎。
注：祝希哲：祝允明，字希哲。
注：维扬：扬州。
注：盐使者：两淮巡盐御史。
注：课税：盐税。
注：玄妙观：苏州道观，在今苏州观前街。
注：募缘：募化缘金。
注：诣台造请：到官署拜访。
注：怒吒：怒喝。
注：游食者流：游手好闲、混饭吃的人。
注：折节：屈己下人。
注：牛眠石：形似牛卧的石头。
注：嵯峨：高峻。
注：峥嵘：形容突出。
注：圮：倒塌。
注：葺：修缮。
注：檄：官府文书。
注：长、吴二邑：长洲、吴县，皆属苏州。
注：尹：县令。
注：关说：说情。
注：按吴：巡察苏州。
注：解元：乡试第一，唐寅曾中解元。
注：京兆：祝允明曾任应天府通判，称“祝京兆”。
注：畀：给予。
# 佣
题解：唐伯虎假扮华安入华学士家，得婢桂华，后以身份揭晓相对大笑，即“三笑”故事的来源。
原：唐子畏往茅山进香，道出无锡。晚泊河下，登岸闲步，见肩舆东来，女从如云，中有丫环尤艳。唐迹之，如是华学士宅，因逗留，请为佣书。改名华安，复宠任，谋为择妇，因得此婢，名桂华。居数日，为巫臣之逃。华令人索之，不得。久之，华偶至阊门，见书肆中一人持文翻阅，极类安。私询之，人云：“此唐解元也。”明日，修刺往谒，审视无异。及茶至，而枝指露，益信，然终难启齿。唐命酒对酌，华不能忍，稍述华安始末以挑之。唐但唯唯。华又云：“貌正肖公，不知何故？”唐又唯唯。华不安，欲起别去。唐曰：“少从容，当有所请。”酒复数行，唐命烛异入后堂，召诸婢拥新娘出拜。华愕然。唐曰：“无伤也。”拜毕，因携女近毕曰：“公向言某似华安，不识挂华亦似此女否？”乃相与大笑而别。见《泾林续记》。
注：茅山：江苏句容，道教名山。
注：无锡：今江苏无锡。
注：肩舆：轿子。
注：华学士：华珵，明代无锡人，一说华察，待考。
注：佣书：受雇抄书。
注：华安：唐寅所用化名。
注：桂华：丫环名。
注：巫臣之逃：用楚申公巫臣携夏姬奔晋事，指带婢女出走。
注：阊门：苏州城西门。
注：书肆：书铺。
注：修刺：递名帖。
注：枝指：多生的指头，唐寅有枝指。
注：《泾林续记》：明周玄晔所撰笔记。
# 祝京兆
题解：祝允明好欠债，借银器砸毁、借白袍典当，又因窘迫而卖字，写其放荡不羁。
原：祝京兆有债癖。每肩舆出，则索逋者累累相随。盖债家谓：“不住索，恐其复借”，而京兆亦恬然不为怪也。尝托言款客，往友家借银镶锺数事。既借，主人心疑，遣仆随其舆察之，则已汲汲擗银而弃胚于外矣。仆追止之。京兆曰：“借我即我物也！汝欲用，亦拿一两事去不妨。”又岁尽乏用，遍走柬于所亲知，托言吊丧，借得白员领共五十馀件，并付质库。过岁首，诸有奴云集，则皆索白员领者也。觅典票，已失之矣。
注：祝京兆：祝允明。
注：债癖：欠债成癖。
注：索逋者：讨债者。
注：恬然：安然。
注：银镶锺：银镶茶杯。
注：擗：掰开。
注：胚：胎，指银器胎。
注：白员领：白圆领袍。
注：质库：当铺。
注：典票：当票。
原：祝希哲见古法书名画，每捐业蓄之。即故昂其直，弗较。或留客，值窘时，即以所蓄易值，得初其仅什一二耳。黠者俟其窘日，持少钱米，乞文及手书，辄得。已小饶，更自贵也。一富家持厚币求公书墓文。公鄙而不许。既窘极，友人乘间为言。公曰：“必计字偿钱乃可。”富家治酒延之。公半酣，趣笔墨砚来，因令前置一器，每书一字，则投十钱于器内。既书可二、三百字，睨视器中，曰：“足矣！”欣然持器竟出。众留之不得，富家因别倩人笔焉。
注：法书：名人字帖。
注：名画：著名画作。
注：捐业：舍弃产业。
注：故昂其直：存心抬高价格。
注：黠者：狡猾的人。
注：乞文：求诗文。
注：手书：亲笔字。
注：墓文：墓志铭。
注：趣：催促。
注：睨：斜视。
注：倩：请。
# 白羊肉羹
题解：罗友为尝白羊肉羹而赴宴，吃饱便走，毫无愧色，写其旷达，出《世说新语》。
原：罗友，字他仁，襄阳人，作荆州从事。桓宣武为王车骑洽集别。友进坐良久，辞出。宣武曰：“卿向欲谘事，何以便去？”答曰：“友闻白羊肉羹，一生未曾得吃，故冒求前耳。无事可谘。今已饱，不复驻。”了无怍色。
注：罗友：东晋人，字宅仁，襄阳人，《晋书》有传。
注：荆州从事：荆州刺史属官。
注：桓宣武：桓温，谥宣武。
注：王车骑洽：王洽，字敬和，官车骑将军，赴任。
注：谘事：请示事情。
注：冒求前：冒昧前来。
注：怍色：惭色。
# 裴御史
题解：崔瞻在御史台自带珍馐独食，裴御史自带匕箸来吃，被称名士，写不拘小节。
原：崔瞻在御史台，恒于宅中送食，备尽珍羞，别室独餐，处之自若。有一御史姓裴，伺瞻食，便往造焉。瞻不与交言，又不命匕箸。裴坐视瞻食罢而退。明日，裴自携匕箸，恣情饮啖。瞻曰：“君不拘小节，定名士！”于是每与同食。
注：崔瞻：北齐人，字彦通，《北齐书》有传，风度雅致。
注：御史台：监察官署。
注：珍羞：美味。
注：匕箸：勺子和筷子。
注：恣情饮啖：随意吃。
# 《汉书》下酒
题解：苏舜钦读《汉书》以酒下，杜衍见其“张良击秦”处满饮，笑称有此下酒物，一斗不算多。
原：苏子美豪放好饮，在外舅杜祁公家，每夕读书，以一斗为率。公密觇之。苏读《汉书·张良传》，至良与客狙击秦皇帝，抚掌曰：“惜乎击之不中！”遂满引一大白。又读至“良曰：‘始臣起自下邳，与上会于留，此天以授陛下。’”又抚案曰：“君臣相遇，其难如此！”复举一大白。公笑曰：“有如此下物，一斗不足多也。”
注：苏子美：苏舜钦，字子美，北宋诗人。
注：外舅：岳父。
注：杜祁公：杜衍，封祁国公，北宋名相，苏舜钦岳父。
注：率：标准。
注：觇：偷看。
注：狙击秦皇帝：《史记·留侯世家》载张良与力士在博浪沙击秦始皇。
注：满引一大白：满杯饮一大杯，“大白”指大酒杯。
注：下邳：张良避难处。
注：天以授陛下：《史记·留侯世家》张良语刘邦。
# 刘伶
题解：刘伶裸体在屋中，称天地为房屋，屋室为裤子，是《世说新语·任诞》名篇。
原：刘伶恒纵酒放达。或脱衣裸形在屋中，人见讥之。伶曰：“我以天地为栋宇，屋室为裈衣。诸君何以入我裈中？”
注：刘伶：“竹林七贤”之一。
注：放达：不拘礼法。
注：裸形：裸体。
注：栋宇：房屋。
注：裈衣：裤子。
# 二张
题解：张献翼与张孝资二人效刘伶而置锸，及郭嗣焕与张孝资不拘主客，皆写吴中文士之狂。
原：张敉堂慕刘伶达生，置一锸，铭曰：“死便埋我。”出或令人负之。臧获以为耻。曰：“汝非伯化仆也。”笑而置之壁间。张孝资一见大喜，持以相随，曰：“此非俗人所知。”客有乞一荷者，拒之，曰：“毋污此锸。”遇酒后，遂不肯持，曰：“见者以吾党为醉，便涉相戏。”
注：张敉堂：张献翼，字幼于，号敉堂，吴中文士，言行放诞。
注：达生：通达生死。
注：锸：铁锹，刘伶出行常使人荷锸相随，说“死便掘地埋我”。
注：臧获：奴婢。
注：伯化：待考。
注：张孝资：张孝资，吴中人，待考。
注：吾党：我辈。
原：郭郡倅嗣焕，善张幼于。尝订夜谈，途遇张孝资，偕之径造，南面大嚼。郭不问客，张不问主。
注：郭郡倅嗣焕：郭嗣焕，待考。
注：郡倅：知府副职，通判。
注：善：交好。
注：径造：直接前往。
注：南面大嚼：面南而坐大吃，南面为尊位。
# 豪饮
题解：石曼卿豪饮，有“囚饮”“巢饮”“鳖饮”等名；司马消难以车轮括颈饮；光逸裸体窥饮，写魏晋以来豪饮之风。
原：石曼卿善豪饮，与布衣刘潜为友。尝通判海州，刘潜访之。曼卿与潜剧饮，中夜酒欲竭，顾瓮中有醋斗馀，乃倾入酒中，并饮之。每与客痛饮，露发跣足，著械而坐，谓之“囚饮”。饮于木杪，谓之“巢饮”。取槁束之，引首出饮，谓之“鳖饮”。其狂纵大率如此。廨后为一庵，常过其间，名之曰“扪虱阉”。未尝一日不醉。
注：石曼卿：石延年。
注：布衣刘潜：刘潜，北宋处士，字仲方，与石延年交好。
注：通判海州：通判，州府副长官；海州今江苏连云港。
注：醋斗馀：一斗多醋。
注：露发跣足：披头赤脚。
注：著械：戴枷锁。
注：囚饮：像囚犯般饮。
注：木杪：树梢。
注：巢饮：像鸟巢饮。
注：鳖饮：缩头如鳖饮。
注：廨：官署。
注：扪虱：晋王猛扪虱而谈，此取名。
原：黄门郎司马消难，尝遇高季式，与之酣饮，重门并闭，取车轮括消难颈，又自以一轮括颈。消难笑而从之。
注：黄门郎：黄门侍郎。
注：司马消难：北齐人，后叛归北周。
注：高季式：北齐将领，《北齐书》有传。
注：重门并闭：关闭几重门。
注：括颈：套在颈上。
原：光孟祖避难渡江，欲投胡毋彦国。初至，胡彦国和谢鲲诸人散发裸袒，闭室酣饮，已累日。孟祖将排户，守者不听。孟祖便于户外脱衣露顶，于狗窦中窥之而大叫。彦国惊曰：“他人决不能尔，必我孟祖”遽呼入，与饮。
注：光孟祖：光逸，字孟祖，东晋人。
注：胡毋彦国：胡毋辅之，字彦国。
注：谢鲲：东晋名士。
注：散发裸袒：披头散发赤身。
注：狗窦：狗洞。
注：遽：立刻。
# 酒狂
题解：俞华麓醉后喧哗，巡抚参劾他“聊有晋人风度，绝无汉官威仪”，他笑称“聊有”不够，写酒狂。
原：俞华麓宦京师，有乡人邀饮，醉后大哗。某大僚居密饮所，患疾，使人请勿哗。俞曰：“尔患疾，吾亦患酒狂，各无害也。”哗如故。后俞迁闽，而某适抚闽，疏劾曰：“聊有晋人风度，绝无汉官威仪。”俞拍案笑曰：“言‘绝无’，可谓知己；但云‘聊有’，不无遗憾！”
注：俞华麓：见前。
注：大哗：大声喧哗。
注：大僚：大官。
注：酒狂：醉后狂放。
注：迁闽：调任福建。
注：抚闽：任福建巡抚。
注：晋人风度：魏晋名士风度。
注：汉官威仪：汉代官员的威严。
# 郑鲜之
题解：郑鲜之性通率，宋武帝宴请朝贵独不召，他自行前往，写其通脱。
原：宋郑鲜之为人通率，为武帝所押。上曾内殿宴饮，朝贵毕至，唯不召鲜之。坐定，谓群臣曰：“郑鲜之必当自来。”俄而外启：“尚书郑鲜之诣神兽门求启事。”帝大笑，引入。
注：郑鲜之：南朝宋名臣，《宋书》有传，性通率。
注：武帝：宋武帝刘裕。
注：内殿：宫内。
注：神兽门：建康宫门。
注：启事：奏事。
# 饮不择偶

注：何承裕：北宋人，曾任盩厔、咸阳令。
注：盩厔：今陕西周至。
注：咸阳：今陕西咸阳。
注：接坐：并排坐。
注：引满：满杯。
注：见罔：受欺骗。
注：杖：杖责。
原：谢长史几卿性通脱，会意便行。尝预乐游苑宴，不得醉而还。因诣道边酒垆，停车褰幔，与车前三驺对饮。观者如堵，谢处之自若。
注：谢长史几卿：谢几卿，南朝梁人，《梁书》有传，性通脱。
注：会意便行：随心所至。
注：乐游苑：建康宫苑。
注：酒垆：酒馆。
注：褰幔：揭起车帘。
注：三驺：车前三个骑从。
注：观者如堵：围观者如墙。
原：袁尹疏放好酒，尝步屟白杨郊野间，道遇一士人，便呼与酣饮。明日此人谓被知遇，诣门求通。袁曰：“昨饮酒无偶，聊相共耳，勿复为烦。”
注：袁尹：待考。

注：白杨郊野：待考。

# 刘公荣
题解：刘伶式的酒徒，刘公荣不择饮伴，三类人都与之饮，写其通达。
原：刘公荣与人饮酒，杂秽非类。人或讥之。答曰：“胜公荣者，不可不与饮；不如公荣者，亦不可不与饮；是公荣辈者，又不可不与饮。”故终日共饮而醉。
注：刘公荣：刘昶，字公荣，晋人，与阮籍等友善。
注：杂秽非类：不分贵贱。
注：胜公荣者：比自己强的人。
# 皇甫亮

注：病酒：因饮酒而病。
# 李仲元
题解：李仲元以德行被荐为县令，乡人饯行，一月多酣饮，终究不赴任。
原：李仲元居成都圭里，一乡皆化其德，以荐起家县令。乡人共饯之，因共酣饮月馀。太守使人促行，仲元云：“本不之官。”
注：李仲元：东汉成都人，字仲元，《华阳国志》载，称其不仕。
注：成都圭里：成都乡里。
注：起家：出仕。
注：酣饮：畅饮。
注：促行：催他上路。
# 陶成
题解：陶成才艺卓绝，不拘小节，因事除名，写才子放达。
原：陶成，字懋学，号云湖，宝就人也。性至巧，尝见银工制器，效之，即出其右。小时从师，见师母，图其像，次见其女，又图之，皆通真。师怒，逐去。及师母死，传神者皆弗逮，卒用其所图像焉。中式上公车，二月五日矣，语其婿朱升之曰：“闻张家某氏丁香盛开，子其同吾游乎？”升之曰：“去试仅三日，公更何往？”成不许。明旦，升之他避。笑曰：“彼欲进士急耶？”买舆迳下，醉其家五日。及揭晓，升之登第。其乡人醵钱为贺，曰：“公婿捷矣，幸为我辈作图以往。”成曰：“善。”即举笔模丁香一本，尤妙绝。家故饶，轻财好侠。尝一至京师，费白金二千。有一面交，卒推分与之。他日以挟妓事露，御史欲全之，观其诗，诡曰：“此殆非陶成作也。”成曰：“天下歌诗岂出陶成之右，而为他人作乎？”御史骂之，遂除名。
注：陶成：明代画家，字懋学，号云湖，宝应人，《明史》载，待考。
注：宝就：疑当作“宝应”。
注：出其右：超过其上。
注：传神：画像传神。
注：通真：逼真。
注：中式：中举。
注：上公车：赴京会试。
注：丁香：花名。
注：揭晓：放榜。
注：醵钱：凑钱。
注：捷：中试。
注：模：描绘。
注：面交：萍水之交。
注：推分：分出财物。
注：挟妓：与妓同游。
注：御史：监察御史。
注：除名：革职。

# 徐昌谷别墅

# 阮籍
题解：阮籍的任诞故事：自求东平、驳杀母之论、醉卧邻妇侧、哭兵家女、青白眼。
原：阮籍自言“平生曾游东平，乐其风土。”司马昭大悦，即拜籍东平相。籍乘驴到郡，坏府舍屏障，使内外相望，法令清简，旬日而还。昭引为大将军从事中郎。有司言子杀母者，籍曰：“嘻！杀父乃可，至杀母乎？”坐者怪其失言。籍曰：“禽兽知母而不知父。杀父，禽兽耳。杀母，禽兽不若！”众乃悦服。
注：阮籍：“竹林七贤”之一，《晋书》有传。
注：东平：今山东东平。
注：司马昭：晋文王。
注：东平相：东平国的相。
注：屏障：屏风。
注：从事中郎：大将军府属官。
注：子杀母者：杀母的案子。
注：禽兽：兽类，知母不知父。
注：悦服：心悦诚服。
原：邻家少妇有美色，当垆沽酒。籍尝诣饮，醉便卧其侧。兵家女有才色，未嫁而死。籍不识其父兄，径往哭之，尽哀而返。
注：当垆沽酒：在酒肆卖酒。
注：兵家女：军户之女。
注：哭之：为其痛哭。
原：籍能为青白眼，见礼俗士，以白眼对之。常言：“礼岂为我设耶？”时有母丧，嵇喜来吊。阮作白眼，喜不怿而去。喜弟康闻之，乃备酒挟琴造焉。阮大悦，遂见青眼。
注：青白眼：阮籍对喜欢的人以青眼，对讨厌的人以白眼。
注：礼俗士：拘守礼法的世俗人。
注：礼岂为我设：《晋书》载语。
注：嵇喜：嵇康之兄，官至扬州刺史。
注：不怿：不高兴。
注：喜弟康：嵇康，“竹林七贤”之一。
注：挟琴：带着琴。

# 揖妓
题解：俞华麓因旧日与某妓交好，被妓罚当众长揖数十，写文人狎妓之趣。
原：俞华麓大夫与一妓善。后有宴俞者，别召一妓侍饮。他日遇所善妓于生公石，数呼之，不应，曰：“知罪矣。”妓曰：“汝知罪，即于此长揖数十，使举山之人大笑，方赦汝。”遂如其言，见者大笑。旁客曰：“殊失观瞻。”曰：“观瞻吾不惜，但恐曩日侍饮人知之，必以此法难我耳。”
注：俞华麓大夫：见前。

注：长揖：拱手礼。
注：举山：全山的人。
注：观瞻：观感与体面。

# 滕元发
题解：滕元发早年为范仲淹的馆客，私下狎游，范设法劝他，滕醉后长揖问读何书，范只能走入内室，写少年放浪。
原：滕达道微时，为范文正馆客，常私就狎邪饮。范病之。一夕，候其出，迳坐达道书室，明烛读书，以俟其至。达道大醉，竟入，长揖，问范氏：“读何书？”曰：“《汉书》。”复问：“汉高帝何如？”范逡巡走入。
注：滕达道：滕元发，字达道，北宋人，早年为范仲淹所器重。
注：微时：贫寒微贱时。
注：范文正：范仲淹，谥文正。
注：馆客：门客。
注：狎邪：狎妓。
注：病之：担忧。
注：逡巡：退缩。
# 收司成榜
题解：张献翼在入学时遇到严禁游行榜，仍径入旧院，向姜宝请“开一面之网”，写其戏谑。
原：张幼于初入成均，姜大司成宝裁士如束湿，戒六院毋游行。张才至白门，先入旧院，见榜禁辄收之，谒姜曰：“请开一面之网。”姜笑曰：“吾故疑有此。”
注：张幼于：张献翼，字幼于。
注：成均：国子监，指入监读书。
注：姜大司成宝：姜宝，南京国子监祭酒，“司成”即祭酒。
注：裁士如束湿：管束学生甚严，“束湿”喻严厉。
注：六院：南京六科。
注：白门：南京。
注：旧院：南京妓院区，南京秦淮旧院。
注：开一面之网：《史记·殷本纪》载商汤“网开三面”，请从宽。
# 僧壁画《西厢》
题解：丘濬见寺中四壁画《西厢》，僧说从此悟禅，引“怎当他临去秋波那一转”，是以艳曲入佛门的趣谈。
原：丘琼山过一寺，见四壁俱画《西厢》，曰：“空门安得有此？”僧曰：“老僧从此悟禅。”丘问：“何处悟？”答曰：“是‘怎当他临去秋波那一转’。”
注：丘琼山：丘濬，号琼山，明代名臣，著《大学衍义补》。
注：《西厢》：王实甫《西厢记》。
注：空门：佛门。
注：悟禅：悟到禅理。
注：怎当他临去秋波那一转：《西厢记》第一本第一折张生语，写初见莺莺。
# 汤义仍讲学
题解：汤显祖称自己讲的是“情”，与理学家所讲的“性”不同，是情与理之争的名言。
原：张洪阳相公见《玉茗堂四记》，谓汤义仍曰：“君有如此妙才，何不讲学？”汤曰：“此正吾讲学。公所讲是性，吾所讲是情。”
注：张洪阳相公：张位，号洪阳，明万历朝宰相。
注：《玉茗堂四记》：汤显祖“临川四梦”（《紫钗记》《牡丹亭》《南柯记》《邯郸记》），因居玉茗堂，称“玉茗堂四梦”，此作“四记”，待考。
注：汤义仍：汤显祖，字义仍，号若士。
注：讲学：讲授理学。
注：性：理学所讲的人性、天理。
注：情：汤显祖主张“情”。
# 谢尚
题解：谢尚参加桓子野宴时，刚参加完葬礼三日仍着丧服，被诸人拉去，酣宴半途才发觉未脱孝衣。
原：玉、刘共在杭南，酣宴于桓子野学。谢镇西尚往尚书墓还，葬后三日，反哭。诸人欲要之，初遣一信，犹未许，然已停车；重要，便回驾。诸人入门迎之，把臂使下，裁得脱帻，著幅酣宴，半坐，乃觉未脱衰。

注：桓子野：桓伊，字叔夏，小字子野，东晋将领，善吹笛。
注：谢镇西尚：谢尚，字仁祖，官镇西将军。
注：反哭：葬后返家哭奠。
注：要：邀请。
注：脱帻：去掉头巾。
注：著幅：戴头巾。
注：衰：丧服。
# 王子猷
题解：王子猷雪夜访戴逵，乘兴而来、兴尽而返；又请桓伊吹笛，两人客主不交一言，是《世说新语》名篇。
原：王也猷居山阴。夜大雪，眠觉，开室，命酌酒。四望皎然，因起傍皇，泳左思《招隐诗》。忽忆戴安道。时戴在剡，即便夜乘小船就之。经宿方至，造门不前而返。人问其故。王曰：“吾本乘兴而来，兴尽而返，何必见戴？”
注：王也猷：王徽之，字子猷，王羲之之子，“也”当作“子”，疑误。
注：山阴：今浙江绍兴。
注：皎然：洁白明亮。
注：傍皇：徘徊。
注：左思《招隐诗》：西晋左思作。
注：戴安道：戴逵，字安道，东晋隐士。
注：剡：今浙江嵊州。
注：乘兴而来，兴尽而返：《世说新语·任诞》。
原：王子猷出都，尚在渚下。旧闻桓子野善吹笛，而不相识。遇桓于岸上过，王在船中，客有识之者，云是桓子野。王便令人与相闻云：“闻君善吹笛，试为我一奏。”桓时已贵显，素闻王名，即便下车，踞胡床为作三调。弄毕，便上车去，客主不交一言。
注：出都：离开京城建康。
注：渚下：秦淮河边。
注：桓子野：见前。
注：相闻：通报。
注：胡床：交椅。
注：三调：三曲。
注：客主不交一言：王子猷与桓子野始终不说话。
# 张季鹰

# 争猫
