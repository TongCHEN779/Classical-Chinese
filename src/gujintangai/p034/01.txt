# 正文
题解：《妖异》部总评：冯梦龙论屈轶、獬豸等瑞兽实为虚名，说治世妖祥皆虚，末世则妖多实，并点明本部为全书第三十四部。
原：〔子犹曰：妖祥无定名也；如有定，则人力无如何矣。屈轶指佞，獬豸触奸，物之上瑞也。然以指佞触奸之事，而徒责之一草一兽，安用人为？且圣世无奸佞，又何以章屈轶，獬豸之奇乎？圣世既不必有，而未世又不见有，则屈轶、獬豸亦虚名耳。虽然，圣世德胜，妖祥皆虚，末世祥多虚而妖多实，鬼以之灵，物以之怪，人以之疵厉，此其故可思也。集《妖异》第三十四。〕
注：子犹曰：冯梦龙自称，下为评语。
注：妖祥：不祥之兆与吉祥之兆。
注：屈轶指佞：屈轶，传说尧时生于庭的草，遇佞人则指之，见《论衡·是应》。
注：獬豸触奸：獬豸是传说中的神兽，见人争斗则触不直者，见《论衡》。
注：上瑞：最高的祥瑞。
注：章：彰显。
注：末世：衰亡之世。
注：疵厉：灾病，疫害。
注：集《妖异》第三十四：《妖异》为全书第三十四部，所收为各类怪异之事。

# 肉异
题解：前赵嘉平四年陨肉发哭，刘后生蛇虎，皇后死后肉失，是十六国时期的怪异传说。
原：前赵嘉平四年，有流星坠于平阳北十里。视之，则有肉长三十步，广二十七步，臭闻于平阳，肉旁常有哭声，昼夜不止。已而刘后产一蛇一虎，各害人而走，寻之不得，顷之乃在陨肉之旁。后卒，乃失此肉。哭声亦止。
注：前赵：十六国之一，匈奴刘氏所建，都平阳。
注：嘉平四年：前赵刘曜年号，当为嘉平四年（314）前后，待考。
注：平阳：今山西临汾。
注：刘后：疑指刘曜之后，待考。
注：陨肉：天上落下的肉块。

# 天画
题解：记宋滕涉时青州霜成花状、金末河冰成龟纹花鸟，皆称“天画”。
原：滕涉，天圣中为青州太守。盛冬浓霜，屋瓦皆成百花之状，以纸摹之。又《大金国志》：金末，河冰冻成龟文，又有花卉禽鸟之状，巧过绘缕。此天画也。
注：滕涉：滕宗谅，字子京，宋仁宗朝官员，曾知岳州等；此处作“滕涉”待考。
注：天圣：宋仁宗年号（1023—1032）。
注：青州：今山东青州。
注：《大金国志》：旧题宇文懋昭撰，记金朝史事。
注：龟文：龟裂之纹。
注：绘缕：彩绘与刺绣。
# 弘治二异
题解：弘治年间浙江、陕西奏报天象奇异，作者借以说明盛世也有怪变。
原：弘治最为盛世，而己酉、庚戌间一时奇变。如浙江奏景云县屏风山有异物成群，其状如马，大如羊，其色白，数以万计，首尾相衔。从西南石牛山凌空而去，自午至申乃灭。居民老幼男女，无弗见者。又陕西庆阳府雨石无数，大者如鹅卵，小者如鸡头实。说长道短，刺刺不休。皆见之奏章，良可怪也。
注：弘治：明孝宗年号（1488—1505）。
注：己酉、庚戌：弘治二年（1489）、三年（1490）。
注：景云县：疑为“景宁县”之误，浙江处州府属县；待考。
注：屏风山：待考。
注：石牛山：待考。
注：午至申：十一时至十七时。
注：庆阳府：今甘肃庆阳。
注：鸡头实：芡实。
注：刺刺不休：说个没完。
注：奏章：向朝廷的奏报。

# 石臼斗
题解：武清县石臼与碌碡相斗于麦地，乡人用木隔之都被损折，沉入污池、深坎后仍复相斗，三日乃止。
原：武清县民家石臼，与邻家碌碡，皆自滚至麦地上，跳跃相斗。乡人聚观，以木隔之，木皆损折，斗不可解。至晚方息。乡人怪之，以臼沉污池中，以碡坠深坎，相去各百馀步。其夜碡与臼复斗于池边地上，麦苗皆环。秀才李廷瑞闻之，亟往观焉。斗犹不辍，乍前乍却，或磕或触，硁然有声，火星炸落。三日乃止。
注：武清县：今天津武清。
注：石臼：舂米用的石器。
注：碌碡：碾场用的石滚。
注：秀才李廷瑞：生员李廷瑞，待考。
注：硁然：金石撞击声。
注：炸落：迸落。
# 铛异
题解：引《广记》，唐郑𬘡家中铛釜能行走，折足者亦被同伴负过水渠，最后化为灰烬，是器物成妖之异。
原：《广记》：唐宰相郑𬘡与弟少卿缊同居昭国里。一日厨馔将备，其釜忽如物于灶中筑之，离灶尽馀，连筑不已。旁有铛十馀所，并烹庖将熟，皆两耳慢摇，良久悉腾上灶，每三铛负一釜而行，其馀列行引从，自厨中出地。有足折久废者，亦跳踯而随之。出厨东过水渠，诸铛并行无碍，而折足者不能过。举家惊异聚观，有小儿咒之曰：“既能为怪，折足者何不能前？”诸铛乃弃釜庭中，却返，每两铛负一折足者以过，往入少卿院堂前排列。乃闻空中轰然如崩屋声，悉为埃烬矣。
注：《广记》：《太平广记》，此条出《酉阳杂俎》。
注：郑𬘡：唐宰相，《旧唐书》作“郑絪”。
注：缊：郑缊，郑絪之弟。
注：昭国里：长安坊名。
注：筑：撞，捣。
注：铛：三足的温器。
注：跳踯：跳跃。
注：埃烬：灰烬。

# 犬猫异

# 蝇异

# 黄鼠怪
题解：无锡龙庭华家柱中矮人为黄鼠所变，被毙后同类求命、举哀、送葬、续偶，屋内平静，是笔记中鼠妖拟人之异。
原：无锡县龙庭华家，氏族甲于江左。有宗人某，堂大柱内急穿二穴，常见走出两矮人，可二三寸许。主人怪之，择日延道士诵经为厌胜之法。两矮人复出听经。逐之，则又无迹。命寨其穴。而旁更穿一穴，出入如故。主人治药弩，令奴张以伺之。既出，毙其一，一疾走去。视之，乃雌黄鼠也！少顷，忽有矮人百馀辈出与主人索命。仆从哗噪而走。又少顷，复有七、八人以白练蒙首，出堂中恸哭。仍复逐去。久之，闻柱中发铃钹声。众谓送葬。又久之，闻柱中起箫鼓声。众谓鼠中续偶。闭其堂经月，怪便寂然。
注：无锡：今江苏无锡。
注：龙庭华家：无锡望族，待考。
注：氏族甲于江左：家族在江南数第一。
注：厌胜：用符咒制服妖邪的方术。
注：药弩：涂药的弩箭。
注：黄鼠：黄鼠狼。
注：白练：白色的熟绢，举丧所用。
注：铃钹：铃与铙钹，丧礼乐器。
注：箫鼓：喜事所用乐器。
注：续偶：续弦，再婚。

# 玉贞娘子
题解：程迥迁居临安，家中飞来五六寸高的“玉贞娘子”，能预言祸福，人入观交钱，程家小康，一年后飞去。
原：程迥者，伊川之后。绍兴八年，来居临安之洋街。门临通衢，垂帘为蔽。一旦有物如燕，瞥然自外飞入，径著于堂壁。家人近视，乃一美妇，仅长五、六寸，而形体皆具，容服甚丽。见人殊不惊，小声历历可辨。自言：“我是玉贞娘子，偶然至此，非为灾祸。苟能事我，亦甚善。”其家乃就壁为小龛，香水奉之。能预言休咎，皆验。好事者争往求观，人输百钱，方为启龛。至得络绎，程氏为小康。如是期年，忽复飞去，不知所在。
注：程迥：南宋理学家，字可久，应有生平，此处沿用故事人名。
注：伊川：程颐，号伊川先生。
注：绍兴八年：1138年。
注：临安：今杭州。
注：洋街：杭州街名，待考。
注：通衢：大道。
注：龛：供奉神像的小阁。
注：休咎：吉凶。
注：络绎：往来不绝。
注：期年：满一年。

# 镟中佛象
题解：万历癸未常熟丘郡家锡镟中的鸡肉蒸汽凝为佛殿，一家罗拜，三日不灭，最后浮草船于河，见于《戒庵漫笔》。
原：常熟丘郡家食橱内，锡镟置熟鸡半只，忘之矣。偶婢检器皿，见橱边光焰。发视之，乃镟中鸡蒸气结成一小殿宇，中坐佛一尊，如世间大士像，眉目分明。婢奔告郡。郡移于堂上，率家人罗拜之。三日犹不灭，召巫者束一草船，浮之于城河。时万历癸未正月初六日。见《戒庵漫笔》。
注：常熟：今江苏常熟。
注：丘郡：疑为丘姓之人，待考。
注：锡镟：锡制温酒器。
注：大士：菩萨，此处指观音。
注：罗拜：环绕礼拜。
注：草船：纸或草扎成的小船，用以送神。
注：万历癸未：万历十一年（1583）。
注：《戒庵漫笔》：明李诩撰笔记。

# 鳖异
题解：记万历年间鳖腹中有老人、比丘，王户部之鳖腹有鬼判，诸事见于邸报，皆是怪异之谈。
原：万历己卯，严州建德县有渔者获一鳖，重八斤。一酒家买之悬室中，夜半常作人声。明日割烹之，腹有老人长六寸许，五官皆具，首戴皮帽。大异之，以闻于具与郡。郡守杨公廷诰时入觐，命以木匣盛之，携至京师，诸贵人传观焉。又丁未年，遂昌县民宋甲剖一鳖，中有比丘端坐，握摩尼珠，衫履斩然。俱见邸报。
注：万历己卯：万历七年（1579）。
注：严州建德县：今浙江建德。
注：割烹：宰杀烹煮。
注：杨公廷诰：杨廷诰，严州知府，待考。
注：入觐：入京朝见。
注：丁未：万历三十五年（1607）。
注：遂昌县：今浙江遂昌。
注：比丘：佛教出家男子。
注：摩尼珠：如意宝珠。
注：邸报：明代官府抄发的消息通报。
原：颍川王户部在通州时，一日宴客，庖人烹鳖。剖之，有鬼、判各一。朱发蓝面，皂帽绿袍；左执簿，右执笔，种种皆具，刻画所不能及。王自是遂断兹味。

# 狐假子路

原：东昌宣圣殿，设空体木像。正德中，子路忽人语云：“我仲由也！夫子命我主此土祸福。”人争祭奠，必令祭者暂出闭门。顷之，入视，肴核都无馀者。一御史经其地曰：“此必妖也！”多设烧酒劝之，俄而无声，乃一狐寐于侧。御史笑曰：“以汝希仲由，乃学宰予耶？”
注：东昌：东昌府，今山东聊城。

注：空体木像：中空的木像。
注：子路：仲由，孔子弟子。
注：肴核：肉食与果品。
注：希：仰慕，效法。
注：宰予：孔子弟子，曾昼寝，被孔子斥“朽木不可雕也”，见《论语·公冶长》。
# 鬼畏面具
题解：金陵卖面具的人借宿大姓庄居，戴面具吓走来与主人之女往来的黑鱼精，原来鬼怪畏恶相。
原：金陵有人担面具出售，即俗所谓“鬼脸子”者。行至石灰山下，遇雨沾涩，乃借宿大姓庄居。庄丁不纳，权顿檐下，愁不能寐。而面具经雨将坏，乃拾薪爇火熯之。首戴一枚，两手及两膝各冒其一，以近燎。至三更许，有一黑大汉，穿一黑单衣，且前且却。其人念必异物，惧其面具而然，乃大声叱之。黑汉前跪曰： “我黑鱼精也！”家何在？”曰：“在此里许水塘中。与主人之女有交，故每夕来往。不意有犯尊神，望恕其责。”其人叱之使去。明旦，访主人之女，果病祟。遂告之故。竭塘渔之，得乌鱼，重百馀斤。乃腌而担归。
注：金陵：今南京。
注：鬼脸子：面具，俗称。
注：石灰山：南京郊外地名，待考。
注：沾涩：雨水沾湿而不便。
注：权顿：暂时放置。
注：爇：点燃。
注：熯：烘干。
注：三更：夜里十一时至一时。
注：尊神：对神灵的敬称。
注：竭塘渔之：把塘水抽干捕鱼。
# 鬼张
题解：弘治中高邮张指挥救起漂浮的女子并娶之，婢女窥见其取头绾发，原来是败船板成精，其子后袭职，被称“鬼张指挥”。
原：弘治中，高邮张指挥无嗣，求妾未得。偶出湖上，见败船板载一女甚丽，波浮而来。问之，曰：“妾，某邑人。舟覆，一家皆没。妾赖板得存，幸救我。” 张援得之，甚宠爱。逾年生子。女栉沐，必掩户。一日婢从隙窥之，见女取头置膝上绾结，加簪珥，始加于颈。大惊，密以启张。张未信。他日张觇之，果然。知为妖，排户入斩之，乃一败船板耳。子已数岁，无他异，后袭职。至今称“鬼张指挥”云。
注：弘治：明孝宗年号。
注：指挥：卫所武官。
注：败船板：破船板。
注：栉沐：梳洗。
注：绾结：盘发结髻。
注：簪珥：簪子与耳环。
注：觇：窥视。
# 无鬼论
题解：阮瞻坚持无鬼论，被来客自称是鬼并变形，是魏晋志怪中的著名故事。
原：阮瞻素执无鬼论。忽有客通名，诣瞻寒温结，聊谈名理。良久，及鬼神事，反复甚苦。客遂屈，作色曰：“鬼神，古圣所传，君何得独言无？既仆便是鬼！”于是变为异形，须臾消灭。
注：阮瞻：西晋人，字千里，阮咸之子，持无鬼论，事见《搜神记》。
注：名理：名理之学，辨析事理。
注：作色：变脸。
注：异形：怪异的形状。

# 饮不饮
题解：记元载闻酒气即醉、被挑去酒魔后日饮一斗，镇阳士人呕出酒虫后恶酒，二事相对。
原：元载不饮，其鼻闻气已醉。人以针挑其鼻尖，出一小虫，曰：“此酒魔也！”由是日饮一斗。
注：元载：唐代宗朝宰相，后被诛。
