# 正文
题解：《矜嫚》部卷首小引：子犹以谦者自恭、矜者自嫚立论，指斥骄傲狂妄，收集本部各则。
原：〔子犹曰：谦者不期恭，恭矣；矜者不期，嫚矣。达士旷观，才流雅负，虽占高源，亦违中路。彼不检兮，扬衡学步；自视若升，视人若堕，狎侮诋諆，日益骄固。臣虐其君，子弄其父，如痴如狂，可笑可怒。君子谦谦，慎防阶祸！集《矜嫚》第十二。〕
注：子犹曰：冯梦龙评语。
注：谦者不期恭，恭矣：谦虚的人不求恭敬，自然恭敬。
注：矜者不期，嫚矣：骄矜的人不求傲慢，自然傲慢。
注：达士旷观：通达之人眼光开阔。
注：才流雅负：才士高自期许。
注：占高源：占据高处根基。
注：违中路：背离中道。
注：不检：不检点。
注：扬衡学步：待考，疑指故作姿态而学步，《庄子·秋水》“邯郸学步”。
注：狎侮诋諆：轻慢侮辱毁谤。
注：谦谦：《周易·谦卦》“谦谦君子”。
注：阶祸：招致祸患。
注：集《矜嫚》第十二：本书第十二部。
# 负图先生
题解：季充号“负图先生”，常食菊、术，旬日不语，说世间无可食无可语，是狂傲的人物。
原：季充号“负图先生”，常饵菊术，经旬不语，人问何以，曰：“世间无可食，亦无可语者。”
注：季充：待考，号“负图先生”。
注：负图先生：背负图的隐士，待考。
注：饵：服食。
注：菊术：菊花与白术，道家服食。
注：经旬：十天。
# 韩山石
题解：庾信自南入北，只看重温子升《韩山碑》，其余皆讥为驴鸣犬吠，写其傲视北方文士。
原：庾信自南朝至北方，唯爱温子升作《韩山碑》。或问：“北方何如？”信曰：“唯韩山一片石堪与语，馀若驴鸣犬吠耳。”
注：庾信：南北朝文学家，初仕梁，后留北周。
注：温子升：北魏诗人，擅碑志，《魏书》有传。
注：《韩山碑》：温子升所作《韩陵山寺碑》。
注：堪与语：可以交谈。
注：驴鸣犬吠：贬低诸人文章。
# 福先寺碑文
题解：裴度修福先寺，皇甫湜索高价撰碑文，裴度如数付给，写文人自负。
原：裴度修福先寺，将求碑文于白居易。判官皇甫湜怒曰：“近舍湜而远取居易，请从此辞！”度亟谢，随以文属湜。湜饮酒挥毫立就，度酬以车马玩器约千缗。湜怒曰：“碑三千字，每字不值绢三匹乎？”度又依数酬之。湜又索文改窜。度笑曰：“文已妙绝，增一字不得矣。”
注：裴度：唐代宰相，封晋国公。
注：福先寺：洛阳寺院，裴度重修。
注：白居易：唐代诗人。
注：判官：节度使属官。
注：皇甫湜：唐代文学家，韩愈弟子。
注：亟谢：连忙道歉。
注：属：嘱托。
注：立就：立刻写成。
注：千缗：一千贯钱。
注：改窜：改动。
# 首冠
题解：卢肇谢启自称“首冠蓬山”，被试官质问，他以顽石在上巨鳌戴之相对，一座大笑。
原：开成初，卢肇就江西解试，为试官末送。肇有谢启云：“巨鳌赑，首冠蓬山。”试官谓之曰：“昨恨人数挤排，深惭名第奉浼，何云首冠？”肇曰：“顽石处上，巨鳌戴之，岂非首冠？”一坐大笑。
注：开成：唐文宗年号。
注：卢肇：唐代状元，江西宜春人。
注：解试：州府举荐科举考生的考试。
注：末送：末名。
注：谢启：谢启，答谢文书。
注：首冠蓬山：巨鳌背负蓬莱仙山，首冠即居首位；“赑屭”原作“赑”，形容用力。
注：蓬山：蓬莱仙山。
注：挤排：挤占名额。
注：奉浼：请托。
注：首冠：第一名。
# 殷、桓相侮
题解：殷浩与桓温互相较量，殷浩说宁作我，又被桓温以诗威胁，是《世说新语·品藻》名篇。
原：殷深源少与桓温齐名，常有竞心。桓问殷：“卿何如我？”殷云：“我与我周旋久，宁作我。”殷尝作诗示桓，桓玩侮之，曰：“汝慎勿犯我；犯我，当出汝诗示人也！”
注：殷深源：殷浩，字深源，东晋名士，与桓温齐名。
注：桓温：东晋权臣。
注：竞心：竞争之心。
注：我与我周旋久，宁作我：《世说新语》载殷浩答语。
注：玩侮：戏弄。
# 李邕
题解：李邕轻视萧诚的字，萧诚伪作古帖骗他称善，揭穿后他又改口，写文人傲气。
原：李邕尝不许萧诚书，诚乃诈作古帖，令纸故暗，持示邕，曰：“此乃右军真迹，如何？”邕看称善。诚以实告之。邕复取视曰：“细看亦未能全好。”
注：李邕：唐代书法家，擅行书。
注：萧诚：待考。
注：古帖：古代名家字帖。
注：纸故暗：纸故意做旧。
注：右军：王羲之。
注：真迹：亲笔真品。
# 三灾石
题解：萧颖士以“三灾石”讥歙砚主人的字、文、几案，写其刻薄。
原：萧颖士尝至李韶家，见歙砚颇良，语同行者曰：“君识此砚乎？盖三灾石也。”同行者不喻，退而问之。曰：“字札不奇，一灾也；文辞不忧，二灾也；窗几狼籍，三灾也。”
注：萧颖士：唐代文学家，才华自负。
注：李韶：待考。
注：歙砚：安徽歙县所产砚，著名。
注：三灾石：萧颖士自造戏语，意在讥主人字不奇、文不忧、窗几凌乱。
注：字札：书法。
注：狼籍：杂乱。
# 藏拙
题解：徐陵出使北齐，将魏收的文集沉于江中，说“藏拙”，写其轻视魏收。
原：梁徐陵使于齐。收魏收有文学，北朝之秀，录其文集以遗陵，命传之江左。陵还，济江而沉之。从者问故，曰：“吾与魏公藏掘。”
注：徐陵：南朝陈文学家，《玉台新咏》编者。
注：使于齐：出使北齐。
注：魏收：北齐文学家，著《魏书》，《北齐书》有传。
注：遗：赠送。
注：江左：江南。
注：济江：渡江。
注：藏掘：疑当作“藏拙”，意为把拙作藏起来，此处讥魏收文拙。
# 崔丞相聪明
题解：韩愈说崔丞相聪明，因同朝二十余年从不论文章，是对不识文章者的幽默讥讽。
原：韩愈常语李程曰：“愈与崔丞相同年往还，直是聪明过人！”李曰：“何处过人？”韩曰：“共愈往还二十馀年，不曾说著文章。”
注：韩愈：唐代文学家。
注：李程：唐代宗室，官至宰相，善文。
注：崔丞相：崔群，唐宪宗朝宰相。
注：同年：同榜进士。
注：往还：往来。
注：说著文章：谈论文章。
# 郑元礼诗
题解：崔昂与魏收之弟比较，卢思道讥其对妹夫魏收不公，写文坛互相轻视。
原：郑元礼，崔昂妇弟；魏收，昂之妹夫。昂持元礼数诗示卢思道，曰：“元礼比来诗咏亦不减魏收。”思道曰：“未觉元礼贤于魏收，且知妹丈疏于妇弟。”
注：郑元礼：郑元礼，崔昂之妻弟，待考。
注：崔昂：北齐人，《北齐书》有传。
注：魏收：北齐文人，崔昂之妹夫。
注：卢思道：北朝文人，《北史》有传。
注：比来：近来。
注：妹丈：妹夫。
# 选五凤楼手
题解：韩洎讥其兄韩浦的文章，称自己为“选五凤楼手”，韩浦以蜀笺诗戏之，写兄弟互讥。
原：韩浦、韩洎兄弟皆有文辞。洎尝轻浦，语人曰：“吾兄为文，譬如绳枢草舍，聊蔽风雨。予之为文，是选五凤楼手。”浦闻而笑之。适有人遗蜀笺，浦作诗与洎曰：“十样蛮笺出益州，寄来人自浣溪头。愚兄得此全无用，助尔添修五凤楼。”
注：韩浦、韩洎：五代宋初人，韩浦、韩洎兄弟，均擅文。
注：绳枢草舍：以草绳作门枢的草舍，喻简陋。
注：选五凤楼手：唐代韩浑称“五凤楼手”，喻文才高绝，五凤楼为唐代宫楼。
注：蜀笺：四川所产彩笺。
注：益州：今四川成都。
注：浣溪：成都浣花溪，造纸处。
注：蛮笺：蜀纸别称。
注：修五凤楼：用纸修五凤楼，讥洎自负。
# 郤方回奴
题解：郤超家奴有意向文章，王羲之赞，刘惔回以“不如方回，故是常奴”，是《世说新语》谐谑。
原：郤方回家有伧奴，知及文章，事事有意。王右军向刘尹称之。刘问：“何如方回？”王曰：“此正小人有意向耳，何得比方回？”刘曰：“若不如方回，故是常奴。”
注：郤方回：郤愔，字方回，东晋人，郤超之父。
注：伧奴：粗鄙的奴仆，伧为晋人对北方人蔑称。
注：王右军：王羲之。
注：刘尹：刘惔，曾为丹阳尹。
注：意向：志趣。
# 韩叔言
题解：韩叔言性好戏谑，以艾薰烧投贽者、以纸塞鼻、称耳聋，讥人文章，写其刻薄。
原：韩叔言性好谑浪。有投贽太荒恶者，使妓炷艾薰之。俟其人来，出而嗅之，曰：“之子卷轴何多艾气？”宋齐丘凡建碑碣，皆自为文，命韩八分书之。乃以纸塞鼻曰：“其词秽且臭！”又魏明尝携近诗诣之。韩托以目病。明请自吟。韩曰：“耳聋加剧。”
注：韩叔言：待考。
注：谑浪：戏谑。
注：投贽：呈送作品求见。
注：炷艾：点燃艾草。
注：卷轴：书卷。
注：宋齐丘：南唐宰相，好文。
注：碑碣：石碑。
注：韩八分书：用八分书（隶书）书写。
注：魏明：待考。
注：托以目病：假称眼病。
注：耳聋加剧：假称耳聋。
# 夔州诸咏
题解：蔡子木唱夔州诗，吴国伦酣睡如鼾声相和，是以睡讥文的趣事。
原：蔡子木酒后自歌其夔州诸咏。甫发歌，吴国伦辄鼾寝，鼾声与歌相低昂；歌竟，鼾亦止。
注：蔡子木：蔡汝楠，字子木，明代文人。
注：夔州诸咏：杜甫在夔州所作诗。
注：吴国伦：字明卿，明代后七子之一。
注：鼾寝：打呼噜睡觉。
注：低昂：高低。
# 三分诗
题解：郭祥正问东坡其诗几分，东坡说七分读、三分诗，讥其诗平庸，是文人谐谑。
原：郭祥正尝出诗一轴示东坡，先自吟诵，曰：“此诗几分？”坡曰：“十分。”祥正惊喜，问之。坡曰：“七分来是读，三分来是诗。”
注：郭祥正：北宋诗人，字功父，与苏轼同时。
注：东坡：苏轼。
注：七分来是读，三分来是诗：苏轼戏言，意谓读出来的成分多，诗味少。
# 《六合赋》
题解：刘孔昭写《六合赋》自矜，魏收讥其大愚，邢邵比之为“疥骆驼”，写自负者被讥。
原：刘孔昭缉缀一赋，以《六合》为名，自谓绝份。曾以吴魏收而不拜，收忿谓曰：“赋名《六合》，巴是大愚；文又愚于《六合》，君四体又愚于文。”刘不胜忿，以示邢子才。子才曰：“君此赋，正似疥骆驼，伏而无妩媚。”
注：刘孔昭：北齐人，待考。
注：缉缀：拼凑。
注：六合：天地四方。
注：绝份：无与伦比。
注：魏收：北齐文人。
注：邢子才：邢邵，字子才。
注：疥骆驼：有癣疥的骆驼，比喻伏而无光泽，《北齐书》载。
注：妩媚：美好。
# 文胖
题解：文氏后人“文胖”文书俱拙，俞华麓劝他勿参加岁试，是对不成才者的讥讽。
原：茂苑文氏皆聪颖，龙工书，独一人号文胖者，亦诸生，文与书并掘。遇岁试，俞华麓力劝勿往。惊问何故。乃曰：“如子之文，虽有衡山之书亦无用；即王守溪文，而子书之，人亦懒看矣！恐黜不尽辜，是以忧之。”
注：茂苑：苏州古称。
注：文氏：苏州文徵明家族。
注：龙：待考。
注：文胖：待考。
注：诸生：秀才。
注：岁试：学政主持的考试。
注：俞华麓：见前。
注：衡山之书：文徵明号衡山，擅书法。
注：王守溪文：王鏊，号守溪，明代八股名家。
注：黜：革除。
# 贾岛

注：贾岛：唐代诗人，曾为僧，称无本。

注：攘臂：捋袖伸臂。

注：长江簿：长江县主簿，在今四川蓬溪。
# 柳三变
题解：柳永自称“奉圣旨填词柳三变”，是因被仁宗讥为“且去填词”，写文人自嘲。
原：柳耆卿为屯田员外郎，初名三变。自作词云：“才子词人，自是白衣卿相。”后有荐于朝者，仁宗曰：“此人风前月下且去填词！”由是不得志，无复检率，自称：“奉圣旨填词柳三变。”
注：柳耆卿：柳永，字耆卿，北宋词人。
注：屯田员外郎：工部屯田司属官。
注：三变：柳永初名三变。
注：白衣卿相：布衣却如卿相，出自柳永《鹤冲天》词“才子词人，自是白衣卿相”。
注：仁宗：宋仁宗。
注：风前月下：指儿女情长。
注：检率：检点约束。
注：奉圣旨填词：自嘲。
# 罗隐

# 杜审言
题解：杜审言临终自夸压倒群才，判词让苏味道羞死，写其狂傲。
原：杜审言将死，语宋之问、武平一曰：“吾在，久压公等。今且死，固大慰，但恨不见替人。”登封中，苏味道为天官侍郎，审言预选试。判讫，谓人曰：“味道必死矣！”人问其故，曰：“见吾判自当羞死！”
注：杜审言：初唐诗人，杜甫祖父，狂傲，《旧唐书》有传。
注：宋之问、武平一：二人皆初唐文士。
注：替人：接班人。
注：登封：武则天登封中岳嵩山年号。
注：苏味道：唐代宰相，诗人，号“苏模棱”。
注：天官侍郎：吏部侍郎。
注：预选试：参加选试。
注：判：判词。

原：石曼卿一日谓僧秘演曰：“馆俸清薄，恨不得痛饮。”演曰：“非久当引一酒主人奉谒。”不数日，引一纳粟牛监簿来，以宫醪十担为贽。演为传刺，曼卿愕然延之，乃问：“甲第何许？”牛曰：“一别舍介繁台之侧。”曼卿语演曰：“繁台寺阁虚爽可爱，久不一登。”牛曰：“学士倘有兴，当具酒肴从游。”曼卿因许之。一日休沐，约演同登。演预戒生大陈饮具。石、演高歌褫带，饮至落景。曼卿醉喜曰：“此游可纪！”乃以盆渍墨，濡巨笔，题云：“石延年曼卿同空门诗友老演登此。”生拜叩曰：“尘贱之人，幸获陪侍，乞挂一名，以免贱迹。”曼卿大醉，握笔沉虑，目演曰：“大武生，捧砚用事可也！”竟题云：“牛某捧砚。”永叔诗曰：“捧砚得全牛。”

题解：郭忠恕善画而性傲，只自己想画才画，对富人所求，画孩童放风筝线长数丈，使富人不快，写艺术家傲骨。
原：郭恕先忠恕善画。有求者，必怒而云，竟欲画即自为之。时与役夫小民入市肆饮，曰：“吾所与游，皆子类也！”寓岐下时，有富人子喜画，日给醇酒，待以甚厚。久乃以情言，且致匹素。郭为画小童持线车放风鸢，引线数丈满之。富人子大怒，与郭遂绝。

注：役夫：劳役。
注：市肆：市场店铺。
注：岐下：岐州，今陕西凤翔。
注：匹素：一匹白绢。
注：风鸢：风筝。
注：线车：线轴。
# 残客
题解：张缵、罗含对不愿交往的人，拒见何敬容的“残客”，或不愿多交往，写傲骨。
原：吏部张缵与何敬容意趣不协。敬容居权轴，宾客辐辏。有诣缵者，辄拒不前，曰：“吾不能对何敬容残客。”
注：吏部张缵：张缵，南朝梁人，字伯绪，《梁书》有传。
注：何敬容：梁武帝时重臣。
注：权轴：权力中枢。
注：辐辏：车辐汇集，喻宾客众多。
注：残客：被他人拣剩的客人。
原：罗君章含曾在人家，主人令与座上客共语。答曰：“相识已多，不烦复尔。”
注：罗君章含：罗含，字君章，东晋文人，《晋书》有传。
注：共语：交谈。
注：不烦复尔：不必麻烦再相识。
# 蔡公客
题解：蔡谟被王濛、刘惔轻视，以“夷甫无君辈客”回敬，是《世说新语》名篇。
原：王、刘每不重蔡公。二人尝诣蔡，语良久，乃问蔡曰：“公自言何如夷甫。”答曰：“身不如夷甫。”王、刘相目而笑，曰：“公何不如？”答曰：“夷甫无君辈客。”
注：王、刘：王濛、刘惔。
注：蔡公：蔡谟，字道明，东晋重臣。
注：夷甫：王衍，字夷甫，西晋名士。
注：无君辈客：没有你们这样的客人，反讽两人不如王衍的宾客。
# 张景胤
题解：张敷性不耐杂，宋文帝令载沙门同行而不肯，对狄当、周赳等人设床远客，写其孤傲。
原：宋张敷，迁江夏王义恭记室参军。义恭就文帝求一学义沙门，会敷赴假，还江陵，入辞。帝令以后车载沙门往，谓曰：“道中可得言晤。”敷不奉诏，曰： “臣性不耐杂。”中书舍人狄当、周赳并管要务，以敷同省名家，欲诣之。赳曰：“彼若不相容接，不如勿往。”当曰：“吾等并已员外郎矣，何忧不得共坐？”敷先旁设二床，去壁三、四尺；二客就席，便呼左右曰：“移我床远客！”赳等失色而去。

注：中书舍人：中书省属官。

# 坏面

# 喏样

# 幼戏郡侯
原：孙周翰自幼精敏。其父穆之携见郡侯。时值春宴，侯与座客簪花。侯因命曰：“口吹杨柳成新曲。”翰曰：“头带花枝学后生。”侯笑曰：“何遽便戏老夫？”
# 侮老
原：杨大年弱冠，与周翰、朱昂同在禁掖，二老已皤然矣。杨每论事，则侮之曰：“二老翁以为何如？”翰不能堪，正色曰：“君莫欺老，老亦终留与君！”昂曰：“莫留与他，免得后人又欺他！”
# 姚彪
原：姚彪与张温俱至武昌，遇吴兴沈珩守风粮尽，遣人从彪贷盐一百斛。彪性峻直，得书不答；方与温谈论久，呼左右倒百斛盐著江中，谓温曰：“明吾不惜，惜所与耳！”
# 谢方眼

# 恃枯骨
原：梁朱异轻傲朝贤，不避贵戚。人或诲之。异曰：“我以寒士遭遇，诸贵皆恃枯骨见轻。我若下之，为蔑尤甚，我是以先之。”
# 嵇康
原：嵇康性好锻。初居贫，常与向秀共锻于大树之下，以自给。颖川锺会往造焉。康不为之礼，而锻不辍，良久，会去，康谓曰：“何所闻而来？何所见而去？”会曰：“闻所闻而来，见所见而去。”
# 祢正平
原：祢衡性傲，不肯谒曹操。操欲辱之，录为鼓吏，以帛绢制衣作一岑牟，一单绞，及小裈。鼓吏度者，皆当脱故衣，易新衣。次传衡，不肯易衣。吏嗬之。衡便于操前先脱裈，次脱馀衣，裸身而立，徐徐著岑牟，次著单绞，后乃著裈。复击鼓，作“渔阳”掺挝，颜色无怍。操笑谓四座曰：“本欲辱衡，衡反辱孤。”孔融退而责之。衡许复往。操喜，敕门者有客便通，待之极宴。衡乃著布单衣，疏巾，手持三尺棁杖，坐在大营门，以杖棰地大骂。操以其才名，不杀，令送刘表。临发，众饯之于城南，相戒云：“俟衡到，当共卧坐以折之。”衡一至，便大号。众问其故。曰：“坐者大冢，卧者为尸。尸冢之间，能不悲乎？”
