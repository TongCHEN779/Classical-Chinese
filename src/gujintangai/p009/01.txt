# 正文
题解：《癖嗜》部卷首小引：子犹谈人各有所好，如甘带、嗜鼠之别，难分对错，借此引出本部收录的各种嗜好。
原：〔子犹曰：耳目口体之情，大致相似也。盖自“水厄”可畏，“酪奴”不尊，而茶冤矣。故先茶，而饮以欢之，而食以充之，而寝以息之，于是乎书画金石以清其玩，吟讽讴歌以畅其怀，博奕田猎以逞其欲，花木竹石以写其趣。迨香水杂陈，内外毕具，而坐客之谈谐其可少乎？凡此非富贵不办，而佞佛布施，正为生生世世富贵地耳。然而天授既殊，情缘亦异，盈缩爱憎，自然之歧也。蝍且甘带，鸱鸦嗜鼠；甲弃乙收，孰正唐、陆哭笑之是非？集《癖嗜》第九。〕
注：子犹曰：冯梦龙评语。
注：水厄：茶的戏称，见《世说新语·纰漏》，以饮茶为苦事。
注：酪奴：茶的戏称，北魏时人讥茶为“酪奴”，《洛阳伽蓝记》载王肃好茗饮，称茶为酪奴。
注：茶冤：茶被冤枉，指茶遭轻贱。
注：书画金石：书法、绘画与金石碑刻。
注：吟讽讴歌：吟诗歌唱。
注：博奕田猎：赌博下棋与打猎。
注：香水杂陈：香料与香水一并摆设。
注：佞佛布施：谄佛施舍，祈福来世。
注：天授：天赋。
注：情缘：爱好的因缘。
注：盈缩爱憎：多少与爱恶。
注：蝍且甘带：《庄子·齐物论》“蝍且甘带，鸱鸦耆鼠”，蝍且即蜈蚣，带指小蛇。
注：鸱鸦嗜鼠：鸱鸦爱吃老鼠。
注：唐、陆哭笑之是非：唐、陆之意待考。
注：集《癖嗜》第九：本书第九部。
# 茶
题解：记王濛、王肃等嗜茶之人，以及元代卢廷璧爱茶成癖，以茶具行礼，说明茶癖之深。
原：王濛好茶，人至辄饮之。士大夫甚以为苦。每欲往候，必云：“今日有水厄。”王肃喜茗，一饮一斗，人号“漏卮”。
注：王濛：东晋名士，《世说新语》载其好饮茶，客至必饮，士大夫以为苦，称“水厄”。
注：水厄：见前，饮茶之苦。
注：王肃：北魏人，原仕南齐，嗜茗，称“漏卮”，《洛阳伽蓝记》载。
注：漏卮：渗漏的酒杯，喻饮量大。
原：卢廷璧嗜茶成癖，号“茶庵”。尝蓄元僧讵可庭茶具十事，时具衣冠拜之。
注：卢廷璧：元末明初人，号“茶庵”，待考。
注：元僧讵可庭：元代僧人，待考。
注：茶具十事：十件茶具。
注：衣冠拜之：整衣冠而拜，以示敬重。
# 耽饮
题解：七则嗜酒故事：毕卓盗饮、刘伶誓酒、孔群饮不辍、郑泉愿为酒壶、艾子戏答、汝南王作酒池，写酒徒之癖。
原：毕卓为吏部郎。比舍郎酿酒熟，卓因醉夜至其瓮间取饮。主者谓是盗，执而缚之，已知为吏部郎，方释焉。
注：毕卓：东晋人，字茂世，官吏部郎，嗜酒，《晋书》有传。
注：吏部郎：吏部属官。
注：比舍郎：邻居的郎官。
注：瓮：酒坛。
注：主者：管酒的人。
原：刘伶病酒，渴甚，从妇求酒。妻捐酒毁器，涕泣谏曰：“君过饮，非摄生之道，必宜断之。”伶曰：“善！吾不能自禁，唯当誓鬼神耳。便可具酒肉。”妇从之。伶跪而誓曰：“天生刘伶，以酒为名，一饮一斛，五斗解酲。妇人之言，慎不可听！”仍饮酒御肉，颓然复醉。
注：刘伶：晋代“竹林七贤”之一，酒徒，著《酒德颂》。
注：病酒：因饮酒而病。
注：捐酒毁器：倒掉酒，毁坏酒器。
注：摄生：养生。
注：具酒肉：备下酒肉，供祭神。
注：斛：古量器。
注：解酲：解酒。
注：慎不可听：千万不可听。
注：御肉：食肉。
注：颓然：醉倒貌。
原：鸿胪卿孔群好酒。尝与亲旧书云：“今年田得七百斛秫米，不了曲蘖事。”王丞相劝使节饮，曰：“不见酒家覆瓿布，日月靡烂？”群曰：“不尔，不见糟肉乃更堪久？”
注：鸿胪卿：九卿之一，掌礼仪。
注：孔群：东晋人，《晋书》有传，好酒。
注：秫米：糯米，可酿酒。
注：曲蘖：酒曲，酿酒之物。
注：王丞相：王导，东晋宰相。
注：覆瓿布：盖酒坛的布，“日月靡烂”则言酒耗伤身体。
注：糟肉：用酒糟腌的肉。
原：郑泉临卒，语同辈曰：“必葬我陶家之侧，庶百年之后，化而为土，幸见取为酒壶，实获我心矣！”
注：郑泉：三国吴人，嗜酒，《吴书》有传。
注：陶家：烧陶器的人家。
注：庶：或许。
注：实获我心：正合我意。
原：艾子好饮，一日大饮而哕。门人密袖猪脏置哕中，指示曰：“凡人具五脏，今公因饮而出一脏矣，其何以生？”艾子熟视，笑曰：“唐三藏尚活，况四耶？”
注：艾子：宋代笑话中的人物，旧题苏轼《艾子杂说》。
注：哕：呕吐。
注：猪脏：猪的内脏。
注：唐三藏：玄奘，此处借“三藏”与“三脏”谐音，戏答。
注：五脏：心肝脾肺肾。
原：汝南王琎取云梦石甃，泛春渠以畜酒，作金银龟鱼浮沉其中，为酌酒具。自称“酿王”兼“曲部尚书”。
注：汝南王琎：唐宗室汝南郡王李琎，嗜酒，号“酒王”，《旧唐书》有传。
注：云梦石：云梦所产之石。
注：甃：砌石。
注：春渠：春水渠。
注：畜酒：储酒。
注：曲部尚书：酒曲部长官，戏号。
# 善饮
题解：彭泽与曾棨两位大员善饮，一个以烧酒灌倒秀才，一个把酒灌进纸人也面不改色，写豪饮者的气度。
原：大司马彭公泽，善饮。偶访郭武定勋，问侯：“今年酿若何？”郭曰：“小胜”。且曰：“幸尚早，能小尝否？”曰：“可。”延之侧室，尚不肯脱衣，曰：“主人不堪酬酢。”郭曰：“适有张秀才，量似可，然何足以当巨公？”彭笑曰：“不妨，请见之。”使侍坐，取两银舟相对，鲑炙蔬果，以渐罗列。酒十馀行，解带褫衣，曰：“进部尚可迟也！”属有微雪，又十馀行，曰：“部幸鲜事，可无进矣！”轰对无算。至暮，摹其腹曰：“酒太甘，当以烧酒送之。”张谢不任。乃命取前酒沃张，而自举烧酒，复十觥，始去。
注：大司马：兵部尚书的别称。
注：彭公泽：彭泽，明代官员，兵部尚书，《明史》有传。
注：郭武定勋：郭勋，封武定侯，明代勋贵。
注：酬酢：宴席上的应酬。
注：张秀才：待考。
注：巨公：大官。
注：银舟：银制的酒杯。
注：鲑炙：鱼与烤肉。
注：褫衣：脱去外衣。
注：进部：回部署办公。
注：轰对：对饮。
注：无算：不计数，饮酒不限数量。
注：烧酒：蒸馏酒。
注：谢不任：谢不胜酒力。
注：觥：酒杯。
原：曾公棨伟仪雄干，善饮啖，人莫测其量。张英国辅欲试之，密使人围其腹作纸俑，置厅事后。乃邀公饮，如其饮器注俑中。竟日，俑已溢，别注瓮中，又溢。公神色不动。夜半具舆从送归第，属使者善待之，意公必醉。公归，亟呼家人设酒劳舆隶。公取觞，复大酌。隶皆醉去，公方就寝。
注：曾公棨：曾棨，字子棨，明永乐年间状元，翰林学士，《明史》有传。
注：伟仪雄干：身材魁伟。
注：张英国辅：张辅，封英国公，明代名将。
注：作纸俑：用纸做成与其腹围相当的人。
注：厅事：大堂。
注：舆从：车轿随从。
注：舆隶：轿夫与差役。
# 食宪章
题解：段文昌讲究饮食，编《食经》五十卷，厨房号“炼珍堂”，被称“食宪章”。
原：段文昌丞相精馔事，第中疱所榜曰“炼珍堂”，在途号“行珍馆。”自编《食经》五十卷，时称为“食宪章”。
注：段文昌：唐代宰相，精于饮食，《旧唐书》有传。
注：疱：厨房。
注：炼珍堂：段文昌家厨房匾额。
注：行珍馆：段文昌在外行路时的厨房。
注：《食经》：段文昌所编，已佚。
注：食宪章：关于饮食的典章，戏称。
# 措大言志
题解：苏轼记两个穷措大言志，一个愿吃饱就睡，一个愿吃了又吃，以讽人欲无厌。
原：东坡云：有二措大，相与言志。一曰：“我平生不足，惟饭与睡耳。他日得志，当饱吃饭了便睡，睡了又吃饭。”一云：“若我吃了又吃，何暇复睡？”
注：措大：旧时对贫寒读书人的称呼，含讥讽。
注：东坡：苏轼。
注：言志：谈志向。
注：惟饭与睡：只想吃饭与睡觉；《东坡志林》载此事。
注：何暇复睡：哪有空睡觉。
# 善啖
题解：几则善啖的人：山涛、赵温叔、张齐贤、元退处士、孙铁舍，写其饭量惊人。
原：山涛酒后哺啜，折筋不休。
注：山涛：“竹林七贤”之一，晋代名臣，《晋书》有传。
注：哺啜：吃喝。
注：折筋不休：把筷子折断仍吃不停。
原：《癸辛杂志》：赵相温叔健啖。致仕日，召一士人同食，各啖若干。临别，士人腰间有声，疑其腹裂，问之，云：“平生苦饥，以带束之。适蒙赐饱，不觉带断，非有他也。”
注：《癸辛杂志》：宋周密撰《癸辛杂识》，此处作“杂志”，待考。
注：赵相温叔：赵雄，字温叔，南宋宰相，《宋史》有传。
注：健啖：饭量大。
注：致仕：退休。
注：带断：腰带断。
原：《归田录》：张齐贤每食，肥肉数斤。尝小恶，欲服天寿院黑神丸。常人服不过一丸，公命以五七两为一大剂，夹以胡饼而啖之。及罢相，知安州，与客食，厨吏置一大桶，窃视所食，如其物投桶中。至暮满桶。
注：《归田录》：北宋欧阳修撰笔记。
注：张齐贤：北宋宰相，以饭量大著名，《宋史》有传。
注：小恶：小病。
注：天寿院黑神丸：药名，待考。
注：胡饼：芝麻烧饼，西域传来。
注：知安州：任安州知州，今湖北安陆。
注：厨吏：厨房小吏。
原：元退处士年逾七十，无齿，咀嚼愈壮。常曰：“今始知齿之妨物！”
注：元退处士：待考。
注：处士：不仕之士。
注：咀嚼愈壮：越嚼越有劲。
注：齿之妨物：牙齿妨碍吃东西。
原：江阴侯孙名铁舍者，腹大善啖，平生未尝自见其足。永乐间，至京乞恩。太宗命光禄寺茶饭，计食六十斤。谢恩，拜不能起；命两卫士挟之。因不得袭荫。后家不给，食馒头，又食煨茄，俱成箩以充饥。
注：江阴侯：明代江阴侯吴高，此“孙”疑为另一江阴侯后人，待考。
注：铁舍：人名。
注：永乐：明成祖年号。
注：乞恩：请求恩赐。
注：太宗：明成祖，嘉靖后追尊太宗。
注：光禄寺：掌宫廷膳食的官署。
注：袭荫：承袭先人爵位。
注：煨茄：烤茄子。
注：箩：竹箩。
# 王弇州《朝野异闻》
题解：王世贞《朝野异闻》所记数位善啖善饮的明代官员，从毛伯温、王恕到王国光，写其饮啖之壮。
原：徐相存斋提学江西时，道遇毛尚书伯温舟。谒之，语小洽。毛曰：“公得无饥否？”即呼具小点心来。侍者捧大漆盘四，其二盘装炙鹅，鹅皆大脔，其二盘装馒头，如碗大者各五十许。又不置箸，以手掇之；二银碗飞酒。长啜大嚼，傍若无人。徐虽不能多食，而少年勇于酒，互举无算。至暮，欢然别曰：“公大器也！”迨毛下安南还，华亭亦副八座矣。毛食兼数人。尝主湖广鹿鸣宴，诸生七十五人，人陪二大白，不醉。
注：徐相存斋：徐阶，号存斋，嘉靖时内阁首辅，华亭人。
注：提学江西：任江西提学副使。
注：毛尚书伯温：毛伯温，字汝厉，明代兵部尚书，《明史》有传。
注：炙鹅：烤鹅。
注：脔：肉块。
注：箸：筷子。
注：飞酒：催酒，劝饮。
注：安南：越南。
注：华亭：指徐阶，华亭人。
注：副八座：任六部尚书之副，指侍郎。
注：鹿鸣宴：乡试后宴请考官和新举人的宴会。
注：二大白：两大杯。
原：秦晋诸公多长大，善饮啖。王端毅公恕，年九十馀，每辰起进食，牛羊犬豕肉或鸡凫之类三十碗，碗可一二斤；熟菜一大碗，面饼二盘，各堆高箸许；清酒三大碗，碗可盛二升。饮啖至尽，起，摩腹徐行，周还约二里所，复坐读书，以为恒。至九十三，一日食减三碗，面省可一盘，亭午而逝。杨襄毅公博，每啖面一瓯，辄两举筋，凡十六举筋，而罄八瓯。大虏深入，人人惴恐。公时在部覆疏，遣问甫毕，食肥肉三斤许，包子三十，酒数升，辄大睡，鼻息如雷。人服其器量。其后阳城王太宰国光、蒲州王大司马崇古，皆长七尺馀，啖尤伟。太宰切白肉作大脔，犹以为薄，夹进之。一进必百脔，饮必三斗。大醉后苦热，不能升公座。啖巨柿四十，顷刻都尽。
注：秦晋：陕西、山西。
注：王端毅公恕：王恕，谥端毅，明代名臣，陕西三原人，《明史》有传。
注：凫：野鸭。
注：杨襄毅公博：杨博，谥襄毅，明代兵部尚书，山西蒲州人。
注：大虏：北方入侵者。
注：部覆疏：在兵部批复奏疏。
注：阳城王太宰国光：王国光，山西阳城人，吏部尚书。
注：蒲州王大司马崇古：王崇古，山西蒲州人，兵部尚书。
注：太宰：吏部尚书的别称。
注：公座：官署大堂座位。
原：王令赐绂言：其乡有令张者，善饮啖，居恒不能快意。一日邻有驴毙，其值轻，张使买之，烹适熟，而女弟之婿至，亦以善啖名。邀使共饮。婿知为驴肉也，辞以饭后。俄顷肉至，凡两大盘，盘各可十馀斤，胡饼各百馀，蒜葱醯酱各具。用手撮之，顷刻俱尽。视婿啖得半而止，笑曰：“果饭后耶？何孱也！为汝代之。”即以手掇啖复尽。举浊酒两斗许，起拊腹曰：“今日始得一饱。”宗戚间有呼张饭者，必先延之别室，而与肉如式，而后出与客酬酢，尚兼数人。不然，怒，竟去矣。每烹肉，不令过熟，曰：“过熟安用我牌为？”指其腹：“此不堪一大釜耶？”
注：王令赐绂：待考。
注：居恒：平日。
注：女弟：妹妹。
注：醯酱：醋和酱。
注：孱：弱。
注：宗戚：宗亲外戚。

原：则天时，兵部郎朱前疑貌鬼，有美妻，不爱。洛中西门酒坊有婢奇鬼，蓬头垢面，伛肩凸腹。前疑大悦之，殆忘寝食。一人嘲曰：“宿瘤蒙爱，信哉！”一人笑曰：“云龙风虎，类也！”
注：则天：武则天。
注：朱前疑：武周官员，兵部郎，《朝野佥载》载。

注：酒坊：酒家。
注：伛肩：驼背。

注：云龙风虎：《周易》“云从龙，风从虎”，喻同类相求。
# 好脚臭
题解：岳乙爱闻脚臭，宴中离席去闻路人脚，写怪癖。
原：吴中岳乙喜闻脚臭。尝值宴集，忽不见。或曰：“彼非逃酒者，殆必有故。”令人侦之，则道傍有行客，方企息，理脚缠，秽气蒸蒸，是人低回留之不去。
注：吴中：吴地，苏州一带。
注：岳乙：待考。
注：宴集：宴会。
注：企息：踮脚休息。
注：脚缠：裹脚布。
注：低回：徘徊。
# 笑癖哭癖
题解：陆云笑癖、唐衢哭癖，两相对映，写情绪的极端之癖。
原：陆士龙云，有笑癖，尝著衰绖上船，水中自见其影，便大笑不已，落水几死。尝谒司空张华，华多须，以袋盛之。云见华，不及拜而笑倒。
注：陆士龙云：陆云，字士龙，西晋文学家，陆机之弟，《晋书》载其患笑癖。
注：衰绖：丧服。
注：司空张华：西晋名臣，须多。
注：笑倒：笑得站不住。
原：唐衢应进士，不第。能为歌诗，意多感发。见人文章有叹伤者，读讫必哭，涕泗不能已。每与人言论，发声一号，音词哀切，莫不凄然。尝游太原，属戎帅军宴。衢得预会，酒酣言事，抗音而哭，一席不乐，为之罢会。
注：唐衢：中唐诗人，善哭，《旧唐书》有传。
注：应进士：参加进士科考试。
注：歌诗：诗歌。
注：涕泗：眼泪鼻涕。
注：号：大哭。
注：太原：太原府。
注：戎帅：军事长官。
注：军宴：军队宴会。
注：抗音：高声。
