# 正文
题解：此为《贪秽部》总叙，冯梦龙慨叹人为财而生死荣辱，举陆念先投金于涧的“痴”为反衬，交代部目《贪秽》第十五。
原：〔子犹曰：人生于财，死于财，荣辱于财。无钱对菊，彭泽令亦当败兴。倘孔氏绝粮而死，还称大圣人否？无怪乎世俗之营营矣！究竟人寿几何？一生吃著，亦自有限，到散场时，毫厘将不去，只落得子孙争嚷多、眼泪少。死而无知，直到枉却；如其有知，懊悔又不知如何也！吾苏陆念先，应徐少宰记室聘。比就馆，绝不作一字。徐无如何，乃为道地游塞上，抵大帅某，以三十镒为寿。既去戟门，陆对金大恸，曰：“以汝故获祸者多矣！吾何用汝为！”即投之涧水中。人笑其痴，孰知正为痴人说法乎？集《贪秽》第十五。〕
注：子犹曰：冯梦龙自评。
注：无钱对菊，彭泽令亦当败兴：陶渊明曾任彭泽令，重阳无酒，坐菊丛中，后有人送酒（檀道鸾《续晋阳秋》）。
注：孔氏绝粮：孔子困于陈蔡之间绝粮，事见《论语·卫灵公》《史记·孔子世家》。
注：营营：往来忙碌，追逐名利，语出《诗经·小雅·青蝇》。
注：吃著：衣食，吃用。
注：毫厘将不去：连一毫一厘也带不走。
注：枉却：白白浪费。
注：陆念先：苏州人，待考。
注：徐少宰：少宰是吏部侍郎的别称，“徐少宰”待考。
注：记室：掌文书章奏的幕僚。
注：就馆：到幕府任事。
注：道地：预作安排，为之铺路。
注：塞上：边塞。
注：大帅：统兵的主将。
注：镒：古代重量单位，二十两（一说二十四两）为一镒。
注：戟门：古时官署、贵人家门前列戟，称戟门。
注：痴人说法：佛教用语，对痴迷之人讲法。
# 如意
题解：三则关于贪取之事：东家食西家宿的女子、钱昆求任无通判处的故事，以及刘垂的五窟堂，都以“如意”为题，写人心贪欲。
原：《风俗通》云：齐人有女，二家同往求之。东家子鬼而富，西家子好而贫。父母不能决，使其女偏袒示意。女便两袒。母问其故。答曰：“欲东家食、西家宿。”
注：风俗通：东汉应劭著。
注：东家子鬼而富，西家子好而贫：东家子貌丑而富，西家子貌美而贫；“鬼”指丑陋。
注：偏袒：袒露一臂。
注：两袒：两臂皆袒。
注：欲东家食、西家宿：想在富的东家吃饭，到美的西家睡觉，此语为后世常引的成语“东食西宿”。
原：《归田录》云：国初，通判常与知州争权，每云“我是郡监”。有钱昆者，浙人，嗜蟹，常求补外，曰：“但得有蟹无通判处，则可。”东坡诗云：“欲问君王乞符竹，但忧无蟹有监州。”
注：归田录：北宋欧阳修所撰笔记。
注：通判：宋代州府佐官，监察知州，有“监州”之称。
注：知州：一州长官。
注：郡监：郡中监察官，此指通判。
注：钱昆：字裕之，宋钱塘人，官至尚书，好食蟹，事见《归田录》。
注：补外：由京官外放。
注：东坡诗：苏轼《和蒋夔寄茶》诗：“欲问君王乞符竹，但忧无蟹有监州。”
注：符竹：竹使符，汉代郡守凭信，后借指出任郡守。
注：监州：即通判。
原：同舍生刘垂，有口才，曾号“虚空锦”。说他日得志事，曰：“有钱当作五窟堂：呈香窟，尽种梅花；秦香窟，周悬射脐；越香窟，植岩桂；蜀香窟，栽椒；楚香窟，畦兰。四时草木，各占一时。予日入麝窟，便足了一生。死且为香鬼，况于生乎？”其后仕而贪，财不副心而卒。
注：同舍生：同学。
注：刘垂：宋代人，待考；号“虚空锦”，指其只会空谈。
注：五窟堂：想建的五座香窟之堂。
注：射脐：即“麝脐”，麝香出于雄麝脐部，射、麝音近。
注：越香窟：越地多桂，故植岩桂。
注：岩桂：桂花，山岩间的桂树。
注：椒：花椒，蜀地多产。
注：畦兰：成畦种兰。
注：麝窟：麝香窟。
注：香鬼：死后做香鬼。
# 舍利
题解：张虔钊先赈灾后倍征，又被禅僧一语戏谑；全条以“舍利”双关，写贪利而冒仁名。
原：张虔钊镇沧州日，因旱，民饥，发廪赈之。方上闻，帝甚嘉奖。他日秋成，倍斗征敛，朝野鄙之。在蜀，问一禅僧云：“如何是舍利？”对曰：“剩置僦居，即得‘舍利’。”张但惭笑。
注：张虔钊：字德基，五代后唐、后蜀将领，镇沧州，后降后蜀。
注：沧州：今河北沧州。
注：发廪：开仓。
注：上闻：上报朝廷。
注：帝：指后唐明宗（李嗣源）。
注：倍斗征敛：加倍收粮，“倍斗”指用大斗收租。
注：舍利：佛教称高僧火化后所留遗骨；这里“舍利”谐“舍”与“利”，僧人戏其舍了又取利。
注：剩置僦居：多余东西放在租屋里，“剩”“僦”或有谐音，原意待考。
# 抱鸡、养竹
题解：夏侯彪之用鸡抱卵、养笋生利，都是在百姓不知时敛财，被写成贪鄙，事见《朝野佥载》。
原：《广记》：唐新昌县令夏侯彪之，初下车，问里正曰：“鸡卵一钱几颗？”曰：“三颗。”彪之乃遣取十千钱，令买三万颗，谓里正曰：“未便要，且寄鸡母抱之。”遂成三万头鸡，经数月长成，令县吏：“与我卖。”一鸡三十钱，半年之间，成三十万。又问：“问笋一钱几茎？”曰：“五茎。”又限十千钱付之，买得五万茎。谓里正曰：“吾未须笋，且林中养之。”至秋竹成，一茎十文，积成五十万。其贪鄙不道皆此类。
注：广记：《太平广记》，宋李昉等编。
注：夏侯彪之：唐新昌县令，事见《朝野佥载》，《北史》作夏侯彪。
注：下车：官吏初到任。
注：里正：唐制百户为里，里正管理户口赋役。
注：十千钱：十贯钱，一千钱为一贯。
注：鸡母：母鸡。
注：抱：孵。
注：茎：笋量词。
注：贪鄙不道：贪婪卑鄙，不合道。
# 卖粪天子
题解：裴舒请卖马粪，被刘仁轨以“卖马粪天子”之名劝阻，记载了唐初朝臣顾惜国体。
原：唐少府监裴舒，奏请卖马粪，计岁得钱二十万缗。刘仁轨曰：“恐后代称唐家卖马粪，非佳名也。”乃止。
注：少府监：官署名，掌百工技艺，裴舒任监，史作“少府监”。
注：裴舒：唐高宗时人，待考；一说此事在咸亨年间。
注：缗：成串的钱，一千文为一缗。
注：刘仁轨：字正则，唐初名臣，官至尚书左仆射，《旧唐书》有传。
# 婢担粪
题解：王衍之妻郭氏贪鄙，令婢路上担粪，被小叔王澄劝阻，反要打他，写贪妇的蛮横。
原：王夷甫妻郭氏贪，令婢路上担粪。王平子年十四年，谏之。郭怒曰：“夫人以小郎嘱新妇，不以新妇嘱小郎！”捉澄衣裙，将与杖。平子力争得脱。
注：王夷甫：王衍，字夷甫，西晋名士，清谈领袖，官至太尉。
注：郭氏：王衍妻，郭槐之侄，贪婪无度，《世说新语·规箴》有记。
注：王平子：王澄，字平子，王衍之弟。
注：夫人以小郎嘱新妇：先夫人（婆婆）把小叔托付给我（新妇），不是把我托付给小叔。
注：捉：抓住。
注：澄：王澄。
# 鬻水
题解：慕容评在潞川阻挡王猛，却封山泉卖水敛财，士卒怨愤而败，是贪致亡国的例子。
原：前燕太傅慕容评，屯兵潞川，以拒王猛。鄣固山泉，鬻水与军人，绢一匹，得水二石，积钱帛如山。士卒怨愤而败。
注：前燕：十六国之一，慕容儁建。
注：太傅：官名，三公之一。
注：慕容评：前燕宗室，字太傅，晚年贪鄙。
注：潞川：今山西潞城一带，前燕与前秦决战之地（370年）。
注：王猛：前秦宰相，字景略，北海人。
注：鄣固山泉：封堵山泉。
注：鬻：卖。
注：石：容量单位，十斗为一石。
# 假子猷
题解：解宾王任利州转运使，所到行衙将竹子砍光卖钱，被称“假子猷”，嘲其以爱竹之名而贪利。
原：解宾王作利漕，将代还，凡有行衙所在，竹皆伐卖之。时人呼为“假子猷”。
注：解宾王：待考。
注：利漕：利州路转运使，“漕”指转运。
注：将代还：将要卸任回京。
注：行衙：官吏出行时的临时驻所。
注：子猷：王徽之字子猷，晋人，酷爱竹，称“何可一日无此君”，事见《世说新语·任诞》；“假子猷”即假冒子猷者。
# 钱当酒
题解：苏五奴妻有姿色，被人邀去陪酒，苏五奴只要钱，说有钱虽被打也醉，笑其贪财无耻。
原：苏五奴妻善歌舞，亦有姿色。有邀请其妻者，五奴辄随之。人欲醉五奴以狎其妻，多劝之酒。五奴曰：“但多与我钱，虽吃锤亦醉，不须酒也。”
注：苏五奴：唐人，事见《朝野佥载》。
注：狎：轻慢亲昵。
注：吃锤：挨打。
# 偷鞋刺史
题解：郑仁凯自己不买新鞋，让家奴偷下属的鞋，被控后抵赖“刺史不是守鞋人”，写贪秽无赖。
原：郑仁凯性贪秽。尝为密州刺史，家奴告以鞋敝，即呼吏新鞋者，令之上树摘果，俾奴窃其鞋而去。吏诉之。仁凯曰：“刺史不是守鞋人。”
注：郑仁凯：唐人，《朝野佥载》作“郑仁凯”，待考。
注：贪秽：贪污，污秽。
注：密州：今山东诸城一带。
注：敝：破旧。
注：俾：使。
注：守鞋人：看管鞋子的人。
# 匿金叵罗
题解：祖珽席上偷金叵罗，被搜出藏在发髻中，毫无羞耻，又偷铜叠，写其贪鄙。
原：魏神武帝宴僚属，于坐失金叵罗。窦太后令饮者皆脱帽，果在祖孝征髻中。见者以为深耻，孝征怡然自若。又孝征饮司马世云家，藏铜叠三面，为厨人搜出。
注：魏神武帝：东魏高欢，东魏时大丞相，追尊北齐神武帝。
注：金叵罗：金制的酒杯，叵罗原是胡语。
注：窦太后：疑当作“娄太后”，即高欢妻娄昭君，此处待考。
注：祖孝征：祖珽，字孝征，北齐权臣，好财。
注：髻：发髻。
注：司马世云：北齐人，司马世云。
注：铜叠：铜碟。
# 银佛
题解：苏监察趁废寺之机将银佛袖归，被称“苏扛佛”，温庭筠以“蜜陀僧”对之，讥其贪佛财。
原：张林奏毁佛寺。有苏监察者，检天下废寺，凡银佛一尺以下，多袖归。人号“苏扛佛”。温庭筠笑曰：“好对‘蜜陀僧’。”
注：张林：疑当作“张林”或“张琳”，指会昌年间奏请毁寺者，待考。
注：苏监察：唐监察御史，待考。
注：检：检查，清点。
注：袖归：藏在袖里带走。
注：苏扛佛：戏称，“扛”是搬运的意思。
注：温庭筠：字飞卿，晚唐诗人、词人。
注：蜜陀僧：矿物药，成分为氧化铅，谐音“密陀僧”，与“苏扛佛”对仗工整。
# 献罗汉
题解：曹翰攻下江南时将金银珠宝借运罗汉之名运走，被称“押扛罗汉”，写武将借佛物谋私。
原：曹翰下江南日，尽取其金帛宝货，连百馀舟，私盗以归。无以为名，乃取庐山东林寺罗汉，每舟载十馀尊。献之，诏赐相国寺。时谓之“押扛罗汉”。
注：曹翰：北宋初将领，太平兴国初下江州，《宋史》有传。
注：江南：指江南诸地，此指南唐故地。
注：庐山东林寺：东晋慧远所建名寺。
注：罗汉：佛教中修得阿罗汉果的圣者，东林寺有十六罗汉像。
注：相国寺：北宋东京名寺，在今河南开封。
注：押扛：押运、扛抬。
# 盗伪辇
题解：王镇恶破姚泓后盗宝，又取伪辇剔其金银，被刘裕看破而一笑，写武将贪利。
原：王镇恶性贪。既破姚泓，盗取府库无算。刘裕念其功，不问。又盗泓伪辇。裕惊，使人觇之。镇恶剔取其金银，弃辇于垣侧。裕大笑。
注：王镇恶：东晋末刘裕部将，北海剧人，王猛之孙。
注：姚泓：后秦末代君主，417年被刘裕灭。
注：伪辇：对敌国所乘车驾的贬称。
注：刘裕：南朝宋开国皇帝。
注：觇：窥视，察看。
注：垣：矮墙。
# 科钱造像
题解：窦知范借为死者造像之名向二百里正征钱，却只拿一尺来高的小像抵债，写县令贪污的无耻。
原：唐瀛州饶阳县令窦知范贪污。有一里正死，范集里正二百人，为之造像，各科钱一贯。既纳钱二百千。荡曰：“里正地下受罪，先须救急。我先选得一像，且以贷之。”于袖中出像，仅五寸许。
注：瀛州饶阳：今河北饶阳。
注：窦知范：唐人，事见《朝野佥载》，待考。
注：里正：见前。
注：造像：为死者造佛像追福。
注：科钱：摊派钱款。
注：荡曰：疑当作“范曰”，指窦知范说。
注：贷：借给，指以像抵借。
# 取油客子金
题解：安重霸召油客邓子下棋，却只让其久立，终以中金数铤才得脱身，写官吏借棋索贿。
原：蜀简州刺史安重霸，黩货无厌。州民有油客子者，姓邓，能棋，其力粗赡。安召与对敌，只令立侍。每落子，俾其退立于西北牖下：“俟我算路，乃进！” 终日不下十数子而已。邓生久立，饥倦不堪。次日又召。或讽邓子曰：“此侯贿，本不为棋，何不献效而自求退？”邓生然之，以中金数铤获免。
注：安重霸：后蜀简州刺史，事见《北梦琐言》。
注：黩货无厌：贪财无度。
注：简州：今四川简阳。
注：油客：卖油的商人。
注：粗赡：略有富足。
注：对敌：对弈。
注：牖：窗户。
注：算路：思考棋路。
注：献效：献纳。
注：中金：中等的金子。
注：铤：金银块的量词。
# 张鹭鹚
题解：张某表面廉洁，却榜称生日不得献送，众吏会意献“寿衣”，又告知县君生日不要再送，被讥为“张鹭鹚”。
原：开宝中，神泉县令张某，外廉而内实贪。一日自榜县门云：“某月某日是知县生日。告示门内典级诸色人，不得辄有献送。”有一曹吏与众议曰：“宰君明言生日，意令我辈知也。言不得献送，是谦也。”众曰：“然。”至日各持缣献之，命曰：“寿衣”。宰一无所拒，感领而已。复告之曰：“后月某日，是县君生日，更莫将来。”无不嗤者。众进士以鹭鹚诗讽之云：“飞来疑似鹤，下处却寻鱼。”
注：开宝：宋太祖年号（968—976）。
注：神泉县：今地待考。
注：外廉而内实贪：表面清廉，实际贪鄙。
注：典级诸色人：下属各类吏役人员。
注：宰君：对县令的尊称。
注：缣：细绢，常作财物与礼品。
注：县君：县令之妻的称呼，亦是封号。

# 古物
题解：刘义恭爱古物，何勖送来狗枷和犊鼻，戏称李斯狗枷、相如犊鼻，借以讽其求取无厌。
原：江夏王义恭，性爱古物，常遍就朝士求之。侍中何勖已有所送，而征索不已。何意不平，尝出行道中，见狗枷、败犊鼻，命仆取归，饰以箱，送之。笺曰：“承复需古物，今奉李斯狗枷，相如犊鼻。”
注：江夏王义恭：刘义恭，宋文帝之弟，封江夏王。
注：何勖：字伟业，南朝宋人，官侍中。
注：侍中：门下省长官，皇帝近臣。
注：征索：索取。
注：狗枷：套狗颈的木枷。
注：败犊鼻：破的犊鼻裈，即短裤。
注：笺：书信。
注：李斯狗枷：李斯被杀前叹“欲牵黄犬”，此指狗枷。
注：相如犊鼻：司马相如与卓文君在临邛卖酒，自着犊鼻裈，事见《史记·司马相如列传》。
# 铜臭
题解：崔烈买官五百万为司徒，儿子崔均说外人嫌其“铜臭”，是“铜臭”一词的出典。
原：崔烈入钱五百万，为司徒。及辞帝，帝曰：“悔不少靳，可至千万。”子均，字孔平，亦有时名。烈问均曰：“我作公，天下谓何如？”对曰：“大人少有高名，不谓不当为公，但海内嫌其铜臭！”
注：崔烈：字威考，东汉涿郡安平人，灵帝时买司徒，事见《后汉书·崔骃传》。
注：入钱：买官。
注：司徒：三公之一。
注：靳：吝惜。
注：均：崔均，字孔平，崔烈之子。
注：作公：做三公。
注：铜臭：铜钱的臭味，嘲讽买官者。
# 贪位
题解：夏侯嘉正之贪和裴聿的“八榻将军”，前者想知制诰一日，后者因被打八榻而升八阶，写人对官位的贪恋。
原：夏侯嘉正性贪，常言：“若能见水银成银一钱，知制诰一日，死亦无恨！”则天时，夏官侍郎侯知一，以年老敕令致仕。知一乃诣朝堂，跳跃驰走，以示轻捷。时谓“不伏致仕”。
注：夏侯嘉正：字会之，宋初人，官至知制诰，事见《宋史》。
注：水银成银：古炼丹术中想把水银炼成银子。
注：知制诰：起草诏书的官职，文臣荣选。
注：则天：武则天。
注：夏官侍郎：武周改兵部为夏官，侍郎为其副。
注：侯知一：武周时人，《朝野佥载》有其事。
注：致仕：退休。
注：朝堂：朝廷议事之处。
注：不伏致仕：不服老退休。
原：《朝野佥载》：滕王为隆州刺史，多不法。参军裴聿谏止之。王怒，令左右掴榻。他日聿入计，具诉于帝。帝问聿：“曾被几榻？”聿曰：“前后八榻。”即令迁八阶。聿归叹曰：“何其命薄？若言九榻，当入五品矣！”闻者哂之，号“八榻将军”。
注：朝野佥载：唐张鷟撰。
注：滕王：李元婴，唐高祖之子，封滕王，曾任隆州刺史。
注：隆州：今四川阆中。
注：参军：州府属官。
注：裴聿：待考。
注：掴榻：疑当作“掴搨”，打；“榻”同“搨”，拍击。
注：入计：入朝上计，向朝廷报告政绩。
注：迁八阶：官位升八级。
注：五品：唐代五品以上为高官。
注：八榻将军：戏称，“榻”谐“搨”，被打八次，升八阶。
