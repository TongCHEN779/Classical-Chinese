# 大唐故雁门郡解府君墓志铭
原：府君讳进字进，族茂雁门，派别条分，今籍于京兆府，鄠县八步乡解村人也。祖讳齐，父乐道，不仕，府君即乐道之第二子也。修短不意，去元和四年三月四日疾，终于河南府河阳县太平乡树楼村之私第，春秋六十有五，即以元和五年十一月十一日，权厝于私第北二里之原。礼也。孀妻李氏，偕老愿违，哀号痛切。嗣子忠信、次子少迁、次子少恭、次子少璘、次子少仪、次阿小、长新妇曹氏等，号天叩地，柴毁过礼，殆不胜丧。窀穸云具，礼物咸备。恐坟陇有变，故刻颂立名，以作永年之记。
原：茫茫蒿里，寂寂松扉。痛君子之长逝，殁寒泉而不归。

# 大唐扶风马氏墓志
原：廿三娘马氏，名姹，扶风人也。故侍中太原尹，子曾主父；故太子谕德兼兵部郎中，子之王父；故鄂州州从事，子之先父也。子生于珥貂之家，育在纨绮之室。笄年廿岁，灼如英。期偶适耀（阙）我后嗣何华而不实，祉福不临？以元和八年七月三日，洪水忽来，浸溢夏汭，合郭为患。顾比（阙）遂假官航以虞（阙）。

# 大唐故员府君夫人墓志铭
原：（阙）昔因周文王之后，分郡于南阳。祖讳宪，格高调逸，学富才雄，退卧云林，高道不事。父讳麟，文词间世，儒素成家，器宇深沉，风神朗悟。一心孤高，寒峰映月，为量不测，发言有征。心常怀分，义尤济贫，远迩之人，咸怀其德。何修短之有命，以元和十一年五月十八日，启手足而告终，春秋卌有六。夫人房氏，雍容令仪，肃穆懿范，毕舅姑之大礼，享年卌有二。同年八月十六日，续夫而殁。兄昌，忝同支气，痛苦莲心。嗣子元启，攀号擗踊，仰告皇天，罄家有无，备终大礼，以元和十一年十二月廿九日，合祔大茔而安坟垄。山谷变改，托于铭记其德。词曰：
原：穷灯暗暗，泉室冥冥。孤坟对月，荒野荧荧。千秋万岁，永隔恩情。

# 刘夫人辛氏墓志铭
原：唐故平卢军节度押衙兼左厢兵马使银青光禄大夫、云麾将军、检校国子祭酒兼御史中丞、上柱国、食邑二千五百户刘公夫人，陇西郡人也。父讳行俭，夫人即府君长女也。聘于彭城刘公，公不幸早薨。夫人禀山岳之粹灵，受人伦之大福，博行而多闻，发言而合礼，素德全备，淑慎威仪。迨于姻亲，俯仰咸若，挺霜操而驰其声，汇女功而发其誉。夫人六十有六，以太和九年秋七月廿日而薨。夫人有子二人：长子平卢节度衙前虞候、云麾将军、试殿中监上柱国克勤，次子节度散〈（阙一字）〉将克恭。生女一人，日引子等，哀毁过礼，杖而不起，乃扶护灵柩，当年冬十月七日，祔葬于青州益都县永固乡广固之里。以先茔不利，故别迁宅兆，西据于〈（阙一字）〉倚山印之崇秀，东极于荒，南眺青山，北临于郡。仍书铭于墓内，铭曰：
原：白玉无瑕，青松有节。德仪咸备，行偕先列。弃〈（阙一字）〉世而归天，流芳华而不歇。苍茫野色，云悲鸿咽。林〈（阙二字）〉兮悲风，光娟娟兮夜月。

# 唐故冯府君墓志铭
原：府君讳伦，字环周，长乐人也。曾祖思，祖炎、父璋，俱养性邱园，高尚不仕。府君即璋第二子，幼而简约，长而宏雅，恬然自处，不趋世利。礼则凝重，器宇沈深，虽荣之与辱，不能动其色，忘言得意，忻忻如也。轻财重义，博识多能，理性内融，徽猷外发。男公造立身恭谨，色养兢兢。二女令淑有闻，各娉他室。
原：呜呼斯人！不保遐寿，少乖摄卫，伏枕弥旬，药术无征，奄随风烛，以太和十年八月一日，终于私第，享年七十。府君殄隔壁，阴云暗惨，鸟雀悲鸣。至理元微，天何可问？男女迷谬，叩地号天，闾巷伤闻，为之慜然！夫人陈氏，蓬首灰心，沈哀骨立，徒想琼田之草，无复返魂之香，以其年十月十五日，葬于江夏长乐乡射亭里之原。礼也。北背黄鹤之岭，南瞻八缺之峰，恐年代侵疏，川原变易，克石记事，永将不易。辞曰：
原：日月至明，尚有盈缺。邱山至壮，尚有崩裂。感彼冯君，随波生灭。时惟孟冬，析析悲风。凝阴蔽野，苦雾霾空。敬勒斯志，千载无穷。

# 故天水姜夫人墓志铭
原：大唐故驸马都尉天水姜庆初女，适故殿中侍御史刘元质，享年七十三。于开成三年十月一日，终于鄂州私第。以其年十二月二十一日，权厝黄鹤山南原。礼也。惧陵谷之多变，故为斯铭，用纪悠久之祀。

# 唐贝州永济县故马公郝氏二夫人墓志铭
原：君讳恒，父讳超，其先扶风郡人也。昔马融注解，累代钦崇风，后允因官徙居甘陵郡，乃祖乃父，遂为永济县人焉。公以礼为度，以德为车，衣著篇章，饮食经籍。谢家鲍氏，羞当章句之流，耻也文学之列。金石为节，松竹表贞，乱代逃名，庸君隐迹，怀宝不仕，韬道迷邦，于是道德互门，仁者为里。
原：呜呼！天不慭遗，神莫见祐。元和七年七月廿一日，寝疾终于沙邱方私第也，享年卌十，时也日月无光，云天惨色，闾巷遏密，行路伤嗟，权殡县西一里。先夫人松萝靡托，葛藟无依，结誓指于柏舟，空泪流于斑竹，以开成六年正月十三日，与二夫人迁葬于故茔。礼也。仲子〈（阙二字）〉尽〈（阙一字）〉以竭家资，因为迁祔，恐（阙）改易，刻〈（阙一字）〉为纪：
原：平生志贞，松筠表节。坚劲金石，洁白冰雪。〈（阙一字）〉遍乾坤，光连子孙。辉赫三代，荣庆一门。道〈（阙二字）〉字，名彰四海。天何奄祸于幽魂，骨肉永闭于长夜，何时再睹明昏？

# 唐处士包公夫人墓志铭
原：夫人姓张，其先清河人也。皇父讳邻，夫人生有妍姿，长修言行。包君前取义阳朱夫人，而生四子，不幸朱夫人中年下世，及终丧，亲迎娉夫人为继室。敬爱均乎长幼，周旋广备亲疏，抚育前男，恩过己子。呜呼夫人！行年六十有六，以会昌三年十月九日，奄终钱唐县方兴乡之私第。包君以再伤齐体，追悼何心，尽礼居丧，卜时将葬。前男女哀慕无容，以其年癸亥十二月十一日丙申，葬于履泰乡之高原。礼也。恐陵谷以变，更托斯文之可。铭曰：
原：噫夫人兮！倏忽流年，〈（阙三字）〉兮冥寞荒原，惨惨灵谷，悠悠夜泉。未〈（阙三字）〉归于此焉。

# 唐故尹府君夫人朱氏墓志铭
原：曾〈（阙一字）〉祖从家状官告坠失不叙。府君讳澄，其先望在天水，贯居秦州，后子孙分散，各处一方，今权居孟州，即为河阳县人也。公为人端耿，量雅恬和，与人结交，千金不易，一言道合，驷马不追，远近钦风，花城共美。奈何积善无庆，天降其祸，去开成四年，告终于私第，春秋六十有七。夫人朱氏，即世广陵郡人也。笄年秦晋匹配，归于尹氏之门；妇道礼仪，不亏晨夕之孝。接事舅姑，能善能柔；和睦六亲，乡闾传礼。奈何大运将至，卧疾连绵，千方无效，万药无征，启托坚贤，其疾不愈，〈（阙一字）〉会昌四年十月十九日，终于私室，春秋六十有三。男女七人；长子元庆，新妇王氏；次子元礼，新妇戴氏；次子元简，新妇贾氏；次子元雅，新妇王氏；小子元殷，未婚；长女十四娘，夫张氏；十五娘，归开氏。嗣子等非法不行，非礼不动，〈（阙二字）〉焉有丈夫之志，儿女等叫天泣血，五内分崩，称家有无，将〈（阙一字）〉葬事，卜得会昌四年十一月十八日，葬于孟州河阳县安乐乡〈（阙二字）〉村。礼也。恐年代〈（阙一字）〉远，陵谷有迁，刊石为文，乃申铭曰：
原：嗟乎尹君，生为哲人。言无嵒失，花城共闻。千金交结，恩义长存。招贤纳士，礼法芳新。嗟乎尹君，没为异人。嗣子择兆，安葬神魂。千秋万载，〈（阙二字）〉子孙。

# 汝南周君墓志铭
原：君讳文遂，字道从。祖讳岩先，父讳通。君即通之长子也。幼读儒书，长而习礼，弱冠之岁，咸誉所知。内孝亲姻，外穆僚友，不能苦滥于琴酒，乃绾职于监司。三五年间，荣誉可奖。何期未申公表，奄卒壮年。呜呼！霜剑摧锋，鸣琴绝轸，春秋卅有五，大中二年三月十五日，终于天长之私馆也。以其年十月二十九日，祔于先祖妣王夫人列域，以为窀穸。礼也。娶宏农杨氏，恭孝内谐，举案从礼。一子三岁，名曰“小君”。令弟二人，曰文遇、文造，悼鸰原而遽绝，谁济急难，桐荆干摧，雁行何续？敢忘兄友，铭志弟恭。固请长词，用彰后纪者焉。铭曰：
原：呜呼周君，世命奚促。三十五岁，祸来冲福。手剑摧锋，身绅弃王。欲济舟倾，风前失烛。一旦归冥，百龄何续？千岁之中，再生王国。

# 唐陆君夫人孙氏墓志铭
原：夫人，吴大皇帝十九代孙德之女也，令淑有闻，名传四德，笄年归于陆氏。君名瑛，有子三，二男一女。长男宏诜，次曰宏谘，并未有所娶。女则初笄之岁，未有所归。夫人以大中四年遇疾，百药无征，千灵靡究，即是岁仲夏月三日而终，春秋五十有七。男女号踊，泣血摧咽，亲戚悲噫。日月逾迈，龟筮叶从，于其年季秋月末旬八日，而安厝富阳县西廿里上黄山墓。然而礼墓则南登极峭，北达长衢，东西即富春孙氏之山矣！虑年月将浸，故列砖记其志铭曰：
原：穆穆夫人，名传四德。染疾不愈，殁归泉路。苍茫山谷，冥冥九泉。恐年月浸，志铭列砖。

# 大唐魏博节度别奏刘公故太原郭氏夫人墓志铭
原：夫人太原盛族，远祖因官迁居于大名，今为魏郡人也。三代祖并辕门上将，名冠古今，勋业俱高，不可具载。父君佐使宅亲事兵马使押衙，以亏裘饰身，文武不坠，守忠事上，信义居怀，可谓丈夫矣！夫人即押衙之长女也。以初笄而归于刘公，在家而令淑有闻，出嫁而四德克备。吁！上天难问，〈（阙一字）〉短不容，不幸以大中六年五月十二日，终于府元城县慕化坊之私宅也，享年廿五矣。呜呼！父母肠断，良人痛心，生死路殊，龟筮叶吉，以其年闰七月九日，迁柩于府西南五里贵乡县王赵村祔先茔。礼也。虑邱垄之更变，故刊贞石为铭。其词曰：
原：婉娩柔仪，言容和茂。妇德可观，进退可度。上天不均，掩同薤露。大魏西南，良玉瘗土。万古千秋，永扃幽户。

# 万氏夫人墓志
原：有唐大中六年龙集壬申十二月十三日，豫章郡万夫人终于扬州江都来凤之里，年卅九。爰自笄年归于阎氏之室，育三男一女：长子公庆，次曰公闵，幼曰公间。卜其宅兆，即以当月廿四日，窆于扬子县界江滨乡白社村。其地东西十丈，南北十五丈。刻字于墓，庶乎后迷，万古千秋，永为后记。

# 唐故陆氏刘夫人墓志铭
原：夫人彭城郡人也，父峰皆词林学，趋官迹立。笄年礼聘，适于陆门，盥帨鸡鸣，严勤妇节。大期俄届，呜呼！于大中九年七月（阙）日，寝疾终于华亭邑内之私室也，芳年四十有七。以其年十一月一日。葬于县东三里买宋氏地之新茔。礼也。有子三人，长度次夫、师（阙）。师虽以幼童，哀诉过礼。恐代异时移，故刊贞石。铭曰：
