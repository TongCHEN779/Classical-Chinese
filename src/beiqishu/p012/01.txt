# 文宣四王
原：文宣五男：李后生废帝及太原王绍德，冯世妇生范阳王绍义，裴嫔生西河王绍仁，颜嫔生陇西王绍廉。

# 太原王绍德
原：太原王绍德，文宣第二子也。天保末，为开府仪同三司。武成因怒李后，骂绍德曰：“你父打我时，竟不来救！”以刀环築杀之，亲以土埋之遊豫园。武平元年，诏以范阳王子辨才为後，袭太原王。

# 范阳王绍义
原：范阳王绍义，文宣第三子也。初封广阳，後封范阳。历位侍中、清都尹。好与群小同饮，擅置内参，打杀博士任方荣。武成尝杖之二百，送付昭信后，后又杖一百。及後主奔邺，以绍义为尚书令、定州刺史。周武帝克并州，以封辅相为北朔州总管。此地齐以重镇，诸勇士多聚焉。前长史赵穆、司马王当万等谋执辅相，迎任城王於瀛州。事不果，便迎绍义。绍义至马邑。辅相及其属韩阿各奴等数十人皆齐叛臣，自肆州以北城戍二百八十餘尽从辅相，及绍义至，皆反焉。绍义与灵州刺史袁洪猛引兵南出，欲取并州，至新兴而肆州已为周守。前队二仪同以所部降周。周兵撃显州，执刺史陆琼，又攻陷诸城。绍义还保北朔。周将宇文神举军逼马邑，绍义遣杜明达拒之，兵大败。绍义曰：“有死而已，不能降人。”遂奔突厥。众三千家，令之曰：“欲还者任意。”於是哭拜别者太半。突厥他钵可汗谓文宣为英雄天子，以绍义重踝似之，甚见爱重，凡齐人在北者，悉隶绍义。高宝寧在营州，表上尊号，绍义遂即皇帝位，称武平元年。以赵穆为天水王。他钵闻宝寧得平州，亦招诸部，各举兵南向，云共立范阳王作齐帝，为其报雠。周武帝大集兵於雲阳，将亲北伐，遇疾暴崩。绍义闻之，以为天赞己。卢昌斯据范阳，亦表迎绍义。俄而周将宇文神举攻灭昌期。其日，绍义適至幽州，闻周总管出兵于外，欲乘虚取蓟城，列天子旌旗，登燕昭王冢，乘高望远，部分兵众。神举遣大将军宇文恩将四千人驰救幽州，半为齐军所杀。绍义闻范阳城陷，素服举哀，回军入突厥。周人购之於他钵，又使贺若谊往说之。他钵犹不忍，遂伪与绍义猎於南境，使谊执之，流于蜀。绍义妃渤海封孝琬女，自突厥逃归。绍义在蜀，遗妃书云：“夷狄无信，送吾於此。”竟死蜀中。

# 西河王绍仁
原：西河王绍仁，文宣第四子也，天保末，为开府仪同三司。寻薨。

# 陇西王绍廉
原：陇西王绍廉，文宣第五子也。初封长乐，後改焉。性粗暴，尝拔刀逐绍义，绍义走入厩，闭门拒之。绍义初为清都尹，未及理事，绍廉先往，唤囚悉出，率意决遣之。能饮酒，一举数升，终以此薨。

# 孝昭六王
原：孝昭七男：元后生乐陵王百年，桑氏生襄城王亮，出後襄城景王，诸姬生汝南王彦理、始平王彦德、城阳王彦基、定阳王彦康、汝阳王彦忠。

# 乐陵王百年
原：乐陵王百年，孝昭第二子也。孝昭初即位，在晋阳，群臣请建中宫及太子，帝谦未许，都下百僚又有请，乃称太后令立为皇太子。帝临崩，遗诏传位於武成，並有手书，其末曰：“百年无罪，汝可以乐处置之，勿学前人。”大寧中，封乐陵王。河清三年五月，白虹围日再重，又横贯而不达。赤星见，帝以盆水承星影而盖之，一夜盆自破。欲以百年厌之。会博陵人贾德胄教百年书，百年尝作数“敕”字，德胄封以奏。帝乃發怒，使召百年。百年被召，自知不免，割带玦留与妃斛律氏。见帝於玄都苑凉风堂，使百年书“敕”字，验与德胄所奏相似，遣左右乱捶撃之，又令人曳百年绕堂且走且打，所过处血皆遍地。气息将尽，曰：“乞命，願与阿叔作奴。”遂斩之，弃诸池，池水尽赤，於後园亲看埋之。妃把玦哀号，不肯食，月餘亦死，玦犹在手，拳不可开，时年十四，其父光自擘之，乃开。後主时，改九院为二十七院，掘得一小尸，绯袍金带，一髻一解，一足有靴。诸内参窃言，百年太子也，或言太原王绍德。诏以襄成王子白泽袭爵乐陵王。齐亡，入关，徙蜀死。

# 汝南王彦理
原：汝南王彦理，武平初封王，位开府、清都尹。齐亡，入关，随例授仪同大将军，封县子。女入太子宫，故得不死。隋开皇中，卒并州刺史。

# 始平、城阳、定阳、汝阳诸王
原：始平王彦德、城阳王彦基、定阳王彦康、汝阳王彦忠，与汝南同受封，並加仪同三司，後事阙。

# 武成十二王
原：武成十三男：胡皇后生後主及琅邪王俨，李夫人生南阳王绰，後宫生齐安王廓、北平王贞、高平王仁英、淮南王仁光、西河王仁幾、乐平王仁邕、颍川王仁俭、安乐王仁雅、丹阳王仁直、东海王仁谦。

# 南阳王绰
原：南阳王绰，字仁通，武成长子也。以五月五日辰时生，至午时，後主乃生。武成以绰母李夫人非正嫡，故贬为第二，初名融，字君明，出後汉阳王。河清三年，改封南阳，别为汉阳置後。
原：绰始十餘岁，留守晋阳。爱波斯狗，尉破胡谏之，欻然斫杀数狗，狼藉在地。破胡惊走，不敢復言。後为司徒、冀州刺史，好裸人，使踞为兽状，纵犬噬而食之。左转定州，汲井水为後池，在楼上弹人。好微行，遊猎无度，恣情强暴，云学文宣伯为人。有妇人抱儿在路，走避入草，绰夺其儿饲波斯狗。妇人号哭，绰怒，又纵狗使食，狗不食，涂以儿血，乃食焉。後主闻之，诏锁绰赴行在所。至而宥之。问在州何者最乐，对曰：“多取蝎将蛆混，看极乐。”後主即夜索蝎一斗，比晓得三二升，置诸浴斛，使人裸卧斛中，号叫宛转。帝与绰临观，喜噱不已，谓绰曰：“如此乐事，何不早驰驿奏闻。”绰由是大为後主宠，拜大将军，朝夕同戏。韩长鸾间之，除齐州刺史。将發，长鸾令绰亲信诬告其反，奏云：“此犯国法，不可赦。”後主不忍显戮，使宠胡何猥萨後园与绰相扑，扼杀之。瘗於兴圣佛寺。经四百餘日乃大敛，颜色毛發皆如生，俗云五月五日生者脑不坏。绰兄弟皆呼父为兄兄，嫡母为家家，乳母为姊姊，妇为妹妹。齐亡，妃郑氏为周武帝所幸，请葬绰。敕所司葬於永平陵北。

# 琅邪王俨
原：琅邪王俨，字仁威，武成第三子也。初封东平王，拜开府、侍中、中书监、京畿大都督、领军大将军、领御史中丞，迁司徒、尚书令、大将军、录尚书事、大司马。魏氏旧制，中丞出，清道，与皇太子分路行，王公皆遥住车，去牛，顿轭於地，以待中丞过，其或迟违，则赤棒棒之。自都邺後，此仪浸绝，武成欲雄宠俨，乃使一依旧制。初从北宫出，将上中丞，凡京畿步骑，领军之官属，中丞之威仪，司徒之卤簿，莫不毕备。帝与胡后在华林园东门外张幕，隔青纱步障观之。遣中贵骤马趣仗，不得入，自言奉敕，赤棒应声碎其鞍，马惊人坠。帝大笑，以为善。更敕令驻车，传语良久，观者倾京邑。俨恒在宫中，坐含光殿以视事，诸父皆拜焉。帝幸并州，俨常居守，毎送驾，或半路，或至晋阳，乃还。王师罗常从驾，後至，武成欲罪之，辞曰：“臣与第三子别，留连不觉晩。”武成忆俨，为之下泣，舍师罗不问。俨器服玩饰，皆与後主同，所须悉官给。於南宫尝见新冰早李，还，怒曰：“尊兄已有，我何意无！”从是，後主先得新奇，属官及工匠必获罪。太上、胡后犹以为不足。俨常患喉，使医下针，张目不瞬。又言於帝曰：“阿兄懦，何能率左右？”帝毎称曰：“此黠儿也，当有所成。”以後主为劣，有废立意。
原：武成崩，改封琅邪。俨以和土开、骆提婆等奢恣，盛修第宅，意甚不平，尝谓曰：“君等所营宅早晩当就，何太迟也。”二人相谓曰：“琅邪王眼光奕奕，数步射人，向者暂对，不觉汗出，天子前奏事尚不然。”由是忌之。
原：武平二年，出俨居北宫，五日一朝，不復得毎日见太后。四月，诏除太保，餘官悉解，犹带中丞，督京畿。以北城有武库，欲移俨於外，然後夺其兵权。治书侍御史王子宜与俨左右开府高舍洛、中常侍刘辟疆说俨曰：“殿下被疏，正由士开间构，何可出北宫入百姓丛中也。”俨谓侍中冯子琮曰：“士开罪重，儿欲杀之。”子琮心欲废帝而立俨，因赞成其事。俨乃令子宜表弹士开罪，请付禁推。子琮杂以他文书奏之，後主不审省而可之。俨诳领军厍狄伏连曰：“奉敕令军收士开。”伏连以咨子琮，且请覆奏。子琮曰：“琅邪王受敕，何须重奏。”伏连信之，伏五十人於神兽门外，诘旦，执士开送御史。俨使冯永洛就臺斩之。
原：俨徒本意唯杀士开，及是，因逼俨曰：“事既然，不可中止。”俨遂率京畿军士三千餘人屯千秋门。帝使刘桃枝将禁兵八十人召俨。桃枝遥拜，俨命反缚，将斩之，禁兵散走。帝又使冯子琮召俨，俨辞曰：“士开昔来实合万死，谋废至尊，剃家家头使作阿尼，故拥兵马欲坐著孙凤珍宅上，臣为是矫诏诛之。尊兄若欲杀臣，不敢逃罪，若放臣，願遣姊姊来迎臣，臣即入见。”姊姊即陆令萱也，俨欲诱出杀之。令萱执刀帝後，闻之战栗。又使韩长鸾召俨，俨将入，刘辟疆牵衣谏曰：“若不斩提婆母子，殿下无由得入。”广寧、安德二王適从西来，欲助成其事，曰：“何不入？”辟疆曰：“人少。”安德王顾众而言曰：“孝昭帝杀杨遵彦，止八十人，今乃数千，何言人少？”後主泣启太后曰：“有缘更见家家，无缘永别。”乃急召斛律光，俨亦召之。光闻杀士开，抚掌大笑曰：“龙子作事，固自不似凡人。”入见後主於永巷。帝率宿卫者步骑四百，授甲将出战。光曰：“小儿辈弄兵，与交手即乱。鄙谚云‘奴见大家心死’，至尊宜自至千秋门，琅邪必不敢动。”皮景和亦以为然，後主从之。光步道，使人出曰：“大家来。”俨徒骇散。帝驻马桥上，遥呼之，俨犹立不进。光就谓曰：“天子弟杀一汉，何所苦。”执其手，强引以前。请帝曰：“琅邪王年少，肠肥脑满，轻为举措，长大自不復然，願宽其罪。”帝拔俨带刀环乱築辫头，良久乃释之。收伏连及高舍洛、王子宜、刘辟疆、都督翟显贵於後园，帝亲射之而後斩，皆支解，暴之都街下。文武职吏尽欲杀之。光以皆勋贵子弟，恐人心不安，赵彦深亦云《春秋》责帅，於是罪之各有差。俨之未获罪也，邺北城有白马佛塔，是石季龙为澄公所作，俨将修之。巫曰：“若动此浮图，北城失主。”不从，破至第二级，得白蛇长数丈，回旋失之，数旬而败。
原：自是太后处俨於宫内，食必自尝之。陆令萱说帝曰：“人称琅邪王聪明雄勇，当今无敌，观其相表，殆非人臣。自专杀以来，常怀恐惧，宜早为计。”何洪珍与和士开素善，亦请杀之。未决，以食舆密迎祖珽问之，珽称周公诛管叔，季友鸩庆父，帝纳其言。以俨之晋阳，使右卫大将军赵元侃诱执俨。元侃曰：“臣昔事先帝，日见先帝爱王，今寧就死，不能行。”帝出元侃为豫州刺史。九月下旬，帝启太后曰：“明旦欲与仁威出猎，须早出早还。”是夜四更，帝召俨，俨疑之。陆令萱曰：“兄兄唤，儿何不去？”俨出至永巷，刘桃枝反接其手。俨呼曰：“乞见家家、尊兄！”桃枝以袂塞其口，反袍蒙头负出，至大明宫，鼻血满面，立杀之，时年十四。不脱靴，裹以席，埋於室内。帝使启太后，临哭十餘声，便拥入殿。明年三月，葬於邺西，赠谥曰楚恭哀帝，以慰太后。有遗腹四男，生数月皆幽死。以平阳王淹孙世俊嗣。
原：俨妃，李祖钦女也，进为楚帝后，居宣则宫。齐亡，乃嫁焉。

# 齐安王廓
原：齐安王廓，字仁弘，武成第四子也。性长者，无过行。位特进、开府、仪同三司、定州刺史。

# 北平王贞
原：北平王贞，字仁坚，武成第五子也。沈审宽恕。帝常曰：“此儿得我凤毛。”位司州牧、京畿大都督，兼尚书令、录尚书事。帝行幸，总留臺事。积年，後主以贞长大，渐忌之。阿那肱承旨，令冯士幹劾繫贞於狱，夺其留後权。

# 高平王仁英
原：高平王仁英，武成第六子也。举止轩昂，精神无检格。位定州刺史。

# 淮南王仁光
原：淮南王仁光，武成第七子也。性躁且暴，位清都尹。次西河王仁幾，生而无骨，不自支持；次乐平王仁邕；次颍川王仁俭；次安乐王仁雅，从小有喑疾；次丹阳王仁直；次东海王仁谦。皆养於北宫。琅邪王死後，诸王守禁弥切。武平末年，仁邕已下始得出外，供给俭薄，取充而已。寻後主穷蹙，以廓为光州，贞为青州，仁英为冀州，仁俭为胶州，仁直为济州刺史。自廓已下，多与後主死於长安。仁英以清狂，仁雅以喑疾，获免，倶徙蜀。隋开皇中，追仁英，诏与萧琮、陈叔宝修其本宗祭礼。未幾而卒。

# 後主五男
原：後主五男：穆皇后生幼主，诸姬生东平王恪，次善德，次买德，次质钱。胡太后以恪嗣琅邪王，寻夭折。齐灭，周武帝以任城已下大小三十王归长安，皆有封爵。其後不从戮者散配西土，皆死边。

# 论
原：论曰：武成残忍姦秽，事极人伦。太原迹异猜嫌，情非衅逆，祸起昭信，遂及淫刑。嗟乎！欲求长世，未之有也。以孝昭德音，庶可庆流後嗣，百年之酷，盖济南之滥觞。其云“莫效前人”之言，可为伤叹，各爱其子，岂其然乎？琅邪虽无师傅之资，而早闻气尚。士开淫乱，多历岁年，一朝剿绝，庆集朝野，以之受毙，深可痛焉。然专戮之衅，未之或免，赠帝谥恭，矫枉过直，观过知仁，不亦异於是乎？
