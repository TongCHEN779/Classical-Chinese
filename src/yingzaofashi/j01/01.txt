# 宫
原：《易·系辞》：上古穴居而野处，后世圣人易之以宫室，上栋下宇，以待风雨。
原：《诗》：作于楚宫，揆之以日，作于楚室。
原：《礼》：儒一亩之宫，环堵之室。
原：《尔雅》：宫谓之室，室谓之宫。〈（皆所以通古今之异语，明同实而两名。）〉室有东西厢曰庙，〈（夹室前堂。）〉无东西厢有室曰寝。〈（但有大室。）〉西南隅谓之奥，〈（室中隐奥处。）〉西北隅谓之屋漏，〈（《诗》曰：尚不愧于屋漏，其义未详。）〉东北隅谓之宧，〈（宧见《礼》，亦未详。）〉东南隅谓之窔。〈（《礼》曰：归室聚窔。窔亦隐暗。）〉
原：《墨子》：子墨子曰：古之民未知为宫室，时就陵阜而居，穴而处，下润湿伤民。故圣王作为宫室之法曰：高足以辟润湿，旁足以圉风寒，上足以待霜雪雨露，宫墙之高足以别男女之礼。
原：《白虎通义》：黄帝作宫。
原：《世本》：禹作宫。
原：《说文》：宅，所托也。
原：《释名》：宫，穹也，屋见于垣上，穹崇然也。室，实也，言人物实满其中也。寝，寝也，所寝息也。舍，于中舍息也。屋，奥也，其中温奥也。宅，择也，择吉处而营之也。
原：《风俗通义》：自古宫、室一也。汉来尊者以为号，下乃避之也。
原：《义训》：小屋谓之廑，〈（音近）〉。深屋谓之庝，〈（音同）〉。偏舍谓之𢋃〈（音亶）〉𢋃谓之㢀〈（音次）〉，宫室相连谓之謻〈（直移切）〉，因岩成室谓之广，〈（音俨。）〉坏室谓之庘，〈（音压。）〉夹室谓之厢，塔下室谓之龛，龛谓之椌〈（音空）〉，空室谓之䆲䆡，〈（上音康，下音郎。）〉深谓之㽎㽎，〈（音耽。）〉颓谓之批甫，〈（上音批，下音甫。）〉不平谓之庯庩。〈（上音逋，下音途。）〉

# 阙
原：《周官》：太宰以正月示治法于象魏。
原：《春秋公羊传》：天子诸侯台门。天子外阙两观，诸侯内阙一观。
原：《尔雅》：观谓之阙。〈（宫门双阙也。）〉
原：《白虎通义》：门必有阙者何？阙者，所以释门别尊卑也。
原：《风俗通义》：鲁昭公设两观于门，是谓之阙。
原：《说文》：阙门观也。
原：《释名》：阙，阙也，在门两旁中央阙然为道也。观，观也，于上观望也。
原：《博雅》：象魏，阙也。
原：崔豹《古今注》：阙，观也。古者每门树两观于前，所以标表宫门也。其上可居，登之可远观，人臣将朝，到此则思其所阙，故谓之阙。其上皆垩土，其下皆画云气、仙灵、奇禽、怪兽，以示四方。苍龙、白虎、玄武、朱雀，并画其形。
原：《义训》：观谓之阙，阙谓之皇。

# 殿
原：〈（堂附）〉
原：《苍颉篇》：殿，大堂也。〈（徐坚注云：商周以前其名不载，〈秦本纪〉始曰作前殿。）〉
原：《周官考工记》夏后氏世室，堂修二七，广四修一。商人重屋，堂修七寻，堂崇三尺。周人明堂，东西九筵，南北七筵，堂崇一筵。〈（郑司农注云：修，南北之深也。夏度以步，今堂修十四步，其广益以四分修之一，则堂广十七步半。商度以寻，周度以筵，六尺曰步，八尺曰寻，九尺曰筵。）〉
原：《礼记》：天子之堂九尺，诸侯七尺，大夫五尺，士三尺。
原：《墨子》：尧、舜堂高三尺。
原：《说文》：堂，殿也。
原：《释名》：堂犹堂堂，高显貌也。殿，殿鄂也。
原：《尚书大传》：天子之堂高九雉，公侯七雉，子男五雉。〈（雉长三尺。）〉
原：《博雅》：堂堭，殿也。
原：《义训》：汉曰殿，周曰寝。

# 楼
原：《尔雅》：狭而修曲曰楼。
原：《淮南子》：延楼栈道，鸡栖井幹。
原：《史记》：方士言于武帝曰，黄帝为五城十二楼，以候神人。帝乃立神台井幹楼，高五十丈。
原：《说文》：楼，重屋也。
原：《释名》楼，谓牖户之间有射孔㥪㥪然也。

# 亭
原：《说文》：亭，民所安定也。亭有楼，从高省，从丁声也。
原：《释名》：亭，停也，人所亭集也。
原：《风俗通义》：谨按，春秋国语有寓望，谓今亭也。汉家因秦，大率十里一亭。亭，留也。今语有亭留、亭待，盖行旅宿食之所馆也。亭亦平也，民有讼诤，吏留辨处勿失其正也。

# 台榭
原：《老子》：九层之台，起于累土。
原：《礼记·月令》：五月，可以居高明，可以处台榭。
原：《尔雅》：无室曰榭。〈（榭即今堂堭。）〉
原：又：观四方而高曰台，有木曰榭。〈（积土四方者。）〉
原：《汉书》：坐皇堂上。〈（室而无四壁曰皇。）〉
原：《释名》：台，持也，筑土坚高，能自胜持也。

# 城
原：《周官·考工记》：匠人营国，方九里，旁三门。国中九经九纬，经涂九轨。王宫门阿之制五雉，宫隅之制七雉，城隅之制九雉。〈（国中，城内也。经纬，涂也。经纬之涂皆容方九轨。轨谓辙广，凡八尺，九轨箦七十二尺，雉长三丈，高一丈，度高以高，度广以广。）〉
原：《春秋·左氏传》：计丈尺、揣高卑、度厚薄、仞沟洫，物土方、议远迩、量事期、计徒庸、虑材用、书糇粮以令役，此筑城之义也。
原：《公羊传》：城雉者何？五版而堵，五堵而雉，百雉而城。〈（天子之城千雉，高七雉，公侯百雉，高五雉；子男五十雉，高三雉。）〉
原：《礼记·月令》：每岁孟秋之月补城郭，仲秋之月筑城郭。
原：《管子》：内之为城，外之为郭。
原：《吴越春秋》：鮌越筑城以卫君，造郭以守民。
原：《说文》：城以盛民也。墉，城垣也，堞，城上女垣也。
原：《五经异义》：天子之城高九仞，公侯七仞，伯五仞，子男三仞。
原：《释名》：城，盛也，盛受国都也。郭，廓也，廓落在城外也。城上垣谓之睥睨，言于孔中睥睨非常也。亦曰陴，言陴助城之高也。亦曰女墙，言其卑小，比之于城，若女子之于丈夫也。
原：《博物志》：禹作城，强者攻，弱者守，敌者战。城郭自禹始也。

# 墙
原：《周官·考工记》：匠人为沟洫，墙厚三尺，崇三之。〈（高厚以是为率，足以相胜。）〉
原：《尚书》：既勤坦墉。
原：《诗》：崇墉屹屹。
原：《春秋左氏传》：有墙以蔽恶。
原：《尔雅》：墙谓之墉。
原：《淮南子》：舜作室，筑墙茨屋，令人皆知去岩穴。各有室家，此其始也。
原：《说文》：堵，垣也。五版为一堵。㙩，周垣也。埒，卑垣也。壁，垣也。垣蔽曰墙。栽，筑墙长版也。〈（今谓之膊版。）〉干，筑墙端木也。〈（今谓之墙师。）〉
原：《尚书大传》：天子贲墉，诸侯疏杼。〈（贲，大也，言大墙正道直也。疏，犹衰也。杼亦墙也。言衰杀其上，不得正直。）〉
原：《释名》：墙，障也，所以自障蔽也。垣，援也，人所依止以为援卫也。墉，容也，所以隐蔽形容也。壁，辟也，所以辟御风寒也。
原：《博雅》：㙩、〈（力雕切。）〉䧘〈（音篆。）〉墉、院、〈（音桓。）〉廦、〈（音壁，又即壁反。）〉墙，垣也。
原：《义训》：㡯〈（音乇。）〉楼墙也。穿垣谓之𤗇，音空。为垣谓之厽。〈（音累。）〉周谓之㙩，〈（音了。）〉㙩谓之𥦺〈（音垣）〉。

# 柱础
原：《淮南子》：山云蒸，柱础润。
原：《说文》：𬃊，〈（之日切。）〉柎也。柎，阑足也。榰，〈（章移切。）〉柱砥也。古用木，今以石。
原：《博雅》：础、磶、〈（音昔。）〉磌，〈（音真，徒年切。）〉礩也。镵〈（音谗）〉谓之铍。〈（音披。）〉镌〈（醉全切，又予兖切。）〉谓之錾。惭敢切。
原：《义训》：础谓之磩，〈（仄六切。）〉磩谓之礩，礩谓之磶，磶谓之磉。〈（音颡，今谓之石锭。音顶。）〉

# 定平
原：《周官·考工记》：匠人建国，水地以垂。〈（于四角立植而垂，以水望其高下，高下既定，乃为位而平地。）〉
原：《庄子》：水静则平，中准，大匠取法焉。
原：《管子》：夫准坏险以为平。

# 取正
原：《诗》：定之方中，又：揆之以日。定，营室也。方中，昏正四方也。揆，度也。度日出日入，以知东西。南视定，北准极，以正南北。）
原：《周礼·天官》：惟王建国，辨方正位。
原：《考工记》：置𣙗以垂，视以景，为规识日出之景与日入之景；夜考之极星，以正朝夕。〈（自日出而画其景端，以至日入既，则为规，测景两端之内规之，规之交乃审也。度两交之间，中屈之以指𣙗，则南北正。日中之景最短者也。极星谓北辰。）〉
原：《管子》：夫绳扶拨以为正。
原：《字林》槫，〈（时钏切。）〉垂臬望也。
原：《刊谬正俗音字》：今山东匠人犹言垂绳视正为槫也。

# 材
原：《周礼》：任工以饬材事。
原：《吕氏春秋》：夫大匠之为宫室也，景小大而知材木矣。
原：《史记》：山居千章之楸。〈（章，材也。）〉
原：班固《汉书》：将作大匠属官有主章长丞。〈（旧将作大匠主材吏名章曹椽。）〉
原：又〈西都赋〉：因瓌材而究奇。
原：弁兰《许昌宫赋》：材靡隐而不华。
原：《说文》：𣙗，刻也。𣙗音至。
原：《传子》：构大厦者先择匠而后简材。（今或谓之方桁。桁音衡。按：构屋之法，其规矩制度皆以章𣙗为祖。今语以人举止失措者谓之失章失𣙗，盖此也。

# 栱
原：《尔雅》閞谓之槉。（柱上欂也。亦名枅，又曰㭼。閞音弁，槉音疾。
原：《苍颉篇》：枅柱上方木。
原：《释名》：栾，挛也，其体上曲，挛拳然也。
原：王延寿《鲁灵光殿赋》：曲枅要绍而环句。（曲枅栱也。
原：《博雅》：欂谓之枅曲枅谓之挛。〈（枅音古妍切。又间鸡。）〉
原：薛综《西京赋》注：栾，柱上曲木，两头受栌者。
原：左思《吴都赋》雕栾镂楶。〈（栾栱也）〉。

# 飞昂
原：《说文》：櫼，楔也。
原：何晏《景福殿赋》：飞昂鸟踊。
原：又：櫼栌角落以相承。〈（李善曰：飞昂之形类鸟之飞。今人名屋四阿栱曰櫼昂，櫼即昂也。）〉
原：刘梁《七举》：双覆井菱，荷垂英昂。
原：《义训》：斜角谓之飞㭿。（今谓之下昂者，以昂尖下指故也。下昂尖䫜下平。又有上昂，如昂桯挑斡者，施之于屋内，或平坐之下。昂字又作枊，或作㭿者，皆吾郎切。䫜，于交切，俗作凹者非是。

# 爵头
原：《释名》上入曰爵头，形似爵头也。〈（今俗谓之耍头，又谓之胡孙头。朔方人谓之𧋢䗥头。𧋢音勃，䗥音纵。）〉

# 枓
原：《论语》：山节藻棁。〈（节，栭也。）〉
原：《尔雅》：栭谓之楶。〈（即栌也。）〉
原：《说文》：栌，柱上柎也。栭，枅上标也。
原：《释名》：卢在柱端，都卢负屋之重也。枓在栾两头，如斗，负上檼也。
原：《博雅》：楶谓之栌。〈（节楶，古文通用。）〉
原：《鲁灵光殿赋》：层栌磥佹以岌峨。〈（栌枓也。）〉
原：《义训》柱斗谓之㭼。〈（音沓。）〉

# 铺作
原：汉《柏梁诗》：大匠曰：柱枅欂栌相支持。
原：《景福殿赋》：桁梧复叠，势合形离。〈（桁梧，枓栱也，皆重叠而施，其势或合或离。）〉又櫼栌各落以相承，栾栱夭蟜而交结。
原：徐陵《太极殿铭》：千栌赫奕，万栱崚层。
原：李白《明堂赋》：走栱夤缘。
原：李华《含元殿赋》：云薄万栱。
原：又悬栌骈凑。〈（今以枓栱层数相叠出跳多寡次序谓之铺作。）〉

# 平坐
原：张衡《西京赋》阁道穹隆。〈（阁道，飞陛也。）〉又隥道逦倚以正东。〈（隥道阁道也。）〉
原：《鲁灵光殿赋》：飞陛揭孽，缘云上征，中坐垂景，俯视流星。
原：《义训》，阁道谓之飞陛，飞陛谓之墱。〈（今俗谓之平坐，亦曰鼓坐。）〉

# 梁
原：《尔雅》：杗廇谓之梁。〈（屋大梁也。杗武方切。廇，力又切。）〉
原：司马相如《长门赋》：委参差以糠梁〈（糠虚也。）〉
原：《西都赋》抗应龙之虹梁〈（梁曲如虹也。）〉
原：《释名》：梁，强梁也。何晏《景福殿赋》：双枚既修。〈（两重作梁也。）〉又：重桴乃饰。〈（重桴，在外作两重牵也。）〉
原：《博雅》：曲梁谓之𦊑。〈（音柳。）〉
原：《义训》：梁谓之欐。〈（音礼。）〉

# 柱
原：《诗》：有觉其楹。
原：《春秋·庄公》丹桓宫楹。礼：楹，天子丹，诸侯黝，大夫苍，士黈。〈（黈，黄色也。）〉又：三家视桓楹〈（柱曰植曰桓。）〉
原：《西京赋》：雕玉瑱以居楹。〈（瑱，音镇。）〉
原：《说文》：楹，柱也。
原：《释名》：柱，住也。楹，亭也，亭亭然孤立旁无所依也。齐鲁读曰轻。轻，胜也，孤立独处，能胜任上重也。
原：何晏《景福殿赋》：金楹齐列，玉舄承跋。〈（玉为矴以承柱下。跋，柱根也。）〉

# 阳马
原：《周官·考工记》：殷人四阿重屋。〈（四阿，若今四注屋也。）〉
原：《尔雅》：直不受檐谓之交。（谓五架屋际，椽不直上檐，交于檼上。
原：《说文》：柧棱，殿堂上最高处也。
原：何晏《景福殿赋》：承以阳马。〈（阳马，屋四角引出以承短椽者。）〉
原：左思《魏都赋》：齐龙首以涌霤。〈（屋上四角雨水入龙口中，泻之于地也。）〉
原：张景阳《七命》：阴虬负檐，阳马翼阿。
原：《义训》：阙角谓之柧棱。〈（今俗谓之角梁。又谓之梁抹者，盖语讹也。）〉

# 侏儒柱
原：《论语》：山节藻棁。
原：《尔雅》梁上楹谓之棁〈（侏儒柱也。）〉
原：扬雄《甘泉赋》：抗浮柱之飞榱。〈（浮柱，即梁上柱也。）〉
原：《释名》：棳，棳儒也，梁上短柱也。棳儒犹侏儒，短故因以名之也。
原：《鲁灵光殿赋》：胡人遥集于上楹。〈（今俗谓之蜀柱。）〉

# 斜柱
原：《长门赋》离楼梧而相樘。〈（丑庚切。）〉
原：《说文》：樘，邪柱也。
原：《释名》：忤在梁上，两头相触牾也。
原：《鲁灵光殿赋》：枝樘杈枒而斜据。〈（枝樘，梁上交木也。杈枒相柱而斜据其间也。）〉
原：《义训》：斜柱谓之梧。〈（今俗谓之义手。）〉
