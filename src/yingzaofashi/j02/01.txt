# 栋
原：《易》：栋隆，吉。
原：《尔雅》：栋谓之桴。〈（屋檼也。）〉
原：《仪礼》：序则物当栋，堂则物当楣。〈（是制五架之屋也。正中曰栋，次曰楣，前曰庋。九伪切，又九委切。）〉
原：《西都赋》：列棼橑以布翼，荷栋桴而高骧〈（棼、桴，皆栋也。）〉
原：扬雄《方言》：甍谓之霤。〈（即屋檼也。）〉
原：《说文》，极，栋也。栋，屋极也。檼，棼也。甍，屋栋也。〈（徐锴曰；所以承瓦，故从瓦。）〉
原：《释名》：檼，隐也，所以隐桷也。或谓之望，言高可望也。或谓之栋。栋，中也，居屋之中也。屋脊曰甍。甍，蒙也，在上蒙覆屋也。
原：《博雅》檼，栋也。
原：《义训》：屋栋谓之甍。〈（今谓之槫，亦谓之檩，又谓之櫋。）〉

# 两际
原：《尔雅》：桷直而遂谓之阅。〈（谓五架屋际椽相正当。）〉
原：《甘泉赋》：日月才经于柍桭。〈（柍，于两切。桭音真。）〉
原：《义训》：屋端谓之柍桭。〈（今谓之废。）〉

# 搏风
原：《仪礼》：直于东荣。〈（荣，屋翼也。）〉
原：《甘泉赋》：列宿乃施于上荣。
原：《说文》：屋梠之两头起者为荣。
原：《义训》：搏风谓之荣。〈（今谓之搏风版。）〉

# 柎
原：《说文》：棼，复屋栋也。
原：《鲁灵光殿赋》：狡兔跧伏于柎侧。〈（柎，枓上横木，刻兔形，致木于背也。）〉
原：《义训》：复栋谓之棼。〈（今俗谓之替木。）〉

# 椽
原：《易》：鸿渐于木，或得其桷。
原：《春秋左氏传》：桓公伐郑，以大宫之椽为卢门之椽。
原：《国语》：天子之室，斲其椽而砻之，加密石焉。诸侯砻之，大夫斲之，士首之。〈（密，细密文理。石谓砥也。先粗砻之，加以密砥。首之，斲斲首也。）〉
原：《尔雅》：桷谓之榱。〈（屋椽也。）〉
原：《甘泉赋》：琁题玉英。〈（题，头也。榱椽之头皆以玉饰。）〉
原：《说文》：秦名为屋椽，周谓之榱，齐鲁谓之桷。
原：又：椽方曰桷，短椽谓之梀。〈（耻绿切。）〉
原：《释名》：桷，确也，其形细而疏确也。或谓之椽。椽，传也，传次而布列之也。或谓之榱，在檼旁下列，衰衰然垂也。
原：《博雅》：榱、橑、〈（鲁好切。）〉桷、梀，椽也。
原：《景福殿赋》：爰有禁楄，勒分翼张。〈（禁楄，短椽也。楄，蒲沔切。）〉
原：陆德明《春秋左氏传音义》：圜曰椽。

# 檐
原：〈（馀廉切。或作櫩。俗作檐者非是。）〉
原：《易·系辞》上栋下宇，以待风雨。
原：《诗》：如跂斯翼，如矢斯棘，如鸟斯革，如翚斯飞。〈（疏云：言檐阿之势，似鸟飞也。翼言其体，飞言其势也。）〉
原：《尔雅》：檐谓之樀〈（屋梠也。）〉
原：《礼》：复廇重檐，天子之庙饰也。
原：《仪礼》：宾升，主人阼阶上，当楣。〈（楣，前梁也。）〉
原：《淮南子》：橑檐榱题。〈（檐，屋垂也。）〉
原：《方言》：屋梠谓之棂。〈（即屋檐也。）〉
原：《说文》：秦谓屋联櫋曰楣，齐谓之檐，楚谓之梠橝，〈（徒含切。）〉屋梠前也。庌，〈（音雅）〉庑也。宇，屋边也。
原：《释名》：楣，眉也，近前若面之有眉也。又曰：梠，梠旅也，连旅旅也。或谓之槾。槾，绵也，绵连榱头，使齐平也。宇，羽也，如鸟羽自蔽覆者也。
原：《西京赋》：飞檐䡾䡾。
原：又：镂槛文㮰。〈（㮰，连檐也。）〉
原：《景福殿赋》：㮰梠椽櫋。〈（连檐木，以承瓦也。）〉
原：《博雅》：楣、檐、棂，梠也。
原：《义训》屋垂谓之宇，宇下谓之庑，步檐谓之廊，嵏廊谓之岩，檐㮰谓之庮。〈（音由。）〉

# 举折
原：《周官·考工记》匠人为沟洫，葺屋三分，瓦屋四分。〈（各分其修，以其一为峻。）〉
原：《通俗文》：屋上平曰陠〈（必孤切。）〉
原：《刊谬正俗音字》：陠，今犹言陠峻也。
原：唐柳宗元《梓人传》：昼宫于堵，盈尺而曲尽其制，计其毫厘而构大厦，无进退焉。
原：皇朝景文公宋祁《笔录》：今造屋有曲折者谓之庯峻。齐魏间以人有仪矩可喜者谓之庯峭，盖庯峻也。〈（今谓之举折。）〉

# 门
原：《易》：重门击柝，以待暴客。
原：《诗》：衡门之下，可以栖迟。又：乃立皋门，皋门有闶；乃立应门，应门锵锵。
原：《诗义》：横一木作门，而上无屋，谓之衡门。
原：《春秋左氏传》：高其闬闳。
原：《公羊传》：齿著于门阖。〈（何休云阖扇也。）〉
原：《尔雅》：闬谓之门，正门谓之应门。柣谓之阈，（阈，门限也。疏云：俗谓之地柣。〈（十结切。）〉枨谓之楔，〈（门两旁木。李巡曰：梱上两旁木。）〉楣谓之梁，〈（门户上横木。）〉枢谓之椳。〈（门户扉枢。）〉枢达北方谓之落时，〈（门持枢者，或达北檼，以为固也。）〉落时谓之厄〈（道二名也。）〉。橛谓之𫔶，〈（门阃。）〉阖谓之扉，所以止扉谓之闳。〈（门辟旁长橛也。长杙即门橛也。）〉植谓之傅，傅谓之突。〈（户持鏁植也。见埤苍。）〉
原：《说文》：阁，门旁户也。闺，持立之门，上圜下方，有似圭。
原：《风俗通义》：门户铺首。昔公输班之水，见蠡曰，见汝形。蠡适出头，般以足昼图之，蠡引闭其其户，终不可得开，遂施之于门户，云人闭藏如是，固周密矣。
原：《博雅》闼谓之门。䦏，〈（呼计切。）〉扇扉也。限谓之丞。橛〈（巨月切。）〉机，𫔶𣏔〈（苦木切。）〉也。
原：《释名》：门，扪也，在外为人所扪摸也。户，护也，所以谨护闭塞也。
原：《声类》曰庑，堂下周屋也。
原：《义训》：门饰金谓之铺，铺谓之鏂。〈（音欧。今俗谓之浮沤钉也。）〉门持关谓之摙〈（音连）〉户版谓之𥳐䉳。〈（上音牵，下音先。）〉门上木谓之枅。扉谓之户，户谓之䦏。臬谓之柣。限谓之阃，阃谓之阅。闳谓之扊扅，〈（上音琰，下音移。）〉扊扅谓之䦔。（音坦。广韵曰：所以止扉。门上梁谓之𣔺，〈（音帽。）〉𣔺谓之阘。〈（音沓。）〉键谓之㧀〈（音及。）〉开谓之䦱。〈（音伟。）〉阖谓之𨸅。〈（音蛭。）〉外关谓之扄，外启谓之閮〈（音挺。）〉，门次谓之𨷓。高门谓之𨶈〈（音唐。）〉；𨶈谓之阆。荆门谓之荜。石门谓之庯。〈（音孚。）〉

# 乌头门
原：《唐六典》：六品以上仍通用乌头大门。
原：唐上官仪《投壶经》：第一箭入谓之初箭，再入谓之乌头，取门双表之义。
原：《义训》：表楬，阀阅也。〈（楬音竭。今呼为棂星门。）〉

# 华表
原：《说文》：桓，亭邮表也。
原：《前汉书》注：旧亭传于四角面百步筑土四方，上有屋，屋上有柱，出高丈馀，有大版贯柱四出，名曰桓表。县所治夹两边各一桓。陈宋之俗言桓声如和，今犹谓之和表。颜师古云，即华表也。
原：崔豹《古今注》：程雅问曰，尧设诽谤之木何也？答曰，今之华表。以横木交柱头，状如华，形似桔槔，大路交衢悉施焉，或谓之表木，以表王者纳谏，亦以表识衢路。秦乃除之，汉始复焉。今西京谓之交午柱。

# 窗
原：《周官·考工记》：四旁两夹窗。〈（窗，助户为明。每室四户八窗也。）〉
原：《尔雅》：牖户之间谓之扆。〈（窗东户西也。）〉
原：《说文》：窗穿壁，以木为交窗，向北出牖也。在墙曰牖，在屋曰窗。棂，楯间子也。栊，房室之处也。
原：《释名》：窗，聪也，于内窥见外为聪明也。
原：《博雅》：窗牖，𨷿〈（虚谅切。）〉也。
原：《义训》：交窗谓之牖，棂窗谓之疏，牖牍谓之篰〈（音部。）〉绮窗谓之廲〈（音黎）〉廔〈（音娄）〉。房疏谓之栊。

# 平棋
原：《史记》：汉武帝建章后阁平机中有驺牙出焉。〈（今本作平乐者误。）〉
原：《山海经图》：作平橑，云今之平棋也。〈（古谓之承尘。今宫殿中其上悉用草架梁栿承屋盖之重，如攀额、樘柱、敦㮇、方槫之类，及纵横固济之物，皆不施斤斧。于明栿背上架算桯方，以方椽施版，谓之平暗，以平版贴华谓之平棋。俗亦呼为平起者，语讹也。）〉

# 斗八藻井
原：《西京赋》：蒂倒茄于藻井，披红葩之狎猎。〈（藻井当栋中，交木如井，画以藻文，饰以莲茎，缀其根于井中，其华下垂，故云倒也。）〉
原：《鲁灵光殿赋》：圜渊方井，反植荷蕖。〈（为方井，图以圜渊及芙蓉。华叶向下，故云反植。）〉
原：《风俗通义》：殿堂象东井形，刻作荷蔆。蔆，水物也，所以厌火。
原：沈约《宋书》：殿屋之为圜泉、方井兼荷华者，以厌火祥。〈（今以四方造者谓之斗四。）〉

# 钩阑
原：《西都赋》：舍棂槛而却倚，若颠坠而复稽。
原：《鲁灵光殿赋》：长途升降，轩槛曼延。〈（轩槛，钩阑也。）〉
原：《博雅》：阑、槛、栊、梐，牢也。
原：《景福殿赋》：棂槛邳张，钩错矩成，楯类腾蛇，槢以琼英，如螭之蟠，如虬之停。〈（棂槛，钩阑也。言钩阑中错为方斜之文。楯，钩阑上横木也。）〉
原：《汉书》：朱云忠谏，攀槛，槛折。及治槛，上曰：勿易，因而辑之，以旌直臣。〈（今殿钩阑当中两栱不施寻杖，谓之折槛，亦谓之龙池。）〉
原：《义训》：阑楯谓之柃，阶槛谓之阑。

# 拒马叉子
原：《周礼·天官》：掌舍设梐枑再重。〈（故书枑为拒。郑司农云：梐，榱梐也。拒受居溜水涑橐者也。）〉行马再重者，以周卫有内外列。〈（杜子春读为梐枑，谓行马者也。）〉
原：《义训》：梐枑，行马也。〈（今谓之拒马叉子。）〉

# 屏风
原：《周礼》：掌次设皇邸。〈（邸，后版也。谓后版屏风与染羽象凤凰羽色以为之。）〉
原：《礼记》：天子当扆而立。又天子负扆南乡而立。〈（扆，屏风也。斧扆为斧文屏风于户牖之间。）〉
原：《尔雅》：牖户之间谓之扆，其内谓之家。〈（今人称家，义出于此。）〉
原：《释名》：屏风，可以障风也。扆，倚也，在后所依倚也。

# 槏柱
原：《义训》：牖边柱谓之槏。〈（若减切。今梁或额槫及之下施柱以安门窗者，谓之{存心}柱，盖语讹也。{存心}，俗音蘸，字书不载。）〉

# 露篱
原：《释名》：㰚，离也，以柴竹作之，疏离离也。青徐曰裾。裾，居也，居其中也。栅，迹也，以木作之，上平，迹然也。又谓之撤。撤，紧也，诜诜然紧也。
原：《博雅》：据、〈（巨于切。）〉栫、〈（在见切。）〉藩、筚〈（音必）〉椤、落，〈（音落。）〉杝离也。栅谓之㮶。〈（音朔。）〉
原：《义训》：篱谓之藩〈（今谓之露篱。）〉

# 鸱尾
原：《汉纪》：柏梁殿灾后，越巫言，海中有鱼，虬尾似鸱，激浪即降雨。遂作其象于屋，以厌火祥。时人或谓之鸱吻，非也。
原：《谭宾录》：东海有鱼，虬尾似鸱，鼓浪即降雨，遂设象于屋脊。

# 瓦
原：《诗》：乃生女子，载弄之瓦。
原：《说文》：瓦，土器已烧之总名也。旊，周家塼埴之工也。〈（旊分两切。）〉
原：《古史考》：昆吾氏作瓦。
原：《释名》：瓦，踝也。踝，确坚貌也。亦言腂也，在外腂见之也。
原：《博物志》：桀作瓦。
原：《义训》：瓦谓之㽇〈（音觳）〉，半瓦谓之㼪〈（音浃）〉，㼪谓之㼽〈（音爽）〉。牝瓦谓之瓪〈（音版）〉，瓪谓之㡲〈（音还）〉。牡瓦谓之𤭧〈（音皆）〉，𤭧谓之𤮚〈（音雷）〉。小瓦谓之𤮏〈（音横）〉。

# 涂
原：《尚书·梓材篇》：若作室家，既勤垣墉，唯其涂塈茨。
原：《周官·守祧》：其祧，则守祧黝垩之。
原：《诗》：塞向墐户。〈（墐，涂也。）〉
原：《论语》：粪土之墙，不可杇也。
原：《尔雅》：镘谓之杇，地谓之黝，墙谓之垩。〈（泥镘也，一名杇，涂工之作具也。以黑饰地谓之黝，以白饰墙谓之垩。）〉
原：《说文》：垷〈（胡典切。）〉墐〈（渠吝切。）〉涂也。杇，所以涂也。秦谓之杇，关东谓之槾。
原：《释名》：泥，迩近也，以水沃土，使相黏近也。塈犹煟，煟，细泽貌也。
原：《博雅》：黝、垩、〈（乌故切。）〉垷〈（岘又胡典切。）〉墐、墀、塈、𢅼、〈（奴回切。）〉𡔆、〈（力奉切。）〉𥻇、〈（古湛切。）〉塓、〈（莫典切。）〉培，〈（音裴）〉封涂也。
原：《义训》涂谓之塓，〈（音觅）〉塓谓之𡔆。〈（音垅）〉仰涂谓之塈。〈（音洎。）〉

# 彩画
原：《周官》：以猷鬼神祇。〈（猷，谓图画也。）〉
原：《世本》：史皇作图。〈（宋衷曰：史皇，黄帝臣。图，谓图画形象也。）〉
原：《尔雅》：猷，图也，画形也。
原：《西京赋》：绣栭云楣，镂槛文㮰。〈（五臣曰：画为绣云之饰。㮰，连檐也。皆饰为文彩。）〉故其馆室次舍彩饰纤缛，裛以藻绣，文以朱绿。〈（馆室之上，缠饰藻绣朱绿之文。）〉
原：《吴都赋》：青琐丹楹，图以云气画以仙灵。〈（青琐，画为琐文，染以青色，及画云气神仙、灵奇之物。）〉
原：谢赫《画品》夫图者，画之权舆；缋者，画之末迹，总而名之为画。仓颉造文字，其体有六：一曰鸟书，书端象鸟头，此即图画之类，尚标书称，未受画名。逮史皇作图。犹略体物；有虞作缋，始备象形。今画之法，盖兴于重华之世也。穷神测幽，于用甚博。〈（今以施之于缣素之类者谓之画；布彩于梁栋枓栱或素象什么物之类者，俗谓之装鉴，以粉朱丹三色为屋宇门窗之饰者，谓之刷染。）〉

# 阶
原：《说文》除，殿阶也，阶，陛也。阼，主阶也。陛，升高阶也。陔，阶次也。
原：《释名》：阶，陛也，陛，卑也。有高卑也。天子殿谓之纳陛，以纳人之言也。阶，梯也，如梯有等差也。
原：《博雅》：戺〈（仕已切。）〉橉，〈（力忍切。）〉砌也。
原：《义训》：殿基谓之隚〈（音堂。）〉殿阶次序谓之陔。除谓之阶，阶谓之墒。〈（音的。）〉阶下齿谓之墄〈（七仄切。）〉东阶谓之阼。霤外砌谓之戺。

# 塼

# 井
原：《周书》：黄帝穿井。
原：《世本》：化益作井。〈（宋衷曰：化益伯益也。尧臣。）〉
原：《易传》：井，通也，物所通用也。
原：《说文》：甃，井壁也。
原：《释名》：井，清也，泉之清洁者也。
原：《风俗通义》：井者，法也，节也，言法制居人，令节其饮食，无穷竭也。以不渫涤为井泥。〈（《易》云：井泥不食。渫息列切。）〉不停污曰井渫，涤井曰浚。井水清曰冽。〈（《易》曰：井渫不食。又曰：井冽寒泉。）〉

# 总例
原：诸取圜者以规，方者以矩，直者抨绳取则，立者垂绳取正，横者定水取平。诸径围斜长依下项：圜径七，其围二十有二。
原：方一百，其斜一百四十有一。八棱径六十，每面二十有五，其斜六十有五。六棱径八十有七，每面五十，其斜一百。圜径内取方，一百中得七十一。
原：方内取圜，径一得一。〈（八棱、六棱取圜准此。）〉诸称广厚者，谓熟材。称长者，皆别计出卯。
原：诸称长功者，谓四月、五月、六月、七月；中功谓二月、三月、八月、九月；短功谓十月、十一月、十二月正月。
原：诸称功者谓中功，以十分为率。长功加一分，短功减一分。诸式内功限并以军工计定。若和雇人造作者，即减军工三分之一。〈（谓如军工应计三功，即和雇人计二功之类。）〉
原：诸称本功者，以本等所得功十分为率。诸称增高广之类而加功者，减亦如之。诸功称尺者，皆以方计。若土功或材木，则厚亦如之。
原：诸造作功并以生材。即名件之类或有收旧及已造堪就用而不须更改者，并计数于元料账内除豁。
原：诸造作并依功限。即长广各有增减法者，各随所用细计；如不载增减者，各以本等合得功限内计分数增减。
原：诸营缮计料，并于式内指定一等，随法算计。若非泛抛降或制度有异，应与式不同及该载不尽名色等第者，并比类增减。〈（其完葺增修之类准此。）〉
