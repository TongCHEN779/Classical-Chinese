# 本门导读
题解：“方正”说的是立身端直、守礼不阿。本门所记多是魏晋士人面对权势、亲故乃至帝王时不肯曲从的言行，或刚烈，或冷峭，或以一句话守住分寸。

# 一｜陈太丘与友期行
原：陈太丘与友期行，期日中。过中不至，太丘舍去，去后乃至。元方时年七岁，门外戏。客问元方：“尊君在不？”答曰：“待君久不至，已去。”友人便怒，曰：“非人哉！与人期行，相委而去。”元方曰：“君与家君期日中。日中不至，则是无信；对子骂父，则是无礼。”友人惭，下车引之，元方入门不顾。|| 陈寔和朋友约好一同出行，说定正午动身。过了正午朋友还没来，陈寔便不再等，自己走了，走后那人才到。陈纪当时七岁，正在门外玩耍。客人问他：“你父亲在家吗？”陈纪答：“等您许久不来，已经先走了。”那人便发起火来：“真不是人！跟别人约好同行，却丢下人自己走了。”陈纪说：“您和我父亲约在正午。正午不到，是不守信；当着儿子骂他父亲，是没有礼貌。”那人羞愧，下车来拉他，陈纪径自走进家门，头也不回。
注：陈太丘：陈寔，东汉颍川许县人，做过太丘县长，世称陈太丘。
注：期行：约定时间同行。
注：日中：正午。
注：元方：陈纪，字元方，陈寔长子，以德行孝友著称。
注：尊君：对他人父亲的敬称；
注：家君：对人称自己的父亲。
注：委：丢下。

# 二｜南阳宗世林
原：南阳宗世林，魏武同时，而甚薄其为人，不与之交。及魏武作司空，总朝政，从容问宗曰：“可以交未？”答曰：“松柏之志犹存。”世林既以忤旨见疏，位不配德。文帝兄弟每造其门，皆独拜床下。其见礼如此。|| 南阳人宗世林和曹操是同时代的人，很看不起曹操的为人，不肯和他结交。等到曹操做了司空，总揽朝政，闲谈时问宗世林：“现在可以交个朋友了吧？”宗世林答：“我那松柏般的心志还在。”宗世林因违逆曹操的意思被冷落，官位与他的德望很不相称。可是曹丕兄弟每次登门，都要单独在他坐榻前下拜。他受人敬重竟到这种程度。
注：宗世林：宗承，字世林，南阳人，以德行知名，曾拒绝曹操结交。
注：魏武：曹操，死后追尊为魏武帝。
注：司空：三公之一。
注：松柏之志：松柏经冬不凋，喻坚守节操、不随时势改变。
注：文帝兄弟：曹丕、曹植等。
注：床：坐榻。

# 三｜魏文帝受禅
原：魏文帝受禅，陈群有戚容。帝问曰：“朕应天受命，卿何以不乐？”群曰：“臣与华歆服膺先朝，今虽欣圣化，犹义形于色。”|| 魏文帝曹丕接受汉献帝禅让登基，陈群脸上却带着哀伤。文帝问他：“朕顺应天命登位，你为什么不高兴？”陈群答：“臣和华歆都曾真心侍奉前朝，如今虽然为陛下的圣明教化而欢喜，对旧主的情义还是不由得流露在脸上。”
注：受禅：接受前朝皇帝让出的帝位。公元220年曹丕代汉称帝。
注：陈群：陈寔之孙，曹魏重臣，官至司空。
注：华歆：汉末魏初名臣，入魏官至司徒。
注：服膺：衷心信奉、牢记。
注：先朝：指汉朝。
注：义形于色：对旧主的情义表现在脸上。

# 四｜郭淮作关中都督
原：郭淮作关中都督，甚得民情，亦屡有战庸。淮妻，太尉王凌之妹，坐凌事当并诛。使者征摄甚急，淮使戒装，克日当发。州府文武及百姓劝淮举兵，淮不许。至期，遣妻，百姓号泣追呼者数万人。行数十里，淮乃命左右追夫人还，于是文武奔驰，如徇身首之急。既至，淮与宣帝书曰：“五子哀恋，思念其母。其母既亡，则无五子；五子若殒，亦复无淮。”宣帝乃表，特原淮妻。|| 郭淮任关中都督，很得民心，也多次立有战功。郭淮的妻子是太尉王凌的妹妹，因王凌的案子应当连坐处死。使者来拿人催得很紧，郭淮让妻子整理行装，定好日子出发。州府里的文武官员和百姓都劝郭淮起兵抗拒，郭淮不答应。到了日子，他打发妻子上路，百姓哭喊着追送的有好几万人。走了几十里，郭淮才命左右把夫人追回来，于是文武官员飞马奔驰，急得像是去救自己的性命一般。妻子回来后，郭淮给司马懿写信说：“我的五个儿子悲伤依恋，思念母亲。母亲若死了，五个儿子也就活不成；五个儿子若死了，也就不会再有我郭淮了。”司马懿于是上表，特别赦免了郭淮的妻子。
注：郭淮：字伯济，曹魏名将，长期镇守关中，抵御蜀汉。
注：都督：统领一方军事的长官。
注：战庸：战功。庸，功劳。
注：王凌：曹魏太尉，谋立楚王曹彪，事泄自尽，被夷三族。
注：坐：因……获罪。
注：征摄：追捕拘押。
注：戒装：整治行装。
注：克日：限定日期。
注：徇：通“殉”，此处犹言为救性命而奔走，存疑。
注：宣帝：司马懿，晋朝建立后追尊为宣帝。
注：表：上奏章。
注：原：宽赦。

# 五｜诸葛亮之次渭滨
原：诸葛亮之次渭滨，关中震动。魏明帝深惧晋宣王战，乃遣辛毗为军司马。宣王既与亮对渭而陈，亮设诱谲万方。宣王果大忿，将欲应之以重兵。亮遣间谍觇之，还曰：“有一老夫，毅然仗黄钺，当军门立，军不得出。”亮曰：“此必辛佐治也。”|| 诸葛亮驻军渭水之滨，关中为之震动。魏明帝很怕司马懿出战，就派辛毗去做军师。司马懿和诸葛亮隔着渭水列阵，诸葛亮千方百计地设计引诱激怒他。司马懿果然大怒，准备出动重兵应战。诸葛亮派探子去侦察，回来报告说：“有个老头，神色坚毅，手握黄钺，挡在军营门口站着，军队出不来。”诸葛亮说：“这一定是辛佐治了。”
注：次：军队驻扎。
注：渭滨：渭水岸边，指五丈原一带。
注：魏明帝：曹叡，曹丕之子。
注：晋宣王：司马懿。
注：辛毗：字佐治，曹魏大臣，以刚直敢谏著称。
注：军司马：此指监军性质的军师。
注：诱谲（jué）：引诱欺骗。
注：觇（chān）：窥探。
注：黄钺（yuè）：饰金的大斧，代表天子的权威。

# 六｜夏侯玄既被桎梏
原：夏侯玄既被桎梏，时钟毓为廷尉，钟会先不与玄相知，因便狎之。玄曰：“虽复刑余之人，未敢闻命！”考掠初无一言，临刑东市，颜色不异。|| 夏侯玄被戴上脚镣手铐时，钟毓正做廷尉，他弟弟钟会过去和夏侯玄并无交情，这时却趁机对他轻慢狎昵。夏侯玄说：“我虽然已是受刑的罪人，也不敢听从你的摆布！”拷打审问时始终一言不发，押到东市行刑，脸色也毫无变化。
注：夏侯玄：字太初，曹魏名士，玄学领袖之一，因卷入李丰等谋诛司马师一事被杀。
注：桎梏（zhì gù）：脚镣与手铐。
注：钟毓、钟会：钟繇之子，兄弟二人。
注：廷尉：掌刑狱的长官。
注：狎（xiá）：亲近而不庄重，带有戏弄之意。
注：刑余之人：受过刑的人。
注：考掠：拷打审讯。
注：初：始终，完全。
注：东市：行刑之处的代称。

# 七｜夏侯泰初与广陵陈本善
原：夏侯泰初与广陵陈本善。本与玄在本母前宴饮，本弟骞行还，径入，至堂户。泰初因起曰：“可得同，不可得而杂。”|| 夏侯玄和广陵人陈本交好。陈本和夏侯玄在陈本母亲面前饮酒，陈本的弟弟陈骞从外面回来，径直走进来，到了堂屋门口。夏侯玄便站起身说：“可以同道相聚，却不能和不相干的人混在一处。”
注：夏侯泰初：即夏侯玄。
注：陈本：字休元，曹魏大臣陈矫之子。
注：骞：陈骞（qiān），陈本之弟，后仕晋，官至大司马。
注：同、杂：同，志趣相合者相聚；杂，与不投合的人混杂。

# 八｜高贵乡公薨
原：高贵乡公薨，内外喧哗。司马文王问侍中陈泰曰：“何以静之？”泰云：“唯杀贾充以谢天下。”文王曰：“可复下此不？”对曰：“但见其上，未见其下。”|| 高贵乡公被杀，朝廷内外议论纷纷。司马昭问侍中陈泰：“怎样才能让局面安定下来？”陈泰说：“只有杀了贾充，向天下谢罪。”司马昭说：“还能有比这轻一点的办法吗？”陈泰答：“我只看到比这更重的，没看到比这更轻的。”
注：高贵乡公：曹髦，曹魏第四位皇帝，不甘受制于司马昭，率宫人讨伐，被贾充指使的部下杀死。
注：薨：此处指死。
注：司马文王：司马昭，谥文王。
注：陈泰：陈群之子，时任侍中。
注：贾充：司马昭心腹，弑君一事的主使者。
注：谢：谢罪。
注：上、下：指比杀贾充更重或更轻的处置；言下之意，更重的就是追究司马昭本人。

# 九｜和峤为武帝所亲重
原：和峤为武帝所亲重，语峤曰：“东宫顷似更成进，卿试往看。”还，问：“何如？”答云：“皇太子圣质如初。”|| 和峤受晋武帝亲近器重，武帝对他说：“太子近来好像长进了些，你去看看。”和峤回来，武帝问：“怎么样？”他答：“皇太子的天资和当初一样。”
注：和峤：字长舆，西晋大臣，以清正著称，曾直言太子不堪继位。
注：武帝：晋武帝司马炎。
注：东宫：太子居所，代指太子司马衷，即后来的晋惠帝，素称愚钝。
注：顷：近来。
注：成进：成熟长进。
注：圣质如初：表面恭维“圣质”，实指毫无长进。

# 十｜诸葛靓后入晋
原：诸葛靓后入晋，除大司马，召不起。以与晋室有仇，常背洛水而坐。与武帝有旧，帝欲见之而无由，乃请诸葛妃呼靓。既来，帝就太妃间相见。礼毕，酒酣，帝曰：“卿故复忆竹马之好不？”靓曰：“臣不能吞炭漆身，今日复睹圣颜。”因涕泗百行。帝于是惭悔而出。|| 诸葛靓后来到了晋朝，被任命为大司马，他不应召。因为和晋室有杀父之仇，他常常背对着洛水而坐。他和晋武帝小时候有交情，武帝想见他却找不到由头，就请诸葛妃把他叫来。诸葛靓来了，武帝到太妃那里和他相见。行过礼，酒喝到酣处，武帝说：“你还记得咱们小时候骑竹马的情谊吗？”诸葛靓说：“臣没能像豫让那样吞炭漆身为父报仇，今天又见到了陛下的面容。”说着泪流满面。武帝于是惭愧懊悔地出去了。
注：诸葛靓（jìng）：诸葛诞之子，曾仕东吴，吴亡后入晋。
注：除：授官。
注：与晋室有仇：其父诸葛诞起兵反司马昭，兵败被杀。
注：背洛水而坐：洛阳在洛水边，背水而坐表示不愿面向晋都。
注：诸葛妃：诸葛靓之姊，琅邪王司马伷之妃，武帝的婶母，下文“太妃”即指她。
注：竹马之好：童年玩伴的交情。
注：吞炭漆身：战国时豫让为报智伯之仇，漆身为癞、吞炭使哑以变形刺杀赵襄子。

# 十一｜武帝语和峤曰
原：武帝语和峤曰：“我欲先痛骂王武子，然后爵之。”峤曰：“武子俊爽，恐不可屈。”帝遂召武子，苦责之，因曰：“知愧不？”武子曰：“尺布斗粟之谣，常为陛下耻之！它人能令疏亲，臣不能使亲疏，以此愧陛下。”|| 晋武帝对和峤说：“我想先把王济痛骂一顿，然后再给他封爵。”和峤说：“王济为人英爽，恐怕骂不服他。”武帝还是召来王济，狠狠责备了一通，接着问：“知道惭愧吗？”王济说：“每想起‘尺布斗粟’的歌谣，我常替陛下感到羞耻！别人能让疏远的人变得亲近，我却没能让亲近的人不被疏远，为此对陛下感到惭愧。”
注：王武子：王济，字武子，晋武帝的女婿，豪爽有才辩。
注：爵之：封给他爵位。
注：尺布斗粟之谣：汉文帝之弟淮南王刘长获罪流放死于途中，民谣讽刺兄弟不能相容。当时武帝逼同母弟齐王司马攸离京就国，王济屡谏，故借此讽刺。
注：它人能令疏亲二句：大意是自己未能劝阻武帝疏远至亲，语带反讽。

# 十二｜杜预之荆州
原：杜预之荆州，顿七里桥，朝士悉祖。预少贱，好豪侠，不为物所许。杨济既名氏雄俊，不堪，不坐而去。须臾，和长舆来，问：“杨右卫何在？”客曰：“向来，不坐而去。”长舆曰：“必大夏门下盘马。”往大夏门，果大阅骑，长舆抱内车，共载归，坐如初。|| 杜预去荆州赴任，在七里桥停驻，朝中官员都来为他饯行。杜预年轻时地位低微，好行侠仗义，不被众人看重。杨济出身名门、才俊出众，受不了这种场面，没坐下就走了。不一会儿，和峤来了，问：“杨右卫在哪儿？”客人说：“刚才来过，没坐就走了。”和峤说：“他一定在大夏门下骑马兜圈子。”赶到大夏门，杨济果然在那里检阅骑兵，和峤把他抱进车里，一起乘车回来，杨济这才像原先那样入座。
注：杜预：字元凯，西晋名将、学者，以灭吴之功封侯，著《春秋左氏经传集解》。
注：之：往。
注：顿：停驻。
注：七里桥：在洛阳城东。
注：祖：设宴送行。
注：物：众人。
注：许：称许。
注：杨济：字文通，晋武帝杨皇后的叔父，官右卫将军，名门子弟。
注：大夏门：洛阳城北门。
注：盘马：骑马盘旋。
注：内：通“纳”，放进。

# 十三｜杜预拜镇南将军
原：杜预拜镇南将军，朝士悉至，皆在连榻坐。时亦有裴叔则。羊稚舒后至，曰：“杜元凯乃复连榻坐客！”不坐便去。杜请裴追之，羊去数里住马，既而俱还杜许。|| 杜预被任命为镇南将军，朝中官员都来道贺，都坐在连榻上。当时裴楷也在座。羊琇最后才到，说：“杜元凯竟然让客人坐连榻！”不肯落座就走了。杜预请裴楷去追他，羊琇走出几里路停下马来，不久两人一同回到杜预那里。
注：连榻：几个人同坐的长榻，用来待客显得简慢。
注：裴叔则：裴楷，字叔则，西晋名士。
注：羊稚舒：羊琇，字稚舒，晋武帝的亲信，官至中护军。
注：住马：停住马。
注：许：处所。

# 十四｜晋武帝时荀勖为中书监
原：晋武帝时，荀勖为中书监，和峤为令。故事，监、令由来共车。峤性雅正，常疾勖谄谀。后公车来，峤便登，正向前坐，不复容勖。勖方更觅车，然后得去。监、令各给车自此始。|| 晋武帝时，荀勖任中书监，和峤任中书令。按老规矩，监和令向来同乘一辆车。和峤生性端方正直，常常厌恶荀勖逢迎拍马。后来官车来了，和峤就先上车，端端正正朝前坐着，不再给荀勖留位子。荀勖只好另找车子，然后才走得了。中书监、中书令各配一辆车，就是从这件事开始的。
注：荀勖（xù）：字公曾，西晋大臣，善于迎合上意。
注：中书监、令：中书省的正副长官，同掌机要。
注：故事：旧例。
注：由来：向来。
注：雅正：端方正直。
注：疾：憎恶。
注：谄谀（chǎn yú）：奉承讨好。
注：公车：官家派的车。
注：给：配给。

# 十五｜山公大儿著短帢
原：山公大儿著短帢，车中倚。武帝欲见之，山公不敢辞，问儿，儿不肯行。时论乃云胜山公。|| 山涛的大儿子戴着便帽，靠在车里。晋武帝想召见他，山涛不敢推辞，回去问儿子，儿子不肯去。当时舆论便说他胜过山涛。
注：山公：山涛，字巨源，“竹林七贤”之一，入晋位至司徒。
注：大儿：长子山该，存疑。
注：短帢（qià）：一种便帽，非正式场合的装束。

# 十六｜向雄为河内主簿
原：向雄为河内主簿，有公事不及雄，而太守刘淮横怒，遂与杖遣之。雄后为黄门郎，刘为侍中，初不交言。武帝闻之，敕雄复君臣之好。雄不得已，诣刘，再拜曰：“向受诏而来，而君臣之义绝，何如？”于是即去。武帝闻尚不和，乃怒问雄曰：“我令卿复君臣之好，何以犹绝？”雄曰：“古之君子，进人以礼，退人以礼；今之君子，进人若将加诸膝，退人若将坠诸渊。臣于刘河内，不为戎首，亦已幸甚，安复为君臣之好？”武帝从之。|| 向雄做河内郡主簿时，有件公事本与他无关，太守刘淮却蛮横发怒，把他打了板子赶走。后来向雄做了黄门郎，刘淮做了侍中，两人始终不说话。晋武帝听说后，命向雄恢复和刘淮从前的上下级情分。向雄没办法，去见刘淮，拜了两拜说：“我刚才奉诏前来，可我们之间的君臣情义已经断了，您看怎么办？”说完就走了。武帝听说两人仍不和，就生气地问向雄：“我叫你恢复君臣情分，为什么还是断绝？”向雄说：“古时的君子，用人按礼，罢人也按礼；如今的君子，用人时好像要把人抱到膝上，罢人时好像要把人推进深渊。我对刘河内不去当挑起争端的祸首，已经很好了，哪还能恢复什么君臣情分？”武帝也就由他去了。
注：向雄：字茂伯，河内人，西晋官员，以刚直著称。
注：主簿：郡府掌文书的属官。
注：刘淮：字君平，曾任河内太守。一说名当作“準”，书中注亦指出，存疑，此照印本录作“淮”。
注：横怒：蛮横发怒。
注：与杖：施以杖刑。
注：君臣：汉晋时郡守与属吏之间也称君臣。
注：敕：皇帝命令。
注：加诸膝、坠诸渊：语出《礼记·檀弓》，形容用人、弃人全凭好恶。
注：戎首：挑起争斗的祸首。

# 十七｜齐王冏为大司马
原：齐王冏为大司马，辅政，嵇绍为侍中，诣冏咨事。冏设宰会，召葛旟、董艾等共论时宜。旟等白冏：“嵇侍中善于丝竹，公可令操之。”遂送乐器，绍推却不受。冏曰：“今日共为欢，卿何却邪？”绍曰：“公协辅皇室，令作事可法。绍虽官卑，职备常伯，操丝比竹，盖乐官之事，不可以先王法服，为伶人之业。今逼高命，不敢苟辞，当释冠冕，袭私服，此绍之心也。”旟等不自得而退。|| 齐王司马冏任大司马辅政，嵇绍任侍中，到他那里请示公事。司马冏设宴招待僚属，召来葛旟、董艾等人一同议论时事。葛旟等人对司马冏说：“嵇侍中擅长音乐，主公可以让他演奏一曲。”于是送上乐器，嵇绍推辞不接。司马冏说：“今天大家一起欢聚，您为什么推辞呢？”嵇绍说：“您辅佐皇室，所作所为应当可为人效法。我嵇绍官职虽低，也忝列天子近臣，弹琴吹管是乐官的事，不能穿着先王规定的朝服去干伶人的营生。如今被您的命令所逼，不敢随便推辞，那就请让我脱下冠冕，换上便服再弹，这是我的心意。”葛旟等人讨了个没趣，只好退下。
注：齐王冏（jiǒng）：司马冏，西晋宗室，起兵诛赵王伦后以大司马辅政，骄恣专权，后被杀。
注：嵇绍：嵇康之子，以忠节著称，后为护卫晋惠帝而死。
注：咨事：请示公务。
注：宰会：宴请僚属的集会。
注：葛旟（yú）、董艾：均为司马冏亲信。
注：时宜：适合时势的措施。
注：丝竹：弦乐和管乐，泛指音乐。
注：常伯：皇帝左右近侍之官，此指侍中。
注：法服：礼制规定的官服。
注：伶人：乐工。
注：袭：穿上。

# 十八｜卢志于众坐问陆士衡
原：卢志于众坐问陆士衡：“陆逊、陆抗是君何物？”答曰：“如卿于卢毓、卢珽。”士龙失色。既出户，谓兄曰：“何至如此！彼容不相知也。”士衡正色曰：“我父、祖名播海内，宁有不知？鬼子敢尔！”议者疑二陆优劣，谢公以此定之。|| 卢志在众人面前问陆机：“陆逊、陆抗是你什么人？”陆机答：“就像卢毓、卢珽跟你的关系一样。”陆云吓得变了脸色。出门后，他对哥哥说：“何必弄到这个地步！他也许真的不知道。”陆机严肃地说：“我父亲和祖父名扬天下，他岂能不知道？这鬼子竟敢如此！”评论的人原本拿不准二陆谁高谁低，谢安就凭这件事作了定论。
注：卢志：字子道，范阳人，西晋官员。
注：陆士衡：陆机，字士衡，吴郡人，西晋著名文学家。
注：陆逊：陆机祖父，东吴丞相；
注：陆抗：陆机之父，东吴大司马。
注：何物：什么人。当面直呼人父祖名讳，在当时是极大的冒犯。
注：卢毓：卢志祖父，曹魏重臣；
注：卢珽：卢志之父。陆机以直呼其父祖之名回敬。
注：士龙：陆云，陆机之弟。
注：容：或许。
注：鬼子：相传卢氏先人卢充曾与鬼女结婚生子，故陆机以此辱骂。
注：谢公：谢安。

# 十九｜羊忱性甚贞烈
原：羊忱性甚贞烈。赵王伦为相国，忱为太傅长史，乃版以参相国军事。使者卒至，忱深惧豫祸，不暇被马，于是帖骑而避。使者追之，忱善射，矢左右发，使者不敢进，遂得免。|| 羊忱生性非常刚正。赵王司马伦当相国时，羊忱任太傅长史，司马伦便下版文任命他为参相国军事。使者突然来到，羊忱很怕卷入祸事，来不及给马套上鞍子，就光着马背骑上去逃走。使者追赶他，羊忱擅长射箭，左右开弓，使者不敢再追，他终于得以脱身。
注：羊忱：字长和，泰山人，西晋官员，善书法。
注：贞烈：坚贞刚烈。
注：赵王伦：司马伦，曾杀贾后专权，后篡位称帝，旋即败亡。
注：太傅长史：太傅府的属官之长。
注：版：写在木版上的任命文书。
注：参相国军事：相国府的参军。
注：卒（cù）：通“猝”，突然。
注：豫祸：牵连进祸事。豫，参与。
注：被马：给马加上鞍鞯。
注：帖骑：不用鞍子贴身骑在马背上。

# 二十｜王太尉不与庾子嵩交
原：王太尉不与庾子嵩交，庾卿之不置。王曰：“君不得为尔。”庾曰：“卿自君我，我自卿卿。我自用我法，卿自用卿法。”|| 王衍不和庾敳交往，庾敳却一个劲儿地用“卿”称呼他。王衍说：“您不能这样叫我。”庾敳说：“你尽管称我为‘君’，我自管叫你作‘卿’。我用我的叫法，你用你的叫法。”
注：王太尉：王衍，字夷甫，西晋清谈领袖，官至太尉。
注：庾子嵩：庾敳（ái），字子嵩，西晋名士。
注：卿：对平辈或下级的亲昵称呼，用于不熟悉的人显得不恭；
注：君：较客气的称呼。
注：不置：不停。
注：尔：这样。
注：卿自君我二句：你自称我为君，我自称你为卿，前一字作动词用。

# 二十一｜阮宣子伐社树
原：阮宣子伐社树，有人止之。宣子曰：“社而为树，伐树则社亡；树而为社，伐树则社移矣。”|| 阮修要砍土地庙的树，有人阻止他。阮修说：“如果土地神就是这棵树，砍了树土地神也就没了；如果树只是土地神的寄托，砍了树，土地神自会搬到别处去。”
注：阮宣子：阮修，字宣子，西晋名士，好《老》《易》，不信鬼神。
注：社：土地神，也指祭祀土地神的处所；社树是社坛旁被视为神灵所依的树。

# 二十二｜阮宣子论鬼神有无者
原：阮宣子论鬼神有无者。或以人死有鬼，宣子独以为无，曰：“今见鬼者云，著生时衣服，若人死有鬼，衣服复有鬼邪？”|| 阮修和人讨论鬼神有没有。有人认为人死后变鬼，唯独阮修认为没有，他说：“如今那些说见过鬼的人，都说鬼穿着生前的衣服；如果人死了有鬼，难道衣服也有鬼吗？”
注：著：穿。

# 二十三｜元皇帝既登阼
原：元皇帝既登阼，以郑后之宠，欲舍明帝而立简文。时议者咸谓舍长立少，既于理非伦，且明帝以聪亮英断，益宜为储副。周、王诸公并苦争恳切。唯刁玄亮独欲奉少主，以阿帝旨。|| 晋元帝即位后，因为宠爱郑夫人，想舍弃长子明帝，改立郑夫人所生的简文帝。当时议论的人都认为舍长立幼，于理不合，况且明帝聪明果断，更适合做太子。周顗、王导等大臣都苦苦恳切地力争。只有刁协一个人想拥戴幼子，以迎合元帝的心意。
注：元皇帝：晋元帝司马睿，东晋开国之君。
注：登阼（zuò）：登上帝位。阼，帝王即位所登的台阶。
注：郑后：郑阿春，元帝宠妃，简文帝之母，后追尊为太后。
注：明帝：司马绍，元帝长子。
注：简文：司马昱，后为简文帝。
注：非伦：不合伦理次序。
注：储副：太子。
注：周、王：周顗、王导。
注：刁玄亮：刁协，字玄亮，元帝亲信，时任尚书令。
注：阿：迎合。
原：元帝便欲施行，虑诸公不奉诏，于是先唤周侯、丞相入，然后欲出诏付刁。周、王既入，始至阶头，帝逆遣传诏遏，使就东厢。周侯未悟，即却略下阶。丞相披拨传诏，径至御床前，曰：“不审陛下何以见臣？”帝默然无言，乃探怀中黄纸诏裂掷之。由此皇储始定。周侯方慨然愧叹曰：“我常自言胜茂弘，今始知不如也！”|| 元帝便打算实行，又担心大臣们不肯奉诏，就先召周顗和王导入宫，然后想把诏书交给刁协。周顗、王导进来，刚走到台阶前，元帝预先派传诏的人拦住他们，让他们去东厢房。周顗没有醒悟，就退下了台阶。王导却拨开传诏的人，径直走到皇帝坐榻前，说：“不知陛下为什么召见臣？”元帝沉默不语，从怀里掏出写在黄纸上的诏书撕碎扔掉了。从此太子的人选才定下来。周顗这才感慨又惭愧地说：“我常说自己胜过王茂弘，今天才知道不如他啊！”
注：周侯：周顗（yǐ），字伯仁，袭爵武城侯。
注：丞相：王导，字茂弘，东晋开国重臣。
注：逆：预先。
注：遏（è）：阻拦。
注：却略：倒退。
注：披拨：用手拨开。
注：御床：皇帝的坐榻。
注：审：知道。
注：黄纸诏：诏书写在黄纸上。

# 二十四｜王丞相初在江左
原：王丞相初在江左，欲结援吴人，请婚陆太尉。对曰：“培塿无松柏，薰莸不同器。玩虽不才，义不为乱伦之始。”|| 王导刚到江东时，想结交吴地士族作为援助，向陆玩请求结亲。陆玩回答：“小土丘上长不出松柏，香草和臭草不能装在一个器皿里。我陆玩虽然无才，按道义也不能做坏了门第规矩的第一个人。”
注：王丞相：王导。
注：江左：江东，指东晋所在的长江下游地区。
注：吴人：江东本地士族。
注：陆太尉：陆玩，吴郡人，江东大族，死后赠太尉。
注：培塿（pǒu lǒu）：小土丘。
注：薰莸（yóu）：香草与臭草。两句以小丘、臭草自比，实为婉拒，暗含轻视北来士族之意。
注：乱伦：此指打乱门第等级的婚配。

# 二十五｜诸葛恢大女适太尉庾亮儿
原：诸葛恢大女适太尉庾亮儿，次女适徐州刺史羊忱儿。亮子被苏峻害，改适江虨。恢儿娶邓攸女。于时谢尚书求其小女婚。恢乃云：“羊、邓是世婚，江家我顾伊，庾家伊顾我，不能复与谢裒儿婚。”及恢亡，遂婚。于是王右军往谢家看新妇，犹有恢之遗法：威仪端详，容服光整。王叹曰：“我在遣女，裁得尔耳！”|| 诸葛恢的大女儿嫁给太尉庾亮的儿子，二女儿嫁给徐州刺史羊忱的儿子。庾亮的儿子被苏峻杀害后，大女儿改嫁江虨。诸葛恢的儿子娶了邓攸的女儿。当时尚书谢裒为儿子求娶他的小女儿。诸葛恢却说：“羊家、邓家和我家是世代联姻，江家是我照顾他，庾家是他照顾我，不能再和谢裒的儿子结亲了。”等诸葛恢死后，两家终于结了亲。于是王羲之到谢家去看新娘，新娘还保有诸葛恢留下的家风：举止端庄安详，仪容服饰鲜亮整齐。王羲之赞叹道：“我嫁女儿的时候，也不过能做到这样罢了！”
注：诸葛恢：字道明，琅邪人，东晋大臣，出身高门。
注：适：出嫁。
注：苏峻：东晋将领，起兵作乱，攻入建康。
注：江虨（bīn）：字思玄，东晋名士，官至尚书仆射。
注：邓攸：东晋名臣，以清廉著称。
注：谢尚书：谢裒（póu），谢安之父，时谢氏门第尚不及诸葛氏。
注：世婚：世代通婚。
注：顾：照顾、抬举。
注：伊：他。
注：王右军：王羲之。
注：遗法：留下的家风规矩。
注：裁：通“才”。
注：尔：如此。

# 二十六｜周叔治作晋陵太守
原：周叔治作晋陵太守，周侯、仲智往别。叔治以将别，涕泗不止。仲智恚之曰：“斯人乃妇女，与人别，唯啼泣！”便舍去。周侯独留，与饮酒言话，临别流涕，抚其背曰：“奴好自爱。”|| 周谟去做晋陵太守，哥哥周顗、周嵩去送别。周谟因为就要分别，哭个不停。周嵩恼火地说：“这人竟像个妇人，跟人分别只会哭哭啼啼！”说完撇下他走了。周顗独自留下，和他喝酒说话，临别时流着泪，拍着他的背说：“小弟，好好保重自己。”
注：周叔治：周谟，字叔治，周顗之弟。
注：晋陵：郡名，治所在今江苏常州。
注：周侯：周顗。
注：仲智：周嵩，字仲智，周顗之弟、周谟之兄，性格刚直。
注：恚（huì）：恼怒。
注：奴：兄长对弟弟的昵称。

# 二十七｜周伯仁为吏部尚书
原：周伯仁为吏部尚书，在省内，夜疾危急。时刁玄亮为尚书令，营救备亲好之至，良久小损。明旦，报仲智，仲智狼狈来。始入户，刁下床对之大泣，说伯仁昨危急之状。仲智手批之，刁为辟易于户侧。既前，都不问病，直云：“君在中朝，与和长舆齐名，那与佞人刁协有情！”径便出。|| 周顗任吏部尚书时，夜里在尚书省发了急病，十分危险。当时刁协任尚书令，尽心竭力地救护，亲热周到到了极点，过了好久病情才稍有好转。第二天早上，派人通知周嵩，周嵩慌忙赶来。他刚一进门，刁协就从坐榻上下来对着他大哭，诉说周顗昨夜的危急情形。周嵩抬手就给了他一巴掌，刁协被打得退到门边。周嵩走到哥哥跟前，一句也不问病情，直接说：“你在西晋朝廷时，和和峤齐名，怎么会和奸佞小人刁协有交情！”说完径直出去了。
注：周伯仁：周顗。
注：省：官署，此指尚书省。
注：刁玄亮：刁协。
注：备亲好之至：极尽亲密友好之情。
注：小损：病情稍减。
注：狼狈：慌忙急迫。
注：批：用手掌打。

# 二十八｜王含作庐江郡
原：王含作庐江郡，贪浊狼籍。王敦护其兄，故于众坐称：“家兄在郡定佳，庐江人士咸称之。”时何充为敦主簿，在坐，正色曰：“充即庐江人，所闻异于此！”敦默然。旁人为之反侧，充晏然神意自若。|| 王含任庐江太守，贪污不法，名声极坏。王敦袒护哥哥，故意在众人面前说：“家兄在郡里政绩一定很好，庐江的人士都称赞他。”当时何充是王敦的主簿，也在座，他神色严正地说：“我何充就是庐江人，我听到的和这不一样！”王敦默不作声。旁边的人都替何充捏一把汗，何充却安然自若，神态如常。
注：王含：王敦之兄，后随王敦作乱，兵败被杀。
注：庐江郡：治所在今安徽庐江一带。
注：狼籍：也作“狼藉”，散乱不堪，此指名声败坏。
注：王敦：东晋权臣，王导从兄，后起兵谋逆。
注：何充：字次道，庐江人，后官至宰辅，以正直著称。
注：主簿：掌文书的属官。
注：反侧：坐立不安。
注：晏然：安然。

# 二十九｜顾孟著尝以酒劝周伯仁
原：顾孟著尝以酒劝周伯仁，伯仁不受。顾因移劝柱，而语柱曰：“讵可便作栋梁自遇？”周得之欣然，遂为衿契。|| 顾显曾向周顗敬酒，周顗不肯喝。顾显便转身向柱子敬酒，还对柱子说：“你怎么就把自己当成栋梁看待了呢？”周顗听了很高兴，两人于是成了知心朋友。
注：顾孟著：顾显，字孟著，吴郡人，顾荣之侄，东晋初任散骑侍郎。
注：讵：岂，怎么。
注：自遇：自己看待自己。“栋梁”一语双关，既指柱子，也暗讽周顗以栋梁之臣自居。
注：衿（jīn）契：意气相投的好友。
