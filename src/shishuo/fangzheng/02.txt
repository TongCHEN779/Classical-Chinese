# 三十｜明帝在西堂
原：明帝在西堂，会诸公饮酒，未大醉，帝问：“今名臣共集，何如尧、舜时？”周伯仁为仆射，因厉声曰：“今虽同人主，复那得等于圣治！”帝大怒，还内，作手诏满一黄纸，遂付廷尉令收，因欲杀之。后数日，诏出周，群臣往省之。周曰：“近知当不死，罪不足至此。”|| 晋明帝在西堂召集大臣们饮酒，还没喝到大醉，明帝问道：“如今名臣济济一堂，比起尧、舜的时代怎么样？”当时周顗任仆射，便厉声说：“如今的君主虽然同样是人主，又怎能比得上圣王之治！”明帝大怒，回到内宫，亲手写了满满一张黄纸的诏书，交给廷尉，命令逮捕周顗，想借此杀了他。过了几天，又下诏放周顗出来，大臣们都去看望他。周顗说：“前些天我就知道自己不会死，这点罪还够不上死罪。”
注：明帝：东晋明帝司马绍，元帝之子。
注：周伯仁：周顗（yǐ），字伯仁，汝南安成人，以清望和嗜酒著称，时任尚书仆射。
注：收：逮捕。廷尉：掌管刑狱的长官。
注：省（xǐng）：探望。

# 三十一｜王大将军当下
原：王大将军当下，时咸谓无缘尔。伯仁曰：“今主非尧、舜，何能无过？且人臣安得称兵以向朝廷？处仲狼抗刚愎，王平子何在？”|| 大将军王敦将要起兵东下京城，当时人们都认为他没有理由这样做。周顗说：“当今君主不是尧、舜，怎么可能没有过失？可是做臣子的又怎么能起兵对着朝廷？处仲这人骄横凶狠、刚愎自用，你们看看王平子如今在哪里？”
注：王大将军：王敦，字处仲，琅邪临沂人，王导的堂兄，东晋初拥兵上游，曾两度举兵犯京。
注：当下：将要从武昌顺流东下建康。无缘尔：没有理由这样做。
注：狼抗：凶狠傲慢。刚愎：固执任性，不听人言。
注：王平子：王澄，字平子，王敦族弟，被王敦杀害；周顗举此事说明王敦连亲族都下得了手。

# 三十二｜王敦既下，住船石头
原：王敦既下，住船石头，欲有废明帝意。宾客盈坐，敦知帝聪明，欲以不孝废之。每言帝不孝之状，而皆云：“温太真所说。温尝为东宫率，后为吾司马，甚悉之。”|| 王敦领兵东下以后，把船停在石头城，有废黜明帝的打算。满座宾客之时，王敦知道明帝聪明，便想用不孝的罪名来废掉他。他每次说到明帝不孝的情形，都说：“这是温太真讲的。温峤曾做过东宫卫率，后来做我的司马，对这些很清楚。”
注：石头：石头城，在建康西面，是拱卫京城的军事要地。
注：明帝：此时尚为太子，称帝是追述之辞。
注：温太真：温峤，字太真，太原祁县人，东晋名臣。
注：东宫率：太子宫中的卫队长官。司马：将军府中总管军务的属官。
原：须臾，温来，敦便奋其威容，问温曰：“皇太子作人何似？”温曰：“小人无以测君子。”敦声色并厉，欲以威力使从己，乃重问温：“太子何以称佳？”温曰：“钩深致远，盖非浅识所测。然以礼侍亲，可称为孝。”|| 不一会儿温峤来了，王敦便摆出威严的样子，问他：“皇太子为人怎么样？”温峤说：“我这种小人没法揣测君子。”王敦声音脸色都严厉起来，想用威势逼他顺从自己，又问温峤：“太子凭什么称得上好？”温峤说：“太子探究深奥、谋虑长远，不是我这样见识浅薄的人能测度的。但是他依礼侍奉双亲，可以称得上孝。”
注：奋其威容：摆出威严凶狠的面孔。
注：钩深致远：语出《周易·系辞》，指探求深奥、致力远大。

# 三十三｜王大将军既反
原：王大将军既反，至石头，周伯仁往见之。谓周曰：“卿何以相负？”对曰：“公戎车犯正，下官忝率六军，而王师不振，以此负公。”|| 大将军王敦起兵反叛，到了石头城，周顗去见他。王敦对周顗说：“你为什么辜负我？”周顗回答说：“您兴兵冒犯朝廷，下官不才，率领六军抵御，可是王师不能振作，因此辜负了您。”
注：卿何以相负：王敦对周顗曾有恩惠，又知周顗在朝中反对自己，故有此责问。
注：戎车犯正：驾兵车侵犯正统朝廷，即起兵作乱。
注：忝（tiǎn）：谦辞，表示有愧于担任某职。六军：天子的军队。
注：以此负公：反话，表面认“负”，实指自己未能打败他，语带讥讽。

# 三十四｜苏峻既至石头
原：苏峻既至石头，百僚奔散，唯侍中钟雅独在帝侧。或谓钟曰：“见可而进，知难而退，古之道也。君性亮直，必不容于寇雠，何不用随时之宜，而坐待其弊邪？”钟曰：“国乱不能匡，君危不能济，而各逊遁以求免，吾惧董狐将执简而进矣！”|| 苏峻的叛军到了石头城，百官四散奔逃，只有侍中钟雅独自守在成帝身边。有人对钟雅说：“看到可行就前进，知道艰难就后退，这是自古以来的道理。您性情诚实正直，一定不会被敌寇所容，为什么不随机应变，而要坐等祸败呢？”钟雅说：“国家动乱不能匡正，君主危急不能救助，却各自逃避以求免祸，我怕董狐就要拿着竹简上前来记下这笔账了！”
注：苏峻：长广掖县人，东晋将领，咸和二年（327年）起兵反叛，攻陷建康，挟持成帝至石头城。
注：钟雅：字彦胄，颍川长社人，时任侍中，后为苏峻所害。帝：晋成帝司马衍。
注：见可而进，知难而退：语本《左传》，原指用兵之道。弊：同“毙”，败亡。
注：董狐：春秋晋国史官，以秉笔直书著称，曾书“赵盾弑其君”。执简：拿着竹简记事。

# 三十五｜庾公临去
原：庾公临去，顾语钟后事，深以相委。钟曰：“栋折榱崩，谁之责邪？”庾曰：“今日之事，不容复言，卿当期克复之效耳。”钟曰：“想足下不愧荀林父耳。”|| 庾亮临出逃时，回头把以后的事交代给钟雅，郑重地托付给他。钟雅说：“栋梁折断，椽子崩塌，这是谁的责任呢？”庾亮说：“今天的事，不必再说了，您就等着看我收复京城的成效吧。”钟雅说：“想来您不会愧对荀林父吧。”
注：庾公：庾亮，字元规，颍川鄢陵人，成帝之舅，执掌朝政；苏峻之乱即由他强征苏峻入朝而激起，京城失守后出奔。
注：榱（cuī）：椽子。栋折榱崩：比喻国家倾覆。
注：克复：打败敌人，收复失地。
注：荀林父：春秋晋国大臣，邲之战败于楚，晋景公仍予留用，后大败赤狄立功。钟雅以此激励庾亮将功补过，语中仍含责备。

# 三十六｜苏峻时，孔群在横塘
原：苏峻时，孔群在横塘为匡术所逼。王丞相保存术，因众坐戏语，令术劝群酒，以释横塘之憾。群答曰：“德非孔子，厄同匡人。虽阳和布气，鹰化为鸠，至于识者，犹憎其眼。”|| 苏峻作乱时，孔群在横塘曾受匡术逼迫。后来丞相王导保全了匡术，趁着众人在座说笑的时候，让匡术向孔群劝酒，以消除横塘结下的怨恨。孔群回答说：“我的德行比不上孔子，遭的困厄却和孔子被匡人围困一样。即使春阳和暖、万物生发，老鹰变成了斑鸠，可是认得它的人，还是憎恶它那双眼睛。”
注：孔群：字敬休，会稽山阴人，性情刚直，好饮酒。
注：匡术：苏峻部将，后归降朝廷。横塘：地名，在建康附近。
注：厄同匡人：孔子曾在匡地被围；这里借“匡”字双关匡术。
注：鹰化为鸠：古人以为仲春时鹰会变成鸠，比喻恶人改头换面，但本性难移。

# 三十七｜苏子高事平
原：苏子高事平，王、庾诸公欲用孔廷尉为丹阳。乱离之后，百姓凋弊，孔慨然曰：“昔肃祖临崩，诸君亲升御床，并蒙眷识，共奉遗诏。孔坦疏贱，不在顾命之列。既有艰难，则以微臣为先，今犹俎上腐肉，任人脍截耳！”于是拂衣而去，诸公亦止。|| 苏峻之乱平定后，王导、庾亮等人想任用孔坦做丹阳尹。当时经过战乱流离，百姓困苦凋敝，孔坦感慨地说：“当年明帝临终时，诸位都亲自登上御床前，一同蒙受先帝的眷顾赏识，共同接受遗诏。我孔坦关系疏远、地位低微，不在顾命大臣之列。如今有了艰难的差事，倒先推我出来，我简直就像砧板上的一块腐肉，任凭别人切割罢了！”于是拂袖而去，诸位大臣也就作罢了。
注：苏子高：苏峻，字子高。
注：孔廷尉：孔坦，字君平，会稽山阴人，官至廷尉。丹阳：丹阳尹，京畿所在郡的长官。
注：肃祖：晋明帝的庙号。御床：皇帝的卧床。顾命：君主临终托付后事。
注：俎（zǔ）：切肉的砧板。脍（kuài）：把肉切细。

# 三十八｜孔车骑与中丞共行
原：孔车骑与中丞共行，在御道逢匡术，宾从甚盛，因往与车骑共语。中丞初不视，直云：“鹰化为鸠，众鸟犹恶其眼。”术大怒，便欲刃之。车骑下车，抱术曰：“族弟发狂，卿为我宥之！”始得全首领。|| 孔愉和孔群一同出行，在御道上遇到匡术，匡术随从宾客很多，便过来和孔愉说话。孔群一眼也不看他，只是说：“鹰变成了鸠，众鸟还是讨厌它的眼睛。”匡术大怒，当即要拔刀杀他。孔愉下车抱住匡术说：“我族弟发疯了，请您看在我面上饶了他吧！”孔群这才保全了脑袋。
注：孔车骑：孔愉，字敬康，会稽山阴人，死后追赠车骑将军。中丞：孔群，时任御史中丞。
注：御道：京城中专供皇帝车驾通行的大道。
注：初不视：根本不看。初，全然。
注：宥（yòu）：宽恕。首领：头颅，指性命。

# 三十九｜梅颐尝有惠于陶公
原：梅颐尝有惠于陶公。后为豫章太守，有事，王丞相遣收之。侃曰：“天子富于春秋，万机自诸侯出，王公既得录，陶公何为不可放？”乃遣人于江口夺之。颐见陶公，拜，陶公止之。颐曰：“梅仲真膝，明日岂可复屈邪？”|| 梅颐曾经对陶侃有恩。后来梅颐做豫章太守，犯了事，丞相王导派人去逮捕他。陶侃说：“天子年纪还小，国家政事都由诸侯做主，王公既然能抓人，我陶公为什么不能放人？”于是派人在江口把梅颐夺了回来。梅颐见到陶侃，下拜，陶侃拦住了他。梅颐说：“我梅仲真的膝盖，明天难道还能再向别人弯下吗？”
注：梅颐：字仲真，汝南西平人，曾任豫章太守。
注：陶公：陶侃，字士行，东晋名将，时为荆州刺史，镇守上游。
注：富于春秋：年纪尚轻，指成帝年幼。万机：日常繁多的政务。
注：录：逮捕拘押。末句意谓：今日拜了救命恩人，往后便不再向他人屈膝。

# 四十｜王丞相作女伎
原：王丞相作女伎，施设床席。蔡公先在坐，不说而去，王亦不留。|| 丞相王导安排女伎表演，摆设了坐榻席位。蔡谟原先已在座，很不高兴地走了，王导也不挽留他。
注：女伎（jì）：表演歌舞的女艺人。
注：蔡公：蔡谟，字道明，陈留考城人，为人方正，官至司徒（辞不就）。
注：说：同“悦”。

# 四十一｜何次道、庾季坚二人
原：何次道、庾季坚二人并为元辅。成帝初崩，于时嗣君未定。何欲立嗣子，庾及朝议以外寇方强，嗣子冲幼，乃立康帝。康帝登阼，会群臣，谓何曰：“朕今所以承大业，为谁之议？”何答曰：“陛下龙飞，此是庾冰之功，非臣之力。于时用微臣之议，今不睹盛明之世。”帝有惭色。|| 何充、庾冰二人同为辅政大臣。成帝刚去世时，继位的君主还没定下来。何充想立成帝的嫡子，庾冰和朝臣们的意见则认为外敌正强，嫡子太年幼，于是立了康帝。康帝即位后，会见群臣，对何充说：“朕如今之所以能继承大业，是谁的主意？”何充回答说：“陛下登上帝位，这是庾冰的功劳，不是我的力量。当时如果采用了我的意见，今天就看不到这样的盛明之世了。”康帝面有惭色。
注：何次道：何充，字次道，庐江灊县人，东晋重臣。庾季坚：庾冰，字季坚，庾亮之弟。元辅：首要的辅政大臣。
注：嗣子：成帝的儿子，即后来的哀帝、废帝，当时尚在襁褓。冲幼：年幼。
注：康帝：司马岳，成帝同母弟。登阼（zuò）：即位。
注：龙飞：比喻帝王即位。何充的答话表面恭维，实则直言当初并不赞成立康帝。

# 四十二｜江仆射年少
原：江仆射年少，王丞相呼与共棋。王手尝不如两道许，而欲敌道戏，试以观之。江不即下。王曰：“君何以不行？”江曰：“恐不得尔。”傍有客曰：“此年少戏乃不恶。”王徐举首曰：“此年少非唯围棋见胜。”|| 江虨年轻时，丞相王导叫他一起下围棋。王导的棋艺本来要比他差两子左右，却想不让子平下，借此看看他。江虨不立刻落子。王导说：“你为什么不走棋？”江虨说：“恐怕不能这样下。”旁边有位客人说：“这年轻人的棋下得还真不坏。”王导慢慢抬起头说：“这年轻人不只是围棋比人强。”
注：江仆射：江虨（bīn），字思玄，陈留圉县人，官至尚书仆射。
注：手：棋艺。道：棋盘上的格路，代指棋子。许：表示约数。
注：敌道戏：双方对等下棋，不让子。
注：恐不得尔：江虨不肯迁就长辈而失棋理，正见其方正。

# 四十三｜孔君平疾笃
原：孔君平疾笃，庾司空为会稽，省之。相问讯甚至，为之流涕。庾既下床，孔慨然曰：“大丈夫将终，不问安国宁家之术，乃作儿女子相问！”庾闻，回谢之，请其话言。|| 孔坦病重，庾冰当时任会稽内史，去探望他。庾冰问候得十分周到，还为他流下眼泪。庾冰离开坐榻后，孔坦感慨地说：“大丈夫临死，你不问安邦定国的办法，却像小儿女一样来问候我！”庾冰听了，转身向他道歉，请他留下遗言。
注：孔君平：孔坦，字君平。疾笃：病重。
注：庾司空：庾冰，死后追赠司空。为会稽：任会稽内史。
注：省（xǐng）：探望。问讯：问候。至：周到恳切。
注：谢：道歉。话言：有益的言论，这里指临终嘱托。

# 四十四｜桓大司马诣刘尹
原：桓大司马诣刘尹，卧不起。桓弯弹弹刘枕，丸迸碎床褥间。刘作色而起曰：“使君，如馨地宁可斗战求胜？”桓甚有恨容。|| 大司马桓温去拜访刘惔，刘惔躺着不起身。桓温拉开弹弓去射刘惔的枕头，弹丸迸碎在床褥之间。刘惔变了脸色起身说：“使君，这样子难道就能打仗取胜吗？”桓温脸上露出很恼恨的神色。
注：桓大司马：桓温，字元子，谯国龙亢人，东晋权臣，官至大司马。刘尹：刘惔，字真长，沛国相县人，曾任丹阳尹，清谈名士。
注：使君：对州郡长官的尊称。
注：如馨（xīn）地：这样，如此，晋时口语。
注：斗战求胜：刘惔借弹弓射枕讥讽桓温用兵不利，触其痛处。

# 四十五｜后来年少多有道深公者
原：后来年少多有道深公者，深公谓曰：“黄吻年少，勿为评论宿士。昔尝与元明二帝、王庾二公周旋。”|| 后辈年轻人很多都议论竺法深，竺法深对他们说：“黄口小儿，不要随便评论前辈名士。我从前曾经和元帝、明帝两位皇帝，以及王导、庾亮两位大人交往过。”
注：深公：竺法深，名潜，东晋高僧，出身琅邪王氏，与名士交游。
注：黄吻：雏鸟嘴边的黄色，喻年幼无知。
注：宿士：年高有声望的人。周旋：交往应酬。

# 四十六｜王中郎年少时
原：王中郎年少时，江虨为仆射，领选，欲拟之为尚书郎。有语王者，王曰：“自过江来，尚书郎正用第二人，何得拟我！”江闻而止。|| 王坦之年轻时，江虨任尚书仆射，主管选拔官员，打算提名他做尚书郎。有人告诉了王坦之，王坦之说：“自从南渡过江以来，尚书郎只用第二流的人，怎么能提名我！”江虨听说后便作罢了。
注：王中郎：王坦之，字文度，太原晋阳人，王述之子，曾任北中郎将。
注：领选：主管官员选任。拟：拟议，提名。
注：第二人：第二流人物。东晋重门第，尚书郎已被高门视为不够清贵的职位。

# 四十七｜王述转尚书令
原：王述转尚书令，事行便拜。文度曰：“故应让杜、许。”蓝田云：“汝谓我堪此不？”文度曰：“何为不堪！但克让自是美事，恐不可阙。”蓝田慨然曰：“既云堪，何为复让？人言汝胜我，定不如我。”|| 王述调任尚书令，任命一下达就接受了。王坦之说：“按理总该推让给杜、许二人吧。”王述说：“你认为我能不能胜任这个职位？”王坦之说：“怎么不能胜任！只是能够谦让本身是美事，恐怕这个礼节不能缺。”王述感慨地说：“既然说能胜任，为什么还要推让？人家都说你胜过我，我看你到底不如我。”
注：王述：字怀祖，太原晋阳人，袭爵蓝田侯，故称“蓝田”。转：调任。
注：拜：接受官职。故应：本来应当。杜、许：所指未详，存疑。
注：克让：能够谦让。阙：同“缺”。

# 四十八｜孙兴公作《庾公诔》
原：孙兴公作《庾公诔》，文多托寄之辞。既成，示庾道恩。庾见，慨然送还之，曰：“先君与君自不至于此。”|| 孙绰写了一篇《庾公诔》，文中有很多寄托自己与死者深情厚谊的话。写成后，拿给庾羲看。庾羲看了，很感慨地把文章送还给他，说：“先父和您，本来还没有到这样的交情。”
注：孙兴公：孙绰，字兴公，太原中都人，东晋文学家，以文才著称。
注：《庾公诔（lěi）》：悼念庾亮的诔文。诔，叙述死者生平、表示哀悼的文体。
注：托寄之辞：借诔文寄托与死者交情的言辞。
注：庾道恩：庾羲，小字道恩，庾亮之子。

# 四十九｜王长史求东阳
原：王长史求东阳，抚军不用。后疾笃，临终，抚军哀叹曰：“吾将负仲祖。”于此命用之。长史曰：“人言会稽王痴，真痴。”|| 王濛请求出任东阳太守，抚军司马昱没有用他。后来王濛病重，临终时，司马昱哀叹说：“我将要对不起仲祖了。”于是下令任用他。王濛说：“人家说会稽王痴，真是痴啊。”
注：王长史：王濛，字仲祖，太原晋阳人，曾任司徒左长史，清谈名士。东阳：东阳郡，此指东阳太守之职。
注：抚军：司马昱，时任抚军大将军，封会稽王，即后来的简文帝。
注：痴：王濛嫌他临终才任用，于事无补，用人不当其时，故讥之。

# 五十｜刘简作桓宣武别驾
原：刘简作桓宣武别驾，后为东曹参军，颇以刚直见疏。尝听记，简都无言。宣武问：“刘东曹何以不下意？”答曰：“会不能用。”宣武亦无怪色。|| 刘简做桓温的别驾，后来任东曹参军，因为太刚直而被疏远。有一次听桓温议论公文政事，刘简一言不发。桓温问：“刘东曹为什么不说说意见？”刘简回答：“说了反正也不会被采用。”桓温也没有怪罪的神色。
注：刘简：字仲约，南阳人，曾为桓温僚属。桓宣武：桓温，谥宣武。
注：别驾：州刺史的佐官。东曹参军：将军府中掌管人事的属官。
注：记：公府中的教令文书。下意：发表意见。
注：会：反正，总归。

# 五十一｜刘真长、王仲祖共行
原：刘真长、王仲祖共行，日旰未食。有相识小人贻其餐，肴案甚盛，真长辞焉。仲祖曰：“聊以充虚，何苦辞？”真长曰：“小人都不可与作缘。”|| 刘惔和王濛一同出行，天色晚了还没吃饭。有个相识的小人物给他们送来饭食，菜肴摆得很丰盛，刘惔推辞不吃。王濛说：“姑且用来充饥，何苦推辞？”刘惔说：“小人物全都不能跟他们打交道。”
注：刘真长：刘惔。王仲祖：王濛。
注：日旰（gàn）：天色已晚。
注：小人：当时士族对平民、仆役等身份低下者的称呼。肴案：盛菜肴的木盘。
注：充虚：充饥。作缘：结交，攀上关系。

# 五十二｜王修龄尝在东山
原：王修龄尝在东山，甚贫乏。陶胡奴为乌程令，送一船米遗之。却不肯取，直答语：“王修龄若饥，自当就谢仁祖索食，不须陶胡奴米。”|| 王胡之曾经住在东山，生活很贫困。陶范当乌程县令，送了一船米给他。王胡之推辞不肯收，直截了当地回话说：“我王修龄如果饿了，自然会到谢仁祖那里去要饭吃，用不着陶胡奴的米。”
注：王修龄：王胡之，字修龄，琅邪临沂人，王廙之子。东山：在今浙江上虞，名士隐居之地。
注：陶胡奴：陶范，小字胡奴，陶侃之子；陶家出身寒门，故王胡之轻视他。
注：遗（wèi）：赠送。却：推辞。
注：谢仁祖：谢尚，字仁祖，陈郡阳夏人，出身高门。

# 五十三｜阮光禄赴山陵
原：阮光禄赴山陵，至都，不往殷、刘许，过事便还。诸人相与追之，阮亦知时流必当逐己，乃遄疾而去，至方山不相及。刘尹时为会稽，乃叹曰：“我入，当泊安石渚下耳，不敢复近思旷傍。伊便能捉杖打人，不易。”|| 阮裕赶赴京城参加皇帝的葬礼，到了京都，不去殷浩、刘惔那里，葬礼一过便回去了。众人一起去追他，阮裕也知道当时的名流一定会追自己，就急速离开了，众人一直追到方山也没追上。刘惔当时正要去做会稽内史，于是感叹说：“我到了东边，就把船停在谢安石的小洲下好了，不敢再靠近思旷身边。他是能拿起棍子打人的，不好对付啊。”
注：阮光禄：阮裕，字思旷，陈留尉氏人，曾授金紫光禄大夫，性好隐逸。山陵：帝王陵墓，此指成帝葬礼。
注：殷、刘：殷浩、刘惔。许：处所。
注：遄（chuán）疾：急速。方山：在今江苏南京东南，为出京东行的要道。
注：安石：谢安，字安石。渚（zhǔ）：水中小洲。伊：他。捉杖打人：比喻阮裕对追逐名利者毫不客气。

# 五十四｜王、刘与桓公共至覆舟山看
原：王、刘与桓公共至覆舟山看。酒酣后，刘牵脚加桓公颈。桓公甚不堪，举手拨去。既还，王长史语刘曰：“伊讵可以形色加人不？”|| 王濛、刘惔和桓温一同到覆舟山游览。酒喝得正酣时，刘惔把脚搁到桓温的脖子上。桓温很受不了，抬手把它拨开了。回来以后，王濛对刘惔说：“他难道可以把脸色摆给人看吗？”
注：王、刘：王濛、刘惔。覆舟山：在今江苏南京东北，因山形如倒扣的船而得名。
注：伊：他，指桓温。讵（jù）：岂，难道。
注：形色加人：把喜怒表露在脸上给人看。魏晋名士以喜怒不形于色为高，王濛此言是讥桓温不能自持。

# 五十五｜桓公问桓子野
原：桓公问桓子野：“谢安石料万石必败，何以不谏？”子野答曰：“故当出于难犯耳。”桓作色曰：“万石挠弱凡才，有何严颜难犯！”|| 桓温问桓伊：“谢安石料到谢万石一定会失败，为什么不劝阻他？”桓伊回答：“大概是因为他不好冒犯吧。”桓温变了脸色说：“万石是个懦弱的平庸之才，有什么威严让人不敢冒犯！”
注：桓子野：桓伊，字叔夏，小字子野，谯国铚县人，善吹笛，后为淝水之战名将。
注：万石：谢万，字万石，谢安之弟，北伐时溃败被废。
注：故当：大概，想必。难犯：难以冒犯。
注：挠（náo）弱：怯懦软弱。

# 五十六｜罗君章曾在人家
原：罗君章曾在人家，主人令与坐上客共语。答曰：“相识已多，不烦复尔。”|| 罗含曾在别人家做客，主人让他和座上的客人交谈。他回答说：“我认识的人已经够多了，不必再这样麻烦了。”
注：罗君章：罗含，字君章，桂阳耒阳人，有文才，为桓温所器重，官至廷尉、长沙相。
注：不烦复尔：不必再这样。尔，如此。

# 五十七｜韩康伯病
原：韩康伯病，拄杖前庭消摇。见诸谢皆富贵，轰隐交路，叹曰：“此复何异王莽时！”|| 韩康伯病了，拄着拐杖在前庭散步。看到谢家诸人个个富贵显赫，车马轰鸣，往来不绝，感叹道：“这跟王莽那个时候又有什么两样！”
注：韩康伯：韩伯，字康伯，颍川长社人，玄学家，曾注《周易·系辞》。
注：消摇：同“逍遥”，悠闲散步。
注：诸谢：指谢安一门子弟。轰隐交路：车马声隆隆，在道路上交错往来。
注：王莽：西汉末外戚，专权后篡汉建新朝。韩康伯借此讥谢氏一门权势过盛。

# 五十八｜王文度为桓公长史时
原：王文度为桓公长史时，桓为儿求王女，王许咨蓝田。既还，蓝田爱念文度，虽长大犹抱著膝上。文度因言桓求己女婚。蓝田大怒，排文度下膝，曰：“恶见！文度已复痴，畏桓温面？兵，那可嫁女与之！”|| 王坦之做桓温长史的时候，桓温替儿子向王坦之的女儿求婚，王坦之答应回去和父亲商量。¦回家后，王述疼爱王坦之，虽然儿子已经长大成人，还是把他抱在膝上。¦王坦之趁机说起桓温求娶自己女儿的事。¦王述大怒，把王坦之从膝上推下去，说：“真是糊涂见识！¦文度你又犯傻了吗？怕得罪桓温的面子？¦一个当兵的，怎么能把女儿嫁给他家！”
注：王文度：王坦之。桓公：桓温。长史：将军府属官之首。
注：咨：商量。蓝田：王述，王坦之之父。
注：恶见：糟糕的见解。
注：兵：当兵的。桓氏以武功起家，王述以门第自高，故轻之。
原：文度还报云：“下官家中先得婚处。”桓公曰：“吾知矣，此尊府君不肯耳。”后桓女遂嫁文度儿。|| 王坦之回复桓温说：“下官家里已经先给女儿找好了婆家。”桓温说：“我明白了，这是令尊大人不肯罢了。”后来桓温的女儿倒嫁给了王坦之的儿子。
注：尊府君：对对方父亲的敬称。
注：文度儿：王坦之之子王愷，存疑。

# 五十九｜王子敬数岁时
原：王子敬数岁时，尝看诸门生樗蒲，见有胜负，因曰：“南风不竞。”门生辈轻其小儿，乃曰：“此郎亦管中窥豹，时见一斑。”子敬瞋目曰：“远惭荀奉倩，近愧刘真长。”遂拂衣而去。|| 王献之才几岁时，有一次看门客们玩樗蒲，看出了胜负之势，便说：“南边的要输。”门客们轻视他是个小孩子，就说：“这位小郎君也是从竹管里看豹子，偶尔看到一块斑纹罢了。”王献之瞪着眼说：“远的我惭愧比不上荀奉倩，近的我愧对刘真长。”于是拂袖而去。
注：王子敬：王献之，字子敬，王羲之之子，书法家。
注：门生：依附于士族门下的人。樗蒲（chū pú）：古代一种掷采赌博的游戏。
注：南风不竞：语出《左传》，原指南方楚军士气不振，这里借指坐在南边的一方要输。
注：管中窥豹：从管孔里看豹，只见一斑。荀奉倩：荀粲，字奉倩，三国魏人，以清高不交俗客著称；刘真长：刘惔，亦以不与小人打交道著称。王献之意谓自己不屑与门生辈交往，有愧于二人。

# 六十｜谢公闻羊绥佳
原：谢公闻羊绥佳，致意令来，终不肯诣。后绥为太学博士，因事见谢公，公即取以为主簿。|| 谢安听说羊绥人品好，托人传话让他来见，他始终不肯登门。后来羊绥做了太学博士，因公事去见谢安，谢安当即任用他做了主簿。
注：谢公：谢安。羊绥：字仲彦，泰山人，官至中书侍郎。
注：致意：托人传达心意。诣：拜访。
注：太学博士：太学中的教官。主簿：府中掌管文书的重要属官。

# 六十一｜王右军与谢公诣阮公
原：王右军与谢公诣阮公，至门，语谢：“故当共推主人。”谢曰：“推人正自难。”|| 王羲之和谢安去拜访阮裕，到了门口，王羲之对谢安说：“我们自然应该一起推崇主人。”谢安说：“推崇别人，正是难事。”
注：王右军：王羲之，字逸少，曾任右军将军。阮公：阮裕。
注：故当：本当，自然应该。推：推崇，推许。
注：推人正自难：谢安意谓不肯随口奉承人，存心方正。

# 六十二｜太极殿始成
原：太极殿始成，王子敬时为谢公长史，谢送版，使王题之。王有不平色，语信云：“可掷著门外。”谢后见王，曰：“题之上殿何若？昔魏朝韦诞诸人，亦自为也。”王曰：“魏祚所以不长。”谢以为名言。|| 太极殿刚建成，王献之当时任谢安的长史，谢安派人送去匾额木板，让王献之题字。王献之露出不平的神色，对送信的人说：“可以把它扔到门外。”谢安后来见到王献之，说：“把字题好挂上大殿怎么样？从前魏朝的韦诞等人，也是亲自做过这种事的。”王献之说：“这就是魏朝国运不长的原因。”谢安认为这是名言。
注：太极殿：东晋宫城中的正殿，孝武帝时重修。
注：版：用来做匾额的木板。信：送信的使者。
注：韦诞：字仲将，三国魏书法家，相传曾被吊上凌云台题匾，下来后须发皆白，告诫子孙勿学书法。
注：祚（zuò）：国运。王献之以为让士大夫做工匠之事是轻贱人才，故有此语。

# 六十三｜王恭欲请江卢奴为长史
原：王恭欲请江卢奴为长史，晨往诣江，江犹在帐中。王坐，不敢即言，良久乃得及。江不应，直唤人取酒，自饮一碗，又不与王。王且笑且言：“那得独饮？”江云：“卿亦复须邪？”更使酌与王，王饮酒毕，因得自解去。未出户，江叹曰：“人自量，固为难。”|| 王恭想请江敳做他的长史，一早就去拜访江敳，江敳还在床帐里没起来。王恭坐着，不敢马上开口，过了好久才说到这件事。江敳不答话，只是叫人拿酒来，自己喝了一碗，也不给王恭。王恭边笑边说：“怎么能一个人喝呢？”江敳说：“你也要喝吗？”这才又叫人给王恭斟酒，王恭喝完，借机脱身告辞。还没走出门，江敳叹道：“人要估量自己，本来就是难事啊。”
注：王恭：字孝伯，太原晋阳人，孝武帝皇后之兄，东晋后期重臣。
注：江卢奴：江敳（ái），字仲凯，小字卢奴，江虨之子。
注：自解去：找个台阶自行告辞。
注：人自量，固为难：江敳讥王恭不自量力，竟想让自己屈居其下。

# 六十四｜孝武问王爽
原：孝武问王爽：“卿何如卿兄？”王答曰：“风流秀出，臣不如恭，忠孝亦何可以假人！”|| 孝武帝问王爽：“你比你哥哥怎么样？”王爽回答：“风度出众，我不如王恭；至于忠孝，又怎么能让给别人！”
注：孝武：东晋孝武帝司马曜。王爽：王恭之弟，官至侍中。
注：风流：风度仪态。秀出：优秀出众。
注：假人：让给别人。

# 六十五｜王爽与司马太傅饮酒
原：王爽与司马太傅饮酒。太傅醉，呼王为“小子”。王曰：“亡祖长史，与简文皇帝为布衣之交。亡姑、亡姊，伉俪二宫。何小子之有？”|| 王爽和太傅司马道子一起喝酒。司马道子喝醉了，叫王爽为“小子”。王爽说：“我已故的祖父长史，和简文皇帝是布衣之交。我已故的姑母、姐姐，都是两代宫中的皇后。哪来什么小子？”
注：司马太傅：司马道子，简文帝之子，孝武帝之弟，专权于东晋后期。
注：亡祖长史：王濛，王爽的祖父，曾任司徒左长史。布衣之交：未显贵时的朋友。
注：亡姑：王濛之女王穆之，晋哀帝皇后。亡姊：王法慧，孝武帝皇后。伉俪二宫：在两代宫中作配为后。
注：王爽之意：司马道子是简文帝之子，论辈分、论门第都没资格称他“小子”。

# 六十六｜张玄与王建武先不相识
原：张玄与王建武先不相识，后遇于范豫章许，范令二人共语。张因正坐敛衽，王孰视良久，不对。张大失望，便去。范苦譬留之，遂不肯住。|| 张玄和王忱原先互不相识，后来在范宁家里遇到，范宁让两人交谈。张玄于是端坐整好衣襟，王忱盯着他看了好一会儿，却不答话。张玄大失所望，便要离开。范宁苦苦劝解挽留他，他终究不肯留下。
注：张玄：张玄之，字祖希，吴郡人，以才学著称，与谢玄并称“南北二玄”。
注：王建武：王忱，字元达，小字佛大，王坦之之子，曾任建武将军。范豫章：范宁，字武子，曾任豫章太守，王忱的舅父。许：处所。
注：敛衽（rèn）：整理衣襟，表示恭敬。孰视：仔细看。孰，同“熟”。
注：苦譬：极力开导劝解。
原：范是王之舅，乃让王曰：“张玄，吴士之秀，亦见遇于时，而使至于此，深不可解。”王笑曰：“张祖希若欲相识，自应见诣。”范驰报张，张便束带造之。遂举觞对语，宾主无愧色。|| 范宁是王忱的舅舅，于是责备王忱说：“张玄是吴地士人中的佼佼者，也受到当时的器重，你却让他落到这种地步，实在叫人不能理解。”王忱笑着说：“张祖希如果想结识我，自然应该登门来拜访。”范宁赶快把话告诉张玄，张玄便穿戴整齐去拜访王忱。两人于是举杯对谈，宾主都没有愧色。
注：让：责备。见遇于时：受到当时人的赏识。
注：束带：束好衣带，穿戴整齐，表示郑重。造：登门拜访。
注：宾主无愧色：意谓按礼相见，双方都不失身份。
