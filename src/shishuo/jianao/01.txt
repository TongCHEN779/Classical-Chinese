# 本门导读
题解：简傲，是怠慢礼数、目中无人的态度。魏晋名士常借箕踞、不答、不顾主人之类举动表达对世俗名分的蔑视，其中有真率洒脱，也不乏骄矜失礼。

# 一｜晋文王功德盛大
原：晋文王功德盛大，坐席严敬，拟于王者。唯阮籍在坐，箕踞啸歌，酣放自若。|| 晋文王司马昭功业德望极盛，他座席上的人都庄重恭敬，排场与帝王相当。只有阮籍在座时，叉开两腿坐着，又长啸又唱歌，畅饮放纵，旁若无事。
注：晋文王：司马昭，魏末权臣，其子司马炎代魏后追尊为文帝。
注：箕踞：两腿伸直岔开而坐，形似簸箕，在当时是极不恭敬的坐姿。
注：酣放：纵酒放任。

# 二｜王戎弱冠诣阮籍
原：王戎弱冠诣阮籍，时刘公荣在坐。阮谓王曰：“偶有二斗美酒，当与君共饮，彼公荣者无预焉。”二人交觞酬酢，公荣遂不得一杯，而言语谈戏，三人无异。或有问之者，阮答曰：“胜公荣者，不得不与饮酒；不如公荣者，不可不与饮酒；唯公荣，可不与饮酒。”|| 王戎二十岁左右去拜访阮籍，当时刘公荣也在座。阮籍对王戎说：“碰巧有两斗好酒，该和你一起喝，那位公荣就不必参与了。”两人你敬我、我敬你，刘公荣始终没喝上一杯，可说笑谈天，三个人并无两样。有人问起这事，阮籍答道：“比公荣强的人，不能不和他喝；不如公荣的人，又不可不和他喝；只有公荣，可以不和他喝。”
注：弱冠：古代男子二十岁行冠礼，体格尚未强壮，故称二十岁左右为弱冠。
注：刘公荣：刘昶，字公荣，以好酒、与人不择而饮著称。
注：交觞酬酢：互相举杯劝酒。酬，主敬客；酢（zuò），客回敬。
注：阮籍的话套用了刘公荣自己“胜我者不可不饮”之类的口头禅，借此调侃他。

# 三｜钟士季精有才理
原：钟士季精有才理，先不识嵇康，钟要于时贤俊之士，俱往寻康。康方大树下锻，向子期为佐鼓排。康扬槌不辍，傍若无人，移时不交一言。钟起去，康曰：“何所闻而来？何所见而去？”钟曰：“闻所闻而来，见所见而去。”|| 钟会精明有才思，原先不认识嵇康，他邀集当时的一批才俊之士，一同去拜访嵇康。嵇康正在大树下打铁，向秀在旁替他拉风箱。嵇康不停地挥锤，旁若无人，过了好一阵也不跟他们说一句话。钟会起身要走，嵇康问：“听说了什么而来？看到了什么而去？”钟会答：“听到了所听到的而来，看到了所看到的而去。”
注：钟士季：钟会，字士季，魏太傅钟繇之子，后为司马氏重臣，嵇康之死与他的谗言有关。
注：要（yāo）：邀请。
注：向子期：向秀，字子期，竹林七贤之一，与嵇康交好。
注：鼓排：拉动风箱鼓风。排，冶铁用的鼓风器。

# 四｜嵇康与吕安善
原：嵇康与吕安善，每相思，千里命驾。安后来，值康不在，喜出户延之，不入，题门上作“凤”去。喜不觉，犹以为欣，故作。“凤”字凡鸟也。|| 嵇康和吕安交情很深，每当想念对方，就算相隔千里也要备车去相见。后来吕安来访，正碰上嵇康不在家，嵇喜出门迎他进去，吕安不进门，在门上写了个“凤”字就走了。嵇喜没有察觉，还以为是夸他，所以才写这个字。其实“凤”字拆开来就是“凡鸟”。
注：吕安：字仲悌，嵇康好友，后受诬下狱，嵇康为他辩护而一同被杀。
注：喜：嵇喜，字公穆，嵇康之兄，入仕为官，为阮籍、吕安等所轻。
注：凡鸟：繁体“鳳”由“凡”“鳥”构成，吕安借此讥嵇喜是庸常之辈。

# 五｜陆士衡初入洛
原：陆士衡初入洛，咨张公所宜诣，刘道真是其一。陆既往，刘尚在哀制中。性嗜酒，礼毕，初无他言，唯问：“东吴有长柄壶卢，卿得种来不？”陆兄弟殊失望，乃悔往。|| 陆机初到洛阳，向张华请教该去拜访哪些人，刘道真是其中之一。陆机兄弟去了，刘道真还在服丧期间。他生性好酒，见过礼后，一句别的话也没有，只问：“东吴有一种长柄葫芦，你们带了种子来没有？”陆氏兄弟大失所望，后悔这一趟。
注：陆士衡：陆机，字士衡，吴郡人，吴亡后与弟陆云入洛，以文才名世。
注：张公：张华，西晋名臣，好奖掖后进。
注：刘道真：刘宝，字道真。
注：哀制：守丧期间。服丧本应戒酒，他却只惦着盛酒的葫芦，可见其简傲。

# 六｜王平子出为荆州
原：王平子出为荆州，王太尉及时贤送者倾路。时庭中有大树，上有鹊巢，平子脱衣巾，径上树取鹊子，凉衣拘阂树枝，便复脱去。得鹊子还下弄，神色自若，傍若无人。|| 王澄出任荆州刺史，王衍和当时的名士来送行的挤满了道路。当时院中有棵大树，上面有个喜鹊窝，王澄脱掉外衣和头巾，径直爬上树去掏小喜鹊，贴身的衣服被树枝挂住，就干脆又脱了。掏到小鹊后下树摆弄，神色自如，旁若无人。
注：王平子：王澄，字平子，王衍之弟，以放诞著称。
注：王太尉：王衍，西晋清谈领袖，官至太尉。
注：凉衣：贴身的单衣。拘阂：钩挂、阻碍。

# 七｜高坐道人于丞相坐
原：高坐道人于丞相坐，恒偃卧其侧。见卞令，肃然改容云：“彼是礼法人。”|| 高坐和尚在丞相王导家作客，常常仰面躺在王导身边。一见卞壸来了，就收敛神色端正起来，说：“他是讲究礼法的人。”
注：高坐道人：西域来华僧人帛尸梨蜜多罗，时人称“高坐”。道人，当时对僧人的称呼。
注：丞相：王导。
注：卞令：卞壸（kǔn），字望之，官尚书令，为人方正守礼。

# 八｜桓宣武作徐州
原：桓宣武作徐州，时谢奕为晋陵，先粗经虚怀，而乃无异常。及桓迁荆州，将西之间，意气甚笃，奕弗之疑。唯谢虎子妇王悟其旨，每曰：“桓荆州用意殊异，必与晋陵俱西矣。”俄而引奕为司马。|| 桓温任徐州刺史时，谢奕任晋陵太守，两人起初只是略有往来、客气相待，并没有什么特别。等到桓温调任荆州，将要西行的那段时间，对谢奕情意十分殷切，谢奕并没起疑。只有谢据的妻子王氏看出了其中用意，常说：“桓荆州的心思很不一般，一定要带晋陵一起西去了。”不久，桓温果然举荐谢奕做了司马。
注：桓宣武：桓温，谥宣武。作徐州：任徐州刺史。
注：谢奕：字无奕，谢安之兄。为晋陵：任晋陵太守。
注：粗经虚怀：大致有过一些谦和的往来，交情尚浅。
注：谢虎子：谢据，小字虎子，谢奕之弟。妇王：其妻王氏。
原：奕既上，犹推布衣交。在温坐，岸帻啸咏，无异常日。宣武每曰：“我方外司马。”遂因酒，转无朝夕礼。桓舍入内，奕辄复随去。后至奕醉，温往主许避之。主曰：“君无狂司马，我何由得相见？”|| 谢奕上任以后，仍旧把桓温当作布衣之交。在桓温座上，他把头巾推起露出额头，长啸吟咏，和平日毫无二致。桓温常说：“这是我的方外司马。”后来他借着酒兴，连早晚该有的礼节也不讲了。桓温躲开他进入内室，谢奕总是又跟了进去。到后来谢奕一喝醉，桓温就跑到公主那里去躲他。公主说：“您要是没有这位狂司马，我哪有机会见到您呢？”
注：布衣交：不论官位贵贱的平交朋友。
注：岸帻（zé）：把头巾推高，露出额头，是洒脱不拘的样子。
注：方外：世俗礼法之外。
注：主：桓温之妻南康长公主。许：处所。

# 九｜谢万在兄前
原：谢万在兄前，欲起索便器。于时阮思旷在坐曰：“新出门户，笃而无礼。”|| 谢万在兄长面前，要起身去找便壶。当时阮裕在座，说：“新兴起来的人家，人倒厚道，就是不懂礼数。”
注：谢万：字万石，谢安之弟。
注：便器：便壶、溺器。
注：阮思旷：阮裕，字思旷，出身陈留阮氏旧族。
注：新出门户：新近显贵起来的家族，暗讽谢氏门第不如旧族深厚。

# 十｜谢中郎是王蓝田女婿
原：谢中郎是王蓝田女婿，尝著白纶巾，肩舆径至扬州听事，见王，直言曰：“人言君侯痴，君侯信自痴。”蓝田曰：“非无此论，但晚令耳。”|| 谢万是王述的女婿，有一次戴着白纶巾，坐着肩舆直接到了扬州刺史府的厅堂，见了王述，直截了当地说：“人家都说您痴，您果然是痴。”王述说：“并不是没有这种说法，只不过我是晚年才有了好名声罢了。”
注：谢中郎：谢万，曾任从事中郎。王蓝田：王述，袭爵蓝田侯，时任扬州刺史。
注：纶（guān）巾：配有青丝带的头巾，是闲居便服，见长辈、长官时戴之属失礼。
注：肩舆：两人抬的轿子。听事：官署厅堂。
注：晚令：晚年才得令名。王述早年因性情迟缓被人目为痴，后渐以清贞知名。

# 十一｜王子猷作桓车骑骑兵参军
原：王子猷作桓车骑骑兵参军，桓问曰：“卿何署？”答曰：“不知何署，时见牵马来，似是马曹。”桓又问：“官有几马？”答曰：“不问马，何由知其数？”又问：“马比死多少？”答曰：“未知生，焉知死？”|| 王徽之做桓冲的骑兵参军，桓冲问他：“你在哪个部门？”他答：“不知道是哪个部门，常看见有人牵马进来，大概是马曹吧。”桓冲又问：“官府里有多少马？”他答：“孔子不问马，我怎么知道有多少？”又问：“马近来死了多少？”他答：“活的都不知道，哪知道死的？”
注：王子猷：王徽之，字子猷，王羲之之子，性情放诞。
注：桓车骑：桓冲，桓温之弟，官车骑将军。
注：不问马：《论语·乡党》载马厩失火，孔子只问伤人没有，“不问马”。
注：未知生，焉知死：《论语·先进》孔子答子路语，此处借来答马的死亡数。比：近来。

# 十二｜谢公尝与谢万共出西
原：谢公尝与谢万共出西，过吴郡，阿万欲相与共萃王恬许，太傅云：“恐伊不必酬汝，意不足尔。”万犹苦要，太傅坚不回，万乃独往。|| 谢安曾和谢万一道西行去京城，路过吴郡，谢万想约谢安一起到王恬那里去聚聚，谢安说：“恐怕他未必会搭理你，我看不值得去。”谢万还是再三邀请，谢安坚决不改主意，谢万只好一个人去了。
注：谢公、太傅：谢安。
注：萃：聚会。王恬：字敬豫，小字螭虎，王导次子。许：住处。
注：苦要（yāo）：极力邀请。
原：坐少时，王便入门内，谢殊有欣色，以为厚待己。良久，乃沐头散发而出，亦不坐，仍据胡床，在中庭晒头，神气傲迈，了无相酬对意。谢于是乃还，未至船，逆呼太傅，安曰：“阿螭不作尔！”|| 坐了不一会儿，王恬就进里屋去了，谢万颇有喜色，以为他要好好款待自己。过了很久，王恬才洗了头、披着头发出来，也不陪坐，自顾叉腿坐在胡床上，在院子里晒头发，神态高傲，全无应酬他的意思。谢万只好回来，还没到船边，就先喊谢安，谢安说：“阿螭可不会装模作样地敷衍你！”
注：据胡床：叉开腿坐在胡床上。胡床，从北方传入的可折叠坐具。
注：逆：预先、迎着。
注：阿螭（chī）：王恬的小名。不作尔：意谓王恬本来就是这个样子，不肯做表面应酬；一说为“不值得这样”，存疑。

# 十三｜王子猷作桓车骑参军
原：王子猷作桓车骑参军。桓谓王曰：“卿在府久，比当相料理。”初不答，直高视，以手版拄颊云：“西山朝来，致有爽气。”|| 王徽之做桓冲的参军。桓冲对他说：“你在府里很久了，近来该处理些公事了。”王徽之一句也不回答，只是抬眼望着远处，用手板撑着脸颊说：“西山早晨以来，颇有一股清爽之气。”
注：比：近来。料理：处置、安排公务。
注：手版：即笏，官员谒见上司时手持的狭长板子。拄（zhǔ）：撑着。
注：致：极、甚。爽气：清朗之气。

# 十四｜谢万北征
原：谢万北征，常以啸咏自高，未尝抚慰众士。谢公甚器爱万，而审其必败，乃俱行，从容谓万曰：“汝为元帅，宜数唤诸将宴会，以说众心。”万从之。因召集诸将，都无所说，直以如意指四坐云：“诸君皆是劲卒。”诸将甚忿恨之。|| 谢万北伐时，常常长啸吟咏自命清高，从不慰问将士。谢安非常看重、爱护谢万，但判断他必定失败，就跟他一同出征，找个机会对他说：“你身为元帅，应当多召集将领们宴饮，好让大家心里高兴。”谢万照办了。可召来诸将以后，他什么也没说，只拿如意指着满座的人说：“诸位都是精壮的兵卒。”将领们十分怨恨他。
注：谢万北征：东晋升平年间谢万率军北伐前燕，后溃败。
注：数（shuò）：屡次。说：同“悦”。
注：如意：一种柄端弯曲的器物，名士清谈时常握在手中。
注：劲卒：将领忌讳被称为“卒”，谢万以此称呼诸将，等于当众轻侮。
原：谢公欲深著恩信，自队主将帅以下，无不身造，厚相逊谢。及万事败，军中因欲除之。复云：“当为隐士。”故幸而得免。|| 谢安想深深树立恩德信义，从队主到将帅，没有一个不亲自登门拜访，再三谦逊致歉。等到谢万兵败，军中有人想趁机除掉他，又说：“应当看在隐士的面上。”谢万因此侥幸免于一死。
注：队主：一队之长，低级军官。身造：亲自登门。
注：隐士：指谢安，他当时尚隐居东山，未正式出仕。

# 十五｜王子敬兄弟见郗公
原：王子敬兄弟见郗公，蹑履问讯，甚修外生礼。及嘉宾死，皆著高屐，仪容轻慢。命坐，皆云：“有事，不暇坐。”既去，郗公慨然曰：“使嘉宾不死，鼠辈敢尔？”|| 王献之兄弟去见舅舅郗愔，都穿着正式的鞋子问候起居，十分讲究外甥的礼节。等到郗超死后，他们再来都穿着高齿木屐，神态轻慢。郗愔让他们坐，他们都说：“有事，没空坐。”走了以后，郗愔感慨地说：“要是嘉宾还活着，这些小子敢这样吗？”
注：王子敬：王献之，字子敬，王羲之之子。郗公：郗愔，王羲之妻弟，为王氏兄弟之舅。
注：蹑履：穿鞋。履为正式场合所穿，屐为闲居便鞋。
注：外生：即外甥。
注：嘉宾：郗超，字嘉宾，郗愔之子，为桓温谋主，权势颇重。

# 十六｜王子猷尝行过吴中
原：王子猷尝行过吴中，见一士大夫家极有好竹。主已知子猷当往，乃洒扫施设，在厅事坐相待。王肩舆径造竹下，讽啸良久。主已失望，犹冀还当通，遂直欲出门。主人大不堪，便令左右闭门，不听出。王更以此赏主人，乃留坐，尽欢而去。|| 王徽之有一次路过吴中，见一户士大夫家里有很好的竹子。主人已经知道王徽之会来，就洒扫庭院、布置陈设，坐在厅堂里等他。王徽之坐着轿子直奔竹林，吟咏长啸了很久。主人已经很失望，还指望他看完回来时会通报相见，不料他竟径直要出门。主人实在忍受不了，就叫手下关上大门，不放他出去。王徽之反倒因此赏识起主人来，于是留下来坐谈，尽兴才离开。
注：吴中：吴郡一带，今江苏苏州。
注：讽啸：吟咏、长啸。
注：通：通报求见。不听出：不让出去。
注：更：反而。

# 十七｜王子敬自会稽经吴
原：王子敬自会稽经吴，闻顾辟疆有名园，先不识主人，径往其家。值顾方集宾友酣燕，而王游历既毕，指麾好恶，傍若无人。顾勃然不堪曰：“傲主人，非礼也；以贵骄人，非道也。失此二者，不足齿之，伧耳。”便驱其左右出门。王独在舆上，回转顾望，左右移时不至，然后令送著门外，怡然不屑。|| 王献之从会稽经过吴郡，听说顾辟疆有座名园，他事先并不认识主人，就径直到了顾家。正碰上顾辟疆在和宾客朋友畅饮宴会，王献之游遍园子之后，就评点起哪里好、哪里不好，旁若无人。顾辟疆勃然大怒，忍不住说：“对主人傲慢，是无礼；仗着门第高贵轻视别人，是无道。两样都失了，这种人不值一提，不过是个伧夫罢了。”就把王献之的随从赶出门去。王献之独自坐在轿子上，回头四下张望，随从很久都没回来，他便让主人家把自己送到门外，神情安然，满不在乎。
注：顾辟疆：吴郡顾氏子弟，其园林为当时吴中名园。
注：酣燕：畅饮宴乐。燕，同“宴”。指麾（huī）：指点评论。
注：不足齿：不值得与之并列、谈论。伧（cāng）：粗鄙之人，南人常以此称北方来的士人。
注：怡然不屑：神态自若，毫不介意。
