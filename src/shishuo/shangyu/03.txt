# 一百零三｜桓宣武表云
原：桓宣武表云：“谢尚神怀挺率，少致民誉。”|| 桓温在上给朝廷的奏表里说：“谢尚胸襟爽直坦荡，年纪轻轻就博得了百姓的称誉。”
注：桓宣武：桓温，谥宣武。表：臣下呈给皇帝的奏章。
注：谢尚：字仁祖，陈郡阳夏人，谢鲲之子，官至镇西将军，谢安的堂兄。
注：挺率：挺拔直率，不拘泥做作。
# 一百零四｜世目谢尚为“令达”
原：世目谢尚为“令达”。阮遥集云：“清畅似达。”或云：“尚自然令上。”|| 世人评谢尚为“美好而通达”。阮孚说：“他清朗舒展，看上去像是通达。”也有人说：“谢尚天生就是美好出众的人。”
注：目：品评，给人下评语。令达：美善通达。
注：阮遥集：阮孚，字遥集，阮咸之子。
注：似达：像是达，言下有“未必真达”之意，存疑。令上：美好而超群。
# 一百零五｜桓大司马病
原：桓大司马病，谢公往省病，从东门入。桓公遥望，叹曰：“吾门中久不见如此人！”|| 桓温生病，谢安前去探望，从东门进来。桓温远远望见他，叹道：“我门下好久没见过这样的人物了！”
注：桓大司马：桓温，官至大司马。谢公：谢安。
注：省（xǐng）病：探望病人。
# 一百零六｜简文目敬豫为“朗豫”
原：简文目敬豫为“朗豫”。|| 简文帝评王恬为“开朗而和乐”。
注：简文：东晋简文帝司马昱。
注：敬豫：王恬，字敬豫，王导次子。
注：朗豫：明朗而安和愉悦；巧用其字“豫”作评。
# 一百零七｜孙兴公为庾公参军
原：孙兴公为庾公参军，共游白石山，卫君长在坐。孙曰：“此子神情都不关山水，而能作文。”庾公曰：“卫风韵虽不及卿诸人，倾倒处亦不近。”孙遂沐浴此言。|| 孙绰做庾亮的参军时，一同去游白石山，卫永也在座。孙绰说：“这个人的神情跟山水毫不相干，却也能写文章。”庾亮说：“卫永的风度韵致虽然比不上你们几位，可他让人倾心的地方也不浅啊。”孙绰于是把这句话牢牢记在心里，反复体味。
注：孙兴公：孙绰，字兴公，东晋文学家。庾公：庾亮。
注：白石山：山名，所在说法不一，存疑。卫君长：卫永，字君长，曾为庾亮属官。
注：倾倒：使人倾心佩服。不近：不浅近，不寻常。
注：沐浴：比喻深受浸润，反复玩味。
# 一百零八｜王右军目陈玄伯
原：王右军目陈玄伯：“垒块有正骨。”|| 王羲之评陈泰：“心中有不平的块垒，骨子里却刚正。”
注：王右军：王羲之，曾任右军将军。陈玄伯：陈泰，字玄伯，三国魏人，陈群之子。
注：垒块：同“磊块”，比喻胸中郁结不平之气；一说指为人棱角分明。正骨：刚正的骨气。
# 一百零九｜王长史云
原：王长史云：“刘尹知我，胜我自知。”|| 王濛说：“刘惔了解我，胜过我了解自己。”
注：王长史：王濛，字仲祖，曾任司徒左长史。
注：刘尹：刘惔，字真长，曾任丹阳尹，与王濛交好。
# 一百一十｜王、刘听林公讲
原：王、刘听林公讲，王语刘曰：“向高坐者，故是凶物。”复更听，王又曰：“自是钵盂后王、何人也。”|| 王濛、刘惔去听支道林讲经，王濛对刘惔说：“刚才坐在高座上的，原来是个坏东西。”又接着听了一阵，王濛又说：“他本就是僧门中的王弼、何晏啊。”
注：王、刘：王濛、刘惔。林公：支遁，字道林，东晋名僧。
注：高坐：讲经说法者所坐的高座。凶物：本指不祥之人，这里是戏谑的反语，先抑后扬。
注：复：书中注明底本作“东”，据他本改。
注：钵盂（bō yú）：僧人食器，代指僧徒。王、何：王弼、何晏，魏正始玄学的代表。
# 一百一十一｜许玄度言
原：许玄度言：“《琴赋》所谓‘非至精者，不能与之析理’，刘尹其人；‘非渊静者，不能与之闲止’，简文其人。”|| 许询说：“《琴赋》里所说的‘不是最精通的人，不能和他剖析道理’，刘惔就是这样的人；‘不是深沉宁静的人，不能和他安闲共处’，简文帝就是这样的人。”
注：许玄度：许询，字玄度，东晋名士，善清谈与玄言诗。
注：《琴赋》：嵇康所作。原意说琴，许询借来品人。
注：渊静：深沉恬静。闲止：安闲地相处。
# 一百一十二｜魏隐兄弟少有学义
原：魏隐兄弟少有学义，总角诣谢奉。奉与语，大说之，曰：“大宗虽衰，魏氏已复有人。”|| 魏隐兄弟从小就有学问，还是孩童时去拜访谢奉。谢奉同他们交谈，非常喜欢，说：“你们家这一大族虽然衰落了，魏家却已经又有人才了。”
注：魏隐：字安时，会稽上虞人，东晋时任御史中丞等职；其弟魏逷（tì）。
注：总角：儿童束发为两髻，代指童年。谢奉：字弘道，会稽山阴人，官至吏部尚书。
注：说：同“悦”。大宗：家族的主支，这里敬称对方家族。
# 一百一十三｜简文云：“渊源语不超诣简至
原：简文云：“渊源语不超诣简至，然经纶思寻处，故有局陈。”|| 简文帝说：“殷浩的言谈谈不上高超精要，可是在筹划思索的地方，确实有章法布局。”
注：渊源：殷浩，字渊源，东晋清谈名家。
注：超诣：超拔高远。简至：简要而切中。
注：经纶：本为整理丝线，引申为筹划条理。故：确实。局陈：格局阵势，“陈”同“阵”，指言谈有章法。
# 一百一十四｜初，法汰北来
原：初，法汰北来，未知名，王领军供养之。每与周旋行来，往名胜许，辄与俱。不得汰，便停车不行。因此名遂重。|| 当初竺法汰从北方来，还没有名气，王洽供养着他。王洽每回应酬往来，到名流那里去，总是带他一起。法汰去不了，王洽就停下车不走。法汰的名声因此就重起来了。
注：法汰：竺法汰，东晋僧人，与道安同学，后南渡。
注：王领军：王洽，字敬和，王导之子，曾任中领军。
注：周旋行来：交际往来。名胜：名流。许：处所。
# 一百一十五｜王长史与大司马书
原：王长史与大司马书，道渊源“识致安处，足副时谈”。|| 王濛给桓温写信，说殷浩“见识情致与平日为人处世，都配得上时人的称誉”。
注：王长史：王濛。大司马：桓温。渊源：殷浩。
注：识致：见识与情趣。安处：平居自处。副：相称。时谈：当时的舆论评价。
# 一百一十六｜谢公云：“刘尹语审细
原：谢公云：“刘尹语审细。”|| 谢安说：“刘惔说话审慎细致。”
注：谢公：谢安。刘尹：刘惔。审细：周密精细。
# 一百一十七｜桓公语嘉宾
原：桓公语嘉宾：“阿源有德有言，向使作令仆，足以仪刑百揆，朝廷用违其才耳。”|| 桓温对郗超说：“殷浩有德行，也有好言论，当初如果让他做尚书令、仆射，足够做百官的表率，可惜朝廷没有用在他的长处上罢了。”
注：嘉宾：郗超，小字嘉宾，桓温的心腹谋士。阿源：殷浩。
注：令仆：尚书令与尚书仆射。仪刑：做榜样、典范。百揆（kuí）：百官。
注：用违其才：殷浩曾受命北伐，兵败被废，桓温此语即指此事。
# 一百一十八｜简文语嘉宾
原：简文语嘉宾：“刘尹语末后亦小异，回复其言，亦乃无过。”|| 简文帝对郗超说：“刘惔的话说到末尾，跟前面也有些小出入，但反复体味他的话，竟然也没有什么差错。”
注：简文：简文帝。嘉宾：郗超。刘尹：刘惔。
注：小异：略有不同。回复：反复玩味。
# 一百一十九｜孙兴公、许玄度共在白楼亭
原：孙兴公、许玄度共在白楼亭，共商略先往名达。林公既非所关，听讫云：“二贤故自有才情。”|| 孙绰、许询一起在白楼亭，共同评议前代的名流贤达。支道林对这些本来就不关心，听完后说：“二位确实是有才情的。”
注：白楼亭：亭名，在会稽一带。
注：商略：品评议论。先往名达：以往的名士贤达。
注：故自：确实，本来就。
# 一百二十｜王右军道东阳
原：王右军道东阳：“我家阿林，章清太出。”|| 王羲之称道王临之：“我们家的阿临，才华显赫，清俊得太出众了。”
注：东阳：王临之，字仲产，王羲之的族人，官至东阳太守。
注：阿林：书中原作“林”，当作“临”，即王临之的昵称。
注：章清：彰明清朗；章，同“彰”。太出：极为出众。
# 一百二十一｜王长史与刘尹书
原：王长史与刘尹书，道渊源：“触事长易。”|| 王濛给刘惔写信，称道殷浩：“遇事总是处理得平易从容。”
注：触事：遇到事情。长：同“常”。易：平易，不费力。
# 一百二十二｜谢中郎云
原：谢中郎云：“王修载乐托之性，出自门风。”|| 谢万说：“王修载那种放达不羁的性情，是从他家门风气里来的。”
注：谢中郎：谢万，字万石，谢安之弟，曾任西中郎将。
注：王修载：王耆之，字修载，琅邪王氏子弟。
注：乐（luò）托：同“落拓”，放旷不拘小节。门风：家风。
# 一百二十三｜林公云：“王敬仁是超悟人
原：林公云：“王敬仁是超悟人。”|| 支道林说：“王修是个悟性超群的人。”
注：王敬仁：王修，字敬仁，王濛之子，早慧，年少而卒。
注：超悟：领悟力超常。
# 一百二十四｜刘尹先推谢镇西
原：刘尹先推谢镇西，谢后雅重刘，曰：“昔尝北面。”|| 刘惔先推崇谢尚，谢尚后来也非常敬重刘惔，说：“我从前曾以弟子之礼对待过他。”
注：谢镇西：谢尚，曾任镇西将军。雅：甚，很。
注：北面：古时弟子面北拜师，指执弟子礼。
# 一百二十五｜谢太傅称王修龄曰
原：谢太傅称王修龄曰：“司州可与林泽游。”|| 谢安称赞王胡之说：“王司州是可以一起到山林水泽中游赏的人。”
注：谢太傅：谢安，死后追赠太傅。
注：王修龄：王胡之，字修龄，王廙之子，曾被任为司州刺史，故称司州。
注：林泽游：游于山林川泽，暗指可共隐逸、共赏风物。
# 一百二十六｜谚曰：“扬州独步王文度
原：谚曰：“扬州独步王文度，后来出人郗嘉宾。”|| 民间流传的话说：“扬州独一无二的是王坦之，后辈中超群出众的是郗超。”
注：独步：独一无二，无人能比。王文度：王坦之，字文度，王述之子。
注：后来：后辈。出人：超出众人。郗嘉宾：郗超。
# 一百二十七｜人问王长史江虨兄弟群从
原：人问王长史江虨兄弟群从，王答曰：“诸江皆复足自生活。”|| 有人向王濛打听江虨兄弟和堂兄弟们怎么样，王濛答道：“江家这些人，个个都足以自立于世。”
注：江虨（bīn）：字思玄，济阳考城人，东晋官至尚书仆射。群从：同族的堂兄弟、子侄。
注：自生活：自立，凭自己立足；一说指能自存其家声，存疑。
# 一百二十八｜谢太傅道安北
原：谢太傅道安北：“见之乃不使人厌，然出户去，不复使人思。”|| 谢安评论王坦之：“见面时并不叫人讨厌，可是他一出门走了，也就不再让人想念。”
注：安北：王坦之，死后追赠安北将军，故称。
# 一百二十九｜谢公云：“司州造胜遍决
原：谢公云：“司州造胜遍决。”|| 谢安说：“王胡之谈玄能达到精妙的境地，各种疑难都能一一剖决。”
注：司州：王胡之。造胜：达到胜境，指清谈入妙。
注：遍决：普遍地解决疑难问题。
# 一百三十｜刘尹云：“见何次道饮酒
原：刘尹云：“见何次道饮酒，使人欲倾家酿。”|| 刘惔说：“看何充喝酒的样子，让人想把家里酿的酒全倒出来请他。”
注：何次道：何充，字次道，东晋官至录尚书事，好饮酒而有雅量。
注：家酿：自家所酿的酒。
# 一百三十一｜谢太傅语真长
原：谢太傅语真长：“阿龄于此事，故欲太厉。”刘曰：“亦名士之高操者。”|| 谢安对刘惔说：“阿龄在这件事上，确实有点太严厉了。”刘惔说：“他也算是名士里节操高的人了。”
注：真长：刘惔的字。阿龄：王胡之，字修龄，故称。
注：此事：所指不明，或谓立身操守之事，存疑。厉：严峻刻厉。
# 一百三十二｜王子猷说
原：王子猷说：“世目士少为朗，我家亦以为彻朗。”|| 王徽之说：“世人评祖约为开朗，我也认为他是通透爽朗的。”
注：王子猷：王徽之，字子猷，王羲之之子。
注：士少：祖约，字士少，祖逖之弟。
注：我家：自称，即“我”。彻朗：通透明朗。
# 一百三十三｜谢公云：“长史语甚不多
原：谢公云：“长史语甚不多，可谓有令音。”|| 谢安说：“王长史话并不多，可称得上是有美好的言辞。”
注：长史：王濛。令音：美好的言辞声调。
# 一百三十四｜谢镇西道敬仁
原：谢镇西道敬仁：“文学镞镞，无能不新。”|| 谢尚称道王修：“他的文章学问锋芒出众，凡所擅长的没有不新颖的。”
注：谢镇西：谢尚。敬仁：王修。
注：文学：文章学术。镞镞（zú）：箭镞般尖锐挺出，形容才华出众。
注：无能不新：所能之事无不新颖；一说意为没有才能就不会出新，存疑。
# 一百三十五｜刘尹道江道群
原：刘尹道江道群：“不能言而能不言。”|| 刘惔评论江灌：“他不擅长清谈，却能做到不谈。”
注：江道群：江灌，字道群，江虨的族弟。
注：言：这里指玄谈。言下之意：知所短而能藏拙，也是难得。
# 一百三十六｜林公云：“见司州警悟交至
原：林公云：“见司州警悟交至，使人不得住，亦终日忘疲。”|| 支道林说：“见到王胡之，机敏与颖悟交相迸发，让人应接得停不下来，可也整天都忘了疲倦。”
注：司州：王胡之。警悟：机警聪悟。交至：交互而来。
注：不得住：停不下来，应接不暇。
# 一百三十七｜世称苟子秀出
原：世称苟子秀出，阿兴清和。|| 世人称赞王修出类拔萃，王蕴清朗平和。
注：苟子：王修的小字。
注：阿兴：王蕴，字叔仁，小字阿兴，王修之弟，官至会稽内史。
# 一百三十八｜简文云：“刘尹茗柯有实理
原：简文云：“刘尹茗柯有实理。”|| 简文帝说：“刘惔看似醉醺醺的，说的话却实实在在有道理。”
注：茗柯：同“酩酊”，大醉貌；一说意为如树干般质朴，存疑。实理：真实的道理。
# 一百三十九｜谢胡儿作著作郎
原：谢胡儿作著作郎，尝作《王堪传》，不谙堪是何似人，咨谢公。谢公答曰：“世胄亦被遇。堪，烈之子，阮千里姨兄弟，潘安仁中外。安仁诗所谓‘子亲伊姑，我父唯舅’，是许允婿。”|| 谢朗任著作郎时，曾写《王堪传》，不清楚王堪是怎样一个人，就去问谢安。谢安答道：“王世胄也是受过朝廷恩遇的。王堪是王烈的儿子，是阮瞻的姨表兄弟，和潘岳是姑舅表亲。潘岳诗里说的‘你的母亲是我的姑姑，我的父亲是你的舅舅’，说的就是他。他是许允的女婿。”
注：谢胡儿：谢朗，字长度，小字胡儿，谢安的侄子。著作郎：负责撰修国史的官。
注：王堪：字世胄，西晋人，官至尚书左丞，后为石勒所害。谙：熟悉。被遇：受到君主的知遇。
注：阮千里：阮瞻，字千里。潘安仁：潘岳，字安仁。中外：中表亲，舅家子女与姑家子女互称。
注：“子亲伊姑”二句：出自潘岳赠王堪之诗。许允：三国魏人，字士宗，曾任吏部郎，后被司马师所害。
# 一百四十｜谢太傅重邓仆射
原：谢太傅重邓仆射，常言：“天地无知，使伯道无儿。”|| 谢安敬重邓攸，常说：“天地真是无知，竟让伯道没有儿子。”
注：邓仆射：邓攸，字伯道，官至尚书右仆射。
注：伯道无儿：邓攸在战乱中逃难，为保全侄子而舍弃了亲生儿子，此后终身无子，时人哀之。
# 一百四十一｜谢公与王右军书曰
原：谢公与王右军书曰：“敬和栖托好佳。”|| 谢安给王羲之写信说：“王洽安身立命的地方非常好。”
注：敬和：王洽的字。
注：栖托：寄身之处；一说指其心性寄托，存疑。好佳：很好。
# 一百四十二｜吴四姓旧目云
原：吴四姓旧目云：“张文，朱武，陆忠，顾厚。”|| 对吴郡四大姓，向来有这样的评语：“张家尚文，朱家尚武，陆家忠诚，顾家宽厚。”
注：吴四姓：吴郡张、朱、陆、顾四大士族。旧目：旧有的品评。
# 一百四十三｜谢公语王孝伯
原：谢公语王孝伯：“君家蓝田，举体无常人事。”|| 谢安对王恭说：“你们家那位蓝田侯，浑身上下没有一点平常人的做派。”
注：王孝伯：王恭，字孝伯，王蕴之子。
注：蓝田：王述，袭封蓝田侯，王恭的族祖辈，性情急躁而率真。
注：举体：全身，整个人。
# 一百四十四｜许掾尝诣简文
原：许掾尝诣简文，尔夜风恬月朗，乃共作曲室中语。襟怀之咏，偏是许之所长，辞寄清婉，有逾平日。简文虽契素，此遇尤相咨嗟，不觉造膝，共叉手语，达于将旦。既而曰：“玄度才情，故未易多有许。”|| 许询有一回去拜访简文帝，那天夜里风静月明，两人便在内室里叙谈。抒写胸怀的吟咏，偏偏是许询最擅长的，他的言辞寄意清丽婉转，胜过平时。简文帝虽然素来和他投合，这次相会尤其赞叹不已，不知不觉两人膝盖挨着膝盖，拉着手说话，一直谈到天快亮。事后简文帝说：“像玄度这样的才情，确实不容易多得啊。”
注：许掾：许询，曾被征为司徒掾，未就，故称。
注：尔夜：那天夜里。曲室：深曲隐蔽的内室。
注：契素：素来情意相投。咨嗟：赞叹。造膝：膝与膝相接，形容亲近。叉手：互相握手。
注：故未易多有许：确实不容易多有这样的人；许，如此、这样。
# 一百四十五｜殷允出西
原：殷允出西，郗超与袁虎书云：“子思求良朋，托好足下，勿以开美求之。”世目袁为“开美”，故子敬诗曰：“袁生开美度。”|| 殷允要往西边去，郗超给袁宏写信说：“子思要寻求好朋友，想与您结交，请不要用你那‘开美’的标准来要求他。”世人评袁宏为“开朗美好”，所以王献之有诗说：“袁生有开朗美好的气度。”
注：殷允：字子思，陈郡长平人，官至吏部尚书。出西：往西方赴任，具体所指存疑。
注：袁虎：袁宏，小字虎，东晋文学家。
注：开美：开朗美好。子敬：王献之的字。
# 一百四十六｜谢车骑问谢公
原：谢车骑问谢公：“真长性至峭，何足乃重？”答曰：“是不见耳！阿见子敬，尚使人不能已。”|| 谢玄问谢安：“刘真长性情极其严峻，哪里值得这样敬重？”谢安答道：“那是你没见过他罢了！我见到子敬，尚且叫人倾倒不已呢。”
注：谢车骑：谢玄，谢安之侄，死后追赠车骑将军。
注：峭：严峻，不易亲近。乃：如此。
注：阿：我，自称。子敬：王献之。末句意谓连子敬都令人难以自已，何况刘惔，存疑。
# 一百四十七｜谢公领中书监
原：谢公领中书监，王东亭有事，应同上省。王后至，坐促，王、谢虽不通，太傅犹敛膝容之。王神意闲畅，谢公倾目。还谓刘夫人曰：“向见阿瓜，故自未易有，虽不相关，正自使人不能已已。”|| 谢安兼任中书监，王珣有公事，照例要一同到中书省去。王珣后到，座位狭窄，王、谢两家虽然已不往来，谢安仍收拢膝盖给他让出位子。王珣神态闲适舒畅，谢安一直注目看他。回家后对刘夫人说：“刚才见到阿瓜，确实是不容易有的人物，虽然两家已不相干，可还是叫人心里放不下。”
注：领：兼任。中书监：中书省长官。王东亭：王珣，字元琳，封东亭侯。上省：去中书省。
注：坐促：座位局促。不通：不往来，王、谢两家先有婚姻后已断绝。
注：倾目：注目。刘夫人：谢安之妻，刘惔之妹。阿瓜：王珣的小名，存疑。
注：正自：只是。不能已已：不能停止；前“已”为停止，后“已”为语气词。
# 一百四十八｜王子敬语谢公
原：王子敬语谢公：“公故萧洒。”谢曰：“身不萧洒。君道身最得，身正自调畅。”|| 王献之对谢安说：“您确实潇洒。”谢安说：“我并不潇洒。您对我的评论最中肯，我其实只是心情调和舒畅罢了。”
注：故：确实。萧洒：同“潇洒”。
注：身：我。道：评论。得：得当，中肯。
注：调畅：调和舒畅。此句另有他解，存疑。
# 一百四十九｜谢车骑初见王文度曰
原：谢车骑初见王文度曰：“见文度，虽萧洒相遇，其复愔愔竟夕。”|| 谢玄初次见到王坦之后说：“见了文度，虽然只是偶然相遇，却一整夜都感到他那份安和闲雅。”
注：王文度：王坦之。萧洒：这里指不经意、偶然。
注：其：语助词。愔愔（yīn）：安和静默的样子。竟夕：整夜。
# 一百五十｜范豫章谓王荆州
原：范豫章谓王荆州：“卿风流俊望，真后来之秀。”王曰：“不有此舅，焉有此甥！”|| 范宁对王忱说：“你风度俊逸、声望很高，真是后起之秀。”王忱说：“没有这样的舅舅，哪会有这样的外甥！”
注：范豫章：范宁，曾任豫章太守。王荆州：王忱，曾任荆州刺史，范宁是他的舅舅。
注：风流：风度仪表。俊望：美好的名望。
# 一百五十一｜子敬与子猷书道
原：子敬与子猷书道：“兄伯萧索寡会，遇酒则酣畅忘反，乃自可矜。”|| 王献之写信给王徽之说：“兄长平时冷落孤寂，少与人投合，可一碰到酒就畅饮忘归，这真是值得称赏的。”
注：子敬：王献之。子猷：王徽之，献之之兄。兄伯：对兄长的称呼。
注：萧索：孤寂冷落。寡会：少与人相投。
注：矜：夸赞，看重。
# 一百五十二｜张天锡世雄凉州
原：张天锡世雄凉州，以力弱诣京师，虽远方殊类，亦边人之杰也。闻皇京多才，钦羡弥至。犹在渚住，司马著作往诣之。言容鄙陋，无可观听。天锡心甚悔来，以遐外可以自固。|| 张天锡家族世代称雄凉州，因为势力衰弱才归附京城。他虽是远方异族，也算得上边地的豪杰。他听说京城人才众多，更加钦佩羡慕。还在江边住着的时候，司马著作去拜访他，那人言谈粗俗、相貌丑陋，没什么可看可听的。张天锡心里很后悔来了，认为在边远之地本可以自保。
注：张天锡：前凉末代君主，降前秦，后于淝水之战时投奔东晋。世雄：世代称雄。凉州：治所在今甘肃武威。
注：殊类：异族，与中原不同的人。弥至：更甚。渚：水边，指江边。
注：司马著作：姓司马、任著作郎的人，其人事迹不详。
注：遐外：边远之地。自固：自保。
原：王弥有俊才美誉，当时闻而造焉。既至，天锡见其风神清令，言话如流，陈说古今，无不贯悉。又谙人物氏族中表，皆有证据。天锡讶服。|| 王珉有俊美的才华和好名声，当时听说后就去拜访他。王珉到后，张天锡见他风度神采清朗俊美，说话滔滔如流水，讲古论今，无不贯通熟悉；又熟知各家人物的宗族世系和中表亲戚关系，都说得有根有据。张天锡惊讶佩服。
注：王弥：王珉，字季琰，小字僧弥，王珣之弟，这里以小字简称。
注：造：拜访。风神：风度神采。清令：清朗美好。贯悉：贯通熟悉。
注：谙（ān）：熟悉。氏族中表：宗族谱系与姻亲关系。
# 一百五十三｜王恭始与王建武甚有情
原：王恭始与王建武甚有情，后遇袁悦之间，遂致疑隙。然每至兴会，故有相思时。恭尝行散至京口射堂，于时清露晨流，新桐初引。恭目之曰：“王大故自濯濯。”|| 王恭起初和王忱感情很好，后来遭到袁悦的挑拨离间，于是彼此生了猜疑隔阂。可是每当兴致来了，还是会想念他。王恭曾经行散走到京口的射堂，当时清晨的露水在流动，新生的桐叶刚刚抽芽。王恭品评王忱说：“王大确实清朗明净啊。”
注：王建武：王忱，曾任建武将军，小字佛大，故称王大。
注：袁悦：袁悦之，字元礼，东晋人，以挑拨被诛。间：离间。疑隙：猜疑嫌隙。兴会：兴致到来。
注：行散：服五石散后走动以发散药性。京口：今江苏镇江。射堂：习射之所。
注：引：生长，抽芽。濯濯：明净清新的样子，借眼前清景比人。
# 一百五十四｜司马太傅为二王目曰
原：司马太傅为二王目曰：“孝伯亭亭直上，阿大罗罗清疏。”|| 司马道子品评王恭、王忱二人说：“孝伯高高挺立，一直向上；阿大放旷疏朗，清爽洒脱。”
注：司马太傅：司马道子，东晋会稽王，曾任太傅。二王：王恭与王忱。
注：亭亭：高耸挺直的样子。阿大：王忱。罗罗：疏朗不拘的样子。清疏：清朗疏放。
# 一百五十五｜王恭有清辞简旨
原：王恭有清辞简旨，能叙说，而读书少，颇有重出。有人道：“孝伯常有新意，不觉为烦。”|| 王恭言辞清新、意旨简明，善于陈述，可是读书少，说话常有重复。有人说：“孝伯常常有新意，叫人并不觉得烦。”
注：清辞简旨：言辞清新，意旨简要。叙说：陈述。重出：重复出现。
# 一百五十六｜殷仲堪丧后
题解：殷仲堪为桓玄所逼死，桓玄问的正是死于己手之人，殷仲文的回答委婉而有分寸。
原：殷仲堪丧后，桓玄问仲文：“卿家仲堪，定是何似人？”仲文曰：“虽不能休明一世，足以映彻九泉。”|| 殷仲堪死后，桓玄问殷仲文：“你们家的仲堪，到底是个怎样的人？”殷仲文说：“他虽然没能在当世大放光明，却足以照亮九泉之下。”
注：殷仲堪：东晋荆州刺史，后与桓玄相争兵败被杀。桓玄：桓温之子。仲文：殷仲文，殷仲堪的从弟，桓玄的姐夫。
注：定：究竟。休明：美好光明。映彻：照透。九泉：地下，阴间。
