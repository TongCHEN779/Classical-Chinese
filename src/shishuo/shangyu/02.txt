# 四十六｜王大将军与元皇表云
原：王大将军与元皇表云：“舒风概简正，允作雅人，自多于邃，最是臣少所知拔。中间夷甫、澄见语：‘卿知处明、茂弘。茂弘已有令名，真副卿清论；处明亲疏无知之者。吾常以卿言为意，殊未有得，恐已悔之。’臣慨然曰：‘君以此试。’顷来始乃有称之者，言常人正自患知之使过，不知使负实。”|| 大将军王敦给晋元帝上表说：“王舒风度气概简率端正，确实算得上雅士，本就胜过王邃，是臣年轻时最看重、最用心提携的人。¦其间王夷甫和王澄对我说：‘你赏识处明和茂弘。¦茂弘已经有了好名声，果然配得上你的高评；可处明却不论亲疏都没人知道他。¦我们常把你的话放在心上，却始终没看出什么来，恐怕你自己也后悔了吧。’¦臣感慨地答道：‘那就请你们拿这件事来验证吧。’¦近来才终于有人称道他。可见一般人只担心赏识人过了头，却不知道也会让人的实际才能被埋没。”
注：王大将军：王敦，字处仲，东晋初权臣，官至大将军，后起兵作乱。
注：元皇：晋元帝司马睿。
注：舒：王舒，字处明，王敦堂弟。
注：邃：王邃，王舒之弟。
注：夷甫、澄：王衍（字夷甫）与其弟王澄。
注：茂弘：王导的字。
注：负实：辜负、埋没其实际才能；一说使名声与实际不相符，存疑。

# 四十七｜周侯于荆州败绩还
原：周侯于荆州败绩还，未得用。王丞相与人书曰：“雅流弘器，何可得遗？”|| 周顗在荆州吃了败仗回来，一直没有被起用。王导给人写信说：“这样高雅一流、器量宏大的人物，怎么能弃置不用呢？”
注：周侯：周顗（yǐ），字伯仁，袭爵武城侯，故称周侯。曾任荆州刺史，为杜弢所败。
注：王丞相：王导，字茂弘，东晋开国重臣。
注：弘器：大器，指器量宏大之人。

# 四十八｜时人欲题目高坐而未能
原：时人欲题目高坐而未能，桓廷尉以问周侯。周侯曰：“可谓卓朗。”桓公曰：“精神渊著。”|| 当时人想给高坐道人下个品评，却找不到合适的话。廷尉桓彝拿这事去问周顗。¦周顗说：“可以说是卓异爽朗。”¦桓温说：“精神深沉而又显露。”
注：题目：品评，给人下评语。
注：高坐：西域僧人帛尸梨蜜多罗，时人称高坐道人。
注：桓廷尉：桓彝，桓温之父，曾任廷尉。
注：桓公：桓温。
注：渊著：深邃而又显明。

# 四十九｜王大将军称其儿云
原：王大将军称其儿云：“其神候似欲可。”|| 王敦夸奖他的儿子说：“他的神采气度好像还过得去。”
注：其儿：王应，字安期，本为王敦之兄王含之子，过继给王敦。
注：神候：神情气度。
注：欲可：差不多可以，还算不错。

# 五十｜卞令目叔向
原：卞令目叔向：“朗朗如百间屋。”|| 卞壸品评叔向：“开朗敞亮，就像上百间的大屋子。”
注：卞令：卞壸（kǔn），字望之，东晋名臣，曾任尚书令。
注：叔向：一说指春秋晋国大夫羊舌肸；一说指卞壸的叔父，事迹不详，存疑。

# 五十一｜王敦为大将军
原：王敦为大将军，镇豫章。卫玠避乱，从洛投敦。相见欣然，谈话弥日。于时谢鲲为长史，敦谓鲲曰：“不意永嘉之中，复闻正始之音。阿平若在，当复绝倒。”|| 王敦做大将军，镇守豫章。卫玠躲避战乱，从洛阳来投奔他。两人一见如故，清谈了整整一天。当时谢鲲在王敦府中任长史，王敦对谢鲲说：“想不到在永嘉年间，还能再听到正始年间那样的清谈之音。阿平要是还在，又该为之倾倒了。”
注：豫章：郡名，治所在今江西南昌。
注：卫玠：字叔宝，西晋末名士，以容貌秀美、善谈玄理著称。
注：谢鲲：字幼舆，好老庄，东晋名士。
注：长史：将军府中的属官之长。
注：永嘉：晋怀帝年号（307—313），时值天下大乱。
注：正始之音：指魏正始年间何晏、王弼等人倡导的玄学清谈风气。
注：阿平：王澄，字平子。
注：绝倒：佩服得倾倒。

# 五十二｜王平子与人书
原：王平子与人书，称其儿“风气日上，足散人怀”。|| 王澄给人写信，称赞自己的儿子“风度气质一天比一天出众，足以让人心怀舒畅”。
注：王平子：王澄，字平子，王衍之弟。
注：其儿：王澄之子，名字存疑。
注：散人怀：舒散人的胸怀，使人心情开朗。

# 五十三｜胡毋彦国吐佳言如屑
原：胡毋彦国吐佳言如屑，后进领袖。|| 胡毋辅之说起妙语来，像锯木头的木屑一样纷纷不断，是后辈中的领袖人物。
注：胡毋彦国：胡毋辅之，字彦国，西晋名士，“八达”之一。胡毋为复姓。
注：如屑：像木屑纷纷落下，比喻言谈滔滔不绝。

# 五十四｜王丞相云刁玄亮之察察
原：王丞相云：“刁玄亮之察察，戴若思之岩岩，卞望之之峰距。”|| 王导说：“刁协精明细察，戴渊威严峻峭，卞壸锋芒外露。”
注：刁玄亮：刁协，字玄亮，东晋初任尚书令，执法严苛。
注：察察：明察细辨的样子。
注：戴若思：戴渊，字若思（《晋书》避唐讳称“戴若思”），东晋将领，后为王敦所杀。
注：岩岩：如山岩般高峻威严。
注：卞望之：卞壸。
注：峰距：像山峰、鸡距一样峭拔有锋芒。

# 五十五｜大将军语右军
原：大将军语右军：“汝是我佳子弟，当不减阮主簿。”|| 王敦对王羲之说：“你是我们家的好子弟，应当不比阮主簿差。”
注：右军：王羲之，王敦的堂侄，后官至右军将军。
注：阮主簿：阮裕，字思旷，曾任王敦主簿，以识度著称。

# 五十六｜世目周侯
原：世目周侯：“嶷如断山。”|| 世人品评周顗：“峻拔挺立，就像一座陡峭孤立的山峰。”
注：周侯：周顗。
注：嶷（nì）：高峻突出的样子。
注：断山：如刀削般陡峭的山。

# 五十七｜王丞相招祖约夜语
原：王丞相招祖约夜语，至晓不眠。明旦有客，公头鬓未理，亦小倦。客曰：“公昨如是，似失眠。”公曰：“昨与士少语，遂使人忘疲。”|| 王导请祖约晚上来聊天，一直谈到天亮没睡。第二天早上有客人来，王导头发鬓角还没梳理，人也有点疲倦。客人说：“您昨天这样子，好像是没睡好。”王导说：“昨晚跟士少聊天，聊得让人忘了疲倦。”
注：祖约：字士少，祖逖之弟，后随苏峻作乱。
注：小倦：略有倦意。

# 五十八｜王大将军与丞相书
原：王大将军与丞相书，称杨朗曰：“世彦识器理致，才隐明断。既为国器，且是杨侯淮之子。位望殊为陵迟，卿亦足与之处。”|| 王敦写信给王导，称赞杨朗说：“世彦见识器量、思理情致都好，才学深藏，又能明断。他既是治国之才，又是杨淮侯的儿子。如今地位声望却很是衰落，你也值得跟他结交。”
注：杨朗：字世彦，曾在王敦手下任职。
注：识器：见识器度。
注：理致：思理意趣。
注：才隐：才学深沉不外露。
注：国器：可以担当国事的人才。
注：杨侯淮：当作“杨准”，杨朗之父，西晋时官至冀州刺史；书中如此，照录。
注：陵迟：衰落。
注：处：交往，相处。

# 五十九｜何次道往丞相许
原：何次道往丞相许，丞相以麈尾指坐，呼何共坐曰：“来，来，此是君坐。”|| 何充到王导那里去，王导用麈尾指着自己的座位，招呼何充一起坐，说：“来，来，这是你的位子。”
注：何次道：何充，字次道，王导的姻亲，深得王导器重，后官至宰辅。
注：许：处所。
注：麈（zhǔ）尾：用麈的尾毛做的拂子，魏晋名士清谈时常手执。

# 六十｜丞相治扬州廨舍
原：丞相治扬州廨舍，按行而言曰：“我正为次道治此尔！”何少为王公所重，故屡发此叹。|| 王导修缮扬州刺史的官署，一边巡视一边说：“我这只是替次道修的罢了！”何充年轻时就受王导器重，所以王导屡次发出这样的感叹。
注：治：修整。
注：廨（xiè）舍：官署。王导时兼领扬州刺史。
注：按行：巡视察看。
注：正：只是。

# 六十一｜王丞相拜司徒而叹曰
原：王丞相拜司徒而叹曰：“刘王乔若过江，我不独拜公。”|| 王导被任命为司徒时感叹说：“刘王乔如果也过了江，我就不会独自一人位列三公了。”
注：刘王乔：刘畴，字王乔，西晋名士，在北方死于战乱，未能南渡。
注：司徒：三公之一。
注：拜公：被授予三公之位。

# 六十二｜王蓝田为人晚成
原：王蓝田为人晚成，时人乃谓之痴。王丞相以其东海子，辟为掾。常集聚，王公每发言，众人竞赞之。述于末坐曰：“主非尧、舜，何得事事皆是？”丞相甚相叹赏。|| 王述成名较晚，当时人甚至说他呆傻。王导因为他是东海太守王承的儿子，征召他做属官。有一次大家聚会，王导每说一句话，众人都争着称赞。王述坐在末座说：“主公又不是尧、舜，怎么可能每件事都对？”王导对他非常赞赏。
注：王蓝田：王述，字怀祖，袭爵蓝田侯。
注：晚成：成名晚。
注：东海：王述之父王承，曾任东海太守，名重一时。
注：辟（bì）：征召。
注：掾（yuàn）：属官。
注：主：下属对长官的称呼。

# 六十三｜世目杨朗沉审经断
原：世目杨朗：“沉审经断。”蔡司徒云：“若使中朝不乱，杨氏作公方未已。”谢公云：“朗是大才。”|| 世人品评杨朗：“沉稳审慎，处事有决断。”蔡谟说：“假如西晋朝廷没有大乱，杨家做三公的人还会接连不断。”谢安说：“杨朗是个大才。”
注：沉审：沉着审慎。
注：经断：处理事务能决断；一说“经”指经略，存疑。
注：蔡司徒：蔡谟，字道明，东晋时官至司徒。
注：中朝：东晋人称西晋为中朝。
注：谢公：谢安。

# 六十四｜刘万安即道真从子
原：刘万安即道真从子，庾公所谓“灼然玉举”。又云：“千人亦见，百人亦见。”|| 刘绥是刘宝的侄子，就是庾琮所说的“光彩照人，像美玉一样挺立”的那位。庾琮又说：“他在千人之中也显得出来，在百人之中也显得出来。”
注：刘万安：刘绥，字万安。
注：道真：刘宝，字道真。
注：从子：侄子。
注：庾公：庾琮，存疑。
注：灼然玉举：光彩鲜明，如美玉高举。

# 六十五｜庾公为护军
原：庾公为护军，属桓廷尉觅一佳吏，乃经年。桓后遇见徐宁而知之，遂致于庾公曰：“人所应有，其不必有；人所应无，己不必无。真海岱清士！”|| 庾亮做护军将军时，托桓彝替他物色一个好属吏，结果找了一年多。桓彝后来遇见徐宁，认定了他，就推荐给庾亮说：“别人该有的，他不一定有；别人该没有的，他也不一定没有。真是海岱一带的清雅之士！”
注：庾公：庾亮，字元规，东晋外戚重臣。
注：护军：护军将军，掌武官选用。
注：属（zhǔ）：嘱托。
注：经年：过了一整年。
注：徐宁：字安期，东海郯人，后官至江州刺史。
注：海岱：东海与泰山之间，指今山东一带。

# 六十六｜桓茂伦云褚季野皮里阳秋
原：桓茂伦云：“褚季野皮里阳秋。”谓其裁中也。|| 桓彝说：“褚季野肚皮里藏着一部《春秋》。”意思是说他嘴上不评论，心里自有褒贬。
注：桓茂伦：桓彝，字茂伦。
注：褚季野：褚裒（póu），字季野，晋康帝皇后之父。
注：皮里阳秋：即“皮里春秋”，晋简文帝郑太后名阿春，晋人避讳改“春”为“阳”。《春秋》寓褒贬于一字，故以此喻心中暗有评判。
注：裁中：在心中裁断是非。

# 六十七｜何次道尝送东人
原：何次道尝送东人，瞻望，见贾宁在后轮中曰：“此人不死，终为诸侯上客。”|| 何充有一次送别东边来的人，远远望去，看见贾宁坐在后面的车上，便说：“这人如果不死，终究会成为一方诸侯的座上宾。”
注：东人：指从三吴等东土来的人。
注：贾宁：字建宁，曾为苏峻出谋划策，后归顺朝廷，官至新安太守。
注：后轮：后面的车。

# 六十八｜杜弘治墓崩
原：杜弘治墓崩，哀容不称。庾公顾谓诸客曰：“弘治至羸，不可以致哀。”又曰：“弘治哭不可哀。”|| 杜乂家的祖坟崩塌了，他脸上的悲哀之色与这件事不太相称。庾亮回头对客人们说：“弘治身体极其瘦弱，不能尽情哀伤。”又说：“弘治哭起来不能太悲伤。”
注：杜弘治：杜乂（yì），字弘治，杜预之孙，以风姿秀美著称。
注：不称（chèn）：不相称。
注：羸（léi）：瘦弱。
注：致哀：尽哀。

# 六十九｜世称庾文康为丰年玉
原：世称“庾文康为丰年玉，稚恭为荒年谷”。庾家论云：“是文康称恭为荒年谷，庾长仁为丰年玉。”|| 世人都说“庾亮是丰年的美玉，庾翼是荒年的谷子”。庾家人自己却说：“这是文康称赞稚恭是荒年的谷子，庾长仁是丰年的美玉。”
注：庾文康：庾亮，谥文康。
注：丰年玉：太平时的珍宝，喻治世之才。
注：稚恭：庾翼，字稚恭，庾亮之弟。
注：荒年谷：饥荒时的救命粮，喻乱世济时之才。
注：庾长仁：庾统，字长仁，小字赤玉，庾亮之侄。

# 七十｜世目杜弘治标鲜
原：世目：“杜弘治标鲜，季野穆少。”|| 世人品评说：“杜弘治仪表清秀鲜明，褚季野性情宁静淡泊。”
注：标鲜：风标鲜明，指仪容清秀。
注：穆少：和穆少欲，指宁静淡泊。

# 七十一｜有人目杜弘治
原：有人目杜弘治：“标鲜清令，盛德之风，可乐咏也。”|| 有人品评杜乂：“仪表鲜明、清秀美好，有盛德之人的风范，值得歌咏赞美。”
注：清令：清秀美好。
注：乐咏：配乐歌咏。

# 七十二｜庾公云逸少国举
原：庾公云：“逸少国举。”故庾倪为碑文云：“拔萃国举。”|| 庾亮说：“逸少是全国推举的人物。”所以庾倩为王羲之写碑文时说：“出类拔萃，举国推重。”
注：逸少：王羲之，字逸少。
注：国举：为全国所推举。
注：庾倪：庾倩，字少彦，小字倪，庾冰之子，后为桓温所害。
注：拔萃：出类拔萃。

# 七十三｜庾稚恭与桓温书
原：庾稚恭与桓温书，称：“刘道生日夕在事，大小殊快。义怀通乐既佳，且足作友，正实良器。推此与君同济艰不者也。”|| 庾翼写信给桓温，称赞说：“刘道生早晚勤于公务，上上下下都很满意。他胸怀道义、通达乐观，已经很好了，又值得交朋友，实在是个良才。我把他推荐给你，可以同你一起渡过艰难困厄。”
注：刘道生：刘恢，字道生，曾任车骑司马。
注：日夕在事：日夜忙于公事。
注：殊快：很是称心。
注：义怀通乐：胸怀道义，通达快乐。
注：艰不（pǐ）：艰难困苦；
注：“不”通“否”。

# 七十四｜王蓝田拜扬州
原：王蓝田拜扬州，主簿请讳，教云：“亡祖，先君，名播海内，远近所知。内讳不出于外，余无所讳。”|| 王述被任命为扬州刺史，主簿请示需要避讳哪些名字，王述批示说：“我已故的祖父和父亲，名声传遍天下，远近都知道。¦家中女眷的名讳不传到外面。此外没有什么要避讳的。”
注：拜扬州：被任命为扬州刺史。
注：请讳：请问应避讳的家人名字，晋人重家讳。
注：教：长官对下属的批示。
注：内讳：家中女性长辈的名讳。《礼记》有“妇讳不出门”之说。

# 七十五｜萧中郎孙承公妇父
原：萧中郎，孙承公妇父。刘尹在抚军坐，时拟为太常，刘尹云：“萧祖周不知便可作三公不？自此以还，无所不堪。”|| 萧轮是孙统的岳父。刘惔在抚军将军司马昱座上，当时正打算让萧轮做太常，刘惔说：“萧祖周不知能否做到三公？三公以下的官，他没有什么不能胜任的。”
注：萧中郎：萧轮，字祖周，曾任国子博士等职。
注：孙承公：孙统，字承公，孙绰之兄。
注：妇父：岳父。
注：刘尹：刘惔（tán），字真长，曾任丹阳尹。
注：抚军：司马昱，即后来的简文帝。
注：太常：九卿之一，掌宗庙礼仪。
注：以还：以下。
注：堪：胜任。

# 七十六｜谢太傅未冠
原：谢太傅未冠，始出西，诣王长史，清言良久。去后，苟子问曰：“向客何如尊？”长史曰：“向客亹亹，为来逼人。”|| 谢安还没成年的时候，第一次西去京城，拜访王濛，两人清谈了很久。谢安走后，王脩问父亲：“刚才那位客人比起您来怎么样？”王濛说：“刚才那位客人谈吐滔滔不倦，简直有些逼人呢。”
注：谢太傅：谢安，死后追赠太傅。
注：未冠：不满二十岁。
注：出西：往西到京城建康。
注：王长史：王濛，字仲祖，曾任司徒左长史。
注：苟子：王脩，字敬仁，小字苟子，王濛之子。
注：尊：对父亲的敬称。
注：亹亹（wěi）：勤勉不倦、娓娓不绝的样子。
注：为来：确实、颇为，存疑。

# 七十七｜王右军语刘尹
原：王右军语刘尹：“故当共推安石。”刘尹曰：“若安石东山志立，当与天下共推之。”|| 王羲之对刘惔说：“我们应当一起推举谢安石。”刘惔说：“如果安石隐居东山的志向坚定不移，那就该和天下人一起推重他。”
注：安石：谢安，字安石。
注：故当：自当，应当。
注：东山志：谢安早年隐居会稽东山，不肯出仕，此指隐逸之志。

# 七十八｜谢公称蓝田
原：谢公称蓝田：“掇皮皆真。”|| 谢安称赞王述：“剥去外皮，里面全是真的。”
注：蓝田：王述。
注：掇（duō）皮：剥去表皮。
注：皆真：喻其为人表里如一、真率无伪。

# 七十九｜桓温行经王敦墓边过
题解：王敦曾起兵犯阙，桓温晚年也怀不臣之心，故此叹颇耐人寻味。
原：桓温行经王敦墓边过，望之云：“可儿！可儿！”|| 桓温从王敦的墓旁经过，望着坟墓说：“了不起的人物！了不起的人物！”
注：可儿：可人，令人称许、合心意的人。

# 八十｜殷中军道王右军云
原：殷中军道王右军云：“逸少清贵人，吾于之甚至，一时无所后。”|| 殷浩谈起王羲之说：“逸少是清高尊贵的人物，我对他推重到了极点，当时没有人能排在他前头。”
注：殷中军：殷浩，字渊源，曾任中军将军，以善清谈著称。
注：甚至：极其推重。
注：无所后：不居于任何人之后，即无人能比；一说无人能及其后，存疑。

# 八十一｜王仲祖称殷渊源
原：王仲祖称殷渊源：“非以长胜人，处长亦胜人。”|| 王濛称赞殷浩说：“他不仅以长处胜过别人，在如何对待自己的长处上也胜过别人。”
注：王仲祖：王濛。
注：处长：对待、安处自己的长处，指不自矜炫。

# 八十二｜王司州与殷中军语
原：王司州与殷中军语，叹云：“己之府奥，早已倾写而见；殷陈势浩汗，众源未可得测。”|| 王胡之和殷浩交谈之后，感叹说：“我自己肚子里那点东西，早就倾倒得一干二净了；殷浩的阵势浩浩荡荡，他那许多源头还深不可测呢。”
注：王司州：王胡之，字修龄，曾任司州刺史。
注：府奥：府库深处，喻胸中所藏。
注：倾写：倾泻，“写”同“泻”。
注：陈：同“阵”。
注：浩汗：广大无边的样子。

# 八十三｜王长史谓林公
原：王长史谓林公：“真长可谓金玉满堂。”林公曰：“金玉满堂，复何为简选？”王曰：“非为简选，直致言处自寡耳。”|| 王濛对支遁说：“真长真可以说是金玉满堂。”支遁说：“既然金玉满堂，又何必在言辞上挑挑拣拣？”王濛说：“不是他挑拣，只是他开口的时候本来话就少罢了。”
注：林公：支遁，字道林，东晋高僧，精于玄学。
注：真长：刘惔。
注：金玉满堂：语出《老子》，此喻才学丰富。
注：简选：挑选。
注：直：只是。
注：致言：发言。

# 八十四｜王长史道江道群
原：王长史道江道群：“人可应有，乃不必有；人可应无，己必无。”|| 王濛评论江灌说：“别人该有的，他不一定有；别人该没有的，他一定没有。”
注：江道群：江灌，字道群，陈留人，历任吏部郎、吴郡太守等。

# 八十五｜会稽孔沈魏颛虞球
原：会稽孔沈、魏颛、虞球、虞存、谢奉并是四族之俊，于时之杰。孙兴公目之曰：“沈为孔家金，颛为魏家玉，虞为长、琳宗，谢为弘道伏。”|| 会稽的孔沈、魏颛、虞球、虞存、谢奉，都是四大家族中的俊才，当时的杰出人物。孙绰品评他们说：“孔沈是孔家的金子，魏颛是魏家的美玉，虞家尊崇道长和和琳，谢家敬服弘道。”
注：孔沈：字德度，会稽人。
注：魏颛：字长齐，官至山阴令。
注：虞球：字和琳。
注：虞存：字道长。
注：谢奉：字弘道。
注：四族：孔、魏、虞、谢四姓。
注：孙兴公：孙绰，字兴公，东晋文学家。
注：宗：尊崇。
注：伏：佩服。

# 八十六｜王仲祖刘真长造殷中军谈
原：王仲祖、刘真长造殷中军谈，谈竟，俱载去。刘谓王曰：“渊源真可。”王曰：“卿故堕其云雾中。”|| 王濛和刘惔一起到殷浩家清谈，谈完以后同车回去。刘惔对王濛说：“渊源真行。”王濛说：“你果然掉进他的云山雾罩里去了。”
注：造：拜访。
注：可：表示称许，相当于“不错”。
注：故：固然，果然。
注：云雾：喻言谈玄远迷离，令人难辨。

# 八十七｜刘尹每称王长史云
原：刘尹每称王长史云：“性至通而自然有节。”|| 刘惔常常称赞王濛说：“他性情极其通达，却又自然而然地有分寸。”
注：通：通达不拘。
注：节：节制，分寸。

# 八十八｜王右军道谢万石
原：王右军道谢万石“在林泽中，为自遒上”；叹林公“器朗神俊”；道祖士少“风领毛骨，恐没世不复见如此人”；道刘真长“标云柯而不扶疏”。|| 王羲之评谢万“在山林水泽之间，自显得刚健挺拔”；赞叹支遁“器量开朗，神采俊逸”；评祖约“风度仪表、骨相毛发都不同凡俗，恐怕这辈子再也见不到这样的人了”；评刘惔“像一棵高耸入云的大树，枝叶却并不繁茂纷披”。
注：谢万石：谢万，字万石，谢安之弟。
注：遒（qiú）上：刚健挺拔。
注：器朗神俊：器宇开朗，神采俊秀。
注：风领毛骨：风度、仪表、毛发、骨相。
注：没世：终身。
注：标：高耸。
注：云柯：入云的树枝。
注：扶疏：枝叶繁茂四散，此喻刘惔高峻而简约。

# 八十九｜简文目庾赤玉
原：简文目庾赤玉：“省率治除。”谢仁祖云：“庾赤玉胸中无宿物。”|| 简文帝品评庾统：“简率坦直，修整自持。”谢尚说：“庾赤玉心里不存隔夜的东西。”
注：简文：晋简文帝司马昱。
注：庾赤玉：庾统，小字赤玉。
注：省率：简约直率。
注：治除：修治清除，指修身自持；义存疑。
注：谢仁祖：谢尚，字仁祖。
注：宿物：隔夜之物，喻积存心中的芥蒂。

# 九十｜殷中军道韩太常曰
原：殷中军道韩太常曰：“康伯少自标置，居然是出群器。及其发言遣辞，往往有情致。”|| 殷浩评论韩伯说：“康伯年轻时就很自负，确实是超群的人才。等到他开口谈吐、遣词用句，常常很有情趣风致。”
注：韩太常：韩伯，字康伯，殷浩外甥，官至太常，注《周易·系辞》。
注：自标置：自我标榜，自视甚高。
注：居然：显然，确实。
注：遣辞：运用言辞。
注：情致：情趣风致。

# 九十一｜简文道王怀祖
原：简文道王怀祖：“才既不长，于荣利又不淡，直以真率少许，便足对人多多许。”|| 简文帝评论王述说：“他才能本来不算出众，对名利又不淡泊，只凭着那么一点真率，就足以抵得上别人的许许多多了。”
注：王怀祖：王述。
注：荣利：名位利禄。
注：直：只是。
注：少许、多多许：一点点，许许多多。

# 九十二｜林公谓王右军云
原：林公谓王右军云：“长史作数百语，无非德音，如恨不苦。”王曰：“长史自不欲苦物。”|| 支遁对王羲之说：“王长史说了几百句话，句句都是好话，只可惜不能把人难住。”王羲之说：“长史本来就不想难为人。”
注：长史：王濛。
注：德音：善言，美好的言辞。
注：如：只是，无奈。
注：苦：使人困窘，指辩难中压倒对方。
注：物：指人。

# 九十三｜殷中军与人书
原：殷中军与人书，道谢万：“文理转遒，成殊不易。”|| 殷浩写信给别人，评论谢万说：“他的文章义理越来越遒劲，能有这样的成就很不容易。”
注：文理：文辞义理。
注：转：越发。
注：遒：雄健有力。

# 九十四｜王长史云江思悛思怀所通
原：王长史云：“江思悛思怀所通，不翅儒域。”|| 王濛说：“江思悛的思想所通达的，不只是儒家这一领域。”
注：江思悛（quān）：江惇，字思悛，好学博通，兼综儒道，屡征不就。
注：不翅：不止，“翅”通“啻”。

# 九十五｜许玄度送母始出都
原：许玄度送母始出都，人问刘尹：“玄度定称所闻不？”刘曰：“才情过于所闻。”|| 许询送母亲，刚到京城，有人问刘惔：“许玄度到底和传闻中相符吗？”刘惔说：“他的才情比传闻的还要高。”
注：许玄度：许询，字玄度，东晋名士、玄言诗人，长期隐居。
注：出都：到京都。
注：定：究竟。
注：称（chèn）：相称。
注：不：同“否”。
注：才情：才华情致。

# 九十六｜阮光禄云王家有三年少
原：阮光禄云：“王家有三年少：右军，安期，长豫。”|| 阮裕说：“王家有三位少年英才：右军、安期、长豫。”
注：阮光禄：阮裕，曾任金紫光禄大夫。
注：安期：王应，字安期。
注：长豫：王悦，字长豫，王导长子。

# 九十七｜谢公道豫章
原：谢公道豫章：“若遇七贤，必自把臂入林。”|| 谢安评论谢鲲说：“他要是遇上竹林七贤，一定会和他们手挽着手走进竹林。”
注：豫章：谢鲲，曾任豫章太守，谢安的伯父。
注：七贤：竹林七贤，嵇康、阮籍等人。
注：把臂：挽着手臂，表示亲密。

# 九十八｜王长史叹林公
原：王长史叹林公：“寻微之功，不减辅嗣。”|| 王濛赞叹支遁说：“他探求精微玄理的功夫，不比王弼差。”
注：寻微：探寻精微的义理。
注：辅嗣：王弼，字辅嗣，魏正始玄学家，注《老子》《周易》。

# 九十九｜殷渊源在墓所几十年
原：殷渊源在墓所几十年。于时朝野以拟管、葛，起不起，以卜江左兴亡。|| 殷浩在祖先墓地隐居将近十年。当时朝野都把他比作管仲、诸葛亮，拿他出不出山来预测东晋的兴亡。
注：墓所：守墓之处，殷浩屏居墓所不仕。
注：几：将近。
注：管、葛：管仲、诸葛亮，历史上的名相。
注：起：出仕。
注：卜：预测。
注：江左：江东，指东晋。

# 一百｜殷中军道右军
原：殷中军道右军：“清鉴贵要。”|| 殷浩评论王羲之：“见识清明，地位尊贵显要。”
注：清鉴：清明的识鉴。
注：贵要：尊贵显要；一说指见识可贵而切要，存疑。

# 一百零一｜谢太傅为桓公司马
原：谢太傅为桓公司马。桓诣谢，值谢梳头，遽取衣帻。桓公云：“何烦此！”因下共语至暝。既去，谓左右曰：“颇曾见如此人不？”|| 谢安做桓温的司马。桓温去拜访谢安，正赶上谢安在梳头，谢安急忙去拿衣服和头巾。桓温说：“何必这么麻烦！”于是下车跟他一直谈到天黑。离开以后，桓温对身边的人说：“你们可曾见过这样的人物吗？”
注：桓公：桓温，东晋权臣。
注：司马：将军府属官，掌军事。
注：遽（jù）：急忙。
注：帻（zé）：头巾。
注：暝（míng）：天黑。

# 一百零二｜谢公作宣武司马
原：谢公作宣武司马，属门生数十人于田曹中郎赵悦子。悦子以告宣武，宣武云：“且为用半。”赵俄而悉用之，曰：“昔安石在东山，缙绅敦逼，恐不豫人事。况今自乡选，反违之邪？”|| 谢安做桓温的司马时，把几十个门生托付给田曹中郎赵悦。赵悦把这事报告桓温，桓温说：“先用一半吧。”不久赵悦把他们全都任用了，说：“当年安石隐居东山时，士大夫们一再催逼他出来，还怕他不肯过问世事。何况如今是他亲自从乡里选拔的人，我们反倒要违背他吗？”
注：宣武：桓温，谥宣武。
注：属（zhǔ）：托付。
注：田曹中郎：掌管农田事务的属官。
注：赵悦子：赵悦，字悦子，官至左卫将军。
注：且：暂且。
注：俄而：不久。
注：缙绅：士大夫。
注：敦逼：催促逼迫。
注：豫：参与。
注：人事：世间事务，指出仕。
注：乡选：从乡里选拔人才。
