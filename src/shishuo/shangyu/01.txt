# 本门导读
题解：“赏誉”即欣赏与称誉。本门汇集汉末至东晋名士之间的品题赞语，多以山川、草木、珍宝作比，一两句便勾勒出人物的风神气度，可见当时重才情、重风韵的品评风尚。

# 一｜陈仲举尝叹曰
原：陈仲举尝叹曰：“若周子居者，真治国之器。譬诸宝剑，则世之干将。”|| 陈蕃曾经感叹说：“像周子居这样的人，真是治理国家的大材。若拿宝剑来比，他就是当世的干将。”
注：陈仲举：陈蕃，字仲举，东汉名臣，官至太傅，与宦官斗争而死。
注：周子居：周乘，字子居，东汉汝南人，以刚直清正著称。
注：干将：古代名剑，相传为春秋吴国铸剑师干将所铸，后泛指利剑。

# 二｜世目李元礼
原：世目李元礼：“谡谡如劲松下风。”|| 世人品评李膺说：“他凛然有风，像吹过挺拔松树下的劲风。”
注：目：品评、题目人物。
注：李元礼：李膺，字元礼，东汉名士，以风骨峻整为士人所宗。
注：谡谡（sù）：劲挺有力、风声萧飒的样子。

# 三｜谢子微见许子将兄弟
原：谢子微见许子将兄弟曰：“平舆之渊，有二龙焉。”见许子政弱冠之时，叹曰：“若许子政者，有干国之器。正色忠謇，则陈仲举之匹；伐恶退不肖，范孟博之风。”|| 谢甄见到许劭兄弟，说：“平舆的深潭里，藏着两条龙啊。”见到刚满二十岁的许虔，感叹说：“像许子政这样的人，有支撑国家的才干。他神色端严、忠直敢言，可与陈蕃相比；惩治奸恶、斥退小人，又有范滂的风范。”
注：谢子微：谢甄，字子微，东汉汝南人，善于品鉴人物。
注：许子将兄弟：许劭，字子将，以主持“月旦评”闻名；其兄许虔，字子政。二人皆汝南平舆人。
注：干国之器：能做国家栋梁的才具。忠謇（jiǎn）：忠诚正直、敢于直言。
注：范孟博：范滂，字孟博，东汉名士，嫉恶如仇，死于党锢之祸。

# 四｜公孙度目邴原
原：公孙度目邴原：“所谓云中白鹤，非燕雀之网所能罗也。”|| 公孙度评论邴原说：“这就是人们所说的云中白鹤，不是捕燕雀的小网能网得住的。”
注：公孙度：东汉末割据辽东的军阀，自称辽东侯。
注：邴原：字根矩，北海朱虚人，汉末避乱辽东，以操守清高著称，后设法离去。
注：罗：用网捕捉。

# 五｜钟士季目王安丰
原：钟士季目王安丰：“阿戎了了解人意。”谓：“裴公之谈，经日不竭。”吏部郎阙，文帝问其人于钟会。会曰：“裴楷清通，王戎简要，皆其选也。”于是用裴。|| 钟会评王戎说：“阿戎聪明伶俐，善解人意。”又说：“裴公清谈起来，一整天也说不完。”吏部郎出缺，晋文帝向钟会询问合适人选。钟会说：“裴楷清明通达，王戎简约得要，都是合适的人选。”于是任用了裴楷。
注：钟士季：钟会，字士季，魏国重臣，后谋反被杀。
注：王安丰：王戎，字濬冲，封安丰侯，竹林七贤之一。阿戎是长辈对他的昵称。
注：了了：聪慧明白。
注：文帝：司马昭，西晋建立后追尊为文帝。

# 六｜王濬冲、裴叔则二人
原：王濬冲、裴叔则二人总角诣钟士季。须臾去，后客问钟曰：“向二童何如？”钟曰：“裴楷清通，王戎简要。后二十年，此二贤当为吏部尚书，冀尔时天下无滞才。”|| 王戎和裴楷还是孩童时，一同去拜访钟会。待了一会儿就走了，后来的客人问钟会：“刚才那两个孩子怎么样？”钟会说：“裴楷清明通达，王戎简约得要。二十年后，这两位贤才该当做吏部尚书，盼望到那时天下再没有被埋没的人才。”
注：总角：古时儿童把头发扎成两个髻，借指童年。
注：裴叔则：裴楷，字叔则，西晋名士，风神清秀。
注：吏部尚书：主管官员选拔任免的长官。滞才：被埋没、未被任用的人才。

# 七｜谚曰
原：谚曰：“后来领袖有裴秀。”|| 当时有谚语说：“后起之秀的领袖，要数裴秀。”
注：裴秀：字季彦，西晋大臣，官至司空，以绘制地图、提出制图之法闻名。
注：后来：后辈，后起之人。

# 八｜裴令公目夏侯太初
原：裴令公目夏侯太初：“肃肃如入廊庙中，不修敬而人自敬。”一曰：“如入宗庙，琅琅但见礼乐器。见钟士季，如观武库，但睹矛戟。见傅兰硕，汪廧靡所不有。见山巨源，如登山临下，幽然深远。”|| 裴楷评论夏侯玄说：“庄严肃穆，好像走进了朝堂，他不刻意让人尊敬，人们自然就敬重他。”另一种说法是：“好像走进宗庙，满眼只见琳琅的礼器乐器。见到钟会，像在参观兵器库，只看到矛戟森森。见到傅嘏，浩浩荡荡，无所不包。见到山涛，像登上高山俯视下方，幽深而辽远。”
注：裴令公：裴楷，曾任中书令，故称。夏侯太初：夏侯玄，字太初，曹魏名士，后被司马师所杀。
注：廊庙：朝廷。修敬：刻意整饬仪容以求人敬。
注：傅兰硕：傅嘏，字兰石（书中作“兰硕”），魏国大臣，以识鉴见称。汪廧：汪洋广大的样子，异文作“江廧”，存疑。
注：山巨源：山涛，字巨源，竹林七贤之一，官至吏部尚书，以知人善选著称。

# 九｜羊公还洛
原：羊公还洛，郭奕为野王令。羊至界，遣人要之，郭便自往。既见，叹曰：“羊叔子何必减郭太业！”复往羊许，小悉还，又叹曰：“羊叔子去人远矣！”羊既去，郭送之弥日，一举数百里，遂以出境免官。复叹曰：“羊叔子何必减颜子！”|| 羊祜回洛阳，当时郭奕任野王县令。羊祜到了野王县界，派人去邀请他，郭奕便亲自前往。见面后，郭奕赞叹道：“羊叔子未必比我郭太业差！”后来再去羊祜那里，没多久回来，又赞叹道：“羊叔子远远超出常人了！”羊祜离开时，郭奕送了他整整一天，一口气走了几百里，因此擅离县境而被免了官。他又赞叹说：“羊叔子未必比颜回差！”
注：羊公：羊祜，字叔子，西晋名将，镇守襄阳，德望甚高。
注：郭奕：字太业，西晋太原人，少有名望，官至尚书。野王：县名，在今河南沁阳。
注：要：邀请。何必减：不见得不如。小悉：不多时，一会儿。
注：颜子：颜回，孔子最贤的弟子。

# 十｜王戎目山巨源
原：王戎目山巨源：“如璞玉浑金，人皆钦其宝，莫知名其器。”|| 王戎评论山涛说：“他像未经雕琢的玉、未经冶炼的金，人人都敬重这是宝物，却没人能说出它究竟是什么器物。”
注：璞玉浑金：未琢之玉、未炼之金，比喻天然质朴而内蕴贵重。
注：名其器：给它的器量定个名目，意思是其气度难以形容。

# 十一｜羊长和父繇与太傅祜
原：羊长和父繇与太傅祜同堂相善，仕至车骑掾，蚤卒。长和兄弟五人幼孤。祜来哭，见长和哀容举止，宛若成人，乃叹曰：“从兄不亡矣！”|| 羊忱的父亲羊繇和太傅羊祜是堂兄弟，交情很好，羊繇官至车骑将军属官，很早就去世了。羊忱兄弟五人自幼成了孤儿。羊祜前来吊丧，看见羊忱悲哀的神情和举止，俨然像个大人，便感叹说：“堂兄没有死啊！”
注：羊长和：羊忱，字长和，西晋人。
注：同堂：同祖父的堂兄弟。车骑掾：车骑将军府的属官。
注：蚤：通“早”。从兄：堂兄。

# 十二｜山公举阮咸为吏部郎
原：山公举阮咸为吏部郎，目曰：“清真寡欲，万物不能移也。”|| 山涛推荐阮咸做吏部郎，评价他说：“清白真淳，欲望寡少，世间万物都不能改变他的心志。”
注：阮咸：字仲容，阮籍之侄，竹林七贤之一，精通音律，善弹琵琶。
注：清真：纯洁质朴。

# 十三｜王戎目阮文业
原：王戎目阮文业：“清伦有鉴识，汉元以来，未有此人。”|| 王戎评论阮武说：“人品清高，又有识人的眼光，从汉朝开国以来，还没有过这样的人。”
注：阮文业：阮武，字文业，曹魏陈留人，阮籍族兄，以知人著称。
注：清伦：清高的人品流辈。鉴识：识别人物的眼力。汉元：汉朝初年。

# 十四｜武元夏目裴、王曰
原：武元夏目裴、王曰：“戎尚约，楷清通。”|| 武陔评论裴楷、王戎说：“王戎崇尚简约，裴楷清明通达。”
注：武元夏：武陔，字元夏，魏晋之际人，入晋官至左仆射。

# 十五｜庾子嵩目和峤
原：庾子嵩目和峤：“森森如千丈松，虽磊砢有节目，施之大厦，有栋梁之用。”|| 庾敳评论和峤说：“他高耸挺拔，像千丈高的青松，虽然枝干盘曲、多有节疤，但用来建造大厦，却能做栋梁。”
注：庾子嵩：庾敳（ái），字子嵩，西晋名士，好老庄。
注：和峤：字长舆，西晋大臣，家富而性吝，为人方正。
注：森森：高耸繁茂的样子。磊砢（luǒ）：树木多节、盘结不平；节目：树干上的节疤与纹理纠结处，喻性格上的棱角。

# 十六｜王戎云
原：王戎云：“太尉神姿高彻，如瑶林琼树，自然是风尘外物。”|| 王戎说：“太尉风神高远明澈，好像玉树琼林，天生就是超出尘俗之外的人物。”
注：太尉：王衍，字夷甫，王戎从弟，西晋清谈领袖，官至太尉。
注：高彻：高远清澈。瑶林琼树：美玉般的树林，喻人品高洁。
注：风尘：尘世、俗世。

# 十七｜王汝南既除所生服
题解：王湛少时沉默寡言，被族人当作“痴人”，本则写侄子王济如何发现这位叔父的真面目。
原：王汝南既除所生服，遂停墓所。兄子济每来拜墓，略不过叔，叔亦不候。济脱时过，止寒温而已。|| 王湛为父亲守丧期满，脱去丧服后，就留住在墓地。他哥哥的儿子王济每次来扫墓，几乎从不去看望叔叔，叔叔也不等候他。王济偶尔去看一看，也只是寒暄几句罢了。
注：王汝南：王湛，字处冲，王浑之弟，后官至汝南内史，故称。
注：除所生服：为生身父亲守丧期满，除去丧服。停：留住。
注：略不：几乎不。脱：偶或。寒温：嘘寒问暖，客套话。
原：后聊试问近事，答对甚有音辞，出济意外，济极惋愕。仍与语，转造精微。济先略无子侄之敬，既闻其言，不觉懔然，心形俱肃。遂留共语，弥日累夜。|| 后来王济随便试着问了些近来的事，叔叔应答起来很有言辞，大出王济意料，他十分惊讶。接着再谈下去，越谈越进入精深微妙之境。王济原先对叔叔毫无晚辈应有的敬意，听了他这番话，不觉肃然起敬，从心里到外表都庄重起来。于是留下来一起谈论，一连几天几夜。
注：音辞：言谈辞令。惋愕：惊叹诧异。
注：造：到达。懔（lǐn）然：肃然敬畏的样子。弥日累夜：连日连夜。
原：济虽俊爽，自视缺然，乃喟然叹曰：“家有名士，三十年而不知！”济去，叔送至门。济从骑有一马，绝难乘，少能骑者。济聊问叔：“好骑乘不？”曰：“亦好尔。”济又使骑难乘马。叔姿形既妙，回策如萦，名骑无以过之。|| 王济虽然才气俊逸爽朗，此时也觉得自己有所不及，于是长叹道：“家里有位名士，我三十年来竟不知道！”王济要走了，叔叔送他到门口。王济随从的马匹中有一匹极难驾驭，很少有人骑得了。王济随口问叔叔：“喜欢骑马吗？”叔叔说：“也还喜欢。”王济就让他骑这匹难骑的马。叔叔骑在马上姿态优美，挥鞭盘旋自如，就是有名的骑手也比不上他。
注：缺然：若有所失、自觉不足。喟（kuì）然：叹息的样子。
注：从骑：随从的马匹。好骑乘不：喜欢骑马吗；不，同“否”。
注：回策如萦：挥鞭回旋，如丝线萦绕般圆转自如。
原：济益叹其难测，非复一事。既还，浑问济：“何以暂行累日？”济曰：“始得一叔。”浑问其故，济具叹述如此。浑曰：“何如我？”济曰：“济以上人。”|| 王济更加感叹叔叔深不可测，不只是一件事上如此。回家后，父亲王浑问他：“怎么出去一趟就好几天？”王济说：“我刚刚得了一位叔叔。”王浑问是怎么回事，王济便把经过赞叹着一一讲了。王浑问：“比我怎么样？”王济说：“是在我王济之上的人。”
注：浑：王浑，字玄冲，王济之父、王湛之兄，西晋重臣，官至司徒。
注：暂行：短暂外出。济以上人：比我王济高明的人；言外之意未与父亲相比，语带机锋。
原：武帝每见济，辄以湛调之曰：“卿家痴叔死未？”济常无以答。既而得叔后，武帝又问如前，济曰：“臣叔不痴。”称其实美。帝曰：“谁比？”济曰：“山涛以下，魏舒以上。”于是显名，年二十八始宦。|| 晋武帝每次见到王济，总拿王湛开玩笑说：“你家那个傻叔叔死了没有？”王济常常无言以对。等到了解了叔叔之后，武帝又像以前那样问，王济说：“臣的叔叔并不傻。”接着称道他实在的美德。武帝问：“可以和谁相比？”王济说：“在山涛之下，魏舒之上。”王湛从此出了名，二十八岁才开始做官。
注：武帝：晋武帝司马炎。调（tiáo）：开玩笑、戏弄。
注：魏舒：字阳元，西晋人，早年不为人知，后官至司徒，以器量见称。

# 十八｜裴仆射
原：裴仆射，时人谓为言谈之林薮。|| 裴頠，当时的人称他是言谈汇聚的渊薮。
注：裴仆射：裴頠（wěi），字逸民，裴秀之子，官至尚书仆射，著有《崇有论》。
注：林薮（sǒu）：山林与水泽，万物聚集之地，喻言谈丰富、议论荟萃。

# 十九｜张华见褚陶
原：张华见褚陶，语陆平原曰：“君兄弟龙跃云津，顾彦先凤鸣朝阳，谓东南之宝已尽，不意复见褚生。”陆曰：“公未睹不鸣不跃者耳。”|| 张华见过褚陶后，对陆机说：“你们兄弟像蛟龙在天河中腾跃，顾荣像凤凰对着朝阳鸣唱，我以为东南的宝贝都已经见尽了，没想到又见到了褚生。”陆机说：“那是您还没见到那些既不鸣叫也不腾跃的人罢了。”
注：张华：字茂先，西晋大臣、文学家，著《博物志》，好奖掖后进。
注：褚陶：字季雅，吴郡人，少聪慧，有文名。陆平原：陆机，曾任平原内史，故称。
注：云津：天河。顾彦先：顾荣，字彦先，吴郡名士。
注：凤鸣朝阳：语出《诗经·大雅·卷阿》“凤凰鸣矣，于彼高冈；梧桐生矣，于彼朝阳”，喻贤才逢时。

# 二十｜有问秀才
原：有问秀才：“吴旧姓何如？”答曰：“吴府君，圣王之老成，明时之俊乂；朱永长，理物之至德，清选之高望；严仲弼，九皋之鸣鹤，空谷之白驹；顾彦先，八音之琴瑟，五色之龙章；张威伯，岁寒之茂松，幽夜之逸光；陆士衡、士龙，鸿鹄之裴回，悬鼓之待槌。|| 有人问蔡洪：“吴地的旧日世家人物怎么样？”蔡洪回答：“吴府君是圣明君王倚重的老成之臣，太平时代的杰出之士；朱永长有治理百姓的至高德行，在清贵的官职中享有崇高声望；严仲弼是深泽中长鸣的仙鹤，空谷里的白驹；顾彦先是八音里的琴瑟，五色中的龙纹；张威伯是岁寒不凋的青松，暗夜里放出的光芒；陆士衡、陆士龙兄弟，是徘徊高翔的鸿鹄，是高悬着等待鼓槌的大鼓。
注：秀才：此指蔡洪，字叔开，吴郡人，入晋举秀才。旧姓：世家大族。
注：吴府君：吴展，字士季，东吴时曾任太守等职。俊乂（yì）：才德出众的人。
注：朱永长：朱诞；严仲弼：严隐；张威伯：张畅，皆吴郡人，事迹存疑。
注：九皋之鸣鹤：语出《诗经·小雅·鹤鸣》“鹤鸣于九皋”；空谷之白驹：语出《诗经·小雅·白驹》，皆喻隐居的贤人。裴回：同“徘徊”。
原：凡此诸君：以洪笔为锄耒，以纸札为良田，以玄默为稼穑，以义理为丰年，以谈论为英华，以忠恕为珍宝，著文章为锦绣，蕴五经为缯帛，坐谦虚为席荐，张义让为帷幕，行仁义为室宇，修道德为广宅。”|| 所有这些先生，都把大笔当作锄头和犁，把纸张当作良田，把沉静寡言当作耕种收割，把通晓义理当作丰收之年，把言谈议论当作花朵，把忠恕之道当作珍宝；写出文章就是锦绣，蕴藏五经就是丝帛，安坐于谦虚之上如坐草席，张开礼义谦让作为帷幕，推行仁义就是房屋，修养道德就是宽大的宅院。”
注：洪笔：大笔。耒（lěi）：犁一类的翻土农具。纸札：纸张。
注：玄默：沉静不多言。稼穑（sè）：耕种与收获。英华：花朵，喻文采。
注：缯（zēng）帛：丝织品的总称。席荐：坐卧用的草席垫子。

# 二十一｜人问王夷甫
原：人问王夷甫：“山巨源义理何如？是谁辈？”王曰：“此人初不肯以谈自居，然不读《老》、《庄》，时闻其咏，往往与其旨合。”|| 有人问王衍：“山涛在玄理上怎么样？跟谁属于一路人？”王衍说：“这个人从来不肯以清谈家自居，虽然不读《老子》《庄子》，可时常听他吟咏谈论，往往和老庄的旨趣暗合。”
注：王夷甫：王衍。义理：玄学的名理之学。谁辈：和谁同类。
注：初不：从来不、全不。

# 二十二｜洛中雅雅有三嘏
原：洛中雅雅有三嘏：刘粹字纯嘏，宏字终嘏，漠字冲嘏，是亲兄弟，王安丰甥，并是王安丰女婿。宏，真长祖也。洛中铮铮冯惠卿，名荪，是播子。荪与邢乔俱司徒李胤外孙，及胤子顺并知名。时称：“冯才清，李才明，纯粹邢。”|| 洛阳城里温文尔雅的有“三嘏”：刘粹字纯嘏，刘宏字终嘏，刘漠字冲嘏，他们是亲兄弟，是王戎的外甥，又都是王戎的女婿。刘宏是刘惔的祖父。洛阳城里刚正出众的有冯惠卿，名荪，是冯播的儿子。冯荪和邢乔都是司徒李胤的外孙，与李胤的儿子李顺都很有名气。当时人称：“冯荪才思清朗，李顺才识明达，纯美无瑕要数邢乔。”
注：雅雅：温文闲雅的样子。嘏（gǔ）：本义为福。
注：真长：刘惔，字真长，东晋清谈名士。
注：铮铮：金属相击声，喻人刚正出众。冯荪：西晋人，后为长沙王司马乂所杀。
注：李胤：字宣伯，西晋大臣，官至司徒。邢乔：字曾伯，西晋河间人。

# 二十三｜卫伯玉为尚书令
原：卫伯玉为尚书令，见乐广与中朝名士谈议，奇之曰：“自昔诸人没已来，常恐微言将绝，今乃复闻斯言于君矣！”命子弟造之，曰：“此人，人之水镜也，见之若披云雾睹青天。”|| 卫瓘任尚书令时，见到乐广和朝中名士清谈议论，对他十分惊异，说：“自从过去那些名士去世以来，我常担心精妙的玄言要断绝了，如今竟又从您这里听到这样的话！”于是让家中子弟去拜访乐广，说：“这个人是人中的明水清镜，见到他就像拨开云雾望见了青天。”
注：卫伯玉：卫瓘（guàn），字伯玉，西晋重臣，后被贾后所杀。
注：乐广：字彦辅，西晋清谈名士，官至尚书令。中朝：东晋人称西晋为中朝。
注：微言：精深微妙的言论，此指玄谈。造：拜访。
注：水镜：止水与明镜，喻人明澈、能照见事理。

# 二十四｜王太尉曰
原：王太尉曰：“见裴令公精明朗然，笼盖人上，非凡识也。若死而可作，当与之同归。”或云王戎语。|| 王衍说：“看裴楷精明爽朗，气度笼罩众人之上，不是见识平凡的人。假如死去的人能够复生，我一定要追随他。”也有人说这是王戎的话。
注：裴令公：裴楷。笼盖：覆盖，指超出众人。
注：死而可作：语出《礼记·檀弓下》，意为死者若能复活；作，起。同归：一同归往，即追随。

# 二十五｜王夷甫自叹
原：王夷甫自叹：“我与乐令谈，未尝不觉我言为烦。”|| 王衍自己感叹说：“我和乐令清谈，没有一次不觉得自己的话太啰嗦。”
注：乐令：乐广，官至尚书令。乐广清谈以言简意赅著称。

# 二十六｜郭子玄有俊才
原：郭子玄有俊才，能言《老》、《庄》，庾敳尝称之，每曰：“郭子玄何必减庾子嵩！”|| 郭象才华出众，擅长谈论《老子》《庄子》，庾敳曾经称赞他，常常说：“郭子玄不见得比我庾子嵩差！”
注：郭子玄：郭象，字子玄，西晋玄学家，有《庄子注》传世。
注：庾敳：字子嵩，此处自称其字，语带自负。

# 二十七｜王平子目太尉
原：王平子目太尉：“阿兄形似道，而神锋太俊。”太尉答曰：“诚不如卿落落穆穆。”|| 王澄评论哥哥王衍说：“阿兄外表像个得道的人，只是神采锋芒太露了。”王衍回答说：“确实比不上你那样疏放而又和穆。”
注：王平子：王澄，字平子，王衍之弟，性放达。
注：神锋：神采锋芒。俊：此指锐利外露。
注：落落穆穆：落落，疏阔不拘；穆穆，静穆和缓。二字合言其风度散淡，或含调侃，存疑。

# 二十八｜太傅府有三才
原：太傅府有三才：刘庆孙长才，潘阳仲大才，裴景声清才。|| 太傅府中有三位人才：刘舆是擅长谋划的长才，潘滔是器局宏大的大才，裴邈是清正雅洁的清才。
注：太傅：东海王司马越，西晋末执掌朝政。
注：刘庆孙：刘舆，字庆孙，刘琨之兄。潘阳仲：潘滔，字阳仲。裴景声：裴邈，字景声。
注：长才：多谋善断之才，具体所指存疑。

# 二十九｜林下诸贤
原：林下诸贤，各有俊才子：籍子浑，器量弘旷；康子绍，清远雅正；涛子简，疏通高素；咸子瞻，虚夷有远志，瞻弟孚，爽朗多所遗；秀子纯、悌，并令淑有清流；戎子万子，有大成之风，苗而不秀；唯伶子无闻。凡此诸子，唯瞻为冠，绍、简亦见重当世。|| 竹林诸贤，各有才俊的儿子：阮籍之子阮浑，器量宽宏旷达；嵇康之子嵇绍，志趣清远，品行端正；山涛之子山简，通达高洁；阮咸之子阮瞻，谦和平易，怀有远大志向，阮瞻之弟阮孚，爽朗洒脱，对许多事都不放在心上；向秀之子向纯、向悌，都美好善良，属清流人物；王戎之子王万子，有成大器的气象，可惜像禾苗未及抽穗就早早凋落；只有刘伶的儿子默默无闻。这些人中，唯有阮瞻最为出众，嵇绍、山简也被当时人所看重。
注：林下诸贤：竹林七贤，即嵇康、阮籍、山涛、向秀、阮咸、王戎、刘伶。
注：嵇绍：嵇康之子，后于荡阴之役以身护卫晋惠帝而死。山简：字季伦，后镇襄阳，好饮酒。
注：虚夷：谦虚平和。多所遗：对很多世事都能看淡遗落。令淑：美善。
注：苗而不秀：语出《论语·子罕》，庄稼出苗而未开花，喻人早夭；王万子名绥，十九岁卒。

# 三十｜庾子躬有废疾
原：庾子躬有废疾，甚知名。家在城西，号曰“城西公府”。|| 庾琮身有残疾，却很有名望。他家住在城西，人称“城西公府”。
注：庾子躬：庾琮，字子躬，西晋人，庾峻之子、庾敳之兄。
注：废疾：残疾。公府：三公的府第，此为美称，称其门庭名望堪比公府。

# 三十一｜王夷甫语乐令
原：王夷甫语乐令：“名士无多人，故当容平子知。”|| 王衍对乐广说：“名士没有多少人，本来就应当等王平子来鉴识评定。”
注：平子：王澄，王衍之弟。
注：容：待、让。知：识别、品鉴。一说意为名士不多，应当让平子也算一个，存疑。

# 三十二｜王太尉云
原：王太尉云：“郭子玄语议如悬河写水，注而不竭。”|| 王衍说：“郭象谈论起来，就像高悬的河流向下倾泻，滔滔奔注，永不枯竭。”
注：郭子玄：郭象。写：同“泻”。注：灌注、奔流。“口若悬河”一语即出于此。

# 三十三｜司马太傅府多名士
原：司马太傅府多名士，一时俊异。庾文康云：“见子嵩在其中，常自神王。”|| 太傅司马越府中名士众多，都是一时俊杰。庾亮说：“看到庾敳在他们中间，总是精神焕发、自得其乐。”
注：司马太傅：东海王司马越。俊异：杰出不凡的人。
注：庾文康：庾亮，字元规，谥文康，东晋外戚重臣。子嵩：庾敳。
注：神王：精神旺盛；王，同“旺”。

# 三十四｜太傅东海王镇许昌
原：太傅东海王镇许昌，以王安期为记室参军，雅相知重。敕世子毗曰：“夫学之所益者浅，体之所安者深。闲习礼度，不如式瞻仪形；讽味遗言，不如亲承音旨。王参军人伦之表，汝其师之！”|| 太傅东海王司马越镇守许昌时，任用王承为记室参军，对他非常赏识器重。司马越告诫世子司马毗说：“从书本学到的益处浅，亲身体会所得的收获深。熟习礼仪法度，不如亲眼瞻仰贤人的仪容风范；诵读玩味前人遗言，不如亲耳聆听贤人的言谈旨趣。王参军是众人的表率，你要拜他为师！”
注：王安期：王承，字安期，西晋末名士，清虚寡欲，东晋初称第一。
注：记室参军：掌管文书的属官。雅：很、甚。敕：告诫。世子：王侯的嫡长子；毗，司马毗。
注：式瞻：瞻仰；式，句首语气词。仪形：仪容风范。音旨：言谈的意旨。
注：人伦之表：人们的楷模。
原：或曰：“王、赵、邓三参军，人伦之表，汝其师之！”谓安期、邓伯道、赵穆也。袁宏作《名士传》，直云王参军。或云赵家先犹有此本。|| 也有人说是：“王、赵、邓三位参军都是众人的表率，你要拜他们为师！”指的是王承、邓攸、赵穆三人。袁宏写《名士传》，只说王参军。又有人说赵家先前还保存着这个说法的本子。
注：邓伯道：邓攸，字伯道，西晋末人，以弃子保侄之事著名。
注：赵穆：字季子，西晋汲郡人。
注：袁宏：字彦伯，东晋史学家、文学家，著有《后汉纪》《名士传》等。

# 三十五｜庾太尉少为王眉子所知
原：庾太尉少为王眉子所知。庾过江，叹王曰：“庇其宇下，使人忘寒暑。”|| 庾亮年少时受到王玄的赏识。庾亮渡江南下以后，感叹王玄说：“在他的屋檐下受他庇护，能让人忘掉寒冷与炎热。”
注：庾太尉：庾亮，死后追赠太尉。王眉子：王玄，字眉子，王衍之子。
注：宇下：屋檐之下。

# 三十六｜谢幼舆曰
原：谢幼舆曰：“友人王眉子清通简畅，嵇延祖弘雅劭长，董仲道卓荦有致度。”|| 谢鲲说：“我的朋友王玄清明通达，简易舒畅；嵇绍宽宏高雅，美好出众；董养卓越超群，富有风度。”
注：谢幼舆：谢鲲，字幼舆，东晋名士，性放达。
注：嵇延祖：嵇绍，字延祖。劭（shào）长：美好优秀。
注：董仲道：董养，字仲道，西晋末隐士，预见天下将乱，携妻入蜀山不知所终。卓荦（luò）：超群出众。致度：风致气度。

# 三十七｜王公目太尉
原：王公目太尉：“岩岩清峙，壁立千仞。”|| 王导评论王衍说：“他巍然高耸，清峻挺立，像千仞峭壁一样直立。”
注：王公：王导，字茂弘，东晋开国丞相。太尉：王衍，王导的族兄。
注：岩岩：高峻的样子。仞：古代长度单位，约七八尺，“千仞”极言其高。

# 三十八｜庾太尉在洛下
原：庾太尉在洛下，问讯中郎。中郎留之云：“诸人当来。”寻温元甫、刘王乔、裴叔则俱至，酬酢终日。庾公犹忆刘、裴之才俊，元甫之清中。|| 庾亮在洛阳时，去问候庾敳。庾敳留他说：“各位朋友就要来了。”不久温几、刘畴、裴楷都来了，彼此饮酒应答了一整天。庾亮后来还记得刘畴、裴楷的才华俊逸，温几的清和中正。
注：中郎：庾敳，曾任从事中郎。问讯：问候。
注：温元甫：温几，字元甫，西晋太原人。刘王乔：刘畴，字王乔，西晋彭城人。
注：裴叔则：裴楷。按裴楷卒年早于庾亮成年，二人恐难同席，或为他人之误，存疑。
注：酬酢（zuò）：宾主互相敬酒。清中：清和中正。

# 三十九｜蔡司徒在洛
原：蔡司徒在洛，见陆机兄弟住参佐廨中，三间瓦屋，士龙住东头，士衡住西头。士龙为人，文弱可爱；士衡长七尺余，声作钟声，言多慷慨。|| 蔡谟在洛阳时，看见陆机兄弟住在僚属的官舍里，三间瓦房，陆云住东头，陆机住西头。陆云为人文雅柔弱，招人喜爱；陆机身高七尺多，声音像洪钟，言谈多慷慨激昂。
注：蔡司徒：蔡谟，字道明，东晋大臣，后被任为司徒。
注：陆机兄弟：陆机字士衡，陆云字士龙，吴郡人，西晋著名文学家，并称“二陆”。
注：参佐：僚属。廨（xiè）：官署、官舍。

# 四十｜王长史是庾子躬外孙
原：王长史是庾子躬外孙，丞相目子躬云：“入理泓然，我已上人。”|| 王濛是庾琮的外孙，丞相王导评论庾琮说：“他深入玄理，如深水般清澈澄明，是在我之上的人。”
注：王长史：王濛，字仲祖，东晋清谈名士，曾任司徒左长史。
注：丞相：王导。泓然：水深而清的样子。已上：以上。

# 四十一｜庾太尉目庾中郎
原：庾太尉目庾中郎：“家从谈谈之许。”|| 庾亮评论庾敳说：“我家这位叔父，是清谈中的宗主。”
注：庾中郎：庾敳，是庾亮的堂叔。家从：自家的从父，即堂叔伯。
注：谈谈之许：费解，一说当作“谈之祖”，指清谈的宗师，存疑。

# 四十二｜庾公目中郎
原：庾公目中郎：“神气融散，差如得上。”|| 庾亮评论庾敳说：“他神情气度和融疏散，大致算得上是上等人物。”
注：融散：和融散淡、闲适不拘。
注：差如得上：意谓颇能算作上品；差，略、颇。一说为能超拔向上，存疑。

# 四十三｜刘琨称祖车骑为朗诣
原：刘琨称祖车骑为朗诣，曰：“少为王敦所叹。”|| 刘琨称赞祖逖开朗通达，说：“他年轻时就受到王敦的赞叹。”
注：刘琨：字越石，西晋末将领，坚守并州抗击胡人，与祖逖为友，有“闻鸡起舞”之事。
注：祖车骑：祖逖，字士稚，东晋初北伐名将，有“中流击楫”之誓，死后追赠车骑将军。
注：朗诣：开朗而有造诣，通达明敏。王敦：字处仲，王导从兄，东晋权臣，后起兵作乱。

# 四十四｜时人目庾中郎
原：时人目庾中郎：“善于托大，长于自藏。”|| 当时的人评论庾敳说：“他擅长把自己寄托于高远旷大之中，又善于隐藏自己。”
注：托大：寄心于大道，胸怀宽广而不拘世务。
注：自藏：韬光晦迹，不显露锋芒。

# 四十五｜王平子迈世有俊才
原：王平子迈世有俊才，少所推服。每闻卫玠言，辄叹息绝倒。|| 王澄才华卓越，超出世人，很少有他佩服的人。可每次听到卫玠的谈论，总要赞叹不已，佩服得五体投地。
注：迈世：超越世俗、高出当世。推服：推崇佩服。
注：卫玠：字叔宝，西晋末清谈名士，风神秀异，有“看杀卫玠”之说。
注：绝倒：倾倒、佩服到极点，一说笑得前仰后合，此取前义。
