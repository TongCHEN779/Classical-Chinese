# 二十四｜桓大司马乘雪欲猎
原：桓大司马乘雪欲猎，先过王、刘诸人许。真长见其装束单急，问：“老贼欲持此何作？”桓曰：“我若不为此，卿辈亦那得坐谈？”|| 大司马桓温趁着下雪想去打猎，先到王濛、刘惔等人的住处走一趟。刘惔见他一身短衣紧束的戎装，问道：“老贼打扮成这样要干什么去？”桓温说：“我要是不干这个，你们这班人又哪能安安稳稳坐着清谈？”
注：桓大司马：桓温，字元子，谯国龙亢人，东晋权臣，官至大司马。
注：过：探访。
注：许：处所。
注：王、刘：王濛与刘惔，都是当时清谈名士。
注：真长：刘惔的字。
注：单急：衣服单薄紧身，指出猎的戎装。
注：老贼：老家伙，朋友间的戏骂。
注：那得：怎能。

# 二十五｜褚季野问孙盛
原：褚季野问孙盛：“卿国史何当成？”孙云：“久应竟。在公无暇，故至今日。”褚曰：“古人‘述而不作’，何必在蚕室中？”|| 褚裒问孙盛：“你那部国史什么时候能写成？”孙盛说：“早该完稿了。只因公务缠身没有空闲，才拖到今天。”褚裒说：“古人讲‘只传述不创作’，又何必非等进了蚕室才动笔呢？”
注：褚季野：褚裒（póu），字季野，东晋外戚，康献皇后之父。
注：孙盛：字安国，东晋史家，著《晋阳秋》《魏氏春秋》。
注：何当：何时。
注：竟：完成。
注：述而不作：语出《论语·述而》，孔子自谓只传述旧闻、不另行创作。
注：蚕室：受宫刑者养伤的密室；司马迁受宫刑后发愤著《史记》，褚裒借此调侃。

# 二十六｜谢公在东山
原：谢公在东山，朝命屡降而不动。后出为桓宣武司马，将发新亭，朝士咸出瞻送。高灵时为中丞，亦往相祖，先时多少饮酒，因倚如醉，戏曰：“卿屡违朝旨，高卧东山，诸人每相与言：‘安石不肯出，将如苍生何？’今亦苍生将如卿何？”谢笑而不答。|| 谢安隐居东山，朝廷的征召一道道下来，他都不为所动。后来出山做了桓温的司马，将从新亭动身，朝中官员都出城来送行。高崧当时任御史中丞，也去饯别，事先喝了点酒，便借着几分醉意，开玩笑说：“您一再违抗朝廷旨意，在东山高枕而卧，大家常在一起议论：‘安石不肯出山，叫天下百姓怎么办？’如今倒要问问：天下百姓又拿您怎么办呢？”谢安只是笑，不作回答。
注：谢公：谢安，字安石，陈郡阳夏人，早年隐居会稽东山，后出仕，官至太保。
注：桓宣武：桓温，死后谥宣武。
注：新亭：建康城南的亭子，送往迎来之地。
注：高灵：高崧，小字阿灵，东晋人，官至侍中。
注：中丞：御史中丞。
注：祖：设宴饯行。
注：多少：稍稍，略微。
注：苍生：百姓。

# 二十七｜初，谢安在东山居
原：初，谢安在东山居，布衣，时兄弟已有富贵者，翕集家门，倾动人物。刘夫人戏谓安曰：“大丈夫不当如此乎？”谢乃捉鼻曰：“但恐不免耳。”|| 当初谢安在东山隐居，还是个平民，那时他的兄弟中已经有人做了大官，富贵显赫，宾客车马聚满家门，引得众人倾慕。刘夫人跟谢安开玩笑说：“大丈夫不就该像这样吗？”谢安捏着鼻子说：“只怕我也躲不掉啊。”
注：布衣：平民，指尚未做官。
注：翕（xī）集：聚集。
注：倾动人物：使世人倾倒动心。
注：刘夫人：谢安之妻，刘惔的妹妹。
注：捉鼻：捏住鼻子，一说是掩鼻作吟、故作嫌弃之态，存疑。

# 二十八｜支道林因人就深公买印山
原：支道林因人就深公买印山，深公答曰：“未闻巢、由买山而隐。”|| 支道林托人去向竺法深买印山，竺法深回答说：“从没听说巢父、许由是买了山才去隐居的。”
注：支道林：支遁，字道林，东晋名僧，善清谈。
注：因：托，经由。
注：就：向。
注：深公：竺道潜，字法深，东晋高僧，隐居剡县山中。
注：印山：当作“岇（áng）山”，在剡县（今浙江嵊州），书中原作“印山”，从原文。
注：巢、由：巢父、许由，传说中尧时的隐士，尧欲让天下而不受。

# 二十九｜王、刘每不重蔡公
原：王、刘每不重蔡公。二人尝诣蔡，语良久，乃问蔡曰：“公自言何如夷甫？”答曰：“身不如夷甫。”王、刘相目而笑曰：“公何处不如？”答曰：“夷甫无君辈客。”|| 王濛、刘惔常常不把蔡谟放在眼里。两人曾去拜访蔡谟，谈了很久，便问他：“您自己说说，比王夷甫如何？”蔡谟答：“我不如夷甫。”王、刘二人相视而笑，追问：“您哪里不如他？”蔡谟答：“夷甫家没有你们这样的客人。”
注：蔡公：蔡谟，字道明，东晋大臣，博学，官至司徒。
注：夷甫：王衍的字，西晋清谈领袖，名重一时。
注：身：我。
注：相目：互相使眼色。

# 三十｜张吴兴年八岁
原：张吴兴年八岁，亏齿，先达知其不常，故戏之曰：“君口中何为开狗窦？”张应声答曰：“正使君辈从此中出入。”|| 张玄之八岁时掉了门牙，前辈名流知道他不是寻常孩子，故意逗他说：“你嘴里怎么开了个狗洞？”张玄之应声答道：“正是好让你们这些人从这里进进出出。”
注：张吴兴：张玄之，字祖希，东晋人，曾任吴兴太守。
注：亏齿：缺牙，指换牙。
注：先达：有声望的前辈。
注：不常：不同寻常。
注：狗窦：墙上供狗出入的洞。

# 三十一｜郝隆七月七日出日中仰卧
原：郝隆七月七日出日中仰卧，人问其故，答曰：“我晒书。”|| 七月七日这天，郝隆跑到太阳底下仰面躺着。有人问他为什么，他回答：“我在晒书。”
注：郝隆：字佐治，汲郡人，曾为桓温参军。
注：七月七日：当时风俗在这天曝晒书籍衣物；郝隆自谓满腹诗书，故晒肚皮。

# 三十二｜谢公始有东山之志
原：谢公始有东山之志，后严命屡臻，势不获已，始就桓公司马。于时人有饷桓公药草，中有远志。公取以问谢：“此药又名小草，何一物而有二称？”谢未即答。时郝隆在坐，应声答曰：“此甚易解。处则为远志，出则为小草。”谢甚有愧色。桓公目谢而笑曰：“郝参军此过乃不恶，亦极有会。”|| 谢安起初抱定隐居东山的志向，后来朝廷的严令一再下达，势不得已，才出任桓温的司马。¦那时有人送给桓温一些药草，其中有一味远志。¦桓温拿起来问谢安：“这味药又叫小草，为什么一样东西有两个名字？”¦谢安没有马上回答。¦当时郝隆在座，随口答道：“这很好解释：¦藏在地下时叫远志，长出地面就叫小草。”¦谢安脸上很有愧色。¦桓温看着谢安笑道：“郝参军这番解释倒是不坏，也很有意味。”
注：严命屡臻：朝廷严厉的征召一再到来。
注：不获已：不得已。
注：就：就任。
注：饷（xiǎng）：赠送。
注：远志：草药名，根入药称远志，地上苗叶称小草。
注：处、出：双关，既指药草根在土中、苗出地面，又指隐居不仕与出山做官。
注：此过：一本作“此通”，通即解说，作“通”义长，此处从书中原文。
注：会：意趣。

# 三十三｜庾园客诣孙监
原：庾园客诣孙监，值行，见齐庄在外，尚幼，而有神意。庾试之曰：“孙安国何在？”即答曰：“庾稚恭家。”庾大笑曰：“诸孙大盛，有儿如此。”又答曰：“未若诸庾之翼翼。”还，语人曰：“我故胜，得重唤奴父名。”|| 庾爰之去拜访秘书监孙盛，正赶上他外出，看见他儿子齐庄在门外，年纪还小，却很有神采。庾爰之有意试他，说：“孙安国在哪儿？”齐庄立刻答道：“在庾稚恭家。”庾爰之大笑说：“孙家真是兴旺啊，竟有这样的儿子。”齐庄又答：“还比不上庾家这般翼翼兴盛。”齐庄回家后对人说：“我到底赢了，我多叫了那小子父亲的名字一回。”
注：庾园客：庾爰之，小字园客，庾翼之子。
注：孙监：孙盛，字安国，官至秘书监。
注：值行：正赶上（孙盛）外出。
注：齐庄：孙放，字齐庄，孙盛之子。
注：神意：神采。
注：直呼对方父亲的名字是失礼的挑衅，庾爰之称“孙安国”，齐庄便回敬“庾稚恭”（庾翼字稚恭）。
注：诸孙大盛、诸庾翼翼：双方各嵌对方父名中的字（盛、翼）相讥。
注：奴：对庾爰之的蔑称。

# 三十四｜范玄平在简文坐
原：范玄平在简文坐，谈欲屈，引王长史曰：“卿助我。”王曰：“此非拔山力所能助。”|| 范汪在简文帝那里作客，清谈中眼看要理屈辞穷，便拉住王濛说：“你帮帮我。”王濛说：“这可不是有拔山的力气就帮得了的。”
注：范玄平：范汪，字玄平，东晋人，博学，官至徐、兖二州刺史。
注：简文：简文帝司马昱。
注：屈：理屈。
注：引：拉，牵。
注：王长史：王濛，曾任司徒左长史。
注：拔山力：项羽《垓下歌》有“力拔山兮气盖世”，意谓理亏非蛮力可救。

# 三十五｜郝隆为桓公南蛮参军
原：郝隆为桓公南蛮参军。三月三日会，作诗，不能者罚酒三升。隆初以不能受罚，既饮，揽笔便作一句云：“娵隅跃清池。”桓问：“娵隅是何物？”答曰：“蛮名鱼为娵隅。”桓公曰：“作诗何以作蛮语？”隆曰：“千里投公，始得蛮府参军，那得不作蛮语也？”|| 郝隆在桓温手下做南蛮校尉府的参军。三月三日聚会，大家作诗，作不出的罚酒三升。郝隆起先以作不出为由领了罚，喝完后，却提笔写了一句：“娵隅跃清池。”桓温问：“娵隅是什么东西？”郝隆答：“蛮人管鱼叫娵隅。”桓温说：“作诗为什么用蛮话？”郝隆说：“我千里迢迢来投奔您，才捞到个蛮府参军，怎能不说蛮话呢？”
注：南蛮参军：桓温任荆州刺史时兼领南蛮校尉，参军为其属官。
注：三月三日会：上巳节，士人临水宴集，修禊赋诗。
注：揽笔：提笔。
注：娵（jū）隅：西南少数民族称鱼的话。
注：蛮府参军：借“南蛮”字面自嘲官卑位冷，暗含怨望。

# 三十六｜袁羊尝诣刘恢
原：袁羊尝诣刘恢，恢在内眠未起。袁因作诗调之曰：“角枕粲文茵，锦衾烂长筵。”刘尚晋明帝女，主见诗，不平曰：“袁羊，古之遗狂。”|| 袁乔曾去拜访刘惔，刘惔还在内室睡觉没起床。袁乔便作诗逗他：“角枕映着花褥子，锦被铺满长竹席。”刘惔娶的是晋明帝的女儿，公主看了这诗，很不高兴，说：“袁羊真是古时留下来的狂人。”
注：袁羊：袁乔，字彦叔，小字羊，东晋人。
注：刘恢：当作“刘惔”，书中原文作“恢”，据下文娶明帝女当指刘惔。
注：调：调笑。
注：“角枕”二句：化用《诗经·唐风·葛生》“角枕粲兮，锦衾烂兮”，原诗为思念亡人之作，用来写人睡卧，暗含不祥与轻佻。
注：文茵：有花纹的褥垫。
注：长筵：长竹席。
注：尚：娶公主为妻。
注：遗狂：遗留下来的狂徒。

# 三十七｜殷洪远答孙兴公诗云
原：殷洪远答孙兴公诗云：“聊复放一曲。”刘真长笑其语拙，问曰：“君欲云那放？”殷曰：“㯓腊亦放，何必其枪铃邪？”|| 殷融答孙绰的诗里写道：“姑且再放一曲。”刘惔笑他用语笨拙，问道：“你说怎么个放法？”殷融说：“咚咚的鼓声也是放，何必非得是叮当的钟铃声呢？”
注：殷洪远：殷融，字洪远，东晋人，善清谈，官至太常卿。
注：孙兴公：孙绰，字兴公。
注：聊复：姑且再。
注：放：放声，发声。
注：那：怎么。
注：㯓（tà）腊：象声词，形容鼓一类乐器的声音，字形存疑。
注：枪（qiāng）铃：象声词，形容钟铃之声。

# 三十八｜桓公既废海西
原：桓公既废海西，立简文。侍中谢公见桓公拜，桓惊笑曰：“安石，卿何事至尔？”谢曰：“未有君拜于前，臣立于后。”|| 桓温废黜了海西公，拥立简文帝。侍中谢安见了桓温便下拜，桓温吃惊地笑道：“安石，你何至于这样？”谢安说：“哪有君主在前面下拜，臣子却在后面站着的道理。”
注：海西：海西公司马奕，东晋皇帝，被桓温废黜，降为海西公。
注：简文：简文帝司马昱。
注：侍中：侍从皇帝左右的近臣。
注：至尔：到这个地步。
注：谢安之语暗讽桓温权势凌驾于皇帝之上，连新君都要向他下拜。

# 三十九｜郗重熙与谢公书道
原：郗重熙与谢公书道：“王敬仁闻一年少怀问鼎，不知桓公德衰？为复后生可畏？”|| 郗昙给谢安写信说：“王修听说有个年轻人心怀问鼎之志，不知道是桓公的德行衰败了呢，¦还是后生可畏呢？”
注：郗重熙：郗昙，字重熙，郗鉴之子，官至北中郎将。
注：王敬仁：王修，字敬仁，王濛之子，早慧，二十四岁卒。
注：问鼎：楚庄王问周鼎轻重，比喻图谋夺取政权。
注：为复：还是。
注：年少所指，旧说即桓温；信中以“德衰”“后生可畏”反讽，具体所指存疑。

# 四十｜张苍梧是张凭之祖
原：张苍梧是张凭之祖，尝语凭父曰：“我不如汝。”凭父未解所以。苍梧曰：“汝有佳儿。”凭时年数岁，敛手曰：“阿翁，讵宜以子戏父？”|| 张镇是张凭的祖父，曾对张凭的父亲说：“我不如你。”张凭的父亲不明白为什么。张镇说：“你有个好儿子。”张凭当时才几岁，拱着手说：“爷爷，怎么能拿儿子来取笑父亲呢？”
注：张苍梧：张镇，字义远，曾任苍梧太守。
注：张凭：字长宗，东晋名士，官至御史中丞。
注：敛手：拱手，表示恭敬。
注：阿翁：对祖父的称呼。
注：讵（jù）：岂，怎么。
注：张镇言下之意是自己的儿子不如孙子，故张凭说他借儿子开父亲的玩笑。

# 四十一｜习凿齿、孙兴公未相识
原：习凿齿、孙兴公未相识，同在桓公坐。桓语孙：“可与习参军共语。”孙云：“蠢尔蛮荆，敢与大邦为仇？”习云：“薄伐猃狁，至于太原。”|| 习凿齿和孙绰互不相识，一同在桓温家作客。桓温对孙绰说：“你可以和习参军聊聊。”孙绰说：“蠢蠢的荆州蛮子，竟敢与大国作对？”习凿齿说：“出兵讨伐猃狁，一直打到太原。”
注：习凿齿：字彦威，襄阳人，曾为桓温属下参军，著《汉晋春秋》。
注：“蠢尔”二句：出自《诗经·小雅·采芑》，原指周伐荆楚；习凿齿是荆州人，孙绰借此嘲他。
注：“薄伐”二句：出自《诗经·小雅·六月》。
注：猃狁（xiǎn yǔn）：北方民族。孙绰是太原人，习凿齿以此回敬。

# 四十二｜桓豹奴是王丹阳外生
原：桓豹奴是王丹阳外生，形似其舅，桓甚讳之。宣武云：“不恒相似，时似耳。恒似是形，时似是神。”桓逾不说。|| 桓嗣是王混的外甥，相貌像他舅舅，桓嗣很忌讳别人说这事。桓温说：“也不是一直像，只是有时候像罢了。一直像的是外形，有时像的是神气。”桓嗣听了更不高兴。
注：桓豹奴：桓嗣，字恭祖，小字豹奴，桓冲之子，官至江州刺史。
注：王丹阳：王混，王导之孙，官至丹阳尹。
注：外生：外甥。
注：恒：经常，一直。
注：说：同“悦”。桓温表面宽解，实则说他连神气都像舅舅，更添一层揶揄。

# 四十三｜王子猷诣谢万
原：王子猷诣谢万，林公先在坐，瞻瞩甚高。王曰：“若林公须发并全，神情当复胜此不？”谢曰：“唇齿相须，不可以偏亡。须发何关于神明？”林公意甚恶，曰：“七尺之躯，今日委君二贤。”|| 王徽之去拜访谢万，支道林已先在座，顾盼之间神情十分高傲。王徽之说：“要是林公胡须头发都齐全，神情是不是还要胜过现在？”谢万说：“嘴唇和牙齿相互依存，缺一不可。胡须头发跟精神有什么关系？”支道林心里很不痛快，说：“我这七尺之躯，今天就交给二位贤者去评头论足吧。”
注：王子猷（yóu）：王徽之，字子猷，王羲之之子，性情放诞。
注：谢万：字万石，谢安之弟。
注：林公：支道林，僧人剃发，又容貌丑陋。
注：瞻瞩：顾盼的神情。
注：须：依存，又与“胡须”之“须”双关。
注：偏亡：缺失一方。
注：意甚恶：心情很坏。
注：委：交付。原文“曰”后缺冒号，补。

# 四十四｜郗司空拜北府
原：郗司空拜北府，王黄门诣郗门拜云：“应变将略，非其所长。”骤咏之不已。郗仓谓嘉宾曰：“公今日拜，子猷言语殊不逊，深不可容！”嘉宾曰：“此是陈寿作诸葛评，人以汝家比武侯，复何所言！”|| 郗愔受任北府长官，王徽之到郗家道贺，说：“随机应变的用兵谋略，不是他的长处。”一遍又一遍地吟诵个不停。郗融对郗超说：“父亲今天受官，子猷说话这么不恭敬，实在不能容忍！”郗超说：“这是陈寿评诸葛亮的话，人家把你父亲比作武侯，你还有什么可说的！”
注：郗司空：郗愔，字方回，郗鉴之子，曾镇京口，死赠司空。
注：北府：京口的别称。
注：拜：受官。
注：王黄门：王徽之，曾任黄门侍郎，是郗愔的外甥。
注：“应变将略”二句：陈寿《三国志》评诸葛亮语。
注：骤：屡次。
注：郗仓：郗融，小字仓，郗愔次子。
注：嘉宾：郗超，字景兴，小字嘉宾，郗愔长子。
注：汝家：你父亲。
