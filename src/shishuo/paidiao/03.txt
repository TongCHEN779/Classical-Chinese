# 四十五｜王子猷诣谢公
原：王子猷诣谢公，谢曰：“云何七言诗？”子猷承问，答曰：“昂昂若千里之驹，泛泛若水中之凫。”|| 王徽之去拜访谢安，谢安问：“七言诗是什么样子的？”王徽之顺着话头，答道：“昂首挺胸，像一匹千里马；随波漂荡，像水里的一只野鸭。”
注：王子猷：王徽之，字子猷，王羲之之子，性情放诞。谢公：谢安。
注：昂昂二句：出自《楚辞·卜居》，原是反问之辞。王徽之借两句七字语充作“七言诗”的样子，答得随口又俏皮。
注：凫（fú）：野鸭。

# 四十六｜王文度、范荣期俱为简文所要
原：王文度、范荣期俱为简文所要，范年大而位小，王年小而位大。将前，更相推在前，既移久，王遂在范后。王因谓曰：“簸之扬之，糠秕在前。”范曰：“洮之汰之，沙砾在后。”|| 王坦之、范启一同受简文帝邀请。范启年纪大而官位低，王坦之年纪轻而官位高。¦快要进去时，两人互相推让对方走在前面，推了好一阵，王坦之终于走到了范启后面。¦王坦之便说：“簸啊扬啊，糠皮秕子飘在前头。”¦范启答道：“淘啊洗啊，沙子石子沉在后头。”
注：王文度：王坦之，字文度，东晋名臣。范荣期：范启，字荣期。简文：简文帝司马昱，时尚为相王。要（yāo）：邀请。
注：簸之扬之：簸动谷物，轻的糠秕先飞出去，借以讥范启走在前面。
注：洮（táo）之汰之：用水淘洗，沉在后面的是沙砾，范启以此反讥王坦之。

# 四十七｜刘遵祖少为殷中军所知
原：刘遵祖少为殷中军所知，称之于庾公。庾公甚忻然，便取为佐。既见，坐之独榻上与语。刘尔日殊不称，庾小失望，遂名之为“羊公鹤”。昔羊叔子有鹤善舞，尝向客称之，客试使驱来，氃氋而不肯舞。故称比之。|| 刘爰之年轻时受到殷浩赏识，殷浩在庾亮面前称扬他。庾亮很高兴，就聘他做僚属。见面后，庾亮让他单独坐一张榻和他谈话。刘爰之那天表现大不相称，庾亮有点失望，就叫他“羊公鹤”。从前羊祜有只鹤善于跳舞，他曾向客人夸耀，客人让人把鹤赶来试试，那鹤却蓬松着羽毛，就是不肯跳。所以庾亮拿它来比刘爰之。
注：刘遵祖：刘爰之，字遵祖，东晋人。殷中军：殷浩，曾任中军将军。庾公：庾亮。
注：独榻：单人坐榻，让客人独坐，是优待之礼。
注：羊叔子：羊祜，字叔子，西晋名将，镇守荆州。
注：氃氋（tóng méng）：羽毛松散蓬乱的样子。

# 四十八｜魏长齐雅有体量
原：魏长齐雅有体量，而才学非所经。初宦当出，虞存嘲之曰：“与卿约法三章：谈者死，文笔者刑，商略抵罪。”魏怡然而笑，无忤于色。|| 魏顗很有气度，可才学不是他的长处。他刚要出去做官时，虞存跟他开玩笑说：“跟你约法三章：清谈的处死，舞文弄墨的判刑，品评人物的抵罪。”魏顗乐呵呵地笑了，脸上毫无不快之色。
注：魏长齐：魏顗，字长齐，会稽人，官至山阴令。体量：度量、气度。
注：虞存：字道长，会稽山阴人，官至尚书吏部郎。
注：约法三章：借用汉高祖入关与父老约法三章的典故。谈、文笔、商略恰是名士所长，虞存故意“禁”之，暗笑魏顗三样都不会。
注：商略：品评人物。忤：抵触。

# 四十九｜郗嘉宾书与袁虎
原：郗嘉宾书与袁虎，道戴安道、谢居士云：“恒任之风，当有所弘耳。”以袁无恒，故以此激之。|| 郗超写信给袁宏，谈到戴逵、谢敷时说：“他们那种持之以恒、担当自任的风范，应当好好发扬才是。”因为袁宏做事没有恒心，所以拿这话来刺激他。
注：郗嘉宾：郗超，字嘉宾，桓温谋主。袁虎：袁宏，小字虎，以文才著称。
注：戴安道：戴逵，字安道，隐居不仕。谢居士：谢敷，隐居不仕，奉佛，故称居士。
注：恒任：有恒心、能自任其事。“恒任”二字确切含义存疑。弘：发扬。

# 五十｜范启与郗嘉宾书曰
原：范启与郗嘉宾书曰：“子敬举体无饶纵，掇皮无余润。”郗答曰：“举体无余润，何如举体非真者？”范性矜假多烦，故嘲之。|| 范启给郗超写信说：“王献之浑身上下没一点多余的地方，剥了皮也挤不出半点油水。”郗超回信说：“浑身没油水，比起浑身上下没一处是真的，又怎么样呢？”范启生性爱装模作样，又啰唆烦琐，所以郗超拿这话嘲讽他。
注：子敬：王献之，字子敬，形貌清瘦。举体：全身。饶纵：多余、丰满。
注：掇（duō）皮：剥去皮。余润：多余的油水、丰润之处。
注：矜假：矜持做作。

# 五十一｜二郗奉道
原：二郗奉道，二何奉佛，皆以财贿。谢中郎云：“二郗谄于道，二何佞于佛。”|| 郗家兄弟信奉道教，何家兄弟信奉佛教，都在上面花了大把钱财。谢万说：“郗家二位是巴结道教，何家二位是讨好佛教。”
注：二郗：郗愔、郗昙兄弟，信奉天师道。二何：何充、何准兄弟，崇奉佛教。
注：谢中郎：谢万，谢安之弟。
注：谄（chǎn）、佞（nìng）：都是谄媚讨好的意思，谢万以此讽刺他们用钱财求福。

# 五十二｜王文度在西州
原：王文度在西州，与林法师讲，韩、孙诸人并在坐。林公理每欲小屈，孙兴公曰：“法师今日如著弊絮在荆棘中，触地挂阂。”|| 王坦之在西州时，和支道林法师讲论义理，韩伯、孙绰等人都在座。支道林的道理常常略处下风，孙绰说：“法师今天就像穿着破棉絮走进荆棘丛里，碰到哪儿都被挂住。”
注：西州：扬州刺史治所，在建康台城之西，故称。林法师：支遁，字道林，东晋名僧，善谈玄理。
注：韩、孙：韩伯（字康伯）、孙绰（字兴公）。小屈：稍稍理屈。
注：著弊絮：穿着破旧的絮衣。触地：处处。挂阂（ài）：牵挂阻碍。

# 五十三｜范荣期见郗超俗情不淡
原：范荣期见郗超俗情不淡，戏之曰：“夷、齐、巢、许，一诣垂名，何必劳神苦形，支策据梧邪？”郗未答，韩康伯曰：“何不使游刃皆虚？”|| 范启见郗超世俗之情还没有淡去，便取笑他说：“伯夷、叔齐、巢父、许由，一下子就名垂后世了，何必费尽心力、劳苦身体，像师旷那样拄着杖、像惠子那样靠着梧桐苦苦思索呢？”郗超还没回答，韩伯说：“何不让刀刃都在空隙间游走呢？”
注：夷、齐、巢、许：伯夷、叔齐、巢父、许由，古代著名的高士隐者。一诣：一下子达到。
注：支策据梧：语本《庄子·齐物论》，师旷拄杖击节，惠子倚梧桐而论辩，指苦心劳神于技艺辩说。
注：游刃皆虚：用《庄子·养生主》庖丁解牛“游刃有余”之意，言顺乎自然，处世便可从容无碍。韩伯此语是替郗超解围，还是兼讽范启，存疑。

# 五十四｜简文在殿上行
原：简文在殿上行，右军与孙兴公在后。右军指简文语孙曰：“此啖名客。”简文顾曰：“天下自有利齿儿。”后王光禄作会稽，谢车骑出曲阿祖之，王孝伯罢秘书丞在坐，谢言及此事，因视孝伯曰：“王丞齿似不钝。”王曰：“不钝，颇亦验。”|| 简文帝在殿上走着，王羲之和孙绰跟在后面。¦王羲之指着简文帝对孙绰说：“这是个贪图名声的家伙。”¦简文帝回头说：“天下本来就有牙尖嘴利的小子。”¦后来王蕴出任会稽内史，谢玄到曲阿为他饯行，王恭刚被免去秘书丞，也在座。谢玄说起这件事，就看着王恭说：“王丞的牙齿看来也不钝。”¦王恭说：“不钝，倒也颇有些应验。”
注：右军：王羲之。孙兴公：孙绰。啖名客：贪吃名声的人，戏说简文帝好名。
注：利齿儿：牙齿锋利的人，指嘴巴刻薄、爱讥评人的人。
注：王光禄：王蕴，曾任光禄大夫。谢车骑：谢玄。祖：饯行。曲阿：县名，今江苏丹阳。
注：王孝伯：王恭，字孝伯，王蕴之子。王恭说“颇亦验”，大概指自己因口齿锋利而遭罢官，具体所指存疑。

# 五十五｜谢遏夏月尝仰卧
原：谢遏夏月尝仰卧，谢公清晨卒来，不暇著衣，跣出屋外，方蹑履问讯。公曰：“汝可谓‘前倨而后恭’。”|| 谢玄夏天曾经仰面躺着，谢安一大早突然来了，谢玄来不及穿衣服，光着脚跑出屋外，这才穿上鞋子问候。谢安说：“你这真可以说是‘先前傲慢，后来恭敬’啊。”
注：谢遏：谢玄，小字遏，谢安之侄。谢公：谢安。卒（cù）：同“猝”，突然。
注：跣（xiǎn）：赤脚。蹑履：穿上鞋。
注：前倨而后恭：语出《战国策·秦策》，苏秦之嫂先前对他傲慢、后来恭敬。谢安借来打趣谢玄先“仰卧”后“蹑履”。倨，傲慢，这里双关仰躺的姿态。

# 五十六｜顾长康作殷荆州佐
原：顾长康作殷荆州佐，请假还东。尔时例不给布颿，顾苦求之，乃得。发至破冢，遭风大败。作笺与殷云：“地名破冢，真破冢而出。行人安稳，布颿无恙。”|| 顾恺之做殷仲堪的僚属，请假回东边老家。那时按惯例不给僚属配帆船，顾恺之苦苦请求，才借到了。船开到破冢，遇上大风，船坏得厉害。他写信给殷仲堪说：“地名叫破冢，我真是破开坟墓逃出来了。行人安稳，布帆无恙。”
注：顾长康：顾恺之，字长康，东晋画家，好诙谐。殷荆州：殷仲堪，时任荆州刺史。
注：给（jǐ）：供给。布颿（fān）：布帆，指帆船。
注：破冢（zhǒng）：地名，在今湖北江陵以东。顾恺之借地名说自己死里逃生。
注：行人安稳，布颿无恙：明明船已大坏，偏说帆船无恙，是故作宽慰的戏言。

# 五十七｜苻朗初过江
原：苻朗初过江，王咨议大好事，问中国人物及风土所生，终无极已，朗大患之。次复问奴婢贵贱，朗云：“谨厚有识中者，乃至十万；无意为奴婢问者，止数千耳。”|| 苻朗刚渡江南来时，王肃之特别爱打听事，问他中原的人物以及风土物产，没完没了，苻朗烦透了。接着王肃之又问奴婢价钱的高低，苻朗说：“谨慎厚道、有见识的，能值到十万；不懂事、专爱打听奴婢之类问题的，只值几千罢了。”
注：苻朗：字元达，前秦苻坚之侄，后降东晋。
注：王咨议：王肃之，王羲之之子，曾任骠骑咨议参军。
注：中国：指中原地区。终无极已：没完没了。患：厌烦。
注：无意：愚昧不懂事。苻朗借奴婢价钱，暗骂发问的人不值钱。

# 五十八｜东府客馆是版屋
原：东府客馆是版屋。谢景重诣太傅，时宾客满中，初不交言，直仰视云：“王乃复西戎其屋。”|| 东府的宾馆是木板盖的房子。谢重去拜见太傅司马道子，当时宾客满堂，他跟谁都不搭话，只是抬头望着屋顶说：“大王竟然把自己的房子弄得像西戎人的一样。”
注：东府：会稽王司马道子的府第，在建康城东，故称。版屋：木板建的房子。
注：谢景重：谢重，字景重，曾任会稽王长史。太傅：司马道子，封会稽王，官至太傅。
注：西戎其屋：语本《诗经·秦风·小戎》“在其板屋”，西戎之地以木板为屋，此用作动词，戏言王府简陋。

# 五十九｜顾长康啖甘蔗
原：顾长康啖甘蔗，先食尾。人问所以，云：“渐至佳境。”|| 顾恺之吃甘蔗，先从梢头吃起。有人问他为什么，他说：“这样越吃越甜，渐渐进入佳境。”
注：顾长康：顾恺之。甘蔗梢头味淡，根部最甜，所以先吃尾部是由淡入甜。

# 六十｜孝武属王珣求女婿曰
原：孝武属王珣求女婿曰：“王敦、桓温磊砢之流，既不可复得，且小如意，亦好豫人家事，酷非所须。正如真长、子敬比，最佳。”珣举谢混。后袁山松欲拟谢婚，王曰：“卿莫近禁脔。”|| 孝武帝托王珣替他物色女婿，说：“像王敦、桓温那样才气超群的人，已经不可能再有了，况且他们稍一得志，就爱插手别人的家事，这种人我实在不需要。最好是刘惔、王献之那一类的人。”王珣推荐了谢混。后来袁山松想把女儿许配谢混，王珣说：“你可别去碰皇上的那块禁脔。”
注：孝武：东晋孝武帝司马曜。属（zhǔ）：同“嘱”，托付。王珣：王导之孙。
注：磊砢（luǒ）：才能卓越、气度不凡。王敦、桓温都是驸马，后来权倾朝野。小如意：稍稍得意。豫：参与，干预。
注：真长：刘惔，字真长；子敬：王献之。二人都是驸马，以清雅著称。谢混：谢安之孙，后尚晋陵公主。
注：禁脔（luán）：晋元帝时猪颈肉最美，专供皇帝，群臣不敢吃，称“禁脔”，比喻别人不得染指之物。

# 六十一｜桓南郡与殷荆州语次
原：桓南郡与殷荆州语次，因共作了语。顾恺之曰：“火烧平原无遗燎。”桓曰：“白布缠棺竖旒旐。”殷曰：“投鱼深渊放飞鸟。”次复作危语。桓曰：“矛头淅米剑头炊。”殷曰：“百岁老翁攀枯枝。”顾曰：“井上辘轳卧婴儿。”殷有一参军在坐，云：“盲人骑瞎马，夜半临深池。”殷曰：“咄咄逼人！”仲堪眇目故也。|| 桓玄和殷仲堪闲谈时，顺便一起玩“了语”。顾恺之说：“大火烧平原，余火都不剩。”桓玄说：“白布裹棺材，竖起引魂幡。”殷仲堪说：“鱼儿投深渊，鸟儿放上天。”接着又玩“危语”。桓玄说：“矛尖上淘米，剑尖上做饭。”殷仲堪说：“百岁老翁爬枯枝。”顾恺之说：“井口辘轳上睡婴儿。”殷仲堪手下一位参军也在座，说：“瞎子骑着瞎马，半夜走到深水池边。”殷仲堪说：“这可太逼人了！”因为殷仲堪瞎了一只眼。
注：桓南郡：桓玄，袭封南郡公。殷荆州：殷仲堪。语次：谈话之间。
注：了语：一种语言游戏，各说一句押韵的话，意思都要有“完结”之意。燎：余火。旒旐（liú zhào）：出殡时的魂幡。
注：危语：同样的游戏，句句描写危险情景。淅（xī）米：淘米。辘轳（lù lu）：井上汲水的绞车。
注：咄咄（duō）：惊叹声。眇（miǎo）目：一只眼瞎。参军的话正戳中殷仲堪的短处。

# 六十二｜桓玄出射
原：桓玄出射，有一刘参军与周参军朋赌，垂成，唯少一破。刘谓周曰：“卿此起不破，我当挞卿。”周曰：“何至受卿挞？”刘曰：“伯禽之贵，尚不免挞，而况于卿！”周殊无忤色。桓语庾伯鸾曰：“刘参军宜停读书，周参军且勤学问。”|| 桓玄出去射箭，有位刘参军和周参军结成一组赌输赢，眼看就要赢了，只差射中一箭。刘参军对周参军说：“你这一箭要是射不中，我就要打你。”周参军说：“哪至于挨你的打？”刘参军说：“伯禽那样尊贵，尚且免不了挨打，何况是你！”周参军丝毫没有不高兴的样子。桓玄对庾鸿说：“刘参军该停下别读书了，周参军却还得好好学习。”
注：朋赌：结组赌射。垂成：快要成功。破：射中靶子。
注：伯禽：周公之子，封于鲁。相传成王有过，周公便鞭打伯禽以示教诫。刘参军以周公自比，占了周参军的便宜。
注：庾伯鸾：庾鸿，字伯鸾。桓玄的意思是：刘参军读了点书就拿来占人便宜，周参军却连被占便宜都听不出来。

# 六十三｜桓南郡与道曜讲老子
原：桓南郡与道曜讲《老子》，王侍中为主簿，在坐。桓曰：“王主簿可顾名思义。”王未答，且大笑。桓曰：“王思道能作大家儿笑。”|| 桓玄和道曜讲论《老子》，王桢之当时任主簿，也在座。桓玄说：“王主簿可以看看自己的名字，想想其中的意思。”王桢之没有回答，只是放声大笑。桓玄说：“王思道倒是会摆出大家子弟的笑法。”
注：桓南郡：桓玄。道曜：人名，生平不详。
注：王侍中：王桢之，字思道，王徽之之子，后官至侍中。
注：顾名思义：王桢之字“思道”，而《老子》讲“道”，桓玄借此打趣他。
注：大家儿：世家大族的子弟。桓玄以笑代答的应付，存几分讽刺。

# 六十四｜祖广行恒缩头
原：祖广行恒缩头。诣桓南郡，始下车，桓曰：“天甚晴朗，祖参军如从屋漏中来。”|| 祖广走路总是缩着脖子。他去拜访桓玄，刚下车，桓玄就说：“天这么晴朗，祖参军倒像是从漏雨的屋子里钻出来的。”
注：祖广：字渊度，范阳人，任桓玄参军。
注：桓南郡：桓玄。始：才，刚刚。屋漏：屋顶漏雨，人在其中就会缩头躲水。

# 六十五｜桓玄素轻桓崖
原：桓玄素轻桓崖。崖在京下有好桃，玄连就求之，遂不得佳者。玄与殷仲文书，以为嗤笑曰：“德之休明，肃慎贡其楛矢；如其不尔，篱壁间物，亦不可得也。”|| 桓玄向来看不起桓修。桓修在京城有好桃树，桓玄一次次去讨桃，却始终没得到好的。桓玄写信给殷仲文，拿这事取笑说：“德行美好清明的时候，连远方的肃慎都来进贡楛木箭；要是不这样，就连篱笆墙边长的东西，也休想得到。”
注：桓崖：桓修，小字崖，桓玄的堂兄弟，尚简文帝女。京下：京城，指建康。就：前往。遂：竟然。
注：殷仲文：桓玄的姐夫，后随桓玄作乱。
注：肃慎贡其楛（hù）矢：肃慎是古代东北民族，周初曾进贡楛木箭杆的箭，事见《国语》。桓玄自嘲德望不足，实则讥桓修吝啬。
注：篱壁间物：篱笆墙边的寻常东西，指园中桃子。
