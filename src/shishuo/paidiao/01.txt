# 本门导读
题解：排调，即互相嘲戏调笑。魏晋士人斗嘴，常借谐音、讳字、经典成语翻出妙语，以机敏应对见才情，往往笑中带刺，也透出时人的门第观念与人情冷暖。

# 一｜诸葛瑾为豫州
原：诸葛瑾为豫州，遣别驾到台，语云：“小儿知谈，卿可与语。”连往诣恪，恪不与相见。后于张辅吴坐中相遇，别驾唤恪：“咄咄郎君。”恪因嘲之曰：“豫州乱矣，何咄咄之有？”答曰：“君明臣贤，未闻其乱。”恪曰：“昔唐尧在上，四凶在下。”答曰：“非唯四凶，亦有丹朱。”于是一坐大笑。|| 诸葛瑾任豫州刺史时，派别驾到京城的官署去，临行嘱咐他：“我那小儿子能言善谈，你可以和他聊聊。”¦别驾接连去拜访诸葛恪，诸葛恪都不见他。¦后来两人在张昭家的宴席上碰面，别驾招呼诸葛恪：“哎呀呀，小郎君！”¦诸葛恪趁机嘲弄他：“豫州出乱子了吗？有什么好哎呀的？”¦别驾答：“君主英明，臣下贤良，没听说有什么乱子。”¦诸葛恪说：“从前唐尧在上，底下照样有四凶。”¦别驾答：“不但有四凶，还有个丹朱呢。”¦于是满座大笑。
注：诸葛瑾：字子瑜，诸葛亮之兄，仕吴。
注：为豫州：任豫州刺史（遥领）。
注：别驾：州刺史的高级佐吏。
注：台：中央官署。
注：恪：诸葛恪，字元逊，诸葛瑾长子，以机辩知名，后官至太傅，被杀。
注：张辅吴：张昭，封辅吴将军。
注：咄咄：惊叹声。
注：四凶：传说尧时共工、驩兜、三苗、鲧四个恶人。
注：丹朱：尧之子，不肖。别驾以丹朱回敬，讥诸葛恪是长官的不肖之子。

# 二｜晋文帝与二陈共车
原：晋文帝与二陈共车，过唤钟会同载，即驶车委去。比出，已远。既至，因嘲之曰：“与人期行，何以迟迟？望卿遥遥不至。”会答曰：“矫然懿实，何必同群？”帝复问会：“皋繇何如人？”答曰：“上不及尧、舜，下不逮周、孔，亦一时之懿士。”|| 晋文帝司马昭和陈骞、陈泰同乘一辆车，路过钟会家时叫他一起坐车，随即又赶着车扔下他走了。等钟会出来，车已经走远了。钟会赶到以后，司马昭嘲笑他说：“和人约好同行，为什么迟迟不来？望着你，遥遥不到。”钟会答：“矫然出众、美好诚实的人，何必与众人合群？”司马昭又问钟会：“皋繇是怎样的人？”钟会答：“上比不上尧、舜，下赶不上周公、孔子，也算一时的懿美之士。”
注：晋文帝：司马昭，其父名懿。
注：二陈：陈骞与陈泰，陈骞之父名矫，陈泰之父名群。
注：委去：丢下而去。
注：比：等到。
注：遥遥：“遥”与钟会之父钟繇的“繇”同音，司马昭借此犯钟会家讳取笑。
注：矫、懿、群：钟会一句话里分别嵌入陈骞、司马昭、陈泰三人父名回敬；“皋繇”“懿士”又是一来一往的讳字之戏。

# 三｜钟毓为黄门郎
原：钟毓为黄门郎，有机警，在景王坐燕饮。时陈群子玄伯、武周子元夏同在坐，共嘲毓。景王曰：“皋繇何如人？”对曰：“古之懿士。”顾谓玄伯、元夏曰：“君子周而不比，群而不党。”|| 钟毓做黄门郎，为人机警，有一次在景王司马师座上宴饮。当时陈群的儿子陈泰、武周的儿子武陔也在座，一起拿他取笑。司马师问：“皋繇是怎样的人？”钟毓答：“古代的懿美之士。”又回头对陈泰、武陔说：“君子周而不比，群而不党。”
注：钟毓：字稚叔，钟繇长子、钟会之兄。
注：黄门郎：侍从皇帝、传达诏命的官。
注：景王：司马师，司马懿长子，晋朝建立后追尊为景帝。
注：玄伯：陈泰的字。
注：元夏：武陔的字，其父武周。
注：钟毓以“懿”回敬司马师，又引《论语》“周而不比”“群而不党”，暗含武周、陈群之名。

# 四｜嵇阮山刘在竹林酣饮
原：嵇、阮、山、刘在竹林酣饮，王戎后往，步兵曰：“俗物已复来败人意！”王笑曰：“卿辈意亦复可败邪？”|| 嵇康、阮籍、山涛、刘伶在竹林里畅饮，王戎后到，阮籍说：“俗物又来败坏人的兴致了！”王戎笑道：“你们这些人的兴致，也是能败坏得了的吗？”
注：嵇、阮、山、刘：嵇康、阮籍、山涛、刘伶，与王戎等合称竹林七贤。
注：步兵：阮籍，曾任步兵校尉。
注：败人意：扫人兴致。

# 五｜晋武帝问孙皓
原：晋武帝问孙皓：“闻南人好作《尔汝歌》，颇能为不？”皓正饮酒，因举觞劝帝而言曰：“昔与汝为邻，今与汝为臣。上汝一杯酒，令汝寿万春。”帝悔之。|| 晋武帝问孙皓：“听说南方人喜欢作《尔汝歌》，你会不会作？”孙皓正在喝酒，就举起酒杯向武帝劝酒，唱道：“从前和你是邻居，如今给你当臣子。敬你一杯酒，祝你寿万春。”武帝听了后悔不该问。
注：晋武帝：司马炎，西晋开国之君。
注：孙皓：吴国末代君主，降晋后封归命侯。
注：《尔汝歌》：江南民间歌谣，歌中以“尔”“汝”相称，表示亲昵而不拘礼。孙皓借此当面称武帝为“汝”。
注：觞（shāng）：酒杯。

# 六｜孙子荆年少时欲隐
原：孙子荆年少时欲隐，语王武子“当枕石漱流”，误曰“漱石枕流”。王曰：“流可枕，石可漱乎？”孙曰：“所以枕流，欲洗其耳；所以漱石，欲砺其齿。”|| 孙楚年轻时想去隐居，对王济说“要去枕石漱流”，却误说成了“漱石枕流”。王济说：“流水能当枕头，石头能用来漱口吗？”孙楚说：“之所以枕着流水，是想洗耳朵；之所以用石头漱口，是想磨砺牙齿。”
注：孙子荆：孙楚，字子荆，太原人，有才气，好自负。
注：王武子：王济，字武子。
注：枕石漱流：枕山石、饮溪流，形容隐居山林。
注：洗其耳：用许由闻尧让天下而洗耳的典故。
注：砺：磨。

# 七｜头责秦子羽云
题解：此则出自晋人张敏的游戏文章《头责子羽文》，借“头”责备主人，讥讽当时庸才显达。
原：头责秦子羽云：“子曾不如太原温颙，颍川荀寓，范阳张华，士卿刘许，义阳邹湛，河南郑诩。此数子者，或謇吃无宫商，或尫陋希言语，或淹伊多姿态，或讙哗少智谞，或口如含胶饴，或头如巾齑杵。而犹以文采可观，意思详序，攀龙附凤，并登天府。”|| 秦子羽的脑袋责备秦子羽说：“你竟然比不上太原的温颙、颍川的荀寓、范阳的张华、士卿刘许、义阳的邹湛、河南的郑诩。这几个人，有的口吃说话不成腔调，有的瘦弱丑陋很少开口，有的扭扭捏捏做作多姿，有的吵吵嚷嚷缺少智慧，有的嘴里像含着糖稀，有的脑袋像裹着头巾的捣菜杵。可他们还是凭着文采可观、思路周密，攀附权贵，都登上了朝廷的高位。”
注：秦子羽：文中假托的人物，存疑。
注：曾：竟然。
注：謇（jiǎn）吃：口吃。
注：无宫商：说话不成音调。
注：尫（wāng）陋：瘦弱丑陋。
注：淹伊：扭捏作态的样子。
注：讙哗：喧闹。
注：智谞（xū）：智慧。
注：胶饴（yí）：糖稀。
注：巾齑（jī）杵：裹着巾的捣菜杵，形容头形难看。
注：天府：朝廷。

# 八｜王浑与妇钟氏共坐
原：王浑与妇钟氏共坐，见武子从庭过，浑欣然谓妇曰：“生儿如此，足慰人意。”妇笑曰：“若使新妇得配参军，生儿故可不啻如此。”|| 王浑和妻子钟氏坐在一起，看见儿子王济从院子里走过，王浑高兴地对妻子说：“生了这样的儿子，足以让人宽心了。”妻子笑道：“要是我能嫁给参军，生的儿子本来还不止这样呢。”
注：王浑：字玄冲，西晋重臣，王济之父。
注：钟氏：钟琰，魏太傅钟繇曾孙女，有才识。
注：新妇：当时妇人的自称。
注：参军：指王浑之弟王沦，曾任大将军参军，有才名而早逝。
注：不啻（chì）：不止。

# 九｜荀鸣鹤陆士龙二人未相识
原：荀鸣鹤、陆士龙二人未相识，俱会张茂先坐。张令共语，以其并有大才，可勿作常语。陆举手曰：“云间陆士龙。”荀答曰：“日下荀鸣鹤。”陆曰：“既开青云睹白雉，何不张尔弓，布尔矢？”荀答曰：“本谓云龙骙骙，定是山鹿野麋。兽弱弩强，是以发迟。”张乃抚掌大笑。|| 荀隐和陆云两人互不相识，一同在张华家作客。张华让他们交谈，因为两人都很有才，嘱咐他们别说寻常话。陆云拱手说：“云间陆士龙。”荀隐答：“日下荀鸣鹤。”陆云说：“既然拨开青云看见了白雉，为什么不拉开你的弓、搭上你的箭？”荀隐答：“原以为是云中矫健的龙，没想到是山里的鹿、野地的麋。野兽太弱而弓弩太强，所以迟迟不发。”张华听了拍手大笑。
注：荀鸣鹤：荀隐，字鸣鹤，颍川人。
注：陆士龙：陆云，字士龙，陆机之弟，吴郡华亭人。
注：张茂先：张华。
注：云间：华亭的别称。
注：日下：京城一带，荀隐家近洛阳，故称。两人以“云”“龙”“日”“鹤”各嵌字号对答。
注：白雉：白色野鸡，陆云以“雉”比“鹤”，讥荀隐。
注：骙骙（kuí）：强健的样子。
注：定：竟然。
注：麋：麋鹿，荀隐反讥陆云不是龙。

# 十｜陆太尉诣王丞相
原：陆太尉诣王丞相，王公食以酪。陆还，遂病。明日，与王笺云：“昨食酪小过，通夜委顿。民虽吴人，几为伧鬼。”|| 陆玩去拜访王导，王导请他吃奶酪。陆玩回家后就病了。第二天，他给王导写信说：“昨天奶酪吃多了一点，整夜难受。我虽是吴地人，却差点成了北方伧鬼。”
注：陆太尉：陆玩，字士瑶，吴郡人，官至司空，死后追赠太尉。
注：王丞相：王导。
注：酪（lào）：牛羊乳制成的食品，北方人常食，南人不惯。
注：笺：给尊长的书信。
注：委顿：疲困不支。
注：伧（cāng）鬼：南人蔑称北人为“伧”，陆玩借吃北方食物生病自嘲，也暗讽北人。

# 十一｜元帝皇子生
原：元帝皇子生，普赐群臣。殷洪乔谢曰：“皇子诞育，普天同庆。臣无勋焉，而猥颁厚赉。”中宗笑曰：“此事岂可使卿有勋邪？”|| 晋元帝的皇子出生，普遍赏赐群臣。殷羡谢恩说：“皇子诞生，普天同庆。臣在这件事上没有功劳，却蒙您颁下丰厚的赏赐。”元帝笑道：“这种事怎么能让你有功劳呢？”
注：元帝：司马睿，东晋开国之君，庙号中宗。
注：殷洪乔：殷羡，字洪乔，官至豫章太守。
注：猥：谦词，犹言“辱蒙”。
注：厚赉（lài）：丰厚的赏赐。
注：元帝之言是双关的玩笑：生皇子之事，臣下当然不能“有功”。

# 十二｜诸葛令王丞相共争姓族先后
原：诸葛令、王丞相共争姓族先后，王曰：“何不言葛、王，而云王、葛？”令曰：“譬言驴马，不言马驴，驴宁胜马邪？”|| 诸葛恢和王导一起争论两家姓氏的先后，王导说：“为什么人们不说‘葛王’，而说‘王葛’？”诸葛恢说：“好比人们说‘驴马’，不说‘马驴’，难道驴就胜过马吗？”
注：诸葛令：诸葛恢，字道明，官至尚书令。
注：姓族先后：门第高下。时人并称“王葛”，王在前。
注：宁（nìng）：难道。诸葛恢以“驴马”为喻，意谓排在前面未必更好。

# 十三｜刘真长始见王丞相
原：刘真长始见王丞相，时盛暑之月，丞相以腹熨弹棋局，曰：“何乃渹？”刘既出，人问：“见王公云何？”刘曰：“未见他异，唯闻作吴语耳。”|| 刘惔初次拜见王导，正值盛夏，王导把肚子贴在弹棋盘上，说：“怎么这样凉啊？”刘惔出来以后，有人问：“见了王公觉得怎么样？”刘惔说：“没看出有什么特别，只听见他讲吴语罢了。”
注：刘真长：刘惔，字真长，东晋名士，官至丹阳尹。
注：熨（yùn）：紧贴。
注：弹棋局：弹棋的棋盘，多为石制。
注：渹（qìng）：凉，吴地方言。王导本是北方士族，南渡后学说吴语以笼络江东人士。

# 十四｜王公与朝士共饮酒
原：王公与朝士共饮酒，举琉璃碗谓伯仁曰：“此碗腹殊空，谓之宝器，何邪？”答曰：“此碗英英，诚为清彻，所以为宝耳。”|| 王导和朝中官员一起喝酒，举起琉璃碗对周顗说：“这碗肚子里空空的，却称作宝器，为什么呢？”周顗答：“这碗晶莹剔透，确实清澈纯净，所以才是宝物啊。”
注：王公：王导。
注：伯仁：周顗（yǐ），字伯仁。
注：腹殊空：王导借碗嘲周顗腹中空虚。
注：英英：晶莹明亮。
注：清彻：清澈透明。周顗借以自许清白。

# 十五｜谢幼舆谓周侯曰
原：谢幼舆谓周侯曰：“卿类社树，远望之，峨峨拂青天；就而视之，其根则群狐所托，下聚溷而已。”答曰：“枝条拂青天，不以为高；群狐乱其下，不以为浊。聚溷之秽，卿之所保，何足自称？”|| 谢鲲对周顗说：“你像社庙里的大树，远远望去，高高地直拂青天；走近一看，树根是一群狐狸栖身的地方，底下聚着的不过是污秽罢了。”周顗回答：“枝条拂着青天，我不认为高；群狐在下面捣乱，我也不认为浊。至于聚集的污秽，那是你自己所守着的，有什么值得拿来说嘴的？”
注：谢幼舆：谢鲲，字幼舆，放达不拘。
注：周侯：周顗，袭父爵武城侯。
注：社树：土地庙旁的大树。
注：峨峨：高耸的样子。
注：就：靠近。
注：溷（hùn）：粪秽。周顗身居高位而好与狎客游，谢鲲以此相讥。
注：秽（huì）：肮脏。
注：保：守持。
注：称：夸说。

# 十六｜王长豫幼便和令
原：王长豫幼便和令，丞相爱恣甚笃。每共围棋，丞相欲举行，长豫按指不听。丞相笑曰：“讵得尔？相与似有瓜葛。”|| 王悦从小就温和乖巧，王导对他十分宠爱纵容。每次父子一起下围棋，王导要落子，王悦就按住他的手指不让。王导笑着说：“怎么能这样？咱们俩好像还有点亲戚关系吧。”
注：王长豫：王悦，字长豫，王导长子，早卒。
注：和令：温和美好。
注：爱恣：宠爱放纵。
注：举行：拿起棋子落下。
注：不听：不许。
注：讵（jù）：岂。
注：瓜葛：瓜与葛都蔓生缠绕，喻亲戚关系。父子本是至亲，王导故意说“似有瓜葛”，是玩笑语。

# 十七｜明帝问周伯仁
原：明帝问周伯仁：“真长何如人？”答曰：“故是千斤犗特。”王公笑其言。伯仁曰：“不如卷角牸，有盘辟之好。”|| 晋明帝问周顗：“刘惔是个怎样的人？”周顗答：“确实是一头有千斤力气的阉公牛。”王导笑话他这句话。周顗说：“总比不上角都卷起来的老母牛，善于周旋打转。”
注：明帝：司马绍，元帝之子。
注：真长：刘惔。
注：故：确实。
注：犗（jiè）特：阉割过的公牛，喻有力而驯顺。
注：卷角牸（zì）：角已卷曲的老母牛。
注：盘辟：盘旋周转，讥王导善于周旋应付。

# 十八｜王丞相枕周伯仁膝
原：王丞相枕周伯仁膝，指其腹曰：“卿此中何所有？”答曰：“此中空洞无物，然容卿辈数百人。”|| 王导枕在周顗的腿上，指着他的肚子说：“你这里头装了些什么？”周顗答：“这里面空空荡荡什么也没有，可容得下几百个你这样的人。”
注：周伯仁：周顗。以腹中空洞自嘲，又以能容数百个王导回敬，语带双关。

# 十九｜干宝向刘真长叙其搜神记
原：干宝向刘真长叙其《搜神记》，刘曰：“卿可谓鬼之董狐。”|| 干宝向刘惔讲述他写的《搜神记》，刘惔说：“你可以说是鬼神世界的董狐了。”
注：干宝：字令升，东晋史学家，著《晋纪》，又采集神怪故事成《搜神记》。
注：董狐：春秋时晋国史官，秉笔直书，被孔子称为“古之良史”。刘惔以此称干宝，既是称许也是调侃。

# 二十｜许文思往顾和许
原：许文思往顾和许，顾先在帐中眠。许至，便径就床角枕共语。既而唤顾共行，顾乃命左右取杭上新衣，易己体上所著。许笑曰：“卿乃复有行来衣乎？”|| 许文思到顾和家去，顾和正在帐子里睡觉。许文思一到，就直接上床，枕着角枕和他聊天。过了一会儿叫顾和一起出门，顾和便叫手下取来衣架上的新衣服，换掉身上穿的。许文思笑道：“你居然还有专门出门穿的衣服啊？”
注：许文思：许琛，字文思，生平不详。
注：顾和：字君孝，吴郡人，东晋名臣。
注：许：住处。
注：角枕：以兽角装饰的枕头。
注：杭：通“桁”（hàng），衣架。
注：行来衣：出门见人穿的衣服。许文思笑顾和讲究外表。

# 二十一｜康僧渊目深而鼻高
原：康僧渊目深而鼻高，王丞相每调之。僧渊曰：“鼻者，面之山；目者，面之渊。山不高则不灵，渊不深则不清。”|| 康僧渊眼窝深、鼻梁高，王导常拿这个开他玩笑。康僧渊说：“鼻子是脸上的山，眼睛是脸上的潭。山不高就没有灵气，潭不深就不会清澈。”
注：康僧渊：东晋僧人，西域胡人血统，精通佛理。
注：调（tiáo）：嘲弄。
注：渊：深潭。

# 二十二｜何次道往瓦官寺
原：何次道往瓦官寺，礼拜甚勤，阮思旷语之曰：“卿志大宇宙，勇迈终古。”何曰：“卿今日何故忽见推？”阮曰：“我图数千户郡，尚不能得；卿乃图作佛，不亦大乎？”|| 何充到瓦官寺去，礼佛十分殷勤，阮裕对他说：“你的志向比宇宙还大，勇气超过古往今来所有人。”何充说：“你今天怎么忽然推崇起我来了？”阮裕说：“我想谋个几千户的郡守都还得不到；你竟然想成佛，志向不是很大吗？”
注：何次道：何充，字次道，东晋宰相，笃信佛教。
注：瓦官寺：建康的佛寺。
注：阮思旷：阮裕。
注：迈：超过。
注：终古：自古以来。
注：推：推崇。
注：图：谋求。
注：数千户郡：一个几千户的郡，指郡守之职。

# 二十三｜庾征西大举征胡
原：庾征西大举征胡，既成行，止镇襄阳。殷豫章与书，送一折角如意以调之。庾答书曰：“得所致，虽是败物，犹欲理而用之。”|| 庾翼大举出兵讨伐胡人，出发以后，却只是驻守在襄阳。殷羡给他写信，送了一柄断了角的如意来取笑他。庾翼回信说：“收到你送的东西了，虽是件破损的东西，我还是想修好了用它。”
注：庾征西：庾翼，庾亮之弟，官征西将军。
注：征胡：庾翼曾大举北伐，结果止于襄阳，未能进击。
注：殷豫章：殷羡，曾任豫章太守。
注：折角如意：断了角的如意，暗讽庾翼的北伐有始无终。
注：败物：破损之物。
注：理：修理。庾翼意谓还要整顿再用，回应得体而不失风度。
