# 本门导读
题解：“品藻”就是品评人物、分别高下。本门不论一人的好坏，而是把两人或数人放在一起比较长短，看谁更胜一筹，是魏晋清谈中最常见也最见锋芒的话题。

# 一｜汝南陈仲举、颍川李元礼
原：汝南陈仲举、颍川李元礼二人，共论其功德，不能定先后。蔡伯喈评之曰：“陈仲举强于犯上，李元礼严于摄下，犯上难，摄下易。”仲举遂在“三君”之下，元礼居“八俊”之上。|| 汝南的陈仲举和颍川的李元礼，人们一起评论两人的功业德行，定不下谁先谁后。蔡伯喈评论说：“陈仲举敢于顶撞上司，李元礼善于严管下属；顶撞上司难，管束下属易。”于是陈仲举排在“三君”的末位，李元礼列在“八俊”的首位。
注：陈仲举：陈蕃，字仲举，东汉名臣，汝南平舆人，官至太傅。
注：李元礼：李膺，字元礼，颍川襄城人，东汉党人领袖。
注：蔡伯喈：蔡邕，字伯喈，东汉文学家、书法家。
注：三君、八俊：东汉末士人互相标榜的称号，“三君”指窦武、刘淑、陈蕃，“八俊”以李膺为首。

# 二｜庞士元至吴
原：庞士元至吴，吴人并友之，见陆绩、顾劭、全琮，而为之目曰：“陆子所谓驽马有逸足之用，顾子所谓驽牛可以负重致远。”或问：“如所目，陆为胜邪？”曰：“驽马虽精速，能致一人耳。驽牛一日行百里，所致岂一人哉？”吴人无以难。“全子好声名，似汝南樊子昭。”|| 庞士元到了吴地，吴地名士都来与他结交。他见了陆绩、顾劭、全琮，给他们下评语说：“陆先生好比一匹劣马却有快腿的用处，顾先生好比一头笨牛却能驮着重物走远路。”¦有人问：“照您这样评，是陆绩更强吗？”¦他说：“劣马即便跑得又快又好，也只能驮一个人罢了。¦笨牛一天走一百里，驮的哪里只一个人呢？”¦吴人没法反驳。¦他又说：“全先生爱好名声，像汝南的樊子昭。”
注：庞士元：庞统，字士元，襄阳人，号“凤雏”，后为刘备谋士。
注：陆绩：字公纪，吴郡人，精通天文历算；顾劭：字孝则，吴郡人；全琮：字子璜，吴郡钱唐人，官至大司马。
注：目：品评，给人下评语。驽：劣马，引申为才能平庸。
注：樊子昭：东汉末汝南人，出身寒微而得许劭赏识。

# 三｜顾劭尝与庞士元宿语
原：顾劭尝与庞士元宿语，问曰：“闻子名知人，吾与足下孰愈？”曰：“陶冶世俗，与时浮沉，吾不如子；论王霸之余策，览倚伏之要害，吾似有一日之长。”劭亦安其言。|| 顾劭曾和庞士元同宿夜谈，问道：“听说您以善于识人出名，我和您谁更强？”庞士元说：“教化风俗、随时势进退，我不如您；论说王道霸道的谋略，洞察祸福相倚的关键，我好像比您略胜一点。”顾劭也认为他说得恰当。
注：名知人：以善于鉴识人物出名。愈：胜过。
注：倚伏：《老子》“祸兮福之所倚，福兮祸之所伏”，指祸福相互转化。
注：一日之长：比别人稍强一点的谦辞。

# 四｜诸葛瑾、弟亮及从弟诞
原：诸葛瑾、弟亮及从弟诞，并有盛名，各在一国。于时以为蜀得其龙，吴得其虎，魏得其狗。诞在魏，与夏侯玄齐名；瑾在吴，吴朝服其弘量。|| 诸葛瑾、他弟弟诸葛亮和堂弟诸葛诞，都很有名望，各在一国任职。当时人认为蜀国得到了诸葛家的龙，吴国得到了虎，魏国得到了狗。诸葛诞在魏国，和夏侯玄齐名；诸葛瑾在吴国，吴国朝廷都佩服他的宽宏气度。
注：诸葛瑾：字子瑜，诸葛亮之兄，仕吴官至大将军。
注：诸葛诞：字公休，诸葛氏族弟，仕魏，后起兵反司马氏被杀。
注：狗：此处与龙、虎并举，意在分等次，未必纯为贬义，旧说不一，存疑。
注：夏侯玄：字太初，魏国名士。

# 五｜司马文王问武陔
原：司马文王问武陔：“陈玄伯何如其父司空？”陔曰：“通雅博畅，能以天下声教为己任者，不如也；明练简至，立功立事，过之。”|| 司马昭问武陔：“陈玄伯比他父亲陈司空怎么样？”武陔说：“通达雅正、渊博通畅，能把天下的教化当作自己的责任，这方面他不如父亲；精明干练、简要周到，建功立业，这方面超过了父亲。”
注：司马文王：司马昭，谥文王。武陔：字元夏，魏晋间人。
注：陈玄伯：陈泰，字玄伯；其父陈群，魏司空。
注：声教：声威与教化。明练：精明干练。简至：简要而周到。

# 六｜正始中，人士比论
原：正始中，人士比论，以五荀方五陈：荀淑方陈寔，荀靖方陈谌，荀爽方陈纪，荀彧方陈群，荀𫖮方陈泰。又以八裴方八王：裴徽方王祥，裴楷方王夷甫，裴康方王绥，裴绰方王澄，裴瓒方王敦，裴遐方王导，裴𬱟方王戎，裴邈方王玄。|| 正始年间，名士们比较评论人物，拿荀家五人来比陈家五人：荀淑比陈寔，荀靖比陈谌，荀爽比陈纪，荀彧比陈群，荀𫖮比陈泰。又拿裴家八人比王家八人：裴徽比王祥，裴楷比王夷甫，裴康比王绥，裴绰比王澄，裴瓒比王敦，裴遐比王导，裴𬱟比王戎，裴邈比王玄。
注：正始：魏齐王曹芳年号（240—249）。方：比拟。
注：五荀、五陈：颍川荀氏与陈氏两大名族各五代（或五人）人物。
注：王夷甫：王衍。八裴、八王：河东裴氏与琅邪王氏各八人。其中有些人物年代晚于正始，所谓“正始中”或系泛说，存疑。
注：𫖮（yǐ）、𬱟（wěi）：人名用字。

# 七｜冀州刺史杨淮二子乔与髦
原：冀州刺史杨淮二子乔与髦，俱总角为成器。淮与裴𬱟、乐广友善，遣见之。𬱟性弘方，爱乔之有高韵，谓淮曰：“乔当及卿，髦小减也。”广性清淳，爱髦之有神检，谓淮曰：“乔自及卿，然髦尤精出。”淮笑曰：“我二儿之优劣，乃裴、乐之优劣。”论者，以为乔虽高韵，而检不匝；乐言为得。然并为后出之俊。|| 冀州刺史杨淮的两个儿子杨乔和杨髦，都在童年时就成了材。杨淮和裴𬱟、乐广交好，就让两个儿子去拜见他们。裴𬱟性情旷达方正，喜欢杨乔有高雅的风韵，对杨淮说：“杨乔能赶上你，杨髦稍差一点。”乐广性情清明淳朴，喜欢杨髦有精神操守，对杨淮说：“杨乔固然赶得上你，但杨髦更加精粹出众。”杨淮笑道：“我两个儿子的高下，正是裴、乐二位的高下。”评论的人认为，杨乔虽然风韵高雅，但操守不够周全；乐广的话说得对。不过兄弟俩都是后起的俊才。
注：杨淮：一说当作杨准，存疑。总角：童年把头发扎成两个髻，代指幼年。
注：裴𬱟：字逸民，西晋名士；乐广：字彦辅，西晋清谈名士。
注：减：不如。神检：精神上的约束、操守。
注：匝（zā）：周全，完满。

# 八｜刘令言始入洛
原：刘令言始入洛，见诸名士而叹曰：“王夷甫太解明，乐彦辅我所敬，张茂先我所不解，周弘武巧于用短，杜方叔拙于用长。”|| 刘令言初到洛阳，见了各位名士后感叹说：“王夷甫太聪明透彻了，乐彦辅是我所敬重的，张茂先是我看不透的，周弘武善于运用自己的短处，杜方叔不善于发挥自己的长处。”
注：刘令言：刘讷，字令言，西晋彭城人。
注：王夷甫：王衍；乐彦辅：乐广；张茂先：张华，西晋博学之士，官至司空。
注：周弘武：周恢；杜方叔：杜育，有才藻，号“神童”。

# 九｜王夷甫云
原：王夷甫云：“闾丘冲优于满奋、郝隆。此三人并是高才，冲最先达。”|| 王夷甫说：“闾丘冲比满奋、郝隆强。这三个人都是高才，而闾丘冲最通达。”
注：闾丘冲：字宾卿，西晋人。满奋：字武秋，西晋人。郝隆：字弘始，西晋人（与东晋讥嘲晒书的郝隆非一人）。
注：先达：先通达事理，一说指最早显达，存疑。

# 十｜王夷甫以王东海比乐令
原：王夷甫以王东海比乐令，故王中郎作碑云：“当时标榜，为乐广之俪。”|| 王夷甫拿王东海来比乐令，所以王中郎给王东海作碑文时写道：“当时的人品评他，认为他与乐广并驾齐驱。”
注：王东海：王承，字安期，曾任东海内史（太守）。乐令：乐广，官至尚书令。
注：王中郎：王坦之，王承之孙。标榜：品评称扬。俪（lì）：配偶，引申为匹敌、并列。

# 十一｜庾中郎与王平子雁行
原：庾中郎与王平子雁行。|| 庾中郎和王平子并驾齐驱。
注：庾中郎：庾敳（ái），字子嵩，西晋名士。王平子：王澄，王衍之弟。
注：雁行（háng）：像雁群飞行那样并排，喻名望相当。

# 十二｜王大将军在西朝时
原：王大将军在西朝时，见周侯辄扇障面不得住。后度江左，不能复尔。王叹曰：“不知我进，伯仁退？”|| 王大将军在西晋朝时，见到周侯，总是不停地用扇子遮着脸。后来渡江到了江东，就不再这样了。王敦感叹说：“不知道是我长进了，还是伯仁退步了？”
注：王大将军：王敦。西朝：指西晋，都洛阳。
注：周侯：周𫖮（yǐ），字伯仁，袭爵武城侯。以扇障面：表示敬畏、自惭不敢正视。
注：江左：江东，指东晋。尔：这样。

# 十三｜会稽虞騑，元皇时与桓宣武同侠
原：会稽虞騑，元皇时与桓宣武同侠，其人有才理胜望。王丞相尝谓騑曰：“孔愉有公才而无公望，丁潭有公望而无公才。兼之者其在卿乎？”騑未达而丧。|| 会稽人虞騑，晋元帝时与桓宣武同僚，这个人才思与名望都很突出。王丞相曾对虞騑说：“孔愉有做三公的才干却没有三公的名望，丁潭有三公的名望却没有三公的才干。两样兼备的，大概就是您吧？”虞騑还没有显达就去世了。
注：虞騑（fēi）：字思行，会稽余姚人。书中印作“马”旁加“非”的类推简化字，因字库缺字，此处用繁体“騑”。元皇：晋元帝司马睿。
注：桓宣武同侠：书中原文如此；一般认为“宣武”当作“宣城”（桓温之父桓彝，曾任宣城内史），“侠”当作“僚”。此处仍按原文录入，译文从“同僚”之说。
注：公才、公望：担任三公所需的才干与声望。孔愉：字敬康；丁潭：字世康，二人都是会稽人。
注：达：显达。

# 十四｜明帝问周伯仁
原：明帝问周伯仁：“卿自谓何如郗鉴？”周曰：“鉴方臣，如有功夫。”复问郗，郗曰：“周𫖮比臣，有国士门风。”|| 晋明帝问周伯仁：“你自己觉得比郗鉴怎么样？”周伯仁说：“郗鉴和我比，似乎更有修养功夫。”明帝又问郗鉴，郗鉴说：“周𫖮和我比，有国士的家风。”
注：明帝：晋明帝司马绍。周伯仁：周𫖮。郗鉴：字道徽，东晋重臣，官至太尉。
注：功夫：修养上下的工夫。
注：国士：一国中才德出众的人。门风：家族的风范。

# 十五｜王大将军下，庾公问
原：王大将军下，庾公问：“闻卿有四友，何者是？”答曰：“君家中郎、我家太尉、阿平、胡毋彦国。阿平故当最劣。”庾曰：“似未肯劣。”庾又问：“何者居其右？”王曰：“自有人。”又问：“何者是？”王曰：“噫！其自有公论。”左右蹑公，公乃止。|| 王大将军东下京城，庾公问他：“听说您有四位朋友，都是谁？”王敦答道：“您家的中郎、我家的太尉、阿平、胡毋彦国。阿平自然是最差的。”庾公说：“他似乎不肯居末。”庾公又问：“哪一位居首？”王敦说：“自然有人。”又问：“是谁？”王敦说：“唉！这自有公论。”身边的人踩庾公的脚，庾公才不再问了。
注：王大将军：王敦。下：沿江东下到京城建康。庾公：庾亮。
注：君家中郎：庾敳，庾亮的叔父。我家太尉：王衍，王敦的族兄。阿平：王澄，字平子。胡毋彦国：胡毋辅之，字彦国。
注：右：古人以右为尊，居其右即居首位。
注：蹑（niè）：踩。左右踩脚示意，大概是暗示王敦自认居首，不宜追问。

# 十六｜人问丞相
原：人问丞相：“周侯何如和峤？”答曰：“长舆嵯峨。”|| 有人问王丞相：“周侯比和峤怎么样？”王导答道：“长舆高峻挺拔。”
注：丞相：王导。周侯：周𫖮。和峤：字长舆，西晋大臣，以家富而吝著称。
注：嵯峨（cuó é）：山势高峻，喻人物品格超群。

# 十七｜明帝问谢鲲
原：明帝问谢鲲：“君自谓何如庾亮？”答曰：“端委庙堂，使百僚准则，臣不如亮；一丘一壑，自谓过之。”|| 晋明帝问谢鲲：“你自己觉得比庾亮怎么样？”谢鲲答道：“穿戴整齐立于朝廷，让百官以为榜样，我不如庾亮；至于隐居山林、寄情丘壑，我自认为超过他。”
注：谢鲲：字幼舆，东晋名士，好老庄，任达不拘。
注：端委：古代礼服，代指身着朝服。庙堂：朝廷。准则：效法。
注：一丘一壑：指隐逸山水的生活。

# 十八｜王丞相二弟不过江
原：王丞相二弟不过江，曰颖，曰敞。时论以颖比邓伯道，敞比温忠武。议郎、祭酒者也。|| 王丞相有两个弟弟没有渡江南来，一个叫王颖，一个叫王敞。当时舆论拿王颖比邓伯道，拿王敞比温忠武。他们分别做过议郎和祭酒。
注：不过江：西晋末未随众渡江南迁，早卒于北方。
注：邓伯道：邓攸，字伯道，以德行著称。温忠武：温峤，谥忠武。
注：议郎、祭酒者也：说王颖曾任议郎，王敞曾被召为丞相祭酒。

# 十九｜明帝问周侯
原：明帝问周侯：“论者以卿比郗鉴，云何？”周曰：“陛下不须牵𫖮比。”|| 晋明帝问周侯：“议论的人拿你跟郗鉴相比，你怎么看？”周侯说：“陛下不必拉我去和他比。”
注：周侯：周𫖮。牵：拉扯。周𫖮意在不屑与郗鉴并列，一说是谦辞，存疑。

# 二十｜王丞相云
原：王丞相云：“顷下论以我比安期、千里，亦推此二人；唯共推太尉，此君特秀。”|| 王丞相说：“近来议论拿我比安期、千里，我也推重这两个人；只是大家都应共同推崇太尉，这位实在特别出众。”
注：王丞相：王导。顷下：近来。
注：安期：王承，字安期。千里：阮瞻，字千里。
注：太尉：王衍。秀：出众。

# 二十一｜宋祎曾为王大将军妾
原：宋祎曾为王大将军妾，后属谢镇西。镇西问祎：“我何如王？”答曰：“王比使君，田舍、贵人耳。”镇西妖冶故也。|| 宋祎曾经是王大将军的侍妾，后来归了谢镇西。谢镇西问宋祎：“我比王敦怎么样？”宋祎答道：“王敦和您相比，就是乡下佬和贵公子罢了。”这是因为谢镇西长得妖艳漂亮的缘故。
注：宋祎（yī）：东晋美人，善吹笛，相传为石崇宠姬绿珠的弟子。
注：谢镇西：谢尚，字仁祖，曾任镇西将军。使君：对州郡长官的尊称，此指谢尚。
注：田舍：乡下人。妖冶：艳丽动人。

# 二十二｜明帝问周伯仁
原：明帝问周伯仁：“卿自谓何如庾元规？”对曰：“萧条方外，亮不如臣；从容廊庙，臣不如亮。”|| 晋明帝问周伯仁：“你自己觉得比庾元规怎么样？”周伯仁答道：“超然于世俗之外，庾亮不如我；从容出入朝廷，我不如庾亮。”
注：庾元规：庾亮，字元规。
注：萧条：超脱闲远。方外：世俗之外。廊庙：朝廷。

# 二十三｜王丞相辟王蓝田为掾
原：王丞相辟王蓝田为掾，庾公问丞相：“蓝田何似？”王曰：“真独简贵，不减父祖，旷然澹处，故当不如尔。”|| 王丞相征召王蓝田做属官，庾公问丞相：“蓝田这人怎么样？”王导说：“率真、特立、简约、高贵，不比他父亲、祖父差；但说到胸怀旷达、恬淡自处，自然还是不如他们。”
注：辟（bì）：征召。掾（yuàn）：属官。王蓝田：王述，袭封蓝田侯。
注：父祖：王述之父王承、祖父王湛。
注：澹处：恬淡自处，不慕名利。故当：自然，应当。

# 二十四｜卞望之云
原：卞望之云：“郗公体中有三反：方于事上，好下佞己，一反；治身清贞，大修计校，二反；自好读书，憎人学问，三反。”|| 卞望之说：“郗公身上有三处自相矛盾：侍奉君上很正直，却喜欢下属奉承自己，这是一矛盾；自身清白守正，却很爱斤斤计较，这是二矛盾；自己爱读书，却讨厌别人做学问，这是三矛盾。”
注：卞望之：卞壶（kǔn），字望之，东晋大臣，苏峻之乱中战死。
注：郗公：郗鉴。反：自相矛盾之处。
注：方：方正。佞（nìng）：谄媚。计校：计较。

# 二十五｜世论温太真
原：世论温太真是过江第二流之高者。时名辈共说人物，第一将尽之间，温常失色。|| 世人评论温太真是渡江南来人物中第二流里的佼佼者。当时名流们一起品评人物，第一流快要数完的时候，温太真常常紧张得变了脸色。
注：温太真：温峤，字太真。过江：指西晋末随晋室南渡的士人。
注：名辈：名流。失色：因紧张而变了脸色——他盼着自己被列入第一流。

# 二十六｜王丞相云：“见谢仁祖
原：王丞相云：“见谢仁祖，恒令人得上。与何次道语，唯举手指地曰：‘正自尔馨。’”|| 王丞相说：“见到谢仁祖，总让人精神向上。跟何次道说话，他只是举手指着地说：‘正是这样。’”
注：谢仁祖：谢尚。得上：精神被提升，超凡向上。
注：何次道：何充，字次道，东晋宰相。
注：尔馨：如此，这样（晋人口语）。此则意在对比，何充言谈平实，不能令人振起，具体意味存疑。

# 二十七｜何次道为宰相
原：何次道为宰相，人有讥其信任不得其人。阮思旷慨然曰：“次道自不至此。但布衣超居宰相之位，可恨唯此一条而已。”|| 何次道做宰相，有人讥讽他所信用的人不得当。阮思旷感慨地说：“次道本来不至于这样。只是以平民之身越级坐到宰相的位置，可遗憾的也就这一条罢了。”
注：阮思旷：阮裕，字思旷，东晋名士。
注：自：本来。布衣：平民，此指何充出身不够显赫而骤登高位，一说指其未经历练，存疑。

# 二十八｜王右军少时
原：王右军少时，丞相云：“逸少何缘复减万安邪？”|| 王右军年少时，王丞相说：“逸少凭什么就比不上万安呢？”
注：王右军：王羲之，字逸少，官至右军将军。丞相：王导，王羲之的从伯父。
注：何缘：为什么。减：不如。万安：刘绥，字万安。

# 二十九｜郗司空家有伧奴
原：郗司空家有伧奴，知及文章，事事有意。王右军向刘尹称之，刘问：“何如方回？”王曰：“此正小人有意向耳，何得便比方回？”刘曰：“若不如方回，故是常奴耳。”|| 郗司空家有个北方来的奴仆，懂得文章，样样事都有点见识。王右军向刘尹称赞他，刘尹问：“比方回怎么样？”王右军说：“这只是个下人有些志趣罢了，怎么就能跟方回比？”刘尹说：“要是比不上方回，那就只是个平常的奴仆而已。”
注：郗司空：郗鉴。伧（cāng）：南方人对北方人的蔑称。
注：刘尹：刘惔，字真长，曾任丹阳尹。方回：郗愔，字方回，郗鉴长子，王羲之的妻弟。
注：意向：志趣。刘惔此语暗含讥讽郗愔，意思是这奴仆其实不比方回差。

# 三十｜时人道阮思旷
原：时人道阮思旷：骨气不及右军，简秀不如真长，韶润不如仲祖，思致不如渊源，而兼有诸人之美。|| 当时人评论阮思旷：骨相气概不及王右军，简约俊秀不如刘真长，温润美好不如王仲祖，才思情致不如殷渊源，却兼有这几个人的长处。
注：骨气：风骨气概。右军：王羲之。真长：刘惔。
注：韶润：美好温润。仲祖：王濛，字仲祖。
注：思致：才思情致。渊源：殷浩，字渊源。

# 三十一｜简文云：“何平叔巧累于理
原：简文云：“何平叔巧累于理，嵇叔夜俊伤其道。”|| 简文帝说：“何平叔的机巧拖累了他的义理，嵇叔夜的才气损伤了他所守的大道。”
注：简文：晋简文帝司马昱。何平叔：何晏，字平叔，魏玄学家。
注：嵇叔夜：嵇康，字叔夜，竹林七贤之一。俊：才智超群。

# 三十二｜时人共论晋武帝出齐王之与立惠帝
原：时人共论晋武帝出齐王之与立惠帝，其失孰多，多谓立惠帝为重。桓温曰：“不然。使子继父业，弟承家祀，有何不可？”|| 当时人一起议论晋武帝把齐王赶出朝廷与立惠帝为太子这两件事，哪个过失更大，多数人认为立惠帝的过失更重。桓温说：“不对。让儿子继承父亲的基业，让弟弟承接家族的祭祀，有什么不可以？”
注：晋武帝：司马炎。齐王：司马攸，武帝之弟，过继给司马师，素有贤名，被遣出朝回封国，忧愤而死。
注：惠帝：司马衷，武帝之子，愚钝不任事。
注：弟承家祀：司马攸过继承司马师一支的香火，桓温以此为两事都合乎宗法开脱，其言或别有寄托，存疑。

# 三十三｜人问殷渊源
原：人问殷渊源：“当世王公以卿比裴叔道，云何？”殷曰：“故当以识通暗处。”|| 有人问殷渊源：“当代的王公贵人拿您比裴叔道，您怎么看？”殷浩说：“想来是因为我们的见识都能通达幽深之处吧。”
注：殷渊源：殷浩。裴叔道：裴遐，字叔道，西晋善清谈者。
注：暗处：幽深隐微的义理。

# 三十四｜抚军问殷浩
原：抚军问殷浩：“卿定何如裴逸民？”良久答曰：“故当胜耳。”|| 抚军问殷浩：“你到底比裴逸民怎么样？”殷浩过了好一阵才答道：“自然是胜过他吧。”
注：抚军：司马昱，即位前曾任抚军将军。定：究竟。
注：裴逸民：裴𬱟。良久：殷浩迟疑良久，可见其自负而又不便直言。

# 三十五｜桓公少与殷侯齐名
原：桓公少与殷侯齐名，常有竞心。桓问殷：“卿何如我？”殷云：“我与我周旋久，宁作我。”|| 桓公年轻时与殷侯齐名，常有一争高下的心思。桓温问殷浩：“你比我怎么样？”殷浩说：“我跟我自己打交道很久了，宁可做我自己。”
注：桓公：桓温。殷侯：殷浩。
注：周旋：交往、相处。宁作我：宁愿做我，不羡慕你——答得不卑不亢，成为名言。

# 三十六｜抚军问孙兴公
原：抚军问孙兴公：“刘真长何如？”曰：“清蔚简令。”“王仲祖何如？”曰：“温润恬和。”“桓温何如？”曰：“高爽迈出。”“谢仁祖何如？”曰：“清易令达。”“阮思旷何如？”曰：“弘润通长。”“袁羊何如？”曰：“洮洮清便。”“殷洪远何如？”曰：“远有致思。”|| 抚军问孙兴公：“刘真长怎么样？”答：“清雅有文采，简约美好。”“王仲祖怎么样？”答：“温和润泽，恬淡平和。”“桓温怎么样？”答：“高迈爽朗，卓然出众。”“谢仁祖怎么样？”答：“清简平易，美好通达。”“阮思旷怎么样？”答：“宽宏温润，通达和善。”“袁羊怎么样？”答：“言谈滔滔，清爽便捷。”“殷洪远怎么样？”答：“志趣高远，富有情思。”
注：抚军：司马昱。孙兴公：孙绰，字兴公，东晋文学家。
注：清蔚：清高而有文采。简令：简约美好。
注：袁羊：袁乔，小字羊。洮洮（táo）：言谈流畅的样子，一说形容清高，存疑。
注：殷洪远：殷融，字洪远，殷浩的叔父。
原：“卿自谓何如？”曰：“下官才能所经，悉不如诸贤。至于斟酌时宜，笼罩当世，亦多所不及。然以不才，时复托怀玄胜，远咏《老》、《庄》，萧条高寄，不与时务经怀，自谓此心无所与让也。”|| “你自己觉得怎么样？”孙绰说：“下官的才能和经历，全都比不上各位贤士。至于审时度势、驾驭一世，也有很多赶不上的地方。不过我这个不成材的人，时常把情怀寄托在玄远美妙的境界里，悠然吟咏《老子》《庄子》，超脱闲逸、寄心高远，不把世务放在心上，自认为这份心境是不让给任何人的。”
注：斟酌时宜：权衡时势所需。笼罩：统摄，驾驭。
注：玄胜：玄理的佳妙境界。萧条高寄：超然闲远，寄情高处。
注：经怀：挂在心上。让：谦让，逊色。

# 三十七｜桓大司马下都
原：桓大司马下都，问真长曰：“闻会稽王语奇进，尔邪？”刘曰：“极进，然故是第二流中人耳。”桓曰：“第一流复是谁？”刘曰：“正是我辈耳。”|| 桓大司马来到京城，问刘真长说：“听说会稽王清谈大有长进，是这样吗？”刘惔说：“长进极大，不过仍然是第二流中的人罢了。”桓温说：“那第一流又是谁？”刘惔说：“正是我们这些人啊。”
注：桓大司马：桓温。下都：到京城建康。真长：刘惔。
注：会稽王：司马昱，即后来的简文帝。语：指清谈。奇：很，非常。尔：如此。

# 三十八｜殷侯既废
原：殷侯既废，桓公语诸人曰：“少时与渊源共骑竹马，我弃去，已辄取之，故当出我下。”|| 殷侯被废为平民以后，桓公对众人说：“小时候我和渊源一起骑竹马，我扔掉不要了，他总是捡去骑，所以他本该在我之下。”
注：殷侯既废：殷浩北伐失败，被桓温上奏废为庶人。
注：竹马：儿童当马骑的竹竿。已：随即，一说完毕，存疑。辄：总是。

# 三十九｜人问抚军
原：人问抚军：“殷浩谈竟何如？”答曰：“不能胜人，差可献酬群心。”|| 有人问抚军：“殷浩的清谈到底怎么样？”司马昱答道：“不能压倒别人，但还能让大家心里满意。”
注：抚军：司马昱。竟：究竟。
注：差：略，还算。献酬：主客互相敬酒，引申为应答周旋，使人满意。

# 四十｜简文云：“谢安南清令不如其弟
原：简文云：“谢安南清令不如其弟，学义不及孔岩，居然自胜。”|| 简文帝说：“谢安南清秀美好不如他弟弟，学问义理比不上孔岩，可他显然自有过人之处。”
注：谢安南：谢奉，官至安南将军。其弟：谢聘，字弘远。
注：孔岩：书中注引一说当作“孔严”，字彭祖，会稽山阴人，存疑。
注：居然：显然，分明。自胜：自有胜过人的地方。

# 四十一｜未废海西公时
原：未废海西公时，王元琳问桓元子：“箕子、比干迹异心同，不审明公孰是孰非？”曰：“仁称不异，宁为管仲。”|| 还没废黜海西公的时候，王元琳问桓元子：“箕子、比干事迹不同而用心相同，不知明公认为谁对谁错？”桓温说：“既然仁人的称号没有不同，我宁愿做管仲。”
注：海西公：晋废帝司马奕，被桓温废为海西公。王元琳：王珣，字元琳。桓元子：桓温，字元子。
注：箕子、比干：都是殷纣王的叔伯辈，箕子装疯为奴，比干强谏被剖心，孔子并称二人为仁。
注：审：知道。管仲：先事公子纠，纠死后转事齐桓公成就霸业。桓温以管仲自比，暗示不必为旧主殉死，流露其废立之心。

# 四十二｜刘丹阳、王长史在瓦官寺集
原：刘丹阳、王长史在瓦官寺集，桓护军亦在坐，共商略西朝及江左人物。或问：“杜弘治何如卫虎？”桓答曰：“弘治肤清，卫虎奕奕神令。”王、刘善其言。|| 刘丹阳、王长史在瓦官寺聚会，桓护军也在座，一起品评西晋和东晋的人物。有人问：“杜弘治比卫虎怎么样？”桓伊答道：“弘治肌肤清秀，卫虎神采焕发、精神美好。”王濛、刘惔都称赞他说得好。
注：刘丹阳：刘惔。王长史：王濛。瓦官寺：东晋建康名寺。
注：桓护军：桓伊，曾任护军将军。商略：品评。西朝：西晋。江左：东晋。
注：杜弘治：杜乂（yì），以美貌著称。卫虎：卫玠，小字虎，以容貌清秀闻名。
注：肤清：外表清秀。奕奕：神采焕发。

# 四十三｜刘尹抚王长史背曰
原：刘尹抚王长史背曰：“阿奴比丞相，但有都长。”|| 刘尹拍着王长史的背说：“阿奴你比起丞相来，只是多了一份俊美雅致罢了。”
注：刘尹：刘惔。王长史：王濛。阿奴：对晚辈或亲近者的昵称。丞相：王导。
注：都长：仪容闲雅美好。“但有”一句语带调侃，意谓除此之外都不如王导。
