# 四十四｜刘尹、王长史同坐
原：刘尹、王长史同坐，长史酒酣起舞。刘尹曰：“阿奴今日不复减向子期。”|| 刘惔和王濛坐在一起，王濛喝到酒酣耳热，起身跳起舞来。刘惔说：“阿奴今天这一舞，可不比向子期差了。”
注：刘尹：刘惔，字真长，曾任丹阳尹，清谈名士。
注：王长史：王濛，字仲祖，曾任司徒左长史；
注：“阿奴”是刘惔对他的昵称。
注：减：逊于，比不上。
注：向子期：向秀，字子期，竹林七贤之一，以放达著称。

# 四十五｜桓公问孔西阳
原：桓公问孔西阳：“安石何如仲文？”孔思未对，反问公曰：“何如？”答曰：“安石居然不可陵践，其处故乃胜也。”|| 桓温问孔严：“谢安石和殷仲文相比怎么样？”孔严想了想没回答，反过来问桓温：“您看呢？”桓温答道：“安石自有一种叫人不敢欺侮的气度，他立身处世的分寸，确实更胜一筹。”
注：桓公：桓温，东晋权臣。
注：孔西阳：孔严，封西阳侯。
注：安石：谢安的字。
注：仲文：殷仲文，桓温的女婿。殷仲文年辈远晚于谢安，此处人名或有误，存疑。
注：陵践：欺凌，践踏。
注：处：处世，立身。

# 四十六｜谢公与时贤共赏说
原：谢公与时贤共赏说，遏、胡儿并在坐。公问李弘度曰：“卿家平阳，何如乐令？”于是李潸然流涕曰：“赵王篡逆，乐令亲授玺绶。亡伯雅正，耻处乱朝，遂至仰药，恐难以相比。此自显于事实，非私亲之言。”谢公语胡儿曰：“有识者果不异人意。”|| 谢安和当时的名流一起品评人物，谢玄、谢朗都在座。¦谢安问李充：“你家的平阳太守，比起乐令来怎么样？”¦李充听了，泪水簌簌而下，说：“赵王篡位叛逆的时候，乐令亲手把玉玺印绶交了出去。¦我那过世的伯父为人正直，耻于在乱朝做官，最后服毒自尽。两人恐怕难以相提并论。¦这是事实摆在那里，并不是我偏袒自家亲人的话。”¦谢安对谢朗说：“有见识的人，看法果然和众人没什么两样。”
注：赏说：品评人物，谈论赏鉴。
注：遏：谢玄小字。
注：胡儿：谢朗小字，谢安之侄。
注：李弘度：李充，字弘度，东晋文士。
注：平阳：李重，曾任平阳太守，是李充的伯父。
注：乐令：乐广，曾任尚书令。赵王司马伦篡位时，乐广作为大臣奉上玺绶。
注：仰药：服毒自杀。

# 四十七｜王修龄问王长史
原：王修龄问王长史：“我家临川，何如卿家宛陵？”长史未答，修龄曰：“临川誉贵。”长史曰：“宛陵未为不贵。”|| 王胡之问王濛：“我家的临川，比你家的宛陵怎么样？”王濛还没回答，王胡之就说：“临川名声显贵。”王濛说：“宛陵的名声也未必不贵重。”
注：王修龄：王胡之，字修龄。
注：临川：王羲之，曾任临川太守，与王胡之同族。
注：宛陵：王述，曾任宛陵令，与王濛同属太原王氏。
注：誉贵：声誉高贵。

# 四十八｜刘尹至王长史许清言
原：刘尹至王长史许清言，时苟子年十三，倚床边听。既去，问父曰：“刘尹语何如尊？”长史曰：“韶音令辞不如我，往辄破的胜我。”|| 刘惔到王濛家里清谈，当时王修十三岁，靠在坐榻边旁听。刘惔走后，王修问父亲：“刘尹的谈论比起父亲来怎么样？”王濛说：“论音调好听、辞藻优美，他不如我；论一开口就切中要害，他胜过我。”
注：许：处所。
注：清言：清谈。
注：苟子：王修，字敬仁，小字苟子，王濛之子，早慧善言理。
注：尊：对父亲的敬称。
注：韶音令辞：悦耳的声调、美好的言辞。
注：往辄破的：每次交锋都射中靶心，比喻一语中的。

# 四十九｜谢万寿春败后
原：谢万寿春败后，简文问郗超：“万自可败，那得乃尔失士卒情？”超曰：“伊以率任之性，欲区别智勇。”|| 谢万在寿春兵败以后，简文帝问郗超：“谢万打败仗倒也罢了，怎么会失掉士卒的人心到这种地步？”郗超说：“他凭着自己那种率性放任的脾气，偏要把将士分成有智的、有勇的来区别对待。”
注：谢万：字万石，谢安之弟。北伐时在寿春一带溃败，事后被废为庶人。
注：简文：东晋简文帝司马昱。
注：郗超：字景兴，一字嘉宾，桓温的谋士。
注：那得乃尔：怎么会这样。
注：率任：率性任意。
注：区别智勇：谢万曾对诸将以“劲卒”相称，大失人心；此句具体所指，存疑。

# 五十｜刘尹谓谢仁祖曰
原：刘尹谓谢仁祖曰：“自吾有四友，门人加亲。”谓许玄度曰：“自吾有由，恶言不及于耳。”二人皆受而不恨。|| 刘惔对谢尚说：“自从我有了你这样的朋友，门下弟子就更加亲近我了。”又对许询说：“自从我有了你这个子路，难听的话就再也传不到我耳朵里了。”两人都欣然接受，毫无不快。
注：谢仁祖：谢尚，字仁祖，谢安的堂兄。
注：许玄度：许询，字玄度，清谈名士。
注：四友：一说当作“回也”，即以颜回比谢尚；孔子曾说有颜回之后门人更加亲近。存疑。
注：由：仲由，即子路。孔子说自从有了子路，恶言就听不到了，因子路刚勇护师。

# 五十一｜世目殷中军
原：世目殷中军：“思纬淹通，比羊叔子。”|| 世人品评殷浩：“思路渊博通达，可以和羊叔子相比。”
注：目：品评。
注：殷中军：殷浩，曾任中军将军。
注：思纬：思路，思理。
注：淹通：渊博通达。
注：羊叔子：羊祜，字叔子，西晋名将，镇守襄阳，德望很高。

# 五十二｜有人问谢安石、王坦之
原：有人问谢安石、王坦之优劣于桓公。桓公停欲言，中悔，曰：“卿喜传人语，不能复语卿。”|| 有人向桓温打听谢安和王坦之谁高谁低。桓温正要开口，半路又后悔了，说：“你喜欢把别人的话传来传去，我不能再告诉你了。”
注：王坦之：字文度，与谢安齐名。
注：停：正当，正要。

# 五十三｜王中郎尝问刘长沙曰
原：王中郎尝问刘长沙曰：“我何如苟子？”刘答曰：“卿才乃当不胜苟子，然会名处多。”王笑曰：“痴。”|| 王坦之曾问刘奭：“我比王修怎么样？”刘奭答道：“论才学，你大概胜不过王修；不过你领会名理的地方要多些。”王坦之笑道：“傻话。”
注：王中郎：王坦之，曾任北中郎将。
注：刘长沙：刘奭（shì），曾任长沙相。
注：苟子：王修的小字。
注：会名：领悟名理。
注：痴：傻，说人呆。王坦之似嫌对方说法前后不通，语带戏谑。

# 五十四｜支道林问孙兴公
原：支道林问孙兴公：“君何如许掾？”孙曰：“高情远致，弟子早已服膺；一吟一咏，许将北面。”|| 支道林问孙绰：“你比许询怎么样？”孙绰说：“论高尚的情怀、深远的意趣，弟子我早就心悦诚服；至于吟诗作赋，许询可得向我称臣了。”
注：支道林：支遁，字道林，东晋高僧，善清谈。
注：孙兴公：孙绰，字兴公，东晋文学家。
注：许掾：许询，曾被征为司徒掾，未就。
注：服膺：衷心佩服，铭记于心。
注：北面：古代臣子、学生面向北行礼，引申为甘拜下风。

# 五十五｜王右军问许玄度
原：王右军问许玄度：“卿自言何如安石？”许未答，王因曰：“安石故相与雄，阿万当裂眼争邪？”|| 王羲之问许询：“你自己说说，比谢安怎么样？”许询还没回答，王羲之便接着说：“安石本来就可以和你一较雄长，难道阿万也要瞪大眼睛来争吗？”
注：王右军：王羲之，曾任右军将军。
注：安石：书中原文作“安石”，一说当作“安、万”，即谢安、谢万。存疑。
注：相与雄：彼此争雄，难分高下。
注：阿万：谢万。
注：裂眼：睁大眼睛，怒目相争。

# 五十六｜刘尹云
原：刘尹云：“人言江虨田舍，江乃自田宅屯。”|| 刘惔说：“人家说江虨像个乡巴佬，江虨本来就是有田有宅有庄子的人。”
注：江虨（bīn）：字思玄，东晋官员，曾任护军将军。
注：田舍：乡下人，带有讥讽之意。
注：田宅屯：田地、住宅、村庄；刘惔借“田舍”一词顺势打趣，语意双关，存疑。

# 五十七｜谢公云
原：谢公云：“金谷中苏绍最胜。”绍是石崇姊夫，苏则孙，愉子也。|| 谢安说：“金谷园那次诗会上，苏绍的诗最好。”苏绍是石崇的姐夫，苏则的孙子，苏愉的儿子。
注：金谷：石崇在洛阳城外修建的金谷园，他曾在此大宴宾客、赋诗。
注：石崇：西晋富豪，以奢侈著称，后被赵王司马伦所杀。
注：苏则：三国魏官员。
注：愉：苏愉，苏则之子。

# 五十八｜刘尹目庾中郎
原：刘尹目庾中郎：“虽言不愔愔似道，突兀差可以拟道。”|| 刘惔品评庾敳：“他的言谈虽然不像得道者那样和顺安详，但那股峭拔不群的劲头，倒也大致可以和道相比了。”
注：庾中郎：庾敳（ái），字子嵩，西晋名士，曾任吏部郎、从事中郎。
注：愔愔（yīn）：和悦安详的样子。
注：道：指玄远的老庄之道。
注：突兀：高耸特出。
注：差：大致，略微。
注：拟：比拟。

# 五十九｜孙承公云
原：孙承公云：“谢公清于无奕，润于林道。”|| 孙统说：“谢安比谢奕清高，比陈逵温润。”
注：孙承公：孙统，字承公，孙绰之兄。
注：无奕：谢奕，字无奕，谢安之兄，谢玄之父。
注：林道：陈逵，字林道，东晋官员。

# 六十｜或问林公
原：或问林公：“司州何如二谢？”林公曰：“故当攀安提万。”|| 有人问支道林：“王司州比谢家兄弟怎么样？”支道林说：“自然是往上攀着谢安，往下提携着谢万。”
注：林公：支道林。
注：司州：王胡之，曾被任命为司州刺史。
注：二谢：谢安、谢万兄弟。
注：攀、提：一攀一提，意谓在两人之间，不及谢安而胜过谢万。

# 六十一｜孙兴公、许玄度皆一时名流
原：孙兴公、许玄度皆一时名流。或重许高情，则鄙孙秽行；或爱孙才藻，而无取于许。|| 孙绰和许询都是当时的名流。有人看重许询的高雅情操，就鄙薄孙绰品行不端；有人欣赏孙绰的文采，就觉得许询一无可取。
注：孙兴公：孙绰，字兴公；书中印作“孙公兴”，当系误倒，已改正。
注：秽行：品行污浊。孙绰为人颇受时人非议。
注：才藻：才思文采。

# 六十二｜郗嘉宾道谢公
原：郗嘉宾道谢公：“造膝虽不深彻，而缠绵纶至。”又曰：“右军诣嘉宾。”嘉宾闻之云：“不得称诣，政得谓之朋耳。”谢公以嘉宾言为得。|| 郗超评论谢安：“促膝交谈时虽然说不上深刻透彻，却情意绵密、条理周到。”又有人说：“王右军的造诣在郗嘉宾之上。”郗超听了说：“不能说造诣更高，只能说彼此相当罢了。”谢安认为郗超的话说得对。
注：郗嘉宾：郗超，小字嘉宾。
注：造膝：促膝，引申为当面交谈。
注：缠绵纶至：情意深厚、条理周密。纶，丝线，引申为条理。
注：诣：造诣，谓所到达的境界更高。
注：政：同“正”，只。
注：朋：同等，相当。

# 六十三｜庾道季云
原：庾道季云：“思理伦和，吾愧康伯；志力强正，吾愧文度。自此以还，吾皆百之。”|| 庾龢说：“思路条理清晰和顺，我比不上韩康伯；意志坚强正直，我比不上王文度。除此以外，我都胜过别人百倍。”
注：庾道季：庾龢，字道季，庾亮之子。
注：伦和：有条理而和谐。
注：康伯：韩伯，字康伯，东晋玄学家。
注：文度：王坦之的字。
注：以还：以外，以下。
注：百之：超过百倍。

# 六十四｜王僧恩轻林公
原：王僧恩轻林公，蓝田曰：“勿学汝兄，汝兄自不如伊。”|| 王祎之瞧不起支道林，他父亲王述说：“别学你哥哥，你哥哥本来就比不上他。”
注：王僧恩：王祎（yī）之，小字僧恩，王述之子。
注：蓝田：王述，袭封蓝田侯。
注：汝兄：指王坦之。王坦之曾作文非难支道林。

# 六十五｜简文问孙兴公
原：简文问孙兴公：“袁羊何似？”答曰：“不知者不负其才，知之者无取其体。”|| 简文帝问孙绰：“袁羊这个人怎么样？”孙绰答道：“不了解他的人，不会小看他的才能；了解他的人，对他的为人却无可称道。”
注：袁羊：袁乔，小字羊，东晋官员，有文才。
注：负：辜负，轻视。
注：体：为人、品格。

# 六十六｜蔡叔子云
原：蔡叔子云：“韩康伯虽无骨干，然亦肤立。”|| 蔡系说：“韩康伯虽然没有骨架子，可外表也还立得起来。”
注：蔡叔子：蔡系，蔡谟之子。
注：骨干：骨架；韩康伯身体肥胖，这里兼指风骨。
注：肤立：皮肉撑得住，即外表尚能立得住，语带调侃。

# 六十七｜郗嘉宾问谢太傅曰
原：郗嘉宾问谢太傅曰：“林公谈何如嵇公？”谢云：“嵇公勤著脚，裁可得去耳。”又问：“殷何如支？”谢曰：“正尔有超拔，支乃过殷。然亹亹论辩，恐殷欲制支。”|| 郗超问谢安：“支道林的清谈比嵇康怎么样？”¦谢安说：“嵇康得拼命迈开脚，才勉强跟得上。”¦郗超又问：“殷浩比支道林怎么样？”¦谢安说：“单论超逸拔俗，支道林胜过殷浩；¦可要说滔滔不绝地论辩，恐怕殷浩能压倒支道林。”
注：嵇公：嵇康，竹林七贤之一。
注：勤著脚：使劲迈步，比喻努力追赶。
注：裁：通“才”，仅仅。
注：正尔：只就此而言。
注：超拔：超凡脱俗。
注：亹亹（wěi）：连绵不绝的样子。
注：制：胜过，压倒。

# 六十八｜庾道季云
原：庾道季云：“廉颇、蔺相如虽千载上死人，懔懔恒如有生气；曹蜍、李志虽见在，厌厌如九泉下人。人皆如此，便可结绳而治，但恐狐狸猯狢啖尽。”|| 庾龢说：“廉颇、蔺相如虽是千年前的死人，却凛凛然始终像活着一样有生气；曹蜍、李志虽然眼下还活着，却恹恹无神，像九泉之下的人。要是人人都像他们这样，就可以回到结绳记事的太古之世去了，只怕人都要被狐狸貉獾吃光了。”
注：廉颇、蔺相如：战国时赵国的名将与名相。
注：懔懔（lǐn）：严正可畏的样子。
注：曹蜍：曹茂之，小字蜍（chú）。
注：李志：东晋官员。
注：见：同“现”。
注：厌厌：精神萎靡。
注：结绳而治：上古无文字时结绳记事，指民风淳朴、无为而治的远古时代。
注：猯（tuān）：猪獾。
注：狢（hé）：同“貉”。
注：啖：吃。

# 六十九｜卫君长是萧祖周妇兄
原：卫君长是萧祖周妇兄，谢公问孙僧奴：“君家道卫君长云何？”孙曰：“云是世业人。”谢曰：“殊不尔，卫自是理义人。”于时以比殷洪远。|| 卫永是萧轮的妻兄。谢安问孙腾：“你家里人怎么评价卫君长？”¦孙腾说：“说他是个建功立业的人。”¦谢安说：“根本不是这样，卫君长自是个讲究名理的人。”¦当时人们拿他和殷融相比。
注：卫君长：卫永，字君长。
注：萧祖周：萧轮，字祖周。
注：妇兄：妻子的哥哥。
注：孙僧奴：孙腾，小字僧奴。
注：君家：你家，敬称。
注：世业人：一说指以功业为务的人，存疑。
注：理义人：长于名理玄谈的人。
注：殷洪远：殷融，字洪远，善谈玄理。

# 七十｜王子敬问谢公
原：王子敬问谢公：“林公何如庾公？”谢殊不受，答曰：“先辈初无论，庾公自足没林公。”|| 王献之问谢安：“支道林比庾亮怎么样？”谢安很不认可这样相比，答道：“前辈们从来没拿他们相提并论过，庾公本来就足以盖过支道林。”
注：王子敬：王献之，字子敬，王羲之之子，书法家。
注：庾公：庾亮，东晋重臣。
注：不受：不接受，不认可。
注：初无论：从来没有这样议论。
注：没：盖过，超越。

# 七十一｜谢遏诸人共道竹林优劣
原：谢遏诸人共道竹林优劣，谢公云：“先辈初不臧贬七贤。”|| 谢玄等人一起议论竹林七贤的高下，谢安说：“前辈们从来不褒贬七贤。”
注：竹林：竹林七贤，即嵇康、阮籍、山涛、向秀、刘伶、阮咸、王戎。
注：臧贬：褒贬。臧，善，称许。

# 七十二｜有人以王中郎比车骑
原：有人以王中郎比车骑。车骑闻之曰：“伊窟窟成就。”|| 有人拿王坦之和谢玄相比。谢玄听了说：“他是靠勤勤恳恳才有今天的成就。”
注：王中郎：王坦之。
注：车骑：谢玄，死后追赠车骑将军。
注：窟窟：一说当作“掘掘”（kū），勤勉用力的样子；言外之意是王坦之靠苦功而非天分。存疑。

# 七十三｜谢太傅谓王孝伯
原：谢太傅谓王孝伯：“刘尹亦奇自知，然不言胜长史。”|| 谢安对王恭说：“刘尹也是极有自知之明的人，可他从不说自己胜过王长史。”
注：王孝伯：王恭，字孝伯，王濛之孙。书中引号误作反引号，已改正。
注：奇：非常，极。
注：长史：王濛，即王恭的祖父。

# 七十四｜王黄门兄弟三人俱诣谢公
原：王黄门兄弟三人俱诣谢公，子猷、子重多说俗事，子敬寒温而已。既出，坐客问谢公：“向三贤孰愈？”谢公曰：“小者最胜。”客曰：“何以知之？”谢公曰：“吉人之辞寡，躁人之辞多。推此知之。”|| 王徽之兄弟三人一起去拜访谢安，徽之、操之大谈世俗琐事，献之只是寒暄几句而已。他们走后，在座的客人问谢安：“刚才那三位贤才，谁更好？”谢安说：“最小的那个最好。”客人问：“凭什么知道？”谢安说：“‘贤善的人话少，浮躁的人话多。’由此推断出来的。”
注：王黄门：王徽之，字子猷，曾任黄门侍郎。
注：兄弟三人：王徽之、王操之、王献之。
注：子重：王操之的字。
注：寒温：寒暄问候。
注：向：刚才。
注：愈：胜，更好。
注：“吉人之辞寡”二句：出自《周易·系辞下》。吉人，善人；躁人，浮躁的人。

# 七十五｜谢公问王子敬
原：谢公问王子敬：“君书何如君家尊？”答曰：“固当不同。”公曰：“外人论殊不尔。”王曰：“外人那得知？”|| 谢安问王献之：“你的字比你父亲怎么样？”王献之答道：“自然各有不同。”谢安说：“外面的人可完全不是这么说的。”王献之说：“外人哪里懂得？”
注：君家尊：您的父亲，指王羲之。
注：固当：本来，自然。
注：殊不尔：完全不是这样。

# 七十六｜王孝伯问谢太傅
原：王孝伯问谢太傅：“林公何如长史？”太傅曰：“长史韶兴。”问：“何如刘尹？”谢曰：“噫！刘尹秀。”王曰：“若如公言，并不如此二人邪？”谢云：“身意正尔也。”|| 王恭问谢安：“支道林比王长史怎么样？”谢安说：“长史有美好的兴致。”又问：“比刘尹怎么样？”谢安说：“唉！刘尹俊秀。”王恭说：“照您这么说，支道林是两人都比不上了？”谢安说：“我的意思正是这样。”
注：韶兴：美好的情致、兴会。
注：秀：出众，俊秀。
注：身：我，第一人称。
注：正尔：正是如此。

# 七十七｜人有问太傅
原：人有问太傅：“子敬可是先辈谁比？”谢曰：“阿敬近撮王、刘之标。”|| 有人问谢安：“子敬可以和前辈中的哪一位相比？”谢安说：“阿敬大概是集中了王濛、刘惔两人的风度。”
注：子敬：王献之。
注：近：接近，大体上。
注：撮：聚合，汇集。
注：王、刘：王濛、刘惔。
注：标：风度，标格。

# 七十八｜谢公语孝伯
原：谢公语孝伯：“君祖比刘尹，故为得逮。”孝伯云：“刘尹非不能逮，直不逮。”|| 谢安对王恭说：“你祖父比起刘尹来，还是赶得上的。”王恭说：“刘尹倒不是赶不上，只是不去赶罢了。”
注：君祖：王恭的祖父王濛。
注：逮：及，赶得上。
注：直：只是。
注：孝伯答语之意，历来理解不一，一说意谓刘惔并非不及，只是不屑于比；存疑。

# 七十九｜袁彦伯为吏部郎
原：袁彦伯为吏部郎，子敬与郗嘉宾书曰：“彦伯已入，殊足顿兴往之气。故知捶挞自难为人，冀小却，当复差耳。”|| 袁宏当了吏部郎，王献之写信给郗超说：“彦伯已经进了吏部，这很足以挫伤他那股意气风发的劲头。可见受人鞭打的日子本来就难熬，希望过些时候，他的情况会好转吧。”
注：袁彦伯：袁宏，字彦伯，东晋文学家，性情豪放。
注：顿：挫折，挫伤。
注：兴往之气：意兴勃发、一往无前的气概。
注：捶挞：鞭打，指当时郎官犯错要受杖责。
注：小却：稍后。
注：差（chài）：同“瘥”，病愈，引申为好转。

# 八十｜王子猷、子敬兄弟共赏《高士传》
原：王子猷、子敬兄弟共赏《高士传》人及赞，子敬赏“井丹高洁”，子猷云：“未若‘长卿慢世’。”|| 王徽之、王献之兄弟一起欣赏《高士传》里的人物和赞语。献之欣赏“井丹高洁”这一篇，徽之说：“不如‘长卿慢世’好。”
注：《高士传》：记隐逸高士的书，嵇康、皇甫谧都作过。
注：赞：附在传后的韵语评赞。
注：井丹：东汉高士，博学，不肯奔走权门。
注：长卿：司马相如，字长卿，西汉辞赋家，放诞不拘礼法。
注：慢世：轻慢世俗。

# 八十一｜有人问袁侍中曰
原：有人问袁侍中曰：“殷仲堪何如韩康伯？”答曰：“理义所得，优劣乃复未辨。然门庭萧寂，居然有名士风流，殷不及韩。”故殷作诔云：“荆门昼掩，闲庭晏然。”|| 有人问袁恪之：“殷仲堪比韩康伯怎么样？”他答道：“在义理上的心得，两人的高下竟然还分辨不出。但要说门庭冷清寂寞，自然而然有名士风度，殷仲堪就比不上韩康伯了。”所以殷仲堪给韩康伯写诔文时说：“荆条编的柴门白天也关着，空寂的庭院一派安宁。”
注：袁侍中：袁恪之，官至侍中。
注：殷仲堪：东晋名士，后任荆州刺史。
注：乃复：竟然还。
注：萧寂：冷清寂静。
注：居然：显然，自然而然。
注：诔：哀悼死者、叙其生平的文辞。
注：荆门：用荆条编的门，形容简朴。
注：晏然：安宁平静。

# 八十二｜王子敬问谢公
原：王子敬问谢公：“嘉宾何如道季？”答曰：“道季诚复钞撮清悟，嘉宾故自上。”|| 王献之问谢安：“郗嘉宾比庾道季怎么样？”谢安答道：“道季确实能博采众说、悟性清明，但嘉宾本来就更高一筹。”
注：嘉宾：郗超。
注：道季：庾龢。
注：诚复：确实。
注：钞撮：摘取汇集。钞，同“抄”。
注：清悟：领悟清明。
注：故自：本来就。
注：上：在上，胜过。

# 八十三｜王珣疾，临困
原：王珣疾，临困，问王武冈曰：“世论以我家领军比谁？”武冈曰：“世以比王北中郎。”东亭转卧向壁，叹曰：“人固不可以无年！”|| 王珣病重，临终前问王谧：“世人拿我父亲领军比作谁？”王谧说：“世人把他比作王北中郎。”王珣转过身面朝墙壁躺着，叹息道：“人果然不能不长寿啊！”
注：王珣：字元琳，王导之孙，封东亭侯。
注：困：病危。
注：王武冈：王谧（mì），王导之孙，袭封武冈侯。
注：领军：王洽，王珣之父，曾任中领军，早逝。
注：王北中郎：王坦之。
注：无年：没有寿数。王珣感慨父亲早死，未能充分显名，以致只被比作王坦之。

# 八十四｜王孝伯道谢公
原：王孝伯道谢公：“浓至。”又曰：“长史虚，刘尹秀，谢公融。”|| 王恭称赞谢安：“浓厚深沉。”又说：“王长史谦虚，刘尹俊秀，谢公圆融。”
注：浓至：情致浓厚而深至。
注：虚：虚怀，谦冲。
注：秀：秀拔出众。
注：融：融通和畅，处处调和。

# 八十五｜王孝伯问谢公
原：王孝伯问谢公：“林公何如右军？”谢曰：“右军胜林公。林公在司州前，亦贵彻。”|| 王恭问谢安：“支道林比王右军怎么样？”谢安说：“右军胜过支道林。不过支道林在王司州之上，也算得上尊贵通达了。”
注：右军：王羲之。
注：司州：王胡之。
注：贵彻：尊贵通达。

# 八十六｜桓玄为太傅
原：桓玄为太傅，大会，朝臣毕集。坐裁竟，问王桢之曰：“我何如卿第七叔？”于时宾客为之咽气。王徐徐答曰：“亡叔是一时之标，公是千载之英。”一坐欢然。|| 桓玄当太尉时，大宴宾客，朝中大臣全都到了。刚刚坐定，桓玄就问王桢之：“我比你七叔怎么样？”当时满座宾客都为王桢之屏住了呼吸。王桢之不慌不忙地回答：“先叔是一个时代的楷模，您是千年难遇的英杰。”满座的人都高兴起来。
注：桓玄：桓温之子，后篡晋称帝。
注：太傅：桓玄所任实为太尉，此处“太傅”当作“太尉”。
注：裁竟：刚刚完毕。裁，通“才”。
注：王桢之：王徽之之子。
注：第七叔：王献之，排行第七。
注：咽气：屏住呼吸，形容紧张。
注：标：楷模。
注：英：英杰。王桢之答语两边都抬，巧妙避开了比较。

# 八十七｜桓玄问刘太常曰
原：桓玄问刘太常曰：“我何如谢太傅？”刘答曰：“公高，太傅深。”又曰：“何如贤舅子敬？”答曰：“楂梨橘柚，各有其美。”|| 桓玄问刘瑾：“我比谢太傅怎么样？”刘瑾答道：“您高远，太傅深沉。”桓玄又问：“比你的好舅舅子敬怎么样？”刘瑾答道：“山楂、梨子、橘子、柚子，各有各的美味。”
注：刘太常：刘瑾，曾任太常卿，王羲之的外孙，所以称王献之为舅。
注：谢太傅：谢安。
注：楂梨橘柚：四种水果，味道各异，比喻各有所长，难分高下。

# 八十八｜旧以桓谦比殷仲文
原：旧以桓谦比殷仲文。桓玄时，仲文入，桓于庭中望见之，谓同坐曰：“我家中军，那得及此也！”|| 从前人们拿桓谦和殷仲文相比。桓玄当政时，有一回殷仲文进来，桓玄在庭院里远远望见他，对同座的人说：“我家的中军，哪里比得上这个人！”
注：桓谦：桓冲之子，桓玄的堂兄弟，曾任中军将军。
注：殷仲文：东晋文士，桓玄的姐夫，以风姿才藻闻名。
