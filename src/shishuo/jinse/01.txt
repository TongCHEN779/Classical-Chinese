# 本门导读
题解：“俭啬”说的是节省过了头，成了小气抠门。本门九则，王戎一人就占了四则，钻李核、讨单衣、夜夜算账，名士的另一面被写得入木三分；也有庾亮“留薤白”这样以俭见才干的佳话。

# 一｜和峤性至俭
原：和峤性至俭，家有好李，王武子求之，与不过数十。王武子因其上直，率将少年能食之者，持斧诣园，饱共啖毕，伐之，送一车枝与和公，问曰：“何如君李？”和既得，唯笑而已。|| 和峤生性极其吝啬，家里有好品种的李树，王济向他讨李子，他给的不过几十个。王济趁他进宫值班，领着一帮能吃的年轻人，拿着斧头闯进园子，大伙一起吃个饱，然后把树砍了，送了一车树枝给和峤，问他：“比起您家的李子怎么样？”和峤收到后，只是笑笑罢了。
注：和峤：字长舆，西晋大臣，家资豪富而性极吝啬，时人讥其有“钱癖”。
注：王武子：王济，字武子，晋武帝的女婿，豪奢任性；他是和峤的妻弟。
注：上直：入宫当值。直，同“值”。
注：诣（yì）：到……去。
注：啖（dàn）：吃。

# 二｜王戎俭吝
原：王戎俭吝，其从子婚，与一单衣，后更责之。|| 王戎小气，侄子结婚，他送了一件单衣，过后又把它要了回去。
注：王戎：字濬冲，琅邪临沂人，“竹林七贤”中年纪最小者，官至司徒，以聚敛吝啬著称。
注：从（zòng）子：侄子。
注：责：索取，讨还。

# 三｜司徒王戎既贵且富
原：司徒王戎既贵且富，区宅、僮牧、膏田、水碓之属，洛下无比。契疏鞅掌，每与夫人烛下散筹算计。|| 司徒王戎地位显贵又极其富有，房舍、奴仆、良田、水碓这一类产业，洛阳城里没人比得上。契据账簿多得忙不过来，他常常和夫人在灯下摆开算筹算账。
注：区宅：房屋宅院。
注：僮牧：家奴和放牧的仆役。
注：膏田：肥沃的田地。
注：水碓（duì）：借水力带动的舂米器械，当时是重要的生财之具。
注：契疏：契约账目。
注：鞅掌：事务繁多，忙乱不堪。
注：散筹：摊开算筹。筹是古代计数用的小竹棍。

# 四｜王戎有好李
原：王戎有好李，常卖之，恐人得其种，恒钻其核。|| 王戎家有好李子，常拿去卖，又怕别人得到他家的良种，总是先把李核钻破。
注：种：指可以种植的果核。
注：恒：常常，总是。

# 五｜王戎女适裴頠
原：王戎女适裴頠，贷钱数万。女归，戎色不说。女遽还钱，乃释然。|| 王戎的女儿嫁给裴頠，曾向他借了几万钱。¦女儿回娘家时，王戎脸色很不高兴；¦女儿赶紧把钱还上，他这才转怒为喜。
注：适：女子出嫁。
注：裴頠（wěi）：字逸民，西晋名士，著《崇有论》。
注：说：同“悦”。
注：遽（jù）：急忙。
注：释然：心中疙瘩消解的样子。

# 六｜卫江州在寻阳
原：卫江州在寻阳，有知旧人投之，都不料理，唯饷王不留行一斤。此人得饷，便命驾。李弘范闻之曰：“家舅刻薄，乃复驱使草木。”|| 卫展任江州刺史驻在寻阳时，有个老相识来投奔他，他一概不加照应，只送了一斤“王不留行”。那人得了这份礼，当即叫人套车走了。李弘范听说后道：“我舅舅真是刻薄，竟然连草木都差遣来替他送客。”
注：卫江州：卫展，字道舒，东晋时任江州刺史。
注：寻阳：郡县名，在今江西九江一带。
注：料理：照顾，安顿。
注：饷：赠送。
注：王不留行：草药名。卫展取其字面“王不留客”之意，婉转下逐客令。
注：李弘范：卫展的外甥，名字与生平存疑。

# 七｜王丞相俭节
原：王丞相俭节，帐下甘果盈溢不散，涉春烂败。都督白之，公令舍去，曰：“慎不可令大郎知。”|| 丞相王导很节俭，帐下的甜美果品堆得满满的也不肯分给人，过了春天都烂掉了。都督来禀报，王导叫人扔掉，叮嘱说：“千万别让大郎知道。”
注：王丞相：王导，字茂弘，东晋开国重臣，历仕三朝。
注：都督：此指府中总管杂务的属吏。
注：白：禀告。
注：大郎：王导的长子王悦。王导为何怕他知道，原文未说，大约是羞于让儿子看到自己吝啬到让果子烂掉。

# 八｜苏峻之乱
原：苏峻之乱，庾太尉南奔见陶公，陶公雅相赏重。陶性俭吝。及食，啖薤，庾因留白。陶问：“用此何为？”庾云：“故可种。”于是大叹庾非唯风流，兼有治实。|| 苏峻作乱时，庾亮往南逃去投奔陶侃，陶侃很赏识看重他。陶侃生性节俭吝啬。到吃饭时，吃的是薤菜，庾亮把薤白的根头留下不吃。陶侃问：“留这个做什么？”庾亮说：“还可以拿去种。”陶侃于是大为赞叹，说庾亮不仅风度潇洒，还有治事的实际才干。
注：苏峻之乱：东晋成帝咸和二年（327），苏峻与祖约以讨庾亮为名起兵，攻入建康。
注：庾太尉：庾亮，字元规，明穆皇后之兄，当时执政，死后追赠太尉。
注：陶公：陶侃，字士行，时为荆州刺史，以勤俭干练著称。
注：薤（xiè）：一种多年生草本，鳞茎叫薤白，可食，也可再种。
注：治实：处理实务的才能。

# 九｜郗公大聚敛
原：郗公大聚敛，有钱数千万。嘉宾意甚不同，常朝旦问讯。郗家法，子弟不坐，因倚语移时，遂及财货事。郗公曰：“汝正当欲得吾钱耳！”乃开库一日，令任意用。郗公始正谓损数百万许。嘉宾遂一日乞与亲友，周旋略尽。郗公闻之，惊怪不能已已。|| 郗愔大肆聚敛，积钱几千万。儿子郗超心里很不以为然，一天早晨照例去问安。郗家规矩，子弟在长辈面前不能坐，他就站着说了好半天话，终于说到了钱财上。郗愔说：“你不过是想得到我的钱罢了！”于是开库一天，任他取用。郗愔起初以为不过损失几百万罢了。郗超却在一天之内把钱分送给亲戚朋友和往来的人，几乎送光。郗愔听说后，惊愕得半天回不过神来。
注：郗公：郗愔（yīn），字方回，郗鉴之子，信奉天师道，好聚财。
注：嘉宾：郗超，字嘉宾，郗愔之子，桓温的重要谋士。
注：问讯：问安。
注：倚语：站着说话。
注：移时：过了好一阵。
注：乞与：给予。
注：周旋：指交往的人。
注：已已：停止；
注：“不能已已”即止不住。
