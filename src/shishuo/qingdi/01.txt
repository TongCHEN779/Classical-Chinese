# 本门导读
题解：轻诋就是轻视、诋毁。本门收录魏晋名士之间带刺的评语，有的一针见血，有的出于门户成见或意气之争，从中可见当时士人言语的锋利与人情的好恶。

# 一｜王太尉问眉子
原：王太尉问眉子：“汝叔名士，何以不相推重？”眉子曰：“何有名士终日妄语？”|| 太尉王衍问儿子王玄：“你叔叔是名士，你为什么不推重他？”王玄说：“哪有成天胡说八道的名士？”
注：王太尉：王衍，字夷甫，西晋名士，官至太尉。
注：眉子：王玄，字眉子，王衍之子。
注：汝叔：指王澄，字平子，王衍之弟，以放达著称。

# 二｜庾元规语周伯仁
原：庾元规语周伯仁：“诸人皆以君方乐。”周曰：“何乐？谓乐毅邪？”庾曰：“不尔，乐令耳。”周曰：“何乃刻画无盐，以唐突西子也？”|| 庾亮对周顗说：“大家都拿您跟乐氏相比。”周顗说：“哪个乐氏？是说乐毅吗？”庾亮说：“不是，是乐令。”周顗说：“怎么竟然精心描画丑女无盐，去冒犯美人西施呢？”
注：庾元规：庾亮，字元规，东晋外戚重臣。
注：周伯仁：周顗（yǐ），字伯仁，东晋名士。
注：方：比拟。
注：乐毅：战国时燕国名将。
注：乐令：乐广，西晋清谈名士，曾任尚书令。
注：无盐：战国时齐国丑女钟离春，后世用作丑女的代称。
注：西子：西施。
注：唐突：冒犯。意谓拿自己比乐广是贬低了乐广。

# 三｜深公云
原：深公云：“人谓庾元规名士，胸中柴棘三斗许。”|| 竺法深说：“人们都说庾亮是名士，可他心里装着大约三斗荆棘。”
注：深公：竺道潜，字法深，东晋高僧。
注：柴棘：柴草荆棘，比喻心机深险、心胸不坦荡。
注：许：表示约数。

# 四｜庾公权重
原：庾公权重，足倾王公。庾在石头，王在冶城坐，大风扬尘，王以扇拂尘曰：“元规尘污人。”|| 庾亮权势很重，足以压倒王导。庾亮驻在石头城，王导坐在冶城，一阵大风扬起尘土，王导用扇子拂着尘土说：“元规的尘土脏了人。”
注：庾公：庾亮，以帝舅身份执掌朝政。
注：王公：王导，东晋丞相。
注：倾：压倒。
注：石头：石头城，在今江苏南京西。
注：冶城：古城名，也在今南京。石头城在冶城上风方向，王导借风尘讥讽庾亮。

# 五｜王右军少时甚涩讷
原：王右军少时甚涩讷，在大将军许，王、庾二公后来，右军便起欲去。大将军留之曰：“尔家司空、元规，复可所难？”|| 王羲之年轻时说话很迟钝，有一次在大将军王敦那里，王导、庾亮两位后来到了，王羲之就起身要走。王敦挽留他说：“是你家的司空和元规罢了，又有什么可为难的？”
注：王右军：王羲之，曾任右军将军。
注：涩讷（nè）：言语迟钝，不善说话。
注：大将军：王敦，王羲之的族伯。
注：许：处所。
注：司空：王导，曾任司空。
注：元规：庾亮。
注：复可所难：又有什么可怕为难的；“可”字一说当作“何”，存疑。

# 六｜王丞相轻蔡公
原：王丞相轻蔡公，曰：“我与安期、千里共游洛水边，何处闻有蔡充儿？”|| 丞相王导看不起蔡谟，说：“我和王安期、阮千里一起在洛水边游玩的时候，哪里听说过有个蔡充的儿子？”
注：蔡公：蔡谟，字道明，东晋大臣，官至司徒。
注：安期：王承，字安期。
注：千里：阮瞻，字千里。二人都是西晋名士。
注：蔡充：蔡谟之父，西晋人。王导以资历压人，言下之意蔡谟当年还是无名小辈。

# 七｜褚太傅初渡江
原：褚太傅初渡江，尝入东，至金昌亭，吴中豪右燕集亭中。褚公虽素有重名，于时造次不相识别。敕左右多与茗汁，少著粽，汁尽辄益，使终不得食。褚公饮讫，徐举手共语云：“褚季野。”于是四坐惊散，无不狼狈。|| 褚裒刚过江南下时，曾经到东边去，走到金昌亭，吴地的豪门大族正在亭中宴饮聚会。褚裒虽然向来很有名望，当时仓促之间他们并不认识他。主人吩咐手下多给他茶水，少放点心，茶一喝完就添上，让他始终吃不到东西。褚裒喝完茶，慢慢举手向众人说：“我是褚季野。”于是满座的人惊慌四散，没有一个不狼狈的。
注：褚太傅：褚裒（póu），字季野，东晋外戚，死后追赠太傅。
注：金昌亭：驿亭名，在今江苏苏州。
注：豪右：豪门大族。
注：燕集：宴饮聚会，燕同“宴”。
注：造次：仓促。
注：敕（chì）：吩咐。
注：茗汁：茶水。
注：粽：一种茶点，具体所指存疑。
注：益：添加。

# 八｜王右军在南
原：王右军在南，丞相与书，每叹子侄不令，云：“虎豘、虎犊，还其所如。”|| 王羲之在南方的时候，丞相王导给他写信，常常感叹自家子侄不成器，说：“虎豘、虎犊，真跟他们的名字一个样。”
注：丞相：王导，王羲之的族伯。
注：不令：不好，不成材。
注：虎豘（tún）：王彭之的小名。
注：虎犊：王彪之的小名。二人都是王导的族侄。豘是小猪，犊是小牛。
注：还其所如：正像他们的名字那样，讥其才质平庸。

# 九｜褚太傅南下
原：褚太傅南下，孙长乐于船中视之。言次及刘真长死，孙流涕，因讽咏曰：“人之云亡，邦国殄瘁。”褚大怒曰：“真长平生，何尝相比数，而卿今日作此面向人！”孙回泣向褚曰：“卿当念我！”时咸笑其才而性鄙。|| 褚裒南下，孙绰到船上去看他。说话间谈到刘惔去世，孙绰流下眼泪，随即吟诵道：“贤人逝去了，国家也就衰败了。”褚裒大怒说：“真长生前何曾把你当回事，你今天却在人前摆出这副面孔！”孙绰收起眼泪对褚裒说：“你该可怜可怜我！”当时人都笑他有才学而品性鄙俗。
注：孙长乐：孙绰，字兴公，袭封长乐侯，东晋文士。
注：刘真长：刘惔，字真长，东晋清谈名士。
注：言次：说话之间。
注：“人之云亡”二句：出自《诗经·大雅·瞻卬》，云为语助词，殄瘁（cuì）指困穷衰败。
注：比数：看得上，当回事。

# 十｜谢镇西书与殷扬州
原：谢镇西书与殷扬州，为真长求会稽。殷答曰：“真长标同伐异，侠之大者。常谓使君降阶为甚，乃复为之驱驰邪？”|| 谢尚写信给殷浩，替刘惔求取会稽郡守的职位。殷浩回答说：“刘真长这个人，跟自己意见相同的就捧，不同的就攻，是心胸最狭隘的人。我常觉得您对他屈尊得太过分了，如今竟还要替他奔走吗？”
注：谢镇西：谢尚，字仁祖，曾任镇西将军。
注：殷扬州：殷浩，字渊源，曾任扬州刺史。
注：标同伐异：标榜和自己相同的，攻击和自己不同的。
注：侠：通“狭”，狭隘。
注：使君：对州郡长官的尊称。
注：降阶：走下台阶相迎，表示屈尊礼待。
注：驱驰：奔走效力。

# 十一｜桓公入洛
原：桓公入洛，过淮、泗，践北境，与诸僚属登平乘楼，眺瞩中原，慨然曰：“遂使神州陆沉，百年丘墟，王夷甫诸人不得不任其责！”|| 桓温进军洛阳，渡过淮水、泗水，踏上北方的土地，和僚属们登上大船的船楼，远望中原，感慨地说：“终于使中原沦陷，百年来成为一片废墟，王夷甫这班人不能不承担责任！”
注：桓公：桓温，字元子，东晋权臣。
注：入洛：指桓温北伐收复洛阳。
注：平乘楼：大船上的楼台。
注：神州陆沉：比喻国土沦丧。
注：丘墟：废墟。
注：王夷甫：王衍，西晋末清谈领袖，常被视为误国之人。
原：袁虎率尔对曰：“运自有废兴，岂必诸人之过？”桓公懔然作色，顾谓四坐曰：“诸君颇闻刘景升不？有大牛重千斤，啖刍豆十倍于常牛，负重致远，曾不若一羸牸。魏武入荆州，烹以飨士卒，于时莫不称快。”意以况袁。四坐既骇，袁亦失色。|| 袁宏轻率地答道：“国运本来就有兴有衰，难道一定是他们的过错？”桓温神色严峻地变了脸，环顾满座说：“诸位听说过刘景升吗？他有一头大牛，重达千斤，吃的草料豆子比普通的牛多十倍，可是驮重物走远路，还比不上一头瘦弱的母牛。魏武帝进了荆州，就把它宰了犒劳士兵，当时没有人不叫好。”意思是拿这头牛来比袁宏。满座的人都吓坏了，袁宏也变了脸色。
注：袁虎：袁宏，字彦伯，小字虎，东晋文学家，时为桓温僚属。
注：率尔：轻率的样子。
注：懔然：神色严厉。
注：刘景升：刘表，字景升，汉末荆州牧。
注：啖（dàn）：吃。
注：刍豆：草料和豆子。
注：羸牸（léi zì）：瘦弱的母牛。
注：魏武：魏武帝曹操。
注：飨：用酒食犒劳。
注：况：比拟。

# 十二｜袁虎、伏滔同在桓公府
原：袁虎、伏滔同在桓公府，桓公每游燕，辄命袁、伏，袁甚耻之，恒叹曰：“公之厚意，未足以荣国士。与伏滔比肩，亦何辱如之？”|| 袁宏和伏滔同在桓温府中任职，桓温每次游玩宴饮，总要把袁宏、伏滔一起叫上，袁宏觉得这是莫大的耻辱，常常叹息说：“桓公的厚意，不足以让国士觉得荣耀；¦跟伏滔并列，还有什么耻辱比得上这个？”
注：伏滔：字玄度，东晋文士，曾任桓温参军。
注：游燕：游乐宴饮。
注：国士：一国中才能出众的人，袁宏自指。
注：比肩：并列。

# 十三｜高柔在东
原：高柔在东，甚为谢仁祖所重。既出，不为王、刘所知。仁祖曰：“近见高柔大自敷奏，然未有所得。”真长云：“故不可在偏地居，轻在角䚥中为人作议论。”高柔闻之云：“我就伊无所求。”|| 高柔在东边的时候，很受谢尚器重。等到出来做官，却得不到王濛、刘惔的赏识。谢尚说：“近来看到高柔大肆上书陈奏，可是没有什么收获。”刘惔说：“本来就不该住在偏僻地方，轻易地缩在角落里让人评头论足。”高柔听说后说：“我对他本来就没什么可求的。”
注：高柔：字世远，乐安人，东晋时曾任安固令。
注：在东：指在会稽一带。
注：谢仁祖：谢尚。
注：王、刘：王濛、刘惔，都是当时名流。
注：敷奏：向朝廷陈述进言。
注：角䚥（nuò）：角落，偏僻之处。
注：就伊：对他，向他。
原：人有向真长学此言者，真长曰：“我实亦无可与伊者。”然游燕犹与诸人书：“可要安固。”安固者，高柔也。|| 有人把这话学给刘惔听，刘惔说：“我其实也没什么可给他的。”可是每逢游乐宴饮，他还是写信给众人说：“可以请安固来。”安固，就是高柔。
注：要（yāo）：邀请。
注：安固：高柔曾任安固令，故以官称之。

# 十四｜刘尹、江虨、王叔虎
原：刘尹、江虨、王叔虎、孙兴公同坐，江、王有相轻色。虨以手歙叔虎云：“酷吏！”词色甚强。刘尹顾谓：“此是瞋邪？非特是丑言声、拙视瞻。”|| 刘惔、江虨、王彪之、孙绰坐在一起，江虨和王彪之脸上都有互相看不起的神情。江虨用手朝王彪之一比划，说：“酷吏！”言辞神色都很强硬。刘惔回头说：“这是发怒吗？不光是说话难听，样子也难看。”
注：刘尹：刘惔，曾任丹阳尹。
注：江虨（bīn）：字思玄，东晋大臣。
注：王叔虎：王彪之，字叔虎。
注：孙兴公：孙绰。
注：歙（shè）：用手作出威吓的动作，确切含义存疑。
注：瞋（chēn）：发怒。
注：非特：不只。
注：视瞻：眼神仪态。

# 十五｜孙绰作《列仙·商丘子赞》
原：孙绰作《列仙·商丘子赞》曰：“所牧何物？殆非真猪。傥遇风云，为我龙摅。”时人多以为能。王蓝田语人云：“近见孙家儿作文，道‘何物’、‘真猪’也。”|| 孙绰写《列仙传·商丘子赞》说：“他放牧的是什么？恐怕不是真猪。倘若遇上风云，就会化成龙为我腾飞。”当时人大多认为写得好。王述对人说：“近来看到孙家那小子作文章，满纸是‘何物’‘真猪’之类的话。”
注：商丘子：传说中的仙人，以牧猪为生，见《列仙传》。
注：赞：一种韵文，用来赞美或总评。
注：殆：大概。
注：傥：同“倘”，假如。
注：龙摅（shū）：像龙一样腾飞。
注：王蓝田：王述，字怀祖，袭封蓝田侯。他嫌孙绰用语鄙俗。

# 十六｜桓公欲迁都
原：桓公欲迁都，以张拓定之业。孙长乐上表谏，此议甚有理。桓见表心服，而忿其为异，令人致意孙云：“君何不寻《遂初赋》，而强知人家国事！”|| 桓温想迁都洛阳，以扩大开拓安定国家的功业。孙绰上表劝谏，这番议论很有道理。桓温看了奏表心里服气，却恼恨他唱反调，派人去对孙绰说：“你为什么不去追寻你《遂初赋》里的心愿，却硬要过问人家的国家大事！”
注：迁都：指桓温北伐后上表请求迁都洛阳。
注：张：扩大。
注：拓定：开拓平定。
注：孙长乐：孙绰。
注：《遂初赋》：孙绰所作，自述归隐山林、遂其初志的心愿。
注：知：过问，干预。

# 十七｜孙长乐兄弟就谢公宿
原：孙长乐兄弟就谢公宿，言至款杂。刘夫人在壁后听之，具闻其语。谢公明日还，问：“昨客何似？”刘对曰：“亡兄门未有如此宾客。”谢深有愧色。|| 孙绰兄弟到谢安家住宿，谈话非常空泛杂乱。刘夫人在墙后听着，把他们的话全听到了。谢安第二天回来，问：“昨天的客人怎么样？”刘夫人回答说：“我去世的哥哥门下，从没有过这样的宾客。”谢安脸上很有惭愧之色。
注：孙长乐兄弟：孙绰和他的哥哥孙统。
注：谢公：谢安。
注：款杂：空泛杂乱。款，空。
注：刘夫人：谢安之妻，刘惔之妹。
注：亡兄：指刘惔，时已去世。

# 十八｜简文与许玄度共语
原：简文与许玄度共语，许云：“举君亲为难。”简文便不复答，许去后而言曰：“玄度故可不至于此。”|| 简文帝和许询一起谈论，许询说：“提出君主和父母孰轻孰重的问题，是很难回答的。”简文帝就不再接话，许询走后才说：“玄度本来可以不至于说这种话。”
注：简文：东晋简文帝司马昱，即位前为会稽王。
注：许玄度：许询，字玄度，东晋名士。
注：举君亲为难：把君与亲放在一起比较是难题。此题涉及忠孝冲突，在帝王面前提出显得失当。
注：故：本来。

# 十九｜谢万寿春败后还
原：谢万寿春败后还，书与王右军云：“惭负宿顾。”右军推书曰：“此禹、汤之戒。”|| 谢万在寿春大败后回来，写信给王羲之说：“很惭愧辜负了您一向的关照。”王羲之把信推开说：“这是大禹、商汤责己的话。”
注：谢万：字万石，谢安之弟。东晋升平年间率军北伐，在寿春一带溃败。
注：宿顾：平素的关怀照顾。王羲之曾写信告诫谢万要善待下属，谢万没有听从。
注：禹、汤之戒：禹、汤以责己自省著称。王羲之意谓谢万现在才说这种话，不过是空谈，含讥讽。

# 二十｜蔡伯喈睹睐笛椽
原：蔡伯喈睹睐笛椽，孙兴公听妓，振且摆折。王右军闻，大嗔曰：“三祖寿乐器，虺瓦吊孙家儿打折！”|| 蔡邕慧眼看中屋椽竹子而制成的笛子，传到孙绰手里，他听歌伎唱歌时拿它打拍子，又挥又敲，竟把它打断了。王羲之听说后大怒说：“祖宗三代传下来的乐器，竟被孙家这小子打断了！”
注：蔡伯喈：蔡邕，字伯喈，东汉末文学家、音乐家。相传他在柯亭见屋椽竹子好，取下制成笛子，音色绝妙。
注：睹睐：看中，赏识。
注：孙兴公：孙绰。
注：听妓：听歌伎演唱。
注：振且摆折：挥动敲击以致折断。
注：嗔（chēn）：发怒。
注：三祖寿乐器：祖传三代的乐器。
注：虺（huǐ）瓦吊：语义难解，或为骂人之词，存疑。

# 二十一｜王中郎与林公绝不相得
原：王中郎与林公绝不相得。王谓林公诡辩，林公道王云：“著腻颜帢，绤布单衣，挟《左传》，逐郑康成车后，问是何物尘垢囊？”|| 王坦之和支道林彼此完全合不来。王坦之说支道林是诡辩，支道林说王坦之：“戴着油腻的旧便帽，穿着粗布单衣，夹着一部《左传》，跟在郑康成的车后跑，请问这是个什么装尘土污垢的口袋？”
注：王中郎：王坦之，字文度，曾任北中郎将。
注：林公：支道林，名遁，东晋名僧。
注：相得：彼此投合。
注：腻颜帢（qià）：油腻的颜帢。颜帢是额前有横缝的便帽，东晋时已过时。
注：绤（xì）布：粗葛布。
注：郑康成：郑玄，字康成，东汉经学大师。支道林讥王坦之是拘守章句的腐儒。

# 二十二｜孙长乐作王长史诔
原：孙长乐作王长史诔云：“余与夫子，交非势利，心犹澄水，同此玄味。”王孝伯见曰：“才士不逊，亡祖何至与此人周旋！”|| 孙绰为王濛写诔文说：“我和夫子相交，不是为了权势利益，两心像清水一样明净，共同品味玄理的意趣。”王恭看到后说：“有才的文人真不谦逊，我已故的祖父哪里至于跟这种人交往！”
注：王长史：王濛，字仲祖，曾任司徒左长史。
注：诔（lěi）：哀悼死者、叙述其德行的文体。
注：玄味：玄理的意味。
注：王孝伯：王恭，字孝伯，王濛之孙。
注：周旋：交往。

# 二十三｜谢太傅谓子侄曰
原：谢太傅谓子侄曰：“中郎始是独有千载。”车骑曰：“中郎衿抱未虚，复那得独有？”|| 谢安对子侄们说：“中郎才算得上千载独一的人物。”谢玄说：“中郎的胸怀还不够虚旷，又怎么能算独一无二？”
注：谢太傅：谢安。
注：中郎：谢万，曾任抚军从事中郎。
注：始：才。
注：车骑：谢玄，字幼度，谢安之侄，死后追赠车骑将军。
注：衿抱：胸怀。
注：虚：虚怀，不自满。

# 二十四｜庾道季诧谢公曰
原：庾道季诧谢公曰：“裴郎云：‘谢安谓裴郎乃可不恶，何得为复饮酒？’裴郎又云：‘谢安目支道林如九方皋之相马，略其玄黄，取其俊逸。’”谢公云：“都无此二语，裴自为此辞耳。”|| 庾龢告诉谢安说：“裴郎的书里写着：‘谢安说裴郎确实不坏，可为什么还要喝酒呢？’裴郎又写道：‘谢安品评支道林，就像九方皋相马，不管毛色是黑是黄，只取它的神骏超逸。’”谢安说：“我根本没说过这两句话，是裴启自己编出来的。”
注：庾道季：庾龢，字道季，庾亮之子。
注：诧：告诉。
注：裴郎：裴启，字荣期，东晋人，著有笔记《语林》，多记当时名士言行。
注：九方皋：春秋时善相马的人，相马只看马的内在神骏，不在意毛色。
注：目：品评。
原：庾意甚不以为好，因陈东亭《经酒垆下赋》。读毕，都不下赏裁，直云：“君乃复作裴氏学！”于此《语林》遂废。今时有者，皆是先写，无复谢语。|| 庾龢很不以为然，于是背诵王珣的《经酒垆下赋》。读完后，谢安一句评价也没有，只说：“你竟然也学起裴家那一套来了！”从此《语林》就不再流行。现在还能见到的，都是早先抄写的本子，里面不再有谢安的话了。
注：东亭：王珣，字元琳，封东亭侯。
注：《经酒垆下赋》：王珣所作，追怀嵇康、阮籍等人的旧游；此赋可能也被收进《语林》，存疑。
注：赏裁：赞赏评判。
注：直：只。
注：《语林》：裴启所撰笔记小说，后已失传，《世说新语》多取材于此。

# 二十五｜王北中郎不为林公所知
原：王北中郎不为林公所知，乃著论《沙门不得为高士论》，大略云：“高士必在于纵心调畅。沙门虽云俗外，反更束于教，非情性自得之谓也。”|| 王坦之得不到支道林的赏识，于是写了一篇《沙门不得为高士论》，大意说：“高士一定要心志放任、舒畅自在。和尚虽然号称超脱世俗，反而更受教规束缚，算不上性情自适。”
注：王北中郎：王坦之。
注：林公：支道林。
注：知：赏识。
注：沙门：佛教僧侣。
注：高士：志趣高洁、超然世外的人。
注：纵心调畅：放任心性，和谐舒畅。
注：束于教：受佛教戒律约束。

# 二十六｜人问顾长康
原：人问顾长康：“何以不作洛生咏？”答曰：“何至作老婢声？”|| 有人问顾恺之：“你为什么不学洛下书生的吟咏腔调？”他回答说：“何至于去学老婢女的声音？”
注：顾长康：顾恺之，字长康，东晋画家、文学家。
注：洛生咏：洛阳书生吟诵诗文的腔调，声音重浊，东晋士族竞相模仿。
注：老婢：老年女仆。

# 二十七｜殷顗、庾恒并是谢镇西外孙
原：殷顗、庾恒并是谢镇西外孙，殷少而率悟，庾每不推。尝俱诣谢公，谢公孰视殷曰：“阿巢故似镇西。”于是庾下声语曰：“定何似？”谢公续复云：“巢颊似镇西。”庾复云：“颊似，足作健不？”|| 殷顗、庾恒都是谢尚的外孙，殷顗从小就坦率聪敏，庾恒却总不服他。有一次两人一起去拜见谢安，谢安仔细端详殷顗说：“阿巢确实像镇西。”于是庾恒低声说：“到底哪里像？”谢安接着又说：“阿巢的脸颊像镇西。”庾恒又说：“脸颊像，就足以成为强者吗？”
注：殷顗（yǐ）：字伯通，小字巢。
注：庾恒：字敬则，庾龢之子。
注：谢镇西：谢尚。
注：率悟：直率聪悟。
注：推：推崇，佩服。
注：孰视：仔细看，孰同“熟”。
注：故：确实。
注：下声：低声。
注：定：究竟。
注：作健：成为有作为的强者。
注：不（fǒu）：同“否”。

# 二十八｜旧目韩康伯
原：旧目韩康伯“将肘无风骨”。|| 过去人们评论韩康伯，说他“胳膊肘粗大，却没有风骨”。
注：韩康伯：韩伯，字康伯，东晋玄学家。
注：目：品评。
注：将肘：粗壮的胳膊肘；将，大。
注：风骨：人的风度气骨。

# 二十九｜苻宏叛来归国
原：苻宏叛来归国，谢太傅每加接引。宏自以有才，多好上人，坐上无折之者。适王子猷来，太傅使共语。子猷直孰视良久，回语太傅云：“亦复竟不异人。”宏大惭而退。|| 苻宏背离前秦来投奔东晋，谢安常常接待引荐他。苻宏自以为有才，总爱压人一头，在座的没人能折服他。正赶上王徽之来了，谢安让他们两人交谈。王徽之只是盯着苻宏看了好半天，回头对谢安说：“说到底也没什么和别人不同的。”苻宏非常羞惭地退了出去。
注：苻宏：前秦皇帝苻坚的太子，苻坚败亡后投奔东晋。
注：归国：归附东晋。
注：接引：接待引荐。
注：上人：凌驾于他人之上。
注：折：使之折服。
注：王子猷（yóu）：王徽之，字子猷，王羲之之子，性情傲诞。
注：竟：终究。

# 三十｜支道林入东
原：支道林入东，见王子猷兄弟，还，人问：“见诸王何如？”答曰：“见一群白颈乌，但闻唤哑哑声。”|| 支道林到会稽去，见了王徽之兄弟，回来后有人问他：“见到王家诸位，觉得怎么样？”他回答说：“看到一群白脖子乌鸦，只听见哑哑地叫唤。”
注：入东：到会稽一带去。
注：王子猷兄弟：王羲之的几个儿子。
注：白颈乌：讥王氏子弟多穿白领衣服；一说讽刺他们说话爱用“唯诺”之声，存疑。
注：哑哑：乌鸦叫声。

# 三十一｜王中郎举许玄度为吏部郎
原：王中郎举许玄度为吏部郎，郗重熙曰：“相王好事，不可使阿讷在坐头。”|| 王坦之推荐许询担任吏部郎，郗昙说：“相王喜欢多事，不能让阿讷坐在那个位子上。”
注：王中郎：王坦之。
注：许玄度：许询。
注：吏部郎：吏部掌管官员选拔的郎官，职位清要。
注：郗重熙：郗昙，字重熙，郗鉴之子。
注：相王：简文帝司马昱即位前以会稽王身份任丞相，故称。
注：好事：喜欢多事。
注：阿讷：许询的小名。
注：坐头：座位，指吏部郎的位子。

# 三十二｜王兴道谓谢望蔡
原：王兴道谓谢望蔡：“霍霍如失鹰师。”|| 王和之评论谢琰说：“急急躁躁的，像个丢了鹰的驯鹰人。”
注：王兴道：王和之，字兴道，王胡之之子。
注：谢望蔡：谢琰，字瑗度，谢安之子，因淝水之战有功封望蔡公。
注：霍霍：急躁不安的样子。
注：鹰师：驯养猎鹰的人。

# 三十三｜桓南郡每见人不快
原：桓南郡每见人不快，辄嗔云：“君得哀家梨，当复不烝食不？”|| 桓玄每次见到人迟钝不爽利，总是生气地说：“你要是得了哀家梨，该不会也蒸着吃吧？”
注：桓南郡：桓玄，桓温之子，袭封南郡公。
注：不快：不爽利，迟钝。
注：哀家梨：相传汉代秣陵哀仲家的梨，又大又甜，入口即化。
注：烝：同“蒸”。好梨本应生吃，蒸了便糟蹋了，讥人不辨好坏。
注：不（fǒu）：同“否”。
