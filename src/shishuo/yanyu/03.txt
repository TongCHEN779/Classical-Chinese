# 五十一｜张玄之、顾敷是顾和中外孙
原：张玄之、顾敷是顾和中外孙，皆少而聪惠，和并知之，而常谓顾胜，亲重偏至，张颇不恹。于时，张年九岁，顾年七岁。和与俱至寺中，见佛般泥洹像，弟子有泣者，有不泣者。和以问二孙。玄谓：“被亲故泣，不被亲故不泣。”敷曰：“不然。当由忘情故不泣，不能忘情故泣。”|| 张玄之和顾敷分别是顾和的外孙和孙子，两人从小就聪明伶俐，顾和都很赏识，却常说顾敷更胜一筹，对他格外偏爱看重，张玄之心里颇不服气。那时张玄之九岁，顾敷七岁。顾和带着他们一起到寺庙里，看见佛祖涅槃的卧像，像旁的弟子有的在哭，有的没哭。顾和便拿这件事问两个孙辈。张玄之说：“受佛亲近的就哭，没受亲近的就不哭。”顾敷说：“不对。应当是能忘却情感的不哭，忘不了情感的才哭。”
注：张玄之、顾敷：张玄之，字祖希，东晋人，后官至吏部尚书；顾敷，字祖根，有才早慧，年少即卒。
注：顾和：字君孝，吴郡人，东晋大臣，官至尚书令。
注：中外孙：孙子与外孙，顾敷是孙，张玄之是外孙。
注：恹（yàn）：此处同“厌”，满意、心服；
注：“不恹”即不服气。
注：般泥洹：梵语音译，即涅槃，指佛陀入灭；
注：“般泥洹像”即佛陀临终侧卧之像。

# 五十二｜庾法畅造庾太尉
原：庾法畅造庾太尉，握麈尾至佳。公曰：“此至佳，那得在？”法畅曰：“廉者不求，贪者不与，故得在耳。”|| 法畅和尚去拜访庾亮，手里握着的麈尾非常精美。庾亮说：“这么好的东西，怎么还能留在你手里？”法畅说：“廉洁的人不会向我讨，贪心的人我不给，所以就一直留着了。”
注：庾法畅：一般认为当作“康法畅”，东晋僧人，善清谈；书中印作“庾”，照录。
注：庾太尉：庾亮，东晋外戚重臣，死后追赠太尉。
注：麈（zhǔ）尾：用兽尾毛做成的拂尘，魏晋名士清谈时常执于手中。
注：那得在：怎么还能保留得住。

# 五十三｜庾稚恭为荆州
原：庾稚恭为荆州，以毛扇上武帝，武帝疑是故物。侍中刘劭曰：“柏梁云构，工匠先居其下；管弦繁奏，钟、夔先听其音。稚恭上扇，以好不以新。”庾后闻之，曰：“此人宜在帝左右。”|| 庾翼任荆州刺史时，把一柄羽毛扇进献给皇帝，皇帝怀疑这是用过的旧扇子。侍中刘劭说：“柏梁台高耸入云，工匠们先在下面住过；管弦乐齐声演奏，钟子期、夔这样的知音先听过。稚恭献扇，看重的是它好，不是它新。”庾翼后来听说了，说：“这样的人正适合待在皇帝身边。”
注：庾稚恭：庾翼，字稚恭，庾亮之弟，继兄镇守荆州，有志北伐。
注：武帝：此时在位的是东晋成帝，“武帝”当为“成帝”之误，存疑。
注：柏梁：汉武帝所建柏梁台，以高峻著称。
注：云构：高入云霄的建筑。
注：钟、夔：钟子期与舜时乐官夔，都是精通音律的人。

# 五十四｜何骠骑亡后
原：何骠骑亡后，征褚公入。既至石头，王长史、刘尹同诣褚。褚曰：“真长，何以处我？”真长顾王曰：“此子能言。”褚因视王，王曰：“国自有周公。”|| 骠骑将军何充去世后，朝廷征召褚裒入京。褚裒到了石头城，王濛和刘惔一同去拜见他。褚裒问：“真长，朝廷会怎么安置我？”刘惔回头看着王濛说：“这位先生会说话。”褚裒于是看向王濛，王濛说：“国家自有周公在。”
注：何骠骑：何充，东晋大臣，曾任骠骑将军，辅政多年。
注：褚公：褚裒（póu），康献褚太后之父，当时镇守京口，朝议欲召他入朝辅政。
注：王长史、刘尹：王濛，曾任司徒左长史；刘惔，字真长，曾任丹阳尹。
注：周公：以辅佐成王的周公比喻会稽王司马昱，暗示辅政自有其人，劝褚裒不必入朝。

# 五十五｜桓公北征
原：桓公北征，经金城，见前为琅邪时种柳，皆已十围，慨然曰：“木犹如此，人何以堪！”攀枝执条，泫然流泪。|| 桓温北伐，途经金城，看见自己从前任琅邪内史时种下的柳树，都已粗到十围了，感慨地说：“树木尚且变成这样，人又怎么经受得住！”他攀着树枝，握着柳条，不禁潸然泪下。
注：桓公：桓温，字元子，东晋权臣，多次北伐。此指太和四年（369）北伐前燕。
注：金城：地名，在今江苏句容一带，桓温任琅邪内史时镇守于此。
注：围：计量粗细的单位，约两手合抱。
注：泫（xuàn）然：流泪的样子。

# 五十六｜简文作抚军时
原：简文作抚军时，尝与桓宣武俱入朝，更相让在前。宣武不得已而先之，因曰：“伯也执殳，为王前驱。”简文曰：“所谓‘无小无大，从公于迈’。”|| 简文帝还是抚军大将军的时候，曾和桓温一同上朝，两人互相谦让，请对方走在前面。桓温不得已先走，便说：“伯也执殳，为王前驱。”简文帝答道：“这就是所谓‘无小无大，从公于迈’啊。”
注：简文：东晋简文帝司马昱，即位前曾任抚军大将军。
注：桓宣武：桓温，谥宣武。
注：伯也执殳，为王前驱：出自《诗经·卫风·伯兮》，意为手持兵器为君王开路。殳（shū），古代长柄兵器。
注：无小无大，从公于迈：出自《诗经·鲁颂·泮水》，意为无论官小官大，都跟随您前行；简文帝借此回敬，以“公”尊称桓温。

# 五十七｜顾悦与简文同年
原：顾悦与简文同年，而发蚤白。简文曰：“卿何以先白？”对曰：“蒲柳之姿，望秋而落；松柏之质，经霜弥茂。”|| 顾悦和简文帝同岁，头发却早早白了。简文帝问：“你的头发怎么比我先白？”顾悦答道：“蒲柳的资质，一到秋天就凋零；松柏的本性，经了霜反而更加茂盛。”
注：顾悦：字君叔，东晋晋陵人，官至尚书左丞。
注：蚤：通“早”。
注：蒲柳：水杨，入秋早凋，常用来自比体弱或地位卑微。
注：望：临近、面对。
注：弥：更加。

# 五十八｜桓公入峡
原：桓公入峡，绝壁天悬，腾波迅急，乃叹曰：“既为忠臣，不得为孝子，如何！”|| 桓温率军进入三峡，只见峭壁高悬如在天际，波涛翻腾，水流湍急，于是叹息道：“既然做了忠臣，就做不成孝子，有什么办法呢！”
注：桓公入峡：指永和二年（346）桓温率军溯江入蜀讨伐成汉，途经三峡。
注：既为忠臣，不得为孝子：用汉代典故，王阳为益州刺史，行至九折坂险处，以身体受之父母为由退回，是为孝子；后王尊至此，叱驭而过，自称忠臣。

# 五十九｜初，荧惑入太微
原：初，荧惑入太微，寻废海西；简文登阼，复入太微，帝恶之。时郗超为中书，在直。引超入曰：“天命修短，故非所计。政当无复近日事不？”超曰：“大司马方将外固封疆，内镇社稷，必无若此之虑。臣为陛下以百口保之。”|| 起初，火星侵入太微星区，不久海西公就被废黜；简文帝登上帝位后，火星又一次进入太微，简文帝对此十分厌恶。当时郗超任中书侍郎，正在宫中值班。简文帝把他叫进来说：“寿命长短，本来就不是我所计较的。只是不会再发生前些日子那样的事吧？”郗超说：“大司马正要对外巩固边疆，对内安定社稷，一定不会有这样的打算。我愿拿全家上百口人的性命替陛下担保。”
注：荧惑入太微：荧惑即火星，太微为星垣名，古人视火星入太微为帝位不安的凶兆。
注：废海西：太和六年（371）桓温废晋帝司马奕为海西公，另立简文帝。
注：登阼（zuò）：登上帝位。
注：郗超：字景兴，郗鉴之孙，桓温的心腹谋士，时任中书侍郎。
注：在直：正在值班。
注：政：通“正”，只是。
注：大司马：指桓温。
原：帝因诵庾仲初诗曰：“志士痛朝危，忠臣哀主辱。”声甚凄厉。郗受假还东，帝曰：“致意尊公，家国之事，遂至于此。由是身不能以道匡卫，思患预防。愧叹之深，言何能喻！”因泣下流襟。|| 简文帝于是吟诵庾阐的诗：“志士痛朝危，忠臣哀主辱。”声音非常凄凉。后来郗超请假回东边探亲，简文帝说：“代我向令尊致意，国家的事竟到了这一步。都怪我不能依正道匡正护卫，在祸患未至时预先防范。我心中惭愧悲叹之深，哪里是言语说得尽的！”说着泪流满襟。
注：庾仲初：庾阐，字仲初，东晋文学家。
注：尊公：对别人父亲的敬称，此指郗超之父郗愔（yīn），他忠于晋室，与儿子立场不同。
注：身：晋人常用作第一人称，我。
注：喻：表达、说清。

# 六十｜简文在暗室中坐
原：简文在暗室中坐，召宣武。宣武至，问上何在。简文曰：“某在斯！”时人以为能。|| 简文帝坐在一间昏暗的屋子里，召桓温来见。桓温到了，问皇上在哪儿。简文帝说：“某在斯！”当时的人都认为他应对得巧妙。
注：某在斯：语出《论语·卫灵公》，孔子为盲乐师引路时告诉他“某在斯，某在斯”。简文帝借用此语，既回答了所在，又暗含自居引导者的意味。
注：能：有才能，此指善于言辞。

# 六十一｜简文入华林园
原：简文入华林园，顾谓左右曰：“会心处不必在远。翳然林水，便自有濠、濮间想也，觉鸟兽禽鱼自来亲人。”|| 简文帝走进华林园，回头对身边的人说：“让人心领神会的地方不一定在远方。这里林木掩映、溪水清幽，自然就让人生出庄子游于濠水、钓于濮水那样的遐想，觉得鸟兽禽鱼都主动来亲近人了。”
注：华林园：建康宫苑，故址在今南京鸡鸣山一带。
注：会心：心领神会，有所感悟。
注：翳（yì）然：林木遮蔽幽深的样子。
注：濠、濮间想：《庄子·秋水》载庄子与惠子游于濠梁之上论鱼之乐，又载庄子钓于濮水、辞楚王之聘；此指逍遥自适的情怀。

# 六十二｜谢太傅语王右军曰
原：谢太傅语王右军曰：“中年伤于哀乐，与亲友别，辄作数日恶。”王曰：“年在桑榆，自然至此，正赖丝竹陶写。恒恐儿辈觉，损欣乐之趣。”|| 谢安对王羲之说：“人到中年，容易被哀伤之情所伤，每次和亲友分别，总要难受好几天。”王羲之说：“人到晚年，自然会这样，正要靠音乐来排遣抒发。只是常怕被晚辈们察觉，扫了大家欢乐的兴致。”
注：谢太傅：谢安，东晋名相，死后赠太傅。
注：王右军：王羲之，曾任右军将军，著名书法家。
注：哀乐：偏义复词，偏指哀。
注：恶：心情不好。
注：桑榆：日落时余晖照在桑榆树梢，比喻晚年。
注：丝竹：弦乐与管乐，泛指音乐。
注：陶写：陶冶性情，宣泄忧思。

# 六十三｜支道林常养数匹马
原：支道林常养数匹马。或言道人畜马不韵。支曰：“贫道重其神骏。”|| 支道林常常养着几匹马。有人说出家人养马不够风雅。支道林说：“贫道看重的是它们神采俊逸。”
注：支道林：支遁，字道林，东晋高僧，精通老庄，善清谈。
注：道人：魏晋时对僧人的称呼。
注：韵：风雅、有情致。
注：神骏：神采俊逸，气度不凡。

# 六十四｜刘尹与桓宣武共听讲
原：刘尹与桓宣武共听讲《礼记》。桓云：“时有入心处，便觉咫尺玄门。”刘曰：“此未关至极，自是金华殿之语。”|| 刘惔和桓温一起听人讲《礼记》。桓温说：“不时有打动人心的地方，便觉得离玄妙之门只有咫尺之遥了。”刘惔说：“这还没触及最高的境界，不过是金华殿上儒生讲经的话罢了。”
注：刘尹：刘惔，曾任丹阳尹，推崇玄学。
注：玄门：玄妙之门，语本《老子》“玄之又玄，众妙之门”，指玄理的最高境界。
注：至极：最高的道理。
注：金华殿之语：汉成帝时在金华殿令儒臣讲授《尚书》《论语》，此指儒家的章句之谈。

# 六十五｜羊秉为抚军参军
原：羊秉为抚军参军，少亡，有令誉，夏侯孝若为之叙，极相赞悼。羊权为黄门侍郎，侍简文坐。帝问曰：“夏侯湛作《羊秉叙》，绝可想。是卿何物？有后不？”权潸然对曰：“亡伯令问夙彰，而无有继嗣；虽名播天听，然胤绝圣世。”帝嗟慨久之。|| 羊秉做抚军参军，年纪轻轻就去世了，生前名声很好，夏侯湛为他写了一篇叙文，极力称赞并表示哀悼。羊权任黄门侍郎，陪简文帝坐着。简文帝问：“夏侯湛作的《羊秉叙》，实在令人追想。羊秉是你什么人？有后代吗？”羊权流着泪回答：“先伯父美名早著，却没有子嗣；虽然名声传到了皇上耳中，后嗣却在这圣明之世断绝了。”简文帝为此感叹了很久。
注：羊秉：字长达，泰山平阳人，任抚军参军，三十多岁去世。
注：夏侯孝若：夏侯湛，字孝若，西晋文学家，与潘岳交好，并称“连璧”。
注：何物：什么人。
注：不：同“否”。
注：令问：美好的名声。
注：夙彰：早已显扬。
注：天听：皇帝的听闻。
注：胤（yìn）：后代。

# 六十六｜王长史与刘真长别后相见
原：王长史与刘真长别后相见，王谓刘曰：“卿更长进。”答曰：“此若‘天之自高’耳。”|| 王濛和刘惔分别后再见面，王濛对刘惔说：“你又长进了。”刘惔答道：“这就像‘天本来就高’罢了。”
注：王长史：王濛。
注：刘真长：刘惔。
注：天之自高：语出《庄子·田子方》“天之自高，地之自厚，日月之自明，夫何修焉”，意谓高明出于本性，不必刻意修为；刘惔借此自许，语带诙谐。

# 六十七｜刘尹云
原：刘尹云：“人想王荆产佳，此想长松下当有清风耳。”|| 刘惔说：“人们想象王荆产一定很出色，这就好比想象高大的松树下自然该有清风罢了。”
注：王荆产：王微，小字荆产，王澄之子，官至右军司马。
注：此句意谓王微出身名门，人们自然推想他好，如同想当然地认为长松之下必有清风；褒贬之意存疑。

# 六十八｜王仲祖闻蛮语不解
原：王仲祖闻蛮语不解，茫然曰：“若使介葛卢来朝，故当不昧此语。”|| 王濛听南方少数民族说话，一句也听不懂，茫然地说：“要是让介葛卢来朝见，大概就能听明白这些话了。”
注：王仲祖：王濛，字仲祖。
注：蛮：古代对南方少数民族的称呼。
注：介葛卢：春秋时东夷介国国君，据《左传》载能听懂牛的叫声。王濛以此自嘲，把蛮语比作兽语。
注：故当：或许、大概。
注：不昧：明白。

# 六十九｜刘真长为丹阳尹
原：刘真长为丹阳尹，许玄度出都，就刘宿，床帷新丽，饮食丰甘。许曰：“若保全此处，殊胜东山。”刘曰：“卿若知吉凶由人，吾安得不保此！”王逸少在坐，曰：“令巢、许遇稷、契，当无此言。”二人并有愧色。|| 刘惔任丹阳尹时，许询来到京城，住在刘惔那里，床铺帷帐崭新华丽，饮食丰盛可口。许询说：“若能守住这样的地方，可比在东山隐居强多了。”刘惔说：“你要是懂得吉凶祸福全在人为，我怎能不守住这一切！”王羲之当时在座，说：“假如巢父、许由遇上稷、契那样的贤臣，应当不会说这种话。”两人听了都面带愧色。
注：许玄度：许询，字玄度，东晋名士，善玄言诗，隐居不仕。
注：出都：到京城去。
注：东山：在会稽上虞，谢安隐居之地，代指隐居生活。
注：王逸少：王羲之，字逸少。
注：巢、许：巢父、许由，尧时隐士，拒不受天下。
注：稷、契：后稷、契，尧舜时贤臣。王羲之意谓真正的隐士即便遇上明主贤臣也不改其志，讽二人贪恋安乐。

# 七十｜王右军与谢太傅共登冶城
原：王右军与谢太傅共登冶城，谢悠然远想，有高世之志。王谓谢曰：“夏禹勤王，手足胼胝；文王旰食，日不暇给。今四郊多垒，宜人人自效，而虚谈废务，浮文妨要，恐非当今所宜。”谢答曰：“秦任商鞅，二世而亡，岂清言致患邪？”|| 王羲之和谢安一起登上冶城，谢安悠然神往，流露出超然世外的志趣。王羲之对谢安说：“夏禹操劳国事，手脚都磨出了老茧；周文王忙到天晚才吃饭，时间总是不够用。如今四方边境多有战事，人人都该为国效力，而空谈荒废政务，浮华的文辞妨碍要事，恐怕不合当今时势。”谢安答道：“秦国任用商鞅，传到二世就灭亡了，难道也是清谈招来的祸患吗？”
注：冶城：故址在今南京朝天宫一带，相传春秋吴王夫差曾在此冶铸。
注：胼胝（pián zhī）：手脚因劳作磨出的厚茧。
注：旰（gàn）食：天晚才进食，形容勤于政事。
注：四郊多垒：四方营垒众多，指战事频繁。
注：商鞅：战国时卫国人，在秦主持变法，以严刑峻法著称。

# 七十一｜谢太傅寒雪日内集
原：谢太傅寒雪日内集，与儿女讲论文义。俄而雪骤，公欣然曰：“白雪纷纷何所似？”兄子胡儿曰：“撒盐空中差可拟。”兄女曰：“未若柳絮因风起。”公大笑乐。即公大兄无奕女，左将军王凝之妻也。|| 一个寒冷的下雪天，谢安把家里人聚在一起，和子侄辈讲论诗文的义理。不一会儿雪下得又大又急，谢安高兴地问：“这纷纷扬扬的白雪像什么？”侄子谢朗说：“把盐撒在空中，差不多可以相比。”侄女说：“不如说是柳絮乘风飞起。”谢安开怀大笑。这位侄女就是谢安长兄谢奕的女儿，左将军王凝之的妻子。
注：内集：家人聚会。
注：儿女：泛指子侄辈。
注：胡儿：谢朗的小名，谢安之侄。
注：差可拟：大致可以比拟。
注：无奕女：谢奕字无奕，其女即谢道韫，以才思敏捷著称，后世以“咏絮之才”称才女。
注：王凝之：王羲之次子，官至左将军、会稽内史。

# 七十二｜王中郎令伏玄度
原：王中郎令伏玄度、习凿齿论青、楚人物，临成，以示韩康伯，韩康伯都无言。王曰：“何故不言？”韩曰：“无可无不可。”|| 王坦之让伏滔、习凿齿评论青州、楚地的历史人物，文章快写成时，拿给韩康伯看，韩康伯一句话也不说。王坦之问：“为什么不说话？”韩康伯说：“无所谓可，也无所谓不可。”
注：王中郎：王坦之，字文度，曾任北中郎将。
注：伏玄度：伏滔，字玄度，青州人。
注：习凿齿：字彦威，襄阳人，著《汉晋春秋》。二人各为本地人物争高下。
注：青、楚：青州与荆楚一带，分别是伏滔、习凿齿的故乡。
注：无可无不可：语出《论语·微子》，此指不偏向任何一方。
注：韩康伯：韩伯，字康伯，东晋玄学家。

# 七十三｜刘尹云
原：刘尹云：“清风朗月，辄思玄度。”|| 刘惔说：“每逢清风明月的时候，就会想念许玄度。”
注：玄度：许询，以风神清逸著称，刘惔与他交情深厚。

# 七十四｜荀中郎在京口
原：荀中郎在京口，登北固望海云：“虽未睹三山，便自使人有凌云意。若秦、汉之君，必当褰裳濡足。”|| 荀羡驻守京口时，登上北固山远望大海，说：“虽然还没看见海上三座神山，已经让人有了飘然凌云的意思。如果是秦始皇、汉武帝那样的君主，必定会提起衣裳、沾湿双脚，下海去寻仙了。”
注：荀中郎：荀羡，字令则，官北中郎将、徐州刺史，镇守京口（今江苏镇江）。
注：北固：北固山，在镇江城北，临长江。
注：三山：传说中的海上三神山，蓬莱、方丈、瀛洲。
注：褰（qiān）裳濡（rú）足：撩起衣服，沾湿双脚，指涉水入海求仙。

# 七十五｜谢公云
原：谢公云：“圣贤去人，其间亦迩。”子侄未之许。公叹曰：“若郗超闻此语，必不至河汉。”|| 谢安说：“圣贤和普通人之间的距离，其实也很近。”子侄们都不赞同。谢安叹息道：“要是郗超听到这话，一定不会认为是不着边际的空话。”
注：去：距离。
注：迩（ěr）：近。
注：未之许：不赞同这个说法。
注：河汉：银河，此指言语浩渺迂远、不着边际，语本《庄子·逍遥游》。

# 七十六｜支公好鹤
原：支公好鹤，住剡东岇山。有人遗其双鹤，少时翅长欲飞，支意惜之，乃铩其翮。鹤轩翥不复能飞，乃反顾翅垂头，视之如有懊丧意。林曰：“既有凌霄之姿，何肯为人作耳目近玩？”养令翮成，置使飞去。|| 支道林喜爱鹤，住在剡县东面的岇山。有人送给他一对鹤，不久鹤的翅膀长成，想要飞走，支道林舍不得，就剪短了它们的翅羽。鹤振翅想飞却再也飞不起来，于是回头看看翅膀，垂下了头，看上去像是很懊丧。支道林说：“它们既然有直上云霄的姿质，怎么肯给人当作眼前的玩物？”于是把鹤养到羽翎重新长好，放它们飞走了。
注：剡（shàn）：剡县，今浙江嵊州一带。
注：岇（àng）山：山名，在剡县东。
注：遗（wèi）：赠送。
注：铩（shā）：摧折、剪短。
注：翮（hé）：羽毛的硬管，代指翅羽。
注：轩翥（zhù）：振翅高飞的样子。
注：近玩：身边赏玩之物。

# 七十七｜谢中郎经曲阿后湖
原：谢中郎经曲阿后湖，问左右：“此是何水？”答曰：“曲阿湖。”谢曰：“故当渊注渟著，纳而不流。”|| 谢万经过曲阿后湖，问随从：“这是什么水？”随从回答：“曲阿湖。”谢万说：“难怪它深水汇聚、停蓄不动，只容纳而不流走。”
注：谢中郎：谢万，字万石，谢安之弟，曾任西中郎将。
注：曲阿后湖：即练湖，在今江苏丹阳。曲阿是地名，谢万借“曲”字发挥。
注：渊注渟（tíng）著（zhuó）：深水灌注，停留积聚。著，附着、停留。

# 七十八｜晋武帝每饷山涛恒少
原：晋武帝每饷山涛恒少。谢太傅以问子弟，车骑答曰：“当由欲者不多，而使与者忘少。”|| 晋武帝每次赏赐山涛，东西总是很少。谢安拿这件事问子侄们，谢玄回答说：“想必是因为接受的人所求不多，才让赐予的人忘了给得少。”
注：饷：赏赐、馈赠。
注：山涛：字巨源，“竹林七贤”之一，晋初任吏部尚书，以清廉著称。
注：车骑：谢玄，谢安之侄，淝水之战功臣，死后追赠车骑将军。

# 七十九｜谢胡儿语庾道季
原：谢胡儿语庾道季：“诸人莫当就卿谈，可坚城垒。”庾曰：“若文度来，我以偏师待之；康伯来，济河焚舟。”|| 谢朗对庾和说：“大家可能要到你这里来清谈，你可得把营垒守牢。”庾和说：“如果王坦之来，我只派一支偏师应付；如果韩康伯来，那我就要渡河烧船，决一死战了。”
注：谢胡儿：谢朗。
注：庾道季：庾龢（hé），字道季，庾亮之子，有文名。
注：莫当：或许、可能会。
注：坚城垒：加固营垒，比喻做好论辩准备。
注：文度：王坦之。
注：康伯：韩伯。
注：偏师：主力之外的部分兵力。
注：济河焚舟：语出《左传·文公三年》，渡河后烧掉船只，表示有进无退。

# 八十｜李弘度常叹不被遇
原：李弘度常叹不被遇。殷扬州知其家贫，问：“君能屈志百里不？”李答曰：“《北门》之叹，久已上闻；穷猿奔林，岂暇择木？”遂授剡县。|| 李充常常感叹自己得不到赏识。殷浩知道他家境贫寒，问他：“您肯委屈自己去做个县令吗？”李充回答：“我像《北门》诗中那样的叹息，早就让上面知道了；走投无路的猿猴逃进树林，哪还顾得上挑选树木？”于是殷浩任命他为剡县县令。
注：李弘度：李充，字弘度，东晋学者，曾编定《晋元帝四部书目》，分经史子集四部。
注：殷扬州：殷浩，曾任扬州刺史。
注：百里：古时一县辖地约百里，代指县令。
注：《北门》：《诗经·邶风》篇名，写士人仕途困顿、家境贫寒的哀叹。
注：穷猿：走投无路的猿。

# 八十一｜王司州至吴兴印渚中看
原：王司州至吴兴印渚中看，叹曰：“非唯使人情开涤，亦觉日月清朗。”|| 王胡之到吴兴的印渚游览，赞叹说：“这里不仅让人心胸开阔、尘虑涤尽，连日月也显得格外清朗。”
注：王司州：王胡之，字修龄，琅邪王氏子弟，曾被任命为司州刺史。
注：印渚：吴兴境内的水边胜地，具体所在存疑。
注：开涤：开朗洗涤，指胸怀舒畅、俗念消除。
