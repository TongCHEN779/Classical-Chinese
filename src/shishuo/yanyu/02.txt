# 二十四｜王武子、孙子荆各言其土地
原：王武子、孙子荆各言其土地人物之美。王云：“其地坦而平，其水淡而清，其人廉且贞。”孙云：“其山嶵巍以嵯峨，其水泙渫而扬波，其人磊砢而英多。”|| 王济和孙楚各自夸耀家乡的山川与人物。王济说：“我们那里地势坦荡平阔，河水淡泊清澈，人物廉洁而正直。”孙楚说：“我们那里山峦高耸、峰势险峻，河水层层翻涌、扬起波澜，人物磊落不凡、英才辈出。”
注：王武子：王济，字武子，太原晋阳人，王浑之子，晋武帝的女婿，以才辩豪奢著称。
注：孙子荆：孙楚，字子荆，太原中都人，才气高而性傲。
注：嶵（zuì）巍、嵯峨：都是山势高峻的样子。
注：泙渫（pēng dié）：水波相激、层叠涌动的样子；
注：磊砢（luǒ）：才能卓异、壮伟不凡。
# 二十五｜乐令女适大将军成都王颖
原：乐令女适大将军成都王颖，王兄长沙王执权于洛，遂构兵相图。长沙王亲近小人，远外君子，凡在朝者，人怀危惧。乐令既允朝望，加有婚亲，群小谗于长沙。长沙尝问乐令，乐令神色自若，徐答曰：“岂以五男易一女？”由是释然，无复疑虑。|| 乐广的女儿嫁给了大将军成都王司马颖，司马颖的哥哥长沙王司马乂在洛阳掌权，兄弟俩于是兵戎相见。长沙王亲近小人、疏远君子，凡是在朝为官的，人人自危。乐广本就深孚众望，又与成都王有姻亲关系，一班小人便在长沙王面前说他的坏话。长沙王曾当面质问乐广，乐广神色如常，从容答道：“我怎么会拿五个儿子去换一个女儿呢？”长沙王从此释怀，不再猜疑他。
注：乐令：乐广，字彦辅，官至尚书令，以清谈名重一时。
注：成都王颖：司马颖，晋武帝之子，封成都王；
注：长沙王：司马乂（yì），亦武帝之子。二人都是“八王之乱”中的人物。
注：构兵相图：发兵交战，互相谋夺。
注：允朝望：合乎朝野的期望，即素有声望。
# 二十六｜陆机诣王武子
原：陆机诣王武子，武子前置数斛羊酪，指以示陆曰：“卿江东何以敌此？”陆云：“有千里莼羹，但未下盐豉耳。”|| 陆机去拜访王济，王济面前摆着好几斛羊奶酪，他指给陆机看，说：“你们江东有什么能比得上这个？”陆机说：“有千里湖的莼菜羹——只是还没放盐豉罢了。”
注：陆机：字士衡，吴郡吴县人，陆逊之孙，吴亡后入洛，以文才著称。
注：斛（hú）：量器名，也作容量单位。
注：千里莼（chún）羹：千里，一说为湖名（在今江苏溧阳），一说泛指千里之地；莼菜是水生植物，嫩叶可做羹。
注：未下盐豉（chǐ）：通行本多作“末下盐豉”，“末下”或亦地名，历来解说不一，存疑。此处照书中所印作“未”。
# 二十七｜中朝有小儿
原：中朝有小儿，父病，行乞药。主人问病，曰：“患疟也。”主人曰：“尊侯明德君子，何以病疟？”答曰：“来病君子，所以为疟耳。”|| 西晋时有个小孩，父亲生了病，他出门讨药。主人问是什么病，他说：“得了疟疾。”主人说：“令尊是德行高明的君子，怎么会得疟疾呢？”小孩答道：“它专来折磨君子，所以才叫‘疟’呀。”
注：中朝：东晋人对西晋的称呼。
注：尊侯：对别人父亲的敬称。
注：疟：与“虐”同音，小孩借谐音作双关，意谓这病专来虐害君子。
# 二十八｜崔正熊诣都郡
原：崔正熊诣都郡，都郡将姓陈，问正熊：“君去崔杼几世？”答曰：“民去崔杼，如明府之去陈恒。”|| 崔豹去拜见都郡太守，太守姓陈，问崔豹：“您离崔杼有几代了？”崔豹答道：“小民离崔杼的代数，就跟您离陈恒的代数一样。”
注：崔正熊：崔豹，字正熊，西晋人，著有《古今注》。
注：都郡：以他郡太守兼领本郡军事者，一说为郡名，存疑；
注：郡将：郡太守。
注：崔杼（zhù）：春秋时齐国大夫，杀齐庄公。
注：陈恒：春秋时齐国大夫，杀齐简公。两人同为弑君之臣，崔豹以此反唇相讥。
注：明府：对太守的尊称。
# 二十九｜元帝始过江
原：元帝始过江，谓顾骠骑曰：“寄人国土，心常怀惭。”荣跪对曰：“臣闻王者以天下为家，是以耿、亳无定处，九鼎迁洛邑。愿陛下勿以迁都为念。”|| 晋元帝刚渡江南来时，对顾荣说：“寄居在别人的国土上，心里常常觉得惭愧。”顾荣跪下答道：“臣听说帝王以天下为家，所以商朝的都城在耿、亳之间迁来迁去，没有定所；九鼎也被迁到了洛邑。希望陛下不要把迁都的事放在心上。”
注：元帝：东晋元帝司马睿，西晋末南渡，后在建康称帝。
注：顾骠骑：顾荣，字彦先，江南吴郡大族，死后追赠骠骑将军。
注：耿、亳（bó）：都是商代的都城，商人曾屡次迁都。
注：九鼎：相传夏禹所铸，为传国重器，周武王灭商后迁于洛邑。
# 三十｜庾公造周伯仁
原：庾公造周伯仁，伯仁曰：“君何所欣说而忽肥？”庾曰：“君复何所忧惨而忽瘦？”伯仁曰：“吾无所忧，直是清虚日来，滓秽日去耳。”|| 庾亮去拜访周顗，周顗说：“您有什么高兴事，忽然胖了？”庾亮说：“那您又有什么愁苦事，忽然瘦了？”周顗说：“我没什么可愁的，只是清虚之气一天天进来，污浊之物一天天离去罢了。”
注：庾公：庾亮，字元规，东晋外戚重臣。
注：周伯仁：周顗（yǐ），字伯仁，东晋名士，后为王敦所杀。
注：欣说：欣悦，“说”同“悦”。
注：直：只是。
注：滓（zǐ）秽：渣滓污秽。周顗借此暗讽庾亮之胖是“浊气”所积。
# 三十一｜过江诸人
原：过江诸人，每至美日，辄相邀新亭，藉卉饮宴。周侯中坐而叹曰：“风景不殊，正自有山河之异！”皆相视流泪。唯王丞相愀然变色曰：“当共戮力王室，克复神州，何至作楚囚相对！”|| 南渡过江的那些士人，每逢风和日丽的好天气，总要相约到新亭，坐在草地上饮酒宴乐。周顗坐到半途叹息说：“风景没有什么不同，只是山河已经换了模样！”众人听了都相对流泪。只有丞相王导神色一变，说：“大家正该同心协力辅佐王室，收复中原，何至于像囚徒一样相对哭泣！”
注：新亭：在建康（今南京）城南，临江，是当时饯别宴游之地。
注：藉卉（jiè huì）：坐在草地上。卉，草的总称。
注：周侯：周顗，袭父爵为武城侯。
注：正自：只是。
注：楚囚：本指春秋时被晋国囚禁的楚人钟仪，后泛指处境窘迫、相对悲泣的人。
# 三十二｜卫洗马初欲渡江
原：卫洗马初欲渡江，形神惨顇，语左右云：“见此芒芒，不觉百端交集。苟未免有情，亦复谁能遣此！”|| 卫玠当初要渡江南下时，形容憔悴、神情凄伤，对身边的人说：“看见这茫茫江水，不由得百感交集。人只要还不能忘情，又有谁能排遣得了这种心绪呢！”
注：卫洗（xiǎn）马：卫玠，字叔宝，西晋名士，风姿秀美，官至太子洗马。
注：惨顇（cuì）：凄惨憔悴。顇，同“悴”。
注：芒芒：同“茫茫”，辽阔无边的样子。
# 三十三｜顾司空未知名
原：顾司空未知名，诣王丞相。丞相小极，对之疲睡。顾思所以叩会之，因谓同坐曰：“昔每闻元公道公协赞中宗，保全江表。体小不安，令人喘息。”丞相因觉，谓顾曰：“此子珪璋特达，机警有锋。”|| 顾和还没有出名的时候，去拜见丞相王导。王导有些疲倦，对着他就打起瞌睡来。顾和想找个办法和他攀谈，便对同座的人说：“从前常听族叔元公说，王公辅佐中宗皇帝，保全了江南。如今贵体稍有不适，真叫人焦急不安。”王导听了便醒过来，对顾和说：“这年轻人像珪璋一样出众，机灵敏捷，言辞有锋芒。”
注：顾司空：顾和，字君孝，吴郡人，顾荣族侄，官至尚书令，死后赠司空。
注：小极：有点疲惫。
注：叩会：叩问交谈，设法搭上话。
注：元公：顾荣，谥号元。
注：中宗：晋元帝的庙号。
注：江表：长江以南，从中原看在江外，故称。
注：珪璋（guī zhāng）特达：珪、璋是贵重的玉器，比喻人品才具出众。
# 三十四｜会稽贺生
原：会稽贺生，体识清远，言行以礼。不徒东南之美，实为海内之秀。|| 会稽的贺先生，禀性和识见清明高远，一言一行都合乎礼法。他不仅是东南一地的俊美人才，实在是全国的杰出人物。
注：贺生：贺循，字彦先，会稽山阴人，精通礼学，东晋初为江南士族领袖之一。生，“先生”的省称。
注：体识：禀性与见识。
# 三十五｜刘琨虽隔阂寇戎
原：刘琨虽隔阂寇戎，志存本朝，谓温峤曰：“班彪识刘氏之复兴，马援知汉光之可辅。今晋祚虽衰，天命未改，吾欲立功于河北，使卿延誉于江南，子其行乎？”温曰：“峤虽不敏，才非昔人，明公以桓、文之姿，建匡立之功，岂敢辞命！”|| 刘琨虽然被敌寇阻隔在北方，心志却始终系于晋室。他对温峤说：“当年班彪看出刘氏必将复兴，马援知道汉光武帝值得辅佐。¦如今晋朝的国运虽然衰微，天命并没有改变。我想在黄河以北建功立业，让你到江南去替我传扬声名，你愿意去吗？”¦温峤说：“我虽然不聪明，才能比不上古人，但明公有齐桓、晋文那样的气度，要建立匡复王室的功业，我怎敢推辞这个使命！”
注：刘琨：字越石，西晋末任并州刺史，长期坚守北方抗击刘渊、石勒。
注：寇戎：指北方少数民族政权的军队。
注：温峤（qiáo）：字太真，刘琨的外甥，后为东晋重臣。
注：班彪：东汉史学家，曾作《王命论》，认定汉室当复兴。
注：马援：东汉名将，初在隗嚣处，见刘秀后认定其可以辅佐。
注：桓、文：齐桓公、晋文公，春秋霸主，以尊王攘夷著称。
注：匡立：匡正扶立王室。
# 三十六｜温峤初为刘琨使来过江
原：温峤初为刘琨使来过江。于时江左营建始尔，纲纪未举。温新至，深有诸虑。既诣王丞相，陈主上幽越、社稷焚灭、山陵夷毁之酷，有黍离之痛。|| 温峤当初作为刘琨的使者渡江南来。那时江南的政权刚刚草创，法度纲纪都还没有建立起来。温峤刚到，心中有种种忧虑。拜见丞相王导后，他陈述了皇帝被俘流离、宗庙社稷被焚毁、先帝陵墓被夷平的惨状，满怀《黍离》那样的亡国之痛。
注：江左：江东，长江下游以东地区，指东晋政权所在。
注：始尔：刚刚开始。尔，语助词。
注：主上幽越：指晋怀帝、愍帝先后被匈奴汉国俘虏，囚于平阳。幽，囚禁；越，流离在外。
注：山陵：帝王陵墓。
注：黍离：《诗经·王风》篇名，旧说是周大夫见故都宫室尽为禾黍而作，后用来指亡国之悲。
原：温忠慨深烈，言与泗俱，丞相亦与之对泣。叙情既毕，便深自陈结，丞相亦厚相酬纳。既出，欢然言曰：“江左自有管夷吾，此复何忧！”|| 温峤忠诚慷慨、情深意烈，边说边流泪，王导也和他相对而泣。倾诉完心中的悲情，温峤便恳切地表达了深相结纳的意思，王导也诚挚地回应接纳了他。出来以后，温峤高兴地说：“江东自有管仲这样的人物，还有什么可担忧的！”
注：言与泗俱：话和眼泪鼻涕一起流下。泗，鼻涕，这里泛指涕泪。
注：陈结：陈述心意，表示愿意结交。
注：酬纳：应答接纳。
注：管夷吾：管仲，名夷吾，辅佐齐桓公成就霸业，这里用来比王导。
# 三十七｜王敦兄含为光禄勋
原：王敦兄含为光禄勋。敦既逆谋，屯据南州，含委职奔姑孰。王丞相诣阙谢。司徒、丞相、扬州官僚问讯，仓卒不知何辞。顾司空时为扬州别驾，援翰曰：“王光禄远避流言，明公蒙尘路次，群下不宁，不审尊体起居何如？”|| 王敦的哥哥王含任光禄勋。王敦起兵谋反后，屯驻在姑孰，王含丢下官职投奔到姑孰去了。丞相王导到宫门前请罪。司徒、丞相、扬州各府的属官们要去问候他，仓促之间不知该说些什么。顾和当时任扬州别驾，提笔写道：“王光禄远远地躲避流言，明公您却在路途上蒙受风尘，属下们都很不安，不知您的身体起居怎么样？”
注：王敦：王导的族兄，东晋初手握重兵，两次起兵攻向建康。
注：王含：王敦之兄。
注：光禄勋：官名，掌宫廷宿卫。
注：南州：指姑孰（今安徽当涂），长江重要渡口。
注：委职：弃官。
注：诣阙谢：到宫门前请罪。王导因族兄谋反而自请处分。此事所载官职、时间与史实有出入，存疑。
注：援翰：提笔。
注：蒙尘路次：在路途中奔波受苦。顾和措辞把王含出奔说成“避流言”，委婉得体。
# 三十八｜郗太尉拜司空
原：郗太尉拜司空，语同坐曰：“平生意不在多，值世故纷纭，遂至台鼎。朱博翰音，实愧于怀。”|| 郗鉴被任命为司空，对同座的人说：“我平生的志向并不高，只是碰上世事纷乱，才做到了三公的位子。就像朱博那样徒有虚声、名不副实，心里实在惭愧。”
注：郗（chī）太尉：郗鉴，字道徽，东晋重臣，历任司空、太尉。
注：世故：世事变故，指时局动荡。
注：台鼎：三公之位。台为星名，鼎为重器，都用来比喻宰辅。
注：朱博翰音：西汉朱博拜相时殿上有大声如钟鸣，被认为是空名得进的妖异。
注：“翰音”出自《周易》，指高飞的声音，喻声名超过实际。
# 三十九｜高坐道人不作汉语
原：高坐道人不作汉语。或问此意，简文曰：“以简应对之烦。”|| 高坐道人不讲汉语。有人问他这样做是什么用意，简文帝说：“是为了省掉应酬答对的麻烦。”
注：高坐道人：西域僧人帛尸梨密多罗，晋时人尊称“高坐”。道人，当时对僧人的称呼。
注：简文：晋简文帝司马昱，时为会稽王，好清谈。
注：简：省去，免掉。
# 四十｜周仆射雍容好仪形
原：周仆射雍容好仪形。诣王公，初下车，隐数人，王公含笑看之。既坐，傲然啸咏。王公曰：“卿欲希嵇、阮邪？”答曰：“何敢近舍明公，远希嵇、阮！”|| 周顗举止从容，仪表出众。他去拜访王导，刚下车，靠在几个人身上，王导含笑看着他。坐下以后，他旁若无人地长啸吟咏起来。王导说：“您是想效仿嵇康、阮籍吗？”周顗答道：“我怎敢舍弃近在眼前的明公，去仰慕远在过去的嵇康、阮籍呢！”
注：周仆射（yè）：周顗，官至尚书左仆射。
注：隐（yìn）：倚靠。
注：啸咏：撮口长啸、吟咏诗句，是魏晋名士的风尚。
注：希：仰慕、效法。
注：嵇、阮：嵇康、阮籍，竹林名士，以放达著称。
# 四十一｜庾公尝入佛图
原：庾公尝入佛图，见卧佛，曰：“此子疲于津梁。”于时以为名言。|| 庾亮曾经走进佛寺，看见一尊卧佛，说：“这位先生是因为普渡众生累倒了。”当时人们都认为这是名言。
注：佛图：佛寺，也作“浮图”。
注：卧佛：佛像的一种，表现释迦牟尼侧卧入灭之相。
注：津梁：渡口和桥梁，比喻佛接引众生出离苦海。
# 四十二｜挚瞻曾作四郡太守
原：挚瞻曾作四郡太守、大将军户曹参军，复出作内史，年始二十九。尝别王敦，敦谓瞻曰：“卿年未三十，已为万石，亦太蚤。”瞻曰：“方于将军少为太早，比之甘罗已为太老。”|| 挚瞻做过四个郡的太守和大将军府的户曹参军，后又调出去任内史，那时才二十九岁。有一次他向王敦辞别，王敦对他说：“你还不到三十岁，就已经做到万石的官了，也太早了些。”挚瞻说：“跟将军您比，是稍稍早了点；跟甘罗比，已经算太老了。”
注：挚瞻：字景游，晋人，曾任多郡太守，与王敦不和，后为王敦所杀。
注：大将军：指王敦。
注：户曹参军：将军府属官，管户籍农桑等事。
注：内史：王国中相当于太守的长官。
注：万石：郡守、内史俸禄为二千石，挚瞻历任数职，累计而称万石，含有调侃意味。
注：蚤：同“早”。
注：方：比。
注：甘罗：战国时秦人，十二岁出使赵国立功，拜为上卿。
# 四十三｜梁国杨氏子九岁
原：梁国杨氏子九岁，甚聪惠。孔君平诣其父，父不在，乃呼儿出。为设果，果有杨梅。孔指以示儿曰：“此是君家果。”儿应声答曰：“未闻孔雀是夫子家禽。”|| 梁国杨家的孩子九岁，非常聪明。孔坦来拜访他父亲，父亲不在家，便把孩子叫了出来。孩子给客人摆上果品，其中有杨梅。孔坦指着杨梅给孩子看，说：“这是你家的果子。”孩子随口答道：“没听说孔雀是先生家的鸟呀。”
注：梁国：郡国名，治所在今河南商丘一带。
注：聪惠：同“聪慧”。
注：孔君平：孔坦，字君平，会稽山阴人，东晋时官至廷尉。
注：夫子：对长辈、尊者的敬称。孔坦以“杨”姓开玩笑，孩子便以“孔”姓回敬。
# 四十四｜孔廷尉以裘与从弟沈
原：孔廷尉以裘与从弟沈，沈辞不受。廷尉曰：“晏平仲之俭，祠其先人，豚肩不掩豆，犹狐裘数十年，卿复何辞此？”于是受而服之。|| 孔坦把一件皮衣送给堂弟孔沈，孔沈推辞不肯收。孔坦说：“晏婴那样节俭，祭祀祖先时，用的猪腿小得盖不住盛器，可一件狐皮袍子还穿了几十年，你又何必推辞这件皮衣呢？”孔沈于是收下穿上了。
注：孔廷尉：孔坦。
注：从弟沈：孔沈，字德度，孔坦的堂弟。
注：晏平仲：晏婴，字平仲，春秋时齐国名相，以节俭著称。
注：豚肩不掩豆：祭祀用的猪腿小得盖不住豆。豆，古代盛肉的器皿。
注：狐裘数十年：晏子一件狐裘穿了三十年，孔坦借此说明节俭与穿裘并不矛盾。
# 四十五｜佛图澄与诸石游
原：佛图澄与诸石游，林公曰：“澄以石虎为海鸥鸟。”|| 佛图澄与石勒、石虎等人交往，支遁说：“佛图澄是把石虎当作海鸥来看待的。”
注：佛图澄：西域高僧，西晋末到洛阳，得石勒、石虎信重。
注：诸石：指后赵石勒、石虎等人。
注：林公：支遁，字道林，东晋高僧，善清谈。
注：海鸥鸟：典出《列子》：海边有人与鸥鸟相亲，鸥鸟每天成百飞来；后来他起了捉鸥之心，鸥鸟便不再落下。意谓佛图澄心无机巧，故能与暴虐的石虎相安。
# 四十六｜谢仁祖年八岁
原：谢仁祖年八岁，谢豫章将送客，尔时语已神悟，自参上流。诸人咸共叹之，曰：“年少，一坐之颜回。”仁祖曰：“坐无尼父，焉别颜回？”|| 谢尚八岁时，父亲谢鲲带他去送客，那时他谈吐已经颖悟过人，自然跻身上等人物之列。大家都赞叹他说：“小小年纪，就是这满座中的颜回啊。”谢尚说：“座中没有孔子，怎么分辨得出谁是颜回？”
注：谢仁祖：谢尚，字仁祖，谢鲲之子，东晋名士，后任镇西将军。
注：谢豫章：谢鲲，字幼舆，曾任豫章太守，好老庄。
注：将：带领。
注：神悟：领悟力超常。
注：参上流：列入上等人物之中。
注：颜回：孔子最得意的弟子。
注：尼父：对孔子的尊称。谢尚言下之意是在座诸人无一能比孔子。
# 四十七｜陶公疾笃
原：陶公疾笃，都无献替之言，朝士以为恨。仁祖闻之，曰：“时无竖刁，故不贻陶公话言。”时贤以为德音。|| 陶侃病重时，一句进谏朝政的话也没有留下，朝中官员都觉得遗憾。谢尚听说后说：“如今朝中没有竖刁那样的小人，所以陶公用不着留下遗言。”当时的贤达都认为这是好话。
注：陶公：陶侃，字士行，东晋名将，长期镇守荆州。
注：疾笃：病重。
注：献替：“献可替否”的省称，指向君主进献良策、劝止过失。
注：竖刁：齐桓公宠信的宦官，管仲临终曾劝桓公勿用此人，后果然作乱。谢尚借此称颂当朝清明。
注：贻：留下。
注：话言：遗言。
注：德音：善言。
# 四十八｜竺法深在简文坐
原：竺法深在简文坐，刘尹问：“道人何以游朱门？”答曰：“君自见其朱门，贫道如游蓬户。”或云卞令。|| 竺法深在简文帝家做客，刘惔问他：“出家人为什么要在富贵人家走动？”竺法深答道：“您自己看到的是朱门，贫僧看来，就像在草屋人家走动一样。”也有人说问话的是卞壸。
注：竺法深：东晋高僧竺道潜，字法深。
注：简文：简文帝司马昱，当时尚未即位。
注：刘尹：刘惔，字真长，曾任丹阳尹，清谈名家。
注：朱门：红漆大门，指王侯富贵之家。
注：蓬户：用蓬草编成的门，指贫寒之家。
注：卞令：卞壸（kǔn），字望之，东晋尚书令，苏峻之乱中战死。
# 四十九｜孙盛为庾公记室参军
原：孙盛为庾公记室参军，从猎，将其二儿俱行，庾公不知。忽于猎场见齐庄，时年七八岁，庾谓曰：“君亦复来邪？”应声答曰：“所谓‘无小无大，从公于迈’。”|| 孙盛做庾亮的记室参军，跟随庾亮去打猎，把两个儿子也带去了，庾亮并不知道。庾亮忽然在猎场上看见孙放，那时他才七八岁，庾亮对他说：“你也来了吗？”孙放随声答道：“这就是《诗经》里说的‘无论大小，都跟着主公出行’啊。”
注：孙盛：字安国，太原中都人，东晋史学家，著有《晋阳秋》等。
注：记室参军：幕府中掌文书的属官。
注：庾公：庾亮。
注：将：带着。
注：齐庄：孙放，字齐庄，孙盛次子。
注：无小无大，从公于迈：语出《诗经·鲁颂·泮水》，原意是百官不分大小都随鲁侯出行，这里借“小”“大”指孩子大人，借“公”指庾亮。
# 五十｜孙齐由、齐庄二人小时
原：孙齐由、齐庄二人小时诣庾公。公问齐由何字，答曰：“字齐由。”公曰：“欲何齐邪？”曰：“齐许由。”齐庄何字，答曰：“字齐庄。”公曰：“欲何齐？”曰：“齐庄周。”公曰：“何不慕仲尼而慕庄周？”对曰：“圣人生知，故难企慕。”庾公大喜小儿对。|| 孙潜、孙放兄弟俩小时候去拜见庾亮。庾亮问孙潜字什么，他答：“字齐由。”庾亮说：“想向谁看齐呢？”答：“向许由看齐。”又问孙放字什么，答：“字齐庄。”庾亮说：“想向谁看齐？”答：“向庄周看齐。”庾亮说：“为什么不仰慕孔子，却仰慕庄周呢？”孙放答道：“圣人是生来就明白事理的，所以难以企及仰慕。”庾亮非常喜欢这个小孩的回答。
注：孙齐由：孙潜，字齐由，孙盛长子。
注：齐庄：孙放。
注：许由：传说中的上古隐士，尧要让天下给他，他不肯接受。
注：庄周：庄子。
注：生知：生而知之，语本《论语》，指圣人天生明理。
注：企慕：踮起脚来仰望，指追慕。
