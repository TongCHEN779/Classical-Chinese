# 八十二｜谢万作豫州都督
原：谢万作豫州都督，新拜，当西之都邑，相送累日，谢疲顿。于是高侍中往，径就谢坐，因问：“卿今仗节方州，当疆理西蕃，何以为政？”谢粗道其意。高便为谢道形势，作数百语。谢遂起坐。高去后，谢追曰：“阿酃故粗有才具。”谢因此得终坐。|| 谢万出任豫州都督，刚受任命，要西去州治赴职，送行的人一连好几天络绎不绝，谢万累得筋疲力尽。这时侍中高崧前去，径直走到谢万身边坐下，问他：“您如今持节镇守一方，要治理西边的屏障之地，打算怎样施政？”谢万大略说了说自己的想法。高崧便替谢万分析时局形势，一口气讲了几百句话。谢万于是坐直了身子认真听。高崧走后，谢万回想起来说：“阿酃这人原来还真有些才干。”谢万也因为这番谈话提起了精神，把送行的客人一直应酬到底。
注：谢万：字万石，谢安之弟，东晋名士，升平年间任西中郎将、豫州刺史，都督数州军事。
注：高侍中：高崧，字茂琰，小字阿酃（líng），广陵人，官至侍中。
注：仗节方州：手持符节镇守一州。疆理西蕃：治理西部屏障地区，豫州在京城建康之西，故称。
注：起坐：由斜倚改为端坐，表示重视；终坐：坚持到送别结束。

# 八十三｜袁彦伯为谢安南司马
原：袁彦伯为谢安南司马，都下诸人送至濑乡。将别，既自凄惘，叹曰：“江山辽落，居然有万里之势！”|| 袁宏去做安南将军谢奉的司马，京城的朋友们一直送他到濑乡。临别之际，他本已心中凄然怅惘，于是叹道：“江山如此辽阔空远，真有万里之遥的气势啊！”
注：袁彦伯：袁宏，字彦伯，东晋文学家、史学家，著有《后汉纪》等。
注：谢安南：谢奉，曾任安南将军，故称。司马：将军府属官，掌管府中事务。
注：濑乡：地名，在今江苏溧阳一带。辽落：辽阔空旷。居然：显然，确实。

# 八十四｜孙绰赋《遂初》
原：孙绰赋《遂初》，筑室畎川，自言见止足之分。斋前种一株松，恒自手壅治之。高世远时亦邻居，语孙曰：“松树子非不楚楚可怜，但永无栋梁用耳！”孙曰：“枫柳虽合抱，亦何所施？”|| 孙绰写了《遂初赋》，在畎川盖了房子隐居，自称懂得知足知止的本分。他在书斋前种了一棵松树，常常亲手为它培土施肥。高柔当时正好和他做邻居，对孙绰说：“这小松树倒不是不秀美可爱，只可惜永远成不了栋梁之材！”孙绰回答：“枫树柳树长得再粗，粗到两手合抱，又能派上什么用场呢？”
注：孙绰：字兴公，东晋文学家，好隐逸，以文才著称。《遂初》：即《遂初赋》，抒写遂其初志、退隐山林之意。
注：畎（quǎn）川：地名，具体所在存疑。
注：止足之分：知止知足的本分，语意本于《老子》“知足不辱，知止不殆”。壅治：培土养护。
注：高世远：高柔，字世远，东晋人，与孙绰为邻。楚楚：鲜明秀美的样子。

# 八十五｜桓征西治江陵城甚丽
原：桓征西治江陵城甚丽，会宾僚出江津望之，云：“若能目此城者，有赏。”顾长康时为客在坐，目曰：“遥望层城，丹楼如霞。”桓即赏以二婢。|| 桓温把江陵城修建得十分壮丽，他召集宾客僚属来到江边渡口眺望，说：“谁能给这座城一句品题，有赏。”顾恺之当时作为客人在座，随口品题道：“远望如同昆仑层城，朱红楼阁灿若云霞。”桓温当即赏给他两名婢女。
注：桓征西：桓温，曾任征西大将军，故称。江陵：荆州治所，在今湖北。
注：江津：江边渡口。目：品评、题目。
注：顾长康：顾恺之，字长康，东晋大画家，有才绝、画绝、痴绝之称。
注：层城：传说昆仑山上的最高一重城，借以夸赞江陵。

# 八十六｜王子敬语王孝伯曰
原：王子敬语王孝伯曰：“羊叔子自复佳耳，然亦何与人事，故不如铜雀台上妓。”|| 王献之对王恭说：“羊祜固然是了不起，可他跟我们有什么相干？所以还不如铜雀台上的歌女，起码能娱人耳目。”
注：王子敬：王献之，字子敬，王羲之之子。王孝伯：王恭，字孝伯。
注：羊叔子：羊祜，字叔子，西晋名臣，镇守襄阳，为灭吴谋划。
注：铜雀台上妓：曹操临终嘱咐，让歌妓在铜雀台上按时奏乐歌舞。

# 八十七｜林公见东阳长山曰
原：林公见东阳长山曰：“何其坦迤！”|| 支道林看到东阳郡的长山，说：“多么平坦绵长啊！”
注：林公：支遁，字道林，东晋高僧，善清谈。
注：东阳：郡名，在今浙江金华一带。长山：山名。
注：坦迤（yǐ）：平坦而连绵延伸。

# 八十八｜顾长康从会稽还
原：顾长康从会稽还，人问山川之美，顾云：“千岩竞秀，万壑争流，草木蒙笼其上，若云兴霞蔚。”|| 顾恺之从会稽回来，有人问他那里山川有多美，顾恺之说：“千座山峰争奇斗秀，万道溪谷竞相奔流，草木葱茏覆盖其上，就像云气蒸腾、彩霞聚集一般。”
注：会稽：郡名，治所在今浙江绍兴，以山水秀丽著称。
注：壑：山谷，此指山间溪流。蒙笼：草木茂密覆盖的样子。
注：云兴霞蔚：云彩升腾，霞光聚集，形容景色绚丽。

# 八十九｜简文崩
原：简文崩，孝武年十余岁，立，至暝不临。左右启：“依常应临。”帝曰：“哀至则哭，何常之有！”|| 简文帝驾崩，孝武帝才十来岁，即位后到了黄昏还不去哭灵。左右侍从禀告说：“按照常礼应该去哭临了。”孝武帝说：“悲痛到了自然会哭，哪有什么常礼可言！”
注：简文：东晋简文帝司马昱。孝武：孝武帝司马曜，简文帝之子。
注：暝：黄昏。临（lìn）：帝王或尊长丧事中前往哭吊。

# 九十｜孝武将讲《孝经》
原：孝武将讲《孝经》，谢公兄弟与诸人私庭讲习。车武子难苦问谢，谓袁羊曰：“不问则德音有遗，多问则重劳二谢。”袁曰：“必无此嫌。”车曰：“何以知尔？”袁曰：“何尝见明镜疲于屡照，清流惮于惠风？”|| 孝武帝将要讲解《孝经》，谢安兄弟和其他几个人先在自家庭院里研习。车胤为难于反复向谢氏兄弟请教，对袁乔说：“不问吧，怕漏掉他们的高论；问多了吧，又太劳烦二位谢公。”袁乔说：“一定不会有这种嫌疑。”车胤问：“你怎么知道？”袁乔说：“哪里见过明镜因为常被人照而疲倦，清流因为和风吹拂而害怕的呢？”
注：谢公兄弟：谢安与其弟谢石。私庭：私宅庭院。
注：车武子：车胤，字武子，少时家贫，有囊萤夜读的故事。苦问：一再发问。
注：袁羊：袁乔，小字羊，东晋人，曾为桓温司马。按袁乔卒于穆帝时，与孝武讲经年代不合，此“袁羊”所指存疑。
注：德音：善言，指高明的见解。惠风：和风。

# 九十一｜王子敬云
原：王子敬云：“从山阴道上行，山川自相映发，使人应接不暇。若秋冬之际，尤难为怀。”|| 王献之说：“在山阴道上走，山光水色交相辉映，美景接连扑面而来，叫人看都看不过来。若是赶上秋冬之交，更让人心绪难平，难以忘怀。”
注：山阴：县名，今浙江绍兴。
注：映发：互相映衬生发。应接不暇：景物太多，来不及一一观赏。
注：难为怀：情怀难以排遣，形容感触深切。

# 九十二｜谢太傅问诸子侄
原：谢太傅问诸子侄：“子弟亦何预人事，而正欲使其佳？”诸人莫有言者，车骑答曰：“譬如芝兰玉树，欲使其生于阶庭耳。”|| 谢安问子侄们：“子弟们与我们自身有什么相干，为什么偏偏希望他们优秀出众呢？”大家都没有说话，谢玄回答说：“就像芝兰玉树，人们总希望它们长在自家的阶前庭院里罢了。”
注：谢太傅：谢安，死后追赠太傅。预：干预，相关。
注：车骑：谢玄，谢安之侄，死后追赠车骑将军，淝水之战的主将之一。
注：芝兰玉树：香草和美玉般的树，比喻优秀的子弟。

# 九十三｜道壹道人好整饰音辞
原：道壹道人好整饰音辞。从都下还东山，经吴中。已而会雪下，未甚寒，诸道人问在道所经。壹公曰：“风霜固所不论，乃先集其惨澹；郊邑正自飘瞥，林岫便已皓然。”|| 道壹和尚喜欢修饰辞藻、讲究音韵。他从京城回东山，途经吴郡。不久正赶上下雪，天还不算太冷，和尚们问他一路上的见闻。道壹说：“风霜自然不必说了，先是天色聚起一片阴沉暗淡；城郊城内刚刚雪花飘飞，远处林木山峦便已一片洁白。”
注：道壹：东晋僧人，俗姓陆，以文辞见长。整饰：修饰整理。
注：东山：在今浙江上虞，谢安曾隐居于此。吴中：吴郡一带，今江苏苏州。
注：集其惨澹：聚集起阴暗的天色，化用《诗经·小雅·頍弁》“先集维霰”句意。
注：飘瞥：雪花飘飞闪动。林岫（xiù）：树林与山峰。皓然：洁白的样子。

# 九十四｜张天锡为凉州刺史
原：张天锡为凉州刺史，称制西隅。既为苻坚所禽，用为侍中。后于寿阳俱败，至都，为孝武所器。每入言论，无不竟日。颇有嫉己者，于坐问张：“北方何物可贵？”张曰：“桑椹甘香，鸱鸮革响。淳酪养性，人无嫉心。”|| 张天锡任凉州刺史，在西部边陲自立为君。后来被苻坚俘虏，被任用为侍中。苻坚在寿阳大败时，他也随之归晋，来到京城，受到孝武帝的器重。他每次入宫谈论，没有不谈上一整天的。有不少人嫉妒他，有人在座上问张天锡：“北方有什么值得珍贵的东西？”张天锡说：“桑椹甘甜芳香，鸱鸮也改了恶声。醇厚的奶酪滋养性情，人们没有嫉妒之心。”
注：张天锡：前凉末代君主，后降前秦，淝水之战后归东晋。称制：行使帝王权力。西隅：西部边地，指凉州。
注：苻坚：前秦国君，淝水之战败于东晋。禽：同“擒”。寿阳：今安徽寿县，淝水之战发生地附近。
注：鸱鸮（chī xiāo）革响：猫头鹰改变叫声。化用《诗经·鲁颂·泮水》鸮食桑椹而“怀我好音”之意，暗讽在座者不如北方的恶鸟能变好。
注：淳酪：醇厚的奶酪。末句反讽嫉妒者。

# 九十五｜顾长康拜桓宣武墓
原：顾长康拜桓宣武墓，作诗云：“山崩溟海竭，鱼鸟将何依。”人问之曰：“卿凭重桓乃尔，哭之状其可见乎？”顾曰：“鼻如广莫长风，眼如悬河决溜。”或曰：“声如震雷破山，泪如倾河注海。”|| 顾恺之去祭拜桓温的墓，作诗说：“高山崩塌，大海枯竭，鱼儿鸟儿将依靠什么？”有人问他：“你这样倚重桓公，哭他时是什么样子，能说给我们听听吗？”顾恺之说：“鼻息如同旷野上的长风，眼泪好像悬河决口奔泻。”另一种说法是：“哭声如惊雷震破山岳，眼泪像倾倒的大河注入大海。”
注：桓宣武：桓温，谥宣武。顾恺之曾为其参军，受其器重。
注：溟海：大海。凭重：依靠、倚重。
注：广莫：辽阔空旷，语出《庄子》“广莫之野”。悬河决溜：瀑布般急流决口而下。

# 九十六｜毛伯成既负其才气
原：毛伯成既负其才气，常称：“宁为兰摧玉折，不作萧敷艾荣。”|| 毛玄自负才华意气，常常说：“宁可做被摧折的兰草、被击碎的美玉，也不做开花繁茂的蒿草艾草。”
注：毛伯成：毛玄，字伯成，东晋人，官至征西行军参军。
注：兰摧玉折：比喻高洁之士宁可受摧残而死。
注：萧敷艾荣：蒿艾开花繁茂，比喻庸人小人得志荣显。萧、艾皆为贱草。

# 九十七｜范甯作豫章
原：范甯作豫章，八日请佛有板，众僧疑，或欲作答。有小沙弥在坐末，曰：“世尊默然，则为许可。”众从其义。|| 范甯任豫章太守时，四月初八那天迎请佛像，还写了一份请佛的文书，僧人们犹豫不定，有人想写文书答复。座位末尾有个小沙弥说：“世尊沉默不语，就是表示许可了。”大家都依从了他的意见。
注：范甯：字武子，东晋经学家，曾任豫章太守，著《春秋穀梁传集解》。豫章：郡名，治所在今江西南昌。
注：八日：农历四月初八，相传为佛诞日，寺院举行浴佛等法会。
注：板：写在木板上的文书，此指请佛的文书。
注：沙弥：初出家受十戒的小僧。世尊：佛教徒对释迦牟尼的尊称。佛经中常以“默然”表示应允。

# 九十八｜司马太傅斋中夜坐
原：司马太傅斋中夜坐，于时天月明净，都无纤翳，太傅叹以为佳。谢景重在坐，答曰：“意谓乃不如微云点缀。”太傅因戏谢曰：“卿居心不净，乃复强欲滓秽太清邪？”|| 司马道子夜里在书斋中闲坐，当时天空晴朗，月色明净，没有一丝云彩遮掩，司马道子赞叹景色真美。谢重在座，接话说：“依我看，倒不如有些淡云点缀一下更好。”司马道子于是跟他开玩笑说：“你心地不干净，竟还想硬把这清澈的天空弄脏吗？”
注：司马太傅：司马道子，简文帝之子，孝武帝之弟，封会稽王，专擅朝政。
注：纤翳（yì）：一丝遮蔽，指微云。
注：谢景重：谢重，字景重，谢朗之子，曾为司马道子长史。
注：滓（zǐ）秽：污染。太清：天空。

# 九十九｜王中郎甚爱张天锡
原：王中郎甚爱张天锡，问之曰：“卿观过江诸人，经纬江左轨辙，有何伟异？后来之彦，复何如中原？”张曰：“研求幽邃，自王、何以还；因时修制，荀、乐之风。”王曰：“卿知见有余，何故为苻坚所制？”答曰：“阳消阴息，故天步屯蹇，否剥成象，岂足多讥？”|| 王中郎很喜爱张天锡，问他：“你看渡江南来的这些人，他们治理江东的法度有什么特别出众的地方？后起的俊彦，与中原人物相比又如何？”张天锡说：“钻研深奥的义理，自王弼、何晏以来就是如此；依照时势修订制度，有荀顗、乐广的遗风。”王中郎说：“你的见识绰绰有余，为什么会被苻坚制服？”张天锡回答：“阳气消退、阴气增长，所以国运艰难；否卦、剥卦的征象已经显现，这又哪里值得多加讥笑呢？”
注：王中郎：一般认为指王坦之，但王坦之卒于张天锡归晋之前，所指何人存疑。
注：经纬：治理、谋划。江左：江东，东晋所辖地区。轨辙：车辙，引申为法度规则。彦：才德出众的人。
注：王、何：王弼、何晏，魏正始玄学代表人物。荀、乐：一般解作荀顗、荀勖与乐广，所指存疑。
注：阳消阴息：阳衰阴长。天步：国运。屯（zhūn）蹇（jiǎn）、否（pǐ）剥：均为《周易》卦名，象征艰难阻塞、衰落。

# 一百｜谢景重女适王孝伯儿
原：谢景重女适王孝伯儿，二门公甚相爱美。谢为太傅长史，被弹，王即取作长史，带晋陵郡。太傅已构嫌孝伯，不欲使其得谢，还取作咨议，外示絷维，而实以乖间之。|| 谢重的女儿嫁给王恭的儿子，两家的家长彼此十分欣赏。谢重任司马道子的长史，遭到弹劾，王恭随即聘他为自己的长史，并兼任晋陵太守。司马道子早已与王恭结下怨隙，不想让王恭得到谢重，就又把谢重召回来任咨议参军，表面上是挽留重用人才，实际上是借此离间他们二人。
注：谢景重：谢重。适：女子出嫁。王孝伯：王恭，东晋外戚，后起兵反对司马道子，兵败被杀。
注：太傅：司马道子。带：兼领。晋陵郡：治所在今江苏镇江一带。
注：咨议：咨议参军，王府中掌参谋的官。絷（zhí）维：拴住马留下来，语出《诗经·小雅·白驹》，比喻挽留贤才。乖间：离间。
原：及孝伯败后，太傅绕东府城行散，僚属悉在南门，要望候拜。时谓谢曰：“王宁异谋，云是卿为其计。”谢曾无惧色，敛笏对曰：“乐彦辅有言：‘岂以五男易一女。’”太傅善其对，因举酒劝之曰：“故自佳，故自佳。”|| 等到王恭兵败以后，司马道子绕着东府城散步行药，僚属们都在南门迎候拜见。司马道子当时对谢重说：“王宁谋反，听说是你替他出的主意。”谢重竟毫无惧色，收起手板回答说：“乐广说过：‘难道会拿五个儿子去换一个女儿吗？’”司马道子很赞赏他的回答，于是举杯劝他喝酒，说：“说得真好，说得真好。”
注：东府城：建康城东的府城，为宰辅所居。行散：服五石散后步行以散发药力，魏晋风习。
注：要（yāo）望：迎候。王宁：王恭小字阿宁，故称。
注：曾：竟然。敛笏（hù）：收拢手板，表示恭敬。
注：乐彦辅：乐广，字彦辅。其女嫁成都王司马颖，长沙王疑之，乐广答以“岂以五男易一女”，表明不会因亲家而连累全家；谢重借此言自己不会为女儿的公公王恭谋划。

# 一百零一｜桓玄义兴还后
原：桓玄义兴还后，见司马太傅，太傅已醉，坐上多客，问人云：“桓温来欲作贼，如何？”桓玄伏不得起。谢景重时为长史，举板答曰：“故宣武公黜昏暗，登圣明，功超伊、霍，纷纭之议，裁之圣鉴。”太傅曰：“我知，我知。”即举酒云：“桓义兴，劝卿酒！”桓出谢过。|| 桓玄从义兴回来后，去拜见司马道子。司马道子已经喝醉了，座上客人很多，他问众人说：“桓温晚年想要造反，是不是这样？”¦桓玄吓得伏在地上起不来。¦谢重当时任长史，举起手板回答说：“已故的宣武公废黜昏庸之君，拥立圣明之主，功劳超过伊尹、霍光。那些纷纷扰扰的议论，还请您圣明裁断。”¦司马道子说：“我知道，我知道。”¦随即举杯说：“桓义兴，敬你一杯！”¦桓玄离席向司马道子谢罪。
注：桓玄：桓温之子，曾任义兴太守，后篡晋自立。义兴：郡名，治所在今江苏宜兴。
注：作贼：谋反。
注：宣武公：桓温。黜昏暗，登圣明：指桓温废海西公司马奕，拥立简文帝。
注：伊、霍：伊尹、霍光，均有废立君主而安定国家的事迹。圣鉴：对尊者明察的敬称。

# 一百零二｜宣武移镇南州
原：宣武移镇南州，制街衢平直。人谓王东亭曰：“丞相初营建康，无所因承，而制置纡曲，方此为劣。”东亭曰：“此丞相乃所以为巧。江左地促，不如中国。若使阡陌条畅，则一览而尽；故纡余委曲，若不可测。”|| 桓温移镇姑孰，把街道修得平坦笔直。有人对王珣说：“丞相王导当初营建建康时，没有现成的规制可以沿袭，所以街道设计得弯弯曲曲，和南州相比就差了。”王珣说：“这正是丞相的巧妙之处。江东地方狭小，比不上中原。如果让街道笔直通畅，一眼就望到头了；所以故意修得迂回曲折，让人觉得深不可测。”
注：南州：姑孰，在今安徽当涂，位于建康之南。制：修建。街衢（qú）：街道。
注：王东亭：王珣，王导之孙，封东亭侯。丞相：王导，东晋开国重臣，主持营建建康。
注：因承：沿袭继承。方：比较。地促：地域狭小。中国：指中原。
注：阡陌：本指田间小路，此指街道。纡余委曲：迂回曲折。

# 一百零三｜桓玄诣殷荆州
原：桓玄诣殷荆州，殷在妾房昼眠，左右辞不之通。桓后言及此事，殷云：“初不眠，纵有此，岂不以‘贤贤易色’也？”|| 桓玄去拜访殷仲堪，殷仲堪正在小妾房中睡午觉，侍从推辞不给桓玄通报。桓玄后来谈起这件事，殷仲堪说：“我当时根本没睡；即使真有这回事，难道我就不能看重贤人而轻视女色吗？”
注：殷荆州：殷仲堪，曾任荆州刺史。
注：不之通：不为他通报。初：根本，全然。
注：贤贤易色：语出《论语·学而》，意为尊重贤人而看轻女色；殷仲堪借以表示若知桓玄来，必舍妾房而相见。

# 一百零四｜桓玄问羊孚
原：桓玄问羊孚：“何以共重吴声？”羊曰：“当以其妖而浮。”|| 桓玄问羊孚：“为什么大家都看重吴地的歌曲？”羊孚说：“大概是因为它妖娆婉媚、轻浮流荡吧。”
注：羊孚：字子道，东晋人，有文才，为桓玄所赏识。
注：吴声：江南吴地的民歌，多咏男女之情，今存于《乐府诗集》。
注：妖而浮：妖冶婉丽而轻柔浮艳。

# 一百零五｜谢混问羊孚
原：谢混问羊孚：“何以器举瑚琏？”羊曰：“故当以为接神之器。”|| 谢混问羊孚：“孔子用‘器’来比喻子贡时，为什么偏偏举出瑚琏？”羊孚说：“自然是因为瑚琏是用来祭祀接引神灵的器物啊。”
注：谢混：字叔源，谢安之孙，娶晋陵公主，以诗文著称，后为刘裕所杀。
注：瑚琏：宗庙中盛黍稷的贵重礼器。《论语·公冶长》中孔子说子贡是“器”，又说是“瑚琏”。
注：接神之器：祭祀时供奉神灵所用的器物，暗示子贡虽为“器”，却是最尊贵的一种。

# 一百零六｜桓玄既篡位后
原：桓玄既篡位后，御床微陷，群臣失色。侍中殷仲文进曰：“当由圣德渊重，厚地所以不能载。”时人善之。|| 桓玄篡位以后，他的御座微微下陷，群臣都大惊失色。侍中殷仲文上前说：“这应当是由于圣上德行深厚沉重，连厚实的大地也承载不起了。”当时人都称赞他说得巧妙。
注：篡位：桓玄于元兴二年（403）废晋安帝，自立为帝，国号楚，不久败亡。
注：御床：皇帝的坐榻。
注：殷仲文：殷仲堪的堂弟，桓玄的姐夫，以文才著称，为桓玄所用。渊重：深厚。

# 一百零七｜桓玄既篡位
原：桓玄既篡位，将改置直馆，问左右：“虎贲中郎省应在何处？”有人答曰：“无省。”当时殊忤旨。问：“何以知无？”答曰：“潘岳《秋兴赋叙》曰：‘余兼虎贲中郎将，寓直散骑之省。’”玄咨嗟称善。|| 桓玄篡位以后，打算重新安排值班的官署，问身边的人：“虎贲中郎将的官署应该设在哪里？”有人回答：“没有这个官署。”这话在当时很不合桓玄的心意。桓玄问：“你凭什么知道没有？”那人答道：“潘岳《秋兴赋》的序里说：‘我兼任虎贲中郎将，借住在散骑常侍的官署里值班。’”桓玄听了连声赞叹说好。
注：直馆：值班的馆舍。直，同“值”。
注：虎贲中郎：虎贲中郎将，统领宫廷卫士的武官。省：官署。忤旨：违逆上意。
注：潘岳：字安仁，西晋文学家，作《秋兴赋》，序中自述寓直之事。寓直：寄居在别的官署值班。散骑：散骑常侍，侍从皇帝左右的官。

# 一百零八｜谢灵运好戴曲柄笠
原：谢灵运好戴曲柄笠，孔隐士谓曰：“卿欲希心高远，何不能遗曲盖之貌？”谢答曰：“将不畏影者未能忘怀？”|| 谢灵运喜欢戴一种带弯柄的斗笠，隐士孔淳之对他说：“你想让心志高洁旷远，为什么还丢不掉这曲柄伞盖似的样子呢？”谢灵运回答说：“莫非是像那个害怕影子的人一样，您自己还没能忘掉形迹吧？”
注：谢灵运：谢玄之孙，袭封康乐公，南朝宋诗人，山水诗的开创者。曲柄笠：带弯柄的斗笠，形似官员出行所用的曲柄伞盖。
注：孔隐士：孔淳之，字彦深，南朝宋人，隐居不仕。希心：仰慕、追求之心。遗：舍弃。
注：将不：莫非，恐怕。畏影者：《庄子·渔父》中有人怕自己的影子和足迹，拼命奔跑想摆脱，终于力竭而死。谢灵运以此反讥孔淳之执着于外表形迹。
