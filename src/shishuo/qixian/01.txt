# 本门导读
题解：“企羡”是仰慕、羡慕。本门六则，有人仰慕时贤风度，有人以被比作古人为荣，看重的多是气度神采而非外表，可见当时士人的审美与追求。

# 一｜王丞相拜司空
原：王丞相拜司空，桓廷尉作两髻、葛裙、策杖，路边窥之，叹曰：“人言阿龙超，阿龙故自超。”不觉至台门。|| 王导被任命为司空，桓彝梳着两个发髻，穿着葛布裙，拄着手杖，在路边偷偷看他，赞叹道：“人们都说阿龙出众超群，阿龙果然就是超群出众。”不知不觉一路跟着走到了台门。
注：王丞相：王导，字茂弘，东晋开国重臣，历仕三朝。
注：司空：三公之一。
注：桓廷尉：桓彝，字茂伦，桓温之父，善于品鉴人物，死后追赠廷尉。
注：阿龙：王导的小名。
注：故自：本来就是。
注：台门：朝廷官署的大门。

# 二｜王丞相过江
原：王丞相过江，自说昔在洛水边，数与裴成公、阮千里诸贤共谈道。羊曼曰：“人久以此许卿，何须复尔？”王曰：“亦不言我须此，但欲尔时不可得耳！”|| 王导渡江以后，常说起从前在洛水边，多次和裴頠、阮瞻诸位贤士一起谈论玄理。羊曼说：“人们早就因为这个称许你了，何必还要一再提起呢？”王导说：“我也不是说需要借这个抬高自己，只是那样的时光再也找不回来了啊！”
注：过江：西晋末年中原大乱，士族纷纷渡江南下。
注：数（shuò）：屡次。
注：裴成公：裴頠，字逸民，谥成，西晋名士，著有《崇有论》。
注：阮千里：阮瞻，字千里，阮咸之子，善谈玄理。
注：羊曼：字祖延，东晋名士，性情旷达。
注：许：称许，推重。
注：尔时：那个时候。

# 三｜王右军得人以《兰亭集序》
原：王右军得人以《兰亭集序》方《金谷诗序》，又以己敌石崇，甚有欣色。|| 王羲之听说有人把他的《兰亭集序》比作《金谷诗序》，又把他本人和石崇相提并论，脸上露出很高兴的神色。
注：王右军：王羲之，曾任右军将军。
注：《兰亭集序》：永和九年上巳日，王羲之与谢安等人修禊于会稽兰亭，饮酒赋诗，他为诗集作序。
注：方：比拟。
注：《金谷诗序》：西晋石崇在洛阳金谷园宴集宾客赋诗，并为诗集作序。
注：敌：相当，匹敌。

# 四｜王司州先为庾公记室参军
原：王司州先为庾公记室参军，后取殷浩为长史。始到，庾公欲遣王使下都。王自启求住曰：“下官希见盛德，渊源始至，犹贪与少日周旋。”|| 王胡之起先担任庾亮的记室参军，后来庾亮又聘殷浩做长史。殷浩刚到任，庾亮想派王胡之出使京都。王胡之自己请求留下来，说：“下官平时难得见到德望隆盛的人物，渊源刚刚到来，还想多跟他相处几天。”
注：王司州：王胡之，字修龄，曾任司州刺史。
注：庾公：庾亮，东晋外戚重臣。
注：记室参军：掌管文书表章的属官。
注：长史：府中僚属之长。
注：下都：东下到京城建康。
注：启：陈述，禀告。
注：住：留下。
注：渊源：殷浩的字，以善清谈知名。
注：周旋：交往相处。

# 五｜郗嘉宾得人以己比苻坚
原：郗嘉宾得人以己比苻坚，大喜。|| 郗超听说有人把自己比作苻坚，非常高兴。
注：郗嘉宾：郗超，字景兴，小字嘉宾，郗愔之子，是桓温的主要谋士。
注：苻坚：前秦君主，雄才大略，一度统一北方。郗超以此自喜，或因被看作有经略天下之才，存疑。

# 六｜孟昶未达时
原：孟昶未达时，家在京口。尝见王恭乘高舆，被鹤氅裘。于时微雪，昶于篱间窥之，叹曰：“此真神仙中人！”|| 孟昶还没有发迹的时候，家住京口。他曾经看见王恭坐着高车，披着鹤氅裘。当时正飘着小雪，孟昶从篱笆缝里偷看，赞叹道：“这真是神仙一样的人物啊！”
注：孟昶（chǎng）：字彦达，东晋末人，后随刘裕起兵讨桓玄，官至尚书左仆射。
注：达：显达。
注：京口：今江苏镇江，东晋军事重镇。
注：王恭：字孝伯，东晋外戚，以风姿清美著称。
注：高舆：高大的车。
注：被（pī）：同“披”。
注：鹤氅（chǎng）裘：用鸟羽织成的外衣。
