# 本门导读
题解：“黜免”是罢官、贬斥。本门记的是士人在宦途上的失意：有的蒙冤被逐，有的因过被罢，有的失势后满腹怨愤，从中可见魏晋政局的动荡与仕途的凶险无常。

# 一｜诸葛厷在西朝
原：诸葛厷在西朝，少有清誉，为王夷甫所重，时论亦以拟王。后为继母族党所谗，诬之为狂逆。将远徙，友人王夷甫之徒诣槛车与别。厷问：“朝廷何以徙我？”王曰：“言卿狂逆。”厷曰：“逆则应杀，狂何所徙？”|| 诸葛厷在西晋时，年少便有清高的名声，受到王衍的器重，当时舆论也把他和王衍相提并论。后来他被继母家族的人诬陷，说他狂放悖逆。将要流放远方时，朋友王衍等人到囚车前和他告别。诸葛厷问：“朝廷凭什么流放我？”王衍说：“说你又狂又逆。”诸葛厷说：“若是逆，就该杀头；若只是狂，又凭什么流放？”
注：诸葛厷（gōng）：字茂远，西晋琅邪人，有才名。西朝：指西晋，相对于东晋而言。
注：王夷甫：王衍，字夷甫，西晋清谈领袖，位至宰辅。拟：比拟。
注：族党：同族亲属。槛（jiàn）车：押送犯人的囚车。
注：徙（xǐ）：流放。

# 二｜桓公入蜀至三峡中
原：桓公入蜀，至三峡中，部伍中有得猿子者，其母缘岸哀号，行百余里不去，遂跳上船，至便即绝。破视其腹中，肠皆寸寸断。公闻之怒，命黜其人。|| 桓温领兵入蜀，到了三峡一带，队伍中有人捉到一只小猿，母猿沿着江岸哀号，跟着走了一百多里都不肯离开，最后跳上船来，一落到船上就断了气。剖开它的肚子一看，肠子都一寸一寸地断了。桓温听说后大怒，下令罢免了那个人。
注：桓公：桓温，字元子，东晋权臣。入蜀：桓温于永和年间西征，灭成汉。
注：部伍：军中队伍。猿子：小猿。缘岸：沿着江岸。
注：黜：罢免。此事即“肝肠寸断”一语的来历之一。

# 三｜殷中军被废在信安
原：殷中军被废，在信安，终日恒书空作字，扬州吏民寻义逐之，窃视，唯作“咄咄怪事”四字而已。|| 殷浩被废为平民后，住在信安，整天用手指在空中写字。扬州的官吏百姓想弄清他写的是什么，跟在后面偷看，原来只写着“咄咄怪事”四个字罢了。
注：殷中军：殷浩，字渊源，曾任中军将军、扬州刺史，北伐失败后被桓温奏请废为庶人。
注：信安：县名，在今浙江衢州一带。书空：以手指在空中比画写字。
注：寻义：探求其中的意思。咄（duō）咄：惊叹声，表示事出意外、难以理解。

# 四｜桓公坐有参军椅烝薤
原：桓公坐有参军椅烝薤，不时解，共食者又不助，而椅终不放，举坐皆笑。桓公曰：“同盘尚不相助，况复危难乎？”敕令免官。|| 桓温的宴席上，有位参军用筷子夹蒸薤，薤叶粘连，一时夹不开，同盘吃饭的人又不帮他一把，他却始终夹着不放，满座的人都笑了。桓温说：“同吃一盘菜尚且不肯相助，何况遇到危难呢？”下令罢免了那个同盘人的官职。
注：桓公：桓温。参军：将军府中的僚属。
注：椅：此处应作“掎”（jǐ），牵引，指用筷子夹取。书中原作“椅”，照录。
注：烝薤（xiè）：蒸熟的薤。烝，同“蒸”。薤，一种多年生草本植物，叶细长，鳞茎可食。
注：不时解：一时分不开。况复：何况。敕令：下令。

# 五｜殷中军废后恨简文
原：殷中军废后，恨简文曰：“上人著百尺楼上，儋梯将去。”|| 殷浩被废以后，怨恨简文帝，说：“把人送上百尺高楼，却扛起梯子走了。”
注：殷中军：殷浩。简文：司马昱，当时以会稽王辅政，后即位为简文帝，殷浩出任北伐系出其意。
注：著（zhuó）：放置。儋（dān）：同“担”，扛。将去：拿走。

# 六｜邓竟陵免官后赴山陵
原：邓竟陵免官后赴山陵，过见大司马桓公。公问之曰：“卿何以更瘦？”邓曰：“有愧于叔达，不能不恨于破甑。”|| 邓遐被免官后，去参加皇帝的葬礼，顺路拜访大司马桓温。桓温问他：“你怎么更瘦了？”邓遐说：“比起孟叔达我很惭愧，我做不到对打破的甑毫不挂怀。”
注：邓竟陵：邓遐，字应远，曾任竟陵太守，以勇武著称，为桓温所免官。
注：山陵：帝王的陵墓，此指帝王的葬礼。过见：顺路拜访。
注：叔达：孟敏，字叔达，东汉人。他背着的甑落地摔破，他头也不回地走了，说“甑已经破了，看它有什么用”。
注：甑（zèng）：古代蒸饭的瓦器。此借破甑比喻已丢掉的官职。

# 七｜桓宣武既废太宰父子
原：桓宣武既废太宰父子，仍上表曰：“应割近情，以存远计。若除太宰父子，可无后忧。”简文手答表曰：“所不忍言，况过于言？”宣武又重表，辞转苦切。简文更答曰：“若晋室灵长，明公便宜奉行此诏；如大运去矣，请避贤路。”桓公读诏，手战流汗，于此乃止。太宰父子远徙新安。|| 桓温罢免了太宰司马晞父子之后，又上表说：“应当割舍亲属之情，来保全长远之计。如果除掉太宰父子，就可以没有后患了。”简文帝亲笔批答说：“这是我连说都不忍说的话，何况做出比说更过分的事呢？”桓温再次上表，言辞更加恳切急迫。简文帝又批答说：“如果晋朝国运绵长，您就应当遵行这道诏书；如果晋朝气数已尽，就请让我退位，给贤者让路。”桓温读了诏书，手发抖，直冒汗，这件事才就此作罢。太宰父子被远远流放到新安。
注：桓宣武：桓温，谥宣武。太宰父子：司马晞及其子司马综。司马晞是简文帝之兄，官至太宰，好武，为桓温所忌。
注：近情：骨肉亲情。手答：亲笔批答。
注：灵长：绵延长久。避贤路：让出贤者进身之路，即退位。
注：战：发抖。新安：郡名，在今浙江淳安一带。

# 八｜桓玄败后殷仲文
原：桓玄败后，殷仲文还为大司马咨议，意似二三，非复往日。大司马府听前有一老槐，甚扶疏。殷因月朔，与众在听，视槐良久，叹曰：“槐树婆娑，无复生意！”|| 桓玄失败以后，殷仲文回到朝廷，担任大司马府的咨议参军，心神不定，不再像往日那样了。大司马府厅堂前有一棵老槐树，枝叶纷披。殷仲文趁着初一，和众人聚在厅中，望着槐树看了很久，叹息说：“槐树枝叶婆娑，再没有生机了！”
注：桓玄：桓温之子，晋安帝时篡位称帝，国号楚，不久为刘裕所败被杀。
注：殷仲文：桓玄的姐夫，曾附桓玄，后归朝廷，终为刘裕所杀，有文才。咨议：咨议参军，幕府属官。
注：二三：三心二意，心神不定。听：同“厅”。扶疏：枝叶分披的样子。
注：月朔：每月初一。婆娑：枝叶纷披摇曳。生意：生机。此语借老槐自伤失意。

# 九｜殷仲文既素有名望
原：殷仲文既素有名望，自谓必当阿衡朝政。忽作东阳太守，意甚不平，及之郡，至富阳，慨然叹曰：“看此山川形势，当复出一孙伯符。”|| 殷仲文向来有名望，自认为一定会执掌朝政、辅佐君主。¦忽然被派去做东阳太守，心里很不服气。赴任途中到了富阳，感慨地叹息道：“看这里的山川形势，该会再出一个孙伯符吧。”
注：阿（ē）衡：商朝伊尹的称号，后泛指辅政大臣，此作动词，意为主持朝政。
注：东阳：郡名，在今浙江金华一带。之郡：前往郡治赴任。
注：富阳：今浙江杭州富阳，是孙策的家乡。
注：孙伯符：孙策，字伯符，孙坚之子，平定江东，奠定东吴基业。言下流露出不臣之心。
