# 本门导读
题解：“文学”原为孔门四科之一，本门所记多是汉末至东晋的学术与清谈逸事：经学注疏、玄理辩难、佛理讲论，以及诗文才思，可见魏晋学风之盛与名士言谈之妙。

# 一｜郑玄在马融门下
原：郑玄在马融门下，三年不得相见，高足弟子传授而已。尝算浑天不合，诸弟子莫能解。或言玄能者，融召令算，一转便决，众咸骇服。|| 郑玄在马融门下求学，三年都没能见上老师一面，只由马融的高徒转授学业。有一次马融用浑天仪推算天象，结果对不上，弟子们谁也解决不了。有人说郑玄能算，马融便叫他来推算，他把算具一转就解决了，众人都惊叹佩服。
注：郑玄：字康成，北海高密人，东汉经学大师，遍注群经。
注：马融：字季长，扶风茂陵人，东汉著名经学家，门生众多。
注：浑天：指浑天仪推算日月星辰的方法；不合，指算出的结果与实际不符。
原：及玄业成辞归，既而融有“礼乐皆东”之叹，恐玄擅名而心忌焉。玄亦疑有追，乃坐桥下，在水上据屐。融果转式逐之，告左右曰：“玄在土下水上而据木，此必死矣。”遂罢追。玄竟以得免。|| 等郑玄学成告辞回乡，不久马融就感叹“礼乐的学问都随他东去了”，担心郑玄名声盖过自己，心中生出忌恨。郑玄也料到会有人追来，就坐在桥底下，踩着木屐浮在水面上。马融果然转动式盘占卜他的去向，对左右说：“郑玄在土之下、水之上，又倚靠着木头，这是必死之兆。”于是不再追赶。郑玄竟因此脱身。
注：礼乐皆东：郑玄家在马融家乡之东，意谓学问的精髓被他带走了。
注：据屐：踩着、倚着木屐。据，凭靠。
注：式：古代占卜用的器具，上圆下方，可以转动推算。此事近于传说，未必可信。

# 二｜郑玄欲注《春秋传》
原：郑玄欲注《春秋传》，尚未成。时行与服子慎遇，宿客舍。先未相识，服在外车上与人说己注《传》意，玄听之良久，多与己同。玄就车与语曰：“吾久欲注，尚未了。听君向言，多与吾同，今当尽以所注与君。”遂为《服氏注》。|| 郑玄想给《左传》作注，还没完成。一次外出时与服虔相遇，同住在一家客店里。两人先前并不认识，服虔在外面车上跟别人讲自己注《左传》的见解，郑玄听了很久，发现大多与自己的看法相同。郑玄便走到车边对他说：“我早就想注这部书，至今没有完成。听您刚才所说，多与我相合，现在我把所作的注全部送给您。”于是有了《服氏注》。
注：《春秋传》：此指《春秋左氏传》。
注：服子慎：服虔，字子慎，东汉经学家，著有《春秋左氏传解谊》。
注：向：刚才。

# 三｜郑玄家奴婢皆读书
原：郑玄家奴婢皆读书。尝使一婢，不称旨，将挞之，方自陈说，玄怒，使人曳著泥中。须臾，复有一婢来，问曰：“胡为乎泥中？”答曰：“薄言往愬，逢彼之怒。”|| 郑玄家的奴婢都读过书。有一次他差使一个婢女办事，不合心意，要打她，她正要分辩，郑玄发了火，叫人把她拖到泥里。不一会儿，又一个婢女过来，问她：“为何在泥中？”她答道：“我本想去诉说，正撞上他发怒。”
注：称旨：合乎心意。挞（tà）：鞭打。
注：曳著（zhuó）：拖到。
注：胡为乎泥中：出自《诗经·邶风·式微》，借诗句发问。
注：薄言往愬，逢彼之怒：出自《诗经·邶风·柏舟》，借诗句作答。愬（sù），诉说。两婢一问一答都用《诗》句，见郑门学风。

# 四｜服虔既善《春秋》
原：服虔既善《春秋》，将为注，欲参考同异。闻崔烈集门生讲传，遂匿姓名，为烈门人赁作食。每当至讲时，辄窃听户壁间。既知不能逾己，稍共诸生叙其短长。烈闻，不测何人，然素闻虔名，意疑之。明蚤往，及未寤，便呼：“子慎！子慎！”虔不觉惊应，遂相与友善。|| 服虔精通《春秋》，准备为它作注，想比较各家说法的异同。听说崔烈召集门生讲《左传》，便隐去姓名，受雇给崔烈的门生做饭。每到讲课时，就躲在门外墙边偷听。知道崔烈的见解超不过自己后，渐渐和那些学生谈论崔说的得失。崔烈听说了，猜不出是什么人，但他素来听过服虔的名声，心里怀疑是他。第二天一早去找，趁他还没睡醒，就喊：“子慎！子慎！”服虔不觉一惊，脱口应了一声，两人从此结为好友。
注：崔烈：字威考，涿郡人，东汉灵帝时官至司徒、太尉。
注：赁（lìn）：受雇做工。
注：蚤：通“早”。寤：睡醒。

# 五｜钟会撰《四本论》始毕
原：钟会撰《四本论》始毕，甚欲使嵇公一见。置怀中，既定，畏其难，怀不敢出，于户外遥掷，便回急走。|| 钟会刚写完《四本论》，很想让嵇康看一看。他把文章揣在怀里，到了嵇家，又怕嵇康诘难，不敢掏出来，就在门外远远地把文章扔了进去，转身急忙跑开。
注：钟会：字士季，颍川长社人，曹魏重臣，有才辩。
注：《四本论》：论才能与德性之间同、异、合、离四种关系的文章。
注：嵇公：嵇康，字叔夜，“竹林七贤”之一。
注：难（nàn）：诘问、驳难。

# 六｜何晏为吏部尚书
原：何晏为吏部尚书，有位望，时谈客盈坐。王弼未弱冠，往见之。晏闻弼名，因条向者胜理语弼曰：“此理仆以为极，可得复难不？”弼便作难，一坐人便以为屈。于是弼自为客主数番，皆一坐所不及。|| 何晏任吏部尚书时，地位高、名望重，来清谈的宾客常常坐满一堂。王弼还不到二十岁，前去拜见他。何晏早听说过王弼的名气，就把先前谈论中最精辟的道理一条条列出来，对王弼说：“这些道理我认为已经到头了，你还能再驳吗？”王弼便提出驳难，满座的人都认为何晏输了。接着王弼又自己设问、自己作答，反复好几轮，所谈都是满座之人比不上的。
注：何晏：字平叔，曹魏玄学家，与王弼并称，开正始清谈之风。
注：王弼：字辅嗣，山阳人，少年早慧，注《老子》《周易》，二十四岁卒。弱冠：二十岁。
注：条：逐条陈列。向者：先前。
注：自为客主：清谈中一方发难为客、一方应答为主，王弼一人兼任两方。

# 七｜何平叔注《老子》始成
原：何平叔注《老子》始成，诣王辅嗣，见王注精奇，乃神伏，曰：“若斯人，可与论天人之际矣。”因以所注为《道》、《德》二论。|| 何晏刚注完《老子》，去拜访王弼，看到王弼的注精妙奇特，便打心底佩服，说：“像这样的人，才可以和他谈论天道与人事之间的道理啊。”于是把自己的注改写成《道论》《德论》两篇。
注：何平叔：何晏。王辅嗣：王弼。
注：天人之际：天道与人事之间的关系，语出司马迁。

# 八｜王辅嗣弱冠诣裴徽
原：王辅嗣弱冠诣裴徽，徽问曰：“夫无者，诚万物之所资，圣人莫肯致言，而老子申之无已，何邪？”弼曰：“圣人体无，无又不可以训，故言必及有；老、庄未免于有，恒训其所不足。”|| 王弼二十岁左右去拜访裴徽，裴徽问他：“‘无’确实是万物所依凭的根本，可圣人孔子从不肯谈它，老子却反复申说没完，这是为什么？”王弼说：“圣人本身就体现了‘无’，而‘无’又无法用言语说清，所以他开口必定落在‘有’上；老子、庄子还没能免于‘有’，所以总在讲自己所欠缺的‘无’。”
注：裴徽：字文季，河东闻喜人，善谈玄理，官至冀州刺史。
注：资：凭借、依托。致言：发表言论。
注：体无：亲身体现“无”的境界。训：解说。

# 九｜傅嘏善言虚胜
原：傅嘏善言虚胜，荀粲谈尚玄远，每至共语，有争而不相喻。裴冀州释二家之义，通彼我之怀，常使两情皆得，彼此俱畅。|| 傅嘏擅长谈论虚无玄妙之理，荀粲谈话崇尚玄远之旨，两人每次交谈，总是争论而互不理解。冀州刺史裴徽为他们阐释双方的意思，沟通彼此的想法，常常使两人都得其所欲，各自心满意足。
注：傅嘏（gǔ）：字兰石，北地泥阳人，曹魏大臣，善论才性。
注：荀粲：字奉倩，颍川颍阴人，荀彧幼子，好言道家玄理。
注：虚胜：虚无玄妙的佳境。喻：明白、理解。
注：裴冀州：裴徽，曾任冀州刺史。

# 十｜何晏注《老子》未毕
原：何晏注《老子》未毕，见王弼自说注《老子》旨。何意多所短，不复得作声，但应诺诺。遂不复注，因作《道德论》。|| 何晏注《老子》还没完成，听王弼讲述自己注《老子》的要旨。何晏觉得自己的见解多有不足，再也说不出话来，只是连声应“是，是”。于是不再作注，改写了《道德论》。
注：短：不足、欠缺。
注：诺诺：连声应答之声。此则与第七则所记为同一事的不同传闻。

# 十一｜中朝时有怀道之流
原：中朝时有怀道之流，有诣王夷甫咨疑者。值王昨已语多，小极，不复相酬答，乃谓客曰：“身今少恶，裴逸民亦近在此，君可往问。”|| 西晋时有个倾心玄学的人，去拜访王衍请教疑难。正赶上王衍前一天话说得太多，有些疲乏，不想再应答，就对客人说：“我今天身子不大舒服，裴逸民也住在附近，您可以去问他。”
注：中朝：东晋人称西晋为中朝。怀道：向慕玄学之道。
注：王夷甫：王衍，字夷甫，西晋清谈领袖，官至太尉。
注：小极：稍感疲惫。身：我。少恶：有点不舒服。
注：裴逸民：裴頠（wěi），字逸民，西晋名臣，著《崇有论》。

# 十二｜裴成公作《崇有论》
原：裴成公作《崇有论》，时人攻难之，莫能折，唯王夷甫来，如小屈。时人即以王理难裴，理还复申。|| 裴頠写了《崇有论》，当时的人纷纷攻驳，却没人能驳倒他，只有王衍来辩，他似乎稍稍落了下风。可等别人拿王衍的道理去诘难裴頠时，裴頠的道理又重新伸张开来。
注：裴成公：裴頠，死后谥“成”。《崇有论》：针对当时崇尚虚无的风气而作，主张以“有”为本。
注：折：驳倒、折服。屈：理亏。申：伸张，重新站住脚。

# 十三｜诸葛厷年少不肯学问
原：诸葛厷年少不肯学问，始与王夷甫谈，便已超诣。王叹曰：“卿天才卓出，若复小加研寻，一无所愧。”厷后看《庄》、《老》，更与王语，便足相抗衡。|| 诸葛厷年轻时不肯求学问道，可刚和王衍交谈，就已显出超凡的造诣。王衍赞叹道：“你天资卓越，要是再稍微下点钻研的功夫，就什么也不欠缺了。”诸葛厷后来读了《庄子》《老子》，再和王衍谈论，就足以与他分庭抗礼了。
注：诸葛厷（hóng）：字茂远，琅邪人，西晋名士，有逸才。
注：超诣：造诣超出常人。研寻：钻研探求。

# 十四｜卫玠总角时
原：卫玠总角时，问乐令梦，乐云：“是想。”卫曰：“形神所不接而梦，岂是想邪？”乐云：“因也。未尝梦乘车入鼠穴，捣齑啖铁杵，皆无想无因故也。”卫思“因”经日不得，遂成病。乐闻，故命驾为剖析之，卫即小差。乐叹曰：“此儿胸中当必无膏肓之疾。”|| 卫玠童年时，问尚书令乐广人为什么会做梦，乐广说：“是因为心有所想。”卫玠说：“身体和精神都没接触过的东西也会梦到，难道也是想出来的吗？”乐广说：“那是有所因缘。人从没梦见坐着车钻进老鼠洞，或捣碎姜蒜去吃铁杵，就是因为既无所想、也无所因。”卫玠琢磨这个“因”字，好几天想不通，竟想出病来。乐广听说，特意坐车去给他剖析，卫玠的病随即好了些。乐广感叹说：“这孩子心里一定不会有难以化解的疑结。”
注：卫玠：字叔宝，西晋名士，以风神秀美、善谈玄理著称。总角：童年。
注：乐令：乐广，字彦辅，官至尚书令，善清谈，后为卫玠岳父。
注：齑（jī）：捣碎的姜、蒜、菜末。差（chài）：病愈。
注：膏肓之疾：难治之病，此喻郁结不解的心病。

# 十五｜庾子嵩读《庄子》
原：庾子嵩读《庄子》，开卷一尺许便放去，曰：“了不异人意。”|| 庾敳读《庄子》，书卷才展开一尺来长就放下了，说：“跟我的想法全无两样。”
注：庾子嵩：庾敳（ái），字子嵩，颍川鄢陵人，好老庄，为王衍所重。
注：开卷：古书为卷轴，读时展开。了：完全。

# 十六｜客问乐令“旨不至”者
原：客问乐令“旨不至”者，乐亦不复剖析文句，直以麈尾柄确几曰：“至不？”客曰：“至。”乐因又举麈尾曰：“若至者，那得去？”于是客乃悟服。乐辞约而旨达，皆此类。|| 有客人问乐广“旨不至”是什么意思，乐广也不去分析字句，只用麈尾柄敲了敲几案，问：“到了没有？”客人说：“到了。”乐广又把麈尾举起来，说：“如果真到了，怎么又能离开呢？”客人这才领悟，心服口服。乐广言辞简约而意思通达，都是这一类。
注：旨不至：《庄子·天下》所载名家辩题“指不至，至不绝”，旨，通“指”，大意谓概念与所指之物不能真正达到同一。具体解释历来说法不一，存疑。
注：麈（zhǔ）尾：清谈时手执的拂尘类器具。确：敲击。几：小桌。

# 十七｜初，注《庄子》者数十家
原：初，注《庄子》者数十家，莫能究其旨要。向秀于旧注外为解义，妙析奇致，大畅玄风，唯《秋水》、《至乐》二篇未竟，而秀卒。秀子幼，义遂零落，然犹有别本。|| 当初，注《庄子》的有几十家，没有一家能探明它的要旨。向秀在旧注之外另作解释，精妙地剖析其中奇特的意趣，使玄学之风大为畅行，只有《秋水》《至乐》两篇没注完，向秀就去世了。向秀的儿子还小，他的注解于是散失，不过还有另外的抄本流传。
注：向秀：字子期，河内怀人，“竹林七贤”之一，注《庄子》。
注：奇致：奇妙的意趣。
原：郭象者，为人薄行，有俊才，见秀义不传于世，遂窃以为己注。乃自注《秋水》、《至乐》二篇，又易《马蹄》一篇，其余众篇，或定点文句而已。后秀义别本出，故今有向、郭二《庄》，其义一也。|| 郭象这个人品行轻薄，却有出众的才智，他见向秀的注解没有流传于世，就偷来当作自己的注。他自己注了《秋水》《至乐》两篇，又改换了《马蹄》一篇的注，其余各篇只是在文句上作些修订罢了。后来向秀注的另一个抄本出现了，所以现在有向秀、郭象两种《庄子》注，内容其实是一样的。
注：郭象：字子玄，河南人，西晋玄学家，今传《庄子注》即署其名。所谓“窃注”之说，后世学者多有争议。
注：薄行：品行不端。
注：定点：订正、点改文句；或以为当作“点定”。

# 十八｜阮宣子有令闻
原：阮宣子有令闻，太尉王夷甫见而问曰：“老庄与圣教同异？”对曰：“将无同。”太尉善其言，辟之为掾。世谓“三语掾”。卫玠嘲之曰：“一言可辟，何假于三！”宣子曰：“苟是天下人望，亦可无言而辟，复何假一！”遂相与为友。|| 阮修素有美名，太尉王衍见了他就问：“老庄之学与儒家圣教是同还是异？”阮修答：“莫非是相同的吧？”王衍很欣赏这句话，征召他做了属官。世人称他为“三语掾”。卫玠嘲笑他说：“一个字就够被征召了，何必借助三个字！”阮修说：“如果是天下所仰望的人，一个字不说也可以被征召，又何必借助那一个字！”两人于是成了朋友。
注：阮宣子：阮修，字宣子，陈留尉氏人，阮籍族侄，好《易》《老》，善清谈。
注：将无同：莫非相同吧。“将无”是魏晋口语，表委婉揣度。
注：辟（bì）：征召任用。掾（yuàn）：属官。

# 十九｜裴散骑娶王太尉女
原：裴散骑娶王太尉女，婚后三日，诸婿大会，当时名士，王、裴子弟悉集。郭子玄在坐，挑与裴谈。子玄才甚丰赡，始数交，未快；郭陈张甚盛，裴徐理前语，理致甚微，四坐咨嗟称快。王亦以为奇，谓诸人曰：“君辈勿为尔，将受困寡人女婿。”|| 散骑常侍裴遐娶了太尉王衍的女儿，婚后第三天，王家的女婿们聚会，当时的名士和王、裴两家的子弟都来了。郭象也在座，主动挑起话头和裴遐清谈。郭象才学十分丰富，起初交锋几个回合，还不见精彩；等郭象铺陈发挥、气势正盛时，裴遐不慌不忙地梳理前面的话题，义理情致极其精微，满座之人都赞叹叫好。王衍也觉得惊奇，对众人说：“你们别再这样谈下去了，要被我女婿难住了。”
注：裴散骑：裴遐，字叔道，河东闻喜人，善言玄理，曾任散骑郎。王太尉：王衍。
注：郭子玄：郭象。挑：挑起话头。
注：丰赡（shàn）：丰富充足。陈张：铺陈张扬。咨嗟：赞叹。
注：寡人：此为王衍自称，晋人常用。

# 二十｜卫玠始度江
原：卫玠始度江，见王大将军。因夜坐，大将军命谢幼舆。玠见谢，甚说之，都不复顾王，遂达旦微言，王永夕不得豫。玠体素羸，恒为母所禁。尔夕忽极，于此病笃，遂不起。|| 卫玠刚渡江南下时，去拜见大将军王敦。晚上闲坐，王敦叫来了谢鲲。卫玠见到谢鲲，十分欢喜，完全不再理会王敦，两人一直清谈玄理到天亮，王敦整夜插不上话。卫玠身体一向瘦弱，母亲常常禁止他清谈。这一夜他忽然疲惫至极，从此病重，就再也没起来。
注：度：通“渡”。王大将军：王敦，字处仲，王导从兄，东晋初权臣。
注：谢幼舆：谢鲲，字幼舆，好老庄，善清谈。
注：说：同“悦”。微言：精微的玄理之谈。豫：参与。
注：羸（léi）：瘦弱。笃：病重。

# 二十一｜旧云，王丞相过江左
原：旧云，王丞相过江左，止道声无哀乐、养生、言尽意三理而已，然宛转关生，无所不入。|| 旧时传说，丞相王导渡江到江东以后，只谈声无哀乐、养生、言尽意这三个论题而已，然而他辗转生发、触类旁通，没有什么道理不能引入其中。
注：王丞相：王导，字茂弘，东晋开国重臣。江左：江东。
注：声无哀乐、养生：嵇康有《声无哀乐论》《养生论》。言尽意：欧阳建有《言尽意论》。
注：宛转关生：辗转关联，生发出新义。

# 二十二｜殷中军为庾公长史
原：殷中军为庾公长史，下都，王丞相为之集，桓公、王长史、王蓝田、谢镇西并在。丞相自起解帐带麈尾，语殷曰：“身今日当与君共谈析理。”既共清言，遂达三更。丞相与殷共相往反，其余诸贤略无所关。|| 殷浩担任庾亮的长史，东下到京城，丞相王导为他召集聚会，桓温、王濛、王述、谢尚都在座。王导亲自起身解下挂在帐带上的麈尾，对殷浩说：“我今天要和您一起谈玄析理。”两人清谈起来，一直到三更天。王导与殷浩你来我往地辩难，其余几位贤士几乎插不上嘴。
注：殷中军：殷浩，字渊源，东晋清谈名家，曾任中军将军。庾公：庾亮。
注：下都：从荆州顺江东下到京城建康。
注：王长史：王濛。王蓝田：王述，袭封蓝田侯。谢镇西：谢尚。
注：身：我，晋人自称。关：参与。
原：既彼我相尽，丞相乃叹曰：“向来语乃竟未知理源所归。至于辞喻不相负，正始之音，正当尔耳。”明旦，桓宣武语人曰：“昨夜听殷、王清言，甚佳，仁祖亦不寂寞，我亦时复造心，顾看两王掾，辄翣如生母狗馨。”|| 等双方都把道理说尽了，王导感叹道：“刚才谈了半天，竟还不知玄理的本源归于何处。至于言辞和譬喻彼此相称，正始年间的清谈之风，大概就是这样吧。”第二天早上，桓温对人说：“昨晚听殷浩、王导清谈，非常精彩，谢尚也不觉得寂寞，我也时时心有所悟；回头看那两位王姓属官，只会眨巴着眼，像刚下崽的母狗一样。”
注：理源：玄理的本源。辞喻不相负：言辞与譬喻相称，不相违背。
注：正始之音：指魏正始年间何晏、王弼开创的清谈风气。
注：仁祖：谢尚的字。造心：心有所得。两王掾：指王濛、王述，当时都是王导的属官。
注：翣（shà）：通“眨”。馨：晋时口语，犹“那样”“般”。

# 二十三｜殷中军见佛经
原：殷中军见佛经，云：“理亦应阿堵上。”|| 殷浩读到佛经，说：“玄理也该在这里头。”
注：殷中军：殷浩。
注：阿堵：晋时口语，犹“这”“这个”。

# 二十四｜谢安年少时
原：谢安年少时，请阮光禄道《白马论》，为论以示谢。于是谢不即解阮语，重相咨尽。阮乃叹曰：“非但能言人不可得，正索解人亦不可得！”|| 谢安年轻时，请阮裕讲解《白马论》，阮裕写了一篇文章给他看。当时谢安没能立刻理解阮裕的话，反复追问以求透彻。阮裕于是感叹道：“不但能讲透的人难得，就连想找一个能听懂的人也难得啊！”
注：阮光禄：阮裕，字思旷，曾任金紫光禄大夫。
注：《白马论》：战国公孙龙所作，提出“白马非马”的名家论题。
注：重（chóng）相咨尽：一再询问，力求弄透。索解人：寻求能理解的人。

# 二十五｜褚季野语孙安国云
原：褚季野语孙安国云：“北人学问，渊综广博。”孙答曰：“南人学问，清通简要。”支道林闻之，曰：“圣贤固所忘言。自中人以还，北人看书，如显处视月；南人学问，如牖中窥日。”|| 褚裒对孙盛说：“北方人做学问，深厚综合，广博无边。”孙盛答道：“南方人做学问，清爽通达，简明扼要。”支道林听了说：“圣贤本来就领会于心而无须言语。至于中等以下的人，北方人读书，好比在敞亮处看月亮；南方人做学问，好比从窗洞里看太阳。”
注：褚季野：褚裒（póu），字季野，河南阳翟人。孙安国：孙盛，字安国，太原中都人，史学家。
注：支道林：支遁，字道林，东晋名僧，善谈玄理。
注：忘言：得意而忘言，语出《庄子·外物》。中人以还：中等资质以下的人。
注：牖（yǒu）：窗户。此喻北学博而不精、南学精而不博。

# 二十六｜刘真长与殷渊源谈
原：刘真长与殷渊源谈，刘理如小屈，殷曰：“恶！卿不欲作将善云梯仰攻？”|| 刘惔与殷浩谈玄，刘惔的道理似乎稍稍落了下风，殷浩说：“哎！你就不想造一架好云梯来仰攻吗？”
注：刘真长：刘惔，字真长，沛国相人，东晋清谈名家。殷渊源：殷浩。
注：恶（wū）：叹词。
注：云梯：古代攻城用的长梯。此以攻城为喻，挑激对方再来辩驳。

# 二十七｜殷中军云
原：殷中军云：“康伯未得我牙后慧。”|| 殷浩说：“韩康伯连我牙缝里剩下的一点聪明都还没学到。”
注：康伯：韩伯，字康伯，殷浩的外甥，后注《周易》系辞等。
注：牙后慧：言语之外的余慧，后来“拾人牙慧”一语即出于此。

# 二十八｜谢镇西少时
原：谢镇西少时，闻殷浩能清言，故往造之。殷未过有所通，为谢标榜诸义，作数百语，既有佳致，兼辞条丰蔚，甚足以动心骇听。谢注神倾意，不觉流汗交面。殷徐语左右：“取手巾与谢郎拭面。”|| 谢尚年轻时，听说殷浩擅长清谈，特地前去拜访。殷浩并没有过多发挥，只是为谢尚揭示了几条义理，说了几百句话，既有美妙的情致，又言辞丰富华美，很能打动人心、令人惊叹。谢尚全神贯注地听，不知不觉汗流满面。殷浩不慌不忙地对左右说：“拿手巾来给谢郎擦擦脸。”
注：谢镇西：谢尚，字仁祖，曾任镇西将军。造：拜访。
注：标榜：揭示、标举。佳致：美好的情趣。
注：辞条丰蔚：言辞条理丰富而有文采。注神倾意：全神贯注。

# 二十九｜宣武集诸名胜讲《易》
原：宣武集诸名胜讲《易》，日说一卦。简文欲听，闻此便还，曰：“义自当有难易，其以一卦为限邪？”|| 桓温召集众多名流讲解《周易》，每天讲一卦。简文帝本想去听，听说是这样就回去了，说：“义理自然有难有易，怎么能用一天一卦来限定呢？”
注：宣武：桓温，谥宣武。名胜：名流。
注：简文：简文帝司马昱，当时尚为相王。

# 三十｜有北来道人好才理
原：有北来道人好才理，与林公相遇于瓦官寺，讲《小品》。于时竺法深、孙兴公悉共听。此道人语，屡设疑难，林公辩答清析，辞气俱爽。此道人每辄摧屈。|| 有个从北方来的僧人喜欢谈论玄理，与支道林在瓦官寺相遇，一起讲《小品》。当时竺法深、孙绰都在一旁听讲。这个僧人说话时屡屡提出疑难，支道林辩答清楚明晰，言辞与气度都很爽朗。这个僧人每次都被驳倒。
注：道人：晋时称僧人为道人。才理：玄理。林公：支遁。
注：瓦官寺：东晋时建康名寺。《小品》：《小品般若经》，大乘般若类经典。
注：竺法深：竺潜，字法深，东晋名僧。孙兴公：孙绰，字兴公，东晋文学家。
注：摧屈：挫败折服。
原：孙问深公：“上人当是逆风家，向来何以都不言？”深公笑而不答。林公曰：“白旃檀非不馥，焉能逆风？”深公得此义，夷然不屑。|| 孙绰问竺法深：“上人应当是能逆风而上的人物，刚才为什么一句话都不说？”竺法深笑而不答。支道林说：“白旃檀不是不香，可哪能逆着风把香气送过来呢？”竺法深听了这话，泰然自若，毫不在意。
注：上人：对僧人的敬称。逆风家：能逆风而进、迎难辩驳的人。
注：白旃（zhān）檀：檀香木。馥（fù）：香。支遁借佛典香喻，暗示竺法深即便有学问也敌不过自己，带有讥讽。
注：夷然不屑：神态平静，毫不介意。

# 三十一｜孙安国往殷中军许共论
原：孙安国往殷中军许共论，往反精苦，客主无间。左右进食，冷而复暖者数四。彼我奋掷麈尾，悉脱落，满餐饭中，宾主遂至莫忘食。殷乃语孙曰：“卿莫作强口马，我当穿卿鼻！”孙曰：“卿不见决鼻牛，人当穿卿颊！”|| 孙盛到殷浩那里一起谈论，两人往来辩难，竭尽心力，宾主之间毫无破绽可乘。¦仆人送上饭菜，冷了又热、热了又冷，反复好几次。¦双方奋力挥动麈尾，麈尾的毛都脱落下来，落满了饭菜，两人一直谈到傍晚也忘了吃饭。¦殷浩便对孙盛说：“你别当那嘴硬的马，我要给你穿上鼻绳！”¦孙盛说：“你没见过挣断鼻绳的牛吗？人家会把你的腮帮子穿透！”
注：孙安国：孙盛。殷中军：殷浩。许：处所。
注：精苦：用尽心思。无间（jiàn）：无隙可乘。
注：莫：同“暮”。
注：强（jiàng）口马：不肯受辔头的倔马。决鼻牛：挣断鼻绳的牛。马不穿鼻，殷浩的话有破绽，孙盛便顺势反讥。

# 三十二｜庄子《逍遥篇》
原：庄子《逍遥篇》，旧是难处，诸名贤所可钻味，而不能拔理于郭、向之外。支道林在白马寺中，将冯太常共语，因及《逍遥》。支卓然标新理于二家之表，立异义于众贤之外，皆是诸名贤寻味之所不得。后遂用支理。|| 《庄子·逍遥游》历来是难解之处，众多名贤都曾钻研品味，却都不能在郭象、向秀的解释之外另出新理。支道林在白马寺中，与太常冯怀交谈，谈到了《逍遥游》。支道林卓然在郭、向两家之外标举新理，在众贤之外确立不同的见解，都是名贤们探求而未能得到的。后来人们便采用了支道林的解释。
注：《逍遥篇》：《庄子》首篇《逍遥游》。钻味：钻研玩味。拔理：提出超出前人的义理。
注：白马寺：此指建康（一说余杭）的白马寺，非洛阳白马寺，存疑。
注：将：与。冯太常：冯怀，字祖思，曾任太常。
注：标新理：揭示新义。“标新立异”一语出此。表：外。

# 三十三｜殷中军尝至刘尹所
原：殷中军尝至刘尹所，清言良久，殷理小屈，游辞不已，刘亦不复答。殷去后，乃云：“田舍儿强学人作尔馨语！”|| 殷浩曾到刘惔那里，两人清谈了很久，殷浩的道理渐渐落了下风，就不停地说些不着边际的话，刘惔也不再回应。殷浩走后，刘惔才说：“乡下佬硬学别人说这种话！”
注：刘尹：刘惔，曾任丹阳尹。
注：游辞：浮泛无根、东拉西扯的话。
注：田舍儿：乡下人，鄙称。尔馨：如此、这样，晋时口语。

# 三十四｜殷中军虽思虑通长
原：殷中军虽思虑通长，然于才性偏精，忽言及“四本”，便若汤池铁城，无可攻之势。|| 殷浩虽然思辨方面样样擅长，但对才性问题尤其精通，偶然谈到“四本”，就像有沸水护城河、铁铸城墙一般，叫人无从进攻。
注：通长：全面擅长。才性：才能与德性的关系，魏晋清谈重要论题。
注：四本：即钟会《四本论》所论才性同、异、合、离四说，见本门第五则。
注：汤池铁城：沸水的护城河、铁铸的城墙，形容防守坚不可摧。
