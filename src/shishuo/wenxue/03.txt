# 六十八｜左太冲作《三都赋》初成
原：左太冲作《三都赋》初成，时人互有讥訾，思意不惬。后示张公，张曰：“此二京可三，然君文未重于世，宜以经高名之士。”思乃询求于皇甫谧。谧见之嗟叹，遂为作叙。于是先相非贰者，莫不敛衽赞述焉。|| 左思的《三都赋》刚写成时，当时的人你一言我一语地挑毛病，左思心里很不痛快。后来他拿给张华看，张华说：“这篇赋足以和《两都》《二京》并列为三，可是你的文名还没被世人看重，最好请一位名望高的人过目推荐。”左思便去求教皇甫谧。皇甫谧读后赞叹不已，就替它写了序。于是先前那些说三道四的人，没有不整衣肃容、交口称赞的。
注：左太冲：左思，字太冲，西晋临淄人，貌丑口讷而文才出众，《三都赋》写成后洛阳为之纸贵。
注：讥訾（zǐ）：讥笑非议。惬（qiè）：满意，畅快。
注：二京：指班固《两都赋》与张衡《二京赋》，皆写长安、洛阳的名篇。“可三”即可与之鼎足为三。
注：皇甫谧：字士安，西晋学者、医家，屡征不仕，名望极高。敛衽：整理衣襟，表示恭敬。

# 六十九｜刘伶著《酒德颂》
原：刘伶著《酒德颂》，意气所寄。|| 刘伶写《酒德颂》，把自己的胸襟志趣全都寄托在里面了。
注：刘伶：字伯伦，西晋沛国人，竹林七贤之一，以纵酒放达著称。《酒德颂》借颂酒抒发蔑视礼法、超然物外的情怀。

# 七十｜乐令善于清言
原：乐令善于清言，而不长于手笔。将让河南尹，请潘岳为表。潘云：“可作耳，要当得君意。”乐为述己所以为让，标位二百许语。潘直取错综，便成名笔。时人咸云：“若乐不假潘之文，潘不取乐之旨，则无以成斯矣。”|| 乐广擅长清谈，却不擅长动笔写文章。他打算辞去河南尹一职，请潘岳替他写表章。潘岳说：“写倒是可以写，只是得先知道您的意思。”乐广便讲了自己为什么要辞官，前前后后理出两百来句话。潘岳只是把这些话拿来调配组织一番，就成了一篇名作。当时的人都说：“要是乐广不借潘岳的文笔，潘岳不用乐广的意旨，就成不了这样的好文章。”
注：乐令：乐广，字彦辅，西晋名士，官至尚书令，以善清谈著称。
注：手笔：指撰写文章。表：臣下呈给皇帝的奏章。
注：标位：标举陈述，条理地说出要点。错综：交错组合，加以编排润色。

# 七十一｜夏侯湛作《周诗》成
原：夏侯湛作《周诗》成，示潘安仁。安仁曰：“此非徒温雅，乃别见孝悌之性。”潘因此遂作《家风诗》。|| 夏侯湛写成《周诗》，拿给潘岳看。潘岳说：“这诗不只是温和典雅，还能从中另外看出孝顺友爱的天性。”潘岳受此触动，也写了一首《家风诗》。
注：夏侯湛：字孝若，西晋文学家，与潘岳交好，时称“连璧”。《周诗》：《诗经·小雅》中有六篇有题无辞的“笙诗”，夏侯湛为之补写，称《周诗》。
注：潘安仁：潘岳，字安仁，西晋文学家。孝悌（tì）：孝顺父母，敬爱兄长。

# 七十二｜孙子荆除妇服
原：孙子荆除妇服，作诗以示王武子。王曰：“未知文生于情，情生于文？览之凄然，增伉俪之重。”|| 孙楚为亡妻服丧期满，脱去丧服，写了一首诗拿给王济看。王济说：“真不知道是文辞从感情中生出来，还是感情从文辞中生出来？读了让人心中凄然，更觉得夫妻情分深重。”
注：孙子荆：孙楚，字子荆，西晋文学家，性情高傲。除妇服：为妻子服丧期满，除去丧服。
注：王武子：王济，字武子，西晋名士，孙楚的好友。伉俪：夫妻。

# 七十三｜太叔广甚辩给
原：太叔广甚辩给，而挚仲治长于翰墨，俱为列卿。每至公坐，广谈，仲治不能对；退，著笔难广，广又不能答。|| 太叔广口才十分敏捷，挚虞则擅长写文章，两人都位列九卿。每到公开的聚会上，太叔广一发言，挚虞就接不上话；可回去以后，挚虞写文章反驳太叔广，太叔广又回答不了。
注：太叔广：复姓太叔，名广，西晋人，以善辩著称。辩给（jǐ）：能言善辩，应对敏捷。
注：挚仲治：挚虞，字仲治，西晋学者，曾编《文章流别集》。翰墨：笔墨，指写文章。
注：列卿：九卿之列，高级官员。公坐：公开的集会场合。

# 七十四｜江左殷太常父子
原：江左殷太常父子并能言理，亦有辩讷之异。扬州口谈至剧，太常辄云：“汝更思吾论。”|| 东晋殷融和侄子殷浩都善于谈玄说理，不过一个口齿伶俐，一个不善言辞。殷浩谈论起来锋芒逼人，殷融每每只是说：“你再好好想想我的论点。”
注：殷太常父子：殷融与其侄殷浩。殷融官至太常，殷浩曾任扬州刺史，故称“扬州”。晋人亦称叔侄为父子。
注：辩讷（nè）：口才敏捷与言语迟钝。剧：激烈，锋利。

# 七十五｜庾子嵩作《意赋》成
原：庾子嵩作《意赋》成，从子文康见，问曰：“若有意邪，非赋之所尽；若无意邪，复何所赋？”答曰：“正在有意无意之间。”|| 庾敳写成《意赋》，他的侄子庾亮看了，问道：“如果您是有意的，那就不是一篇赋能说尽的；如果是无意的，那又写赋做什么呢？”庾敳答道：“正好在有意与无意之间。”
注：庾子嵩：庾敳（ái），字子嵩，西晋名士，好老庄。《意赋》借以抒写胸怀。
注：从子：侄子。文康：庾亮，谥文康，东晋重臣。

# 七十六｜郭景纯诗云
原：郭景纯诗云：“林无静树，川无停流。”阮孚云：“泓峥萧瑟，实不可言。每读此文，辄觉神超形越。”|| 郭璞有两句诗：“林中没有静止的树，河里没有停驻的流水。”阮孚说：“那种水深山高、风过林梢的意境，真是说不出来。每读到这两句，总觉得精神超然、身心都飘到尘世之外去了。”
注：郭景纯：郭璞，字景纯，两晋之际文学家、方术家，以《游仙诗》著称。
注：阮孚：字遥集，阮咸之子，东晋名士，嗜酒放达。
注：泓峥：水深山高。萧瑟：风吹草木之声。神超形越：精神超脱，形体也仿佛超离尘俗。

# 七十七｜庾阐始作《扬都赋》
题解：“亮”字直犯庾亮之名，庾阐得知庾亮要看，便改字避讳；“望”字为何一并改动，旧说不一，存疑。
原：庾阐始作《扬都赋》，道温、庾云：“温挺义之标，庾作民之望。方响则金声，比德则玉亮。”庾公闻赋成，求看，兼赠贶之。阐更改“望”为“俊”，以“亮”为“润”云。|| 庾阐起初写《扬都赋》，说到温峤和庾亮时写道：“温峤树立起道义的标杆，庾亮成为百姓仰望的人物。比声音，他们如金钟铿锵；比德行，他们如美玉明亮。”庾亮听说赋已写成，要来看，还送了礼物给他。庾阐于是把“望”字改成“俊”，把“亮”字改成“润”。
注：庾阐：字仲初，东晋文学家。《扬都赋》：描写东晋都城建康的赋作。
注：温、庾：温峤与庾亮，平定苏峻之乱的功臣。
注：贶（kuàng）：赠送。

# 七十八｜孙兴公作《庾公诔》
原：孙兴公作《庾公诔》，袁羊曰：“见此张缓。”于是以为名赏。|| 孙绰写了《庾公诔》，袁乔说：“从这篇文章里看到了张弛有度。”这话于是成了有名的品评。
注：孙兴公：孙绰，字兴公，东晋文学家，善作碑诔。《庾公诔》：哀悼庾亮的诔文。
注：袁羊：袁乔，小字羊，东晋人。张缓：即张弛，语出《礼记》“一张一弛，文武之道”，此指文章节奏松紧得宜。
注：名赏：有名的鉴赏之语。

# 七十九｜庾仲初作《扬都赋》成
原：庾仲初作《扬都赋》成，以呈庾亮。亮以亲族之怀，大为其名价，云可三二京、四三都。于此人人竞写，都下纸为之贵。谢太傅云：“不得尔。此是屋下架屋耳。事事拟学，而不免俭狭。”|| 庾阐写成《扬都赋》，呈给庾亮。庾亮出于同族的情分，极力替它抬高身价，说可以和《二京赋》并列为三，与《三都赋》并列为四。于是人人争相抄写，京城的纸价都因此涨了。谢安却说：“不该这样。这不过是在屋子底下再搭一间屋子罢了。处处模仿前人，难免显得局促贫乏。”
注：庾仲初：庾阐。名价：名声与身价。三二京、四三都：与《二京赋》合而为三，与《三都赋》合而为四。
注：谢太傅：谢安。屋下架屋：比喻重复模仿，毫无新创。俭狭：贫乏狭窄。

# 八十｜习凿齿史才不常
原：习凿齿史才不常，宣武甚器之，未三十，便用为荆州治中。凿齿谢笺亦云：“不遇明公，荆州老从事耳！”后至都见简文，返命，宣武问：“见相王何如？”答云：“一生不曾见此人。”从此忤旨，出为衡阳郡，性理遂错。于病中犹作《汉晋春秋》，品评卓逸。|| 习凿齿的史学才能非同一般，桓温很器重他，他还不到三十岁，就被任用为荆州治中。习凿齿在答谢的信中也说：“若不是遇到您，我不过是荆州一个熬到老的从事罢了！”后来他到京城谒见简文帝，回来复命时，桓温问：“见了相王，觉得怎么样？”他回答说：“我这辈子从没见过这样的人。”从此违逆了桓温的心意，被外放为衡阳郡太守，精神也就失常了。他在病中仍旧写作《汉晋春秋》，议论见解卓越超群。
注：习凿齿：字彦威，东晋史学家，襄阳人。宣武：桓温，谥宣武，时镇荆州。
注：治中：州刺史的属官，主管文书众务。从事：州郡佐吏。
注：相王：简文帝司马昱，即位前以会稽王为丞相，故称。答语盛赞简文，令有篡位之心的桓温不快。
注：《汉晋春秋》：习凿齿所著史书，以蜀汉为正统，或谓意在抑制桓温野心。性理：心性神志。

# 八十一｜孙兴公云
原：孙兴公云：“《三都》、《二京》，五经鼓吹。”|| 孙绰说：“《三都赋》《二京赋》，是为五经吹奏助兴的乐章。”
注：《三都》：左思《三都赋》。《二京》：张衡《二京赋》。
注：鼓吹：本指仪仗中的鼓乐，引申为宣扬、羽翼。意谓这些大赋能发扬经义。

# 八十二｜谢太傅问主簿陆退
原：谢太傅问主簿陆退：“张凭何以作母诔，而不作父诔？”退答曰：“故当是丈夫之德，表于事行；妇人之美，非诔不显。”|| 谢安问主簿陆退：“张凭为什么给母亲写诔文，却不给父亲写？”陆退答道：“想来是因为男子的德行，从他的事业作为中就能显现；而妇女的美德，不靠诔文就无从彰显。”
注：陆退：东晋人，张凭的女婿，时为谢安主簿。张凭：字长宗，东晋名士。
注：诔（lěi）：叙述死者生平、表示哀悼的文体。丈夫：男子。事行：事业与行为。

# 八十三｜王敬仁年十三作《贤人论》
原：王敬仁年十三作《贤人论》，长史送示真长，真长答云：“见敬仁所作论，便足参微言。”|| 王脩十三岁时写了《贤人论》，他的父亲王濛把文章送给刘惔看，刘惔回复说：“看了敬仁这篇论，就知道他已经足以参与精微玄妙的清谈了。”
注：王敬仁：王脩，字敬仁，王濛之子，少有才名，早卒。
注：长史：王濛，曾任司徒左长史。真长：刘惔，字真长，东晋清谈名家。
注：参：参与，领会。微言：精深微妙的言论，此指玄理清谈。

# 八十四｜孙兴公云潘文烂若披锦
原：孙兴公云：“潘文烂若披锦，无处不善；陆文若排沙简金，往往见宝。”|| 孙绰说：“潘岳的文章灿烂得像铺开的锦缎，没有一处不好；陆机的文章像拨开沙子挑拣金子，时常能见到宝贝。”
注：潘：潘岳。陆：陆机，字士衡，西晋文学家。
注：披锦：展开锦缎。排沙简金：拨开沙子拣出金子。简：挑选。

# 八十五｜简文称许掾云
原：简文称许掾云：“玄度五言诗，可谓妙绝时人。”|| 简文帝称赞许询说：“玄度的五言诗，可以说是绝妙超群，当世无人能及。”
注：许掾（yuàn）：许询，字玄度，东晋玄言诗人，曾被征为司徒掾，不就。简文：简文帝司马昱。

# 八十六｜孙兴公作《天台赋》成
原：孙兴公作《天台赋》成，以示范荣期，云：“卿试掷地，要作金石声。”范曰：“恐子之金石，非宫商中声。”然每至佳句，辄云：“应是我辈语。”|| 孙绰写成《天台赋》，拿给范启看，说：“你试着把它扔到地上，一定会发出金石般的声响。”范启说：“只怕你这金石之声，不合宫商的音律。”可是每读到好句子，他又总是说：“这才是咱们这类人该说的话。”
注：《天台赋》：即《游天台山赋》，孙绰的代表作，辞采清丽。
注：范荣期：范启，字荣期，东晋人，以才学知名。
注：金石声：钟磬之声，比喻文辞铿锵。宫商：五音的代称。中声：合于音律的和谐之声。范启是先抑后扬的戏谑。

# 八十七｜桓公见谢安石作简文谥议
原：桓公见谢安石作简文谥议，看竟，掷与坐上诸客曰：“此是安石碎金。”|| 桓温看到谢安为简文帝写的谥议，读完后，扔给在座的客人们说：“这是安石的零碎金子。”
注：桓公：桓温。谢安石：谢安，字安石。谥议：议定帝王死后谥号的文书。
注：碎金：零碎的金子，比喻短小而精美的文字。

# 八十八｜袁虎少贫
原：袁虎少贫，尝为人佣载运租。谢镇西经船行，其夜清风朗月，闻江渚间估客船上有咏诗声，甚有情致，所诵五言，又其所未尝闻，叹美不能已。即遣委曲讯问，乃是袁自咏其所作《咏史诗》。因此相要，大相赏得。|| 袁宏年轻时家境贫寒，曾受雇替人用船运送租米。镇西将军谢尚乘船经过，那天夜里风清月朗，他听到江边沙洲旁的商船上有人在吟诗，很有情味，所吟的五言诗又是他从没听过的，不禁赞叹不止。他当即派人去仔细打听，原来是袁宏在吟诵自己写的《咏史诗》。谢尚于是邀请他过来，对他大加赏识，两人相处得十分投合。
注：袁虎：袁宏，字彦伯，小字虎，东晋文学家、史学家。佣：受雇做工。
注：谢镇西：谢尚，谢安的堂兄，曾任镇西将军。
注：江渚（zhǔ）：江中小洲。估客：商人。委曲：详细地，原原本本地。
注：要（yāo）：邀请。赏得：赏识而投合。

# 八十九｜孙兴公云潘文浅而净
原：孙兴公云：“潘文浅而净，陆文深而芜。”|| 孙绰说：“潘岳的文章浅显却干净，陆机的文章深厚却繁杂。”
注：芜：繁杂，不够精简。

# 九十｜裴郎作《语林》
原：裴郎作《语林》，始出，大为远近所传。时流年少，无不传写，各有一通。载王东亭作《经王公酒垆下赋》，甚有才情。|| 裴启写了《语林》，刚一问世，就在远近广为流传。当时的名流和年轻人，没有不传抄的，人手一部。书中记载了王珣所作的《经王公酒垆下赋》，很有才情。
注：裴郎：裴启，字荣期，东晋人。《语林》：记汉魏至东晋名士言行的小说集，今佚，《世说新语》多取材于此。
注：时流：当时的名流。通：量词，一部，一份。
注：王东亭：王珣，封东亭侯。王公酒垆：王戎说起曾与嵇康、阮籍同饮的那家酒店。此赋与《语林》后来的遭遇，另见《轻诋》篇。

# 九十一｜谢万作《八贤论》
原：谢万作《八贤论》，与孙兴公往反，小有利钝。谢后出以示顾君齐，顾曰：“我亦作，知卿当无所名。”|| 谢万写了《八贤论》，和孙绰反复辩难，彼此互有胜负。谢万后来拿出来给顾夷看，顾夷说：“我也写过，料想你这篇该没有什么可称道的。”
注：谢万：字万石，谢安之弟。《八贤论》：论屈原、贾谊等四隐四显八人，今佚。
注：往反：往复辩论。利钝：胜负，高下。
注：顾君齐：顾夷，字君齐，东晋吴郡人。无所名：无可称道。一说意为“难以分出高下”，存疑。

# 九十二｜桓宣武命袁彦伯作《北征赋》
原：桓宣武命袁彦伯作《北征赋》，既成，公与时贤共看，咸嗟叹之。时王珣在坐，云：“恨少一句。得‘写’字足韵当佳。”袁即于坐揽笔益云：“感不绝于余心，溯流风而独写。”公谓王曰：“当今不得不以此事推袁。”|| 桓温命袁宏写《北征赋》，写成后，桓温和当时的名流一起观看，大家都赞叹不已。当时王珣在座，说：“可惜少了一句。要是能用个‘写’字押上韵，就更好了。”袁宏当即在座上提笔添了两句：“感慨在我心中绵绵不绝，迎着长风独自抒写情怀。”桓温对王珣说：“如今在这件事上，不得不推袁宏为第一。”
注：桓宣武：桓温。袁彦伯：袁宏。《北征赋》：记桓温北伐之作。
注：足韵：补足韵脚。揽笔：提笔。益：增添。
注：流风：长风。写：抒写，倾吐。推：推许，推崇。

# 九十三｜孙兴公道
原：孙兴公道：“曹辅佐才如白地明光锦，裁为负版绔，非无文采，酷无裁制。”|| 孙绰说：“曹毗的才华像白底的明光锦，却被裁成了役夫穿的裤子，不是没有文采，只是太不懂剪裁了。”
注：曹辅佐：曹毗，字辅佐，东晋文学家。
注：白地明光锦：一种白底的名贵锦缎。负版：背负木板的役夫，指地位低下的人。绔：同“裤”。
注：酷：极，甚。裁制：剪裁，比喻写作时对材料的取舍安排。

# 九十四｜袁彦伯作《名士传》成
原：袁彦伯作《名士传》成，见谢公。公笑曰：“我尝与诸人道江北事，特作狡狯耳，彦伯遂以著书。”|| 袁宏写成《名士传》，拿去见谢安。谢安笑着说：“我曾经跟大家聊过些江北的旧事，不过是说着好玩罢了，彦伯竟然拿来写成了书。”
注：《名士传》：袁宏所著，分正始、竹林、中朝三类记魏晋名士，今佚。
注：江北事：指渡江之前西晋的名士旧事。狡狯（kuài）：戏耍，玩笑。

# 九十五｜王东亭到桓公吏
原：王东亭到桓公吏，既伏阁下，桓令人窃取其白事。东亭即于阁下更作，无复向一字。|| 王珣到桓温手下做属吏，已经在官署门前候见，桓温派人偷偷拿走了他的呈文。王珣当即在官署门前重新写了一份，没有一个字和先前那份重复。
注：王东亭：王珣。到桓公吏：到桓温府中任属吏。
注：伏阁：在官署前跪候请见。白事：陈述事情的文书。更作：重写。向：先前。

# 九十六｜桓宣武北征
原：桓宣武北征，袁虎时从，被责免官。会须露布文，唤袁倚马前令作。手不辍笔，俄得七纸，殊可观。东亭在侧，极叹其才。袁虎云：“当令齿舌间得利。”|| 桓温北伐，袁宏当时随军，因事受责被免了官。恰好急需一篇露布文告，桓温叫袁宏靠在马前起草。袁宏笔不停挥，一会儿就写满了七张纸，写得非常精彩。王珣在旁边，极力赞叹他的才华。袁宏说：“也该让我从你们的齿舌之间得点好处了。”
注：露布：不封口、公开宣示的檄文或捷报。倚马前令作：后世“倚马可待”一语即出于此。
注：俄：一会儿。东亭：王珣。
注：齿舌间得利：意谓从众人的称赞中得到实际好处（如复官）。一说是自嘲只能得些口头夸奖，存疑。

# 九十七｜袁宏始作《东征赋》
原：袁宏始作《东征赋》，都不道陶公。胡奴诱之狭室中，临以白刃，曰：“先公勋业如是，君作《东征赋》，云何相忽略？”宏窘蹙无计，便答：“我大道公，何以云无？”因诵曰：“精金百炼，在割能断。功则治人，职思靖乱。长沙之勋，为史所赞。”|| 袁宏起初写《东征赋》，一句也没提到陶侃。陶侃的儿子胡奴把他骗进一间小屋，拿明晃晃的刀对着他，说：“先父的功业那样显赫，你写《东征赋》，为什么把他略过不提？”袁宏窘迫得无计可施，就答道：“我大大地称道了陶公，怎么能说没有？”接着便念道：“精纯的金子经过百炼，切割起来无坚不断。论功劳能安定民心，论职守一心平定祸乱。长沙公的功勋，为史家所称赞。”
注：《东征赋》：袁宏记东晋渡江诸名臣的赋作。陶公：陶侃，东晋名将，封长沙郡公。
注：胡奴：陶范，小字胡奴，陶侃之子。
注：窘蹙（cù）：窘迫。治人：安定百姓。靖乱：平定叛乱。

# 九十八｜或问顾长康
原：或问顾长康：“君《筝赋》何如嵇康《琴赋》？”顾曰：“不赏者，作后出相遗；深识者，亦以高奇见贵。”|| 有人问顾恺之：“您的《筝赋》比嵇康的《琴赋》怎么样？”顾恺之说：“不懂欣赏的人，会因为它出得晚而丢在一边；真正有眼光的人，也会因为它高妙奇特而看重它。”
注：顾长康：顾恺之，字长康，东晋画家、文学家。《筝赋》今已不全。
注：嵇康《琴赋》：嵇康论琴的名篇，被推为音乐赋之冠。遗：丢弃。

# 九十九｜殷仲文天才宏赡
原：殷仲文天才宏赡，而读书不甚广博，亮叹曰：“若使殷仲文读书半袁豹，才不减班固。”|| 殷仲文天生才华丰沛，但读书不太广博，傅亮感叹说：“假如殷仲文读的书有袁豹的一半，他的才华就不会比班固差。”
注：殷仲文：东晋末文学家，桓玄的姐夫，后被刘裕所杀。宏赡（shàn）：宏大丰富。
注：亮：据书中注为傅亮，东晋末、刘宋初大臣，长于文辞。存疑：旧本或无“亮”字，所指有异说。
注：袁豹：字士蔚，东晋末人，好学博闻。班固：东汉史学家、辞赋家，著《汉书》《两都赋》。

# 一百｜羊孚作《雪赞》云
原：羊孚作《雪赞》云：“资清以化，乘气以霏。遇象能鲜，即洁成辉。”桓胤遂以书扇。|| 羊孚写了一篇《雪赞》：“凭借清寒化生而成，乘着气流纷纷飘飞。遇到万物能使它鲜明，就着洁白化作光辉。”桓胤于是把它写在了扇子上。
注：羊孚：字子道，东晋末文士，与桓玄交好。
注：资：凭借。霏：纷飞。象：物象，景物。
注：桓胤：桓冲之孙，东晋末人，后受桓玄事牵连被杀。

# 一百零一｜王孝伯在京行散
原：王孝伯在京行散，至其弟王睹户前，问：“古诗中何句为最？”睹思未答。孝伯咏“所遇无故物，焉得不速老”：“此句为佳。”|| 王恭在京城服药后散步行药，走到弟弟王爽的门前，问道：“古诗里哪一句最好？”王爽还在思索，没来得及回答。王恭便吟诵“所遇无故物，焉得不速老”，说：“这一句最好。”
注：王孝伯：王恭，字孝伯，东晋外戚，后起兵失败被杀。
注：行散：魏晋人服五石散后须走动以散发药性，称行散。王睹：王爽，小字睹，王恭之弟。
注：“所遇”二句：出自《古诗十九首·回车驾言迈》，感叹眼前已无旧物，人怎能不迅速衰老。

# 一百零二｜桓玄尝登江陵城南楼
原：桓玄尝登江陵城南楼云：“我今欲为王孝伯作诔。”因吟啸良久，随而下笔，一坐之间，诔以之成。|| 桓玄曾经登上江陵城的南楼，说：“我现在要给王恭写一篇诔文。”于是长声吟啸了好一阵，随即落笔，只坐了片刻工夫，诔文就写成了。
注：桓玄：桓温之子，东晋末权臣，后篡位称帝。江陵：今属湖北。
注：王孝伯：王恭，曾与桓玄结盟起兵。吟啸：吟咏长啸。一坐之间：坐一次的工夫，形容极快。

# 一百零三｜桓玄初并西夏
原：桓玄初并西夏，领荆、江二州、二府、一国。于时始雪，五处俱贺，五版并入。玄在听事上，版至，即答版后，皆粲然成章，不相揉杂。|| 桓玄刚吞并西部地区时，兼领荆州、江州两州，两个将军府，还有一个封国。当时正下初雪，这五处同时送来贺笺，五份贺版一起呈上。桓玄坐在厅堂上，贺版一到，就在版的背面作答，每一篇都文采灿然，各自成章，互不混杂。
注：西夏：指建康以西的荆、雍一带。桓玄于隆安年间袭杀殷仲堪、杨佺期而据其地。
注：二府：都督府与将军府之类的两个幕府。一国：桓玄承袭的南郡公封国。
注：版：写在木板上的文书，此指贺笺。听事：官署的厅堂。粲然：鲜明有文采的样子。揉杂：混杂。

# 一百零四｜桓玄下都
原：桓玄下都，羊孚时为兖州别驾，从京来诣门，笺云：“自顷世故睽离，心事沦蕴。明公启晨光于积晦，澄百流以一源。”桓见笺，驰唤前，云：“子道，子道，来何迟！”即用为记室参军。孟昶为刘牢之主簿，诣门谢，见云：“羊侯，羊侯，百口赖卿。”|| 桓玄攻入京都后，羊孚当时任兖州别驾，从京口赶来登门求见，名笺上写道：“近来世事变乱，亲友离散，心中的话一直郁积着说不出。您在长久的昏暗中开启了晨光，用一道清源澄清了百条浊流。”桓玄看了笺，赶紧叫他进来，说：“子道，子道，怎么来得这么晚！”当即任命他为记室参军。孟昶原是刘牢之的主簿，登门向桓玄谢罪，见到羊孚就说：“羊侯，羊侯，我全家上百口人的性命全靠您了。”
注：下都：指桓玄东下攻入建康。羊孚：字子道。别驾：州刺史的高级佐吏。京：此指京口（今江苏镇江），兖州侨治所在。
注：睽（kuí）离：分离，乖隔。沦蕴：沉积郁结。积晦：长久的昏暗。
注：记室参军：将军府中掌管文书的属官。
注：孟昶（chǎng）：东晋末人，时为刘牢之主簿；刘牢之曾与桓玄为敌，故孟昶须登门谢罪，求羊孚庇护。
