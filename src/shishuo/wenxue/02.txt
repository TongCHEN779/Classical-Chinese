# 三十五｜支道林造《即色论》
原：支道林造《即色论》，论成，示王中郎，中郎都无言。支曰：“默而识之乎？”王曰：“既无文殊，谁能见赏？”|| 支道林写成了《即色论》，拿给王中郎看，王中郎一言不发。支道林问：“您是默默记在心里了吗？”王中郎答：“这里既然没有文殊菩萨，又有谁能赏识它呢？”
注：支道林：支遁，字道林，东晋高僧，精通老庄与般若学，是清谈名家。
注：《即色论》：支遁阐发般若“色即是空”之义的论著，其说被称为“即色宗”。
注：王中郎：王坦之，字文度，官北中郎将，故称。
注：文殊：文殊师利菩萨，以智慧著称。王坦之借《维摩诘经》中维摩诘默然不语、文殊赞叹的典故，暗讽支遁之论无人能识，语带机锋。
# 三十六｜王逸少作会稽
原：王逸少作会稽，初至，支道林在焉。孙兴公谓王曰：“支道林拔新领异，胸怀所及乃自佳，卿欲见不？”王本自有一往隽气，殊自轻之。后孙与支共载往王许，王都领域，不与交言。须臾支退。后正值王当行，车已在门，支语王曰：“君未可去，贫道与君小语。”因论《庄子·逍遥游》。支作数千言，才藻新奇，花烂映发。王遂披襟解带，留连不能已。|| 王羲之出任会稽内史，刚到任时，支道林也在那里。孙绰对王羲之说：“支道林能标新立异，见识所及之处实在精妙，您想见见他吗？”王羲之本来就有一股超逸不群的傲气，很看不起支道林。后来孙绰和支道林同乘一车到王家，王羲之始终自守门户，不跟支道林交谈。不一会儿支道林就告辞了。后来有一次正赶上王羲之要出门，车子已经停在门口，支道林对他说：“您先别走，贫僧想跟您说几句。”于是谈起《庄子·逍遥游》。支道林一口气讲了几千字，文采新颖奇特，如繁花灿烂、交相辉映。王羲之于是敞开衣襟、解下衣带，流连忘返，舍不得离开。
注：王逸少：王羲之，字逸少，东晋书法家，曾任会稽内史。
注：孙兴公：孙绰，字兴公，东晋文学家、玄言诗人。
注：一往隽气：一股超拔不凡的傲气。隽，同“俊”。
注：领域：自设界限，与人保持距离。披襟解带：本已整装待发，此时宽衣留下，可见为之倾倒。
# 三十七｜三乘佛家滞义
原：三乘佛家滞义，支道林分判，使三乘炳然。诸人在下坐听，皆云可通。支下坐，自共说，正当得两，入三便乱。今义弟子虽传，犹不尽得。|| 三乘是佛家教义中难以疏通的问题，支道林加以分析辨别，使三乘之义清清楚楚。众人在下座听讲，都说能够领会。等支道林走下讲座，大家自己相互讨论，却只能讲通两乘，一涉及第三乘就乱了。如今他的义理虽有弟子传承，仍不能完全掌握。
注：三乘：佛教指引众生解脱的三种途径，即声闻乘、缘觉乘、菩萨乘。乘，车乘，喻运载。
注：滞义：滞涩难通的义理。
注：炳然：明白显著的样子。正当：只，仅。
# 三十八｜许掾年少时
原：许掾年少时，人以比王苟子，许大不平。时诸人士及支法师并在会稽西寺讲，王亦在焉。许意甚忿，便往西寺与王论理，共决优劣，苦相折挫，王遂大屈。许复执王理，王执许理，更相覆疏，王复屈。许谓支法师曰：“弟子向语何似？”支从容曰：“君语佳则佳矣，何至相苦邪？岂是求理中之谈哉？”|| 许询年轻时，人们把他和王修相提并论，许询很不服气。当时许多名士和支法师都在会稽西寺讲论，王修也在。许询心中很是愤愤，就到西寺与王修辩论义理，要一决高下，双方竭力挫折对方，结果王修大败。许询又反过来持王修原先的论点，让王修持自己的论点，再次反复辩驳，王修又输了。许询问支法师：“弟子刚才说得怎么样？”支法师不慌不忙地说：“您的话好是好，可何必弄得这样彼此为难呢？这哪里是追求义理的谈论呢？”
注：许掾：许询，字玄度，东晋名士，曾被征为司徒掾，不就，故称许掾。
注：王苟子：王修，字敬仁，小字苟子，王濛之子，早有清名，年仅二十四岁而卒。
注：西寺：会稽城西的寺院。覆疏：反复辩驳疏解。
注：理中：合乎义理之中正，此指以求真理为目的的谈论。
# 三十九｜林道人诣谢公
原：林道人诣谢公，东阳时始总角，新病起，体未堪劳，与林公讲论，遂至相苦。母王夫人在壁后听之，再遣信令还，而太傅留之。王夫人因自出，云：“新妇少遭家难，一生所寄，唯在此儿。”因流涕抱儿以归。谢公语同坐曰：“家嫂辞情慷慨，致可传述，恨不使朝士见！”|| 支道林去拜访谢安，谢朗当时还是个孩子，刚刚病好，身体还经不起劳累，却跟支道林辩论，以至于彼此争得很苦。他母亲王夫人在墙壁后面听着，两次派人传话叫他回去，谢安却把他留住了。王夫人于是亲自出来，说：“我年轻时就遭遇家门不幸，一生的寄托，全在这个孩子身上。”说着流泪抱起儿子回去了。谢安对在座的人说：“我嫂嫂言辞情意激昂动人，极值得传颂，可惜没能让朝中士人看到！”
注：林道人：支遁。谢公：谢安，字安石，后官至太傅。
注：东阳：谢朗，字长度，谢安之侄，官至东阳太守。总角：儿童束发为两髻，指童年。
注：王夫人：谢朗之母，谢据之妻。谢据早亡，故云“少遭家难”。新妇：已婚妇女的自称。
注：信：传话的人。致：极，最。
# 四十｜支道林许掾诸人
原：支道林、许掾诸人共在会稽王斋头，支为法师，许为都讲。支通一义，四坐莫不厌心；许送一难，众人莫不抃舞。但共嗟咏二家之美，不辩其理之所在。|| 支道林、许询等人一起在会稽王的书斋里，支道林担任法师，许询担任都讲。支道林每阐明一条义理，满座的人无不心满意足；许询每提出一个疑难，众人无不拍手叫好。大家只是一同赞叹两人的精彩，却并不去分辨其中的道理究竟在哪里。
注：会稽王：司马昱，即后来的简文帝。斋头：书斋，静室。
注：法师、都讲：讲经时，都讲负责唱经发问，法师负责讲解答疑。
注：厌心：满足于心。厌，满足。抃（biàn）舞：拍手跳跃，形容极其欢喜。
# 四十一｜谢车骑在安西艰中
原：谢车骑在安西艰中，林道人往就语，将夕乃退。有人道上见者，问云：“公何处来？”答云：“今日与谢孝剧谈一出来。”|| 谢玄在为父亲谢奕守丧期间，支道林前去找他谈论，快到傍晚才回。有人在路上遇见他，问道：“您从哪里来？”支道林答：“今天跟谢孝子痛痛快快谈了一场回来。”
注：谢车骑：谢玄，字幼度，淝水之战的主将，死后追赠车骑将军。
注：安西艰：谢玄之父谢奕曾任安西将军，“艰”指居父母之丧。
注：谢孝：指正在守孝的谢玄。剧谈：畅谈。一出：一番，一场。
# 四十二｜支道林初从东出
原：支道林初从东出，住东安寺中。王长史宿构精理，并撰其才藻，往与支语，不大当对。王叙致作数百语，自谓是名理奇藻。支徐徐谓曰：“身与君别多年，君义言了不长进。”王大惭而退。|| 支道林刚从东边来到京城，住在东安寺里。王濛事先构思好了精深的义理，又挑选好了华美的辞藻，前去与支道林谈论，却不太能与他匹敌。王濛铺陈叙说了几百句话，自以为是名理精妙、辞藻奇丽。支道林慢慢地对他说：“我和您分别多年，您在义理言谈上竟一点没有长进。”王濛非常惭愧地退了出去。
注：从东出：从会稽到京城建康。会稽在建康之东，故称。
注：王长史：王濛，字仲祖，东晋清谈名士，曾任司徒左长史。按王濛卒于永和三年，支遁到京城在哀帝时，时间不合，此事或属传闻之误，存疑。
注：撰：同“选”，选择。当对：相当，匹敌。
注：叙致：铺陈叙述旨趣。名理：魏晋清谈中辨析名实、事理的学问。了：全然。
# 四十三｜殷中军读《小品》
原：殷中军读《小品》，下二百签，皆是精微，世之幽滞。尝欲与支道林辩之，竟不得。今《小品》犹存。|| 殷浩读《小品》，在书里夹了二百个签条，标出的都是精深微妙、世人难以通晓的地方。他曾想跟支道林辩论这些问题，最终没能如愿。如今那部《小品》还保存着。
注：殷中军：殷浩，字深源，东晋清谈名家，官至中军将军。
注：《小品》：《小品般若波罗蜜经》，佛经名，篇幅较《大品》为短。
注：签：标记用的签条。幽滞：深奥难通之处。
# 四十四｜佛经以为祛练神明
原：佛经以为祛练神明，则圣人可致。简文云：“不知便可登峰造极不？然陶练之功，尚不可诬。”|| 佛经认为，只要去除尘念、修炼心神，就可以成佛。简文帝说：“不知道是否真能达到最高境界？不过陶冶修炼的功效，总还是不能抹杀的。”
注：祛（qū）练神明：去除杂念，修炼精神。祛，除去。
注：圣人：此指佛。致：达到。
注：简文：东晋简文帝司马昱。诬：抹杀，否认。
# 四十五｜于法开始与支公争名
原：于法开始与支公争名，后情渐归支，意甚不分，遂遁迹剡下。遣弟子出都，语使过会稽。于时支公正讲《小品》。开戒弟子：“道林讲，比汝至，当在某品中。”因示语攻难数十番，云：“旧此中不可复通。”弟子如言诣支公。正值讲，因谨述开意，往反多时，林公遂屈，厉声曰：“君何足复受人寄载来！”|| 于法开起初和支道林争夺名望，后来人心渐渐归向支道林，于法开心里很不服气，就隐居到剡县去了。他派弟子到京都去，嘱咐弟子途中经过会稽。当时支道林正在讲《小品》。于法开告诫弟子说：“道林讲经，等你到那里，应该正讲到某一品。”于是把几十个回合的攻驳问难教给弟子，说：“以往在这里是讲不通的。”弟子照他的话去拜见支道林。正赶上支道林在讲，弟子就小心地陈述于法开的意见，往返辩论了很久，支道林终于理屈，厉声说：“你何必替人捎话来呢！”
注：于法开：东晋高僧，于法兰弟子，兼通医术，常与支遁争论“即色空”之义。
注：情：众人之心。分：通“忿”，不服气。剡（shàn）下：剡县，今浙江嵊州一带。
注：比：及，等到。品：佛经的篇章。
注：寄载：受人委托，代人传话。支遁此语既是认输，也讥对方并非自出机杼。
# 四十六｜殷中军问自然无心
原：殷中军问：“自然无心于禀受，何以正善人少，恶人多？”诸人莫有言者。刘尹答曰：“譬如写水著地，正自纵横流漫，略无正方圆者。”一时绝叹，以为名通。|| 殷浩问道：“大自然赋予人的禀性本是无心的，为什么偏偏善人少、恶人多呢？”在座的人没有一个回答。刘惔答道：“就好比把水倒在地上，只会四处横流漫溢，几乎没有恰好流成方形或圆形的。”当时众人赞叹不已，认为是高明的解说。
注：禀受：人从自然承受的气质、品性。
注：正：恰恰，偏偏；下文“正自”之“正”为只、仅。
注：刘尹：刘惔，字真长，东晋清谈名士，曾任丹阳尹。写（xiè）：倾泻。
注：名通：精妙的解说。通，阐释义理使之通畅。
# 四十七｜康僧渊初过江
原：康僧渊初过江，未有知者，恒周旋市肆，乞索以自营。忽往殷渊源许，值盛有宾客，殷使坐，粗与寒温，遂及义理。语言辞旨，曾无愧色，领略粗举，一往参诣，由是知之。|| 康僧渊刚到江南时，没有人知道他，常常在街市间往来，靠乞讨维持生活。有一天他忽然到殷浩那里去，正赶上宾客满座，殷浩让他坐下，跟他简单寒暄几句，就谈到了玄理。康僧渊无论言语还是意趣，都毫无逊色，他把领会到的大略一提，便直抵玄理深处，人们从此知道了他。
注：康僧渊：东晋僧人，本为西域人，生于长安，成帝时南渡。
注：周旋：往来。市肆：集市店铺。自营：自谋生计。
注：殷渊源：殷浩，字深源（唐人避讳作“渊源”）。许：处所。
注：领略：领会的要点。粗举：略加陈述。参诣：探究而达到的境界。
# 四十八｜殷谢诸人共集
原：殷、谢诸人共集，谢因问殷：“眼往属万形，万形来入眼不？”|| 殷浩、谢安等人聚在一起，谢安趁机问殷浩：“眼睛去注视万物，那么万物会进到眼睛里来吗？”
注：殷、谢：殷浩、谢安。
注：属（zhǔ）：注视。万形：万物。此问涉及认识中主客关系，是当时清谈话题。
# 四十九｜人有问殷中军
原：人有问殷中军：“何以将得位而梦棺器，将得财而梦矢秽？”殷曰：“官本是臭腐，所以将得而梦棺尸；财本是粪土，所以将得而梦秽污。”时人以为名通。|| 有人问殷浩：“为什么将要得到官位时会梦见棺材，将要得到钱财时会梦见粪便？”殷浩说：“官位本是腐臭的东西，所以快得到时就梦见棺材尸体；钱财本是粪土，所以快得到时就梦见污秽之物。”当时的人认为这是高明的解说。
注：殷中军：殷浩。棺器：棺材。
注：矢：通“屎”。
# 五十｜殷中军被废东阳
原：殷中军被废东阳，始看佛经。初视《维摩诘》，疑般若波罗密太多；后见《小品》，恨此语少。|| 殷浩被罢官废居东阳，才开始读佛经。起初看《维摩诘经》，嫌里面“般若波罗密”说得太多；后来读了《小品》，又遗憾这句话说得太少。
注：被废东阳：殷浩北伐失败，遭桓温弹劾，被废为平民，迁居东阳郡信安县。
注：《维摩诘》：《维摩诘所说经》，大乘佛教重要经典。
注：般若波罗密：梵语音译，意为以智慧达到彼岸，一般写作“般若波罗蜜”。
注：《小品》：《小品般若经》，专讲般若之义。
# 五十一｜支道林殷渊源
原：支道林、殷渊源俱在相王许，相王谓二人：“可试一交言。而才性殆是渊源崤函之固，君其慎焉！”支初作，改辙远之，数四交，不觉入其玄中。相王抚肩笑曰：“此自是其胜场，安可争锋！”|| 支道林、殷浩都在相王司马昱那里，相王对两人说：“你们不妨试着交谈一番。不过‘才性’问题大概是渊源的崤山函谷般的坚固堡垒，您可要当心啊！”支道林刚开始谈时，有意改换路数避开这个话题，可交锋了三四个回合后，不知不觉就被引入殷浩的玄理之中。相王拍着支道林的肩膀笑道：“这本来就是他的拿手领域，怎么能跟他争锋呢！”
注：相王：司马昱，时以会稽王居相位，故称，后即位为简文帝。
注：才性：魏晋清谈论题，讨论才能与本性的关系，殷浩尤擅此道。
注：崤（xiáo）函之固：崤山与函谷关，皆险要关隘，喻难以攻破。
注：改辙：改变路线，指转换话题。胜场：擅长之处。
# 五十二｜谢公因子弟集聚
原：谢公因子弟集聚，问：“《毛诗》何句最佳？”遏称曰：“昔我往矣，杨柳依依；今我来思，雨雪霏霏。”公曰：“讦谟定命，远猷辰告。”谓此句偏有雅人深致。|| 谢安趁子侄们聚会时问道：“《毛诗》中哪一句最好？”谢玄称引道：“当初我出征时，杨柳轻柔飘拂；如今我归来时，雪花纷纷飘落。”谢安说：“‘以宏大的谋略定下国家命运，把长远的计划及时宣告天下。’”认为这两句格外有高雅之士的深远情致。
注：《毛诗》：毛亨、毛苌所传的《诗经》，汉以后通行，故以代称《诗经》。
注：遏：谢玄小字遏，谢安之侄。所引出自《诗经·小雅·采薇》。思：语末助词。霏霏：雪盛貌。
注：讦（xū）谟定命，远猷（yóu）辰告：出自《诗经·大雅·抑》。讦，大；谟，谋略；猷，谋划；辰，按时。
注：雅人深致：雅士的深远情趣。谢玄重文辞之美，谢安重经国之怀，二人旨趣可见。
# 五十三｜张凭举孝廉
原：张凭举孝廉，出都，负其才气，谓必参时彦。欲诣刘尹，乡里及同举者共笑之。张遂诣刘。刘洗濯料事，处之下坐，唯通寒暑，神意不接。张欲自发无端。|| 张凭被举为孝廉，来到京城，他倚仗自己的才气，认为一定能跻身当时名流之列。他想去拜访刘惔，同乡和同时被举荐的人都嘲笑他。张凭还是去拜访了刘惔。刘惔正在洗涤、料理杂事，把他安排在下座，只跟他寒暄了几句，神情意态上并不理会他。张凭想自己挑起话头，却找不到机会。
注：张凭：字长宗，东晋吴郡人，后官至吏部郎、御史中丞。
注：孝廉：汉代以来选拔官吏的科目之一，由郡国举荐孝顺清廉之人。
注：参：跻身，列入。时彦：当时的俊才。
注：洗濯（zhuó）料事：洗涤、料理杂事。端：头绪。
原：顷之，长史诸贤来清言，客主有不通处，张乃遥于末坐判之，言约旨远，足畅彼我之怀，一坐皆惊。真长延之上坐，清言弥日，因留宿至晓。张退，刘曰：“卿且去，正当取卿共诣抚军。”|| 不一会儿，王濛等名士来清谈，主客之间有讲不通的地方，张凭就远远地在末座上加以评判，言辞简约而旨意深远，足以使双方的心意都畅达，满座的人都很吃惊。刘惔请他坐到上座，清谈了一整天，又留他住到天亮。张凭告辞时，刘惔说：“您先回去，我正要带您一起去拜见抚军。”
注：长史：王濛，曾任司徒左长史。
注：判：评断，裁决。
注：弥日：终日。正当：即将，正要。
注：抚军：司马昱，时任抚军大将军，即后来的简文帝。
原：张还船，同侣问何处宿，张笑而不答。须臾，真长遣传教觅张孝廉船，同侣惋愕。即同载诣抚军，至门，刘前进谓抚军曰：“下官今日为公得一太常博士妙选。”既前，抚军与之话言，咨嗟称善，曰：“张凭勃窣为理窟。”即用为太常博士。|| 张凭回到船上，同伴问他昨夜在哪里住，张凭笑而不答。不一会儿，刘惔派传令的小吏来找张孝廉的船，同伴们又惊又叹。刘惔随即和张凭同乘一车去拜见抚军，到了门口，刘惔先进去对抚军说：“下官今天替您找到了一位太常博士的上好人选。”张凭进见后，抚军跟他交谈，连连赞叹叫好，说：“张凭才华横溢，真是义理的渊薮。”当即任用他为太常博士。
注：传教：郡府中传达命令的小吏。惋愕：惊叹。
注：太常博士：太常属官，掌礼仪、备顾问，须学识渊博。妙选：上好的人选。
注：勃窣（sū）：形容才思奔涌、文采纷披之貌，存疑。理窟：义理汇聚之所。
# 五十四｜汰法师云
原：汰法师云：“六通、三明同归，正异名耳。”|| 竺法汰法师说：“‘六通’和‘三明’归趣相同，只是名称不同罢了。”
注：汰法师：竺法汰，东晋高僧，与道安同学，曾在建康瓦官寺讲《放光经》。
注：六通：佛家所说六种神通，即天眼通、天耳通、神足通、他心通、宿命通、漏尽通。
注：三明：宿命明、天眼明、漏尽明，与六通中的三通相当。正：只，仅。
# 五十五｜支道林许谢盛德共集
原：支道林、许、谢盛德共集王家，谢顾谓诸人：“今日可谓彦会。时既不可留，此集固亦难常，当共言咏，以写其怀。”许便问主人：“有《庄子》不？”正得《渔父》一篇。谢看题，便各使四坐通。|| 支道林、许询、谢安这几位德才兼美的人一起聚在王濛家，谢安环顾众人说：“今天可算是群贤盛会。时光既然留不住，这样的聚会也难得常有，大家应当一起谈论吟咏，来抒发各自的情怀。”许询便问主人：“有《庄子》吗？”恰好翻到《渔父》一篇。谢安看了题目，就让在座的人各自阐述。
注：许：许询。谢：谢安。王家：王濛家。盛德：品德美盛之人，此为对诸人的美称。
注：彦会：贤士之会。写：抒发。
注：《渔父》：《庄子》篇名，写渔父劝诫孔子返璞归真。通：阐释义理。
原：支道林先通，作七百许语，叙致精丽，才藻奇拔，众咸称善。于是四坐各言怀毕，谢问曰：“卿等尽不？”皆曰：“今日之言，少不自竭。”|| 支道林先阐述，说了七百来句话，铺叙精美华丽，才情辞藻奇特超群，众人都称好。于是在座的人各自抒发完了见解，谢安问道：“诸位说尽了吗？”大家都说：“今天的发言，很少有不竭尽自己所能的。”
注：叙致：叙述的条理与意趣。奇拔：奇特出众。
原：谢后粗难，因自叙其意，作万余语，才峰秀逸，既自难干，加意气拟托，萧然自得，四坐莫不厌心。支谓谢曰：“君一往奔诣，故复自佳耳。”|| 谢安随后先大略地提出疑难，接着陈述自己的见解，说了一万多字，才思锋芒秀拔超逸，本已难以辩驳，再加上意气寄托其中，潇洒自得，满座的人无不心满意足。支道林对谢安说：“您一路直奔要旨，所以自然格外精彩啊。”
注：粗难：大略地提出诘难。
注：难干：难以冒犯、反驳。拟托：寄托。萧然：潇洒超脱的样子。
注：厌心：心中满足。奔诣：径直到达深处。
# 五十六｜殷中军孙安国王谢
原：殷中军、孙安国、王、谢能言诸贤，悉在会稽王许，殷与孙共论《易象妙于见形》，孙语道合，意气干云。一坐咸不安孙理，而辞不能屈。会稽王慨然叹曰：“使真长来，故应有以制彼。”即迎真长，孙意己不如。|| 殷浩、孙盛、王濛、谢尚这些善于清谈的名士，都聚在会稽王司马昱那里，殷浩和孙盛一起讨论《易象妙于见形》，孙盛的言论自成道理，意气高昂直冲云霄。满座的人都不认同孙盛的道理，却在言辞上驳不倒他。会稽王感慨地叹道：“要是刘真长来了，一定有办法制服他。”随即派人去接刘惔，孙盛心里已经觉得自己比不上了。
注：孙安国：孙盛，字安国，东晋史学家，著有《晋阳秋》。王、谢：王濛、谢尚。
注：会稽王：司马昱，即后来的简文帝。
注：《易象妙于见形》：孙盛所作的论文，已佚，论《易》象之理。
注：道合：合于道理，自成其说。干云：直冲云霄，形容气势盛。
原：真长既至，先令孙自叙本理。孙粗说己语，亦觉殊不及向。刘便作二百许语，辞难简切，孙理遂屈。一坐同时拊掌而笑，称美良久。|| 刘惔到了以后，先让孙盛自己陈述原来的论点。孙盛大略说了说自己的见解，也觉得远不如刚才说得好。刘惔于是说了两百来句话，诘难简明切要，孙盛的论点终于被驳倒了。满座的人同时拍手大笑，称赞了好久。
注：真长：刘惔，字真长。本理：原来的论点。向：先前。
注：辞难：言辞诘难。简切：简明切要。拊（fǔ）掌：拍手。
# 五十七｜僧意在瓦官寺中
原：僧意在瓦官寺中，王苟子来，与共语，便使其唱理。意谓王曰：“圣人有情不？”王曰：“无。”重问曰：“圣人如柱邪？”王曰：“如筹算。虽无情，运之者有情。”僧意云：“谁运圣人邪？”苟子不得答而去。|| 僧意住在瓦官寺里，王修来了，跟他交谈，僧意就请王修先提出论题。僧意问王修：“圣人有情吗？”王修说：“没有。”又问：“那圣人像柱子一样吗？”王修说：“像算筹。算筹虽然无情，运用它的人却是有情的。”僧意说：“那么是谁在运用圣人呢？”王修答不上来，就走了。
注：僧意：东晋僧人，事迹不详。瓦官寺：建康名寺。
注：王苟子：王修，小字苟子。唱理：首先提出义理。唱，同“倡”。
注：圣人有情无情：魏晋玄学重要论题，何晏主张圣人无情，王弼主张圣人有情而不为情所累。
注：筹算：计算用的筹码。
# 五十八｜司马太傅问谢车骑
原：司马太傅问谢车骑：“惠子其书五车，何以无一言入玄？”谢曰：“故当是其妙处不传。”|| 司马道子问谢玄：“惠子的著作有五车之多，为什么没有一句话涉及玄理？”谢玄说：“想必是他的精妙之处没有流传下来吧。”
注：司马太傅：司马道子，东晋会稽王，曾任太傅。谢车骑：谢玄。
注：惠子其书五车：语出《庄子·天下》“惠施多方，其书五车”。惠子即惠施，战国名家人物，庄子的友人。
注：入玄：涉及玄理。故当：想必，大概。
# 五十九｜殷中军被废
原：殷中军被废，徙东阳，大读佛经，皆精解，唯至事数处不解。遇见一道人，问所签，便释然。|| 殷浩被罢官，迁居东阳，大量阅读佛经，都能透彻理解，只是读到“事数”的地方弄不明白。后来遇见一位僧人，向他请教自己标了签的地方，便豁然明白了。
注：殷中军：殷浩。被废徙东阳：殷浩北伐失败，被废为平民，迁居东阳郡信安县。
注：事数：佛教中成组列举的名相，如五阴、十二入、四谛、十二因缘等。
注：道人：此指僧人。签：读书时在疑难处所加的标签。释然：疑团消除的样子。
# 六十｜殷仲堪精核玄论
原：殷仲堪精核玄论，人谓莫不研究。殷乃叹曰：“使我解‘四本’，谈不翅尔。”|| 殷仲堪精心考究玄学理论，人们说他没有什么不研究透的。殷仲堪却感叹道：“假如我能弄懂‘四本’，我的谈论就不止现在这样了。”
注：殷仲堪：东晋末名士，善清谈，后任荆州刺史。精核：精心考察。
注：四本：指才性同、才性异、才性合、才性离四种论说，三国钟会曾汇集为《四本论》。
注：不翅（chì）：不只，不止。翅，通“啻”。尔：如此。
# 六十一｜殷荆州曾问远公
原：殷荆州曾问远公：“《易》以何为体？”答曰：“《易》以感为体。”殷曰：“铜山西崩，灵钟东应，便是《易》耶？”远公笑而不答。|| 殷仲堪曾问慧远：“《周易》以什么为本体？”慧远答：“《周易》以感应为本体。”殷仲堪说：“西边的铜山崩塌，东边的灵钟就随之鸣响，这就是《周易》吗？”慧远笑笑没有回答。
注：殷荆州：殷仲堪，曾任荆州刺史。远公：慧远，东晋高僧，道安弟子，久居庐山东林寺，后世尊为净土宗初祖。
注：体：本体。感：感应，交感相应。
注：铜山西崩，灵钟东应：相传汉代未央宫前的钟无故自鸣，东方朔认为是铜山崩塌、同类相感所致，不久蜀地果然报告山崩。殷仲堪借此问难，意含诘疑。
# 六十二｜羊孚弟娶王永言女
原：羊孚弟娶王永言女，及王家见婿，孚送弟俱往。时永言父东阳尚在，殷仲堪是东阳女婿，亦在坐。孚雅善理义，乃与仲堪道《齐物》，殷难之。羊云：“君四番后当得见同。”殷笑曰：“乃可得尽，何必相同。”乃至四番后一通。殷咨嗟曰：“仆便无以相异！”叹为新拔者久之。|| 羊孚的弟弟娶了王永言的女儿，到王家会见女婿时，羊孚陪弟弟一同前往。当时王永言的父亲王东阳还在世，殷仲堪是王东阳的女婿，也在座。羊孚很善于谈论义理，就跟殷仲堪谈起《齐物论》，殷仲堪对他提出诘难。羊孚说：“您辩过四个回合后，就会和我的见解相同了。”殷仲堪笑道：“能把道理谈透就行，何必一定相同。”等辩到四个回合后，两人的见解果然相通了。殷仲堪赞叹说：“我已经没有什么不同的见解了！”对羊孚的新颖卓异赞叹了很久。
注：羊孚：字子道，东晋名士，善言理。其弟名羊辅。
注：王永言：王讷之，字永言。东阳：王临之，王永言之父，曾任东阳太守。
注：雅：很，极。《齐物》：《庄子·齐物论》。
注：番：回合。新拔：新颖拔俗。
# 六十三｜殷仲堪云
原：殷仲堪云：“三日不读《道德经》，便觉舌本间强。”|| 殷仲堪说：“三天不读《道德经》，就觉得舌根发僵。”
注：《道德经》：即《老子》。
注：舌本：舌根。强（jiàng）：僵硬，不灵活。言不读《老子》便谈吐不利。
# 六十四｜提婆初至
原：提婆初至，为东亭第讲《阿毗昙》。始发讲，坐裁半，僧弥便云：“都已晓。”即于坐分数四有意道人，更就余屋自讲。提婆讲竟，东亭问法冈道人曰：“弟子都未解，阿弥那得已解？所得云何？”曰：“大略全是，故当小未精核耳。”|| 僧伽提婆刚到京城时，在东亭侯王珣府上讲解《阿毗昙》。刚开讲，才讲到一半，王珉就说：“我全都明白了。”随即在座中分出三四位有见识的僧人，到别的屋里自己讲起来。提婆讲完后，王珣问法冈和尚：“我还完全没弄懂，阿弥怎么就已经懂了？他领会得怎么样？”法冈说：“大体上全对，只是小处还不够精细罢了。”
注：提婆：僧伽提婆，东晋时来华的西域僧人，罽宾国人，曾在庐山、建康译经。
注：东亭：王珣，字元琳，封东亭侯，王导之孙。《阿毗昙》：即《阿毗达磨》，佛教论藏，意为“对法”。
注：裁：通“才”。僧弥：王珉，小字僧弥，王珣之弟；下文“阿弥”是对他的昵称。
注：数四：三四个。有意道人：有见识的僧人。法冈道人：东晋僧人，事迹不详。精核：精细周详。
# 六十五｜桓南郡与殷荆州共谈
原：桓南郡与殷荆州共谈，每相攻难。年余后但一两番。桓自叹才思转退，殷云：“此乃是君转解。”|| 桓玄和殷仲堪一起清谈，常常相互攻驳诘难。过了一年多，每次只辩一两个回合了。桓玄自己叹息才思渐渐减退，殷仲堪说：“这其实是您的理解逐渐长进了。”
注：桓南郡：桓玄，桓温之子，袭封南郡公。殷荆州：殷仲堪。
注：攻难：辩驳诘难。转：渐渐。
# 六十六｜文帝尝令东阿王
原：文帝尝令东阿王七步中作诗，不成者行大法。应声便为诗曰：“煮豆持作羹，漉菽以为汁。萁在釜下然，豆在釜中泣。本自同根生，相煎何太急！”帝深有惭色。|| 魏文帝曹丕曾命令东阿王曹植在走七步的工夫里作成一首诗，作不成就要处以极刑。曹植应声作诗道：“煮豆子来做羹汤，滤过豆子取它的汁。豆秸在锅底下燃烧，豆子在锅里哭泣。我们本来是同一条根上生出来的，你煎熬我为何这样急迫！”文帝听了，脸上露出深深的惭愧之色。
注：文帝：魏文帝曹丕。东阿王：曹植，字子建，曹丕之弟，曾封东阿王，后封陈王。
注：大法：极刑，死刑。
注：漉（lù）：过滤。菽：豆类。
注：萁（qí）：豆秸。然：同“燃”。
# 六十七｜魏朝封晋文王为公
原：魏朝封晋文王为公，备礼九锡，文王固让不受。公卿将校当诣府敦喻，司空郑冲驰遣信就阮籍求文。籍时在袁孝尼家，宿醉扶起，书札为之，无所点定，乃写付使。时人以为神笔。|| 魏朝要封晋文王司马昭为晋公，备齐了九锡之礼，司马昭坚决推辞不肯接受。公卿将校要到他府上去劝说，司空郑冲急忙派人到阮籍那里求一篇劝进文章。阮籍当时在袁孝尼家，昨夜的醉意还没消，被人扶起来，在木札上写成文稿，一字不改，就誊写好交给了来使。当时的人认为这是神来之笔。
注：晋文王：司马昭，魏末权臣，其子司马炎代魏后追尊为文帝。
注：九锡：帝王赐给重臣的九种器物，为最高礼遇，汉魏以来常为篡位的前奏。
注：敦喻：督促劝说。郑冲：魏末任司空。信：使者。
注：袁孝尼：袁准，字孝尼，魏晋间学者。书札：写在木札上。点定：修改文字。
