# 本门导读
题解：“术解”指精通某种专门技艺。本门记魏晋人在音律、相墓占卜、相马辨味、医药诸方面的异能，郭璞一人独占数则，可见当时方术风气之盛。

# 一｜荀勖善解音声
原：荀勖善解音声，时论谓之“闇解”。遂调律吕，正雅乐。每至正会，殿庭作乐，自调宫商，无不谐韵。阮咸妙赏，时谓“神解”。每公会作乐，而心谓之不调，既无一言直勖，意忌之，遂出阮为始平太守。后有一田父耕于野，得周时玉尺，便是天下正尺。荀试以校己所治钟鼓、金石、丝竹，皆觉短一黍，于是伏阮神识。|| 荀勖精通乐理，当时舆论说他是“默会于心”的行家。于是由他来调定音律，整顿朝廷雅乐。每逢元旦大朝会，殿前奏乐，他亲自调校五音，没有一处不和谐的。阮咸对音乐的鉴赏更是绝妙，时人称他为“神解”。每次公宴奏乐，阮咸心里总觉得音调不准，却始终没说过一句荀勖调得对，荀勖心里便忌恨他，于是把阮咸外放为始平太守。后来有个老农在田里耕地，挖得一把周代的玉尺，正是天下标准的尺度。荀勖拿它去校验自己所制的钟鼓、金石、丝竹各种乐器，发现全都短了一粒黍子那么长，这才佩服阮咸识见神妙。
注：荀勖（xù）：字公曾，颍川颍阴人，西晋大臣，官至中书监、尚书令，曾主持修订律吕。
注：闇（ān）解：闇同“谙”，熟习通晓，指不假外求、心中自明。
注：律吕：古代定音的十二律，阳为律、阴为吕，合称律吕。
注：阮咸：字仲容，阮籍之侄，“竹林七贤”之一，精通音律，善弹琵琶。
注：直：以为对，认可。
注：一黍：古以黍粒排列定长度，一黍约当一分，形容相差极微。
注：伏：同“服”，信服。

# 二｜荀勖尝在晋武帝坐上
原：荀勖尝在晋武帝坐上食笋进饭，谓在坐人曰：“此是劳薪炊也。”坐者未之信，密遣问之，实用故车脚。|| 荀勖有一次在晋武帝的宴席上吃笋就饭，对同座的人说：“这是用‘劳薪’烧出来的。”在座的人不信，暗中派人去厨下打听，果然是用旧车轮子当柴烧的。
注：晋武帝：司马炎，西晋开国皇帝。
注：劳薪：用久经劳损的木料做的柴，这里指旧车轮。
注：车脚：车轮。

# 三｜人有相羊祜父墓
原：人有相羊祜父墓，后应出受命君。祜恶其言，遂掘断墓后以坏其势。相者立视之，曰：“犹应出折臂三公。”俄而祜坠马折臂，位果至公。|| 有个看风水的人相了羊祜父亲的坟墓，说他家后代当出一位承受天命的君主。羊祜讨厌这话，就把坟墓后面挖断，破坏它的地势。看风水的人站在那里看了看，说：“还会出一位断了胳膊的三公。”不久羊祜从马上摔下来折断了手臂，官位果然做到了三公。
注：羊祜：字叔子，泰山南城人，西晋名将，镇守襄阳，筹划灭吴，死后追赠太傅。
注：受命君：承受天命的君主，即开国帝王。
注：恶（wù）：厌恶。
注：势：地势，风水家所谓山川形势。
注：三公：朝廷最高的三个官位，晋代以太尉、司徒、司空为三公。

# 四｜王武子善解马性
原：王武子善解马性。尝乘一马，著连钱障泥，前有水，终日不肯渡。王云：“此必是惜障泥。”使人解去，便径渡。|| 王济很懂马的脾性。他曾骑一匹马，马身上披着连钱花纹的障泥，前面有条河，马一整天都不肯过。王济说：“这一定是舍不得弄脏它的障泥。”叫人把障泥解下来，马就径直过去了。
注：王武子：王济，字武子，太原晋阳人，王浑之子，晋武帝的女婿，豪奢爱马。
注：著（zhuó）：穿戴，披挂。
注：连钱：铜钱一个接一个相连的花纹。
注：障泥：垂在马鞍两侧遮挡泥水的垫子。

# 五｜陈述为大将军掾
原：陈述为大将军掾，甚见爱重。及亡，郭璞往哭之，甚哀，乃呼曰：“嗣祖，焉知非福！”俄而大将军作乱，如其所言。|| 陈述做大将军王敦的属官，很受器重。他死后，郭璞前去吊哭，哭得十分悲伤，却喊道：“嗣祖啊，怎知这不是福气呢！”不久王敦起兵作乱，正应了郭璞的话。
注：陈述：字嗣祖，颍川许昌人，有美名，任王敦的掾属，早卒。
注：大将军：指王敦，东晋初以大将军镇武昌，后起兵叛乱。
注：掾（yuàn）：属官。
注：郭璞：字景纯，河东闻喜人，两晋之际的文学家、训诂家，精于卜筮风水，后因劝阻王敦谋反被杀。

# 六｜晋明帝解占冢宅
原：晋明帝解占冢宅，闻郭璞为人葬，帝微服往看，因问主人：“何以葬龙角？此法当灭族！”主人曰：“郭云此葬龙耳，不出三年，当致天子。”帝问：“为是出天子邪？”答曰：“非出天子，能致天子问耳。”|| 晋明帝懂得占卜墓地吉凶，听说郭璞在替人选地下葬，便换了便服前去察看，顺便问墓主：“为什么葬在龙角上？照这种葬法是要灭族的！”主人说：“郭璞说这是葬在龙耳上，不出三年，就会招来天子。”明帝问：“是说会出天子吗？”主人答道：“不是出天子，是能招得天子来问话罢了。”
注：晋明帝：司马绍，东晋第二位皇帝。
注：冢宅：坟墓。
注：微服：帝王官员换上平民衣服出行，以免被人认出。
注：龙角、龙耳：风水家把绵延起伏的山脉比作龙，龙角、龙耳是龙形山势上的不同部位，吉凶各异。
注：致：招来。

# 七｜郭景纯过江
原：郭景纯过江，居于暨阳，墓去水不盈百步。时人以为近水，景纯曰：“将当为陆。”今沙涨，去墓数十里皆为桑田。其诗曰：“北阜烈烈，巨海混混，垒垒三坟，唯母与昆。”|| 郭璞南渡长江后，住在暨阳，他家的坟墓离江水不到一百步。当时人都认为离水太近，郭璞说：“这里将来会变成陆地。”如今泥沙淤积，离坟墓几十里的地方都成了农田。他有诗写道：“北边的土山巍巍高耸，大海浩浩奔流，三座坟茔累累相连，安葬着我的母亲和兄长。”
注：过江：指西晋末北方士人渡江南迁。
注：暨阳：县名，在今江苏江阴一带。
注：桑田：耕地，与“沧海”相对，暗合沧海桑田之意。
注：阜：土山。
注：烈烈：高峻的样子。
注：混混：同“滚滚”，水势浩大奔流。
注：垒垒：重叠相连的样子。
注：唯：句首语气词。
注：昆：兄。

# 八｜王丞相令郭璞试作一卦
原：王丞相令郭璞试作一卦。卦成，郭意色甚恶，云：“公有震厄。”王问：“有可消伏理不？”郭曰：“命驾西出数里，得一柏树，截断如公长，置床上常寝处，灾可消矣。”王从其语，数日中，果震柏粉碎。子弟皆称庆。大将军云：“君乃复委罪于树木！”|| 王导叫郭璞试着给他起一卦。卦象出来，郭璞神色很难看，说：“您有遭雷击的灾祸。”王导问：“有没有办法消除？”郭璞说：“您坐车往西走几里路，找到一棵柏树，截下一段跟您身长一样的，放在床上平常睡觉的地方，灾祸就可以消除了。”王导照他的话做了，几天之内，那段柏木果然被雷劈得粉碎。家中子弟都来道贺。大将军王敦却说：“你居然把罪过推到一棵树身上了！”
注：王丞相：王导，字茂弘，琅邪临沂人，东晋开国元勋，历仕三朝，官至丞相。
注：震厄：雷击之灾。震，雷。
注：消伏：消除、制伏。
注：不（fǒu）：同“否”。
注：命驾：吩咐备车出行。
注：大将军：王敦，王导的堂兄。
注：委罪：推卸罪责。王敦此语是调侃，意谓王导拿柏树当了替身。

# 九｜桓公有主簿
原：桓公有主簿，善别酒，有酒辄令先尝，好者谓“青州从事”，恶者谓“平原督邮”。青州有齐郡，平原有鬲县；“从事”言到脐，“督邮”言在鬲上住。|| 桓温手下有个主簿，很会品酒，桓温一有酒就叫他先尝，好酒他称为“青州从事”，劣酒称为“平原督邮”。原来青州有个齐郡，平原有个鬲县：“从事”是说酒力一直到得了肚脐，“督邮”是说酒力只停在膈膜上面。
注：桓公：桓温，字元子，谯国龙亢人，东晋权臣，官至大司马。
注：主簿：掌管文书簿籍的属官。
注：从事：州刺史的属官；
注：督邮：郡守的属官，一高一低，用来分别好酒劣酒。
注：齐、脐同音，鬲、膈同音，这是借地名谐音的隐语：好酒下肚直达脐下，劣酒只到胸膈。
注：鬲（gé）：同“膈”，膈膜。

# 十｜郗愔信道甚精勤
原：郗愔信道甚精勤，常患腹内恶，诸医不可疗。闻于法开有名，往迎之。既来便脉，云：“君侯所患，正是精进太过所致耳。”合一剂汤与之。一服即大下，去数段许纸，如拳大，剖看，乃先所服符也。|| 郗愔信奉天师道，十分虔诚用功，常常肚子里不舒服，许多医生都治不好。他听说于法开很有名，就去把他请来。于法开一到就给他诊脉，说：“君侯这病，正是修道太用功造成的。”于是配了一剂汤药给他。一服下去就大泻，泻出好几团纸，每团有拳头大，剖开一看，原来是他先前吞下去的符箓。
注：郗愔（xī yīn）：字方回，高平金乡人，郗鉴之子，官至司空，与其弟郗昙皆奉天师道。
注：于法开：东晋僧人，精通医术，与支道林争名。
注：君侯：对有爵位或高官者的敬称。
注：精进：本为佛道两家用语，指专心修持不懈，这里带有讽意。
注：大下：大泻。
注：符：道士书画的符箓，信徒常烧化或吞服以求驱邪治病。

# 十一｜殷中军妙解经脉
原：殷中军妙解经脉，中年都废。有常所给使，忽叩头流血。浩问其故，云：“有死事，终不可说。”诘问良久，乃云：“小人母年垂百岁，抱疾来久，若蒙官一脉，便有活理，讫就屠戮无恨。”浩感其至性，遂令舁来，为诊脉处方。始服一剂汤便愈。于是悉焚经方。|| 殷浩精通医术，到中年就全都撂下了。有个平日供他使唤的仆役，忽然向他磕头，磕得血流满面。殷浩问他缘故，他说：“这是一件关乎性命的事，可终究说不出口。”追问了好久，他才说：“小人的母亲快一百岁了，病了很久，若能承蒙长官给她把一次脉，就有活下去的指望，治完了就是把我杀了也没有怨恨。”殷浩被他的孝心感动，就叫人把老人抬来，给她诊脉开方。刚服了一剂汤药，病就好了。从此殷浩把医书药方全都烧掉了。
注：殷中军：殷浩，字渊源，陈郡长平人，东晋清谈名家，官至中军将军，北伐失败后被废为庶人。
注：经脉：本指人体气血运行的通道，这里代指医术。
注：给使：供差遣的仆役。
注：官：仆役对主人的称呼。
注：讫：完毕，指诊治结束之后。
注：至性：天性中的至诚，这里指孝心。
注：舁（yú）：抬。
注：经方：医书和药方。殷浩焚书的用意，原文未明说，或是不愿再以医术受人求请，存疑。
