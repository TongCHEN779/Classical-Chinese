# 本门导读
题解：“识鉴”就是识人、断事的眼力。本门所记，多是魏晋人物凭一面之缘、一席之谈，便预判他人的成败祸福与时局走向，事后往往应验，可见当时品鉴人物风气之盛。
# 一｜曹公少时见乔玄
原：曹公少时见乔玄，玄谓曰：“天下方乱，群雄虎争，拨而理之，非君乎？然君实是乱世之英雄，治世之奸贼。恨吾老矣，不见君富贵，当以子孙相累。”|| 曹操年轻时去拜见乔玄，乔玄对他说：“天下眼看就要大乱，群雄像猛虎一样相争，能拨乱反正、收拾这个局面的，不就是你吗？不过你实在是乱世里的英雄，太平世道里的奸贼。可惜我老了，看不到你富贵那一天，只好把子孙托付给你了。”
注：曹公：曹操。
注：乔玄：字公祖，东汉梁国睢阳人，官至太尉，以善于识人著称。
注：拨而理之：拨乱而治理之，即平定乱局。
注：相累：相烦劳，这里是托付照顾的客气说法。
# 二｜曹公问裴潜曰
原：曹公问裴潜曰：“卿昔与刘备共在荆州，卿以备才如何？”潜曰：“使居中国，能乱人，不能为治；若乘边守险，足为一方之主。”|| 曹操问裴潜：“你从前和刘备一起待在荆州，你看刘备的才干怎么样？”裴潜说：“让他待在中原，只能扰乱百姓，治理不了；要是让他占据边地、扼守险要，足以做一方的霸主。”
注：裴潜：字文行，河东闻喜人，曾避乱荆州，后归曹操，魏时官至尚书令。
注：中国：指中原地区。
注：乘边守险：凭借边远之地，据守险要。
# 三｜何晏、邓飏、夏侯玄并求傅嘏交
原：何晏、邓飏、夏侯玄并求傅嘏交，而嘏终不许。诸人乃因荀粲说合之，谓嘏曰：“夏侯太初一时之杰士，虚心于子，而卿意怀不可交。合则好成，不合则致隙。二贤若穆，则国之休。此蔺相如所以下廉颇也。”|| 何晏、邓飏、夏侯玄都想和傅嘏结交，傅嘏始终不肯。他们就托荀粲去撮合，荀粲对傅嘏说：“夏侯太初是当世的杰出人物，对你很是虚心，你心里却觉得不能和他交往。合得来就能成就好事，合不来就会结下嫌隙。两位贤者若能和睦，那是国家的福分。这正是当年蔺相如肯退让廉颇的缘故啊。”
注：何晏：字平叔，曹操养子兼女婿，好老庄，为正始玄学领袖，后为司马懿所杀。邓飏：字玄茂，与何晏同党，同时被杀。
注：夏侯玄：字太初，魏名士，后因谋诛司马师事泄被杀。傅嘏（gǔ）：字兰石，魏臣，以识鉴见称。
注：荀粲：字奉倩，荀彧之子，善谈玄理。说合：从中介绍撮合。
注：蔺相如所以下廉颇：赵相蔺相如以国事为重，屡次避让廉颇，终成将相之和。休：美善，福庆。
原：傅曰：“夏侯太初志大心劳，能合虚誉，诚所谓利口覆国之人。何晏、邓飏有为而躁，博而寡要，外好利而内无关籥，贵同恶异，多言而妒前。多言多衅，妒前无亲。以吾观之，此三贤者皆败德之人尔，远之犹恐罹祸，况可亲之邪？”后皆如其言。|| 傅嘏说：“夏侯太初志向大而心思劳碌，善于聚拢虚名，正是古人说的那种凭一张利嘴就能颠覆国家的人。何晏、邓飏想有作为却浮躁，学问广博却抓不住要领，表面上贪图利益，内心却没有约束，喜欢意见相同的，厌恶意见不同的，话多而嫉妒胜过自己的人。话多就容易招来祸端，嫉妒强过自己的人就不会有人亲近。依我看，这三位贤者都是败坏德行的人罢了，离他们远一点尚且怕受牵连，何况去亲近他们呢？”后来三人的下场都像他说的那样。
注：心劳：心思用得太多，劳神费力。
注：利口覆国：语本《论语·阳货》“恶利口之覆邦家者”，指巧言善辩足以倾覆国家。
注：关籥（yuè）：门闩锁钥，比喻内心的约束检点。
注：妒前：嫉妒超过自己的人。衅：嫌隙，祸端。罹：遭受。
# 四｜晋武帝讲武于宣武场
原：晋武帝讲武于宣武场，帝欲偃武修文，亲自临幸，悉召群臣。山公谓不宜尔，因与诸尚书言孙、吴用兵本意，遂究论，举坐无不咨嗟，皆曰：“山少傅乃天下名言。”|| 晋武帝在宣武场讲论武事，他想停息武备、振兴文教，便亲自驾临，把群臣全都召来。山涛认为不该这样，于是和各位尚书谈起孙武、吴起用兵的本意，深入推究论述，满座的人无不赞叹，都说：“山少傅的话真是天下的至理名言。”
注：晋武帝：司马炎，西晋开国皇帝。宣武场：洛阳城北的演武场。
注：偃武修文：停息武备，修明文教。临幸：帝王亲临。
注：山公：山涛，字巨源，“竹林七贤”之一，曾任太子少傅，故称山少傅。
注：孙、吴：孙武、吴起，春秋战国时的兵家。咨嗟：赞叹。
原：后诸王骄汰，轻遘祸难，于是寇盗处处蚁合，郡国多以无备，不能制服，遂渐炽盛，皆如公言。时人以谓山涛不学孙、吴，而暗与之理会。王夷甫亦叹云：“公暗与道合。”|| 后来分封的诸王骄纵奢侈，轻易就酿成祸乱，于是盗贼到处像蚂蚁一样聚集，各郡国大多因为没有武备而无法制服，乱势便越来越盛，全都应了山涛的话。当时人认为山涛没有学过孙、吴兵法，却暗中与其道理相合。王衍也感叹说：“山公的见解与大道暗合。”
注：骄汰：骄纵奢侈。汰，过分。遘（gòu）：造成，遭遇。
注：蚁合：像蚂蚁那样聚集，极言其多。
注：王夷甫：王衍，字夷甫，西晋清谈领袖。
# 五｜王夷甫父乂为平北将军
原：王夷甫父乂为平北将军，有公事，使行人论，不得。时夷甫在京师，命驾见仆射羊祜、尚书山涛。夷甫时总角，姿才秀异，叙致既快，事加有理，涛甚奇之。既退，看之不辍，乃叹曰：“生儿不当如王夷甫邪？”羊祜曰：“乱天下者，必此子也。”|| 王衍的父亲王乂任平北将军，有件公事要申说，派使者去陈述，没有办成。当时王衍在京城，便叫人备车去见仆射羊祜和尚书山涛。王衍那时还是个孩童，姿容才华都很出众，陈述事情既爽快，又说得头头是道，山涛很惊奇。王衍告退后，山涛还一直目送着他，感叹道：“生儿子不就该像王夷甫这样吗？”羊祜却说：“将来搅乱天下的，一定是这孩子。”
注：王乂：王衍之父，官至平北将军。行人：使者。
注：羊祜：字叔子，西晋名臣，力主伐吴，曾任尚书左仆射。
注：总角：古时儿童把头发扎成两个髻，借指童年。
注：叙致：叙述事理，陈说的条理。
# 六｜潘阳仲见王敦小时
原：潘阳仲见王敦小时，谓曰：“君蜂目已露，但豺声未振耳。必能食人，亦当为人所食。”|| 潘滔见到小时候的王敦，对他说：“你那胡蜂一样的眼睛已经露出来了，只是豺狼般的声音还没发出来罢了。你将来必定能吃人，也必定会被人吃掉。”
注：潘阳仲：潘滔，字阳仲，西晋荥阳人，有识鉴。
注：王敦：字处仲，王导堂兄，东晋初权臣，后举兵叛乱，病死军中。
注：蜂目、豺声：语本《左传·文公元年》形容楚太子商臣“蜂目而豺声，忍人也”，指凶狠残忍之相。
# 七｜石勒不知书
原：石勒不知书，使人读《汉书》。闻郦食其劝立六国后，刻印将授之，大惊曰：“此法当失，云何得遂有天下？”至留侯谏，乃曰：“赖有此耳！”|| 石勒不识字，叫人给他读《汉书》。听到郦食其劝刘邦封立六国的后代，已经刻好印要授给他们，石勒大惊道：“这个办法要坏事，怎么还能得到天下？”等听到留侯张良进谏劝阻，才说：“全靠有这个人啊！”
注：石勒：字世龙，羯族人，十六国时后赵的建立者，不识字而有雄略。
注：郦食其（lì yì jī）：秦汉之际刘邦的谋士，曾劝刘邦复立六国之后以弱楚。
注：留侯：张良，封留侯。他以“借箸”为刘邦分析立六国后之弊，刘邦遂销毁已刻之印。
# 八｜卫玠年五岁
原：卫玠年五岁，神衿可爱。祖太保曰：“此儿有异，顾吾老，不见其大耳！”|| 卫玠五岁时，神情气度十分可爱。他祖父太保卫瓘说：“这孩子与众不同，只可惜我老了，看不到他长大了！”
注：卫玠：字叔宝，西晋名士，以容貌俊美、善谈玄理著称。
注：神衿：神态和襟怀。
注：祖太保：卫玠的祖父卫瓘（guàn），官至太保，后为楚王司马玮所杀。顾：只是，但。
# 九｜刘越石云
原：刘越石云：“华彦夏识能不足，强果有余。”|| 刘琨说：“华彦夏见识才能不够，倔强果决却有余。”
注：刘越石：刘琨，字越石，西晋末名将、诗人，坚守并州抗击刘渊、石勒。
注：华彦夏：华轶，字彦夏，西晋末任江州刺史，不服琅邪王司马睿（后来的晋元帝）之命，兵败被杀。
注：强果：刚强果断，这里略含固执之意。
# 十｜张季鹰辟齐王东曹掾
原：张季鹰辟齐王东曹掾，在洛，见秋风起，因思吴中菰菜羹、鲈鱼脍，曰：“人生贵得适意尔，何能羁宦数千里以要名爵！”遂命驾便归。俄而齐王败，时人皆谓为见机。|| 张翰被齐王征召为东曹掾，在洛阳看见秋风起了，便想念起家乡吴中的菰菜羹和鲈鱼脍，说：“人生可贵的是能称心如意罢了，怎么能在几千里外做官受拘束，去求取名位呢！”于是叫人备车，当即回乡。不久齐王失败，当时人都说他能预见先机。
注：张季鹰：张翰，字季鹰，吴郡人，有文才，放达不拘。
注：辟：征召。齐王：司马冏，八王之一，曾专政，后兵败被杀。东曹掾：官府中东曹的属官。
注：菰（gū）菜：茭白。鲈鱼脍（kuài）：切细的鲈鱼片。后世以“莼鲈之思”指思乡归隐之情。
注：羁宦：客居他乡做官。要（yāo）：求取。见机：事先察觉事态的苗头。
# 十一｜诸葛道明初过江左
原：诸葛道明初过江左，自名道明，名亚王、庾之下。先为临沂令，丞相谓曰：“明府当为黑头公。”|| 诸葛恢刚渡江到江南时，自己取名叫道明，名望仅次于王导、庾亮。他先前做临沂县令时，丞相王导就对他说：“您一定会在头发还黑的时候就位列三公。”
注：诸葛道明：诸葛恢，字道明，琅邪阳都人，东晋时官至尚书令。“自名道明”一句，诸本理解不一，存疑。
注：江左：江东，即长江下游以南地区。亚：次一等。王、庾：王导、庾亮。
注：丞相：王导。明府：对郡守、县令的尊称。
注：黑头公：年纪尚轻、头发未白时就位至三公。
# 十二｜王平子素不知眉子
原：王平子素不知眉子，曰：“志大其量，终当死坞壁间。”|| 王澄一向不赏识王玄，说：“他的志向超过了他的器量，最后会死在乡野的堡垒之中。”
注：王平子：王澄，字平子，王衍之弟，以放达著称。
注：眉子：王玄，字眉子，王衍之子，少有才名，后在乱中被害。
注：不知：不了解，不看重。坞壁：乱世中民间修筑的防御小堡。
# 十三｜王大将军始下
原：王大将军始下，杨朗苦谏不从，遂为王致力，乘中鸣云露车径前，曰：“听下官鼓音，一进而捷。”王先把其手曰：“事克，当相用为荆州。”既而忘之，以为南郡。|| 大将军王敦起兵东下时，杨朗苦苦劝阻，王敦不听，杨朗只好为王敦出力，乘着中鸣云露车一直向前，说：“听我的鼓声，一冲就能取胜。”王敦事先拉着他的手说：“事成之后，就任用你做荆州刺史。”后来却忘了这话，只让他做了南郡太守。
注：王大将军：王敦。始下：指王敦从武昌起兵顺江东下进攻建康。
注：杨朗：字世彦，弘农人，东晋时官至雍州刺史。
注：中鸣云露车：一种设有高台、可登高望敌并击鼓指挥的战车，形制细节存疑。
注：南郡：郡名，治所在今湖北江陵。
原：王败后，明帝收朗，欲杀之。帝寻崩，得免。后兼三公，署数十人为官属。此诸人当时并无名，后皆被知遇。于时称其知人。|| 王敦失败后，明帝逮捕了杨朗，要杀他。不久明帝去世，杨朗才得以幸免。后来他兼任三公曹，委任了几十个人做属官。这些人当时都没有名气，后来全都受到赏识重用。当时人称赞他善于识人。
注：明帝：晋明帝司马绍。收：拘捕。寻：不久。
注：三公：此处指三公曹，尚书省中掌选拔官吏的部门，一说即三公之职，存疑。
注：知遇：受到赏识和重用。
# 十四｜周伯仁母冬至举酒赐三子
原：周伯仁母冬至举酒赐三子曰：“吾本谓度江托足无所，尔家有相，尔等并罗列吾前，复何忧！”|| 周顗的母亲在冬至那天举酒赐给三个儿子，说：“我本来以为渡江以后没有落脚之处，好在你们家有福相，你们都在我跟前排排站着，我还有什么可担心的！”
注：周伯仁：周顗（yǐ），字伯仁，东晋名士，后为王敦所杀。三子：周顗、周嵩、周谟。
注：度江：渡江南迁。托足：立足，安身。相：福相，好运。
原：周嵩起，长跪而泣曰：“不如阿母言。伯仁为人志大而才短，名重而识暗，好乘人之弊，此非自全之道；嵩性狼抗，亦不容于世；唯阿奴碌碌，当在阿母目下耳。”|| 周嵩站起来，直身跪着哭道：“不像母亲说的那样。伯仁为人志向大而才能短，名声重而见识浅，又喜欢趁人之危，这不是保全自己的办法；我性情刚愎倨傲，也不会被世道所容；只有阿奴平平庸庸，才能一直待在母亲眼前罢了。”
注：周嵩：字仲智，周顗之弟，性刚直，后亦为王敦所害。长跪：直身而跪，表示恭敬。
注：识暗：见识不明。乘人之弊：趁别人有过失或困厄时加以攻击。
注：狼抗：傲慢刚戾，不肯屈从。
注：阿奴：周谟的小名，三兄弟中最小。碌碌：平庸无奇。
# 十五｜王大将军既亡
原：王大将军既亡，王应欲投世儒，世儒为江州。王含欲投王舒，舒为荆州。含语应曰：“大将军平素与江州云何，而汝欲归之？”|| 大将军王敦死后，王应想去投奔王彬，王彬当时任江州刺史。王含想去投奔王舒，王舒当时任荆州刺史。王含对王应说：“大将军平日和江州的关系怎么样，你却想去投靠他？”
注：王应：字安期，王含之子，过继给无子的王敦为嗣。王含：王敦之兄，曾随王敦作乱。
注：世儒：王彬，字世儒，王敦堂弟，曾当面指责王敦，时任江州刺史。
注：王舒：字处明，王敦堂弟，时任荆州刺史。
原：应曰：“此乃所以宜往也。江州当人强盛时，能抗同异，此非常人所行。及睹衰厄，必兴愍恻。荆州守文，岂能作意表行事！”含不从，遂共投舒。舒果沉含父子于江。彬闻应当来，密具船以待之，竟不得来，深以为恨。|| 王应说：“这正是应该去投奔他的原因。江州在别人势力强盛的时候，敢于提出不同意见，这不是一般人做得到的。等他看到人家衰败困厄，一定会生出怜悯之心。荆州只会按常规办事，哪能做出意料之外的事情呢！”王含不听，便和王应一起投奔王舒。王舒果然把王含父子沉入了长江。王彬听说王应要来，暗中准备好船只等候他，结果他终究没能来，王彬为此深感遗憾。
注：抗同异：直言提出不同意见。同异，偏义复词，偏指“异”。
注：愍恻：怜悯同情。
注：守文：拘守成法，循规蹈矩。意表：意料之外。
# 十六｜武昌孟嘉作庾太尉州从事
原：武昌孟嘉作庾太尉州从事，已知名。褚太傅有知人鉴，罢豫章还，过武昌，问庾曰：“闻孟从事佳，今在此不？”庾云：“试自求之。”褚眄睐良久，指嘉曰：“此君小异，得无是乎？”庾大笑曰：“然。”于时既叹褚之默识，又欣嘉之见赏。|| 武昌人孟嘉在太尉庾亮手下做州从事，已经有了名气。太傅褚裒有识人的眼力，他卸任豫章太守回京，路过武昌，问庾亮说：“听说孟从事很出色，现在在这里吗？”庾亮说：“你自己找找看。”褚裒左右打量了很久，指着孟嘉说：“这位稍有些与众不同，莫非就是他？”庾亮大笑道：“正是。”当时的人既赞叹褚裒默默一看就能认出人来，又为孟嘉得到赏识而高兴。
注：孟嘉：字万年，江夏人，以风度闲雅著称，陶渊明的外祖父。庾太尉：庾亮。州从事：州刺史的属吏。
注：褚太傅：褚裒（póu），字季野，东晋外戚，死后追赠太傅。鉴：鉴别人物的眼力。
注：不：同“否”。眄睐（miǎn lài）：左右顾盼，四处察看。
注：得无：莫非，该不是。默识：不说话而心中识别。
# 十七｜戴安道年十余岁
原：戴安道年十余岁，在瓦官寺画。王长史见之，曰：“此童非徒能画，亦终当致名。恨吾老，不见其盛时耳！”|| 戴逵十几岁时，在瓦官寺作画。王濛看见了，说：“这孩子不只是会画画，将来也一定会成名。可惜我老了，看不到他名声大盛的时候了！”
注：戴安道：戴逵，字安道，东晋著名画家、雕塑家，隐居不仕。
注：瓦官寺：东晋时建康的佛寺。
注：王长史：王濛，字仲祖，曾任司徒左长史，东晋名士。致名：获得名声。
# 十八｜王仲祖、谢仁祖、刘真长俱至丹阳墓所
原：王仲祖、谢仁祖、刘真长俱至丹阳墓所省殷扬州，殊有确然之志。既反，王、谢相谓曰：“渊源不起，当如苍生何？”深为忧叹。刘曰：“卿诸人真忧渊源不起邪？”|| 王濛、谢尚、刘惔一同到丹阳殷浩居住的墓地去看望他，发现他隐居的心意非常坚决。回来以后，王濛、谢尚互相说道：“渊源不肯出山，天下百姓可怎么办？”深为忧虑叹息。刘惔说：“你们几位真的是担心渊源不出山吗？”
注：谢仁祖：谢尚，字仁祖，谢安从兄。刘真长：刘惔（tán），字真长，东晋清谈名士。
注：殷扬州：殷浩，字渊源，后任扬州刺史，故称。他早年屏居墓所，屡征不起；后出任北伐失败，被废为庶人。
注：确然之志：坚定不移的退隐之志，语本《周易·乾·文言》“确乎其不可拔”。
注：刘惔反问之意，似暗示殷浩并非真心隐退、出山亦未必有成，存疑。
# 十九｜小庾临终
原：小庾临终，自表以子园客为代。朝廷虑其不从命，未知所遣，乃共议用桓温。刘尹曰：“使伊去，必能克定西楚，然恐不可复制。”|| 庾翼临终时，亲自上表请求让儿子园客接替自己。朝廷担心他家不听命令，又不知派谁去，于是共同商议起用桓温。刘惔说：“派他去，一定能平定西楚，只怕以后就再也控制不住他了。”
注：小庾：庾翼，字稚恭，庾亮之弟，时任荆州刺史，故称小庾。
注：园客：庾爰之的小字，庾翼之子。
注：刘尹：刘惔，曾任丹阳尹。伊：他。
注：西楚：指荆州一带，古属楚地，在京城建康之西。
# 二十｜桓公将伐蜀
原：桓公将伐蜀，在事诸贤咸以李势在蜀既久，承藉累叶，且形据上流，三峡未易可克。唯刘尹云：“伊必能克蜀。观其蒲博，不必得则不为。”|| 桓温要讨伐蜀地，当政的诸位大臣都认为李势在蜀地经营已久，凭借着好几代的基业，又占据长江上游的地势，三峡一带不容易攻下。只有刘惔说：“他一定能攻下蜀地。看他赌博就知道，没有必胜的把握是不会出手的。”
注：桓公：桓温，字元子，东晋权臣，永和三年灭成汉。
注：李势：成汉末代君主。承藉累叶：凭借累世的基业。叶，世代。
注：蒲博：即樗蒲（chū pú），古代一种掷采赌胜的博戏。
# 二十一｜谢公在东山畜妓
原：谢公在东山畜妓，简文曰：“安石必出，既与人同乐，亦不得不与人同忧。”|| 谢安隐居东山时养着歌伎，简文帝说：“安石一定会出山，他既然能与人同享欢乐，也就不能不与人共担忧患。”
注：谢公：谢安，字安石，东晋名相，早年隐居会稽东山。
注：妓：歌舞伎乐之人。
注：简文：晋简文帝司马昱，即位前为会稽王、长期辅政。
# 二十二｜郗超与谢玄不善
原：郗超与谢玄不善。苻坚将问晋鼎，既已狼噬梁、岐，又虎视淮阴矣。于时朝议遣玄北讨，人间颇有异同之论，唯超曰：“是必济事。吾昔尝与共在桓宣武府，见使才皆尽，虽履屐之间，亦得其任。以此推之，容必能立勋。”元功既举，时人咸叹超之先觉，又重其不以爱憎匿善。|| 郗超和谢玄关系不好。苻坚图谋夺取晋朝天下，已经像恶狼一样吞并了梁州、岐山一带，又像猛虎一样盯着淮河以南。当时朝廷商议派谢玄北上征讨，人们议论纷纷，颇有不同意见，只有郗超说：“这个人一定能成事。我从前和他一起在桓温的幕府共事，见他用人都能尽其所长，即使是鞋履之类的小事，也安排得各得其所。由此推断，他想必能建立功勋。”大功告成以后，当时人都赞叹郗超有先见之明，又敬重他不因个人好恶而埋没别人的长处。
注：郗超：字景兴，桓温的重要谋士。谢玄：字幼度，谢安之侄，组建北府兵，淝水之战大破前秦。
注：苻坚：前秦君主。问晋鼎：图谋夺取晋朝政权，化用楚庄王“问鼎”之典。
注：梁、岐：梁州与岐山一带，在今陕西西南部。淮阴：泛指淮河以南地区。
注：履屐之间：鞋履之类的细事。容：或许，想必。元功：大功，指淝水之战的胜利。
# 二十三｜韩康伯与谢玄亦无深好
原：韩康伯与谢玄亦无深好，玄北征后，巷议疑其不振。康伯曰：“此人好名，必能战。”玄闻之，甚忿，常于众中厉色曰：“丈夫提千兵入死地，以事君亲故发，不得复云为名！”|| 韩伯和谢玄也没有深交，谢玄北征以后，街谈巷议都怀疑他打不好。韩伯说：“这个人爱好名声，一定能打仗。”谢玄听说后，十分恼怒，常常当着众人声色俱厉地说：“大丈夫率领千军万马深入死地，是为了报效君上才出征的，不许再说是为了名声！”
注：韩康伯：韩伯，字康伯，东晋玄学家，曾为《周易》作注。
注：巷议：街头巷尾的议论。不振：不能振作取胜。
注：君亲：偏指君主。
# 二十四｜褚期生少时
原：褚期生少时，谢公甚知之，恒云：“褚期生若不佳者，仆不复相士！”|| 褚爽年少时，谢安很赏识他，常说：“褚期生如果不出色，我就再也不给人看相评品了！”
注：褚期生：褚爽，小字期生，褚裒之孙，东晋人。
注：相士：鉴别评品人物。
# 二十五｜郗超与傅瑗周旋
原：郗超与傅瑗周旋。瑗见其二子，并总发。超观之良久，谓瑗曰：“小者才名皆胜，然保卿家，终当在兄。”即傅亮兄弟也。|| 郗超与傅瑗有交往。傅瑗让两个儿子出来拜见，两人都还是孩童。郗超看了很久，对傅瑗说：“小的那个才能和名声都会更胜一筹，但是保全你们家的，终究还得靠哥哥。”这就是傅亮兄弟俩。
注：傅瑗：字叔玉，北地灵州人，东晋时官至安成太守。周旋：交往应酬。
注：总发：束发为髻，指童年。
注：傅亮兄弟：兄傅迪，弟傅亮。傅亮以文才显于刘宋，位至宰辅，后被宋文帝所杀；傅迪官至五兵尚书，结局如何应验郗超之言，细节存疑。
# 二十六｜王恭随父在会稽
原：王恭随父在会稽，王大自都来拜墓，恭暂往墓下看之。二人素善，遂十余日方还。父问恭：“何故多日？”对曰：“与阿大语，蝉连不得归。”因语之曰：“恐阿大非尔之友，终乖爱好。”果如其言。|| 王恭随父亲住在会稽，王忱从京城来扫墓，王恭便到墓地去看他，打算只待一会儿。两人一向交好，结果过了十几天才回来。父亲问王恭：“为什么去了这么多天？”王恭回答：“和阿大聊天，话头接连不断，没法回来。”父亲于是对他说：“恐怕阿大不是你真正的朋友，你们的交好终究会破裂。”后来果然像他说的那样。
注：王恭：字孝伯，东晋外戚，后起兵反对司马道子，兵败被杀。父：王蕴。
注：王大：王忱，字元达，小字佛大，人称阿大，与王恭同族，后两人失和。
注：暂：短时间，表示原本只打算稍去即回。蝉连：连续不断。
注：乖：背离，不合。
# 二十七｜车胤父作南平郡功曹
原：车胤父作南平郡功曹，太守王胡之避司马无忌之难，置郡于澧阴。是时胤十余岁，胡之每出，尝于篱中见而异焉，谓胤父曰：“此儿当致高名。”后游集，恒命之。胤长，又为桓宣武所知，清通于多士之世，官至选曹尚书。|| 车胤的父亲在南平郡任功曹，太守王胡之为了躲避司马无忌的报复，把郡治迁到了澧水南岸。当时车胤十几岁，王胡之每次外出，常常从篱笆间看见他，觉得他与众不同，对他父亲说：“这孩子将来会享有盛名。”后来每逢游乐聚会，总叫车胤参加。车胤长大后，又得到桓温的赏识，在人才济济的时代显得清明通达，官做到吏部尚书。
注：车胤：字武子，南平人，少时家贫，有“囊萤夜读”的故事。功曹：郡守属官，掌人事。
注：王胡之：字修龄，王廙之子。王廙曾奉王敦之命杀害谯王司马承，司马承之子司马无忌欲报父仇，故胡之避之。
注：澧阴：澧水南岸。澧水在今湖南北部，流入洞庭湖。底本印作“沣阴”，当为“澧阴”之误，径改。
注：选曹尚书：即吏部尚书，主管官吏选拔。
# 二十八｜王忱死，西镇未定
原：王忱死，西镇未定，朝贵人人有望。时殷仲堪在门下，虽居机要，资名轻小，人情未以方岳相许。晋孝武欲拔亲近腹心，遂以殷为荆州。|| 王忱死后，西边重镇荆州的长官还没确定，朝中权贵人人都有指望。当时殷仲堪在门下省任职，虽然身居机要，但资历名望都浅，人们并不认为他能当方面大员。晋孝武帝想提拔自己亲近的心腹，于是任命殷仲堪为荆州刺史。
注：西镇：指荆州，为东晋西部重镇。王忱死前任荆州刺史。
注：殷仲堪：东晋陈郡人，善清言，时任黄门侍郎，后出任荆州刺史，为桓玄所杀。门下：门下省，侍从皇帝、参与机要的机构。
注：方岳：四方诸侯之长，借指地方大员。许：期许。
注：晋孝武：晋孝武帝司马曜。
原：事定，诏未出。王珣问殷曰：“陕西何故未有处分？”殷曰：“已有人。”王历问公卿，咸云：“非。”王自计才地，必应任己。复问：“非我邪？”殷曰：“亦似非。”其夜，诏出用殷。王语所亲曰：“岂有黄门郎而受如此任！仲堪此举，乃是国之亡征。”|| 事情已定，诏书还没颁出。王珣问殷仲堪：“荆州为什么还没有安排？”殷仲堪说：“已经有人了。”王珣把公卿一个个问遍，殷仲堪都说：“不是。”王珣自己估量才干和门第，认为一定该轮到自己。又问：“不是我吗？”殷仲堪说：“好像也不是。”当天夜里，诏书颁出，任用的是殷仲堪。王珣对亲信说：“哪有黄门侍郎担当这样重任的！仲堪这次被提拔，是国家要灭亡的征兆。”
注：王珣：字元琳，王导之孙，东晋名臣，善书法。
注：陕西：周初周公、召公以陕为界分治东西，后以“分陕”喻方面重任，这里借指荆州。处分：安排。
注：才地：才能与门第。
注：黄门郎：黄门侍郎，殷仲堪时任此职，品位不高。
