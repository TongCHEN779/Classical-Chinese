# 本门导读
题解：“纰漏”指疏忽差错。本门所记多是无心之失：或孤陋寡闻闹了笑话，或言语冒犯触人隐痛，或轻信传言空欢喜一场，读来往往令人失笑。

# 一｜王敦初尚主
原：王敦初尚主，如厕，见漆箱盛干枣，本以塞鼻，王谓厕上亦下果，食遂至尽。既还，婢擎金澡盘盛水，琉璃碗盛澡豆，因倒著水中而饮之，谓是干饭。群婢莫不掩口而笑之。|| 王敦刚娶了公主，上厕所时，看见漆箱里盛着干枣。这本是用来塞鼻子挡臭气的，王敦以为厕所里也摆了果品，竟一个不剩全吃了。回来后，婢女端着金盆盛水，又用琉璃碗盛着澡豆，王敦就把澡豆倒进水里喝了，以为那是干粮。婢女们无不掩着嘴笑他。
注：王敦：字处仲，东晋权臣，娶晋武帝之女襄城公主。尚主：娶公主为妻。
注：如厕：上厕所。下果：摆设果品。
注：擎（qíng）：托举。澡盘：盥洗用的盆。
注：澡豆：用豆粉等制成的洗涤用品，类似后世的肥皂。干饭：干粮。

# 二｜元皇初见贺司空
原：元皇初见贺司空，言及吴时事，问：“孙皓烧锯截一贺头，是谁？”司空未得言，元皇自忆曰：“是贺劭。”司空流涕曰：“臣父遭遇无道，创巨痛深，无以仰答明诏。”元皇愧惭，三日不出。|| 晋元帝初次接见贺循，谈到东吴时的旧事，问道：“孙皓用烧红的锯子锯下一个姓贺的人的头，那人是谁？”贺循还没开口，元帝自己想起来了：“是贺劭。”贺循流着泪说：“臣的父亲遭遇无道昏君，创伤巨大，痛苦深切，臣实在无法回答陛下的垂问。”元帝又惭愧又懊悔，三天没有出门。
注：元皇：东晋元帝司马睿。贺司空：贺循，字彦先，会稽山阴人，江东名士，死后追赠司空。
注：孙皓：东吴末代君主，以残暴著称。
注：贺劭：字兴伯，贺循之父，在吴任中书令，因直谏得罪孙皓被杀。
注：明诏：对皇帝问话的敬称。

# 三｜蔡司徒渡江
原：蔡司徒渡江，见彭蜞，大喜曰：“蟹有八足，加以二螯。”令烹之。既食，吐下委顿，方知非蟹。后向谢仁祖说此事，谢曰：“卿读《尔雅》不熟，几为《劝学》死。”|| 蔡谟渡江南来，看见彭蜞，非常高兴，说：“蟹有八只脚，再加两只大钳。”叫人煮了吃。吃完后上吐下泻，精神萎靡，这才知道那不是螃蟹。后来他对谢尚说起这件事，谢尚说：“你《尔雅》读得不熟，差点被《劝学》害死。”
注：蔡司徒：蔡谟，字道明，东晋大臣，官至司徒。彭蜞（qí）：一种形似小蟹的水边动物，不宜食用。
注：螯（áo）：蟹类前端的大钳。吐下：呕吐腹泻。委顿：困乏萎靡。
注：谢仁祖：谢尚，字仁祖，谢安的堂兄。
注：《尔雅》：古代解释词义名物的书，其中区分了彭蜞与蟹。《劝学》：蔡谟的先辈族人蔡邕作有《劝学篇》，中有“蟹有八足，加以二螯”之语，蔡谟据书认物而误。

# 四｜任育长年少时
原：任育长年少时，甚有令名。武帝崩，选百二十挽郎，一时之秀彦，育长亦在其中。王安丰选女婿，从挽郎搜其胜者，且择取四人，任犹在其中。童少时，神明可爱，时人谓育长影亦好。|| 任瞻年轻时，名声很好。晋武帝去世，挑选一百二十名挽郎，都是一时的俊秀人才，任瞻也在其中。王戎挑选女婿，从挽郎里寻找最出色的，先选出四个人，任瞻仍在里面。他童年时神采清明，招人喜爱，当时人说任瞻连影子都是好看的。
注：任育长：任瞻，字育长，西晋时历任谒者仆射、天门太守等职。令名：美好的名声。
注：挽郎：帝王出殡时牵引灵车、唱挽歌的少年，多选世家子弟充任。秀彦：才俊之士。
注：王安丰：王戎，封安丰侯，竹林七贤之一。
注：神明：精神气度。
原：自过江，便失志。王丞相请先度时贤共至石头迎之，犹作畴日相待，一见便觉有异。坐席竟，下饮，便问人云：“此为茶，为茗？”觉有异色，乃自申明云：“向问饮为热、为冷耳。”尝行从棺邸下度，流涕悲哀。王丞相闻之曰：“此是有情痴。”|| 渡江南来以后，他就神志恍惚了。丞相王导邀请先过江的名流一起到石头城迎接他，仍像从前那样待他，可一见面就觉得他有些异样。坐定之后，端上饮料，他便问人：“这是茶，还是茗？”察觉到别人神色有异，就自己解释说：“我刚才是问喝的东西是热的还是冷的。”他曾经从棺材铺前走过，竟流泪悲伤起来。王导听说后说：“这是个多情的痴人。”
注：失志：神志失常，恍惚。先度：先渡江的人。畴日：往日。
注：茶、茗：本为一物，旧说早采为茶、晚采为茗。任瞻问出外行话，又借“茗”“冷”音近掩饰。
注：棺邸：棺材铺。有情痴：痴情之人，心有所感而不能自已。

# 五｜谢虎子尝上屋熏鼠
原：谢虎子尝上屋熏鼠。胡儿既无由知父为此事，闻人道痴人有作此者，戏笑之，时道此非复一过。太傅既了己之不知，因其言次，语胡儿曰：“世人以此谤中郎，亦言我共作此。”胡儿懊热，一月日闭斋不出。太傅虚托引己之过，以相开悟，可谓德教。|| 谢据曾经爬上屋顶熏老鼠。谢朗无从知道这是父亲干过的事，听人说有个傻子做过这种事，就拿来取笑，还不止一次地说起。谢安明白谢朗并不知情，便趁他说起这事的时候，对他说：“世人拿这件事来诽谤中郎，还说我也和他一起干过。”谢朗懊悔烦闷，关在书房里一个月没出门。谢安假托把过错揽到自己身上，借此开导他，真可以称得上是以德教人了。
注：谢虎子：谢据，小字虎子，谢安之兄。
注：胡儿：谢朗，小字胡儿，谢据之子，谢安之侄。无由：无从。
注：非复一过：不止一次。了：明白。言次：说话之间。
注：中郎：指谢据，一说因其在兄弟中排行第二而称。懊热：懊恼烦躁。斋：书房。

# 六｜殷仲堪父病虚悸
原：殷仲堪父病虚悸，闻床下蚁动，谓是牛斗。孝武不知是殷公，问仲堪：“有一殷，病如此不？”仲堪流涕而起曰：“臣进退唯谷。”|| 殷仲堪的父亲患了虚悸病，听见床底下蚂蚁爬动，以为是牛在打架。孝武帝不知道那就是殷仲堪的父亲，问殷仲堪：“有个姓殷的，得的病是这样的吗？”殷仲堪流着泪站起来说：“臣实在进退两难。”
注：殷仲堪父：殷师，字师子，官至晋陵太守。虚悸：因体虚而心悸惊惕的病症。
注：孝武：东晋孝武帝司马曜。不：同“否”。
注：进退唯谷：语出《诗经·大雅·桑柔》，谷，穷尽，比喻处境困窘；答则揭父之病，不答则违君之问。

# 七｜虞啸父为孝武侍中
原：虞啸父为孝武侍中，帝从容问曰：“卿在门下，初不闻有所献替。”虞家富春，近海，谓帝望其意气，对曰：“天时尚暖，鮆鱼虾鱃未可致，寻当有所上献。”帝抚掌大笑。|| 虞啸父任孝武帝的侍中，孝武帝闲谈时问他：“你在门下省任职，从来没听说你进献过什么意见。”虞家在富春，靠近海边，他以为皇帝是想要他进贡些礼物，便回答说：“天气还暖和，鮆鱼、虾酱之类还弄不到，过些日子自当有所进献。”孝武帝拍着手大笑。
注：虞啸父：会稽余姚人，东晋官至侍中，为孝武帝所亲近。从容：随意闲谈。
注：门下：门下省，侍中所属的官署，掌侍从顾问。献替：“献可替否”的省语，即进言兴利除弊。
注：富春：县名，在今浙江富阳。意气：此指贡献的礼物、心意。
注：鮆（jì）鱼：一种海鱼。鱃（qiū）：存疑，或解为腌制的鱼虾酱类。寻：不久。

# 八｜王大丧后
原：王大丧后，朝论或云国宝应作荆州。国宝主簿夜函白事云：“荆州事已行。”国宝大喜，其夜开阁，唤纲纪。话势虽不及作荆州，而意色甚恬。晓遣参问，都无此事。即唤主簿数之曰：“卿何以误人事邪？”|| 王忱死后，朝廷议论，有人说王国宝应当去做荆州刺史。王国宝的主簿连夜封函报告说：“荆州的任命已经定下了。”王国宝大喜，当夜打开官署的侧门，把主簿召来。谈话中虽然没有说到做荆州刺史的事，神色却十分安然自得。天亮后派人去打听核实，根本没有这回事。他立刻叫来主簿，责备他说：“你为什么误我的事？”
注：王大：王忱，小字佛大，王国宝之弟，官至荆州刺史，死于任上。
注：主簿：掌管文书簿籍的属官。夜函白事：连夜用封函呈报事情。
注：阁：通“閤”（gé），官署的侧门、小门。纲纪：州郡的主要属官，此指主簿。
注：恬：安然自得。参问：探问核实。数（shǔ）：责备，数落。
