# 本门导读
题解：豪爽指气概豪迈、行事爽快。本门十三则，近半写王敦，也写祖逖、庾翼、桓温、桓玄等人，多见击鼓、吟诗、出征时的意气飞扬，乃至跋扈之态。

# 一｜王大将军年少时
原：王大将军年少时，旧有田舍名，语音亦楚。武帝唤时贤共言伎艺事，人皆多有所知，唯王都无所关，意色殊恶。自言知打鼓吹，帝令取鼓与之。于坐振袖而起，扬槌奋击，音节谐捷，神气豪上，傍若无人，举坐叹其雄爽。|| 王敦年轻时，向来有乡巴佬的名声，说话口音也土气。晋武帝召集当时名流一起谈论技艺，大家多少都懂一些，只有王敦一概插不上话，脸色非常难看。他自称会击鼓，武帝就叫人拿鼓给他。他在座中抖袖站起，扬起鼓槌奋力敲打，节奏和谐急促，神气豪迈昂扬，旁若无人，满座都赞叹他雄健豪爽。
注：王大将军：王敦，字处仲，琅邪临沂人，王导堂兄，娶晋武帝之女，东晋初官至大将军，后举兵作乱。
注：田舍：乡下人，带轻视意味。
注：楚：粗俗，这里指口音土气。
注：武帝：晋武帝司马炎。
注：无所关：毫不相干，插不上话。
注：鼓吹：这里偏指击鼓。
注：谐捷：和谐而急促。

# 二｜王处仲世许高尚之目
原：王处仲，世许高尚之目，尝荒恣于色，体为之弊。左右谏之，处仲曰：“吾乃不觉尔，如此者甚易耳！”乃开后阁，驱诸婢妾数十人出路，任其所之，时人叹焉。|| 王敦，世人公认他有“高尚”的品评。他曾经沉溺女色，身体因此疲惫不堪。¦身边的人劝他，王敦说：“我竟然没察觉到这一点，这样的事很好办！”¦于是打开后院的小门，把几十个婢妾赶到路上，任凭她们去哪里，当时人都为之赞叹。
注：王处仲：王敦，字处仲。
注：许：称许。
注：目：品评之语。
注：荒恣：放纵无度。
注：弊：疲困。
注：后阁：内室，妻妾所居。

# 三｜王大将军自目
原：王大将军自目：“高朗疏率，学通《左氏》。”|| 王敦给自己的评语是：“高尚开朗，疏放直率，学问精通《左传》。”
注：自目：自我品评。
注：疏率：疏放坦率。
注：《左氏》：《春秋左氏传》，即《左传》。

# 四｜王处仲每酒后
原：王处仲每酒后，辄咏“老骥伏枥，志在千里。烈士暮年，壮心不已”。以如意打唾壶，壶口尽缺。|| 王敦每次喝了酒，总要吟诵“老骥伏枥，志在千里。¦烈士暮年，壮心不已”这几句，¦一边用如意敲打唾壶打拍子，壶口都被敲得满是缺口。
注：“老骥”四句：出自曹操乐府《步出夏门行·龟虽寿》。
注：骥：千里马。
注：枥：马槽。
注：烈士：有雄心壮志的人。
注：如意：器物名，柄端作灵芝或云叶形，可供搔痒、指划或把玩。
注：唾壶：痰盂。

# 五｜晋明帝欲起池台
原：晋明帝欲起池台，元帝不许。帝时为太子，好武养士，一夕中作池，比晓便成。今太子西池是也。|| 晋明帝想修建池沼台榭，元帝不准。明帝那时还是太子，喜好武事，蓄养了一批勇士，便让他们在一夜之间挖池，到天亮就挖成了。如今的太子西池就是它。
注：晋明帝：司马绍，时为太子。
注：元帝：司马睿，明帝之父。
注：池台：池沼台榭，游赏之所。
注：比晓：等到天亮。
注：太子西池：东晋建康城中的池苑名。

# 六｜王大将军始欲下都
原：王大将军始欲下都处分树置，先遣参军告朝廷，讽旨时贤。祖车骑尚未镇寿春，瞋目厉声语使人曰：“卿语阿黑，何敢不逊！催摄面去，须臾不尔，我将三千兵槊脚令上！”王闻之而止。|| 王敦起初打算东下京都，安排调整朝廷官员，先派参军去告知朝廷，向当时的名流暗示自己的意图。祖逖那时还没出镇寿春，瞪着眼厉声对来使说：“你去告诉阿黑，怎敢如此放肆！叫他赶快掉头回去，稍有迟延，我就带三千兵马用长矛戳他的脚，把他赶回上游去！”王敦听说后就作罢了。
注：下都：从上游的武昌顺江东下到京城建康。
注：处分树置：安排调动，指改换朝廷官员。
注：讽旨：委婉地透露意图。
注：祖车骑：祖逖，字士稚，范阳遒县人，以北伐中原著称，死后追赠车骑将军。
注：阿黑：王敦小字。
注：不逊：不恭顺。
注：催摄面去：赶快转身回去。面，通“偭”，背向。
注：槊（shuò）：长矛，这里用作动词，指刺。

# 七｜庾稚恭既常有中原之志
原：庾稚恭既常有中原之志，文康时，权重未在己。及季坚作相，忌兵畏祸，与稚恭历同异者久之，乃果行。倾荆、汉之力，穷舟车之势，师次于襄阳，大会参佐，陈其旌甲，亲授弧矢曰：“我之此行，若此射矣！”遂三起三叠。徒众属目，其气十倍。|| 庾翼一向怀有收复中原的志向，庾亮执政时，兵权还不在他手里。等到庾冰当了宰相，怕动兵惹祸，和庾翼意见不合争执了很久，庾翼最终还是出兵了。他调动荆州、汉水一带的全部力量，用尽了船只车辆，大军驻扎在襄阳，召集全体僚属，排列旗帜甲兵，亲自拿起弓箭说：“我这次出征，就像这一箭一样！”于是连发三箭，三箭皆中，鼓声三次响起。众人都注目观看，士气高涨了十倍。
注：庾稚恭：庾翼，字稚恭，庾亮之弟，继庾亮任荆州刺史，镇守武昌，力主北伐。
注：文康：庾亮，谥文康。
注：季坚：庾冰，字季坚，庾亮之弟、庾翼之兄，时在朝执政。
注：历同异：偏指意见不同，反复争执。
注：次：驻扎。
注：参佐：属官。
注：三起三叠：三发三中。起指发箭，叠指射中后击鼓为号（一说如此，存疑）。

# 八｜桓宣武平蜀
原：桓宣武平蜀，集参僚置酒于李势殿，巴、蜀缙绅莫不来萃。桓既素有雄情爽气，加尔日音调英发，叙古今成败由人，存亡系才。其状磊落，一坐叹赏。既散，诸人追味余言。于时寻阳周馥曰：“恨卿辈不见王大将军。”|| 桓温平定蜀地后，召集僚属在李势的宫殿里摆酒，巴蜀的士绅没有不来聚会的。桓温本就气概雄豪爽朗，加上那天言辞音调格外英发，讲古往今来的成败都在于人，国家存亡系于人才。他那副磊落的神态，满座都赞叹欣赏。散席后，大家还在回味他的话。当时寻阳人周馥说：“可惜你们没见过王大将军。”
注：桓宣武平蜀：东晋永和年间桓温率军西征，灭成汉。
注：李势：成汉末代君主，降晋。
注：缙绅：士大夫。
注：萃：聚集。
注：尔日：那天。
注：英发：英气勃发。
注：磊落：俊伟洒脱。
注：周馥：寻阳人，曾为王敦属官。此意谓王敦的气概更胜桓温。按此周馥与西晋末年任镇东将军的周馥恐非一人，存疑。

# 九｜桓公读《高士传》
原：桓公读《高士传》，至於陵仲子便掷去，曰：“谁能作此溪刻自处！”|| 桓温读《高士传》，读到於陵仲子就把书扔开，说：“谁能这样苛刻地对待自己！”
注：桓公：桓温。
注：《高士传》：晋皇甫谧所撰，记古代隐逸之士的事迹。
注：於（wū）陵仲子：陈仲子，战国齐人，以兄食禄为不义，避居於陵，宁愿自食其力、忍饥挨饿也不受不义之禄。
注：溪刻：苛刻。
注：自处：对待自己。

# 十｜桓石虔
原：桓石虔，司空豁之长庶也，小字镇恶。年十七八，未被举，而童隶已呼为镇恶郎。尝住宣武斋头。从征枋头，车骑冲没陈，左右莫能先救。宣武谓曰：“汝叔落贼，汝知不？”石虔闻之，气甚奋。命朱辟为副，策马于数万众中，莫有抗者，径致冲还，三军叹服。河朔后以其名断疟。|| 桓石虔是司空桓豁的庶出长子，小字镇恶。¦十七八岁时，还没有得到家族正式承认，可家里的仆役已经称他“镇恶郎”了。¦他曾住在桓温的书斋里。¦随桓温北征到枋头，车骑将军桓冲陷入敌阵，身边的人没有谁敢抢先去救。¦桓温对他说：“你叔叔落入贼手了，你知道吗？”¦石虔听了，意气奋发，¦命朱辟做副手，策马冲进数万敌军之中，没有人能抵挡，径直把桓冲救了回来，全军叹服。¦后来黄河以北一带竟拿他的名字来驱除疟疾。
注：桓石虔：桓温之侄，骁勇善战，后官至豫州刺史。
注：司空豁：桓豁，桓温之弟，官至荆州刺史，死后赠司空。
注：长（zhǎng）庶：妾所生诸子中的长子。
注：被举：得到正式承认，确立身份。
注：童隶：家中仆役。
注：斋头：书斋、居室。
注：枋头：地名，在今河南浚县一带，桓温第三次北伐在此大败。
注：没（mò）陈：陷入敌阵，陈同“阵”。
注：朱辟：生平不详。
注：断疟：用他的名字驱除疟鬼，可见威名之盛。

# 十一｜陈林道在西岸
原：陈林道在西岸，都下诸人共要至牛渚会。陈理既佳，人欲共言折，陈以如意拄颊，望鸡笼山叹曰：“孙伯符志业不遂！”于是竟坐不得谈。|| 陈逵驻守在长江西岸时，京城的朋友们一起邀他到牛渚山聚会。陈逵谈玄理很高明，大家想一起用言辞驳倒他，陈逵却用如意撑着脸颊，望着鸡笼山感叹说：“孙伯符的志向事业没能完成啊！”于是整场聚会再也谈不下去了。
注：陈林道：陈逵，字林道，东晋人，曾任淮南太守。
注：西岸：长江西岸，指其驻地。
注：要（yāo）：邀请。
注：牛渚：山名，在今安徽马鞍山一带，山脚突入长江处称采石矶。
注：言折：用言论折服对方。
注：拄颊：支着脸颊。
注：鸡笼山：在今南京，山形如鸡笼。
注：孙伯符：孙策，字伯符，开创东吴基业，二十六岁早逝。
注：竟坐：满座、整个聚会。

# 十二｜王司州在谢公坐
原：王司州在谢公坐，咏“入不言兮出不辞，乘回风兮载云旗”。语人云：“当尔时，觉一坐无人。”|| 王胡之在谢安家做客，吟诵“入不言兮出不辞，乘回风兮载云旗”。事后他对人说：“那个时候，我觉得满座好像一个人也没有。”
注：王司州：王胡之，字修龄，王廙之子，曾被任命为司州刺史。
注：谢公：谢安。
注：“入不言兮”二句：出自屈原《九歌·少司命》，写神灵来去飘忽，不言不辞，乘旋风、驾云旗而去。
注：尔时：那时。

# 十三｜桓玄西下
原：桓玄西下，入石头，外白司马梁王奔叛。玄时事形已济，在平乘上笳鼓并作，直高咏云：“箫管有遗音，梁王安在哉？”|| 桓玄从西面顺江而下，进入石头城，外面报告说司马梁王逃跑了。桓玄这时大局已定，在大船上胡笳与鼓声齐鸣，他只是高声吟诵：“箫管有遗音，梁王安在哉？”
注：桓玄西下：桓玄自荆州起兵东下，攻入建康，旋即篡晋称帝。
注：石头：石头城，建康西面的要塞。
注：白：禀报。
注：司马梁王：司马珍之，晋宗室，封梁王。
注：事形已济：形势已经成功。
注：平乘：一种大船。
注：笳：胡笳，北方民族的吹奏乐器。
注：“箫管有遗音”二句：出自阮籍《咏怀诗》，原指战国魏王（都大梁，称梁王），桓玄借以双关眼前逃走的梁王司马珍之。
