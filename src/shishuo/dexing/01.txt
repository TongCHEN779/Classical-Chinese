# 本门导读
题解：德行居孔门四科之首，本门以汉末清流开篇，历魏晋名士，记孝悌、友道、廉让、宽厚诸事，可见乱世之中士人对品行的看重与标榜。

# 一｜陈仲举言为士则
原：陈仲举言为士则，行为世范，登车揽辔，有澄清天下之志。为豫章太守，至，便问徐孺子所在，欲先看之。主簿白：“群情欲府君先入廨。”陈曰：“武王式商容之闾，席不暇暖。吾之礼贤，有何不可！”|| 陈蕃的言论是读书人的准则，行事是世人的楷模，一登上车子拉起缰绳，就怀着廓清天下的抱负。他出任豫章太守，刚到任，就打听徐孺子住在哪里，想先去拜访他。主簿禀告说：“大家都希望府君先进官署。”陈蕃说：“周武王灭商后，连座席都没坐暖，就去商容的里门前扶轼致敬。我礼敬贤人，有什么不可以的！”
注：陈仲举：陈蕃，字仲举，东汉末汝南人，桓帝、灵帝时名臣，清流领袖，后谋诛宦官事败被害。
注：揽辔：手持缰绳，指出任官职、奔赴任所。
注：徐孺子：徐稚，字孺子，豫章南昌人，屡征不仕的高士。
注：式商容之闾：式，同“轼”，扶着车前横木俯身致敬；商容为商代贤人；闾，里巷之门。
注：廨（xiè）：官署。

# 二｜周子居常云
原：周子居常云：“吾时月不见黄叔度，则鄙吝之心已复生矣！”|| 周乘常说：“我只要隔上一段日子没见到黄叔度，那些庸俗贪鄙的念头就又冒出来了！”
注：周子居：周乘，字子居，东汉汝南人，以刚直著称。
注：黄叔度：黄宪，字叔度，汝南慎阳人，出身寒微而德行高洁，时人比之颜回。
注：时月：一季或一月，泛指一段时间。

# 三｜郭林宗至汝南
原：郭林宗至汝南，造袁奉高，车不停轨，鸾不辍轭；诣黄叔度，乃弥日信宿。人问其故，林宗曰：“叔度汪汪如万顷之陂，澄之不清，扰之不浊。其器深广，难测量也。”|| 郭泰到汝南，去拜访袁阆，车子还没停稳、铃铛还在响就告辞了；去拜访黄宪，却整天盘桓，连住了两夜。有人问他缘故，郭泰说：“叔度宽广深沉，像万顷的大湖，想让它更清也清不了，搅动它也浑不了。他的器量深广，实在难以估量。”
注：郭林宗：郭泰，字林宗，太原介休人，东汉末太学生领袖，以善于品评人物著称。
注：袁奉高：袁阆，字奉高，汝南人，东汉士人。
注：鸾：车上的铃。
注：辍：停止。
注：轭（è）：套在牲口颈上的曲木。
注：弥日：整日。
注：信宿：连住两夜。
注：陂（bēi）：湖泊、池塘。

# 四｜李元礼风格秀整
原：李元礼风格秀整，高自标持，欲以天下名教是非为己任。后进之士有升其堂者，皆以为登龙门。|| 李膺风度清秀端严，自视甚高，立志以维护天下的名教是非为己任。后辈读书人凡能进入他家厅堂的，都觉得像是登上了龙门。
注：李元礼：李膺，字元礼，颍川襄城人，东汉末清流领袖，党锢之祸中死于狱。
注：高自标持：自我期许很高，不随流俗。
注：名教：以正名定分为核心的儒家礼教。
注：登龙门：传说鲤鱼跃过龙门即化为龙，比喻得到名人接纳而声价倍增。

# 五｜李元礼尝叹荀淑、钟皓
原：李元礼尝叹荀淑、钟皓曰：“荀君清识难尚，钟君至德可师。”|| 李膺曾赞叹荀淑和钟皓说：“荀君见识清明，难以超越；钟君德行崇高，可以奉为师表。”
注：荀淑：字季和，颍川颍阴人，荀子后裔，东汉名士，号称“神君”。
注：钟皓：字季明，颍川长社人，以德行著称，隐居教授，门徒众多。
注：尚：超过。

# 六｜陈太丘诣荀朗陵
原：陈太丘诣荀朗陵，贫俭无仆役，乃使元方将车，季方持杖后从，长文尚小，载著车中。既至，荀使叔慈应门，慈明行酒，余六龙下食，文若亦小，坐著膝前。于时太史奏：“真人东行。”|| 陈寔去拜访荀淑，家里清贫节俭，没有仆人，就让大儿子元方赶车，小儿子季方拿着手杖跟在后面，孙子长文年纪还小，就放在车里。到了荀家，荀淑叫儿子叔慈出门迎客，慈明斟酒，其余六个儿子端菜上饭，孙子文若也还小，就坐在祖父膝前。当时太史上奏说：“有贤人向东行去了。”
注：陈太丘：陈寔（shí），字仲弓，颍川许县人，曾任太丘长，故称。
注：荀朗陵：荀淑，曾任朗陵侯相，故称。
注：元方、季方：陈寔之子陈纪、陈谌。
注：长文：陈纪之子陈群，后为曹魏重臣。
注：将车：驾车。
注：叔慈、慈明：荀淑之子荀靖、荀爽；荀淑八子皆有才名，时称“八龙”。
注：文若：荀淑之孙荀彧（yù）。
注：真人东行：太史观天象，见德星聚集，奏称有贤人东行，是借天象称颂两家。

# 七｜客有问陈季方
原：客有问陈季方：“足下家君太丘有何功德而荷天下重名？”季方曰：“吾家君譬如桂树生泰山之阿，上有万仞之高，下有不测之深；上为甘露所沾，下为渊泉所润。当斯之时，桂树焉知泰山之高，渊泉之深？不知有功德与无也。”|| 有客人问陈谌：“您父亲陈太丘有什么功德，竟能享有天下盛名？”季方说：“我父亲好比一株桂树，长在泰山的山坳里，上面是万仞高峰，下面是深不可测的幽谷；上有甘露滋润，下有深泉浇灌。在这种时候，桂树哪里知道泰山有多高、深泉有多深呢？我也不知道他有没有功德。”
注：家君：称对方或自己的父亲，此处客人称季方之父。
注：荷：承受。
注：阿（ē）：山的曲折处。
注：仞（rèn）：古代长度单位，七尺或八尺为一仞。
注：季方此答以桂树自然生长作比，意谓父亲德行出于天性，不自知其功德，其名自至。

# 八｜陈元方子长文
原：陈元方子长文，有英才，与季方子孝先各论其父功德，争之不能决。咨于太丘，太丘曰：“元方难为兄，季方难为弟。”|| 陈纪的儿子陈群才华出众，他和陈谌的儿子陈忠各自夸说自己父亲的功德，争来争去分不出高下，便去问祖父陈寔。陈寔说：“元方难以做他的哥哥，季方也难以做他的弟弟。”
注：孝先：陈忠，字孝先，陈谌之子。
注：咨：询问。
注：难为兄、难为弟：意谓二人德行相当，兄弟难分高下；后世成语“难兄难弟”源出于此。

# 九｜荀巨伯远看友人疾
原：荀巨伯远看友人疾，值胡贼攻郡，友人语巨伯曰：“吾今死矣，子可去。”巨伯曰：“远来相视，子令吾去，败义以求生，岂荀巨伯所行邪？”贼既至，谓巨伯曰：“大军至，一郡尽空，汝何男子，而敢独止？”巨伯曰：“友人有疾，不忍委之，宁以我身代友人命。”贼相谓曰：“我辈无义之人，而入有义之国。”遂班军而还，一郡并获全。|| 荀巨伯远道去探望生病的朋友，恰逢胡兵攻打郡城，朋友对他说：“我这回是死定了，你快走吧。”巨伯说：“我大老远来看你，你却叫我走，丢下道义来求活命，这难道是我荀巨伯干得出的事吗？”胡兵进了城，对巨伯说：“大军一到，全城的人都跑光了，你是什么样的汉子，竟敢一个人留下？”巨伯说：“朋友有病，我不忍心丢下他，宁愿拿我的性命换他的性命。”胡兵们互相说：“我们这些不讲道义的人，竟闯进了讲道义的地方。”于是撤兵回去，全城都因此得以保全。
注：荀巨伯：东汉桓帝时颍川人，生平不详。
注：胡贼：指侵扰边郡的北方少数民族军队。
注：委：抛弃。
注：国：这里泛指地方。
注：班军：撤军。

# 十｜华歆遇子弟甚整
原：华歆遇子弟甚整，虽闲室之内，严若朝典；陈元方兄弟恣柔爱之道。而二门之里，两不失雍熙之轨焉。|| 华歆对待家中子弟非常严整，即使在家闲居，也庄重得像朝廷典礼；陈纪兄弟之间则尽情以温和亲爱相待。两家门风虽然不同，却都不失和睦安乐的规范。
注：华歆（xīn）：字子鱼，平原高唐人，汉末名士，入魏官至太尉。
注：遇：对待。
注：整：严肃。
注：朝典：朝廷的典礼。
注：恣：放任，尽情。
注：雍熙：和乐融洽。
注：轨：法度。

# 十一｜管宁、华歆共园中锄菜
原：管宁、华歆共园中锄菜，见地有片金，管挥锄与瓦石不异，华捉而掷去之。又尝同席读书，有乘轩冕过门者，宁读如故，歆废书出看。宁割席分坐，曰：“子非吾友也！”|| 管宁和华歆一起在园子里锄菜，看见地上有一片金子，管宁照样挥锄，把它看得和瓦片石块没有两样，华歆却把它拾起来再扔掉。两人又曾同坐一张席子读书，有达官乘着华车从门前经过，管宁照旧读书，华歆却放下书跑出去看。管宁便割断席子分开坐，说：“你不是我的朋友！”
注：管宁：字幼安，北海朱虚人，汉末避乱辽东，讲学授徒，魏时屡征不就。
注：捉：拿起。
注：席：古人铺席坐地。
注：轩冕：轩是大夫以上所乘有帷幕的车，冕是礼冠，合指显贵之人；此处偏重“轩”。

# 十二｜王朗每以识度推华歆
原：王朗每以识度推华歆。歆蜡日尝集子侄燕饮，王亦学之。有人向张华说此事，张曰：“王之学华，皆是形骸之外，去之所以更远。”|| 王朗常常推崇华歆的见识气度。华歆曾在蜡日召集子侄们宴饮，王朗也跟着学。有人跟张华说起这件事，张华说：“王朗学华歆，学的都是外在的形迹，所以离华歆反而更远了。”
注：王朗：字景兴，东海郯人，汉末魏初名臣，官至司徒。
注：识度：见识与器量。
注：蜡（zhà）日：岁末合祭百神之日，有宴饮之俗。
注：燕饮：宴饮，燕通“宴”。
注：张华：字茂先，范阳方城人，西晋名臣，博学多识，著《博物志》。
注：形骸之外：身体之外的东西，指表面形式而非内在精神。

# 十三｜华歆、王朗俱乘船避难
原：华歆、王朗俱乘船避难，有一人欲依附，歆辄难之。朗曰：“幸尚宽，何为不可？”后贼追至，王欲舍所携人。歆曰：“本所以疑，正为此耳。既已纳其自托，宁可以急相弃邪？”遂携拯如初。世以此定华、王之优劣。|| 华歆和王朗一同乘船避难，有个人想搭船跟着走，华歆当即表示为难。王朗说：“船上恰好还宽敞，为什么不行？”后来贼兵追上来了，王朗就想丢下那个搭船的人。华歆说：“我当初之所以犹豫，正是怕出现这种情况。既然已经答应了他的托付，怎么能因为情势危急就抛弃他呢？”于是仍像当初那样带着他、救护他。世人就凭这件事评定华歆和王朗的高下。
注：依附：跟随搭船。
注：难之：认为这件事难办，表示不赞成。
注：宁（nìng）：难道，岂。

# 十四｜王祥事后母朱夫人甚谨
原：王祥事后母朱夫人甚谨。家有一李树，结子殊好，母恒使守之。时风雨忽至，祥抱树而泣。祥尝在别床眠，母自往暗斫之；值祥私起，空斫得被。既还，知母憾之不已，因跪前请死。母于是感悟，爱之如己子。|| 王祥侍奉后母朱夫人非常恭谨。家里有一棵李树，结的果子特别好，后母常叫他看守。有时风雨忽然袭来，王祥就抱着李树哭泣。王祥曾在另一张床上睡觉，后母亲自摸黑去砍他；恰好王祥起身小解，后母只砍中了被子。王祥回来后，知道后母对自己怨恨不止，就跪在她面前请求处死。后母这才受到感动而醒悟，从此疼爱他像亲生儿子一样。
注：王祥：字休徵，琅邪临沂人，以孝著称，魏晋间官至太保。
注：谨：恭敬小心。
注：私起：起夜小解。
注：憾：怨恨。
注：感悟：受感动而醒悟。

# 十五｜晋文王称阮嗣宗至慎
原：晋文王称阮嗣宗至慎，每与之言，言皆玄远，未尝臧否人物。|| 晋文王称赞阮籍极其谨慎，每次跟他谈话，他说的都是玄虚深远的道理，从来不评论别人的好坏。
注：晋文王：司马昭，字子上，魏末执掌朝政，封晋王，其子司马炎代魏后追尊为文帝。
注：阮嗣宗：阮籍，字嗣宗，陈留尉氏人，竹林七贤之一，在魏晋易代之际以醉酒、慎言避祸。
注：臧否（zāng pǐ）：褒贬，评论好坏。

# 十六｜王戎云与嵇康居二十年
原：王戎云：“与嵇康居二十年，未尝见其喜愠之色。”|| 王戎说：“我和嵇康相处了二十年，从没见他脸上露出过喜怒的神色。”
注：王戎：字濬冲，琅邪临沂人，竹林七贤中年最少者，西晋时官至司徒。
注：嵇康：字叔夜，谯国铚县人，竹林七贤之一，善琴好老庄，后为司马昭所杀。
注：愠（yùn）：怨怒。

# 十七｜王戎、和峤同时遭大丧
原：王戎、和峤同时遭大丧，俱以孝称。王鸡骨支床，和哭泣备礼。武帝谓刘仲雄曰：“卿数省王、和不？闻和哀苦过礼，使人忧之。”仲雄曰：“和峤虽备礼，神气不损；王戎虽不备礼，而哀毁骨立。臣以和峤生孝，王戎死孝。陛下不应忧峤，而应忧戎。”|| 王戎和和峤同时遭遇父母之丧，两人都以孝顺著称。王戎瘦得皮包骨头，只能靠床支撑着身子；和峤则哭泣守丧，礼数周全。晋武帝对刘毅说：“你常去看望王戎、和峤吗？听说和峤哀伤悲苦超过了礼制，真让人担心。”刘毅说：“和峤虽然礼数周全，精神元气却没有损伤；王戎虽然不拘礼数，却因哀伤过度，瘦得只剩一把骨头。我认为和峤是保全性命的孝，王戎是以命相拼的孝。陛下不该为和峤担心，倒该为王戎担心。”
注：和峤（qiáo）：字长舆，汝南西平人，西晋大臣，家富而吝。
注：大丧：父母之丧。
注：鸡骨支床：形容极度消瘦，卧床不起。
注：备礼：礼数完备。
注：武帝：晋武帝司马炎。
注：刘仲雄：刘毅，字仲雄，东莱掖人，以刚正敢言著称。
注：数（shuò）：屡次。
注：省：探望。
注：不（fǒu）：同“否”。
注：哀毁骨立：因哀伤而形销骨立。

# 十八｜梁王、赵王
原：梁王、赵王，国之近属，贵重当时。裴令公岁请二国租钱数百万，以恤中表之贫者。或讥之曰：“何以乞物行惠？”裴曰：“损有余，补不足，天之道也。”|| 梁王、赵王是皇家近亲，在当时地位尊贵显赫。裴楷每年都向这两个封国讨要几百万租税钱，用来周济亲戚中贫困的人。有人讥讽他说：“为什么讨来别人的东西去做好人？”裴楷说：“减损多余的，补给不足的，这正是天道啊。”
注：梁王：司马肜（róng），司马懿之子。
注：赵王：司马伦，司马懿之子，后篡位被杀。
注：裴令公：裴楷，字叔则，河东闻喜人，官至中书令，故称“令公”，风神俊朗，时称“玉人”。
注：中表：父亲姊妹的子女为外，母亲兄弟姊妹的子女为内，统称中表，泛指亲戚。
注：恤：救济。
注：损有余，补不足：语出《老子》第七十七章，“天之道，损有余而补不足”。

# 十九｜王戎云太保居在正始中
原：王戎云：“太保居在正始中，不在能言之流；及与之言，理中清远。将无以德掩其言？”|| 王戎说：“太保王祥身处正始年间，不算是那批擅长清谈的人；可是真跟他交谈起来，说理却恰当而清雅深远。莫非是他的德行太高，把言谈的才能给遮掩了？”
注：太保：指王祥，晋初官至太保。
注：正始：魏齐王曹芳年号（240—249），何晏、王弼等倡导玄学清谈，盛极一时。
注：能言之流：指擅长清谈的名士。
注：中（zhòng）：恰当，合理。
注：将无：莫非，表示委婉的推测，实含肯定之意。

# 二十｜王安丰遭艰
原：王安丰遭艰，至性过人。裴令往吊之，曰：“若使一恸果能伤人，濬冲必不免灭性之讥。”|| 王戎遭遇父母之丧，孝心之真挚远超常人。裴楷前去吊唁，说：“如果一场痛哭真能伤害身体，那濬冲一定免不了要被人讥为哀毁丧身了。”
注：王安丰：王戎，封安丰县侯，故称。
注：遭艰：遭遇父母之丧。
注：至性：天性中真挚的孝心。
注：一恸（tòng）：一场极度悲痛的哭泣。
注：灭性：因哀伤过度而毁身丧命；《孝经》主张“毁不灭性”，居丧不应伤及性命。

# 二十一｜王戎父浑有令名
原：王戎父浑，有令名，官至凉州刺史。浑薨，所历九郡义故，怀其德惠，相率致赙数百万，戎悉不受。|| 王戎的父亲王浑有很好的名声，官做到凉州刺史。王浑去世后，他任职过的九个郡的旧部故交，感念他的恩德，纷纷送来几百万钱帮助办丧事，王戎一概没有收下。
注：浑：王浑，字长源，王戎之父，曹魏时任凉州刺史（与西晋另一位司徒王浑同名异人）。
注：薨（hōng）：古称诸侯或高官去世。
注：义故：因恩义结交的旧部、故人。
注：赙（fù）：送给丧家助办丧事的财物。

# 二十二｜刘道真尝为徒
原：刘道真尝为徒。扶风王骏以五百匹布赎之，既而用为从事中郎。当时以为美事。|| 刘宝曾经沦为服劳役的囚徒。扶风王司马骏用五百匹布把他赎了出来，不久又任用他做从事中郎。当时人们把这件事传为美谈。
注：刘道真：刘宝，字道真，高平人，西晋名士，后官至安北将军。
注：徒：服劳役的刑徒。
注：扶风王骏：司马骏，司马懿之子，封扶风王，宗室中以贤德著称。
注：从事中郎：将帅府中的属官。

# 二十三｜王平子、胡毋彦国诸人
原：王平子、胡毋彦国诸人，皆以任放为达，或有裸体者。乐广笑曰：“名教中自有乐地，何为乃尔也？”|| 王澄、胡毋辅之这些人，都把放纵任性当作旷达，有的甚至赤身露体。乐广笑着说：“名教之中自有快乐的天地，何必搞成这个样子呢？”
注：王平子：王澄，字平子，王衍之弟。
注：胡毋彦国：胡毋辅之，字彦国，嗜酒放达。二人皆西晋放诞名士。
注：任放：任性放纵。
注：达：通达，指超脱礼法。
注：乐广：字彦辅，南阳淯阳人，西晋清谈名士，官至尚书令。
注：乃尔：如此，这样。

# 二十四｜郗公值永嘉丧乱
原：郗公值永嘉丧乱，在乡里，甚穷馁。乡人以公名德，传共饴之。公常携兄子迈及外生周翼二小儿往食，乡人曰：“各自饥困，以君之贤，欲共济君耳，恐不能兼有所存。”公于是独往食，辄含饭著两颊边，还，吐与二儿。后并得存，同过江。郗公亡，翼为剡县，解职归，席苫于公灵床头，心丧终三年。|| 郗鉴遇上永嘉之乱，在家乡穷困挨饿。乡亲们因为他有名望、有德行，就轮流供他饭吃。郗鉴常常带着侄儿郗迈和外甥周翼两个孩子一起去吃，乡亲们说：“大家各自都在挨饿受困，因为您贤德，才想着一起接济您，恐怕没法连带养活别人了。”郗鉴从此就独自去吃，每次都把饭含在两腮里，回来再吐出来喂两个孩子。后来两个孩子都活了下来，一同渡江南下。郗鉴去世时，周翼正任剡县县令，他辞去官职回来，在郗鉴的灵床前铺草垫守丧，心中服丧整整三年。
注：郗（xī）公：郗鉴，字道徽，高平金乡人，东晋重臣，官至太尉。
注：永嘉丧乱：晋怀帝永嘉年间，匈奴刘聪等攻陷洛阳，中原大乱，士族纷纷南渡。
注：馁（něi）：饥饿。
注：传共饴（sì）之：轮流给他饭吃。饴，同“饲”。
注：外生：外甥。
注：为剡（shàn）县：任剡县县令。
注：席苫（shān）：睡在草垫上，古代守丧之礼。
注：心丧：不穿丧服而心中哀悼守丧。

# 二十五｜顾荣在洛阳
原：顾荣在洛阳，尝应人请，觉行炙人有欲炙之色，因辍己施焉。同坐嗤之。荣曰：“岂有终日执之，而不知其味者乎？”后遭乱渡江，每经危急，常有一人左右己。问其所以，乃受炙人也。|| 顾荣在洛阳时，有一次应邀赴宴，发觉端送烤肉的仆人露出想吃烤肉的神情，就停下不吃，把自己那份给了他。同席的人都讥笑他。顾荣说：“哪有整天端着烤肉，却不知道它是什么滋味的道理？”后来遭逢战乱渡江南下，每逢危急关头，总有一个人在身边护助他。问他为什么这样做，原来就是当年得到烤肉的那个人。
注：顾荣：字彦先，吴郡吴县人，江南大族，入晋为官，后辅佐司马睿立足江东。
注：行炙人：传送烤肉的仆役。
注：炙：烤肉。
注：辍：停止。
注：嗤（chī）：讥笑。
注：左右：作动词，护助、扶持。

# 二十六｜祖光禄少孤贫
原：祖光禄少孤贫，性至孝，常自为母炊爨作食。王平北闻其佳名，以两婢饷之，因取为中郎。有人戏之曰：“奴价倍婢。”祖云：“百里奚亦何必轻于五羖之皮邪！”|| 祖纳年少时丧父家贫，天性极孝，常亲自为母亲生火做饭。平北将军王乂听说了他的好名声，就送给他两个婢女，又召他做中郎。有人跟他开玩笑说：“你这个奴才的身价是婢女的两倍。”祖纳说：“百里奚的身价，又何尝比五张黑公羊皮轻呢！”
注：祖光禄：祖纳，字士言，范阳遒县人，祖逖之兄，官至光禄大夫，故称。
注：炊爨（cuàn）：烧火做饭。
注：饷：赠送。
注：王平北：王乂（yì），字叔元，王衍之父，官平北将军，故称。
注：中郎：官名，此指其幕府中的属官。
注：五羖（gǔ）之皮：百里奚本为虞国大夫，流落楚地，秦穆公以五张黑公羊皮将他赎回并重用。祖纳借此自比，意谓被人以物“换”来，并不辱没身价。
