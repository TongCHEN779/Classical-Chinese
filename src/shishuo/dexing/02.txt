# 二十七｜周镇罢临川郡还都
原：周镇罢临川郡还都，未及上住，泊青溪渚，王丞相往看之。时夏月，暴雨卒至，舫至狭小，而又大漏，殆无复坐处。王曰：“胡威之清，何以过此！”即启用为吴兴郡。|| 周镇卸任临川郡守回到京都，还没来得及上岸安顿，船暂泊在青溪的小洲边，丞相王导前去看望他。当时正值夏天，暴雨突然落下，那条船本就极窄小，又漏得厉害，几乎找不到一块能坐的干地方。王导说：“胡威那样的清廉，又怎能胜过这个！”随即上奏起用他做吴兴郡守。
注：周镇：字康时，东晋陈留人，为官清静寡欲，做过临川、吴兴太守。
注：王丞相：王导，字茂弘，琅邪临沂人，东晋开国重臣，辅佐元、明、成三帝。
注：卒：通“猝”，突然。
注：舫：船。
注：胡威：字伯武，魏晋间人，与其父胡质都以清廉著称。

# 二十八｜邓攸始避难
原：邓攸始避难，于道中弃己子，全弟子。既过江，取一妾，甚宠爱。历年后，讯其所由，妾具说是北人遭乱，忆父母姓名，乃攸之甥也。攸素有德业，言行无玷，闻之哀恨终身，遂不复畜妾。|| 邓攸当初逃避战乱时，在半路上舍弃了自己的儿子，保全了弟弟的儿子。渡江南下以后，他娶了一个妾，十分宠爱。过了几年，问起她的来历，妾详细说了自己是北方人，因遭乱流落至此，又回忆起父母的姓名，原来竟是邓攸的外甥女。邓攸向来品德事业都很好，言行没有一点污点，听到这件事，悲痛悔恨了一辈子，从此再也不纳妾。
注：邓攸：字伯道，西晋末平阳襄陵人，永嘉之乱中为保全亡弟之子舍弃亲子，南渡后官至尚书右仆射。
注：取：同“娶”。
注：玷（diàn）：玉上的斑点，比喻品行上的缺点。
注：畜：收养，这里指纳妾。

# 二十九｜王长豫为人谨顺
原：王长豫为人谨顺，事亲尽色养之孝。丞相见长豫辄喜，见敬豫辄嗔。长豫与丞相语，恒以慎密为端。丞相还台，及行，未尝不送至车后。恒与曹夫人并当箱箧。长豫亡后，丞相还台，登车后，哭至台门；曹夫人作簏，封而不忍开。|| 王悦为人恭谨孝顺，侍奉父母总是和颜悦色，尽到孝道。王导一见到王悦就高兴，一见到王恬就生气。王悦和父亲说话，总把谨慎周密当作根本。王导回尚书台办公，临走时，王悦没有一次不送到车后。他常和母亲曹夫人一起收拾箱笼。王悦死后，王导回台，上了车，一路哭到台门；曹夫人收拾好的箱子，封起来再也不忍心打开。
注：王长豫：王悦，字长豫，王导长子，早卒。
注：敬豫：王恬，字敬豫，王导次子，少时好武、不拘礼法。
注：色养：侍奉父母时始终保持和悦的脸色，语本《论语·为政》“色难”。
注：台：尚书台，王导时以丞相领尚书事。
注：当（dàng）：料理。
注：箱箧（qiè）：箱子。
注：曹夫人：王导之妻曹淑。
注：簏（lù）：竹箱。

# 三十｜桓常侍闻人道深公者
原：桓常侍闻人道深公者，辄曰：“此公既有宿名，加先达知称，又与先人至交，不宜说之。”|| 桓彝每听到有人议论竺法深，总是说：“这位先生早有声望，又受到前辈们的称许，并且和我先父是至交，不应该议论他。”
注：桓常侍：桓彝，字茂伦，谯国龙亢人，曾任散骑常侍，苏峻之乱中守泾县殉难。
注：深公：竺道潜，字法深，东晋名僧，与王导、庾亮等名士交往。
注：宿名：素来的名望。
注：先达：前辈名流。
注：知称：赏识称许。
注：先人：已故的父亲。

# 三十一｜庾公乘马有的卢
原：庾公乘马有的卢，或语令卖去。庾云：“卖之必有买者，即复害其主，宁可不安己而移于他人哉？昔孙叔敖杀两头蛇以为后人，古之美谈。效之，不亦达乎？”|| 庾亮所骑的马里有一匹的卢马，有人劝他把它卖掉。¦庾亮说：“卖它一定有人买，那就又会害了它的新主人。哪能因为它对自己不利，就把祸患转嫁给别人呢？¦从前孙叔敖杀死两头蛇，为的是后来的人不再受害，这是古来的美谈。¦我学他的样子，不也是明理通达吗？”
注：庾公：庾亮，字元规，颍川鄢陵人，明帝皇后之兄，东晋重臣。
注：的（dì）卢：额上有白斑的马，旧说是妨害主人的凶马。
注：孙叔敖：春秋楚国令尹。相传他幼时见两头蛇，听说见者必死，便杀而埋之，免得别人再看见。
注：达：通达事理。

# 三十二｜阮光禄在剡
原：阮光禄在剡，曾有好车，借者无不皆给。有人葬母，意欲借而不敢言，阮后闻之，叹曰：“吾有车，而使人不敢借，何以车为？”遂焚之。|| 阮裕住在剡县时，有一辆好车，凡来借的，没有不借给的。¦有个人要安葬母亲，心里想借车却不敢开口。阮裕后来听说了，叹息道：“我有车，却让人不敢来借，还要车做什么？”¦于是把车烧了。
注：阮光禄：阮裕，字思旷，陈留尉氏人，屡辞征召，隐居剡县，曾被征为金紫光禄大夫，故称。
注：剡（shàn）：县名，在今浙江嵊州一带。

# 三十三｜谢奕作剡令
原：谢奕作剡令，有一老翁犯法，谢以醇酒罚之，乃至过醉而犹未已。太傅时年七八岁，著青布绔，在兄膝边坐，谏曰：“阿兄，老翁可念，何可作此！”奕于是改容曰：“阿奴欲放去邪？”遂遣之。|| 谢奕做剡县县令时，有个老头犯了法，谢奕罚他喝烈酒，老人已经醉得不行了还不肯停。谢安当时才七八岁，穿着青布裤子，坐在哥哥膝边，劝道：“哥哥，老人家多可怜，怎么能这样做！”谢奕这才缓和了脸色，说：“阿奴是想放他走吗？”就把老人放了。
注：谢奕：字无奕，陈郡阳夏人，谢安之兄，谢玄之父，官至安西将军、豫州刺史。
注：醇酒：味厚的烈酒。
注：已：停止。
注：太傅：谢安，字安石，东晋名相，淝水之战时总揽全局，死后赠太傅。
注：绔：同“裤”。
注：可念：可怜。
注：改容：改变神色。
注：阿奴：对年幼亲近者的昵称。

# 三十四｜谢太傅绝重褚公
原：谢太傅绝重褚公，常称：“褚季野虽不言，而四时之气亦备。”|| 谢安极其敬重褚裒，常称赞说：“褚季野虽然嘴上不说什么，可心里春夏秋冬的气象样样都有。”
注：褚公：褚裒（póu），字季野，河南阳翟人，康帝皇后之父，以不轻易臧否人物著称。
注：四时之气：四季的气象，比喻胸中褒贬分明、无所不备。

# 三十五｜刘尹在郡
原：刘尹在郡，临终绵惙，闻阁下祠神鼓舞，正色曰：“莫得淫祀！”外请杀车中牛祭神，真长答曰：“‘丘之祷久矣。’勿复为烦。”|| 刘惔在丹阳尹任上，临终病得奄奄一息，听到楼阁下有人击鼓跳舞祭神，便正色说：“不许搞不合礼法的祭祀！”外面的人请求杀掉拉车的牛来祭神，刘惔回答说：“‘我早就祈祷过了。’不要再麻烦了。”
注：刘尹：刘惔（tán），字真长，沛国相人，清谈名士，任丹阳尹，故称刘尹。
注：郡：指丹阳郡。
注：绵惙（chuò）：气息微弱，病势垂危。
注：淫祀：不合礼制、滥行的祭祀。
注：丘之祷久矣：语出《论语·述而》，孔子病重时拒绝子路请祷之语，刘惔借以婉拒。

# 三十六｜谢公夫人教儿
原：谢公夫人教儿，问太傅：“那得初不见君教儿？”答曰：“我常自教儿。”|| 谢安夫人教导儿子时，问谢安：“怎么从没见你教过儿子？”谢安回答：“我一直在用自己的言行教他们。”
注：谢公夫人：谢安之妻刘氏，刘惔之妹。
注：那得：怎么。
注：初不：从来不。

# 三十七｜晋简文为抚军时
原：晋简文为抚军时，所坐床上尘不听拂，见鼠行迹，视以为佳。有参军见鼠白日行，以手板批杀之，抚军意色不说。门下起弹，教曰：“鼠被害尚不能忘怀，今复以鼠损人，无乃不可乎？”|| 晋简文帝做抚军将军时，所坐的坐榻上的灰尘不许人擦掉，看见老鼠爬过的足迹，还觉得很好看。有个参军见老鼠大白天出来走动，用手板把它打死了，简文帝脸上露出不高兴的神色。手下的人要弹劾这个参军，简文帝发下指示说：“老鼠被打死，我尚且不能释怀，如今又为了一只老鼠去伤害人，恐怕不行吧？”
注：晋简文：东晋简文帝司马昱，字道万，即位前曾任抚军大将军，好玄学。
注：床：坐具。
注：不听：不许。
注：参军：将军府属官。
注：手板：笏，官员手持的狭长板子。
注：批：击打。
注：说：同“悦”。
注：弹：弹劾。
注：教：上级对下级的告示。
注：无乃：恐怕，表委婉的反问。

# 三十八｜范宣年八岁
原：范宣年八岁，后园挑菜，误伤指，大啼。人问“痛邪”？答曰：“非为痛，身体发肤，不敢毁伤，是以啼耳。”宣洁行廉约，韩豫章遗绢百匹，不受；减五十匹，复不受。如是减半，遂至一匹，既终不受。韩后与范同载，就车中裂二丈与范云：“人宁可使妇无裈邪？”范笑而受之。|| 范宣八岁时，在后园挑菜，不小心割伤了手指，放声大哭。¦有人问他：“疼吗？”¦他回答：“不是因为疼。身体发肤受之父母，不敢毁伤，所以才哭。”¦范宣品行高洁，廉洁俭约。韩伯送他一百匹绢，他不收；减到五十匹，还是不收。¦就这样一次次减半，一直减到一匹，他始终不肯接受。¦后来韩伯和范宣同坐一辆车，就在车里扯下两丈绢递给范宣，说：“一个人难道能让自己的妻子连裤子都没得穿吗？”¦范宣笑着收下了。
注：范宣：字宣子，陈留人，东晋学者，博通儒学，屡征不就。
注：身体发肤，不敢毁伤：语出《孝经》，意谓身体受之父母，爱护它就是孝。
注：韩豫章：韩伯，字康伯，颍川长社人，曾任豫章太守。
注：遗（wèi）：赠送。
注：宁可：难道能。
注：裈（kūn）：裤子。

# 三十九｜王子敬病笃
原：王子敬病笃，道家上章，应首过，问子敬：“由来有何异同得失？”子敬云：“不觉有余事，唯忆与郗家离婚。”|| 王献之病重，按道家的规矩要请道士向天神上表，病人应当坦白自己的过错。道士问王献之：“一向以来有什么过失？”¦王献之说：“想不起有别的事，只记得和郗家离了婚。”
注：王子敬：王献之，字子敬，王羲之第七子，书法家，与父并称“二王”。
注：笃：病重。
注：道家：指信奉五斗米道的道士。
注：上章：向神灵上表祈祷。
注：首过：自陈罪过。
注：异同得失：偏义复词，偏指过失。
注：与郗家离婚：王献之原娶表姐郗道茂，后被迫离婚，另娶新安公主，一生引为憾事。

# 四十｜殷仲堪既为荆州
原：殷仲堪既为荆州，值水俭，食常五碗盘，外无余肴。饭粒脱落盘席间，辄拾以啖之。虽欲率物，亦缘其性真素。每语子弟云：“勿以我受任方州，云我豁平昔时意，今吾处之不易。贫者士之常，焉得登枝而捐其本！尔曹其存之。”|| 殷仲堪当了荆州刺史以后，正赶上水灾歉收，他吃饭常常只用五碗盘装的饭菜，此外不加别的菜。¦饭粒掉在盘子里或席子上，总是捡起来吃掉。¦这样做虽然有给众人做表率的意思，也是由于他本性真率朴素。¦他常对子弟们说：“不要因为我做了一州长官，就说我把平日的志向抛开了。如今我处在这个位置上，并没有改变。¦清贫是读书人的本分，哪能爬上了高枝就丢掉根本！¦你们要记住这话。”
注：殷仲堪：陈郡人，善清言，孝武帝时任荆州刺史，后为桓玄所败而死。
注：水俭：水灾造成的歉收。
注：五碗盘：一盘托五只小碗的成套食器。
注：啖（dàn）：吃。
注：率物：为众人做表率。
注：方州：大州，指一州长官之任。
注：豁：舍弃。
注：捐：抛弃。
注：尔曹：你们。

# 四十一｜初，桓南郡、杨广共说殷荆州
原：初，桓南郡、杨广共说殷荆州，宜夺殷觊南蛮以自树。觊亦即晓其旨。尝因行散，率尔去下舍，便不复还，内外无预知者。意色萧然，远同斗生之无愠。时论以此多之。|| 当初，桓玄和杨广一同劝说殷仲堪，应该夺取殷觊的南蛮校尉之职，来壮大自己。殷觊也随即明白了他们的用意。有一次他借着服药后出门行散，随随便便地离开了官舍，就再也没有回去，家里家外事先没有一个人知道。他神情淡然，很像当年令尹子文三次被罢官而毫无怨色。当时的舆论因此称赞他。
注：桓南郡：桓玄，桓温之子，袭封南郡公，后篡晋称帝。
注：杨广：字德度，弘农华阴人，殷仲堪的部属。
注：殷觊（jì）：字伯道，殷仲堪的堂兄，时任南蛮校尉。
注：南蛮：南蛮校尉，掌荆楚一带少数民族事务的武职。
注：行散：服五石散后须走动以发散药性。
注：率尔：随意，轻率。
注：下舍：官舍。
注：斗生：楚令尹斗穀於菟（dòu gòu wū tú），字子文，三次罢官而无愠色。
注：多：称赞。

# 四十二｜王仆射在江州
原：王仆射在江州，为殷、桓所逐，奔窜豫章，存亡未测。王绥在都，既忧戚在貌，居处饮食，每事有降。时人谓为“试守孝子”。|| 王愉在江州刺史任上，被殷仲堪、桓玄的兵马驱逐，逃到豫章，生死不明。他的儿子王绥在京城，满脸忧伤，起居饮食，样样都降低标准。当时的人称他为“试用期的孝子”。
注：王仆射（yè）：王愉，字茂和，太原晋阳人，时任江州刺史，桓玄篡位后为尚书仆射。
注：殷、桓：殷仲堪、桓玄。
注：豫章：郡名，治所在今江西南昌。
注：王绥：字彦猷，王愉之子，后与父同因谋反被杀。
注：试守：官吏正式任用前的试用。父亲生死未卜就先行孝子之礼，故以此戏称。

# 四十三｜桓南郡既破殷荆州
原：桓南郡既破殷荆州，收殷将佐十许人，咨议罗企生亦在焉。桓素待企生厚，将有所戮，先遣人语云：“若谢我，当释罪。”企生答曰：“为殷荆州吏，今荆州奔亡，存亡未判，我何颜谢桓公！”既出市，桓又遣人问：“欲何言？”答曰：“昔晋文王杀嵇康，而嵇绍为晋忠臣。从公乞一弟以养老母。”桓亦如言宥之。桓先曾以一羔裘与企生母胡，胡时在豫章，企生问至，即日焚裘。|| 桓玄打败殷仲堪后，拘捕了殷仲堪手下十几个将领僚属，咨议参军罗企生也在其中。桓玄向来待罗企生很好，准备杀一些人之前，先派人对他说：“如果你向我认错，就免你的罪。”罗企生回答：“我是殷荆州的属吏，如今荆州出逃，生死还没弄清楚，我有什么脸面向桓公认错！”被押到刑场后，桓玄又派人问他：“还想说什么？”他回答：“从前晋文王杀了嵇康，可嵇绍后来成了晋朝的忠臣。我向桓公求一个弟弟的性命，好让他奉养老母。”桓玄也依他所言赦免了他的弟弟。桓玄先前曾送给罗企生的母亲胡氏一件羔羊皮袍，胡氏当时在豫章，企生被杀的消息传到，她当天就把皮袍烧了。
注：罗企生：字宗伯，豫章人，任殷仲堪的咨议参军，殷败后被桓玄所杀。
注：咨议：咨议参军，备咨询谋议的属官。
注：谢：认错，道歉。
注：判：分明。
注：市：刑场，古代常在闹市行刑。
注：晋文王：司马昭，杀嵇康。嵇绍为嵇康之子，后仕晋，在荡阴之战中以身护卫惠帝而死。
注：宥：赦免。
注：羔裘：羊羔皮袍。
注：问：音讯。

# 四十四｜王恭从会稽还
原：王恭从会稽还，王大看之。见其坐六尺簟，因语恭：“卿东来，故应有此物，可以一领及我。”恭无言。大去后，即举所坐者送之。既无余席，便坐荐上。后大闻之，甚惊曰：“吾本谓卿多，故求耳。”对曰：“丈人不悉恭，恭作人无长物。”|| 王恭从会稽回来，王忱去看他。见他坐着一张六尺长的竹席，就对王恭说：“你从东边来，自然该有这种东西，可以送我一张。”王恭没说话。王忱走后，王恭就把自己坐的那张送了过去。他自己没有多余的席子，就坐在草垫上。后来王忱听说了，十分吃惊，说：“我原以为你有很多，才向你要的。”王恭回答：“您不了解我，我做人向来没有多余的东西。”
注：王恭：字孝伯，太原晋阳人，孝武帝皇后之兄，后起兵讨王国宝等，兵败被杀。
注：会稽：郡名，治今浙江绍兴。
注：王大：王忱，字元达，小字佛大，王坦之之子，与王恭齐名。
注：簟（diàn）：竹席。
注：领：量词，一张。
注：荐：草垫子。
注：丈人：对人的尊称。
注：长（zhàng）物：多余的东西。

# 四十五｜吴郡陈遗
原：吴郡陈遗，家至孝。母好食铛底焦饭，遗作郡主簿，恒装一囊，每煮食，辄贮录焦饭，归以遗母。后值孙恩贼出吴郡，袁府君即日便征。遗已聚敛得数斗焦饭，未展归家，遂带以从军。战于沪渎，败，军人溃散，逃走山泽，皆多饥死，遗独以焦饭得活。时人以为纯孝之报也。|| 吴郡人陈遗，在家非常孝顺。他母亲爱吃锅底的焦饭，陈遗在郡里做主簿时，常带着一只口袋，每次煮饭，总把锅巴收存起来，回家时带给母亲。后来碰上孙恩作乱攻打吴郡，太守袁山松当天就出兵征讨。陈遗已经攒了几斗焦饭，来不及送回家，就带着随军出发。在沪渎交战失利，军队溃散，士兵们逃进山林水泽，大多饿死了，唯独陈遗靠着那些焦饭活了下来。当时的人认为这是他纯孝的回报。
注：陈遗：吴郡人，生平不详。
注：铛（chēng）：平底浅锅。
注：主簿：掌文书簿籍的属官。
注：贮录：储存收藏。
注：遗（wèi）：送给。
注：孙恩：东晋末五斗米道首领，聚众起事，攻掠会稽、吴郡等地。
注：袁府君：吴郡太守袁山松，后在沪渎战死。
注：未展：来不及。
注：沪渎（dú）：水名，在今上海一带吴淞江下游入海处。

# 四十六｜孔仆射为孝武侍中
原：孔仆射为孝武侍中，豫蒙眷接。烈宗山陵，孔时为太常，形素羸瘦，著重服，竟日涕泗流涟，见者以为真孝子。|| 孔安国做孝武帝的侍中，曾受到皇帝的关怀厚待。孝武帝驾崩时，孔安国正任太常，他身体一向瘦弱，穿着重孝，整天鼻涕眼泪流个不停，看见的人都认为他是真正的孝子。
注：孔仆射：孔安国，会稽山阴人，孝武帝时任侍中、太常，安帝时官至尚书仆射。
注：豫：参与，这里指得以。
注：眷接：关爱厚待。
注：烈宗：晋孝武帝司马曜的庙号。
注：山陵：帝王陵墓，借指帝王去世。
注：太常：掌礼乐祭祀的官。
注：羸（léi）瘦：瘦弱。
注：重服：最重的丧服。

# 四十七｜吴道助、附子兄弟
原：吴道助、附子兄弟居在丹阳郡后，遭母童夫人艰，朝夕哭临，及思至，宾客吊省，号踊哀绝，路人为之落泪。韩康伯时为丹阳尹，母殷在郡，每闻二吴之哭，辄为凄恻，语康伯曰：“汝若为选官，当好料理此人。”康伯亦甚相知。韩后果为吏部尚书，大吴不免哀制，小吴遂大贵达。|| 吴坦之、吴隐之兄弟住在丹阳郡府的后面，遭遇母亲童夫人的丧事，早晚哭祭，到了穿孝服守丧、宾客前来吊唁时，他们捶胸顿足，哀痛欲绝，连过路的人都为之落泪。韩康伯当时任丹阳尹，母亲殷氏住在郡府里，每次听到吴家兄弟的哭声，都为之悲伤，对康伯说：“你将来如果主管选官，应当好好照顾这两个人。”康伯也很了解他们。后来韩康伯果然做了吏部尚书，可哥哥吴坦之因守丧哀伤过度而死，弟弟吴隐之终于显贵发达。
注：吴道助：吴坦之，字处靖，小字道助。
注：附子：吴隐之，字处默，小字附子，以清廉著称，官至广州刺史。二人为濮阳鄄城人。
注：艰：父母之丧。
注：哭临：举哀哭祭。
注：思至：此处所用底本注读作“缌绖”，指披麻戴孝的丧期；也有人理解为哀思涌来之时，存疑。
注：号踊：哭号顿足。
注：韩康伯：韩伯，母殷氏为殷浩之姊。
注：丹阳尹：京畿丹阳郡的长官。
注：选官：主管选拔官员的官。
注：料理：照顾，安排。
注：哀制：守丧期间的哀伤，“不免哀制”谓因居丧哀毁而死。
