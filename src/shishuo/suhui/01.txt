# 本门导读
题解：夙惠即早慧。本门七则都写孩童的聪敏应对，或过耳不忘，或巧于辞令，或言行近乎成人，可见魏晋时人对少年才性的看重与品题。

# 一｜宾客诣陈太丘宿
原：宾客诣陈太丘宿，太丘使元方、季方炊。客与太丘论议，二人进火，俱委而窃听，炊忘著箄，饭落釜中。太丘问：“炊何不馏？”元方、季方长跪曰：“大人与客语，乃俱窃听，炊忘著箄，饭今成糜。”太丘曰：“尔颇有所识不？”对曰：“仿佛志之。”二子俱说，更相易夺，言无遗失。太丘曰：“如此，但糜自可，何必饭也！”|| 有客人到陈寔家留宿，陈寔叫儿子元方、季方去做饭。客人和陈寔谈论起来，两个孩子生好火，就都丢下灶头去偷听，蒸饭时忘了放箅子，米都掉进了锅里。陈寔问：“饭怎么没蒸出来？”元方、季方直身跪着说：“父亲和客人说话，我们俩都去偷听了，蒸饭忘了放箅子，饭如今煮成了粥。”陈寔说：“那你们记住了些什么没有？”两人答道：“大致记得。”于是兄弟俩一起复述，你纠正我、我补充你，说的话一点也没漏。陈寔说：“既然这样，喝粥也就行了，何必非吃干饭不可！”
注：陈太丘：陈寔（shí），字仲弓，东汉颍川许县人，曾任太丘县长，以德行著称。
注：元方、季方：陈寔之子陈纪（字元方）、陈谌（字季方），兄弟均有贤名。
注：箄（bì）：蒸饭时垫在锅里的竹箅子。馏：把米先煮后蒸熟。糜（mí）：粥。
注：识（zhì）：记住。更相易夺：互相订正补充。

# 二｜何晏七岁
原：何晏七岁，明惠若神，魏武奇爱之。因晏在宫内，欲以为子。晏乃画地令方，自处其中。人问其故，答曰：“何氏之庐也。”魏武知之，即遣还。|| 何晏七岁时，聪明得出神入化，曹操非常喜爱他。因为何晏住在宫里，曹操想认他做儿子。何晏就在地上画了个方框，自己待在里面。有人问他这是做什么，他回答：“这是何家的房子。”曹操知道后，立刻把他送回何家。
注：何晏：字平叔，南阳宛县人，汉末大将军何进之孙。其母尹氏为曹操所纳，他随母入宫抚养，后为魏玄学名士。
注：魏武：曹操，死后追尊为魏武帝。
注：明惠：聪明。惠，同“慧”。

# 三｜晋明帝数岁
原：晋明帝数岁，坐元帝膝上。有人从长安来，元帝问洛下消息，潸然流涕。明帝问何以致泣，具以东渡意告之。因问明帝：“汝意谓长安何如日远？”答曰：“日远。不闻人从日边来，居然可知。”元帝异之。明日，集群臣宴会，告以此意，更重问之。乃答曰：“日近。”元帝失色曰：“尔何故异昨日之言邪？”答曰：“举目见日，不见长安。”|| 晋明帝才几岁时，坐在元帝膝上。有人从长安来，元帝向他打听洛阳的消息，不禁潸然泪下。明帝问父亲为什么哭，元帝就把衣冠南渡的原委告诉了他。接着问明帝：“你觉得长安和太阳比，哪个远？”明帝答：“太阳远。没听说有人从太阳那边来，这显然就知道了。”元帝很惊奇。第二天召集群臣宴饮，元帝把这番话讲给大家听，又重新问明帝一遍。明帝却答：“太阳近。”元帝变了脸色说：“你为什么和昨天说的不一样？”明帝答：“抬眼就看得见太阳，却看不见长安。”
注：晋明帝：司马绍，元帝长子，东晋第二位皇帝。
注：元帝：司马睿，西晋宗室，永嘉之乱后南渡，在建康建立东晋。
注：洛下：洛阳一带，西晋旧都。东渡：指晋室南迁江东。
注：潸（shān）然：流泪的样子。居然：显然。

# 四｜司空顾和与时贤共清言
原：司空顾和与时贤共清言，张玄之、顾敷是中外孙，年并七岁，在床边戏。于时闻语，神情如不相属。瞑于灯下，二儿共叙客主之言，都无遗失。顾公越席而提其耳曰：“不意衰宗复生此宝。”|| 司空顾和和当时的名流一起清谈，他的外孙张玄之、孙子顾敷都才七岁，在坐榻边玩耍。那时听大人谈话，两人神情好像毫不在意。后来顾和在灯下闭目养神，两个孩子一起复述客人与主人的谈论，一句也没漏掉。顾和离开坐席，提着他们的耳朵说：“想不到我们这个衰落的家族又出了这样的宝贝。”
注：顾和：字君孝，吴郡吴县人，东晋大臣，官至尚书令，死后追赠司空。
注：中外孙：孙子与外孙。儿子所生为中，女儿所生为外。张玄之是外孙，顾敷是孙子。
注：清言：清谈。不相属（zhǔ）：不相关注，像是没在听。
注：瞑：闭眼。衰宗：衰微的家族，自谦之辞。

# 五｜韩康伯数岁
原：韩康伯数岁，家酷贫，至大寒，止得襦。母殷夫人自成之，令康伯捉熨斗，谓康伯曰：“且著襦，寻作复裈。”儿云：“已足，不须复裈也。”母问其故，答曰：“火在熨斗中而柄热，今既著襦，下亦当暖，故不须耳。”母甚异之，知为国器。|| 韩康伯才几岁时，家里极穷，到了严冬，只有一件短袄可穿。母亲殷夫人亲手给他缝制，让康伯拿着熨斗，对他说：“先穿上短袄，过些日子再给你做条夹裤。”孩子说：“够了，用不着夹裤。”母亲问为什么，他答道：“火在熨斗里，连柄都热了，如今穿上了短袄，下身自然也该暖和，所以用不着。”母亲十分惊奇，知道这孩子将来是治国的人才。
注：韩康伯：韩伯，字康伯，颍川长社人，东晋玄学家，官至吏部尚书，曾注《周易·系辞》。
注：殷夫人：韩伯之母，殷浩之姊。
注：襦（rú）：短袄。复裈（kūn）：夹裤。
注：寻：不久。国器：可以治国的大才。

# 六｜晋孝武年十二
原：晋孝武年十二，时冬天，昼日不著复衣，但著单练衫五六重，夜则累茵褥。谢公谏曰：“圣体宜令有常。陛下昼过冷，夜过热，恐非摄养之术。”帝曰：“昼动夜静。”谢公出叹曰：“上理不减先帝。”|| 晋孝武帝十二岁那年，正值冬天，白天不穿夹衣，只穿五六层白绢单衫，夜里却叠铺好几层褥垫。谢安劝谏说：“皇上的身体应当顺乎常规。陛下白天太冷，夜里太热，恐怕不是养身之道。”孝武帝说：“白天要活动，夜里要安静。”谢安出来感叹道：“皇上谈理的本事不比先帝差。”
注：晋孝武：司马曜，简文帝之子，东晋皇帝，十一岁即位。
注：复衣：夹衣。单练衫：白色熟绢做的单衣。
注：茵褥：垫褥。谢公：谢安。摄养：调养身体。
注：先帝：指孝武帝之父简文帝司马昱，素好玄谈。

# 七｜桓宣武薨
原：桓宣武薨，桓南郡年五岁，服始除，桓车骑与送故文武别，因指语南郡：“此皆汝家故吏佐。”玄应声恸哭，酸感傍人。车骑每自目己坐曰：“灵宝成人，当以此坐还之。”鞠爱过于所生。|| 桓温去世时，桓玄才五岁，丧服刚除，桓冲和送葬的文武官员告别，指着他们对桓玄说：“这些都是你家的旧部属。”桓玄应声痛哭，悲伤得让旁人也心酸。桓冲常常看着自己的座位说：“等灵宝长大成人，就把这个位子还给他。”他抚养疼爱桓玄，胜过自己亲生的孩子。
注：桓宣武：桓温，谥宣武。薨（hōng）：高官或诸侯死去。
注：桓南郡：桓玄，桓温幼子，小字灵宝，袭封南郡公，后篡晋称帝，兵败被杀。
注：桓车骑：桓冲，桓温之弟，官至车骑将军，桓温死后接掌其兵权。
注：送故：送葬的旧属。酸感：悲痛感动。鞠爱：抚育爱护。所生：亲生子女。
