# 本门导读
题解：“忿狷”指易怒急躁、气量偏狭。本门八则，有王述筷子戳鸡蛋的千古笑谈，也有王述面壁忍骂的克制、谢安品评王献之的矜持；写人发怒，往往正见其性情。

# 一｜魏武有一妓
原：魏武有一妓，声最清高，而情性酷恶。欲杀则爱才，欲置则不堪。于是选百人，一时俱教。少时，果有一人声及之，便杀恶性者。|| 曹操有个歌女，嗓音最为清亮高亢，可是性情极坏。想杀了她又爱惜她的才艺，想放过她又实在受不了。于是挑选了一百人，同时一起教她们唱。不久，果然有一个人的歌声赶上了她，曹操就把那个脾气坏的杀了。
注：魏武：曹操，死后追尊魏武帝。
注：妓：歌舞女艺人。
注：酷恶：极坏。
注：置：搁下不管。
注：不堪：受不了。
注：及：赶得上。

# 二｜王蓝田性急
原：王蓝田性急。尝食鸡子，以箸刺之，不得，便大怒，举以掷地。鸡子于地圆转未止，仍下地以屐齿蹍之，又不得，瞋甚，复于地取内口中，啮破即吐之。王右军闻而大笑曰：“使安期有此性，犹当无一豪可论，况蓝田邪？”|| 王述性子急。有一次吃鸡蛋，用筷子去戳，没戳着，就大发脾气，抓起来扔到地上。鸡蛋在地上滴溜溜转个不停，他又下地用木屐齿去踩，又没踩着，气得要命，又从地上捡起来塞进嘴里，咬破了马上吐掉。王羲之听说后大笑道：“就算是王安期有这种脾气，也没有一丝一毫可取之处，何况是王蓝田呢？”
注：王蓝田：王述，字怀祖，袭爵蓝田侯，官至尚书令，以性急闻名。
注：鸡子：鸡蛋。
注：箸（zhù）：筷子。
注：屐（jī）：木底鞋，底下有齿。
注：蹍（niǎn）：踩，碾。
注：瞋（chēn）：发怒。
注：内：同“纳”，放进。
注：啮（niè）：咬。
注：安期：王承，字安期，王述之父，东晋初名臣，声望很高。
注：豪：同“毫”。

# 三｜王司州尝乘雪往王螭许
原：王司州尝乘雪往王螭许。司州言气少有牾逆于螭，便作色不夷。司州觉恶，便舆床就之，持其臂曰：“汝讵复足与老兄计？”螭拨其手曰：“冷如鬼手馨，强来捉人臂！”|| 王胡之有一次冒着雪到王恬那里去。王胡之说话的口气稍有冒犯王恬之处，王恬就变了脸色，很不高兴。王胡之察觉情形不妙，就把坐榻挪过去靠近他，拉着他的胳膊说：“你难道还值得跟老哥我计较吗？”王恬拨开他的手说：“冰得像鬼手似的，还硬要来抓人家胳膊！”
注：王司州：王胡之，字修龄，曾任司州刺史。
注：王螭（chī）：王恬，小字螭虎，王导之子。
注：许：住处。
注：牾（wǔ）逆：抵触，冒犯。
注：作色：变脸。
注：不夷：不平和，不高兴。
注：舆床：抬动坐榻。
注：讵（jù）：岂，难道。
注：馨：晋宋时口语，“如……馨”即“像……那样”。

# 四｜桓宣武与袁彦道樗蒱
原：桓宣武与袁彦道樗蒱。袁彦道齿不合，遂厉色掷去五木。温太真云：“见袁生迁怒，知颜子为贵。”|| 桓温和袁耽一起玩樗蒱。袁耽掷出的点子不合心意，就沉下脸把五木摔了出去。温峤说：“看到袁先生拿东西撒气，才知道颜回的可贵。”
注：桓宣武：桓温，谥宣武。
注：袁彦道：袁耽，字彦道，陈郡阳夏人，豪迈好赌。
注：樗蒱（chū pú）：古代一种博戏，掷五枚木子定输赢。
注：齿：掷出的采。
注：五木：樗蒱所用的五枚木制骰子。
注：温太真：温峤，字太真，东晋名臣。
注：迁怒：把怒气发到别处。《论语》称颜回“不迁怒，不贰过”。

# 五｜谢无奕性粗强
原：谢无奕性粗强，以事不相得，自往数王蓝田，肆言极骂。王正色面壁不敢动，半日，谢去。良久，转头问左右小吏曰：“去未？”答云：“已去。”然后复坐。时人叹其性急而能有所容。|| 谢奕性情粗暴倔强，因为一件事和王述合不来，亲自上门数落王述，放开嗓子痛骂。王述板着脸面对墙壁，一动不动，过了半天，谢奕走了。又过了好久，王述转过头问身边的小吏：“走了没有？”小吏答：“已经走了。”他这才重新坐好。当时的人赞叹他虽然性急，却也能够容人。
注：谢无奕：谢奕，字无奕，谢安之兄，官至豫州刺史。
注：粗强（jiàng）：粗鲁倔强。
注：不相得：彼此不合。
注：数（shǔ）：当面列举过错来指责。
注：肆言：放肆地说。
注：面壁：脸朝墙壁。
注：容：容忍。

# 六｜王令诣谢公
原：王令诣谢公，值习凿齿已在坐，当与并榻。王徙倚不坐，公引之与对榻。去后，语胡儿曰：“子敬实自清立，但人为尔多矜咳，殊足损其自然。”|| 王献之去拜访谢安，正赶上习凿齿已经在座，按理他该和习凿齿同坐一榻。王献之徘徊着不肯坐下，谢安就领他到对面的榻上坐。王献之走后，谢安对谢朗说：“子敬确实清高自立，只是做人这样矜持固执，很是损害他的自然天性。”
注：王令：王献之，字子敬，王羲之之子，官至中书令。
注：习凿齿：字彦威，东晋史学家，著《汉晋春秋》，出身非高门。
注：并榻：同坐一榻。
注：徙倚：徘徊犹豫。
注：胡儿：谢朗的小名，谢安之侄。
注：矜咳：矜持做作。“咳”字在此的确切含义存疑。

# 七｜王大、王恭尝俱在何仆射坐
原：王大、王恭尝俱在何仆射坐，恭时为丹阳尹，大始拜荆州。讫将乖之际，大劝恭酒，恭不为饮，大逼强之，转苦，便各以裙带绕手。恭府近千人，悉呼入斋；大左右虽少，亦命前，意便欲相杀。何仆射无计，因起排坐二人之间，方得分散。所谓势利之交，古人羞之。|| 王忱和王恭曾一同在何澄家作客，王恭当时任丹阳尹，王忱刚被任命为荆州刺史。到快要分别的时候，王忱劝王恭喝酒，王恭不肯喝，王忱硬逼他喝，越劝越凶，两人便各自把裙带缠在手上，准备动手。王恭府里将近一千人，全被叫进屋来；王忱手下虽少，也叫他们上前，看那架势是要拼个你死我活。何澄无计可施，只好起身挤坐到两人中间，这才把他们分开。这就是所谓的势利之交，古人是以此为羞的。
注：王大：王忱，小字佛大，人称王大，王坦之之子。
注：王恭：字孝伯，孝武帝王皇后之兄。
注：何仆射：何澄，字季玄，官至尚书左仆射。
注：讫（qì）：到，及。
注：乖：分离。
注：苦：强劝不休。
注：裙带绕手：把下衣的带子缠在手上，作打斗准备。
注：排：挤开、插入。

# 八｜桓南郡小儿时
原：桓南郡小儿时，与诸从兄弟各养鹅共斗。南郡鹅每不如，甚以为忿。乃夜往鹅栏间，取诸兄弟鹅悉杀之。既晓，家人咸以惊骇，云是变怪，以白车骑。车骑曰：“无所致怪，当是南郡戏耳！”问，果如之。|| 桓玄小时候，和堂兄弟们各自养鹅来斗。桓玄的鹅总是斗不过，他非常恼恨。于是夜里跑到鹅栏里，把兄弟们的鹅全都杀了。天亮后，家里人都很惊恐，说是出了妖怪，去报告桓冲。桓冲说：“哪有什么东西作怪，一定是南郡在胡闹！”一问，果然如此。
注：桓南郡：桓玄，桓温之子，袭爵南郡公，后篡晋称帝，旋即败亡。
注：从（zòng）兄弟：堂兄弟。
注：变怪：怪异的变故。
注：白：禀告。
注：车骑：桓冲，桓温之弟、桓玄之叔，曾任车骑将军。
