# 本门导读
题解：“巧艺”指精巧的技艺。本门记魏晋时的弹棋、围棋、建筑、书法与绘画，尤以顾恺之论画诸则最见神采，“传神写照”一语即出于此。

# 一｜弹棋始自魏
原：弹棋始自魏，宫内用妆奁戏。文帝于此戏特妙，用手巾角拂之，无不中。有客自云能，帝使为之。客著葛巾角，低头拂棋，妙逾于帝。|| 弹棋这种游戏起于魏代，宫女们在梳妆匣上玩它。魏文帝对这种游戏特别拿手，用手巾角一拂，没有弹不中的。有位客人自称也会，文帝就让他来玩。客人用头上戴的葛巾角，低下头去拂棋子，技艺比文帝还高明。
注：弹棋：古代的一种博戏，两人对局，各以己方棋子弹击对方棋子。
注：妆奁（lián）：妇女梳妆用的匣子，盖面平整，可充棋盘。
注：文帝：魏文帝曹丕。
注：拂：轻轻擦过，这里指弹击棋子。
注：葛巾：用葛布做的头巾，客人以头巾角拂棋，更显奇巧。

# 二｜陵云台楼观精巧
原：陵云台楼观精巧，先称平众木轻重，然后造构，乃无锱铢相负揭。台虽高峻，常随风摇动，而终无倾倒之理。魏明帝登台，惧其势危，别以大材扶持之，楼即颓坏。论者谓轻重力偏故也。|| 陵云台的楼阁建得十分精巧，先把所有木料的轻重称量均衡，然后才动工搭建，竟然没有一丝一毫的偏差。台虽然高耸，常随着风摇晃，却始终没有倒塌的可能。魏明帝登上台去，怕它形势危险，另外用大木头把它撑住，楼台随即就坍塌了。评论的人说，这是因为轻重受力偏斜的缘故。
注：陵云台：魏文帝时在洛阳所筑的高台，今已不存。
注：楼观（guàn）：楼台。
注：锱铢（zī zhū）：古代极小的重量单位，喻极其微小。
注：负揭：一头沉下、一头翘起，指轻重不平衡。
注：魏明帝：曹叡（ruì），曹丕之子。
注：颓坏：倒塌。

# 三｜韦仲将能书
原：韦仲将能书。魏明帝起殿，欲安榜，使仲将登梯题之。既下，头鬓皓然。因敕儿孙勿复学书。|| 韦诞擅长书法。魏明帝建造宫殿，要挂匾额，叫韦诞登上梯子去题写。等他下来，头发鬓角都白了。于是他告诫儿孙不要再学书法。
注：韦仲将：韦诞，字仲将，京兆杜陵人，魏代著名书法家，宫殿匾额多出其手。
注：榜：匾额。
注：题之：在高处悬着的匾上题字，人在梯上，极其惊险。
注：皓然：雪白的样子，极言惊惧之甚。
注：敕（chì）：告诫。

# 四｜钟会是荀济北从舅
原：钟会是荀济北从舅，二人情好不协。荀有宝剑，可直百万，常在母钟夫人许。会善书，学荀手迹，作书与母取剑，仍窃去不还。荀勖知是钟而无由得也，思所以报之。后钟兄弟以千万起一宅，始成，甚精丽，未得移住。荀极善画，乃潜往画钟门堂，作太傅形象，衣冠状貌如平生。二钟入门，便大感恸，宅遂空废。|| 钟会是荀勖的堂舅，两人交情不好。荀勖有一把宝剑，价值上百万，平时放在母亲钟夫人那里。钟会擅长书法，模仿荀勖的笔迹，写信给钟夫人把剑要了来，就此偷走不还。荀勖知道是钟会干的，却没办法要回来，便琢磨着怎么报复他。后来钟家兄弟花了一千万钱造了一座宅院，刚刚落成，十分精美华丽，还没来得及搬进去住。荀勖极善绘画，就偷偷跑去在钟家门侧的厅堂上画了太傅钟繇的像，衣冠容貌和生前一模一样。钟会兄弟一进门，便悲痛万分，这座宅子于是空置荒废了。
注：钟会：字士季，颍川长社人，钟繇之子，魏末权臣，伐蜀后谋反被杀。
注：荀济北：荀勖，晋初封济北郡公，故称。
注：从舅：母亲的堂兄弟。
注：直：同“值”。
注：许：处所。
注：仍：于是，就。
注：门堂：门侧的堂屋。
注：太傅：钟繇，钟会之父，官至太傅，以书法名世。
注：二钟：钟会与其兄钟毓。
注：感恸（tòng）：触动而极度悲痛。

# 五｜羊长和博学工书
原：羊长和博学工书，能骑射，善围棋。诸羊后多知书，而射、弈余艺莫逮。|| 羊忱学识渊博，擅长书法，会骑马射箭，又精于围棋。羊家后人大多懂书法，但骑射、下棋这些技艺都赶不上他。
注：羊长和：羊忱，字长和，泰山南城人，西晋末官至扬州刺史。
注：工书：擅长书法。
注：知书：懂书法。
注：弈：下棋。
注：莫逮：没有人比得上。

# 六｜戴安道就范宣学
原：戴安道就范宣学，视范所为，范读书亦读书，范抄书亦抄书。唯独好画，范以为无用，不宜劳思于此。戴乃画《南都赋图》，范看毕咨嗟，甚以为有益，始重画。|| 戴逵跟着范宣求学，处处看范宣的样子做：范宣读书他也读书，范宣抄书他也抄书。唯独他喜欢画画，范宣认为没有用处，不该在这上面费心思。戴逵于是画了一幅《南都赋图》，范宣看完连声赞叹，认为很有益处，从此才重视绘画。
注：戴安道：戴逵，字安道，谯郡铚县人，东晋隐士，善鼓琴，工书画，尤长于人物、佛像。
注：范宣：字宣子，陈留人，东晋儒者，隐居讲学，以清俭著称。
注：就：跟从。
注：《南都赋》：东汉张衡所作，铺写南阳风物。戴逵据赋意作图。
注：咨嗟：赞叹。

# 七｜谢太傅云
原：谢太傅云：“顾长康画，有苍生来所无。”|| 谢安说：“顾恺之的画，是自有人类以来从来没有过的。”
注：谢太傅：谢安，字安石，陈郡阳夏人，东晋名相，死后追赠太傅。
注：顾长康：顾恺之，字长康，晋陵无锡人，东晋大画家，时人称其才绝、画绝、痴绝。
注：苍生：百姓、人类。

# 八｜戴安道中年画行像
原：戴安道中年画行像甚精妙。庾道季看之，语戴云：“神明太俗，由卿世情未尽。”戴云：“唯务光当免卿此语耳。”|| 戴逵中年时画的佛像非常精妙。庾龢看了，对戴逵说：“神态太俗气，这是因为你的尘俗之心还没去干净。”戴逵说：“恐怕只有务光才能免得了您这句评语吧。”
注：行像：佛像。佛教有用车载佛像巡行的仪式，称“行像”，这里指供巡行的佛像。
注：庾道季：庾龢，字道季，颍川鄢陵人，庾亮之子，有名于清谈。
注：神明：神情、精神面貌。
注：世情：世俗之念。
注：务光：传说中夏末的隐士，商汤欲让天下给他，他以为受辱，负石自沉。戴逵意谓世上除了务光这样的人，谁都难免有俗情，语带反讥。

# 九｜顾长康画裴叔则
原：顾长康画裴叔则，颊上益三毛。人问其故，顾曰：“裴楷俊朗有识具，正此是其识具。”看画者寻之，定觉益三毛如有神明，殊胜未安时。|| 顾恺之画裴楷像，在脸颊上添了三根毫毛。有人问他什么缘故，顾恺之说：“裴楷俊逸爽朗，有见识才具，这三根毛正是他的见识才具。”看画的人细细品味，果然觉得添上三根毛后像是有了精神，远胜过没添的时候。
注：裴叔则：裴楷，字叔则，河东闻喜人，西晋名士，风神高迈，人称“玉人”。
注：益：增加。
注：识具：见识与才干。
注：寻：玩味、揣摩。
注：定：果真。
注：神明：神采。
注：殊：很，远远。
注：安：安放，指添上。

# 十｜王中郎以围棋是坐隐
原：王中郎以围棋是坐隐，支公以围棋为手谈。|| 王坦之把围棋叫作“坐着隐居”，支道林把围棋叫作“用手清谈”。
注：王中郎：王坦之，字文度，太原晋阳人，东晋大臣，官至北中郎将、中书令。
注：支公：支遁，字道林，东晋名僧，善清谈，与名士交游。
注：坐隐：对弈时心无旁骛，如同坐而隐遁；
注：手谈：落子往还，如同以手对答清谈。二语后来都成了围棋的别称。

# 十一｜顾长康好写起人形
原：顾长康好写起人形，欲图殷荆州，殷曰：“我形恶，不烦耳。”顾曰：“明府正为眼尔。但明点童子，飞白拂其上，使如轻云之蔽日。”|| 顾恺之喜欢给人画像，想画殷仲堪，殷仲堪说：“我相貌丑，就不劳烦你了。”顾恺之说：“您不过是因为眼睛罢了。只要把瞳仁点得清清楚楚，再用飞白笔法在上面轻轻一扫，让它像淡淡的云彩遮住太阳一样就好了。”
注：写起：描摹、绘写。“起”字之义，诸说不一，存疑。
注：殷荆州：殷仲堪，陈郡长平人，东晋末任荆州刺史，一目失明。
注：明府：对太守、刺史等长官的敬称。
注：童子：同“瞳子”，眼珠。
注：飞白：一种笔法，笔画中露出丝丝白痕，显得轻虚飘逸。
注：拂：轻扫。

# 十二｜顾长康画谢幼舆在岩石里
原：顾长康画谢幼舆在岩石里。人问其所以，顾曰：“谢云：‘一丘一壑，自谓过之。’此子宜置丘壑中。”|| 顾恺之给谢鲲画像，把他画在山岩之间。有人问他为什么这样画，顾恺之说：“谢鲲自己说过：‘若论寄情于一丘一壑，我自认为胜过庾亮。’这位先生正该安置在山水丘壑之中。”
注：谢幼舆：谢鲲，字幼舆，陈国阳夏人，西晋末名士，任达不拘。
注：一丘一壑，自谓过之：晋明帝曾问谢鲲与庾亮相比如何，谢鲲说朝堂上端正持重、为百官表率，自己不如庾亮；至于放情山水，自认为胜过他。事见《品藻》篇。

# 十三｜顾长康画人
原：顾长康画人，或数年不点目精。人问其故，顾曰：“四体妍蚩，本无关于妙处；传神写照，正在阿堵中。”|| 顾恺之画人像，有时画好了几年都不点眼珠。有人问他缘故，顾恺之说：“身体四肢画得美丑，本来与画的精妙之处无关；要传达人的精神、画出人的真容，关键正在这个东西里头。”
注：目精：眼珠。精，同“睛”。
注：妍蚩（chī）：美与丑。蚩，同“媸”，丑陋。
注：传神写照：传达神韵，描绘形貌。
注：阿堵：六朝口语，“这个”，此处指眼睛。

# 十四｜顾长康道
原：顾长康道：“画‘手挥五弦’易，‘目送归鸿’难。”|| 顾恺之说：“画‘手挥五弦’容易，画‘目送归鸿’就难了。”
注：手挥五弦、目送归鸿：出自嵇康《赠秀才入军》诗。手拨琴弦是外在动作，易于描画；目光追随远去的飞鸿，要画出那份悠远的神思，则极难。
