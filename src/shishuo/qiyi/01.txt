# 本门导读
题解：“栖逸”即隐居山林、超然世外。本门记魏晋隐士与好隐之人，有苏门长啸的真人，也有辞官不就、守志不移的高士，还旁及资助隐者、半仕半隐的种种情态，可见当时崇尚隐逸的风气。

# 一｜阮步兵啸闻数百步
原：阮步兵啸闻数百步。苏门山中，忽有真人，樵伐者咸共传说。阮籍往观，见其人拥膝岩侧，籍登岭就之，箕踞相对。|| 阮籍的啸声能传出几百步远。苏门山里，忽然来了一位得道的真人，砍柴的人都在相互传说。阮籍前去察看，见那人抱着膝盖坐在山岩旁，阮籍便登上山岭走到他跟前，两人都叉开两腿面对面坐着。
注：阮步兵：阮籍，字嗣宗，陈留尉氏人，“竹林七贤”之一，曾任步兵校尉，世称阮步兵。啸：撮口发出长而清越的声音，魏晋名士好为之。
注：苏门山：山名，在今河南辉县一带。
注：真人：道家称修道有成、返璞归真的人。
注：箕踞（jī jù）：两腿张开平伸而坐，形如簸箕，是不拘礼法的坐姿。
原：籍商略终古，上陈黄、农玄寂之道，下考三代盛德之美，以问之，仡然不应；复叙有为之教，栖神导气之术，以观之，彼犹如前，凝瞩不转。|| 阮籍纵论远古以来的事，往上讲黄帝、神农那种玄远寂静的大道，往下考论夏商周三代盛德的美政，拿这些来请教他，他却昂着头一声不吭；阮籍又讲起儒家积极有为的教化，以及道家安神导气的修炼法门，看他怎样反应，他还是像先前一样，目光凝定，眼珠都不转一下。
注：商略：商讨、评议。终古：自古以来，久远之事。
注：黄、农：黄帝与神农氏。玄寂：玄妙幽寂。
注：仡（yì）然：昂首不动的样子。
注：栖神导气：安定精神、导引呼吸，道家养生修炼之术。凝瞩：目光专注不移。
原：籍因对之长啸。良久，乃笑曰：“可更作。”籍复啸。意尽退。还半岭许，闻上㗅然有声，如数部鼓吹，林谷传响。顾看，乃向人啸也。|| 阮籍于是对着他长啸一声。过了好久，那人才笑着说：“可以再来一次。”阮籍又啸了一回，兴致尽了便告退。下到半山腰左右，听见山上传来悠长清亮的声音，好像几支乐队在合奏，响彻山林幽谷。回头一看，原来正是刚才那人在长啸。
注：许：表示约数，左右。㗅（qiú）然：形容啸声清越悠长。
注：鼓吹：以鼓、钲、箫、笳等合奏的乐队，原为军乐。
注：向人：刚才那个人。

# 二｜嵇康游于汲郡山中
原：嵇康游于汲郡山中，遇道士孙登，遂与之游。康临去，登曰：“君才则高矣，保身之道不足。”|| 嵇康在汲郡的山里游历，遇见道士孙登，就跟着他一起游处。嵇康临走时，孙登说：“您的才华确实很高，可保全自身的本事却不够啊。”
注：嵇康：字叔夜，谯国铚县人，“竹林七贤”之一，后为司马昭所杀，正应了孙登的话。
注：汲郡：郡名，治所在今河南卫辉一带。
注：孙登：字公和，魏晋之际的隐士，居汲郡山中，无家室，好读《易》、善弹琴长啸。

# 三｜山公将去选曹
原：山公将去选曹，欲举嵇康，康与书告绝。|| 山涛将要离开吏部选官的职位，想推荐嵇康接替自己，嵇康写信给他宣布绝交。
注：山公：山涛，字巨源，河内怀县人，“竹林七贤”之一，曾任吏部郎、吏部尚书，主持选官。
注：选曹：主管选拔官吏的部门，即吏部。
注：与书告绝：即后世所传嵇康《与山巨源绝交书》，信中自陈不堪为官，借以明志。

# 四｜李廞是茂曾第五子
原：李廞是茂曾第五子，清贞有远操，而少羸病，不肯婚宦。居在临海，住兄侍中墓下。既有高名，王丞相欲招礼之，故辟为府掾。廞得笺命，笑曰：“茂弘乃复以一爵假人。”|| 李廞是李重的第五个儿子，品性清白贞正，有高远的志节，但从小瘦弱多病，不肯娶妻，也不肯做官。他住在临海，守着哥哥李侍中的墓地居住。他已经很有名望了，丞相王导想礼聘他，特地征召他做丞相府的属官。李廞接到任命文书，笑着说：“王茂弘竟然又拿一个官爵来送人了。”
注：李廞（xīn）：字宗子，江夏人，西晋名臣李重之子，善草书，以病辞官不就。茂曾：李重的字。
注：羸（léi）病：瘦弱多病。婚宦：娶妻和做官。
注：兄侍中：李廞之兄李式，曾任侍中，葬于临海。临海：郡名，治所在今浙江临海。
注：王丞相：王导，字茂弘，东晋开国重臣。辟：征召。府掾（yuàn）：官府中的属吏。笺命：任命的文书。假人：给予别人，带调侃意味。

# 五｜何骠骑弟以高情避世
原：何骠骑弟以高情避世，而骠骑劝之令仕，答曰：“予第五之名，何必减骠骑！”|| 何充的弟弟凭着高洁的情怀避世隐居，何充却劝他出来做官，他回答说：“我这个何老五的名声，未必就比你骠骑将军差！”
注：何骠骑：何充，字次道，庐江灊县人，东晋重臣，曾任骠骑将军。弟：何准，字幼道，排行第五，隐居不仕。
注：高情：高远的情操。
注：何必：未必。减：逊于，不如。

# 六｜阮光禄在东山
原：阮光禄在东山，萧然无事，常内足于怀。有人以问王右军，右军曰：“此君近不惊宠辱，虽古之沉冥，何以过此？”|| 阮裕住在东山，清静闲散，无所事事，心里却常常感到很满足。有人拿他的情形去问王羲之，王羲之说：“这位先生近来已经到了宠辱不惊的地步，即使古代那些深隐不露的高士，又怎能超过他呢？”
注：阮光禄：阮裕，字思旷，陈留尉氏人，东晋名士，曾被授金紫光禄大夫，多次辞官隐居。东山：在今浙江上虞一带。
注：萧然：清闲寂静的样子。
注：王右军：王羲之，字逸少，曾任右军将军，书法家。
注：不惊宠辱：语本《老子》“宠辱若惊”，此反用之，指得失荣辱都不动心。沉冥：深藏隐晦的人，指隐士。

# 七｜孔车骑少有嘉遁意
原：孔车骑少有嘉遁意，年四十余，始应安东命。未仕宦时，常独寝，歌吹自箴诲。自称孔郎，游散名山。百姓谓有道术，为生立庙。今犹有孔郎庙。|| 孔愉年轻时就有隐居避世的心愿，四十多岁才接受安东将军的征召。还没做官的时候，他常常一个人独居，靠吟咏弹唱来自我规诫勉励。他自称孔郎，在名山间悠游散步。老百姓认为他身怀道术，在他活着时就给他建了庙。到现在还有孔郎庙。
注：孔车骑：孔愉，字敬康，会稽山阴人，东晋官员，死后追赠车骑将军。
注：嘉遁（dùn）：合乎正道的隐退，语出《周易·遁卦》。
注：安东：安东将军，指司马睿（即位前任此职），后为东晋元帝。
注：歌吹：唱歌与吹奏，泛指吟咏弹唱。箴（zhēn）诲：规劝教诲。

# 八｜南阳刘驎之
原：南阳刘驎之，高率，善史传，隐于阳岐。于时苻坚临江，荆州刺史桓冲将尽讦谟之益，征为长史，遣人船往迎，赠贶甚厚。|| 南阳人刘驎之，品性高洁率真，精通史书，隐居在阳岐。当时苻坚的大军逼近长江，荆州刺史桓冲想广纳良谋来应对，征召刘驎之做长史，派人驾船去迎接，赠送的礼物十分丰厚。
注：刘驎之：字子骥，南阳人，东晋隐士，好游山水；陶渊明《桃花源记》末所提“南阳刘子骥”即此人。
注：阳岐：地名，在长江边，离荆州治所不远。
注：苻坚：前秦君主，曾大举南侵东晋。桓冲：字幼子，桓温之弟，时任荆州刺史。
注：讦谟（xū mó）：宏大的谋划，“讦”通“訏”。赠贶（kuàng）：赠送的财物。
原：驎之闻命，便升舟，悉不受所饷，缘道以乞穷乏，比至上明亦尽。一见冲，因陈无用，翛然而退。|| 刘驎之接到任命，立刻上了船，送来的礼物一件也不收下，沿途都拿去施舍给穷苦的人，等到了上明，东西也就分完了。他一见到桓冲，就陈说自己是个没用的人，然后飘然而去。
注：饷（xiǎng）：赠送。乞：给予。
注：比：等到。上明：地名，桓冲镇守荆州时所筑城，在长江南岸。
注：翛（xiāo）然：无拘无束、超脱自在的样子。
原：居阳岐积年，衣食有无，常与村人共。值己匮乏，村人亦如之。甚厚，为乡闾所安。|| 他在阳岐住了多年，吃的穿的不论多少，常常和村里人共享。碰上他自己短缺的时候，村里人也同样接济他。他待人十分厚道，乡里人都乐于和他相处。
注：积年：多年。
注：匮（kuì）乏：缺乏。乡闾（lǘ）：乡里。安：安心亲近，乐于相处。

# 九｜南阳翟道渊与汝南周子南
原：南阳翟道渊与汝南周子南少相友，共隐于寻阳。庾太尉说周以当世之务，周遂仕，翟秉志弥固。其后周诣翟，翟不与语。|| 南阳人翟汤和汝南人周邵年轻时就是好友，一起隐居在寻阳。庾亮拿当世的政务去游说周邵，周邵就出来做官了，翟汤却更加坚守自己的志向。后来周邵去拜访翟汤，翟汤不跟他说话。
注：翟道渊：翟汤，字道渊，南阳人，东晋隐士，屡次征召都不应。
注：周子南：周邵，字子南，汝南人，后应庾亮之召出仕。
注：寻阳：郡名，治所在今江西九江一带。庾太尉：庾亮，字元规，东晋外戚重臣，死后追赠太尉。说（shuì）：劝说。
注：秉志：坚守志向。弥：更加。

# 十｜孟万年及弟少孤
原：孟万年及弟少孤，居武昌阳新县。万年游宦，有盛名当世。少孤未尝出，京邑人士思欲见之，乃遣信报少孤云：“兄病笃。”狼狈至都。时贤见之者，莫不嗟重。因相谓曰：“少孤如此，万年可死。”|| 孟嘉和弟弟孟陋住在武昌阳新县。孟嘉出外做官，在当时享有盛名。孟陋从来没有出过门，京城的名流想见见他，就派人送信给孟陋说：“你哥哥病得很重。”孟陋急急忙忙赶到京城。当时的贤达见到他，没有不赞叹敬重的，于是互相说道：“有少孤这样的弟弟，万年就是死了也可以放心了。”
注：孟万年：孟嘉，字万年，江夏人，东晋名士，曾为桓温参军，陶渊明的外祖父。少孤：孟陋，字少孤，孟嘉之弟，隐居不仕，博学多通。
注：游宦：离家在外做官。信：送信的使者。
注：狼狈：匆忙窘迫的样子。嗟重：赞叹敬重。
注：万年可死：意谓孟家有少孤这样的人物，万年即使死了也无遗憾；一说是戏言万年的名声将被弟弟盖过。

# 十一｜康僧渊在豫章
原：康僧渊在豫章，去郭数十里立精舍。旁连岭，带长川，芳林列于轩庭，清流激于堂宇。乃闲居研讲，希心理味。庾公诸人多往看之，观其运用吐纳，风流转佳。加已处之怡然，亦有以自得，声名乃兴。后不堪，遂出。|| 康僧渊在豫章时，在离城几十里的地方建了一座精舍。精舍旁边连着山岭，环绕着长河，芬芳的树林排列在长廊庭院前，清澈的溪流在厅堂屋宇四周激荡。他就在这里闲居研习讲论，潜心体会义理的意味。庾亮等人常常去看他，看他运气吐纳的样子，风度更加美好。加上他自己身处其中安然愉悦，也颇有自得之意，于是名声大起。后来他受不了来访的纷扰，就离开了那里。
注：康僧渊：东晋僧人，本西域人，生于长安，成帝时过江，善谈佛理。豫章：郡名，治所在今江西南昌。
注：郭：外城。精舍：僧人修行讲经的住所。轩庭：长廊和庭院。
注：希心：倾心，专注。理味：义理的意趣。庾公：庾亮。
注：吐纳：吐故纳新，一种调息养生之法。风流：风度神采。后不堪：指后来不堪访客之扰，具体所指存疑。

# 十二｜戴安道既厉操东山
原：戴安道既厉操东山，而其兄欲建式遏之功。谢太傅曰：“卿兄弟志业，何其太殊？”戴曰：“下官不堪其忧，家弟不改其乐。”|| 戴逵在东山砥砺节操，他的哥哥却想为国家建立保境安民的功业。谢安对戴逯说：“你们兄弟的志向事业，怎么差别这样大？”戴逯说：“我是受不了那份清苦，舍弟却始终不改他的乐趣。”
注：戴安道：戴逵，字安道，谯国人，东晋隐士，善鼓琴、工书画，隐居剡县，屡征不就。厉操：磨砺节操。
注：其兄：戴逯，字安丘，以武功显，官至大司农。式遏（è）：遏止敌寇、安定国家，语出《诗经·大雅·民劳》。
注：谢太傅：谢安，字安石，东晋名相，死后追赠太傅。
注：不堪其忧、不改其乐：化用《论语·雍也》孔子称赞颜回“人不堪其忧，回也不改其乐”，戴逯借此自谦，又称赞弟弟安贫乐道，答得巧妙。

# 十三｜许玄度隐在永兴南幽穴中
原：许玄度隐在永兴南幽穴中，每致四方诸侯之遗。或谓许曰：“尝闻箕山人，似不尔耳。”许曰：“筐篚苞苴，故当轻于天下之宝耳。”|| 许询隐居在永兴南边幽深的山洞里，常常招来各地长官送的礼物。有人对许询说：“曾听说箕山上的隐士，好像不是这样的啊。”许询说：“这些筐子里、草包里装来的礼物，总比天下这件宝贝轻多了吧。”
注：许玄度：许询，字玄度，高阳人，东晋名士，好隐居游山，善玄言诗，与谢安、支遁等交好。永兴：县名，在今浙江萧山一带。
注：致：招来。诸侯：指各地州郡长官。遗（wèi）：馈赠之物。
注：箕山人：指尧时隐士许由，相传尧要让天下给他，他逃到箕山隐居。不尔：不是这样。
注：筐篚（fěi）：竹编的方筐和圆筐。苞苴（jū）：用草包裹的礼物。天下之宝：指天子之位。许询以许由辞天下自比，意谓收些小礼无伤高洁，答得狡黠。

# 十四｜范宣未尝入公门
原：范宣未尝入公门，韩康伯与同载，遂诱俱入郡，范便于车后趋下。|| 范宣从来不进官府的大门。有一次韩伯和他同坐一辆车，想趁机哄他一起进郡府，范宣发觉了，就从车后头赶紧跳下车溜走了。
注：范宣：字宣子，陈留人，东晋儒者，终身不仕，以讲学为业。公门：官府。
注：韩康伯：韩伯，字康伯，颍川人，东晋玄学家，时任豫章太守一类官职，具体存疑。
注：郡：郡府，官署。趋：小步快走。

# 十五｜郗超每闻欲高尚隐退者
原：郗超每闻欲高尚隐退者，辄为办百万资，并为造立居宇。在剡，为戴公起宅，甚精整。戴始往旧居，与所亲书曰：“近至剡，如官舍。”郗为傅约亦办百万资，傅隐事差互，故不果遗。|| 郗超每次听说有人想要高蹈隐退，总要为他筹备百万钱财，还给他建造住宅。在剡县，他为戴逵造了一座宅院，十分精致整齐。戴逵刚搬进去住，给亲友写信说：“最近到了剡县，住得像官府的房舍一样。”郗超也为傅约筹备了百万钱财，但傅约隐居的事出了岔子，所以这笔钱最终没有送出去。
注：郗超：字景兴，一字嘉宾，高平金乡人，郗鉴之孙，桓温的谋士，崇信佛教，好资助隐士。
注：剡（shàn）：县名，在今浙江嵊州一带。戴公：戴逵。
注：始往旧居：“旧”字费解，或以为衍文，存疑。如官舍：说新居之好如同官署，语带调侃。
注：傅约：其人生平不详，存疑。差互：差错，没有办成。不果遗（wèi）：最终没有送出。

# 十六｜许掾好游山水
原：许掾好游山水，而体便登陟。时人云：“许非徒有胜情，实有济胜之具。”|| 许询喜欢游览山水，身体又轻捷，便于攀登。当时人说：“许询不仅有游赏佳境的雅兴，还确实有一副能够登临胜景的好身板。”
注：许掾（yuàn）：许询，曾被征为司徒掾，未就，故称。
注：便：轻捷灵便。登陟（zhì）：攀登。
注：胜情：游赏佳山水的高雅情趣。济胜之具：能够到达胜境的凭借，指强健的身体，说法风趣。

# 十七｜郗尚书与谢居士善
原：郗尚书与谢居士善，常称：“谢庆绪识见虽不绝人，可以累心处都尽。”|| 郗恢和谢敷交好，常常称赞他说：“谢庆绪的见识虽然不算超群绝伦，但凡是能牵累心神的东西，在他那里都已经干干净净了。”
注：郗尚书：郗恢，字道胤，郗昙之子，东晋官员，曾任雍州刺史，后被征为尚书，途中遇害。
注：谢居士：谢敷，字庆绪，会稽人，信奉佛教，隐居不仕。居士：在家修行的佛教信徒，也指不仕的隐士。
注：绝人：超过常人。累心：牵累心神，指世俗的欲念牵挂。
