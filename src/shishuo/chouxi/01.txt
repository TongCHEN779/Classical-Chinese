# 本门导读
题解：“仇隙”指仇怨与嫌隙。本门八则，从孙秀报复石崇、潘岳，到王羲之与王述结怨愤死、司马无忌为父复仇，写尽魏晋士族之间睚眦必报的恩怨，也是全书的收束。

# 一｜孙秀既恨石崇不与绿珠
原：孙秀既恨石崇不与绿珠，又憾潘岳昔遇之不以礼。后秀为中书令，岳省内见之，因唤曰：“孙令，忆畴昔周旋不？”秀曰：“中心藏之，何日忘之？”岳于是始知必不免。|| 孙秀既恨石崇不肯把绿珠给他，又怨潘岳从前待他无礼。后来孙秀当了中书令，潘岳在官署中见到他，便招呼说：“孙令公，还记得我们从前的交往吗？”孙秀说：“藏在心中，哪一天忘得了？”潘岳这才明白自己必定难逃一劫。
注：孙秀：西晋琅邪人，赵王司马伦的亲信，后专擅朝政，伦败被杀。
注：石崇：字季伦，西晋巨富。
注：绿珠：石崇的爱妾，善吹笛。
注：潘岳：字安仁，西晋文学家。据说孙秀早年在潘父手下当小吏，屡遭潘岳欺辱。
注：省内：官署之中。
注：畴昔：从前。
注：周旋：交往。
注：不：同“否”。
注：中心藏之，何日忘之：《诗经·小雅·隰桑》中的句子，原为思念之辞，孙秀借来表示记恨不忘。
原：后收石崇、欧阳坚石，同日收岳。石先送市，亦不相知。潘后至，石谓潘曰：“安仁，卿亦复尔邪？”潘曰：“可谓‘白首同所归’。”潘《金谷集诗》云：“投分寄石友，白首同所归。”乃成其谶。|| 后来孙秀逮捕石崇、欧阳坚石，同一天也抓了潘岳。石崇先被押到刑场，彼此还不知道对方的情况。潘岳随后被押到，石崇对他说：“安仁，你也落到这一步了吗？”潘岳说：“这真可以说是‘白首同所归’了。”潘岳在《金谷集诗》里写过：“投分寄石友，白首同所归。”竟成了他们的谶语。
注：收：逮捕。
注：欧阳坚石：欧阳建，字坚石，石崇的外甥，有才名，同时遇害。
注：市：刑场，古时在闹市行刑。
注：投分寄石友：以情谊托付给坚如磐石的朋友；“石友”暗合石崇之姓。
注：白首同所归：原意白头偕老、同归一处，此时应验为同赴刑场。
注：谶（chèn）：预示后事的话。

# 二｜刘玙兄弟少时为王恺所憎
原：刘玙兄弟少时为王恺所憎，尝召二人宿，欲默除之。令作阬，阬毕，垂加害矣。石崇素与玙、琨善，闻就恺宿，知当有变，便夜往诣恺，问二刘所在。恺卒迫不得讳，答云：“在后斋中眠。”石便径入，自牵出，同车而去，语曰：“少年何以轻就人宿？”|| 刘玙兄弟年轻时被王恺憎恨，王恺曾经召二人来家住宿，想暗中除掉他们。他叫人挖坑，坑挖好了，眼看就要下手。石崇一向与刘玙、刘琨交好，听说他们去王恺家过夜，知道要出事，就连夜去拜访王恺，问二刘在哪里。王恺仓促之间无法隐瞒，只好回答：“在后面书房里睡觉。”石崇便径直进去，亲手把二人拉出来，同车离开，对他们说：“年轻人怎么能随随便便到别人家去过夜？”
注：刘玙（yú）：字庆孙，刘琨之兄，西晋人。
注：刘琨：字越石，后为西晋名将。
注：王恺：字君夫，晋武帝的舅父，以豪奢与石崇斗富著称。
注：默除：暗中除掉。
注：阬（kēng）：同“坑”。
注：垂：将要。
注：卒（cù）迫：仓促急迫。
注：讳：隐瞒。
注：后斋：后院的书房。

# 三｜王大将军执司马愍王
原：王大将军执司马愍王，夜遣世将载王于车而杀之，当时不尽知也，虽愍王家亦未之皆悉，而无忌兄弟皆稚。王胡之与无忌长甚相昵，胡之尝共游。|| 王大将军捉住了司马愍王，夜里派王世将用车载走愍王并把他杀了，当时外人并不全都知道，即便愍王的家人也不完全清楚，而司马无忌兄弟都还年幼。王胡之和无忌长大后十分亲近，有一回两人一起出游。
注：王大将军：王敦，东晋权臣，起兵作乱。
注：司马愍王：司马丞，字元敬，封谯王，起兵讨王敦，兵败被杀，谥愍。
注：世将：王廙（yì），字世将，王敦的堂弟，当时任荆州刺史。
注：无忌：司马无忌，字公寿，司马丞之子。
注：王胡之：字修龄，王廙之子。
注：昵：亲近。
原：无忌入告母，请为馔，母流涕曰：“王敦昔肆酷汝父，假手世将。吾所以积年不告汝者，王氏门强，汝兄弟尚幼，不欲使此声著，盖以避祸耳。”无忌惊号，抽刃而出，胡之去已远。|| 无忌进屋告诉母亲，请她准备饭食招待，母亲流着泪说：“当年王敦残害你父亲，就是借了王世将的手。我之所以多年不告诉你，是因为王家势大，你们兄弟还小，不想让这事张扬出去，只是为了避祸罢了。”无忌大惊痛哭，拔刀冲出门去，王胡之早已走远了。
注：馔（zhuàn）：饭食。
注：肆酷：肆意残害。
注：假手：借他人之手。
注：声著：消息传扬开。
注：号（háo）：大哭。

# 四｜应镇南作荆州
原：应镇南作荆州，王修载、谯王子无忌同至新亭与别。坐上宾甚多，不悟二人俱到。有一客道：“谯王丞致祸，非大将军意，正是平南所为耳。”无忌因夺直兵参军刀，便欲斫。修载走投水，舸上人接取，得免。|| 应镇南出任荆州刺史时，王修载和谯王的儿子司马无忌一同到新亭为他送别。座上宾客很多，没想到这两人都来了。有个客人说：“谯王司马丞遭难，并不是大将军的意思，只是平南将军干的罢了。”无忌听了就夺过值班参军的刀，要去砍王修载。王修载逃跑跳进水里，被船上的人救起，才得以幸免。
注：应镇南：应詹，字思远，死后追赠镇南将军。
注：作荆州：据史传当为任江州刺史，存疑。
注：王修载：王耆之，字修载，王廙之子。
注：新亭：建康城南的送别之地。
注：平南：王廙，曾任平南将军，即害死谯王者，故无忌要杀其子。
注：直兵参军：值班的参军。直，同“值”。
注：斫（zhuó）：砍。
注：舸（gě）：大船。

# 五｜王右军素轻蓝田
原：王右军素轻蓝田。蓝田晚节论誉转重，右军尤不平。蓝田于会稽丁艰，停山阴治丧。右军代为郡，屡言出吊，连日不果。后诣门自通，主人既哭，不前而去，以陵辱之。于是彼此嫌隙大构。|| 王右军一向看不起王蓝田。王蓝田晚年声望越来越高，王右军尤其愤愤不平。王蓝田在会稽内史任上遭逢母丧，留在山阴办理丧事。王右军接替他做会稽内史，屡次说要去吊唁，接连几天都没去成。后来登门自报姓名，等主人哭起来了，他却不上前吊慰就走了，以此羞辱对方。从此两人结下了很深的仇怨。
注：王右军：王羲之，官至右军将军，东晋大书法家。
注：蓝田：王述，字怀祖，袭封蓝田侯。
注：晚节：晚年。
注：丁艰：遭父母之丧，此指母丧。
注：山阴：会稽郡治，今浙江绍兴。
注：自通：自己通报姓名。按吊丧之礼，主人哭后吊客应上前致哀，王羲之不前而去，是有意侮辱。
注：大构：深深结成。
原：后蓝田临扬州，右军尚在郡。初得消息，遣一参军诣朝廷，求分会稽为越州。使人受意失旨，大为时贤所笑。蓝田密令从事数其郡诸不法，以先有隙，令自为其宜。右军遂称疾去郡，以愤慨致终。|| 后来王蓝田出任扬州刺史，成了上司，王右军还在会稽郡任上。他一得到消息，就派一名参军到朝廷，请求把会稽从扬州划出来另设越州。派去的人领会错了意图，把事情办砸了，被当时的名士大大取笑。王蓝田暗中命从事一条条列举会稽郡的种种不法之事，因为两人先前有嫌隙，就让王右军自己看着办。王右军于是称病辞去郡职，最终在愤懑中去世。
注：临扬州：任扬州刺史。会稽郡隶属扬州，王述因此成为王羲之的上级。
注：受意失旨：领受了使命却未能达成本意。
注：从事：州刺史的属官。
注：数（shǔ）：列举罪状。
注：自为其宜：让他自己去妥善处置，实为逼迫。

# 六｜王东亭与孝伯语
原：王东亭与孝伯语，后渐异，孝伯谓东亭曰：“卿便不可复测。”答曰：“王陵廷争，陈平从默，但问克终云何耳。”|| 王东亭和王孝伯交谈，后来两人意见渐渐不合，王孝伯对王东亭说：“你简直让人捉摸不透了。”王东亭回答：“王陵在朝廷上力争，陈平却沉默顺从，只要问最后的结果如何就是了。”
注：王东亭：王珣，封东亭侯。
注：孝伯：王恭，字孝伯，晋孝武帝皇后之兄。
注：渐异：意见逐渐分歧。据史载二人都与司马道子不和，后来立场有别。
注：王陵廷争，陈平从默：吕后欲封诸吕为王，王陵当廷反对，陈平则顺从不言；王陵责之，陈平答以当面力争自己不如他，安定刘氏天下则他不如自己。王珣借此说明自己外示顺从，自有归宿。
注：克终：最终结局。
注：云何：如何。

# 七｜王孝伯死
原：王孝伯死，县其首于大桁。司马太傅命驾出，至标所，孰视首，曰：“卿何故趣欲杀我邪？”|| 王孝伯死后，首级被悬挂在朱雀桥上示众。司马太傅叫人驾车出去，到了悬首的木杆下，仔细端详那颗头颅，说：“你为什么急着要杀我呢？”
注：王孝伯：王恭，起兵讨伐司马道子，兵败被杀。
注：县：同“悬”。
注：大桁（háng）：浮桥，指建康秦淮河上的朱雀桥。
注：司马太傅：会稽王司马道子，当时执掌朝政。
注：标所：悬挂首级的高杆处。
注：孰视：同“熟视”，仔细看。
注：趣（cù）：急促。

# 八｜桓玄将篡
原：桓玄将篡，桓脩欲因玄在脩母许袭之。庾夫人云：“汝等近过我余年，我养之，不忍见行此事。”|| 桓玄将要篡位时，桓脩想趁桓玄到自己母亲那里时袭杀他。庾夫人说：“你们就等我过完这几年余生吧，桓玄是我养大的，我不忍心看你们做这种事。”
注：桓玄：桓温之子，公元403年篡晋称帝，国号楚，次年被刘裕击败身死。
注：桓脩：桓冲之子，桓玄的堂兄弟。
注：许：处所。
注：庾夫人：桓冲之妻，桓脩之母；桓玄幼年曾由她抚养。
注：近过我余年：暂且等我度过晚年。近，暂且、稍待。
