# 本门导读
题解：“伤逝”是哀悼亡者。魏晋名士推崇“情之所钟，正在我辈”，本门十九则写他们哭友悼亲，或学驴鸣，或抚琴恸绝，往往不拘礼法而真情毕露。

# 一｜王仲宣好驴鸣
原：王仲宣好驴鸣。既葬，文帝临其丧，顾语同游曰：“王好驴鸣，可各作一声以送之。”赴客皆一作驴鸣。|| 王粲生前喜欢听驴叫。下葬的时候，魏文帝曹丕亲临吊丧，回头对一同前来的朋友们说：“王仲宣爱听驴叫，大家可以每人学一声驴叫来送他。”来送葬的宾客于是都学了一声驴叫。
注：王仲宣：王粲，字仲宣，山阳高平人，建安七子之一，以诗赋著称，随曹操南征途中病卒。
注：文帝：魏文帝曹丕，当时尚为魏太子。临（lìn）：哭吊死者。
注：赴客：前来吊丧送葬的客人。

# 二｜王濬冲为尚书令
原：王濬冲为尚书令，著公服，乘轺车，经黄公酒垆下过。顾谓后车客：“吾昔与嵇叔夜、阮嗣宗共酣饮于此垆。竹林之游，亦预其末。自嵇生夭、阮公亡以来，便为时所羁绁。今日视此虽近，邈若山河。”|| 王戎任尚书令时，穿着官服，坐着轻车，从黄公酒店门前经过。他回头对后面车上的客人说：“我从前和嵇叔夜、阮嗣宗一起在这家酒店里痛饮。竹林之游，我也忝列末座。自从嵇康早死、阮籍去世以后，我就被世事牵绊住了。今天看这酒店虽然近在眼前，却觉得远隔山河一般。”
注：王濬冲：王戎，字濬冲，竹林七贤中年纪最小者，后官至司徒。
注：轺（yáo）车：一马驾的轻便小车。酒垆：酒店里安放酒瓮的土台，代指酒店。
注：嵇叔夜：嵇康。阮嗣宗：阮籍。二人都是竹林七贤的领袖人物。预其末：参与其中而居末位，自谦之辞。
注：羁绁（jī xiè）：马笼头和缰绳，比喻束缚。邈：遥远。

# 三｜孙子荆以有才
原：孙子荆以有才，少所推服，唯雅敬王武子。武子丧时，名士无不至者。子荆后来，临尸恸哭，宾客莫不垂涕。哭毕，向灵床曰：“卿常好我作驴鸣，今我为卿作。”体似真声，宾客皆笑。孙举头曰：“使君辈存，令此人死！”|| 孙楚仗着自己有才华，很少推崇佩服别人，只是非常敬重王济。王济办丧事时，名士没有不来吊唁的。孙楚后到，对着遗体放声痛哭，宾客们没有不跟着落泪的。哭完了，他朝着灵床说：“你平时爱听我学驴叫，今天我为你叫一回。”学得活像真驴的声音，宾客们都笑了。孙楚抬起头说：“偏让你们这些人活着，却叫这个人死了！”
注：孙子荆：孙楚，字子荆，太原中都人，西晋文士，才气高而性情傲。
注：雅：甚，很。王武子：王济，字武子，王浑之子，晋武帝的女婿，豪爽有才。
注：灵床：停放遗体或供奉亡者的床位。
注：体似真声：模仿得形神毕肖，像真驴叫一样。

# 四｜王戎丧儿万子
原：王戎丧儿万子，山简往省之，王悲不自胜。简曰：“孩抱中物，何至于此？”王曰：“圣人忘情，最下不及情。情之所钟，正在我辈。”简服其言，更为之恸。|| 王戎死了儿子万子，山简去探望他，王戎悲痛得不能自已。山简说：“不过是个还在怀抱里的孩子，何至于伤心成这样？”王戎说：“圣人能忘掉情感，最下等的人又谈不上有情。情感最专注深切的，恰恰就是我们这样的人。”山简信服他的话，反倒也为之痛哭起来。
注：万子：王戎之子王绥，小字万子，早卒。“孩抱中物”与刘孝标注所记年十九不合，存疑。
注：山简：字季伦，山涛之子，西晋名士。省（xǐng）：探望。
注：忘情：超然于喜怒哀乐之外。不及情：够不上谈情。钟：聚集，专注。
注：更：反而。恸：极度悲痛。

# 五｜有人哭和长舆曰
原：有人哭和长舆曰：“峨峨若千丈松崩。”|| 有人哭吊和峤时说：“他的去世，就像高耸的千丈青松轰然倒下。”
注：和长舆：和峤，字长舆，西晋大臣，官至中书令、侍中，以器量深厚、为人刚正著称。
注：峨峨：高峻的样子。

# 六｜卫洗马以永嘉六年丧
原：卫洗马以永嘉六年丧，谢鲲哭之，感动路人。咸和中，丞相王公教曰：“卫洗马当改葬。此君风流名士，海内所瞻，可修薄祭，以敦旧好。”|| 卫玠在永嘉六年去世，谢鲲哭他哭得十分悲痛，连过路的人都为之感动。咸和年间，丞相王导下教令说：“卫洗马应当改葬。这位先生是风流名士，为天下人所仰望，可以备办一点简单的祭品，以此加深昔日的情谊。”
注：卫洗（xiǎn）马：卫玠，字叔宝，曾任太子洗马，以容貌清秀、善谈玄理闻名，二十七岁早卒。
注：永嘉六年：公元312年。永嘉为晋怀帝年号。咸和：晋成帝年号（326—334）。
注：谢鲲：字幼舆，东晋名士，卫玠的好友。教：诸侯、重臣发布的文告。
注：薄祭：菲薄的祭品，谦辞。敦：加厚，增进。

# 七｜顾彦先平生好琴
原：顾彦先平生好琴，及丧，家人常以琴置灵床上。张季鹰往哭之，不胜其恸，遂径上床，鼓琴作数曲，竟，抚琴曰：“顾彦先颇复赏此不？”因又大恸，遂不执孝子手而出。|| 顾荣一辈子喜欢弹琴，他死后，家里人常把琴放在灵床上。张翰前去哭吊，悲痛得难以自持，竟直接坐上灵床，弹了几支曲子，弹完了抚着琴说：“顾彦先还能欣赏这曲子吗？”说着又放声痛哭，竟连孝子的手也没握就走了。
注：顾彦先：顾荣，字彦先，吴郡人，东吴丞相顾雍之孙，入晋后为江东士族领袖。
注：张季鹰：张翰，字季鹰，吴郡人，放达不羁，与顾荣同乡交好。
注：不（fǒu）：同“否”。
注：执孝子手：按丧礼，吊唁者应握孝子之手表示慰问；张翰不执，是悲痛之极而不顾礼数。

# 八｜庾亮儿遭苏峻难遇害
原：庾亮儿遭苏峻难遇害。诸葛道明女为庾儿妇，既寡，将改适，与亮书及之。亮答曰：“贤女尚少，故其宜也。感念亡儿，若在初没。”|| 庾亮的儿子在苏峻之乱中遇害。诸葛恢的女儿是庾亮的儿媳，守寡之后打算改嫁，诸葛恢在给庾亮的信里提到了这件事。庾亮回信说：“令爱还年轻，改嫁本是应当的。只是我想念死去的儿子，仿佛他刚刚离世一样。”
注：庾亮儿：庾亮之子庾会，咸和年间苏峻作乱时在建康遇害。
注：苏峻难：东晋成帝时苏峻起兵攻入建康的叛乱。
注：诸葛道明：诸葛恢，字道明，东晋大臣。改适：改嫁。
注：没（mò）：通“殁”，死。

# 九｜庾文康亡
原：庾文康亡，何扬州临葬，云：“埋玉树著土中，使人情何能已已！”|| 庾亮去世，何充去参加葬礼，说：“把一株玉树埋进土里，叫人心里怎么能平静得下来！”
注：庾文康：庾亮，谥文康。
注：何扬州：何充，字次道，曾任扬州刺史，东晋重臣。
注：玉树：比喻人风姿俊美、品格高洁。著（zhuó）：放置。
注：已已：停止，平息；后一个“已”是语气词。

# 十｜王长史病笃
原：王长史病笃，寝卧灯下，转麈尾视之，叹曰：“如此人，曾不得四十！”及亡，刘尹临殡，以犀柄麈尾著柩中，因恸绝。|| 王濛病重，躺在灯下，转动着麈尾端详，叹息道：“像这样的人，竟然活不到四十岁！”他死后，刘惔来参加入殓，把一柄犀角柄的麈尾放进他的棺材里，随即悲痛得昏死过去。
注：王长史：王濛，字仲祖，东晋名士，曾任司徒左长史，年三十九卒。
注：麈（zhǔ）尾：用鹿类尾毛制成的拂尘，清谈时手执以助谈兴，是名士的标志。
注：刘尹：刘惔，字真长，曾任丹阳尹，与王濛交情最深。殡：入殓停柩。
注：柩：装有尸体的棺材。

# 十一｜支道林丧法虔之后
原：支道林丧法虔之后，精神霣丧，风味转坠。常谓人曰：“昔匠石废斤于郢人，牙生辍弦于钟子，推己外求，良不虚也。冥契既逝，发言莫赏，中心蕴结，余其亡矣！”却后一年，支遂殒。|| 支道林失去法虔之后，精神颓丧，风采神韵也一天天衰减。他常对人说：“从前匠石因为郢人死了而不再挥斧，伯牙因为钟子期死了而不再弹琴，拿自己的遭遇去推想别人，确实不是假的。心意相契的知己已经去了，我说的话再没人欣赏，心里郁结难解，我恐怕也要死了！”过了一年，支道林果然去世。
注：支道林：支遁，字道林，东晋高僧，精于玄理，与名士交游甚广。法虔：僧人，支遁的同学，善义理。
注：霣（yǔn）丧：坠落沮丧。风味：风度韵味。
注：匠石废斤于郢人：典出《庄子·徐无鬼》，郢人鼻尖沾了薄如蝇翼的白灰，匠石挥斧削去而鼻不伤；郢人死后，匠石便无可施技。斤：斧子。
注：牙生辍弦于钟子：伯牙善鼓琴，钟子期能听出其志趣；钟子期死，伯牙终身不再弹琴。冥契：默然相契的知音。

# 十二｜郗嘉宾丧
原：郗嘉宾丧，左右白郗公：“郎丧。”既闻不悲，因语左右：“殡时可道。”公往临殡，一恸几绝。|| 郗超死了，身边的人禀告郗愔：“少爷去世了。”郗愔听了并不显得悲伤，只对左右说：“入殓的时候告诉我。”到了入殓时，郗愔前去哭吊，一下子悲痛得几乎断了气。
注：郗嘉宾：郗超。郗公：郗超之父郗愔，字方回，东晋大臣，信奉道教。
注：郎：仆从对少主人的称呼。
注：殡：入殓。

# 十三｜戴公见林法师墓
原：戴公见林法师墓曰：“德音未远，而拱木已积。冀神理绵绵，不与气运俱尽耳。”|| 戴逵看到支道林法师的墓，说：“他的言谈仿佛还在耳边，墓上的树木却已经长到合抱粗了。但愿他那精妙的义理能绵延不绝，不随着他的命数一同消逝。”
注：戴公：戴逵，字安道，东晋隐士，善琴书绘画。林法师：支道林。
注：德音：对他人言谈的敬称。
注：拱木：两手合抱粗的树，语本《左传》“尔墓之木拱矣”，指人死已久。
注：神理：精微的玄理。气运：气数，寿命。

# 十四｜王子敬与羊绥善
原：王子敬与羊绥善。绥清淳简贵，为中书郎，少亡。王深相痛悼，语东亭云：“是国家可惜人。”|| 王献之和羊绥交情很好。羊绥为人清正淳朴、简约高贵，做过中书郎，年纪轻轻就死了。王献之深为痛惜，对王珣说：“这是国家应当珍惜的人才啊。”
注：王子敬：王献之，字子敬，王羲之第七子，书法家。羊绥：字仲彦，泰山人，官至中书侍郎。
注：清淳（chún）：清白朴实。简贵：简约而尊贵。
注：东亭：王珣，字元琳，王导之孙，封东亭侯，与王献之同族。

# 十五｜王东亭与谢公交恶
原：王东亭与谢公交恶。王在东闻谢丧，便出都诣子敬道：“欲哭谢公。”子敬始卧，闻其言，便惊起曰：“所望于法护。”|| 王珣和谢安彼此结怨。王珣在东边听说谢安去世，便赶到京城去见王献之，说：“我想去哭吊谢公。”王献之本来躺着，听了这话，一下子惊起说：“这正是我对你法护所期望的。”
注：谢公：谢安。交恶（wù）：结仇，关系破裂。王珣与谢家曾有婚姻纠葛，因而两家失和。
注：出都：到京城建康去。
注：法护：王珣的小名。
原：王于是往哭。督帅刁约不听前，曰：“官平生在时，不见此客。”王亦不与语，直前哭，甚恸，不执末婢手而退。|| 王珣于是前往哭吊。谢家帐下的督帅刁约不让他上前，说：“我家主公在世的时候，从不见这位客人。”王珣也不和他争辩，径直上前痛哭，哭得非常伤心，哭完也没有去握谢琰的手就退了出来。
注：督帅：统领兵卒的武官。刁约：生平不详。听：允许。
注：官：对主人的称呼，这里指谢安。
注：末婢：谢安之子谢琰的小字。不执其手，是不按吊唁常礼慰问孝子。

# 十六｜王子猷、子敬俱病笃
原：王子猷、子敬俱病笃，而子敬先亡。子猷问左右：“何以都不闻消息？此已丧矣！”语时了不悲。便索舆来奔丧，都不哭。|| 王徽之、王献之兄弟都病得很重，而王献之先死了。王徽之问身边的人：“怎么一点消息也听不到？这是已经死了啊！”说的时候一点也不显得悲伤。随即要来车子去奔丧，一路上一声也没哭。
注：王子猷（yóu）：王徽之，字子猷，王羲之第五子，任性放达。子敬：王献之，其弟。
注：了：完全。舆：车。
原：子敬素好琴，便径入坐灵床上，取子敬琴弹，弦既不调，掷地云：“子敬，子敬，人琴俱亡！”因恸绝良久。月余亦卒。|| 王献之向来爱弹琴，王徽之便径直进去坐在灵床上，拿过献之的琴来弹，琴弦怎么也调不准，他把琴往地上一扔，说：“子敬啊子敬，人和琴都没了！”于是悲痛得昏过去很久。一个多月后，王徽之也去世了。
注：调（tiáo）：音调和谐。
注：人琴俱亡：后世用作悼念亡友、睹物伤人的成语。

# 十七｜孝武山陵夕
原：孝武山陵夕，王孝伯入临，告其诸弟曰：“虽榱桷惟新，便自有《黍离》之哀。”|| 晋孝武帝去世的那天晚上，王恭进宫哭吊，对他的几个弟弟说：“宫殿的椽子虽然还是新的，却已经让人生出《黍离》那样的亡国之悲了。”
注：孝武：东晋孝武帝司马曜。山陵：帝王坟墓，代指帝王去世。
注：王孝伯：王恭，孝武帝皇后之兄。入临：入宫哭吊。
注：榱桷（cuī jué）：屋椽，这里代指宫殿建筑。
注：《黍离》：《诗经·王风》篇名，写周大夫路过故都宗庙废墟，见禾黍满地而伤悼，后用作哀叹亡国的典故。

# 十八｜羊孚年三十一卒
原：羊孚年三十一卒，桓玄与羊欣书曰：“贤从情所信寄，暴疾而殒。祝予之叹，如何可言！”|| 羊孚三十一岁就去世了，桓玄给羊欣写信说：“令堂兄是我感情上所信赖寄托的人，竟突然得急病死了。这种‘天要断绝我’的悲叹，叫我怎么说得出来！”
注：羊孚：字子道，泰山人，桓玄的亲信。羊欣：字敬元，羊孚的从弟，善书法。
注：贤从（cóng）：对他人堂兄弟的敬称。信寄：信赖托付。殒：死。
注：祝予：语出《公羊传》，颜渊死，孔子叹“天丧予”；子路死，叹“天祝予”。祝：断绝。

# 十九｜桓玄当篡位
原：桓玄当篡位，语卞鞠云：“昔羊子道恒禁吾此意。今腹心丧羊孚，爪牙失索元，而匆匆作此诋突，讵允天心？”|| 桓玄将要篡夺帝位时，对卞范之说：“从前羊子道总是劝阻我这个念头。如今心腹之中没了羊孚，武将之中失了索元，却匆匆忙忙干这种冒犯之事，难道合乎天意吗？”
注：当：将要。篡位：桓玄于元兴二年（403）废晋安帝自立，国号楚，次年败死。
注：卞鞠：卞范之，字敬祖，小字鞠，桓玄的长史和亲信。
注：羊子道：羊孚。爪牙：比喻武将。索元：桓玄部将，生平细节存疑。
注：诋（dǐ）突：冒犯，触犯，指篡位之举。讵（jù）：难道。允：合乎。
