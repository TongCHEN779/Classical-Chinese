# 本门导读
题解：“贤媛”指有德有识的女子。本门所记，有的是母亲教子、妻子劝夫，有的是临难不惧、言辞机敏，也有才女相互品评，可见魏晋女子的见识与风骨。

# 一｜陈婴者，东阳人
原：陈婴者，东阳人。少修德行，著称乡党。秦末大乱，东阳人欲奉婴为王，母曰：“不可！自我为汝家妇，少见贫贱，一旦富贵，不祥。不如以兵属人，事成少受其利；不成祸有所归。”|| 陈婴是东阳人。¦年轻时就砥砺品行，在乡里很有名声。¦秦朝末年天下大乱，东阳人想拥立陈婴称王，他母亲说：“不行！¦自从我嫁到你家做媳妇，一直见你家贫寒低微，忽然一下子大富大贵，不是好兆头。¦不如把兵马交给别人统领，事情成了，自己多少沾些好处；不成，灾祸也自有人去承担。”
注：陈婴：秦末东阳人，起兵后归附项梁，入汉封堂邑侯。
注：东阳：秦县名，故地在今安徽天长一带。
注：乡党：乡里，同乡人。
注：属（zhǔ）：交付，托付。

# 二｜汉元帝宫人既多
原：汉元帝宫人既多，乃令画工图之，欲有呼者，辄披图召之。其中常者，皆行货赂。王明君姿容甚丽，志不苟求，工遂毁为其状。后匈奴来和，求美女于汉帝，帝以明君充行。既召见而惜之，但名字已去，不欲中改，于是遂行。|| 汉元帝后宫的宫女太多，就叫画工把她们一一画下来，想召谁侍奉，便翻看画像去召。宫女中相貌平常的，都去贿赂画工。王明君容貌极美，却不肯苟且求人，画工便把她画得很丑。后来匈奴前来求和，向汉帝讨要美女，元帝就拿王明君充数。等到召来一见，元帝十分舍不得，可是名字已经报给匈奴，不想中途更改，于是她就这样远嫁了。
注：汉元帝：刘奭（shì），西汉皇帝，宣帝之子。
注：图：画像，这里作动词。
注：披：翻开，翻阅。
注：王明君：即王昭君，名嫱。晋人避司马昭讳改称“明君”，后出塞嫁匈奴呼韩邪单于。
注：去：送出去，指名单已交付匈奴。

# 三｜汉成帝幸赵飞燕
原：汉成帝幸赵飞燕，飞燕谗班婕妤祝诅，于是考问。辞曰：“妾闻死生有命，富贵在天。修善尚不蒙福，为邪欲以何望？若鬼神有知，不受邪佞之诉；若其无知，诉之何益？故不为也。”|| 汉成帝宠爱赵飞燕，赵飞燕诬陷班婕妤请鬼神诅咒，成帝于是把班婕妤抓来审问。她供述说：“我听说死生由命，富贵在天。行善尚且得不到福报，做坏事又能指望什么呢？假如鬼神有灵，就不会接受奸邪小人的祷告；假如鬼神无知，向它祷告又有什么用？所以我不做这种事。”
注：汉成帝：刘骜，元帝之子。
注：幸：宠爱。
注：赵飞燕：本为歌舞伎，得成帝宠爱，后立为皇后。
注：班婕妤（jié yú）：成帝妃嫔，有文才，失宠后自请侍奉太后于长信宫。婕妤是妃嫔称号。
注：祝诅：向鬼神祷告，求降祸于人。
注：考问：拷打审讯。

# 四｜魏武帝崩，文帝悉取
原：魏武帝崩，文帝悉取武帝宫人自侍。及帝病困，卞后出看疾。太后入户，见直侍并是昔日所爱幸者。太后问：“何时来邪？”云：“正伏魄时过。”因不复前而叹曰：“狗鼠不食汝余，死故应尔！”至山陵，亦竟不临。|| 魏武帝曹操去世，文帝曹丕把武帝的宫人全都收来侍奉自己。等到文帝病危，卞太后前去探病。太后一进门，看见值班侍候的都是先帝从前宠爱的人。太后问：“你们什么时候来的？”回答说：“正在为先帝招魂的时候过来的。”太后于是不再往前走，叹息说：“连猪狗都不吃你剩下的东西，你本来就该死！”直到文帝下葬，太后也始终没有去哭吊。
注：魏武帝：曹操。
注：文帝：曹丕。
注：卞后：曹操之妻，曹丕生母，曹丕称帝后尊为太后。
注：直侍：值班侍奉的人。直，同“值”。
注：伏魄：人死后招魂的仪式。
注：山陵：帝王陵墓，借指葬礼。
注：临：哭吊死者。

# 五｜赵母嫁女
原：赵母嫁女，女临去，敕之曰：“慎勿为好！”女曰：“不为好，可为恶邪？”母曰：“好尚不可为，其况恶乎！”|| 赵母嫁女儿，女儿临出门时，她叮嘱道：“千万别去做好事！”女儿说：“不做好事，难道可以做坏事吗？”赵母说：“好事尚且不可做，何况坏事呢！”
注：赵母：三国吴人，虞韪之妻，以才学著称，孙权召入宫中，曾注《列女传》。
注：敕（chì）：告诫，叮嘱。
注：为好：刻意做好事。意谓不要显露锋芒、招人嫉妒，安分守己即可。

# 六｜许允妇是阮卫尉女
原：许允妇是阮卫尉女，德如妹，奇丑。交礼竟，允无复入理，家人深以为忧。会允有客至，妇令婢视之，还答曰：“是桓郎。”桓郎者，桓范也，妇云：“无忧，桓必劝入。”|| 许允的妻子是卫尉阮共的女儿、阮德如的妹妹，长得奇丑。¦行完婚礼，许允再也没有进新房的意思，家里人都为此十分担忧。¦正好许允有客人来，新娘叫婢女去看是谁，婢女回来说：“是桓郎。”¦桓郎就是桓范。新娘说：“不用担心，桓郎一定会劝他进来。”
注：许允：字士宗，高阳人，曹魏时官至中领军，后为司马师所害。
注：阮卫尉：阮共，曹魏时任卫尉。
注：德如：阮侃，字德如，阮共之子。
注：交礼：婚礼中新人交拜之礼。
注：理：意思，打算。
注：桓范：字元则，曹魏大司农，后附曹爽被司马懿所杀。
原：桓果语许云：“阮家既嫁丑女与卿，故当有意，卿宜察之。”许便回入内。既见妇，即欲出。妇料其此出，无复入理，便捉裾停之。|| 桓范果然对许允说：“阮家既然把丑女儿嫁给你，必定有他们的用意，你应该好好体察。”许允就转身回到新房。可一见到新娘，又想往外走。新娘料想他这一走就不会再进来了，便拽住他的衣襟把他留住。
注：故当：必定，一定。
注：裾（jū）：衣襟。
原：许因谓曰：“妇有四德，卿有其几？”妇曰：“新妇所乏唯容尔。然士有百行，君有几？”许云：“皆备。”妇曰：“夫百行以德为首，君好色不好德，何谓皆备？”允有惭色，遂相敬重。|| 许允于是对她说：“妇人该有四种德行，你占了几样？”新娘说：“我缺的只是容貌罢了。可是读书人该有百种品行，你又有几样？”许允说：“样样都有。”新娘说：“百种品行以德为首，你爱好美色而不爱好德行，怎么能说样样都有？”许允面露惭愧，从此夫妻相互敬重。
注：四德：古时要求妇女具备的妇德、妇言、妇容、妇功。
注：百行：士人应有的各种品行。
注：好色不好德：化用《论语·子罕》“吾未见好德如好色者也”。

# 七｜许允为吏部郎
原：许允为吏部郎，多用其乡里，魏明帝遣虎贲收之。其妇出诫允曰：“明主可以理夺，难以情求。”既至，帝核问之。允对曰：“‘举尔所知’。臣之乡人，臣所知也。陛下检校为称职与不，若不称职，臣受其罪。”|| 许允任吏部郎时，任用了很多同乡，魏明帝派禁卫武士去逮捕他。他妻子出来告诫他说：“对英明的君主，可以用道理去说服，难以靠求情打动。”到了朝堂，明帝追问此事。许允答道：“孔子说‘推举你所了解的人’。我的同乡，正是我所了解的人。请陛下查核他们称职与否，如果不称职，我甘愿受罚。”
注：吏部郎：吏部属官，掌管官吏的选拔任用。
注：魏明帝：曹叡，曹丕之子。
注：虎贲（bēn）：宫中禁卫武士。
注：收：逮捕。
注：举尔所知：语出《论语·子路》，孔子教仲弓推举自己所了解的贤才。
注：检校：查核。
注：不（fǒu）：同“否”。
原：既检校，皆官得其人，于是乃释。允衣服败坏，诏赐新衣。初，允被收，举家号哭。阮新妇自若云：“勿忧，寻还。”作粟粥待，顷之允至。|| 查核下来，那些人都是官职与人才相称，于是就把许允放了。¦见许允衣服破旧，明帝还下诏赏给他新衣。¦当初许允被捕时，全家号啕大哭，¦只有阮氏神态如常地说：“别担心，他很快就会回来。”¦她煮好小米粥等着，不一会儿许允果然回来了。
注：自若：神情镇定，和平常一样。
注：寻：不久。
注：顷之：一会儿。

# 八｜许允为晋景王所诛
原：许允为晋景王所诛，门生走入告其妇。妇正在机中，神色不变，曰：“蚤知尔耳！”门人欲藏其儿，妇曰：“无豫诸儿事。”后徙居墓所，景王遣钟会看之，若才流及父，当收。|| 许允被晋景王司马师杀害，他的门生跑进来告诉他妻子。她正在织布机上织布，神色不变，说：“早就料到会这样了！”门生想把许允的儿子们藏起来，她说：“不关孩子们的事。”后来一家迁居到许允墓旁守丧，司马师派钟会去察看，打算如果儿子们的才能比得上父亲，就逮捕他们。
注：晋景王：司马师，司马懿长子，曹魏时专权，晋朝建立后追尊为景帝。
注：机：织布机。
注：蚤：同“早”。
注：尔：如此。
注：豫：干预，相关。
注：钟会：字士季，司马氏心腹谋臣，后在蜀中谋反被杀。
注：才流：才能品类。
原：儿以咨母。母曰：“汝等虽佳，才具不多，率胸怀与语，便无所忧。不须极哀，会止便止。又可少问朝事。”儿从之，会反以状对，卒免。|| 儿子们向母亲请教对策。母亲说：“你们虽然不错，但才干有限，只管坦坦荡荡地照心里想的跟他说话，就不用担心。不必哀痛到极点，钟会停止哭了你们也就停止。也可以稍微问问朝廷里的事。”儿子们照着做了，钟会回去把情况如实禀报，他们终于幸免于难。
注：咨（zī）：询问，商量。
注：才具：才能。
注：率：直率，坦然。
注：反：同“返”。
注：状：情形。
注：卒：终于。

# 九｜王公渊娶诸葛诞女
原：王公渊娶诸葛诞女。入室，言语始交，王谓妇曰：“新妇神色卑下，殊不似公休！”妇曰：“大丈夫不能仿佛彦云，而令妇人比踪英杰？”|| 王公渊娶了诸葛诞的女儿。进了洞房，两人刚开始说话，王公渊就对妻子说：“新娘子神态气度低下，一点也不像你父亲公休！”妻子说：“大丈夫自己比不上父亲彦云，倒要妇道人家去追比英雄豪杰？”
注：王公渊：王广，字公渊，王凌之子，有才学，因父谋废立事败一同被杀。
注：诸葛诞：字公休，曹魏大将，后起兵反司马氏被杀。
注：仿佛：近似，比得上。
注：彦云：王凌的字，曹魏太尉。称人父字以相讥。
注：比踪：追随比肩。

# 十｜王经少贫苦
原：王经少贫苦，仕至二千石，母语之曰：“汝本寒家子，仕至二千石，此可以止乎？”经不能用。为尚书，助魏，不忠于晋，被收。涕泣辞母曰：“不从母敕，以至今日。”母都无戚容，语之曰：“为子则孝，为臣则忠，有孝有忠，何负吾邪？”|| 王经年轻时家境贫苦，后来做到二千石的官，母亲对他说：“你本是贫寒人家的孩子，做官到了二千石，可以就此停住了吧？”王经没有听从。后来他任尚书，忠于魏室，不肯依附司马氏，被逮捕。他流着泪向母亲告别说：“没有听母亲的教诲，才落到今天这个地步。”母亲脸上毫无悲戚之色，对他说：“做儿子能孝顺，做臣子能尽忠，既孝且忠，你哪里对不起我呢？”
注：王经：字彦纬，曹魏尚书，高贵乡公曹髦讨司马昭时不肯告密，事后被杀。
注：二千石：汉魏郡守一级官员的俸禄等级，借指郡守。
注：晋：指当时专权的司马氏，晋朝尚未建立，追称为晋。
注：敕（chì）：告诫。
注：都：全然。

# 十一｜山公与嵇、阮一面
原：山公与嵇、阮一面，契若金兰。山妻韩氏觉公与二人异于常交，问公，公曰：“我当年可以为友者，唯此二生耳。”妻曰：“负羁之妻亦亲观狐、赵，意欲窥之，可乎？”|| 山涛与嵇康、阮籍一见面，就情投意合，交情如同金兰。山涛的妻子韩氏察觉丈夫和这两个人的交情不同寻常，就问他，山涛说：“我如今可以结为朋友的，只有这两位先生了。”妻子说：“当年僖负羁的妻子也曾亲自观察过狐偃、赵衰，我也想偷偷看看他们，可以吗？”
注：山公：山涛，字巨源，竹林七贤之一，入晋官至司徒。
注：嵇、阮：嵇康、阮籍。
注：契若金兰：情意相投，如金之坚、如兰之香，语本《周易·系辞》。
注：负羁之妻：春秋时曹国大夫僖负羁之妻，曾观察流亡的晋公子重耳的随从狐偃、赵衰，断定重耳必能返国称霸。
原：他日，二人来，妻劝公止之宿，具酒肉。夜穿墉以视之，达旦忘反。公入曰：“二人何如？”妻曰：“君才致殊不如，正当以识度相友耳。”公曰：“伊辈亦常以我度为胜。”|| 有一天，两人来了，妻子劝山涛留他们住下，备好酒肉。夜里她在墙上挖个洞偷看，一直看到天亮，忘了回房。山涛进来问：“这两个人怎么样？”妻子说：“你的才情志趣远远比不上他们，只配凭见识和气度跟他们交朋友罢了。”山涛说：“他们也常认为我的气度胜过他们。”
注：墉（yōng）：墙。
注：达旦：直到天亮。
注：才致：才华情致。
注：殊：很，极。
注：识度：见识与气量。
注：伊辈：他们。

# 十二｜王浑妻钟氏生女令淑
原：王浑妻钟氏生女令淑，武子为妹求简美对而未得，有兵家子，有俊才，欲以妹妻之，乃白母。曰：“诚是才者，其地可遗，然要令我见。”武子乃令兵儿与群小杂处，使母帷中察之。|| 王浑的妻子钟氏生了个女儿，美好贤淑，王武子想为妹妹挑一个好夫婿，一直没有找到。有个军户人家的儿子，才华出众，王武子想把妹妹嫁给他，就去禀告母亲。¦母亲说：“如果真有才干，门第可以不计较，但要让我亲眼看看。”¦王武子就让那个军户子弟和一群平民混在一起，让母亲在帷幕后观察。
注：王浑：字玄冲，西晋大臣，官至司徒。
注：钟氏：钟繇曾孙女，有才识。
注：武子：王济，字武子，王浑之子，以才气豪奢著称。
注：简：挑选。
注：美对：好配偶。
注：兵家子：军户出身的子弟，当时地位低下。
注：地：门第。
注：遗：抛开不计。
原：既而母谓武子曰：“如此衣形者，是汝所拟者非邪？”武子曰：“是也。”母曰：“此才足以拔萃，然地寒，不有长年，不得申其才用。观其形骨，必不寿，不可与婚。”武子从之。兵儿数年果亡。|| 看过之后，母亲对王武子说：“穿着这样衣服、长着这副模样的，就是你看中的人吧？”王武子说：“是的。”母亲说：“这人的才华足以出类拔萃，可是门第寒微，若没有长寿，就无法施展他的才能。看他的形貌骨相，一定不长寿，不能跟他结亲。”王武子听从了。那个军户子弟过了几年果然死了。
注：拟：打算，选定。
注：拔萃：出众。
注：申：同“伸”，施展。
注：形骨：形貌骨相。

# 十三｜贾充前妇，是李丰女
原：贾充前妇，是李丰女。丰被诛，离婚徙边，后遇赦得还。充先已取郭配女，武帝特听置左右夫人。李氏别住外，不肯还充舍。|| 贾充的前妻是李丰的女儿。李丰被杀后，她与贾充离婚，被流放到边地，后来遇到大赦才得以回来。贾充此前已经娶了郭配的女儿，晋武帝特许他同时设立左、右两位夫人。李氏另住在外面，不肯回到贾充家。
注：贾充：字公闾，司马氏心腹，入晋位至太尉。
注：李丰：字安国，曹魏中书令，因谋除司马师被杀。
注：郭配：曹魏城阳太守，其女郭槐嫁贾充，以凶悍善妒闻名。
注：听：准许。
原：郭氏语充，欲就省李，充曰：“彼刚介有才气，卿往不如不去。”郭氏于是盛威仪，多将侍婢。既至，入户，李氏起迎，郭不觉脚自屈，因跪再拜。既反，语充，充曰：“语卿道何物？”|| 郭氏对贾充说，想去看望李氏。贾充说：“她性格刚直，又有才气，你去了还不如不去。”¦郭氏于是摆足了排场，带了很多侍女。¦到了那里，一进门，李氏起身相迎，郭氏不知不觉两腿发软，就跪下拜了两拜。¦回来后告诉贾充，贾充说：“我跟你说过什么来着？”
注：省（xǐng）：探望。
注：刚介：刚强耿直。
注：盛威仪：讲究排场，盛装打扮。
注：将：带领。
注：何物：什么，当时口语。

# 十四｜贾充妻李氏作《女训》
原：贾充妻李氏作《女训》，行于世。李氏女，齐献王妃；郭氏女，惠帝后。充卒，李、郭女各欲令其母合葬，经年不决。贾后废，李氏乃祔葬，遂定。|| 贾充的妻子李氏写了《女训》，流传于世。李氏的女儿是齐献王的王妃；郭氏的女儿是晋惠帝的皇后。贾充死后，李氏、郭氏的女儿各自都想让自己的母亲与贾充合葬，争执多年没有结果。直到贾后被废，李氏才得以与贾充合葬，事情才定下来。
注：《女训》：李氏所作训诫女子的书，已失传。
注：齐献王：司马攸，晋武帝之弟，封齐王，谥献。
注：惠帝后：贾南风，郭氏所生，晋惠帝皇后，专权乱政，后被赵王司马伦废杀。
注：祔（fù）葬：合葬。

# 十五｜王汝南少无婚
原：王汝南少无婚，自求郝普女。司空以其痴，会无婚处，任其意便许之。既婚，果有令姿淑德。生东海，遂为王氏母仪。或问汝南：“何以知之？”曰：“尝见井上取水，举动容止不失常，未尝忤观，以此知之。”|| 王汝南年轻时没有娶亲，自己要求娶郝普的女儿。他父亲王司空认为他痴呆，反正也找不到人家结亲，就随他的意思答应了。婚后，郝氏果然容貌美好、品德贤淑。她生了王东海，后来成为王家做母亲的典范。有人问王汝南：“你怎么知道她好？”他说：“我曾见她在井边打水，举止仪态从不失常，从没有让人看着不顺眼的地方，凭这个知道的。”
注：王汝南：王湛，字处冲，王昶之子，曾任汝南内史，少时人以为痴。
注：郝普：太原人，曹魏时任郡守，门第不高。
注：司空：王昶，字文舒，王湛之父，曹魏司空。
注：会：反正，总归。
注：东海：王承，王湛之子，曾任东海内史。
注：母仪：母亲的典范。
注：忤观：看着不顺眼。

# 十六｜王司徒妇，钟氏女
原：王司徒妇，钟氏女，太傅曾孙，亦有俊才女德。钟、郝为娣姒，雅相亲重。钟不以贵陵郝，郝亦不以贱下钟。东海家内，则郝夫人之法；京陵家内，范钟夫人之礼。|| 王司徒的妻子是钟家的女儿、太傅钟繇的曾孙女，也有出众的才华和女子的美德。钟氏与郝氏是妯娌，彼此非常亲近敬重。钟氏不因出身高贵而欺压郝氏，郝氏也不因出身低微而在钟氏面前自卑。王东海家里，以郝夫人的规矩为准则；王京陵家里，以钟夫人的礼法为典范。
注：王司徒：王浑，王昶之子，王湛之兄，袭父爵京陵侯，官至司徒。
注：太傅：钟繇，曹魏太傅，以书法著名。
注：娣姒（dì sì）：妯娌。
注：雅：甚，很。
注：陵：欺凌。
注：则、范：都是效法、作为典范的意思。

# 十七｜李平阳，秦州子
原：李平阳，秦州子，中夏名士，于时以比王夷甫。孙秀初欲立威权，咸云：“乐令民望，不可杀，减李重者又不足杀。”遂逼重自裁。|| 李平阳是李秦州的儿子，是中原的名士，当时人把他和王夷甫相比。孙秀起初想树立权威，身边的人都说：“乐令是众望所归的人物，杀不得；比李重差的人，又不值得杀。”于是就逼李重自尽。
注：李平阳：李重，字茂曾，曾任平阳太守。
注：秦州：其父李秉，曾任秦州刺史。
注：王夷甫：王衍，西晋清谈领袖。
注：孙秀：赵王司马伦的谋主，司马伦篡位时专权，后被杀。
注：乐令：乐广，时任尚书令，素有名望。
注：减：不及，次于。
注：自裁：自杀。
原：初，重在家，有人走从门入，出髻中疏示重。重看之色动，入内示其女，女直叫“绝”。了其意，出则自裁。此女甚高明，重每咨焉。|| 当初，李重在家，有人跑着从门外进来，从发髻里取出一份奏疏给他看。李重看后脸色大变，进内室拿给女儿看，女儿只是叫了一声“绝”。李重明白了她的意思，出来就自杀了。这个女儿见识很高明，李重常常向她请教。
注：走：跑。
注：疏：奏章，文书。
注：色动：脸色变了。
注：直：只是。
注：了：明白。
注：咨：咨询，商量。

# 十八｜周浚作安东时
原：周浚作安东时，行猎，值暴雨，过汝南李氏。李氏富足，而男子不在。有女名络秀，闻外有贵人，与一婢于内宰猪羊，作数十人饮食，事事精办，不闻有人声。密觇之，独见一女子，状貌非常，浚因求为妾。|| 周浚任安东将军时，外出打猎，遇上暴雨，路过汝南李家。李家很富足，可是男人都不在家。有个女儿名叫络秀，听说外面来了贵人，就和一个婢女在里面杀猪宰羊，做了几十人的饭菜，样样办得精致周到，却听不到一点人声。周浚暗中偷看，只见一个女子，相貌不同寻常，于是请求娶她为妾。
注：周浚：字开林，汝南安成人，西晋时以平吴之功封侯，官至安东将军。
注：汝南：郡名，治所在今河南境内。
注：觇（chān）：偷看，窥视。
原：父兄不许，络秀曰：“门户殄瘁，何惜一女？若连姻贵族，将来或大益。”父兄从之。遂生伯仁兄弟。|| 父亲和兄长不答应，络秀说：“咱家门第衰败，何必舍不得一个女儿？如果能与贵族结亲，将来或许大有好处。”父兄听从了她。后来她生下了周伯仁兄弟。
注：殄瘁（tiǎn cuì）：衰败困顿。
注：伯仁：周顗（yǐ），字伯仁，周浚之子，东晋名臣，为王敦所杀。
原：络秀语伯仁等：“我所以屈节为汝家作妾，门户计耳。汝若不与吾家作亲亲者，吾亦不惜余年！”伯仁等悉从命。由此李氏在世，得方幅齿遇。|| 络秀对伯仁兄弟说：“我之所以委屈自己到你们家做妾，只是为娘家门户着想罢了。你们要是不跟我娘家当亲戚走动，我这条老命也不要了！”伯仁兄弟都听从了她的话。从此李家在世上，得到了正正当当的礼遇。
注：屈节：降低身份。
注：门户计：为家族门第考虑。
注：亲亲：亲戚。
注：方幅：正式，堂堂正正，当时口语。
注：齿遇：被同等看待，受到礼遇。

# 十九｜陶公少有大志
原：陶公少有大志，家酷贫，与母湛氏同居。同郡范逵素知名，举孝廉，投侃宿。于时冰雪积日，侃室如悬磬，而逵马仆甚多。侃母湛氏语侃曰：“汝但出外留客，吾自为计。”|| 陶侃年轻时就有远大志向，家里极穷，和母亲湛氏住在一起。同郡的范逵一向有名望，被举为孝廉，到陶侃家投宿。当时冰雪连日不化，陶侃家里空空荡荡，而范逵的车马仆从却很多。陶侃的母亲湛氏对陶侃说：“你只管到外面把客人留下，我自有办法。”
注：陶公：陶侃，字士行，鄱阳人，后迁庐江寻阳，东晋名将，官至太尉，封长沙郡公。
注：范逵：鄱阳人，有名于乡里，与陶侃交好。
注：孝廉：汉魏以来选举官吏的科目。
注：室如悬磬（qìng）：屋里空无一物，像悬挂的石磬一样空。语出《左传》。
原：湛头发委地，下为二髲，卖得数斛米；斫诸屋柱，悉割半为薪；剉诸荐，以为马草。日夕，遂设精食，从者皆无所乏。|| 湛氏的头发长得拖到地上，她剪下来做成两副假发，卖了换来几斛米；又把几根房柱砍下来，都劈去一半当柴烧；把草垫铡碎当马料。到了傍晚，就摆上了精美的饭食，连随从也都一无所缺。
注：委：下垂，拖。
注：髲（bì）：假发。
注：斛（hú）：量器名，也是容量单位。
注：斫（zhuó）：砍。
注：剉（cuò）：铡碎。
注：荐：草垫。
原：逵既叹其才辩，又深愧其厚意。明旦去，侃追送不已，且百里许。逵曰：“路已远，君宜还。”侃犹不返。逵曰：“卿可去矣。至洛阳，当相为美谈。”侃乃返。逵及洛，遂称之于羊晫、顾荣诸人。大获美誉。|| 范逵既赞叹陶侃的才干与口才，又对他的深情厚意深感不安。¦第二天离开时，陶侃一路追送，送了将近一百里。¦范逵说：“路已经很远了，你该回去了。”¦陶侃还是不回。¦范逵说：“你可以回去了。¦到了洛阳，我一定替你说好话。”¦陶侃这才回去。¦范逵到了洛阳，就在羊晫、顾荣等人面前称赞他，¦陶侃因此大获美名。
注：且：将近。
注：许：左右，表约数。
注：羊晫（zhuó）：曾任十郡中正，掌管人物品评。
注：顾荣：字彦先，吴郡名士，入晋后颇有声望。

# 二十｜陶公少时作鱼梁吏
原：陶公少时作鱼梁吏，尝以坩鲊饷母。母封鲊付使，反书责侃曰：“汝为吏，以官物见饷，非唯不益，乃增吾忧也。”|| 陶侃年轻时做管理鱼梁的小吏，曾经把一坛腌鱼送给母亲。母亲把腌鱼原封不动交给送东西的人带回，还写信责备陶侃说：“你当官吏，拿公家的东西送给我，不但对我没有好处，反倒增添了我的忧虑。”
注：鱼梁吏：管理鱼梁（拦水捕鱼设施）的小官。
注：坩（gān）：陶制容器。
注：鲊（zhǎ）：腌制的鱼。
注：饷（xiǎng）：赠送食物。
注：反书：回信。

# 二十一｜桓宣武平蜀
原：桓宣武平蜀，以李势妹为妾，甚有宠，常著斋后。主始不知，既闻，与数十婢拔白刃袭之。正值李梳头，发委藉地，肤色玉曜，不为动容。徐曰：“国破家亡，无心至此，今日若能见杀，乃是本怀。”主惭而退。|| 桓温平定蜀地后，娶了李势的妹妹为妾，非常宠爱她，常把她安置在书斋后面。¦公主起初不知道，听说后，带着几十个婢女拔出明晃晃的刀去袭击她。¦正赶上李氏在梳头，长发垂下铺在地上，肌肤像玉一样光洁照人，她神色毫不变动，¦从容地说：“国破家亡，我本无心来到这里，今天如果能被杀死，倒正合我的本愿。”¦公主惭愧地退了出去。
注：桓宣武：桓温，谥宣武，东晋权臣，永和三年灭成汉。
注：李势：成汉末代君主，降晋后封归义侯。
注：著：安置。
注：主：南康长公主，晋明帝之女，桓温之妻。
注：委藉：垂落铺地。
注：曜（yào）：光亮。

# 二十二｜庾玉台，希之弟也
原：庾玉台，希之弟也。希诛，将戮玉台。玉台子妇，宣武弟桓豁女也，徒跣求进。阍禁不内，女厉声曰：“是何小人？我伯父门，不听我前！”因突入，号泣请曰：“庾玉台常因人，脚短三寸，当复能作贼不？”宣武笑曰：“婿故自急。”遂原玉台一门。|| 庾玉台是庾希的弟弟。庾希被杀后，桓温又要杀庾玉台。庾玉台的儿媳是桓温弟弟桓豁的女儿，她光着脚跑去求见桓温。守门人拦着不让进，她厉声喝道：“你是什么小人？这是我伯父家的门，竟敢不让我进！”于是冲了进去，哭喊着求情说：“庾玉台平时走路都要靠人搀扶，脚比别人短三寸，难道还能造反吗？”桓温笑着说：“女婿家的事，侄女自然着急。”于是赦免了庾玉台一家。
注：庾玉台：庾友，小字玉台，庾冰之子，官至东阳太守。
注：希：庾希，庾冰长子，因与桓温为敌被杀。
注：桓豁：字朗子，桓温之弟，官至征西大将军。
注：徒跣（xiǎn）：赤脚。
注：阍（hūn）：守门人。
注：内：同“纳”。
注：因人：依靠别人扶持。
注：故自：确实，自然。
注：原：赦免。

# 二十三｜谢公夫人帏诸婢
原：谢公夫人帏诸婢，使在前作伎，使太傅暂见，便下帏。太傅索更开，夫人云：“恐伤盛德。”|| 谢安的夫人用帷幕把婢女们挡起来，让她们在帷幕前表演歌舞，只让谢安看了一会儿，就把帷幕放下了。谢安要求再打开，夫人说：“只怕有损您的美德。”
注：谢公夫人：谢安之妻刘氏，刘惔之妹。
注：帏（wéi）：帷幕，这里作动词，用帷幕遮挡。
注：作伎：表演歌舞乐曲。
注：太傅：谢安，死后追赠太傅。
注：盛德：美德。话中带讽，暗指谢安好声色。

# 二十四｜桓车骑不好著新衣
原：桓车骑不好著新衣，浴后，妇故送新衣与。车骑大怒，催使持去。妇更持还，传语云：“衣不经新，何由而故？”桓公大笑，著之。|| 桓车骑不喜欢穿新衣服。一次洗过澡，妻子特意送了新衣服给他。¦他大发脾气，催人赶快拿走。¦妻子又让人拿回来，传话说：“衣服不经过新的时候，怎么会变成旧的呢？”¦桓冲大笑，把衣服穿上了。
注：桓车骑：桓冲，字幼子，桓温之弟，官至车骑将军。
注：故：特意。
注：衣不经新，何由而故：妙在以常理破其执拗，又暗含人事新旧相替之理。

# 二十五｜王右军郗夫人谓二弟
原：王右军郗夫人谓二弟司空、中郎曰：“王家见二谢，倾筐倒庋；见汝辈来，平平尔。汝可无烦复往。”|| 王羲之的妻子郗夫人对两个弟弟郗司空、郗中郎说：“王家人见到谢家二位来，恨不得把箱柜都翻出来款待；见到你们来，就平平淡淡的。你们往后不必再费事去了。”
注：王右军：王羲之，官至右军将军。
注：郗夫人：郗鉴之女郗璿。
注：司空：郗愔，郗鉴长子，死后赠司空。
注：中郎：郗昙，郗鉴次子，曾任北中郎将。
注：二谢：谢安、谢万兄弟。
注：倾筐倒庋（guǐ）：把箱子、架子里的东西倒出来，比喻倾其所有热情招待。

# 二十六｜王凝之谢夫人既往王氏
原：王凝之谢夫人既往王氏，大薄凝之。既还谢家，意大不说。太傅慰释之曰：“王郎，逸少之子，人身亦不恶，汝何以恨乃尔？”答曰：“一门叔父，则有阿大、中郎；群从兄弟，则有封、胡、遏、末。不意天壤之中，乃有王郎！”|| 王凝之的妻子谢夫人嫁到王家后，非常看不起王凝之。回到娘家谢家时，心里很不高兴。叔父谢安宽慰她说：“王郎是逸少的儿子，人品才貌也不差，你为什么怨恨到这种地步？”她回答说：“我们一家的叔父辈里，有阿大、中郎这样的人；同族兄弟里，有封、胡、遏、末这样的人。没想到天地之间，竟然还有王郎这样的人！”
注：王凝之：王羲之次子，官至会稽内史，孙恩起事时被杀。
注：谢夫人：谢道韫，谢奕之女，以才学著称。
注：说：同“悦”。
注：逸少：王羲之的字。
注：人身：人品才貌。
注：乃尔：如此。
注：阿大：谢尚，谢道韫的堂叔。
注：中郎：谢据，谢安之兄。
注：存疑：“阿大”“中郎”所指历来有异说。
注：封、胡、遏、末：谢韶（小字封）、谢朗（小字胡）、谢玄（小字遏）、谢渊（小字末），都是谢家子弟。

# 二十七｜韩康伯母隐古几毁坏
原：韩康伯母隐古几毁坏，卞鞠见几恶，欲易之。答曰：“我若不隐此，汝何以得见古物？”|| 韩康伯的母亲平时靠着的一张旧几案坏了，外孙卞鞠见几案破旧，想给她换掉。她回答说：“我要是不靠着这个，你哪能见到古物呢？”
注：韩康伯：韩伯，字康伯，东晋玄学家。其母殷氏，殷浩之姊。
注：隐：倚靠。
注：几（jī）：供人倚靠的矮桌。
注：卞鞠：殷氏的外孙，一说即卞范之（存疑），后为桓玄亲信。
注：恶：破旧。
注：易：更换。

# 二十八｜王江州夫人语谢遏曰
原：王江州夫人语谢遏曰：“汝何以都不复进？为是尘务经心，天分有限？”|| 王江州的夫人对谢遏说：“你为什么一点长进也没有了？是因为俗事缠心，还是天资有限？”
注：王江州夫人：谢道韫。其夫王凝之曾任江州刺史，故称。
注：谢遏：谢玄，小字遏，谢道韫之弟，后为淝水之战主将。
注：为是：还是，表示选择。
注：尘务：世俗事务。
注：经心：缠绕于心。

# 二十九｜郗嘉宾丧
原：郗嘉宾丧，妇兄弟欲迎妹还，终不肯归，曰：“生纵不得与郗郎同室，死宁不同穴？”|| 郗嘉宾死后，他妻子的兄弟想把妹妹接回娘家，她始终不肯回去，说：“活着即使不能和郗郎同居一室，死后难道还不能同葬一穴吗？”
注：郗嘉宾：郗超，字嘉宾，郗愔之子，桓温的谋士。
注：妇：郗超之妻，周闵之女。
注：纵：即使。
注：宁：难道。
注：同穴：合葬。语本《诗经·王风·大车》“死则同穴”。

# 三十｜谢遏绝重其姊
原：谢遏绝重其姊，张玄常称其妹，欲以敌之。有济尼者，并游张、谢二家，人问其优劣，答曰：“王夫人神情散朗，故有林下风气；顾家妇清心玉映，自是闺房之秀。”|| 谢玄极为推重他的姐姐，张玄常常称赞自己的妹妹，想拿她来和谢玄的姐姐相匹敌。有个叫济尼的尼姑，同时与张、谢两家往来，有人问她两人谁高谁低，她回答说：“王夫人神情潇洒开朗，确实有竹林名士的风度；顾家媳妇心地清澈，如美玉映照，自然是闺阁中的佼佼者。”
注：张玄：张玄之，字祖希，吴郡人，与谢玄齐名，时称“南北二玄”。其妹嫁顾家。
注：敌：匹敌，相当。
注：林下风气：竹林名士那样超脱旷达的风度。
注：清心玉映：心地清明，如玉般光彩映人。
注：闺房之秀：女子中的优秀者。两句评语各有侧重，暗含高下。

# 三十一｜王尚书惠尝看王右军夫人
原：王尚书惠尝看王右军夫人，问：“眼耳未觉恶不？”答曰：“发白齿落，属乎形骸；至于眼耳，关于神明，那可便与人隔？”|| 尚书王惠曾去看望王羲之的夫人，问她：“眼睛耳朵没觉得有什么不好吧？”她回答说：“头发白了，牙齿掉了，那属于身体；至于眼睛耳朵，关系到人的精神，怎么能就这样和人隔绝呢？”
注：王尚书惠：王惠，字令明，王导曾孙，刘宋时官至吏部尚书。
注：王右军夫人：王羲之之妻郗璿，时已年高。
注：恶：有病，不舒服。
注：不：同“否”。
注：形骸（hái）：身体躯壳。
注：神明：精神。

# 三十二｜韩康伯母殷，随孙绘之之衡阳
原：韩康伯母殷，随孙绘之之衡阳，于阖庐洲中逢桓南郡。卞鞠是其外孙，时来问讯。谓鞠曰：“我不死，见此竖二世作贼！”|| 韩康伯的母亲殷氏，跟随孙子韩绘之到衡阳去，在阖庐洲遇到了桓南郡。卞鞠是她的外孙，在桓玄手下，时常来问候她。她对卞鞠说：“我老不死，竟看到这小子父子两代作乱造反！”
注：韩康伯母殷：殷氏，殷浩之姊。
注：绘之：韩绘之，韩康伯之子，官衡阳太守。
注：阖（hé）庐洲：长江中的沙洲名。
注：桓南郡：桓玄，桓温之子，袭封南郡公，后篡晋称帝。
注：竖：小子，骂人的话。
注：二世作贼：指桓温、桓玄父子两代图谋篡逆。
原：在衡阳数年，绘之遇桓景真之难也，殷抚尸哭曰：“汝父昔罢豫章，征书朝至夕发。汝去郡邑数年，为物不得动，遂及于难，夫复何言！”|| 在衡阳住了几年，韩绘之遭遇桓景真作乱被害，殷氏抚着尸体哭道：“你父亲当年卸任豫章太守，征召的文书早上到，他晚上就动身了。你离任郡守已经好几年，却被俗务牵累，不肯离开，终于遭了难，还有什么可说的！”
注：桓景真：桓亮，字景真，桓玄从子。桓玄败亡后，他在湘中起兵作乱，杀害了韩绘之。
注：罢：免职，卸任。
注：豫章：郡名，指韩康伯曾任豫章太守。
注：征书：朝廷征召的文书。
注：为物不得动：被事务、财物牵绊而不能脱身。
