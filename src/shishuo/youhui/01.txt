# 本门导读
题解：“尤悔”取《论语》“言寡尤，行寡悔”之意，指过失与悔恨。本门记魏晋帝王将相、名士文人做错事、说错话之后的愧悔、自责与感叹，王导“我不杀周侯，周侯由我而死”一语最为沉痛。

# 一｜魏文帝忌弟任城王骁壮
原：魏文帝忌弟任城王骁壮，因在卞太后阁共围棋，并啖枣，文帝以毒置诸枣蒂中，自选可食者而进。王弗悟，遂杂进之。既中毒，太后索水救之。帝预敕左右毁瓶罐，太后徒跣趋井，无以汲。须臾，遂卒。复欲害东阿，太后曰：“汝已杀我任城，不得复杀我东阿！”|| 魏文帝曹丕忌恨弟弟任城王曹彰勇猛强悍，趁着两人在卞太后房中一起下棋、吃枣，曹丕事先把毒药放进一些枣子的蒂里，自己挑没毒的吃。任城王没有察觉，有毒没毒的混着都吃了。毒性发作后，太后找水要救他。曹丕早已吩咐左右把瓶瓶罐罐都砸毁了，太后光着脚跑到井边，却没有东西打水。不一会儿，任城王就死了。曹丕又想害东阿王曹植，太后说：“你已经杀了我的任城，不许再杀我的东阿！”
注：魏文帝：曹丕，字子桓，曹操之子，代汉称帝，建立魏国。
注：任城王：曹彰，字子文，曹丕同母弟，勇武善战。骁壮：勇猛健壮。
注：卞太后：曹操之妻，曹丕、曹彰、曹植之母。阁：内室。啖（dàn）：吃。
注：徒跣（xiǎn）：赤着脚。东阿：东阿王曹植，字子建，以文才著称。

# 二｜王浑后妻
原：王浑后妻，琅邪颜氏女。王时为徐州刺史，交礼拜讫，王将答拜，观者咸曰：“王侯州将，新妇州民，恐无由答拜。”王乃止。武子以其父不答拜，不成礼，恐非夫妇，不为之拜，谓为“颜妾”。颜氏耻之，以其门贵，终不敢离。|| 王浑续娶的妻子，是琅邪颜家的女儿。王浑当时任徐州刺史，行交拜礼时，新娘拜完，王浑正要回拜，围观的人都说：“王侯是本州长官，新娘是本州百姓，恐怕没有回拜的道理。”王浑就没有回拜。他的儿子王济认为父亲没有回拜，婚礼就不算完成，恐怕算不得正式夫妻，所以不向她行子女之礼，称她为“颜妾”。颜氏深以为耻，但因王家门第高贵，始终不敢提出离去。
注：王浑：字玄冲，太原晋阳人，西晋大臣，袭封京陵侯。
注：琅邪：郡名，在今山东东南部。交礼：婚礼中新婚夫妇相互交拜。
注：州将：州的长官，即刺史。
注：武子：王济，字武子，王浑之子，西晋名士。

# 三｜陆平原河桥败
原：陆平原河桥败，为卢志所谗，被诛。临刑叹曰：“欲闻华亭鹤唳，可复得乎？”|| 陆机在河桥战败，遭卢志进谗，被处死。临刑时他叹息说：“想再听一听华亭的鹤鸣，还能听得到吗？”
注：陆平原：陆机，字士衡，吴郡吴人，曾任平原内史，西晋著名文学家。
注：河桥败：陆机受成都王司马颖之命统兵讨伐长沙王司马乂，在河桥一带大败。
注：卢志：字子道，成都王司马颖的谋臣，与陆机有隙。
注：华亭鹤唳（lì）：华亭在今上海松江一带，陆氏故里，陆机兄弟入洛前曾在此闲居读书。唳：鹤鸣。

# 四｜刘琨善能招延
原：刘琨善能招延，而拙于抚御。一日虽有数千人归投，其逃散而去，亦复如此，所以卒无所建。|| 刘琨很会招揽人才，却不善于安抚驾驭。一天里虽有几千人来投奔他，逃散离去的也有那么多，所以他终究没能建立什么功业。
注：刘琨：字越石，西晋末任并州刺史，在北方孤军抗击刘渊、石勒，后为段匹磾所杀。
注：招延：招揽延请。抚御：安抚统御。

# 五｜王平子始下
原：王平子始下，丞相语大将军：“不可复使羌人东行。”平子面似羌。|| 王澄刚从荆州东下到建康，丞相王导对大将军王敦说：“不能再让那个羌人往东边来了。”原来王澄长得像羌人。
注：王平子：王澄，曾任荆州刺史。下：顺江东下。
注：丞相：王导。大将军：王敦。二人与王澄同出琅邪王氏，后来王澄果然为王敦所杀。
注：羌人：西北少数民族，此借指相貌似羌的王澄。

# 六｜王大将军起事
原：王大将军起事，丞相兄弟诣阙谢。周侯深忧诸王，始入，甚有忧色。丞相呼周侯曰：“百口委卿！”周直过不应。既入，苦相存救。既释，周大说，饮酒。及出，诸王故在门。周曰：“今年杀诸贼奴，当取金印如斗大系肘后。”|| 大将军王敦起兵作乱，丞相王导带着兄弟子侄到宫门前请罪。周顗很替王家担忧，刚进宫时，脸上满是愁容。王导招呼他说：“我全家百口性命就托付给你了！”周顗径直走过，没有理他。进宫以后，周顗竭力替王家求情救护。皇帝宽免了王家，周顗非常高兴，喝起酒来。等他出宫，王家众人还在门口。周顗说：“今年杀了这班贼子，就能弄个斗大的金印挂在胳膊肘后头。”
注：王大将军：王敦。起事：东晋永昌元年王敦以讨刘隗为名从武昌起兵。
注：诣阙谢：到宫门请罪。周侯：周顗（yǐ），字伯仁，袭爵武城侯，时任尚书左仆射。
注：存救：保全救护。说：通“悦”。
注：故：仍然。金印如斗大系肘后：意谓立大功、封大官，是周顗故作冷语。
原：大将军至石头，问丞相曰：“周侯可为三公不？”丞相不答。又问：“可为尚书令不？”又不应。因云：“如此，唯当杀之耳！”复默然。逮周侯被害，丞相后知周侯救己，叹曰：“我不杀周侯，周侯由我而死，幽冥中负此人！”|| 王敦攻到石头城，问王导：“周顗可以做三公吗？”王导不回答。又问：“可以做尚书令吗？”王导还是不应声。王敦便说：“既然这样，就只有杀掉他了！”王导又沉默不语。等到周顗被害，王导后来才知道周顗曾救过自己，叹息道：“我虽没有亲手杀周侯，周侯却是因我而死，我在九泉之下也对不起这个人！”
注：石头：石头城，在建康西，军事要地。
注：三公：太尉、司徒、司空，朝廷最高官位。尚书令：尚书省长官，执掌政务中枢。
注：逮：及，等到。幽冥：阴间。负：辜负，对不起。

# 七｜王导、温峤俱见明帝
原：王导、温峤俱见明帝，帝问温前世所以得天下之由，温未答。顷，王曰：“温峤年少未谙，臣为陛下陈之。”王乃具叙宣王创业之始，诛夷名族，宠树同己，及文王之末高贵乡公事。明帝闻之，覆面著床曰：“若如公言，祚安得长！”|| 王导、温峤一同进见晋明帝，明帝问温峤前代祖先是怎样得到天下的，温峤没有回答。过了一会儿，王导说：“温峤年轻，不熟悉这些事，让臣来替陛下讲讲。”于是详细讲了宣王司马懿开创基业之初，如何诛灭名门大族，宠信扶植依附自己的人，以及文王司马昭晚年高贵乡公被杀的事。明帝听罢，把脸埋在坐榻上说：“如果真像您说的那样，晋朝的国运怎么能长久呢！”
注：明帝：东晋明帝司马绍。温峤：字太真，东晋重臣。
注：宣王：司马懿，晋朝奠基者，追尊宣帝。诛夷名族：指杀曹爽、何晏等并夷其三族。
注：文王：司马昭，追尊文帝。高贵乡公：魏帝曹髦，率宫人讨司马昭，被成济刺死。
注：著床：贴在坐榻上。祚（zuò）：国运，帝位。

# 八｜王大将军于众坐中曰
原：王大将军于众坐中曰：“诸周由来未有作三公者。”有人答曰：“唯周侯邑五马领头而不克。”大将军曰：“我与周洛下相遇，一面顿尽。值世纷纭，遂至于此！”因为流涕。|| 大将军王敦在众人面前说：“周家历来没有做到三公的。”有人接话说：“只有周侯，好比掷五木已经到了头彩，却差一步没能取胜。”王敦说：“我和周顗在洛阳相识，一见面就倾心相交。偏偏碰上世道混乱，竟弄到这个地步！”说着就为他流下泪来。
注：诸周：周顗家族的人。
注：五马领头而不克：以博戏为喻，五马即五木，古代博具；意谓周顗官位已近三公，却功亏一篑。“邑”字义不明，存疑。
注：洛下：洛阳。一面顿尽：初次见面便倾心相知。纷纭：纷乱。

# 九｜温公初受刘司空使劝进
原：温公初受刘司空使劝进。母崔氏固驻之，峤绝裾而去。迄于崇贵，乡品犹不过也。每爵，皆发诏。|| 温峤当初受司空刘琨派遣，南下劝司马睿即帝位。他母亲崔氏坚决拦阻，温峤扯断衣襟走了。直到他地位尊贵之后，乡里的品评仍然不让他通过。所以每次给他加官晋爵，朝廷都要专门下诏书。
注：温公：温峤。刘司空：刘琨，时为司空。劝进：劝说他人登上帝位，此指劝司马睿称帝。
注：驻：阻止，留住。绝裾（jū）：扯断衣襟，表示决意离去。
注：乡品：魏晋九品中正制下乡里对士人的品评，入仕升迁须凭此。不过：不予通过，因其弃母远行被视为不孝。
注：发诏：特下诏书，以绕过乡品的限制。

# 十｜庾公欲起周子南
原：庾公欲起周子南，子南执辞愈固。庾每诣周，庾从南门入，周从后门出。庾尝一往奄至，周不及去，相对终日。庾从周索食，周出蔬食，庾亦强饭，极欢。并语世故，约相推引，同佐世之任。既仕，至将军二千石，而不称意。中宵慨然曰：“大丈夫乃为庾元规所卖！”一叹，遂发背而卒。|| 庾亮想请周邵出来做官，周邵推辞得越发坚决。庾亮每次去拜访，从南门进来，周邵就从后门溜走。有一回庾亮突然登门，周邵来不及躲开，两人只好对坐了一整天。庾亮向周邵要饭吃，周邵端出粗茶淡饭，庾亮也勉强吃下，谈得十分畅快。两人一起议论世事，约定互相举荐提携，共同担当辅佐朝廷的重任。周邵出仕后，做到将军、郡守，却并不称心。半夜里他感慨地说：“大丈夫竟被庾元规给出卖了！”这一声长叹之后，他背上毒疮发作，就死了。
注：庾公：庾亮，字元规，东晋外戚重臣。起：起用。
注：周子南：周邵，字子南，曾隐居寻阳庐山，后出仕至镇蛮将军、西阳太守。
注：奄（yǎn）至：突然到来。强（qiǎng）饭：勉强吃饭。
注：二千石：汉晋郡守俸禄为二千石，代指郡守一级官员。发背：背部生痈疽。

# 十一｜阮思旷奉大法
原：阮思旷奉大法，敬信甚至。大儿年未弱冠，忽被笃疾。儿既是偏所爱重，为之祈请三宝，昼夜不懈。谓至诚有感者，必当蒙佑。而儿遂不济。于是结恨释氏，宿命都除。|| 阮裕信奉佛法，虔诚到了极点。他的大儿子还不满二十岁，忽然得了重病。这孩子是他特别疼爱看重的，他便为儿子向佛祖祈祷，日夜不停。他以为只要心意至诚，必能感动神明，得到庇佑。可儿子终究没有救活。于是他对佛门怀恨在心，从前信奉的因果宿命之说也全都抛弃了。
注：阮思旷：阮裕，字思旷，东晋名士，阮籍族弟。大法：佛法。
注：弱冠：古代男子二十岁行冠礼，称弱冠。笃疾：重病。
注：三宝：佛教称佛、法、僧为三宝。释氏：佛教，因释迦牟尼得名。
注：宿命：佛教认为今生祸福由前世业因决定的说法。

# 十二｜桓宣武对简文帝
原：桓宣武对简文帝，不甚得语。废海西后，宜自申叙，乃豫撰数百语，陈废立之意。既见简文，简文便泣下数十行。宣武矜愧，不得一言。|| 桓温面对简文帝，不太会说话。废黜海西公以后，他觉得应当亲自向新帝说明原委，就预先准备了几百句话，打算陈述废旧立新的用意。等见到简文帝，简文帝一见面就泪流满面。桓温又窘又愧，一句话也说不出来。
注：桓宣武：桓温，东晋权臣，谥宣武。简文帝：司马昱，由桓温拥立。
注：废海西：桓温废晋帝司马奕为海西公，改立简文帝。申叙：申述说明。
注：豫：同“预”。矜愧：局促羞愧。

# 十三｜桓公卧语曰
原：桓公卧语曰：“作此寂寂，将为文、景所笑。”既而屈起坐曰：“既不能流芳后世，亦不足复遗臭万载邪？”|| 桓温躺着自言自语：“这样默默无闻，将来要被文帝、景帝笑话。”过了一会儿，他猛地坐起来说：“既然不能流芳百世，难道连遗臭万年也做不到吗？”
注：桓公：桓温。寂寂：冷清无为。
注：文、景：晋文帝司马昭、景帝司马师，二人篡魏而为晋室奠基。
注：屈起：猛然起身。屈，通“崛”。

# 十四｜谢太傅于东船行
原：谢太傅于东船行，小人引船，或迟或速，或停或待。又放船从横，撞人触岸。公初不呵谴，人谓公常无嗔喜。曾送兄征西葬还，日莫雨，驶小人皆醉，不可处分。公乃于车中手取车柱撞驭人，声色甚厉。夫以水性沉柔，入隘奔激，方之人情，固知迫隘之地，无得保其夷粹。|| 谢安在会稽乘船出行，船夫拉船，时慢时快，时停时等；有时又任船横冲直撞，撞了人，碰了岸。谢安从来不加呵斥，人们都说谢公向来喜怒不形于色。有一次他给哥哥谢奕送葬回来，天晚下雨，车夫都喝醉了，没法驾车。谢安就在车里拿起车柱去捅车夫，声色十分严厉。水的本性深沉柔和，流进狭窄险要处就会奔腾激荡；拿来比人情，就知道人处在逼仄困窘的境地，也难以保持平和纯粹的心境了。
注：谢太傅：谢安。东：指会稽，在建康以东。小人：仆役，此指船夫。
注：从横：纵横，任意乱行。呵谴：呵斥责备。嗔：发怒。
注：兄征西：谢安之兄谢奕，死后追赠镇西将军，此称“征西”，存疑。莫：同“暮”。
注：驶小人：原书如此，意指驾车的仆人，一本作“驭人”。处分：安排，指挥。夷粹：平和纯正。

# 十五｜简文见田稻
原：简文见田稻，不识，问是何草，左右答是稻。简文还，三日不出，云：“宁有赖其末而不识其本！”|| 简文帝看见田里的稻子，不认识，问这是什么草，侍从回答是稻子。简文帝回去后，三天没出门，说：“哪有靠它的果实活命，却连它的本根都不认得的道理！”
注：简文：晋简文帝司马昱。
注：宁：难道，哪有。末：末梢，指稻米。本：根本，指稻株。

# 十六｜桓车骑在上明畋猎
原：桓车骑在上明畋猎，东信至，传淮上大捷。语左右云：“群谢年少大破贼。”因发病薨。谈者以为此死，贤于让扬之荆。|| 桓冲正在上明打猎，东边来了信使，传来淮上大捷的消息。他对左右说：“谢家那帮年轻人竟大破贼军了。”随即发病去世。议论的人认为他这样死，比当初把扬州让给谢安、自己去荆州还要可贵。
注：桓车骑：桓冲，桓温之弟，官至车骑将军。上明：城名，桓冲镇荆州时所筑，在今湖北松滋一带。畋（tián）猎：打猎。
注：淮上大捷：太元八年谢玄等在淝水大破前秦苻坚。
注：群谢年少：指谢玄、谢琰等谢氏子弟。桓冲原以为他们年少不经事，必败无疑，闻捷后羞惭发病。
注：薨（hōng）：诸侯、高官之死。让扬之荆：桓冲曾把扬州刺史之职让与谢安，自己出镇荆州。“贤于”一语褒贬，旧解不一，存疑。

# 十七｜桓公初报破殷荆州
原：桓公初报破殷荆州，曾讲《论语》，至“富与贵，是人之所欲，不以其道，得之不处”，玄意色甚恶。|| 桓玄刚得到打败殷仲堪的捷报，恰好正在讲《论语》，讲到“富与贵，是人之所欲，不以其道，得之不处”这一句，桓玄的脸色十分难看。
注：桓公：桓玄，桓温之子，后篡晋称帝，旋即败死。殷荆州：殷仲堪，时任荆州刺史，与桓玄先结盟后反目，为其所败。
注：曾：当作“会”，正好。
注：“富与贵”几句：出《论语·里仁》，说富贵人人想要，但不用正道得来，君子不会安享。
