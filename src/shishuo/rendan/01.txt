# 本门导读
题解：任诞，就是任性放诞、不守常规。本门以竹林七贤开篇，多写名士纵酒、居丧不拘礼法、蔑视世俗的言行，其中既有真率与反抗，也有避祸与颓放，是魏晋风度最张扬的一面。

# 一｜陈留阮籍、谯国嵇康
原：陈留阮籍、谯国嵇康、河内山涛，三人年皆相比，康年少亚之。预此契者，沛国刘伶、陈留阮咸、河内向秀、琅邪王戎。七人常集于竹林之下，肆意酣畅，故世谓竹林七贤。|| 陈留的阮籍、谯国的嵇康、河内的山涛，三个人年纪都差不多，嵇康稍稍小一点。参与这个交游圈子的，还有沛国的刘伶、陈留的阮咸、河内的向秀、琅邪的王戎。七个人常常聚在竹林里，随心所欲，痛快饮酒，所以世人称他们为“竹林七贤”。
注：陈留、谯国、河内：皆郡国名，分别在今河南开封一带、安徽亳州一带、河南沁阳一带。
注：相比：相近。亚：次一等，这里指年纪稍小。
注：预此契者：参加这一结交的人。契，意气相投的约会、交情。
注：酣畅：饮酒尽兴。

# 二｜阮籍遭母丧
原：阮籍遭母丧，在晋文王坐，进酒肉。司隶何曾亦在坐，曰：“明公方以孝治天下，而阮籍以重丧，显于公坐饮酒食肉，宜流之海外，以正风教。”文王曰：“嗣宗毁顿如此，君不能共忧之，何谓？且有疾而饮酒食肉，固丧礼也。”籍饮啖不辍，神色自若。|| 阮籍在为母亲服丧期间，在晋文王的席上照样吃酒吃肉。司隶校尉何曾也在座，说：“明公正以孝道治理天下，阮籍身负重丧，却公然在您的席上喝酒吃肉，应当把他流放到边远之地，来端正风俗教化。”文王说：“嗣宗哀伤憔悴到这个地步，你不能和我一起替他担忧，这是什么道理？况且有病时喝酒吃肉，本来就合乎丧礼。”阮籍吃喝不停，神色如常。
注：晋文王：司马昭，曹魏权臣，其子司马炎代魏建晋后追尊为文帝。
注：何曾：字颖考，以讲究礼法、生活奢侈著称，入晋位至太傅。司隶：司隶校尉，督察京畿百官的官。
注：嗣宗：阮籍的字。毁顿：因居丧哀痛而形体消瘦、精神困乏。
注：有疾而饮酒食肉：《礼记·曲礼》有居丧有病可饮酒食肉之说，司马昭借此替阮籍开脱。

# 三｜刘伶病酒
原：刘伶病酒，渴甚，从妇求酒。妇捐酒毁器，涕泣谏曰：“君饮太过，非摄生之道，必宜断之！”伶曰：“甚善。我不能自禁，唯当祝鬼神，自誓断之耳。便可具酒肉。”妇曰：“敬闻命。”供酒肉于神前，请伶祝誓。伶跪而祝曰：“天生刘伶，以酒为名，一饮一斛，五斗解酲。妇人之言，慎不可听！”便引酒进肉，隗然已醉矣。|| 刘伶喝酒伤了身子，口渴得厉害，向妻子要酒。妻子把酒倒掉，把酒器砸了，哭着劝他：“你喝得太过了，这不是养生之道，一定要戒掉！”刘伶说：“好极了。只是我自己管不住自己，只有向鬼神祷告，亲自发誓戒酒才行。你去备办酒肉吧。”妻子说：“遵命。”把酒肉摆到神像前，请刘伶祷告发誓。刘伶跪下祝告说：“天生我刘伶，靠酒活命；一喝就是一斛，再来五斗醒醒酒。女人家的话，千万不能听！”说罢拿起酒就喝，抓起肉就吃，不一会儿已经醉倒了。
注：刘伶：字伯伦，沛国人，竹林七贤之一，以嗜酒闻名，著《酒德颂》。病酒：饮酒过量而致病。
注：捐：抛弃。摄生：保养身体。祝：向神祷告。
注：名：通“命”。斛（hú）：量器，十斗为一斛。酲（chéng）：酒醉后神志不清的病态。
注：隗然：醉倒的样子。隗，读wěi。

# 四｜刘公荣与人饮酒
原：刘公荣与人饮酒，杂秽非类。人或讥之，答曰：“胜公荣者，不可不与饮；不如公荣者，亦不可不与饮；是公荣辈者，又不可不与饮。故终日共饮而醉。”|| 刘昶和人喝酒，酒伴杂七杂八，什么人都有。有人讥讽他，他回答说：“比我公荣强的，不能不同他喝；不如我公荣的，也不能不同他喝；和我公荣同一类的，更不能不同他喝。所以我整天跟人一起喝得大醉。”
注：刘公荣：刘昶，字公荣，沛国人，嗜酒，为人通达。
注：杂秽非类：酒伴混杂，不是同一流品的人。

# 五｜步兵校尉缺
原：步兵校尉缺，厨中有贮酒数百斛，阮籍乃求为步兵校尉。|| 步兵校尉出了缺，听说步兵营的厨房里存着几百斛酒，阮籍就请求去当步兵校尉。
注：步兵校尉：统领宿卫兵的武官。阮籍因此职被后人称为“阮步兵”。

# 六｜刘伶恒纵酒放达
原：刘伶恒纵酒放达，或脱衣裸形在屋中。人见讥之，伶曰：“我以天地为栋宇，屋室为裈衣，诸君何为入我裈中？”|| 刘伶常常纵酒放任，有时在屋里脱光衣服，赤身裸体。有人看见了讥笑他，刘伶说：“我把天地当作房屋，把房屋当作裤子，诸位为什么钻到我裤子里来？”
注：放达：放纵旷达，不拘礼法。
注：栋宇：房屋。裈（kūn）衣：裤子。

# 七｜阮籍嫂尝还家
原：阮籍嫂尝还家，籍见与别。或讥之，籍曰：“礼岂为我辈设也？”|| 阮籍的嫂子有一次回娘家，阮籍去见她，和她道别。有人讥讽他，阮籍说：“礼法难道是为我们这种人定的吗？”
注：还家：指妇人回娘家。
注：礼：古礼有“嫂叔不通问”之说，叔嫂之间不得往来问候，阮籍此举即违此礼。

# 八｜阮公邻家妇有美色
原：阮公邻家妇有美色，当垆酤酒。阮与王安丰常从妇饮酒，阮醉，便眠其妇侧。夫始殊疑之，伺察，终无他意。|| 阮籍邻居家的媳妇长得很美，在酒垆前卖酒。阮籍和王戎常到她那里喝酒，阮籍喝醉了，就躺在那妇人身边睡觉。她丈夫起初很是怀疑，暗中留心观察，发现阮籍始终没有别的意思。
注：当垆：坐在酒垆边卖酒。垆，酒店里安放酒瓮的土台。酤（gū）：卖酒。
注：王安丰：王戎，字濬冲，竹林七贤之一，封安丰侯，故称。
注：伺察：暗中察看。

# 九｜阮籍当葬母
原：阮籍当葬母，蒸一肥豚，饮酒二斗，然后临诀，直言：“穷矣！”都得一号，因吐血，废顿良久。|| 阮籍要安葬母亲时，蒸了一头肥小猪，喝了二斗酒，然后去和母亲遗体诀别，只说了一句：“完了！”总共只哭号了一声，就吐了血，很久都萎靡不振。
注：豚（tún）：小猪。临诀：面对遗体作最后的告别。
注：穷矣：到头了、完了，极言哀痛无路。存疑：或以为当时哭丧有此用语。
注：都：总共。号（háo）：放声大哭。废顿：身心衰竭，委顿不起。

# 十｜阮仲容、步兵居道南
原：阮仲容、步兵居道南，诸阮居道北；北阮皆富，南阮贫。七月七日，北阮盛晒衣，皆纱罗锦绮。仲容家以竿挂大布犊鼻裈于中庭，人或怪之，答曰：“未能免俗，聊复尔耳！”|| 阮咸和阮籍住在大路南边，其他姓阮的住在路北；北边的阮家都富，南边的阮家穷。七月七日，北阮家大晒衣服，全是绫罗绸缎。阮咸却用竹竿在院子里挑起一条粗布短裤。有人觉得奇怪，他回答：“我也免不了俗，姑且这样凑凑热闹罢了！”
注：阮仲容：阮咸，字仲容，阮籍之侄，竹林七贤之一，善弹琵琶。步兵：阮籍。
注：七月七日：当时风俗，此日晾晒衣物书籍，富家借以夸耀。
注：犊鼻裈：一种短裤，形似牛犊之鼻，劳作时所穿。
注：聊复尔耳：姑且也这样做做罢了。

# 十一｜阮步兵丧母
原：阮步兵丧母，裴令公往吊之。阮方醉，散发坐床，箕踞不哭。裴至，下席于地，哭吊喭毕，便去。或问裴：“凡吊，主人哭，客乃为礼。阮既不哭，君何为哭？”裴曰：“阮方外之人，故不崇礼制。我辈俗中人，故以仪轨自居。”时人叹为两得其中。|| 阮籍的母亲去世，裴楷前去吊唁。阮籍正喝醉了，披散着头发坐在床上，两腿叉开，也不哭。裴楷到后，在地上铺了席子坐下，哭过、致过慰问，就走了。有人问裴楷：“凡是吊丧，主人先哭，客人才行礼。阮籍既然不哭，您为什么要哭？”裴楷说：“阮籍是超脱世外的人，所以不尊崇礼制；我们是世俗中人，所以按礼仪规矩来要求自己。”当时人赞叹两人都做得恰如其分。
注：裴令公：裴楷，字叔则，河东闻喜人，官至中书令，故称令公；以风神俊朗著称。
注：箕踞（jī jù）：两腿伸开而坐，形如簸箕，被视为傲慢无礼的坐姿。
注：喭（yàn）：同“唁”，慰问死者家属。
注：方外：世俗礼法之外。仪轨：礼仪规范。

# 十二｜诸阮皆能饮酒
原：诸阮皆能饮酒，仲容至宗人间共集，不复用常杯斟酌，以大瓮盛酒，围坐，相向大酌。时有群猪来饮，直接去上，便共饮之。|| 阮家人都能喝酒。阮咸到族人那里聚会，不再用平常的杯子斟酒，而是拿大瓮盛酒，大家围坐，面对面地狂饮。当时有一群猪也来喝，阮咸他们直接凑上去，就跟猪一起喝了。
注：宗人：同族的人。斟酌：斟酒饮酒。
注：直接去上：径直凑上前去。存疑：一说“接去上”指把猪喝过的上层酒撇掉。

# 十三｜阮浑长成
原：阮浑长成，风气韵度似父，亦欲作达。步兵曰：“仲容已预之，卿不得复尔。”|| 阮浑长大成人，风度气质很像父亲，也想学着放达任性。阮籍说：“仲容已经加入我们这一伙了，你不能再这样。”
注：阮浑：字长成，阮籍之子，西晋时官至太子中庶子。
注：作达：做放达不拘的事。预：参与。

# 十四｜裴成公妇，王戎女
原：裴成公妇，王戎女。王戎晨往裴许，不通径前。裴从床南下，女从北下，相对作宾主，了无异色。|| 裴頠的妻子是王戎的女儿。王戎一大早到裴家去，不经通报就径直进了内室。裴頠从床的南边下来，女儿从床的北边下来，与王戎相对，行宾主之礼，脸上一点异样的神色都没有。
注：裴成公：裴頠（wěi），字逸民，裴楷之侄，西晋名臣，著《崇有论》，死后谥“成”。
注：许：处所。不通：不经通报。了无：毫无。

# 十五｜阮仲容先幸姑家鲜卑婢
原：阮仲容先幸姑家鲜卑婢，及居母丧，姑当远移，初云当留婢，既发，定将去。仲容借客驴，著重服，自追之。累骑而返，曰：“人种不可失！”即遥集之母也。|| 阮咸早先宠爱姑母家的一个鲜卑族婢女。等到他为母亲守丧时，姑母要搬到远方去，起初说要把婢女留下，临出发时，终究还是带走了。阮咸借了客人的驴，穿着孝服，亲自去追。两人同骑一头驴回来，他说：“人种可不能丢！”这婢女就是阮遥集的母亲。
注：幸：宠爱。鲜卑：古代北方民族名。
注：定将去：最终还是带走了。将，带。重服：为父母服丧所穿的重孝之服。
注：累骑：两人同乘一骑。
注：遥集：阮孚，字遥集，阮咸之子。

# 十六｜任恺既失权势
原：任恺既失权势，不复自检括。或谓和峤曰：“卿何以坐视元裒败而不救？”和曰：“元裒如北夏门，拉攞自欲坏，非一木所能支。”|| 任恺失去权势以后，不再约束自己。有人对和峤说：“你为什么眼看着元裒败落下去却不救他？”和峤说：“元裒就像北夏门，自己已经要塌了，不是一根木头撑得住的。”
注：任恺：字元裒（póu），西晋武帝时历任侍中、吏部尚书等职，后为贾充所排挤，失意而终。
注：检括：检点约束。和峤：字长舆，西晋大臣，与任恺交好。
注：北夏门：洛阳城北面的城门。
注：拉攞（lā luó）：折裂崩坏的样子。攞，书中印作“扌”旁加“罗”的简化字形，此录作通行字形。

# 十七｜刘道真少时
原：刘道真少时，常渔草泽，善歌啸，闻者莫不留连。有一老妪，识其非常人，甚乐其歌啸，乃杀豚进之。道真食豚尽，了不谢。妪见不饱，又进一豚。食半余半，乃还之。后为吏部郎，妪儿为小令史，道真超用之。不知所由，问母，母告之。于是赍牛酒诣道真，道真曰：“去，去！无可复用相报。”|| 刘宝年轻时，常在荒野湖泽里打鱼，擅长歌唱长啸，听到的人无不流连忘返。有个老妇人看出他不是寻常人，又很喜欢听他歌啸，就杀了一头小猪送给他吃。刘宝把猪吃了个精光，一句谢也没说。老妇人见他没吃饱，又送上一头。这回他吃了一半，剩下一半，就还给了老妇人。后来刘宝当了吏部郎，老妇人的儿子是个小令史，刘宝破格提拔了他。那儿子不知是什么缘故，问母亲，母亲告诉了他。于是他带着牛肉和酒去拜见刘宝，刘宝说：“走吧，走吧！没什么可再拿来报答的了。”
注：刘道真：刘宝，字道真，高平人，西晋时历任吏部郎、安北将军等职。
注：歌啸：歌唱、吹口哨般地长啸，为当时名士所好。
注：令史：官府中掌管文书的低级吏员。超用：越级提拔。
注：赍（jī）：携带。诣：前往拜见。

# 十八｜阮宣子常步行
原：阮宣子常步行，以百钱挂杖头，至酒店，便独酣畅，虽当世贵盛，不肯诣也。|| 阮修常常步行外出，把一百文钱挂在手杖头上，走到酒店，就一个人痛快地喝起来。即使是当时的权贵显要，他也不肯去拜访。
注：阮宣子：阮修，字宣子，阮籍的族侄，西晋名士，善清谈，不营世务。
注：贵盛：地位尊贵、权势显赫的人。

# 十九｜山季伦为荆州
原：山季伦为荆州，时出酣畅，人为之歌曰：“山公时一醉，径造高阳池，日莫倒载归，茗艼无所知。复能乘骏马，倒著白接䍦，举手问葛彊，何如并州儿？”高阳池在襄阳。彊是其爱将，并州人也。|| 山简任荆州刺史时，常常出门痛饮。有人为他编了首歌：“山公时常要一醉，直奔高阳池而去；日落时横躺在车里回来，醉得什么都不知道。有时还能骑骏马，白头巾反戴在头上；举手问那葛彊：比你这并州小伙怎么样？”高阳池在襄阳。葛彊是他的爱将，并州人。
注：山季伦：山简，字季伦，山涛之子，西晋末镇守襄阳，好酒。
注：高阳池：襄阳的一处园池，山简常在此饮酒，借用汉初“高阳酒徒”郦食其的典故命名。
注：日莫：即“日暮”。倒载：醉卧于车中。茗艼（mǐng dǐng）：即“酩酊”，大醉。
注：倒著白接䍦（lí）：把白色头巾反戴着。接䍦，一种头巾帽。并州：今山西一带，以出勇武之士著称。

# 二十｜张季鹰纵任不拘
原：张季鹰纵任不拘，时人号为“江东步兵”。或谓之曰：“卿乃可纵适一时，独不为身后名邪？”答曰：“使我有身后名，不如即时一杯酒！”|| 张翰放纵任性、不受拘束，当时人称他为“江东步兵”。有人对他说：“你尽可以图一时的快活，难道就不为死后的名声着想吗？”他回答：“让我有死后的名声，还不如眼前一杯酒！”
注：张季鹰：张翰，字季鹰，吴郡吴县人，曾在齐王司马冏手下任职，见时局将乱，借思念家乡莼菜鲈鱼辞官归隐。
注：江东步兵：意谓江东的阮籍（阮步兵）。
注：乃可：尽可以。独：难道。身后名：死后的名声。

# 二十一｜毕茂世云
原：毕茂世云：“一手持蟹螯，一手持酒杯，拍浮酒池中，便足了一生。”|| 毕卓说：“一手拿着蟹钳，一手端着酒杯，在酒池里游来游去，这一辈子就心满意足了。”
注：毕茂世：毕卓，字茂世，东晋初人，曾任吏部郎，嗜酒放达，曾夜间偷饮邻家酒而被缚。
注：蟹螯（áo）：蟹的大钳。拍浮：游水。

# 二十二｜贺司空入洛赴命
原：贺司空入洛赴命，为太孙舍人，经吴阊门，在船中弹琴。张季鹰本不相识，先在金阊亭，闻弦甚清，下船就贺，因共语，便大相知说。问贺：“卿欲何之？”贺曰：“入洛赴命，正尔进路。”张曰：“吾亦有事北京，因路寄载。”便与贺同发。初不告家，家追问乃知。|| 贺循到洛阳去接受任命，做太孙舍人，途经吴县阊门，在船里弹琴。张翰本来不认识他，事先正在金阊亭上，听到琴声很清越，就下到船上去找贺循，于是两人交谈起来，彼此十分投契欣赏。张翰问贺循：“您要到哪里去？”贺循说：“到洛阳去就任，正在赶路。”张翰说：“我也有事要去京城，顺路搭你的船吧。”就跟贺循一起出发了。他起初没告诉家里，家人追问才知道。
注：贺司空：贺循，字彦先，会稽山阴人，东晋时官至太常，死后追赠司空。
注：太孙舍人：太孙属官。存疑：有学者认为当作“太子舍人”。
注：阊门：吴县（今苏州）西城门。金阊亭：阊门外的亭子。
注：知说：相知而喜悦。说，同“悦”。北京：指北方的京城洛阳，二人皆吴人，故云。

# 二十三｜祖车骑过江时
原：祖车骑过江时，公私俭薄，无好服玩。王、庾诸公共就祖，忽见裘袍重叠，珍饰盈列。诸公怪问之，祖曰：“昨夜复南塘一出。”祖于时恒自使健儿鼓行劫钞，在事之人亦容而不问。|| 祖逖刚渡江南来时，官府私家都很贫乏，没有什么好的衣物玩好。王导、庾亮等人一同去看望祖逖，忽然看见他那里皮袍堆了一层又一层，珍宝饰物摆满了一排排。诸公奇怪地问他，祖逖说：“昨晚又去南塘走了一趟。”祖逖当时常常让手下壮士明目张胆地去抢劫，当权的人也容忍他，不加追问。
注：祖车骑：祖逖，字士稚，范阳遒县人，东晋初北伐名将，死后追赠车骑将军。
注：王、庾：王导、庾亮，东晋初执政重臣。服玩：衣服和玩赏之物。
注：南塘：建康秦淮河南岸一带地名。
注：鼓行：公然大张旗鼓地行动。劫钞：抢劫掠夺。在事之人：当政者。

# 二十四｜鸿胪卿孔群好饮酒
原：鸿胪卿孔群好饮酒，王丞相语云：“卿何为恒饮酒？不见酒家覆瓿布，日月糜烂？”群曰：“不尔。不见糟肉乃更堪久？”群尝书与亲旧：“今年田得七百斛秫米，不了麹糵事。”|| 鸿胪卿孔群爱喝酒，王丞相对他说：“你为什么老喝酒？没看见酒家盖酒坛的布，日子一久就烂掉了吗？”孔群说：“不是这样。没看见用酒糟腌过的肉反而更经放吗？”孔群曾写信给亲友说：“今年田里收了七百斛秫米，还不够酿酒用的。”
注：鸿胪卿：掌管朝会礼仪的官。孔群：字敬林，会稽山阴人，东晋时官至御史中丞，嗜酒。
注：王丞相：王导。瓿（bù）：小瓮，盛酒的陶器。
注：秫（shú）米：黏高粱，可酿酒。
注：不了：不够。麹糵（qū niè）：酒曲，代指酿酒。

# 二十五｜有人讥周仆射
原：有人讥周仆射与亲友言戏秽杂无检节。周曰：“吾若万里长江，何能不千里一曲。”|| 有人讥讽周顗和亲友说笑时言语污秽杂乱，毫不检点。周顗说：“我好比万里长江，哪能不千里拐一个弯呢。”
注：周仆射（yè）：周顗（yǐ），字伯仁，东晋初官至尚书左仆射，以嗜酒、雅量著称，后为王敦所杀。
注：秽杂：粗俗下流。检节：检点节制。

# 二十六｜温太真位未高时
原：温太真位未高时，屡与扬州、淮中估客樗蒱，与辄不竞。尝一过大输物，戏屈，无因得反。与庾亮善，于舫中大唤亮曰：“卿可赎我！”庾即送直，然后得还。经此数四。|| 温峤官位还不高的时候，屡次和扬州、淮河一带的行商赌樗蒱，一赌就输。有一回输得很惨，赌本输光，没办法回去。他和庾亮交好，就在船上大声喊庾亮：“你快来赎我！”庾亮立刻送钱过来，他这才得以回去。这样的事有过好几次。
注：温太真：温峤，字太真，太原祁县人，东晋名臣，平定苏峻之乱有功。
注：估客：往来贩运的商人。樗蒱（chū pú）：古代一种掷采赌博的游戏。
注：不竞：不能取胜。一过：一次、一局。戏屈：赌输了。反：同“返”。
注：直：同“值”，指赎金。数四：好几次。
