# 二十七｜温公喜慢语
原：温公喜慢语，卞令礼法自居。至庾公许，大相剖击，温发口鄙秽，庾公徐曰：“太真终日无鄙言。”|| 温峤说话喜欢随随便便、出言不逊，卞壸却以恪守礼法自命。两人到庾亮那里，互相激烈攻驳，温峤张口就是粗俗难听的话，庾亮慢条斯理地说：“太真一整天可没说过一句粗话。”
注：温公：温峤，字太真，东晋初名臣，平苏峻之乱有大功。慢语：轻慢放肆、不拘礼数的话。
注：卞令：卞壸（kǔn），字望之，官至尚书令，以严守礼法著称，苏峻之乱中战死。
注：许：处所，“庾公许”即庾亮那里。剖击：剖析攻驳，互相辩难。
注：太真终日无鄙言：庾亮故意反说，以调侃温峤满口粗话，兼为之解围。

# 二十八｜周伯仁风德雅重
原：周伯仁风德雅重，深达危乱。过江积年，恒大饮酒，尝经三日不醒。时人谓之“三日仆射”。|| 周顗风度品德端雅持重，深知时局的危乱。渡江南下多年，他总是狂饮，曾经一连三天醉卧不醒。当时的人称他为“三日仆射”。
注：周伯仁：周顗（yǐ），字伯仁，东晋初官至尚书左仆射，后为王敦所杀。
注：深达危乱：深刻洞察时势的危险动乱。达，通晓。
注：过江：指西晋末中原士族随晋室渡江南迁。

# 二十九｜卫君长为温公长史
原：卫君长为温公长史，温公甚善之，每率尔提酒脯就卫，箕踞相对弥日。卫往温许亦尔。|| 卫永做温峤的长史，温峤和他十分要好，常常兴之所至，提着酒和干肉就到卫永那里，两人叉开腿对坐，一喝就是一整天。卫永去温峤那里也是这样。
注：卫君长：卫永，字君长，曾任温峤的长史，官至左军长史。
注：率尔：随兴而为，不拘形式。脯：干肉。
注：箕踞：两腿叉开平伸而坐，形如簸箕，是不拘礼节的坐姿。弥日：整日。

# 三十｜苏峻乱
原：苏峻乱，诸庾逃散。庾冰时为吴郡，单身奔亡。民吏皆去，唯郡卒独以小船载冰出钱塘口，籧篨覆之。时峻赏募觅冰，属所在搜检甚急。卒舍船市渚，因饮酒醉，还，舞棹向船曰：“何处觅庾吴郡，此中便是！”冰大惶怖，然不敢动。监司见船小装狭，谓卒狂醉，都不复疑。|| 苏峻作乱时，庾氏兄弟四散逃亡。¦庾冰当时任吴郡太守，孤身一人出逃。¦百姓和属吏都走光了，只有郡里一个差役独自用小船载着庾冰逃出钱塘江口，用粗竹席把他盖住。¦当时苏峻悬赏缉拿庾冰，嘱咐各地搜查得很紧。¦那差役把船停下，上江中小洲去买东西，趁机喝醉了酒，回来时挥舞着船桨对着船说：“到哪儿去找庾吴郡？这里头就是！”¦庾冰吓得魂飞魄散，可一动也不敢动。¦巡查的官员见船又小又窄，以为是差役发酒疯，一点也不再怀疑。
注：苏峻乱：东晋成帝咸和二年（327），苏峻以讨伐庾亮为名起兵，攻入建康。诸庾：庾亮、庾冰等庾氏兄弟。
注：庾冰：字季坚，庾亮之弟，时任吴郡太守，后官至车骑将军。
注：籧篨（qú chú）：用竹或苇编成的粗席。属：通“嘱”，嘱令。
注：市渚：到水中小洲上买东西。监司：负责督察搜捕的官吏。
原：自送过淛江，寄山阴魏家，得免。后事平，冰欲报卒，适其所愿。卒曰：“出自厮下，不愿名器。少苦执鞭，恒患不得快饮酒。使其酒足余年，毕矣。无所复须。”冰为起大舍，市奴婢，使门内有百斛酒，终其身。时谓此卒非唯有智，且亦达生。|| 那差役亲自把庾冰送过浙江，寄住在山阴魏家，庾冰才得以脱险。¦后来乱事平定，庾冰想报答他，打算满足他的心愿。¦差役说：“我出身低贱，不想要什么官爵名位。¦从小就苦于给人当差，常常遗憾不能痛痛快快地喝酒。¦要是能让我下半辈子酒喝个够，就心满意足了，¦别的什么都不要。”¦庾冰便替他盖了大房子，买了奴婢，让他家里常存上百斛酒，一直养到他终老。¦当时人说这个差役不但有智谋，而且看透了人生。
注：淛（zhè）江：即浙江，今钱塘江。山阴：县名，今浙江绍兴。
注：厮下：干杂役的卑贱之人。名器：爵位名号与车服仪制，代指官位。
注：执鞭：为人驾车，泛指受人驱使的贱役。斛：量器，十斗为一斛。
注：达生：通达人生之理，不为外物所累。

# 三十一｜殷洪乔作豫章郡
原：殷洪乔作豫章郡，临去，都下人因附百许函书。既至石头，悉掷水中，因祝曰：“沉者自沉，浮者自浮，殷洪乔不能作致书邮！”|| 殷羡出任豫章太守，临走时，京城里的人托他捎带了一百来封书信。走到石头城，他把信全都扔进江里，还念叨说：“该沉的自己沉，该浮的自己浮，我殷洪乔可不能替人当送信的差役！”
注：殷洪乔：殷羡，字洪乔，殷浩之父，官至豫章太守、光禄勋。
注：都下：京城建康。函：封，书信的量词。
注：石头：石头城，在建康西，临长江。祝：祝告，念念有词。致书邮：递送书信的邮差。

# 三十二｜王长史、谢仁祖同为王公掾
原：王长史、谢仁祖同为王公掾，长史云：“谢掾能作异舞。”谢便起舞，神意甚暇。王公熟视，谓客曰：“使人思安丰。”|| 王濛和谢尚一同在王导手下做掾属，王濛说：“谢掾会跳一种奇特的舞。”谢尚当即起身跳舞，神情从容自若。王导仔细看了一会儿，对客人说：“真叫人想起王安丰来。”
注：王长史：王濛，字仲祖，官至司徒左长史。谢仁祖：谢尚，字仁祖，谢安从兄，通音乐，善舞。
注：王公：王导。掾（yuàn）：公府的属官。暇：从容不迫。
注：安丰：王戎，封安丰县侯，竹林七贤之一，以任达洒脱著称。

# 三十三｜王、刘共在杭南
原：王、刘共在杭南，酣宴于桓子野家。谢镇西往尚书墓还，葬后三日反哭。诸人欲要之，初遣一信，犹未许，然已停车；重要，便回驾。诸人门外迎之，把臂便下。裁得脱帻，著帽酣宴。半坐，乃觉未脱衰。|| 王濛、刘惔一起在朱雀桥南，在桓伊家里畅饮。谢尚从谢尚书墓上回来，这是下葬后第三天的反哭之礼。大家想邀他来喝酒，先派了一个人去请，他还没答应，不过已经把车停了下来；再派人去请，他就掉转车头过来了。众人到门外迎接，他挽着人家的胳膊就下了车。刚刚摘下头巾，戴上便帽就痛饮起来。喝到一半，才发觉身上的丧服还没脱。
注：王、刘：王濛、刘惔。杭南：朱雀航之南，建康城中士族聚居之地。航，浮桥。
注：桓子野：桓伊，字叔夏，小字子野，善音乐，东晋时官至护军将军。
注：谢镇西：谢尚，官至镇西将军。尚书：谢裒，谢尚的叔父，官至吏部尚书。反哭：古丧礼，下葬后迎神主回家而哭。
注：要（yāo）：邀请。信：使者。裁：通“才”。帻（zé）：头巾。衰（cuī）：丧服。

# 三十四｜桓宣武少家贫
原：桓宣武少家贫，戏大输，债主敦求甚切。思自振之方，莫知所出。陈郡袁耽俊迈多能，宣武欲求救于耽。耽时居艰，恐致疑，试以告焉，应声便许，略无嫌吝。|| 桓温年轻时家里穷，赌博输得很惨，债主催逼得很紧。他想找个翻身的办法，却想不出来。陈郡的袁耽英爽豪迈，多才多艺，桓温想向他求救。袁耽当时正在守丧，桓温怕他为难，试着把事情告诉他，袁耽一听就答应了，一点都没有推托迟疑。
注：桓宣武：桓温，谥宣武。戏：博戏，赌博。敦求：催逼讨债。
注：袁耽：字彦道，陈郡阳夏人，豪爽多才，善博戏，官至从事中郎。
注：居艰：居丧守孝。嫌吝：嫌弃吝惜，指为难推辞。
原：遂变服，怀布帽，随温去与债主戏。耽素有蓺名，债主就局，曰：“汝故当不办作袁彦道邪？”遂共戏。十万一掷，直上百万数，投马绝叫，傍若无人，探布帽掷对人曰：“汝竟识袁彦道不？”|| 他于是脱下孝服换了装，怀里揣着孝帽，跟着桓温去和债主赌。袁耽向来以赌技出名，债主上了赌局，说：“你总不至于是袁彦道吧？”于是一起赌起来。一掷就是十万，一路涨到百万之数，袁耽掷下筹码，放声大叫，旁若无人，从怀里掏出布帽朝对方扔过去，说：“你到底认不认得袁彦道？”
注：变服：脱去丧服，换上常服。布帽：居丧时戴的帽子。
注：蓺（yì）名：技艺上的名声，蓺同“艺”。故当不办：总该办不到，意为“总不会是”。
注：马：樗蒲等博戏中用来计胜负的筹码。绝叫：大声呼叫。

# 三十五｜王光禄云
原：王光禄云：“酒正使人人自远。”|| 王蕴说：“酒真能让每个人都把自己忘掉。”
注：王光禄：王蕴，字叔仁，太原晋阳人，孝武帝王皇后之父，官至光禄大夫，好饮酒。
注：正：真正，的确。自远：远离自我，忘却自身的拘束。一说远离尘俗，存疑。

# 三十六｜刘尹云
原：刘尹云：“孙承公狂士，每至一处，赏玩累日，或回至半路却返。”|| 刘惔说：“孙承公是个狂放之士，每到一个地方，总要游赏好几天，有时已经往回走到半路，又掉头回去。”
注：刘尹：刘惔，字真长，官至丹阳尹。
注：孙承公：孙统，字承公，孙楚之孙，孙绰之兄，性好山水，放诞不羁。

# 三十七｜袁彦道有二妹
原：袁彦道有二妹：一适殷渊源，一适谢仁祖。语桓宣武云：“恨不更有一人配卿！”|| 袁耽有两个妹妹：一个嫁给了殷浩，一个嫁给了谢尚。他对桓温说：“可惜没有再多一个妹妹许配给你！”
注：袁彦道：袁耽。适：女子出嫁。
注：殷渊源：殷浩，字渊源，清谈名家，后与桓温相争失势。谢仁祖：谢尚。
注：恨不更有一人配卿：袁耽与桓温为赌友，交情深厚，故有此戏言。

# 三十八｜桓车骑在荆州
原：桓车骑在荆州，张玄为侍中，使至江陵，路经阳岐村。俄见一人持半小笼生鱼，径来造船，云：“有鱼欲寄作脍。”张乃维舟而纳之，问其姓字，称是刘遗民。张素闻其名，大相忻待。刘既知张衔命，问：“谢安、王文度并佳不？”张甚欲话言，刘了无停意。|| 桓冲镇守荆州时，张玄任侍中，奉命出使江陵，途经阳岐村。忽然看见一个人提着小半笼活鱼，径直来到船边，说：“有些鱼，想托你们切成鱼脍。”张玄就系住船请他上来，问他姓名，他自称是刘遗民。张玄素来听说过他的名声，非常高兴地接待他。刘遗民知道张玄身负使命，问道：“谢安、王文度都还好吧？”张玄很想同他好好聊聊，刘遗民却全无久留的意思。
注：桓车骑：桓冲，桓温之弟，官至车骑将军，时任荆州刺史。张玄：张玄之，字祖希，以才学知名。
注：脍（kuài）：切得很细的鱼肉。维舟：系船停泊。
注：刘遗民：刘驎之，字子骥，南阳人，隐居阳岐，屡征不就。忻：同“欣”。衔命：奉命。
注：王文度：王坦之，字文度，与谢安同掌朝政。
原：既进脍，便去，云：“向得此鱼，观君船上当有脍具，是故来耳。”于是便去。张乃追至刘家。为设酒，殊不清旨，张高其人，不得已而饮之。方共对饮，刘便先起，云：“今正伐荻，不宜久废。”张亦无以留之。|| 鱼脍一端上来，他就要走，说：“刚才弄到这些鱼，估计您船上该有切脍的刀具，所以才来的。”说完就走了。张玄于是追到刘家。刘遗民为他摆酒，酒却很不清醇，张玄敬重他的为人，只好勉强喝下。两人刚对饮起来，刘遗民就先站起身，说：“眼下正是割荻草的时候，不该耽搁太久。”张玄也没有办法留住他。
注：向：刚才。清旨：清醇甘美。
注：高其人：推重他的人品。荻（dí）：多年生草本，形似芦苇，可编织或作燃料。

# 三十九｜王子猷诣郗雍州
原：王子猷诣郗雍州，雍州在内。见有毾㲪，云：“阿乞那得此物？”令左右送还家。郗出觅之，王曰：“向有大力者负之而趋。”郗无忤色。|| 王徽之去拜访郗恢，郗恢在内室。王徽之看见一条毛毯，说：“阿乞哪儿弄来这东西？”就叫随从送回自己家去。郗恢出来找毛毯，王徽之说：“刚才有个大力士背着它跑了。”郗恢脸上一点不高兴的样子都没有。
注：王子猷：王徽之，字子猷，王羲之之子，性任诞。诣：拜访。
注：郗雍州：郗恢，字道胤，小字阿乞，曾任雍州刺史。
注：毾㲪（tà dēng）：从西域传入的精细毛毯，颇为珍贵。
注：向有大力者负之而趋：化用《庄子·大宗师》“夜半有力者负之而走”之语，以玩笑掩饰。忤色：不悦的脸色。

# 四十｜谢安始出西
原：谢安始出西，戏，失车牛，便杖策步归。道逢刘尹，语曰：“安石将无伤？”谢乃同载而归。|| 谢安刚到京城时，赌博输掉了车和牛，只好拄着手杖走回家。路上碰见刘惔，刘惔对他说：“安石该不会受伤了吧？”谢安就搭他的车一同回去了。
注：出西：指离开会稽，西赴京城建康。戏：赌博。
注：杖策：拄着手杖。刘尹：刘惔。
注：安石：谢安的字。将无：莫非，恐怕，六朝习用的揣测语气。伤：一说指身体受伤，一说指心情受挫，存疑。

# 四十一｜襄阳罗友有大韵
原：襄阳罗友有大韵，少时多谓之痴。尝伺人祠，欲乞食，往太蚤，门未开。主人迎神出见，问以非时何得在此，答曰：“闻卿祠，欲乞一顿食耳。”遂隐门侧，至晓得食便退，了无怍容。|| 襄阳罗友很有不同寻常的风致，年轻时人们多说他痴呆。他曾经打听到有人家祭祀，想去讨顿饭吃，去得太早，人家门还没开。主人出门迎神时看见了他，问他不到时候怎么就在这里，他回答说：“听说您家祭祀，想讨一顿饭吃罢了。”于是躲在门边，等到天亮讨得了食物就走，一点惭愧的神色都没有。
注：罗友：字宅仁，襄阳人，嗜酒放达，为桓温所器重，官至襄阳太守，历广、益二州刺史。韵：风度气韵。
注：伺：探听。祠：祭祀。蚤：通“早”。
注：怍（zuò）容：羞愧的脸色。
原：为人有记功，从桓宣武平蜀，按行蜀城阙观宇，内外道陌广狭，植种果竹多少，皆默记之。后宣武漂洲与简文集，友亦预焉。共道蜀中事，亦有所遗忘，友皆名列，曾无错漏。宣武验以蜀城阙簿，皆如其言，坐者叹服。谢公云：“罗友讵减魏阳元。”|| 他记性极好，随桓温平定蜀地时，巡视蜀城的城楼宫观，城内外道路的宽窄，栽种果树竹子的多少，都默默记在心里。后来桓温在溧洲与简文帝聚会，罗友也在座。大家一起谈起蜀中旧事，有些地方记不清了，罗友都一一列出名目，没有一点差错遗漏。桓温拿蜀城的簿籍来核对，全都和他说的一样，在座的人无不叹服。谢安说：“罗友哪里比魏阳元差呢！”
注：记功：记忆的本领。按行：巡视。阙观：城楼宫观。
注：漂洲：当作“溧洲”，长江中小洲名，书中原文作“漂洲”，照录。简文：晋简文帝司马昱，时为相王。
注：讵（jù）减：哪里比……差。魏阳元：魏舒，字阳元，西晋任城人，官至司徒，少时亦被人目为迟钝，后显达。
原：后为广州刺史，当之镇，刺史桓豁语令莫来宿，答曰：“民已有前期，主人贫，或有酒馔之费，见与甚有旧。请别日奉命。”征西密遣人察之，至夕乃往荆州门下书佐家，处之怡然，不异胜达。在益州，语儿云：“我有五百人食器。”家中大惊，其由来清，而忽有此物，定是二百五十沓乌樏。|| 后来他出任广州刺史，将要赴任时，荆州刺史桓豁让他傍晚来自己府里住宿，他回答说：“下民已经先有约了，那家主人贫寒，也许为我破费了酒菜，他和我交情很深。请容我改天再来领命。”桓豁暗中派人去察看，到了傍晚，罗友竟是去了荆州府里一个书佐家，在那里怡然自得，和对待名流显贵毫无两样。他在益州时，对儿子说：“我有够五百人用的食器。”家里人大吃一惊，他向来清廉，怎么忽然有了这么多东西，原来是二百五十套黑漆食盒。
注：当之镇：将要前往任所。桓豁：桓温之弟，时任荆州刺史，后进号征西将军，故下称“征西”。莫：通“暮”，傍晚。
注：民：罗友为荆州属地之人，对荆州刺史自称“民”以示谦卑。前期：事先的约定。
注：书佐：州郡中掌文书的低级小吏。胜达：名流显达之人。
注：沓（tà）：量词，一套为一沓。樏（lěi）：分格的食盒。乌樏即黑漆食盒，一套两格，故二百五十沓可供五百人。

# 四十二｜桓子野每闻清歌
原：桓子野每闻清歌，辄唤“奈何”。谢公闻之，曰：“子野可谓一往有深情。”|| 桓伊每次听到清越的歌声，总要连声叫“奈何”。谢安听说后，说：“子野真可以说是一往情深。”
注：桓子野：桓伊。清歌：清亮悠扬的歌声，一说指挽歌。
注：奈何：叹息之词，犹言“怎么办”“可怎么好”，表示情不自禁。
注：谢公：谢安。

# 四十三｜张湛好于斋前种松柏
原：张湛好于斋前种松柏。时袁山松出游，每好令左右作挽歌。时人谓“张屋下陈尸，袁道上行殡”。|| 张湛喜欢在书斋前栽种松柏。当时袁山松出外游玩，常常爱让随从唱挽歌。当时的人说：“张湛是屋檐下停放尸首，袁山松是大路上出殡送葬。”
注：张湛：字处度，东晋高平人，官至中书郎，注有《列子》。松柏：古人多植于坟墓，故时人以此相讥。
注：袁山松：一作袁崧，陈郡阳夏人，好音乐，官至吴郡太守，孙恩之乱中遇害。
注：挽歌：送葬时唱的哀歌。殡：出殡送葬。

# 四十四｜罗友作荆州从事
原：罗友作荆州从事，桓宣武为王车骑集别。友进，坐良久，辞出，宣武曰：“卿向欲咨事，何以便去？”答曰：“友闻白羊肉美，一生未曾得吃，故冒求前耳，无事可咨。今已饱，不复须驻。”了无惭色。|| 罗友做荆州从事时，桓温为王洽设宴饯行。罗友进来，坐了很久，告辞出去，桓温说：“你刚才说有事要请教，怎么就走了？”罗友回答说：“我听说白羊肉味美，这辈子还没吃过，所以冒昧求见，其实没什么事要请教。如今已经吃饱，不必再待下去了。”脸上毫无惭愧之色。
注：从事：州刺史的属官。王车骑：王洽，字敬和，王导之子，官至中书令；称“车骑”当与其所任或所赠官号有关，存疑。集别：聚会饯别。
注：向：刚才。咨事：请示公事。求前：请求进见。
注：驻：停留。

# 四十五｜张驎酒后
原：张驎酒后，挽歌甚凄苦。桓车骑曰：“卿非田横门人，何乃顿尔至致？”|| 张湛喝了酒之后唱挽歌，唱得非常凄凉悲苦。桓冲说：“你又不是田横的门客，怎么一下子悲伤到这种地步？”
注：张驎：张湛，小字驎。桓车骑：桓冲。
注：田横：秦末齐国贵族，曾自立为齐王，汉初不愿称臣，自杀，其门客作挽歌以寄哀思，相传《薤露》《蒿里》即由此而来。
注：顿尔：突然这样。至致：到达极点，一作“至到”，存疑。

# 四十六｜王子猷尝暂寄人空宅住
原：王子猷尝暂寄人空宅住，便令种竹。或问：“暂住何烦尔？”王啸咏良久，直指竹曰：“何可一日无此君？”|| 王徽之曾经暂时借住在别人的空宅里，一住进去就叫人种竹子。有人问：“只是暂住，何必这样费事？”王徽之吟啸良久，径直指着竹子说：“怎么能一天没有这位先生呢？”
注：王子猷：王徽之。烦尔：如此麻烦。
注：啸咏：撮口长啸、吟咏诗句，魏晋名士常以此抒怀。
注：此君：这位先生，以拟人的称呼指竹，后世遂以“此君”为竹的代称。

# 四十七｜王子猷居山阴
原：王子猷居山阴，夜大雪，眠觉，开室命酌酒，四望皎然。因起彷徨，咏左思《招隐诗》，忽忆戴安道。时戴在剡，即便夜乘小船就之。经宿方至，造门不前而返。人问其故，王曰：“吾本乘兴而行，兴尽而返，何必见戴！”|| 王徽之住在山阴时，一天夜里下了大雪，他一觉醒来，打开房门，叫人斟酒，举目四望，一片皎洁。于是起身徘徊，吟诵左思的《招隐诗》，忽然想起了戴逵。当时戴逵住在剡县，他当即连夜坐小船去找他。船行了一整夜才到，到了门口却不进去，转身就回来了。有人问他是什么缘故，王徽之说：“我本来是乘着兴致去的，兴致尽了就回来，何必一定要见到戴安道！”
注：山阴：县名，今浙江绍兴，晋时属会稽郡。
注：彷徨：徘徊。《招隐诗》：西晋左思所作，写山林隐士的清幽生活。
注：戴安道：戴逵，字安道，东晋隐士，善鼓琴、绘画，隐居剡县。剡（shàn）：县名，今浙江嵊州一带。
注：经宿：经过一夜。造门：到了门前。

# 四十八｜王卫军云
原：王卫军云：“酒正自引人著胜地。”|| 王荟说：“酒的确能把人带进美妙的境界。”
注：王卫军：王荟，字敬文，王导之子，官至会稽内史、镇军将军；称“卫军”，或因曾任或追赠卫将军，存疑。
注：正自：确实，“自”为语助。著：到达。胜地：美好的境地。

# 四十九｜王子猷出都
原：王子猷出都，尚在渚下。旧闻桓子野善吹笛，而不相识。遇桓于岸上过，王在船中，客有识之者，云是桓子野，王便令人与相闻，云：“闻君善吹笛，试为我一奏。”桓时已贵显，素闻王名，即便回下车，踞胡床，为作三调。弄毕，便上车去。客主不交一言。|| 王徽之奉召进京，船还停在青溪渚边。¦他早就听说桓伊擅长吹笛，但彼此并不相识。¦正巧碰上桓伊从岸上经过，王徽之在船中，客人里有认识桓伊的，说那就是桓子野。王徽之便派人去传话，说：“听说您擅长吹笛，请为我吹奏一曲。”¦桓伊当时已经地位显贵，但一向听说王徽之的名声，当即转身下车，坐在胡床上，为他吹了三支曲子。¦吹完，就上车走了。¦客人和主人之间没有交谈一句话。
注：出都：赴京城。渚下：指建康东南青溪的渡口。
注：桓子野：桓伊，善吹笛，号称江左第一。相闻：传话、通消息。
注：回下车：转身下车，晋时车从后面上下。胡床：一种可折叠的轻便坐具。三调：三支曲子，相传即后世《梅花三弄》所本，存疑。

# 五十｜桓南郡被召作太子洗马
原：桓南郡被召作太子洗马，船泊荻渚，王大服散后已小醉，往看桓。桓为设酒，不能冷饮，频语左右令“温酒来”，桓乃流涕呜咽。王便欲去，桓以手巾掩泪，因谓王曰：“犯我家讳，何预卿事！”王叹曰：“灵宝故自达！”|| 桓玄被征召去做太子洗马，船停在荻渚，王忱服了五石散之后已经有些醉意，前去探望桓玄。桓玄为他摆酒，王忱服散后不能喝冷酒，一再吩咐随从“把酒温来”，桓玄听了就流泪哽咽起来。王忱便要告辞，桓玄用手巾捂着眼泪，对王忱说：“犯了我的家讳，与你有什么相干！”王忱赞叹说：“灵宝果然通达！”
注：桓南郡：桓玄，字敬道，小字灵宝，桓温之子，袭封南郡公。太子洗（xiǎn）马：东宫属官，掌图籍、充前导。
注：荻渚：地名，在今湖北江陵附近。王大：王忱，小字佛大，时称王大。散：五石散，又称寒食散，服后须饮温酒、吃冷食以发散药性。
注：家讳：父祖的名讳。桓玄之父名温，故闻“温酒”而悲泣。预：干涉，关涉。
注：故自：本来，果然。

# 五十一｜王孝伯问王大
原：王孝伯问王大：“阮籍何如司马相如？”王大曰：“阮籍胸中垒块，故须酒浇之。”|| 王恭问王忱：“阮籍比司马相如怎么样？”王忱说：“阮籍心中郁积着块垒，所以需要用酒来浇。”
注：王孝伯：王恭，字孝伯，孝武帝王皇后之兄，后起兵讨王国宝，兵败被杀。王大：王忱。
注：阮籍：字嗣宗，竹林七贤之一，嗜酒，以醉避祸。司马相如：西汉辞赋家。
注：垒块：土块，比喻胸中郁结的不平之气。王忱以为二人才情相当，所异者在阮籍心有郁结，一说如此，存疑。

# 五十二｜王佛大叹言
原：王佛大叹言：“三日不饮酒，觉形神不复相亲。”|| 王忱感叹说：“三天不喝酒，就觉得身体和精神不再相依相亲了。”
注：王佛大：王忱，小字佛大，官至荆州刺史，嗜酒，常连日不醒。
注：形神：形体与精神。不复相亲：彼此疏离，形同魂不守舍。

# 五十三｜王孝伯言
原：王孝伯言：“名士不必须奇才，但使常得无事，痛饮酒，熟读《离骚》，便可称名士。”|| 王恭说：“做名士不一定要有奇才，只要能经常清闲无事，尽情喝酒，熟读《离骚》，就可以称为名士了。”
注：王孝伯：王恭。但使：只要。
注：无事：无所事事，不为俗务所累。《离骚》：屈原的长篇抒情诗，魏晋名士常吟诵以寄怀抱。

# 五十四｜王长史登茅山
原：王长史登茅山，大恸哭曰：“琅邪王伯舆，终当为情死。”|| 王廞登上茅山，放声痛哭，说：“琅邪王伯舆，到头来一定是为情而死的。”
注：王长史：王廞（xīn），字伯舆，王导之孙，王荟之子，曾任司徒左长史。居母丧时应王恭之召起兵，后王恭罢兵令其解散，王廞不从，反攻王恭，兵败下落不明。
注：茅山：山名，在今江苏句容东南。琅邪：王氏郡望，今山东临沂一带。
