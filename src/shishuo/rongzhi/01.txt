# 本门导读
题解：“容止”指仪容与举止。魏晋士人看重风姿神采，品评人物常从相貌、气度说起，又往往以玉山、松风、朝霞、春柳作比；本门所记多是这类赞叹，也写到丑陋、病弱、醉态，可见当时人对形神之美的讲究。

# 一｜魏武将见匈奴使
原：魏武将见匈奴使，自以形陋，不足雄远国，使崔季珪代，帝自捉刀立床头。既毕，令间谍问曰：“魏王何如？”匈奴使答曰：“魏王雅望非常，然床头捉刀人，此乃英雄也。”魏武闻之，追杀此使。|| 魏武帝曹操要接见匈奴使者，自认为相貌丑陋，不足以在远方之国面前显示威严，就让崔琰冒充自己，自己握着刀站在坐榻旁边。接见完了，派密探去问使者：“魏王怎么样？”匈奴使者回答：“魏王风度高雅，非同一般；可是榻边那个握刀的人，才是真英雄。”曹操听说后，派人追去把这个使者杀了。
注：魏武：曹操，死后追尊为魏武帝；此时尚为魏王。
注：雄远国：在远方之国面前称雄，显出威仪。
注：崔季珪：崔琰，字季珪，清河东武城人，仪表堂堂，须长四尺，为曹操所敬重，后被赐死。
注：床：坐榻。捉刀：握刀，后世“捉刀”“捉刀人”即由此而来，转指代人作文。

# 二｜何平叔美姿仪
原：何平叔美姿仪，面至白。魏明帝疑其傅粉，正夏月，与热汤饼。既啖，大汗出，以朱衣自拭，色转皎然。|| 何晏仪容姿态俊美，脸色极白。魏明帝怀疑他搽了粉，正当盛夏，特意赏他热汤面吃。何晏吃完，大汗淋漓，用红色的官服擦脸，脸色反而更加白净光洁。
注：何平叔：何晏，字平叔，曹操养子兼女婿，玄学名家。
注：魏明帝：曹叡。一说此事当在魏文帝曹丕时，存疑。
注：傅粉：搽粉。汤饼：热汤煮的面片，类似今之面条。
注：啖（dàn）：吃。皎然：洁白的样子。

# 三｜魏明帝使后弟毛曾
原：魏明帝使后弟毛曾与夏侯玄共坐，时人谓“蒹葭倚玉树”。|| 魏明帝让皇后的弟弟毛曾和夏侯玄并排坐着，当时人说这是“芦苇靠着玉树”。
注：毛曾：明帝毛皇后之弟，出身寒微，因外戚得官。
注：夏侯玄：字太初，曹魏宗室姻亲，名士，风度俊雅。
注：蒹葭（jiān jiā）：芦苇，喻卑微之人。玉树：传说中的玉质仙树，喻风姿秀美者。

# 四｜时人目夏侯太初
原：时人目夏侯太初“朗朗如日月之入怀”，李安国“颓唐如玉山之将崩”。|| 当时人评论夏侯玄，说他“明朗照人，好像日月投入怀中”；评论李丰，说他“精神萎顿，好像一座玉山将要倾倒”。
注：目：品评，题目。
注：李安国：李丰，字安国，曹魏中书令，后因谋除司马师被杀。
注：颓唐：委顿不振。玉山之将崩：形容醉倒或倦态，而仍不失美好。

# 五｜嵇康身长七尺八寸
原：嵇康身长七尺八寸，风姿特秀。见者叹曰：“萧萧肃肃，爽朗清举。”或云：“肃肃如松下风，高而徐引。”山公曰：“嵇叔夜之为人也，岩岩若孤松之独立；其醉也，傀俄若玉山之将崩。”|| 嵇康身高七尺八寸，风度姿容特别出众。见过他的人赞叹说：“潇洒严整，爽朗清高。”有人说：“像松树下吹过的风，飒飒作响，高远而悠长。”山涛说：“嵇叔夜为人，高峻挺拔，像一棵孤松独自屹立；他喝醉的时候，巍峨欲倒，像一座玉山将要崩塌。”
注：嵇康：字叔夜，谯国铚县人，“竹林七贤”之一，后为司马昭所杀。
注：萧萧肃肃：潇洒而端严。清举：清朗高拔。
注：山公：山涛，字巨源，竹林七贤之一，与嵇康为友。
注：岩岩：高峻的样子。傀俄（guī é）：同“巍峨”，高大而将倾的样子。

# 六｜裴令公目王安丰
原：裴令公目王安丰：“眼烂烂如岩下电。”|| 裴楷品评王戎说：“他的眼睛闪闪发亮，像山岩下的闪电。”
注：裴令公：裴楷，字叔则，西晋名士，官至中书令。
注：王安丰：王戎，字濬冲，竹林七贤之一，封安丰县侯。
注：烂烂：明亮有光的样子。

# 七｜潘岳妙有姿容
原：潘岳妙有姿容，好神情。少时挟弹出洛阳道，妇人遇者，莫不连手共萦之。左太冲绝丑，亦复效岳游遨。于是群妪齐共乱唾之，委顿而返。|| 潘岳容貌极美，神情风度也好。年轻时带着弹弓走在洛阳的大道上，碰见他的妇女，无不手拉着手把他围起来。左思长得极丑，也学潘岳出外游逛，结果一群妇女一齐朝他乱吐唾沫，他只好垂头丧气地回去了。
注：潘岳：字安仁，西晋文学家，以美貌著称。
注：挟弹：带着弹弓。萦：环绕，围住。
注：左太冲：左思，字太冲，西晋文学家，作《三都赋》。
注：妪（yù）：妇人。委顿：狼狈疲惫，没精打采。

# 八｜王夷甫容貌整丽
原：王夷甫容貌整丽，妙于谈玄。恒捉白玉柄麈尾，与手都无分别。|| 王衍容貌端正秀美，擅长谈论玄理。他常拿着一柄白玉柄的麈尾，那玉柄和他的手白得竟分不出彼此。
注：王夷甫：王衍，字夷甫，西晋清谈领袖，官至太尉。
注：麈（zhǔ）尾：以麈的尾毛制成的拂子，清谈时执以助谈。
注：都：完全。

# 九｜潘安仁、夏侯湛并有美容
原：潘安仁、夏侯湛并有美容，喜同行，时人谓之“连璧”。|| 潘岳和夏侯湛都容貌俊美，喜欢一同出行，当时人称他们为“连璧”。
注：夏侯湛：字孝若，西晋文学家，与潘岳交好。
注：连璧：两块并连的美玉，比喻两个同样出色的人。

# 十｜裴令公有俊容姿
原：裴令公有俊容姿，一旦有疾，至困，惠帝使王夷甫往看。裴方向壁卧，闻王使至，强回视之。王出，语人曰：“双眸闪闪若岩下电，精神挺动，体中故小恶。”|| 裴楷容貌俊美，有一天生了病，病得很重，晋惠帝派王衍去探望。裴楷正面朝墙躺着，听说王衍奉命来了，勉强转过头来看他。王衍出来后对人说：“他两眼闪闪发光，像山岩下的闪电，精神依旧振作，只是身体确实有点不舒服罢了。”
注：困：病重。惠帝：晋惠帝司马衷。
注：挺动：振作而有生气。
注：故：确实，本来。小恶：小有不适。

# 十一｜有人语王戎曰
原：有人语王戎曰：“嵇延祖卓卓如野鹤之在鸡群。”答曰：“君未见其父耳。”|| 有人对王戎说：“嵇绍出类拔萃，就像野鹤站在鸡群里。”王戎答道：“那是您没见过他父亲罢了。”
注：嵇延祖：嵇绍，字延祖，嵇康之子，后为护卫晋惠帝而死。
注：卓卓：高超出众的样子。此即成语“鹤立鸡群”所本。

# 十二｜裴令公有俊容仪
原：裴令公有俊容仪，脱冠冕，粗服乱头皆好。时人以为“玉人”。见者曰：“见裴叔则，如玉山上行，光映照人。”|| 裴楷仪容俊美，即使摘了冠帽，穿着粗布衣服、头发蓬乱，也一样好看。当时人称他为“玉人”。见过他的人说：“看见裴叔则，就像在玉山上行走，光彩照人。”
注：冠冕：礼帽，泛指冠戴。
注：粗服乱头：衣着粗陋，头发不梳，即不加修饰。

# 十三｜刘伶身长六尺
原：刘伶身长六尺，貌甚丑悴，而悠悠忽忽，土木形骸。|| 刘伶身高只有六尺，相貌非常丑陋憔悴，可他整日悠悠然恍恍然，把身体看作土木一般，毫不修饰。
注：刘伶：字伯伦，竹林七贤之一，以嗜酒放达著称。
注：丑悴（cuì）：丑陋憔悴。悠悠忽忽：飘忽悠闲、浑不在意的样子。
注：土木形骸：视形体如土木，不加打扮。

# 十四｜骠骑王武子是卫玠之舅
原：骠骑王武子是卫玠之舅，俊爽有风姿。见玠，辄叹曰：“珠玉在侧，觉我形秽。”|| 骠骑将军王济是卫玠的舅舅，英俊豪爽，很有风度。可每次见到卫玠，总要叹道：“珠玉就在身边，倒觉得我自己形貌丑陋了。”
注：王武子：王济，字武子，王浑之子，晋武帝女婿，死后追赠骠骑将军。
注：卫玠：字叔宝，西晋末名士，以美貌和善清谈著称。
注：形秽：形貌丑陋，后有成语“自惭形秽”。

# 十五｜有人诣王太尉
原：有人诣王太尉，遇安丰、大将军、丞相在坐；往别屋，见季胤、平子。还，语人曰：“今日之行，触目见琳琅珠玉。”|| 有人去拜访王衍，碰上王戎、王敦、王导都在座；到另一间屋里，又见到王诩、王澄。回来后对人说：“今天这一趟，满眼看到的都是美玉明珠。”
注：王太尉：王衍。安丰：王戎。大将军：王敦。丞相：王导。皆琅邪王氏。
注：季胤：王诩，字季胤，王衍之弟。平子：王澄，字平子，王衍之弟。
注：琳琅：美玉。

# 十六｜王丞相见卫洗马曰
原：王丞相见卫洗马曰：“居然有羸，虽复终日调畅，若不堪罗绮。”|| 王导见到卫玠，说：“他显然很瘦弱，虽说整天都在调养身体，可看上去好像连轻软的绫罗衣裳都承受不起。”
注：卫洗马：卫玠，曾任太子洗（xiǎn）马。
注：居然：显然。羸（léi）：瘦弱。
注：调畅：调养，使身体舒畅。罗绮：轻软的丝织品。

# 十七｜王大将军称太尉
原：王大将军称太尉：“处众人中，似珠玉在瓦石间。”|| 王敦称赞王衍说：“他处在众人当中，就像珠玉落在瓦片石块之间。”
注：王大将军：王敦，字处仲，王导从兄，东晋初权臣。太尉：王衍，王敦的族兄。

# 十八｜庾子嵩长不满七尺
原：庾子嵩长不满七尺，腰带十围，颓然自放。|| 庾敳身高不到七尺，腰却有十围粗，总是一副散漫随意、放任自适的样子。
注：庾子嵩：庾敳（ái），字子嵩，西晋名士，好老庄。
注：围：计量粗细的单位，约两手合抱之一圈，说法不一。
注：颓然自放：松散随便，自我放任。

# 十九｜卫玠从豫章至下都
原：卫玠从豫章至下都，人久闻其名，观者如堵墙。玠先有羸疾，体不堪劳，遂成病而死。时人谓“看杀卫玠”。|| 卫玠从豫章来到京城建康，人们早就听说他的大名，围观的人多得像一堵堵墙。卫玠本来就体弱多病，身体经不起劳累，于是病倒而死。当时人说是“看杀了卫玠”。
注：豫章：郡名，治所在今江西南昌。下都：指东晋都城建康，相对于旧都洛阳而言。
注：如堵墙：像墙一样围着，形容人多。

# 二十｜周伯仁道桓茂伦
原：周伯仁道桓茂伦：“嵚崎历落可笑人。”或云谢幼舆言。|| 周顗评论桓彝说：“这人磊落不凡、与众不同，真是个可爱的人。”也有人说这话是谢鲲说的。
注：周伯仁：周顗（yǐ），字伯仁，东晋名士。桓茂伦：桓彝，字茂伦，桓温之父。
注：嵚崎（qīn qí）：山势险峻，喻品格奇特。历落：错落不凡，喻才能出众。
注：可笑：可爱、令人喜欢，非今义。
注：谢幼舆：谢鲲，字幼舆，东晋名士。

# 二十一｜周侯说王长史父
原：周侯说王长史父：“形貌既伟，雅怀有概，保而用之，可作诸许物也。”|| 周顗评论王濛的父亲王讷说：“他形貌魁伟，胸怀高雅又有气概，好好爱护任用他，能办成许多事情。”
注：周侯：周顗，袭封武城侯。
注：王长史父：王讷，字文开，王濛之父。王长史即王濛，字仲祖，曾任司徒左长史。
注：概：气概，节概。诸许物：许多事情。

# 二十二｜祖士少见卫君长云
原：祖士少见卫君长云：“此人有旄仗下形。”|| 祖约见到卫永，说：“这个人有站在旌旄仪仗下的将帅气象。”
注：祖士少：祖约，字士少，祖逖之弟，后参与苏峻之乱。
注：卫君长：卫永，字君长，曾为温峤属官。
注：旄（máo）仗：用牦牛尾装饰的旗帜仪仗，为将帅所用。

# 二十三｜石头事故
原：石头事故，朝廷倾覆。温忠武与庾文康投陶公求救，陶公云：“肃祖顾命不见及，且苏峻作乱，衅由诸庾，诛其兄弟，不足以谢天下。”于时庾在温船后闻之，忧怖无计。|| 苏峻攻陷石头城那次变乱，朝廷倾覆。温峤和庾亮投奔陶侃求援，陶侃说：“明帝临终托付大臣，没有轮到我；况且苏峻作乱，祸端是由庾家兄弟引起的，就是把他们兄弟杀光，也不足以向天下谢罪。”当时庾亮正在温峤的船后听到这话，又忧又怕，不知如何是好。
注：石头事故：指咸和二年（327）苏峻、祖约以讨庾亮为名起兵，攻入建康，挟成帝于石头城。
注：温忠武：温峤，谥忠武。庾文康：庾亮，谥文康，明帝皇后之兄。陶公：陶侃，时为荆州刺史，拥重兵。
注：肃祖：晋明帝庙号。顾命：帝王临终遗命辅政。不见及：没有提到我。
注：衅：祸端，罪过。
原：别日，温劝庾见陶，庾犹豫未能往，温曰：“溪狗我所悉，卿但见之，必无忧也！”庾风姿神貌，陶一见便改观。谈宴竟日，爱重顿至。|| 又一天，温峤劝庾亮去见陶侃，庾亮迟疑着不敢去。温峤说：“那溪狗我是了解的，你只管去见他，保管没事！”庾亮风度神采出众，陶侃一见便改变了看法，两人谈笑宴饮了一整天，陶侃对他立刻喜爱敬重起来。
注：溪狗：当时对江西一带出身低微者的蔑称，陶侃出身寒门，故温峤戏称之。“溪”一作“傒”。
注：改观：改变看法。竟日：整天。

# 二十四｜庾太尉在武昌
原：庾太尉在武昌，秋夜气佳景清，佐吏殷浩、王胡之之徒登南楼理咏。音调始遒，闻函道中有屐声甚厉，定是庾公。俄而率左右十许人步来，诸贤欲起避之，公徐云：“诸君少住，老子于此处兴复不浅。”因便据胡床与诸人咏谑，竟坐甚得任乐。|| 庾亮镇守武昌时，一个秋夜天气爽朗、景色清幽，他的属官殷浩、王胡之等人登上南楼吟诗唱咏。声调正渐趋高亢，听见楼梯上木屐声响得很急，料定是庾公来了。不一会儿，庾亮带着十来个随从走上楼来，众人想起身回避，庾亮不慌不忙地说：“诸位暂且留步，老夫对这种事兴致也不浅呢。”于是就坐在胡床上，和大家一起吟咏说笑，满座的人都玩得尽兴快活。
注：庾太尉：庾亮，死后追赠太尉；时以征西将军镇武昌。
注：殷浩：字渊源，东晋名士，善清谈。王胡之：字修龄，王廙之子。理咏：吟咏诗歌。
注：遒（qiú）：强劲。函道：楼梯，楼道。屐：木底鞋。
注：胡床：从胡地传入的折叠坐具。谑（xuè）：戏谑说笑。竟坐：满座。
原：后王逸少下，与丞相言及此事，丞相曰：“元规尔时风范不得不小颓。”右军答曰：“唯丘壑独存。”|| 后来王羲之东下建康，和丞相王导谈起这件事，王导说：“元规那时的风度，不能不说有点减损了。”王羲之答道：“只有那份寄情山水的高情雅致还留着。”
注：王逸少：王羲之，字逸少，后官右军将军，时为庾亮属官。下：自上游武昌顺江而下至建康。
注：元规：庾亮的字。颓：衰减。
注：丘壑：山水丘谷，指隐逸高雅的情趣。

# 二十五｜王敬豫有美形
原：王敬豫有美形，问讯王公。王公抚其肩曰：“阿奴恨才不称。”又云：“敬豫事事似王公。”|| 王恬容貌俊美，去给父亲王导请安。王导拍着他的肩膀说：“我儿呀，可惜才学配不上这副相貌。”又有人说：“敬豫样样都像王公。”
注：王敬豫：王恬，字敬豫，王导次子，善隶书、围棋。
注：问讯：问安。阿奴：长辈对晚辈的昵称。
注：恨：遗憾。不称（chèn）：不相称。

# 二十六｜王右军见杜弘治
原：王右军见杜弘治，叹曰：“面如凝脂，眼如点漆，此神仙中人。”时人有称王长史形者，蔡公曰：“恨诸人不见杜弘治耳。”|| 王羲之见到杜乂，赞叹说：“脸像凝结的油脂一样白润，眼睛像点了漆一样乌亮，这真是神仙中人。”当时有人称赞王濛的相貌，蔡谟说：“可惜这些人没见过杜弘治罢了。”
注：杜弘治：杜乂，字弘治，杜预之孙，以美貌著称，其女为晋成帝皇后。
注：凝脂：凝固的油脂，形容皮肤白嫩细润。点漆：形容眼珠黑亮。
注：蔡公：蔡谟，字道明，东晋大臣，官至司徒。

# 二十七｜刘尹道桓公
原：刘尹道桓公：“鬓如反猬皮，眉如紫石棱，自是孙仲谋、司马宣王一流人。”|| 刘惔评论桓温说：“他的鬓发像翻过来的刺猬皮，根根竖起；眉棱像紫石英的棱角，自然是孙权、司马懿一类的人物。”
注：刘尹：刘惔，字真长，曾任丹阳尹。桓公：桓温，东晋权臣。
注：反猬皮：倒翻的刺猬皮，形容鬓毛刚硬竖立。紫石棱：紫石英的棱角，形容眉骨突出。
注：孙仲谋：孙权。司马宣王：司马懿。二人皆有雄才，亦有奇相。

# 二十八｜王敬伦风姿似父
原：王敬伦风姿似父，作侍中，加授桓公公服，从大门入。桓公望之曰：“大奴固自有凤毛。”|| 王劭风度姿态很像他父亲。他任侍中时，奉命去给桓温加授官服，从大门进来。桓温望着他说：“大奴确实有他父亲的凤毛啊。”
注：王敬伦：王劭，字敬伦，小字大奴，王导之子。
注：公服：官服，此指朝廷加授的礼服。
注：凤毛：凤凰的羽毛，比喻子孙有父祖的风采。

# 二十九｜林公道王长史
原：林公道王长史：“敛衿作一来，何其轩轩韶举！”|| 支道林评论王濛说：“他整一整衣襟走过来，是何等轩昂俊美！”
注：林公：支遁，字道林，东晋高僧，善清谈，与名士交游。
注：敛衿（jīn）：整理衣襟，表示庄重。作一来：走过来，一说起身，存疑。
注：轩轩：神采飞扬的样子。韶举：美好高举。

# 三十｜时人目王右军
原：时人目王右军：“飘如游云，矫若惊龙。”|| 当时人品评王羲之说：“飘逸得像浮游的云，矫健得像受惊腾起的龙。”
注：王右军：王羲之。此语后人多用来形容其书法笔势。
注：矫：矫健有力。

# 三十一｜王长史尝病
原：王长史尝病，亲疏不通。林公来，守门人遽启之曰：“一异人在门，不敢不启。”王笑曰：“此必林公。”|| 王濛有一次生病，不论亲朋还是生客，一概不予通报。支道林来了，守门人急忙进去禀报说：“有个模样奇特的人在门口，不敢不报。”王濛笑道：“这一定是林公。”
注：亲疏不通：亲近的、疏远的客人都不通报。
注：遽（jù）：急忙。启：禀告。
注：异人：相貌与众不同的人。支遁相貌奇特，故云。

# 三十二｜或以方谢仁祖不乃重者
原：或以方谢仁祖不乃重者。桓大司马曰：“诸君莫轻道，仁祖企脚北窗下弹琵琶，故自有天际真人想。”|| 有人品评谢尚，不怎么看重他。桓温说：“诸位别轻易议论他，仁祖翘着脚在北窗下弹琵琶的时候，确实让人想到天上的仙人。”
注：方：比拟，品评。谢仁祖：谢尚，字仁祖，谢安从兄，多才艺。不乃重：不很看重。
注：桓大司马：桓温。
注：企脚：翘起脚，一说踮起脚跟，存疑。天际真人：天上的仙人。想：意态，令人生出的联想。

# 三十三｜王长史为中书郎
原：王长史为中书郎，往敬和许。尔时积雪，长史从门外下车，步入尚书，著公服。敬和遥望叹曰：“此不复似世中人！”|| 王濛任中书郎时，到王洽那里去。当时满地积雪，王濛在门外下了车，穿着官服步行进入尚书省。王洽远远望见，赞叹道：“这简直不像人世间的人了！”
注：敬和：王洽，字敬和，王导之子。许：处所。
注：尚书：尚书省官署。
注：著（zhuó）：穿。公服：官服。

# 三十四｜简文作相王时
原：简文作相王时，与谢公共诣桓宣武。王珣先在内，桓语王：“卿尝欲见相王，可住帐里。”二客既去，桓谓王曰：“定何如？”王曰：“相王作辅，自然湛若神君。公亦万夫之望，不然，仆射何得自没？”|| 简文帝还是以会稽王身份辅政的时候，和谢安一起去拜访桓温。王珣先已在里面，桓温对他说：“你一直想见见相王，可以留在帐子后面看。”两位客人走后，桓温问王珣：“到底怎么样？”王珣说：“相王身居辅政之位，自然深沉明澈，像神明一般。您也是万众仰望的人物，不然的话，谢仆射怎么肯屈身埋没自己来拜访您呢？”
注：简文：晋简文帝司马昱，即位前以会稽王辅政，称“相王”。
注：谢公：谢安。桓宣武：桓温，谥宣武。王珣：字元琳，王导之孙，时为桓温主簿。
注：湛（zhàn）：深沉澄澈。神君：神明。
注：仆射（yè）：指谢安。按谢安任尚书仆射在后，此系追称，存疑。自没：自甘埋没、屈居人下。

# 三十五｜海西时
原：海西时，诸公每朝，朝堂犹暗，唯会稽王来，轩轩如朝霞举。|| 海西公在位的时候，大臣们每次上朝，朝堂里还是昏暗的，只有会稽王一到，神采焕发，就像朝霞升起一般。
注：海西：晋废帝司马奕，在位五年，被桓温废为海西公。
注：会稽王：司马昱，即后来的简文帝。
注：轩轩：神采飞扬的样子。

# 三十六｜谢车骑道谢公
原：谢车骑道谢公：“游肆复无乃高唱，但恭坐捻鼻顾睐，便自有寝处山泽间仪。”|| 谢玄称道谢安说：“他游乐时并不怎么高声吟唱，只是端端正正坐着，捏着鼻子左右顾盼，自然就有一种栖身山林川泽的高士风仪。”
注：谢车骑：谢玄，谢安之侄，淝水之战主将，死后追赠车骑将军。
注：游肆：游乐，一说游乐场所。无乃：不怎么。高唱：高声吟咏。
注：捻（niǎn）鼻：捏鼻子。谢安有鼻疾，吟咏声带鼻音，时人仿效为“洛生咏”，此处或与之有关，存疑。顾睐（lài）：环顾。
注：寝处山泽间仪：隐居山林者的风度。

# 三十七｜谢公云
原：谢公云：“见林公双眼，黯黯明黑。”孙兴公见林公：“棱棱露其爽。”|| 谢安说：“看支道林的一双眼睛，深沉幽黑而又明亮。”孙绰见到支道林，说：“他神情峻峭，透出一股英爽之气。”
注：黯黯（àn）：深黑的样子。
注：孙兴公：孙绰，字兴公，东晋文学家，与支遁交好。
注：棱棱（léng）：威严峻峭的样子。爽：英爽之气。

# 三十八｜庾长仁与诸弟入吴
原：庾长仁与诸弟入吴，欲住亭中宿。诸弟先上，见群小满屋，都无相避意。长仁曰：“我试观之。”乃策杖将一小儿，始入门，诸客望其神姿，一时退匿。|| 庾统和几个弟弟到吴郡去，想在驿亭里住一宿。弟弟们先进去，只见满屋都是平民百姓，全无让地方的意思。庾统说：“我去试试看。”于是拄着拐杖，带着一个小僮，刚一进门，满屋客人望见他的神采风姿，一下子都退避躲开了。
注：庾长仁：庾统，字长仁，庾亮之侄，早卒。
注：亭：驿亭，供旅人歇宿之所。群小：平民百姓，一说身份低微之人。
注：策杖：拄着手杖。将：带领。匿：躲避。

# 三十九｜有人叹王恭形茂者
原：有人叹王恭形茂者，云：“濯濯如春月柳。”|| 有人赞叹王恭仪容俊美，说：“他清新明秀，像春天里的杨柳。”
注：王恭：字孝伯，东晋外戚，孝武帝王皇后之兄，以清操美仪著称，后起兵失败被杀。
注：形茂：形貌美好。濯濯（zhuó）：清新明净的样子。春月：春天。
