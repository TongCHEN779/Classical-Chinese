# 峰州鱼
原：峰州有一道水，从吐蕃中来，夏冷如冰雪。有鱼长一二寸，来去有时，盖水上如粥。人取烹之而食，千万家取不可尽。不知所从来。

# 海虾
原：刘恂者曾登海舶，入舵楼，忽见窗板悬二巨虾壳。头、尾、钳、足具全，各七八尺。首占其一分，嘴尖利如锋刃，嘴上有须如红箸，各长二三尺。双脚有钳，钳粗如人大指，长二尺馀，上有芒刺如蔷薇枝，赤而铦硬，手不可触。脑壳烘透，弯环尺馀，何止于杯盂也。《北户录》云：“滕循为广州刺史，有客语循曰：‘虾须有一丈长者，堪为拄杖。’循不之信，客去东海，取须四尺以示循，方伏其异。”

# 瓦屋子
原：瓦屋子，盖蚌蛤之类也，南中旧呼为蚶子。顷因卢钧尚书作镇，遂改为瓦屋子，以其壳上有棱如瓦垅，故以此名焉。壳中有肉，紫色而满腹，广人犹重之，多烧以荐酒，俗呼为天脔炙。食多即壅气，背膊烦疼，未测其性也。

# 印鱼
原：印鱼，长一尺三寸，额上四方如印，有字，诸大鱼应死者，先以印印之。

# 石斑鱼
原：僧行儒言，建州有石斑鱼，好与蛇交。南中多隔蜂窠，窠大如壶，常群螫人。土人取石斑鱼就蜂侧炙之，标于竿上，向日，令鱼影落其窠上，须臾，有鸟大如燕数百，互击其窠，窠碎落如叶，蜂亦全尽。

# 井鱼
原：唐段成式云，井鱼脑有穴，每嗡水，辄于脑穴蹙出，如飞泉，散落海中，舟人竞以空器贮之。海水咸苦，经鱼脑穴出，反淡如泉水焉。成式见梵僧善提胜说。

# 异鱼
原：异鱼，东海人常获鱼，长五六尺，腹胃成胡鹿刀槊之状，或号秦皇鱼。

# 螃𧒯
原：傍海大鱼，脊上有石十二时，一名篱头溺，一名螃𧒯，其溺甚毒。

# 鱓鱼
原：郫县侯生者，于沤麻池侧得鱓鱼，大可尺围，烹而食之，发白复黑，齿落复生，自此轻健。

# 玳瑁
原：玳瑁形状似龟，唯腹背甲有烘点。《本草》云：“玳瑁解毒，其大者悉婆萨石，兼云辟邪。”广南卢亭，获活玳瑁龟一枚以献连帅嗣薛王。王令生取背甲小者二片，带于左臂上以辟毒。龟被生揭其甲，甚极苦楚。后养于使宅后北池，伺其揭处渐生，复遣卢亭送于海畔。或云，玳瑁若生，带之有验，是饮馔中有盅毒，玳瑁甲即自摇动；若死，无此验。

# 海术
原：南海有水族，前左脚长，前右脚短，口在肋旁背上，常以左脚捉物，置于右脚，右脚中有齿啮之，方内于口。大三尺馀，其声“术术”，南人呼为海术。

# 海镜
原：海镜，广人呼为膏叶，盘两片，合以成形。壳圆，中甚莹滑。日照如云母光。内有少肉如蚌胎，腹中有红蟹子，其小如黄豆，而螯具足。海镜饥，则蟹出拾食，蟹饱归腹，海镜亦饱。或迫之以火，则蟹子走出，离肠腹立毙。或生剖之，有蟹子活在腹中，逡巡亦毙。

# 水母
原：水母，广州谓之水母，闽谓之魠。其形乃浑然凝结一物，有淡紫色者，有白色者，大如覆帽，小者如碗。肠下有物如悬絮，俗谓之足，而无口眼。常有数十虾寄腹下，咂食其涎。浮泛水上，捕者或遇之，即欻然而没，乃是虾有所见耳。南中好食之，云性暖，治河鱼之疾，然甚腥，须以草木灰点生油再三洗之，莹净如水精紫玉。肉厚可二寸，薄处亦寸馀，先煮椒桂或豆蔻，生姜缕切而炸之，或以五辣肉醋，或以虾醋，如鲙食之。最宜虾醋，亦物类相摄耳。水母本阴海凝结之物，食而暖补，其理未详。

# 蟹
原：蟹，八月腹内有芒，芒真稻芒也，长寸许，向东输与海神，未输芒，不可食。

# 百足蟹
原：善苑国出百足蟹，长九尺，四螯。煎为胶，谓之螯胶，胜凤喙胶也。

# 螗蟹
原：平原郡贡螗蟹，彩于河间界，每年生贡。斲冰火照，悬老犬肉，蟹觉犬肉即浮，因取之。一枚直百钱，以毡密束于驿马上，驰之至京。

# 䱜鱼
原：䱜鱼，章安县出焉。子朝出索食，暮还入母腹，中容四子。颊赤如金，甚健，网不能制，俗呼为河伯健儿。

# 鹦鹉螺
原：鹦鹉螺，旋尖处屈而咮，如鹦鹉嘴，故以此名，壳上青绿斑，大者可受二升。壳内光莹如云母，装为酒杯，奇而可玩。

# 红螺
原：红螺，大小亦类鹦鹉螺，壳薄而红，亦堪为酒器。刳小螺为足，缀以胶漆，尤可佳尚也。

# 鸯龟
原：初宁县里多鸯龟，壳薄狭而燥，头似鹅，不与常龟同，而能啮犬也。

# 鲵鱼
原：鲵鱼如鲇，四足长尾，能上树。天旱，辄含水上山，以草叶覆身，张口，鸟来饮水，辄吸食之。声如小儿，峡中人食之，先缚于树鞭之，身上白汁出，如构汁，去此方可食，不尔有毒。

# 鲎
原：鲎雌常负雄而行，渔者必得其双。南人列肆卖之，雄者少肉。旧说，过海辄相积于背，高尺馀，如帆，乘风游行。今鲎壳上有物，高七八寸，如石珊瑚，俗呼鲎帆。至今闽岭重鲎酱。十二足，壳可为冠，次于白角。南人取其尾为小如意。

# 飞鱼
原：飞鱼，朗山朗水有之，鱼长一尺，能飞，即凌云空，息即归潭底。

# 虎蟹
原：虎蟹，壳上有虎斑，可装为酒器，与红蟹皆产琼崖海边，虽非珍奇，亦不易彩得也。

# 蚝
原：蚝即牡蛎也，其初生海岛边，如拳石，四面渐长。有高一二丈者，巉岩如山，每一房内，蚝肉一片，随其所生，前后大小不等。每潮来，诸蚝皆开房，伺虫蚁入，即合之。海夷卢亭者以斧楔取壳，烧以烈火，蚝即启房，挑取其肉，贮以小竹筐，赴虚市，以易西骨米。蚝肉大者腌为炙，小者炒食，肉中有滋味。食之即甚，壅肠骨。

# 赤𩽼公
原：鲤脊中鳞一道，每鳞上有黑点，大小皆三十六鳞。唐朝律，取得鲤鱼，即宜放，仍不得吃。说赤𩽼公，卖者决六十。

# 雷穴鱼
原：兴州有一处名雷穴，水常半穴，每雷声，水塞穴流，鱼随流而出。百姓每候雷声，绕树布网，获鱼无限。非雷声，渔子聚鼓击于穴口，鱼亦辄出，所获半于雷时。韦行规为兴州刺史时，与亲故书，说其事。

# 虬尾
原：东海有鱼，虬尾似鸱，鼓浪即降雨，遂设像于屋脊。

# 牛鱼
原：海上取牛鱼皮悬之，海潮至，即毛竖。

# 蝤𥒥
原：蝤𥒥，大者长尺馀，两螯至强。八月能与虎斗，虎不如。随大潮退壳，一退一长。

# 奔䱐
原：奔䱐，一名瀱，非鱼非蛟，大如舡，长二三丈，若鲇，有两乳在腹下，雄雌阴阳类人。取其子著岸上，声如婴儿啼。项上有孔，通头，气出哧哧作声，必大风，行者以为候。相传懒妇所化，杀一头，得膏三四斛，取之烧灯，照读书纺绩辄暗。照欢乐之处则明。

# 系臂
原：系臂如龟，入海捕之，必先祭。又陈所取之数，则自出，因取之。若不信，则风浪覆舡。

# 鸡嘴鱼
原：李德裕幼时，常于明州见一水族，有两足，嘴似鸡，身如鱼。

# 剑鱼
原：海鱼千岁为剑鱼，一名琵琶鱼，形似琵琶而喜鸣，因以为名。虎鱼老则为蛟；江中小鱼，化为蝗而食五谷者，百岁为鼠。

# 懒妇鱼
原：淮南有懒妇鱼，俗云，昔杨氏家妇，为姑所怒，溺水死为鱼。其脂膏可燃灯烛，以之照鼓琴瑟博奕，则烂然有光，若照纺绩，则不复明。

# 黄雀化蛤
原：淮水中，黄雀至秋化为蛤，至春复为黄雀，雀五百年化为蜃蛤。

# 天牛鱼
原：天牛鱼，方员三丈，眼大如斗，口在肋下，露齿无唇，两肉角如臂，两翼长六尺，尾五尺。
