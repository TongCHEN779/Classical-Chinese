# 循吏列传
题解：本卷记春秋时孙叔敖、子产、公仪休、石奢、李离五位奉公守法、以德化民的官吏。司马迁全选古人而不录一位汉代官吏，与紧随其后的《酷吏列传》形成鲜明对照，寄寓了对当时严刑峻法之风的批评。
# 太史公曰
原：太史公曰：法令所以导民也，刑罚所以禁奸也。文武不备，良民惧然身修者，官未曾乱也。奉职循理，亦可以为治，何必威严哉？|| 太史公说：法令是用来引导百姓的，刑罚是用来禁止奸邪的。即使法令和刑罚不够完备，善良的百姓仍能心存敬畏、修身自律，那是因为官吏没有胡作非为。官吏只要尽职守法、按常理办事，也同样可以把国家治理好，又何必一定要依靠威严的刑罚呢？
注：文武：指法令（文）与刑罚（武）。
注：惧然：心存戒惧的样子。
# 孙叔敖
原：孙叔敖者，楚之处士也。虞丘相进之于楚庄王以自代也。三月为楚相，施教导民，上下和合，世俗盛美，政缓禁止，吏无奸邪，盗贼不起。秋冬则劝民山采，春夏以水，各得其所便，民皆乐其生。|| 孙叔敖是楚国一位没有做官的贤士。楚相虞丘把他推荐给楚庄王，让他接替自己。他做楚相三个月，就施行教化、引导百姓，使得全国上下和睦，风俗淳美，政令宽缓而有禁必止，官吏中没有奸邪之徒，盗贼也不再出现。秋冬季节，他鼓励百姓进山采伐林木，到春夏河水上涨时，就利用水路把木材运出去，人人各得其便，百姓都安居乐业。
注：孙叔敖：春秋时楚国令尹，以贤能著称，曾主持兴修水利。
注：处士：有才德而隐居不仕的人。
注：虞丘：楚庄王时的楚相，生平事迹不详。楚庄王：春秋时楚国国君，春秋五霸之一。
注：春夏以水：春夏水涨时，借水流运送山中采伐的木材。
原：庄王以为币轻，更以小为大，百姓不便，皆去其业。市令言之相曰：“市乱，民莫安其处，次行不定。”相曰：“如此几何顷乎？”市令曰：“三月顷。”相曰：“罢，吾今令之复矣。”|| 楚庄王认为楚国的钱币太轻，下令把小钱改铸成大钱，百姓觉得很不方便，纷纷放弃了原来的营生。管理市场的市令向孙叔敖报告说：“市场乱了，百姓都不能安心经营，店铺摊位的秩序也不稳定。”孙叔敖问：“这样有多久了？”市令说：“有三个月了。”孙叔敖说：“你回去吧，我现在就让市场恢复原样。”
注：币：钱币。
注：市令：管理市场的官员。
注：次行：市场中排列的店铺摊位。次，市中的店肆；行，行列。
原：后五日，朝，相言之王曰：“前日更币，以为轻。今市令来言曰‘市乱，民莫安其处，次行之不定’。臣请遂令复如故。”王许之，下令三日而市复如故。|| 五天以后，上朝时，孙叔敖对庄王说：“前些时候更改币制，是因为认为旧币太轻。如今市令来报告说‘市场乱了，百姓都不能安心经营，店铺摊位的秩序也不稳定’。我请求就此下令恢复原来的币制。”庄王同意了，命令下达三天后，市场就恢复了原来的样子。
原：楚民俗好庳车，王以为庳车不便马，欲下令使高之。相曰：“令数下，民不知所从，不可。王必欲高车，臣请教闾里使高其梱。乘车者皆君子，君子不能数下车。”王许之。居半岁，民悉自高其车。|| 楚国百姓的习俗是喜欢乘坐矮车，庄王认为矮车不便于驾马，想下令让百姓把车加高。孙叔敖说：“政令下达得太频繁，百姓就会无所适从，这样不好。大王如果一定要把车加高，我请求让乡里人家把门槛加高。乘车的都是有身份的君子，君子不能频繁地下车。”庄王同意了。过了半年，百姓都自动把自己的车加高了。
注：庳（bì）车：车身低矮的车。
注：梱（kǔn）：门槛。门槛加高，矮车过不去，乘车者又不愿屡屡下车，自然会把车加高。
原：此不教而民从其化，近者视而效之，远者四面望而法之。故三得相而不喜，知其材自得之也；三去相而不悔，知非己之罪也。|| 这就是不用强令教导而百姓自然顺从他的教化，近处的人看见了就仿效他，远处的人从四面八方观望而效法他。所以孙叔敖三次当上楚相也不沾沾自喜，因为他知道那是凭自己的才能得来的；三次被罢去相位也不懊悔，因为他知道那不是自己的过错。
# 子产
原：子产者，郑之列大夫也。郑昭君之时，以所爱徐挚为相，国乱，上下不亲，父子不和。大宫子期言之君，以子产为相。|| 子产是郑国的一位大夫。郑昭君在位时，任用自己宠爱的徐挚为相，国家混乱，上下不相亲近，父子之间也不和睦。大宫子期向国君进言，国君就任用子产为相。
注：子产：名侨，字子产，春秋时郑国著名的政治家，执政期间进行多项改革。
注：郑昭君：郑国国君，所指存疑。子产执政在郑简公、定公时，此处所记与《左传》不合。
注：徐挚、大宫子期：人名，事迹不详，存疑。
原：为相一年，竖子不戏狎，斑白不提挈，僮子不犁畔。二年，市不豫贾。三年，门不夜关，道不拾遗。四年，田器不归。五年，士无尺籍，丧期不令而治。|| 子产做相一年，轻薄少年不再嬉戏胡闹，头发花白的老人不用再提拿重物，孩童不必下田耕地。两年后，市场上不再有人哄抬物价。三年后，夜里不用关门，路上没有人捡拾别人丢失的东西。四年后，农具可以放在田里不必带回家。五年后，士人不必再被登记服兵役，丧葬的期限不用下令，百姓也能自觉遵守。
注：竖子：未成年的少年，此指轻薄少年。戏狎：嬉戏打闹，举止轻慢。
注：斑白：头发花白的老人。提挈：手提肩扛。
注：豫贾（jià）：虚抬物价，漫天要价。贾，同“价”。
注：尺籍：征兵用的军籍簿册。
原：治郑二十六年而死，丁壮号哭，老人儿啼，曰：“子产去我死乎！民将安归？”|| 子产治理郑国二十六年后去世，青壮年放声痛哭，老人像孩子一样啼哭，说：“子产离开我们死去了！百姓今后依靠谁呢？”
注：丁壮：成年男子。
# 公仪休
原：公仪休者，鲁博士也。以高弟为鲁相。奉法循理，无所变更，百官自正。使食禄者不得与下民争利，受大者不得取小。|| 公仪休是鲁国的博士。因才学优异而被任命为鲁国的相。他奉公守法，按常理办事，不随意变更制度，百官自然行为端正。他规定享受俸禄的官员不得与百姓争夺利益，已经得到厚禄的人不得再贪取小利。
注：公仪休：战国时鲁国人，鲁穆公时为相。
注：博士：古代掌管通晓古今、备咨询的学官。
注：高弟：成绩优等。弟，通“第”。
原：客有遗相鱼者，相不受。客曰：“闻君嗜鱼，遗君鱼，何故不受也？”相曰：“以嗜鱼，故不受也。今为相，能自给鱼；今受鱼而免，谁复给我鱼者？吾故不受也。”|| 有位客人送鱼给公仪休，他不接受。客人说：“听说您喜欢吃鱼，送鱼给您，为什么不收呢？”公仪休说：“正因为我喜欢吃鱼，所以才不收。现在我做相，自己买得起鱼；如果收了鱼而被免官，还有谁会再给我鱼呢？所以我不收。”
注：遗（wèi）：赠送。
原：食茹而美，拔其园葵而弃之。见其家织布好，而疾出其家妇，燔其机，云“欲令农士工女安所雠其货乎”？|| 他吃到自家种的蔬菜觉得味道很好，就把园中的葵菜全拔掉扔了。他看到家里织的布很好，就立刻把织布的妻子送回娘家，还烧掉了织机，说：“难道要让农夫和织女没有地方卖掉他们的货物吗？”
注：茹：蔬菜。葵：古代常食的一种蔬菜，即冬葵。
注：出：休弃妻子，让她离开夫家。
注：雠（chóu）：售出，卖。
# 石奢
原：石奢者，楚昭王相也。坚直廉正，无所阿避。行县，道有杀人者，相追之，乃其父也。纵其父而还自系焉。使人言之王曰：“杀人者，臣之父也。夫以父立政，不孝也；废法纵罪，非忠也；臣罪当死。”|| 石奢是楚昭王的相。他刚强正直、廉洁公正，从不逢迎讨好，也不回避权贵。他到各县巡视，路上遇到有人杀人，他追上去，发现凶手竟是自己的父亲。他放走了父亲，回来后把自己囚禁起来。他派人对昭王说：“杀人的是我的父亲。如果惩治父亲来树立政令，就是不孝；如果废弃法律、放纵罪犯，就是不忠；我的罪应当处死。”
注：楚昭王：春秋末楚国国君，名珍（一作壬）。
注：阿避：曲意逢迎和回避。
注：行县：巡视所属各县。
注：以父立政：用惩治父亲的办法来树立政令的威信。
原：王曰：“追而不及，不当伏罪，子其治事矣。”石奢曰：“不私其父，非孝子也；不奉主法，非忠臣也。王赦其罪，上惠也；伏诛而死，臣职也。”遂不受令，自刎而死。|| 昭王说：“你去追却没有追上，不应当认罪受罚，你还是去处理政事吧。”石奢说：“不偏护自己的父亲，就不是孝子；不执行君主的法令，就不是忠臣。大王赦免我的罪，是君上的恩惠；接受惩处而死，是臣子的本分。”于是不接受昭王的命令，自刎而死。
注：私：偏护。
# 李离
原：李离者，晋文公之理也。过听杀人，自拘当死。文公曰：“官有贵贱，罚有轻重。下吏有过，非子之罪也。”李离曰：“臣居官为长，不与吏让位；受禄为多，不与下分利。今过听杀人，傅其罪下吏，非所闻也。”辞不受令。|| 李离是晋文公的法官。他因误听了错误的案情而判杀了人，就把自己拘禁起来，判自己死罪。晋文公说：“官职有高有低，刑罚有轻有重。这是你手下官吏的过失，不是你的罪过。”李离说：“我担任的是长官，没有把职位让给属吏；我领的俸禄多，也没有把好处分给下属。如今我误听案情而错杀了人，却把罪责推给下属，我从没听说过有这样的道理。”他推辞，不接受文公的命令。
注：晋文公：名重耳，春秋时晋国国君，春秋五霸之一。
注：理：狱官，掌管刑狱的官。
注：过听：误听，听信了不实之辞。
注：傅：同“附”，推给，归咎。
原：文公曰：“子则自以为有罪，寡人亦有罪邪？”李离曰：“理有法，失刑则刑，失死则死。公以臣能听微决疑，故使为理。今过听杀人，罪当死。”遂不受令，伏剑而死。|| 文公说：“你认为自己有罪，那么任用你的寡人也有罪吗？”李离说：“狱官有自己的法规，错判了刑就要自己受刑，错判了死罪就要自己偿命。您因为我能明察细微、决断疑难，所以任命我做狱官。现在我误听案情错杀了人，按罪应当处死。”于是不接受命令，伏剑自杀而死。
注：失刑则刑，失死则死：误判人受刑的，自己就要受同样的刑；误判人死的，自己就要抵死。
注：听微决疑：明察细微的案情，决断疑难的案件。
# 太史公曰
原：太史公曰：孙叔敖出一言，郢市复。子产病死，郑民号哭。公仪子见好布而家妇逐。石奢纵父而死，楚昭名立。李离过杀而伏剑，晋文以正国法。|| 太史公说：孙叔敖一句话，郢都的市场就恢复了原貌。子产病逝，郑国百姓放声痛哭。公仪休看见家中织出好布，就把妻子休回娘家。石奢放走父亲后自杀，楚昭王的名声因此得以树立。李离错杀了人而伏剑自尽，晋文公借此整肃了国家法纪。
注：郢：楚国都城，在今湖北江陵西北。
