# 昭公二十一年·经
题解：本年周景王铸无射大钟，宋华、向二族据南里再叛，经鸿口、新里、赭丘诸战，在齐、晋等国援助下被围于南里；蔡侯朱被逐奔楚。传文以赭丘之战车上对射一节写得最为细致。
原：二十有一年春，王三月，葬蔡平公。|| 二十一年春季，周历三月，安葬蔡平公。
注：蔡平公：蔡国国君，名庐，上年冬去世。
注：王三月：周王历法的三月。
原：夏，晋侯使士鞅来聘。宋华亥、向宁、华定自陈入于宋南里以叛。|| 夏季，晋顷公派士鞅来鲁国聘问。¦宋国的华亥、向宁、华定从陈国进入宋都的南里，据守叛乱。
注：士鞅：晋国大夫，即范献子，士匄之子。
注：华亥、向宁、华定：宋国大夫，上年作乱失败后逃往陈国。
注：南里：宋国都城中的里名。
原：秋七月壬午朔，日有食之。|| 秋季七月初一壬午，发生日食。
注：朔：农历每月初一。
原：八月乙亥，叔辄卒。|| 八月乙亥日，叔辄去世。
注：叔辄：鲁国大夫，叔氏，传文称“子叔”；世系一说为叔弓之子，待考。
原：冬，蔡侯朱出奔楚。公如晋，至河乃复。|| 冬季，蔡侯朱逃亡到楚国。¦昭公前往晋国，到了黄河边就返回了。
注：蔡侯朱：蔡平公之子，新即位的蔡君，不久被逐。
注：至河乃复：到黄河边就回来；据传文，是晋国辞谢不受。

# 昭公二十一年·传
原：二十一年春，天王将铸无射。泠州鸠曰：“王其以心疾死乎！夫乐，天子之职也；夫音，乐之舆也；而钟，音之器也。天子省风以作乐，器以钟之，舆以行之。小者不窕，大者不槬，则和于物。物和则嘉成。故和声入于耳，而藏于心，心亿则乐。窕则不咸，总则不容，心是以感，感实生疾。今钟槬矣，王心弗堪，其能久乎？”|| 二十一年春季，周景王准备铸造名为无射的大钟。¦泠州鸠说：“天王大概会因心病而死吧！¦音乐是天子掌管的事；声音是音乐的载体；而钟是发出声音的器物。¦天子考察各地风俗来制作音乐，用乐器把声音聚合起来，用声音把音乐传播出去。¦小钟的声音不纤弱，大钟的声音不洪大过度，就能与万物和谐。¦万物和谐，美好的乐事就能成就。¦所以和谐的乐声进入耳朵，藏在心里，心安就快乐。¦声音纤弱就不能充满听觉，声音过大耳朵就容受不了，心因此受到震动，震动就会生病。¦如今这口钟声音过大了，天王的心承受不了，他能活得长久吗？”
注：天王：指周景王，名贵。
注：无射（yì）：钟名，以十二律中的无射律命名。
注：泠（líng）州鸠：周王室的乐官，泠是乐官的称呼，州鸠是名。
注：省风：考察各地风俗与风气，据以制乐。
注：窕（tiǎo）：细小不足，指钟声纤弱。
注：槬（huà）：宽大，指钟声过于洪大。
注：心亿：心中安定；亿，安。
注：校：“总则不容”，通行本作“槬则不容”，与上文“小者不窕，大者不槬”相应，“总”疑讹。
原：三月，葬蔡平公。蔡大子朱失位，位在卑。大夫送葬者归，见昭子。昭子问蔡故，以告。昭子叹曰：“蔡其亡乎！若不亡，是君也必不终。诗曰：‘不解于位，民之攸塈。’今蔡侯始即位，而适卑，身将从之。”|| 三月，安葬蔡平公。¦蔡国太子朱丧失了应有的位次，站在较低的位置。¦送葬的鲁国大夫回国，去见昭子。¦昭子问起蔡国的情况，他们就把这事告诉了他。¦昭子叹息说：“蔡国大概要灭亡了吧！¦如果不灭亡，这位国君也一定不得善终。¦《诗》说：‘在位不懈怠，百姓才能安息。’¦如今蔡侯刚即位就站到低位上去，自身也将随着降低了。”
注：大子朱：即太子朱，蔡平公之子；作为丧主，本应站在嗣君的位置上。
注：昭子：叔孙婼，鲁国叔孙氏宗主，谥昭。
注：不解于位，民之攸塈：出自《诗·大雅·假乐》；解，通“懈”；攸，所；塈（xì），安息。
原：夏，晋士鞅来聘，叔孙为政。季孙欲恶诸晋，使有司以齐鲍国归费之礼为士鞅。士鞅怒，曰：“鲍国之位下，其国小，而使鞅从其牢礼，是卑敝邑也。将复诸寡君。”鲁人恐，加四牢焉，为十一牢。|| 夏季，晋国的士鞅来鲁国聘问，当时叔孙婼主持政务。¦季孙想让叔孙在晋国结怨，便让主管官员按照招待齐国鲍国归还费邑时的礼节来接待士鞅。¦士鞅发怒说：“鲍国地位低，他的国家又小，却让我按照他所受的牲牢之礼，这是轻视我国。¦我要回去报告寡君。”¦鲁国人害怕了，增加四牢，共为十一牢。
注：叔孙为政：叔孙婼主持政务，负责接待来宾。
注：季孙：季平子季孙意如，鲁国执政大夫。
注：恶诸晋：使叔孙得罪于晋国。
注：鲍国归费之礼：鲍国，齐国大夫鲍文子；昭公十四年他送还费邑，鲁国以七牢之礼招待他。
注：牢：宴享或祭祀所用牛、羊、猪一套为一牢。
原：宋华费遂生华䝙、华多僚、华登，䝙为少司马，多僚为御士，与䝙相恶，乃谮诸公曰：“䝙将纳亡人。”亟言之。公曰：“司马以吾故，亡其良子。死亡有命，吾不可以再亡之。”对曰：“君若爱司马，则如亡。死如可逃，何远之有？”公惧，使侍人召司马之侍人宜僚，饮之酒，而使告司马。司马叹曰：“必多僚也。吾有谗子而弗能杀，吾又不死。抑君有命，可若何？”乃与公谋逐华䝙，将使田孟诸而遣之。公饮之酒，厚酬之，赐及从者。司马亦如之。张匄尤之，曰：“必有故。”使子皮承宜僚以剑而讯之。宜僚尽以告。张匄欲杀多僚，子皮曰：“司马老矣，登之谓甚，吾又重之，不如亡也。”五月丙申，子皮将见司马而行，则遇多僚御司马而朝。张匄不胜其怒，遂与子皮、臼任、郑翩杀多僚，劫司马以叛，而召亡人。壬寅，华、向入。乐大心、丰愆、华牼御诸横。华氏居卢门，以南里叛。六月庚午，宋城旧鄘及桑林之门而守之。|| 宋国华费遂生了华䝙、华多僚、华登，华䝙任少司马，多僚任御士，与华䝙互相憎恨，便在宋元公面前诬陷说：“华䝙将要接纳逃亡在外的人。”¦多次这样说。¦宋元公说：“司马因为我的缘故，已经失去了他的好儿子。¦死和逃亡都有命数，我不能再让他的儿子出亡。”¦多僚回答说：“国君如果爱护司马，就该自己出亡。¦如果死能够逃避，那么逃得多远都不算远。”¦宋元公害怕了，派侍从召来司马的侍从宜僚，请他喝酒，让他去告诉司马。¦司马叹息说：“一定是多僚干的。¦我有个进谗言的儿子却不能杀他，我自己又不死。¦况且国君已有命令，又能怎么样呢？”¦于是和宋元公商量驱逐华䝙，准备让他到孟诸打猎时把他打发走。¦宋元公请华䝙喝酒，厚赠财礼，连随从都有赏赐。¦司马也同样这样做。¦张匄觉得奇怪，说：“一定有缘故。”¦便让子皮用剑胁迫宜僚加以审问。¦宜僚全都说了出来。¦张匄想杀多僚，子皮说：“父亲老了，华登出逃已让他十分伤心，我再加重他的伤痛，不如我出逃吧。”¦五月丙申，子皮准备拜见司马后动身，正碰上多僚驾车送司马上朝。¦张匄压不住怒火，就和子皮、臼任、郑翩杀了多僚，劫持司马叛乱，并召回逃亡的人。¦壬寅，华氏、向氏进入宋都。¦乐大心、丰愆、华牼在横地抵御他们。¦华氏据守卢门，凭借南里叛乱。¦六月庚午，宋国修筑旧鄘城和桑林城门来防守。
注：华费遂：宋国大司马，华氏族人，即下文的“司马”。
注：少司马：大司马的副职。
注：御士：侍卫国君的近臣，一说掌驾车。
注：谮（zèn）：说坏话诬陷人。
注：亡人：指上年出奔陈国的华亥、向宁等人。
注：公：指宋元公，名佐。
注：良子：好儿子，指上年出奔的华登。
注：宜僚：华费遂的侍从。
注：孟诸：宋国大泽名，在今河南商丘东北。
注：张匄（gài）：华䝙的家臣。
注：子皮：即华䝙，子皮是他的字。
注：登之谓甚：华登出奔已使父亲非常伤痛。
注：臼任、郑翩：华䝙一党的宋人。
注：乐大心、丰愆、华牼：宋国站在元公一边的大夫。
注：横：宋国地名，疑在都城附近。
注：卢门：宋国都城的城门名。
注：旧鄘（yōng）：宋都旧城名，一说为城墙名，待考。
注：桑林之门：宋都城门名。
原：秋七月壬午朔，日有食之。公问于梓慎曰：“是何物也？祸福何为？”对曰：“二至二分，日有食之，不为灾。日月之行也，分同道也，至相过也。其他月则为灾，阳不克也，故常为水。”于是叔辄哭日食。昭子曰：“子叔将死，非所哭也。”八月，叔辄卒。|| 秋季七月初一壬午，发生日食。¦昭公向梓慎询问说：“这是什么征兆？¦是祸还是福？”¦梓慎回答说：“在二至二分时发生日食，不算灾异。¦日月的运行，春分秋分时同在一条道上，冬至夏至时相互交错而过。¦在其他月份发生日食就算灾异，那是阳气胜不过阴气，所以常会发生水灾。”¦当时叔辄为日食而哭。¦昭子说：“子叔快要死了，这不是他该哭的事。”¦八月，叔辄去世。
注：梓慎：鲁国大夫，精通天文星象。
注：二至二分：冬至、夏至和春分、秋分。
注：阳不克：阳气不能胜过阴气；古人以日为阳、月为阴。
注：子叔：即叔辄。
原：冬十月，华登以吴师救华氏。齐乌枝鸣戍宋。厨人濮曰：“军志有之：‘先人有夺人之心，后人有待其衰。’盍及其劳且未定也伐诸？若入而固，则华氏众矣，悔无及也。”从之。丙寅，齐师、宋师败吴师于鸿口，获其二帅公子苦雂、偃州员。华登帅其馀以败宋师。公欲出，厨人濮曰：“吾小人，可藉死，而不能送亡，君请待之。”乃徇曰：“杨徽者，公徒也。”众从之。公自杨门见之，下而巡之，曰：“国亡君死，二三子之耻也，岂专孤之罪也？”齐乌枝鸣曰：“用少莫如齐致死，齐致死莫如去备。彼多兵矣，请皆用剑。”从之。华氏北，复即之。厨人濮以裳裹首而荷以走，曰：“得华登矣！”遂败华氏于新里。翟偻新居于新里，既战，说甲于公而归。华姓居于公里，亦如之。十一月癸未，公子城以晋师至。曹翰胡会晋荀吴、齐苑何忌、卫公子朝救宋。丙戌，与华氏战于赭丘。郑翩愿为鹳，其御愿为鹅。子禄御公子城，庄堇为右。于犨御吕封人华豹，张匄为右。相遇，城还。华豹曰：“城也！”城怒而反之。将注，豹则关矣。曰：“平公之灵，尚辅相余！”豹射，出其间。将注，则又关矣。曰：“不狎，鄙！”抽矢。城射之，殪。张匄抽殳而下，射之，折股。扶伏而击之，折轸。又射之，死。干犨请一矢，城曰：“余言汝于君。”封曰：“不死伍乘，军之大刑也。干刑而从子，君焉用之？子速诸！”乃射之，殪。大败华氏，围诸南里。华亥搏膺而呼，见华䝙，曰：“吾为栾氏矣！”䝙曰：“子无我迋。不幸而后亡。”使华登如楚乞师。华䝙以车十五乘、徒七十人犯师而出，食于睢上，哭而送之，乃复入。楚薳越帅师将逆华氏。大宰犯谏曰：“诸侯唯宋事其君，今又争国，释君而臣是助，无乃不可乎？”王曰：“而告我也后，既许之矣。”|| 冬季十月，华登带着吴国军队来救援华氏。¦齐国的乌枝鸣戍守宋国。¦厨邑大夫濮说：“《军志》上有这样的话：‘先发制人可以夺去敌人的斗志，后发制人要等待敌人衰竭。’¦何不趁他们疲劳而且尚未安定时去攻打？¦如果他们进来以后站稳脚跟，华氏的人就多了，后悔就来不及了。”¦宋人听从了他。¦丙寅，齐军、宋军在鸿口打败吴军，俘获了吴军两名将领公子苦雂和偃州员。¦华登率领剩下的军队打败了宋军。¦宋元公想逃走，厨人濮说：“我是小人物，可以为国君战死，却不能护送国君逃亡，请国君等一等。”¦于是在军中巡行宣告说：“挥动旗帜的人，就是国君的士兵。”¦众人都听从了。¦宋元公从扬门看见了他们，走下城楼巡视众人，说：“国家灭亡国君死去，这是你们诸位的耻辱，难道只是我一个人的罪过吗？”¦乌枝鸣说：“使用少量兵力，不如一齐拼死；一齐拼死，不如撤去防护装备。¦他们兵器很多，请都用剑和他们拼杀。”¦宋人听从了他。¦华氏败逃，宋军又追上去。¦厨人濮用衣裳包着一颗人头扛着奔跑，喊道：“我杀了华登了！”¦于是在新里打败了华氏。¦翟偻新住在新里，战斗结束后，到元公那里脱下铠甲归附公室。¦华姓住在公里，也同样这样做。¦十一月癸未，公子城带着晋国军队到达。¦曹国的翰胡会合晋国的荀吴、齐国的苑何忌、卫国的公子朝救援宋国。¦丙戌，与华氏在赭丘交战。¦郑翩想布鹳阵，他的御者想布鹅阵。¦子禄为公子城驾车，庄堇担任车右。¦干犨为吕封人华豹驾车，张匄担任车右。¦两车相遇，公子城掉头退回。¦华豹喊道：“城啊！”¦公子城发怒，回车迎战。¦公子城正要搭箭，华豹已经拉满了弓。¦公子城说：“平公的神灵，希望保佑我！”¦华豹放箭，箭从公子城和御者之间穿过。¦公子城又要搭箭，华豹又已经拉满了弓。¦公子城说：“不让我轮流射一箭，太卑鄙了！”¦华豹便把箭从弦上抽了下来。¦公子城射他，把他射死了。¦张匄拿着殳跳下车，公子城射他，射断了他的大腿。¦张匄爬过去用殳击打，打断了公子城的车轸。¦公子城再射他，他死了。¦干犨请求公子城射自己一箭，公子城说：“我会在国君面前为你说情。”¦干犨说：“不和同车的人一起死，是军中的重刑。¦犯了军刑而跟从您，国君哪里用得着我？¦您快射吧！”¦公子城就射了他，把他射死了。¦宋军大败华氏，把他们围困在南里。¦华亥捶胸呼喊，见到华䝙，说：“我们要成为栾氏了！”¦华䝙说：“您不要吓唬我。¦只有不走运才会灭亡。”¦于是派华登到楚国请求出兵。¦华䝙带着十五辆战车、七十名步兵冲出包围，在睢水边吃了饭，哭着送别华登，然后又冲回南里。¦楚国的薳越率军准备迎接华氏。¦太宰犯劝谏说：“诸侯之中只有宋国的臣下还事奉他们的国君，如今又来争夺国家，舍弃国君而帮助臣下，恐怕不可以吧？”¦楚平王说：“你告诉我晚了，我已经答应他们了。”
注：华登以吴师：华登上年出奔吴国，此时带吴兵来救华氏。
注：乌枝鸣：齐国大夫。
注：厨人濮：宋国厨邑的大夫，名濮；一说为掌膳食之官，待考。
注：军志：古代兵书名，已佚。
注：鸿口：宋国地名，在今河南商丘一带。
注：公子苦雂、偃州员：吴军的两名将领。
注：藉死：借以一死，指为国君效死。
注：杨徽：举起旗帜；杨，通“扬”；徽，旗帜。
注：杨门：宋都城门名。
注：二三子：你们诸位。
注：齐致死：一齐拼死作战。
注：去备：撤去盾甲等防护装备。
注：北：败逃。
注：新里：宋都内的里名。

# 昭公二十三年·经

# 昭公二十三年·传
原：二十三年春，王正月壬寅朔，二师围郊。癸卯，郊、𬩽溃。丁未，晋师在平阴，王师在泽邑。王使告间，庚戌，还。|| 二十三年春季，周历正月初一壬寅，两国军队包围郊地。¦癸卯，郊地和鄩地溃散。¦丁未，晋军驻在平阴，王师驻在泽邑。¦敬王派人告诉晋军局势已经缓和，庚戌，晋军回国。

注：𬩽：即鄩（xún），周地名。
注：平阴、泽邑：周地名。
注：告间：报告局势稍有缓和；间，病情好转，引申为缓和。
原：邾人城翼，还，将自离姑。公孙鉏曰：“鲁将御我。”欲自武城还，循山而南。徐鉏、丘弱、茅地曰：“道下，遇雨，将不出，是不归也。”遂自离姑。武城人塞其前，断其后之木而弗殊。邾师过之，乃推而蹙之，遂取邾师，获鉏、弱、地。邾人愬于晋，晋人来讨。叔孙婼如晋，晋人执之。书曰“晋人执我行人叔孙婼”，言使人也。晋人使与邾大夫坐。叔孙曰：“列国之卿当小国之君，固周制也。邾又夷也。寡君之命介子服回在，请使当之，不敢废周制故也。”乃不果坐。韩宣子使邾人取其众，将以叔孙与之。叔孙闻之，去众与兵而朝。士弥牟谓韩宣子曰：“子弗良图，而以叔孙与其仇，叔孙必死之。鲁亡叔孙，必亡邾。邾君亡国，将焉归？子虽悔之，何及？所谓盟主，讨违命也。若皆相执，焉用盟主？”乃弗与，使各居一馆。士伯听其辞而愬诸宣子，乃皆执之。士伯御叔孙，从者四人，过邾馆以如吏。先归邾子。士伯曰：“以刍荛之难，从者之病，将馆子于都。”叔孙旦而立，期焉。乃馆诸箕。舍子服昭伯于他邑。范献子求货于叔孙，使请冠焉。取其冠法，而与之两冠，曰：“尽矣。”为叔孙故，申丰以货如晋。叔孙曰：“见我，吾告女所行货。”见，而不出。吏人之与叔孙居于箕者，请其吠狗，弗与。及将归，杀而与之食之。叔孙所馆者，虽一日必葺其墙屋，去之如始至。|| 邾国人在翼地筑城，回国时，准备取道离姑。¦公孙鉏说：“鲁国会阻击我们。”¦想从武城返回，沿着山向南走。¦徐鉏、丘弱、茅地说：“道路低洼，遇上下雨，就出不去了，这是回不了国的。”¦于是仍从离姑经过。¦武城人在前面堵截，把他们后面的树木砍得将断未断。¦邾军过去后，就推倒树木，把他们困住，于是俘获了邾军，抓住了徐鉏、丘弱、茅地。¦邾国人向晋国控诉，晋国人来鲁国问罪。¦叔孙婼前往晋国，晋国人拘捕了他。¦《春秋》记载“晋人执我行人叔孙婼”，是说他是使者。¦晋国人让叔孙婼和邾国大夫对质。¦叔孙说：“列国的卿相当于小国的国君，这本来就是周朝的制度。¦何况邾国又是夷人。¦寡君任命的副使子服回在这里，请让他去对质，这是因为不敢废弃周朝的制度。”¦于是没有对质。¦韩宣子让邾国人聚集他们的人众，准备把叔孙交给他们。¦叔孙听说了，不带随从和兵器去朝见。¦士弥牟对韩宣子说：“您不好好考虑，却把叔孙交给他的仇人，叔孙一定会为此而死。¦鲁国失去叔孙，一定会灭掉邾国。¦邾君失去国家，将回到哪里去？¦您即使后悔，又怎么来得及？¦所谓盟主，是讨伐违背命令的国家的。¦如果都互相拘捕，哪里还用得着盟主？”¦于是没有把叔孙交出去，让两方各住一个馆舍。¦士伯听取了双方的申辩，然后报告韩宣子，于是把两人都拘禁起来。¦士伯为叔孙驾车，只带四个随从，经过邾国人的馆舍前往官吏那里。¦晋国先把邾君放回国。¦士伯说：“因为柴草供应困难，随从辛苦，要把您安置到别的城邑去。”¦叔孙从清早就站着，等候命令。¦于是把他安置在箕地。¦把子服昭伯安置在另一个城邑。¦范献子向叔孙索取财货，派人向他求取帽子。¦叔孙取来那人帽子的尺寸，送给他两顶帽子，说：“全在这里了。”¦为了叔孙的缘故，申丰带着财货到晋国去。¦叔孙说：“来见我，我告诉你财货该送给谁。”¦申丰见了叔孙，叔孙就把他留住不让出去。¦和叔孙同住在箕地的晋国官吏，向他讨要看门的狗，叔孙不给。¦等到将要回国时，叔孙把狗杀了给他们吃。¦叔孙住过的馆舍，即使只住一天，也一定修葺墙壁房屋，离开时像刚到时一样。

# 昭公二十四年·经
