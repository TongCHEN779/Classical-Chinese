# 哀公元年·经
题解：鲁哀公即位，楚围蔡，吴败越于夫椒而许越求和，齐卫伐晋以救范氏。传文以伍员谏阻许越、逢滑论陈不可弃楚、子西论吴将自败三段长篇说辞为主体。
原：元年春，王正月，公即位。楚子、陈侯、随侯、许男围蔡。鼷鼠食郊牛，改卜牛。|| 元年春季，周历正月，哀公即位。¦楚昭王、陈侯、随侯、许男包围蔡国。¦小鼷鼠咬伤了郊祭用的牛，于是改卜另一头牛。
注：公即位：鲁哀公名蒋，定公之子。
注：楚子：楚昭王，名轸。
注：随侯：随国国君；随为姬姓国，在今湖北随州，时附属于楚。
注：许男：许国国君，姜姓，爵为男。
注：鼷（xī）鼠：一种很小的鼠。
注：郊牛：郊祭上天所用的牛，须先占卜选定。
原：夏，四月，辛巳郊。|| 夏季，四月辛巳日，举行郊祭。
注：郊：在国都南郊祭天；一说郊祭当在正月，四月举行已经失时，所以经文记下。
原：秋，齐侯、卫侯伐晋。|| 秋季，齐侯、卫侯攻打晋国。
注：齐侯、卫侯：齐景公与卫灵公，此时支持晋国的范氏、中行氏。
原：冬，仲孙何忌帅师伐邾。|| 冬季，仲孙何忌率军攻打邾国。
注：仲孙何忌：鲁卿，即孟懿子。
注：邾（zhū）：国名，曹姓，在今山东邹城一带。

# 哀公元年·传
原：元年春，楚子围蔡，报柏举也。里而栽，广丈，高倍。夫屯，昼夜九日，如子西之素。蔡人男女以辨，使疆于江、汝之间，而还。蔡于是乎请迁于吴，吴王夫差败越于夫椒，报檇李也，遂入越。越子以甲楯五千，保于会稽，使大夫种因吴大宰嚭以行成。吴子将许之，伍员曰：“不可。臣闻之：‘树德莫如滋，去疾莫如尽。’昔有过浇，杀斟灌以伐斟𬩽，灭夏后相。后缗方娠，逃出自窦，归于有仍，生少康焉，为仍牧正，惎浇能戒之。浇使椒求之，逃奔有虞，为之庖正，以除其害。虞思于是妻之以二姚，而邑诸纶，有田一成，有众一旅，能布其德，而兆其谋，以收夏众，抚其官职；使女艾谍浇，使季杼诱豷，遂灭过、戈，复禹之绩，祀夏配天，不失旧物。今吴不如过，而越大于少康，或将丰之，不亦难乎！句践能亲而务施，施不失人，亲不弃劳，与我同壤，而世为仇雠，于是乎克而弗取，将又存之，违天而长寇仇，后虽悔之，不可食巳。姬之衰也，日可俟也；介在蛮夷，而长寇仇，以是求伯，必不行矣。”弗听，退而告人曰：“越十年生聚，而十年教训；二十年之外，吴其为沼乎！”|| 元年春季，楚昭王包围蔡国，是为了报复柏举之战。¦楚军在离蔡都一里处筑起围垒，宽一丈，高二丈。¦士兵驻守其中，昼夜不停干了九天，完全按照子西预先的规划。¦蔡国人把男女分别排列出来投降，楚国让蔡国迁到长江和汝水之间，然后撤兵。¦蔡国于是向吴国请求迁到吴国附近；吴王夫差在夫椒打败越国，报复檇李之役，接着攻入越国。¦越王带着五千名披甲持盾的士兵退守会稽，派大夫文种通过吴国太宰嚭去求和。¦吴王打算答应，伍员说：“不行。¦我听说：‘树立德行最好是不断增益，去除疾患最好是彻底根除。’¦从前有过国的浇，杀了斟灌，又攻打斟鄩，灭掉夏后相。¦相的妻子后缗正怀着身孕，从墙洞逃出，回到娘家有仍氏，生下了少康；少康后来做了有仍氏的牧正，对浇心怀仇恨而又能处处戒备。¦浇派椒去搜捕他，少康逃奔有虞氏，做了那里的庖正，才躲开了浇的祸害。¦有虞国君虞思于是把两个女儿嫁给他，把纶邑封给他，有方圆十里的田地，有五百人的部众；他能广施恩德，开始谋划复国，收聚夏朝遗民，安抚旧日官员；又派女艾到浇那里刺探，派季杼去引诱豷，终于灭掉了过国和戈国，恢复了大禹的功业，祭祀夏朝祖先并以之配享上天，没有失去旧有的典章器物。¦如今吴国不如当年的过国，而越国比少康强大，如果让越国壮大起来，不也难办了吗！¦勾践能亲近人又致力施惠，施惠不漏掉一个人，亲近不遗弃有功劳的人；越国与我国土地相连，又世代为仇，现在战胜了却不吞并，反而要保存它，这是违背天意而助长仇敌，以后即使后悔，也来不及消除了。¦姬姓的衰落，指日可待了；我们处在蛮夷之间，却还助长仇敌，凭这样去求取霸业，一定行不通。”¦夫差不听，伍员退下后对人说：“越国用十年繁衍人口、积聚财力，再用十年教育训练；二十年以后，吴国的宫室恐怕要变成池沼了！”
注：柏举：地名，在今湖北麻城一带；定公四年吴军在此大败楚军，随后攻入郢都。
注：栽：筑墙时竖立的板，这里指筑起围垒。
注：子西：楚令尹，即公子申。
注：江、汝之间：长江与汝水之间，属楚国境内。
注：夫椒：地名，一说在今江苏太湖中，一说在今浙江绍兴北，待考。
注：檇（zuì）李：地名，在今浙江嘉兴南；定公十四年越在此击败吴军，吴王阖庐伤重而死。
注：会（kuài）稽：山名，在今浙江绍兴东南。
注：大夫种：越大夫文种。
注：嚭（pǐ）：伯嚭，吴国太宰。
注：伍员（yún）：即伍子胥，楚人，父兄被楚平王所杀后奔吴，为吴大夫。
注：过浇（ào）：过国国君浇，寒浞之子，传说中篡夏之人。
注：斟灌、斟𬩽：夏的同姓诸侯国；斟𬩽即斟鄩（xún）。
注：后缗（mín）：夏后相的妻子，有仍氏之女。
注：惎（jì）：怨恨。
注：牧正：掌管畜牧的官长。
注：庖正：掌管膳食的官长。
注：虞思：有虞国君，舜的后裔，姚姓。
注：一成：方圆十里的土地。
注：一旅：五百人。
注：女艾：少康的臣子。
注：季杼（zhù）：少康之子，即后来的夏帝杼。
注：豷（yì）：浇的弟弟，封于戈。
注：校：“不可食巳”之“巳”，当作“已”，疑形近而误。
注：姬之衰：吴国为姬姓，这里指吴国将衰。
注：沼：池沼，指国家灭亡、宫室荒废。
原：三月，越及吴平，吴入越不书。吴不告庆，越不告败也。|| 三月，越国与吴国讲和，吴国攻入越国这件事《春秋》没有记载。¦这是因为吴国没有来报告胜利，越国也没有来报告失败。
注：不书：《春秋》不记载；鲁史一般依据别国来告才记录，未来告则不书。
原：夏，四月，齐侯、卫侯救邯郸，围五鹿。吴之入楚也，使召陈怀公，怀公朝国人而问焉，曰：“欲与楚者右，欲与吴者左。陈人从田，无田从党。”逢滑当公而进曰：“臣闻国之兴也以福，其亡也以祸。今吴未有福，楚未有祸，楚未可弃，吴未可从；而晋盟主也，若以晋辞，吴若何？”公曰：“国胜君亡，非祸而何？”对曰：“国之有是多矣，何必不复？小国犹复，况大国乎？臣闻国之兴也，视民如伤，是其福也；其亡也，以民为土芥，是其祸也。楚虽无德，亦不艾杀其民；吴日敝于兵，暴骨如莽，而未见德焉。天其或者正训楚也，祸之适吴，其何日之有？”陈侯从之，及夫差克越，乃修先君之怨。|| 夏季，四月，齐侯、卫侯救援邯郸，包围五鹿。¦当初吴国攻入楚国时，派人召见陈怀公，怀公召集国人询问，说：“想亲附楚国的站到右边，想亲附吴国的站到左边。¦陈国人有田地的按田地所在方位站，没有田地的跟随亲族站。”¦逢滑正对着怀公走上前说：“我听说国家兴盛是由于有福，灭亡是由于有祸。¦如今吴国还没有福，楚国还没有祸，楚国不可抛弃，吴国不可跟从；而且晋国是盟主，如果用晋国作推辞，吴国能怎么样呢？”¦怀公说：“楚国被攻破，国君出逃，这不是祸又是什么？”¦逢滑回答说：“国家遭遇这种事的多了，凭什么说它一定不能恢复？¦小国尚且能恢复，何况大国呢？¦我听说国家兴盛时，看待百姓如同看待伤病之人，这是它的福；国家灭亡时，把百姓当作泥土草芥，这是它的祸。¦楚国即使没有德行，也不肆意杀戮百姓；吴国天天被战争拖累，暴露的尸骨像野草一样多，却看不到它施行德政。¦上天或许正是借此教训楚国，而祸患降到吴国头上，还会要多少日子呢？”¦陈怀公听从了他；等到夫差战胜越国，便要报复先君时结下的怨恨。
注：五鹿：晋邑，一说在今河北大名东，一说在今河南濮阳北。
注：陈怀公：陈国国君，名柳。
注：从田：按田地所在方位站队；一说田近楚者从楚，近吴者从吴。
注：逢（páng）滑：陈大夫。
注：土芥：泥土和小草，比喻极其轻贱。
注：先君之怨：指陈怀公当年不应吴王阖庐之召而结下的怨恨。
原：秋，八月，吴侵陈，修旧怨也。齐侯、卫侯会于干侯，救范氏也。师及齐师、卫孔圉、鲜虞人伐晋，取棘蒲。吴师在陈，楚大夫皆惧曰：“阖庐惟能用其民，以败我于柏举，今闻其嗣又甚焉，将若之何？”子西曰：“二三子恤不相睦，无患吴矣。昔阖庐食不二味，居不重席，室不崇坛，器不彤镂，宫室不观，舟车不饰，衣服财用，择不取费；在国，天有菑疠，亲巡其孤寡，而共其乏困；在军，熟食者分而后敢食，其所尝者，卒乘与焉，勤恤其民，而与之劳逸：是以民不罢劳，死不知旷，吾先大夫子常易之，所以败我也。今闻夫差，次有台榭陂池焉，宿有妃嫱嫔御焉，一日之行，所欲必成，玩好必从，珍异是聚，观乐是务，视民如仇，而用之日新，夫先自败也已，安能败我？”|| 秋季，八月，吴国侵袭陈国，这是为了报复旧怨。¦齐侯、卫侯在乾侯会见，是为了救援范氏。¦鲁军与齐军、卫国孔圉以及鲜虞人一起攻打晋国，攻取棘蒲。¦吴军驻扎在陈国，楚国大夫都很害怕，说：“阖庐只因善于使用他的百姓，就在柏举打败了我们；如今听说他的继承人比他更厉害，该怎么办？”¦子西说：“诸位只须担心彼此不和睦，不必担忧吴国。¦从前阖庐吃饭不用两样菜，坐不铺两层席子，房屋不建在高台上，器物不加红漆雕饰，宫室不造楼台观榭，车船不加装饰，衣服和财物，选用不浪费的；在国内，上天降下灾害疫病，他亲自巡视孤儿寡妇，供给他们缺乏的东西；在军中，熟食分给士兵以后自己才敢吃，他品尝的珍味，士卒也都有份；他勤于抚恤百姓，与他们同劳同逸：因此百姓不觉疲劳，死了也知道不是白死；我们的先大夫子常反其道而行，所以吴国能打败我们。¦如今听说夫差，驻扎下来就有台榭池沼，住宿时有嫔妃侍女，即使出行一天，想要的也一定要办到，玩好之物一定随身，搜罗珍奇异物，专心观赏享乐，看待百姓如同仇人，而且每天都有新的役使，这是先自取失败了，怎么能打败我们呢？”
注：干侯：即乾侯，晋邑，在今河北成安东南。
注：范氏：晋卿士吉射一族，与中行氏据朝歌对抗晋君和赵鞅。
注：师：杜预以为指鲁国军队。
注：孔圉（yǔ）：卫大夫，即孔文子。
注：鲜虞：白狄所建之国，在今河北正定一带，后称中山。
注：棘蒲：晋邑，一说在今河北赵县，待考。
注：阖庐：吴王，夫差之父，即位后重用伍员等人，国势大盛。
注：子常：楚令尹囊瓦，柏举之战战败后逃往郑国。
注：旷：空，白白地；“死不知旷”指死者不觉得是白白送死。
注：妃嫱（qiáng）嫔御：君主的姬妾与宫中侍女。
原：冬，十一月，晋赵鞅伐朝歌。|| 冬季，十一月，晋国赵鞅攻打朝歌。
注：赵鞅：晋卿，即赵简子，时执晋政。
注：朝（zhāo）歌：晋邑，在今河南淇县，当时为范氏、中行氏所占据。

# 哀公二年·经
题解：鲁伐邾取漷、沂之田，卫灵公卒而立孙辄，赵鞅纳卫太子蒯聩于戚，晋郑战于铁，蔡迁州来。传文详写赵鞅誓师之辞、蒯聩祷词及战后众人争功。
原：二年春，王二月，季孙斯、叔孙州仇、仲孙何忌帅师伐邾，取漷东田及沂西田。癸巳，叔孙州仇、仲孙何忌及邾人盟于句绎。|| 二年春季，周历二月，季孙斯、叔孙州仇、仲孙何忌率军攻打邾国，夺取了漷水以东和沂水以西的田地。¦癸巳日，叔孙州仇、仲孙何忌与邾国人在句绎结盟。
注：季孙斯：鲁卿，即季桓子。
注：叔孙州仇：鲁卿，即叔孙武叔。
注：漷（kuò）：水名，在今山东滕州一带。
注：沂：水名，这里指鲁国境内的沂水，具体所指一说为小沂水，待考。
注：句（gōu）绎：邾地，在今山东邹城东南。
原：夏，四月，丙子，卫侯元卒。滕子来朝。晋赵鞅帅师纳卫世子蒯瞆于戚。|| 夏季，四月丙子日，卫灵公元去世。¦滕国国君来鲁国朝见。¦晋国赵鞅率军把卫国太子蒯聩送回戚地。
注：卫侯元：卫灵公，名元。
注：滕子：滕国国君，子爵；据后文，当是滕顷公结。
注：世子蒯瞆（kuǎi kuì）：卫灵公太子，定公十四年谋杀灵公夫人南子未成，出奔宋，后至晋；传文作“蒯聩”。
注：戚：卫邑，在今河南濮阳北。
原：秋，八月，甲戌，晋赵鞅帅师及郑罕达帅师战于铁，郑师败绩。|| 秋季，八月甲戌日，晋国赵鞅率军与郑国罕达率领的军队在铁地交战，郑军大败。
注：罕达：郑卿，字子姚。
注：铁：卫地，即铁丘，在今河南濮阳西北。
注：败绩：军队溃败。
原：冬，十月，葬卫灵公。|| 冬季，十月，安葬卫灵公。
注：卫灵公：卫国国君，名元，在位四十二年。
原：十有一月，蔡迁于州来。蔡杀其大夫公子驷。|| 十一月，蔡国迁都到州来。¦蔡国杀了他们的大夫公子驷。
注：州来：本为楚邑，后为吴所有，在今安徽凤台。
注：公子驷：蔡大夫，反对依附吴国迁都。

# 哀公二年·传
原：二年春，伐邾，将伐绞。邾人爱其土，故赂以漷、沂之田而受盟。初，卫侯游于郊，子南仆。公曰：“余无子，将立女。”不对。他日又谓之，对曰：“郢不足以辱社稷，君其改图。君夫人在堂，三揖在下，君命祇辱。”|| 二年春季，鲁国攻打邾国，打算先攻打绞地。¦邾国人爱惜那里的土地，所以用漷水、沂水一带的田地作贿赂，接受了盟约。¦当初，卫灵公在郊外游玩，公子郢为他驾车。¦灵公说：“我没有太子，打算立你。”¦郢没有回答。¦过些日子灵公又对他说起，郢回答说：“我不配玷辱社稷，请君主另作打算。¦君夫人在堂上，卿大夫们在堂下，君主不和他们商量而私下命令我，只会让我蒙受耻辱。”
注：绞：邾邑，地望待考。
注：子南：卫灵公之子公子郢，字子南。
注：仆：驾车。
注：君夫人：指卫灵公夫人南子。
注：三揖：指卿、大夫、士三等臣属，国君对他们各有揖礼，这里代指群臣。
注：祇（zhǐ）：只，恰恰。

# 哀公三年·经
题解：鲁宫失火，桓、僖之庙被焚，季孙斯卒而季氏立嗣生变，晋赵鞅围朝歌，周人杀苌弘。传文细述救火时各官的调度与号令。

# 哀公三年·传
原：三年春，齐、卫围戚，求援于中山。|| 三年春季，齐国、卫国包围戚地，戚地向中山求援。

原：夏，五月，辛卯，司铎火。火逾公宫，桓、僖灾。救火者皆曰：“顾府。”南宫敬叔至，命周人出御书，俟于宫，曰：“庀女而不在，死。”子服景伯至，命宰人出礼书，以待命，命不共，有常刑。校人乘马，巾车脂辖，百官官备，府库慎守，官人肃给。济濡帷幕，郁攸从之，蒙茸公屋，自大庙始，外内以悛，助所不给。有不用命，则有常刑，无赦。公父文伯至，命校人驾乘车。季桓子至，御公立于象魏之外，命救火者伤人则止，财可为也。命藏象魏，曰：“旧章不可亡也。”富父槐至，曰：“无备而官办者，犹拾渖也。”于是乎去表之稿，道还公宫。孔子在陈，闻火，曰：“其桓、僖乎！”刘氏、范氏世为婚姻，苌弘事刘文公，故周与范氏。赵鞅以为讨。|| 夏季，五月辛卯日，司铎官署失火。¦火势越过公宫，烧毁了桓公庙和僖公庙。¦救火的人都说：“先照看府库。”¦南宫敬叔赶到，命令周人搬出国君所阅的书籍，在宫中等候，说：“交给你们保管，如有丢失，处死。”¦子服景伯赶到，命令宰人搬出礼书，等待命令，有命令而不供职的，按常刑处置。¦校人套好马匹，巾车给车辖涂上油脂，百官各守其职，府库严加看守，官员们严肃供应所需。¦把帷幕浸湿，跟着火势去覆盖，用湿物盖住公宫的屋顶，从太庙开始，由外到内依次进行，帮助人手不足的地方。¦有不服从命令的，就按常刑处置，决不赦免。¦公父文伯赶到，命令校人为国君套好车。¦季桓子赶到，为哀公驾车，站在象魏外面，命令救火的人：伤了人就停止，财物可以再造。¦又命令收藏好象魏上的法令，说：“旧的典章不能丢失。”¦富父槐赶到，说：“没有预备而让官员仓促应付，就像拾取泼出去的汁水一样。”¦于是清除火道上的干草，在公宫四周开出隔火道。¦孔子在陈国，听说鲁国失火，说：“大概是桓公、僖公的庙吧！”¦刘氏、范氏世代通婚，苌弘事奉刘文公，所以周室偏袒范氏。¦赵鞅因此向周室问罪。

# 哀公六年·传
原：六年春，晋伐鲜虞，治范氏之乱也。吴伐陈，复修旧怨也。楚子曰：“吾先君与陈有盟，不可以不救。”乃救陈，师于城父。齐陈乞伪事高、国者，每朝必骖乘焉。所从必言诸大夫，曰：“彼皆偃蹇，将弃子之命。皆曰：‘高、国得君，必偪我，盍去诸？’固将谋子，子早图之。图之，莫如尽灭之。需，事之下也。”及朝，则曰：“彼，虎狼也，见我在子之侧，杀我无日矣，请就之位。”又谓诸大夫曰：“二子者祸矣，恃得君而欲谋二三子，曰：‘国之多难，贵宠之由，尽去之而后君定。’既成谋矣，盍及其未作也先诸？作而后悔，亦无及也。”大夫从之。|| 六年春季，晋国攻打鲜虞，是为了惩治它参与范氏之乱。¦吴国攻打陈国，是再次报复旧怨。¦楚昭王说：“我们先君与陈国有盟约，不能不救。”¦于是救援陈国，驻军在城父。¦齐国陈乞假装事奉高氏、国氏，每次他们上朝，必定陪乘在车上。¦跟随时就对他们讲大夫们的坏话，说：“他们都很骄横，将要不听从您的命令。¦他们都说：‘高氏、国氏得到国君宠信，必定逼迫我们，何不除掉他们？’¦他们本来就要谋算您，您要早作打算。¦要打算的话，不如把他们全部消灭。¦迟疑等待，是办事的下策。”¦到了朝廷上，又说：“他们是虎狼，见我在您身边，杀我是早晚的事了，请让我回到自己的位置上去。”¦又对大夫们说：“那两个人要作祸了，倚仗得到国君宠信而想谋害诸位，他们说：‘国家多难，是由于贵宠之臣，全部除掉他们以后国君才能安定。’¦他们已经定好计谋了，为什么不趁他们还没动手抢先下手呢？¦等他们动手后再后悔，也来不及了。”¦大夫们听从了他。
