# 昭公十五年·经
题解：本年晋国荀吴伐鲜虞、围鼓，拒绝接受叛降而以信义取城；周景王先后丧太子寿与穆后，宴晋使时索求彝器，有籍谈“数典忘祖”之事。经文简记吴子卒、叔弓卒于祭等事，传文多借人物对话展开议论。
原：十有五年春，王正月，吴子夷末卒。|| 昭公十五年春季，周历正月，吴王夷末去世。
注：吴子夷末：吴国国君，寿梦之子，诸樊之弟，又作夷昧、馀昧。
注：王正月：周历正月；《春秋》纪月前冠“王”，表示奉行周王的历法。
原：二月癸酉，有事于武宫，籥入，叔弓卒。去乐，卒事。|| 二月癸酉日，在武公庙举行祭祀，执籥的舞者进场时，叔弓去世。¦撤去音乐，把祭事进行完毕。
注：有事：指举行祭祀。
注：武宫：鲁武公的庙。
注：籥（yuè）入：执籥的舞者入庙起舞；籥，一种管乐器，文舞时所执。
注：叔弓：鲁国大夫，谥敬子。
原：夏，蔡朝吴出奔郑。|| 夏季，蔡国的朝吴逃亡到郑国。
注：朝吴：蔡国大夫，蔡声子之子，曾助楚平王得位，平王复立蔡国后居于蔡。
原：六月丁巳朔，日有食之。|| 六月丁巳初一，发生日食。
注：朔：农历每月初一。
原：秋，晋荀吴帅师伐鲜虞。|| 秋季，晋国荀吴率领军队攻打鲜虞。
注：荀吴：晋国卿，中行氏，谥穆子。
注：鲜虞：白狄所建之国，在今河北正定一带，后称中山。
原：冬，公如晋。|| 冬季，昭公前往晋国。
注：公：指鲁昭公，名稠。

# 昭公十五年·传
原：十五年春，将禘于武公，戒百官。梓慎曰：“禘之日，其有咎乎！吾见赤墨之祲，非祭祥也，丧氛也。其在莅事乎！”二月癸酉，禘，叔弓莅事，籥入而卒。去乐，卒事，礼也。|| 十五年春季，鲁国准备在武公庙举行禘祭，告诫百官斋戒。¦梓慎说：“禘祭那天，恐怕会有灾祸吧！¦我看见了红黑色的妖气，这不是祭祀的吉兆，而是丧事的凶气。¦大概会应在主持祭事的人身上吧！”¦二月癸酉日，举行禘祭，叔弓主持祭事，执籥的舞者进场时他就死了。¦撤去音乐，把祭事进行完毕，这是合乎礼的。
注：禘（dì）：宗庙的大祭。
注：戒百官：告诫百官预先斋戒。
注：梓慎：鲁国大夫，善观天象、占验吉凶。
注：祲（jìn）：古人所谓预示吉凶的云气。
注：莅事：到场主持祭事。
原：楚费无极害朝吴之在蔡也，欲去之，乃谓之曰：“王唯信子，故处子于蔡。子亦长矣，而在下位，辱。必求之，吾助子请。”又谓其上之人曰：“王唯信吴，故处诸蔡。二三子莫之如也，而在其上，不亦难乎？弗图，必及于难。”夏，蔡人逐朝吴，朝吴出奔郑。王怒曰：“余唯信吴，故寘诸蔡。且微吴，吾不及此。女何故去之？”无极对曰：“臣岂不欲吴？然而前知其为人之异也。吴在蔡，蔡必速飞。去吴，所以翦其翼也。”|| 楚国的费无极嫉恨朝吴在蔡国得势，想除掉他，就对朝吴说：“君王只信任您，所以把您安置在蔡国。¦您年纪也不小了，却处在低位，这是耻辱。¦一定要谋求高位，我帮您去请求。”¦又对朝吴的上级们说：“君王只信任朝吴，所以把他安置在蔡国。¦你们几位都比不上他，却位居他之上，不是很危险吗？¦不早作打算，一定会遭祸。”¦夏季，蔡国人赶走了朝吴，朝吴逃亡到郑国。¦楚平王发怒说：“我只信任朝吴，所以把他安置在蔡国。¦况且如果没有朝吴，我到不了今天的地位。¦你为什么赶走他？”¦费无极回答说：“下臣难道不想要朝吴吗？¦但是早就知道他为人与众不同。¦朝吴在蔡国，蔡国必定很快就会高飞而去。¦赶走朝吴，正是为了剪除蔡国的翅膀。”
注：费无极：楚国大夫，楚平王的宠臣，以谗毁著称。
注：王：指楚平王。
注：二三子：诸位，指位居朝吴之上的蔡国诸大夫。
注：微：如果没有。
注：吾不及此：楚平王争位时，朝吴曾率蔡人相助，故有此语。
注：翦其翼：剪去它的翅膀，比喻削弱蔡国，使其不能脱离楚国。
原：六月乙丑，王大子寿卒。|| 六月乙丑日，周景王的太子寿去世。
注：王大子寿：周景王的太子，名寿；大子，即太子。
原：秋八月戊寅，王穆后崩。|| 秋季八月戊寅日，周景王的王后穆后去世。
注：穆后：周景王的王后，太子寿之母。
注：崩：天子、王后去世称崩。
原：晋荀吴帅师伐鲜虞，围鼓。鼓人或请以城叛，穆子弗许。左右曰：“师徒不勤，而可以获城，何故不为？”穆子曰：“吾闻诸叔向曰：‘好恶不愆，民知所适，事无不济。’或以吾城叛，吾所甚恶也；人以城来，吾独何好焉？赏所甚恶，若所好何？若其弗赏，是失信也，何以庇民？力能则进，否则退，量力而行。吾不可以欲城而迩奸，所丧滋多。”使鼓人杀叛人而缮守备。围鼓三月，鼓人或请降。使其民见，曰：“犹有食色，姑修而城。”军吏曰：“获城而弗取，勤民而顿兵，何以事君？”穆子曰：“吾以事君也。获一邑而教民怠，将焉用邑？邑以贾怠，不如完旧。贾怠无卒，弃旧不祥。鼓人能事其君，我亦能事吾君。率义不爽，好恶不愆，城可获而民知义所，有死命而无二心，不亦可乎？”鼓人告食竭力尽，而后取之。克鼓而反，不戮一人，以鼓子截鞮归。|| 晋国荀吴率领军队攻打鲜虞，包围了鼓国。¦鼓国有人请求献城反叛来归，荀吴不答应。¦左右的人说：“不必劳累军队就可以得到城邑，为什么不干？”¦荀吴说：“我从叔向那里听说：‘喜好和厌恶都不出差错，百姓就知道该往哪里去，事情没有办不成的。’¦有人拿我们的城邑反叛，是我最痛恨的；别人带着城邑来投降，我为什么偏偏喜欢呢？¦奖赏我最痛恨的行为，那对我所喜欢的又该怎么办？¦如果不奖赏他，就是失信，又凭什么庇护百姓？¦力量能做到就前进，不能就后退，估量自己的力量去行事。¦我不能因为想得到城邑而接近奸邪，那样损失会更多。”¦于是让鼓国人杀掉叛徒，修缮守备。¦包围鼓国三个月，鼓国有人请求投降。¦荀吴让鼓国的百姓来相见，说：“看你们的脸色还像有饭吃，姑且回去修好你们的城防吧。”¦军吏说：“能得到城邑却不取，使百姓劳苦、损耗兵力，拿什么来事奉国君？”¦荀吴说：“我正是用这个来事奉国君的。¦得到一座城邑却教百姓懈怠，要城邑做什么用？¦用城邑换来懈怠，不如保全原有的勤勉。¦换来懈怠没有好结局，丢弃原有的品德不吉利。¦鼓国人能够事奉他们的国君，我也能够事奉我的国君。¦遵循道义不出差错，喜好厌恶不出偏失，城邑可以得到，百姓也懂得道义所在，肯为君命效死而没有二心，不也是可以的吗？”¦直到鼓国人报告粮食吃完、力量用尽，然后才攻取了它。¦攻克鼓国后返回，没有杀一个人，带着鼓国国君截鞮回国。
注：鼓：白狄别种所建的小国，附属于鲜虞，在今河北晋州一带。
注：穆子：即荀吴，谥穆。
注：叔向：晋国大夫羊舌肸（xī），字叔向，以博学知礼著称。
注：愆（qiān）：过失，差错。
注：迩奸：接近奸邪之人。
注：食色：吃饱饭的面色，表明城中尚有存粮。
注：顿兵：使兵力疲敝受损。
注：贾（gǔ）怠：换来懈怠；贾，买，换取。
注：完旧：保全原有的东西，指百姓原有的勤勉和忠信。
注：率义不爽：遵循道义没有差错；爽，差失。
注：鼓子截鞮：鼓国国君，名截鞮。
注：校：截鞮，通行本多作“鸢鞮”，疑形近而异，待考。
原：冬，公如晋，平丘之会故也。|| 冬季，昭公前往晋国，这是由于平丘之会的缘故。
注：平丘之会：昭公十三年晋合诸侯于平丘，以鲁侵邾、莒为由不许鲁昭公与盟，并拘留季孙意如，所以昭公前往晋国修好。
原：十二月，晋荀跞如周，葬穆后，籍谈为介。既葬，除丧，以文伯宴，樽以鲁壶。王曰：“伯氏，诸侯皆有以镇抚王室，晋独无有，何也？”文伯揖籍谈。对曰：“诸侯之封也，皆受明器于王室，以镇抚其社稷，故能荐彝器于王。晋居深山，戎狄之与邻，而远于王室，王灵不及，拜戎不暇，其何以献器？”王曰：“叔氏，而忘诸乎！叔父唐叔，成王之母弟也，其反无分乎？密须之鼓与其大路，文所以大蒐也；阙巩之甲，武所以克商也。唐叔受之，以处参虚，匡有戎狄。其后襄之二路，戚钺、秬鬯，彤弓、虎贲，文公受之，以有南阳之田，抚征东夏，非分而何？夫有勋而不废，有绩而载，奉之以土田，抚之以彝器，旌之以车服，明之以文章，子孙不忘，所谓福也。福祚之不登，叔父焉在？且昔而高祖孙伯黡司晋之典籍，以为大政，故曰籍氏。及辛有之二子董之晋，于是乎有董史。女，司典之后也，何故忘之？”籍谈不能对。宾出，王曰：“籍父其无后乎！数典而忘其祖。”籍谈归，以告叔向。叔向曰：“王其不终乎！吾闻之：‘所乐必卒焉。’今王乐忧，若卒以忧，不可谓终。王一岁而有三年之丧二焉，于是乎以丧宾宴，又求彝器，乐忧甚矣，且非礼也。彝器之来，嘉功之由，非由丧也。三年之丧，虽贵遂服，礼也。王虽弗遂，宴乐以早，亦非礼也。礼，王之大经也。一动而失二礼，无大经矣。言以考典，典以志经。忘经而多言，举典，将焉用之？”|| 十二月，晋国荀跞到成周去，参加穆后的葬礼，籍谈做副使。¦安葬完毕后，除去丧服，周景王设宴招待荀跞，用鲁国进献的壶作酒樽。¦周景王说：“伯氏，诸侯都有礼器进献来镇抚王室，唯独晋国没有，为什么？”¦荀跞向籍谈作揖，请他回答。¦籍谈回答说：“诸侯受封的时候，都从王室接受了宝器，用来镇抚他们的国家，所以能向天子进献彝器。¦晋国处在深山之中，与戎狄为邻，远离王室，天子的威灵达不到，忙于应付戎人还来不及，哪里能献上礼器呢？”¦周景王说：“叔氏，你忘了吗！¦叔父唐叔是成王的同母弟弟，难道反而没有得到赏赐吗？¦密须的大鼓和大路车，是文王用来检阅军队的；阙巩的铠甲，是武王用来战胜商朝的。¦唐叔接受了这些，用来居处在参星的分野，治理戎狄。¦此后襄王所赐的两辆大车，斧钺、黑黍香酒，红色的弓、勇士，文公接受了，因而拥有南阳的土地，安抚征讨东方诸国，这不是赏赐又是什么？¦有了功勋不被废弃，有了功绩就记载在册，用土地来奉养他，用彝器来安抚他，用车马服饰来表彰他，用旌旗文饰来显扬他，使子孙不忘，这就是所谓的福。¦这样的福禄不加记载，叔父的功业又在哪里呢？¦而且从前你的高祖孙伯黡掌管晋国的典籍，主持国家大政，所以称为籍氏。¦到辛有的两个儿子到晋国董理史事，晋国从此才有董史。¦你是掌管典籍者的后代，为什么忘了这些呢？”¦籍谈回答不出来。¦宾客退出后，周景王说：“籍父恐怕没有后嗣了吧！¦列举典故却忘了自己的祖先。”¦籍谈回国后，把这件事告诉了叔向。¦叔向说：“天子恐怕不得善终吧！¦我听说：‘一个人以什么为乐，必定死于什么。’¦如今天子以忧为乐，如果因忧而死，就不能叫作善终。¦天子一年之中有了两次三年之丧，却在这时与吊丧的宾客宴饮，又索求彝器，以忧为乐太过分了，而且也不合礼。¦彝器的到来，是由于嘉奖功勋，不是由于丧事。¦三年之丧，即使尊贵也要服满，这是礼。¦天子即使不服满丧期，过早地宴饮作乐，也是不合礼的。¦礼，是天子的重大法则。¦一个举动就失去了两项礼，就没有重大法则了。¦言语用来考究典籍，典籍用来记载法则。¦忘记了法则而多发言论，举出典故又有什么用呢？”
注：荀跞（lì）：晋国大夫，谥文子，即下文的文伯。
注：籍谈：晋国大夫，籍氏，为晋国掌管典籍者的后代。
注：介：副使。
注：樽以鲁壶：用鲁国所献的壶作酒樽。
注：伯氏：周王对正使荀跞的称呼。
注：明器：这里指天子分赐诸侯的宝器。
注：彝器：宗庙常用的礼器，如钟鼎之类。
注：叔氏：周王对副使籍谈的称呼。
注：唐叔：晋国始封君叔虞，周成王之弟，封于唐。
注：密须之鼓：密须国的大鼓；密须，商时姞姓国，在今甘肃灵台一带，为文王所灭。
注：大路：天子、诸侯所乘的大车；路，通“辂”。
注：阙巩之甲：阙巩国所产的铠甲；阙巩地望待考。
注：参（shēn）虚：参星的分野，指晋地。
注：襄之二路：周襄王赐给晋文公的两辆车，指城濮之战后所赐的大辂、戎辂。
注：戚钺：斧钺，象征征伐之权。
注：秬鬯（jù chàng）：用黑黍和郁金草酿成的香酒，用于祭祀。
注：彤弓、虎贲：红色的弓和勇猛的卫士，都是天子赐予方伯的。
注：南阳之田：指晋文公勤王后周襄王所赐的阳樊、温、原等地，在今河南济源、沁阳一带。
注：东夏：东方诸国。
注：孙伯黡（yǎn）：籍谈的高祖，晋国掌管典籍的官员。
注：辛有：周平王时大夫，其子入晋为史官，为董氏之祖。
注：董史：晋国董氏世袭的史官。
注：籍父：周王对籍谈的称呼。
注：数典而忘其祖：列举典章故事，却忘记了自己祖先的职守。
注：三年之丧：太子寿与穆后先后去世，周王为嫡子、王后都要服三年之丧。
注：遂服：服满丧期。
注：大经：根本的法则。

# 昭公十六年·经
题解：本年鲁昭公在晋被扣留，晋昭公去世；郑国子产拒绝以玉环送给韩宣子，郑国六卿为韩宣子饯行时赋诗言志。传文以子产与韩起的往来为主，兼记鲁国子服昭伯论晋政。
原：十有六年春，齐侯伐徐。楚子诱戎蛮子杀之。|| 昭公十六年春季，齐景公攻打徐国。¦楚平王诱骗戎蛮的国君，并杀了他。
注：齐侯：齐景公，名杵臼。
注：徐：嬴姓国，在今江苏泗洪一带。
注：戎蛮子：戎蛮国君，名嘉；戎蛮在今河南汝州一带。
注：楚子：楚平王，名弃疾，即位后改名熊居。
原：夏，公至自晋。|| 夏季，昭公从晋国回来。
注：公至自晋：国君出行归来，告于宗庙，《春秋》书“至自某”。
原：秋八月己亥，晋侯夷卒。|| 秋季八月己亥日，晋昭公夷去世。
注：晋侯夷：晋昭公，名夷，晋平公之子。
原：九月，大雩。季孙意如如晋。|| 九月，举行盛大的求雨祭祀。¦季孙意如前往晋国。
注：大雩（yú）：盛大的求雨祭祀。
注：季孙意如：鲁国执政卿，谥平子。
原：冬十月，葬晋昭公。|| 冬季十月，安葬晋昭公。
