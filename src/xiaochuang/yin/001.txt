# 001｜任大冶引
题解：卷首诸引是任大冶、汝调鼎、徐履吉、倪煌、陆绍琏为《剑扫》（即《小窗幽记》）所作的序文，称赞陆绍珩摘录古今清言，用来扫除俗情、唤醒世人的沉醉。原站残缺处以“。。。”“？”“□”标示，照录不补，白话中注明有缺文。
原：今夫载籍浩繁，指归直捷。六经《语》《孟》，总蕲开豁心灵；诸子百家，无非透露性术。故片语居要，则累牍连篇，皆成注脚；而谈言微中，即村讴里曲，致足解颐。悟得满山碧绿青黄，头头是道；恁举眼前砂石瓦砾，片片皆金。矧其冷客孤吟，寄趣颇同禅悦；而幽人癖韵，命意不诡宗风。是岂不比《击壤》歌沧，可资采录，犹愈于《齐谐》棘问，备载逍遥者哉？|| 典籍浩繁众多，但它们的宗旨却直截了当。¦六经和《论语》《孟子》，总是希望开启人的心灵；诸子百家之书，也无非是揭示人的心性与心术。¦所以只要一句话切中要害，那么连篇累牍的文字都成了它的注脚；言谈若能委婉地切中事理，即使是乡村里巷的小曲，也足以使人开颜欢笑。¦领悟了道理，满山的青绿黄碧，处处都合于大道；任凭拿起眼前的砂石瓦砾，片片都是黄金。¦况且冷落的客子独自吟咏，所寄托的意趣颇与参禅的喜悦相同；隐士的癖好与风韵，立意也不违背禅家的宗风。¦这岂不是可以和《击壤歌》、沧浪之歌相比，值得采录，更胜过《齐谐》所记、商汤问棘那样专门记载逍遥之事的文字吗？
注：蕲（qí）：求，希望。
注：性术：心性与心术。
注：谈言微中（zhòng）：语出《史记·滑稽列传》，指言谈委婉而切中要害。
注：解颐：开颜而笑。
注：头头是道：原为禅家语，指处处都合于道。
注：恁：任凭。
注：矧（shěn）：况且。
注：禅悦：参禅入定所得的喜悦。
注：宗风：禅宗各家的门风。
注：《击壤》：相传尧时老人击壤而歌，即《击壤歌》。
注：歌沧：疑指“沧浪之水清兮”的《孺子歌》，与《击壤》同属古代民歌。
注：《齐谐》棘问：《庄子·逍遥游》称“齐谐者，志怪者也”，又引“汤之问棘也是已”，两者都与逍遥之说相关。

# 002｜任大冶引
原：湘客陆君，寄情二酉。探玄微于邺架，摘以丹铅；志感慨于秦灰，命曰《剑扫》。盖愤俗情之沿袭，而断以慧刀；亦悯世界之沉迷，而渡之宝筏。试当酒后，或际茶馀，巡檐读映梅花，隔座如闻松籁，便觉名利顿尽，清虚欲来。生公应为点头，平子且当绝倒，何必搘颐拄 颊，听水声于田间；斗酒双柑，聆黄鹂于春日也。只恐厌实逃虚，哆口都羞垄断；而借虚博实，托足乃是终南。对宾客说有谈空，舌本芳兰可掇；课童仆求田问舍，胸中柴栅未忘。譬之火宅僧听偈参禅，欲念不胜扰扰，何必粉黛招挑；又如瞌睡汉当场演剧，鼾睡尚尔齁齁，矧听朱弦疏越？此等妖魔，剑不能扫；念兹恶趣，笔亦空灵。倘谓剑术之未工，吾更为湘客说剑。|| 湘客陆君，把情趣寄托在书籍之中。¦他在丰富的藏书中探求玄妙精微的道理，用丹铅圈点摘录；在劫后残存的典籍中寄托感慨，把书取名为《剑扫》。¦大概是愤恨世俗之情相沿成习，便用智慧之刀斩断它；也是怜悯世人沉迷不悟，便用宝筏来超度他们。¦试着在酒后或饮茶之余，沿着屋檐、映着梅花来读它，好像隔座听到松涛之声，便觉得名利之心顿时消尽，清静虚灵之境将要到来。¦竺道生若在也会为之点头，王平子也会为之倾倒，又何必托着下巴、撑着脸颊，到田间去听流水声；或带着一斗酒、两只柑子，在春日里去听黄鹂鸣叫呢？¦只怕有人厌弃实务、逃入虚无，张口便以垄断谋利为羞；却又借清虚之名博取实利，把隐居当作进身的终南捷径。¦对着宾客谈有说空，舌尖上仿佛能拾取芳兰；督促童仆买田置屋，心中的藩篱却始终没有忘掉。¦这好比火宅中的僧人听偈参禅，欲念已经纷扰不止，何必还要美色来挑逗；又如瞌睡汉当场演戏，鼾声尚且齁齁不断，更何况去听朱弦疏越的雅乐呢？¦这一类妖魔，剑也扫除不了；想到这种恶劣的趣味，笔墨也显得空灵无力。¦倘若说这是剑术还不够精湛，那我就再为湘客讲一讲剑术吧。
注：二酉：大酉山、小酉山，相传山洞中藏书千卷，后用以指藏书丰富。
注：邺架：唐代李泌封邺侯，家中藏书极多，后称藏书为邺架。
注：丹铅：朱砂和铅粉，古人校书点勘所用。
注：秦灰：秦始皇焚书的灰烬，这里借指劫后残存的古籍。
注：宝筏：佛家语，比喻引渡众生脱离苦海的佛法。
注：生公：东晋高僧竺道生，相传他讲经时顽石为之点头。
注：平子：西晋王澄字平子，每听卫玠谈玄，便叹服倾倒，事见《晋书·卫玠传》。
注：搘（zhī）颐拄颊：托着下巴、撑着脸颊，形容闲坐沉思之态。
注：斗酒双柑：相传南朝宋戴颙春日携双柑斗酒，说是去听黄鹂声。
注：哆（chǐ）口：张口。
注：垄断：语出《孟子·公孙丑下》，本指高地，后指操纵独占以谋利。
注：终南：唐代卢藏用隐居终南山以求仕进，人称“终南捷径”。
注：说有谈空：谈论佛理中的“有”与“空”，泛指清谈玄理。
注：柴栅：篱笆，比喻心中未除的俗念与隔阂。
注：火宅：佛家语，《法华经》以着火的房屋比喻充满苦难的世间。
注：齁（hōu）齁：鼾声。
注：朱弦疏越：语出《礼记·乐记》，指瑟上的朱红丝弦和底部的疏孔，代指古雅的音乐。
注：校：原文“拄 颊”中间有空格，照录。

# 004｜汝调鼎引
原：晋代风流，宋人名理，两者为今日士子门户。始角于口舌，而议论日纷；既沦于肺肠，而营垒日固。三千年来，须眉丈夫似盲眼，不能点洗；三千年洁净世界，昏昏蒙蒙，总陷利欲场中。嗟乎！嗟乎！尚忍言哉。余痛此恶习，恨无寸铁发其新硎。|| 晋代的风流，宋人的名理，这两者成了今天读书人的门户。¦起初只在口舌上较量，于是议论一天比一天纷繁；后来深入肺腑，于是门户壁垒一天比一天坚固。¦三千年来，男子汉们像瞎了眼，无法点拨洗净；三千年的清净世界，昏昏蒙蒙，全都陷进了追逐利欲的场中。¦唉！¦唉！¦还忍心说下去吗。¦我痛恨这种恶习，只恨没有一把新磨的利刃来斩除它。
注：晋代风流：魏晋名士清谈放达的风度。
注：宋人名理：宋儒辨析义理、性命的学问。
注：门户：派别，门户之见。
注：须眉丈夫：男子。
注：新硎（xíng）：刚在磨刀石上磨过；语本《庄子·养生主》“刀刃若新发于硎”。

# 005｜汝调鼎引
原：吾邑湘客陆氏，天随先生世裔也。腹有锦，口有绣，腕有神，具一时之慧眼，广万世之婆心。甲子秋，偕予囊寸剑，走秣陵，振衣凤台之巅，濯足燕矶之流，远眺钟山氤氲，近挹桃渡笙歌，目饱心醉，此中兴致不浅。三馀之暇，遂以居恒所阅古今清史，披襟再检，博观约取，手录一编，曰《剑扫》，此诚暗室一灯、苦海三老也。|| 我们县的湘客陆君，是天随先生陆龟蒙的后代。¦他腹中有锦绣文章，口中有华美言辞，手腕下有神来之笔，具备一时的慧眼，推广万世的慈悲心肠。¦甲子年秋天，他和我各带一把短剑，前往秣陵，在凤凰台顶抖落衣上的尘土，在燕子矶下的江流中洗脚，远望钟山云气氤氲，近听桃叶渡的笙歌，眼目饱览、心中陶醉，其中兴致不浅。¦在读书的闲暇里，他便把平时所读的古今清雅之书，敞开胸襟重新检阅，广泛阅读、精要选取，亲手抄录成一编，取名《剑扫》，这真是暗室中的一盏明灯、苦海中的老练船夫啊。
注：天随先生：唐代陆龟蒙，号天随子，吴郡人。
注：腹有锦：比喻胸中富于文采。
注：婆心：慈悲恳切之心。
注：秣（mò）陵：今江苏南京的古称。
注：振衣、濯（zhuó）足：语本左思《咏史》“振衣千仞冈，濯足万里流”，表示超脱尘俗。
注：凤台：凤凰台，在南京。
注：燕矶：燕子矶，在南京长江边。
注：桃渡：桃叶渡，秦淮河上的渡口，相传因王献之送其妾桃叶而得名。
注：挹（yì）：舀取，这里指领略。
注：三馀：三国董遇主张以冬天、夜晚、阴雨天这三种空闲读书。
注：三老：一说指船上掌舵、撑篙的老练船工。

# 006｜汝调鼎引
原：夫谈兵说剑，自是世宙有心汉子事，当此士节日阴之时，而俾青电白虹之气、剸犀断蛟之利立试之，其锋芒不可逼视，海内且磨厉以须矣。呜呼！尘埃则干镆失光，颜色则铅刀增彩，世有赏音，而床头之刃宁终在匣也哉？|| 谈论兵法、讲说剑术，本是世间有心志的男子所做的事；在这士人节操日渐晦暗的时候，让这部书带着青电白虹般的剑气、斩犀断蛟般的锋利立即一试，其锋芒必定令人不可逼视，天下之人也将磨砺以待了。¦唉！¦蒙上尘埃，干将、镆铘这样的名剑也会失去光彩；涂上颜色，铅刀也能增添光彩；世上若有知音赏识，床头的宝剑难道会始终藏在匣中吗？
注：世宙：世间。
注：士节日阴：士人的节操日益晦暗。
注：青电白虹：形容剑光如电如虹。
注：剸（tuán）：割断。
注：磨厉以须：磨利兵器以待，语本《左传·昭公十二年》“摩厉以须”。
注：干镆（mò）：干将、镆铘，古代名剑。
注：铅刀：铅制的刀，钝而无用。
注：赏音：知音，赏识的人。

# 008｜徐履吉引
原：内弟湘客从建康返旆，造余。。。余询场后所修何业，则出一帙以示予曰，此古今名人麈下清谈也。客窗闲。。。拣选而汇集之，名曰《剑扫》。二三同志索付剞劂，咸作文以冠其首，请君续笔焉。予思湘客年甫弱冠，方雅志进取，才一鏊翮，胡以还作是。。。也？噫嘻，余知之其目击世态之繁华，士汇之。。。争名者耽耽于朝；争利者逐逐于市。且且丑虏跳梁，乱珰擅政，牛李苏程之党，互相排挤，日甚一日，私心窃厌贱之，必当扫之而后愉快。|| 内弟湘客从建康回来，前来拜访我（以下有缺文）。¦我问他考完之后在修习什么学业，他就拿出一册书给我看，说：这是古今名人挥麈清谈的言语。¦在客居窗下闲暇时（以下有缺文）。¦挑选并汇集起来，取名为《剑扫》。¦几位志同道合的朋友要把它刻印，都写了文章放在书前，请您接着也写一篇。¦我想湘客年纪刚满二十，正怀着进取的雅志，才刚振翅高飞，为什么反倒做起这样的（以下有缺文）¦事来呢？¦唉，我明白了，他亲眼看到世态的繁华，士人群中（以下有缺文）。¦争名的人在朝廷上虎视眈眈；争利的人在市井中奔走追逐。¦加上外寇猖獗跳梁，作乱的宦官专擅朝政，像唐代牛李、宋代苏程那样的朋党互相排挤，一天比一天厉害，他内心暗自厌恶鄙视，一定要扫除这些才觉得痛快。
注：内弟：妻子的弟弟。
注：建康：今江苏南京的古称。
注：返旆（pèi）：回来；旆，旗帜。
注：造：拜访。
注：场后：科举考试之后。
注：麈（zhǔ）下清谈：魏晋名士清谈时常手执麈尾，后以“麈谈”指清谈。
注：剞劂（jī jué）：刻书用的刀具，代指刻版印书。
注：弱冠：古代男子二十岁行冠礼，称弱冠。
注：校：“鏊翮”疑有误字，暂按振翅高飞理解。
注：耽耽：同“眈眈”，注视而有所贪求的样子。
注：校：“且且”疑衍一“且”字。
注：丑虏：对敌寇的蔑称，这里当指当时的后金。
注：乱珰（dāng）：专权乱政的宦官；珰，宦官帽上的饰物，代指宦官。
注：牛李：唐代牛僧孺、李德裕两派的党争。
注：苏程：北宋苏轼的蜀党与程颐的洛党之争。
注：。。。：原站缺字标记，照录。

# 009｜徐履吉引
原：第欲去世界之尘纷，须藉无形之干将；思清人情之魔障，必。。。用之吹毛。剑术精而无坚不破，无劲不摧。城府得以立消，营垒得以顿劈。欹物搴旗之功，顷刻而弃。其新刻一出，而高人达士于呻吟。。。之馀，试练几上，助以清香苦茗朗诵一过，自然渣滓日去，清虚日来；两腋风生，飘飘乎欲仙矣。又奚俗情之难拂哉！|| 只是想要去除世间的尘俗纷扰，必须借助无形的干将宝剑；想要清除人情的魔障，必定（以下有缺文）¦用它那吹毛可断的锋刃。¦剑术精湛，就没有坚固之物不能攻破，没有强劲之敌不能摧毁。¦深藏的城府可以立刻消除，坚固的营垒可以顿时劈开。¦推倒敌物、拔取敌旗那样的功劳，顷刻之间便可弃之不顾。¦这部新刻本一问世，高人达士在吟咏（以下有缺文）¦之余，把它放在几案上试着研读，再以清香和苦茶相助，朗诵一遍，自然杂念渣滓一天天去除，清静虚灵一天天到来；两腋生风，飘飘然像要成仙了。¦又何愁俗情难以拂去呢！
注：第：只是。
注：干将：古代名剑。
注：吹毛：吹毛断发，形容剑刃极其锋利。
注：欹（qī）：倾侧，这里指推倒。
注：搴（qiān）旗：拔取敌人的旗帜。
注：校：“欹物搴旗之功，顷刻而弃”文意不甚通，疑有误字，暂按字面解。
注：两腋风生：语本卢仝咏茶诗“惟觉两腋习习清风生”。
注：奚：何。

# 011｜倪煌引
原：自苍颉绳契启文明，蝌虫禽鸟，亦莫不以一行一画自见于天地之间。而文字之秽杂亦甚矣。迨其后祖龙生，而咸阳一焰尽其秽，而？之不可谓非。古今一大快事也。至于今一劫于村壁文？之间，再劫于？稿试牍之内，三劫于剞劂梨枣之中，而秽杂更不可言矣。安得祖龙再生，复然咸阳已灰之焰，大扫今日之秽乎！？？倪生拍手狂叫曰：“？？？有陆湘客剑扫在！”|| 自从苍颉结绳书契、开启文明，蝌蚪文、虫书、鸟篆等字体，也无不以一笔一画显现在天地之间。¦然而文字的污秽杂乱也很严重了。¦到后来秦始皇出世，咸阳一把大火烧尽了这些污秽，而（此处有缺字）¦这不能说不是。¦古今一件大快人心的事。¦到了今天，文字一劫于乡村墙壁上的文（此处有缺字）¦之间，再劫于（此处有缺字）¦稿和应试文卷之中，三劫于刻版印行的书籍之中，污秽杂乱更是说不尽了。¦怎样才能让秦始皇再生，重新点燃咸阳已成灰烬的大火，大扫今天的污秽呢！（此处有缺字）¦倪生拍手狂叫道：“（此处有缺字）¦有陆湘客的《剑扫》在！”
注：苍颉：即仓颉，传说中造字的人。
注：绳契：结绳记事与刻木书契。
注：蝌虫禽鸟：指蝌蚪文、虫书、鸟篆等古字体。
注：祖龙：指秦始皇。
注：咸阳一焰：指秦始皇焚书。
注：然：同“燃”。
注：梨枣：古代刻书多用梨木、枣木，代指书版。
注：试牍：应试的文章。
注：？：原站缺字标记，照录。

# 013｜陆绍琏引
原：一卷则有一卷之善，观书一日则有一日之善。是以沈□之晚学，典册。。。不十成读书，苏子瞻与王庠书云：“少年为学者，每一书皆作数次读之。富如入海，百货皆有，凡人之精力，不能兼收尽取，但得其所欲求者耳。”退之韩公云：“纪事者必提其要,纂言者必钩其玄。”。。。读书之次，参数公之语，而得余弟《剑扫》之。。。弟生平无他好，惟嗜古人书。得其隽语。。。会心处，辄手录珍玩，沾沾作数日喜。积而成帙，如陈年石，如亲密友，秘不欲令人知。|| 读一卷书就有一卷书的益处，读一天书就有一天书的益处。¦因此沈某晚年为学，典籍（以下有缺文）¦读书不求十成；苏子瞻在给王庠的信中说：“年轻人求学，每一部书都要分几次来读。¦书籍丰富如同进入大海，各种货物应有尽有，人的精力不能全部兼收，只能得到自己所要求的东西罢了。”¦韩退之说：“记事的文字一定要提取它的要点，纂集言论一定要探求它的精微。”¦（此处有缺文。）¦读书的间隙，参照这几位先生的话，从而领会了我弟弟《剑扫》的（以下有缺文）¦我弟弟生平没有别的爱好，只嗜好古人的书。¦读到其中的隽永语句（以下有缺文）¦会心之处，就亲手抄录、珍藏玩味，自得地高兴好几天。¦积累成册，像珍藏多年的奇石，像亲密的朋友，秘藏起来不想让人知道。
注：沈□：原站缺字，所指人物不详。
注：苏子瞻：苏轼字子瞻。
注：王庠（xiáng）：北宋人，与苏轼有书信往来。
注：退之韩公：韩愈字退之；所引两句出自其《进学解》，即“提要钩玄”的出处。
注：校：“不十成读书”文意难明，暂按字面解；引韩语中的半角逗号照录。
注：沾沾：自得的样子。
注：帙（zhì）：书套，代指成册的书。

# 014｜陆绍琏引
原：甲子秋，以试。。。得失之际，澹泊如也。已而出新编相。。。乃畴昔之珍秘，而诸友强以付梓者也。。。展读一过，觉清虚日来，真可齐物我而忘得丧。新编之。。。可以扫一心，即可以醒众醉。学术经济，原非。。。不折之业。何必。。。弟其韬光敛锐，无轻用其馀。。。发砺而试之，精光不可近，视则干城之。。。岂止为一剑之任耶！予不敏不聪，以云间伯仲相埒，而书癖。。。不唯能读而且能到，不唯独嗜而且众好。因附数语，以志予喜，并志予愧。|| 甲子年秋天，他因参加考试（以下有缺文）¦在得失之际，他淡泊安然。¦不久拿出新编的书（以下有缺文）¦原来是他往日珍藏的秘本，被朋友们极力劝说而付印的。（以下有缺文）¦展开读了一遍，觉得清静虚灵一天天到来，真可以把物我看成一体，忘掉得失。¦这部新编的（以下有缺文）¦可以扫除一个人心中的尘垢，也就可以唤醒众人的沉醉。¦学术和经世济民的事业，原本并非（以下有缺文）¦不折的事业。¦何必（以下有缺文）¦希望弟弟收敛光芒和锋芒，不要轻易动用他余下的（以下有缺文）¦磨砺后再试用，精光令人不可接近，看来则是捍卫国家的（以下有缺文）¦岂只是担当一把剑的职责呢！¦我不聪敏，因为和弟弟就像云间陆氏兄弟一样不相上下，而嗜书的癖好（以下有缺文）¦不但能读，而且能领会到位；不但自己独嗜，而且与众人同好。¦因此附上几句话，用来记下我的欣喜，也记下我的惭愧。
注：澹泊如：淡泊安然的样子。
注：付梓（zǐ）：刻版印行；梓，刻书用的木板。
注：齐物我：把物与我看成一体，语本《庄子·齐物论》。
注：得丧：得失。
注：经济：经世济民。
注：韬光敛锐：收敛光芒与锋芒，不显露才能。
注：干城：盾牌和城墙，比喻捍卫者，语出《诗经·周南·兔罝》“公侯干城”。
注：云间伯仲：西晋陆机、陆云兄弟，云间（今上海松江）人；这里以同姓兄弟自比。
注：相埒（liè）：相等。
