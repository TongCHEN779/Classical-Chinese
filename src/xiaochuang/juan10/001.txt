# 卷首语
题解：卷十以“豪”为纲，推崇胸襟开阔、胆识过人的豪杰气概，借诗酒、剑书与山水抒写不平之气和超迈之志。
原：今世矩视尺步之辈，与夫守株待兔之流，是不束缚而阱者也。宇宙寥寥，求一豪者，安得哉？家徒四壁，一掷千金，豪之胆；兴酣落笔，泼墨千言，豪之才；我才必用，黄金复来，豪之语。夫豪既不可得，而后世倜傥之士，或以一言一字写其不平，又安与沈沈故纸同为销没乎！集豪第十。|| 当今那些循规蹈矩、步步拘守的人，以及守株待兔、不知变通的人，都是没有人捆绑却自陷牢笼的人。¦天地之间空空荡荡，想找一个豪杰之士，哪里找得到呢？¦家中只有四面墙壁，却能一掷千金，这是豪杰的胆量；兴致酣畅时提笔，挥洒千言，这是豪杰的才气；“我的才能必有用处，黄金散尽还会再来”，这是豪杰的言语。¦豪杰既然难以得到，那么后世洒脱不羁的人，有时用片言只字抒写心中的不平，又怎能让它们同那些沉埋的旧纸一起湮没呢！¦因此把“豪”汇为第十集。
注：矩视尺步：目光与步履都拘守规矩，形容拘谨刻板。
注：守株待兔：典出《韩非子·五蠹》，宋人见兔撞树桩而死，便守着树桩等兔，比喻拘泥而不知变通。
注：阱：这里用作动词，落入陷阱，指自我拘禁。
注：家徒四壁：家中只有四面墙，形容贫穷；语本《史记·司马相如列传》“家居徒四壁立”。
注：我才必用，黄金复来：化用李白《将进酒》“天生我材必有用，千金散尽还复来”。
注：倜傥（tì tǎng）：洒脱不拘。
注：沈沈故纸：同“沉沉”，指堆积沉埋的旧书旧纸。

# 1
原：桃花马上，春衫少年侠气；贝叶斋中，夜衲老去禅心。|| 骑着桃花马的春衫少年，满是侠义豪气；在贝叶经相伴的书斋里，披着僧衣夜坐的老人，渐渐老去而禅心安定。
注：桃花马：毛色白中带红点的马，古诗中多写少年骑乘。
注：贝叶：贝多罗树的叶子，古印度用来书写佛经，代指佛经。
注：衲（nà）：僧衣；一说“夜衲”指夜间坐禅的僧人。

# 2
原：岳色江声，富煞胸中邱壑；松阴花影，争残局上山河。|| 山岳的景色、江水的声响，使胸中丘壑无比丰富；在松荫花影下对弈，于残局之上争夺山河。
注：富煞：极为丰富；煞，表示程度极深。
注：邱壑：同“丘壑”，山水景致，比喻胸中的境界与构思。
注：残局上山河：指棋局，把棋盘上的争夺比作争夺天下。

# 3
原：骥虽伏枥，足能千里；鹄即垂翅，志在九霄。|| 良马虽然伏在马槽边，脚力仍能日行千里；天鹅即使垂下翅膀，志向仍在九霄之上。
注：骥虽伏枥：化用曹操《龟虽寿》“老骥伏枥，志在千里”；枥（lì），马槽。
注：鹄（hú）：天鹅。
注：即：即使。

# 4
原：个个题诗，写不尽千秋花月；人人作画，描不完大地江山。|| 人人题诗，也写不尽千秋的花月；人人作画，也描不完大地的江山。
注：千秋花月：千百年来的美好风物。
注：写不尽、描不完：极言自然风物无穷，非人力所能穷尽。

# 5
原：慷慨之气，龙泉知我；忧煎之思，毛颖解人。|| 慷慨激昂的意气，只有宝剑懂我；忧愁煎熬的心思，唯有毛笔能体会。
注：龙泉：宝剑名，即龙渊剑，后泛指宝剑。
注：毛颖：毛笔的别称，出自韩愈《毛颖传》。
注：解人：理解人的心意。

# 6
原：不能用世而故为玩世，只恐遇著真英雄；不能经世而故为欺世，只好对著假豪杰。|| 不能为世所用，便故意游戏人间，只怕遇上真英雄；不能治理世事，便故意欺世盗名，也只好对着假豪杰去施展。
注：用世：为世所用，施展抱负。
注：玩世：以不恭的态度对待世事。
注：经世：治理世事。
注：遇著：遇着；著，同“着”。

# 7
原：绿酒但倾，何妨易醉；黄金既散，何论复来。|| 美酒只管倾倒，何妨容易喝醉；黄金既已散尽，又何必计较它能否再来。
注：绿酒：古时新酿的酒带浅绿色，泛指美酒。
注：但：只管。
注：何论复来：反用李白《将进酒》“千金散尽还复来”。

# 8
原：诗酒兴将残，剩却楼头几明月；登临情不己，平分江上半青山。|| 吟诗饮酒的兴致将尽，只剩下楼头几度明月；登山临水的情怀未了，与人平分江上的半壁青山。
注：剩却：剩下；却，助词。
注：登临：登山临水。
注：校：“不己”当作“不已”，形近而误。

# 9
原：闲行消白日，悬李贺呕字之囊；搔首问青天，携谢朓惊人之句。|| 悠闲漫步消磨白天，身上挂着李贺那样盛放诗句的锦囊；搔着头向青天发问，随身带着谢朓那样惊人的诗句。
注：李贺呕字之囊：李商隐《李贺小传》载，李贺出行背着古锦囊，得句即投入囊中，其母说这孩子要把心呕出来才罢休。
注：谢朓（tiǎo）：南齐诗人，诗风清丽，为李白所推崇。
注：搔首问青天：《云仙散录》载李白登华山，叹恨不曾携谢朓惊人之句来，“搔首问青天耳”，此句即用其事。

# 10
原：假英雄专吷不鸣之剑，若尔锋铓，遇真人而落胆；穷豪杰惯作无米之炊，此等作用，当大计而扬眉。|| 假英雄专门对着不会鸣响的剑吹出细声，像他那样的锋芒，遇到真正的人物就会丧胆；穷困的豪杰惯于做无米之炊，这样的本事，到大考核时便可扬眉吐气。
注：吷（xuè）：吹剑环发出的微小声响；《庄子·则阳》有“吹剑首者，吷而已矣”，这里喻虚张声势。
注：锋铓：同“锋芒”。
注：无米之炊：语本俗谚“巧妇难为无米之炊”，指在缺乏条件时也能把事办成。
注：作用：作为，本事。
注：大计：明代对地方官三年一次的考核称“大计”；一说泛指重大的谋划。

# 11
原：深居远俗，尚愁移山有文；纵饮达旦，犹笑醉乡无记。|| 深居简出、远离俗世，还担心有《北山移文》那样的文章来讥讽；彻夜纵酒到天亮，还笑醉乡里没有可记之事。
注：移山有文：指南齐孔稚珪《北山移文》，借山灵口吻讥讽假隐士周颙出山做官。
注：醉乡无记：唐王绩曾作《醉乡记》；这里只释字面，一说意为醉中之境不必有记。
注：达旦：直到天亮。

# 12
原：藜床半穿，管宁真吾师乎；轩冕必顾，华歆洵非友也。|| 坐的藜床已经磨穿一半，管宁真是我的老师啊；见到高官车驾必定回头张望，华歆实在不配做朋友。
注：藜床半穿：据《三国志·管宁传》裴松之注，管宁常坐一木榻，五十余年未尝箕踞，榻上当膝处都磨穿了。
注：轩冕必顾：《世说新语·德行》载管宁、华歆同席读书，有乘轩戴冕的贵人经过，华歆放下书出去观看，管宁割席分坐，说“子非吾友也”。
注：洵（xún）：实在，确实。

# 13
原：车尘马足之下，露出丑形，深山穷谷之中，剩些真影。|| 在车马扬尘的名利场中，人露出丑陋的形态；在深山幽谷里，还留下几分真实的面目。
注：车尘马足：车马往来扬起的尘土，比喻奔走权门、追逐名利。
注：穷谷：幽深的山谷。
注：真影：真实的形影，指本来面目。

# 14
原：吐虹霓之气者，贵挟风霜之色；依日月之光者，毋怀雨露之私。|| 吐出虹霓般豪气的人，贵在带有风霜般凛然的神色；依附日月光辉的人，不要怀有私受恩泽的心思。
注：虹霓之气：比喻豪迈的气概。
注：风霜之色：严正凛然的神色。
注：日月之光、雨露之私：日月比喻君主，雨露比喻恩泽；私，偏私独得。

# 15
原：清襟凝远，卷秋江万顷之波；妙笔纵横，挽昆仑一峰之秀。|| 胸襟清朗、意境悠远，如同卷起秋江万顷波涛；妙笔纵横挥洒，能挽来昆仑一峰的秀色。
注：清襟：清朗的胸襟。
注：凝远：凝重深远。
注：挽：牵引，拉过来。

# 16
原：闻鸡起舞，刘琨其壮士之雄心乎；闻筝起舞，迦叶其开士之素心乎？|| 听到鸡鸣就起身舞剑，这正是刘琨那样壮士的雄心吧；听到筝声就起身而舞，这正是迦叶那样高僧的素心吧？
注：闻鸡起舞：《晋书·祖逖传》载祖逖与刘琨同寝，半夜闻鸡鸣，起而舞剑；刘琨，西晋将领、诗人。
注：迦叶（shè）：佛弟子摩诃迦叶，以苦行著称；佛经有迦叶闻乐不能自持而起舞的说法，一说即此所指。
注：开士：对菩萨或高僧的称呼。
注：素心：纯朴的本心。

# 17
原：友偏天下英杰人士，读尽人间未见之书。|| 结交遍天下的英杰之士，读尽人间未曾见过的书。
注：校：“偏”当作“遍”。
注：英杰：才智出众的人。

# 18
原：读书倦时须看剑，英发之气不磨；作文苦际可歌诗，郁结之怀随畅。|| 读书疲倦时要看看宝剑，奋发的英气便不会消磨；作文苦涩时可以吟唱诗歌，郁结的情怀随之舒畅。
注：英发：英气焕发。
注：歌诗：吟唱诗歌。
注：郁结：忧愁积聚不散。

# 19
原：交友须带三分侠气，作人要存一点素心。|| 交朋友要带三分侠义之气，做人要存一点纯真本心。
注：侠气：见义勇为、重义轻财的气概。
注：素心：纯朴本真的心。

# 20
原：栖守道德者，寂寞一时；依阿权变者，凄凉万古。|| 坚守道德的人，只是寂寞一时；曲从附和、投机取巧的人，却要凄凉万古。
注：栖守：安守，坚守。
注：依阿：曲从附和，没有主见。
注：权变：随机应变，这里指投机取巧；此语亦见洪应明《菜根谭》，作“依阿权势者”。

# 21
原：深山穷谷，能老经济才猷；绝壑断崖，难隐灵文奇字。|| 深山幽谷，能让经世济民的才略老死其中；绝壑断崖，却难以掩藏神妙奇特的文字。
注：经济：经世济民。
注：才猷（yóu）：才能与谋略。
注：灵文奇字：神妙奇特的文字；一说指山崖上的题刻。

# 22
原：献策金门苦未收，归心日夜水东流。扁舟载得愁千斛，闻说君王不税愁。|| 到朝廷献策，苦于不被采纳，归乡之心日夜如流水向东。¦一叶扁舟载满千斛愁绪，听说君王是不收愁税的。
注：金门：金马门，汉代宫门名，待诏之士所在，代指朝廷。
注：斛（hú）：古代量器，十斗为一斛。
注：不税愁：不对愁征税，语带自嘲，言除愁之外别无所有。

# 23
原：世事不堪评，掩卷神游千古上；尘氛应可却，闭门心在万山中。|| 世事不值得评说，合上书卷，神游于千古之上；尘世俗气应能摒除，关起门来，心便在万山之中。
注：掩卷：合上书。
注：尘氛：尘世的俗气。
注：却：退去，摒除。

# 24
原：负心满天地，辜他一片热肠；变态自古今，悬此两只冷眼。|| 天地间到处是负心之人，辜负了一片热心肠；世态反复自古至今都是如此，只好睁着两只冷眼旁观。
注：辜：辜负。
注：变态：世态的变化，指人情反复无常。
注：悬：挂着，这里指睁着。

# 25
原：龙津一剑，尚作合于风雷。胸中数万甲兵，宁终老于牖下。此中空洞原无物，何止容卿数百人。|| 龙津的一把剑，尚且能与风雷相应合。¦胸中藏着数万甲兵，怎能在窗下终老？¦这里面本来空空无物，何止能容下像你这样的几百人。
注：龙津一剑：《晋书·张华传》载雷焕于丰城掘得龙泉、太阿二剑，后剑落延平津，化为双龙，故称“龙津”。
注：胸中数万甲兵：宋人称范仲淹“胸中自有数万甲兵”，喻富有韬略。
注：牖（yǒu）下：窗下，指家中；终老于牖下，指无所作为地老死家中。
注：此中空洞原无物：《世说新语·排调》载王导指周顗之腹问其中有何物，周顗答“此中空洞无物，然容卿辈数百人”。

# 26
原：英雄未转之雄图，假糟邱为霸业；风流不尽之余韵，托花谷为深山。|| 英雄未能施展的宏图，便借酒乡来成就霸业；风流未尽的余韵，便托身花谷当作隐居的深山。
注：未转：未能施行、未能实现。
注：糟邱：同“糟丘”，酒糟堆积成山，指沉湎于酒。
注：花谷：花木繁茂的山谷。

# 27
原：红润口脂，花蕊乍过微雨；翠匀眉黛，柳条徐拂轻风。|| 唇上胭脂红润，像花蕊刚经过一阵微雨；眉黛青翠均匀，像柳条被轻风缓缓吹拂。
注：口脂：涂唇的胭脂。
注：眉黛：画眉用的青黑色颜料，代指眉毛。

# 28
原：满腹有文难骂鬼，措身无地反忧天。|| 满腹文章，却难以骂退鬼魅；连容身之地都没有，反倒为天担忧。
注：难骂鬼：难以用文章骂退鬼魅，喻文才无法对付世间小人；只释字面。
注：措身：安身。
注：忧天：反用《列子·天瑞》杞人忧天的故事，说自身无处立足却心怀天下。

# 29
原：大丈夫居世，生当封侯，死当庙食。不然，闲居可以养志，诗书足以自娱。|| 大丈夫活在世上，活着应当封侯，死后应当立庙受祭。¦不然的话，闲居也可以涵养志向，诗书也足以自我娱乐。
注：庙食：死后立庙，享受祭祀。
注：养志：涵养志向。
注：大丈夫居世：此条语本《后汉书·梁竦传》所载梁竦之言。

# 30
原：不恨我不见古人，惟恨古人不见我。|| 不遗憾我见不到古人，只遗憾古人见不到我。
注：恨：遗憾。
注：不恨我不见古人：语出南朝齐张融，见《南史·张融传》，原作“不恨我不见古人，所恨古人又不见我”。

# 31
原：荣枯得丧，天意安排，浮云过太虚也；用舍行藏，吾心镇定，砥柱在中流乎？|| 荣辱得失，都是天意安排，就像浮云飘过天空罢了；被任用还是被舍弃、出仕还是隐居，我心镇定，就像中流砥柱一般吧？
注：荣枯得丧：荣华与衰败、得到与失去。
注：太虚：天空。
注：用舍行藏：语本《论语·述而》“用之则行，舍之则藏”。
注：砥（dǐ）柱：黄河中的砥柱山，比喻坚定不移。

# 32
原：曹曾积石为仓以藏书，名曹氏石仓。|| 曹曾堆积石头建成仓库来收藏书籍，人称“曹氏石仓”。
注：曹曾：东汉人，以藏书著称；据王嘉《拾遗记》，其藏书处世称“曹氏书仓”。

# 33
原：丈夫须有远图，眼孔如轮，可怪处堂燕雀；豪杰宁无壮志，风棱似铁，不忧当道豺狼。|| 大丈夫应有远大的谋划，眼界像车轮一样宽广，可笑那些安居堂上的燕雀；豪杰怎能没有壮志，风骨棱角像铁一样硬，不怕挡在路上的豺狼。
注：处堂燕雀：《孔丛子》载燕雀安居堂上，自以为安乐，不知灶火将焚屋，比喻居安不知危、目光短浅。
注：风棱：风骨棱角。

原：壮志愤懑难消，高人情深一往。|| 壮志难酬的愤懑难以消除，高人情意深沉一往而不能自已。
注：愤懑（mèn）：愤慨郁闷。
注：情深一往：即一往情深，语出《世说新语·任诞》称桓伊“一往有深情”。

# 100
原：先达笑弹冠，休向侯门轻曳裾；相知犹按剑，莫从世路暗投珠。|| 显达的前辈都嘲笑弹冠相庆的人，不要轻易拖着衣襟到权贵门下奔走；相知的人尚且会按剑相疑，不要在世路上把明珠暗中投给人。
注：先达：显达的前辈。
注：弹冠：弹去帽上灰尘准备出仕，《汉书·王吉传》有“王阳在位，贡公弹冠”之语，喻援引入仕。
注：曳裾（yè jū）：拖着衣襟，指在权贵门下做门客；语出邹阳《上书吴王》“饰固陋之心，则何王之门不可曳长裾乎”。
注：按剑、暗投珠：邹阳《狱中上梁王书》称明月之珠夜光之璧暗投于道，人无不按剑相眄，喻贵重之物不得其人而反招猜疑。
注：相知犹按剑：王维《酌酒与裴迪》有“白首相知犹按剑”之句。
