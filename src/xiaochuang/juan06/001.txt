# 卷首语
题解：卷六以“景”为纲，汇集山居园林、四时风物的清丽文字，借景写心，寄托远离尘嚣、恬淡自适的隐逸情趣。
原：结庐松竹之间，闲云封户；徙倚青林之下，花瓣沾衣。芳草盈阶，茶烟几缕；春光满眼，黄鸟一声。此时可以诗，可以画，而正恐诗不尽言，画不尽意。而高人韵士，能以片言数语尽之者，则谓之诗可，谓之画可，谓高人韵士之诗画亦无不可。集景第六。|| 在松竹之间建一座茅屋，悠闲的白云遮掩着门户；在青翠的树林下徘徊，花瓣沾满衣襟。¦芳草长满台阶，几缕煮茶的轻烟袅袅升起；满眼都是春光，忽听黄莺啼叫一声。¦这时可以吟诗，也可以作画，只怕诗不能把话说尽，画不能把意境表达完。¦而那些高雅有风致的人，能用片言只语把它道尽，那么称它为诗可以，称它为画可以，称它为高人雅士的诗画也未尝不可。¦因此汇集写景的文字，作为第六集。
注：结庐：建造房舍。
注：徙倚：徘徊，来回走动。
注：黄鸟：黄莺，即黄鹂。
注：高人韵士：志趣高远、有风雅韵致的人。

# 1
原：花关曲折，云来不认湾头；草径幽深，落叶但敲门扇。|| 花间的关口曲折回环，白云飘来也认不出河湾在哪里；长满青草的小路幽深僻静，只有落叶轻轻敲打门扇。
注：花关：花丛掩映的关隘门户，一说指花间的门径。
注：湾头：河湾处。
注：但：只，仅。

# 2
原：细草微风，两岸晚山迎短桌；垂杨残月，一江春水送行舟。|| 细草轻拂，微风吹送，两岸傍晚的青山仿佛迎向小桌；垂柳依依，残月挂空，一江春水送走远行的船只。
注：短桌：矮小的桌案。
注：校：“短桌”与下句“行舟”相对，疑为“短棹”之误，棹指船桨，暂按原字解。
注：残月：将落的月亮，多指拂晓时的月。

# 3
原：草色伴河桥，锦缆晓牵三竺雨；花阴连野寺，布帆晴挂六桥烟。|| 青草的颜色伴着河上的桥，清晨牵起华美的船缆，冒着三竺的细雨出行；花荫连着郊野的寺院，晴天挂起布帆，穿过六桥的烟霭。
注：锦缆：用彩丝编成的船缆，形容船只华美。
注：三竺：杭州灵隐山一带的上天竺、中天竺、下天竺三座寺院。
注：六桥：杭州西湖苏堤上的六座桥。

# 4
原：闲步畎亩间，垂柳飘风，新秧翻浪；耕夫荷农器，长歌相应；牧童稚子，倒骑牛背，短笛无腔，吹之不休，大有野趣。|| 在田野间悠闲散步，垂柳随风飘拂，新插的秧苗翻起绿浪；农夫扛着农具，高声唱歌彼此应和；牧童和小孩倒骑在牛背上，短笛吹不成调子，却吹个不停，很有乡野情趣。
注：畎（quǎn）亩：田间，田野；畎，田间的小水沟。
注：荷（hè）：扛，背负。
注：无腔：不成曲调。

# 5
原：夜阑人静，携一童立于清溪之畔，孤鹤忽唳，鱼跃有声，清入肌骨。|| 夜深人静，带着一个童子站在清澈的溪边，一只孤鹤忽然长鸣，游鱼跃出水面发出声响，清寒之气直透肌肤骨髓。
注：夜阑：夜将尽，夜深。
注：唳（lì）：鹤鸣。
注：清入肌骨：清凉之感透入肌骨，也指心神为之清爽。

# 6
原：垂柳小桥，纸窗竹屋，焚香燕坐，手握道书一卷。客来则寻常茶具，本色清言，日暮乃归，不知马蹄为何物。|| 垂柳掩映着小桥，纸糊的窗、竹搭的屋，点上香静坐，手里握着一卷道家典籍。¦有客来就用平常的茶具招待，说些本色质朴的清雅话，天黑了客人才回去，全然不知车马应酬为何物。
注：燕坐：安坐，闲坐；燕，同“宴”，安闲。
注：道书：道家、道教的典籍。
注：本色清言：朴素真率、不涉俗务的谈话。
注：不知马蹄为何物：不知车马往来为何物，指远离官场应酬。

# 7
原：门内有径，径欲曲；径转有屏：屏欲小；屏进有阶，阶欲平；阶畔有花，花欲鲜；花外有墙，墙欲低；墙内有松，松欲古：松底有石，石欲怪；石面有亭，亭欲朴；亭后有竹，竹欲疏；竹尽有室，室欲幽；室旁有路，路欲分；路合有桥，桥欲危；桥边有树，树欲高；树阴有草，草欲青；草上有渠，渠欲细；渠引有泉，泉欲瀑；泉去有山，山欲深：山下有屋，屋欲方；屋角有圃，圃欲宽；圃中有鹤，鹤欲舞；鹤报有客，客不俗；客至有酒，酒欲不却；酒行有醉，醉欲不归。|| 门内要有小路，路要曲折；路转弯处要有照壁，照壁要小；过了照壁要有台阶，台阶要平；台阶旁要有花，花要鲜艳；花外要有墙，墙要低；墙内要有松树，松树要古老；松下要有石头，石头要奇怪；石上要有亭子，亭子要古朴；亭后要有竹林，竹子要稀疏；竹林尽头要有居室，居室要幽静；屋旁要有小路，小路要分岔；路汇合处要有桥，桥要高险；桥边要有树，树要高大；树荫下要有草，草要青翠；草上要有水渠，水渠要细；水渠引来泉水，泉水要成瀑布；泉水流去处要有山，山要幽深；山下要有房屋，房屋要方正；屋角要有园圃，园圃要宽阔；园中要有鹤，鹤要翩翩起舞；鹤鸣报有客来，客人不俗气；客到要有酒，酒要不推辞；酒过数巡要醉，醉了要不想回家。
注：屏：照壁，门内遮挡视线的短墙。
注：危：高而险。
注：圃（pǔ）：种植花木蔬菜的园地。
注：却：推辞，拒绝。

# 8
原：清晨林鸟争鸣，唤醒一枕春梦。独黄鹂百舌，抑扬高下，最可人意。|| 清晨林中鸟儿争相鸣叫，把人从一枕春梦中唤醒。¦只有黄鹂和百舌鸟，叫声抑扬起伏、高低婉转，最合人心意。
注：百舌：鸟名，即乌鸫，善于模仿其他鸟的叫声。
注：可人意：合人心意。

# 9
原：高峰入云，清流见底。两岸石壁，五色交辉，青林翠竹，四时俱备，晓雾将歇，猿鸟乱呜；日夕欲颓，池鳞竞跃，实欲界之仙都。自唐乐以来，未有能与其奇者。|| 高耸的山峰直入云霄，清澈的流水可以见到水底。¦两岸的石壁五彩交相辉映，青翠的树林和竹子四季常在；清晨的雾气将要消散时，猿猴和鸟儿纷乱地鸣叫；夕阳将落时，水中的鱼争相跃出水面，这实在是人间的仙境。¦自从谢灵运以来，再没有能欣赏这种奇景的人了。
注：出处：本条出自南朝梁陶弘景《答谢中书书》。
注：欲界之仙都：人间的仙境；欲界，佛教所说有情欲的众生所居之界，泛指人间。
注：校：“猿鸟乱呜”，陶文作“乱鸣”，“呜”疑为“鸣”之误。
注：校：“唐乐”，陶文作“康乐”，指南朝宋诗人谢灵运，袭封康乐公，此处疑误。
注：与（yù）：参与，这里指领略欣赏。

# 10
原：曲径烟深，路接杏花酒舍；澄江日落，门通杨柳渔家。|| 曲折的小路烟雾深深，路的尽头连着杏花掩映的酒家；清澈的江上夕阳西下，门前通向杨柳环绕的渔家。
注：杏花酒舍：杏花丛中的酒家，化用杜牧《清明》“牧童遥指杏花村”诗意。
注：澄江：清澈的江水。

# 11
原：长松怪石，去墟落不下一二十里。鸟径缘崖，涉水于草莽间。数四左右，两三家相望，鸡犬之声相闻。竹篱草舍，燕处其间，兰菊艺之，霜月春风，日有馀思。临水时种桃梅，儿童婢仆皆布衣短褐，以给薪水，酿村酒而饮之。案有诗书、庄周、太玄、楚辞、黄庭、阴符、楞严、圆觉，数十卷而已。杖藜蹑屐，往来穷谷大川，听流水，看激湍，鉴澄潭，步危桥，坐茂树，探幽壑，升高峰，不亦乐乎！|| 高大的松树和奇怪的山石，离村落不下一二十里。¦鸟才能飞过的小路沿着山崖，要在草丛中涉水而行。¦左右数下来，有两三户人家遥遥相望，鸡鸣狗叫的声音彼此都听得见。¦竹篱笆、茅草屋，安居在其中，种上兰花和菊花，无论霜天月夜还是春风和煦，每天都有不尽的情思。¦临水处时时种些桃树梅树，孩子和仆婢都穿着粗布短衣，去打柴挑水，自己酿造村酒来喝。¦案头放着《诗》《书》《庄子》《太玄》《楚辞》《黄庭经》《阴符经》《楞严经》《圆觉经》，不过几十卷罢了。¦拄着藜杖、穿着木屐，往来于幽深的山谷和大河之间，听流水，看急流，照清潭，走高桥，坐在茂密的树下，探寻幽深的沟壑，登上高峰，不也很快乐吗！
注：墟落：村落。
注：鸟径：只有鸟才能飞越的险峻小路。
注：短褐（hè）：粗布短衣，平民所穿。
注：太玄：西汉扬雄仿《周易》所作的《太玄经》。
注：黄庭、阴符：道教典籍《黄庭经》《阴符经》。
注：楞严、圆觉：佛教经典《楞严经》《圆觉经》。
注：杖藜蹑屐：拄着藜茎做的手杖，穿着木屐。

# 12
原：天气晴朗，步出南郊野寺，沽酒饮之。半醉半醒，携僧上雨花台，看长江一线，风帆摇曳，钟山紫气，掩映黄屋，景趣满前，应接不暇。|| 天气晴朗，步行出南郊到野外的寺院，买酒来喝。¦半醉半醒时，带着僧人登上雨花台，看长江如一条细线，船帆随风摇曳，钟山的紫色云气掩映着帝王的宫阙，美景布满眼前，看都看不过来。
注：雨花台：在今南京城南的山冈，相传梁代云光法师在此讲经，天花如雨坠落。
注：钟山：即今南京紫金山。
注：紫气：祥瑞的紫色云气。
注：黄屋：帝王车盖以黄缯为里，称黄屋，这里借指帝王宫殿陵寝。
注：应接不暇：景物繁多，来不及观赏。

# 13
原：净扫一室，用博山炉爇沈水香，香烟缕缕，直透心窍，最令人精神凝聚。|| 把一间屋子打扫干净，用博山炉点燃沉香，香烟一缕缕升起，直透心窍，最能让人精神凝聚。
注：博山炉：古代香炉，炉盖雕成重叠山峦之形，象征海上仙山博山。
注：爇（ruò）：点燃，焚烧。
注：沈水香：即沉香，因木质沉重入水即沉而得名。

# 14
原：每登高邱，步邃谷，延留燕坐，见悬崖瀑流，寿木垂萝，閟邃岑寂之处，终日忘返。|| 每次登上高高的山丘，走进幽深的山谷，流连安坐，看到悬崖上的瀑布、古老树木上垂挂的藤萝，在那幽深寂静的地方，整天都忘了回去。
注：邱：同“丘”。
注：寿木：古老的树木。
注：閟（bì）邃：幽闭深远。
注：岑寂：寂静冷清。

# 15
原：每遇胜日有好怀，袖手哦古人诗足矣。青山秀水，到眼即可舒啸，何必居篱落下，然后为己物？|| 每逢好天气、心情又好，袖着手吟诵古人的诗就足够了。¦青山秀水，映入眼帘便可以舒心长啸，何必一定要住在自家篱笆里，才算是自己的东西呢？
注：胜日：天气晴好的日子。
注：哦：吟诵。
注：舒啸：放声长啸，抒发胸怀。
注：篱落：篱笆，借指自家宅院。

# 16
原：柴门不扃，筠帘半卷，梁间紫燕，呢呢喃喃，飞出飞入。山人以啸咏佐之，皆各适其性。|| 柴门不上闩，竹帘卷起一半，梁间的紫燕呢呢喃喃，飞进飞出。¦山中隐士吟诗长啸来陪伴它们，彼此都顺适自己的天性。
注：扃（jiōng）：门闩，这里作动词，关门。
注：筠（yún）帘：竹帘；筠，竹子。
注：山人：隐居山中的人。
注：适其性：顺应各自的天性。

# 17
原：风晨月夕，客去后，蒲团可以双跏；烟岛云林，兴来时，竹杖何妨独往。|| 在清风的早晨、明月的夜晚，客人走后，可以在蒲团上盘腿打坐；在烟雾笼罩的小岛、云气缭绕的树林，兴致来时，不妨拄着竹杖独自前往。
注：蒲团：用蒲草编成的圆垫，坐禅所用。
注：双跏（jiā）：双跏趺，两脚交叠盘坐，即佛家的全跏趺坐。

# 18
原：三径竹间，日华淡淡，固野客之良辰；一编窗下，风雨潇潇，亦幽人之好景。|| 竹林间的小路上，阳光淡淡，固然是山野之人的好时光；窗下读一卷书，风雨潇潇，也是隐士的好景致。
注：三径：隐士居处的小路；相传西汉蒋诩隐居，院中辟三径，只与求仲、羊仲往来。
注：日华：日光。
注：一编：一卷书。
注：幽人：幽居的隐士。

# 19
原：乔松十数株，修竹千馀竿；青萝为墙垣，白石为鸟道；流水周于舍下，飞泉落于檐间；绿柳白莲，罗生池砌：时居其中，无不快心。|| 高大的松树十几株，修长的竹子一千多竿；用青萝当作墙垣，用白石铺成小径；流水环绕在屋下，飞泉落在屋檐之间；绿柳和白莲，罗列生长在池边石阶旁；时时住在这里面，没有不畅快的。
注：乔松：高大的松树。
注：鸟道：狭窄险峻、仅容鸟飞的小路，这里指曲折小径。
注：池砌：池边的石阶。

# 20
原：人冷因花寂，湖虚受雨喧。|| 人感到冷落，是因为花也显得寂寞；湖面空阔，所以承受着雨声的喧闹。
注：虚：空阔。
注：喧：喧闹，这里指雨落湖面的声响。

# 21
原：有屋数间，有田数亩。用盆为池，以瓮为牖，墙高于肩，室大于斗。布被暖馀，藜藿饱后。气吐胸中，充塞宇宙，笔落人间，辉映琼玖。人能知止，以退为茂。我自不出，何退之有？心无妄想，足无妄走，人无妄交，物无妄受。炎炎论之，甘处其陋。绰绰言之，无出其右。羲轩之书，未尝去手，尧舜之谈，未尝离口。谭中和天，同乐易友，吟自在诗，饮欢喜酒。百年升平，不为不偶，七十康彊，不为不寿。|| 有房屋几间，有田地几亩。¦用瓦盆当池塘，用破瓮做窗户，墙只比肩膀高，屋子只比斗大一点。¦布被盖得温暖有余，粗茶淡饭吃得饱足。¦胸中吐出的浩然之气充满宇宙，落笔写下的文字光照人间，可与美玉相辉映。¦人能懂得适可而止，以退让求得兴盛。¦我本来就不出仕，又有什么可退的呢？¦心里没有妄想，脚下没有乱走，不随便结交人，不随便收受财物。¦往大处说，我甘心居于简陋之中。¦往宽处说，也没有谁能胜过我。¦伏羲、轩辕的书，从来不曾离手；尧、舜的言论，从来不曾离口。¦谈论中正平和的天理，与平易的朋友同乐，吟咏自在的诗，畅饮欢喜的酒。¦一生遇上太平盛世，不能说没有好运；七十岁仍健康强壮，不能说不长寿。
注：以瓮为牖（yǒu）：用破瓮口做窗户，形容居处贫寒；牖，窗。
注：室大于斗：屋子只比斗略大，形容狭小，即所谓斗室。

# 68

注：倏（shū）尔：忽然，很快地。
注：言旋：回还；言，句首助词，《诗经·小雅·黄鸟》有“言旋言归”之句。

# 69

注：酣酒：畅快饮酒。

# 71

# 72

# 73

# 74
