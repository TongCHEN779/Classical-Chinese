# 001｜自方袍幅巾之态，遍满天下，而超脱
题解：卷十一以“法”为纲，主张士人立身处世既不拘泥成法、也不逾越规矩，从交友、修身、言行、待人等方面讲求中正之道。
原：自方袍幅巾之态，遍满天下，而超脱颖绝之士，遂以同污合流矫之，而世道不古矣。夫迂腐者，既泥于法，而超脱者，又越于法，然则士君子亦不偏不倚，期无所泥越则己矣，何必方袍幅巾，作此迂态耶！集法第十一。|| 自从头戴方巾、身穿方袍的儒者迂腐姿态遍布天下，那些超脱卓绝的人便故意混同流俗来矫正它，于是世道不再淳古了。¦迂腐的人拘泥于法度，超脱的人又逾越法度；既然如此，士君子只要不偏不倚，求得既不拘泥也不逾越就够了，又何必穿戴方袍幅巾，摆出这种迂腐的样子呢！¦因此把“法”汇为第十一集。
注：方袍幅巾：方领的长袍和用整幅绢做的头巾，明代儒生士人的装束，这里代指拘守礼法的迂儒。
注：颖绝：才能出众、超群拔俗。
注：同污合流：混同于污浊的世俗；语本《孟子·尽心下》“同乎流俗，合乎污世”。
注：泥（nì）：拘泥，死守不变。
注：校：“则己矣”之“己”，疑当作“已”，“则已矣”即“就可以了”。

# 002｜一心可以交万友，二心不可以交一友
原：一心可以交万友，二心不可以交一友。|| 一心一意，可以结交成千上万的朋友；三心二意，连一个朋友也交不成。
注：二心：不专一、怀有异心。

# 003｜凡事留不尽之意则机圆，凡物留不尽
原：凡事留不尽之意则机圆，凡物留不尽之意则用裕，凡情留不尽之意则味深，凡言留不尽之意则致远，凡兴留不尽之意则趣多，凡才留不尽之意则神满。|| 凡事留有余地，机变就圆融；凡物留有余地，用度就宽裕；凡情留有余地，滋味就深长；凡言留有余地，意致就深远；凡兴致留有余地，趣味就更多；凡才华留有余地，精神就饱满。
注：机圆：应变灵活圆通。
注：用裕：用度宽裕。
注：致远：意味深远；致，意致、情致。
注：神满：精神充足饱满。

# 004｜有世法，有世缘，有世情。缘非情，
原：有世法，有世缘，有世情。缘非情，则易断；情非法，则易流。|| 世间有世法，有世缘，有世情。¦缘分若没有真情维系，就容易断绝；真情若没有法度约束，就容易流于放纵。
注：世法：世间的法度规矩。
注：世缘：人与人在世间的因缘际会。
注：流：放纵无度，流荡而不知返。

# 005｜世多理所难必之事，莫执宋人道学；
原：世多理所难必之事，莫执宋人道学；世多情所难通之事，莫说晋人风流。|| 世上多有按道理难以断定的事，不要固执宋儒的道学来苛求；世上也多有按人情难以说通的事，不要标榜晋人的风流来开脱。
注：理所难必：依常理难以确定必然如此。
注：宋人道学：宋代程颐、朱熹等人讲求义理心性的学问，后世也称理学。
注：晋人风流：魏晋名士放达不羁、崇尚清谈的风度。

# 006｜与其以衣冠误国，不若以布衣关世；
原：与其以衣冠误国，不若以布衣关世；与其以林下而矜冠裳，不若以廊庙而标泉石。|| 与其身居官位而贻误国家，不如身为平民而关心世事；与其隐居山林却夸耀官服冠冕，不如身在朝廷却标举山水高致。
注：衣冠：官员的服饰，代指做官。
注：布衣：平民的衣服，代指平民。
注：林下：山林之下，指隐居之处。
注：矜冠裳：夸耀官服，指隐者仍以官场身份自炫。
注：廊庙：朝廷。
注：标泉石：标举泉石之趣，指虽在官场而保有隐逸的襟怀。

# 007｜眼界愈大，心肠愈小；地位愈高，举
原：眼界愈大，心肠愈小；地位愈高，举止愈卑。|| 眼界越开阔，用心越细致；地位越高，举止越谦卑。
注：心肠愈小：这里指心思越加细密谨慎，并非心胸狭窄。
注：卑：谦下，不自高。

# 008｜少年人要心忙，忙则摄浮气；老年人
原：少年人要心忙，忙则摄浮气；老年人要心闲，闲则乐余年。|| 年轻人要让心思忙碌起来，忙了就能收住浮躁之气；老年人要让心境闲适下来，闲了就能安享晚年。
注：摄：收敛，约束。
注：浮气：浮躁轻飘的习气。

# 009｜晋人清谈，宋人理学，以晋人遗俗，
原：晋人清谈，宋人理学，以晋人遗俗，以宋人禔躬，合之双美，分之两伤也。|| 晋人的清谈，宋人的理学，用晋人的风度来超脱流俗，用宋人的学问来修身自持，两者合起来便相得益彰，分开来则各有偏失。
注：清谈：魏晋士人崇尚老庄、谈玄论理的风气。
注：遗俗：超脱世俗。
注：禔（zhī）躬：安身修身；禔，安。

# 010｜莫行心上过不去事，莫存事上行不去
原：莫行心上过不去事，莫存事上行不去心。|| 不要做自己良心上过不去的事，也不要存在事情上行不通的念头。
注：心上过不去：于心有愧，良心不安。
注：事上行不去：在实际中行不通、不合情理。

# 011｜忙处事为，常向闲中先检点；动时念
原：忙处事为，常向闲中先检点；动时念想，预从静里密操持。青天白日处节义，自暗室屋漏处培来；旋转乾坤的经纶，自临深履薄处操出。|| 忙碌时所做的事，平常要在闲暇中预先检查；行动时的念头，要事先在安静中细加把持。¦光天化日之下表现出的节操道义，是从独处无人看见的地方培养起来的；扭转天地的经世才略，是从如临深渊、如履薄冰的谨慎中磨炼出来的。
注：检点：检查，约束。
注：操持：把持，修养。
注：暗室屋漏：指无人看见的隐蔽之处；屋漏，古代居室西北角，语本《诗经·大雅·抑》“相在尔室，尚不愧于屋漏”。
注：经纶：整理丝缕，比喻治理国家的才干与谋划。
注：临深履薄：语本《诗经·小雅·小旻》“如临深渊，如履薄冰”，形容谨慎戒惧。

# 012｜以积货财之心积学问，以求功名之念
原：以积货财之心积学问，以求功名之念求道德，以爱子女之心爱父母，以保爵位之策保国家。|| 用积攒钱财的心思来积累学问，用追求功名的念头来追求道德，用疼爱子女的心来孝爱父母，用保住爵位的计策来保卫国家。
注：爵位：官爵和职位。
注：策：计谋，办法。

# 013｜才智英敏者，宜以学问摄其躁；气节
原：才智英敏者，宜以学问摄其躁；气节激昂者，当以德性融其偏。何以下达，惟有饰非；何以上达，无如改过。|| 才智英敏的人，应当用学问来收敛他的浮躁；气节激昂的人，应当用德性来调和他的偏激。¦人凭什么一步步堕落下去？只因为掩饰过错；人凭什么一步步向上进益？没有比改正过错更好的了。
注：摄：收敛，约束。
注：融：调和，消融。
注：下达、上达：语本《论语·宪问》“君子上达，小人下达”，指向下沉沦与向上进德。
注：饰非：掩饰过错。

# 014｜一点不忍的念头，是生民生物之根芽
原：一点不忍的念头，是生民生物之根芽；一段不为的气象，是撑天撑地之柱石。|| 一点不忍伤害的念头，是养育百姓、化生万物的根芽；一股有所不为的气概，是支撑天地的柱石。
注：不忍：不忍心伤害他人，即恻隐之心。
注：生民生物：使百姓与万物得以生养。
注：不为：有所不为，不做不义之事。

# 015｜君子对青天而惧，闻雷霆而不惊；履
原：君子对青天而惧，闻雷霆而不惊；履平地而恐，涉风波而不疑。|| 君子面对青天也心怀敬畏，听到雷霆却不惊慌；走在平地上也小心谨慎，遇到风波却不疑惧。
注：对青天而惧：指平居无事时也常怀敬畏之心。
注：涉风波：经历风浪，比喻遭遇变故。

# 016｜不可乘喜而轻诺，不可因醉而生嗔；
原：不可乘喜而轻诺，不可因醉而生嗔；不可乘快而多事，不可因倦而鲜终。|| 不可趁着高兴就轻易许诺，不可因为醉酒就生气发怒；不可趁着一时痛快就多惹事端，不可因为疲倦就半途而废。
注：轻诺：轻易答应。
注：嗔（chēn）：发怒，生气。
注：鲜（xiǎn）终：很少能坚持到底。

# 017｜意防虑如拨，口防言如遏，身防染如
原：意防虑如拨，口防言如遏，身防染如夺，行防过如割。|| 防范杂念要像拨除杂草，防范失言要像遏止水流，防范沾染恶习要像夺回失物那样急切，防范过失要像割断牵连那样果决。
注：拨：拨除，去除；一说指拨开纷乱的思绪。
注：遏：阻止，遏止。
注：染：沾染不良习气。
注：割：割舍，断绝。

# 018｜白沙在泥，与之俱黑，渐染之习久矣
原：白沙在泥，与之俱黑，渐染之习久矣；他山之石，可以攻玉，切磋之力大焉。|| 白沙落在黑泥里，就会和泥一起变黑，可见潜移默化的影响由来已久；别的山上的石头，可以用来琢磨玉器，可见朋友间切磋砥砺的力量很大。
注：白沙在泥，与之俱黑：语本《荀子·劝学》“白沙在涅，与之俱黑”，比喻环境对人的影响。
注：渐染：逐渐沾染，潜移默化。
注：他山之石，可以攻玉：出自《诗经·小雅·鹤鸣》，比喻借助外力或朋友规劝来改进自己。
注：切磋：加工骨角玉石，比喻相互研讨砥砺。

# 019｜后生辈胸中，落意气两字，有以趣胜
原：后生辈胸中，落意气两字，有以趣胜者，有以味胜者。然宁饶于味，而无饶于趣。|| 年轻人心里一旦有了“意气”二字，有以情趣见长的，有以韵味见长的。¦然而宁可在韵味上丰足，也不要在情趣上过分。
注：落：落下，存有。
注：意气：志趣与气概。
注：趣：外露的情趣、兴致。
注：味：内蕴的韵味、涵养。
注：饶：丰足，多。

# 020｜芳树不用买，韶光贫可支。
原：芳树不用买，韶光贫可支。|| 芬芳的花树不用花钱去买，美好的春光，贫穷的人也能享受。
注：韶光：美好的时光，多指春光。
注：支：支取，这里指享用。

# 021｜寡思虑以养神，剪欲色以养精，靖言
原：寡思虑以养神，剪欲色以养精，靖言语以养气。|| 减少思虑来保养精神，断绝情欲来保养精气，少说话来保养元气。
注：剪：剪除，断绝。
注：靖：安静，这里指少言寡语。
注：神、精、气：传统养生所说的人身三宝。

# 022｜立身高一步方超达，处世退一步方安
原：立身高一步方超达，处世退一步方安乐。|| 立身要比常人高出一步，才能超脱通达；处世要比常人退让一步，才能平安快乐。
注：超达：超脱通达。

# 023｜土君子贫不能济物者，遇人痴迷处，
原：土君子贫不能济物者，遇人痴迷处，出一言提醒之，遇人急难处，出一言解救之，亦是无量功德。|| 士君子贫穷而无力救济他人，遇到别人执迷不悟时，说一句话点醒他，遇到别人危急困难时，说一句话解救他，也是无量的功德。
注：校：“土君子”疑当作“士君子”，形近而误。
注：济物：救济他人。
注：无量功德：佛教语，指功德极大，不可计量。

# 024｜救既败之事者，如驭临崖之马，休轻
原：救既败之事者，如驭临崖之马，休轻策一鞭；图垂成之功者，如挽上滩之舟，莫少停一桌。|| 挽救已经失败的事，就像驾驭已到悬崖边的马，不要轻易再抽一鞭；谋求即将成功的事业，就像拉着逆流上滩的船，一桨也不能稍有停歇。
注：既败：已经失败。
注：策：用鞭子抽打。
注：垂成：将要成功。
注：校：“一桌”之“桌”，疑当作“棹（zhào）”，即船桨。

# 025｜是非邪正之交，少迁就则失从违之正
原：是非邪正之交，少迁就则失从违之正；利害得失之会，太分明则起趋避之嫌。|| 在是非邪正交界的地方，稍有迁就就会失去取舍的正确；在利害得失交会的时候，分得太清楚就会招来趋利避害的嫌疑。
注：从违：依从与违背，指取舍。
注：趋避：趋利避害。

# 026｜事系幽隐，要思回护他，著不得一点
原：事系幽隐，要思回护他，著不得一点攻讦的念头；人属寒微，要思矜礼他，著不得一毫傲睨的气象。|| 事情涉及别人隐私，要想着为他遮掩维护，不能有一点攻击揭发的念头；对方出身寒微，要想着敬重礼待他，不能有一丝傲慢轻视的神气。
注：幽隐：隐秘不愿人知的事。
注：回护：袒护，遮掩。
注：攻讦（jié）：攻击、揭发别人的短处。
注：矜礼：怜惜而以礼相待。
注：傲睨（nì）：傲慢地斜眼看人。

# 027｜毋似小嫌而疏至戚，勿以新怨而忘旧
原：毋似小嫌而疏至戚，勿以新怨而忘旧恩。|| 不要因为小小的嫌隙就疏远至亲，不要因为新的怨恨就忘记旧日的恩情。
注：校：“毋似小嫌”之“似”，疑当作“以”，与下句“勿以新怨”相对。
注：至戚：最亲近的亲属。

# 028｜礼义廉耻，可以律己，不可以绳人。
原：礼义廉耻，可以律己，不可以绳人。律己则寡过，绳人则寡合。|| 礼义廉耻，可以用来约束自己，不可以用来衡量苛求别人。¦约束自己就少犯过错，苛求别人就难以与人相合。
注：律己：约束自己。
注：绳人：用准绳衡量、约束别人；绳，木工取直的墨线。
注：寡合：很少与人合得来。

# 029｜凡事韬晦，不独益己，抑且益人；凡
原：凡事韬晦，不独益己，抑且益人；凡事表暴，不独损人，抑且损己。|| 凡事收敛隐藏，不但有益于自己，而且有益于别人；凡事张扬炫耀，不但损害别人，而且损害自己。
注：韬晦：收敛锋芒，隐藏才能。
注：抑且：而且。
注：表暴（pù）：显露，张扬炫耀。

# 030｜觉人之诈，不形于言；受人之侮，不
原：觉人之诈，不形于言；受人之侮，不动于色。此中有无穷意味，亦有无穷受用。|| 察觉别人的欺诈，不在言语上表露；受到别人的侮辱，不在脸色上流露。¦这当中有无穷的意味，也有无穷的益处。
注：形于言：在言语中显露出来。
注：受用：得益，好处。

# 031｜爵位不宜太盛，太盛则危；能事不宜
原：爵位不宜太盛，太盛则危；能事不宜尽毕，尽毕则衰。|| 爵位不宜太高，太高就危险；能做的事不宜全部做完，做尽了就会衰落。
注：盛：高，显赫。
注：能事：所能做的事，所擅长的本领。
注：尽毕：全部做完。

# 032｜遇故旧之交，意气要愈新；处隐微之
原：遇故旧之交，意气要愈新；处隐微之事，心迹宜愈显；待衰朽之人，恩礼要愈隆。|| 遇到老朋友，情意要更加新鲜；处理隐秘细微的事，心思行迹要更加光明磊落；对待衰老的人，恩惠礼节要更加隆重。
注：故旧：老朋友。
注：隐微：隐秘细微。
注：心迹：内心与行迹。
注：衰朽：衰老之人。

# 033｜用人不宜刻，刻则思效者去；交友不
原：用人不宜刻，刻则思效者去；交友不宜滥，滥则贡谀者来。|| 用人不宜刻薄，刻薄了，想要效力的人就会离去；交友不宜泛滥，泛滥了，阿谀奉承的人就会到来。
注：刻：刻薄，苛刻。
注：思效者：想要效力的人。

# 077｜君子于人，当于有过中求无过，不当

注：尘氛：尘俗之气，比喻世俗的牵累。

原：纷扰固溺志之场，而枯寂亦槁心之地。故学者当栖心玄默，以宁吾真体；亦当适志恬愉，以养吾圆机。|| 纷乱扰攘固然是使志向沉溺的场所，而枯槁寂寞也是使心灵干枯的境地。¦所以求学修身的人应当把心安放在深远静默之中，以安定自己的本真之体；也应当使心志舒适愉悦，来涵养自己圆融灵活的机趣。

注：真体：本来的真性。
注：圆机：圆通灵活的心机、机趣。

# 084｜昨日之非不可留，留之则根烬复萌，

注：宫商：五音中的宫音和商音，泛指音乐。
注：不可得已：一说意为欲罢不能，难以割舍；此句文意不甚明，姑释字面。

# 107｜精神清旺，境境都有会心；志气昏愚
原：精神清旺，境境都有会心；志气昏愚，处处俱成梦幻。|| 精神清爽旺盛，处处境地都能有所领会；志气昏沉愚钝，处处都成了梦幻。
注：会心：领会于心，心有所得。

# 108｜酒能乱性，佛家戒之；酒能养气，仙
原：酒能乱性，佛家戒之；酒能养气，仙家饮之。余于无酒时学佛，有酒时学仙。|| 酒能扰乱心性，所以佛家戒酒；酒能涵养元气，所以仙家饮酒。¦我在没有酒的时候学佛，有酒的时候学仙。
注：乱性：扰乱本性。
注：仙家：指道家修仙之人。

# 109｜烈士不馁，正气以饱其腹；清士不寒
原：烈士不馁，正气以饱其腹；清士不寒，青史以暖其躬；义士不死，天君以生其骸。总之心悬胸中之日月，以任世上之风波。|| 刚烈之士不会饥饿，因为浩然正气填饱了他的肚子；清廉之士不会寒冷，因为青史留名温暖了他的身躯；仗义之士不会死去，因为他的本心使他的形骸永生。¦总之，心中高悬日月般的光明，任凭世上风波起伏。
注：馁（něi）：饥饿。
注：青史：史书，古代以竹简记事，故称。
注：天君：指心；语本《荀子·天论》，以心为统治五官之君。
注：躬：身体。

# 110｜孟郊有句云：“青山碾为尘，白日无
原：孟郊有句云：“青山碾为尘，白日无闲人。”于邺云：“白日若不落，红尘应更深。”又云：“如逢幽隐处，似遇独醒人。”王维云：“行到水穷处，坐看云起时。”又云：“明月松间照，清泉石上流。”皎然云：“少时不见山，便觉无奇趣。”每一吟讽，逸思翩翩。|| 孟郊有诗句说：“青山碾成了尘土，白天里没有一个闲人。”¦于邺说：“太阳如果不落下，红尘应当更加深重。”¦又说：“如果遇到幽深隐僻之处，就像遇到了独自清醒的人。”¦王维说：“走到流水的尽头，坐看白云升起的时候。”¦又说：“明月在松林间照耀，清泉在山石上流淌。”¦皎然说：“短时间不见山，就觉得没有奇妙的意趣。”¦每次吟诵这些诗句，飘逸的情思便翩翩而来。
注：孟郊：唐代诗人，字东野。
注：于邺：唐代诗人，一名于武陵。
注：独醒人：语本《楚辞·渔父》屈原“众人皆醉我独醒”。
注：王维：唐代诗人、画家，字摩诘；“行到”二句见《终南别业》，“明月”二句见《山居秋暝》。
注：皎然：唐代诗僧。
注：吟讽：吟诵。
