# 001｜凡例
题解：凡例交代本书的选材范围、分类体例、校勘与署名原则以及刻印上的用心。
原：一、博采《史记》《汉书》《世说》等书目所经见者，靡不拣入别调者，便不滥摘。|| 一、广泛采录《史记》《汉书》《世说新语》等平常所见的书，凡是别具格调的文字无不选入，除此之外就不滥加摘录。
注：《世说》：南朝宋刘义庆编《世说新语》。
注：别调：别具一格的格调。
注：校：此句句读疑有误，或当作“靡不拣入，别调者便不滥摘”，暂按字面解。

# 002｜凡例
原：一、从来选清言者，俱间杂不伦，今以意趣相合者拟议分类，类各有引，引各导窾，细绎自明。|| 一、以往选辑清言的人，都把各类混杂在一起、不成条理，现在把意趣相合的条目斟酌分类，每类各有引言，引言各自点明要领，细细推究自然明白。
注：清言：清雅隽永的言论。
注：不伦：不成类，不相伦比。
注：拟议：斟酌考虑。
注：导窾（kuǎn）：引向关键空隙处，比喻点明要领；语本《庄子·养生主》“导大窾”。
注：细绎：细细推求。

# 003｜凡例
原：一、群书所取，虽有部分，然或兴到笔随、大同小异者，不妨互收。|| 一、从众书中选取的条目，虽然已分部归类，但有的是兴致所到随笔录下，有的大同小异，不妨在不同部类中互相收录。
注：部分：分部归类。
注：兴到笔随：兴致到了便随手写下。

# 004｜凡例
原：一、集有批点，出韵人口，入韵人目，如磁遇铁，自然相投，不必点缀为工。兹虽无批点，而已入韵目。|| 一、选集如有批语圈点，出自风雅之人的口，进入风雅之人的眼，就像磁石遇到铁，自然相投，不必靠点缀来求工巧。¦这部书虽然没有批点，但已入了风雅之人的眼目。
注：批点：评语和圈点。
注：韵人：风雅之士。

# 005｜凡例
原：一、予居恒手录成帙，复与石臣辈客窗时篝火校雠。有删改，主以独见，参之众裁。|| 一、我平日亲手抄录成册，又和石臣等人在客舍窗下时常挑灯校勘。¦有所删改时，以自己的见解为主，再参照众人的裁断。
注：居恒：平时。
注：石臣：汝调鼎的字，卷首有其所作引。
注：篝火：用笼子罩着的灯火，这里指夜间灯下。
注：校雠（chóu）：校勘文字。

# 006｜凡例
原：一、名公姓氏，非敢妄书。但系同志，即书字号。正望奇文共欣赏，疑义相与晰。|| 一、名人的姓氏，不敢随意书写。¦只要是志同道合的人，就写他的字号。¦正是希望奇文共同欣赏，疑难之处一起辨析。
注：名公：有名望的人。
注：同志：志趣相同的人。
注：奇文共欣赏，疑义相与晰：化用陶渊明《移居》“奇文共欣赏，疑义相与析”。

# 007｜凡例
原：一、是编纵未令长安纸贵，倘蒙玄鉴，嗣有续刻。|| 一、这部书即使不能使长安纸贵，倘若承蒙高明鉴赏，以后还会有续刻。
注：长安纸贵：西晋左思《三都赋》成，传抄者众，“洛阳为之纸贵”，这里改作长安，泛指书受欢迎。
注：玄鉴：高明的鉴察。
注：嗣：此后，接着。

# 008｜凡例
原：一、板取梨木，精择佳纸。更觅刻手名家，笔笔真楷，雅致一叚，苦心珍赏家原之。|| 一、书版选用梨木，精心挑选好纸。¦又寻访刻工名家，一笔一画都是端正的楷书，这一番雅致苦心，希望珍赏的人能够体谅。
注：梨木：木质细密，宜于雕版。
注：真楷：端正的楷书。
注：叚：校：当作“段”。
注：原：体谅。

# 009｜凡例
原：醉古堂天随世孙识。|| 醉古堂主人、天随子的后世子孙记。
注：醉古堂：陆绍珩的堂号。
注：天随世孙：陆龟蒙号天随子，陆绍珩自称其后裔。
注：识（zhì）：记。
