# 卷首语
题解：卷七以“韵”为纲，汇集赏花玩月、焚香品茗、琴棋书画等清雅生活的片段，标举风韵情致，同时讥讽徒具形式、心存俗念的假风雅。
原：人生斯世，不能读尽天下秘书灵笈。有目而昧，有口而哑，有耳而聋，而面上三斗俗尘，何时扫去？则韵之一字，其世人对症之药乎？虽然，今世且有焚香啜茗，清凉在口，尘俗在心，俨然自附于韵，亦何异三家村老妪，动口念阿弥，便云升天成佛也。集韵第七。|| 人生在这世上，不可能读尽天下的珍秘典籍。¦有眼睛却看不清，有嘴却像哑巴，有耳朵却像聋子，脸上蒙着三斗厚的俗世尘土，什么时候才能扫掉呢？¦那么“韵”这一个字，大概就是医治世人俗病的对症良药吧？¦虽说如此，如今世上还有人焚香喝茶，口中清凉，心里却满是尘俗，还俨然以风雅自居，这和偏僻小村里的老太太张口念几声阿弥陀佛，就说自己能升天成佛，又有什么不同呢！¦因此把“韵”汇为第七集。
注：秘书灵笈（jí）：珍藏罕见的书籍；笈，书箱，借指书籍。
注：昧：昏暗不明，这里指看不清事理。
注：三斗俗尘：极言俗气之重；斗，容量单位。
注：韵：风度、情致，指超脱流俗的雅趣。
注：啜（chuò）茗：喝茶。
注：三家村：只有几户人家的偏僻小村，常用来指见识浅陋之地。
注：阿弥：阿弥陀佛的省称，佛教净土宗信徒常念的佛号。

# 1
原：陈慥家蓄数姬，每日晚藏花一枝，使诸姬射覆，中者留宿，时号“花媒”。|| 陈慥家中养着几个姬妾，每天晚上藏起一枝花，让姬妾们猜，猜中的便留下侍寝，当时人称为“花媒”。
注：陈慥（zào）：字季常，北宋人，苏轼的好友，自号龙丘先生；其妻柳氏善妒，有“河东狮吼”的典故。
注：射覆：古代猜物游戏，把东西覆盖起来让人猜测。
注：花媒：以花为媒，指借花定留宿之人。

# 2
原：雪后寻梅，霜前访菊；雨际护兰，风外听竹。|| 雪后去寻访梅花，霜降前去探看菊花；下雨时爱护兰草，起风时去听竹声。
注：霜前访菊：菊花在深秋霜降前后盛开。
注：雨际：下雨的时候。

# 3
原：清斋幽闭，时时暮雨打梨花：冷句忽来，字字秋风吹木叶。|| 清静的书斋幽闭着，不时有傍晚的雨打在梨花上；清冷的诗句忽然涌上心头，字字如同秋风吹落树叶。
注：清斋：清静的书房。
注：暮雨打梨花：化用宋李重元《忆王孙》“雨打梨花深闭门”的意境。
注：冷句：清冷孤峭的诗句。

# 4
原：多方分别，是非之窦易开；一味圆融，人我之见不立。|| 处处计较分别，是非的缺口就容易打开；一心圆通融和，人我对立的成见就不会产生。
注：窦（dòu）：孔穴，缺口。
注：圆融：佛家语，指圆满融通、没有隔阂。
注：人我之见：把自己和他人对立起来的执念，佛家称“我执”。

# 5
原：春云宜山，夏云宜树，秋云宜水，冬云宜野。|| 春天的云宜衬着山看，夏天的云宜衬着树看，秋天的云宜映着水看，冬天的云宜衬着旷野看。
注：宜：适合，相配。

# 6
原：清疏畅快，月色最称风光；潇洒风流，花情何如柳态。|| 清朗疏淡、畅快宜人，月色最配得上这样的风光；潇洒风流，花的情致哪里比得上柳的姿态。
注：称（chèn）：相称，配得上。
注：何如：哪里比得上。一说为“比……怎么样”的比较语。

# 7
原：春夜小窗兀坐，月上木兰有骨，凌冰怀人如玉。因想“雪满山中高士卧，月明林下美人来”，语此际光景颇似。|| 春夜在小窗前独自端坐，月亮升上木兰枝头，花枝清瘦有骨，像凌寒冰雪中怀念的人那样如玉一般。¦于是想起“雪满山中高士卧，月明林下美人来”的诗句，说的正和此时的光景很相像。
注：兀（wù）坐：独自端坐。
注：木兰：落叶乔木，早春开花，花色白或紫。
注：雪满山中高士卧，月明林下美人来：明高启《梅花九首》其一中的诗句，以高士、美人比喻梅花。
注：凌冰怀人如玉：此句费解，疑有脱讹，姑依字面释。

# 8
原：文房供具，借以快目适玩，铺叠如市，颇损雅趣，其点缀之法，罗罗清疏，方能得致。|| 书房里的陈设用具，本是用来悦目赏玩的，如果像市场摆摊一样层层堆放，就很损害雅趣；点缀的方法，要疏朗清爽、错落有致，才能有情趣。
注：文房供具：书房中陈设和使用的器物，如笔墨纸砚、香炉、花瓶等。
注：罗罗清疏：疏朗分明的样子；罗罗，疏朗貌。
注：得致：得到情致。

# 9
原：香令人幽，酒令人远，茶令人爽，琴令人寂，棋令人闲，剑令人侠，杖令人轻，麈令人雅，月令人清，竹令人冷，花令人韵，石令人隽，雪令人旷，僧令人淡，蒲团令人野，美人令人怜，山水令人奇，书史令人博，金石鼎彜令人古。|| 香使人幽静，酒使人旷远，茶使人清爽，琴使人寂静，棋使人悠闲，剑使人有侠气，手杖使人轻健，拂尘使人高雅，月使人清朗，竹使人清冷，花使人有风韵，石使人隽永，雪使人旷达，僧人使人淡泊，蒲团使人有山野之趣，美人使人怜爱，山水使人觉得奇妙，书籍史册使人渊博，金石鼎彝使人古朴。
注：麈（zhǔ）：麈尾，古人清谈时手持的拂尘类器物。
注：隽（juàn）：意味深长。
注：蒲团：用蒲草编成的圆形坐垫，僧人打坐所用。
注：鼎彜（yí）：古代祭祀用的青铜礼器；彜，同“彝”。
注：金石：钟鼎碑碣等古代器物与石刻。

# 10
原：吾斋之中，不尚虚礼，凡入此斋，均为知己。随分款留，忘形笑语，不言是非，不侈荣利，闲谈古今，静玩山水，清茶好酒，以适幽趣，臭味之交，如斯而已。|| 在我的书斋里，不讲究虚礼，凡是进入这书斋的，都是知己。¦随意招待挽留，忘却形迹地谈笑，不议论是非，不夸耀荣华利禄，闲谈古今，静赏山水，有清茶好酒，以满足幽雅的情趣，志趣相投的交往，不过如此罢了。
注：随分：随意，按照现有条件。
注：忘形：不拘形迹，彼此忘却身份礼节。
注：侈：夸耀。
注：臭（xiù）味之交：气味相投的朋友；臭，气味。

# 11
原：窗宜竹雨声，亭宜松风声，几宜洗砚声，榻宜翻书声，月宜琴声，雪宜茶声，春宜筝声，秋宜笛声，夜宜砧声。|| 窗前宜听竹上雨声，亭中宜听松间风声，几案边宜听洗砚声，床榻上宜听翻书声，月下宜听琴声，雪天宜听煮茶声，春天宜听筝声，秋天宜听笛声，夜里宜听捣衣声。
注：几（jī）：小桌，几案。
注：榻：狭长而低矮的床，可坐可卧。
注：砧（zhēn）声：在砧石上捶捣衣物的声音，古诗中常寄托秋思与怀人之情。

# 12
原：鸡坛可以益学，鹤阵可以善兵。|| 鸡坛这样的结交可以增益学问，鹤阵这样的阵法可以使用兵高明。
注：鸡坛：古代越地风俗，交友时设坛祭以鸡犬，立誓结盟，后指交友结盟。一说指晋宋处宗养长鸣鸡，鸡作人语与之终日谈论，宗因此学问大进的故事。
注：鹤阵：古代阵法名，一说即“鹤翼阵”，两翼展开如鹤。

# 13
原：翻经如壁观僧，饮酒如醉道士，横琴如黄葛野人，肃客如碧桃渔父。|| 翻阅佛经像面壁参禅的僧人，饮酒像醉醺醺的道士，横抱古琴像身披葛衣的山野之人，恭敬待客像碧桃花下的渔翁。
注：壁观僧：面壁静观的僧人，相传禅宗初祖达摩在嵩山少林寺面壁九年。
注：黄葛野人：穿黄葛布衣的山野隐士。
注：肃客：恭敬地迎接客人。
注：碧桃渔父：化用陶渊明《桃花源记》中武陵渔人的意象，指桃花源中淳朴好客之人。

# 14
原：竹径款扉，柳阴班席。每当雄才之处，明月停辉，浮云驻影。退而与诸俊髦西湖靓媚，赖此英雄，一洗粉泽。|| 竹林小径叩开柴门，柳荫下铺席而坐。¦每当英雄豪杰聚会的地方，明月也停住光辉，浮云也驻留身影。¦退下来又与诸位才俊同游明丽的西湖，全靠这些英雄人物，洗去了脂粉的柔靡之气。
注：款扉：叩门。
注：班席：铺席而坐；班，铺开。
注：俊髦（máo）：才智杰出的人。
注：靓（jìng）媚：美好妩媚。
注：粉泽：脂粉，比喻柔媚香艳之气。
注：校：此条文句跳脱，“每当雄才之处”“西湖靓媚”之间疑有脱文，姑依字面释。

# 15
原：云林性嗜茶，在惠山中，用核桃、松子肉和白糖，成小块，如石子，置茶中，出以啖客，名曰清泉白石。|| 倪云林生性爱好饮茶，住在惠山时，用核桃、松子仁掺上白糖，做成像石子一样的小块，放入茶中，拿出来招待客人，取名叫“清泉白石”。
注：云林：倪瓒，字元镇，号云林子，元代画家，与黄公望、吴镇、王蒙合称“元四家”，性好洁、嗜茶。
注：惠山：在今江苏无锡，山中惠山泉号称“天下第二泉”。
注：啖（dàn）：给人吃。

# 16
原：有花皆刺眼，无月便攒眉，当场得无妒我；花归三寸管，月代五更灯，此事何可语人？|| 有花时却觉得刺眼，没有月亮就皱眉，在场的人能不嫉妒我吗？把花收进三寸笔管之下，以月光代替五更的灯火，这样的事怎么能对人说呢？
注：攒（cuán）眉：皱眉。
注：三寸管：毛笔，这里指把花写入诗文或画中。
注：五更灯：彻夜读书或写作所点的灯。
注：此条语意隐晦：诸句意脉费解，一说写痴于花月之情难为外人道，姑依字面释。

# 17
原：求校书于女史，论慷慨于青搂。|| 向有学问的女子求教校勘书籍，到青楼中去谈论慷慨意气。
注：校书：校勘书籍；唐代蜀中名妓薛涛有“女校书”之称。
注：女史：古代宫中掌管礼仪、文书的女官，后泛指有才学的女子。
注：校：青搂，当作“青楼”，指妓院。

# 18
原：填不满贪海，攻不破疑城。|| 贪欲之海填不满，疑心之城攻不破。
注：贪海：把贪欲比作无底的大海。
注：疑城：把猜疑比作坚固的城池。

# 19
原：机息便有月到，风来不必苦海。人世心远，自无车尘马迹，何须痼疾丘山？|| 心机止息，自然有明月照来；清风吹来，就不必再身陷苦海。¦在人世中只要心境超远，自然没有车马喧嚣的痕迹，又何必像患了顽症一样迷恋山林呢？
注：机息：机心止息。
注：心远：化用陶渊明《饮酒》“问君何能尔？心远地自偏”。
注：痼（gù）疾丘山：唐代田游岩对唐高宗自称“泉石膏肓，烟霞痼疾”，指酷爱山水成癖。
注：校：“风来不必苦海”句意不完，疑有脱讹，姑依字面释。

# 20
原：郊中野坐，固可班荆；径里闲谈，最宜拂石。|| 在郊外野地里坐着，固然可以铺开荆草当席；在小径中闲谈，最好拂净石头而坐。
注：班荆：把荆草铺在地上坐；典出《左传·襄公二十六年》伍举与声子“班荆相与食”，后指朋友相遇共坐叙旧。

# 21
原：侵云烟而独冷，移开清笑胡床，借竹木以成幽，撤去庄严莲坐。|| 置身云烟之中而独自清冷，搬开供人谈笑的胡床；借竹木营造幽深的境界，撤去庄严的莲花宝座。
注：胡床：一种可以折叠的轻便坐具，由西域传入。
注：莲坐：莲花座，佛像所坐的台座。

# 22
原：幽心人似梅花，韵心士同杨柳。|| 心境幽静的人像梅花，富有情韵的人如同杨柳。
注：幽心：幽静淡泊的心境。
注：韵心：富有风韵情致的心性。

# 23
原：情因年少，酒因境多。|| 多情是因为年少，饮酒多是因为境遇。
注：境：境遇，也可指环境景致。

# 24
原：看书筑得村楼，空山曲抱，趺坐扫来花径，乱水斜穿。|| 为读书建起一座村间小楼，空旷的山峦曲折环抱；为打坐扫开开满花的小路，杂乱的溪流斜穿而过。
注：趺（fū）坐：盘腿而坐，佛教徒的坐禅姿势。
注：曲抱：曲折环抱。

# 25
原：倦时呼鹤舞，醉后倩僧扶。|| 疲倦时唤鹤起舞，醉了以后请僧人搀扶。
注：倩（qìng）：请，央求。

# 26
原：鸟衔幽梦远，只在数尺窗纱，蛩递秋声悄，无言一龛灯火。|| 鸟儿衔走幽梦飞得很远，其实只隔着几尺窗纱；蟋蟀悄悄传送秋声，相伴的只有一龛灯火默默无言。
注：蛩（qióng）：蟋蟀。
注：龛（kān）：供奉神佛的小阁，这里指放灯的壁龛。

# 27
原：借草班荆，安稳林泉之窔；披裘拾穗，逍遥草泽之臞。|| 借草地铺荆而坐，安稳地隐居于林泉深处；披着皮裘拾取遗穗，逍遥自在做一个草野中的清瘦之人。
注：窔（yào）：屋子的东南角，泛指深幽之处。
注：披裘拾穗：《高士传》载春秋时林类年近百岁，披裘拾穗，行歌不辍；又有“披裘公”五月披裘负薪、不拾遗金的故事，均指安贫自得的隐士。
注：草泽：草野，民间。
注：臞（qú）：清瘦，这里指清瘦的隐者。

# 28
原：万绿阴中，小亭避暑，八闼洞开，几簟皆绿。|| 在一片浓绿的树荫中，于小亭里避暑，八面门户全都敞开，几案和竹席都映成了绿色。
注：闼（tà）：门。
注：簟（diàn）：竹席。

# 29
原：雨过蝉声来，花气令人醉。|| 雨过之后传来蝉声，花的香气令人陶醉。
注：花气：花的香气，雨后湿润，花香尤为浓郁。

# 30
原：剸犀截雁之舌锋，逐日追风之脚力。|| 像能斩断犀角、截落飞雁那样锋利的辩才，像能追赶太阳与疾风那样迅捷的脚力。
注：剸（tuán）犀：截断犀牛角，形容锋利；剸，截断。
注：舌锋：言辞的锋芒，指口才。
注：逐日追风：用夸父逐日之典，并借古代骏马“追风”之名，形容奔跑迅疾。

# 31
原：瘦影疏而漏月，香阴气而堕风。|| 清瘦的花影疏疏落落，漏下月光；幽香在阴凉之气中，随风飘落。
注：瘦影：多指梅花疏枝之影，宋林逋《山园小梅》有“疏影横斜水清浅”。
注：校：“香阴气而堕风”文句不顺，与上句不对，疑有讹字，姑依字面释。

# 32
原：修竹到门云里寺，流泉入袖水中人。|| 修长的竹子一直长到门前，那是云中的寺院；流泉仿佛流进衣袖，那是水边的人。
注：修竹：修长的竹子。
注：云里寺：建在高山云雾中的寺院。

# 33
原：诗题半作逃禅偈，酒价都为买药钱。|| 诗题多半写成了逃避尘世、参禅悟道的偈语，买酒的钱都充作了买药的钱。

注：经座并：疑指讲经、读经的座席与人合用，形容贫寒；一说指书案狭窄。此句语意较晦，暂作字面解。

# 42

注：恍忽：同“恍惚”，迷离不清的样子。
