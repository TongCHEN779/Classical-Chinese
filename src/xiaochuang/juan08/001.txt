# 卷首语
题解：卷八以“奇”为纲，收录奇文、奇事、奇语与奇景，借奇崛的议论抒发胸中不平，标举超脱世俗、豪迈真率的襟怀。
原：我辈寂处窗下，视一切人世，俱若蠛蠓婴愧，不堪寓目。而有一奇文怪说，目数行下，便狂呼叫绝，令人喜，令人怒，更令人悲，低徊数过，床头短剑亦呜呜作龙虎吟，便觉人世一切不平，俱付烟水。集奇第八。|| 我们这些人静居窗下，看待人世的一切，都像蠓虫飞舞、婴孩嬉闹般微不足道，不值得一看。¦然而一旦遇到一篇奇文怪论，一目数行读下去，便狂呼叫绝，它使人欢喜，使人愤怒，更使人悲伤，低回吟味几遍，连床头的短剑也呜呜发出龙吟虎啸般的声响，顿时觉得人世间一切不平之事，都交付给了烟波流水。¦于是汇集“奇”为第八集。
注：蠛蠓（miè měng）：一种细小的飞虫，常成群飞舞，比喻微不足道的人和事。
注：婴愧：语意不甚明，疑指婴孩般幼稚可笑之态；一说文字有误，暂按字面理解。
注：目数行下：一眼看下几行，形容读书极快。
注：低徊：同“低回”，反复玩味、流连不已。
注：龙虎吟：形容宝剑在匣中鸣响，如龙吟虎啸，表示激愤难平。
注：俱付烟水：都交付给烟波流水，指一切抛开、不再挂怀。

# 1
原：吕圣公之不问朝士名，张师高之不发窃器奴，韩稚圭之不易持烛兵，不独雅量过人，正是用世高手。|| 吕蒙正不追问讥讽自己的朝官姓名，张师高不揭发偷窃器物的仆人，韩琦不撤换烧着自己胡须的持烛士兵，这些不仅是度量过人，更正是善于处世用事的高手。
注：吕圣公：吕蒙正，北宋宰相。初任参知政事时，有朝士在帘后讥讽他，同僚要追问其姓名，他制止说：一旦知道姓名便终身难忘，不如不知。
注：张师高：其人其事未详；一说当指宋人张齐贤（字师亮），曾知家奴窃取银器而隐忍不发，疑有误字。
注：韩稚圭：韩琦，字稚圭，北宋名臣。相传他夜间写信，持烛的士兵分神，烛火烧了他的鬓须，他只用袖子拂灭，照旧写字；后来见主管官吏要撤换那名士兵，便说“不要换，他已经懂得持烛了”。
注：用世：为世所用，指处理世事、施展才干。

# 2
原：花看水影，竹看月影，美人看帘影。|| 花要看它映在水中的倒影，竹要看它在月下的影子，美人要看她映在帘幕上的身影。
注：帘影：隔着帘子看到的人影，朦胧而有余韵。
注：影：本条以“影”见趣，取其若隐若现、含蓄不尽之美。

# 3
原：佞佛若可忏罪，则刑官无权；寻仙若可延年，则上帝无主。达士尽其在我，至诚贵于自然。|| 如果佞佛就可以忏除罪过，那么执掌刑罚的官员就没有权力了；如果求仙就可以延年益寿，那么上天也就无法主宰人的寿命了。¦通达的人只尽自己的本分，最真诚的心贵在出于自然。
注：佞（nìng）佛：迷信、谄媚佛教，一味烧香拜佛以求福。
注：忏罪：通过忏悔来消除罪过。
注：上帝：指天帝，主宰万物的天神，非指西方宗教之神。
注：达士：见识通达的人。
注：尽其在我：尽力做好属于自己分内的事。

# 4
原：以货财害子孙，不必操戈入室；以学校杀后世，有如按剑伏兵。|| 用钱财害了子孙，不必像拿着武器闯进家门那样明显；用学校误了后代，就好比按着剑埋伏下士兵一样暗藏杀机。
注：操戈入室：拿着武器闯进屋里，比喻公开的侵害；后世也指同室相攻。
注：学校：这里指当时以科举为目的的官学教育，作者讥其束缚、败坏人才。
注：按剑伏兵：手按剑柄、埋伏兵马，比喻暗中的危害。

# 5
原：君子不傲人以不如，不疑人以不肖。|| 君子不因为别人不如自己而傲视他，也不因为别人不贤而猜疑他。
注：不如：才能、地位不及自己。
注：不肖：不贤，品行不好。

# 6
原：读诸葛武侯《出师表》而不堕泪者，其人必不忠；读韩退之《祭十二郎文》而不堕泪者，其人必不友。|| 读诸葛亮的《出师表》而不落泪的人，一定不忠诚；读韩愈的《祭十二郎文》而不落泪的人，一定不友爱。
注：诸葛武侯：诸葛亮，三国蜀汉丞相，封武乡侯，死后谥忠武侯，故称。
注：《出师表》：诸葛亮北伐曹魏前上给后主刘禅的奏表，言辞恳切，表达鞠躬尽瘁的忠诚。
注：韩退之：韩愈，字退之，唐代文学家。
注：《祭十二郎文》：韩愈祭悼侄子韩老成（排行十二）的文章，哀痛真挚。
注：不友：不友爱亲人；友，指兄弟亲族间的情谊。

# 7
原：世味非不浓艳，可以淡然处之。独天下之伟人与奇物，幸一见之，自不觉魄动心惊。|| 世间的滋味并非不浓郁艳丽，但可以淡然对待它。¦唯独天下伟大的人物和奇异的事物，有幸见上一面，自然会不知不觉地心惊魄动。
注：世味：人世的滋味，指功名富贵、声色享乐等。
注：魄动心惊：心神受到强烈震撼。

# 8
原：道上红尘，江中白浪，饶他南面百城；花间明月，松下凉风，输我北窗一枕。|| 道路上的滚滚红尘，江面上的汹涌白浪，就让给那些坐拥百城、南面称尊的人吧；花间的明月，松下的凉风，那些人却比不上我北窗下高卧的一枕清闲。
注：红尘：车马扬起的尘土，借指繁华喧嚣的世俗生活。
注：饶：让，任凭。
注：南面百城：坐北朝南统治众多城邑，比喻权位尊贵、富有；语本《北史·李谧传》“丈夫拥书万卷，何假南面百城”。
注：北窗一枕：用陶渊明自述夏日北窗下高卧、凉风暂至、自谓“羲皇上人”之意，指闲适自得的隐逸生活。

# 9
原：立言亦何容易，必有包天包地、包千古、包来今之识；必有惊天惊地、惊千古、惊来今之才；必有破天破地、破千古、破来今之胆。|| 著书立说哪里是容易的事，一定要有包容天地、包容古往今来的见识；一定要有惊动天地、惊动古往今来的才华；一定要有冲破天地、冲破古往今来的胆量。
注：立言：著书立说，留下有价值的言论；古人以立德、立功、立言为“三不朽”。
注：来今：将来与现今。

# 10
原：圣贤为骨，英雄为胆，日月为目，霹雳为舌。|| 以圣贤作骨骼，以英雄作胆魄，以日月作眼睛，以霹雳作舌头。
注：骨：比喻品格的根本。
注：霹雳为舌：言辞有如霹雳，形容议论雄健、振聋发聩。

# 11
原：瀑布天落，其喷也珠，其泻也练，其响也琴。|| 瀑布从天上落下，喷溅时像颗颗珍珠，倾泻时像一匹白绢，声响像在弹琴。
注：练：白色的熟绢，常用来比喻瀑布、江水。
注：琴：以琴声比喻水声清越。

# 12
原：平易近人，会见神仙济度；瞒心昧己，便有邪祟出来。|| 待人平和随和，自会遇到神仙来救度；欺瞒良心、蒙蔽自己，就会有邪魔鬼祟出来作怪。
注：平易近人：态度和蔼，使人容易亲近。
注：济度：佛道用语，指救助众生、使其脱离苦难。
注：瞒心昧己：违背良心、自欺欺人。
注：邪祟（suì）：作祟害人的鬼怪。

# 13
原：佳人飞去还奔月，骚客狂来欲上天。|| 美人飞去仍是奔向月宫，诗人狂兴发作时想要登上青天。
注：佳人飞去还奔月：用嫦娥偷食灵药飞入月宫的传说。
注：骚客：诗人；由屈原作《离骚》而来。
注：欲上天：化用李白“俱怀逸兴壮思飞，欲上青天揽明月”之意。

# 14
原：涯如沙聚，响若潮吞。|| 水涯好像是沙堆积起来的，水声好像是潮水在吞吐。
注：涯：水边。
注：涯如沙聚，响若潮吞：本条疑是摘自某篇写水景文字的残句，上下文不详，姑按字面解释。

# 15
原：诗书乃圣贤之供案，妻妾乃屋漏之史官。|| 诗书是供奉圣贤的案桌，妻妾是记录人在暗处言行的史官。
注：供案：供奉神佛、祖先的桌案。
注：屋漏：古时室内西北角，是屋中最幽暗之处，借指无人看见的地方；《诗经·大雅·抑》有“尚不愧于屋漏”。
注：屋漏之史官：意谓妻妾朝夕相处，最清楚一个人私下的真实言行。

# 16
原：强项者未必为穷之路，屈膝者未必为通之媒。故铜头铁面，君子落得做个君子；奴颜婢膝，小人枉自做了小人。|| 刚直不屈的人未必就会走上穷困的道路，卑躬屈膝的人也未必能借此通达显贵。¦所以铜头铁面、刚正不阿的，君子落得做个堂堂君子；奴颜婢膝、谄媚逢迎的，小人白白做了卑贱的小人。
注：强项：硬着脖子不肯低头，指刚强不屈；东汉董宣不肯向公主叩头，光武帝称之为“强项令”。
注：媒：媒介，门路。
注：铜头铁面：形容刚正严厉、不讲情面。
注：奴颜婢膝：像奴婢一样卑躬屈膝，形容谄媚讨好。
注：枉自：白白地。

# 17
原：有仙骨者，月亦能飞；无真气者，形终如槁。|| 有仙骨的人，连月亮也能飞上去；没有真气的人，形体终究如枯木一般。
注：仙骨：成仙的资质，也比喻超凡脱俗的气质。
注：真气：道家所说的元气、精气；这里也指真性情。
注：槁：干枯；形如槁木，语出《庄子·齐物论》“形固可使如槁木”。

# 18
原：一世穷根，种在一撚傲骨；千古笑端，伏于几个残牙。|| 一生贫穷的根源，种在一小撮傲骨上；千古以来被人取笑的由头，就藏在几颗残缺的牙齿里。
注：一撚（niǎn）：一小撮；撚，同“捻”。
注：笑端：被人嘲笑的由头。
注：几个残牙：疑指老来齿落、言语或吟哦而招人笑；一说指好发议论的口舌，暂按字面理解。

# 19
原：石怪常疑虎，云闲却类僧。|| 怪异的石头常让人疑心是老虎，悠闲的云朵倒像是僧人。
注：石怪常疑虎：用西汉李广夜见草中石，以为是虎而射之的故事。
注：云闲却类僧：云自在飘游，像四方云游的僧人；僧人也称“云水僧”。

# 20
原：大豪杰，舍己为人，小丈夫，因人利己。|| 大豪杰舍弃自己去成全别人，小人物则借别人来谋取私利。
注：小丈夫：器量狭小的人。
注：因人：凭借、利用别人。

# 21
原：一段世情，全凭冷眼觑破；几番幽趣，半从热肠换来。|| 一段世态人情，全靠冷静的眼光来看穿；几番幽雅的情趣，大半是用一腔热肠换来的。
注：觑（qù）破：看破，看穿。
注：幽趣：幽雅的情趣。
注：热肠：热心肠，真挚热烈的感情。

# 22
原：识尽世间好人，读尽世间好书，看尽世间好山水。|| 结识尽世间的好人，读遍世间的好书，看遍世间的好山好水。
注：尽：全部，到极点。
注：好山水：佳美的山水景致。

# 23
原：舌头无骨，得言句之总持；眼里有筋，具游戏之三昧。|| 舌头没有骨头，却能掌握一切言辞的总纲；眼里有筋，具备随意游戏的自在精髓。
注：总持：佛教语，梵语“陀罗尼”的意译，指总摄一切法、持守不失，这里指言辞的总要。
注：三昧：佛教语，梵语音译，指专注入定；后泛指事物的诀窍、精义。“游戏三昧”指自在无碍、不拘一格的境界。
注：眼里有筋：语意难确解，疑指眼力强劲、看得透彻。

# 24
原：群居闭口，独坐防心。|| 与众人相处时要少说话，独自坐着时要提防心念杂乱。
注：闭口：少说话，谨慎言语。
注：防心：守护内心，防止邪念滋生；与“慎独”之意相近。

# 25
原：当场傀儡，还我为之；大地众生，任渠笑骂。|| 眼前这场傀儡戏，还是由我来操纵；大地上的芸芸众生，任凭他们嘲笑谩骂。
注：傀儡：木偶戏中的木偶，比喻人生如戏。
注：渠：他，他们。

# 26
原：三徙成名，笑范蠡碌碌浮生，纵扁舟忘却五湖风月；一朝解绶，羡渊明飘飘遗世，命巾车归来满室琴书。|| 三次迁居而三处成名，可笑范蠡一生忙忙碌碌，虽然驾着小船泛游五湖，却辜负了五湖的风月；一旦解下官印，羡慕陶渊明飘然离世，驾着巾车归来，满屋都是琴和书。
注：三徙成名：范蠡辅佐越王勾践灭吴后，弃官泛舟五湖，到齐国改名鸱夷子皮致富，又到陶地称陶朱公，三迁皆有名声；见《史记·越王勾践世家》。
注：碌碌：平庸繁忙的样子。
注：解绶：解下系官印的丝带，指辞官；陶渊明任彭泽令八十余日即辞官归隐。
注：巾车：有帷幕装饰的车；《归去来兮辞》有“或命巾车，或棹孤舟”。
注：琴书：陶渊明《归去来兮辞》有“乐琴书以消忧”。

# 27
原：人生不得行胸怀，虽寿百岁，犹夭也。|| 人活一世，如果不能按自己的胸怀去行事，即使活到一百岁，也跟早死没有两样。
注：行胸怀：施展、实现自己的抱负和心意。
注：夭：短命早死。

# 28
原：棋能避世，睡能忘世。棋类耦耕之沮溺，去一不可；睡同御风之列子，独往独来。|| 下棋能够避开世事，睡觉能够忘掉世事。¦下棋好比并肩耕作的长沮、桀溺，两人缺一不可；睡觉如同乘风而行的列子，独来独往。
注：耦（ǒu）耕：两人并肩耕作。
注：沮溺：长沮、桀溺，春秋时的两位隐士，曾并肩耕田，孔子使子路向他们问路；见《论语·微子》。
注：御风之列子：列御寇，相传能乘风而行；《庄子·逍遥游》有“列子御风而行”。

# 29
原：以一石一树与人者，非佳子弟。|| 拿一块石头、一棵树送给别人的，不是好子弟。
注：佳子弟：好子弟，有出息的后辈。
注：以一石一树与人：疑指轻易把家中园林的一石一木送人，即不能守护先人遗物；一说指吝啬小气，送礼只有一石一树。暂存两说。

# 30
原：一勺水，便具四海水味，世法不必尽尝；千江月，总是一轮月光，心珠宜当独朗。|| 一勺水里，就有四海之水的滋味，所以世间的种种法则不必一一尝遍；千条江中的月影，总是同一轮月亮的光辉，所以心中的明珠应当独自明朗。
注：世法：佛教语，指世间的一切事理法则，与“出世法”相对。
注：千江月：佛教常以“千江有水千江月”比喻一理散在万事、万物同具一性。
注：心珠：佛教以明珠比喻人本有的清净心性。

# 31
原：面上扫开十层甲，眉目才无可憎；胸中涤去数斗尘，语言方觉有味。|| 脸上扫去十层厚厚的伪装，眉眼才不会让人厌恶；胸中洗去几斗尘垢，说起话来才觉得有味道。
注：甲：硬壳，这里比喻层层伪装或俗态。
注：可憎：令人厌恶。
注：数斗尘：极言心中的俗念之多；黄庭坚有“胸中尘埃”之说，意近。

# 32

原：怜之一字，吾不乐受，盖有才而徒受人怜，无用可知；傲之一字，吾不敢矜，盖有才而徒以资傲，无用可知。|| “怜”这个字，我不乐意接受，因为有才能却只落得被人怜悯，可见是无用的；“傲”这个字，我不敢自夸，因为有才能却只拿来作傲视别人的资本，可见也是无用的。
注：矜：自负，夸耀。
注：资傲：作为骄傲的资本；资，凭借。

# 59
原：问近日讲章孰佳，坐一块蒲团自佳；问吾济严师孰尊，对一枝红烛自尊。|| 有人问近来哪家讲章最好，我说坐在一块蒲团上自然最好；有人问我们这些人的严师谁最可尊，我说面对一枝红烛自然最尊。
注：讲章：为科举应试而编的解说经书的讲义。
注：蒲团：蒲草编成的圆垫，僧人坐禅所用。
注：吾济：疑当作“吾侪”，我辈。
注：校：“济”疑为“侪”之误，暂依“我辈”解。
注：红烛：指夜读时的烛光，以独自苦读为师。

# 60
原：点破无稽不根之论，只须冷语半言；看透阴阳颠倒之行，惟此冷眼一只。|| 要点破荒诞无据的言论，只需要冷冷的半句话；要看透是非颠倒的行径，只需要这一只冷眼。
注：无稽不根：没有考据、没有根据。
注：冷语：冷静而尖锐的话。
注：阴阳颠倒：比喻是非黑白颠倒。
注：冷眼：冷静旁观的眼光。

# 61
原：古之钓也，以圣贤为竿，道德为纶，仁义为钩，利禄为饵，四海为池，万民为鱼。钓道微矣，非圣人其孰能之。|| 古人的垂钓，是以圣贤为钓竿，以道德为钓丝，以仁义为钓钩，以利禄为钓饵，以四海为池塘，以万民为鱼。¦这种垂钓之道已经衰微了，不是圣人，谁能做到呢。
注：纶（lún）：钓鱼用的丝线。
注：利禄：官位俸禄。
注：微：衰微。
注：其孰能之：谁能做到呢；其，表反问语气。

# 62
原：既稍云于清汉，亦倒影于华池。|| 既像云一般稍稍升向清朗的天河，又把倒影映在华美的池水之中。
注：稍云：疑为“梢云”，高耸入云；稍，一说通“梢”，指树梢。
注：清汉：清朗的天河；汉，银河。
注：华池：华美的池沼，一说指神话中昆仑山上的仙池。
注：校：“稍云”疑作“梢云”。

# 63
原：浮云回度，开月影而弯环；骤雨横飞，挟星精而摇动。|| 飘浮的云回旋流动，拨开后露出一弯弯的月影；急骤的雨横飞而来，裹挟着星光一起摇动。
注：回度：回旋飘过。
注：弯环：弯曲成环的样子。
注：星精：星辰的光华。

# 64
原：天台杰起，绕之以赤霞；赤城孤峙，覆之以莲花。|| 天台山巍然耸起，红霞环绕着它；赤城山孤高独立，上面覆盖着莲花般的峰峦。
注：天台：天台山，在今浙江天台县，为佛教天台宗发源地。
注：赤城：赤城山，在天台县北，土石赤色如城堞，为天台山南门。孙绰《游天台山赋》有“赤城霞起而建标”之句。
注：莲花：此处或指如莲花瓣般环列的山峰，一说指佛寺。

# 65
原：金河别雁，铜柱辞鸢，关山天骨，霜木雕年。|| 金河边离别了飞雁，铜柱旁辞别了鸢鸟，关山显出天然的骨骼，经霜的树木凋零了年华。
注：金河：古水名，在今内蒙古一带，代指北方边塞。
注：铜柱：东汉马援征交趾时所立铜柱，代指南方边疆；马援曾言南方“仰视飞鸢跕跕堕水中”，故以鸢相配。
注：鸢（yuān）：老鹰。
注：天骨：天生的骨骼，形容山势峻峭。
注：雕年：凋零了一年的光景；雕，通“凋”。

# 66
原：翻飞倒影，擢菡萏于湖中；舒艳腾辉，攒䗖𬟽于天畔。|| 花影翻飞、倒映水中，荷花在湖中挺拔而出；光彩舒展、辉光腾起，彩虹在天边聚集。
注：擢（zhuó）：拔起，挺出。
注：菡萏（hàn dàn）：荷花。
注：䗖𬟽（dì dōng）：即“螮蝀”，彩虹。
注：攒（cuán）：聚集。

# 67
原：照万象于晴初，散寥天于日馀。|| 天刚放晴时照亮万象，日暮之后在辽阔的天空中散开。
注：万象：宇宙间一切景象。
注：寥天：辽阔空旷的天空。
注：日馀：日落后的余光时分；馀，同“余”。
注：照、散：本句主语未明言，疑指日光或云霞。
