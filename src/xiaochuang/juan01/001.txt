# 署名
原：松陵陆绍珩湘客父选，兄陆绍琏宗玉父阅。|| 由松陵人陆绍珩（字湘客）选编，他的哥哥陆绍琏（字宗玉）审阅。
注：松陵：今江苏苏州吴江一带的旧称。
注：父：这里读fǔ，附在人名、字号后面的敬称。

# 卷首语
题解：卷一以“醒”为纲，劝人从名利声色的沉迷中醒悟，并从慎言、处世、读书、养心等方面辨析机心与真性。原站每段分别编号，含卷首署名；小标题取原文开头，均为整理者所加。原站疑字不改，以注释说明暂解与存疑。
原：食中山之酒，一醉千日。今世之昏昏逐逐，无一日不醉，无一人不醉，趋名者醉于朝，趋利者醉于野，豪者醉于声色车马，而天下竟为昏迷不醒之天下矣，安得一服清凉，人人解酲，集醒第一。|| 喝了中山的美酒，一醉可以持续千日。¦如今世人昏昏沉沉、奔走追逐，没有一天不醉，没有一个人不醉：求名的陶醉在朝廷，逐利的沉醉在民间，富豪沉迷于歌舞美色、车马享受，天下竟成了昏迷不醒的天下；怎样才能给人人服下一剂清凉药，让大家都醒酒呢？因此把“醒”汇为第一集。
注：中山之酒：传说中使人久醉的美酒，此处借来比喻使人沉迷的事物。
注：解酲（chéng）：解除醉意；酲，酒醉不醒的状态。
注：声色车马：歌舞、美色和车马等享乐之物。

# 1
原：倚才高而玩世，背后须防射影之虫；饰厚貌以欺人，面前恐有照胆之镜。|| 倚仗才高而轻视世俗，要防备背后暗害你的小人；装出忠厚面孔欺骗别人，恐怕面前就有能照破内心的明镜。
注：射影之虫：传说中含沙射影害人的蜮，这里比喻暗中伤人的人。
注：厚貌：表面忠厚的神态。
注：照胆之镜：传说中能照见内脏的镜子，这里比喻能辨明人心的眼光。

# 2
原：怪小人之颠倒豪杰，不知惯颠倒方为小人；惜吾辈之受世折磨，不知惟折磨乃见吾辈。|| 埋怨小人颠倒是非、折辱豪杰，却不知惯于颠倒是非才称得上小人；惋惜我们受世事折磨，却不知只有经过折磨才看得出我们的本色。
注：颠倒：这里指混淆是非，任意抬高或贬低人。
注：吾辈：我们这些人。

# 3
原：花繁柳密处拨得开，才是手段；风狂雨急时立得定，方见脚根。|| 在繁花密柳的诱惑中能拨开牵缠，才算有本领；在狂风暴雨的逆境里能站稳，才看得出根基。
注：花繁柳密：以繁盛景物比喻种种诱惑。
注：脚根：立身的根基，指操守与定力。

# 4
原：澹泊之守，须从秾艳场中试来；镇定之操，还向纷纭境上勘过。|| 淡泊的操守，要到繁华浓艳的场合中试验；镇定的品格，要在纷乱的处境里检验。
注：澹泊：淡泊，不追逐名利。
注：秾（nóng）艳：浓丽繁盛，这里指繁华与诱惑。
注：勘：查验，检验。

# 5
原：市恩不如报德之为厚，要誉不如逃名之为适，矫情不如直节之为真。|| 施恩以收买人心，不如报答别人的恩德来得厚道；谋取赞誉，不如避开名声来得自在；故意装出异于常人的姿态，不如保持正直的节操来得真实。
注：市恩：以施恩换取好感；市，交易。
注：要（yāo）誉：求取赞誉。
注：矫情：故意做作，违背本心而求异于人。
注：直节：正直的节操。

# 6
原：使人有面前之誉，不若使人无背后之毁；使人有乍交之懽，不若使人无久处之厌。|| 使人在面前赞美自己，不如使人在背后没有可诋毁的地方；使人初交时欢喜，不如使人长久相处也不厌烦。
注：乍交：刚刚结交。
注：懽：同“欢”。
注：毁：诋毁，指责。

# 7
原：攻人之恶毋太严，要思其堪受；教人以善莫过高，当原其可从。|| 批评别人的过失不要太严厉，要想想他能否承受；引导别人向善不要要求过高，要体谅他能否做到。
注：攻：指责，批评。
注：原：体察，体谅。

# 8
原：不近人情，举世皆畏途；不察物情，一生俱梦境。|| 不体谅人情，到处都会成为令人畏惧的险路；不明白事物的情理，一辈子都会像活在梦中。
注：畏途：使人畏惧的道路，比喻难以应付的处境。
注：物情：事物的实际情况和情理。

# 9
原：遇沈沈不语之士，切莫输心；见悻悻自好之徒，应须防口。|| 遇到深沉而不说话的人，不要轻易交付真心；见到愤愤自负、自以为好的人，应当谨慎说话。
注：沈沈：同“沉沉”，这里指深沉难测。
注：输心：向人吐露真心。
注：悻悻自好：自负而不悦，认为自己高于别人。

# 10
原：结缨整冠之态，勿以施之焦头烂额之时；绳趋尺步之规，勿以用之救死扶伤之日。|| 整理帽带、端正衣冠的从容姿态，不要拿来应付焦头烂额的急难；行步处处拘守规矩的做法，不要用在救死扶伤的紧要关头。
注：结缨整冠：整理帽带和衣冠。
注：绳趋尺步：行走进退都合乎规矩，指过于拘守仪节。

# 11
原：议事者身在事外，宜悉利害之情；任事者身居事中，当忘利害之虑。|| 议论事情的人置身事外，应当全面弄清利害实情；实际负责的人身在其中，应当放下个人利害的顾虑。
注：悉：详细了解。
注：任事：承担职责，实际办事。
注：利害之虑：这里着重指对自身得失的考虑。

# 12
原：俭，美德也，过则为悭吝，为鄙啬，反伤雅道；让，懿行也，过则为足恭，为曲谨，多出机心。|| 节俭本是美德，过头就成了吝啬和鄙陋小气，反而损害端正的风度；谦让本是美好的品行，过头就成了过分恭顺和拘谨讨好，往往出于算计。
注：悭（qiān）吝：吝啬。
注：雅道：正当而高雅的行为准则。
注：足（jù）恭：过分恭敬，带有讨好的意味。
注：曲谨：委曲拘谨，不能坦然自处。

# 13
原：藏巧于拙，用晦而明，寓清于浊，以屈为伸。|| 把机巧藏在朴拙中，隐去光芒而内心明白，在混浊中保存清白，以退让求得伸展。
注：用晦：收敛光芒，不显露自己的聪明。
注：以屈为伸：借暂时退让来实现伸展。

# 14
原：彼无望德，此无示恩，穷交所以能长；望不胜奢，欲不胜餍，利交所以必忤。|| 受助的一方不期待恩惠，施助的一方不炫示恩德，贫困中的交情才得以长久；期望不断增高，欲望无法满足，为利益而结交的人终究会相互抵触。
注：穷交：困厄贫穷时的交情。
注：餍（yàn）：满足。
注：忤（wǔ）：违逆，冲突。

# 15
原：怨因德彰，故使人德我，不若德怨之两忘；仇因恩立，故使人知恩，不若恩仇之俱泯。|| 恩德过于显露，怨恨也会随之产生，所以与其使人感恩于我，不如让双方都忘掉恩与怨；施恩有时也会结仇，所以与其使人知道自己的恩惠，不如让恩仇一同消失。
注：德我：以我为有恩于自己，感激我。
注：德怨：恩德和怨恨。
注：俱泯：一同消除。

# 16
原：天薄我福，吾厚吾德以迓之；天劳我形，吾逸吾心以补之；天阨我遇，吾亨吾道以通之。|| 上天给我的福分薄，我便厚积德行来迎接它；上天使我的身体劳苦，我便让内心安逸来补偿；上天使我的际遇困厄，我便使自己所守的道通达，以此走出困境。
注：迓（yà）：迎接。
注：阨（è）：困厄。
注：亨吾道：使自己所守的道通达顺畅。

# 17
原：澹泊之士，必为秾艳者所疑；捡饰之人，必为放肆者所忌。|| 淡泊的人，必定容易受到追逐繁华者的猜疑；检束行为的人，必定容易受到放纵者的忌恨。
注：捡饰：检束、修饰自己的行为；原站校勘记说明“捡”与“检”通。
注：放肆：任意放纵，不加约束。

# 18
原：事穷势蹙之人，当原其初心；功成行满之士，要观其末路。|| 对于事情走到尽头、处境困迫的人，应当体察他最初的心意；对于功业成就、德行完备的人，要看他最终怎样收场。
注：势蹙（cù）：处境困迫。
注：原其初心：体察他最初的动机。
注：末路：事情或人生最后的阶段。

# 19
原：好丑心太明，则物不契；贤愚心太明，则人不亲。须是内精明，而外浑厚，使好丑两得其平，贤愚共受其益，才是生成的德量。|| 对美丑的分别心过于鲜明，就难以与万物相合；对贤愚的分别心过于鲜明，就难以与人亲近。¦应当内心明白，外表宽厚，让美丑都得到平等对待，贤愚都分享到好处，才是能成全人的德行和度量。
注：物不契：与外物不能相合。
注：浑厚：宽厚质朴，不显刻薄。
注：生成：这里指成全、养育。

# 20
原：好辩以招尤，不若讱默以怡性；广交以延誉，不若索居以自全；厚费以多营，不若省事以守俭；逞能以受妬，不若韬精以示拙。|| 喜好争辩而招来怨责，不如谨言沉默来涵养性情；广泛结交以扩大声誉，不如独处来保全自己；花费很多去多方经营，不如减少事务来守住俭朴；逞强招致妒忌，不如收敛才华、表现得朴拙。
注：尤：怨责。
注：讱（rèn）默：谨慎少言。
注：索居：独自居处。
注：韬精：收敛才华，不使外露。

# 21
原：费千金而结纳贤豪，孰若倾半瓢之粟以济饥饿；构千楹而招徕宾客，孰若葺数椽之茅以庇孤寒。|| 耗费千金结交贤达豪杰，哪里比得上拿出半瓢粮食救济饥民；建造千间大屋招徕宾客，哪里比得上修补几间茅屋庇护贫寒无依的人。
注：粟：谷物，泛指粮食。
注：楹：柱子，这里用作房屋数量的代称。
注：葺（qì）：修补房屋。
注：椽（chuán）：架在屋梁上承托屋面的木条，借指屋舍。

# 22
原：恩不论多寡，当厄的壶浆，得死力之酬；怨不在浅深，伤心的杯羹，召亡国之祸。|| 恩惠不在多少：危难时送来的一壶饮食，可以得到舍命相报；怨恨不在深浅：一杯使人伤心的肉汤，也可能招来亡国之祸。
注：当厄：正处于危难之中。
注：壶浆：盛在壶中的饮料，泛指慰劳救助的饮食。
注：杯羹：一杯肉汤；这里以微小的饮食恩怨说明其后果可能很大，不宜仅按字面轻视。

# 23
原：仕途虽赫奕，常思林下的风味，则权势之念自轻；世途虽纷华，常思泉下的光景，则利欲之心自淡。|| 做官的处境即使显赫，也常想想山林闲居的滋味，追逐权势的念头便自然减轻；人世即使繁华，也常想想死后的情景，追逐利益的心便自然淡下去。
注：赫奕：显赫盛大。
注：林下：山林之间，借指退隐生活。
注：泉下：地下，借指死后。

# 24
原：居盈满者，如水之将溢未溢，切忌再加一滴；处危急者，如木之将折未折，切忌再加一搦。|| 处境已经丰盈圆满，就像水快要溢出，切忌再添一滴；处境已经危急，就像木头将要折断，切忌再加一点压力。
注：盈满：充足满盛，比喻富贵或权势达到高处。
注：搦（nuò）：握、按，这里指施加压力。

# 25
原：了心自了事，犹根拔而草不生；逃世不逃名，似膻存而蚋还集。|| 把心中的牵挂真正了结，事情也就随之了结，如同拔掉根后草便不再长；避开尘世却不肯放下名声，就像腥膻还在，飞虫仍会聚来。
注：了心：了却心中的执著。
注：膻（shān）：腥臊气味。
注：蚋（ruì）：一种小飞虫。

# 26
原：情最难久，故多情人必至寡情；性自有常，故任性人终不失性。|| 感情最难持久，所以过分多情的人往往终于薄情；本性自有其恒常之处，所以顺任本性的人终究不失本真。
注：任性：这里指顺任本性，与今人所说的任意胡为不尽相同。
注：自有常：自身具有恒常的根本。

# 27
原：才子安心草舍者，足登玉堂；佳人适意蓬门者，堪贮金屋。|| 才子能安心住在草屋中，便配得上登临显贵的厅堂；佳人能自在生活在简陋门庭中，便值得住进华美的房屋。
注：玉堂：华美厅堂，亦借指显贵之地。
注：蓬门：以蓬草为门，借指贫寒之家。
注：金屋：华美的居所。

# 28
原：喜传语者，不可与语。好议事者，不可图事。|| 喜欢传话搬弄的人，不可以向他交谈私事。¦喜欢随口议论事情的人，不可以与他谋划要事。
注：传语：这里指传话、搬弄言语。
注：图事：谋划事情。

# 29
原：甘人之语，多不论其是非；激人之语，多不顾其利害。|| 用话讨好别人的人，往往不管话的是非；用话激怒别人的人，往往不顾事情的利害。
注：甘人之语：使人听着甜美舒服的话。
注：激人之语：刺激、激怒别人的话。

# 30
原：真廉无廉名，立名者，正所以为贪；大巧无巧术，用术者，乃所以为拙。|| 真正廉洁的人不追逐廉洁的名声；刻意树立廉名，正可能是贪求名声。真正高明的技巧不露机巧痕迹；专门卖弄技巧，恰好显出拙劣。
注：立名：这里指有意营造名声。
注：巧术：这里指刻意显露的机巧手段。

# 31
原：为恶而畏人知，恶中犹有善念；为善而急人知，善处即是恶根。|| 做了坏事还怕别人知道，坏念头中尚存一点善意；做了好事急着让别人知道，这种善行里便已经藏着恶的根源。
注：恶根：滋生恶念的根本，这里指邀名求报的私心。

# 32
原：谭山林之乐者，未必真得山林之趣；厌名利之谈者，未必尽忘名利之情。|| 谈论山林生活的快乐，不一定真懂山林的趣味；厌烦名利话题的人，不一定真的忘却了名利之心。
注：谭：同“谈”。
注：尽忘：完全放下，不再牵挂。

# 33
原：从冷视热，然后知热处之奔驰无益；从冗入闲，然后觉闲中之滋味最长。|| 从冷静的立场看热闹的场面，才明白其中奔忙追逐的无益；从繁忙走入清闲，才觉察清闲的滋味最为悠长。
注：冷、热：这里分别比喻冷静超脱与热闹奔竞。
注：冗（rǒng）：繁杂忙碌。

# 34
原：贫士肯济人，才是性天中惠泽；闹场能笃学，方为心地上工夫。|| 贫穷的读书人还肯帮助别人，才是真性情中的仁惠；身在喧闹场合仍能专心学习，才是内心修养的真功夫。
注：性天：人的天性、本性。
注：笃学：专心而切实地学习。

# 35
原：伏久者，飞必高；开先者，谢独早。|| 长久潜伏积蓄，奋飞时必能飞得高；过早开放的花，也会较早凋谢。
注：伏久：长期潜藏、积累。
注：开先：先于别的花开放，借指过早显露。

# 36
原：贪得者，身富而心贫；知足者，身贫而心富；居高者，形逸而神劳；处下者，形劳而神逸。|| 贪得无厌的人，身体富足而内心贫乏；懂得知足的人，生活贫穷而内心富有；处在高位的人，身体安逸而精神劳累；处在低位的人，身体劳苦而精神安闲。
注：神：这里指精神、心神。
注：处下：处在较低的地位。

# 37
原：局量宽大，即住三家邨里，光景不拘；智识卑微，纵居五都市中，神情亦促。|| 胸襟宽广的人，即使住在只有三户人家的小村里，眼界也不局促；见识浅陋的人，即使身处繁华大都市，精神气象也很狭促。
注：局量：胸襟和度量。
注：邨：同“村”。
注：五都市：泛指繁华大城市。
