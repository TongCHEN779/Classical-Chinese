# 001｜松陵陆绍珩湘客父选，兄陆绍琏宗玉
题解：卷三以“峭”为纲，借峻峭刚直之语砥砺士人气节，讥刺苟安颓靡与虚伪做作，并兼及处世、修德、出处进退之道。
原：松陵陆绍珩湘客父选，兄陆绍琏宗玉父阅。溪于汝调鼎石臣父、武水倪煌令倩父参。|| 由松陵人陆绍珩（字湘客）选编，他的哥哥陆绍琏（字宗玉）审阅。¦溪于人汝调鼎（字石臣）、武水人倪煌（字令倩）参与校订。
注：父：这里读fǔ，附在人名、字号后面的敬称。
注：溪于：地名，具体所指待考。
注：武水：地名，一说在今浙江嘉兴一带。
注：参：参订，参与校订。

# 002｜今天下皆妇人矣，封疆缩其地，而中
原：今天下皆妇人矣，封疆缩其地，而中庭之歌舞犹喧；战血枯其人，而满座之貂貚自若。我辈书生，既无诛贼讨乱之柄，而一片报国之忱，惟于寸楮尺只字间见之；使天下之须眉而妇人者，亦耸然有起色。集峭第三。|| 如今天下人都像妇人一样软弱了：疆土一天天缩小，而厅堂里的歌舞仍然喧闹；战场上的血耗尽了百姓，而满座的显贵依旧若无其事。¦我们这些书生，既没有讨伐叛乱的权柄，一片报国的赤诚，只能在片纸只字之间表现出来；希望能让天下那些身为男子却如妇人般怯懦的人，也悚然振作起来。¦因此把“峭”汇为第三集。
注：峭：峻峭，这里指言辞刚直严厉、风骨凛然。
注：封疆：疆界，国土。
注：貂貚：校：“貚”疑为“蝉”之误；貂蝉，汉代以后侍中等近臣冠上的貂尾和蝉形饰物，借指显贵。
注：寸楮（chǔ）尺只字：校：疑有讹误，大意同“片纸只字”；楮，楮树皮可造纸，代指纸。
注：须眉：胡须和眉毛，代指男子。
注：耸然：惊动、振作的样子。

# 003｜忠孝吾家之宝，经史吾家之田。
原：忠孝吾家之宝，经史吾家之田。|| 忠孝是我家的珍宝，经史是我家的田地。
注：经史：儒家经书和史书。
注：田：以田地比喻安身立命、赖以耕耘的根本。

# 004｜闲到白头真是拙，醉逢青眼不知狂。
原：闲到白头真是拙，醉逢青眼不知狂。|| 闲散到白头，真是笨拙；醉中遇到知己青眼相看，便忘了自己的狂态。
注：青眼：正眼相看，表示器重；相传晋阮籍能作青白眼，见所喜之人以青眼相对。

# 005｜兴之所到，不妨呕出惊人心，故不然
原：兴之所到，不妨呕出惊人心，故不然，也须随场作戏。|| 兴致来了，不妨倾吐惊人的心思；如果不是这样，也该随场应景，逢场作戏。
注：呕出惊人心：极力倾吐心血写出惊人之作；化用唐李贺作诗呕心沥血的故事。
注：故不然：校：“故”疑当作“苟”或“固”，暂作“如果不是这样”解。
注：随场作戏：即“逢场作戏”，随着场合应付周旋。

# 006｜放得俗人心下，方可为丈夫。放得丈
原：放得俗人心下，方可为丈夫。放得丈夫心下，方名为仙佛。放得仙佛心下，方名为得道。|| 放得下俗人的心思，才可以成为大丈夫。¦放得下大丈夫的心思，才称得上仙佛。¦放得下仙佛的心思，才称得上得道。
注：放得……心下：把某种心思放下，不再执着。
注：得道：领悟最高的真理。

# 007｜吟诗劣于讲学，骂座恶于足恭。两而
原：吟诗劣于讲学，骂座恶于足恭。两而揆之，宁为薄行狂夫，不作厚颜君子。|| 吟诗不如讲学，当众骂座比过分谦恭还要恶劣。¦两相比较，我宁可做一个品行轻薄的狂人，也不做厚颜无耻的伪君子。
注：骂座：在宴席上辱骂同座；汉灌夫曾使酒骂座，见《史记·魏其武安侯列传》。
注：足（jù）恭：过分恭敬，带有讨好意味。
注：揆（kuí）：揣度，衡量。
注：薄行：品行轻薄。

# 008｜观人题壁，便识文章。
原：观人题壁，便识文章。|| 看一个人在墙壁上的题字题诗，便能知道他的文章才学。
注：题壁：在墙壁上题写诗文。

# 009｜宁为真士夫，不为假道学。
原：宁为真士夫，不为假道学。|| 宁可做一个真正的士大夫，也不做虚伪的道学先生。
注：士夫：即士大夫，读书做官的人。
注：假道学：表面讲理学、内里虚伪的人。

# 010｜宁为兰摧玉折，不作萧敷艾荣。
原：宁为兰摧玉折，不作萧敷艾荣。|| 宁可像兰花被摧残、美玉被折断那样死得高洁，也不愿像蒿艾那样茂盛地苟活。
注：兰摧玉折：比喻贤人横遭夭折；语出《世说新语·言语》毛伯成语“宁为兰摧玉折，不作萧敷艾荣”。
注：萧敷艾荣：萧、艾都是恶草，敷、荣指繁茂，比喻小人得志、苟且偷生。

# 011｜随口利牙，不顾天荒地老；翻肠倒肚
原：随口利牙，不顾天荒地老；翻肠倒肚，那管鬼哭神愁。|| 随口说出锋利的言辞，不管它天荒地老；把肚肠里的话翻倒出来，哪管它鬼哭神愁。
注：利牙：伶牙俐齿，言辞锋利。
注：翻肠倒肚：把心里话全部倾吐出来。

# 012｜身世浮名，馀以梦蝶视之，断不受肉
原：身世浮名，馀以梦蝶视之，断不受肉眼相看。|| 人生际遇和虚浮的名声，我把它们看作庄周梦蝶般的幻梦，绝不用世俗的肉眼去看待。
注：馀：同“余”，我。
注：梦蝶：《庄子·齐物论》载庄周梦为蝴蝶，醒后不知是庄周梦蝶还是蝶梦庄周，比喻人生如梦。
注：肉眼：凡人的眼光，与佛家所说慧眼相对。

# 013｜达人撒手悬崖，俗子沈身苦海。
原：达人撒手悬崖，俗子沈身苦海。|| 通达的人能在悬崖边撒手放下，凡俗的人却沉身在苦海之中。
注：达人：通达事理、看破世情的人。
注：撒手悬崖：禅家语“悬崖撒手”，比喻彻底放下执着。
注：沈：同“沉”。
注：苦海：佛家比喻充满烦恼的尘世。

# 014｜销骨口中，生出莲花九品，铄金舌上
原：销骨口中，生出莲花九品，铄金舌上，容他鹦鹉千言。|| 在能销毁骨头的谗口中，也能生出九品莲花；在能熔化金属的毒舌上，也容他像鹦鹉一样说上千言万语。
注：销骨、铄（shuò）金：语本“众口铄金，积毁销骨”（《史记·邹阳列传》），指谗言毁谤的可怕。
注：莲花九品：佛教净土宗说往生者分九品，坐于莲台，这里比喻清净高洁。
注：鹦鹉千言：像鹦鹉学舌那样喋喋不休。一说全句意谓对谗毁之言泰然容受，不为所动。

# 015｜少言语以当贵，多著述以当富，载清
原：少言语以当贵，多著述以当富，载清名以当车，咀英华以当肉。|| 把少说话当作尊贵，把多著述当作富有，把载着清白名声当作乘车，把品味文章精华当作吃肉。
注：以当：用来当作。句式化用《战国策·齐策》颜斶“晚食以当肉，安步以当车，无罪以当贵”。
注：咀英华：咀嚼文章的精华，指细读好书。

# 016｜竹外窥莺，树外窥水，峰外窥云，难
原：竹外窥莺，树外窥水，峰外窥云，难道我有意无意；鸟来窥人，月来窥酒，雪来窥书，却看他有情无情。|| 隔着竹林看黄莺，隔着树林看流水，隔着山峰看浮云，难道是我有意还是无意？鸟儿飞来看人，月亮照来看酒，雪光映来看书，倒要看看它们是有情还是无情。
注：窥：从缝隙或隐蔽处看，这里泛指观看。

# 017｜体裁如何，出月隐山；情景如何，落
原：体裁如何，出月隐山；情景如何，落日映屿；气魄如何，收露敛色；议论如何，回飇拂渚。|| 文章的体裁该像什么？像月亮初升、山峦隐现；情景该像什么？像落日映照着小岛；气魄该像什么？像收起露水、敛起光色；议论该像什么？像回旋的风掠过水中小洲。
注：体裁：这里指文章的体制风格。
注：回飇（biāo）：回旋的狂风；飇，同“飙”。
注：渚（zhǔ）：水中的小块陆地。
注：按：本条以景物比喻文章各方面的境界，含义较虚，大意只可意会。

# 018｜有大通必有大塞，无奇遇必无奇穷。
原：有大通必有大塞，无奇遇必无奇穷。|| 有大的通达，必定有大的阻塞；没有奇特的遭遇，也就没有奇特的困厄。
注：通、塞：顺利与阻滞。
注：奇穷：异乎寻常的困厄。

# 019｜雾满杨溪，玄豹山间偕日月；云飞翰
原：雾满杨溪，玄豹山间偕日月；云飞翰苑，紫龙天外借风雷。|| 浓雾弥漫杨溪，黑豹在山间隐居，与日月同在；云气飞腾于翰苑，紫龙在天外借助风雷腾飞。
注：玄豹：黑豹；汉刘向《列女传》载南山玄豹在雾雨中七日不下山觅食，以润泽皮毛成其文采，后比喻隐居自重。
注：杨溪：地名，所指不详。
注：翰苑：翰林院，代指文坛或朝廷文职。
注：紫龙：疑比喻得志腾达的才俊。

# 020｜西山霁雪，东岳含烟；驾凤桥以高飞
原：西山霁雪，东岳含烟；驾凤桥以高飞，登雁塔而远𥆮。|| 西山雪后初晴，东岳笼罩着烟云；驾着凤桥高高飞起，登上雁塔向远方眺望。
注：霁（jì）：雨雪停止，天放晴。
注：东岳：泰山。
注：凤桥：所指不详，一说比喻仕进腾达之途。
注：雁塔：西安慈恩寺大雁塔；唐代新科进士有雁塔题名之俗，后以登雁塔比喻科举及第。
注：𥆮：疑即“眺”的异体字，远望。

# 021｜一失脚为千古恨，再回头是百年人。
原：一失脚为千古恨，再回头是百年人。|| 一时失足就成了千古遗恨，再回头时已是百年之身。
注：失脚：失足，比喻犯下大错。
注：百年人：一生已尽的人。此联常见作“一失足成千古恨，再回头是百年身”，旧传为明代唐寅语。

# 022｜居轩冕之中，不可无山林的气味；处
原：居轩冕之中，不可无山林的气味；处林泉之下，须要怀廊庙的经纶。|| 身居高官显位，不能没有山林隐士的气质；隐居山林泉石之间，也必须怀有治理国家的抱负。
注：轩冕：古代大夫以上乘的车和戴的礼帽，代指官位爵禄。
注：林泉：山林泉石，代指隐居之地。
注：廊庙：朝廷。
注：经纶：整理丝缕，比喻治理国家的才能与谋略。

# 023｜学者要有叚兢业的心思，又要有叚潇
原：学者要有叚兢业的心思，又要有叚潇洒的趣味。|| 做学问的人要有一份兢兢业业的心思，又要有一份潇洒自在的情趣。
注：叚：同“段”，这里相当于“一份”“一段”。
注：兢业：兢兢业业，小心谨慎。

# 024｜平民肯种德施惠，便是无位之卿相；
原：平民肯种德施惠，便是无位之卿相；仕夫徒贪权市宠，竟成有爵的乞人。|| 平民如果肯积德行善、施恩于人，便是没有官位的卿相；做官的人只知贪恋权势、讨好邀宠，最终成了有爵位的乞丐。
注：种德：积累德行。
注：卿相：执政的大臣。
注：仕夫：做官的人。
注：市宠：用手段博取宠信；市，买。

# 025｜烦恼场空，身住清凉世界；营求念绝
原：烦恼场空，身住清凉世界；营求念绝，心归自在乾坤。|| 烦恼的场所一空，身子便住进清凉世界；营求的念头一断，心就回到自在天地。
注：清凉世界：佛家语，指远离烦恼炎热的境界。
注：营求：钻营谋求。
注：乾坤：天地。

# 026｜觑破兴衰究竟，人我得失冰消；阅尽
原：觑破兴衰究竟，人我得失冰消；阅尽寂寞繁华，豪杰心肠灰冷。|| 看透兴衰的究竟，人我之间的得失便如冰融化；阅尽寂寞与繁华，豪杰的心肠也如死灰般冷淡。
注：觑（qù）破：看破。
注：究竟：最终的结果与真相。
注：冰消：像冰一样消融。
注：灰冷：如灰烬般冷寂，指不再热衷功名。

# 027｜名衲谈禅，必执经升座，便减三分禅
原：名衲谈禅，必执经升座，便减三分禅理。|| 名僧谈禅，如果一定要手持经卷登上法座，便减去了三分禅理。
注：名衲（nà）：有名的僧人；衲，僧衣，代指僧人。
注：升座：登上讲经的高座。
注：按：禅理重在心悟而不在讲说经文，故云。

# 028｜穷通之境未遭，主持之局已定；老病
原：穷通之境未遭，主持之局已定；老病之势未催，生死之关先破。求之今世，谁堪语此？|| 还没有遭遇穷困或显达的境况，为人处世的主张就已经确定；衰老病痛的情势还没有来催逼，生死的关口就已经先看破了。¦在当今世上寻找，谁能和他谈论这些呢？
注：穷通：困厄与显达。
注：主持之局：自己所把持的立身格局与主张。
注：生死之关：生死的关隘，指对生死的执着。
注：堪：能够。

# 029｜一纸八行，不遇寒温之句；鱼腹雁足
原：一纸八行，不遇寒温之句；鱼腹雁足，空有往来之烦。是以嵇康不作，严光口传，豫章掷之水中，陈秦挂之壁上。|| 一张八行的信笺，读不到几句嘘寒问暖的话；鱼腹雁足的书信往来，只是白白增添烦扰。¦所以嵇康不写信，严光只是口授回复，豫章太守把托带的信全扔进水里，陈泰把别人寄的东西挂在墙上不拆。
注：八行：旧时信笺每页八行，代指书信。
注：寒温：问寒问暖的客套话。
注：鱼腹雁足：代指书信；古乐府有烹鲤鱼得尺素书之句，又有汉苏武系书雁足的传说。
注：嵇康不作：嵇康《与山巨源绝交书》自称不喜欢写信。
注：严光口传：《后汉书·逸民传》载侯霸遣使送信给严光，严光不作书，只口授几句让来人回复。
注：豫章掷之水中：《世说新语·任诞》载殷羡（字洪乔）出任豫章太守，把别人托带的百余封信都扔进江中，说“沉者自沉，浮者自浮，殷洪乔不能作致书邮”。
注：陈秦：校：疑为“陈泰”之误；《三国志·魏书·陈泰传》载陈泰任并州刺史，京中权贵多寄财物托他代买奴婢，他都挂在墙上不拆封。

# 030｜枝头秋叶将落，犹然恋树；檐前野鸟
原：枝头秋叶将落，犹然恋树；檐前野鸟除死，方得离笼。人之处世，可怜如此。|| 枝头的秋叶快要飘落，仍然依恋着树；檐前的野鸟除非死了，才能离开笼子。¦人活在世上，可怜竟也是这样。
注：犹然：仍然。
注：除死：除非死去。

# 031｜士人有百折不回之真心，才有万变不
原：士人有百折不回之真心，才有万变不穷之妙用。|| 读书人有百折不回的真心，才会有应对万变而不穷尽的妙用。
注：百折不回：屡经挫折也不退缩。
注：万变不穷：应对千变万化而办法不尽。

# 032｜立业建功，事事要从实地著脚；若少
原：立业建功，事事要从实地著脚；若少慕声闻，便成伪果。讲道修德，念念要从虚处立基；若稍计功效，便落尘情。|| 建立功业，每件事都要脚踏实地去做；如果稍微贪慕声名，就成了虚假的成果。¦讲道修德，每个念头都要从虚静无求处打下根基；如果稍微计较功效，便落入尘俗的情念。
注：著（zhuó）脚：落脚，立足。
注：少：稍微。
注：伪果：佛家语借用，指虚假的成果。
注：虚处：虚静无为、不求功利的境地。
注：尘情：世俗的情欲与计较。

# 033｜执拗者福轻，而圆融之人，其禄必厚
原：执拗者福轻，而圆融之人，其禄必厚；操切者寿夭，而宽厚之士其年必长；故君子不言命，养性即所以立命；亦不言天，尽人自可以回天。|| 固执任性的人福分浅薄，而圆通随和的人，他的福禄必定丰厚；急躁严苛的人容易短命，而宽厚的人寿命必定长久；所以君子不谈命运，涵养心性就是安身立命的方法；也不谈天意，尽到人力自然可以挽回天意。
注：执拗（niù）：固执任性。
注：圆融：圆通融和，不偏执。
注：操切：急躁严厉。
注：寿夭：寿命短促；夭，早死。
注：立命：确立自己的命运；语本《孟子·尽心上》“修身以俟之，所以立命也”。
注：回天：扭转天意或局势。

# 034｜才智英敏者，宜以学问摄其𨅶；气节
原：才智英敏者，宜以学问摄其𨅶；气节激昂者，当以德性融其偏。|| 才智敏捷出众的人，应当用学问来收敛他的浮躁；气节激昂的人，应当用德性来调和他的偏激。
注：英敏：聪明敏捷。
注：摄：收敛，约束。
注：𨅶：疑即“躁”的异体字，浮躁。
注：融：调和，融化。

# 035｜苍蝇附骥，捷则捷矣，难辞处后之羞
原：苍蝇附骥，捷则捷矣，难辞处后之羞；萝茑依松，高则高矣，未免仰攀之耻。所以君子宁以风霜自挟，毋为鱼鸟亲人。|| 苍蝇附在千里马的尾巴上，快固然是快了，却免不了跟在后面的羞耻；女萝、茑萝依附着松树，高固然是高了，却免不了仰面攀附的耻辱。¦所以君子宁可凭自身经受风霜磨砺，也不做那亲近依附于人的鱼鸟。
注：附骥：附在千里马尾上，比喻依附名人以成名；语本《史记·伯夷列传》“颜渊虽笃学，附骥尾而行益显”。
注：萝茑（niǎo）：女萝和茑，都是攀附他物生长的植物，《诗经·小雅·頍弁》有“茑与女萝，施于松柏”。
注：自挟：自持，靠自己支撑。
注：鱼鸟亲人：一说用《世说新语·言语》“觉鸟兽禽鱼自来亲人”语，这里取其字面，比喻驯顺依人。

# 036｜伺察以为明者，常因明而生暗，故君
原：伺察以为明者，常因明而生暗，故君子以恬养智；奋迅以求速者，多因速而致迟，故君子以重持轻。|| 以暗中窥探为精明的人，常常因为精明反而生出糊涂，所以君子用恬淡来涵养智慧；靠急躁冒进来求快的人，多半因为求快反而迟缓，所以君子用稳重来驾驭轻率。
注：伺察：暗中窥伺、察看别人。
注：奋迅：急速奋起，这里指急躁冒进。
注：以重持轻：以稳重控制轻浮；语意近《老子》“重为轻根”。

# 037｜有面前之誉易，无背后之毁难；有乍
原：有面前之誉易，无背后之毁难；有乍交之欢易，无久处之厌难。|| 让人当面称赞容易，让人背后不诋毁难；与人初交时欢洽容易，长久相处而不生厌难。
注：乍交：刚刚结交。
注：毁：诋毁。

# 038｜宇宙内事，要力担当，又要善摆脱。
原：宇宙内事，要力担当，又要善摆脱。不担当，则无经世之事业，不摆脱，则无出世之襟期。|| 天地间的事情，既要尽力承担，又要善于摆脱。¦不肯承担，就成就不了治理世事的功业；不能摆脱，就没有超脱尘世的胸怀。
注：宇宙内事：天地间的事，泛指世事。
注：经世：治理世事。
注：出世：超脱尘世。
注：襟期：襟怀，胸怀抱负。

# 039｜待人而留有馀不尽之恩，可以维系无
原：待人而留有馀不尽之恩，可以维系无歇之人心；御事而留有馀不尽之智，可以堤防不测之事变。|| 待人时留下有余而未施尽的恩惠，可以维系长久不衰的人心；处事时留下有余而未用尽的智谋，可以防备意想不到的变故。
注：馀：同“余”。
注：无歇：不止息，长久。
注：御事：处理事务。
注：堤防：同“提防”，防备。

# 040｜无事如有事时堤防，可以弭意外之变
原：无事如有事时堤防，可以弭意外之变；有事如无事时镇定，可以销局中之危。|| 无事时要像有事时那样提防，才能消弭意外的变故；有事时要像无事时那样镇定，才能化解局中的危险。
注：弭（mǐ）：消除，平息。
注：销：消除，化解。

# 041｜爱是万缘之根，当知割舍；识是众欲
原：爱是万缘之根，当知割舍；识是众欲之本，要力扫除。|| 爱恋是一切因缘牵累的根源，应当懂得割舍；分别之识是种种欲望的根本，要尽力扫除。
注：万缘：佛教语，一切因缘、牵挂。
注：识：佛教语，指分别、执取外境的心识。

# 042｜舌存，常见齿亡，刚强终不胜柔弱；
原：舌存，常见齿亡，刚强终不胜柔弱；户朽，未闻枢蠹，偏执岂及圆融。|| 舌头还在，却常见牙齿已经脱落，可见刚强终究胜不过柔弱；门板朽坏了，却没听说门轴被蛀，可见偏执哪里比得上圆融。
注：舌存齿亡：语本刘向《说苑·敬慎》常摐（cōng）张口示老子，言舌存因其柔、齿亡因其刚。
注：户朽枢蠹（dù）：语本《吕氏春秋·尽数》“流水不腐，户枢不蝼”；枢，门轴，常转动故不被虫蛀。
注：圆融：圆通融合，不偏执。

# 043｜荣宠旁边辱等待，不必扬扬；困穷背
原：荣宠旁边辱等待，不必扬扬；困穷背后福跟随，何须戚戚。|| 荣耀恩宠的旁边有屈辱在等待，不必得意扬扬；困顿穷苦的背后有福分跟随，何必忧愁悲戚。
注：扬扬：得意的样子。
注：戚戚：忧惧悲伤的样子。

# 044｜看破有尽身躯，万境之尘绿自息；悟
原：看破有尽身躯，万境之尘绿自息；悟入无怀境界，一轮之心月独明。|| 看破这有尽头的身躯，世间万境的尘缘自然止息；领悟进入无所挂怀的境界，心中一轮明月便独自朗照。
注：校：尘绿，疑当作“尘缘”，形近而误；白话按“尘缘”译。
注：无怀：无所挂怀；一说指上古无怀氏之世，喻淳朴无为。
注：心月：佛教语，以明月比喻清净本心。

# 045｜霜天闻鹤唳，雪夜听鸡鸣，得乾坤清
原：霜天闻鹤唳，雪夜听鸡鸣，得乾坤清绝之气；晴空看鸟飞，活水观鱼戏，识宇宙活泼之机。|| 霜天里听鹤鸣，雪夜里听鸡啼，能感受到天地间清冷绝俗之气；晴空中看鸟飞，活水里看鱼游，能体会到宇宙间活泼的生机。
注：唳（lì）：鹤鸣叫。
注：乾坤：天地。
注：机：生机，造化运行的机理。

# 046｜斜阳树下，闲随老衲清谈；深雪堂中
原：斜阳树下，闲随老衲清谈；深雪堂中，戏与骚人白战。|| 夕阳斜照的树下，悠闲地陪着老僧清谈；积雪深厚的堂中，与诗人们游戏般地作白战诗。
注：老衲（nà）：老和尚；衲，僧衣，代指僧人。
注：骚人：诗人。
注：白战：禁用某些常用字作诗，称“白战体”；苏轼《聚星堂雪》有“白战不许持寸铁”，此处正与雪景相合。

# 047｜山月江烟，铁笛数声，便成清赏；天
原：山月江烟，铁笛数声，便成清赏；天风海涛，扁舟一叶，大是奇观。|| 山间明月、江上烟霭，再加几声铁笛，便成了清雅的赏玩；天上长风、海上波涛，驾一叶小舟，真是壮丽的奇观。
注：铁笛：铁制的笛子，相传声音清越，多为隐士所吹。
注：清赏：清雅的赏玩。
注：扁（piān）舟：小船。

# 048｜秋风闭户，夜雨挑灯，卧读离骚泪下
原：秋风闭户，夜雨挑灯，卧读离骚泪下；霁日寻芳，春宵载酒，闲歌乐府神怡。|| 秋风中关起门，夜雨里挑亮灯，躺着读《离骚》，不觉落泪；晴日里寻访花草，春夜里携酒出游，悠闲地唱着乐府，心神怡悦。
注：挑灯：拨亮灯芯。
注：离骚：屈原的代表作，抒发忠而被谤的忧愤。
注：霁（jì）日：雨后放晴的日子。
注：乐府：本为汉代掌管音乐的官署，后指可配乐歌唱的诗歌。

# 049｜云水中载酒，松篁里煎茶，岂必銮坡
原：云水中载酒，松篁里煎茶，岂必銮坡侍宴；山林下著书，花鸟闲得句，何须凤沼挥毫。|| 在云水之间载酒，在松竹林里煎茶，何必非要到翰林院陪侍御宴；在山林下著书，在花鸟间闲中得句，何须到中书省挥笔起草。
注：松篁（huáng）：松树和竹子；篁，竹林。
注：銮坡：唐代翰林院所在地附近有金銮坡，后以銮坡代指翰林院。
注：凤沼：凤凰池，魏晋以来指中书省，代指朝廷机要之地。

# 050｜人生不好古，象鼎牺樽，变为瓦缶；
原：人生不好古，象鼎牺樽，变为瓦缶；世道不怜才，凤毛麟角，化作灰尘。|| 人们若不爱好古物，象鼎、牺樽这样的珍贵礼器，也会被当作瓦盆；世道若不怜惜人才，凤毛麟角般的稀有之才，也会化为灰尘。
注：象鼎牺樽：饰有象形、牛形的古代礼器；牺樽，作牛形或饰牛纹的酒器。
注：瓦缶（fǒu）：瓦盆，粗陋的陶器。
注：凤毛麟角：凤凰的羽毛、麒麟的角，比喻稀少珍贵的人才。

# 051｜要做男子，须负刚肠，欲学古人，当
原：要做男子，须负刚肠，欲学古人，当坚苦志。|| 要做男子汉，就要有刚强的心肠；想学古人，就应坚定刻苦的志向。
注：刚肠：刚直的心肠，刚强的性情。
注：苦志：刻苦的志向。

# 052｜风尘善病，伏枕处一片青山；岁月长
原：风尘善病，伏枕处一片青山；岁月长吟，操觚时千篇白雪。|| 在风尘中奔波常常生病，伏枕养病时眼前只有一片青山；岁月里长久吟咏，提笔作文时写出千篇高雅的诗章。
注：风尘：旅途奔波或世俗纷扰。
注：操觚（gū）：执简写作；觚，古代书写用的木简。
注：白雪：古代高雅的乐曲《阳春白雪》，这里比喻高雅的诗文。

# 053｜亲兄弟析箸，壁合翻作瓜分；士大夫
原：亲兄弟析箸，壁合翻作瓜分；士大夫爱钱，书香化为铜臭。|| 亲兄弟分家，本来像玉璧一样完整，反而像切瓜一样分割；士大夫贪爱钱财，书香气息便化成了铜臭。
注：析箸（zhù）：分筷子，指兄弟分家各自开伙。
注：校：壁合，疑当作“璧合”，指如玉璧般完整合一；原文不改。
注：铜臭：铜钱的气味，讥讽贪财；语本《后汉书·崔寔传》附崔烈事，崔烈以钱买官，其子言人“嫌其铜臭”。

# 054｜心为形役，尘世马牛；身被名牵，樊
原：心为形役，尘世马牛；身被名牵，樊笼鸡骛。|| 心被形体驱使，就是尘世里的牛马；身被名声牵制，就是笼中的鸡鸭。
注：心为形役：语出陶渊明《归去来兮辞》“既自以心为形役”。
注：樊笼：关鸟兽的笼子，比喻束缚。
注：鸡骛（wù）：鸡和鸭；骛，鸭子。

# 055｜懒见俗人，权辞托病；怕逢尘事，诡
原：懒见俗人，权辞托病；怕逢尘事，诡迹逃禅。|| 懒得见俗人，就暂且推说有病；怕碰上尘世俗事，就隐藏行迹逃入禅门。
注：权：暂且，权宜。
注：诡迹：隐匿行迹。
注：逃禅：逃入佛门，指避世参禅。

# 056｜人不通古今，襟裾马牛；士不晓廉耻
原：人不通古今，襟裾马牛；士不晓廉耻，衣冠狗彘。|| 人若不通晓古今，就是穿着衣裳的牛马；读书人若不懂廉耻，就是戴着衣冠的猪狗。
注：襟裾马牛：穿着衣服的牛马；语本韩愈《符读书城南》“人不通古今，马牛而襟裾”。
注：狗彘（zhì）：狗和猪；彘，猪。

# 057｜道院吹笙，松风袅袅；空门洗钵，花
原：道院吹笙，松风袅袅；空门洗钵，花雨纷纷。|| 在道观中吹笙，松风袅袅相随；在佛寺里洗钵，花雨纷纷飘落。
注：道院：道观。
注：笙：簧管乐器，相传王子乔好吹笙作凤鸣，道家多用之。
注：空门：佛门。
注：钵：僧人的食器。
注：花雨：佛经说佛说法时天降众花如雨。

# 058｜囊无阿堵物，岂便求人；盘有水晶盐
原：囊无阿堵物，岂便求人；盘有水晶盐，犹堪留客。|| 袋中没有钱，难道就要去求人；盘里还有水晶般的盐，仍然可以留客。
注：阿（ē）堵物：钱的代称；语出《世说新语·规箴》，王衍口不言钱，称钱为“阿堵物”，阿堵即“这个”。
注：水晶盐：洁白透明的盐；一说指盐中佳品，这里以清贫之物待客。

# 059｜种两倾负郭田，量晴校雨；寻几个知
原：种两倾负郭田，量晴校雨；寻几个知心友，弄月嘲风。|| 种上两顷城郊的田地，计量晴雨来耕作；寻几个知心朋友，一起吟弄风月。
注：校：两倾，疑当作“两顷”；顷，田地面积单位。原文不改。
注：负郭田：靠近城郭的田地，最为肥沃；语出《史记·苏秦列传》“使我有雒阳负郭田二顷”。
注：嘲风弄月：吟咏风月景物。

# 060｜著屐登山，翠微中独逢老衲；乘桴浮
原：著屐登山，翠微中独逢老衲；乘桴浮海，雪浪里群傍闲鸥。|| 穿着木屐登山，在青翠的山腰中独自遇到老僧；乘着木筏漂海，在雪白的浪花里有成群的闲鸥相伴。
注：著屐（jī）：穿木底鞋；南朝谢灵运登山常著特制木屐，称“谢公屐”。
注：翠微：青翠的山色，也指山腰。
注：乘桴（fú）浮海：语出《论语·公冶长》“道不行，乘桴浮于海”；桴，木筏。

# 061｜才士不妨泛驾，辕下驹吾弗愿也；诤
原：才士不妨泛驾，辕下驹吾弗愿也；诤臣岂合摸棱，殿上虎君无尤焉。|| 有才之士不妨不受约束，像辕下小马那样局促，我是不愿意的；直言的臣子怎能模棱两可，像殿上之虎那样敢言，君主也不会怪罪。
注：泛（fěng）驾：翻车，指马不受驾驭，比喻才士不循常规；语本《汉书·武帝纪》“泛驾之马”。
注：辕下驹：车辕下的小马，比喻局促不能自主；语本《史记·魏其武安侯列传》。
注：摸棱：即“模棱”，含糊两可；唐苏味道有“模棱手”之称。
注：殿上虎：宋刘安世直言敢谏，人称“殿上虎”。
注：无尤：不怪罪。

# 062｜荷钱榆荚，飞来都作青蚨；柔玉温香
原：荷钱榆荚，飞来都作青蚨；柔玉温香，观想可成白骨。|| 荷叶如钱、榆荚似钱，飞来都可当作青蚨钱；柔润如玉、温软生香的美人，观想下去也能看成白骨。
注：荷钱：初生的小荷叶，形圆如钱。
注：榆荚：榆树的果实，形似铜钱，俗称榆钱。
注：青蚨（fú）：传说中的虫，母子相随，以其血涂钱，用出后能飞回，后用作钱的代称；见《搜神记》。
注：白骨观：佛教修行法门，观想人身终成白骨，以断贪欲。

# 063｜旅馆题蕉，一路留来魂梦谱；客途惊
原：旅馆题蕉，一路留来魂梦谱；客途惊雁，半天寄落别离书。|| 在旅馆的芭蕉叶上题诗，一路留下来的是魂梦的篇章；客途中被惊起的大雁，在半空中捎来离别的书信。
注：题蕉：在芭蕉叶上题字写诗；相传唐怀素以蕉叶代纸练字。
注：惊雁：受惊的雁；古有鸿雁传书之说。

# 064｜歌儿带烟霞之致，舞女具丘壑之资；
原：歌儿带烟霞之致，舞女具丘壑之资；生成世外风姿，不惯尘中物色。|| 歌童带有烟霞般的超逸意致，舞女具有山水丘壑般的清雅资质；天生一副世外风姿，不习惯尘世中的打扮俗态。
注：歌儿：歌童，歌者。
注：烟霞：山水云霞，比喻隐逸、超尘的情趣。
注：丘壑：山水幽深之处，比喻高远的意境。
注：物色：形貌、打扮。

# 065｜今古文章，只在苏东坡鼻端定优劣；
原：今古文章，只在苏东坡鼻端定优劣；一时人品，却从阮嗣宗眼内别雌黄。|| 古今的文章，只凭苏东坡的鼻子就能断定优劣；当代的人品，却从阮籍的眼中分出高下。
注：苏东坡鼻端：疑用苏轼品评文章之事，具体出处待考，这里取其字面，指鉴赏眼力。
注：阮嗣宗：阮籍，字嗣宗，魏晋竹林七贤之一，能为青白眼，见礼俗之士以白眼对之，见所好者以青眼对之。
注：雌黄：矿物，古人用来涂改错字，引申为评论、评判。

# 066｜魑魅满前，笑著阮家无鬼论；炎嚣阅
原：魑魅满前，笑著阮家无鬼论；炎嚣阅世，愁披刘氏北风图。|| 鬼怪满眼，就笑着写阮家的无鬼论；在炎热喧嚣中阅历世事，就忧愁地展开刘氏的北风图。
注：魑魅（chī mèi）：传说中山林的鬼怪，比喻坏人。
注：阮家无鬼论：晋阮瞻持无鬼论，见《晋书·阮瞻传》。
注：刘氏北风图：东汉刘褒画《北风图》，观者觉凉；见《历代名画记》等。

# 067｜气夺山川，色结烟霞。
原：气夺山川，色结烟霞。|| 气势压倒山川，色彩凝结成烟霞。
注：夺：压倒，胜过。
注：烟霞：云烟霞彩。

# 068｜诗思在灞凌桥上，微吟处，林岫便已
原：诗思在灞凌桥上，微吟处，林岫便已浩然；野趣在镜湖曲边，独往时，山川自相映发。|| 诗思在灞陵桥上，轻声吟咏时，林木山峦已显得浩荡开阔；野趣在镜湖的曲岸边，独自前往时，山川自然相互映照生辉。
注：灞凌桥：即灞陵桥，在长安东；唐宰相郑綮说“诗思在灞桥风雪中驴子上”。凌，疑当作“陵”。
注：林岫（xiù）：树林与峰峦；岫，山。
注：镜湖：即鉴湖，在今浙江绍兴。
注：山川自相映发：语本《世说新语·言语》王献之“从山阴道上行，山川自相映发，使人应接不暇”。

# 069｜至音不合众听，故伯牙绝弦；至宝不
原：至音不合众听，故伯牙绝弦；至宝不同众好，故卞和泣玉。|| 最高妙的音乐不迎合众人的听觉，所以钟子期死后伯牙断弦不再弹琴；最珍贵的宝物不合众人的眼光，所以卞和抱着璞玉痛哭。
注：伯牙绝弦：《吕氏春秋·本味》载，伯牙鼓琴，钟子期能听出其志在高山流水；子期死后，伯牙破琴绝弦，认为世上再无知音。
注：卞和泣玉：《韩非子·和氏》载，楚人卞和得璞玉献给楚王，被当作石头，先后被砍去双脚，后抱璞哭于荆山之下。

# 070｜看文字，须如猛将用兵，直是鏖战一
原：看文字，须如猛将用兵，直是鏖战一阵；亦如酷吏治狱，直是推勘到底，决不恕他。|| 读书看文章，要像猛将打仗，一定要痛痛快快地鏖战一场；又要像严厉的法官审案，一定要追查到底，绝不放过。
注：鏖（áo）战：激烈苦战。
注：酷吏治狱：严酷的官吏审理案件。
注：推勘：审问查究。
注：说明：此语出自朱熹论读书，见《朱子语类》。

# 071｜名山乏侣，不解壁上芒鞋；好景无诗
原：名山乏侣，不解壁上芒鞋；好景无诗，虚携囊中锦字。|| 游览名山却没有同伴，就懒得解下挂在墙上的草鞋；面对好景却写不出诗，就白白带着装诗稿的锦囊。
注：芒鞋：用芒草编成的鞋，指出游的草鞋。
注：锦字：这里指诗句；唐代李贺出游常带锦囊，得句即投入囊中。

# 072｜辽水无极，雁山参云，闺中风暖，陌
原：辽水无极，雁山参云，闺中风暖，陌上草薰。|| 辽水无边无际，雁门山高耸入云；闺房中春风和暖，田间小路上芳草飘香。
注：辽水：辽河，古代东北边地的河流。
注：雁山：雁门山，在今山西北部，古代边塞要地。
注：陌：田间小路。
注：草薰：草木散发香气。
注：说明：此四句出自南朝江淹《别赋》，写征人远戍、思妇在家的离别之境。

# 073｜秋露如珠，秋月如圭；明月白露，光
原：秋露如珠，秋月如圭；明月白露，光阴往来；与子之别，思心徘徊。|| 秋天的露水像珍珠，秋天的月亮像玉圭；明月白露交替，时光来去流转；与你分别以后，思念之心徘徊不已。
注：圭：古代一种上尖下方的玉器，这里形容月亮洁白。
注：光阴往来：时光流逝不停。
注：说明：此数句亦出江淹《别赋》。

# 074｜声应气求之夫，决不在于寻行数墨之
原：声应气求之夫，决不在于寻行数墨之士；风行水上之文，决不在于一字一句之奇。|| 志趣相投、心意相通的人，绝不在那些只会逐行逐字读书的人中间；如风吹水面般自然天成的文章，绝不在于一字一句的新奇。
注：声应气求：语本《周易·乾·文言》“同声相应，同气相求”，指志趣相同的人互相投合。
注：寻行数墨：一行行、一字字地读，指拘泥文字而不得要领。
注：风行水上：语本《周易·涣》象辞，宋人苏洵以风吹水面自成纹理比喻自然成文。

# 075｜夺他人之酒杯，浇自己之礧磈.
原：夺他人之酒杯，浇自己之礧磈.|| 借别人的酒杯，来浇自己心中的郁结不平。
注：礧磈（lěi kuǐ）：同“垒块”，比喻胸中郁积的不平之气。
注：说明：语本《世说新语·任诞》“阮籍胸中垒块，故须酒浇之”，后多指借他人的事或文字抒发自己的感慨。
注：校：句末“.”当作“。”，原文照录。

# 076｜春至不知湘水深，日暮忘却巴陵道。
原：春至不知湘水深，日暮忘却巴陵道。|| 春天来了也不觉得湘江水有多深，天色已晚竟忘了去巴陵的路。
注：湘水：湘江，在今湖南。
注：巴陵：今湖南岳阳一带。
注：说明：此为诗句，出处待考；写沉醉春景、流连忘返。

# 077｜奇曲雅乐，所以禁淫也；锦绣黼黻，
原：奇曲雅乐，所以禁淫也；锦绣黼黻，所以御暴也。缛则太过，是以檀卿刺郑声，周人伤北里。|| 高雅的乐曲，是用来禁止淫靡之风的；锦绣华美的礼服，是用来防御粗暴的。¦过于繁缛就太过分了，所以檀卿讥刺郑国的靡靡之音，周人为北里的淫乐而感伤。
注：黼黻（fǔ fú）：古代礼服上所绣的花纹，泛指华美的礼服。
注：缛（rù）：繁多，繁琐。
注：郑声：春秋时郑国的音乐，旧时被视为淫靡之音。
注：檀卿：人名，事迹未详，疑为古代论乐之人。
注：北里：据《史记·殷本纪》，商纣王命师涓作“北里之舞”，后用以指淫靡的乐舞。

# 078｜静若清夜之列宿，动若流彗之互奔。
原：静若清夜之列宿，动若流彗之互奔。|| 静止时像清朗夜空中排列的星辰，飞动时像流星彗星交错奔驰。
注：列宿（xiù）：天上排列的星宿。
注：流彗：流星和彗星。
注：说明：此句与以下数条疑摘自六朝咏物辞赋，原所咏之物未详。

# 079｜振骏气以摆雷，飞雄光以倒电。
原：振骏气以摆雷，飞雄光以倒电。|| 振发骏逸的气势，仿佛能摇动雷霆；闪耀雄健的光彩，仿佛能使闪电倒转。
注：摆雷：摇撼雷霆。
注：倒电：使闪电倒转，形容光芒之盛。

# 080｜停之如栖鹄，挥之如惊鸿，飘缨蕤于
原：停之如栖鹄，挥之如惊鸿，飘缨蕤于轩幌，发晖曜于群龙。|| 停下时如栖息的天鹅，挥动时如受惊的鸿雁，在车帷窗幔间飘动着下垂的缨饰，在群龙般的仪仗中焕发出光辉。
注：鹄（hú）：天鹅。
注：惊鸿：受惊飞起的鸿雁，形容轻盈飘逸。
注：缨蕤（ruí）：下垂的缨穗饰物。
注：轩幌：车帷或窗幔。
注：群龙：一说指仪仗中的龙旗，一说比喻众多俊杰，疑。

# 081｜始缘甍而冒栋，终开帘而入隙；初便
原：始缘甍而冒栋，终开帘而入隙；初便娟于墀庑，未萦盈于帷席。|| 起初沿着屋脊飘洒，覆盖了栋梁；最后掀开帘子，钻进缝隙；起初在台阶廊下轻盈飞舞，还未在帐幕坐席间缭绕。
注：甍（méng）：屋脊。
注：便娟：轻盈美好的样子。
注：墀庑（chí wǔ）：台阶和廊屋。
注：萦盈：回旋缭绕。
注：说明：此数句出自南朝谢惠连《雪赋》，写雪花飘落。

# 082｜云气荫于丛蓍，金精养于秋菊；落叶
原：云气荫于丛蓍，金精养于秋菊；落叶半床，狂花满屋。|| 云气庇护着丛生的蓍草，秋菊中蕴养着金气的精华；落叶堆了半张床，乱飞的花瓣落满屋子。
注：蓍（shī）：蓍草，古人用其茎占卜。
注：金精：五行中秋属金，这里指秋天的精气；古人认为菊花得金气之精。
注：狂花：随风乱飞的花。
注：说明：此数句出自北周庾信《小园赋》。

# 083｜雨送添砚之水，竹供扫榻之风。
原：雨送添砚之水，竹供扫榻之风。|| 雨水送来添砚的水，竹林送来扫床的清风。
注：砚：砚台，磨墨的文具。
注：榻：狭长低矮的床。

# 084｜血三年而藏碧，魂一变而成红。
原：血三年而藏碧，魂一变而成红。|| 忠臣的血过了三年藏化成碧玉，冤魂一经变化便成了啼血的红色杜鹃。
注：血三年而藏碧：《庄子·外物》载苌弘被杀，“藏其血三年而化为碧”，后以“碧血”指忠臣之血。
注：魂一变而成红：传说蜀帝杜宇死后魂化杜鹃，啼至口中流血，染红杜鹃花；一说如此。

# 085｜举黄花而乘月艳，笼黛叶而卷云翘。
原：举黄花而乘月艳，笼黛叶而卷云翘。|| 高举黄花，借着月色更显艳丽；笼起黛绿的叶子，卷起如云的头饰。
注：黄花：一说指菊花，一说指女子额上的黄色妆饰，疑。
注：黛：青黑色。
注：云翘：古代女子的一种首饰；一说指如云的发髻。
注：说明：此句所咏之物未详，只释字面。

# 086｜垂纶帘外，疑钩势之重悬；透影窗中
原：垂纶帘外，疑钩势之重悬；透影窗中，若镜光之开照。|| 像在帘外垂下钓丝，让人怀疑又挂起了一只钓钩；影子透进窗中，好像明镜打开照人。
注：纶（lún）：钓鱼用的丝线。
注：钩势：新月弯曲如钩的形状；此句疑咏初月。
注：镜光：以镜子比喻月光。

# 087｜叠轻蕊而矜暖，布重泥而讶湿；迹似
原：叠轻蕊而矜暖，布重泥而讶湿；迹似连珠，形如聚粒。|| 堆叠轻软的花蕊，自夸温暖；铺上厚厚的泥土，又惊讶潮湿；留下的痕迹像连串的珠子，形状如聚集的米粒。
注：矜：自夸，自得。
注：讶：惊异。
注：说明：此句疑写燕子衔泥筑巢，所咏之物未详。

# 088｜霄光分晓，出虚窦以双飞；微阴合瞑
原：霄光分晓，出虚窦以双飞；微阴合瞑，舞低檐而并入。|| 夜色退去、天将破晓，它们从空洞中双双飞出；薄暮微暗、天色合拢，又在低矮的屋檐下飞舞着一同归巢。
注：霄光分晓：夜空渐亮，天将破晓。
注：虚窦：空洞，这里指巢穴。
注：瞑（míng）：昏暗，日暮。
注：说明：此句疑写燕子双飞。

# 089｜任他极有见识，看得假认不得真；随
原：任他极有见识，看得假认不得真；随你极有聪明，卖得巧藏不得拙。|| 任凭他再有见识，也只能看透虚假，却认不准真实；随便你再聪明，也只能卖弄机巧，却藏不住笨拙。
注：任他：任凭他。
注：卖得巧：能够卖弄机巧。

# 090｜伤心之事，即懦夫亦动怒发；快心之
原：伤心之事，即懦夫亦动怒发；快心之举，虽愁人亦开笑颜。|| 令人伤心的事，即使懦弱的人也会发怒；令人痛快的举动，即使满怀忧愁的人也会露出笑容。
注：怒发：发怒；一说即“怒发冲冠”之意。
注：快心：使人心里畅快。

# 091｜论官府不如论帝王，以佐史臣之不逮
原：论官府不如论帝王，以佐史臣之不逮；谈闺阃不如谈艳丽，以补风人之见遗。|| 议论官府不如议论帝王，可以补充史官记载的不足；谈论闺房之事不如谈论艳丽之情，可以补足诗人遗漏的见闻。
注：不逮：不及，不足之处。
注：闺阃（kǔn）：妇女居住的内室，代指女子之事。
注：风人：诗人；古有采诗观风之说，故称诗人为风人。

# 092｜是技皆可成名天下，唯无技之人最苦
原：是技皆可成名天下，唯无技之人最苦；片技即足自立天下，唯多技之人最劳。|| 凡是一门技艺都能让人名扬天下，只有没有技艺的人最苦；一点技艺就足以让人自立于世，只有技艺太多的人最劳累。
注：是技：凡是技艺。
注：片技：一点技艺。

# 093｜傲骨、侠骨、媚骨，即枯骨可致千金
原：傲骨、侠骨、媚骨，即枯骨可致千金；冷语、隽语、韵语，即片语亦重九鼎。|| 有傲骨、侠骨、媚骨的人，即使只剩一副枯骨也能值千金；冷峻的话、隽永的话、有韵致的话，即使只言片语也重如九鼎。
注：枯骨可致千金：化用燕昭王时以五百金买千里马之骨的故事，见《战国策·燕策》。
注：隽（juàn）语：意味深长的话。
注：九鼎：相传夏禹铸九鼎，象征国家重器，比喻分量极重。

# 094｜议生草莽无轻重，论到家庭无是非。
原：议生草莽无轻重，论到家庭无是非。|| 议论出自民间草野，就没什么分量；评说涉及自家人，就分不清是非。
注：草莽：草野，指民间、在野之人。
注：家庭：自家人之间；家务事难以断明是非。

# 095｜圣贤不白之衷，托之日月；天地不平
原：圣贤不白之衷，托之日月；天地不平之气，托之风雷。|| 圣贤无法表白的心迹，寄托给日月；天地间的不平之气，寄托给风雷。
注：不白之衷：无法向人表白的内心。
注：托之日月：意谓其心光明，可与日月相照。

# 096｜风流易荡，佯狂近颠。
原：风流易荡，佯狂近颠。|| 风流潇洒容易流于放荡，假装疯狂近乎真的癫狂。
注：佯狂：假装疯癫。
注：颠：通“癫”，疯癫。

# 097｜书载茂先三十乘，便可移家；囊无子
原：书载茂先三十乘，便可移家；囊无子美一文钱，尽堪结客。|| 书籍若有张华那样的三十车，便可以搬家迁居；囊中即使像杜甫那样没有一文钱，也尽可以结交朋友。
注：茂先三十乘（shèng）：晋张华字茂先，好藏书，《晋书·张华传》载其迁居时“载书三十乘”。
注：子美一文钱：杜甫字子美，其《空囊》诗有“囊空恐羞涩，留得一钱看”之句。
注：结客：结交朋友。

# 098｜有作用者，器宇定是不凡；有受用者
原：有作用者，器宇定是不凡；有受用者，才情决然不露。夫人有短，所以见长。|| 能有所作为的人，气度一定不凡；懂得享受生活的人，才情必然不外露。¦人有短处，所以才显得出长处。
注：作用：作为，施展才干。
注：器宇：气度，风度。
注：受用：享受、得益，这里指能安享生活之乐。
注：见（xiàn）：同“现”，显现。

# 099｜松枝自是幽人笔，竹叶常浮野客杯。
原：松枝自是幽人笔，竹叶常浮野客杯。且与少年饮美酒，往来射猎西山头。|| 松枝自然就是隐士的笔，竹叶酒常在山野之人的杯中浮动。¦姑且和少年们痛饮美酒，在西山头往来射猎。
注：幽人：隐士。
注：竹叶：竹叶酒，一种美酒；亦可兼指杯中漂浮的竹叶。
注：野客：山野之人，隐逸者。
注：说明：后两句为唐人诗句，出处待考。

# 100｜好山当户天呈画，古寺为邻僧报钟。
原：好山当户天呈画，古寺为邻僧报钟。|| 美好的山峰正对门户，好比上天呈上一幅画；古寺就在隔壁，僧人敲钟报时。
注：当户：正对门户。
注：报钟：敲钟报时。

# 101｜瑶草与芳兰而并茂，苍松齐古柏以增
原：瑶草与芳兰而并茂，苍松齐古柏以增龄。|| 仙草与芳兰一同繁茂，苍松同古柏一道延年。
注：瑶草：传说中的仙草，泛指珍美的草。
注：齐：与，同。
注：增龄：增添年岁，长寿。

# 102｜群鸿戏海，野鹤游天。
原：群鸿戏海，野鹤游天。|| 成群的鸿雁在海上嬉戏，野鹤在天空中遨游。
注：群鸿戏海：语本南朝梁袁昂《古今书评》评钟繇书法“如云鹄游天，群鸿戏海”，形容气象开阔自在。
注：野鹤：不受羁束的鹤，常比喻隐逸之人。
