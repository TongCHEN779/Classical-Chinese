# 001｜天下有一言之微，而千古如新，一字
题解：卷四以“灵”为纲，认为天地人三才之灵最终凝聚于语言文字，所收多为闲居山水、茶酒花月、谈禅悟道的清言，抒写超脱世俗、涵养灵性的情趣。
原：天下有一言之微，而千古如新，一字之义，而百世如见者，安可泯灭之？故风雷雨露，天之灵，山川名物，地之灵，语言文字，人之灵；毕三才之用，无非一灵以神其间，而又何可泯灭之？集灵第四。|| 天下有一句话虽然细微，却千古常新；一个字的意义，却能让百代之后的人如同亲见，怎么能让它们湮没呢？¦所以风雷雨露是天的灵气，山川名物是地的灵气，语言文字是人的灵气；穷尽天地人三才的作用，无非是一个“灵”字在其中起着神妙的作用，又怎么能让它湮没呢？¦因此把“灵”汇为第四集。
注：泯灭：消失，湮没无闻。
注：三才：指天、地、人。
注：神其间：在其中发挥神妙的作用；神，用作动词。

# 002｜投刺空劳，原非生计；曳裾自屈，岂
原：投刺空劳，原非生计；曳裾自屈，岂是交游。|| 递上名帖求见权贵，只是白费力气，本来就不是谋生的正道；拖着衣襟出入王侯门下，委屈自己，哪里算得上真正的交游。
注：投刺：递上名帖求见；刺，名帖。
注：曳裾（jū）：拖着衣襟，指在权贵门下做食客。语本邹阳《上吴王书》“何王之门不可曳长裾乎”。

# 003｜事遇快意处当转，言遇快意处当住。
原：事遇快意处当转，言遇快意处当住。|| 做事到称心快意的时候应当转身收手，说话到痛快淋漓的时候应当适可而止。
注：快意：称心如意，畅快。
注：住：停止。

# 004｜俭为贤德，不可著意求贤；贫是美称
原：俭为贤德，不可著意求贤；贫是美称，只是难居其美。|| 节俭是贤德，但不可刻意为求贤名而节俭；贫穷是美好的名声，只是难以真正安守其中的美。
注：著（zhuó）意：刻意，有意。
注：难居其美：难以安处于贫穷之中而保全它的美好。

# 005｜志要高华，趣要淡泊。
原：志要高华，趣要淡泊。|| 志向要高远华美，情趣要淡泊清雅。
注：高华：高远而有光彩。
注：趣：志趣，情趣。

# 006｜眼里无点灰尘，方可读书千卷；胸中
原：眼里无点灰尘，方可读书千卷；胸中没些渣滓，才能处世一番。|| 眼里没有一点灰尘，才能读得了千卷书；胸中没有一点渣滓，才能真正在世上立身处事一番。
注：灰尘：比喻偏见、俗念。
注：渣滓（zǐ）：比喻杂念与私欲。

# 007｜眉上几分愁，且去观棋酌酒；心中多
原：眉上几分愁，且去观棋酌酒；心中多少乐，只来种竹浇花。|| 眉间有几分愁绪时，就去看人下棋、饮几杯酒；心中有多少快乐，也只用来种竹浇花。
注：观棋酌酒：看人下棋，斟酒自饮，指借闲事排遣愁怀。
注：只来：只用来，只拿来。

# 008｜茅屋竹窗，贫中之趣，何须脚到李侯
原：茅屋竹窗，贫中之趣，何须脚到李侯门；草帖画谱，闲里所需，直凭心游杨子宅。|| 茅草屋、竹格窗，自有贫困中的乐趣，何必奔走到权贵门下；草书法帖、绘画图谱，是闲居时所需要的，只凭心神去神游扬雄那样的清寂之宅。
注：李侯门：泛指显贵之家的门庭；李侯所指未详。
注：草帖：草书的法帖。
注：杨子宅：即扬子宅，西汉扬雄的居所。扬雄家贫好学，闭门著书；左思《咏史》有“寂寂扬子宅，门无卿相舆”。

# 009｜好香用以熏德，好纸用以垂世，好笔
原：好香用以熏德，好纸用以垂世，好笔用以生花，好墨用以焕彩，好茶用以涤烦，好酒用以消忧。|| 好香用来熏陶德性，好纸用来书写传世之作，好笔用来写出绚丽文章，好墨用来焕发光彩，好茶用来涤除烦闷，好酒用来消解忧愁。
注：垂世：流传后世。
注：生花：比喻文思美妙。相传李白少时梦见笔头生花，此后才华横溢（见《开元天宝遗事》）。
注：涤烦：洗除烦躁。

# 010｜声色娱情，何若净几明窗，一坐息顷
原：声色娱情，何若净几明窗，一坐息顷；利荣驰念，何若名山胜景，一登临时。|| 用歌舞美色来娱乐性情，哪比得上在洁净的几案、明亮的窗前静坐片刻；为名利荣华驰骋心思，哪比得上登临名山胜景的那一刻。
注：声色：歌舞与美色。
注：息顷：一呼一吸之间，指极短的时间。
注：驰念：心思奔逐，念念不忘。

# 011｜竹篱茅舍，石屋花轩，松柏群吟，藤
原：竹篱茅舍，石屋花轩，松柏群吟，藤萝翳景；流水绕户，飞泉挂檐；烟霞欲栖，林壑将瞑。中处野叟山翁四五，予以闲身，作此中主人。坐沉红烛，看遍青山，消我情肠，任他冷眼。|| 竹篱笆、茅草屋，石砌的房子、花木环绕的轩廊，松柏在风中齐声吟啸，藤萝遮掩着光影；流水环绕门前，飞泉挂在屋檐边；云霞仿佛要在这里栖息，山林溪谷即将暗下来。¦其中住着四五位山野老翁，我以清闲之身，做这里的主人。¦坐到红烛燃尽，看遍青山景色，消解我心中的情愁，任凭别人冷眼相看。
注：花轩：花木环绕的有窗长廊或小屋。
注：翳（yì）景：遮蔽光影；景，同“影”，一说指日光。
注：林壑将瞑（míng）：山林溪谷将要昏暗，指黄昏。
注：坐沉红烛：坐到红烛燃尽。

# 012｜问妇索酿，瓮有新刍；呼童煮茶，门
原：问妇索酿，瓮有新刍；呼童煮茶，门临好客。|| 向妻子讨酒，瓮中正有新酿的酒；叫童仆煮茶，门前恰好来了好客人。
注：索酿：讨酒；酿，酒。
注：新刍（chú）：新酿成的酒。

# 013｜花前解佩，湖上停桡，弄月放歌，采
原：花前解佩，湖上停桡，弄月放歌，采莲高醉；晴云微袅，渔笛沧浪，华句一垂，江山共峙。|| 在花前解下佩玉相赠，在湖上停下船桨，赏月放声歌唱，采莲时尽兴大醉；晴空云朵微微飘动，渔人的笛声回荡在沧浪之上，垂下一竿钓丝，便与江山一同屹立。
注：解佩：解下佩玉相赠。传说郑交甫在汉皋台下遇二神女，神女解佩相赠（见《列仙传》）。
注：停桡（ráo）：停桨，泊船；桡，船桨。
注：沧浪：青苍色的水，也令人联想到《孟子》所引“沧浪之水清兮”的渔父之歌。
注：校：“华句一垂”意难通，疑“句”当作“钩”，指垂钓，暂按此解。

# 014｜胸中有灵丹一粒，方能点化俗情，摆
原：胸中有灵丹一粒，方能点化俗情，摆脱世故。|| 胸中有一粒灵丹，才能点化世俗的情欲，摆脱人情世故的牵累。
注：灵丹：道家所炼的神药，这里比喻内心的灵明觉悟。
注：点化：道教谓仙人以法术使物变化，引申为启发、使人觉悟。
注：世故：世俗人情事务。

# 015｜独坐丹房，潇然无事，烹茶一壶，烧
原：独坐丹房，潇然无事，烹茶一壶，烧香一炷，看达摩面壁图。垂帘少顷，不觉心净神清，气柔息定，蒙蒙然如混沌境界，意者揖达摩与之乘槎而见麻姑也。|| 独自坐在清静的丹房里，潇洒无事，煮一壶茶，烧一炷香，观看达摩面壁图。¦垂下帘子片刻，不知不觉心思纯净、神志清明，气息柔和安定，迷迷蒙蒙仿佛回到了天地未分的混沌境界，想来就像拜过达摩，同他乘着木筏去见麻姑了。
注：丹房：炼丹的房间，泛指修道养性的静室。
注：达摩面壁：相传禅宗初祖菩提达摩在嵩山少林寺面壁静坐九年。
注：混沌：传说中天地未分时的元气状态。
注：乘槎（chá）：乘木筏。张华《博物志》载有人乘槎浮海到达天河，后用以指游仙。
注：麻姑：传说中的女仙，见葛洪《神仙传》。
注：意者：想来，大概。

# 016｜无端妖冶，终成泉下骷髅；有分功名
原：无端妖冶，终成泉下骷髅；有分功名，自是梦中蝴蝶。|| 再怎样艳丽无比的美人，终究会成为黄泉下的骷髅；命中有份的功名，也不过是梦中的蝴蝶。
注：无端：无边无际，指极其；一说为无缘无故。
注：泉下：黄泉之下，指死后。
注：梦中蝴蝶：《庄子·齐物论》载庄周梦为蝴蝶，醒后不知是庄周梦蝶还是蝶梦庄周，比喻人生如梦，虚幻无常。

# 017｜累月独处，一室萧条；取云霞为伴侣
原：累月独处，一室萧条；取云霞为伴侣，引青松为心知。或稚子老翁，闲中来过，浊酒一壶，蹲鸱一盂，相共开笑口，所谈浮生闲话，绝不及市朝。客去关门，了无报谢，如是毕馀生足矣。|| 接连几个月独自居住，满屋冷清；把云霞当作伴侣，把青松引为知己。¦有时孩童或老翁在闲暇时来访，一壶浊酒，一盆芋头，一起开怀大笑，所谈都是人生闲话，绝不涉及官场市井。¦客人走了就关上门，也不必回访答谢，这样度过余生就满足了。
注：心知：知心朋友。
注：蹲鸱（chī）：大芋头，因形似蹲伏的鸱鸟而得名，见《史记·货殖列传》。
注：市朝：集市与朝廷，指名利场。
注：报谢：回访答谢。

# 018｜半坞白云耕不尽，一潭明月钓无痕。
原：半坞白云耕不尽，一潭明月钓无痕。|| 半坞白云，怎么耕也耕不尽；一潭明月，垂钓其中也不留痕迹。
注：坞（wù）：四周高中间低的山地。
注：钓无痕：在映月的潭水中垂钓，水面不留痕迹，形容意境空明。

# 019｜茅檐外，忽闻犬吠鸡鸣，恍似云中世
原：茅檐外，忽闻犬吠鸡鸣，恍似云中世界；竹窗下，唯有蝉吟鹊噪，方知静里乾坤。|| 茅屋檐外，忽然听到狗叫鸡鸣，恍惚像是在云中的仙界；竹窗之下，只有蝉吟鹊噪，才知道静中自有天地。
注：云中世界：指仙境。传说淮南王刘安成仙，鸡犬舔食余药也随之升天，鸡鸣天上，犬吠云中（见葛洪《神仙传》）。
注：乾坤：天地。

# 020｜如今休去便休去，若觅了时无了时。
原：如今休去便休去，若觅了时无了时。若能行乐，即今便好快活。身上无病，心上无事，春鸟是笙歌，春花是粉黛。闲得一刻，即为一刻之乐，何必情欲乃为乐耶？|| 现在要罢手就罢手，若想等事情了结的时候，就永远没有了结的时候。¦如果能及时行乐，眼下就很快活。¦身上没有病痛，心里没有烦事，春天的鸟鸣便是笙歌，春天的花朵便是美人。¦能偷闲一刻，就有一刻的快乐，何必要放纵情欲才算快乐呢？
注：休去：罢休，放下。“如今休去便休去，若觅了时无了时”是当时流传的禅语诗句，出处未详。
注：笙歌：吹笙唱歌，泛指音乐歌舞。
注：粉黛：女子的妆饰，代指美女。

# 021｜开眼便觉天地阔，挝鼓非狂；林卧不
原：开眼便觉天地阔，挝鼓非狂；林卧不知寒暑，上床空算。|| 一睁开眼就觉得天地辽阔，像祢衡那样击鼓也不算狂；高卧林中不知寒暑，上了床便把一切盘算放空。
注：挝（zhuā）鼓：击鼓。东汉祢衡曾击鼓骂曹操，被视为狂士（见《后汉书·祢衡传》）。
注：上床空算：意未详，暂解为上床即放下种种算计；一说指空自计算时日。

# 022｜惟俭可以助廉，惟恕可以成德。
原：惟俭可以助廉，惟恕可以成德。|| 只有节俭才能有助于廉洁，只有宽恕才能成就德行。
注：助廉：有助于保持廉洁。
注：恕：推己及人，宽容待人。

# 023｜山泽未必有异士，异士未必在山泽。
原：山泽未必有异士，异士未必在山泽。|| 山林湖泽之中未必有奇人，奇人也未必都在山林湖泽之中。
注：山泽：山林湖泽，指隐士所居之地。
注：异士：才能、品行不同寻常的人。

# 024｜业净六根成慧眼，身无一物到茅庵。
原：业净六根成慧眼，身无一物到茅庵。|| 业障净尽、六根清净，便成就了慧眼；身上不带一物，来到茅庵。
注：六根：佛教语，指眼、耳、鼻、舌、身、意。
注：慧眼：佛教五眼之一，能洞见真空无相之理的眼睛。
注：业：佛教语，指身、口、意所造的业障。

# 025｜人生莫如闲，太闲反生恶业；人生莫
原：人生莫如闲，太闲反生恶业；人生莫如清，太清反类俗情。|| 人生没有比清闲更好的，但太闲反而会生出恶业；人生没有比清高更好的，但太清高反而类似俗人的矫情。
注：恶业：佛教语，指能招致恶报的行为。
注：俗情：世俗的情态，这里指故作清高的俗套。

# 026｜不是一番寒彻骨，怎得梅花扑鼻香。
原：不是一番寒彻骨，怎得梅花扑鼻香。念头稍缓时，便宜庄诵一遍。|| 不经过一番彻骨的寒冷，怎能得到扑鼻的梅花清香。¦念头稍有懈怠时，就应当恭敬地念诵一遍。
注：不是一番寒彻骨：语出唐代黄檗禅师偈语“不是一番寒彻骨，争得梅花扑鼻香”。
注：便宜：就应当。
注：庄诵：端庄恭敬地诵读。

# 027｜梦以昨日为前身，可以今夕为来世。
原：梦以昨日为前身，可以今夕为来世。|| 梦中若可以把昨天当作前世，也就可以把今晚当作来世。
注：前身：佛教语，指前世之身。
注：来世：死后的下一世。

# 028｜读史要耐讹字，正如登山耐仄路，蹈
原：读史要耐讹字，正如登山耐仄路，蹈雪耐危桥，闲居耐俗汉，看花耐恶酒，此方得力。|| 读史书要忍耐错字，正像登山要忍耐狭窄的小路，踏雪要忍耐危险的桥梁，闲居要忍耐庸俗的人，赏花要忍耐劣质的酒，这样才能有所得益。
注：讹（é）字：错字。
注：仄（zè）路：狭窄倾斜的小路。
注：得力：得到益处。

# 029｜世外交情，惟山而已。须有大观眼，
原：世外交情，惟山而已。须有大观眼，济胜具，久住缘，方许与之莫逆。|| 世俗之外的交情，只有山而已。¦必须有纵览大观的眼光、登山涉险的体力、久居山中的缘分，才可以与山结为莫逆之交。
注：大观眼：能纵览壮阔景象的眼光。
注：济胜具：能游览胜景的身体条件。《世说新语·栖逸》说许询善登山，“非徒有胜情，实有济胜之具”。
注：莫逆：心意相投，毫无抵触。

# 030｜九山散樵迹，俗间徜徉自肆，遇佳山
原：九山散樵迹，俗间徜徉自肆，遇佳山水处，盘礡箕踞，四顾无人，则划然长啸，声振林木；有客造榻与语，对曰：“馀方游华胥，接羲皇，未暇理君语。”客之去留，萧然不以为意。|| 九山散樵的事迹是：在俗世中逍遥自在、随心所欲，遇到好山水的地方，便叉开双腿随意而坐，四顾无人，就放声长啸，声音震动林木；有客人来到他的坐榻前同他说话，他回答说：“我正游于华胥之国，拜见伏羲，没空理会您的话。”¦客人去留与否，他都淡然不放在心上。
注：九山散樵：别号，所指未详；一说为编者所仰慕的某位隐士。
注：盘礡（bó）箕踞：随意叉腿而坐，不拘礼节。盘礡，同“般礴”，语出《庄子·田子方》；箕踞，两腿伸开坐，形似簸箕。
注：划然长啸：忽然放声长啸，语出苏轼《后赤壁赋》。
注：华胥：传说中的理想国度，《列子·黄帝》载黄帝梦游华胥氏之国。
注：羲皇：伏羲氏，指太古淳朴之世。
注：馀：同“余”，我。

# 031｜择池纳凉，不若先除热恼；执鞭求富
原：择池纳凉，不若先除热恼；执鞭求富，何如急遣穷愁。|| 选择池边纳凉，不如先消除心中的烦热；拿着鞭子替人驾车以求富贵，哪如赶快打发掉贫穷的愁思。
注：热恼：佛教语，指焦灼苦恼。
注：执鞭求富：《论语·述而》“富而可求也，虽执鞭之士，吾亦为之”，执鞭指替人驾车等低贱差事。
注：遣：排遣，打发。

原：万壑疏风清，两耳闻世语，急须敲玉磬三声；九天凉月净，初心诵其经，胜似撞金钟百下。|| 万壑之间清风疏朗，两耳若听到世俗言语，赶紧敲三声玉磬；九天之上凉月明净，以本初之心诵读经文，胜过撞钟百下。
注：玉磬（qìng）：玉制的磬，一种敲击乐器，寺院用以集众或礼佛。
注：初心：佛教语，指最初发起的菩提之心，引申为纯净的本心。

# 033｜无事而忧，对景不乐，即自家亦不知
原：无事而忧，对景不乐，即自家亦不知是何缘故，这便是一座活地狱，更说甚么铜床铁柱，剑树刀山也。|| 没事却忧愁，面对美景却不快乐，连自己也不知道是什么缘故，这就是一座活地狱，更不用说什么铜床铁柱、剑树刀山了。
注：铜床铁柱，剑树刀山：佛经中所说地狱的种种酷刑。

# 034｜烦恼之场，何种不有，以法眼照之，
原：烦恼之场，何种不有，以法眼照之，奚啻蝎蹈空花。|| 烦恼的场所，什么样的没有，用法眼来观照，何止是蝎子踩在虚幻的空花上那样虚妄。
注：法眼：佛教五眼之一，能洞察一切法相的眼睛。
注：奚啻（chì）：何止。
注：空花：也作“空华”，佛教语，眼病者看见空中有花，比喻虚妄不实。
注：校：“蝎蹈空花”意难通，疑有讹字，暂按字面解作虚幻无实。

原：上高山，入深林，穷回溪，幽泉怪石，无远不到；到则拂草而坐，倾壶而醉，醉则更相枕借以卧，意亦甚适，梦亦同趣。|| 登上高山，进入深林，走遍曲折的溪流，幽深的泉水、奇怪的石头，再远都要去到；到了就拨开草丛坐下，倒出壶中的酒喝醉，醉了就互相枕着躺下，心意十分舒适，连做梦也志趣相同。

注：更相枕借：互相枕靠着；借，垫着。
注：出处：此条化用柳宗元《始得西山宴游记》中的文句。

注：佛书：佛教经典。
注：佳客：志趣相投的客人。

# 037｜客散门扃，风微日落，碧月皎皎当空
原：客散门扃，风微日落，碧月皎皎当空，花阴徐徐满地；近檐鸟宿，远寺钟鸣，荼铛初熟，酒瓮乍开；不成八韵新诗，毕竟一个俗气。|| 客人散去，门已关上，风声细微，太阳落下，碧空明月皎洁当空，花影慢慢铺满地面；檐下鸟儿栖宿，远处寺里传来钟声，茶铛里的茶刚刚煮好，酒瓮也刚刚打开；如果此时作不成一首八韵新诗，终究是一身俗气。
注：扃（jiōng）：关闭门户。
注：荼铛（chēng）：煮茶的锅；荼，古“茶”字。
注：八韵：用八个韵脚的诗，即十六句的排律。

# 038｜不作风波于世上，自无冰炭到胸中。
原：不作风波于世上，自无冰炭到胸中。|| 不在世上兴风作浪，胸中自然不会有冰炭相煎的焦灼。
注：风波：比喻纷争、是非。
注：冰炭：冰与炭不能相容，比喻内心的矛盾冲突与煎熬。

# 039｜秋月当天，纤云都净，露坐空阔去处
原：秋月当天，纤云都净，露坐空阔去处，清光冷浸，此身如在水晶宫里，令人心胆澄澈。|| 秋月高悬天空，细云全都散尽，露天坐在空旷开阔的地方，清冷的月光浸透全身，这身子仿佛在水晶宫里，令人内心澄净透亮。
注：纤云：细薄的云。
注：水晶宫：传说中龙王所居的宫殿，这里形容月光下明澈的境界。
注：心胆：心神，内心。

# 040｜遗子黄金满箧，不如教子一经。
原：遗子黄金满箧，不如教子一经。|| 留给子孙满箱黄金，不如教子孙通晓一部经书。
注：遗（wèi）：赠送，留给。
注：箧（qiè）：小箱子。
注：出处：语本《汉书·韦贤传》邹鲁谚语“遗子黄金满籝，不如一经”。

# 041｜凡醉各有所宜。醉花宜昼，袭其光也
原：凡醉各有所宜。醉花宜昼，袭其光也；醉雪宜夜，清其思也；醉得意宜唱，宣其和也；醉将离宜击钵，壮其神也；醉文人宜谨节奏，畏其侮也；醉俊人宜益觥盂加旗帜，助其怒也；醉楼宜暑，资其清也；醉水宜秋，泛其爽也。此皆审其宜，考其景，反此则失饮矣。|| 凡是醉饮，各有适宜的场合。¦醉于花下适宜在白天，可以借取花的光彩；醉于雪中适宜在夜晚，可以使情思清澈；得意时醉饮适宜歌唱，可以抒发和乐之情；将要离别时醉饮适宜击钵，可以壮大精神；与文人同醉适宜谨守节制，以免失礼受辱；与豪俊之士同醉适宜加大酒器、竖起酒令旗帜，以助长豪气；在楼上醉饮适宜在夏天，借以取得清凉；在水上醉饮适宜在秋天，可以泛舟享受清爽。¦这些都是审度饮酒的适宜和考察当时的景致，与此相反就失去了饮酒的意趣。

注：击钵：敲击铜钵作节拍。
注：觥（gōng）盂：大酒杯和盛酒器。
注：旗帜：酒令所用的令旗，一说指酒旗。
注：失饮：失去饮酒的真趣。

注：茶灶：煮茶的小炉灶。

注：山翠：青翠的山色。

注：不受词赋：不接受其文辞，意谓文才救不了恶行。

注：木鱼：僧人诵经时敲击的木制法器。

注：优钵（bō）：优钵罗，梵语音译，即青莲花，佛经中常用来比喻清净与稀有。

注：机息：机心止息，不再算计。
注：坐忘：语出《庄子·大宗师》，指静坐中物我两忘的境界。
注：蜉（fú）蝣：一种朝生暮死的小虫，比喻生命短暂、事物无常。

注：郁勃：旺盛蓬勃。
注：弄舌：鸟儿婉转鸣叫。
注：潇疏：清爽疏朗。

注：了心：明了、了悟自心。
注：常道：人伦日用中恒常不变的道理。
注：出世：超脱尘世，指修佛修道。

注：深趣：深长的意趣。

注：蛾眉：即峨眉山，在今四川。
注：泰岱：泰山，又称岱宗。

# 052｜人有一字不识，而多诗意；一偈不参
原：人有一字不识，而多诗意；一偈不参，而多禅意；一勺不濡，而多酒意；一石不晓，而多画意；淡宕故也。|| 有的人一个字也不认识，却富有诗意；一句偈语也没参究过，却富有禅意；一勺酒也没沾过，却富有酒意；一块石头也不懂得欣赏，却富有画意；这都是因为他们心性恬淡放旷的缘故。

注：濡（rú）：沾湿，这里指沾唇饮酒。
注：淡宕（dàng）：恬淡而放达不拘。

原：以看世人青白眼，转而看书，则圣贤之真见识；以议论人雌黄口，转而论史，则左狐之真是非。|| 如果把看待世人时那种分别青眼白眼的眼光，转过来用于读书，就能看出圣贤的真见识；如果把议论别人时那张信口雌黄的嘴，转过来用于评论历史，就能辨出左丘明那样的真是非。
注：青白眼：《晋书·阮籍传》载阮籍能作青白眼，对礼俗之士以白眼相待，对知己以青眼相看。

注：左狐：左丘明与狐，疑指左丘明与晋国史官董狐，二人皆以秉笔直书、褒贬分明著称；一说“狐”为字误，存疑。

# 054｜事到全美处，怨我者不能开指摘之端

注：全美：完美无缺。
注：指摘：挑出错误加以批评。
注：至污：极其污浊卑下。

# 055｜必出世者，方能入世，不则世缘易堕
原：必出世者，方能入世，不则世缘易堕；必入世者，方能出世，不则空趣难持。|| 一定要是能出世的人，才能入世，否则容易沉沦于世俗的牵缠；一定要是能入世的人，才能出世，否则空寂的意趣难以持守。

注：入世：投身于世事人情之中。
注：世缘：尘世中的种种牵连纠缠。
注：空趣：空寂清净的意趣，指佛道的超脱境界。

# 087｜清之品有五：睹标致，发厌俗之心，

注：血属：有血缘关系的亲属。

注：偶饭淮阴：韩信（后封淮阴侯）少时贫困，在城下钓鱼，有漂洗丝絮的老妇见他饥饿，给他饭吃，事见《史记·淮阴侯列传》；饭，给人饭吃。
注：醉题便殿：指李白醉中奉诏在宫中作诗的传说；便殿，帝王休息宴游的别殿。一说泛指文人醉中应制。

原：清闲无事，坐卧随心，虽粗衣淡食，自有一段真趣；纷扰不宁，忧患缠身，虽锦衣厚味，只觉万状愁苦。|| 清闲无事，坐卧随心，即使穿粗衣、吃淡饭，自有一种真正的乐趣；纷乱不安，忧患缠身，即使穿锦衣、吃美食，也只觉得万般愁苦。
注：厚味：味道浓美的食物。
注：万状：各种各样的情状。

# 116｜我如为善，虽一介寒士，有人服其德
原：我如为善，虽一介寒士，有人服其德；我如为恶，虽位极人臣，有人议其过。|| 我如果行善，即使只是一个贫寒的读书人，也会有人敬服我的德行；我如果作恶，即使位居群臣之首，也会有人议论我的过错。
注：一介寒士：一个贫寒的读书人；介，个。
注：位极人臣：做到臣子中最高的官位。

# 117｜读理义书，学法帖字；澄心静坐，益
原：读理义书，学法帖字；澄心静坐，益友清谈；小酌半醺，浇花种竹；听琴玩鹤，焚香煮茶；泛舟观山，寓意奕棋。虽有他乐，吾不易矣。|| 读讲义理的书，临摹名家法帖练字；澄净心思静坐，与良友清谈；小饮到半醉，浇花种竹；听琴赏鹤，焚香煮茶；泛舟看山，借下棋寄托情趣。¦即使有别的乐事，我也不拿这些去交换。
注：理义书：阐发义理的书，如经书与理学著作。
注：法帖：供人临摹学习的名家书法范本。
注：半醺（xūn）：微醉。
注：寓意：寄托情趣。
注：易：交换。

# 118｜成名每在穷苦日，败事多因得志时。
原：成名每在穷苦日，败事多因得志时。|| 成就名声往往在穷苦的日子，败坏事情大多因为得志的时候。
注：得志：实现志愿，多指仕途显达、处境顺利。

原：宠辱不惊，肝木自宁；动静以敬，心火自定；饮食有节，脾土不泄；调息寡言，肺金自全；怡神寡欲，肾水自足。|| 受宠受辱都不惊动，肝木自然安宁；动与静都保持恭敬，心火自然平定；饮食有节制，脾土就不会虚泄；调匀呼吸、少说话，肺金自然保全；怡养精神、减少欲望，肾水自然充足。
注：肝木、心火、脾土、肺金、肾水：中医以五行配五脏的说法，肝属木，心属火，脾属土，肺属金，肾属水。
注：调息：调匀呼吸。
注：泄：中医指脾虚泄泻、精气外泄。

# 120｜让利精于取利，逃名巧于邀名。
原：让利精于取利，逃名巧于邀名。|| 让利比争利更高明，逃避名声比求取名声更巧妙。
注：精：精明，高明。
注：邀名：求取名声。

# 121｜彩笔描空，笔不落色，而空亦不受染
原：彩笔描空，笔不落色，而空亦不受染；利刀割水，刀不损锷，而水亦不留痕。|| 用彩笔在空中描画，笔上的颜色落不下去，虚空也不会被染污；用利刀去割水，刀刃不会损伤，水也不留下痕迹。
注：锷（è）：刀剑的刃。
注：不受染：不被沾染，喻心不为外物所累。

# 122｜唾面自干，娄师德不失为雅量；睚眦
原：唾面自干，娄师德不失为雅量；睚眦必报，郭象玄未免为祸胎。|| 被人唾到脸上任它自干，娄师德不失为有宽宏的气量；连瞪一眼的小怨也必定报复，郭象玄未免成为祸患的根源。
注：唾面自干：唐代娄师德告诫其弟，被人唾面不要擦拭，应任其自干，以免更激其怒，事见《新唐书·娄师德传》。
注：睚眦（yá zì）必报：瞪一眼这样的小怨也一定报复。
注：郭象玄：其人其事待考，此处只取其睚眦必报之意。
注：祸胎：祸根。

# 123｜天下可爱的人，都是可怜人；天下可
原：天下可爱的人，都是可怜人；天下可恶的人，都是可惜人。|| 天下可爱的人，都是值得怜惜的人；天下可恶的人，都是令人惋惜的人。
注：可怜：值得怜爱、同情。
注：可惜：令人惋惜。

# 124｜事业文章，随身销毁，而精神万古如
原：事业文章，随身销毁，而精神万古如新；功名富贵，逐世转移，而气节千载一日。|| 事业文章，随着人身死去而消亡，精神却万古常新；功名富贵，随着世事变迁而转移，气节却千年如同一日。
注：随身销毁：随着身死而消失。
注：逐世转移：随着时世变迁而变化。

# 125｜读书到快目处，起一切沉沦之色；说
原：读书到快目处，起一切沉沦之色；说话到洞心处，破一切暧昧之私。|| 读书读到令人眼目畅快的地方，能使一切消沉颓丧的神色振作起来；说话说到透彻人心的地方，能破除一切隐秘不明的私心。
注：快目：使眼目畅快。
注：沉沦之色：消沉颓丧的神色。
注：洞心：洞彻人心。
注：暧昧之私：不光明的私心。

# 126｜谐臣媚子，极天下聪颖之人；秉正嫉
原：谐臣媚子，极天下聪颖之人；秉正嫉邪，作世间忠直之气。|| 以诙谐谄媚取宠的臣子佞幸，都是天下最聪明伶俐的人；秉持正道、憎恶邪恶，才显出世间忠诚正直的气概。
注：谐臣媚子：以诙谐取乐、谄媚讨好侍奉君主的臣子和宠幸之人。
注：秉正嫉邪：坚持正道，憎恶邪恶。

# 127｜隐逸林中无荣辱，道义路上无炎凉。
原：隐逸林中无荣辱，道义路上无炎凉。|| 在隐逸的山林中没有荣辱之分，在道义的路上没有世态炎凉。
注：隐逸：隐居避世。
注：炎凉：冷热，比喻人情势利、世态冷暖。

# 128｜闻谤而怒者，谗之囮；见誉而喜者，
原：闻谤而怒者，谗之囮；见誉而喜者，佞之媒。|| 听到诽谤就发怒的人，是谗言的诱饵；见到赞誉就欢喜的人，是谄媚的媒介。
注：囮（é）：捕鸟时用来引诱同类的活鸟，引申为诱饵。
注：佞（nìng）：用花言巧语谄媚人。
注：媒：媒介，引子。

# 129｜滩浊作画，正如隔帘看月，隔水看花
原：滩浊作画，正如隔帘看月，隔水看花，意在远近之间，亦文章法也。|| 用浅淡朦胧的笔墨作画，正如隔着帘子看月、隔着水看花，意境在远近之间，这也是写文章的方法。
注：校：“滩浊”费解，疑有讹误，一说当作“淡浊”，指浅淡朦胧的笔墨，姑从此意译。
注：文章法：写文章的章法。

# 130｜藏锦于心，藏绣于口；藏珠玉于咳唾
原：藏锦于心，藏绣于口；藏珠玉于咳唾，藏珍奇于笔墨；得时则藏于册府，不得则藏于名山。|| 把锦绣般的文思藏在心中，把华美的辞藻藏在口中；把珠玉般的妙语藏在谈吐间，把珍奇的见识藏在笔墨里；遇到时机就收藏在朝廷的书府中，遇不到时机就藏到名山之中传给后人。
注：锦心绣口：形容文思优美、辞藻华丽；唐柳宗元《乞巧文》有“锦心绣口”之语。
注：咳唾：咳嗽吐唾，这里指言谈；古人以“咳唾成珠”称誉出语精妙。
注：册府：帝王收藏典籍的府库。
注：藏于名山：化用司马迁《报任安书》“藏之名山，传之其人”，指著述不为时用，留待后世。

# 131｜读一篇轩快之书，宛见山青水白；听
原：读一篇轩快之书，宛见山青水白；听几句伶俐之语，如看岳立川行。|| 读一篇爽朗畅快的文章，仿佛看见青山绿水；听几句聪明灵巧的话，好像看到山岳耸立、江河奔流。
注：轩快：轩昂爽快。
注：伶俐：聪明灵巧。
注：岳立川行：山岳挺立，河川奔流，形容气象开阔生动。

# 132｜读书如竹外溪流，洒然而往；咏诗如
原：读书如竹外溪流，洒然而往；咏诗如𬞟末风起，勃焉而扬。|| 读书要像竹林外的溪水，洒脱自在地流去；吟诗要像风从蘋草梢头生起，勃然飞扬。
注：洒然：洒脱无拘的样子。
注：𬞟末风起：𬞟同“蘋”，一种水草；宋玉《风赋》有“风生于地，起于青蘋之末”。
注：勃焉：蓬勃兴起的样子。

注：子弟排场：子弟，这里指演戏的伶人；排场，登场演出的场面。一说泛指游乐子弟的场面。
注：谢：辞去，这里指缺少。
注：缠头之锦：古时赏给歌舞艺人的锦帛，称“缠头”。
注：廉隅：棱角，比喻端方严正的品行与礼节。
注：蕴藉：含蓄宽和，有余味。

注：箑（shà）：扇子。
注：槔（gāo）：桔槔，利用杠杆原理汲水的器具。
注：激水：引水、打水。

注：无定河：在今陕西北部，唐陈陶《陇西行》有“可怜无定河边骨，犹是春闺梦里人”。
注：破镜：比喻夫妻离散，典出南朝陈乐昌公主与徐德言破镜分执的故事。

# 145｜有书癖而无剪裁，徒号书厨；惟名饮
原：有书癖而无剪裁，徒号书厨；惟名饮而少酝藉，终非名饮。|| 有读书的癖好却不懂取舍裁择，只能叫作书橱；只图善饮的名声而缺少含蓄的风度，终究算不得真正的名饮之人。
注：剪裁：取舍，裁择。
注：书厨：比喻读书虽多而不能运用的人；《南史·陆澄传》载王俭称陆澄为“书厨”。
注：名饮：以善饮著名的人，一说指只图饮酒之名。
注：酝藉：同“蕴藉”，含蓄宽和；用“酝”字兼关酒事。

# 146｜飞泉数点雨非雨，空翠几重山又山。
原：飞泉数点雨非雨，空翠几重山又山。|| 飞泉溅起几点水珠，像雨又不是雨；青翠的山色层层叠叠，山外又是山。
注：空翠：青翠的山色，看上去空濛湿润。

# 147｜夜者日之馀，雨者月之馀，冬者岁之
原：夜者日之馀，雨者月之馀，冬者岁之馀。当此三馀，人事稍疏，正可一意问学。|| 夜晚是白天的余暇，雨天是一月中的余暇，冬季是一年的余暇。¦在这三种余暇里，人事稍稍稀少，正好可以专心求学。
注：三馀：语本三国魏董遇，《三国志·魏书·王肃传》裴注引《魏略》载其言“冬者岁之馀，夜者日之馀，阴雨者时之馀”。
注：一意：专心一意。
注：问学：求教学问，指读书治学。

# 148｜树影横床，诗思平凌枕外；云华满纸
原：树影横床，诗思平凌枕外；云华满纸，字意隐跃行间。|| 树影横映在床上，诗思悠然飞越到枕外；云霞般的光彩铺满纸面，字中意趣隐隐跃动在行间。
注：平凌：平平地升腾超越；一说“平”字疑误。
注：云华：云彩的光华，这里形容纸上墨色或映照的光影。
注：隐跃：隐约跃动。

# 149｜耳目宽则天地窄，争务短则日月长。
原：耳目宽则天地窄，争务短则日月长。|| 耳目所追逐的东西多了，天地反而显得狭窄；争竞的事务少了，日月便显得悠长。
注：耳目宽：耳目所及、所求的外物繁多。
注：争务：争竞追逐的事务。

# 150｜秋老洞庭，霜清彭泽。
原：秋老洞庭，霜清彭泽。|| 秋意深沉笼罩洞庭湖，霜气清冷洒落彭泽。
注：秋老：秋深。
注：洞庭：洞庭湖，在今湖南北部。
注：彭泽：古泽名，即今鄱阳湖一带；亦为县名，陶渊明曾任彭泽令。

# 151｜听静夜之钟声，唤醒梦中之梦；观澄
原：听静夜之钟声，唤醒梦中之梦；观澄潭之月影，窥见身外之身。|| 听着静夜里的钟声，唤醒梦中之梦；看着清潭里的月影，窥见形体之外的真我。
注：梦中之梦：人生本如一梦，沉迷其中更是梦中做梦。
注：身外之身：超越肉体形骸的本来面目。

# 152｜事有急之不白者，宽之或自明，毋躁
原：事有急之不白者，宽之或自明，毋躁急以速其忿；人有操之不从者，纵之或自化，毋操切以益其顽。|| 有的事越着急越弄不清楚，放宽一些或许自然就明白了，不要急躁以致激起对方的怒气；有的人越约束越不顺从，放任一些或许自然就感化了，不要急切强迫以致加重他的顽固。
注：白：明白，清楚。
注：速：招致。
注：操切：办事急躁，强行逼迫。

# 153｜士君子贫不能济物者，遇人痴迷处，
原：士君子贫不能济物者，遇人痴迷处，出一言提醒之；遇人急难处，出一言解救之，亦是无量功德。|| 士君子贫穷而不能用财物救济别人，遇到别人执迷不悟的时候，说一句话提醒他；遇到别人危急困难的时候，说一句话解救他，这也是无量的功德。
注：士君子：有学问、有德行的读书人。
注：济物：救助他人。
注：无量功德：佛教语，指无法计量的善行福德。

# 154｜处父兄骨肉之变，宜从容，不宜激烈
原：处父兄骨肉之变，宜从容，不宜激烈；遇朋友交游之失，宜剀切，不宜优游。|| 处理父兄骨肉之间的变故，应当从容，不宜激烈；遇到朋友交往中的过失，应当恳切规劝，不宜宽纵放任。
注：骨肉之变：亲人之间的变故、争端。
注：剀（kǎi）切：恳切直言，切中事理。
注：优游：宽缓放任，不加规劝。

# 155｜问祖宗之德泽，吾身所享者，是当念
原：问祖宗之德泽，吾身所享者，是当念其积累之难；问子孙之福祉，吾身所贻者，是要思其倾覆之易。|| 问起祖宗留下的恩德，凡是我自身享受到的，都应当想到他们积累的艰难；问起子孙的福气，凡是我将留给他们的，都要想到它倾覆的容易。
注：德泽：恩德与福泽。
注：贻（yí）：遗留，留给。
注：倾覆：败落，丧失。

# 156｜韶光去矣，叹眼前岁月无多，可惜年
原：韶光去矣，叹眼前岁月无多，可惜年华如疾马；长啸归与，知身外功名是假，好将姓字任呼牛。|| 美好的时光已经逝去，叹息眼前剩下的岁月不多，可惜年华像疾驰的马一样飞逝；长啸一声归去吧，知道身外的功名都是虚假的，正好让人把我的姓名随便叫作牛也无妨。
注：韶光：美好的时光，多指青春年华。
注：归与：回去吧；语出《论语·公冶长》“归与！归与！”。
注：呼牛：《庄子·天道》载老子言“子呼我牛也而谓之牛，呼我马也而谓之马”，比喻任人称呼、毁誉不计。

# 157｜意慕古，先存古，未敢反古；心持世
原：意慕古，先存古，未敢反古；心持世，外厌世，未能离世。|| 心意倾慕古人，先要保存古道，不敢违背古道；内心想扶持世道，外表却厌弃世俗，终究不能脱离世间。
注：存古：保存古人之道。
注：反古：违背古道。
注：持世：扶持世道。

# 158｜苦恼世上，度不尽许多痴迷汉，人对
原：苦恼世上，度不尽许多痴迷汉，人对之肠热，我对之心冷；嗜欲场中，唤不醒许多伶俐人，人对之心冷，我对之肠热。|| 在苦恼的人世上，度化不尽许多痴迷的人，别人对他们满怀热心，我对他们却心冷；在嗜好欲望的场中，唤不醒许多聪明伶俐的人，别人对他们心冷，我对他们却满怀热心。
注：度：佛教语，度化，使人脱离苦海。
注：肠热：热心，热肠。
注：嗜欲：嗜好与欲望。

# 159｜自古及今，山之胜多妙于天成，每坏
原：自古及今，山之胜多妙于天成，每坏于人造。|| 从古到今，山的胜景大多妙在天然生成，却常常毁坏在人工营造上。
注：胜：美景，胜境。
注：天成：天然生成。

# 160｜画家之妙，皆在运笔之先，运思之际
原：画家之妙，皆在运笔之先，运思之际；一经点染便减机神。|| 画家的妙处，都在下笔之前、构思之时；一经点缀渲染，便减损了灵机神韵。
注：运思：构思。
注：点染：作画时点缀景物、渲染色彩。
注：机神：灵机与神韵。

# 161｜长于笔者，文章即如言语；长于舌者
原：长于笔者，文章即如言语；长于舌者，言语即成文章。昔人谓“丹青乃无言之诗，诗句乃有言之画”；馀则欲丹青似诗，诗句无言，方许各臻妙境。|| 擅长写作的人，写文章就像说话一样自然；擅长言谈的人，说出的话就成了文章。¦前人说“画是不说话的诗，诗是会说话的画”；我却要让画像诗一样，诗句像画一样无需言说，才算各自达到了妙境。
注：长（cháng）于：擅长。
注：丹青：绘画用的颜料，借指绘画。
注：丹青乃无言之诗，诗句乃有言之画：宋人多有此类说法，如“诗是无形画，画是有形诗”。
注：馀：同“余”，我。
注：臻（zhēn）：达到。

# 162｜舞蝶游蜂，忙中之闲，闲中之忙；落
原：舞蝶游蜂，忙中之闲，闲中之忙；落花飞絮，景中之情，情中之景。|| 飞舞的蝴蝶、游荡的蜜蜂，是忙中有闲，闲中有忙；飘落的花瓣、飞扬的柳絮，是景中含情，情中有景。
注：飞絮：随风飘飞的柳絮。

# 163｜五夜鸡鸣，唤起窗前明月；一觉睡起
原：五夜鸡鸣，唤起窗前明月；一觉睡起，看破梦里当年。|| 五更鸡鸣，唤起了窗前的明月；一觉醒来，看破了梦里的往年旧事。
注：五夜：五更，天将亮时。
注：看破：看透，识破。

# 164｜想到非非想，茫然天际白云；明至无
原：想到非非想，茫然天际白云；明至无无明，浑矣台中明月。|| 想到非想非非想的境界，茫茫然如天边的白云；明白到无无明的地步，浑然如台中的明月。
注：非非想：佛教语，指“非想非非想处天”，为无色界最高一层天，其中既非有想，亦非无想。
注：无无明：语出《心经》“无无明，亦无无明尽”；无明，指愚痴迷惑。
注：台中明月：疑化用禅宗“心如明镜台”之意，比喻澄明的心性；一说指月台中的月。

# 165｜逃暑深林，南风逗树；脱帽露顶，沉
原：逃暑深林，南风逗树；脱帽露顶，沉李浮瓜；火宅炎宫，莲花忽迸；较之陶潜卧北窗下，自称羲皇上人，此乐过半矣。|| 躲避暑热进入深林，南风拂动树梢；脱下帽子露出头顶，把李子沉在凉水里、把瓜浮在清泉上；在如火宅炎宫般的酷热中，仿佛忽然迸开一朵莲花；比起陶潜卧在北窗下，自称是伏羲以前的人，这种快乐已超过他一半了。
注：逗：挑动，拂弄。
注：沉李浮瓜：语出曹丕《与朝歌令吴质书》“浮甘瓜于清泉，沉朱李于寒水”，指夏日消暑之乐。
注：火宅：佛教语，《法华经》以着火的房宅比喻充满苦恼的尘世，这里兼指暑热。
注：羲皇上人：伏羲以前的人，指生活闲适自在的人；陶潜《与子俨等疏》有“五六月中，北窗下卧，遇凉风暂至，自谓是羲皇上人”。

# 166｜霜飞空而漫雾，雁照月而猜弦。
原：霜飞空而漫雾，雁照月而猜弦。|| 寒霜飞满天空，像弥漫的雾气；大雁被月光照着，疑心那弯月是弓弦。
注：漫雾：弥漫如雾。
注：猜弦：猜疑弯月是弓弦而惊惧，暗用“惊弓之鸟”之意。

# 167｜既景华而凋彩，亦密照而疏明；若春
原：既景华而凋彩，亦密照而疏明；若春阳之扬花，似秋汉之含星。|| 既能使日光的华彩黯淡，又能细密地照耀、疏朗地明亮；好像春日阳光中扬起的飞花，又似秋夜银河里含着的星辰。
注：景华：日光的光华；景，日光。
注：凋彩：使色彩凋落、黯淡。
注：秋汉：秋夜的银河。
注：出处：本条与前后几条文辞骈俪，疑摘自六朝赋体文字，所咏之物原文未明，一说咏月。

# 168｜景澄则岩岫开镜，风生则芳树流芬。
原：景澄则岩岫开镜，风生则芳树流芬。|| 日光澄明时，山岩峰峦如同打开的明镜；清风吹起时，芬芳的树木流溢香气。
注：景澄：日光澄澈明亮。
注：岩岫（xiù）：山岩与峰峦；岫，山洞，也指山峰。
注：流芬：散发香气。

# 169｜类君子之有道，入暗室而不欺；同至
原：类君子之有道，入暗室而不欺；同至人之无迹，怀明义以应时。|| 好比有道的君子，进入暗室也不自欺；如同不留形迹的至人，怀抱光明的道义去顺应时势。
注：暗室不欺：在无人看见的暗处也不做亏心事，即儒家所说的慎独。
注：至人：道家所称道德修养最高的人；《庄子·逍遥游》有“至人无己”。
注：应时：顺应时势。

# 170｜一翻一覆兮如掌，一死一生兮如轮。
原：一翻一覆兮如掌，一死一生兮如轮。|| 一翻一覆就像翻转手掌一样容易，一死一生如同车轮一般循环不已。
注：如掌：像翻转手掌，形容变化容易而迅速；杜甫《贫交行》有“翻手作云覆手雨”。
注：如轮：像车轮旋转，循环不息；佛教也以车轮比喻生死轮回。
