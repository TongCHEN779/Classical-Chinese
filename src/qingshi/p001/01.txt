# 李妙惠
题解：《李妙惠》节存残文，记李氏题款于后、其夫登第而父母方知其未死的结局；属“情烈”类女子故事，原事前文已佚，仅余结尾。
原：款其后曰：“扬州卢某妻李氏题。”卢后会试登甲榜，捷音至扬州，父母乃知子存，然无及矣。
注：款其后曰：扬州卢某妻李氏题款于后，指在诗或画之后署名；“款”即题署。
注：会试：明清科举在京师举行的考试，中式者再殿试；此处沿用明制。
注：登甲榜：甲榜指进士科，明清称进士为甲榜，举人为乙榜。
注：捷音：科举得中的喜报。
# 申屠氏
题解：《申屠氏》记侯官申屠希光（据行文“希光”为女名）嫁董昌，昌遭豪强方六一陷害而死，希光诈许改嫁，刺杀六一满门并祭夫于墓前，自缢殉夫的烈女故事；为本书“情烈”类中的复仇殉节篇。
原：其父常奇此女，不妄许人。年二十，侯官有董昌，以秀才异等，为虔所识，逐以希光妻昌。希光临行，作留别诗曰：
注：侯官：县名，在今福建福州，明清为福州府治所在县之一。
注：秀才异等：秀才为才俊之士，“异等”指成绩特出；汉唐有秀才科，此处泛指才学出众者。
注：虔：虔州，今江西赣州，宋绍兴年间改名赣州，此用旧名。
注：逐以希光妻昌：“逐”疑当作“遂”，形近之误；“妻”读去声，作动词，把女儿嫁给。希光即申屠氏之字或名。
注：留别诗：临行留给亲友的告别诗，诗句此处未录。
原：入门，绝不复吟，食贫作苦晏如也。居久之，当靖康二年，郡中大豪方六一者，虎而冠者也。闻希光美，心悦而好之，乃使人阴诬昌重罪，罪至族。六一复阳为居间， 得轻比，独昌报杀，妻子幸无死。因使侍者通殷勤，强委禽焉。希光具知其谋，谬许之。密寄其孤于昌之友人。乃求利匕首，怀之以往，谓六一曰：“妾自分身首异处矣，赖君高谊，生死而骨肉之，妾之余，君之身也，敢不奉承君命。但亡人未归浅土，心窃伤之，唯君哀怜，既克葬，乃成礼。”六一大喜，立使人以礼葬之。于是希光伪为色喜，装入室。六一既至，即以吃首刺之帐中，六一立死。因复杀其侍者二人。至夜中，诈谓六一卒病委笃，以次呼其家人。家人皆愕，卒起不意，先后奔入，希光皆杀之，尽灭其宗。因斩六一头，置囊中，驰至董昌葬所，以其头祭之。明旦，悉召山下人告之曰：“吾以此下报董君，吾死不愧魂魄矣。”遂以衣带自缢而死。
注：食贫作苦晏如也：安于贫苦而泰然自若；“晏如”，安然貌，见陶渊明《五柳先生传》“箪瓢屡空，晏如也”。
注：靖康二年：公元1127年；靖康为宋钦宗年号，是年北宋亡于金。
注：大豪：地方上的豪强，势力大者。
注：虎而冠者也：戴着帽子的老虎，喻凶暴残忍而披人皮的人；《史记·酷吏传》有“冠而虎”之类说法。
注：阴诬：暗地里诬陷。
注：族：灭族，一人犯重罪而株连亲族。
注：阳为居间：表面上出面从中说情；“居间”，在两方之间调停。
注：得轻比：比附较轻的律条定罪，即从轻判处。
注：独昌报杀：只有董昌被判处死刑上报；“报”指奏请裁决。
注：委禽：古代婚礼纳采，用雁为聘礼，此指下聘求婚；见《左传·昭公元年》“委禽焉”。
注：谬许：假意答应。
注：孤：孤儿，此指其遗孤。
注：匕首：短剑，可藏袖中。
注：自分：自料，自己心里已断定。
注：身首异处：被杀头，喻死。
注：赖君高谊，生死而骨肉之：意谓靠您的高义，使死者生者都如亲人般得以安顿；“生死而骨肉”化用《左传·襄公二十二年》“生死而肉骨”之语，即救死者使复生，此处反用其意。
注：奉承：遵从、承受。
注：亡人：死者，此指亡夫董昌。
注：浅土：暂厝未能正式安葬的浅坟。
注：成礼：完成婚礼。
注：伪为色喜：假装面露喜色。
注：吃首：当作“匕首”，“吃”为形近致误。
注：帐中：床帐之中。
注：卒病委笃：突然病重垂危；“委笃”为危重、病危。
注：以次：依次，按先后顺序。
注：葬所：墓地。
注：山下人：此指葬所附近山下的乡民。
注：下报：到地下去向亡人回报。
注：衣带自缢：用衣带上吊。
# 从二姑
题解：《从二姑》仅存篇末评语，赞从二姑坚守同穴之盟、以身殉夫，把她比作春秋时殉君的荀息；属“情烈”类的短评残篇。
原：同穴之盟，不食其言，女中之荀息乎!
注：同穴之盟：死后合葬一穴的誓言；《诗经·王风·大车》“穀则异室，死则同穴”。
注：不食其言：不违背自己说过的话，即守信；“食言”见《尚书·汤誓》，意为失信。
注：荀息：春秋晋国大夫，受晋献公托孤于奚齐、卓子，二子被里克所杀，荀息以死践言，见《左传·僖公九年、十年》。
# 泖湖谢氏
题解：《泖湖谢氏》仅存“拔剑自刎”一句，记谢氏以死守节，余文已佚；属“情烈”类。
原：遂拔剑自刎死。
注：自刎：用剑刀割颈自杀。
# 王氏妇
题解：《王氏妇》记王氏妇被掳后题诗投崖保节而死，杨维桢为之题诗，后其夫得子的传闻，属“情烈”类；本节前文残佚。
原：写毕，遂投崖死。后杨廉夫感其事，题诗云：
注：投崖：从悬崖跳下自尽。
注：杨廉夫：杨维桢（1296—1370），字廉夫，号铁崖，元末明初诗人，会稽人，诗体奇崛，称“铁崖体”。
原：后复梦妇人来谢。未几，果得一子。
注：后复梦妇人来谢：梦见（死去的）妇人来致谢，旧时以此示贞烈得报。
# 徐君宝妻
题解：《徐君宝妻》仅存一句词，系宋末徐君宝妻（岳州人）被元军掳后所作《满庭芳》词的结句；其人后投水自尽，属“情烈”类。
原：从今后，梦魂千里，夜夜岳阳楼。
注：岳阳楼：在今湖南岳阳，西临洞庭湖；徐妻为岳州人，故以梦魂夜夜归岳阳楼寄思乡故国之情。
注：梦魂千里：梦中魂魄飞越千里；宋词常语。
# 海昌董氏
题解：《海昌董氏》记董氏守节抚孤，儿子后来成立，官府旌表其门为“慈节”之事；属“情烈”类中的守节篇，前文残缺。
原：又云：
注：又云：承接前面所引诗文，续引另一首。
原：后鉴果能树立。当道为表其闾曰“慈节”云。
注：后鉴果能树立：后来其子“鉴”果然能自立成名；“树立”指立身成事。
注：当道：当权者，指地方官。
注：表其闾：旌表其家门；古时对孝子节妇，官府在里门立牌坊或悬匾表彰，称“表闾”。
注：慈节：旌表匾额之名，表彰母亲既慈且节。
# 章纶母
题解：《章纶母》只存一句，记章纶后来官至礼部侍郎；章纶（1413—1483）为明正统年间进士，以直谏著名，其母守节抚孤之事前文已佚。
原：后纶官至礼侍。
注：礼侍：礼部侍郎的省称，礼部副长官，正三品。

原：其二：
注：其二：关盼盼《燕子楼》三首之第二首，原诗句此处未录。
原：其三：
注：其三：关盼盼《燕子楼》三首之第三首。
原：白乐天爱其诗，和之云：
注：白乐天：白居易（772—846），字乐天，号香山居士，中唐大诗人；其《燕子楼三首》诗序记关盼盼事。
注：和之：依原诗之意或韵作答。
原：又赠绝句讽之：
注：绝句讽之：白居易另赠绝句，讥其未能随主人殉死，相传盼盼读后绝食；此处诗句未录。

# 沈真真
题解：《沈真真》记沈真真被柳某赠给郑某为妾，期约赴京，郑途中病故，真真闻讯守节终身之事；属“情烈”类。
原：柳大喜，俾真真拜谢。郑至京，除国子博士。柳见除目，即送真真赴约。及嘉祥驿，闻还古物故而还。柳嗟叹，遂使别居。真真守节终身。
注：柳大喜，俾真真拜谢：柳氏很高兴，让真真叩拜致谢；“俾”，使。
注：国子博士：国子监教官，唐宋为从五品上，掌教授太学生。
注：除目：任命官员的文书、名册；“除”为授官。
注：嘉祥驿：驿站名，嘉祥县在今山东济宁一带；驿为古代传递文书、供官员歇宿之所。
注：还古：疑为人名，即郑某之字或号，待考。
注：物故：死亡的婉称，汉以来常语。
注：别居：另外安排居处。
注：守节：妇女丈夫死后不再嫁；此处真真未成婚而守，亦称守节。
# 齐锦云
题解：《齐锦云》记妓女齐锦云与某人分别后蓬首垢面、闭门读佛经而病死，众人称其义；属“情烈”类的短篇。
原：锦云既别，蓬首垢面，闭门不出，日读佛书，未几病殁。人咸义之。
注：蓬首垢面：头发散乱如蓬草，脸面污垢不修饰；常形容忧伤不理容。
注：未几：不久。
注：义之：认为她有义，以她为义。
# 朱葵
题解：《朱葵》记杭州妓朱葵与郑翰卿相恋成婚，后被恶少强夺，官府断归郑家，十年后生三子的故事，连带载有判词与评语；属“情烈”类中妓女从良守义的名篇。
原：居月余，葵缱绻不舍。郑乃出犀簪为赠。葵见之曰：“此吾母梦征也，或者其天乎。”郑乃出重赀聘之。葵既嫁，遂屏去艳饰，亲作劳工女红，与郑居吴山之麓。且半载，值月妓周丽卿者，以宅事被逮。周恐，匿不出。翰卿与杭守令皆雅交，乃以二绝为之从臾，卒得脱。诗云：
注：缱绻：情意深厚、难舍难分。
注：犀簪：犀角做的簪子；传其母曾梦犀簪，与此相应，故葵以为天缘。
注：聘：聘娶，用财礼娶亲。
注：女红：女子的针线纺织之事；“红”读 gōng，同“工”。
注：月妓：当时以月为期受聘的歌妓；“月妓”或指订期租赁的妓女，待考。
注：周丽卿：妓女名，余事无考。
注：以宅事被逮：因房屋之事被官府拘捕。
注：守令：地方长官，指杭州府及县的官员。
注：从臾：怂恿、劝说；亦写作“从容”“怂恿”，此处指从中劝说。
注：诗云：此引诗句，本文已略。
原：及翰卿携家入苕溪，俞之假父素无赖，窥郑逆旅，乃募恶少数十人邀诸途，夺姬归，闭之幽室中。葵断发矢曰：“吾宁有死，不受辱。”人卒不敢犯之。翰卿鸣之当道，檄下二令君杂治之。令曰：“曩君为他人居间，乃有打鸭惊鸳鸯语，不意遂成奇谶。”因捕治诸恶少，置之法，而断还归郑。遂断词云：“俞氏，良妇也。丽籍期年，愿得好逑而偕老。郑卿，才士也。硕赀三斛，将携淑女以于归。何期枭獍之无良，几致凤鸾之失偶。相如涤器临邛，令甚耻之；襄王行云巫峡，梦不虚也。凌霄琰气，幸逢合浦之珠；向日葵心，堪并章台之柳。鸳鸯谐波面之欢，行看比翼；鬼蜮潜水中之影，敢复含沙。任将一片云帆，携作八闽春色。苏长公原自风流，祇借数言为三尺；韩夫子岂长贫贱，用联双璧以百年。”后十年，葵生三子，皆韶秀。徐曲公寄之诗云：
注：苕溪：水名，在浙江湖州，上游有东、西苕溪，此处指代湖州。
注：假父：继父。
注：无赖：品行不端的人。
注：逆旅：旅店。
注：恶少：地痞流氓、年轻无赖。
注：邀诸途：在路上拦截。
注：当道：当权的官员，指有司。
注：二令君：指杭州钱塘、仁和两县令；古称县令为“令君”。
注：檄：官府文书；“檄下”指发下公文交办。
注：杂治：会同审理。
注：曩君：从前您；“曩”，往昔。
注：打鸭惊鸳鸯：俗语，打一物而惊动另一物；此处指前次替周丽卿说情时曾戏用此语，事后竟成应验的“谶”。
注：奇谶：奇特的预兆，不料语成预言。
注：置之法：依法处置。
注：断词：判词，官府结案之词，用骈体。
注：俞氏：朱葵本姓俞，其后被俞氏假父所逼；“俞氏”即朱葵。
注：丽籍：妓籍，教坊乐籍。
注：好逑：好配偶；《诗经·周南·关雎》“君子好逑”。
注：郑卿：即郑翰卿。
注：硕赀三斛：形容聘财极多；“斛”为容量单位，宋以前十斗为一斛。
注：淑女以于归：《诗经·周南·桃夭》“之子于归”，指女子出嫁。
注：枭獍：枭为恶鸟，传说食母；獍为恶兽，传说食父；合指忘恩负义的凶徒。
注：凤鸾之失偶：凤凰、鸾鸟失去配偶，喻夫妇被拆散。
注：相如涤器临邛：司马相如与卓文君私奔后在临邛开酒肆，相如亲涤酒器，见《史记·司马相如列传》；“令”指临邛令，此处借以说明官吏所耻之事。
注：襄王行云巫峡：宋玉《高唐赋》载楚襄王梦与巫山神女相会，神女自云“旦为朝云，暮为行雨”，此借梦中遇合喻成婚不虚。
注：凌霄琰气：“琰”疑指美玉之气，“凌霄”喻高洁；此句意为珍宝之气，幸遇合浦之珠，待考。
注：合浦之珠：合浦（今广西合浦）产珍珠，汉孟尝任合浦太守，珠还故浦，后喻失而复得的珍宝。
注：向日葵心：双关朱葵之名，葵花向日，喻忠心；“堪并章台之柳”则用唐韩翃与柳氏故事，见孟棨《本事诗》。
注：章台之柳：唐韩翃的妾柳氏居长安章台，韩作词“章台柳，章台柳”寄之，后柳氏被藩将夺走，赖许俊救回，此喻郑朱事类。
注：鸳鸯谐波面之欢：鸳鸯成对戏于水面，喻夫妇和谐。
注：比翼：比翼鸟，喻夫妻恩爱。
注：鬼蜮：传说中水中害人之物，含沙射影；“鬼蜮潜水中之影，敢复含沙”指奸人不敢再暗中伤人。
注：一片云帆：一片风帆，指乘船南返。
注：八闽：福建旧分八府，称“八闽”，郑翰卿为福建人，故“携作八闽春色”。
注：苏长公：苏轼，在家兄弟中为长，称“长公”；苏轼任杭州太守时曾判妓从良案，传有“从良”判词。
注：三尺：古代刑律写在三尺长的竹简上，后称法律为“三尺”。
注：韩夫子岂长贫贱：与上句“苏长公”对举，借用韩姓人物（疑指韩愈或韩琦）喻郑卿不会长久贫贱，指代待考。
注：双璧：一对美玉，喻郑朱二人才貌相当的佳偶。
注：韶秀：美好秀丽。
注：徐曲公：待考。
原：蓼庵高太史曰：“朱少姬义不辱，卒归郑生。身名俱完，即烈丈夫奚让焉!令君翩翩，有‘斐哉其文’之辞也。”
注：蓼庵高太史：当为明人高某，号蓼庵，官翰林，故称“太史”；待考。
注：义不辱：以义自守而不受辱。
注：斐哉其文：《论语·公冶长》“斐然成章”之意，此处指判词文采斐然，“斐哉”赞叹其文彩华美。
注：翩翩：风采文雅貌；评县令风流倜傥。
原：补遗
注：补遗：编者在正编之后补入的条目，此页之后收入的类目多为遗漏之事。
# 鲁陶婴妻
题解：《鲁陶婴妻》仅存出处提示“出《列女传》”，指鲁国陶婴寡居不嫁、作《黄鹄歌》自誓的故事，见刘向《列女传·贞顺传》。
原：出《列女传》。
注：出《列女传》：说明条目取自西汉刘向所撰《列女传》，所记鲁寡妇陶婴作歌拒婚，今本《列女传》作“鲁寡陶婴”。
