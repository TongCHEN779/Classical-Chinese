# 昭君
题解：汉元帝宫人王昭君请行和亲，终老匈奴，墓称青冢。本条叙昭君入宫、出塞、怨诗与结局，并引评语称其以青冢千古留名，属“情憾类”，写才色被埋没的遗恨。
原：昭君字嫱，南郡人。元帝时，以良家子选入掖庭。或云昭君者，齐国王穰女。年十七，仪容绝丽，以节闻。国中长者求之，王皆不许，乃献元帝。时宫人既多，帝造次不能别房帷。乃令画工图之，披图召幸。他人往往行赂，多得进。昭君自恃其貌，志不苟求，工遂毁为其状。会匈奴单于来朝，求美人为阏氏，帝敕以宫女赐焉。
注：昭君字嫱：《后汉书·南匈奴传》作王昭君，名嫱，字昭君，南郡秭归人。
注：南郡：郡名，治今湖北荆州，辖秭归。
注：掖庭：宫中妃嫔所居，亦指宫女。
注：良家子：清白人家的女儿。
注：齐国王穰女：《西京杂记》等异说，待考。
注：造次：仓促。
注：画工：宫廷画师，《西京杂记》载毛延寿、陈敞等人。
注：披图召幸：依画像召见妃嫔。
注：行赂：行贿。
注：匈奴单于：指呼韩邪单于，竟宁元年（前33）来朝求婚。
注：阏氏：匈奴单于之妻。
原：昭君入宫数载，未得见御，积悲怨，乃请掖庭令求行。单于临辞，大会，帝召女以示之。昭君丰容靓饰，光明汉宫，顾影徘徊，竦动左右。帝见大惊，意欲留之，而重失信于异域，遂与匈奴。昭君戎服乘马，提一琵琶，出塞而去。为会（书）报帝云：
注：掖庭令：管理后宫的官员。
注：丰容靓饰：容貌丰润，打扮华丽。
注：竦动：震动，惊动。
注：重失信于异域：看重与匈奴的信约，不愿失信。
注：戎服：胡人服饰。
注：琵琶：汉时指弦乐器，晋傅玄称昭君出塞作琵琶以慰其思。
注：会（书）：原文括号注“书”，当作“书”，指奏书。
原：“臣妾幸得备禁脔，谓身依日月，死有余芳。而失意丹青，远窜异域，诚得捐躯报主，何敢自怜。
注：禁脔：同上，此指备选嫔妃。
注：日月：喻帝王。
注：死有余芳：死后留名。
注：丹青：绘画，此指画工所绘之像。
注：窜：远走，流放。
原：独惜国家黜陟，移于贱工。南望汉关，徒增怆结耳。有父有弟，惟陛下幸少怜之。”

注：汉关：汉朝的关塞。
注：怆结：悲伤郁结。

注：毛延寿：汉元帝时画工，《西京杂记》载其以受贿丑化宫人而被杀。
注：怨诗：旧传昭君《怨词》，见《琴操》，真伪待考。
原：“秋木萋萋，其叶萎黄。有鸟处山，集于苞桑。养育毛羽，形容生光。既得升云，上游曲房。离

注：苞桑：丛生的桑树。
注：升云：喻入宫。
注：曲房：深邃内室。

注：宫绝旷：上接“离”，指幽居宫中，远离故乡。

注：委食：把食物弃置不顾，指受供养而无所事。

注：西羌：西方的少数民族。
注：峨峨：高大貌。
注：泱泱：水深广貌。
注：恻伤：悲伤。
原：昭君请掖庭令求行，非轻去其乡也。惜其名之不传，与面目之不经见于天下也。王荆公曰：“自是如花画不成，当时枉杀毛延寿。”长卿氏曰：“方昭君之行，‘丰容靓饰，光动左右’，此即昭君图也。‘戎服乘马，提一琵琶出塞而去’，此又即昭君图也。延寿岂能图昭君哉！”余谓延寿即能图昭君，使得进御，不过玉簟筐床，一番恩宠而已。岂若青冢黄昏，令骚客情人凭吊于无穷也！昭君有子曰世违。单于死，世违继立。胡法，父死则妻其母。昭君问世违曰：“汝为汉为胡？”世违愿为胡。昭君乃吞药自杀。胡地草皆黄，惟昭君墓草独青。然则昭君又单于之贞妇矣。贞于汉不得，而贞于胡，究终心未尝忘汉。既死，而以青冢自旌。乃谤者曰：“汉恩自浅胡自深，”岂不冤哉！
注：请掖庭令求行：自己请求出塞。
注：王荆公：王安石，其《明妃曲》有“意态由来画不成，当时枉杀毛延寿”，原文引作“自是如花画不成”，与通行本异。
注：长卿氏：评论者，待考。
注：玉簟筐床：玉席与方床，指宫中恩宠生活。
注：青冢：昭君墓，在今内蒙古呼和浩特南，相传塞外草白独此冢青。
注：骚客：诗人。
注：世违：昭君之子，史载伊屠智牙师，此名异，待考。
注：胡法：匈奴父死妻其后母的习俗，即“收继婚”。
注：吞药自杀：见《琴操》说，正史无载。
注：自旌：自我表彰。
注：汉恩自浅胡自深：王安石《明妃曲》二首其一，原句为“汉恩自浅胡自深，人生乐在相知心”。
# 卫子夫
题解：卫子夫因善歌得幸于汉武帝，又因请出而被立为皇后，评语以之与昭君请行比较，叹昭君命薄。属“情憾类”。
原：汉武帝幸平阳公主家，置酒作乐。卫子夫为讴者，善歌，能造曲。每歌挑上，上喜动，起更衣，子夫因侍尚女轩中，遂得幸。帝见其美发，悦之，纳于宫中。时宫女数千，皆以次幸。子夫新入，在籍末，岁余不得见。上择宫人不中用者出之，子夫因涕泣请出。上曰：“吾夜梦子夫中庭生梓树数株，岂非天意乎。”是夕幸之，竟立为后。生戾太子。子夫之请出，与昭君之求行一也。而徒以美发，遂得正位中宫，昭君于是乎命薄矣。
注：汉武帝：刘彻。
注：平阳公主：武帝之姊，卫子夫原为其家歌女。
注：讴者：歌唱者。
注：更衣：上厕所的委婉语，也指换衣。
注：尚女轩：《史记·外戚世家》作“尚衣轩”，当作“尚衣轩”，更衣的小室。
注：中庭生梓树：武帝梦见中庭长出梓树的故事，待考，《史记》无此梦。
注：戾太子：卫子夫之子刘据，后因巫蛊事自杀。
注：正位中宫：被立为皇后。

# 杜牧
题解：唐代杜牧在湖州看中一少女，与其母约十年后来娶，十四年后才得守湖州，女已嫁人生子，只得作诗自伤。属“情憾类”，写错过的遗憾。
原：太和末，杜牧复自侍御史出佐江西宣州幕。虽所至辄游，而终无属意。及闻湖州名郡，风物妍好，且多奇色，因甘心游之。
注：太和末：太和为唐文宗年号（827—835）。
注：侍御史：御史台属官。
注：宣州幕：宣歙观察使沈传师幕府。宣州，今安徽宣城。
注：风物：风光景物。
原：湖州刺史某乙，牧素所厚者，颇喻其意。及牧至，每为之曲宴周游，凡优姬娼女，力所能致者，悉为出之。牧注目凝视曰：“美矣，未尽善也。”乙复候其意。牧曰：“愿得张水嬉，使州人毕观。候四面云合，某当闲行寓目。冀于此际，或有阅焉。”乙如其言。至旦，两岸观者如堵。迨暮，竟无所得。将罢，舟舣岸。于丛人中，有里姥引鸦头女，年十余岁，牧熟视曰：“此真国色！向诚虚设耳。”因使语其母，将接致舟中。姥女皆惧。牧曰：“且不即纳，当为后期。”姥曰：“他年失信，复当如何？”牧曰：“吾不十年，必守此郡。十年不来，乃从尔所适可也。”母许诺。因以重币结之，为盟而别。故牧归朝，颇以湖州为念。然以官秩尚卑，殊未敢发。寻拜黄州、池州，又移睦州，皆非意也。牧素与周墀善。会墀为相，乃并以三笺于墀，乞守湖州。大中三年，始授湖州刺史。比至郡，则已十四年矣。所约者已从人三载，而生三子。牧既即政，亟使召之。其母惧其见夺，携幼以同往。牧诘其母曰：“曩既许我矣，何为反之？”母曰：“向约十年，十年不来而后嫁，嫁已三年矣。”牧因取其载词视之，俯首移晷，曰：“其词也直，强之不详。”乃厚为礼而遣之。因赋诗以自伤，曰：

注：曲宴周游：特地设宴陪游。
注：优姬娼女：歌舞女和妓女。
注：水嬉：水上游戏，如龙舟竞渡。
注：云合：众人如云聚集。

注：舣岸：船靠岸。

# 建康龙生
题解：明初建康龙生与表姐在姑母家凤尾草下盟誓，因家人阻挠，表姐忧愤自缢；龙生后得高官，凤尾枯死，女转世为男。属“情憾类”，以凤尾草象征未成的誓约。
原：洪武中，有龙生者，本建康人。远祖仕宋，为京官，从隆祐孟太后南迁，留家江右。子孙蕃衍，世守诗书。生行第八，早慧，六岁能诵诗，九岁晓属对，作五七言绝句，诗皆可观。生有姑适祖氏者，特爱生，生往来姑家甚熟。祖有异母兄弟，同居各爨。兄殁，惟嫂陈氏，及二子三女存。长女次女皆适人，惟幼女在室，绝有姿容，长生三岁。生虽少年，颖敏而驯谨，不好弄，且善伺人意。故祖氏一家，闻生来，莫不欢喜。女亦视生如弟兄，不复回避。女母闻生姑称生聪敏好学，深欲婿生。女亦眷眷属目。

题解：林仲子与京师妓女杨闷儿相恋，约定娶归，却因畏父犹豫；闷儿病死，仲子赶到时她仍一息呼唤，二人终未成眷属。属“情憾类”，文末以桃花、棘刺同种于坟，写其薄命。

题解：安史之乱中，杨贵妃缢死于马嵬驿，玄宗此后追思不已，罗袜、香囊、《雨霖铃》和梦中相见，皆写其念旧。属“情憾类”，为本类中人物最著名的一篇。
原：禄山之乱，以诛国忠为名。上欲使皇太子监国，而自亲征。国忠惧，泣诉妃。妃衔土请命，乃止。十五载，六月潼关失守，上幸蜀。至马嵬驿，兵乱，杀国忠，围未解。上出问其故，高力士以贵妃为言。驿有小巷，上不忍回行宫，于巷中倚杖欹首而立。京兆司韦锷谏曰：“愿陛下割恩，以宁国家。"上逡巡入行宫，使力士赐妃死。妃泣涕呜咽，语不胜情。乃曰：“大家好住，妾诚负国，死不恨矣。乞容礼佛。"帝曰：“愿妃子善地受生。"力士遂缢之于佛堂前之梨树下。才绝，而南海进荔枝至。上观之，长号数四，使力士祭之。祭罢，以绣衾覆体，置于驿亭中。六军乃解围。瘗于西郭之外一里许道北坎下。妃时年三十八。上持荔枝于马上谓张野狐曰：“此去剑门，鸟啼花落，水绿山青，无非助朕悲悼妃子之情耳。"上至斜谷口，属霖雨涉旬。于栈道雨中，闻铃声隔山相应，因采其声为《雨霖铃》曲，以寄恨焉。

# 孙楚
题解：西晋孙楚丧妻作文悼念，王济读之，感叹文情相生，伉俪之情更重。属“情憾类”，写文因情而生。
原：孙楚妻亡，为文悼之。武子见其文曰：“未知文生于情，情生于文，见此使人增伉俪之重。"
注：孙楚：字子荆，西晋文学家。
注：武子：王济，字武子，晋名士，孙楚友人。
注：伉俪：夫妻。
注：文生于情，情生于文：《世说新语·伤逝》载王济语，原文稍异。
# 元微之
题解：元稹的元配韦氏早逝，元稹作诗悼之，名句“曾经沧海难为水”也出此处。后娶裴氏。评语讥元稹负崔莺莺而得此报。属“情憾类”。

注：元微之：元稹，字微之，唐诗人。
注：元配：嫡妻。
注：韦氏：韦丛，太子少保韦夏卿之女，字蕙丛，元稹有《遣悲怀》三首。
注：才思：诗才。
原：“谢家最小偏怜女，嫁与黔娄百事乖。顾我无衣搜荩箧，泥他沽酒拔金钗。野蔬充

注：营奠复营斋：为亡妻设祭、请僧诵经。

原：“曾经沧海难为水，除却巫山不是云。"

注：河东裴氏：元稹续娶裴淑，河东人。
注：柔之：裴淑字。
原：微之负崔莺，宜得此报！
注：崔莺：元稹所作传奇《莺莺传》中的崔莺莺，一般认为含有作者自身经历。

# 徐文长
题解：明代徐渭因猜忌杀妻，后悟其为僧报应，作《述梦诗》悼念，自此不再娶。属“情憾类”，写自己造成的遗憾。
原：山阴徐渭，字文长，高才不售。胡少保宗宪总督浙西，聘为记室，宠异特甚。渭常出游，杭州某寺僧徒不礼焉，衔之。夜宿妓家，窃其睡鞋一只，袖之入幕，诡言于少保，得之某寺僧房。少保怒不复详，执其寺僧二三辈，斩之辕门。
注：徐渭：字文长，号青藤，山阴人，明代书画家、文学家。
注：不售：科举不中。
注：胡少保宗宪：胡宗宪，嘉靖时任浙直总督，加太子太保，此作“少保”。
注：记室：掌书记的幕僚。
注：衔之：怀恨。
注：睡鞋：女子睡眠时穿的小鞋。
注：辕门：军营之门。
原：渭为人猜而妒。妻死后再娶，辄以嫌弃。续又娶小妇，有殊色。一日，渭方自外归，忽户内欢笑作声，隔窗斜视，见一俊僧，年可二十余，拥其妇于膝，相抱而坐。渭怒，往取刀杖，趋至欲击之，已不见矣。问妇，妇不知也。后旬日，复自外归，见前少年僧与妇并枕昼卧于床。渭不胜愤怒，声如吼虎，便取灯檠刺之，中妇顶门而死，遂坐法系狱。后有援者获免。一日闲居，忽悟僧报。伤其妇死非罪，赋《述梦诗》二章云：
注：猜而妒：猜疑嫉妒。
注：殊色：特别美的姿色。
注：灯檠：灯台。
注：顶门：头顶。
注：坐法系狱：因犯法被关进监狱。
注：僧报：僧人转生来报复。
注：《述梦诗》：徐渭所作诗。
原：“伯劳打始开，燕子留不住。今夕梦中来，何似当初不飞去。怜羁雌，嗤恶侣。两
注：伯劳：鸟名，古乐府“东飞伯劳西飞燕”，喻分离。
注：羁雌：失侣的孤鸟。
注：嗤：讥笑。
注：恶侣：不好的伴侣。
原：意茫茫坠晚烟，门外鸟啼泪如雨。”
注：茫茫：模糊不清。
原：“跣而濯，宛如昨，罗鞋四钩闲不着。棠梨花下踏黄泥，行踪不到栖鸳阁。"
注：跣而濯：赤脚洗足。
注：罗鞋四钩：罗制的小脚鞋。
注：棠梨：落叶乔木。
注：栖鸳阁：鸳鸯所栖之阁，指闺阁。
原：自是绝不复娶。
注：不复娶：不再续娶。

# 杨幽妍
题解：吴中名妓杨幽妍与张圣清相爱，因鸨母阻隔病重，纳聘后不久即殁，圣清亦哀恸而死；篇末以“为情死”作评，是明末苏南文人狎妓故事的代表。

# 李仲文女
题解：晋时李仲文之女死后借梦与太守之子张子长结为夫妇，因被发冢而不得复生；故事出《法苑珠林》，系六朝志怪中“死而复生”的变格。
原：晋时武都太守李仲文，在郡丧女，年十八，权假葬郡城北。有张世之代为郡。世之男字子长，年二十，侍从在廨中。梦一女，年可十七八，颜色不常，自言“前府尹子，不幸早亡，会今当更生。心相爱乐，故来相就"。如此五六夕，忽然昼见，衣服熏香殊绝。遂为夫妇，寝息。衣皆有袴，如处女。后仲文遣婢视女墓，因过世之妇相问，入廨中，见此女一只履在子长床下。取之，啼泣呼言发冢。归以示，仲文惊愕。遣问世之：“君儿何由得亡女履耶？"世之呼问儿，具陈本末。李、张并谓可怪。发棺视之，女体已生肉，颜姿如故，惟右脚有履。子长梦女曰：“我本得生。今为所发，自尔之后遂死，肉烂不得生矣。万恨之心，当复何言。"泣涕而别。出《法苑珠林》。
注：武都：郡名，今甘肃成县一带。
注：权假葬：暂时借地安葬。
注：廨：官署。
注：前府尹：前任长官，此指李仲文。
注：袴：裤。
注：发冢：掘墓。
注：法苑珠林：唐释道世所编佛教类书，所载此事出《搜神后记》。
原：女之精诚，且能示形于所欢，而不能通梦于父母，自取发掘何耶！
注：通梦：托梦。
# 谈生
题解：谈生遇鬼妇结为夫妻，因违约举火相照而分别，妇留袍使谈生致富，睢阳王认出此袍遂招其为婿；篇末情史氏评“缺憾世界”，总括“情憾类”。
原：谈生者，年四十无妇，常感奋读书经。夜半，有女子，年可十五六，姿颜服饰天下无双，来就生为夫妇。自言：“我与人不同，勿以火照我也。三年之后方可照。"为夫妻，生一儿，已二岁。不能忍，夜伺其寝后，盗照视之。其腰以上，生肉如人，腰下但有枯骨。妇觉。遂言曰：“君负我！我垂生矣，何不能忍一岁，而竟相照也。"生辞谢，涕泣不可复止。云：“与君虽大义永离，然顾念我儿。若贫不自偕活者，暂随我去，当遗君物。"生随之去，入华堂室宇，器物不凡。以一殊袍与之曰：“可以自给。"裂取生衣裾留之而去。后生持袍诣市，睢阳王家买之，得钱千万。王识之曰："是我女袍，此必发墓。"乃取拷之，生具以实对。王犹不信，乃视女冢，冢完如故。发视之，果棺盖下得衣裾。呼其儿，正类王女。王乃信之，即礼谈生以为王婿，表其儿为侍中。
注：读书经：读书和经典。
注：睢阳王：睢阳（今河南商丘）之王，待考。
注：发墓：盗墓。
注：裾：衣襟。
注：侍中：官名，皇帝近臣。
注：表其儿：上表荐举其子。
原：情史氏曰：缺陷世界，可憾实繁，况男女私愿，彼亦有不可告语者矣。即令古押衙、许虞候精灵不泯，化为氤氲大使，亦安能嘿嘿而阴洽之乎！赋情弥深，蓄憾弥广，固其宜也。从来佳人才子，难于凑合。朱淑写恨于断肠，非烟溢情于锦袋。有心者怜之，幸而遇矣，而或东舍徒窥，西厢未践，交眉送恨，赓句联愁，一刻关心，九泉衔怨，与其不谐，不如不遇耳！又，幸而谐矣，而或墙蔓偶牵，原非连理，清风明月，怅然各天，絮语娇欢，终身五内，则又不如不谐者，镜花水月，犹属幻想之依稀也。又，幸而花植幽房，剑归烈士，两情相喻，永好勿谖，而或芝草先枯，彩云易散，红颜顿萎，白首何堪，剩粉遗琴，徒增浩叹，则又似不若飞鸟天边，任尔去来无定处；春风别院，不知摇落几枝花。痛痒纵非隔肤，犹不至摧肝触肺耳！嗟，嗟！无情者既比于土木，有情者又多其伤感，空门谓人生为苦趣，诚然乎，诚然乎！
