# 杜笃
原：杜笃字季雅，京兆杜陵人也。高祖延年，宣帝时为御史大夫。笃少博学，不修小节，不为乡人所礼。居美阳，与美阳令遊，数从请託，不谐，颇相恨。令怒，收笃送京师。会大司马吴汉薨，光武诏诸儒诔之，笃於狱中为诔，辞最高，美帝之，赐帛免刑。
原：笃以关中表裏山河，先帝旧京，不宜改营洛邑，乃上奏《论都赋》曰：
原：皇帝以建武十八年二月甲辰，昇舆洛邑，巡於西岳。推天时，顺斗极，排阊阖，入函谷，观厄於崤、黾，图险於陇、蜀。其三月丁酉，行至长安。经营宫室，伤愍旧京，即诏京兆，乃命扶风，斋肃致敬，告觐园陵。凄然有怀祖之思，喟乎以思诸夏之隆。遂天旋雲遊，造舟於渭，北𣃚泾流。千乘方毂，万骑骈罗，衍陈於岐、梁，东横乎大河。瘗後土，礼B723郊。其岁四月，反於洛都。明年，有诏復函谷关，作大驾宫、六王邸、高车厩於长安。修理东都城门，桥泾、渭，往往缮离观。东临霸、浐，西望昆明，北登长平，规龙首，抚未央，覛平乐，仪建章。
原：是时山东翕然狐疑，意圣朝之西都，惧关门之反拒也。 客有为笃言：“彼C279井之潢污，固不容夫呑舟；且洛邑之渟瀯，曷足以居乎万乘哉？咸阳守国利器，不可久虚，以示奸萌。”笃未甚然其言也，故因为述大汉之崇，世据雍州之利，而今国家未暇之故，以喩客意。曰：
原：笃後仕郡文学掾。以目疾，二十餘年不窥京师。
原：笃之外高祖破羌将军辛武贤，以武略称。笃常叹曰：“杜氏文明善政，而笃不任为吏；辛氏秉义经武，而笃又怯於事。外内五世，至笃衰矣！”
原：女弟適扶风马氏。建初三年，车骑将军马防撃西羌，请笃为从事中郎，战没於射姑山。
原：所著赋、诔、吊、书、赞、《七言》、《女诫》及杂文，凡十八篇。又著《明世论》十五篇。
原：子硕，豪侠，以货殖闻。

# 王隆
原：王隆字文山，冯翊雲阳人也。王莽时，以父任为郎，後避难河西，为窦融左护军。建武中，为新汲令。能文章，所著诗、赋、铭、书凡二十六篇。初，王莽末，沛国史岑子孝亦以文章显，莽以为谒者，著颂、诔、《復神》、《说疾》凡四篇。

# 夏恭
原：夏恭字敬公，梁国蒙人也。习《韩诗》、《孟氏易》，讲授门徒常千餘人。王莽末，盗贼从横，攻没郡县。恭以恩信为众所附，拥兵固守，独安全。光武即位，嘉其忠果，召拜郎中，再迁太山都尉。和集百姓，甚得其欢心。
原：恭善为文，著赋、颂、诗、《励学》凡二十篇。年四十九卒官，诸儒共谥曰宣明君。
原：子牙，少习家业，著赋、颂、赞、诔凡四十篇。举孝廉，早卒，乡人号曰文德先生。

# 傅毅
原：傅毅字武仲，扶风茂陵人也。少傅学。永平中，於平陵习章句，因作《迪志诗》曰：
原：毅以显宗求贤不笃，士多隐处，故作《七激》以为讽。
原：建初中，肃宗博召文学之士，以毅为兰臺令史，拜郎中，与班固、贾逵共典校书。毅追美李明皇帝功德最盛，而庙颂未立，乃依《清庙》作《显宗颂》十篇奏之，由是文雅显於朝廷。
原：车骑将军马防，外戚尊重，请毅为军司马，待以师友之礼。及马氏败，免官归。
原：永元元年，车骑将军窦宪，復请毅为主记室，崔骃为主簿。及宪迁大将军，復以毅为司马，班固为中护军。宪府文章之盛，冠於当世。
原：毅早卒，著诗、赋、诔、颂、祝文、《七激》、连珠凡二十八篇。

# 黄香
原：黄香字文强，江夏安陆人也。年九岁，失母，思慕憔悴，殆不免丧，乡人称其至孝。年十二，大守刘护闻而召之，署门下孝子，甚见爱敬。香家贫，内无僕妾，躬执苦勤，尽心奉养。遂博学经典，究精道術，能文章，京师号曰“天下无双江夏黄童”。
原：初除郎中，元和元年，肃宗诏香诣东观，读所未尝见书。香後告休，及归京师，时千乘王冠，帝会中山邸，乃诏香殿下，顾谓诸王曰：“此‘天下无双江夏黄童’者也。”左右莫不改观。後召诣安福殿言政事，拜尚书郎，数陈得失，赏赉增加。常独止宿臺上，昼夜不离省闼，帝闻善之。
原：永元四年，拜左丞。功满当迁，和帝留，增秩。六年，累迁尚书令。後以为东郡太守，香上疏让曰：“臣江淮孤贱，愚F8D5小生，经学行能，无可算录。遭值太平，先人餘福，得以弱冠特蒙徴用，连阶累任，遂极臺阁。讫无纖介称，报恩效死，诚不意悟。卒被非望，显拜近郡，尊位千里。臣闻量能授官，则职无废事；因劳施爵，则贤愚得宜。臣香小醜，少为诸生，典郡从政，固非所堪。诚恐F8D5顿，孤忝圣恩。又惟机密端首，至为尊要，復非臣香所当久奉。承诏惊惶，不知所裁。臣香年在方刚，適可驱使。願乞餘恩，留备冗官，赐以督责小职，任之宫臺烦事，以毕臣香蝼蚁小志，诚瞑目至願，土灰极荣。”帝亦惜香干用，久习旧事，復留为尚书令，增秩二千石，赐钱三十万。是後遂管枢机，甚见亲重，而香亦ECF3勤物务，忧公如家。
原：十二年，东平清河奏訞言卿仲辽等，所连及且千人。香料别据奏，全活甚众。毎郡国疑罪，辄务求轻科，爱惜人命，毎存忧济。又晓习边事，均量军政，皆得事宜。帝知其精勤，数加恩赏。疾病存问，赐医药。在位多所薦达，宠遇甚盛，议者讥其过幸。
原：延平元年，迁魏郡太守。郡旧有内外园田，常与人分種，收谷岁数千斛。香曰：“《田令》‘商者不农’，《王制》‘仕者不耕’，伐冰食禄之人，不与百姓争利。”乃悉以赋人，课令耕種。时被水年肌，乃分奉禄及所得赏赐班赡贫者，於是豐富之家各出义谷，助官禀贷，荒民获全。後坐水潦事免，数月，卒於家。
原：所著贼、笺、奏、书、令、凡五篇。子琼，自有传。

# 刘毅
原：刘毅，北海敬王子也。初封平望侯，永元中，坐事夺爵。毅少有文辩称。元初元年，上《汉德论》并《宪论》十二篇。时，刘珍、邓耽、尹兑、马融共上书称其美，安帝嘉之，赐钱三万，拜议郎。

# 李尤
原：李尤字伯仁，广汉雒人也。少以文章显。和帝时，侍中贾逵薦尤有相如、杨雄之风，召诣东观，受诏作赋，拜兰臺令史。稍迁，安帝时为谏议大夫，受诏与谒者僕射刘珍等倶撰《汉记》。後帝废太子为济阴王，尤上书谏争。顺帝立，迁乐安相。年八十三卒。所著诗、赋、铭、诔、颂、《七叹》、《哀典》，凡二十八篇。
原：尤同郡李胜，亦有文才，为东观郎，著赋、诔、颂、论数十篇。

# 苏顺
原：苏顺字孝山，京兆霸陵人也。和安间以才学见称。好养生術，隐处求道。晩乃仕，拜郎中，卒於官。所著贼、论、诔、哀辞、杂文，凡十六篇。
原：时，三辅多士，扶风曹众伯师亦有才学，著诔、书、论四篇。又有曹朔，不知何许人，作《汉颂》四篇。

# 刘珍
原：刘珍字秋孙，一名宝，南阳蔡阳人也。少好学。永初中，为谒者僕射。邓太後诏，使与校书刘𫘦𬳿、马融及《五经》博士，校定东观《五观》、诸子传记、百家艺術，整齐脱误，是正文字。永寧元年，太後又诏珍与𫘦𬳿作建武已来名臣传，迁侍中、越骑校尉。延光四年，拜宗正。明年，转卫尉，卒官。著诔、颂、连珠凡七篇。又撰《释名》三十篇，以辩万物之称号雲。

# 葛龚
原：葛龚字元甫，梁国寧陵人也。和帝时，以善文记知名。性慷慨壮烈，勇力过人。安帝永初中，举孝廉，为太官丞，上便宜四事，拜荡阴令。辟太尉府，病不就。州举茂才，为临汾令。居二县，皆有称绩。著文、贼、碑、诔、书记，凡十二篇。

# 王逸
原：王逸字叔师，南郡宜城人也。元初中，举上计吏，为校书郎。顺帝时，为侍中。著《楚辞章句》行於世。其赋、诔、书、论及杂文，凡二十一篇。又作《汉诗》百二十三篇。
原：子延寿，字文考，有俊才。少遊鲁国，作《灵光殿赋》。後蔡邕亦造此赋，未成，及见延寿所为，甚奇之，遂辍翰而已。曾有异梦，意恶之，乃作《梦赋》以自厉。後溺水死，时年二十餘。

# 崔琦
原：崔琦字子玮，涿郡安平人，济北相瑗之宗也。少遊学京师，以文章博通称。初举考廉，为郎。河南尹梁冀闻其才，请与交。冀行多不轨，琦数引古今成败以戒之，冀不能受。乃作《外戚箴》。其辞曰。
原：赦赦外戚，华宠煌煌。昔在帝舜，德隆英、皇。周兴三母，有莘崇汤。宣王晏起，姜后脱簪。齐桓好乐，卫姬不音。皆辅主以礼，扶君以仁，达才进善，以义济身。
原：爰暨未葉，渐已颓亏。贯鱼不叙，九御差池。晋国之难，祸起於丽。惟家之索。牝鸡之晨。专权擅爱，显已蔽人。陵长间旧，圮剥至亲。并後匹嫡，淫女毙陈。
原：匪贤是上，番为司徒。荷爵负乘，采食名都。诗人是刺，德用无怃。暴辛惑妇，拒谏自孤。蝠蛇其心，纵毒不辜。诸父是杀，孕子是刳。天怒地忿，人谋鬼图。甲子昧爽，身首分离。初为天子，後为人螭。
原：非但耽色，母后尤然。不相率以礼，而竞奖以权。先笑後号，卒以辱残。国家泯绝，宗庙烧燔。末嬉丧夏，褒姒毙周，妲已亡殷，赵灵沙丘。戚姬人豕，吕宗以败。陈后作巫，卒死於外。霍欲鸩子，身乃罹废。
原：故曰：无谓我贵，天将尔摧；无恃常好，色有歇微；无怙常幸，爱有陵迟；无曰我能，天人尔违。患生不德，福有慎机。日不常中，月盈有亏。履道者固，杖势者危。微臣司戚，敢告在斯。
原：琦以言不从，失意，復作《白鹄赋》以为风。梁冀见之，呼琦问曰：“百官外内，各有司存，天下云云，岂独吾人之尤，君何激刺之过乎！”琦对曰：“昔管仲相齐，乐闻机谏之言；萧何佐汉，乃设书过之吏。今将军累世臺辅，任齐伊、公，而德政未闻，黎元涂炭。不能结纳贞良，以救祸败，反復欲钳塞士口，杜蔽主聽，将使玄黄改色，马鹿易形乎？”冀无以对，因遣琦归。
原：後除为临济长，不敢之职，解印绶去。冀遂令刺客阴求杀之。客见琦耕於陌上，怀书一卷，息辄偃而咏之。客哀其志，以实告琦，曰：“将军令吾要子，今见君贤者，情怀忍忍。可亟自逃，吾亦於此亡矣。”琦得脱走，冀後竟捕杀之。
原：所著赋、颂、铭、诔、箴、吊、论、《九咨》、《七言》，凡十五篇。

# 边韶
原：边韶字孝先，陈留浚仪人也。以文章知名，教授数百人。韶口辩，曾昼日假卧，弟子私嘲之曰：“边孝先，腹便便。懒读书，但欲眠。”韶潜闻之，应时对曰：“边为姓、考为字。腹便便，《五经》笥。但欲眠，思经事。寐与周公通梦，静与孔子同意。师而可嘲，出何典记？”嘲者大惭。韶之才捷皆此类也。
原：桓帝时，为临颍侯相，徴拜太中大夫，著作东观。再迁北地太守，入拜尚书令。後为陈相，卒官。著诗、颂、碑、铭、书、策，凡十五篇。
