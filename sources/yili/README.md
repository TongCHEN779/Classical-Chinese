# 仪礼

底本为[维基文库《仪礼》今文本目录](https://zh.wikisource.org/w/index.php?title=儀禮&oldid=2675555)所链接的十七篇正文。各篇的原文段落、源页地址和修订号见 `chapters.json`。底本快照只去掉网页排版空白。阅读正文经 ICU 繁转简，保存在 `chapters-simplified.json`，断句及缺文标记沿用底本。书内简介采用同一目录页独立简介的简体字形，见 `intro.json`；首页短介、逐句白话、题解和注释自撰。网页不显示维基来源注释。

各篇注译写入 `src/yili/pNN/01.txt`，使用 `¦` 对应原文句界。运行 `python3 -B tools/prepare_yili.py` 验证注译原文是简体阅读底本的连续前缀，生成尚未注译的原文尾段和 `progress.json`；该命令不会覆盖自撰译注。续编位置见各篇的 `next_paragraph`、`next_text`。书内目录显示各篇实际进度。

今本十七篇全部注译完成。本轮补齐《乡射礼》《大射》《聘礼》《既夕礼》和《有司》余段。全书共 453 个底本段落、5,613 组逐句悬停白话、440 条自撰分行注释。
