# 《聊斋志异》全本整理记录

## 底本与范围

- 底本：项目根目录 `聊斋志异（全四册）.pdf`，中华书局“中华经典名著全本全注全译丛书”，于天池注，孙通海、于天池等译，合计3391个PDF页面。
- 范围：依底本十二卷篇序整理全部小说，另收《聊斋自志》。不以选篇本或其他版本的篇数替代底本目录，不遗漏篇末“异史氏曰”等作者文字。
- 原文依扫描本校录，去除现代注译本的注码；按语意分段。段内白话按原文句子逐句对应，必要时用 `¦` 显式分隔；新增内容须检查 `split_pairs` 未退回整段，使悬停只显示当前句白话。白话、词语注释、题解自撰，不照录底本现代译文、题解。
- 扫描底本没有可提取的文字层。OCR只作草稿，须逐页对照扫描图校核后才写入 `src/`。未校核的识别结果不进入阅读页。

## 文件与检查

- 全站阅读页采用左侧固定、独立滚动目录；窄屏为左侧可展开目录按钮。新增内容沿用 `build.py` 的统一阅读布局，保留逐句悬停白话。

- 内容：`src/liaozhai/juan01/001.txt`起，三位数字文件名按底本篇序排列；同卷多文件由现有构建器顺序拼接。
- 格式：`# 篇名`、`题解：…`、`原：原文 || 白话`、`注：词语：解释`；注释紧跟其所属原译段，每个独立词条各写一行 `注：词语：解释`，不把多个词条合写成一条。生成器兼容旧稿合写格式，网页按钮按拆分后的实际词条计数。
- 生成：`python3 build.py`，输出 `liaozhai/index.html` 和已有内容的卷页。
- 每篇检查：首尾完整、篇序正确、原译逐段对应、生僻字与人名无误、作者论赞未遗漏、无底本现代译文混入原文。
- 接续时同步更新本记录、`progress.json`与根README。卷状态由 `progress.json` 维护，`build.py` 据此自动显示“整理中”与已整理篇数；完成一卷须核对全卷目录后再设为 `complete`。
