## 文件与检查

- 全站阅读页采用左侧固定、独立滚动目录；窄屏为左侧可展开目录按钮。新增内容沿用 `build.py` 的统一阅读布局，保留逐句悬停白话。

- 内容：`src/liaozhai/juan01/001.txt`起，三位数字文件名按底本篇序排列；同卷多文件由现有构建器顺序拼接。
- 格式：`# 篇名`、`题解：…`、`原：原文 || 白话`、`注：词语：解释`；注释紧跟其所属原译段，每个独立词条各写一行 `注：词语：解释`，不把多个词条合写成一条。生成器兼容旧稿合写格式，网页按钮按拆分后的实际词条计数。
- 生成：`python3 build.py`，输出 `liaozhai/index.html` 和已有内容的卷页。
- 每篇检查：首尾完整、篇序正确、原译逐段对应、生僻字与人名无误、作者论赞未遗漏、无底本现代译文混入原文。
