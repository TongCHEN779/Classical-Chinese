# 曾国藩家书

原文据[维基文库《曾國藩家書》](https://zh.wikisource.org/wiki/曾國藩家書)的简体转换页面。该站目前有治学、修身、齐家三章，70封家信，修身篇另附《五箴》等材料。目录所列“第四章”为无正文的红链，没有据此虚构第四章。本辑录本不是编年体十卷本或分类体十二卷本《曾文正公家书》的全集，原站未标明所据刊本，尚未据影印本校勘。

`wikisource/index.json` 和 `wikisource/1.json`—`3.json` 保留页面链接、修订版本、抓取时间、分块正文和 SHA-256。来源仅下载一次，不随构建重新联网。现有 `tools/fetch_wikisource.py` 的 `download`、`save` 函数用于抓取。

`annotations/1.json`—`3.json` 是整理者自撰白话、题解及注释，以缓存中的 block 序号定位。白话以 `¦` 与原文逐句对齐。三章70封家信及9项附文均已完成，共2360个句对、645条独立词注、79项题解。附文依原站标题层级分为《五箴》序及五篇箴文、《养身要言》《求阙斋课程》、附《忮》《求》诗一项，共9项，并非另有9封家信。逐项完成状态见 `progress.json`。

标点整理限两类：删除正文圆括号夹注里的句号，以免“甲名。”这类夹注被阅读器切断为独立句；不改正文用字、称谓、年代、语序或原站段界。治学篇第69块末的孤立开引号“‘”、修身篇第54块末的孤立间隔点“·”移入词注说明，不当作独立原文句；原始缓存保留两处原形。其余夹注以外的标点原样保留。原文标题按层级逐一保留，附文和其子目均可从章内目录跳转，故网页“篇”数不等于家信封数。

已知问题包括：

- 齐家篇“谕纪泽十二月十四日”正文实称“纪瑞侄”。
- 齐家篇“七月初四日”末署初六；修身篇“十一月十七日”末署十六。
- “濨扰”“游戈”“四桥”“兄敷”“积衣、积衣”等疑字及重复照录；逐处说明，未据语意直接改写原文。
- 原站有跨段断句（如“读其／手书”“敬身／之理”）；沿用段界，注出衔接。
- 不同家信中有关风水、扶乩、医药的态度存在变化，保留其各自语境。
- 治学篇“四月二十一日”信中“二公”上文未足二人，书目计数亦有疑，按底本保留，不推补脱文。
- 修身篇“三月三十一日”“八月初四日”等题名与末署日期另有出入；“谕纪鸿九月初一日”正文称纪泽。疑处均在相关词注说明。

补充参校（用于人物和引文词注，不替换本书底本）：

- [《清史稿》卷408·李续宾](https://zh.wikisource.org/zh-hans/清史稿/卷408)：核实迪庵指李续宾，原站作“迪安”。

- [《资治通鉴》四部丛刊本卷212](https://zh.wikisource.org/wiki/資治通鑑_(四部叢刊本)/卷第二百一十二)、[《陔余丛考》卷43](https://zh.wikisource.org/zh-hant/陔餘叢考/43)：核对“天下本无事”是陆象先语；原站“陆务观”照录而出校。
- [《曹寅谷先生全稿》馆藏书目线索](https://www.guoxuedashi.com/shumu/gj-3243213gr.html)：曹寅谷为曹之升，不误作曹文埴。
