# 曾国藩家书

原文据[维基文库《曾國藩家書》](https://zh.wikisource.org/wiki/曾國藩家書)的简体转换页面。该站目前有治学、修身、齐家三章，70封家信，修身篇另附《五箴》等材料。目录所列“第四章”为无正文的红链，没有据此虚构第四章。本辑录本不是编年体十卷本或分类体十二卷本《曾文正公家书》的全集，原站未标明所据刊本，尚未据影印本校勘。

`wikisource/index.json` 和 `wikisource/1.json`—`3.json` 保留页面链接、修订版本、抓取时间、分块正文和 SHA-256。来源仅下载一次，不随构建重新联网。现有 `tools/fetch_wikisource.py` 的 `download`、`save` 函数用于抓取。

`annotations/1.json`—`3.json` 是整理者自撰白话、题解及注释，以缓存中的 block 序号定位。白话以 `¦` 与原文逐句对齐。尚未注译的原文不冒充白话，篇首题解明确标明“待整理”。目前治学篇前2封、修身篇前2封、齐家篇全部11封完成，共15/70封、538个句对、185条独立词注。附文尚待注译，进度详见 `progress.json`。

只删除正文圆括号夹注里的句号，以免“甲名。”这类夹注被阅读器切断为独立句；不改正文用字、称谓、年代、语序或原站段界。夹注以外的标点原样保留。原文标题按层级逐一保留，附文和其子目均可从章内目录跳转，故网页“篇”数不等于家信封数。

已知问题包括：

- 齐家篇“谕纪泽十二月十四日”正文实称“纪瑞侄”。
- 齐家篇“七月初四日”末署初六；修身篇“十一月十七日”末署十六。
- “濨扰”“游戈”“四桥”“兄敷”“积衣、积衣”等疑字及重复照录；已注译部分逐处说明，未据语意直接改写原文。
- 原站有跨段断句（如“读其／手书”“敬身／之理”）；沿用段界，注出衔接。
- 不同家信中有关风水、扶乩、医药的态度存在变化，保留其各自语境。

复现整理、构建和核对：

```bash
python3 tools/prepare_zengguofan.py
python3 build.py
python3 tools/check_zengguofan.py
```
