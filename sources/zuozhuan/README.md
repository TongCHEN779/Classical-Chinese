## 整理办法

- 原文按“年·经”“年·传”分条，次序依原站；每页由若干年组成，页内按年连续。
- 成、襄、昭、定、哀五公的原站文本把每个小句都标成同一个句点（“．”或“。”），无法逐句对译，整理时**只改标点**为通行断句并给引语加引号，不增删改任何汉字；检查脚本去标点后与原站逐字比对。隐至宣公各页保留原站标点（部分长段逗号连写，白话按段对应）。
- 原站疑误字不改，注释中以 `注：校：…` 或“词语：校：…”标明通行本写法；私用区字符（原站无法显示的字形）统一标为〔缺字〕；原站末尾混入的导航文字（“回目录下一篇”）已删。
- 注释以人名（国别、身份）、地名、礼制官制、引《诗》《书》出处、书法术语、难词为主；人物、地望、年代存疑处写“一说”“待考”，不定论。同一条目内同一词语只注一次。

## 工具与验证

- `python3 tools/prepare_zuozhuan.py --split WORKDIR`：把缓存正文切成作业片段；`--merge WORKDIR`：把译注完成的片段按页合并到 `src/zuozhuan/` 并生成 `progress.json`（合并时清理导航行、替换私用区字符）。
- `python3 tools/check_zuozhuan.py`：核对页面原文（去标点）与缓存逐字一致、句数与白话对齐、条目题解、注释锚点及网页注释按钮数、悬停句对。
