## 原文校读

卷一各则原无篇名，网页编号及概括小标题为整理者所加；`000.txt` 为卷首自记，`001.txt` 至 `047.txt` 为按连续原文次序划分的47则。完整保留梦诗、题诗、偈语与作者议论；《经香阁》长篇汉宋学评论没有省略。长篇按叙事和论说结构分段，逐段来源和数量列于 `progress.json`。

据扫描核对“庋架”“抄胥”“絪缊”“搤”“疡医”“䰰”等易误字。“张公钺”系张钺的尊称，不将公字误作姓名；“神已痴矣”指女子神志失常，不是树神消失。保留诗中的“千生”“以东坡”以及正文“暗鬼”等底本用字，注释说明所取句意。盛序“荒诞悖妄者”后底本问号改逗号以连贯全句，并在该段注释标明；其他标点随底本，繁简异体在常用字范围内统一，生僻字保留。

辅助核字参考：[维基文库所录序与二诗](https://zh.wikisource.org/zh-hans/閱微草堂筆記/序)、[《说文解字注》䰰字条](https://ctext.org/wiki.pl?chapter=386737&if=gb&remap=gb)。网页正文以本地扫描为主，不以网上转录覆盖底本；《说文》只辅助识别生僻字。

## 显示格式

每个句末标点对应一条以 `¦` 分隔的白话，悬停或点按只显示当前句。诗句采用 `/` 分行，但仍依句末标点配译。每个注释词条单独一行，网页逐条显示并准确计算“注释（数量）”。原序、郑序、诗二首单列页面，书目首页按底本顺序放在卷一之前；所有阅读页使用共用的左侧固定、独立滚动目录。

做法同卷一：每则一个文件，概括小标题（`NN｜…`）与题解自撰，原文逐段取自缓存，较长的则在句末切开成不超过约650字的小段；经脚本核对与缓存逐字一致、句数与白话段数一致。卷首自记写作“卷首自记｜…”，卷二十四附录写作“附01｜…”至“附07｜…”。
源文本说明：纪昀自注（〈……〉或全角括号）内含句号，按句号切句会留下只剩标点或以逗号起首的碎句；这类碎句在网页构建时并回上一句，译文同步合并，写入文件的白话仍保留与切分一致的段数。疑似错字、缺字、引号不配对与史实、人名出入，均不改原文，写入注释（“校：”或“一说”）。人名生平与出处不能确考者，注中写“待考”或“一说”，部分凭记忆所注，未逐条核对文献。
