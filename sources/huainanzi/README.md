## 沿用格式

`src/huainanzi/juanNN/序号.txt` 按底本正文连续次序存放。`# 编号｜小标题` 及分节为本次整理所加，不冒称原书章目；每节含自撰题解、原文、白话及独立注释。原文的每个句末标点对应一条以 `¦` 分隔的白话，悬停时只显示当前句译文。

每个注释词条独占一行 `注：词语：解释`，网页分别显示并计算“注释（数量）”。目录采用共用的左侧固定、独立滚动样式。古代宇宙论、灾异观念按上下文解释，不改写成现代科学结论。

《聊斋志异》暂停于卷四第12篇《水灾》之后，恢复时从第13篇《诸城某甲》接续，原进度记录保留在 `sources/liaozhai/`。
