# 嘉祐集

据维基文库《嘉祐集》简体转换页修订 7904820，范围为卷一至卷十六及末尾补遗，不以四库本附录代替这份补遗。全文分块快照、修订号和摘要见 `wikisource/main.json`；`catalog.json` 保存十六卷、补遗和原站篇题标记的区块与字符位置。卷七的图表、卷八的子目、卷十四的谱图以及补遗的来源说明仍保存在底本中，后续整理时分别处理。目录与下载原文不等于完成注译。

卷一至卷六已完成全文注译，合计 28 篇、1,181 组逐句白话。卷七《洪范论叙》《洪范论上》已有草稿，接续《洪范论中〈并图〉》；未编完的卷不生成阅读页。详见 `progress.json`。全书简介、各篇题解、白话与释词为本库自撰；疑字不静默改动。

卷二《攻守》部分缺讹参看[单篇《攻守》](https://zh.wikisource.org/zh-hans/攻守)；卷三《孙武》人名参看[《史记·伍子胥列传》](https://ctext.org/text.pl?if=gb&node=7447&show=parallel)，卷四疑字参看[《嘉祐集》卷四](https://ctext.org/wiki.pl?chapter=999108&if=gb&remap=gb)，卷六《易论》“不沚”参看[识典古籍所录本](https://www.shidianguji.com/book/SBCK202/chapter/SBCK202_36)。参校文字只用于释义和说明异文。
