# 嘉祐集

据维基文库《嘉祐集》简体转换页修订 7904820，范围为卷一至卷十六及末尾补遗，不以四库本附录代替这份补遗。全文分块快照、修订号和摘要见 `wikisource/main.json`；`catalog.json` 保存十六卷、补遗和原站篇题标记的区块与字符位置。卷七的图表、卷八的子目、卷十四的谱图以及补遗的辑录说明均按底本保留。

卷一至卷十六及补遗已完成全文注译，合计 155 个底本篇目（组诗按底本合列）、4,612 组逐句白话、532 条分行注释。卷七至卷十共 1,147 组逐句白话、110 条分行注释。十七个阅读页均已生成。详见 `progress.json`。全书简介、各篇题解、白话与释词为本库自撰；疑字不静默改动。

卷二《攻守》部分缺讹参看[单篇《攻守》](https://zh.wikisource.org/zh-hans/攻守)；卷三《孙武》人名参看[《史记·伍子胥列传》](https://ctext.org/text.pl?if=gb&node=7447&show=parallel)，卷四疑字参看[《嘉祐集》卷四](https://ctext.org/wiki.pl?chapter=999108&if=gb&remap=gb)，卷六《易论》“不沚”参看[识典古籍所录本](https://www.shidianguji.com/book/SBCK202/chapter/SBCK202_36)。参校文字只用于释义和说明异文。

卷七两图按底本逐行保留，图框不计入逐句悬停，另作读图说明；卷八八个子目原位保留，正文提及而快照未载的图未补造。疑字参校[《嘉祐集》卷七](https://ctext.org/wiki.pl?chapter=67506&if=gb)、[《嘉祐集》卷八](https://ctext.org/wiki.pl?chapter=524858&if=gb&remap=gb)和[《辨奸论》单篇](https://zh.wikisource.org/wiki/辨姦論)。

卷十一至十四共 28 篇、897 组逐句白话、124 条分行注释。卷十四按底本保留谱图四行，底本同一行末尾的《苏氏族谱亭记》标题单独列出。卷十一“肙々”参看[四库本《嘉祐集》](https://ctext.org/wiki.pl?chapter=873076&if=gb&remap=gb)；卷十四谱例参看[识典古籍所录《嘉祐集》](https://www.shidianguji.com/book/SBCK202/chapter/SBCK202_96)，参校不替换正文。

卷十五、卷十六及补遗本批共 76 个底本篇目、1,387 组逐句白话、131 条分行注释。补遗将与标题连写的分类标记和夹注分开呈现，辑录出处照录。
