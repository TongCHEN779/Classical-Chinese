# 儒林外史

据[维基文库书名页固定修订](https://zh.wikisource.org/w/index.php?title=儒林外史&oldid=1645632)所链接的简体显示版，收第一至第五十六回。各回地址、修订号和正文快照见 `chapters.json`。第五十五回保留底本所列的两种结尾，用版本名区分；书内简介保留末回作者存疑的说明。首页短介自撰，书内简介见 `intro.json`。

不加译文和来源注释。诗词及正文引用的对联使用与《红楼梦》相同的居中样式，书信与公文仍按正文排版。运行 `python3 tools/prepare_rulinwaishi.py` 从快照生成阅读稿。
