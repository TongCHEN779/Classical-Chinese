# 尚书

以维基文库《尚书》目录修订 11123919 为篇序。虞书、夏书、商书、周书传世正文58篇及卷首《书序》均已整理，共2390个逐句悬浮单元。目录标“伪”的篇仍保留，题目标作“伪古文”；清华简与同页所附对读材料不并入传世正文。

首页为自撰短介，书内简介采用维基文库书名页的简体简介，附来源和授权。各篇题解、白话、词条注释为本库自撰。阅读稿去掉原站的注释区、校勘记和括号内的编辑夹注；缓存留存，以便核对取舍。古代篇序属于文献内容，仍按底本收录。疑字不擅改。

《尧典》兼收舜事，《皋陶谟》后半与《益稷》重叠，均按各篇底本分别保留。《汤诰》取页面传世伪古文部分；《金縢》取“传本”，并按同一维基文库修订重新核取旧缓存截断的首段。未据影印本逐字校勘。
