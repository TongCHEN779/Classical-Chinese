## 校录与沿用格式

采用 `src/yantielun/juanNN/序号.txt`，文件编号沿用全书第一至第六十篇的连续编号，卷二将从 `007.txt` 开始。每篇保留原题并附自撰题解；每个原文句末标点对应一条以 `¦` 分隔的白话，悬停时只显示当前句译文。每个注释词条单列一行，网页分别显示并准确计入“注释（数量）”。目录使用共用的左侧固定、独立滚动样式。

据扫描核对“絺纻”“驒騱騵马”“鼲鼦”“鮆窳”“鉏”“埏埴”等易误字，保留“先生”（注疑先王）、“闇饰”“大傲”等底本用字并作解释。朐邴按底本解释为朐地邴氏，不误拆为两姓；末篇“一夫”依上下文指独夫秦始皇，“众不能毕”的众通终。古代方位五行、夷夏称谓与双方价值判断均按历史语境注译，不作为现代事实或本网站立场。

疑字“鮆窳”另以[中国哲学书电子化计划《通有》原文](https://ctext.org/yan-tie-lun/tong-you/zh)辅助核形，正文取字仍以本地扫描件为准。
