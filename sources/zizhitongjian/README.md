## 纪年是怎样得出的

各卷卷首写有“起著雍摄提格，尽玄黓困敦，凡三十五年”一类的岁阳、岁阴纪年。本目录把它们换算成干支和公元年，并以“前403年戊寅为第一卷首年”逐卷接续，**首尾必须与第一卷首年和后周末年（959年己未）吻合**，每卷起年必须落在上一卷末年或其次年。核对中发现并处理了这些问题，均如实记录在 `catalog.json` 的字段里：

- **维基文库的识读错字**（如“强围”“暑维”“淹茂”“玄勣”等）：按60种合法岁阳岁阴搭配取最接近者，并以干支奇偶规则和前后卷接续校验；有此类错字的卷 `source_typo` 为真，共43卷。
- **卷首没有“起…尽…”句的卷**：卷56、57、151、174、184、185、186、187、189、197、218、219、228、229、230、274、286、287，起止年改据正文中的年份标目（如“永明十一年（癸酉，公元四九三年）”）取得，`derived_from_body` 为真。
- **与前后卷接续矛盾的卷首记载**：卷171、201，按前后卷接续改正（卷171“盡閼逢敦”应为“敦牂”、卷201“盡上章困敦”与卷202起年不合），`chain_corrected` 为真；其余各卷与原站卷首记载一致。
- 唐后期至五代的多卷以月份划分（如“起…十一月，尽…二月”），卷首所写“凡N年”与实际跨年数常差一年，这里以干支实算的跨年数（`span_years`）为准，原写的数记在 `stated_years`；相邻两卷可共有同一年。
