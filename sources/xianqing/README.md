## 校读与字形

逐页对照扫描原文，OCR只供定位，不能直接当作正文。补回尤侗序“所著《闲情偶寄》若干卷，用狡狯伎俩，作游戏神通”等漏行；校读“才之纤洪”“尝将誓词于首”“不为夭矣”“不堪为栋为梁”“有怪此书立法未备者”等字句。辨明屐履、嵚崎、诪张、狯獝、橐籥、赫蹄、刌、揝、燂、臜、颩等字，不以识别器的履履、髒等误识代替。

常用繁简字统一为简体，生僻字保留。曲牌用【】标出；正文引文的句号、问号、叹号也分别配译。“不理《梁王忏》”“解三醒”等依此底本用字保留，不径据通行曲本改字；“丧马”依底本保留并释为死马，不擅改作赙马。文中“上声”“阴阳”“入声”等按传统曲律解释，不等同现代普通话声调；蔡邕生平与剧本故事、关汉卿续《西厢》的旧说、赵武听孟姚的典故等，均在注释中区别作品说法与史实判断。
