# 肉蒲团：原文、题解与基础注释

- 底本：[维基文库《肉蒲團》](https://zh.wikisource.org/zh-hans/%E8%82%89%E8%92%B2%E5%9C%98)，收序与二十回正文，共288段、约9.4万字；目录页仅用于补出回目标题（第三回起各回页首原站未列标题）。
- 清初艳情小说，旧题李渔，作者存疑。含露骨成人内容，仅作为古代通俗文学文献收录。
- 全书题解为编者自撰；基础注释共911条，只释词语、典故、官制、风俗与讹字，不对性描写作解释或展开，性相关隐语一律不注。回末评语属底本文字，原样保留。
- 不配白话译文。原文据原站简体显示版，未据刊本影印校勘；原文中的疑误（如年号、诗句出处）只在注里指出，不改正文。
- `wikisource/` 保存首页、序、目录与二十回的原文快照（URL、修订号、SHA-256）。`python3 tools/prepare_roupotuan.py` 只生成原文骨架，检测到已有注释即拒绝覆盖；`python3 tools/check_roupotuan.py` 核对原文覆盖、注释锚点与网页注释按钮数。
