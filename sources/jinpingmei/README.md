# 金瓶梅（崇祯本）

据[维基文库崇祯本目录固定修订](https://zh.wikisource.org/w/index.php?title=金瓶梅_(崇禎本)&oldid=12723392)所链接的简体显示版，收《金瓶梅序》及第一至第一百回。不混用万历词话本。各页地址、修订号、原文段落及底本的分行、诗块标记保存于 `chapters.json`。提取时去掉页面导航、维基异文浮注和脚注，保留底本正文及生僻字。

首页短介自撰；书内简介采用该版本目录页的简体简介，见 `intro.json`。正文为白话小说，不另加现代白话。诗词曲联保留原有分行，按底本诗块、缩进及正文引语识别，复用《红楼梦》的居中样式。运行 `python3 tools/prepare_jinpingmei.py` 从快照生成阅读稿。
