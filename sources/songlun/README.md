## 校录与显示

`src/songlun/juan01/001.txt` 至 `015.txt` 按原书篇序存放；竖线前为原书编号，竖线后小标题为整理者所加。各篇保留连续正文分段，附自撰题解。已据扫描核对“頫首”“稾街之悬”“爚乱”“屝屦”等易误字；“封椿库”等底本用字予以保留并在注释说明。作者的正统观、夷夏观、历史评价按原文语境注译。

每个原文句末标点对应一条以 `¦` 分隔的白话，网页悬停只显示当前句译文。每个注释词条单独一行 `注：词语：解释`，网页分条显示，按钮“注释（数量）”与实际词条数一致。目录使用共用的左侧固定、可独立滚动样式。

遇到的源文本问题均不改原文，写入注释：维基文库原文夹有“一作……”“或无某字”等校语，照原样保留，个别处把句子切碎，白话按切开后的碎句对应；疑似错字、繁转简时的错字（如“与干相革”应为“乾”）、疑脱字及王夫之史实误记（如卷二称太宗修《册府元龟》，实为真宗朝）均在注中说明。
