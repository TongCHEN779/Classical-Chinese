## 整理规则

新增九项均直接取维基文库原文：《兰亭集序》《桃花源记》《赤壁赋》《出师表》《过秦论》《陈情表》《六国论》《醉翁亭记》《阿房宫赋》。不以站内旧稿代替这次的维基文库主文。各缓存的 `selected_blocks` 明确选择正文范围，避免抄入复排版本、书札、后人题跋、附诗或评语：

- 《兰亭集序》只取“竖排”下的通行正文一次，不重复收“横排”和摹本。
- 《桃花源记》只取“记”，不收同页《桃花源诗》。
- 《赤壁赋》指前赋，只取开头六段通行文；不把文征明、董其昌题跋、竖排手迹复录及末附苏轼书札混入。
- 《出师表》指前表；《六国论》为苏洵篇，不收同页后人评论。
- 《过秦论》上中下全文分三节，圆括号可选字词展开，异文另注。中篇一条较长复句保留原字原标点，按逗号处拆为四个逻辑单位，分别配白话。
- 《陈情表》维基文库主页面为《陈情事表》，保留“保卒馀年”等版本用字及结尾“谨拜表以闻”。
- 《醉翁亭记》维基文库前段作“让泉”、后段作“酿泉”，两处各照底本，不静默改字。

《谏太宗十思疏》取维基文库《諫太宗十思疏》全文三段，无异文夹注，原文缓存为 `wikisource/jianshisi.json`。

新增文字中的“一作”夹注逐条移到注释；《桃花源记》夹注中的未展开模板不视为正文；《赤壁赋》“更”后的声调尖括号夹注移出。上列选择和转换均可通过完整来源缓存、区块索引和整理后原文摘要复核。

源稿格式与其他书一致。每段以 `¦` 显式对齐每个句号、问号、叹号、分号结束的原文句子，保留自然段排版；构建设置 `strict_pairs`，句数不匹配或即将退回整段悬浮时立即报错。

去除网页布局换行，小形标点及ASCII标点统一为中文全角。《项脊轩志》正文的“一作逐”夹注移到注释；王守仁篇因网页排版断开的“仁人”“惟以理欲”“是其以吾心”等接合。其他疑字不默改，如《金石录后序》的“来十卷”“五百卷”、王守仁篇的“徐”“体”、赵秉忠篇的“吴天”“鹰鹤”“守圭”等，均在注中说明。

`entries.json` 记录顺序、作者、底本、修订版本、整理动作及整理后原文SHA-256。原文缓存保留原抓取结果，不把新写的白话混入来源。

检查：`python3 tools/check_classics.py`。校验33项齐全、《过秦论》三篇完整、题解注释与逐句译文存在、整理原文与各自底本完整对应、网页逐句对应源稿、目录全部站内可达，并检查折叠注释计数。
