# 洛阳伽蓝记

底本为[维基文库《洛阳伽蓝记》书名页](https://zh.wikisource.org/wiki/洛陽伽藍記)所列序和五卷的简体显示版。各页链接、修订号及原文快照见 `chapters.json`。原书旧夹注及阙字标记照录；维基站方脚注和异文浮层不导入。书内简介取目录页所载提要，见 `intro.json`；首页短介、白话、题解和折叠注释自撰。

运行 `python3 -B tools/prepare_luoyangjialanji.py` 核对译注稿，生成待注译原文尾段及 `progress.json`。注译稿存于各卷的 `01.txt`，不被准备脚本覆盖。阅读页沿用左侧目录与逐句悬停白话。

序及五卷已全部注译，共 201 个原文段落、1,992 组逐句白话、164 条分行注释。
