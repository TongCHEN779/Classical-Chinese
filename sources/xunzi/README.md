# 荀子

底本取维基文库《荀子》主目录的二十卷三十二篇，另收卷首杨倞《荀子序》。目录及书内简介据主页面修订 1641418，见 `wikisource/index.json`；主目录另链的《荀卿新书十二卷三十二篇》为异序目录，未重收。各篇简体电子底本与修订号分别存于 `wikisource/`。

首页短简介为本库自撰；书内简介保留主目录页所录的旧提要。阅读页只收入古书正文、自撰题解、逐句白话和自撰分行注释；不收入原站夹注和编辑校记，来源数据保留备查，不在页面显示。逐篇底本与注译统计见 `progress.json`。

二十卷三十二篇及卷首《荀子序》均已整理，合计 4,784 组逐句白话、406 条分行注释。

新增底本从维基文库简体页面提取正文段落；《性恶》至《赋》及《宥坐》至《尧问》去除尖括号中的夹注和独立的注文段。缓存保留修订号，校验值对应清理后的正文。

更新阅读稿后先运行 `python3 tools/prepare_xunzi.py` 核对底本和句对、刷新进度，再构建网页。构建后运行 `python3 tools/check_xunzi.py` 核对网页。
