# 战国策（士礼居丛书本）

仅据维基文库《戰國策 (士禮居叢書本)》，刘向编、黄丕烈札记。没有拼入其他《战国策》版本正文。底本自身收载的姚本、鲍本、正曰、补曰等校注是本版组成部分，分别照录，不一概归为黄丕烈自撰。

已完成东周28篇、西周17篇、秦策五卷64篇、齐策六卷59篇，以及目录所列六篇序、六篇附文。合计168篇正文与39个序附原文／标题单元、2990组显式逐句对应、4479条注释（含四条卷首原注）；不能称207篇正文。本轮齐策新增1110组完整逐句白话、1578条注释。每篇有自撰题解和释词；白话已全量复读扩写。东周、西周指两周分国，不是朝代东周与西周的历史分期。说辞中的谋略、夸张及史事异说，不能视作已经独立证实的历史。

## 来源与版本

- 目录：<https://zh.wikisource.org/wiki/戰國策_(士禮居叢書本)>，版本2459732。

- 西周：同版 /西周，版本2458657，见 `wikisource/xizhou.json` 和 `xizhou.html.snapshot`。

JSON保存简体显示的结构化文本；固定版本HTML保存原始页面，另记SHA-256。主文中的〈夹注〉移至独立注释行，原位偏移、完整夹注与段落换行保存在progress.json，可逆重构缓存段落。东周、西周、秦策一、齐策一卷首只有原注，分别标明附在首篇，不冒充首篇主文。正文疑误、重文、异名照录，白话和编者注说明未定处，不据别本擅改。未扫描、未OCR，尚未据影印本逐字校勘。
