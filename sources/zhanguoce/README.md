# 战国策（士礼居丛书本）

仅据维基文库《戰國策 (士禮居叢書本)》，刘向编、黄丕烈札记。没有拼入其他《战国策》版本正文。底本自身收载的姚本、鲍本、正曰、补曰等校注是本版组成部分，分别照录，不一概归为黄丕烈自撰。

已完成所据目录三十三卷497篇策文、六篇序、六篇附文及楚策四《越绝书》附引1项。原始分段稿537个来源核验单元、8078组对应；按用户要求合并六序、六附文后，网站35个阅读条目、510篇级目录项、8080组对应、11501条分行注释（含11条卷首原注）。两组句数之差为合并阅读时恢复到正文显示的原小标题“又”“题战国策”两项，不是补造正文。说辞中的夸张、年代错杂及疑字均依底本保留加注；未据影印本逐字校勘。

本轮仅新编宋卫15篇、中山10篇，357组逐句白话、377条分行注释；其他代理所编赵、魏、韩、燕252篇未改写，合并前后的逐页进度指纹已核对保存。
