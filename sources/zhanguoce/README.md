# 战国策（士礼居丛书本）

仅据维基文库《戰國策 (士禮居叢書本)》，刘向编、黄丕烈札记。没有拼入其他《战国策》版本正文。底本自身收载的姚本、鲍本、正曰、补曰等校注是本版组成部分，分别照录，不一概归为黄丕烈自撰。

本轮完成东周28篇、西周17篇，共45篇、315组显式逐句白话、687条注释（含两条卷首原注）。每篇有自撰题解和释词；白话已全量复读扩写。东周、西周指两周分国，不是朝代东周与西周的历史分期。说辞中的谋略、夸张及史事异说，不能视作已经独立证实的历史。

## 来源与版本

- 目录：<https://zh.wikisource.org/wiki/戰國策_(士禮居叢書本)>，版本2459732。
- 东周：同版 /東周，版本2458631，见 `wikisource/dongzhou.json` 和 `dongzhou.html.snapshot`。
- 西周：同版 /西周，版本2458657，见 `wikisource/xizhou.json` 和 `xizhou.html.snapshot`。

JSON保存简体显示的结构化文本；固定版本HTML保存原始页面，另记SHA-256。主文中的〈夹注〉移至独立注释行，原位偏移、完整夹注与段落换行保存在progress.json，可逆重构缓存段落。两卷卷首只有原注，分别标明附在首篇，不冒充首篇主文。正文疑误、重文、异名照录，白话和编者注说明未定处，不据别本擅改。未扫描、未OCR，尚未据影印本逐字校勘。
