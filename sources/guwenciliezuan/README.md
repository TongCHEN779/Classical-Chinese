# 古文辞类纂

- 来源：维基文库《古文辞类纂》目录（每篇一个单页）+ 中国哲学书电子化计划（ctext）维基版 res=625979，抓取脚本 `tools/fetch_guwen.py`、`tools/fetch_guwen_ctext.py`。
- 维基文库缺或无正文的篇目（红链、空页、消歧义页）取 ctext（字符识别本，未校对，偶有讹字、漏字，照录）：见 `ctext_fill.json`；`entries.json` 的 `source` 标明每篇来源，`missing` 列未能收录的篇目。
- 《论语辨》二篇：ctext 合为《论语辩二首》，按文意拆为上（前两段）、下（后两段），拆分处是推断。
- 未收：卷三十一《上凌屯田书》（维基文库无页面、ctext 无此篇）。
- 抓取中删去了维基页眉页脚漏进正文的面包屑（“< 苏轼 < 古文观止”“东坡志林/卷五”）。
