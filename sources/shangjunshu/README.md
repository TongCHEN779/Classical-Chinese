- 《刑约第十六》：总目录列“〈篇亡〉”，卷四正文页直接从《徕民》接《赏刑》。依据总目录插入题解说明，不添加“原：”假正文。

- 原文逐段照快照保存，不以推测悄改疑字。《靳令》的“六虱／十二者”计数、《境内》的爵级和残句、《修权》的“利者武也”等均在注中标示疑义，译文采用上下文可通的大意，不据疑句虚定制度。
