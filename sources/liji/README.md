# 礼记

全书依维基文库小戴本的目录修订 11117484，自《曲礼上》《曲礼下》至《丧服四制》共四十九篇。篇序与源页对应见 `catalog.json`，目录快照及各篇的电子底本、修订号与摘要保存在 `wikisource/`。简介照录维基文库作品页简体原文，附修订来源与授权链接。

已完成《曲礼上》《曲礼下》《檀弓上》《檀弓下》《王制》《月令》《曾子问》《文王世子》《礼运》《礼器》《郊特牲》《内则》《明堂位》《玉藻》《丧服小记》《大传》《少仪》《学记》《乐记》《杂记上》《杂记下》《丧大记》《祭法》《祭义》《祭统》《经解》《哀公问》《仲尼燕居》《孔子闲居》《坊记》《中庸》《表记》《缁衣》《奔丧》《问丧》《服问》《间传》《三年问》《深衣》《投壶》《儒行》《大学》《丧服四制》，照底本篇序刊入本地阅读页；其余在目录标为待整理。《大学》《中庸》依《礼记》原篇，不采用朱熹《章句》的改编与增补。《曲礼上》全篇306组逐句白话、99条分行注释，按主题分18节，底本两见的饭后撤器括文照录。《曲礼下》全篇178组逐句白话、54条分行注释。《檀弓上》全篇456组逐句白话、130条分行注释；保留底本异字与句读，包括“皆吊天子之棺四重”一处并列两事的断句。《檀弓下》保留三个正文区块；原站“他本”“斠勘”导航保留在底本缓存，不作为正文。《王制》照录田亩计数、赋役及各项制度。《月令》十二个月正文与季夏的中央土条均已整理，沿用底本十二个节标题，标题不重复计入悬停句数。《曾子问》保留周公“岂。不可。”等底本句读，在白话与注中交代连读；《文王世子》保留底本两见的“庶子治之”括文。《礼运》全篇175组逐句白话、28条分行注释；《礼器》全篇188组逐句白话、26条分行注释。《郊特牲》全篇268组逐句白话、34条分行注释，三个正文区块完整保留。《内则》全篇286组逐句白话、40条分行注释。《明堂位》全篇78组逐句白话、17条分行注释。《玉藻》至《祭统》十二篇共 2287 组逐句白话、287 条分行注释；自《曲礼上》至《经解》二十六篇已连续整理完毕。《哀公问》至《儒行》补齐十三篇，共 1141 组逐句白话、191 条分行注释；自《曲礼上》至《大学》四十二篇已连续整理完毕。下一篇《冠义》。其余接续状态以 `progress.json` 为准。

本批共完成五篇：《檀弓下》（419组白话、114条注）、《王制》（301组白话、83条注）、《月令》（382组白话、76条注）、《曾子问》（272组白话、63条注）、《文王世子》（177组白话、43条注）。
