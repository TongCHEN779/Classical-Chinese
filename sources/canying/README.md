全文原文已收录，并已完成**全部390段译注**：2410句白话、390条题解、3285条独立注释（含缺字提示）。原站632处夹注仍是底本文字，不计作自撰注释。

全部13页启用逐句悬停白话，触屏点按可读，每条词语注释独占一行；其余12页不显示空白或伪造的译文。第9—14段是题壁诗及其前后叙述，第15—16段是点金寓言与按语，第20—23段是同一组《望江南》辨诬材料，第26—28段是无米引词及上下片；保留原站段号而在题解中说明连续关系，避免误称为各自独立的篇目。

**译注已全部完成**（2026-10-27）；后续可据扫描件校勘疑字，各段疑误处在注中以“疑”“待考”标明。

`src/canying/part01`至`part13`按原站段号保存390个文本文件；`canying/index.html`为全书目录，`part01.html`至`part13.html`为阅读页。使用全站共享的固定、可独立滚动的左侧段落目录及前后页导航。

## 文本处理

- 保留原站简体显示的全部正文、引诗、署名、书名及夹注，不擅改疑似讹字、拆字或异常符号。
- 原站通过`inlinecomment`区分夹注；转写时在原位置补全角括号，使姓名、音注、引文出处与正文不再混成一句。632处夹注仍是底本文字，并非编者撰写。
- 原站含159个Unicode私用区字符，网页未提供可靠字形映射。阅读版逐个改标`〔缺字〕`，并在所在段后提示；原始字符、段号、位置及码位保存在`ctext.json`，可据扫描件续校。没有根据上下文猜字，也没有删除含缺字的句子。
- 原站其他疑似转录问题，如第三段“难火尸辛铸鼎”、第四段“世人宗”“呜佩”等，仍照录，尚不能作为可靠校定文本。不要据此认定历史人名或典故已经核定。

## 来源留存与复核

`ctext.html`保存本次下载的网页，`ctext.json`保存390段原始文本、恢复夹注括号后的文本、阅读版文本、夹注和缺字位置；`progress.json`登记完整原文收录范围、分页及译注状态。下载内容的SHA-256记录在两个JSON文件中；原站本次页面没有可核实的数值修订号，因此不编造版本号。

原文初始化脚本：`python3 tools/prepare_canying.py sources/canying/ctext.html`。该脚本只读取已经下载的文件，不联网，不提取网页导航或页脚，也不执行网页脚本。它要求段号严格为1至390，并检查首尾正文。**已有译注稿后会拒绝重新初始化，防止覆盖译文、题解、注释和进度。** 后续应直接续编`src/canying`中的文本，保留现有译注。

验证：`python3 tools/check_canying.py`核对缓存校验和、段号顺序、632处夹注、159个缺字标记、源文件全文及生成HTML正文逐段一致，并核验已译部分原译句数、193对悬停文字、题解注释状态、折叠按钮数字、目录锚点、来源名称及本地链接。现有8项单元测试及`git diff --check`通过。常规全站重建命令仍为`python3 build.py`；本次仅重建餐樱庑页面和书库首页，避免干扰其他书的并行整理。

## 第1—30段校读说明

原文逐段保持与采集版本相同，未因配译而悄改原字。将原有摘句目录改为编者概括标题；白话、题解和释义均自撰，不复制现代注译本。对“或云”“相传”“窃疑”等，保留传闻、推测的语气。长夹注亦逐句配译，明确区分《词苑丛谈》按语、况周颐按语与本次编者注释。

- 第3段“难火尸辛铸鼎”、第4段“世人宗”“呜佩”、第7段“ウ斋”、第20段“金九”“王金至”等为原站连写、异形或疑讹，原文照录并加辨读。没有依据普通上下文猜补字形。
- 第12段“沈白马”结合《新五代史》卷四十三辨为白马驿杀害朝官、投尸黄河的典故；“卖卢龙”结合《资治通鉴》卷六十五辨为反用田畴拒赏之典，避免误释为白马盟誓或唐末卢龙军阀事件。
- 第17段以《梅溪词》原序署名提供张功甫名镃的参读线索，但没有径改原站缺字。第18段“徽、钦南渡”与徽钦北迁、高宗南渡的基本史事不合，在注中指出，不把它照译成确定史实。
- 第4段夹注对瞿式耜、张同敞及其他将领遭际的概括，第5段“中国第一中西学堂”，均注明属于作者或引书的叙述，未把全部细节宣称为已考证史实。
